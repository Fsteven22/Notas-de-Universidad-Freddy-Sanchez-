# 🎯 Reglas de Inferencia para Cuantificadores

## 📋 Reglas Fundamentales

### ⚡ Instanciación Universal (UI)

> [!success]- 📤 De lo General a lo Particular
> 
> **Regla:**
> 
> ```
> ∀x P(x)
> ────────
>   P(c)
> ```
> 
> **Significado:** Si algo es verdadero para todos, entonces es verdadero para cualquier individuo específico.
> 
> **Condición:** c debe ser un elemento del dominio de cuantificación.
> 
> **Nombre alternativo:** Eliminación del cuantificador universal (∀E)

> [!example]- 🟢 Ejemplos de UI
> 
> **Ejemplo 1: Aplicación directa**
> 
> ```
> 1. ∀x (x ∈ ℝ → x² ≥ 0)    [Premisa]
> 2. 3 ∈ ℝ → 3² ≥ 0         [UI con x = 3]
> 3. 3 ∈ ℝ                  [Hecho]
> 4. 3² ≥ 0                 [Modus ponens: 2, 3]
> ```
> 
> **Ejemplo 2: Con variables**
> 
> ```
> 1. ∀x (Estudiante(x) → Inteligente(x))    [Premisa]
> 2. Estudiante(Juan) → Inteligente(Juan)   [UI con x = Juan]
> 3. Estudiante(Juan)                       [Premisa]
> 4. Inteligente(Juan)                      [Modus ponens: 2, 3]
> ```

### ⚡ Generalización Universal (UG)

> [!note]- 📥 De lo Particular a lo General
> 
> **Regla:**
> 
> ```
> P(x)  [donde x es arbitrario]
> ─────────────────────────────
>         ∀x P(x)
> ```
> 
> **Condición CRUCIAL:** x debe ser una variable completamente arbitraria, sin restricciones previas.
> 
> **Restricciones:**
> 
> - x no debe depender de suposiciones específicas
> - x no debe ser una constante introducida por EI
> - La derivación de P(x) debe ser válida para cualquier valor de x
> 
> **Nombre alternativo:** Introducción del cuantificador universal (∀I)

> [!example]- 🟡 Ejemplos de UG
> 
> **Ejemplo correcto:**
> 
> ```
> 1. Sea x un número par arbitrario           [Suposición]
> 2. ∃k (k ∈ ℤ ∧ x = 2k)                     [Definición de par]
> 3. x = 2k para algún k                       [EI]
> 4. x² = (2k)² = 4k² = 2(2k²)                [Álgebra]
> 5. Par(x²)                                   [Definición: 4]
> 6. Par(x) → Par(x²)                          [Implicación: 1-5]
> 7. ∀x (Par(x) → Par(x²))                     [UG: x es arbitrario]
> ```
> 
> **Error común:**
> 
> ```
> 8. Juan es estudiante                        [Premisa específica]
> 9. Juan es inteligente                       [Premisa específica]
> 10. ∀x (Estudiante(x) → Inteligente(x))       [ERROR: UG inválido]
> ```
> 
> ❌ No podemos generalizar desde un caso específico.

### ⚡ Instanciación Existencial (EI)

> [!warning]- 📤 Extrayendo Testigos Existenciales
> 
> **Regla:**
> 
> ```
> ∃x P(x)
> ────────
>  P(c)
> ```
> 
> **Condición CRÍTICA:** c debe ser una **nueva** constante que no aparece previamente en la demostración.
> 
> **Interpretación:** "Si existe algo con propiedad P, le damos un nombre (c) para poder razonar sobre él."
> 
> **Advertencia:** No podemos asumir nada más sobre c excepto que satisface P.
> 
> **Nombre alternativo:** Eliminación del cuantificador existencial (∃E)

> [!example]- 🟡 Ejemplos de EI
> 
> **Uso correcto:**
> 
> ```
> 1. ∃x (Primo(x) ∧ x > 100)                  [Premisa]
> 2. Primo(c) ∧ c > 100                       [EI con nueva c]
> 3. Primo(c)                                 [Simplificación: 2]
> 4. c > 100                                  [Simplificación: 2]
> 5. ∀x (Primo(x) → Entero(x))                [Premisa]
> 6. Primo(c) → Entero(c)                     [UI: 5]
> 7. Entero(c)                                [Modus ponens: 3, 6]
> ```
> 
> **Errores comunes:**
> 
> ```
> ❌ Error 1: Usar una constante existente
> 8. ∃x Primo(x)
> 9. Primo(2)         [ERROR: 2 ya es una constante específica]
> 
> ❌ Error 2: Reutilizar la constante
> 10. ∃x P(x)
> 11. P(c)             [EI: correcto]
> 12. ∃y Q(y)
> 13. Q(c)             [ERROR: c ya fue usada]
> ```

### ⚡ Generalización Existencial (EG)

> [!success]- 📥 Construyendo Existenciales
> 
> **Regla:**
> 
> ```
> P(c)
> ────────
> ∃x P(x)
> ```
> 
> **Significado:** Si P es verdadero para un individuo específico c, entonces existe alguien para quien P es verdadero.
> 
> **Flexibilidad:** Esta regla es la menos restrictiva - podemos aplicarla a cualquier constante.
> 
> **Nombre alternativo:** Introducción del cuantificador existencial (∃I)

> [!example]- 🟢 Ejemplos de EG
> 
> **Ejemplo directo:**
> 
> ```
> 1. Primo(17)                                [Hecho]
> 2. 17 > 10                                  [Hecho]
> 3. Primo(17) ∧ 17 > 10                      [Conjunción: 1, 2]
> 4. ∃x (Primo(x) ∧ x > 10)                   [EG: 3]
> ```
> 
> **En demostraciones:**
> 
> ```
> 1. ∀x (x ∈ ℕ → ∃y (y ∈ ℕ ∧ y = x + 1))     [Premisa]
> 2. 5 ∈ ℕ → ∃y (y ∈ ℕ ∧ y = 6)              [UI con x = 5]
> 3. 5 ∈ ℕ                                    [Hecho]
> 4. ∃y (y ∈ ℕ ∧ y = 6)                       [Modus ponens: 2, 3]
> ```

## 🔄 Reglas Derivadas

### 🔗 Combinaciones Comunes

> [!tip]- 🧩 Patrones de Uso Frecuente
> 
> **Patrón 1: UI + Modus Ponens**
> 
> ```
> 1. ∀x (P(x) → Q(x))
> 2. P(c)
> ──────────────────
> 3. P(c) → Q(c)         [UI: 1]
> 4. Q(c)                [Modus ponens: 2, 3]
> ```
> 
> **Patrón 2: EI + UI + EG**
> 
> ```
> 1. ∃x P(x)
> 2. ∀x (P(x) → Q(x))
> ──────────────────
> 3. P(c)                [EI: 1]
> 4. P(c) → Q(c)         [UI: 2]
> 5. Q(c)                [Modus ponens: 3, 4]
> 6. ∃x Q(x)             [EG: 5]
> ```
> 
> **Patrón 3: UG con implicación**
> 
> ```
> 1. Sea x arbitrario
> 2. Suponer P(x)
> 3. [derivación de Q(x)]
> 4. Q(x)
> 5. P(x) → Q(x)         [Implicación: 2-4]
> 6. ∀x (P(x) → Q(x))    [UG: 5]
> ```

## 🎯 Estrategias de Aplicación

### 📝 Guía para Demostraciones

> [!success]- 🗺️ Metodología Sistemática
> 
> **Para demostrar ∀x P(x):**
> 
> 1. Introducir x como variable arbitraria
> 2. Demostrar P(x) sin asumir nada específico sobre x
> 3. Aplicar UG
> 
> **Para demostrar ∃x P(x):**
> 
> 4. Encontrar o construir un testigo específico c
> 5. Demostrar P(c)
> 6. Aplicar EG
> 
> **Para usar ∀x P(x):**
> 
> 7. Identificar la instancia que necesitas
> 8. Aplicar UI con esa instancia
> 9. Continuar con el razonamiento
> 
> **Para usar ∃x P(x):**
> 
> 10. Aplicar EI con una nueva constante c
> 11. Razonar sobre c
> 12. No generalizar sobre c con UG

### ⚠️ Errores Comunes a Evitar

> [!warning]- 🚫 Trampas Frecuentes
> 
> **Error 1: Generalizar después de EI**
> 
> ```
> ❌ INCORRECTO:
> 1. ∃x P(x)
> 2. P(c)                [EI]
> 3. ∀x P(x)             [ERROR: c no es arbitraria]
> ```
> 
> **Error 2: UI con término inválido**
> 
> ```
> ❌ INCORRECTO:
> 4. ∀x (x > 0)          [Dominio: ℕ]
> 5. -5 > 0              [ERROR: -5 ∉ ℕ]
> ```
> 
> **Error 3: Reutilizar constantes en EI**
> 
> ```
> ❌ INCORRECTO:
> 6. ∃x P(x)
> 7. P(c)                [EI]
> 8. ∃y Q(y)
> 9. Q(c)                [ERROR: c ya usada]
> ```
> 
> **Error 4: UG con variable dependiente**
> 
> ```
> ❌ INCORRECTO:
> 10. P(x)                [Para algún x específico]
> 11. ∀x P(x)             [ERROR: x no es arbitraria]
> ```

## 💡 Ejemplos Completos

> [!example]- 🎓 Demostraciones Paso a Paso
> 
> **Teorema 1: Transitividad de implicaciones universales**
> 
> ```
> Premisas: ∀x (P(x) → Q(x)), ∀x (Q(x) → R(x))
> Demostrar: ∀x (P(x) → R(x))
> 
> 1. ∀x (P(x) → Q(x))                         [Premisa]
> 2. ∀x (Q(x) → R(x))                         [Premisa]
> 3. Sea x arbitrario                          [Para UG]
> 4. Suponer P(x)                              [Para →]
> 5. P(x) → Q(x)                               [UI: 1]
> 6. Q(x)                                      [Modus ponens: 4, 5]
> 7. Q(x) → R(x)                               [UI: 2]
> 8. R(x)                                      [Modus ponens: 6, 7]
> 9. P(x) → R(x)                               [Implicación: 4-8]
> 10. ∀x (P(x) → R(x))                         [UG: 9]
> ```
> 
> **Teorema 2: Existencial implica existencial**
> 
> ```
> Premisas: ∃x P(x), ∀x (P(x) → Q(x))
> Demostrar: ∃x Q(x)
> 
> 1. ∃x P(x)                                   [Premisa]
> 2. ∀x (P(x) → Q(x))                          [Premisa]
> 3. P(c)                                      [EI: 1, nueva c]
> 4. P(c) → Q(c)                               [UI: 2]
> 5. Q(c)                                      [Modus ponens: 3, 4]
> 6. ∃x Q(x)                                   [EG: 5]
> ```

## 🔗 Relación con Otras Reglas

> [!note]- 🌐 Integración con Lógica Proposicional
> 
> **Las reglas de cuantificadores se combinan con:**
> 
> - Modus ponens, modus tollens
> - Simplificación, conjunción
> - Adición, silogismo disyuntivo
> - Leyes de De Morgan (con cuantificadores)
> 
> **Patrón común:**
> 
> ```
> 1. ∀x (P(x) → Q(x))    [Universal]
> 2. P(a)                [Proposicional]
> 3. P(a) → Q(a)         [UI]
> 4. Q(a)                [Modus ponens - proposicional]
> ```

## 🎯 Ejercicios Prácticos

> [!example]- 💪 Práctica Guiada
> 
> **Nivel 1: Identificación de reglas**
> 
> Identifique qué regla de inferencia se aplica en cada paso:
> ```
> 1. ∀x (P(x) → Q(x))      [Premisa]
> 2. P(a)                  [Premisa]
> 3. P(a) → Q(a)           [¿Qué regla?]
> 4. Q(a)                  [¿Qué regla?]
> ```
> 
> **Nivel 2: Completar demostraciones**
> 
> Complete la siguiente demostración:
> ```
> Premisas: ∀x P(x), ∀x (P(x) → Q(x))
> Demostrar: ∀x Q(x)
> 
> 1. ∀x P(x)               [Premisa]
> 2. ∀x (P(x) → Q(x))      [Premisa]
> 3. Sea x arbitrario      [Para UG]
> 4. ___________           [Complete]
> 5. ___________           [Complete]
> 6. ___________           [Complete]
> 7. ∀x Q(x)               [UG]
> ```
> 
> **Nivel 3: Demostración completa**
> 
> Demuestre formalmente:
> ```
> Premisas: ∃x P(x), ∀x (P(x) → Q(x)), ∀x (Q(x) → R(x))
> Conclusión: ∃x R(x)
> ```
> 
> **Nivel 4: Detección de errores**
> 
> Encuentre el error en esta "demostración":
> ```
> 8. ∃x P(x)               [Premisa]
> 9. P(c)                  [EI]
> 10. ∀x P(x)               [UG: 2]  ← ¿Qué está mal aquí?
> ```

## 💡 Consejos de Estudio

> [!success]- 🎓 Estrategias de Dominio
> 
> **Para practicar efectivamente:**
> 1. Comience con demostraciones simples y aumente la complejidad gradualmente
> 2. Escriba cada paso explícitamente, justificando cada regla usada
> 3. Verifique sus demostraciones con un compañero o herramienta automática
> 4. Cree sus propios ejemplos antes de consultar soluciones
> 
> **Para evitar confusiones:**
> 1. Mantenga un registro de qué variables son arbitrarias vs. específicas
> 2. Liste explícitamente las constantes introducidas por EI
> 3. Marque claramente el alcance de cada suposición
> 4. Use nombres de variables distintos para diferentes cuantificadores
> 
> **Para preparar exámenes:**
> 1. Memorice las cuatro reglas básicas (UI, UG, EI, EG) con sus restricciones
> 2. Practique identificar qué regla aplicar en cada situación
> 3. Revise demostraciones modelo y entienda la estrategia general
> 4. Practique tanto construir demostraciones como encontrar errores
