# 🔢 Operaciones con Números Complejos

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Las operaciones con números complejos extienden las operaciones aritméticas de los números reales, incorporando la unidad imaginaria i. Estas operaciones se pueden realizar tanto en forma rectangular (a + bi) como en forma polar (r∠θ), siendo cada forma más conveniente según la operación que se realice.**
> 
> **Características clave:**
> 
> - **Forma rectangular:** Ideal para suma y resta
> - **Forma polar:** Ideal para multiplicación, división y potencias
> - **Propiedades algebraicas:** Se mantienen las propiedades de campo
> - **Interpretación geométrica:** Cada operación tiene significado visual
> - **Versatilidad:** Conversión entre formas según conveniencia

### 📖 Contexto Histórico

> [!note]- Desarrollo Histórico **Formalización de operaciones (1500-1800):**
> 
> - **Bombelli (1572):** Primeras reglas sistemáticas
>     - "Più di meno via più di meno fa meno"
>     - (Más de menos por más de menos hace menos)
>     - Reglas de multiplicación con imaginarios
> - **Euler (1748):** Notación moderna
>     - Introducción de i
>     - Sistematización de operaciones
>     - Identidades fundamentales
> 
> **Interpretación geométrica (1800-1900):**
> 
> - **Argand (1806) y Wessel (1797):** Representación visual
>     - Suma como adición de vectores
>     - Multiplicación como rotación y escalamiento
> - **Gauss (1831):** Formalización completa
>     - Operaciones en el plano complejo
>     - Teorema fundamental del álgebra
> 
> **Desarrollo analítico (1900-presente):**
> 
> - **Aplicaciones en física:** Impedancia, ondas, cuántica
> - **Ingeniería:** Análisis de circuitos AC
> - **Procesamiento digital:** FFT, filtros

## 📝 Operaciones en Forma Rectangular

> [!success]- Forma a + bi **Suma:**
> 
> ```
> Definición:
> (a + bi) + (c + di) = (a + c) + (b + d)i
> 
> Se suman por separado:
> • Partes reales: a + c
> • Partes imaginarias: b + d
> 
> Propiedades:
> 1. Conmutativa: z₁ + z₂ = z₂ + z₁
> 2. Asociativa: (z₁ + z₂) + z₃ = z₁ + (z₂ + z₃)
> 3. Elemento neutro: z + 0 = z
> 4. Elemento inverso: z + (-z) = 0
> 
> Interpretación geométrica:
> Suma vectorial (regla del paralelogramo)
> ```
> 
> **Ejemplos de suma:**
> 
> ```
> 1. (3 + 2i) + (1 + 4i) = (3 + 1) + (2 + 4)i = 4 + 6i
> 
> 2. (5 - 3i) + (-2 + 7i) = (5 - 2) + (-3 + 7)i = 3 + 4i
> 
> 3. (2 + i) + (2 - i) = 4 + 0i = 4 (suma de conjugados)
> 
> 4. i + 2i + 3i = 6i
> 
> 5. (1 + i) + (1 - i) + (-1 + i) + (-1 - i) = 0
> ```
> 
> **Resta:**
> 
> ```
> Definición:
> (a + bi) - (c + di) = (a - c) + (b - d)i
> 
> Equivalente a: z₁ + (-z₂)
> 
> Propiedades:
> • No conmutativa: z₁ - z₂ ≠ z₂ - z₁ (en general)
> • z - z = 0
> • z - 0 = z
> • 0 - z = -z
> 
> Interpretación geométrica:
> Vector de z₂ a z₁
> ```
> 
> **Ejemplos de resta:**
> 
> ```
> 6. (5 + 3i) - (2 + i) = (5 - 2) + (3 - 1)i = 3 + 2i
> 
> 7. (1 + 4i) - (3 - 2i) = (1 - 3) + (4 - (-2))i = -2 + 6i
> 
> 8. (2 + 3i) - (2 + 3i) = 0
> 
> 9. (a + bi) - (a - bi) = 2bi (diferencia de conjugados)
> ```
> 
> **Multiplicación:**
> 
> ```
> Definición:
> (a + bi)(c + di) = (ac - bd) + (ad + bc)i
> 
> Desarrollo:
> = ac + adi + bci + bdi²
> = ac + adi + bci - bd  (porque i² = -1)
> = (ac - bd) + (ad + bc)i
> 
> Regla mnemotécnica: FOIL
> First, Outer, Inner, Last
> 
> Propiedades:
> 10. Conmutativa: z₁z₂ = z₂z₁
> 11. Asociativa: (z₁z₂)z₃ = z₁(z₂z₃)
> 12. Distributiva: z₁(z₂ + z₃) = z₁z₂ + z₁z₃
> 13. Elemento neutro: z·1 = z
> 14. Elemento inverso (si z ≠ 0): z·z⁻¹ = 1
> ```
> 
> **Ejemplos de multiplicación:**
> 
> ```
> 15. (2 + 3i)(1 - 2i)
>    = 2·1 - 2·2i + 3i·1 - 3i·2i
>    = 2 - 4i + 3i - 6i²
>    = 2 - 4i + 3i + 6
>    = 8 - i
> 
> 16. (3 + i)(3 - i) = 9 - 3i + 3i - i² = 9 + 1 = 10
>    (producto de conjugados: z·z̄ = |z|²)
> 
> 17. i·i = i² = -1
> 
> 18. (1 + i)(1 + i) = 1 + i + i + i² = 1 + 2i - 1 = 2i
> 
> 19. (a + bi)(a - bi) = a² + b² (siempre real y positivo)
> ```
> 
> **División:**
> 
> ```
> Definición:
> (a + bi)/(c + di) = [(a + bi)(c - di)]/[(c + di)(c - di)]
>                   = [(ac + bd) + (bc - ad)i]/(c² + d²)
> 
> Método:
> 20. Multiplicar numerador y denominador por conjugado del denominador
> 21. Simplificar usando i² = -1
> 22. Dividir parte real e imaginaria entre c² + d²
> 
> Condición: c + di ≠ 0 (denominador no nulo)
> 
> Forma general:
> z₁/z₂ = (z₁·z̄₂)/(z₂·z̄₂) = (z₁·z̄₂)/|z₂|²
> ```
> 
> **Ejemplos de división:**
> 
> ```
> 23. (3 + 4i)/(1 - 2i)
>    = [(3 + 4i)(1 + 2i)]/[(1 - 2i)(1 + 2i)]
>    = [(3 - 8) + (6 + 4)i]/(1 + 4)
>    = (-5 + 10i)/5
>    = -1 + 2i
> 
> 24. 1/(1 + i)
>    = (1 - i)/[(1 + i)(1 - i)]
>    = (1 - i)/2
>    = 1/2 - (1/2)i
> 
> 25. i/(2 - i)
>    = [i(2 + i)]/[(2 - i)(2 + i)]
>    = (2i + i²)/(4 + 1)
>    = (2i - 1)/5
>    = -1/5 + (2/5)i
> 
> 26. (a + bi)/(c + di) donde c² + d² = 1:
>    = (a + bi)(c - di)
>    Simplificación directa
> ```

## 🎯 Operaciones en Forma Polar

> [!important]- Forma r∠θ o r(cos θ + i sen θ) **Conversión rectangular ↔ polar:**
> 
> ```
> De rectangular a polar:
> z = a + bi
> r = |z| = √(a² + b²)
> θ = arg(z) = arctan(b/a) [ajustado por cuadrante]
> z = r∠θ = r(cos θ + i sen θ)
> 
> De polar a rectangular:
> z = r∠θ
> a = r cos θ
> b = r sen θ
> z = a + bi
> ```
> 
> **Multiplicación en forma polar:**
> 
> ```
> Regla fundamental:
> z₁·z₂ = r₁∠θ₁ · r₂∠θ₂ = (r₁r₂)∠(θ₁ + θ₂)
> 
> En forma trigonométrica:
> [r₁(cos θ₁ + i sen θ₁)]·[r₂(cos θ₂ + i sen θ₂)]
> = r₁r₂[cos(θ₁ + θ₂) + i sen(θ₁ + θ₂)]
> 
> Interpretación geométrica:
> • Módulos se multiplican: r₁·r₂
> • Argumentos se suman: θ₁ + θ₂
> 
> Rotación de z₂ por ángulo θ₁ y escalamiento por r₁
> ```
> 
> **Ejemplos de multiplicación polar:**
> 
> ```
> 1. z₁ = 2∠30° y z₂ = 3∠45°
>    z₁z₂ = (2·3)∠(30° + 45°) = 6∠75°
> 
> 2. z₁ = 4∠π/3 y z₂ = 2∠π/6
>    z₁z₂ = 8∠(π/3 + π/6) = 8∠π/2
>    En forma rectangular: 8∠π/2 = 0 + 8i = 8i
> 
> 3. Multiplicar 1 + i por sí mismo:
>    1 + i = √2∠45°
>    (1 + i)² = (√2)²∠(45° + 45°) = 2∠90° = 2i
> 
> 4. i·z (multiplicar por i):
>    i = 1∠90°
>    i·z = |z|∠(arg(z) + 90°)
>    Rotación de 90° antihoraria
> ```
> 
> **División en forma polar:**
> 
> ```
> Regla fundamental:
> z₁/z₂ = r₁∠θ₁ / r₂∠θ₂ = (r₁/r₂)∠(θ₁ - θ₂)
> 
> En forma trigonométrica:
> [r₁(cos θ₁ + i sen θ₁)]/[r₂(cos θ₂ + i sen θ₂)]
> = (r₁/r₂)[cos(θ₁ - θ₂) + i sen(θ₁ - θ₂)]
> 
> Interpretación geométrica:
> • Módulos se dividen: r₁/r₂
> • Argumentos se restan: θ₁ - θ₂
> 
> Rotación inversa y escalamiento inverso
> ```
> 
> **Ejemplos de división polar:**
> 
> ```
> 1. z₁ = 6∠120° y z₂ = 2∠30°
>    z₁/z₂ = (6/2)∠(120° - 30°) = 3∠90° = 3i
> 
> 2. z₁ = 8∠π y z₂ = 4∠π/2
>    z₁/z₂ = 2∠(π - π/2) = 2∠π/2 = 2i
> 
> 3. 1/z donde z = 2∠60°
>    1/z = (1/2)∠(-60°) = 0.5∠(-60°)
> 
> 4. z/i donde z = r∠θ
>    z/i = r∠θ / 1∠90° = r∠(θ - 90°)
>    Rotación de -90° (horaria)
> ```
> 
> **Potencias en forma polar (Teorema de De Moivre):**
> 
> ```
> Regla fundamental:
> zⁿ = [r(cos θ + i sen θ)]ⁿ
>    = rⁿ(cos nθ + i sen nθ)
>    = rⁿ∠(nθ)
> 
> Interpretación:
> • Módulo a la n: rⁿ
> • Argumento multiplicado por n: nθ
> 
> Caso especial (círculo unitario, r = 1):
> (cos θ + i sen θ)ⁿ = cos(nθ) + i sen(nθ)
> 
> Esta es la fórmula de De Moivre
> ```
> 
> **Ejemplos de potencias:**
> 
> ```
> 1. (1 + i)⁸
>    1 + i = √2∠45°
>    (1 + i)⁸ = (√2)⁸∠(8·45°)
>             = 2⁴∠360°
>             = 16∠0°
>             = 16
> 
> 2. (2∠30°)⁵ = 2⁵∠(5·30°) = 32∠150°
> 
> 3. i¹⁰⁰
>    i = 1∠90°
>    i¹⁰⁰ = 1¹⁰⁰∠(100·90°) = 1∠9000°
>    9000° = 25·360° = 0° (módulo 360°)
>    i¹⁰⁰ = 1∠0° = 1
> 
> 4. (-1)^(1/2)
>    -1 = 1∠180°
>    (-1)^(1/2) = 1^(1/2)∠(180°/2) = 1∠90° = i
>    (otra raíz: 1∠(-90°) = -i)
> ```

## 📐 Forma Exponencial (Euler)

> [!note]- Notación e^(iθ) **Fórmula de Euler:**
> 
> ```
> e^(iθ) = cos θ + i sen θ
> 
> Forma exponencial de un complejo:
> z = re^(iθ)
> 
> Equivalencias:
> z = a + bi = r(cos θ + i sen θ) = re^(iθ)
> 
> Ventajas:
> • Notación más compacta
> • Operaciones más naturales
> • Conexión con cálculo
> ```
> 
> **Operaciones en forma exponencial:**
> 
> ```
> Multiplicación:
> z₁z₂ = r₁e^(iθ₁) · r₂e^(iθ₂) = r₁r₂e^(i(θ₁+θ₂))
> 
> División:
> z₁/z₂ = r₁e^(iθ₁) / r₂e^(iθ₂) = (r₁/r₂)e^(i(θ₁-θ₂))
> 
> Potencia:
> zⁿ = (re^(iθ))ⁿ = rⁿe^(inθ)
> 
> Conjugado:
> z̄ = re^(-iθ)
> 
> Inverso:
> 1/z = (1/r)e^(-iθ)
> ```
> 
> **Identidades importantes:**
> 
> ```
> 1. e^(iπ) = -1 (Identidad de Euler)
> 2. e^(iπ) + 1 = 0 (forma extendida)
> 3. e^(i2π) = 1
> 4. e^(iπ/2) = i
> 5. e^(-iπ/2) = -i
> 6. |e^(iθ)| = 1 para todo θ real
> 7. e^(z₁+z₂) = e^(z₁)·e^(z₂)
> 8. (e^z)ⁿ = e^(nz)
> ```
> 
> **Funciones trigonométricas:**
> 
> ```
> A partir de e^(iθ) = cos θ + i sen θ
> y e^(-iθ) = cos θ - i sen θ
> 
> Sumando:
> cos θ = (e^(iθ) + e^(-iθ))/2
> 
> Restando:
> sen θ = (e^(iθ) - e^(-iθ))/(2i)
> 
> Tangente:
> tan θ = -i(e^(iθ) - e^(-iθ))/(e^(iθ) + e^(-iθ))
> ```

## 🎨 Interpretación Geométrica de Operaciones

> [!tip]- Visualización en el Plano Complejo **Suma y resta:**
> 
> ```
> Suma z₁ + z₂:
> • Regla del paralelogramo
> • Equivalente a suma de vectores
> • Conmutativa visualmente
> 
>        z₁+z₂
>         ●────┐
>        ╱│    │
>       ╱ │    │z₂
>      ╱  │    │
>     O───●────┘
>       z₁
> 
> Resta z₁ - z₂:
> • Vector de z₂ a z₁
> • z₁ - z₂ = z₁ + (-z₂)
> • No conmutativa
> ```
> 
> **Multiplicación:**
> 
> ```
> z₁·z₂ con z₁ = r₁∠θ₁ y z₂ = r₂∠θ₂:
> 
> 1. Escalar z₁ por factor r₂
> 2. Rotar resultado por ángulo θ₂
> 
> Efecto combinado:
> • Módulo r₁r₂ (estiramiento/contracción)
> • Argumento θ₁ + θ₂ (rotación)
> 
> Multiplicar por i (90° antihorario):
>     y              y
>     ↑              ↑
>   z │            iz│ ┌─●
>     │ ╱            │ │ │
>     │╱             │ │ │
>     O───→ x        O─┘ │→ x
>                       z
> ```
> 
> **División:**
> 
> ```
> z₁/z₂:
> • Contrae por factor 1/r₂
> • Rota por ángulo -θ₂ (horario)
> 
> Inverso 1/z:
> • Inversión respecto al círculo unitario
> • Reflexión respecto al eje real
> • Módulo: 1/|z|
> • Argumento: -arg(z)
> ```
> 
> **Conjugación:**
> 
> ```
> z̄ (conjugado de z):
> • Reflexión respecto al eje real
> • Mantiene módulo: |z̄| = |z|
> • Invierte argumento: arg(z̄) = -arg(z)
> 
>     y
>     ↑
>   z ●
>     │
>     O───→ x
>     │
>   z̄ ●
> ```

## 🧩 Problemas Resueltos Detallados

> [!example]- Ejemplos Complejos **Problema 1: Operaciones mixtas**
> 
> ```
> Simplificar: [(2 + 3i)(1 - i)]/[(3 + i)(2 - i)]
> 
> SOLUCIÓN:
> 
> Numerador:
> (2 + 3i)(1 - i) = 2 - 2i + 3i - 3i²
>                 = 2 - 2i + 3i + 3
>                 = 5 + i
> 
> Denominador:
> (3 + i)(2 - i) = 6 - 3i + 2i - i²
>                = 6 - 3i + 2i + 1
>                = 7 - i
> 
> División:
> (5 + i)/(7 - i) = [(5 + i)(7 + i)]/[(7 - i)(7 + i)]
>                 = [35 + 5i + 7i + i²]/(49 + 1)
>                 = [35 + 12i - 1]/50
>                 = (34 + 12i)/50
>                 = 17/25 + (6/25)i
> ```
> 
> **Problema 2: Potencia usando De Moivre**
> 
> ```
> Calcular (1 - √3i)¹⁰
> 
> SOLUCIÓN:
> 
> Paso 1: Convertir a forma polar
> z = 1 - √3i
> r = √(1² + (-√3)²) = √(1 + 3) = 2
> 
> θ = arctan(-√3/1) = arctan(-√3)
> Cuadrante IV: θ = -π/3 o 5π/3
> 
> z = 2(cos(-π/3) + i sen(-π/3))
> z = 2e^(-iπ/3)
> 
> Paso 2: Aplicar De Moivre
> z¹⁰ = 2¹⁰(cos(-10π/3) + i sen(-10π/3))
>     = 1024(cos(-10π/3) + i sen(-10π/3))
> 
> Simplificar ángulo:
> -10π/3 = -10π/3 + 4π = -10π/3 + 12π/3 = 2π/3
> 
> z¹⁰ = 1024(cos(2π/3) + i sen(2π/3))
>     = 1024(-1/2 + i√3/2)
>     = -512 + 512√3i
> ```
> 
> **Problema 3: Ecuación con operaciones**
> 
> ```
> Resolver: z² + (1 - i)z - 6 - 3i = 0
> 
> SOLUCIÓN:
> 
> Usando fórmula cuadrática:
> z = [-(1-i) ± √((1-i)² + 4(6+3i))]/2
> 
> Paso 1: Calcular (1-i)²
> (1-i)² = 1 - 2i + i² = 1 - 2i - 1 = -2i
> 
> Paso 2: Discriminante
> Δ = -2i + 4(6 + 3i)
>   = -2i + 24 + 12i
>   = 24 + 10i
> 
> Paso 3: Calcular √(24 + 10i)
> Sea √(24 + 10i) = a + bi
> Entonces: (a + bi)² = 24 + 10i
> a² - b² = 24
> 2ab = 10 → ab = 5
> 
> De ab = 5: b = 5/a
> a² - 25/a² = 24
> a⁴ - 24a² - 25 = 0
> 
> Sea u = a²:
> u² - 24u - 25 = 0
> u = (24 ± √(576 + 100))/2 = (24 ± √676)/2 = (24 ± 26)/2
> u = 25 o u = -1 (descartado)
> 
> a² = 25 → a = 5 (tomamos positivo)
> b = 5/5 = 1
> 
> √(24 + 10i) = ±(5 + i)
> 
> Paso 4: Soluciones
> z = [-(1-i) ± (5+i)]/2
> 
> z₁ = [-(1-i) + (5+i)]/2 = [-1+i+5+i]/2 = (4+2i)/2 = 2+i
> z₂ = [-(1-i) - (5+i)]/2 = [-1+i-5-i]/2 = -6/2 = -3
> 
> Soluciones: z₁ = 2 + i, z₂ = -3
> ```
> 
> **Problema 4: Producto de múltiples complejos**
> 
> ```
> Calcular: (1+i)(1+i²)(1+i⁴)(1+i⁸)
> 
> SOLUCIÓN:
> 
> Simplificar potencias de i:
> i² = -1
> i⁴ = (i²)² = 1
> i⁸ = (i⁴)² = 1
> 
> Expresión:
> (1+i)(1+i²)(1+i⁴)(1+i⁸)
> = (1+i)(1-1)(1+1)(1+1)
> = (1+i)(0)(2)(2)
> = 0
> ```
> 
> **Problema 5: División compleja iterada**
> 
> ```
> Simplificar: 1/(1 + 1/(1 + 1/(1 + i)))
> 
> SOLUCIÓN:
> 
> Trabajar de adentro hacia afuera:
> 
> Paso 1: 1/(1 + i)
> 1/(1+i) = (1-i)/[(1+i)(1-i)] = (1-i)/2
> 
> Paso 2: 1 + (1-i)/2
> = 2/2 + (1-i)/2 = (2+1-i)/2 = (3-i)/2
> 
> Paso 3: 1/[(3-i)/2]
> = 2/(3-i) = 2(3+i)/[(3-i)(3+i)]
> = 2(3+i)/(9+1) = 2(3+i)/10 = (3+i)/5
> 
> Paso 4: 1 + (3+i)/5
> = 5/5 + (3+i)/5 = (5+3+i)/5 = (8+i)/5
> 
> Paso 5: 1/[(8+i)/5]
> = 5/(8+i) = 5(8-i)/[(8+i)(8-i)]
> = 5(8-i)/(64+1) = 5(8-i)/65
> = (40-5i)/65 = 8/13 - (1/13)i
> 
> Respuesta: 8/13 - (1/13)i
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes **1. "La multiplicación funciona igual que con reales"**
> 
> ```
> ✗ PARCIALMENTE FALSO
> 
> Correcto: Es conmutativa y asociativa
> Incorrecto: i² = -1, no i² = 1
> 
> Error común:
> (a + bi)(c + di) ≠ ac + bdi
> 
> Correcto:
> (a + bi)(c + di) = (ac - bd) + (ad + bc)i
> ```
> 
> **2. "En forma polar, se suman ángulos al multiplicar"**
> 
> ```
> ✓ CORRECTO para multiplicación
> ✗ FALSO para suma
> 
> Multiplicación: r₁∠θ₁ · r₂∠θ₂ = r₁r₂∠(θ₁+θ₂) ✓
> Suma: r₁∠θ₁ + r₂∠θ₂ ≠ (r₁+r₂)∠(θ₁+θ₂) ✗
> 
> Para suma, convertir a rectangular
> ```
> 
> **3. "√(z₁·z₂) = √z₁ · √z₂ siempre"**
> 
> ```
> ✗ FALSO en general para complejos
> 
> Raíces complejas son multivaluadas
> 
> Ejemplo:
> √((-1)·(-1)) = √1 = 1
> Pero √(-1)·√(-1) = i·i = -1
> 1 ≠ -1
>  ```
> **4. "(z₁ + z₂)² = z₁² + z₂²"**
>  ```
> ✗ FALSO
> 
> Correcto: (z₁ + z₂)² = z₁² + 2z₁z₂ + z₂²
> 
> Ejemplo:
> z₁ = 1, z₂ = i
> (1 + i)² = 1 + 2i + i² = 1 + 2i - 1 = 2i
> 
> Pero z₁² + z₂² = 1 + i² = 1 - 1 = 0
> 2i ≠ 0
> ```
> 
> **5. "El conjugado de un producto es el producto directo"**
> 
> ```
> ✗ MAL EXPRESADO
> 
> Correcto: z̄₁z̄₂ = z̄₁ · z̄₂ (producto de conjugados)
> No: z̄₁z₂ (esto no es una identidad general)
> 
> Propiedad correcta:
> (z₁z₂)̄ = z̄₁ · z̄₂
> El conjugado de un producto es el producto de los conjugados
> ```
> 
> **6. "|z₁ + z₂| = |z₁| + |z₂|"**
> 
> ```
> ✗ FALSO en general
> 
> Solo desigualdad: |z₁ + z₂| ≤ |z₁| + |z₂|
> 
> Igualdad solo cuando:
> arg(z₁) = arg(z₂) (misma dirección)
> 
> Ejemplo:
> z₁ = 1, z₂ = i
> |1 + i| = √2 ≈ 1.414
> |1| + |i| = 1 + 1 = 2
> √2 ≠ 2
> ```
> 
> **7. "arg(z₁z₂) = arg(z₁)·arg(z₂)"**
> 
> ```
> ✗ FALSO
> 
> Correcto: arg(z₁z₂) = arg(z₁) + arg(z₂) (mod 2π)
> 
> Los argumentos se SUMAN, no se multiplican
> ```
> 
> **8. "Dividir por un complejo es complicado"**
> 
> ```
> ✗ MITO
> 
> En forma polar es muy simple:
> z₁/z₂ = (r₁/r₂)∠(θ₁ - θ₂)
> 
> En forma rectangular:
> Multiplicar por conjugado del denominador
> ```

## 🎯 Propiedades Algebraicas Avanzadas

> [!important]- Identidades y Relaciones **Propiedades del conjugado:**
> 
> ```
> 1. z̄̄ = z (involución)
> 2. z + z̄ = 2Re(z)
> 3. z - z̄ = 2i·Im(z)
> 4. z·z̄ = |z|²
> 5. (z₁ + z₂)̄ = z̄₁ + z̄₂
> 6. (z₁z₂)̄ = z̄₁·z̄₂
> 7. (z₁/z₂)̄ = z̄₁/z̄₂
> 8. (z̄)ⁿ = (zⁿ)̄
> 9. z es real ⟺ z = z̄
> 10. z es imaginario puro ⟺ z = -z̄
> ```
> 
> **Propiedades del módulo:**
> 
> ```
> 1. |z| ≥ 0, |z| = 0 ⟺ z = 0
> 2. |z| = |z̄| = |-z|
> 3. |z₁z₂| = |z₁|·|z₂|
> 4. |z₁/z₂| = |z₁|/|z₂| (z₂ ≠ 0)
> 5. |zⁿ| = |z|ⁿ
> 6. |z₁ + z₂| ≤ |z₁| + |z₂| (desigualdad triangular)
> 7. ||z₁| - |z₂|| ≤ |z₁ - z₂|
> 8. |z₁ + z₂|² = |z₁|² + |z₂|² + 2Re(z₁z̄₂)
> 9. |Re(z)| ≤ |z|
> 10. |Im(z)| ≤ |z|
> ```
> 
> **Propiedades del argumento:**
> 
> ```
> 1. arg(z̄) = -arg(z)
> 2. arg(-z) = arg(z) + π (mod 2π)
> 3. arg(z₁z₂) = arg(z₁) + arg(z₂) (mod 2π)
> 4. arg(z₁/z₂) = arg(z₁) - arg(z₂) (mod 2π)
> 5. arg(zⁿ) = n·arg(z) (mod 2π)
> 6. arg(1/z) = -arg(z) (mod 2π)
> ```
> 
> **Identidades de exponenciales:**
> 
> ```
> 1. e^(z₁+z₂) = e^(z₁)·e^(z₂)
> 2. e^(z₁-z₂) = e^(z₁)/e^(z₂)
> 3. (e^z)ⁿ = e^(nz)
> 4. e^(z̄) = e^z̄
> 5. |e^(iθ)| = 1 para θ real
> 6. e^(2πi) = 1
> 7. e^(πi) = -1
> 8. e^(z+2πi) = e^z (periodicidad)
> ```
> 
> **Fórmulas trigonométricas complejas:**
> 
> ```
> Suma de ángulos (vía Euler):
> cos(α + β) = Re(e^(i(α+β))) = Re(e^(iα)·e^(iβ))
> sen(α + β) = Im(e^(i(α+β))) = Im(e^(iα)·e^(iβ))
> 
> Fórmulas de ángulo múltiple:
> cos(nθ) = Re((cos θ + i sen θ)ⁿ)
> sen(nθ) = Im((cos θ + i sen θ)ⁿ)
> 
> Linealización:
> cos^n θ y sen^n θ pueden expresarse como
> combinaciones lineales de cos(kθ) y sen(kθ)
> ```

## 📊 Comparación de Formas

> [!note]- Ventajas y Desventajas **Tabla comparativa:**
> 
> ```
> ┌─────────────┬──────────────┬──────────────┬──────────────┐
> │  Operación  │ Rectangular  │    Polar     │ Exponencial  │
> ├─────────────┼──────────────┼──────────────┼──────────────┤
> │    Suma     │   Muy fácil  │   Difícil    │   Difícil    │
> │             │   Directa    │ Convertir    │  Convertir   │
> ├─────────────┼──────────────┼──────────────┼──────────────┤
> │    Resta    │   Muy fácil  │   Difícil    │   Difícil    │
> │             │   Directa    │ Convertir    │  Convertir   │
> ├─────────────┼──────────────┼──────────────┼──────────────┤
> │Multiplicar  │    Media     │   Muy fácil  │   Muy fácil  │
> │             │  FOIL + i²   │  r₁r₂∠(θ+φ)  │  r₁r₂e^i(θ+φ)│
> ├─────────────┼──────────────┼──────────────┼──────────────┤
> │  Dividir    │    Media     │   Muy fácil  │   Muy fácil  │
> │             │  Conjugado   │  r₁/r₂∠(θ-φ) │ r₁/r₂e^i(θ-φ)│
> ├─────────────┼──────────────┼──────────────┼──────────────┤
> │  Potencia   │   Difícil    │   Muy fácil  │   Muy fácil  │
> │             │  Expandir    │   rⁿ∠(nθ)    │    rⁿe^inθ   │
> ├─────────────┼──────────────┼──────────────┼──────────────┤
> │   Raíces    │   Difícil    │    Fácil     │    Fácil     │
> │             │  Ecuación    │  Fórmula     │   Fórmula    │
> └─────────────┴──────────────┴──────────────┴──────────────┘
> 
> Regla general:
> • Suma/Resta → Forma rectangular
> • Multiplicación/División/Potencia → Forma polar/exponencial
> ```
> 
> **Estrategias de conversión:**
> 
> ```
> Problema con operaciones mixtas:
> 
> 1. Identificar operaciones dominantes
> 2. Si hay más suma/resta: trabajar en rectangular
> 3. Si hay más multiplicación/potencia: trabajar en polar
> 4. Convertir cuando sea necesario
> 
> Ejemplo:
> (2∠30° + 3∠60°)·(4∠45°)
> 
> Estrategia:
> a) Convertir los dos primeros a rectangular
> b) Sumarlos
> c) Convertir suma a polar
> d) Multiplicar en polar
> ```

## 🔬 Aplicaciones de las Operaciones

> [!tip]- Contextos Prácticos **1. Análisis de circuitos AC:**
> 
> ```
> Impedancias en serie: Z_total = Z₁ + Z₂
> (Suma en forma rectangular)
> 
> Impedancias en paralelo: 1/Z_total = 1/Z₁ + 1/Z₂
> (División y suma)
> 
> Corriente: I = V/Z
> (División, mejor en forma polar)
> 
> Potencia compleja: S = V·I*
> (Multiplicación por conjugado)
> ```
> 
> **2. Procesamiento de señales:**
> 
> ```
> Señal compleja: s(t) = Ae^(i(ωt+φ))
> 
> Multiplicación de señales:
> s₁(t)·s₂(t) en frecuencia → convolución
> 
> Filtrado: H(ω)·S(ω)
> (Multiplicación en dominio frecuencial)
> 
> FFT: aprovecha operaciones exponenciales
> ```
> 
> **3. Transformaciones geométricas:**
> 
> ```
> Rotación de θ: z' = ze^(iθ)
> Escalamiento de r: z' = rz
> Traslación: z' = z + z₀
> 
> Composición:
> z' = r(z + z₀)e^(iθ)
> (Multiplicación de transformaciones)
> ```
> 
> **4. Ecuaciones diferenciales:**
> 
> ```
> y'' + ω²y = 0
> 
> Solución compleja:
> y = Ae^(iωt) + Be^(-iωt)
> 
> Operaciones:
> • Derivación: multiplicación por iω
> • Integración: división por iω
> ```
> 
> **5. Mecánica cuántica:**
> 
> ```
> Función de onda: ψ(x,t) = Ae^(i(kx-ωt))
> 
> Superposición:
> ψ_total = ψ₁ + ψ₂ (suma de estados)
> 
> Probabilidad: |ψ|² = ψ·ψ*
> (Producto por conjugado)
> 
> Evolución temporal: ψ(t) = e^(-iHt/ℏ)ψ(0)
> (Multiplicación exponencial)
> ```

## 🧮 Técnicas de Cálculo Eficiente

> [!tip]- Estrategias Avanzadas **Simplificación de potencias de i:**
> 
> ```
> Método del residuo:
> iⁿ = i^(n mod 4)
> 
> Tabla:
> n mod 4 = 0 → iⁿ = 1
> n mod 4 = 1 → iⁿ = i
> n mod 4 = 2 → iⁿ = -1
> n mod 4 = 3 → iⁿ = -i
> 
> Ejemplo rápido:
> i²⁰²⁵ = i^(2025 mod 4) = i¹ = i
> Porque 2025 = 506·4 + 1
> ```
> 
> **Productos de conjugados:**
> 
> ```
> Identidad fundamental:
> (a + bi)(a - bi) = a² + b²
> 
> Uso en división:
> z₁/z₂ = (z₁·z̄₂)/(z₂·z̄₂) = (z₁·z̄₂)/|z₂|²
> 
> El denominador se vuelve real
> ```
> 
> **Factorización compleja:**
> 
> ```
> a² + b² = (a + bi)(a - bi)
> 
> Ejemplo:
> x² + 4 = (x + 2i)(x - 2i)
> x² + 1 = (x + i)(x - i)
> 
> Suma de cuadrados → producto de conjugados
> ```
> 
> **Racionalización compleja:**
> 
> ```
> Para expresión: 1/(a + bi + c + di)
> 
> Agrupar: 1/[(a+c) + (b+d)i]
> Multiplicar por conjugado: [(a+c) - (b+d)i]
> Denominador: (a+c)² + (b+d)²
> ```
> 
> **Cálculo de módulo sin raíz:**
> 
> ```
> En lugar de |z| = √(a² + b²):
> 
> |z|² = z·z̄ = (a + bi)(a - bi) = a² + b²
> 
> Útil cuando solo necesitas comparar módulos
> o cuando aparece al cuadrado
> ```
> 
> **Identidades de ángulos especiales:**
> 
> ```
> Memorizar formas polares comunes:
> 
> 1 = 1∠0°
> i = 1∠90°
> -1 = 1∠180°
> -i = 1∠270° = 1∠(-90°)
> 
> 1+i = √2∠45°
> 1-i = √2∠(-45°)
> √3+i = 2∠30°
> 1+√3i = 2∠60°
> 
> Facilita multiplicaciones rápidas
> ```

## 🎯 Problemas Desafiantes

> [!example]- Nivel Avanzado **Problema 1: Demostración algebraica**
> 
> ```
> Demostrar: Si |z| = 1, entonces |1 + z|² + |1 - z|² = 4
> 
> DEMOSTRACIÓN:
> 
> |1 + z|² = (1 + z)(1 + z)̄
>          = (1 + z)(1 + z̄)
>          = 1 + z + z̄ + zz̄
>          = 1 + z + z̄ + |z|²
>          = 1 + z + z̄ + 1  (porque |z| = 1)
>          = 2 + (z + z̄)
>          = 2 + 2Re(z)
> 
> Similarmente:
> |1 - z|² = (1 - z)(1 - z̄)
>          = 1 - z - z̄ + zz̄
>          = 1 - z - z̄ + 1
>          = 2 - (z + z̄)
>          = 2 - 2Re(z)
> 
> Sumando:
> |1 + z|² + |1 - z|² = [2 + 2Re(z)] + [2 - 2Re(z)]
>                     = 4  ∎
> ```
> 
> **Problema 2: Ecuación compleja no lineal**
> 
> ```
> Resolver: z³ = z̄
> 
> SOLUCIÓN:
> 
> Sea z = re^(iθ) donde r ≥ 0
> Entonces z̄ = re^(-iθ)
> 
> Ecuación:
> r³e^(i3θ) = re^(-iθ)
> 
> Igualando módulos:
> r³ = r
> r³ - r = 0
> r(r² - 1) = 0
> r = 0 o r = 1 (r = -1 descartado, r ≥ 0)
> 
> Caso r = 0:
> z = 0 ✓ (verificar: 0³ = 0̄ = 0)
> 
> Caso r = 1:
> e^(i3θ) = e^(-iθ)
> 3θ = -θ + 2πk, k ∈ ℤ
> 4θ = 2πk
> θ = πk/2
> 
> Para k = 0, 1, 2, 3:
> θ = 0: z = 1
> θ = π/2: z = i
> θ = π: z = -1
> θ = 3π/2: z = -i
> 
> Verificación para z = i:
> i³ = -i = ī ✓
> 
> Soluciones: z ∈ {0, 1, i, -1, -i}
> ```
> 
> **Problema 3: Operación iterada**
> 
> ```
> Sea z₀ = 1 + i. Definir zₙ₊₁ = zₙ².
> Encontrar z₅.
> 
> SOLUCIÓN:
> 
> Método 1 (Polar - más eficiente):
> z₀ = 1 + i = √2∠45°
> 
> z₁ = z₀² = (√2)²∠(2·45°) = 2∠90° = 2i
> z₂ = z₁² = 2²∠(2·90°) = 4∠180° = -4
> z₃ = z₂² = 4²∠(2·180°) = 16∠360° = 16∠0° = 16
> z₄ = z₃² = 16² = 256
> z₅ = z₄² = 256² = 65536
> 
> Patrón general:
> zₙ = (√2)^(2ⁿ) ∠(45°·2ⁿ)
> 
> z₅ = (√2)³² ∠(45°·32)
>    = 2¹⁶ ∠1440°
>    = 65536 ∠0°  (1440° = 4·360°)
>    = 65536
> 
> Método 2 (Verificación rectangular):
> z₀ = 1 + i
> z₁ = (1+i)² = 2i
> z₂ = (2i)² = -4
> z₃ = (-4)² = 16
> z₄ = 16² = 256
> z₅ = 65536 ✓
> ```
> 
> **Problema 4: Optimización**
> 
> ```
> Dados z₁ = 3 + 4i y z₂ = 1 + 2i,
> encontrar z tal que |z - z₁| + |z - z₂| sea mínimo.
> 
> SOLUCIÓN:
> 
> Interpretación geométrica:
> Minimizar suma de distancias de z a z₁ y z₂
> 
> Por desigualdad triangular:
> |z - z₁| + |z - z₂| ≥ |z₁ - z₂|
> 
> La igualdad ocurre cuando z está en el
> segmento de z₁ a z₂
> 
> Cualquier z en el segmento z₁z₂ minimiza la expresión.
> 
> Parametrización del segmento:
> z(t) = (1-t)z₁ + tz₂, 0 ≤ t ≤ 1
> z(t) = (1-t)(3+4i) + t(1+2i)
>      = (3-3t) + (4-4t)i + t + 2ti
>      = (3-2t) + (4-2t)i
> 
> Valor mínimo:
> |z₁ - z₂| = |(3+4i) - (1+2i)|
>           = |2 + 2i|
>           = 2√2
> 
> Respuesta: z ∈ segmento [z₁, z₂]
> Mínimo = 2√2
> ```
> 
> **Problema 5: Identidad trigonométrica**
> 
> ```
> Usar números complejos para demostrar:
> cos 3θ = 4cos³θ - 3cos θ
> 
> DEMOSTRACIÓN:
> 
> Por De Moivre:
> (cos θ + i sen θ)³ = cos 3θ + i sen 3θ
> 
> Expandir lado izquierdo:
> (cos θ + i sen θ)³
> = cos³θ + 3cos²θ(i sen θ) + 3cos θ(i sen θ)² + (i sen θ)³
> = cos³θ + 3icos²θ sen θ - 3cos θ sen²θ - isen³θ
> = (cos³θ - 3cos θ sen²θ) + i(3cos²θ sen θ - sen³θ)
> 
> Igualando partes reales:
> cos 3θ = cos³θ - 3cos θ sen²θ
>        = cos³θ - 3cos θ(1 - cos²θ)
>        = cos³θ - 3cos θ + 3cos³θ
>        = 4cos³θ - 3cos θ  ∎
> ```
