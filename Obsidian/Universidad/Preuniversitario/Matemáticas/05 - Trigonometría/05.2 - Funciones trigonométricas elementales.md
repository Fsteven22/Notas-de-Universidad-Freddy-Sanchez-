# 📐 Funciones Trigonométricas Elementales

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Las funciones trigonométricas relacionan los ángulos de un triángulo con las razones entre sus lados. Originalmente geométricas, se extienden a funciones de ángulos arbitrarios mediante el círculo unitario.**
> 
> **Elementos clave:**
> 
> - **Seis funciones:** seno, coseno, tangente, cotangente, secante, cosecante
> - **Origen:** Razones en triángulos rectángulos
> - **Extensión:** Círculo unitario para todos los ángulos
> - **Periodicidad:** Funciones que se repiten regularmente
> - **Ubicuidad:** Ondas, oscilaciones, movimiento circular

## 📐 Definiciones en Triángulo Rectángulo

> [!success]- Definición Geométrica Básica
> 
> **Triángulo rectángulo:**
> 
> ```
>         C (ángulo recto)
>         |\
>         | \
>      b  |  \ a (hipotenusa)
>         |   \
>         |____\
>         A  c  B
>         
> Respecto al ángulo θ en A:
> - Lado opuesto: a (BC)
> - Lado adyacente: c (AC)
> - Hipotenusa: b (AB)
> ```
> 
> **Las seis funciones trigonométricas:**
> 
> ```
> SENO:        sin(θ) = opuesto/hipotenusa = a/b
> 
> COSENO:      cos(θ) = adyacente/hipotenusa = c/b
> 
> TANGENTE:    tan(θ) = opuesto/adyacente = a/c
> 
> COSECANTE:   csc(θ) = hipotenusa/opuesto = b/a = 1/sin(θ)
> 
> SECANTE:     sec(θ) = hipotenusa/adyacente = b/c = 1/cos(θ)
> 
> COTANGENTE:  cot(θ) = adyacente/opuesto = c/a = 1/tan(θ)
> ```
> 
> **Mnemónico SOHCAHTOA:**
> 
> ```
> SOH: Seno = Opuesto / Hipotenusa
> CAH: Coseno = Adyacente / Hipotenusa  
> TOA: Tangente = Opuesto / Adyacente
> ```
> 
> **Restricción inicial:**
> 
> ```
> En triángulo rectángulo: 0° < θ < 90° (0 < θ < π/2)
> 
> Todas las funciones son positivas en este rango
> ```

## ⭕ Definiciones en el Círculo Unitario

> [!important]- Extensión a Todos los Ángulos
> 
> **Círculo unitario:**
> 
> ```
> Círculo de radio r = 1, centrado en el origen
> Ecuación: x² + y² = 1
> 
>         y
>         ↑
>         |  P(x,y)
>         | /|
>         |/ |θ
>    -----O--+---→ x
>         
> Ángulo θ en posición estándar
> Punto P(x, y) en el círculo
> ```
> 
> **Definiciones para cualquier ángulo:**
> 
> ```
> Si P(x, y) es el punto en el círculo unitario
> correspondiente al ángulo θ, entonces:
> 
> sin(θ) = y    (coordenada y)
> cos(θ) = x    (coordenada x)
> tan(θ) = y/x  (si x ≠ 0)
> 
> csc(θ) = 1/y  (si y ≠ 0)
> sec(θ) = 1/x  (si x ≠ 0)
> cot(θ) = x/y  (si y ≠ 0)
> ```
> 
> **Para círculo de radio r:**
> 
> ```
> Punto P(x, y) a distancia r del origen:
> 
> sin(θ) = y/r
> cos(θ) = x/r
> tan(θ) = y/x
> 
> Esta definición generaliza la del triángulo rectángulo
> ```
> 
> **Ventajas de esta definición:**
> 
> - Válida para cualquier ángulo (incluso > 90°)
> - Permite ángulos negativos
> - Define periodicidad naturalmente
> - Conecta geometría con análisis

## 📊 Dominios y Rangos

> [!tip]- Características de Cada Función
> 
> **Seno: f(θ) = sin(θ)**
> 
> ```
> Dominio: ℝ (todos los ángulos)
> Rango: [-1, 1]
> Periodo: 2π (360°)
> Ceros: θ = nπ, n ∈ ℤ
> Máximos: θ = π/2 + 2nπ → sin(θ) = 1
> Mínimos: θ = 3π/2 + 2nπ → sin(θ) = -1
> ```
> 
> **Coseno: f(θ) = cos(θ)**
> 
> ```
> Dominio: ℝ
> Rango: [-1, 1]
> Periodo: 2π (360°)
> Ceros: θ = π/2 + nπ, n ∈ ℤ
> Máximos: θ = 2nπ → cos(θ) = 1
> Mínimos: θ = π + 2nπ → cos(θ) = -1
> ```
> 
> **Tangente: f(θ) = tan(θ)**
> 
> ```
> Dominio: ℝ \ {π/2 + nπ}, n ∈ ℤ
>         (todos excepto donde cos(θ) = 0)
> Rango: ℝ (todos los reales)
> Periodo: π (180°)
> Ceros: θ = nπ, n ∈ ℤ
> Asíntotas verticales: θ = π/2 + nπ
> ```
> 
> **Cotangente: f(θ) = cot(θ)**
> 
> ```
> Dominio: ℝ \ {nπ}, n ∈ ℤ
>         (todos excepto donde sin(θ) = 0)
> Rango: ℝ
> Periodo: π (180°)
> Ceros: θ = π/2 + nπ, n ∈ ℤ
> Asíntotas verticales: θ = nπ
> ```
> 
> **Secante: f(θ) = sec(θ)**
> 
> ```
> Dominio: ℝ \ {π/2 + nπ}, n ∈ ℤ
> Rango: (-∞, -1] ∪ [1, +∞)
> Periodo: 2π (360°)
> No tiene ceros (nunca es 0)
> Asíntotas verticales: θ = π/2 + nπ
> ```
> 
> **Cosecante: f(θ) = csc(θ)**
> 
> ```
> Dominio: ℝ \ {nπ}, n ∈ ℤ
> Rango: (-∞, -1] ∪ [1, +∞)
> Periodo: 2π (360°)
> No tiene ceros
> Asíntotas verticales: θ = nπ
> ```

## 🔄 Identidades Fundamentales

> [!important]- Relaciones Básicas entre Funciones
> 
> **Identidades recíprocas:**
> 
> ```
> csc(θ) = 1/sin(θ)     sin(θ) = 1/csc(θ)
> sec(θ) = 1/cos(θ)     cos(θ) = 1/sec(θ)
> cot(θ) = 1/tan(θ)     tan(θ) = 1/cot(θ)
> ```
> 
> **Identidades de cociente:**
> 
> ```
> tan(θ) = sin(θ)/cos(θ)
> cot(θ) = cos(θ)/sin(θ)
> ```
> 
> **Identidad pitagórica (fundamental):**
> 
> ```
> sin²(θ) + cos²(θ) = 1
> 
> Variantes:
> 1 + tan²(θ) = sec²(θ)
> 1 + cot²(θ) = csc²(θ)
> ```
> 
> **Identidades de paridad:**
> 
> ```
> sin(-θ) = -sin(θ)    (función impar)
> cos(-θ) = cos(θ)     (función par)
> tan(-θ) = -tan(θ)    (función impar)
> 
> csc(-θ) = -csc(θ)    (función impar)
> sec(-θ) = sec(θ)     (función par)
> cot(-θ) = -cot(θ)    (función impar)
> ```
> 
> **Identidades de cofunction:**
> 
> ```
> sin(π/2 - θ) = cos(θ)
> cos(π/2 - θ) = sin(θ)
> tan(π/2 - θ) = cot(θ)
> 
> csc(π/2 - θ) = sec(θ)
> sec(π/2 - θ) = csc(θ)
> cot(π/2 - θ) = tan(θ)
> ```

## 🌊 Periodicidad

> [!success]- Funciones Periódicas
> 
> **Definición de periodicidad:**
> 
> ```
> Una función f es periódica con periodo p si:
> f(θ + p) = f(θ) para todo θ
> 
> El periodo es el menor valor positivo p que cumple esto
> ```
> 
> **Periodos de las funciones:**
> 
> ```
> sin(θ + 2π) = sin(θ)     Periodo: 2π
> cos(θ + 2π) = cos(θ)     Periodo: 2π
> tan(θ + π) = tan(θ)      Periodo: π
> csc(θ + 2π) = csc(θ)     Periodo: 2π
> sec(θ + 2π) = sec(θ)     Periodo: 2π
> cot(θ + π) = cot(θ)      Periodo: π
> ```
> 
> **Consecuencias:**
> 
> ```
> Para evaluar funciones en ángulos grandes:
> 
> sin(390°) = sin(390° - 360°) = sin(30°) = 1/2
> cos(5π) = cos(5π - 4π) = cos(π) = -1
> tan(9π/4) = tan(9π/4 - 2π) = tan(π/4) = 1
> ```

## 📐 Ángulos de Referencia

> [!tip]- Método para Calcular Valores
> 
> **Definición:**
> 
> ```
> El ángulo de referencia θ_ref es el ángulo agudo
> formado entre el lado terminal del ángulo
> y el eje x (horizontal)
> 
> 0° ≤ θ_ref ≤ 90° (0 ≤ θ_ref ≤ π/2)
> ```
> 
> **Fórmulas por cuadrante:**
> 
> ```
> I:    θ_ref = θ
> II:   θ_ref = 180° - θ  o  π - θ
> III:  θ_ref = θ - 180°  o  θ - π
> IV:   θ_ref = 360° - θ  o  2π - θ
> ```
> 
> **Procedimiento:**
> 
> ```
> 1. Reducir θ al intervalo [0°, 360°) o [0, 2π)
> 2. Determinar cuadrante
> 3. Calcular θ_ref
> 4. Evaluar función en θ_ref
> 5. Aplicar signo según cuadrante
> ```
> 
> **Ejemplos:**
> 
> ```
> 6) sin(150°):
>    Cuadrante II, θ_ref = 180° - 150° = 30°
>    sin(150°) = +sin(30°) = 1/2
> 
> 7) cos(240°):
>    Cuadrante III, θ_ref = 240° - 180° = 60°
>    cos(240°) = -cos(60°) = -1/2
> 
> 8) tan(315°):
>    Cuadrante IV, θ_ref = 360° - 315° = 45°
>    tan(315°) = -tan(45°) = -1
> 
> 9) sin(-210°):
>    Coterminal: -210° + 360° = 150°
>    Cuadrante II, θ_ref = 30°
>    sin(-210°) = sin(150°) = 1/2
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes
> 
> **1. "sin²(θ) = sin(θ²)"**
> 
> ```
> ✗ INCORRECTO
> 
> sin²(θ) = (sin(θ))²  (elevar resultado al cuadrado)
> sin(θ²) = sin(θ·θ)   (seno del ángulo al cuadrado)
> 
> Ejemplo: θ = 30° = π/6
> sin²(30°) = (1/2)² = 1/4
> sin(30°²) = sin(900°) = sin(180°) = 0
> ```
> 
> **2. "sin(A + B) = sin(A) + sin(B)"**
> 
> ```
> ✗ INCORRECTO
> 
> ✓ CORRECTO:
> sin(A + B) = sin(A)cos(B) + cos(A)sin(B)
> 
> Contraejemplo:
> sin(30° + 60°) = sin(90°) = 1
> sin(30°) + sin(60°) = 1/2 + √3/2 ≈ 1.366
> ```
> 
> **3. "tan(θ) = sin(θ)/cos(θ) siempre"**
> 
> ```
> ✗ INCOMPLETO
> 
> ✓ CORRECTO:
> tan(θ) = sin(θ)/cos(θ) cuando cos(θ) ≠ 0
> 
> En θ = 90°: cos(90°) = 0
> tan(90°) está indefinido, no es "1/0"
> ```
> 
> **4. "Confundir grados y radianes"**
> 
> ```
> ✗ ERROR COMÚN
> 
> sin(30°) = 0.5
> sin(30) = sin(30 rad) ≈ -0.988
> 
> SIEMPRE verificar modo de calculadora
> ```
> 
> **5. "sec(θ) = 1/csc(θ)"**
> 
> ```
> ✗ INCORRECTO
> 
> ✓ CORRECTO:
> sec(θ) = 1/cos(θ)
> csc(θ) = 1/sin(θ)
> 
> sec y csc NO son recíprocas entre sí
> ```
> 
> **6. "√(sin²(θ)) = sin(θ)"**
> 
> ```
> ✗ INCORRECTO en general
> 
> ✓ CORRECTO:
> √(sin²(θ)) = |sin(θ)|
> 
> Ejemplo: θ = 210°
> sin(210°) = -1/2
> √(sin²(210°)) = √(1/4) = 1/2 = |−1/2|
> ```

## 🎯 Aplicaciones Básicas

> [!example]- Problemas del Mundo Real
> 
> **1. Altura de un edificio:**
> 
> ```
> Desde 50 m de distancia, el ángulo de elevación
> a la cima es 60°. ¿Altura del edificio?
> 
> tan(60°) = altura/50
> altura = 50·tan(60°) = 50√3 ≈ 86.6 m
> ```
> 
> **2. Longitud de rampa:**
> 
> ```
> Rampa con altura 2 m e inclinación 15°
> ¿Longitud de la rampa?
> 
> sin(15°) = 2/longitud
> longitud = 2/sin(15°) ≈ 7.73 m
> ```
> 
> **3. Movimiento circular:**
> 
> ```
> Punto en círculo de radio 5 m
> Posición angular: 120°
> Coordenadas (x, y)?
> 
> x = 5·cos(120°) = 5·(-1/2) = -2.5 m
> y = 5·sin(120°) = 5·(√3/2) ≈ 4.33 m
> ```
> 
> **4. Onda sinusoidal:**
> 
> ```
> Altura de ola: h(t) = 2sin(πt/3)
> 
> Amplitud: 2 m
> Periodo: T = 2π/(π/3) = 6 s
> En t = 3 s: h(3) = 2sin(π) = 0 m
> ```

## 💡 Estrategias de Resolución

> [!tip]- Cómo Abordar Problemas
> 
> **Para evaluar funciones:**
> 
> 1. Identificar cuadrante del ángulo
> 2. Calcular ángulo de referencia
> 3. Evaluar en ángulo de referencia
> 4. Aplicar signo según cuadrante
> 
> **Para simplificar expresiones:**
> 
> 1. Usar identidades recíprocas y de cociente
> 2. Aplicar identidad pitagórica cuando aparezcan cuadrados
> 3. Buscar factores comunes
> 4. Verificar con valores específicos
> 
> **Para problemas geométricos:**
> 
> 1. Dibujar diagrama claro
> 2. Identificar triángulo rectángulo
> 3. Etiquetar lados conocidos y desconocidos
> 4. Elegir función trigonométrica apropiada
> 5. Verificar unidades y razonabilidad
