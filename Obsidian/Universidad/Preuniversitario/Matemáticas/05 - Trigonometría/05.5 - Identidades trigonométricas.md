# 🔄 Identidades Trigonométricas

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Las identidades trigonométricas son ecuaciones que relacionan las funciones trigonométricas entre sí y que son verdaderas para todos los valores donde ambos lados están definidos.**
> 
> **Características clave:**
> 
> - **Universalidad:** Válidas para todo ángulo (salvo restricciones de dominio)
> - **Herramientas de simplificación:** Transforman expresiones complejas
> - **Base algebraica:** Permiten resolver ecuaciones trigonométricas
> - **Origen geométrico:** Derivan de propiedades del círculo y triángulos
> - **Interconexión:** Muestran relaciones profundas entre las funciones

>

>

> 
> - **Unificación:** Funciones trigonométricas como funciones complejas
> - **Generalización:** Identidades hiperbólicas análogas
> - **Aplicaciones:** Análisis de Fourier, procesamiento de señales

## 🎯 Identidades Fundamentales

### 1️⃣ Identidades Pitagóricas

> [!success]- La Identidad Fundamental **Basadas en el Teorema de Pitágoras aplicado al círculo unitario:**
> 
> **Identidad principal:**
> 
> ```
> sin²(θ) + cos²(θ) = 1
> 
> Origen: x² + y² = 1 en el círculo unitario
> donde x = cos(θ), y = sin(θ)
> ```
> 
> **Variantes dividiendo por cos²(θ):**
> 
> ```
> tan²(θ) + 1 = sec²(θ)
> 
> Derivación:
> sin²(θ)/cos²(θ) + cos²(θ)/cos²(θ) = 1/cos²(θ)
> tan²(θ) + 1 = sec²(θ)
> ```
> 
> **Variantes dividiendo por sin²(θ):**
> 
> ```
> 1 + cot²(θ) = csc²(θ)
> 
> Derivación:
> sin²(θ)/sin²(θ) + cos²(θ)/sin²(θ) = 1/sin²(θ)
> 1 + cot²(θ) = csc²(θ)
> ```

### 2️⃣ Identidades Recíprocas

> [!success]- Relaciones Inversas
> 
> ```
> sin(θ) = 1/csc(θ)    ⟺    csc(θ) = 1/sin(θ)
> 
> cos(θ) = 1/sec(θ)    ⟺    sec(θ) = 1/cos(θ)
> 
> tan(θ) = 1/cot(θ)    ⟺    cot(θ) = 1/tan(θ)
> ```

### 3️⃣ Identidades de Cociente

> [!success]- Tangente y Cotangente
> 
> ```
> tan(θ) = sin(θ)/cos(θ)
> 
> cot(θ) = cos(θ)/sin(θ)
> 
> Válidas donde los denominadores ≠ 0
> ```

## 🔄 Identidades de Ángulos Negativos

> [!tip]- Funciones Pares e Impares **Funciones impares (simétricas respecto al origen):**
> 
> ```
> sin(-θ) = -sin(θ)
> tan(-θ) = -tan(θ)
> cot(-θ) = -cot(θ)
> csc(-θ) = -csc(θ)
> ```
> 
> **Funciones pares (simétricas respecto al eje y):**
> 
> ```
> cos(-θ) = cos(θ)
> sec(-θ) = sec(θ)
> ```

## ➕ Identidades de Suma y Diferencia

> [!important]- Fórmulas Fundamentales **Seno:**
> 
> ```
> sin(α ± β) = sin(α)cos(β) ± cos(α)sin(β)
> 
> Suma: sin(α + β) = sin(α)cos(β) + cos(α)sin(β)
> Resta: sin(α - β) = sin(α)cos(β) - cos(α)sin(β)
> ```
> 
> **Coseno:**
> 
> ```
> cos(α ± β) = cos(α)cos(β) ∓ sin(α)sin(β)
> 
> Suma: cos(α + β) = cos(α)cos(β) - sin(α)sin(β)
> Resta: cos(α - β) = cos(α)cos(β) + sin(α)sin(β)
> 
> ⚠️ Nota el cambio de signo
> ```
> 
> **Tangente:**
> 
> ```
> tan(α ± β) = [tan(α) ± tan(β)]/[1 ∓ tan(α)tan(β)]
> 
> Suma: tan(α + β) = [tan(α) + tan(β)]/[1 - tan(α)tan(β)]
> Resta: tan(α - β) = [tan(α) - tan(β)]/[1 + tan(α)tan(β)]
> ```

> [!example]- Aplicación de Suma y Diferencia **Calcular sin(75°):**
> 
> ```
> sin(75°) = sin(45° + 30°)
>          = sin(45°)cos(30°) + cos(45°)sin(30°)
>          = (√2/2)(√3/2) + (√2/2)(1/2)
>          = (√6 + √2)/4
> ```
> 
> **Calcular cos(π/12):**
> 
> ```
> cos(π/12) = cos(π/3 - π/4)
>           = cos(π/3)cos(π/4) + sin(π/3)sin(π/4)
>           = (1/2)(√2/2) + (√3/2)(√2/2)
>           = (√2 + √6)/4
> ```

## 🔢 Identidades de Ángulo Doble

> [!important]- Duplicación de Ángulos **Seno:**
> 
> ```
> sin(2θ) = 2sin(θ)cos(θ)
> 
> Derivación: sin(θ + θ) con fórmula de suma
> ```
> 
> **Coseno (tres formas):**
> 
> ```
> cos(2θ) = cos²(θ) - sin²(θ)         [forma básica]
>         = 2cos²(θ) - 1               [en términos de cos]
>         = 1 - 2sin²(θ)               [en términos de sin]
> 
> Todas equivalentes por sin²(θ) + cos²(θ) = 1
> ```
> 
> **Tangente:**
> 
> ```
> tan(2θ) = 2tan(θ)/[1 - tan²(θ)]
> ```

## ⚡ Identidades de Reducción de Potencias

> [!tip]- Expresar Potencias en Términos de Primer Orden **Derivadas de las fórmulas de ángulo doble:**
> 
> ```
> sin²(θ) = [1 - cos(2θ)]/2
> 
> cos²(θ) = [1 + cos(2θ)]/2
> 
> tan²(θ) = [1 - cos(2θ)]/[1 + cos(2θ)]
> ```
> 
> **Útiles para:**
> 
> - Integración de potencias trigonométricas
> - Simplificación de expresiones
> - Análisis de Fourier

## 📐 Identidades de Ángulo Medio

> [!important]- Fórmulas de Mitad de Ángulo **Seno:**
> 
> ```
> sin(θ/2) = ±√[(1 - cos(θ))/2]
> 
> Signo depende del cuadrante de θ/2
> ```
> 
> **Coseno:**
> 
> ```
> cos(θ/2) = ±√[(1 + cos(θ))/2]
> ```
> 
> **Tangente (tres formas):**
> 
> ```
> tan(θ/2) = ±√[(1 - cos(θ))/(1 + cos(θ))]
>          = sin(θ)/(1 + cos(θ))
>          = (1 - cos(θ))/sin(θ)
> 
> Las dos últimas no requieren ± (signo automático)
> ```

## 🔀 Identidades de Producto a Suma

> [!tip]- Transformación de Productos
> 
> ```
> sin(α)sin(β) = [cos(α - β) - cos(α + β)]/2
> 
> cos(α)cos(β) = [cos(α - β) + cos(α + β)]/2
> 
> sin(α)cos(β) = [sin(α + β) + sin(α - β)]/2
> 
> cos(α)sin(β) = [sin(α + β) - sin(α - β)]/2
> ```
> 
> **Aplicaciones:**
> 
> - Integración de productos trigonométricos
> - Análisis de ondas (batidos, interferencia)
> - Procesamiento de señales

## 🔁 Identidades de Suma a Producto

> [!tip]- Transformación de Sumas
> 
> ```
> sin(α) + sin(β) = 2sin[(α + β)/2]cos[(α - β)/2]
> 
> sin(α) - sin(β) = 2cos[(α + β)/2]sin[(α - β)/2]
> 
> cos(α) + cos(β) = 2cos[(α + β)/2]cos[(α - β)/2]
> 
> cos(α) - cos(β) = -2sin[(α + β)/2]sin[(α - β)/2]
> ```
> 
> **Técnica de memoria:** Promedios: (α + β)/2 Semipromedios: (α - β)/2

## 🎯 Identidades de Ángulos Complementarios

> [!note]- Cofunciones
> 
> ```
> sin(π/2 - θ) = cos(θ)    cos(π/2 - θ) = sin(θ)
> tan(π/2 - θ) = cot(θ)    cot(π/2 - θ) = tan(θ)
> sec(π/2 - θ) = csc(θ)    csc(π/2 - θ) = sec(θ)
> 
> En grados:
> sin(90° - θ) = cos(θ), etc.
> ```

## ⚡ Estrategias de Demostración

> [!tip]- Técnicas para Probar Identidades **1. Trabajar un lado a la vez:**
> 
> ```
> Elegir el lado más complicado
> Transformarlo hasta obtener el otro lado
> NO mover términos entre lados (no es ecuación)
> ```
> 
> **2. Expresar todo en seno y coseno:**
> 
> ```
> tan(θ) → sin(θ)/cos(θ)
> sec(θ) → 1/cos(θ)
> Etc.
> ```
> 
> **3. Usar identidades fundamentales:**
> 
> ```
> Pitagóricas: sin² + cos² = 1
> Cociente: tan = sin/cos
> Recíprocas: csc = 1/sin
> ```
> 
> **4. Factorizar o multiplicar:**
> 
> ```
> Diferencia de cuadrados
> Factor común
> Multiplicar por forma conjugada
> ```
> 
> **5. Sustituir identidades conocidas:**
> 
> ```
> Reconocer patrones
> Ángulo doble, suma, etc.
> ```

## 📝 Ejemplos de Demostración

> [!example]- Demostraciones Detalladas **Ejemplo 1: Probar (1 - cos(2θ))/(sin(2θ)) = tan(θ)**
> 
> ```
> Lado izquierdo:
> = (1 - cos(2θ))/(sin(2θ))
> = (1 - (1 - 2sin²(θ)))/(2sin(θ)cos(θ))    [ángulo doble]
> = (2sin²(θ))/(2sin(θ)cos(θ))
> = sin(θ)/cos(θ)
> = tan(θ)  ✓
> ```
> 
> **Ejemplo 2: Probar sin(θ)/(1 + cos(θ)) = (1 - cos(θ))/sin(θ)**
> 
> ```
> Lado izquierdo · sin(θ)/sin(θ):
> = sin²(θ)/(sin(θ)(1 + cos(θ)))
> = (1 - cos²(θ))/(sin(θ)(1 + cos(θ)))      [Pitagórica]
> = ((1 - cos(θ))(1 + cos(θ)))/(sin(θ)(1 + cos(θ)))  [diferencia de cuadrados]
> = (1 - cos(θ))/sin(θ)  ✓
> ```
> 
> **Ejemplo 3: Probar sec²(θ) - tan²(θ) = 1**
> 
> ```
> Lado izquierdo:
> = 1/cos²(θ) - sin²(θ)/cos²(θ)
> = (1 - sin²(θ))/cos²(θ)
> = cos²(θ)/cos²(θ)                          [Pitagórica]
> = 1  ✓
> ```

## 🔧 Aplicaciones Prácticas

> [!example]- Simplificación de Expresiones **Ejemplo 1:**
> 
> ```
> Simplificar: (sin(x) + cos(x))²
> 
> = sin²(x) + 2sin(x)cos(x) + cos²(x)
> = (sin²(x) + cos²(x)) + 2sin(x)cos(x)
> = 1 + 2sin(x)cos(x)
> = 1 + sin(2x)                    [ángulo doble]
> ```
> 
> **Ejemplo 2:**
> 
> ```
> Simplificar: tan(x) + cot(x)
> 
> = sin(x)/cos(x) + cos(x)/sin(x)
> = (sin²(x) + cos²(x))/(sin(x)cos(x))
> = 1/(sin(x)cos(x))
> = 2/(2sin(x)cos(x))
> = 2/sin(2x)
> = 2csc(2x)
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes **1. "sin(α + β) = sin(α) + sin(β)"**
> 
> ```
> ✗ INCORRECTO
> ✓ CORRECTO: sin(α + β) = sin(α)cos(β) + cos(α)sin(β)
> 
> Contraejemplo: sin(30° + 60°) ≠ sin(30°) + sin(60°)
> sin(90°) = 1 pero sin(30°) + sin(60°) ≈ 1.366
> ```
> 
> **2. "cos(2θ) = 2cos(θ)"**
> 
> ```
> ✗ INCORRECTO
> ✓ CORRECTO: cos(2θ) = cos²(θ) - sin²(θ)
>                     = 2cos²(θ) - 1
>                     = 1 - 2sin²(θ)
> ```
> 
> **3. "(sin(x))² = sin(x²)"**
> 
> ```
> ✗ INCORRECTO - confunde potencia con composición
> ✓ sin²(x) significa (sin(x))²
> ✓ sin(x²) significa seno de x cuadrada (diferente)
> ```
> 
> **4. "1/sin(x) = sin⁻¹(x)"**
> 
> ```
> ✗ INCORRECTO
> ✓ 1/sin(x) = csc(x) (recíproca)
> ✓ sin⁻¹(x) = arcsin(x) (función inversa)
> ```
> 
> **5. "Mover términos al demostrar"**
> 
> ```
> ✗ Al probar A = B, NO hacer A - B = 0
> ✓ Transformar A hasta obtener B
>   O transformar B hasta obtener A
>   O transformar ambos a C
> ```

> 
> 1. Demuestra: tan θ · cos θ = sin θ
> 2. Simplifica: (1 - sin²θ)/cos θ
> 3. Demuestra: csc²θ - cot²θ = 1
>

>
