# 🎯 Ecuaciones e Inecuaciones Trigonométricas

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Una ecuación trigonométrica es una igualdad que involucra funciones trigonométricas de una variable, cuya solución consiste en encontrar todos los ángulos que satisfacen la ecuación.**
> 
> **Características clave:**
> 
> - **Múltiples soluciones:** Por la periodicidad de las funciones
> - **Soluciones en intervalos:** A menudo se buscan en [0, 2π) o [0°, 360°)
> - **Naturaleza periódica:** Soluciones se repiten cada periodo
> - **Restricciones de dominio:** Considerar donde las funciones están definidas
> - **Verificación necesaria:** Algunas transformaciones pueden introducir soluciones extrañas

### 📖 Contexto Histórico

> [!note]- Desarrollo Histórico **Antigüedad (300 a.C. - 500 d.C.):**
> 
> - **Hiparco y Ptolomeo:** Resolución de triángulos esféricos
> - **Problemas astronómicos:** Ecuaciones trigonométricas implícitas
> - **Métodos geométricos:** Sin notación algebraica
> 
> **Edad Media (500-1500):**
> 
> - **Matemáticos árabes:** Algoritmos para resolver triángulos
> - **Al-Khwarizmi:** Métodos algebraicos aplicados
> - **Trigonometría práctica:** Navegación y astronomía
> 
> **Renacimiento (1500-1800):**
> 
> - **Viète (1579):** Primeras soluciones algebraicas sistemáticas
> - **Euler (1748):** Notación moderna y métodos generales
> - **Periodicidad:** Reconocimiento formal de infinitas soluciones
> 
> **Era Moderna (1800-presente):**
> 
> - **Análisis complejo:** Soluciones en el plano complejo
> - **Métodos numéricos:** Aproximaciones computacionales
> - **Aplicaciones:** Ondas, vibraciones, procesamiento de señales

## 🎯 Tipos de Ecuaciones Trigonométricas

### 1️⃣ Ecuaciones Lineales Básicas

> [!success]- Forma: f(θ) = k **Estructura general:**
> 
> ```
> sin(θ) = k
> cos(θ) = k
> tan(θ) = k
> 
> Donde k es una constante
> ```
> 
> **Solución de sin(θ) = k, |k| ≤ 1:**
> 
> ```
> θ = arcsin(k) + 2nπ           [solución principal]
> θ = π - arcsin(k) + 2nπ       [solución secundaria]
> 
> n ∈ ℤ (todas las soluciones)
> 
> En [0, 2π):
> - Si k > 0: dos soluciones (cuadrantes I y II)
> - Si k = 0: dos soluciones (0 y π)
> - Si k < 0: dos soluciones (cuadrantes III y IV)
> ```
> 
> **Solución de cos(θ) = k, |k| ≤ 1:**
> 
> ```
> θ = arccos(k) + 2nπ
> θ = -arccos(k) + 2nπ = 2π - arccos(k) + 2nπ
> 
> En [0, 2π):
> - Si k > 0: dos soluciones (cuadrantes I y IV)
> - Si k = 0: dos soluciones (π/2 y 3π/2)
> - Si k < 0: dos soluciones (cuadrantes II y III)
> ```
> 
> **Solución de tan(θ) = k:**
> 
> ```
> θ = arctan(k) + nπ
> 
> n ∈ ℤ
> 
> Periodo π (no 2π)
> En [0, 2π): dos soluciones
> ```

> [!example]- Ejemplos de Ecuaciones Básicas **Ejemplo 1: sin(θ) = 1/2**
> 
> ```
> Solución en [0, 2π):
> 
> arcsin(1/2) = π/6
> 
> θ₁ = π/6                    [cuadrante I]
> θ₂ = π - π/6 = 5π/6        [cuadrante II]
> 
> Solución general:
> θ = π/6 + 2nπ  o  θ = 5π/6 + 2nπ, n ∈ ℤ
> ```
> 
> **Ejemplo 2: cos(θ) = -√3/2**
> 
> ```
> Solución en [0, 2π):
> 
> arccos(-√3/2) = 5π/6       [valor principal]
> 
> θ₁ = 5π/6                   [cuadrante II]
> θ₂ = 2π - 5π/6 = 7π/6      [cuadrante III]
> 
> Solución general:
> θ = 5π/6 + 2nπ  o  θ = 7π/6 + 2nπ, n ∈ ℤ
> ```
> 
> **Ejemplo 3: tan(θ) = √3**
> 
> ```
> Solución en [0, 2π):
> 
> arctan(√3) = π/3
> 
> θ₁ = π/3                    [cuadrante I]
> θ₂ = π/3 + π = 4π/3        [cuadrante III]
> 
> Solución general:
> θ = π/3 + nπ, n ∈ ℤ
> ```

### 2️⃣ Ecuaciones Cuadráticas

> [!important]- Forma: a·f²(θ) + b·f(θ) + c = 0 **Método de sustitución:**
> 
> ```
> Sea u = sin(θ), cos(θ), o tan(θ)
> 
> Resolver: au² + bu + c = 0
> 
> u = [-b ± √(b² - 4ac)]/(2a)
> 
> Luego resolver f(θ) = u
> ```
> 
> **Discriminante:**
> 
> ```
> Δ = b² - 4ac
> 
> Δ > 0: dos valores de u → hasta 4 soluciones en [0, 2π)
> Δ = 0: un valor de u → hasta 2 soluciones en [0, 2π)
> Δ < 0: sin soluciones reales
> ```

> [!example]- Ejemplos de Ecuaciones Cuadráticas **Ejemplo 1: 2sin²(θ) - sin(θ) - 1 = 0**
> 
> ```
> Sustitución: u = sin(θ)
> 2u² - u - 1 = 0
> 
> Factorización: (2u + 1)(u - 1) = 0
> 
> u₁ = -1/2  →  sin(θ) = -1/2
> u₂ = 1     →  sin(θ) = 1
> 
> Para sin(θ) = -1/2 en [0, 2π):
> θ₁ = 7π/6  (cuadrante III)
> θ₂ = 11π/6 (cuadrante IV)
> 
> Para sin(θ) = 1:
> θ₃ = π/2
> 
> Soluciones: θ ∈ {π/2, 7π/6, 11π/6}
> ```
> 
> **Ejemplo 2: cos²(θ) + cos(θ) = 0**
> 
> ```
> Factorización directa:
> cos(θ)(cos(θ) + 1) = 0
> 
> cos(θ) = 0  o  cos(θ) = -1
> 
> Para cos(θ) = 0:
> θ₁ = π/2, θ₂ = 3π/2
> 
> Para cos(θ) = -1:
> θ₃ = π
> 
> Soluciones: θ ∈ {π/2, π, 3π/2}
> ```
> 
> **Ejemplo 3: 3tan²(θ) - 1 = 0**
> 
> ```
> tan²(θ) = 1/3
> tan(θ) = ±1/√3 = ±√3/3
> 
> Para tan(θ) = √3/3:
> θ₁ = π/6 (cuadrante I)
> θ₂ = π/6 + π = 7π/6 (cuadrante III)
> 
> Para tan(θ) = -√3/3:
> θ₃ = -π/6 + π = 5π/6 (cuadrante II)
> θ₄ = -π/6 + 2π = 11π/6 (cuadrante IV)
> 
> Soluciones: θ ∈ {π/6, 5π/6, 7π/6, 11π/6}
> ```

### 3️⃣ Ecuaciones con Múltiples Funciones

> [!tip]- Uso de Identidades para Reducir **Estrategia general:**
> 
> ```
> 1. Expresar todo en términos de una función
> 2. Usar identidades pitagóricas
> 3. Resolver la ecuación resultante
> ```
> 
> **Identidades útiles:**
> 
> ```
> sin²(θ) = 1 - cos²(θ)
> cos²(θ) = 1 - sin²(θ)
> tan(θ) = sin(θ)/cos(θ)
> 1 + tan²(θ) = sec²(θ)
> ```

> [!example]- Ejemplos de Múltiples Funciones **Ejemplo 1: sin(θ) + cos(θ) = 1**
> 
> ```
> Método: Elevar al cuadrado (con cuidado)
> 
> (sin(θ) + cos(θ))² = 1²
> sin²(θ) + 2sin(θ)cos(θ) + cos²(θ) = 1
> 1 + 2sin(θ)cos(θ) = 1
> 2sin(θ)cos(θ) = 0
> sin(2θ) = 0
> 
> 2θ = nπ
> θ = nπ/2
> 
> En [0, 2π): θ ∈ {0, π/2, π, 3π/2}
> 
> Verificación (eliminar extrañas):
> θ = 0: sin(0) + cos(0) = 0 + 1 = 1 ✓
> θ = π/2: sin(π/2) + cos(π/2) = 1 + 0 = 1 ✓
> θ = π: sin(π) + cos(π) = 0 - 1 = -1 ✗
> θ = 3π/2: sin(3π/2) + cos(3π/2) = -1 + 0 = -1 ✗
> 
> Soluciones válidas: θ ∈ {0, π/2}
> ```
> 
> **Ejemplo 2: 2sin(θ) = tan(θ)**
> 
> ```
> 2sin(θ) = sin(θ)/cos(θ)
> 2sin(θ)cos(θ) = sin(θ)
> 2sin(θ)cos(θ) - sin(θ) = 0
> sin(θ)(2cos(θ) - 1) = 0
> 
> sin(θ) = 0  o  cos(θ) = 1/2
> 
> Para sin(θ) = 0 en [0, 2π):
> θ₁ = 0, θ₂ = π
> 
> Para cos(θ) = 1/2:
> θ₃ = π/3, θ₄ = 5π/3
> 
> Verificar (tan no definida donde cos = 0):
> Todas válidas
> 
> Soluciones: θ ∈ {0, π/3, π, 5π/3}
> ```
> 
> **Ejemplo 3: sec(θ) = 1 + tan(θ)**
> 
> ```
> 1/cos(θ) = 1 + sin(θ)/cos(θ)
> 1 = cos(θ) + sin(θ)
> 
> Este es el ejemplo anterior
> Soluciones: θ ∈ {0, π/2}
> ```

### 4️⃣ Ecuaciones con Ángulos Múltiples

> [!important]- Ecuaciones con 2θ, 3θ, θ/2, etc. **Método general:**
> 
> ```
> 1. Resolver para el ángulo múltiple
> 2. Despejar θ
> 3. Encontrar todas las soluciones en el intervalo ampliado
> 4. Verificar cuáles caen en [0, 2π)
> ```
> 
> **Para sin(nθ) = k:**
> 
> ```
> nθ debe recorrer n veces el intervalo [0, 2π)
> Es decir, nθ ∈ [0, 2nπ)
> ```

> [!example]- Ejemplos con Ángulos Múltiples **Ejemplo 1: sin(2θ) = √3/2**
> 
> ```
> Sea φ = 2θ
> sin(φ) = √3/2
> 
> En [0, 2π): φ₁ = π/3, φ₂ = 2π/3
> 
> Pero 2θ ∈ [0, 4π) para θ ∈ [0, 2π)
> 
> φ = π/3 + 2nπ o φ = 2π/3 + 2nπ, n = 0, 1
> 
> Para n = 0:
> 2θ = π/3  →  θ₁ = π/6
> 2θ = 2π/3  →  θ₂ = π/3
> 
> Para n = 1:
> 2θ = π/3 + 2π = 7π/3  →  θ₃ = 7π/6
> 2θ = 2π/3 + 2π = 8π/3  →  θ₄ = 4π/3
> 
> Soluciones: θ ∈ {π/6, π/3, 7π/6, 4π/3}
> ```
> 
> **Ejemplo 2: cos(θ/2) = 1/2**
> 
> ```
> Sea φ = θ/2
> cos(φ) = 1/2
> 
> Para θ ∈ [0, 2π), φ ∈ [0, π)
> 
> En [0, 2π): φ₁ = π/3, φ₂ = 5π/3
> Pero solo φ₁ = π/3 está en [0, π)
> 
> θ/2 = π/3
> θ = 2π/3
> 
> Solución: θ = 2π/3
> ```
> 
> **Ejemplo 3: tan(3θ) = 1**
> 
> ```
> 3θ = π/4 + nπ, n ∈ ℤ
> θ = π/12 + nπ/3
> 
> Para θ ∈ [0, 2π):
> n = 0: θ₁ = π/12
> n = 1: θ₂ = π/12 + π/3 = 5π/12
> n = 2: θ₃ = π/12 + 2π/3 = 3π/4
> n = 3: θ₄ = π/12 + π = 13π/12
> n = 4: θ₅ = π/12 + 4π/3 = 17π/12
> n = 5: θ₆ = π/12 + 5π/3 = 21π/12 = 7π/4
> 
> Soluciones: θ ∈ {π/12, 5π/12, 3π/4, 13π/12, 17π/12, 7π/4}
> ```

### 5️⃣ Ecuaciones Factorizables

> [!tip]- Factorización y Propiedad del Producto Cero **Principio:**
> 
> ```
> Si A(θ) · B(θ) = 0
> entonces A(θ) = 0 o B(θ) = 0
> 
> Resolver cada ecuación por separado
> ```

> [!example]- Ejemplos de Factorización **Ejemplo 1: sin(θ)cos(θ) = 0**
> 
> ```
> sin(θ) = 0  o  cos(θ) = 0
> 
> Para sin(θ) = 0 en [0, 2π):
> θ = 0, π
> 
> Para cos(θ) = 0:
> θ = π/2, 3π/2
> 
> Soluciones: θ ∈ {0, π/2, π, 3π/2}
> ```
> 
> **Ejemplo 2: 2cos²(θ) - 3cos(θ) + 1 = 0**
> 
> ```
> Sea u = cos(θ)
> 2u² - 3u + 1 = 0
> (2u - 1)(u - 1) = 0
> 
> u = 1/2  o  u = 1
> 
> cos(θ) = 1/2:
> θ = π/3, 5π/3
> 
> cos(θ) = 1:
> θ = 0
> 
> Soluciones: θ ∈ {0, π/3, 5π/3}
> ```

## 🎯 Estrategias de Resolución

> [!tip]- Procedimiento General **Paso 1: Simplificar la ecuación**
> 
> ```
> - Usar identidades trigonométricas
> - Expresar en términos de una función si es posible
> - Factorizar cuando sea viable
> ```
> 
> **Paso 2: Identificar el tipo**
> 
> ```
> - Lineal básica: f(θ) = k
> - Cuadrática: af²(θ) + bf(θ) + c = 0
> - Múltiples funciones
> - Ángulos múltiples
> ```
> 
> **Paso 3: Resolver algebraicamente**
> 
> ```
> - Aplicar método apropiado según el tipo
> - Considerar el dominio de las funciones
> ```
> 
> **Paso 4: Encontrar soluciones en el intervalo**
> 
> ```
> - Determinar intervalo solicitado (usualmente [0, 2π))
> - Considerar periodicidad
> - Usar círculo unitario o gráficas
> ```
> 
> **Paso 5: Verificar**
> 
> ```
> - Sustituir en la ecuación original
> - Eliminar soluciones extrañas
> - Verificar restricciones de dominio
> ```

## 📊 Inecuaciones Trigonométricas

> [!important]- Desigualdades con Funciones Trigonométricas **Definición:**
> 
> ```
> Inequación trigonométrica: desigualdad que involucra
> funciones trigonométricas
> 
> Ejemplos:
> sin(θ) > 1/2
> cos(θ) ≤ -√2/2
> tan(θ) < 1
> ```
> 
> **Método de resolución:**
> 
> ```
> 1. Resolver la ecuación asociada (cambiar > por =)
> 2. Identificar puntos críticos
> 3. Analizar intervalos entre puntos críticos
> 4. Determinar dónde se satisface la desigualdad
> 5. Expresar solución como unión de intervalos
> ```

> [!example]- Ejemplos de Inecuaciones **Ejemplo 1: sin(θ) ≥ 1/2 en [0, 2π)**
> 
> ```
> Paso 1: Resolver sin(θ) = 1/2
> θ = π/6, 5π/6
> 
> Paso 2: Puntos críticos dividen [0, 2π) en:
> [0, π/6), [π/6, 5π/6], (5π/6, 2π)
> 
> Paso 3: Probar cada intervalo
> θ = 0: sin(0) = 0 < 1/2 ✗
> θ = π/2: sin(π/2) = 1 > 1/2 ✓
> θ = π: sin(π) = 0 < 1/2 ✗
> 
> Paso 4: Por continuidad
> Solución: θ ∈ [π/6, 5π/6]
> ```
> 
> **Ejemplo 2: cos(θ) < -1/2 en [0, 2π)**
> 
> ```
> Resolver cos(θ) = -1/2
> θ = 2π/3, 4π/3
> 
> Intervalos: [0, 2π/3), [2π/3, 4π/3], (4π/3, 2π)
> 
> Probar:
> θ = 0: cos(0) = 1 > -1/2 ✗
> θ = π: cos(π) = -1 < -1/2 ✓
> θ = 3π/2: cos(3π/2) = 0 > -1/2 ✗
> 
> Solución: θ ∈ (2π/3, 4π/3)
> ```
> 
> **Ejemplo 3: tan(θ) > √3 en [0, π)**
> 
> ```
> Resolver tan(θ) = √3
> θ = π/3 (en [0, π))
> 
> Intervalos: [0, π/3), [π/3, π/2), (π/2, π)
> 
> Recordar: tan no definida en π/2
> 
> Probar:
> θ = 0: tan(0) = 0 < √3 ✗
> θ = π/4: tan(π/4) = 1 < √3 ✗
> θ = 5π/12: tan(5π/12) ≈ 2.414 > √3 ✓
> θ = 2π/3: tan(2π/3) ≈ -1.732 < √3 ✗
> 
> Solución: θ ∈ (π/3, π/2)
> ```

## 🔧 Técnicas Especiales

> [!tip]- Métodos Avanzados **1. Sustitución de Weierstrass:**
> 
> ```
> Sea t = tan(θ/2)
> 
> Entonces:
> sin(θ) = 2t/(1 + t²)
> cos(θ) = (1 - t²)/(1 + t²)
> tan(θ) = 2t/(1 - t²)
> 
> Convierte ecuación trigonométrica en algebraica
> ```
> 
> **2. Uso de suma a producto:**
> 
> ```
> sin(α) + sin(β) = 2sin[(α+β)/2]cos[(α-β)/2]
> cos(α) + cos(β) = 2cos[(α+β)/2]cos[(α-β)/2]
> 
> Útil para factorizar sumas
> ```
> 
> **3. Linealización de productos:**
> 
> ```
> sin(α)sin(β) = [cos(α-β) - cos(α+β)]/2
> cos(α)cos(β) = [cos(α-β) + cos(α+β)]/2
> 
> Convierte productos en sumas
> ```

> [!example]- Aplicación de Técnicas Especiales **Ejemplo 1: sin(θ) + sin(3θ) = 0**
> 
> ```
> Suma a producto:
> 2sin[(θ+3θ)/2]cos[(θ-3θ)/2] = 0
> 2sin(2θ)cos(-θ) = 0
> 2sin(2θ)cos(θ) = 0
> 
> sin(2θ) = 0  o  cos(θ) = 0
> 
> Para sin(2θ) = 0:
> 2θ = nπ → θ = nπ/2
> 
> En [0, 2π): θ ∈ {0, π/2, π, 3π/2}
> 
> Para cos(θ) = 0:
> θ ∈ {π/2, 3π/2}
> 
> Unión (eliminando repetidos):
> θ ∈ {0, π/2, π, 3π/2}
> ```
> 
> **Ejemplo 2: 3sin(θ) - 4sin³(θ) = 1**
> 
> ```
> Reconocer: sin(3θ) = 3sin(θ) - 4sin³(θ)
> 
> sin(3θ) = 1
> 3θ = π/2 + 2nπ
> θ = π/6 + 2nπ/3
> 
> En [0, 2π):
> n = 0: θ₁ = π/6
> n = 1: θ₂ = π/6 + 2π/3 = 5π/6
> n = 2: θ₃ = π/6 + 4π/3 = 3π/2
> 
> Soluciones: θ ∈ {π/6, 5π/6, 3π/2}
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes **1. "Dividir por una función trigonométrica"**
> 
> ```
> De sin(θ)cos(θ) = sin(θ)
> ✗ INCORRECTO: dividir por sin(θ)
>   cos(θ) = 1
>   (se pierden soluciones donde sin(θ) = 0)
> 
> ✓ CORRECTO:
>   sin(θ)cos(θ) - sin(θ) = 0
>   sin(θ)(cos(θ) - 1) = 0
>   sin(θ) = 0 o cos(θ) = 1
> ```
> 
> **2. "Elevar al cuadrado sin verificar"**
> 
> ```
> De sin(θ) = -1
> ✗ INCORRECTO:
>   sin²(θ) = 1 (introduce soluciones extrañas)
> 
> ✓ CORRECTO:
>   Resolver directamente: θ = 3π/2
>   O verificar soluciones después de elevar
> ```
> 
> **3. "Olvidar periodicidad"**
> 
> ```
> sin(2θ) = 0 en [0, 2π)
> 
> ✗ INCORRECTO: 2θ = 0, π
>   Solo da θ = 0, π/2
> 
> ✓ CORRECTO: 2θ ∈ [0, 4π)
>   2θ = 0, π, 2π, 3π
>   θ = 0, π/2, π, 3π/2
> ```
> 
> **4. "Invertir desigualdades al multiplicar"**
> 
> ```
> Si -sin(θ) > 0
> 
> ✗ INCORRECTO: sin(θ) > 0 (no invertir el signo)
> ✓ CORRECTO: sin(θ) < 0
> ```
> 
> **5. "Confundir dominio de funciones"**
> 
> ```
> Resolver tan(θ) + cot(θ) = 2
> 
> ⚠️ Recordar: tan y cot no definidas donde
> cos(θ) = 0 y sin(θ) = 0 respectivamente
> 
> Verificar que soluciones no estén en estos puntos
> ```

## 📝 Sistemas de Ecuaciones

> [!note]- Ecuaciones Simultáneas **Método general:**
> 
> ```
> 1. Usar una ecuación para expresar una función en términos de otra
> 2. Sustituir en la segunda ecuación
> 3. Resolver la ecuación resultante
> 4. Verificar en ambas ecuaciones originales
> ```

> [!example]- Ejemplo de Sistema **Sistema:**
> 
> ```
> sin(θ) + cos(θ) = 1
> sin(θ)cos(θ) = 0
> 
> De la segunda ecuación:
> sin(θ) = 0  o  cos(θ) = 0
> 
> Caso 1: sin(θ) = 0
> De la primera: 0 + cos(θ) = 1
> cos(θ) = 1
> θ = 0 ✓
> 
> Caso 2: cos(θ) = 0
> De la primera: sin(θ) + 0 = 1
> sin(θ) = 1
> θ = π/2 ✓
> 
> Soluciones: θ ∈ {0, π/2}
> ```

## 🎯 Aplicaciones Prácticas

> [!example]- Problemas Aplicados **Física - Movimiento armónico:**
> 
> ```
> Posición: x(t) = A·sin(ωt + φ)
> 
> ¿Cuándo x = A/2?
> A·sin(ωt + φ) = A/2
> sin(ωt + φ) = 1/2
> 
> ωt + φ = π/6 + 2nπ o ωt + φ = 5π/6 + 2nπ
> 
> t = (π/6 - φ)/ω + 2nπ/ω o t = (5π/6 - φ)/ω + 2nπ/ω
> 
> Primer instante (n=0, primera solución): t₁ = (π/6 - φ)/ω
> 
> ```
> 
> **Ingeniería - Análisis de ondas:**
> ```
> 
> Dos ondas interfieren: y = sin(x) + cos(x) ¿Dónde y = √2?
> 
> sin(x) + cos(x) = √2 √2[sin(x)/√2 + cos(x)/√2] = √2 sin(x)cos(π/4) + cos(x)sin(π/4) = 1 sin(x + π/4) = 1
> 
> x + π/4 = π/2 + 2nπ x = π/4 + 2nπ
> 
> ```
> 
> **Astronomía - Posición solar:**
> ```
> 
> Altura solar: h(t) = 60·sin(πt/12) grados donde t es hora del día (0-24)
> 
> ¿Cuándo h ≥ 30°? 60·sin(πt/12) ≥ 30 sin(πt/12) ≥ 1/2
> 
> πt/12 = π/6 + 2nπ o πt/12 = 5π/6 + 2nπ t = 2 + 24n o t = 10 + 24n
> 
> En [0, 24): t ∈ [2, 10] (de 2am a 10am)
> ```

> ```
> Para resolver f(θ) = g(θ):
> 
> 1. Graficar y = f(θ) y y = g(θ)
> 2. Puntos de intersección son las soluciones
> 3. Útil cuando método algebraico es difícil
> ```

> ```
> Resolver: sin(θ) = cos(θ) en [0, 2π)

> 
> Algebraicamente:
> sin(θ)/cos(θ) = 1
> tan(θ) = 1

> 
> En [0, 2π): θ ∈ {π/4, 5π/4}
> ```
> 
> **Método del círculo unitario:**
> 
> ```
> Para ecuaciones básicas, usar círculo unitario:
> 
> sin(θ) = y-coordenada
> cos(θ) = x-coordenada
> 
> Ejemplo: cos(θ) = -1/2
> Buscar puntos donde x = -1/2
> Soluciones: θ = 2π/3, 4π/3
> ```

## 📊 Inecuaciones Compuestas

> [!important]- Sistemas de Inecuaciones **Conjunción (Y):**
> 
> ```
> f(θ) > a  Y  g(θ) < b
> 
> Solución: intersección de ambos conjuntos
> S = S₁ ∩ S₂
> ```
> 
> **Disyunción (O):**
> 
> ```
> f(θ) > a  O  g(θ) < b
> 
> Solución: unión de ambos conjuntos
> S = S₁ ∪ S₂
> ```

> [!example]- Ejemplos de Inecuaciones Compuestas **Ejemplo 1: sin(θ) > 1/2 Y cos(θ) > 0**
> 
> ```
> En [0, 2π):
> 
> sin(θ) > 1/2: θ ∈ (π/6, 5π/6)
> cos(θ) > 0: θ ∈ [0, π/2) ∪ (3π/2, 2π)
> 
> Intersección: θ ∈ (π/6, π/2)
> ```
> 
> **Ejemplo 2: cos(θ) ≤ -√2/2 O tan(θ) < -1**
> 
> ```
> En [0, 2π):
> 
> cos(θ) ≤ -√2/2: θ ∈ [3π/4, 5π/4]
> tan(θ) < -1: θ ∈ (π/4, π/2) ∪ (5π/4, 3π/2)
> 
> Unión: θ ∈ (π/4, π/2) ∪ [3π/4, 3π/2)
> ```

## 🧮 Ecuaciones Paramétricas

> [!note]- Ecuaciones con Parámetros **Forma general:**
> 
> ```
> a·sin(θ) + b·cos(θ) = c
> 
> Método: Convertir a una función única
> ```
> 
> **Técnica de conversión:**
> 
> ```
> a·sin(θ) + b·cos(θ) = √(a² + b²)·sin(θ + φ)
> 
> donde tan(φ) = b/a
> 
> Entonces: sin(θ + φ) = c/√(a² + b²)
> ```

> [!example]- Ejemplo Paramétrico **Resolver: 3sin(θ) + 4cos(θ) = 2**
> 
> ```
> Paso 1: Calcular R = √(3² + 4²) = 5
> 
> Paso 2: Encontrar φ tal que tan(φ) = 4/3
> φ = arctan(4/3) ≈ 0.927 rad
> 
> Paso 3: Reescribir
> 5·sin(θ + φ) = 2
> sin(θ + φ) = 2/5
> 
> Paso 4: Resolver
> θ + φ = arcsin(2/5) + 2nπ  o  θ + φ = π - arcsin(2/5) + 2nπ
> 
> θ = arcsin(2/5) - φ + 2nπ  o  θ = π - arcsin(2/5) - φ + 2nπ
> 
> Paso 5: Calcular valores numéricos
> arcsin(2/5) ≈ 0.412
> 
> θ₁ ≈ 0.412 - 0.927 ≈ -0.515 → 2π - 0.515 ≈ 5.768
> θ₂ ≈ π - 0.412 - 0.927 ≈ 1.803
> 
> En [0, 2π): θ ≈ {1.803, 5.768}
> ```

## 🎓 Problemas Resueltos Paso a Paso

> [!example]- Soluciones Detalladas **Problema 1: 2cos²(θ) + 3sin(θ) = 0**
> 
> ```
> SOLUCIÓN:
> 
> Paso 1: Usar identidad pitagórica
> 2(1 - sin²(θ)) + 3sin(θ) = 0
> 2 - 2sin²(θ) + 3sin(θ) = 0
> -2sin²(θ) + 3sin(θ) + 2 = 0
> 2sin²(θ) - 3sin(θ) - 2 = 0
> 
> Paso 2: Sustitución u = sin(θ)
> 2u² - 3u - 2 = 0
> 
> Paso 3: Factorizar
> (2u + 1)(u - 2) = 0
> 
> u = -1/2  o  u = 2
> 
> Paso 4: Resolver
> sin(θ) = -1/2 ✓ (válido)
> θ = 7π/6, 11π/6 en [0, 2π)
> 
> sin(θ) = 2 ✗ (imposible, |sin(θ)| ≤ 1)
> 
> RESPUESTA: θ ∈ {7π/6, 11π/6}
> ```
> 
> **Problema 2: sin(θ) + cos(θ) = √2**
> 
> ```
> SOLUCIÓN:
> 
> Método 1: Elevar al cuadrado
> (sin(θ) + cos(θ))² = 2
> sin²(θ) + 2sin(θ)cos(θ) + cos²(θ) = 2
> 1 + 2sin(θ)cos(θ) = 2
> sin(θ)cos(θ) = 1/2
> sin(2θ) = 1
> 
> 2θ = π/2 + 2nπ
> θ = π/4 + nπ
> 
> En [0, 2π): θ ∈ {π/4, 5π/4}
> 
> Verificación:
> θ = π/4: sin(π/4) + cos(π/4) = √2/2 + √2/2 = √2 ✓
> θ = 5π/4: sin(5π/4) + cos(5π/4) = -√2/2 - √2/2 = -√2 ✗
> 
> RESPUESTA: θ = π/4
> 
> Método 2: Conversión a una función
> √2·sin(θ + π/4) = √2
> sin(θ + π/4) = 1
> θ + π/4 = π/2
> θ = π/4 ✓
> ```
> 
> **Problema 3: tan²(θ) - 2sec(θ) = -2**
> 
> ```
> SOLUCIÓN:
> 
> Paso 1: Usar identidad tan²(θ) = sec²(θ) - 1
> sec²(θ) - 1 - 2sec(θ) = -2
> sec²(θ) - 2sec(θ) + 1 = 0
> 
> Paso 2: Factorizar (trinomio cuadrado perfecto)
> (sec(θ) - 1)² = 0
> sec(θ) = 1
> 
> Paso 3: Resolver
> 1/cos(θ) = 1
> cos(θ) = 1
> θ = 0 en [0, 2π)
> 
> Paso 4: Verificar
> θ = 0: tan²(0) - 2sec(0) = 0 - 2(1) = -2 ✓
> 
> RESPUESTA: θ = 0
> ```
> 
> **Problema 4: sin(3θ) = sin(θ)**
> 
> ```
> SOLUCIÓN:
> 
> Paso 1: Llevar todo a un lado
> sin(3θ) - sin(θ) = 0
> 
> Paso 2: Usar fórmula suma a producto
> 2cos[(3θ + θ)/2]sin[(3θ - θ)/2] = 0
> 2cos(2θ)sin(θ) = 0
> 
> Paso 3: Resolver cada factor
> cos(2θ) = 0  o  sin(θ) = 0
> 
> Para cos(2θ) = 0:
> 2θ = π/2 + nπ
> θ = π/4 + nπ/2
> En [0, 2π): θ ∈ {π/4, 3π/4, 5π/4, 7π/4}
> 
> Para sin(θ) = 0:
> θ ∈ {0, π}
> 
> RESPUESTA: θ ∈ {0, π/4, 3π/4, π, 5π/4, 7π/4}
> ```
> 
> **Problema 5: |sin(θ)| = 1/2 en [0, 2π)**
> 
> ```
> SOLUCIÓN:
> 
> |sin(θ)| = 1/2 significa:
> sin(θ) = 1/2  o  sin(θ) = -1/2
> 
> Para sin(θ) = 1/2:
> θ ∈ {π/6, 5π/6}
> 
> Para sin(θ) = -1/2:
> θ ∈ {7π/6, 11π/6}
> 
> RESPUESTA: θ ∈ {π/6, 5π/6, 7π/6, 11π/6}
> ```

## 🔬 Casos Especiales

> [!warning]- Situaciones que Requieren Atención **1. Ecuaciones sin solución:**
> 
> ```
> sin(θ) = 2
> cos(θ) = -3
> 
> Imposible: |sin(θ)| ≤ 1, |cos(θ)| ≤ 1
> Conjunto solución: ∅
> ```
> 
> **2. Identidades que parecen ecuaciones:**
> 
> ```
> sin²(θ) + cos²(θ) = 1
> 
> No es ecuación para resolver
> Es identidad verdadera para todo θ
> Solución: θ ∈ ℝ
> ```
> 
> **3. Ecuaciones con restricciones implícitas:**
> 
> ```
> tan(θ) + sec(θ) = 1
> 
> Implica: cos(θ) ≠ 0
> Soluciones deben excluir θ = π/2 + nπ
> ```
> 
> **4. Múltiples periodos:**
> 
> ```
> Para sin(nθ) en [0, 2π):
> nθ debe estar en [0, 2nπ)
> 
> Ejemplo: sin(5θ) = 0
> 5θ = kπ, k = 0, 1, ..., 9
> θ = 0, π/5, 2π/5, ..., 9π/5
> (10 soluciones)
> ```

> 
> ```
> En [0, 2π):
> - Ecuación lineal: generalmente 0, 1, o 2 soluciones

> - Ecuación con sin(nθ): hasta 2n soluciones
> - Ecuación con tan(nθ): hasta 2n soluciones

> 
> ```
> Si f(-θ) = f(θ) (función par):
> Soluciones simétricas respecto al eje y
> 
> Si f(-θ) = -f(θ) (función impar):
> Si θ₀ es solución, -θ₀ también puede serlo
> ```

## 🎓 Resumen Ejecutivo

> [!important]- Conceptos Clave para Recordar **Tipos de ecuaciones:**
> 
> - Lineales: f(θ) = k → usar funciones inversas
> - Cuadráticas: af²(θ) + bf(θ) + c = 0 → sustituir u = f(θ)
> - Múltiples funciones → usar identidades para reducir
> - Ángulos múltiples → considerar periodo ampliado
> 
> **Estrategia general:**
> 
> 1. Simplificar usando identidades
> 2. Reducir a una función si es posible
> 3. Resolver algebraicamente
> 4. Encontrar soluciones en el intervalo
> 5. Verificar todas las soluciones
> 
> **Para inecuaciones:**
> 
> - Resolver ecuación asociada (puntos críticos)
> - Analizar intervalos
> - Probar puntos de prueba
> - Expresar como unión de intervalos
> 
> **Errores a evitar:**
> 
> - Dividir por funciones trigonométricas (perder soluciones)
> - Olvidar verificar soluciones extrañas
> - No considerar periodicidad completa
> - Confundir dominio de funciones
> 
> **Verificación esencial:**
> 
> - Sustituir en ecuación original
> - Comprobar restricciones de dominio
> - Confirmar número esperado de soluciones
