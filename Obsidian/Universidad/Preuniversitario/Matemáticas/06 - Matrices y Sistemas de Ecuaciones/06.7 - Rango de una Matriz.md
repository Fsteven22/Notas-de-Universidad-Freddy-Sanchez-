# 📐 Rango de una Matriz

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **El rango de una matriz es el número de filas (o columnas) linealmente independientes. Representa la "dimensión" del espacio generado por sus vectores fila o columna, y mide cuánta información independiente contiene la matriz.**
> 
> **Características clave:**
> 
> - **Dimensión efectiva:** Filas/columnas no redundantes
> - **Información independiente:** Vectores que no se expresan como combinación de otros
> - **Rango ≤ min(m,n):** Limitado por dimensiones
> - **Conexión con sistemas:** Determina existencia de soluciones
> - **Invariante:** Operaciones elementales preservan rango

### 📖 Contexto Histórico

> [!note]- Desarrollo Histórico **Orígenes (1800-1850):**
> 
> - **Gauss (1810):** Eliminación sistemática
>     - Reduce sistemas a forma escalonada
>     - Identifica ecuaciones independientes
> - **Jacobi (1841):** Determinantes menores
>     - Concepto de rango de determinantes
> 
> **Formalización (1850-1900):**
> 
> - **Sylvester (1851):** Término "rango" (rank)
>     - Definición rigurosa
>     - Propiedades fundamentales
> - **Frobenius (1879):** Teoría sistemática
>     - Teorema de Rouché-Frobenius
>     - Rango y sistemas lineales
> 
> **Desarrollo Moderno (1900-presente):**
> 
> - **Independencia lineal:** Conexión con espacios vectoriales
> - **Descomposición en valores singulares:** Interpretación geométrica
> - **Aplicaciones:** Procesamiento señales, compresión datos

## 📝 Definición Formal

> [!success]- Definición Matemática Rigurosa **Definición:** Sea A una matriz m×n. El **rango** de A, denotado rango(A) o rank(A), es:
> 
> ```
> rango(A) = número máximo de filas linealmente independientes
>          = número máximo de columnas linealmente independientes
>          = dimensión del espacio generado por las filas (espacio fila)
>          = dimensión del espacio generado por las columnas (espacio columna)
> ```
> 
> **Definiciones equivalentes:**
> 
> ```
> 1. Rango por filas:
>    Máximo número de filas linealmente independientes
> 
> 2. Rango por columnas:
>    Máximo número de columnas linealmente independientes
> 
> 3. Rango por determinantes:
>    Orden del mayor menor no nulo
> 
> 4. Forma escalonada:
>    Número de filas no nulas en forma escalonada reducida
> ```
> 
> **Teorema fundamental:**
> 
> ```
> Rango por filas = Rango por columnas
> 
> Este resultado justifica hablar simplemente de "rango"
> ```
> 
> **Propiedades básicas:**
> 
> ```
> 0 ≤ rango(A) ≤ min(m, n)
> 
> rango(A) = 0 ⟺ A = matriz nula
> rango(A) = n ⟺ columnas linealmente independientes (rango completo por columnas)
> rango(A) = m ⟺ filas linealmente independientes (rango completo por filas)
> ```

## 🎯 Propiedades Fundamentales

> [!important]- Álgebra del Rango **P1. Rango de la transpuesta:**
> 
> ```
> rango(A) = rango(Aᵀ)
> 
> El rango es invariante bajo transposición
> ```
> 
> **P2. Producto de matrices:**
> 
> ```
> rango(AB) ≤ min(rango(A), rango(B))
> 
> El producto no puede aumentar el rango
> ```
> 
> **P3. Rango y matrices invertibles:**
> 
> ```
> Si P, Q invertibles:
> rango(PAQ) = rango(A)
> 
> Multiplicar por invertibles preserva rango
> ```
> 
> **P4. Suma de matrices:**
> 
> ```
> rango(A + B) ≤ rango(A) + rango(B)
> 
> Desigualdad triangular para rangos
> ```
> 
> **P5. Matriz cuadrada:**
> 
> ```
> Para A (n×n):
> rango(A) = n ⟺ A invertible
>             ⟺ det(A) ≠ 0
>             ⟺ A no singular
> 
> rango(A) < n ⟺ A singular
> ```
> 
> **P6. Operaciones elementales:**
> 
> ```
> Las operaciones elementales de fila/columna
> NO cambian el rango
> 
> Esto justifica usar forma escalonada
> ```

## 🔧 Métodos de Cálculo

### 1️⃣ Método de Forma Escalonada

> [!tip]- Método Estándar **Algoritmo:**
> 
> ```
> 1. Reducir A a forma escalonada por filas
> 2. Contar número de filas no nulas
> 3. Ese número es el rango
> ```
> 
> **Ejemplo:**
> 
> ```
> Calcular rango de:
> 
> A = ⎡ 1  2  3  4 ⎤
>     ⎢ 2  4  6  8 ⎥
>     ⎣ 1  2  5  6 ⎦
> 
> F₂ → F₂ - 2F₁:
> ⎡ 1  2  3  4 ⎤
> ⎢ 0  0  0  0 ⎥
> ⎣ 1  2  5  6 ⎦
> 
> F₃ → F₃ - F₁:
> ⎡ 1  2  3  4 ⎤
> ⎢ 0  0  0  0 ⎥
> ⎣ 0  0  2  2 ⎦
> 
> F₂ ↔ F₃:
> ⎡ 1  2  3  4 ⎤
> ⎢ 0  0  2  2 ⎥
> ⎣ 0  0  0  0 ⎦
> 
> Forma escalonada: 2 filas no nulas
> 
> rango(A) = 2
> ```

### 2️⃣ Método de Determinantes Menores

> [!note]- Definición por Menores **Concepto:**
> 
> ```
> Menor de orden k: determinante de submatriz k×k
> 
> rango(A) = k máximo tal que existe menor
>            de orden k no nulo
> ```
> 
> **Ejemplo:**
> 
> ```
> A = ⎡ 1  2  3 ⎤
>     ⎣ 2  4  5 ⎦
> 
> Menores 2×2:
> |1 2| = 4-4 = 0
> |2 4|
> 
> |1 3| = 5-6 = -1 ≠ 0 ✓
> |2 5|
> 
> |2 3| = 10-12 = -2 ≠ 0 ✓
> |4 5|
> 
> Existe menor 2×2 no nulo → rango(A) ≥ 2
> A es 2×3 → rango(A) ≤ 2
> 
> Por tanto: rango(A) = 2
> ```

### 3️⃣ Método por Independencia Lineal

> [!note]- Análisis Directo **Para filas:**
> 
> ```
> 1. Identificar filas linealmente independientes
> 2. Contarlas
> ```
> 
> **Ejemplo:**
> 
> ```
> A = ⎡ 1  0  2 ⎤
>     ⎢ 0  1  1 ⎥
>     ⎣ 1  1  3 ⎦
> 
> Fila 3 = Fila 1 + Fila 2:
> [1 1 3] = [1 0 2] + [0 1 1] ✓
> 
> Solo 2 filas independientes
> rango(A) = 2
> ```

## 🎯 Rango y Sistemas Lineales

> [!important]- Teorema de Rouché-Frobenius **Para sistema Ax = b:**
> 
> ```
> Sea [A|b] la matriz aumentada
> 
> 1. Sistema compatible (tiene solución) ⟺ rango(A) = rango([A|b])
> 
> 2. Si compatible:
>    • rango(A) = n → solución única
>    • rango(A) < n → infinitas soluciones
> 
> 3. Sistema incompatible ⟺ rango(A) < rango([A|b])
> ```
> 
> **Ejemplo de análisis:**
> 
> ```
> Sistema:
>  x + 2y = 3
> 2x + 4y = 6
>  x + 2y = 5
> 
> A = ⎡1 2⎤,  [A|b] = ⎡1 2 | 3⎤
>     ⎢2 4⎥            ⎢2 4 | 6⎥
>     ⎣1 2⎦            ⎣1 2 | 5⎦
> 
> Reducir [A|b]:
> ⎡1 2 | 3⎤
> ⎢0 0 | 0⎥  (F₂ - 2F₁)
> ⎣0 0 | 2⎦  (F₃ - F₁)
> 
> rango(A) = 1
> rango([A|b]) = 2
> 
> Como rango(A) ≠ rango([A|b]):
> Sistema INCOMPATIBLE (sin solución)
> ```

## 💡 Interpretación Geométrica

> [!note]- Visualización **En ℝ³:**
> 
> ```
> Matriz 3×3 con:
> 
> • rango = 3: vectores generan todo ℝ³
>   → base del espacio
> 
> • rango = 2: vectores generan un plano
>   → coplanares
> 
> • rango = 1: vectores en una recta
>   → colineales
> 
> • rango = 0: solo vector cero
> ```
> 
> **Ejemplo visual:**
> 
> ```
> A = ⎡1 0 0⎤  rango = 3
>     ⎢0 1 0⎥  (ejes coordenados)
>     ⎣0 0 1⎦
> 
> B = ⎡1 2 3⎤  rango = 1
>     ⎢2 4 6⎥  (múltiplos de [1 2 3])
>     ⎣3 6 9⎦
> ```

## 🧩 Problemas Resueltos

> [!example]- Ejemplos Detallados **Problema 1: Rango con parámetro**
> 
> ```
> Determinar rango según valores de k:
> 
> A = ⎡ 1  k  2 ⎤
>     ⎢ 2  3  k ⎥
>     ⎣ 1  1  1 ⎦
> 
> SOLUCIÓN:
> Forma escalonada:
> F₂ → F₂ - 2F₁:
> ⎡ 1    k      2   ⎤
> ⎢ 0  3-2k   k-4  ⎥
> ⎣ 1    1      1   ⎦
> 
> F₃ → F₃ - F₁:
> ⎡ 1    k      2   ⎤
> ⎢ 0  3-2k   k-4  ⎥
> ⎣ 0  1-k    -1   ⎦
> 
> Casos:
> 
> • Si 3-2k ≠ 0 (k ≠ 3/2):
>   F₃ → F₃ - [(1-k)/(3-2k)]F₂
>   Si resultado ≠ 0: rango = 3
>   Si resultado = 0: rango = 2
> 
> • Si k = 3/2:
>   F₂ se anula
>   rango = 2
> 
> [Análisis completo requiere casos específicos]
> ```
> 
> **Problema 2: Rango de producto**
> 
> ```
> Si A es 3×4 con rango(A) = 2 y
> B es 4×5 con rango(B) = 3,
> ¿qué podemos decir de rango(AB)?
> 
> SOLUCIÓN:
> Por propiedad:
> rango(AB) ≤ min(rango(A), rango(B))
> rango(AB) ≤ min(2, 3) = 2
> 
> Además, AB es 3×5, por tanto:
> rango(AB) ≤ min(3, 5) = 3
> 
> Conclusión: rango(AB) ≤ 2
> 
> No podemos determinar valor exacto,
> pero sabemos que rango(AB) ∈ {0, 1, 2}
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes **1. "Rango = número de filas (o columnas)"**
> 
> ```
> ✗ FALSO
> 
> rango ≤ min(m, n), pero puede ser menor
> 
> A = ⎡1 2⎤  tiene 3 filas pero rango = 1
>     ⎢2 4⎥
>     ⎣3 6⎦
> ```
> 
> **2. "Rango(A+B) = rango(A) + rango(B)"**
> 
> ```
> ✗ FALSO
> 
> Solo es desigualdad: rango(A+B) ≤ rango(A) + rango(B)
> 
> Ejemplo:
> A = ⎡1 0⎤, B = ⎡-1  0⎤
>     ⎣0 0⎦      ⎣ 0  1⎦
> 
> rango(A) = 1, rango(B) = 2
> A+B = ⎡0 0⎤, rango(A+B) = 1 ≠ 3
>       ⎣0 1⎦
> ```
> 
> **3. "Rango determina dimensión de la matriz"**
> 
> ```
> ✗ FALSO
> 
> Rango mide independencia, no tamaño
> Matriz 100×100 puede tener rango 1
> ```

## 🎓 Aplicaciones Prácticas

> [!note]- Contextos Reales **1. Compresión de datos:**
> 
> ```
> Matriz de rango bajo → compresión eficiente
> Aproximación de rango k: A ≈ UΣₖVᵀ
> ```
> 
> **2. Procesamiento de imágenes:**
> 
> ```
> Imagen como matriz
> Rango bajo → imagen redundante
> Reducción de rango → compresión
> ```
> 
> **3. Machine Learning:**
> 
> ```
> Matriz de características: rango completo
> → características independientes
> Rango deficiente → multicolinealidad
> ```
> 
> **4. Análisis de circuitos:**
> 
> ```
> rango(matriz de incidencia) = nodos - 1
> Verifica conectividad
> ```
