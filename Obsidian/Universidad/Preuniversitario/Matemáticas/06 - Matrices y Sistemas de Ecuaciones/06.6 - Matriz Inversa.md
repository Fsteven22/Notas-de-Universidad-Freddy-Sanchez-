# 🔄 Matriz Inversa

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **La matriz inversa es el equivalente matricial del recíproco de un número. Así como 5 × (1/5) = 1, una matriz A multiplicada por su inversa A⁻¹ da la matriz identidad. La inversa "deshace" o "revierte" la transformación que representa la matriz original.**
> 
> **Características clave:**
> 
> - **Analogía numérica:** A⁻¹ es como 1/A
> - **Propiedad fundamental:** A·A⁻¹ = A⁻¹·A = I
> - **Existencia limitada:** Solo matrices cuadradas no singulares
> - **Unicidad:** Si existe, es única
> - **Aplicación:** Resolver sistemas Ax = b como x = A⁻¹b

### 📖 Contexto Histórico

> [!note]- Desarrollo Histórico **Orígenes (1750-1850):**
> 
> - **Cramer (1750):** Soluciones explícitas de sistemas
>     - Fórmulas con determinantes
>     - Precursor del concepto de inversa
> - **Cauchy (1812):** Propiedades de determinantes
>     - Condición det(A) ≠ 0 para invertibilidad
> 
> **Formalización (1850-1900):**
> 
> - **Cayley (1858):** "Memoir on the Theory of Matrices"
>     - Define operaciones matriciales formalmente
>     - Concepto explícito de matriz inversa
>     - Notación A⁻¹
> - **Sylvester (1850s):** Matriz adjunta
>     - Fórmula A⁻¹ = (1/det(A))·adj(A)
> - **Frobenius (1878):** Teoría sistemática
> 
> **Desarrollo Moderno (1900-presente):**
> 
> - **Algoritmos computacionales:** Gauss-Jordan
> - **Factorización:** LU, QR para cálculo eficiente
> - **Aplicaciones:** Criptografía, gráficos, control
> - **Pseudoinversa (Moore-Penrose):** Generalización a matrices no cuadradas

## 📐 Definición Formal

> [!success]- Definición Matemática Rigurosa **Definición:** Sea A una matriz cuadrada de orden n×n. La **matriz inversa** de A, denotada A⁻¹, es la matriz que satisface:
> 
> ```
> A·A⁻¹ = A⁻¹·A = I
> 
> donde I es la matriz identidad n×n
> ```
> 
> **Condición de existencia:**
> 
> ```
> A tiene inversa ⟺ A es invertible (no singular)
>                 ⟺ det(A) ≠ 0
>                 ⟺ rango(A) = n
>                 ⟺ Las columnas (filas) de A son linealmente independientes
> ```
> 
> **Unicidad:**
> 
> ```
> Si A⁻¹ existe, entonces es única
> 
> Demostración:
> Supongamos B y C son inversas de A:
> AB = BA = I
> AC = CA = I
> 
> Entonces: B = BI = B(AC) = (BA)C = IC = C
> Por tanto: B = C (única)
> ```
> 
> **Terminología:**
> 
> ```
> - Matriz invertible = no singular = regular
> - Matriz no invertible = singular
> ```

## 🎯 Propiedades Fundamentales

> [!important]- Álgebra de Inversas **P1. Inversa de la inversa:**
> 
> ```
> (A⁻¹)⁻¹ = A
> 
> La inversa es una operación involutiva
> ```
> 
> **P2. Inversa del producto:**
> 
> ```
> (AB)⁻¹ = B⁻¹A⁻¹
> 
> ¡El orden se invierte!
> 
> Generalización:
> (A₁A₂...Aₙ)⁻¹ = Aₙ⁻¹...A₂⁻¹A₁⁻¹
> ```
> 
> **P3. Inversa de la transpuesta:**
> 
> ```
> (Aᵀ)⁻¹ = (A⁻¹)ᵀ
> 
> Se pueden intercambiar las operaciones
> ```
> 
> **P4. Inversa de múltiplo escalar:**
> 
> ```
> (kA)⁻¹ = (1/k)A⁻¹    (k ≠ 0)
> ```
> 
> **P5. Determinante de la inversa:**
> 
> ```
> det(A⁻¹) = 1/det(A)
> 
> Porque: det(A)·det(A⁻¹) = det(AA⁻¹) = det(I) = 1
> ```
> 
> **P6. Inversa de potencias:**
> 
> ```
> (Aⁿ)⁻¹ = (A⁻¹)ⁿ = A⁻ⁿ
> 
> Notación: A⁻ⁿ significa (A⁻¹)ⁿ
> ```

## 🔧 Métodos de Cálculo

### 1️⃣ Matrices 2×2 (Fórmula Directa)

> [!tip]- Caso Especial **Fórmula para matriz 2×2:**
> 
> ```
> A = ⎡ a  b ⎤
>     ⎣ c  d ⎦
> 
> A⁻¹ = 1/(ad-bc) · ⎡  d  -b ⎤
>                    ⎣ -c   a ⎦
> 
> donde ad - bc = det(A) ≠ 0
> ```
> 
> **Algoritmo:**
> 
> ```
> 1. Calcular det(A) = ad - bc
> 2. Si det(A) = 0 → no existe inversa
> 3. Si det(A) ≠ 0:
>    - Intercambiar elementos diagonales: a ↔ d
>    - Cambiar signo a elementos no diagonales: b → -b, c → -c
>    - Dividir todo entre det(A)
> ```
> 
> **Ejemplo:**
> 
> ```
> A = ⎡ 3  1 ⎤
>     ⎣ 5  2 ⎦
> 
> det(A) = 3·2 - 1·5 = 6 - 5 = 1
> 
> A⁻¹ = 1/1 · ⎡  2  -1 ⎤ = ⎡  2  -1 ⎤
>             ⎣ -5   3 ⎦   ⎣ -5   3 ⎦
> 
> Verificación:
> AA⁻¹ = ⎡ 3  1 ⎤⎡  2  -1 ⎤ = ⎡ 6-5   -3+3  ⎤ = ⎡ 1  0 ⎤ = I ✓
>        ⎣ 5  2 ⎦⎣ -5   3 ⎦   ⎣10-10  -5+6  ⎦   ⎣ 0  1 ⎦
> ```

### 2️⃣ Método de Gauss-Jordan

> [!important]- Método General y Eficiente **Idea:** Reducir [A|I] a [I|A⁻¹]
> 
> **Algoritmo:**
> 
> ```
> 1. Formar matriz aumentada: [A | I]
> 2. Aplicar operaciones elementales de fila para transformar:
>    - Lado izquierdo (A) → Identidad (I)
>    - Lado derecho (I) → se transforma en A⁻¹
> 3. Si se logra [I | B], entonces B = A⁻¹
> 4. Si en algún momento hay fila de ceros en lado izquierdo:
>    → A no es invertible
> ```
> 
> **Operaciones elementales permitidas:**
> 
> ```
> 1. Intercambiar filas: Fᵢ ↔ Fⱼ
> 2. Multiplicar fila por k≠0: Fᵢ → kFᵢ
> 3. Sumar múltiplo de fila: Fᵢ → Fᵢ + kFⱼ
> ```
> 
> **Ejemplo completo 3×3:**
> 
> ```
> Encontrar la inversa de:
> 
> A = ⎡ 1  2  3 ⎤
>     ⎢ 0  1  4 ⎥
>     ⎣ 5  6  0 ⎦
> 
> PASO 1: Formar [A|I]
> ⎡ 1  2  3 | 1  0  0 ⎤
> ⎢ 0  1  4 | 0  1  0 ⎥
> ⎣ 5  6  0 | 0  0  1 ⎦
> 
> PASO 2: Hacer ceros debajo del primer pivote (1,1)
> F₃ → F₃ - 5F₁:
> ⎡ 1  2   3 | 1   0  0 ⎤
> ⎢ 0  1   4 | 0   1  0 ⎥
> ⎣ 0 -4 -15 |-5   0  1 ⎦
> 
> PASO 3: Hacer ceros debajo del segundo pivote (2,2)
> F₃ → F₃ + 4F₂:
> ⎡ 1  2   3 | 1   0  0 ⎤
> ⎢ 0  1   4 | 0   1  0 ⎥
> ⎣ 0  0   1 |-5   4  1 ⎦
> 
> PASO 4: Hacer ceros encima del tercer pivote (3,3)
> F₂ → F₂ - 4F₃:
> ⎡ 1  2   3 |  1    0   0 ⎤
> ⎢ 0  1   0 | 20  -15  -4 ⎥
> ⎣ 0  0   1 | -5    4   1 ⎦
> 
> F₁ → F₁ - 3F₃:
> ⎡ 1  2   0 | 16  -12  -3 ⎤
> ⎢ 0  1   0 | 20  -15  -4 ⎥
> ⎣ 0  0   1 | -5    4   1 ⎦
> 
> PASO 5: Hacer ceros encima del segundo pivote (2,2)
> F₁ → F₁ - 2F₂:
> ⎡ 1  0   0 |-24   18   5 ⎤
> ⎢ 0  1   0 | 20  -15  -4 ⎥
> ⎣ 0  0   1 | -5    4   1 ⎦
> 
> RESULTADO:
> A⁻¹ = ⎡-24   18   5 ⎤
>       ⎢ 20  -15  -4 ⎥
>       ⎣ -5    4   1 ⎦
> 
> VERIFICACIÓN (multiplicar A·A⁻¹):
> Primera fila de AA⁻¹:
> [1 2 3]·⎡-24⎤ = -24 + 40 - 15 = 1 ✓
>         ⎢ 20⎥
>         ⎣ -5⎦
> [1 2 3]·⎡ 18⎤ = 18 - 30 + 12 = 0 ✓
>         ⎢-15⎥
>         ⎣  4⎦
> [1 2 3]·⎡ 5⎤ = 5 - 8 + 3 = 0 ✓
>         ⎢-4⎥
>         ⎣ 1⎦
> [Continuar verificando otras filas...]
> ```

### 3️⃣ Método de la Matriz Adjunta

> [!note]- Fórmula con Cofactores **Fórmula:**
> 
> ```
> A⁻¹ = (1/det(A)) · adj(A)
> 
> donde adj(A) = [Cᵢⱼ]ᵀ (transpuesta de matriz de cofactores)
> ```
> 
> **Definiciones:**
> 
> ```
> Menor Mᵢⱼ: determinante de submatriz al eliminar fila i, columna j
> 
> Cofactor Cᵢⱼ = (-1)^(i+j) · Mᵢⱼ
> 
> Matriz de cofactores: [Cᵢⱼ]
> 
> Matriz adjunta (o adjugada): adj(A) = [Cᵢⱼ]ᵀ
> ```
> 
> **Algoritmo:**
> 
> ```
> 1. Verificar det(A) ≠ 0
> 2. Calcular todos los cofactores Cᵢⱼ
> 3. Formar matriz de cofactores [Cᵢⱼ]
> 4. Transponer: adj(A) = [Cᵢⱼ]ᵀ
> 5. Calcular: A⁻¹ = (1/det(A)) · adj(A)
> ```
> 
> **Ejemplo 3×3:**
> 
> ```
> A = ⎡ 1  0  2 ⎤
>     ⎢ 2  1  0 ⎥
>     ⎣ 0  1  1 ⎦
> 
> PASO 1: det(A)
> det(A) = 1|1 0| - 0 + 2|2 1|
>           |1 1|       |0 1|
>        = 1(1-0) + 2(2-0)
>        = 1 + 4 = 5 ≠ 0 ✓ (invertible)
> 
> PASO 2: Calcular cofactores
> 
> C₁₁ = (+)|1 0| = 1-0 = 1
>          |1 1|
> 
> C₁₂ = (-)|2 0| = -(2-0) = -2
>          |0 1|
> 
> C₁₃ = (+)|2 1| = 2-0 = 2
>          |0 1|
> 
> C₂₁ = (-)|0 2| = -(0-2) = 2
>          |1 1|
> 
> C₂₂ = (+)|1 2| = 1-0 = 1
>          |0 1|
> 
> C₂₃ = (-)|1 0| = -(1-0) = -1
>          |0 1|
> 
> C₃₁ = (+)|0 2| = 0-2 = -2
>          |1 0|
> 
> C₃₂ = (-)|1 2| = -(0-4) = 4
>          |2 0|
> 
> C₃₃ = (+)|1 0| = 1-0 = 1
>          |2 1|
> 
> PASO 3: Matriz de cofactores
> [Cᵢⱼ] = ⎡  1  -2   2 ⎤
>         ⎢  2   1  -1 ⎥
>         ⎣ -2   4   1 ⎦
> 
> PASO 4: Transponer
> adj(A) = ⎡  1   2  -2 ⎤
>          ⎢ -2   1   4 ⎥
>          ⎣  2  -1   1 ⎦
> 
> PASO 5: Calcular inversa
> A⁻¹ = (1/5) · ⎡  1   2  -2 ⎤
>               ⎢ -2   1   4 ⎥
>               ⎣  2  -1   1 ⎦
> 
>     = ⎡ 1/5   2/5  -2/5 ⎤
>       ⎢-2/5   1/5   4/5 ⎥
>       ⎣ 2/5  -1/5   1/5 ⎦
> ```
> 
> **Nota:** Este método es teóricamente elegante pero computacionalmente ineficiente para n>3. Usar Gauss-Jordan en la práctica.

### 4️⃣ Método de Factorización LU

> [!note]- Para Múltiples Sistemas **Idea:** Si A = LU, entonces:
> 
> ```
> Para resolver AA⁻¹ = I columna por columna:
> 
> Para cada columna eⱼ de I:
>   1. Resolver Ly = eⱼ  (sustitución progresiva)
>   2. Resolver Ux = y   (sustitución regresiva)
>   3. x es la columna j de A⁻¹
> ```
> 
> **Ventaja:** Eficiente si ya se tiene factorización LU

## 🎯 Matrices Especiales y sus Inversas

### 1️⃣ Matriz Diagonal

> [!tip]- Inversión Trivial
> 
> ```
> D = diag(d₁, d₂, ..., dₙ)
> 
> D⁻¹ = diag(1/d₁, 1/d₂, ..., 1/dₙ)
> 
> Existe ⟺ todos dᵢ ≠ 0
> ```
> 
> **Ejemplo:**
> 
> ```
> D = ⎡ 2  0  0 ⎤
>     ⎢ 0  5  0 ⎥
>     ⎣ 0  0  4 ⎦
> 
> D⁻¹ = ⎡1/2   0    0  ⎤
>       ⎢ 0   1/5   0  ⎥
>       ⎣ 0    0   1/4 ⎦
> 
> Verificación: D·D⁻¹ = I ✓
> ```

### 2️⃣ Matriz Triangular

> [!note]- Sustitución Directa
> 
> ```
> Triangular superior U:
> U⁻¹ también es triangular superior
> 
> Triangular inferior L:
> L⁻¹ también es triangular inferior
> 
> Elementos diagonales: (U⁻¹)ᵢᵢ = 1/uᵢᵢ
> ```
> 
> **Método:** Resolver UX = I usando sustitución regresiva

### 3️⃣ Matriz Ortogonal

> [!important]- Inversa es la Transpuesta
> 
> ```
> Q ortogonal: QᵀQ = I
> 
> Por tanto: Q⁻¹ = Qᵀ
> 
> ¡Inversión trivial!
> ```
> 
> **Ejemplo:**
> 
> ```
> Q = ⎡cos θ  -sin θ⎤  (matriz de rotación)
>     ⎣sin θ   cos θ⎦
> 
> Q⁻¹ = Qᵀ = ⎡ cos θ   sin θ⎤
>            ⎣-sin θ   cos θ⎦
> 
> Representa rotación en sentido opuesto (-θ)
> ```

### 4️⃣ Matriz Simétrica Definida Positiva

> [!note]- Siempre Invertible
> 
> ```
> A simétrica definida positiva:
> - Siempre invertible (det(A) > 0)
> - A⁻¹ también es simétrica definida positiva
> - Método eficiente: Factorización de Cholesky
> ```

### 5️⃣ Matriz Identidad y Escalar

> [!note]- Casos Triviales
> 
> ```
> I⁻¹ = I  (identidad es su propia inversa)
> 
> (kI)⁻¹ = (1/k)I  (k ≠ 0)
> ```

## 💡 Aplicaciones de la Matriz Inversa

### 1️⃣ Resolución de Sistemas Lineales

> [!important]- Método Directo
> 
> ```
> Sistema: Ax = b
> 
> Si det(A) ≠ 0:
>   x = A⁻¹b
> 
> Solución única
> ```
> 
> **Ejemplo:**
> 
> ```
> 2x + y = 5
> x + 3y = 8
> 
> A = ⎡2 1⎤, b = ⎡5⎤
>     ⎣1 3⎦      ⎣8⎦
> 
> det(A) = 6 - 1 = 5
> 
> A⁻¹ = (1/5)⎡ 3  -1⎤
>            ⎣-1   2⎦
> 
> x = A⁻¹b = (1/5)⎡ 3  -1⎤⎡5⎤
>                 ⎣-1   2⎦⎣8⎦
> 
>   = (1/5)⎡15-8⎤ = ⎡7/5⎤ = ⎡1.4⎤
>          ⎣-5+16⎦   ⎣11/5⎦   ⎣2.2⎦
> 
> Solución: x = 1.4, y = 2.2
> ```
> 
> **Nota práctica:** Para un solo sistema, Gauss es más eficiente que calcular A⁻¹

### 2️⃣ Cambio de Base

> [!note]- Transformación de Coordenadas
> 
> ```
> Vector v en base B₁: [v]_{B₁}
> Vector v en base B₂: [v]_{B₂}
> 
> Matriz de cambio: P
> 
> [v]_{B₂} = P⁻¹[v]_{B₁}
> ```

### 3️⃣ Criptografía

> [!example]- Cifrado de Hill
> 
> ```
> Mensaje: M (matriz)
> Clave: K (matriz invertible)
> 
> Cifrado: C = KM
> Descifrado: M = K⁻¹C
> 
> Seguridad: necesita conocer K⁻¹
> ```

### 4️⃣ Gráficos por Computadora

> [!note]- Transformaciones
> 
> ```
> Aplicar transformación: v' = Av
> Deshacer transformación: v = A⁻¹v'
> 
> Composición de transformaciones:
> T = T₁T₂T₃
> T⁻¹ = T₃⁻¹T₂⁻¹T₁⁻¹
> ```

### 5️⃣ Regresión y Estadística

> [!note]- Mínimos Cuadrados
> 
> ```
> Ecuaciones normales: AᵀAx = Aᵀb
> 
> Solución: x = (AᵀA)⁻¹Aᵀb
> 
> (AᵀA)⁻¹Aᵀ llamada pseudoinversa de Moore-Penrose
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes **1. "La inversa siempre existe"**
> 
> ```
> ✗ FALSO
> 
> Solo matrices cuadradas con det(A) ≠ 0
> 
> Contraejemplo:
> A = ⎡1 2⎤  det(A) = 2-2 = 0
>     ⎣1 2⎦
> No tiene inversa
> ```
> 
> **2. "(A+B)⁻¹ = A⁻¹ + B⁻¹"**
> 
> ```
> ✗ FALSO
> 
> La inversa NO distribuye sobre la suma
> 
> Contraejemplo:
> A = ⎡2 0⎤, B = ⎡1 0⎤
>     ⎣0 2⎦      ⎣0 1⎦
> 
> (A+B)⁻¹ = ⎡3 0⎤⁻¹ = ⎡1/3  0 ⎤
>           ⎣0 3⎦      ⎣ 0  1/3⎦
> 
> A⁻¹+B⁻¹ = ⎡1/2 0⎤ + ⎡1 0⎤ = ⎡3/2 0⎤
>           ⎣ 0 1/2⎦   ⎣0 1⎦   ⎣ 0 3/2⎦
> 
> (A+B)⁻¹ ≠ A⁻¹ + B⁻¹
> ```
> 
> **3. "(AB)⁻¹ = A⁻¹B⁻¹"**
> 
> ```
> ✗ FALSO (orden incorrecto)
> ✓ (AB)⁻¹ = B⁻¹A⁻¹
> 
> El orden se invierte
> ```
> 
> **4. "A⁻¹ = 1/A"**
> 
> ```
> ✗ NO TIENE SENTIDO
> 
> No se puede "dividir entre una matriz"
> A⁻¹ es la matriz que satisface AA⁻¹ = I
> ```
> 
> **5. "Calcular A⁻¹ siempre es eficiente para resolver Ax=b"**
> 
> ```
> ✗ FALSO
> 
> Para un solo sistema: Gauss es más eficiente O(n³)
> Calcular A⁻¹: también O(n³) pero con mayor constante
> 
> ✓ A⁻¹ útil si se resuelven múltiples sistemas con misma A
> ```

## 🔍 Condicionamiento y Estabilidad

> [!warning]- Problemas Numéricos **Número de condición:**
> 
> ```
> κ(A) = ||A|| · ||A⁻¹||
> 
> - κ(A) ≈ 1: bien condicionada
> - κ(A) >> 1: mal condicionada
> - κ(A) = ∞: singular
> ```
> 
> **Matriz mal condicionada:**
> 
> ```
> Pequeños errores en A o b causan
> grandes errores en x = A⁻¹b
> 
> Ejemplo (Matriz de Hilbert):
> H = ⎡1    1/2  1/3⎤
>     ⎢1/2  1/3  1/4⎥
>     ⎣1/3  1/4  1/5⎦
> 
> κ(H) muy grande → problemas numéricos
> ```
> 
> **Recomendaciones:**
> 
> ```
> - Usar pivoteo parcial en Gauss-Jordan
> - Factorización QR más estable que LU
> - Regularización para matrices mal condicionadas
> - Evitar calcular A⁻¹ si κ(A) es muy grande
> ```

## 📊 Comparación de Métodos

> [!note]- Tabla Comparativa
> 
> |Método|Complejidad|Ventajas|Desventajas|Mejor para|
> |---|---|---|---|---|
> |**Fórmula 2×2**|O(1)|Inmediata|Solo 2×2|Matrices pequeñas|
> |**Gauss-Jordan**|O(n³)|General, estable|-|Uso general|
> |**Adjunta/Cofactores**|O(n!)|Teóricamente elegante|Muy ineficiente|n≤3, teoría|
> |**Factorización LU**|O(n³)|Múltiples sistemas|Requiere factorización|Varios b|

## 🧩 Problemas Resueltos Detallados

> [!example]- Soluciones Paso a Paso **Problema 1: Inversa 2×2**
> 
> 
> Calcular la inversa de:
> A = ⎡ 4  7 ⎤
>     ⎣ 2  6 ⎦
> ```
> SOLUCIÓN:
> 
> det(A) = 4·6 - 7·2 = 24 - 14 = 10 ≠ 0 ✓
> 
> A⁻¹ = (1/10)⎡  6  -7 ⎤
>             ⎣ -2   4 ⎦
> 
>     = ⎡ 0.6  -0.7 ⎤
>       ⎣-0.2   0.4 ⎦
> 
> VERIFICACIÓN: AA⁻¹ = ⎡ 4 7 ⎤⎡ 0.6 -0.7 ⎤ ⎣ 2 6 ⎦⎣-0.2 0.4 ⎦
> 
> 
>  = ⎡2.4-1.4  -2.8+2.8⎤ = ⎡1 0⎤ = I ✓
>    ⎣1.2-1.2  -1.4+2.4⎦   ⎣0 1⎦
> ```
> 
> 
> 
> **Problema 2: Gauss-Jordan completo**
> ```
> 
> Calcular la inversa usando Gauss-Jordan:
> 
> A = ⎡ 2 1 1 ⎤ ⎢ 1 2 1 ⎥ ⎣ 1 1 2 ⎦
> 
> SOLUCIÓN:
> 
> Formar [A|I]: ⎡ 2 1 1 | 1 0 0 ⎤ ⎢ 1 2 1 | 0 1 0 ⎥ ⎣ 1 1 2 | 0 0 1 ⎦
>

## 🔢 Pseudoinversa (Generalización)

> [!note]- Matriz de Moore-Penrose **Motivación:** Extender concepto de inversa a matrices no cuadradas
> 
> **Definición:**
> 
> ```
> Para matriz A (m×n), la pseudoinversa A⁺ (n×m) satisface:
> 
> 1. AA⁺A = A
> 2. A⁺AA⁺ = A⁺
> 3. (AA⁺)ᵀ = AA⁺
> 4. (A⁺A)ᵀ = A⁺A
> ```
> 
> **Cálculo (caso rango completo):**
> 
> ```
> Si A tiene rango completo por columnas (m > n, rango = n):
> A⁺ = (AᵀA)⁻¹Aᵀ
> 
> Si A tiene rango completo por filas (m < n, rango = m):
> A⁺ = Aᵀ(AAᵀ)⁻¹
> 
> Si A cuadrada e invertible:
> A⁺ = A⁻¹
> ```
> 
> **Aplicación:**
> 
> ```
> Solución de mínimos cuadrados:
> Minimizar ||Ax - b||²
> 
> Solución: x = A⁺b
> ```

## 🎯 Resumen Ejecutivo

> [!important]- Conceptos Clave para Recordar **Definición:**
> 
> - A⁻¹ satisface: AA⁻¹ = A⁻¹A = I
> - Solo matrices cuadradas con det(A) ≠ 0
> - Única si existe
> 
> **Criterio de existencia:**
> 
> ```
> A invertible ⟺ det(A) ≠ 0
>              ⟺ rango(A) = n
>              ⟺ columnas linealmente independientes
> ```
> 
> **Propiedades fundamentales:**
> 
> - (A⁻¹)⁻¹ = A
> - (AB)⁻¹ = B⁻¹A⁻¹ (orden invertido)
> - (Aᵀ)⁻¹ = (A⁻¹)ᵀ
> - det(A⁻¹) = 1/det(A)
> 
> **Métodos de cálculo:**
> 
> - 2×2: Fórmula directa
> - General: Gauss-Jordan [A|I] → [I|A⁻¹]
> - Teórico: A⁻¹ = (1/det(A))·adj(A)
> 
> **Aplicaciones principales:**
> 
> - Resolver sistemas: x = A⁻¹b
> - Cambio de base
> - Criptografía
> - Deshacer transformaciones
> 
> **Advertencias:**
> 
> - No toda matriz tiene inversa
> - (A+B)⁻¹ ≠ A⁻¹ + B⁻¹
> - Calcular A⁻¹ no siempre es lo más eficiente
> - Cuidado con matrices mal condicionadas

## 📈 Teoremas Importantes

> [!important]- Resultados Fundamentales **Teorema 1: Unicidad de la inversa**
> 
> ```
> Si B y C son inversas de A, entonces B = C
> 
> Demostración:
> AB = I y CA = I
> B = IB = (CA)B = C(AB) = CI = C
> ```
> 
> **Teorema 2: Inversa del producto**
> 
> ```
> Si A y B son invertibles, entonces AB es invertible y:
> (AB)⁻¹ = B⁻¹A⁻¹
> 
> Demostración:
> (AB)(B⁻¹A⁻¹) = A(BB⁻¹)A⁻¹ = AIA⁻¹ = AA⁻¹ = I
> (B⁻¹A⁻¹)(AB) = B⁻¹(A⁻¹A)B = B⁻¹IB = B⁻¹B = I
> ```
> 
> **Teorema 3: Matriz invertible y sistemas**
> 
> ```
> Las siguientes afirmaciones son equivalentes para A (n×n):
> 
> 1. A es invertible
> 2. det(A) ≠ 0
> 3. rango(A) = n
> 4. Las columnas de A son linealmente independientes
> 5. Las filas de A son linealmente independientes
> 6. Ax = 0 tiene solo la solución trivial x = 0
> 7. Ax = b tiene solución única para todo b
> 8. A es producto de matrices elementales
> 9. A puede reducirse a I por operaciones elementales
> 10. Los eigenvalores de A son todos no nulos
> ```
> 
> **Teorema 4: Determinante e inversa**
> 
> ```
> Si A es invertible:
> det(A⁻¹) = 1/det(A)
> 
> Corolario: det(A) ≠ 0 es necesario para invertibilidad
> ```
> 
> **Teorema 5: Transpuesta e inversa**
> 
> ```
> Si A es invertible:
> (Aᵀ)⁻¹ = (A⁻¹)ᵀ
> 
> Demostración:
> Aᵀ(A⁻¹)ᵀ = (A⁻¹A)ᵀ = Iᵀ = I
> (A⁻¹)ᵀAᵀ = (AA⁻¹)ᵀ = Iᵀ = I
> ```

>        ⎣C  D⎦
> 
> M⁻¹ = ⎡    A⁻¹ + A⁻¹B(D-CA⁻¹B)⁻¹CA⁻¹    -A⁻¹B(D-CA⁻¹B)⁻¹     ⎤
>       ⎣     -(D-CA⁻¹B)⁻¹CA⁻¹              (D-CA⁻¹B)⁻¹         ⎦
> 
> donde S = D - CA⁻¹B es el complemento de Schur
> ```
> 
> **Caso especial (B o C nulos):**
> 
> ```
> Si M = ⎡A  O⎤ entonces M⁻¹ = ⎡A⁻¹   O  ⎤
>        ⎣C  D⎦              ⎣ X   D⁻¹⎦
> 
> donde X = -D⁻¹CA⁻¹
> ```

### 2️⃣ Lema de Inversión de Matrices (Sherman-Morrison)

> [!tip]- Actualización de Rango 1 **Fórmula:**
> 
> ```
> Si A invertible y u, v vectores columna:
> 
> (A + uvᵀ)⁻¹ = A⁻¹ - (A⁻¹uvᵀA⁻¹)/(1 + vᵀA⁻¹u)
> 
> siempre que 1 + vᵀA⁻¹u ≠ 0
> ```
> 
> **Aplicación:**
> 
> ```
> Actualizar A⁻¹ eficientemente cuando A cambia
> por modificación de rango bajo
> 
> Útil en optimización y estadística
> ```

### 3️⃣ Fórmula de Woodbury

> [!note]- Generalización Sherman-Morrison **Fórmula:**
> 
> ```
> (A + UVᵀ)⁻¹ = A⁻¹ - A⁻¹U(I + VᵀA⁻¹U)⁻¹VᵀA⁻¹
> 
> donde U y V son matrices n×k
> ```
> 
> **Uso:** Inversión eficiente de actualizaciones de bajo rango

### 4️⃣ Derivada de la Inversa

> [!note]- Cálculo Matricial **Fórmula:**
> 
> ```
> Si A(t) es matriz invertible que depende de t:
> 
> d/dt[A⁻¹(t)] = -A⁻¹(t)·[dA/dt]·A⁻¹(t)
> ```
> 
> **Aplicación en optimización continua**

## 🎨 Visualización Geométrica

> [!note]- Interpretación Visual **En ℝ²:**
> 
> ```
> Matriz A: transformación lineal
> - Escala, rota, refleja, sesga
> 
> Matriz A⁻¹: transformación inversa
> - "Deshace" lo que hizo A
> 
> Si A lleva (1,0) → (a,c) y (0,1) → (b,d)
> Entonces A⁻¹ lleva (a,c) → (1,0) y (b,d) → (0,1)
> ```
> 
> **Determinante:**
> 
> ```
> |det(A)| = factor de escala de áreas
> |det(A⁻¹)| = 1/|det(A)| = factor de escala inverso
> 
> A expande área por factor k
> A⁻¹ contrae área por factor 1/k
> ```
> 
> **Ejemplo visual:**
> 
> ```
> A = ⎡2 0⎤  (escala x por 2, y por 3)
>     ⎣0 3⎦
> 
> A⁻¹ = ⎡1/2  0 ⎤  (contrae x por 2, y por 3)
>       ⎣ 0  1/3⎦
> 
> det(A) = 6   (expande áreas ×6)
> det(A⁻¹) = 1/6 (contrae áreas ÷6)
> ```

## 🧮 Cálculo Numérico Avanzado

> [!warning]- Consideraciones Prácticas **Estabilidad numérica:**
> 
> ```
> 1. Evitar inversión explícita cuando sea posible
>    - Para Ax = b: usar solve(A, b) no inv(A) @ b
> 
> 2. Usar pivoteo en Gauss-Jordan
>    - Parcial: intercambiar filas
>    - Total: intercambiar filas y columnas
> 
> 3. Factorizaciones estables:
>    - QR más estable que LU
>    - SVD la más estable (pero más costosa)
> ```
> 
> **Matrices mal condicionadas:**
> 
> ```
> Número de condición grande (κ(A) >> 1):
> 
> - Pequeños errores → grandes variaciones en A⁻¹
> - Regularización: A + εI (añadir pequeña diagonal)
> - Truncated SVD: eliminar valores singulares pequeños
> ```
> 
> **Cuándo NO calcular la inversa:**
> 
> ```
> ✗ Para resolver un solo sistema Ax = b
>   Mejor: eliminación gaussiana O(n³)
>   Inversa: también O(n³) pero con mayor constante
> 
> ✓ Calcular inversa si:
>   - Múltiples sistemas con misma A
>   - Necesitas A⁻¹ explícitamente
>   - n pequeño (n < 100)
> ```

## 🎯 Problemas Desafiantes

> [!example]- Nivel Experto **Problema 1: Matriz con parámetro**
> 
> ```
> Para qué valores de α la matriz es invertible:
> 
> A = ⎡ 1    2    α  ⎤
>     ⎢ 0    α    2  ⎥
>     ⎣ α    0    1  ⎦
> 
> SOLUCIÓN:
> Calcular det(A):
> det(A) = 1·|α 2| - 2·|0 2| + α·|0 α|
>             |0 1|    |α 1|    |α 0|
> 
>        = 1(α·1 - 2·0) - 2(0·1 - 2·α) + α(0·0 - α·α)
>        = α - 2(-2α) + α(-α²)
>        = α + 4α - α³
>        = 5α - α³
>        = α(5 - α²)
>        = α(√5 - α)(√5 + α)
> 
> A invertible ⟺ det(A) ≠ 0
>              ⟺ α ≠ 0, α ≠ ±√5
> 
> RESPUESTA: α ∈ ℝ \ {0, -√5, √5}
> ```
> 
> **Problema 2: Ecuación matricial**
> 
> ```
> Resolver para X:
> AX + B = C
> 
> donde A = ⎡2 1⎤, B = ⎡1 0⎤, C = ⎡3 2⎤
>           ⎣1 1⎦      ⎣0 1⎦      ⎣2 2⎦
> 
> SOLUCIÓN:
> AX = C - B
> X = A⁻¹(C - B)
> 
> C - B = ⎡3 2⎤ - ⎡1 0⎤ = ⎡2 2⎤
>         ⎣2 2⎦   ⎣0 1⎦   ⎣2 1⎦
> 
> Calcular A⁻¹:
> det(A) = 2·1 - 1·1 = 1
> 
> A⁻¹ = ⎡ 1  -1⎤
>       ⎣-1   2⎦
> 
> X = ⎡ 1  -1⎤⎡2 2⎤ = ⎡ 2-2   2-1 ⎤ = ⎡0 1⎤
>     ⎣-1   2⎦⎣2 1⎦   ⎣-2+4  -2+2 ⎦   ⎣2 0⎦
> 
> VERIFICACIÓN:
> AX + B = ⎡2 1⎤⎡0 1⎤ + ⎡1 0⎤
>          ⎣1 1⎦⎣2 0⎦   ⎣0 1⎦
> 
>        = ⎡0+2  2+0⎤ + ⎡1 0⎤ = ⎡3 2⎤ = C ✓
>          ⎣0+2  1+0⎦   ⎣0 1⎦   ⎣2 2⎦
> ```
> 
> **Problema 3: Demostración**
> 
> ```
> Demostrar: Si A² = A (idempotente) y A invertible,
>            entonces A = I
> 
> DEMOSTRACIÓN:
> Dado: A² = A y A invertible (existe A⁻¹)
> 
> Multiplicar ambos lados por A⁻¹:
> A⁻¹A² = A⁻¹A
> (A⁻¹A)A = I
> IA = I
> A = I
> 
> Por tanto, la única matriz idempotente invertible
> es la identidad. ∎
> ```
> 
> **Problema 4: Matriz ortogonal**
> 
> ```
> Demostrar que si Q es ortogonal y λ es eigenvalor de Q,
> entonces |λ| = 1
> 
> DEMOSTRACIÓN:
> Q ortogonal: QᵀQ = I
> λ eigenvalor: Qv = λv para algún v ≠ 0
> 
> ||Qv||² = ||λv||² = |λ|²||v||²
> 
> Pero también:
> ||Qv||² = (Qv)ᵀ(Qv) = vᵀQᵀQv = vᵀIv = vᵀv = ||v||²
> 
> Por tanto:
> |λ|²||v||² = ||v||²
> |λ|² = 1
> |λ| = 1 ∎
> 
> Los eigenvalores de matrices ortogonales tienen módulo 1
> ```

## 🎓 Conceptos Clave - Mapa Mental

> [!important]- Estructura Conceptual
> 
> ```
> MATRIZ INVERSA (A⁻¹)
> │
> ├─── DEFINICIÓN
> │    ├─ AA⁻¹ = A⁻¹A = I
> │    ├─ Solo matrices cuadradas
> │    └─ Única si existe
> │
> ├─── EXISTENCIA
> │    ├─ det(A) ≠ 0
> │    ├─ rango(A) = n
> │    └─ Columnas linealmente independientes
> │
> ├─── PROPIEDADES
> │    ├─ (A⁻¹)⁻¹ = A
> │    ├─ (AB)⁻¹ = B⁻¹A⁻¹
> │    ├─ (Aᵀ)⁻¹ = (A⁻¹)ᵀ
> │    ├─ (kA)⁻¹ = (1/k)A⁻¹
> │    └─ det(A⁻¹) = 1/det(A)
> │
> ├─── MÉTODOS DE CÁLCULO
> │    ├─ Fórmula 2×2 (directa)
> │    ├─ Gauss-Jordan [A|I]→[I|A⁻¹]
> │    ├─ Adjunta: A⁻¹ = (1/det)·adj(A)
> │    └─ Factorización (LU, QR)
> │
> ├─── MATRICES ESPECIALES
> │    ├─ Diagonal: inv de inv elementos
> │    ├─ Ortogonal: Q⁻¹ = Qᵀ
> │    ├─ Triangular: mantiene estructura
> │    └─ Simétrica: inversa simétrica
> │
> ├─── APLICACIONES
> │    ├─ Resolver sistemas: x = A⁻¹b
> │    ├─ Cambio de base
> │    ├─ Criptografía
> │    ├─ Gráficos computadora
> │    └─ Deshacer transformaciones
> │
> └─── CONSIDERACIONES NUMÉRICAS
>      ├─ Número de condición κ(A)
>      ├─ Estabilidad numérica
>      ├─ Cuándo NO calcular inversa
>      └─ Regularización
> ```
