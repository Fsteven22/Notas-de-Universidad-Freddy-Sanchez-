# 🎯 Determinantes

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **El determinante es un número que se asocia a cada matriz cuadrada y contiene información crucial sobre sus propiedades. Es como una "huella digital" que revela si la matriz es invertible, cómo transforma volúmenes, y características geométricas de la transformación lineal asociada.**
> 
> **Características clave:**
> 
> - **Solo matrices cuadradas:** n×n tiene determinante
> - **Resultado escalar:** Un único número real (o complejo)
> - **Notación:** det(A) o |A|
> - **Interpretación geométrica:** Factor de escala de volúmenes
> - **Criterio de invertibilidad:** det(A) ≠ 0 ⟺ A invertible

> - **Sylvester (1850):** Menores y cofactores
> 
> **Teoría Moderna (1850-1900):**
> 
> - **Cayley-Hamilton (1858):** Teorema característico

> 
> **Era Contemporánea:**
> 
> - Algoritmos eficientes de cálculo
> - Aplicaciones en geometría diferencial
> - Jacobiano en cálculo multivariable

## 📐 Definición Formal

> [!success]- Definición Matemática Rigurosa **Definición:** El **determinante** de una matriz cuadrada A de orden n es un escalar que se define recursivamente:
> 
> **Para n=1:**
> 
> ```
> A = [a₁₁]
> det(A) = a₁₁
> ```
> 
> **Para n=2:**
> 
> ```
> A = ⎡ a₁₁  a₁₂ ⎤
>     ⎣ a₂₁  a₂₂ ⎦
>     
> det(A) = a₁₁a₂₂ - a₁₂a₂₁
> ```
> 
> **Para n≥3 (Desarrollo por cofactores):**
> 
> ```
> det(A) = Σ (-1)^(i+j) aᵢⱼ Mᵢⱼ
>          j=1 hasta n
>          
> donde Mᵢⱼ = menor de A eliminando fila i, columna j
> ```
> 
> **Notación:**
> 
> ```
> det(A) = |A| = |aᵢⱼ|
> ```

## 🔢 Cálculo de Determinantes

### 1️⃣ Determinante 2×2

> [!note]- Caso Base **Fórmula:**
> 
> ```
> ⎡ a  b ⎤
> ⎣ c  d ⎦  = ad - bc
> 
> Diagonal principal - diagonal secundaria
> ```
> 
> **Mnemotecnia visual:**
> 
> ```
>   ↘ positivo
> a   b
> c   d
>   ↗ negativo
> ```
> 
> **Ejemplos:**
> 
> ```
> |2  3|
> |1  4| = 2·4 - 3·1 = 8 - 3 = 5
> 
> |5  -2|
> |3   1| = 5·1 - (-2)·3 = 5 + 6 = 11
> 
> |2  4|
> |1  2| = 2·2 - 4·1 = 4 - 4 = 0  (singular)
> ```

### 2️⃣ Determinante 3×3

> [!important]- Regla de Sarrus **Método de Sarrus (solo para 3×3):**
> 
> ```
> ⎡ a₁₁  a₁₂  a₁₃ ⎤
> ⎢ a₂₁  a₂₂  a₂₃ ⎥
> ⎣ a₃₁  a₃₂  a₃₃ ⎦
> 
> Duplicar primeras 2 columnas:
> 
> a₁₁  a₁₂  a₁₃ | a₁₁  a₁₂
> a₂₁  a₂₂  a₂₃ | a₂₁  a₂₂
> a₃₁  a₃₂  a₃₃ | a₃₁  a₃₂
>  ↘    ↘    ↘      ↗    ↗    ↗
> (+)  (+)  (+)   (-)  (-)  (-)
> 
> det = a₁₁a₂₂a₃₃ + a₁₂a₂₃a₃₁ + a₁₃a₂₁a₃₂
>     - a₁₃a₂₂a₃₁ - a₁₁a₂₃a₃₂ - a₁₂a₂₁a₃₃
> ```
> 
> **Ejemplo:**
> 
> ```
> ⎡ 2   1  -1 ⎤
> ⎢ 3   0   2 ⎥
> ⎣ 1  -2   1 ⎦
> 
> Diagonales positivas:
> 2·0·1 = 0
> 1·2·1 = 2
> (-1)·3·(-2) = 6
> Suma: 8
> 
> Diagonales negativas:
> (-1)·0·1 = 0
> 2·2·(-2) = -8
> 1·3·1 = 3
> Suma: -5
> 
> det = 8 - (-5) = 13
> ```

### 3️⃣ Desarrollo por Cofactores

> [!tip]- Método General **Definiciones:**
> 
> ```
> Menor Mᵢⱼ: determinante de la submatriz
>            que resulta al eliminar fila i
>            y columna j
>            
> Cofactor Cᵢⱼ = (-1)^(i+j) Mᵢⱼ
> 
> Signo del cofactor (tablero de ajedrez):
> ⎡ +  -  +  - ⎤
> ⎢ -  +  -  + ⎥
> ⎢ +  -  +  - ⎥
> ⎣ -  +  -  + ⎦
> ```
> 
> **Desarrollo por fila i:**
> 
> ```
> det(A) = Σ aᵢⱼ Cᵢⱼ
>          j=1 hasta n
> ```
> 
> **Desarrollo por columna j:**
> 
> ```
> det(A) = Σ aᵢⱼ Cᵢⱼ
>          i=1 hasta n
> ```
> 
> **Estrategia:** Elegir fila/columna con más ceros

### 4️⃣ Método de Gauss (Triangularización)

> [!important]- Más Eficiente para n≥4 **Idea:** Reducir a triangular superior
> 
> ```
> det(A) = det(U) · (-1)^(intercambios)
>        = producto diagonal de U
> ```
> 
> **Operaciones elementales:**
> 
> ```
> 1. Intercambiar filas: det cambia signo
> 2. Multiplicar fila por k: det multiplica por k
> 3. Sumar múltiplo de fila: det NO cambia
> ```
> 
> **Algoritmo:**
> 
> ```
> 4. Llevar a forma triangular U
> 5. Contar intercambios de filas
> 6. det(A) = (-1)^intercambios · u₁₁·u₂₂·...·uₙₙ
> ```

## 🎯 Propiedades Fundamentales

### 1️⃣ Propiedades Básicas

> [!note]- Reglas Esenciales **P1. Fila/columna de ceros:**
> 
> ```
> Si A tiene fila o columna de ceros → det(A) = 0
> 
> ⎡ 1  2  3 ⎤
> ⎢ 0  0  0 ⎥ → det = 0
> ⎣ 4  5  6 ⎦
> ```
> 
> **P2. Filas/columnas proporcionales:**
> 
> ```
> Si dos filas (o columnas) son proporcionales → det(A) = 0
> 
> ⎡ 1  2  3 ⎤
> ⎢ 2  4  6 ⎥ → det = 0  (F₂ = 2F₁)
> ⎣ 4  5  6 ⎦
> ```
> 
> **P3. Matrices especiales:**
> 
> ```
> det(I) = 1  (identidad)
> det(O) = 0  (nula)
> det(kI) = kⁿ  (escalar, orden n)
> ```
> 
> **P4. Matriz diagonal/triangular:**
> 
> ```
> ⎡ d₁  0   0  ⎤
> ⎢ 0   d₂  0  ⎥ → det = d₁·d₂·d₃
> ⎣ 0   0   d₃ ⎦
> ```

### 2️⃣ Propiedades de Operaciones

> [!important]- Álgebra de Determinantes **P5. Producto:**
> 
> ```
> det(AB) = det(A)·det(B)
> 
> ¡PERO! det(A+B) ≠ det(A) + det(B)
> ```
> 
> **P6. Transpuesta:**
> 
> ```
> det(Aᵀ) = det(A)
> 
> Filas y columnas tienen mismo papel
> ```
> 
> **P7. Inversa:**
> 
> ```
> det(A⁻¹) = 1/det(A)  (si existe)
> 
> det(A)·det(A⁻¹) = det(AA⁻¹) = det(I) = 1
> ```
> 
> **P8. Potencia:**
> 
> ```
> det(Aⁿ) = [det(A)]ⁿ
> ```
> 
> **P9. Múltiplo escalar:**
> 
> ```
> det(kA) = kⁿ·det(A)  (matriz n×n)
> 
> No confundir con det(kI) = kⁿ
> ```

### 3️⃣ Operaciones Elementales

> [!tip]- Efectos en el Determinante **E1. Intercambiar filas/columnas:**
> 
> ```
> det(A') = -det(A)
> 
> Cada intercambio cambia el signo
> ```
> 
> **E2. Multiplicar fila/columna por k:**
> 
> ```
> det(A') = k·det(A)
> ```
> 
> **E3. Sumar múltiplo de fila a otra:**
> 
> ```
> det(A') = det(A)  (no cambia)
> 
> Fᵢ → Fᵢ + kFⱼ
> ```

## 🔍 Interpretación Geométrica

> [!important]- Significado Visual **En ℝ²:**
> 
> ```
> ⎡ a  b ⎤
> ⎣ c  d ⎦
> 
> |det| = área del paralelogramo formado
>         por vectores columna (a,c) y (b,d)
>         
> det > 0: preserva orientación
> det < 0: invierte orientación
> det = 0: colapso a línea (degeneración)
> ```
> 
> **En ℝ³:**
> 
> ```
> |det(A)| = volumen del paralelepípedo
>            formado por vectores columna
>            
> det = 0: vectores coplanares
> ```
> 
> **En ℝⁿ:**
> 
> ```
> |det(A)| = factor de escala del n-volumen
>            bajo transformación lineal T(x) = Ax
> ```

## 💡 Aplicaciones Principales

### 1️⃣ Criterio de Invertibilidad

> [!important]- Condición Necesaria y Suficiente
> 
> ```
> A invertible ⟺ det(A) ≠ 0
> 
> Si det(A) = 0: A es singular (no invertible)
> Si det(A) ≠ 0: A es no singular (invertible)
> ```

### 2️⃣ Regla de Cramer

> [!note]- Solución de Sistemas **Sistema Ax = b con det(A) ≠ 0:**
> 
> ```
> xᵢ = det(Aᵢ)/det(A)
> 
> donde Aᵢ = A con columna i reemplazada por b
> ```
> 
> **Ejemplo 2×2:**
> 
> ```
> 2x + 3y = 8
> 1x + 4y = 11
> 
> A = ⎡2 3⎤,  b = ⎡ 8⎤
>     ⎣1 4⎦      ⎣11⎦
>     
> det(A) = 8 - 3 = 5
> 
> A₁ = ⎡ 8  3⎤ → det(A₁) = 32 - 33 = -1
>      ⎣11  4⎦
> x = -1/5
> 
> A₂ = ⎡2  8⎤ → det(A₂) = 22 - 8 = 14
>      ⎣1 11⎦
> y = 14/5
> ```

### 3️⃣ Cálculo de la Inversa

> [!tip]- Fórmula Explícita
> 
> ```
> A⁻¹ = (1/det(A)) · adj(A)
> 
> donde adj(A) = matriz adjunta
>              = [Cᵢⱼ]ᵀ (transpuesta de cofactores)
> ```

### 4️⃣ Eigenvalores

> [!note]- Ecuación Característica
> 
> ```
> det(A - λI) = 0
> 
> Polinomio característico
> Raíces = eigenvalores de A
> ```

## 📊 Determinantes de Matrices Especiales

> [!note]- Casos Particulares **Diagonal:**
> 
> ```
> det(diag(d₁,...,dₙ)) = d₁·d₂·...·dₙ
> ```
> 
> **Triangular:**
> 
> ```
> det(triangular) = producto diagonal
> ```
> 
> **Ortogonal:**
> 
> ```
> det(Q) = ±1  (pues QᵀQ = I)
> ```
> 
> **Simétrica:**
> 
> ```
> det(A) = det(Aᵀ) = det(A)  ✓ automático
> ```
> 
> **Antisimétrica (orden impar):**
> 
> ```
> det(A) = det(-Aᵀ) = det(-A) = (-1)ⁿdet(A)
> Si n impar: det(A) = 0
> ```
> 
> **Bloques:**
> 
> ```
> det⎡A  O⎤ = det(A)·det(D)
>    ⎣C  D⎦
>    
> det⎡A  B⎤ = det(A)·det(D)  (si A,D conmutan)
>    ⎣O  D⎦
> ```

## 🔧 Métodos Computacionales

> [!tip]- Eficiencia **Complejidad:**
> 
> ```
> Cofactores: O(n!)  - impráctico para n>10
> Gauss: O(n³)       - método estándar
> ```
> 
> **Recomendación:**
> 
> ```
> n ≤ 3: Fórmulas directas
> n ≥ 4: Eliminación gaussiana
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes **1. "det(A+B) = det(A) + det(B)"**
> 
> ```
> ✗ FALSO
> 
> Contraejemplo:
> A = ⎡1 0⎤, B = ⎡0 1⎤
>     ⎣0 1⎦      ⎣1 0⎦
>     
> det(A) = 1, det(B) = -1
> det(A+B) = det⎡1 1⎤ = -1
>               ⎣1 1⎦
> -1 ≠ 1 + (-1) = 0
> ```
> 
> **2. "det(kA) = k·det(A)"**
> 
> ```
> ✗ FALSO (para n×n)
> ✓ det(kA) = kⁿ·det(A)
> ```
> 
> **3. "det(A) = 0 ⟹ A = O"**
> 
> ```
> ✗ FALSO
> 
> ⎡1 1⎤ tiene det = 0 pero no es nula
> ⎣1 1⎦
> ```

## 🎯 Resumen Ejecutivo

> [!important]- Conceptos Clave **Definición:**
> 
> - Escalar asociado a matriz cuadrada
> - Notación: det(A) o |A|
> 
> **Cálculo:**
> 
> - 2×2: ad - bc
> - 3×3: Regla de Sarrus
> - n×n: Cofactores o Gauss
> 
> **Propiedades críticas:**
> 
> - det(AB) = det(A)det(B)
> - det(Aᵀ) = det(A)
> - det(A⁻¹) = 1/det(A)
> - Fila nula → det = 0
> 
> **Interpretación:**
> 
> - Factor de escala de volúmenes
> - Criterio invertibilidad: det ≠ 0
> 
> **Aplicaciones:**
> 
> - Invertibilidad
> - Regla de Cramer
> - Eigenvalores
> - Geometría
