# 🎯 Sistemas de Ecuaciones Lineales

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Un sistema de ecuaciones lineales es un conjunto de ecuaciones donde cada una relaciona las mismas variables de forma lineal (sin potencias, productos o funciones trascendentes). Resolver el sistema significa encontrar todos los valores de las variables que satisfacen simultáneamente todas las ecuaciones.**
> 
> **Características clave:**
> 
> - **Linealidad:** Variables solo en primera potencia
> - **Simultaneidad:** Todas las ecuaciones deben cumplirse a la vez
> - **Solución:** Conjunto de valores que satisfacen todo el sistema
> - **Representación matricial:** Ax = b
> - **Interpretación geométrica:** Intersección de hiperplanos

> 
> - **Cardano (1545):** Métodos algebraicos
> - **Leibniz (1693):** Notación sistemática
> - **Cramer (1750):** Regla de Cramer
>     - Solución explícita usando determinantes
>     - Aplicable pero ineficiente
> 
> **Sistematización (1800-1900):**
> 
> - **Gauss (1809):** Método de eliminación
>     - Cálculo de órbita de Ceres
>     - Algoritmo sistemático y eficiente

> - **Métodos iterativos:** Jacobi, Gauss-Seidel, gradiente conjugado

## 📐 Definición Formal

> [!success]- Definición Matemática Rigurosa **Definición:** Un **sistema de m ecuaciones lineales con n incógnitas** es:
> 
> ```
> a₁₁x₁ + a₁₂x₂ + a₁₃x₃ + ... + a₁ₙxₙ = b₁
> a₂₁x₁ + a₂₂x₂ + a₂₃x₃ + ... + a₂ₙxₙ = b₂
> a₃₁x₁ + a₃₂x₂ + a₃₃x₃ + ... + a₃ₙxₙ = b₃
>  ⋮      ⋮      ⋮             ⋮      ⋮
> aₘ₁x₁ + aₘ₂x₂ + aₘ₃x₃ + ... + aₘₙxₙ = bₘ
> 
> donde:
> - xⱼ: incógnitas (j = 1,...,n)
> - aᵢⱼ: coeficientes (i = 1,...,m; j = 1,...,n)
> - bᵢ: términos independientes (i = 1,...,m)
> ```
> 
> **Forma matricial:**
> 
> ```
> Ax = b
> 
> donde:
> A = [aᵢⱼ]ₘₓₙ  (matriz de coeficientes)
> x = [xⱼ]ₙₓ₁   (vector de incógnitas)
> b = [bᵢ]ₘₓ₁   (vector de términos independientes)
> ```
> 
> **Matriz aumentada:**
> 
> ```
> [A|b] = ⎡ a₁₁  a₁₂  ...  a₁ₙ | b₁ ⎤
>         ⎢ a₂₁  a₂₂  ...  a₂ₙ | b₂ ⎥
>         ⎢  ⋮    ⋮    ⋱    ⋮  |  ⋮ ⎥
>         ⎣ aₘ₁  aₘ₂  ...  aₘₙ | bₘ ⎦
> ```

## 🎨 Clasificación de Sistemas

### 1️⃣ Por Compatibilidad

> [!important]- Existencia de Soluciones **Sistema Compatible (tiene solución):**
> 
> ```
> - Compatible Determinado: Una única solución
> - Compatible Indeterminado: Infinitas soluciones
> ```
> 
> **Sistema Incompatible (sin solución):**
> 
> ```
> No existe ningún conjunto de valores que satisfaga
> todas las ecuaciones simultáneamente
> ```
> 
> **Ejemplos 2×2:**
> 
> ```
> Compatible Determinado:
> x + y = 3
> x - y = 1
> Solución: x = 2, y = 1
> 
> Compatible Indeterminado:
> x + y = 3
> 2x + 2y = 6  (segunda es múltiplo de primera)
> Infinitas soluciones: y = 3 - x
> 
> Incompatible:
> x + y = 3
> x + y = 5  (contradicción)
> Sin solución
> ```

### 2️⃣ Por Tipo de Sistema

> [!note]- Clasificación Estructural **Sistema Homogéneo:**
> 
> ```
> Ax = 0  (todos los términos independientes son cero)
> 
> Siempre tiene al menos la solución trivial: x = 0
> ```
> 
> **Sistema No Homogéneo:**
> 
> ```
> Ax = b  con b ≠ 0
> 
> Puede tener solución o no
> ```
> 
> **Sistema Cuadrado:**
> 
> ```
> m = n  (mismas ecuaciones que incógnitas)
> 
> - Si det(A) ≠ 0: solución única
> - Si det(A) = 0: infinitas soluciones o ninguna
> ```
> 
> **Sistema Sobredeterminado:**
> 
> ```
> m > n  (más ecuaciones que incógnitas)
> 
> Típicamente incompatible (a menos que ecuaciones redundantes)
> ```
> 
> **Sistema Subdeterminado:**
> 
> ```
> m < n  (menos ecuaciones que incógnitas)
> 
> Si compatible: infinitas soluciones
> ```

## 🔍 Teorema de Rouché-Frobenius

> [!important]- Criterio de Compatibilidad **Teorema (Existencia de soluciones):**
> 
> ```
> Sea [A|b] la matriz aumentada del sistema Ax = b
> Sean:
> - rango(A) = r
> - rango([A|b]) = r'
> 
> Entonces:
> 
> 1. Sistema Compatible ⟺ rango(A) = rango([A|b])
>    
>    a) Compatible Determinado ⟺ rango(A) = rango([A|b]) = n
>       (n = número de incógnitas)
>       
>    b) Compatible Indeterminado ⟺ rango(A) = rango([A|b]) < n
>       Grados de libertad = n - rango(A)
>       
> 2. Sistema Incompatible ⟺ rango(A) < rango([A|b])
> ```
> 
> **Interpretación:**
> 
> ```
> - rango(A) = rango([A|b]): vector b es combinación lineal
>                            de columnas de A
>                            
> - rango(A) < rango([A|b]): vector b "sale" del espacio
>                            generado por columnas de A
> ```

## 🔧 Métodos de Resolución

### 1️⃣ Sustitución

> [!note]- Método Básico **Procedimiento:**
> 
> ```
> 1. Despejar una variable de una ecuación
> 2. Sustituir en las demás ecuaciones
> 3. Resolver el sistema reducido
> 4. Retroceder sustituyendo
> ```
> 
> **Ejemplo:**
> 
> ```
> x + y = 5  ... (1)
> 2x - y = 1 ... (2)
> 
> De (1): y = 5 - x
> 
> Sustituir en (2):
> 2x - (5 - x) = 1
> 2x - 5 + x = 1
> 3x = 6
> x = 2
> 
> Volver a (1):
> y = 5 - 2 = 3
> 
> Solución: (x,y) = (2,3)
> ```
> 
> **Ventajas:** Intuitivo, útil para sistemas pequeños **Desventajas:** Tedioso para sistemas grandes

### 2️⃣ Igualación

> [!note]- Despejar Misma Variable **Procedimiento:**
> 
> ```
> 1. Despejar la misma variable en dos ecuaciones
> 2. Igualar las expresiones
> 3. Resolver para otra variable
> 4. Sustituir
> ```
> 
> **Ejemplo:**
> 
> ```
> 2x + y = 7  ... (1)
> x - y = 2   ... (2)
> 
> De (1): y = 7 - 2x
> De (2): y = x - 2
> 
> Igualar:
> 7 - 2x = x - 2
> 9 = 3x
> x = 3
> 
> y = 3 - 2 = 1
> 
> Solución: (x,y) = (3,1)
> ```

### 3️⃣ Reducción (Eliminación)

> [!tip]- Combinar Ecuaciones **Procedimiento:**
> 
> ```
> 1. Multiplicar ecuaciones por constantes apropiadas
> 2. Sumar/restar para eliminar variables
> 3. Resolver sistema reducido
> 4. Sustituir hacia atrás
> ```
> 
> **Ejemplo:**
> 
> ```
> 3x + 2y = 12  ... (1)
> 2x - y = 1    ... (2)
> 
> Multiplicar (2) por 2:
> 4x - 2y = 2   ... (2')
> 
> Sumar (1) + (2'):
> 7x = 14
> x = 2
> 
> Sustituir en (2):
> 2(2) - y = 1
> y = 3
> 
> Solución: (x,y) = (2,3)
> ```

### 4️⃣ Regla de Cramer

> [!note]- Método Determinantal **Aplicable cuando:** Sistema cuadrado (n×n) con det(A) ≠ 0
> 
> **Fórmula:**
> 
> ```
> xᵢ = det(Aᵢ)/det(A)
> 
> donde Aᵢ = matriz A con columna i reemplazada por b
> ```
> 
> **Ejemplo 2×2:**
> 
> ```
> 2x + 3y = 8
> x + 4y = 11
> 
> A = ⎡2  3⎤,  b = ⎡ 8⎤
>     ⎣1  4⎦      ⎣11⎦
> 
> det(A) = 2·4 - 3·1 = 5
> 
> A₁ = ⎡ 8  3⎤ → det(A₁) = 8·4 - 3·11 = -1
>      ⎣11  4⎦
> x = -1/5
> 
> A₂ = ⎡2  8⎤ → det(A₂) = 2·11 - 8·1 = 14
>      ⎣1 11⎦
> y = 14/5
> 
> Solución: (x,y) = (-1/5, 14/5)
> ```
> 
> **Ventajas:** Fórmula explícita **Desventajas:** Ineficiente para n > 3 (O(n!·n))

### 5️⃣ Método de Gauss (Eliminación Gaussiana)

> [!important]- Método Estándar **Objetivo:** Transformar [A|b] a forma escalonada
> 
> **Forma Escalonada (Triangular Superior):**
> 
> ```
> ⎡ * * * * | * ⎤
> ⎢ 0 * * * | * ⎥
> ⎢ 0 0 * * | * ⎥
> ⎣ 0 0 0 * | * ⎦
> 
> * = elemento no nulo (pivote)
> ```
> 
> **Algoritmo:**
> 
> ```
> FASE 1: Eliminación hacia adelante
> Para cada columna j = 1, 2, ..., n-1:
>   1. Elegir pivote (elemento no nulo en diagonal)
>   2. Si necesario, intercambiar filas
>   3. Hacer ceros debajo del pivote:
>      Fᵢ → Fᵢ - (aᵢⱼ/aⱼⱼ)·Fⱼ  para i > j
> 
> FASE 2: Sustitución regresiva
> Resolver desde la última ecuación hacia arriba:
>   xₙ = bₙ'/aₙₙ
>   xₙ₋₁ = (bₙ₋₁' - aₙ₋₁,ₙxₙ)/aₙ₋₁,ₙ₋₁
>   ...
> ```
> 
> **Ejemplo completo:**
> 
> ```
> Sistema:
> x + 2y - z = 3
> 2x + y + z = 6
> x - y + 2z = 1
> 
> Matriz aumentada:
> ⎡ 1   2  -1 | 3 ⎤
> ⎢ 2   1   1 | 6 ⎥
> ⎣ 1  -1   2 | 1 ⎦
> 
> Paso 1: Eliminar x de F₂ y F₃
> F₂ → F₂ - 2F₁:
> ⎡ 1   2  -1 | 3 ⎤
> ⎢ 0  -3   3 | 0 ⎥
> ⎣ 1  -1   2 | 1 ⎦
> 
> F₃ → F₃ - F₁:
> ⎡ 1   2  -1 | 3 ⎤
> ⎢ 0  -3   3 | 0 ⎥
> ⎣ 0  -3   3 |-2 ⎦
> 
> Paso 2: Eliminar y de F₃
> F₃ → F₃ - F₂:
> ⎡ 1   2  -1 | 3 ⎤
> ⎢ 0  -3   3 | 0 ⎥
> ⎣ 0   0   0 |-2 ⎦
> 
> Última fila: 0 = -2  ¡CONTRADICCIÓN!
> 
> CONCLUSIÓN: Sistema INCOMPATIBLE
> ```

### 6️⃣ Método de Gauss-Jordan

> [!important]- Forma Escalonada Reducida **Objetivo:** Llevar [A|b] a forma escalonada reducida
> 
> **Forma Escalonada Reducida:**
> 
> ```
> ⎡ 1  0  0 | * ⎤
> ⎢ 0  1  0 | * ⎥  →  Solución directa
> ⎣ 0  0  1 | * ⎦
> 
> Diagonal de unos, resto ceros
> ```
> 
> **Algoritmo:**
> 
> ```
> 1. Aplicar eliminación gaussiana (forma escalonada)
> 2. Normalizar pivotes (dividir fila por pivote)
> 3. Eliminación hacia atrás (hacer ceros ARRIBA de pivotes)
> ```
> 
> **Ejemplo:**
> 
> ```
> Sistema:
> x + 2y = 5
> 3x + 4y = 11
> 
> [A|b]:
> ⎡ 1  2 | 5 ⎤
> ⎣ 3  4 | 11⎦
> 
> F₂ → F₂ - 3F₁:
> ⎡ 1  2 | 5 ⎤
> ⎣ 0 -2 |-4 ⎦
> 
> F₂ → F₂/(-2):
> ⎡ 1  2 | 5 ⎤
> ⎣ 0  1 | 2 ⎦
> 
> F₁ → F₁ - 2F₂:
> ⎡ 1  0 | 1 ⎤
> ⎣ 0  1 | 2 ⎦
> 
> Solución: x = 1, y = 2
> ```
> 
> **Ventajas:**
> 
> - Solución directa (no requiere sustitución regresiva)
> - Útil para calcular matriz inversa
> 
> **Complejidad:** O(n³) operaciones

## 🎯 Casos Especiales

### 1️⃣ Sistemas Homogéneos

> [!important]- Ax = 0 **Propiedades:**
> 
> ```
> 1. Siempre tiene solución trivial: x = 0
> 
> 2. Soluciones no triviales ⟺ det(A) = 0 (si cuadrado)
>                            ⟺ rango(A) < n
> 
> 3. Conjunto solución es subespacio vectorial
> 
> 4. Si x₁, x₂ son soluciones:
>    - x₁ + x₂ es solución
>    - k·x₁ es solución (∀k ∈ ℝ)
> ```
> 
> **Teorema:**
> 
> ```
> Sistema homogéneo n×n:
> - det(A) ≠ 0 → solo solución trivial
> - det(A) = 0 → infinitas soluciones
> ```

### 2️⃣ Sistemas con Parámetros

> [!note]- Discusión Según Valores **Ejemplo:**
> 
> ```
> x + y = 2
> x + ky = 3
> 
> Matriz aumentada:
> ⎡ 1  1 | 2 ⎤
> ⎣ 1  k | 3 ⎦
> 
> Aplicar Gauss:
> F₂ → F₂ - F₁:
> ⎡ 1    1  | 2 ⎤
> ⎣ 0  k-1  | 1 ⎦
> 
> Discusión:
> 
> Caso 1: k ≠ 1
>   Segunda fila: (k-1)y = 1
>   y = 1/(k-1)
>   x = 2 - y = 2 - 1/(k-1) = (2k-3)/(k-1)
>   
>   Sistema Compatible Determinado
> 
> Caso 2: k = 1
>   Segunda fila: 0·y = 1
>   0 = 1  ¡Contradicción!
>   
>   Sistema Incompatible
> ```

### 3️⃣ Sistemas Equivalentes

> [!note]- Misma Solución **Definición:**
> 
> ```
> Dos sistemas son equivalentes si tienen
> el mismo conjunto solución
> ```
> 
> **Operaciones que preservan equivalencia:**
> 
> ```
> 1. Intercambiar ecuaciones
> 2. Multiplicar ecuación por k ≠ 0
> 3. Sumar múltiplo de ecuación a otra
> ```

## 📐 Interpretación Geométrica

> [!note]- Visualización **En ℝ²:** Cada ecuación lineal es una recta
> 
> ```
> Compatible Determinado:  Rectas se intersectan en 1 punto
> Compatible Indeterminado: Rectas coincidentes (infinitos puntos)
> Incompatible:            Rectas paralelas (ningún punto)
> ```
> 
> **En ℝ³:** Cada ecuación lineal es un plano
> 
> ```
> Compatible Determinado:  Planos se intersectan en 1 punto
> Compatible Indeterminado: Intersección en recta o plano
> Incompatible:            No hay punto común
> ```
> 
> **En ℝⁿ:** Cada ecuación es un hiperplano (n-1 dimensional)
> 
> ```
> Solución = intersección de todos los hiperplanos
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes **1. "Más ecuaciones = más restricciones = sin solución"**
> 
> ```
> ✗ FALSO
> 
> Si las ecuaciones adicionales son dependientes
> (combinaciones lineales de otras), no agregan
> restricciones nuevas
> 
> Ejemplo:
> x + y = 2
> 2x + 2y = 4  (redundante)
> 3x + 3y = 6  (redundante)
> 
> 3 ecuaciones, infinitas soluciones
> ```
> 
> **2. "Sistema cuadrado siempre tiene solución única"**
> 
> ```
> ✗ FALSO
> 
> Necesita det(A) ≠ 0
> 
> Contraejemplo:
> x + y = 2
> 2x + 2y = 5
> 
> det⎡1 1⎤ = 0
>    ⎣2 2⎦
> 
> Sistema incompatible
> ```
> 
> **3. "Dividir entre pivote cero"**
> 
> ```
> ✗ ERROR MATEMÁTICO
> 
> Si pivote = 0, intercambiar filas primero
> Si no hay fila con elemento no nulo en esa columna,
> la columna representa variable libre
> ```
> 
> **4. "Olvidar normalizar al usar Gauss-Jordan"**
> 
> ```
> Después de hacer ceros, dividir por pivote
> para obtener unos en diagonal
> ```

> [!tip]- Guía de Decisión **Sistemas pequeños (2×2, 3×3):**

> ```

> ```

> ```

> ```

> 
> ```
> - Métodos iterativos

> ```
> 
> **Sistemas con parámetros:**
> 
> ```

## 📊 Ejemplo Completo Resuelto

> [!example]- Problema Detallado
> 
> ```
> Resolver y clasificar:
> 
> x + 2y - z = 1
> 2x + y + z = 4
> 3x + 3y = 5
> 
> SOLUCIÓN:
> 
> Matriz aumentada:
> ⎡ 1  2  -1 | 1 ⎤
> ⎢ 2  1   1 | 4 ⎥
> ⎣ 3  3   0 | 5 ⎦
> 
> PASO 1: F₂ → F₂ - 2F₁
> ⎡ 1  2  -1 | 1 ⎤
> ⎢ 0 -3   3 | 2 ⎥
> ⎣ 3  3   0 | 5 ⎦
> 
> PASO 2: F₃ → F₃ - 3F₁
> ⎡ 1  2  -1 | 1 ⎤
> ⎢ 0 -3   3 | 2 ⎥
> ⎣ 0 -3   3 | 2 ⎦
> 
> PASO 3: F₃ → F₃ - F₂
> ⎡ 1  2  -1 | 1 ⎤
> ⎢ 0 -3   3 | 2 ⎥
> ⎣ 0  0   0 | 0 ⎦
> 
> Forma escalonada alcanzada
> 
> ANÁLISIS:
> - Última fila: 0 = 0 (identidad, no contradicción)
> - rango(A) = 2
> - rango([A|b]) = 2
> - rango(A) = rango([A|b]) < 3 (n = 3 incógnitas)
> 
> CONCLUSIÓN: Sistema Compatible Indeterminado
>              Infinitas soluciones (1 grado de libertad)
> 
> PASO 4: Sustitución regresiva
> De F₂: -3y + 3z = 2
>        y = z - 2/3
> 
> De F₁: x + 2y - z = 1
>        x = 1 - 2y + z
>        x = 1 - 2(z - 2/3) + z
>        x = 1 - 2z + 4/3 + z
>        x = 7/3 - z
> 
> SOLUCIÓN GENERAL (z como parámetro libre):
> x = 7/3 - t
> y = t - 2/3
> z = t
> 
> donde t ∈ ℝ (parámetro)
> 
> FORMA VECTORIAL:
> ⎡x⎤   ⎡ 7/3 ⎤   ⎡-1⎤
> ⎢y⎥ = ⎢-2/3 ⎥ + t⎢ 1⎥
> ⎣z⎦   ⎣  0  ⎦   ⎣ 1⎦
> 
> Solución particular + t·(dirección)
> 
> VERIFICACIÓN (con t = 0):
> x = 7/3, y = -2/3, z = 0
> 
> Ecuación 1: 7/3 + 2(-2/3) - 0 = 7/3 - 4/3 = 1 ✓
> Ecuación 2: 2(7/3) + (-2/3) + 0 = 14/3 - 2/3 = 12/3 = 4 ✓
> Ecuación 3: 3(7/3) + 3(-2/3) = 7 - 2 = 5 ✓
> ```

## 🎓 Teoremas Fundamentales

> [!important]- Resultados Clave **Teorema 1: Existencia y Unicidad**
> 
> ```
> Para sistema Ax = b (n×n):
> 
> det(A) ≠ 0 ⟺ Sistema tiene solución única
>            ⟺ A es invertible
>            ⟺ x = A⁻¹b
> ```
> 
> **Teorema 2: Alternativa de Fredholm**
> 
> ```
> Para sistema Ax = b:
> 
> Exactamente una de las siguientes es cierta:
> a) Ax = b tiene solución única
> b) Ax = 0 tiene soluciones no triviales
> ```
> 
> **Teorema 3: Estructura del conjunto solución**
> 
> ```
> Si Ax = b es compatible:
> 
> Solución general = Solución particular + Solución homogénea
> 
> x = xₚ + xₕ
> 
> donde:
> - xₚ: cualquier solución de Ax = b
> - xₕ: solución general de Ax = 0
> ```
> 
> **Teorema 4: Dimensión del espacio solución (homogéneo)**
> 
> ```
> Para sistema homogéneo Ax = 0 (m×n):
> 
> dim(conjunto solución) = n - rango(A)
> 
> Llamado "nulidad" de A
> ```

## 🔄 Métodos Matriciales Avanzados

### 1️⃣ Factorización LU

> [!tip]- Descomposición A = LU **Idea:** Factorizar A = L·U donde:
> 
> ```
> L: matriz triangular inferior (Lower)
> U: matriz triangular superior (Upper)
> ```
> 
> **Ventaja:**
> 
> ```
> Resolver Ax = b se convierte en:
> 
> 1. Ly = b  (sustitución progresiva)
> 2. Ux = y  (sustitución regresiva)
> 
> Eficiente si se resuelven múltiples sistemas
> con misma A pero diferentes b
> ```
> 
> **Ejemplo:**
> 
> ```
> A = ⎡ 2  1  1 ⎤
>     ⎢ 4  3  3 ⎥
>     ⎣ 8  7  9 ⎦
> 
> Factorización:
> L = ⎡ 1  0  0 ⎤    U = ⎡ 2  1  1 ⎤
>     ⎢ 2  1  0 ⎥        ⎢ 0  1  1 ⎥
>     ⎣ 4  3  1 ⎦        ⎣ 0  0  2 ⎦
> 
> Verificar: L·U = A ✓
> ```
> 
> **Complejidad:**
> 
> ```
> - Factorización: O(n³) (una sola vez)
> - Cada solución: O(n²)
> ```

### 2️⃣ Factorización QR

> [!note]- A = QR **Idea:** Factorizar A = Q·R donde:
> 
> ```
> Q: matriz ortogonal (QᵀQ = I)
> R: matriz triangular superior
> ```
> 
> **Ventaja:**
> 
> ```
> - Numéricamente más estable que LU
> - Útil para problemas de mínimos cuadrados
> - Proceso de Gram-Schmidt
> ```
> 
> **Aplicación:**
> 
> ```
> Ax = b  →  QRx = b
>         →  Rx = Qᵀb  (multiplicar por Qᵀ)
>         →  resolver sistema triangular
> ```

### 3️⃣ Factorización de Cholesky

> [!note]- Para Matrices Simétricas Definidas Positivas **Aplicable cuando:** A simétrica y definida positiva
> 
> ```
> A = LLᵀ
> 
> donde L es triangular inferior
> ```
> 
> **Ventajas:**
> 
> ```
> - Más eficiente que LU (casi la mitad de operaciones)
> - Más estable numéricamente
> - Garantiza factorización única
> ```
> 
> **Uso:** Sistemas de ecuaciones normales en mínimos cuadrados

## 🌐 Sistemas Especiales

### 1️⃣ Sistemas Tridiagonales

> [!tip]- Estructura de Banda **Forma:**
> 
> ```
> ⎡ b₁  c₁   0   0  ...  0 ⎤
> ⎢ a₂  b₂  c₂   0  ...  0 ⎥
> ⎢  0  a₃  b₃  c₃  ...  0 ⎥
> ⎢  ⋮   ⋮   ⋱   ⋱   ⋱   ⋮ ⎥
> ⎣  0   0  ...  aₙ  bₙ  ⎦
> 
> Solo tres diagonales no nulas
> ```
> 
> **Algoritmo de Thomas (O(n)):**
> 
> ```
> Eliminación especializada:
> - Recorrido hacia adelante
> - Sustitución hacia atrás
> - Muy eficiente: solo O(n) operaciones
> ```
> 
> **Aplicaciones:**
> 
> ```
> - Diferencias finitas
> - Splines cúbicos
> - Ecuaciones diferenciales
> ```

### 2️⃣ Sistemas con Matrices Dispersas

> [!note]- Mayoría de Elementos Ceros **Estrategias:**
> 
> ```
> - Almacenamiento comprimido (CSR, CSC, COO)
> - Métodos iterativos (no llenar con ceros)
> - Reordenamiento para minimizar fill-in
> ```
> 
> **Aplicaciones:**
> 
> ```
> - Elementos finitos
> - Redes grandes
> - Teoría de grafos
> - Procesamiento de imágenes
> ```

### 3️⃣ Sistemas Sobredeterminados (m > n)

> [!important]- Mínimos Cuadrados **Problema:** Generalmente incompatible
> 
> **Solución:** Minimizar error cuadrático
> 
> ```
> Minimizar ||Ax - b||²
> 
> Solución: x = (AᵀA)⁻¹Aᵀb
> 
> (si AᵀA es invertible)
> ```
> 
> **Ecuaciones Normales:**
> 
> ```
> AᵀAx = Aᵀb
> 
> Sistema n×n (cuadrado)
> ```
> 
> **Aplicación:**
> 
> ```
> - Ajuste de datos experimentales
> - Regresión lineal
> - Interpolación con ruido
> ```

## 📱 Implementación Computacional

> [!example]- Código Python
> 
> ```python
> import numpy as np
> from scipy.linalg import solve, lu, qr
> 
> # Sistema Ax = b
> A = np.array([[2, 1, -1],
>               [1, 3, 2],
>               [3, 1, 1]])
> b = np.array([8, 13, 10])
> 
> # Método 1: Solución directa
> x = solve(A, b)
> print("Solución:", x)
> 
> # Método 2: Usando inversa (menos eficiente)
> A_inv = np.linalg.inv(A)
> x2 = A_inv @ b
> 
> # Método 3: Factorización LU
> P, L, U = lu(A)
> y = solve(L, P @ b)  # Ly = Pb
> x3 = solve(U, y)     # Ux = y
> 
> # Método 4: Factorización QR
> Q, R = qr(A)
> x4 = solve(R, Q.T @ b)
> 
> # Verificación
> residuo = np.linalg.norm(A @ x - b)
> print("Residuo:", residuo)
> 
> # Calcular rangos (compatibilidad)
> rango_A = np.linalg.matrix_rank(A)
> Ab = np.column_stack([A, b])
> rango_Ab = np.linalg.matrix_rank(Ab)
> print(f"rango(A) = {rango_A}")
> print(f"rango([A|b]) = {rango_Ab}")
> 
> # Sistema homogéneo
> A_hom = np.array([[1, 2, 3],
>                   [2, 4, 6],
>                   [1, 2, 3]])
> # Encontrar espacio nulo (soluciones de Ax = 0)
> from scipy.linalg import null_space
> null = null_space(A_hom)
> print("Base del espacio nulo:", null)
> ```

> 
> x + y + z = 1

> x + 3y + λ²z = λ²

> SOLUCIÓN:
> 
> Matriz aumentada:
> ⎡ 1  1   1  | 1  ⎤
> ⎢ 1  2   λ  | λ  ⎥
> ⎣ 1  3   λ² | λ² ⎦
> 
> F₂ → F₂ - F₁:
> ⎡ 1  1      1     | 1     ⎤
> ⎢ 0  1    λ-1     | λ-1   ⎥
> ⎣ 1  3      λ²    | λ²    ⎦

> F₃ → F₃ - F₁:
> ⎡ 1  1      1     | 1     ⎤
> ⎢ 0  1    λ-1     | λ-1   ⎥
> ⎣ 0  2    λ²-1    | λ²-1  ⎦
> 
> F₃ → F₃ - 2F₂:
> ⎡ 1  1      1           | 1         ⎤
> ⎢ 0  1    λ-1           | λ-1       ⎥
> ⎣ 0  0  λ²-1-2(λ-1)     | λ²-1-2(λ-1)⎦
>

> λ² - 1 - 2λ + 2 = λ² - 2λ + 1 = (λ-1)²
> 
> ⎡ 1  1    1     | 1     ⎤
> ⎢ 0  1   λ-1    | λ-1   ⎥
> ⎣ 0  0  (λ-1)²  |(λ-1)² ⎦
> 
> DISCUSIÓN:
> 
> Caso 1: λ ≠ 1
>   (λ-1)² ≠ 0
>   Tercera fila: (λ-1)²z = (λ-1)²
>                 z = 1
>

>                 y = 0
>   
>   Primera fila: x + 0 + 1 = 1
>                 x = 0
>   
>   SOLUCIÓN ÚNICA: (x,y,z) = (0, 0, 1)

>   Tercera fila: 0·z = 0  (identidad 0 = 0)

>                 y = 0

>

>   x = 1 - t
>   y = 0

> x + 2y - z + w = 0
> 
> Variables libres: y, z, w (3 grados de libertad)

> 
> Despejar: x = -2y + z - w
>

> ⎡ x ⎤   ⎡-2y + z - w⎤   ⎡-2⎤       ⎡ 1⎤       ⎡-1⎤
> ⎢ y ⎥ = ⎢     y     ⎥ = ⎢ 1⎥·y  +  ⎢ 0⎥·z  +  ⎢ 0⎥·w
> ⎢ z ⎥   ⎢     z     ⎥   ⎢ 0⎥       ⎢ 1⎥       ⎢ 0⎥
> ⎣ w ⎦   ⎣     w     ⎦   ⎣ 0⎦       ⎣ 0⎦       ⎣ 1⎦
> 
> BASE DEL ESPACIO SOLUCIÓN:
>      ⎡-2⎤      ⎡ 1⎤      ⎡-1⎤
> v₁ = ⎢ 1⎥, v₂ =⎢ 0⎥, v₃ =⎢ 0⎥
>      ⎢ 0⎥      ⎢ 1⎥      ⎢ 0⎥
>      ⎣ 0⎦      ⎣ 0⎦      ⎣ 1⎦
> 
> Dimensión = 3
> Nulidad = 3 = 4 - 1 = n - rango(A) ✓
> 
> VERIFICACIÓN (con v₁):
> 1(-2) + 2(1) - 1(0) + 1(0) = -2 + 2 = 0 ✓
> ```

## 🎯 Resumen Ejecutivo

> [!important]- Conceptos Clave **Definición:**
> 
> - Sistema Ax = b: m ecuaciones, n incógnitas
> - Forma matricial compacta
> 
> **Clasificación:**
> 
> - Compatible Determinado: 1 solución
> - Compatible Indeterminado: ∞ soluciones
> - Incompatible: sin solución
> 
> **Criterio (Rouché-Frobenius):**
> 
> - Compatible ⟺ rango(A) = rango([A|b])
> - Determinado ⟺ rango = n
> - Indeterminado ⟺ rango < n
> 
> **Métodos principales:**
> 
> - Gauss: forma escalonada
> - Gauss-Jordan: forma reducida
> - Cramer: determinantes (n pequeño)
> - Factorización: LU, QR, Cholesky
> 
> **Solución homogénea:**
> 
> - Siempre incluye x = 0
> - dim(soluciones) = n - rango(A)
> 
> **Solución general:**
> 
> - x = xₚ + xₕ (particular + homogénea)
