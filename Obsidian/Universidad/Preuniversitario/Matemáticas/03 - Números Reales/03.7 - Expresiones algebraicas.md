# 🔤 Expresiones Algebraicas

## 🌟 Concepto Fundamental

> [!info]- Visión General **Las expresiones algebraicas son combinaciones de números, variables y operaciones matemáticas que representan valores numéricos y relaciones generales.**
> 
> **Elementos clave:**
> 
> - **Variables:** Símbolos que representan cantidades desconocidas o generales
> - **Constantes:** Valores numéricos fijos
> - **Operaciones:** Suma, resta, multiplicación, división, potenciación
> - **Términos:** Partes separadas por suma o resta
> - **Coeficientes:** Números que multiplican a las variables

### 📖 Contexto Histórico

> [!note]- Desarrollo Histórico del Álgebra
> 
> **Álgebra Antigua (2000 a.C. - 600 d.C.):**
> 
> - **Babilonios (1800 a.C.):** Problemas algebraicos en tablillas cuneiformes
>     - Resolución de ecuaciones cuadráticas geométricamente
>     - Sin notación simbólica, todo en palabras
> - **Egipcios (1650 a.C.):** Papiro de Rhind
>     - Método de "falsa posición" para resolver ecuaciones
> - **Diofanto (250 d.C.):** "Arithmetica"
>     - Primeros símbolos algebraicos rudimentarios
>     - Ecuaciones diofánticas (soluciones enteras)
> 
> **Álgebra Medieval (600 - 1500):**
> 
> - **Al-Khwarizmi (820):** "Al-jabr wa'l-muqābala"
>     - Origen de la palabra "álgebra"
>     - Métodos sistemáticos para resolver ecuaciones
>     - Álgebra retórica (sin símbolos)
> - **Omar Khayyam (1100):** Soluciones geométricas de cúbicas
> - **Fibonacci (1202):** Introduce álgebra árabe en Europa
> 
> **Álgebra Simbólica (1500 - 1800):**
> 
> - **Viète (1591):** Introduce notación simbólica
>     - Variables representadas por letras
>     - Distinción entre conocido (consonantes) y desconocido (vocales)
> - **Descartes (1637):** Notación moderna
>     - Variables: x, y, z para incógnitas
>     - a, b, c para constantes
>     - Exponentes: x², x³
> - **Cardano, Tartaglia, Ferrari (1500s):** Fórmulas para cúbicas y cuárticas
> 
> **Álgebra Moderna (1800 - presente):**
> 
> - **Gauss (1799):** Teorema fundamental del álgebra
> - **Galois, Abel (1820s):** Teoría de grupos, ecuaciones no resolubles por radicales
> - **Boole (1854):** Álgebra de la lógica
> - **Siglo XX:** Álgebra abstracta, estructuras algebraicas

## 📐 Definiciones Básicas

### 🔍 Componentes de una Expresión Algebraica

> [!success]- Elementos Fundamentales
> 
> **Variable:**
> 
> ```
> Símbolo (usualmente una letra) que representa un valor que puede cambiar
> o que es desconocido
> 
> Ejemplos: x, y, z, t, n, a, b
> ```
> 
> **Constante:**
> 
> ```
> Valor numérico fijo que no cambia
> 
> Ejemplos: 5, -3, π, √2, 1/2
> ```
> 
> **Término:**
> 
> ```
> Producto de constantes y variables
> 
> Ejemplos:
> 5x          (coeficiente 5, variable x)
> -3x²y       (coeficiente -3, variables x², y)
> 7           (término constante)
> xy          (coeficiente 1 implícito)
> ```
> 
> **Coeficiente:**
> 
> ```
> Número que multiplica a la parte literal de un término
> 
> En 5x²:     coeficiente = 5
> En -3xy:    coeficiente = -3
> En x:       coeficiente = 1 (implícito)
> En -x:      coeficiente = -1 (implícito)
> ```
> 
> **Parte literal:**
> 
> ```
> Producto de las variables en un término
> 
> En 5x²:     parte literal = x²
> En -3xy:    parte literal = xy
> En 7:       parte literal = 1 (sin variables)
> ```
> 
> **Grado de un término:**
> 
> ```
> Suma de los exponentes de todas las variables
> 
> 5x²:        grado 2
> -3x²y:      grado 3 (2+1)
> 7xy³z²:     grado 6 (1+3+2)
> 8:          grado 0 (término constante)
> ```

> [!example]- Ejemplos de Expresiones Algebraicas
> 
> **Expresión simple:**
> 
> ```
> 3x + 5
> 
> Términos: 3x, 5
> Variables: x
> Constantes: 3, 5
> Coeficientes: 3 (del término 3x)
> Grado: 1
> ```
> 
> **Expresión con múltiples términos:**
> 
> ```
> 2x² - 5x + 7
> 
> Términos: 2x², -5x, 7
> Coeficiente de x²: 2
> Coeficiente de x: -5
> Término independiente: 7
> Grado: 2
> ```
> 
> **Expresión con varias variables:**
> 
> ```
> 4x²y - 3xy² + 2x - y + 6
> 
> Término 1: 4x²y     (grado 3, coef. 4)
> Término 2: -3xy²    (grado 3, coef. -3)
> Término 3: 2x       (grado 1, coef. 2)
> Término 4: -y       (grado 1, coef. -1)
> Término 5: 6        (grado 0, coef. 6)
> 
> Grado de la expresión: 3
> ```

### 🎯 Clasificación por Número de Términos

> [!note]- Tipos de Expresiones según Términos
> 
> **Monomio:**
> 
> ```
> Expresión algebraica con un solo término
> 
> Ejemplos:
> 5x
> -3x²y
> 7
> (2/3)abc
> πr²
> ```
> 
> **Binomio:**
> 
> ```
> Expresión algebraica con dos términos
> 
> Ejemplos:
> x + 5
> 3a - 2b
> x² - 4
> 2x²y + 3xy²
> ```
> 
> **Trinomio:**
> 
> ```
> Expresión algebraica con tres términos
> 
> Ejemplos:
> x² + 2x + 1
> a² - 2ab + b²
> 3x² - 5x + 2
> ```
> 
> **Polinomio:**
> 
> ```
> Expresión algebraica con uno o más términos (término general)
> 
> Forma general en una variable:
> P(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + ... + a₂x² + a₁x + a₀
> 
> donde aᵢ son coeficientes constantes y n es el grado
> 
> Ejemplos:
> x³ - 2x² + 5x - 7
> 4x⁴ + 3x² - x + 9
> ```
> 
> **Multinomio:**
> 
> ```
> Polinomio con muchos términos (término informal)
> 
> Ejemplo:
> x⁵ - 3x⁴ + 2x³ - x² + 7x - 11
> ```

### 📊 Clasificación por Grado

> [!note]- Tipos de Polinomios según Grado
> 
> **Grado 0 - Constante:**
> 
> ```
> P(x) = c    donde c ≠ 0
> 
> Ejemplos: 5, -3, π, √2
> ```
> 
> **Grado 1 - Lineal:**
> 
> ```
> P(x) = ax + b    donde a ≠ 0
> 
> Ejemplos:
> 2x + 3
> -x + 5
> (1/2)x - 7
> ```
> 
> **Grado 2 - Cuadrático:**
> 
> ```
> P(x) = ax² + bx + c    donde a ≠ 0
> 
> Ejemplos:
> x² + 2x + 1
> 3x² - 5x + 2
> -x² + 4
> ```
> 
> **Grado 3 - Cúbico:**
> 
> ```
> P(x) = ax³ + bx² + cx + d    donde a ≠ 0
> 
> Ejemplos:
> x³ - 2x² + x - 1
> 2x³ + 5
> ```
> 
> **Grado 4 - Cuártico:**
> 
> ```
> P(x) = ax⁴ + bx³ + cx² + dx + e    donde a ≠ 0
> 
> Ejemplo:
> x⁴ - 3x² + 2
> ```
> 
> **Grado 5 - Quíntico:**
> 
> ```
> P(x) = ax⁵ + ...    donde a ≠ 0
> 
> Ejemplo:
> x⁵ - 5x³ + 4x
> ```
> 
> **Grado n - Polinomio de grado n:**
> 
> ```
> P(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + ... + a₁x + a₀    donde aₙ ≠ 0
> ```

## ➕ Operaciones con Expresiones Algebraicas

### 🔄 Suma y Resta de Términos Semejantes

> [!important]- Términos Semejantes
> 
> **Definición:** Dos términos son semejantes si tienen la misma parte literal (mismas variables con los mismos exponentes).
> 
> **Regla de suma/resta:**
> 
> ```
> Solo se pueden sumar o restar términos semejantes
> Se suman/restan los coeficientes y se conserva la parte literal
> ```
> 
> **Ejemplos de términos semejantes:**
> 
> ```
> 3x y 5x          (ambos tienen x¹)
> 2x² y -7x²       (ambos tienen x²)
> 4xy y -xy        (ambos tienen xy)
> 5x²y y 3x²y      (ambos tienen x²y)
> ```
> 
> **Ejemplos de términos NO semejantes:**
> 
> ```
> 3x y 5x²         (diferentes exponentes de x)
> 2xy y 3x         (diferentes variables)
> 4x²y y 4xy²      (diferentes exponentes)
> ```

> [!example]- Ejemplos de Suma y Resta
> 
> **Ejemplo 1: Suma de términos semejantes**
> 
> ```
> 3x + 5x = (3 + 5)x = 8x
> 
> 2x² + 7x² = (2 + 7)x² = 9x²
> 
> 4xy + 3xy - 2xy = (4 + 3 - 2)xy = 5xy
> ```
> 
> **Ejemplo 2: Expresión con términos semejantes y no semejantes**
> 
> ```
> 3x² + 5x - 2x² + 7x - 4
> 
> Agrupar términos semejantes:
> (3x² - 2x²) + (5x + 7x) - 4
> 
> Simplificar:
> x² + 12x - 4
> ```
> 
> **Ejemplo 3: Múltiples variables**
> 
> ```
> 5xy + 3x²y - 2xy + 4x²y - 7xy
> 
> Términos con xy: 5xy - 2xy - 7xy = -4xy
> Términos con x²y: 3x²y + 4x²y = 7x²y
> 
> Resultado: 7x²y - 4xy
> ```
> 
> **Ejemplo 4: Expresión compleja**
> 
> ```
> 2x³ - 5x² + 3x - 1 + 4x² + 2x³ - 7x + 5
> 
> Términos con x³: 2x³ + 2x³ = 4x³
> Términos con x²: -5x² + 4x² = -x²
> Términos con x: 3x - 7x = -4x
> Constantes: -1 + 5 = 4
> 
> Resultado: 4x³ - x² - 4x + 4
> ```

### ✖️ Multiplicación de Expresiones

> [!success]- Reglas de Multiplicación
> 
> **Ley de exponentes:**
> 
> ```
> xᵃ · xᵇ = xᵃ⁺ᵇ
> 
> Ejemplos:
> x² · x³ = x⁵
> x · x⁴ = x⁵
> y³ · y = y⁴
> ```
> 
> **Multiplicación de monomios:**
> 
> ```
> (a·xᵐ) · (b·xⁿ) = (ab)·xᵐ⁺ⁿ
> 
> Proceso:
> 1. Multiplicar coeficientes
> 2. Sumar exponentes de variables iguales
> 3. Conservar variables diferentes
> ```
> 
> **Propiedad distributiva:**
> 
> ```
> a(b + c) = ab + ac
> (a + b)(c + d) = ac + ad + bc + bd
> ```

> [!example]- Ejemplos de Multiplicación
> 
> **Ejemplo 1: Monomio por monomio**
> 
> ```
> (3x²) · (5x³) = (3·5) · (x²·x³)
>               = 15x⁵
> 
> (-2xy) · (4x²y³) = (-2·4) · (x·x²) · (y·y³)
>                   = -8x³y⁴
> ```
> 
> **Ejemplo 2: Monomio por polinomio**
> 
> ```
> 3x(2x² - 5x + 4)
> 
> = 3x·2x² + 3x·(-5x) + 3x·4
> = 6x³ - 15x² + 12x
> ```
> 
> **Ejemplo 3: Binomio por binomio**
> 
> ```
> (x + 3)(x + 5)
> 
> = x·x + x·5 + 3·x + 3·5
> = x² + 5x + 3x + 15
> = x² + 8x + 15
> ```
> 
> **Ejemplo 4: Binomio por trinomio**
> 
> ```
> (x + 2)(x² - 3x + 5)
> 
> = x·x² + x·(-3x) + x·5 + 2·x² + 2·(-3x) + 2·5
> = x³ - 3x² + 5x + 2x² - 6x + 10
> = x³ - x² - x + 10
> ```
> 
> **Ejemplo 5: Con varias variables**
> 
> ```
> (2xy)(3x²y - 5xy² + 4)
> 
> = 2xy·3x²y + 2xy·(-5xy²) + 2xy·4
> = 6x³y² - 10x²y³ + 8xy
> ```

### ➗ División de Expresiones

> [!success]- Reglas de División
> 
> **Ley de exponentes:**
> 
> ```
> xᵃ ÷ xᵇ = xᵃ⁻ᵇ    si a ≥ b
> xᵃ ÷ xᵇ = 1/xᵇ⁻ᵃ   si a < b
> 
> Ejemplos:
> x⁵ ÷ x² = x³
> x² ÷ x⁵ = 1/x³
> y⁴ ÷ y = y³
> ```
> 
> **División de monomios:**
> 
> ```
> (a·xᵐ) ÷ (b·xⁿ) = (a/b)·xᵐ⁻ⁿ
> 
> Proceso:
> 1. Dividir coeficientes
> 2. Restar exponentes de variables iguales
> 3. Variables solo en numerador se conservan
> 4. Variables solo en denominador pasan con exponente negativo
> ```

> [!example]- Ejemplos de División
> 
> **Ejemplo 1: Monomio entre monomio**
> 
> ```
> 12x⁵ ÷ 3x²
> 
> = (12÷3) · (x⁵÷x²)
> = 4x³
> ```
> 
> **Ejemplo 2: Con varias variables**
> 
> ```
> 18x³y⁴ ÷ 6xy²
> 
> = (18÷6) · (x³÷x) · (y⁴÷y²)
> = 3x²y²
> ```
> 
> **Ejemplo 3: Polinomio entre monomio**
> 
> ```
> (15x⁴ - 10x³ + 5x²) ÷ 5x²
> 
> = (15x⁴÷5x²) - (10x³÷5x²) + (5x²÷5x²)
> = 3x² - 2x + 1
> ```
> 
> **Ejemplo 4: Con exponentes menores en numerador**
> 
> ```
> 6x²y ÷ 3x⁴y²
> 
> = (6÷3) · (x²÷x⁴) · (y÷y²)
> = 2 · (1/x²) · (1/y)
> = 2/(x²y)
> ```

## 🎨 Productos Notables

### 📐 Binomio al Cuadrado

> [!important]- Fórmulas del Cuadrado
> 
> **Cuadrado de una suma:**
> 
> ```
> (a + b)² = a² + 2ab + b²
> 
> Demostración:
> (a + b)² = (a + b)(a + b)
>          = a·a + a·b + b·a + b·b
>          = a² + 2ab + b²
> ```
> 
> **Cuadrado de una diferencia:**
> 
> ```
> (a - b)² = a² - 2ab + b²
> 
> Demostración:
> (a - b)² = (a - b)(a - b)
>          = a·a + a·(-b) + (-b)·a + (-b)·(-b)
>          = a² - 2ab + b²
> ```
> 
> **Regla mnemotécnica:**
> 
> ```
> (primer término)² ± 2(primer término)(segundo término) + (segundo término)²
> ```

> [!example]- Ejemplos de Binomio al Cuadrado
> 
> **Ejemplo 1:**
> 
> ```
> (x + 5)²
> 
> = x² + 2·x·5 + 5²
> = x² + 10x + 25
> ```
> 
> **Ejemplo 2:**
> 
> ```
> (x - 3)²
> 
> = x² - 2·x·3 + 3²
> = x² - 6x + 9
> ```
> 
> **Ejemplo 3:**
> 
> ```
> (2x + 3y)²
> 
> = (2x)² + 2·(2x)·(3y) + (3y)²
> = 4x² + 12xy + 9y²
> ```
> 
> **Ejemplo 4:**
> 
> ```
> (3a - 4b)²
> 
> = (3a)² - 2·(3a)·(4b) + (4b)²
> = 9a² - 24ab + 16b²
> ```
> 
> **Ejemplo 5:**
> 
> ```
> (x² + 2)²
> 
> = (x²)² + 2·x²·2 + 2²
> = x⁴ + 4x² + 4
> ```

### 🔲 Diferencia de Cuadrados

> [!important]- Fórmula de Diferencia de Cuadrados
> 
> **Fórmula:**
> 
> ```
> a² - b² = (a + b)(a - b)
> 
> Demostración:
> (a + b)(a - b) = a·a + a·(-b) + b·a + b·(-b)
>                = a² - ab + ab - b²
>                = a² - b²
> ```
> 
> **Interpretación:**
> 
> ```
> La diferencia de dos cuadrados se factoriza como el producto
> de la suma por la diferencia de las bases
> ```
> 
> **Uso:**
> 
> - Factorización rápida
> - Simplificación de expresiones
> - Cálculo mental

> [!example]- Ejemplos de Diferencia de Cuadrados
> 
> **Ejemplo 1:**
> 
> ```
> x² - 9 = x² - 3²
>        = (x + 3)(x - 3)
> ```
> 
> **Ejemplo 2:**
> 
> ```
> 4x² - 25 = (2x)² - 5²
>          = (2x + 5)(2x - 5)
> ```
> 
> **Ejemplo 3:**
> 
> ```
> 9a² - 16b² = (3a)² - (4b)²
>            = (3a + 4b)(3a - 4b)
> ```
> 
> **Ejemplo 4:**
> 
> ```
> x⁴ - 1 = (x²)² - 1²
>        = (x² + 1)(x² - 1)
>        = (x² + 1)(x + 1)(x - 1)
> 
> (Aplicando dos veces la fórmula)
> ```
> 
> **Ejemplo 5: Cálculo mental**
> 
> ```
> 103² - 97²
> 
> = (103 + 97)(103 - 97)
> = 200 · 6
> = 1200
> ```

### 🔶 Binomio al Cubo

> [!important]- Fórmulas del Cubo
> 
> **Cubo de una suma:**
> 
> ```
> (a + b)³ = a³ + 3a²b + 3ab² + b³
> 
> Demostración:
> (a + b)³ = (a + b)(a + b)²
>          = (a + b)(a² + 2ab + b²)
>          = a³ + 2a²b + ab² + a²b + 2ab² + b³
>          = a³ + 3a²b + 3ab² + b³
> ```
> 
> **Cubo de una diferencia:**
> 
> ```
> (a - b)³ = a³ - 3a²b + 3ab² - b³
> 
> Demostración similar con signos alternados
> ```
> 
> **Regla mnemotécnica:**
> 
> ```
> (a ± b)³ = a³ ± 3a²b + 3ab² ± b³
> 
> Los signos siguen el patrón: + - + - o + + + +
> Los coeficientes son: 1, 3, 3, 1 (triángulo de Pascal)
> ```

> [!example]- Ejemplos de Binomio al Cubo
> 
> **Ejemplo 1:**
> 
> ```
> (x + 2)³
> 
> = x³ + 3·x²·2 + 3·x·2² + 2³
> = x³ + 6x² + 12x + 8
> ```
> 
> **Ejemplo 2:**
> 
> ```
> (x - 3)³
> 
> = x³ - 3·x²·3 + 3·x·3² - 3³
> = x³ - 9x² + 27x - 27
> ```
> 
> **Ejemplo 3:**
> 
> ```
> (2a + b)³
> 
> = (2a)³ + 3·(2a)²·b + 3·(2a)·b² + b³
> = 8a³ + 12a²b + 6ab² + b³
> ```
> 
> **Ejemplo 4:**
> 
> ```
> (3x - 2y)³
> 
> = (3x)³ - 3·(3x)²·(2y) + 3·(3x)·(2y)² - (2y)³
> = 27x³ - 54x²y + 36xy² - 8y³
> ```

### 🔺 Suma y Diferencia de Cubos

> [!important]- Fórmulas de Cubos
> 
> **Suma de cubos:**
> 
> ```
> a³ + b³ = (a + b)(a² - ab + b²)
> 
> Verificación:
> (a + b)(a² - ab + b²) = a³ - a²b + ab² + a²b - ab² + b³
>                        = a³ + b³
> ```
> 
> **Diferencia de cubos:**
> 
> ```
> a³ - b³ = (a - b)(a² + ab + b²)
> 
> Verificación:
> (a - b)(a² + ab + b²) = a³ + a²b + ab² - a²b - ab² - b³
>                        = a³ - b³
> ```
> 
> **Regla mnemotécnica:**
> 
> ```
> a³ ± b³ = (a ± b)(a² ∓ ab + b²)
> 
> Nota: El signo del medio en el trinomio es OPUESTO al de la suma/diferencia
> ```

> [!example]- Ejemplos de Suma y Diferencia de Cubos
> 
> **Ejemplo 1:**
> 
> ```
> x³ + 8 = x³ + 2³
>        = (x + 2)(x² - 2x + 4)
> ```
> 
> **Ejemplo 2:**
> 
> ```
> x³ - 27 = x³ - 3³
>         = (x - 3)(x² + 3x + 9)
> ```
> 
> **Ejemplo 3:**
> 
> ```
> 8a³ + 27b³ = (2a)³ + (3b)³
>            = (2a + 3b)((2a)² - (2a)(3b) + (3b)²)
>            = (2a + 3b)(4a² - 6ab + 9b²)
> ```
> 
> **Ejemplo 4:**
> 
> ```
> 64x³ - 125y³ = (4x)³ - (5y)³
>              = (4x - 5y)((4x)² + (4x)(5y) + (5y)²)
>              = (4x - 5y)(16x² + 20xy + 25y²)
> ```

### 🔷 Producto de Binomios con Término Común

> [!tip]- Fórmula Especial
> 
> **Fórmula:**
> 
> ```
> (x + a)(x + b) = x² + (a + b)x + ab
> 
> Demostración:
> (x + a)(x + b) = x² + bx + ax + ab
>                = x² + (a + b)x + ab
> ```
> 
> **Regla:**
> 
> ```
> El coeficiente de x es la SUMA de los términos constantes
> El término independiente es el PRODUCTO de los términos constantes
> ```

> [!example]- Ejemplos de Binomios con Término Común
> 
> **Ejemplo 1:**
> 
> ```
> (x + 3)(x + 5)
> 
> = x² + (3 + 5)x + (3)(5)
> = x² + 8x + 15
> ```
> 
> **Ejemplo 2:**
> 
> ```
> (x - 2)(x + 7)
> 
> = x² + (-2 + 7)x + (-2)(7)
> = x² + 5x - 14
> ```
> 
> **Ejemplo 3:**
> 
> ```
> (x - 4)(x - 6)
> 
> = x² + (-4 - 6)x + (-4)(-6)
> = x² - 10x + 24
> ```
> 
> **Ejemplo 4:**
> 
> ```
> (x + 1)(x - 9)
> 
> = x² + (1 - 9)x + (1)(-9)
> = x² - 8x - 9
> ```

## 🔨 Factorización

### 🎯 Concepto de Factorización

> [!success]- ¿Qué es Factorizar?
> 
> **Definición:** Factorizar es expresar un polinomio como producto de factores más simples.
> 
> **Analogía:**
> 
> ```
> Así como 12 = 2 × 2 × 3 (factorización en números primos)
> 
> x² - 4 = (x + 2)(x - 2) (factorización algebraica)
> ```
> 
> **Objetivo:**
> 
> - Simplificar expresiones
> - Resolver ecuaciones
> - Encontrar raíces de polinomios
> - Simplificar fracciones algebraicas
> 
> **Proceso inverso:**
> 
> ```
> Multiplicación ←→ Factorización
> 
> (x + 2)(x - 3) = x² - x - 6
>     ↓                 ↑
> Desarrollar      Factorizar
> ```

### 🔍 Factor Común

> [!important]- Método del Factor Común
> 
> **Principio:** Si todos los términos tienen un factor común, se puede extraer.
> 
> **Proceso:**
> 
> ```
> 1. Identificar el factor común (MCD de coeficientes y variables)
> 2. Dividir cada término entre el factor común
> 3. Escribir como producto: factor común × (resto)
> ```
> 
> **Fórmula general:**
> 
> ```
> ab + ac = a(b + c)
> ```

> [!example]- Ejemplos de Factor Común
> 
> **Ejemplo 1: Factor común numérico**
> 
> ```
> 6x + 9
> 
> Factor común: 3
> 
> = 3(2x + 3)
> 
> Verificación: 3(2x) + 3(3) = 6x + 9 ✓
> ```
> 
> **Ejemplo 2: Factor común con variable**
> 
> ```
> x² + 3x
> 
> Factor común: x
> 
> = x(x + 3)
> 
> Verificación: x(x) + x(3) = x² + 3x ✓
> ```
> 
> **Ejemplo 3: Factor común compuesto**
> 
> ```
> 12x³ - 18x² + 6x
> 
> Factor común: 6x
> 
> = 6x(2x² - 3x + 1)
> 
> Proceso:
> 12x³ ÷ 6x = 2x²
> -18x² ÷ 6x = -3x
> 6x ÷ 6x = 1
> ```
> 
> **Ejemplo 4: Con varias variables**
> 
> ```
> 15x²y³ - 10xy² + 5xy
> 
> Factor común: 5xy
> 
> = 5xy(3xy² - 2y + 1)
> ```
> 
> **Ejemplo 5: Factor común negativo**
> 
> ```
> -4x² - 8x - 12
> 
> Factor común: -4
> 
> = -4(x² + 2x + 3)
> 
> Nota: Es común extraer el signo negativo
> ```

### 🔲 Factorización por Agrupación

> [!important]- Método de Agrupación
> 
> **Principio:** Cuando hay 4 términos, agrupar de 2 en 2 y buscar factor común en cada grupo.
> 
> **Proceso:**
> 
> ```
> 1. Agrupar términos (usualmente los dos primeros y los dos últimos)
> 2. Extraer factor común de cada grupo
> 3. Si queda un factor común entre los grupos, extraerlo
> ```
> 
> **Condición necesaria:** Después de extraer factores en cada grupo, debe quedar un binomio común.

> [!example]- Ejemplos de Agrupación
> 
> **Ejemplo 1:**
> 
> ```
> x³ + 3x² + 2x + 6
> 
> Agrupar: (x³ + 3x²) + (2x + 6)
> 
> Factor común en cada grupo:
> x²(x + 3) + 2(x + 3)
> 
> Factor común (x + 3):
> = (x + 3)(x² + 2)
> ```
> 
> **Ejemplo 2:**
> 
> ```
> 2ax - 3ay + 2bx - 3by
> 
> Agrupar: (2ax - 3ay) + (2bx - 3by)
> 
> Factor común:
> a(2x - 3y) + b(2x - 3y)
> 
> = (2x - 3y)(a + b)
> ```
> 
> **Ejemplo 3:**
> 
> ```
> x³ - 2x² - 3x + 6
> 
> Agrupar: (x³ - 2x²) + (-3x + 6)
> 
> Factor común:
> x²(x - 2) - 3(x - 2)
> 
> = (x - 2)(x² - 3)
> ```
> 
> **Ejemplo 4: Se necesita reordenar**
> 
> ```
> ax + by + ay + bx
> 
> Reordenar: ax + ay + bx + by
> 
> Agrupar: (ax + ay) + (bx + by)
> 
> Factor común:
> a(x + y) + b(x + y)
> 
> = (x + y)(a + b)
> ```

### 🎨 Factorización de Trinomios

> [!important]- Trinomio Cuadrado Perfecto
> 
> **Reconocimiento:** Un trinomio a² + 2ab + b² (o a² - 2ab + b²) es cuadrado perfecto.
> 
> **Criterio de verificación:**
> 
> ```
> 1. El primer término es un cuadrado perfecto: a²
> 2. El tercer término es un cuadrado perfecto: b²
> 3. El término medio es el doble del producto: 2ab
> ```
> 
> **Factorización:**
> 
> ```
> a² + 2ab + b² = (a + b)²
> a² - 2ab + b² = (a - b)²
> ```

> [!example]- Ejemplos de Trinomios Cuadrados Perfectos
> 
> **Ejemplo 1:**
> 
> ```
> x² + 6x + 9
> 
> Verificar:
> x² es cuadrado de x ✓
> 9 es cuadrado de 3 ✓
> 6x = 2(x)(3) ✓
> 
> = (x + 3)²
> ```
> 
> **Ejemplo 2:**
> 
> ```
> 4x² - 12x + 9
> 
> Verificar:
> 4x² = (2x)² ✓
> 9 = 3² ✓
> -12x = -2(2x)(3) ✓
> 
> = (2x - 3)²
> ```
> 
> **Ejemplo 3:**
> 
> ```
> 9a² + 24ab + 16b²
> 
> Verificar:
> 9a² = (3a)² ✓
> 16b² = (4b)² ✓
> 24ab = 2(3a)(4b) ✓
> 
> = (3a + 4b)²
> ```
> 
> **Ejemplo 4: NO es cuadrado perfecto**
> 
> ```
> x² + 5x + 9
> 
> x² = x² ✓
> 9 = 3² ✓
> Pero 5x ≠ 2(x)(3) = 6x ✗
> 
> No es cuadrado perfecto
> ```

### 🔢 Trinomio de la Forma x² + bx + c

> [!important]- Método para x² + bx + c
> 
> **Objetivo:** Factorizar x² + bx + c = (x + p)(x + q)
> 
> **Condiciones:**
> 
> ```
> p + q = b    (suma de p y q es el coeficiente de x)
> p · q = c    (producto de p y q es el término independiente)
> ```
> 
> **Proceso:**
> 
> ```
> 1. Buscar dos números p y q tales que:
>    - Su suma sea b
>    - Su producto sea c
> 2. Escribir: (x + p)(x + q)
> ```
> 
> **Tabla de signos:**
> 
> ```
> Si c > 0:  p y q tienen el mismo signo (el de b)
> Si c < 0:  p y q tienen signos opuestos (el mayor tiene el signo de b)
> ```

> [!example]- Ejemplos de Trinomios x² + bx + c
> 
> **Ejemplo 1:**
> 
> ```
> x² + 5x + 6
> 
> Buscar p y q tales que:
> p + q = 5
> p · q = 6
> 
> Pares que multiplican 6: (1,6), (2,3)
> Par que suma 5: 2 + 3 = 5 ✓
> 
> = (x + 2)(x + 3)
> 
> Verificación: (x + 2)(x + 3) = x² + 3x + 2x + 6 = x² + 5x + 6 ✓
> ```
> 
> **Ejemplo 2:**
> 
> ```
> x² - 7x + 12
> 
> Buscar p y q tales que:
> p + q = -7
> p · q = 12
> 
> Como c > 0 y b < 0, ambos negativos
> Pares: (-1,-12), (-2,-6), (-3,-4)
> Par que suma -7: -3 + (-4) = -7 ✓
> 
> = (x - 3)(x - 4)
> ```
> 
> **Ejemplo 3:**
> 
> ```
> x² + 2x - 15
> 
> Buscar p y q tales que:
> p + q = 2
> p · q = -15
> 
> Como c < 0, signos opuestos
> Pares: (1,-15), (-1,15), (3,-5), (-3,5)
> Par que suma 2: 5 + (-3) = 2 ✓
> 
> = (x + 5)(x - 3)
> ```
> 
> **Ejemplo 4:**
> 
> ```
> x² - x - 20
> 
> Buscar p y q tales que:
> p + q = -1
> p · q = -20
> 
> Pares: (4,-5), (-4,5), (2,-10), (-2,10)
> Par que suma -1: 4 + (-5) = -1 ✓
> 
> = (x + 4)(x - 5)
> ```
> 
> **Ejemplo 5: No factorizable con enteros**
> 
> ```
> x² + 3x + 5
> 
> Buscar p y q tales que:
> p + q = 3
> p · q = 5
> 
> Pares que multiplican 5: (1,5)
> Pero 1 + 5 = 6 ≠ 3
> 
> No se puede factorizar con números enteros
> (Es primo sobre los enteros)
> ```

### 🔷 Trinomio de la Forma ax² + bx + c (a ≠ 1)

> [!important]- Método para ax² + bx + c
> 
> **Método 1: Prueba y error con factores de a y c**
> 
> ```
> ax² + bx + c = (mx + p)(nx + q)
> 
> donde:
> m · n = a
> p · q = c
> mp + nq = b (verificar con productos cruzados)
> ```
> 
> **Método 2: Completar el cuadrado y factorizar**
> 
> **Método 3: Fórmula cuadrática para encontrar raíces**

> [!example]- Ejemplos de Trinomios ax² + bx + c
> 
> **Ejemplo 1:**
> 
> ```
> 2x² + 7x + 3
> 
> Factores de 2: (1,2)
> Factores de 3: (1,3)
> 
> Probar: (2x + 1)(x + 3)
> Verificar término medio: 2x·3 + 1·x = 6x + x = 7x ✓
> 
> = (2x + 1)(x + 3)
> ```
> 
> **Ejemplo 2:**
> 
> ```
> 3x² - 10x + 8
> 
> Factores de 3: (1,3)
> Factores de 8: (1,8), (2,4)
> 
> Como b es negativo y c positivo, ambos términos negativos
> 
> Probar: (3x - 4)(x - 2)
> Verificar: 3x·(-2) + (-4)·x = -6x - 4x = -10x ✓
> 
> = (3x - 4)(x - 2)
> ```
> 
> **Ejemplo 3:**
> 
> ```
> 6x² + x - 2
> 
> Factores de 6: (1,6), (2,3)
> Factores de -2: (1,-2), (-1,2)
> 
> Probar: (2x - 1)(3x + 2)
> Verificar: 2x·2 + (-1)·3x = 4x - 3x = x ✓
> 
> = (2x - 1)(3x + 2)
> ```
> 
> **Ejemplo 4:**
> 
> ```
> 4x² - 9
> 
> Reconocer como diferencia de cuadrados:
> = (2x)² - 3²
> = (2x + 3)(2x - 3)
> ```

### 🎯 Estrategia General de Factorización

> [!tip]- Procedimiento Paso a Paso
> 
> **Orden de verificación:**
> 
> ```
> 1. ¿Hay FACTOR COMÚN?
>    Si sí, extraerlo primero
>    
> 2. ¿Cuántos términos hay?
>    
>    2 términos → Verificar:
>    - Diferencia de cuadrados: a² - b²
>    - Suma/diferencia de cubos: a³ ± b³
>    
>    3 términos → Verificar:
>    - Trinomio cuadrado perfecto
>    - Trinomio x² + bx + c
>    - Trinomio ax² + bx + c
>    
>    4 términos → Intentar:
>    - Agrupación
>    
>    Más términos → Buscar patrones especiales
>    
> 3. ¿Se puede FACTORIZAR MÁS?
>    Verificar cada factor resultante
> ```

> [!example]- Ejemplos de Estrategia General
> 
> **Ejemplo 1: Factor común + diferencia de cuadrados**
> 
> ```
> 3x³ - 12x
> 
> Paso 1: Factor común
> = 3x(x² - 4)
> 
> Paso 2: Factorizar x² - 4
> = 3x(x + 2)(x - 2)
> ```
> 
> **Ejemplo 2: Factor común + trinomio**
> 
> ```
> 2x³ + 8x² + 6x
> 
> Paso 1: Factor común
> = 2x(x² + 4x + 3)
> 
> Paso 2: Factorizar trinomio
> Buscar p, q: p + q = 4, p·q = 3
> p = 1, q = 3
> 
> = 2x(x + 1)(x + 3)
> ```
> 
> **Ejemplo 3: Agrupación**
> 
> ```
> x³ - 3x² - 4x + 12
> 
> Agrupar: (x³ - 3x²) + (-4x + 12)
> = x²(x - 3) - 4(x - 3)
> = (x - 3)(x² - 4)
> = (x - 3)(x + 2)(x - 2)
> ```
> 
> **Ejemplo 4: Complejo**
> 
> ```
> 4x⁴ - 36x²
> 
> Paso 1: Factor común
> = 4x²(x² - 9)
> 
> Paso 2: Diferencia de cuadrados
> = 4x²(x + 3)(x - 3)
> ```

## 🔄 Simplificación de Expresiones

### 📝 Reducción de Términos Semejantes

> [!success]- Proceso de Simplificación
> 
> **Pasos:**
> 
> ```
> 1. Identificar términos semejantes
> 2. Agrupar términos semejantes
> 3. Sumar/restar coeficientes
> 4. Conservar parte literal
> 5. Ordenar resultado (por grado decreciente)
> ```
> 
> **Orden estándar:**
> 
> ```
> - Términos ordenados por grado decreciente
> - Dentro del mismo grado, orden alfabético de variables
> ```

> [!example]- Ejemplos de Simplificación
> 
> **Ejemplo 1:**
> 
> ```
> 5x + 3y - 2x + 7y - x + 4
> 
> Agrupar términos con x: 5x - 2x - x = 2x
> Agrupar términos con y: 3y + 7y = 10y
> Término independiente: 4
> 
> = 2x + 10y + 4
> ```
> 
> **Ejemplo 2:**
> 
> ```
> 3x² - 5xy + 2y² + 7xy - x² + 3y²
> 
> Términos con x²: 3x² - x² = 2x²
> Términos con xy: -5xy + 7xy = 2xy
> Términos con y²: 2y² + 3y² = 5y²
> 
> = 2x² + 2xy + 5y²
> ```
> 
> **Ejemplo 3: Con paréntesis**
> 
> ```
> 3(2x - 5) - 2(x + 3) + 4(x - 1)
> 
> Eliminar paréntesis:
> = 6x - 15 - 2x - 6 + 4x - 4
> 
> Agrupar:
> Términos con x: 6x - 2x + 4x = 8x
> Constantes: -15 - 6 - 4 = -25
> 
> = 8x - 25
> ```

### 🔀 Operaciones Combinadas

> [!important]- Orden de Operaciones
> 
> **Jerarquía (PEMDAS/BODMAS):**
> 
> ```
> 1. Paréntesis/Corchetes/Llaves
> 2. Exponentes/Potencias
> 3. Multiplicación y División (de izquierda a derecha)
> 4. Adición y Sustracción (de izquierda a derecha)
> ```
> 
> **Reglas con signos:**
> 
> ```
> + · + = +
> + · - = -
> - · + = -
> - · - = +
> ```

> [!example]- Ejemplos de Operaciones Combinadas
> 
> **Ejemplo 1:**
> 
> ```
> 2x(3x - 5) - 3(x² - 2x + 1)
> 
> Paso 1: Multiplicar
> = 6x² - 10x - 3x² + 6x - 3
> 
> Paso 2: Agrupar términos semejantes
> = (6x² - 3x²) + (-10x + 6x) - 3
> = 3x² - 4x - 3
> ```
> 
> **Ejemplo 2:**
> 
> ```
> (x + 2)² - (x - 3)(x + 1)
> 
> Paso 1: Desarrollar productos notables
> = (x² + 4x + 4) - (x² + x - 3x - 3)
> = x² + 4x + 4 - x² - x + 3x + 3
> 
> Paso 2: Simplificar
> = (x² - x²) + (4x - x + 3x) + (4 + 3)
> = 6x + 7
> ```
> 
> **Ejemplo 3:**
> 
> ```
> 3[2x - (x + 1)] - 2[3 - (x - 2)]
> 
> Paso 1: Paréntesis internos
> = 3[2x - x - 1] - 2[3 - x + 2]
> = 3[x - 1] - 2[5 - x]
> 
> Paso 2: Corchetes
> = 3x - 3 - 10 + 2x
> 
> Paso 3: Simplificar
> = 5x - 13
> ```

## 📊 Evaluación de Expresiones

### 🔢 Sustitución de Valores

> [!success]- Proceso de Evaluación
> 
> **Pasos:**
> 
> ```
> 1. Escribir la expresión algebraica
> 2. Sustituir cada variable por su valor numérico
> 3. Usar paréntesis alrededor de valores negativos
> 4. Realizar operaciones siguiendo el orden correcto
> 5. Simplificar hasta obtener un número
> ```
> 
> **Precauciones:**
> 
> ```
> - Usar paréntesis para valores negativos
> - Respetar el orden de operaciones
> - Cuidar los signos en operaciones
> ```

> [!example]- Ejemplos de Evaluación
> 
> **Ejemplo 1:**
> 
> ```
> Evaluar: 3x² - 5x + 2  para x = 4
> 
> = 3(4)² - 5(4) + 2
> = 3(16) - 20 + 2
> = 48 - 20 + 2
> = 30
> ```
> 
> **Ejemplo 2: Con valor negativo**
> 
> ```
> Evaluar: 2x² + 7x - 3  para x = -2
> 
> = 2(-2)² + 7(-2) - 3
> = 2(4) - 14 - 3
> = 8 - 14 - 3
> = -9
> ```
> 
> **Ejemplo 3: Varias variables**
> 
> ```
> Evaluar: 2xy - 3x + 4y  para x = 3, y = -2
> 
> = 2(3)(-2) - 3(3) + 4(-2)
> = -12 - 9 - 8
> = -29
> ```
> 
> **Ejemplo 4: Con fracciones**
> 
> ```
> Evaluar: (x² - y²)/(x + y)  para x = 5, y = 3
> 
> = (5² - 3²)/(5 + 3)
> = (25 - 9)/8
> = 16/8
> = 2
> ```

### 🎲 Aplicaciones Prácticas

> [!tip]- Situaciones de Uso
> 
> **1. Fórmulas geométricas:**
> 
> ```
> Área de rectángulo: A = largo × ancho
> Perímetro de círculo: P = 2πr
> Volumen de cilindro: V = πr²h
> ```
> 
> **2. Fórmulas físicas:**
> 
> ```
> Velocidad: v = d/t
> Energía cinética: E = (1/2)mv²
> Fuerza: F = ma
> ```
> 
> **3. Problemas de costos:**
> 
> ```
> Costo total: C = costo_fijo + (costo_unitario × cantidad)
> Ganancia: G = ingreso - costo
> ```
> 
> **4. Problemas de edades:**
> 
> ```
> Edad futura: edad_actual + años
> Edad pasada: edad_actual - años
> ```

> [!example]- Ejemplos Aplicados
> 
> **Ejemplo 1: Geometría**
> 
> ```
> Un rectángulo tiene largo (2x + 3) y ancho (x - 1).
> Encuentra su área cuando x = 5.
> 
> A = (2x + 3)(x - 1)
> A = 2x² - 2x + 3x - 3
> A = 2x² + x - 3
> 
> Para x = 5:
> A = 2(5)² + 5 - 3
> A = 2(25) + 5 - 3
> A = 50 + 5 - 3
> A = 52 unidades cuadradas
> ```
> 
> **Ejemplo 2: Física**
> 
> ```
> La posición de un objeto está dada por:
> s(t) = -5t² + 20t + 3
> 
> ¿Cuál es su posición en t = 2 segundos?
> 
> s(2) = -5(2)² + 20(2) + 3
>      = -5(4) + 40 + 3
>      = -20 + 40 + 3
>      = 23 metros
> ```
> 
> **Ejemplo 3: Economía**
> 
> ```
> Una empresa tiene costos:
> C(x) = 500 + 25x
> 
> donde x es el número de unidades producidas.
> 
> ¿Cuál es el costo de producir 100 unidades?
> 
> C(100) = 500 + 25(100)
>        = 500 + 2500
>        = 3000 dólares
> ```

## ⚠️ Errores Comunes

> [!warning]- Errores Frecuentes y Cómo Evitarlos
> 
> **1. "(a + b)² = a² + b²" ✗**
> 
> ```
> ✗ INCORRECTO: (x + 3)² = x² + 9
> ✓ CORRECTO: (x + 3)² = x² + 6x + 9
> 
> Falta el término medio: 2ab
> ```
> 
> **2. "a(b + c) = ab + c" ✗**
> 
> ```
> ✗ INCORRECTO: 3(x + 2) = 3x + 2
> ✓ CORRECTO: 3(x + 2) = 3x + 6
> 
> Debe distribuirse a TODOS los términos
> ```
> 
> **3. "x² + x² = x⁴" ✗**
> 
> ```
> ✗ INCORRECTO: x² + x² = x⁴
> ✓ CORRECTO: x² + x² = 2x²
> 
> Suma de términos NO es multiplicación
> ```
> 
> **4. "(a + b)/c = a + b/c" ✗**
> 
> ```
> ✗ INCORRECTO: (x + 2)/3 = x + 2/3
> ✓ CORRECTO: (x + 2)/3 = x/3 + 2/3
> 
> Debe dividirse todo el numerador
> ```
> 
> **5. "√(a + b) = √a + √b" ✗**
> 
> ```
> ✗ INCORRECTO: √(9 + 16) = √9 + √16 = 3 + 4 = 7
> ✓ CORRECTO: √(9 + 16) = √25 = 5
> 
> La raíz NO se distribuye sobre la suma
> ```
> 
> 
> **6. "Olvidar signos negativos"**
> 
> ```
> ✗ INCORRECTO: -(x - 3) = -x - 3
> ✓ CORRECTO: -(x - 3) = -x + 3
> 
> El signo negativo cambia TODOS los signos internos
> ```
> 
> **7. "Confundir x² con 2x"**
> 
> ```
> ✗ INCORRECTO: x² = 2x
> ✓ CORRECTO: x² ≠ 2x (excepto para x = 0 o x = 2)
> 
> x² significa x · x, no 2 · x
> ```
> 
> **8. "Cancelar términos incorrectamente"**
> 
> ```
> ✗ INCORRECTO: (x + 3)/x = 3
> ✓ CORRECTO: (x + 3)/x = x/x + 3/x = 1 + 3/x
> 
> Solo se pueden cancelar FACTORES, no términos
> ```
> 
> **9. "Combinar términos no semejantes"**
> 
> ```
> ✗ INCORRECTO: 2x + 3y = 5xy
> ✓ CORRECTO: 2x + 3y (no se puede simplificar más)
> 
> Solo términos con la misma parte literal se combinan
> ```
> 
> **10. "Factorización incompleta"**
> 
> ```
> ✗ INCORRECTO: x² - 4 = (x - 2)
> ✓ CORRECTO: x² - 4 = (x + 2)(x - 2)
> 
> Usar fórmula completa de diferencia de cuadrados
> ```

## 📊 Tabla de Fórmulas Importantes

> [!note]- Resumen de Fórmulas Esenciales
> 
> **Operaciones con exponentes:**
> 
> ```
> xᵃ · xᵇ = xᵃ⁺ᵇ
> xᵃ ÷ xᵇ = xᵃ⁻ᵇ
> (xᵃ)ᵇ = xᵃᵇ
> (xy)ᵃ = xᵃyᵃ
> x⁰ = 1 (x ≠ 0)
> x⁻ⁿ = 1/xⁿ
> ```
> 
> **Productos notables:**
> 
> ```
> (a + b)² = a² + 2ab + b²
> (a - b)² = a² - 2ab + b²
> (a + b)(a - b) = a² - b²
> (a + b)³ = a³ + 3a²b + 3ab² + b³
> (a - b)³ = a³ - 3a²b + 3ab² - b³
> a³ + b³ = (a + b)(a² - ab + b²)
> a³ - b³ = (a - b)(a² + ab + b²)
> (x + a)(x + b) = x² + (a+b)x + ab
> ```
> 
> **Factorización:**
> 
> ```
> Factor común: ab + ac = a(b + c)
> Diferencia cuadrados: a² - b² = (a+b)(a-b)
> Trinomio perfecto: a² ± 2ab + b² = (a ± b)²
> Suma cubos: a³ + b³ = (a+b)(a²-ab+b²)
> Diferencia cubos: a³ - b³ = (a-b)(a²+ab+b²)
> ```

## 🧩 Trucos y Atajos

> [!tip]- Técnicas Avanzadas
> 
> **1. Cálculo mental de productos notables:**
> 
> ```
> Para calcular 103²:
> 103² = (100 + 3)²
>      = 100² + 2(100)(3) + 3²
>      = 10000 + 600 + 9
>      = 10609
> 
> Para 97 × 103:
> = (100 - 3)(100 + 3)
> = 100² - 3²
> = 10000 - 9
> = 9991
> ```
> 
> **2. Factorización por inspección:**
> 
> ```
> Para x² + bx + c:
> - Si c > 0: ambos factores tienen el signo de b
> - Si c < 0: factores con signos opuestos
> - El factor con mayor valor absoluto tiene el signo de b
> ```
> 
> **3. Completar el cuadrado mentalmente:**
> 
> ```
> Para x² + bx:
> Sumar y restar (b/2)²
> 
> x² + 6x = x² + 6x + 9 - 9
>         = (x + 3)² - 9
> ```
> 
> **4. Identificar rápidamente no factorizables:**
> 
> ```
> Para x² + bx + c:
> Si discriminante b² - 4c < 0 → no factorizable en ℝ
> 
> Ejemplo: x² + x + 1
> 1² - 4(1)(1) = 1 - 4 = -3 < 0
> No factorizable con números reales
> ```
