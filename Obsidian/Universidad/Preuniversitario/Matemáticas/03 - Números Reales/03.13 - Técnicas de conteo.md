# 🎯 Técnicas de Conteo

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva
> 
> **Las técnicas de conteo son métodos sistemáticos para contar elementos sin enumerarlos uno a uno.**
> 
> **Elementos clave:**
> 
> - **Principio multiplicativo:** Contar caminos mediante multiplicación
> - **Principio aditivo:** Contar casos mutuamente excluyentes mediante suma
> - **Permutaciones:** Arreglos donde el orden importa
> - **Combinaciones:** Selecciones donde el orden no importa
> - **Aplicaciones:** Probabilidad, estadística, análisis de algoritmos, criptografía

### 📖 Contexto Histórico

> [!note]- Desarrollo Histórico del Conteo
> 
> **Antigüedad (500 a.C. - 1500 d.C.):**
> 
> - **Griegos:** Conteo de figuras geométricas
> - **China antigua:** Problemas combinatorios en juegos
> - **Edad Media:** Combinaciones en música y poesía
> 
> **Período de Formalización (1550-1700):**
> 
> - **Tartaglia (1556):** Primeros estudios sistemáticos
> - **Pascal (1665):** Triángulo de Pascal y coeficientes binomiales
>     - Relación C(n,k) = C(n-1,k-1) + C(n-1,k)
> - **Leibniz (1680s):** Formalización de la combinatoria
> - **Descartes:** Análisis combinatorio en el contexto algebraico
> 
> **Era Moderna (1700-1900):**
> 
> - **Euler (1707-1783):** Teoría de particiones y permutaciones
> - **Bernoulli:** Aplicaciones en probabilidad
> - **Cayley (1821-1895):** Permutaciones y grupos
> - **Sylvester:** Combinatoria e invariantes
> 
> **Era Contemporánea (1900-presente):**
> 
> - **Ramsey (1903-1930):** Teoría de Ramsey
> - **Hardy-Littlewood:** Métodos analíticos en combinatoria
> - **Erdős y Turán (1900s):** Combinatoria extremal
> - **Computación:** Análisis de complejidad algorítmica
> - **Criptografía:** Conteo en sistemas de seguridad

## 🔢 Principios Fundamentales

> [!success]- Principio Multiplicativo (o Principio de Conteo Fundamental)
> 
> **Enunciado:**
> 
> ```
> Si una tarea puede realizarse de m formas,
> y para cada una de ellas una segunda tarea
> puede realizarse de n formas,
> 
> entonces la secuencia de ambas tareas
> puede realizarse de m × n formas
> ```
> 
> **Fórmula general:**
> 
> ```
> Si hay k etapas:
> - Etapa 1: n₁ opciones
> - Etapa 2: n₂ opciones
> - Etapa 3: n₃ opciones
> - ...
> - Etapa k: nₖ opciones
> 
> Total de formas: n₁ × n₂ × n₃ × ... × nₖ
> ```
> 
> **Característica clave:** El número de opciones en cada etapa puede depender de las elecciones anteriores

> [!example]- Ejemplos del Principio Multiplicativo
> 
> **Ejemplo 1: Atuendos**
> 
> ```
> Pantalones: 5 opciones
> Camisas: 3 opciones
> Zapatos: 4 opciones
> 
> Total de atuendos: 5 × 3 × 4 = 60
> ```
> 
> **Ejemplo 2: Placas de automóvil**
> 
> ```
> Formato: 3 letras seguidas de 3 números
> 
> Letras: 26 × 26 × 26 = 26³ = 17,576
> Números: 10 × 10 × 10 = 10³ = 1,000
> 
> Total de placas: 26³ × 10³ = 17,576,000
> ```
> 
> **Ejemplo 3: Contraseñas**
> 
> ```
> Contraseña de 6 caracteres (letras minúsculas o dígitos)
> 
> Cada posición: 26 + 10 = 36 opciones
> 
> Total: 36⁶ = 2,176,782,336
> ```

> [!success]- Principio Aditivo
> 
> **Enunciado:**
> 
> ```
> Si hay m formas de hacer una cosa
> y n formas de hacer otra cosa,
> y estas acciones son mutuamente excluyentes,
> 
> entonces hay m + n formas de hacer una u otra
> ```
> 
> **Fórmula general:**
> 
> ```
> Si un evento puede ocurrir de:
> - Forma 1: n₁ maneras
> - Forma 2: n₂ maneras
> - ...
> - Forma k: nₖ maneras
> 
> (mutuamente excluyentes)
> 
> Total de maneras: n₁ + n₂ + ... + nₖ
> ```
> 
> **Característica clave:** Las categorías NO deben solaparse

> [!example]- Ejemplos del Principio Aditivo
> 
> **Ejemplo 1: Seleccionar bebida**
> 
> ```
> Bebidas frías: 5 opciones
> Bebidas calientes: 3 opciones
> 
> Total de bebidas (asumiendo solo elige una categoría):
> 5 + 3 = 8
> ```
> 
> **Ejemplo 2: Viaje de fin de semana**
> 
> ```
> Ir a playa: 7 destinos
> Ir a montaña: 4 destinos
> Ir a ciudad: 6 destinos
> 
> Total de destinos posibles: 7 + 4 + 6 = 17
> (asumiendo que cada destino es solo una categoría)
> ```

> [!note]- Principio de Inclusión-Exclusión
> 
> **Concepto:**
> 
> ```
> Cuando los eventos NO son mutuamente excluyentes,
> debemos restar los solapamientos
> ```
> 
> **Para 2 conjuntos:**
> 
> ```
> |A ∪ B| = |A| + |B| - |A ∩ B|
> ```
> 
> **Para 3 conjuntos:**
> 
> ```
> |A ∪ B ∪ C| = |A| + |B| + |C|
>              - |A ∩ B| - |A ∩ C| - |B ∩ C|
>              + |A ∩ B ∩ C|
> ```
> 
> **Patrón general:**
> 
> ```
> Suma elementos individuales
> Resta pares de solapamientos
> Suma tríadas de solapamientos
> Resta cuádruplas
> ... (alternando)
> ```

> [!example]- Ejemplo de Inclusión-Exclusión
> 
> **Problema:**
> 
> ```
> En una clase de 100 estudiantes:
> - 60 hablan español
> - 45 hablan inglés
> - 25 hablan ambos idiomas
> 
> ¿Cuántos hablan al menos uno de estos idiomas?
> ```
> 
> **Solución:**
> 
> ```
> |E ∪ I| = |E| + |I| - |E ∩ I|
>         = 60 + 45 - 25
>         = 80 estudiantes
> 
> Verificación alternativa:
> - Solo español: 60 - 25 = 35
> - Solo inglés: 45 - 25 = 20
> - Ambos: 25
> - Total: 35 + 20 + 25 = 80 ✓
> ```

## 📊 Permutaciones

> [!success]- Definición de Permutación
> 
> **Concepto:**
> 
> ```
> Una permutación es un arreglo ordenado de elementos
> donde el ORDEN IMPORTA
> 
> Se cuenta cuántas formas diferentes se pueden arreglar
> elementos tomando algunos o todos
> ```
> 
> **Notación:**
> 
> ```
> P(n,r) o P^n_r o (n)_r o nPr
> 
> Significa: permutaciones de n elementos tomados r a la vez
> ```
> 
> **Fórmula:**
> 
> ```
> P(n,r) = n!/(n-r)!
> 
> Donde n! = n × (n-1) × (n-2) × ... × 2 × 1
> Y 0! = 1
> ```
> 
> **Justificación:**
> 
> ```
> Tenemos n opciones para la 1ª posición
> Tenemos n-1 opciones para la 2ª posición
> Tenemos n-2 opciones para la 3ª posición
> ...
> Tenemos n-r+1 opciones para la r-ª posición
> 
> Total: n × (n-1) × (n-2) × ... × (n-r+1)
>      = n!/(n-r)!
> ```

> [!example]- Ejemplos de Permutaciones
> 
> **Ejemplo 1: Medallas en una carrera**
> 
> ```
> 10 atletas compiten por oro, plata y bronce
> (importa el orden de llegada)
> 
> P(10,3) = 10!/(10-3)!
>         = 10!/7!
>         = 10 × 9 × 8
>         = 720
> ```
> 
> **Ejemplo 2: Palabras de 3 letras**
> 
> ```
> Usando las 26 letras del alfabeto
> (sin repetición)
> 
> P(26,3) = 26 × 25 × 24 = 15,600
> ```
> 
> **Ejemplo 3: Arreglo circular**
> 
> ```
> n personas alrededor de una mesa redonda
> 
> Como no hay "primero", dividimos por n:
> 
> Permutaciones circulares = n!/n = (n-1)!
> 
> Ejemplo: 5 personas
> (5-1)! = 4! = 24 formas
> ```

> [!success]- Permutaciones con Repetición
> 
> **Concepto:**
> 
> ```
> Si hay elementos repetidos, la fórmula cambia
> 
> Si tenemos:
> - n₁ elementos de tipo 1 (indistinguibles entre sí)
> - n₂ elementos de tipo 2 (indistinguibles entre sí)
> - ...
> - nₖ elementos de tipo k (indistinguibles entre sí)
> 
> Donde n₁ + n₂ + ... + nₖ = n
> 
> Permutaciones = n! / (n₁! × n₂! × ... × nₖ!)
> ```
> 
> **Justificación:**
> 
> ```
> Si todos fueran distintos: n! permutaciones
> Pero como hay repeticiones, dividimos por los factoriales
> de los grupos repetidos
> ```

> [!example]- Ejemplo de Permutaciones con Repetición
> 
> **Problema:**
> 
> ```
> ¿De cuántas formas se pueden arreglar las letras
> de la palabra MISSISSIPPI?
> 
> M: 1 vez
> I: 4 veces
> S: 4 veces
> P: 2 veces
> Total: 11 letras
> ```
> 
> **Solución:**
> 
> ```
> Permutaciones = 11! / (1! × 4! × 4! × 2!)
>               = 39,916,800 / (1 × 24 × 24 × 2)
>               = 39,916,800 / 1,152
>               = 34,650
> ```

## 🎁 Combinaciones

> [!success]- Definición de Combinación
> 
> **Concepto:**
> 
> ```
> Una combinación es una selección de elementos
> donde el ORDEN NO IMPORTA
> 
> Se cuenta cuántas formas diferentes se pueden escoger
> elementos sin considerar el orden
> ```
> 
> **Notación:**
> 
> ```
> C(n,r) o C^n_r o (n escolher r) o nCr o (n r)
> 
> Significa: combinaciones de n elementos tomados r a la vez
> ```
> 
> **Fórmula:**
> 
> ```
> C(n,r) = n! / (r! × (n-r)!)
> 
> O equivalentemente:
> C(n,r) = P(n,r) / r!
> ```
> 
> **Justificación:**
> 
> ```
> Si el orden importa: P(n,r) formas
> Pero como el orden NO importa, cada combinación
> se cuenta r! veces (por los r! órdenes posibles)
> 
> Entonces: C(n,r) = P(n,r) / r!
>                  = [n!/(n-r)!] / r!
>                  = n! / (r! × (n-r)!)
> ```

> [!example]- Ejemplos de Combinaciones
> 
> **Ejemplo 1: Comité**
> 
> ```
> Seleccionar 3 personas de 10 para una comisión
> (No importa el orden)
> 
> C(10,3) = 10! / (3! × 7!)
>         = (10 × 9 × 8) / (3 × 2 × 1)
>         = 720 / 6
>         = 120
> ```
> 
> **Ejemplo 2: Mano de póker**
> 
> ```
> Seleccionar 5 cartas de una baraja de 52
> (No importa el orden)
> 
> C(52,5) = 52! / (5! × 47!)
>         = (52 × 51 × 50 × 49 × 48) / (5!)
>         = 311,875,200 / 120
>         = 2,598,960
> ```
> 
> **Ejemplo 3: Combinaciones de toppings**
> 
> ```
> Una pizzería tiene 12 ingredientes opcionales
> ¿De cuántas formas se puede hacer una pizza
> usando exactamente 4 ingredientes?
> 
> C(12,4) = 12! / (4! × 8!)
>         = (12 × 11 × 10 × 9) / (4 × 3 × 2 × 1)
>         = 11,880 / 24
>         = 495
> ```

> [!note]- Propiedades de las Combinaciones
> 
> **Propiedad 1: Simetría**
> 
> ```
> C(n,r) = C(n, n-r)
> 
> Ejemplo: C(5,2) = C(5,3) = 10
> 
> Interpretación: Elegir 2 de 5 es lo mismo que
> dejar fuera 3 de 5
> ```
> 
> **Propiedad 2: Suma**
> 
> ```
> Σ C(n,r) = 2ⁿ  para r=0 hasta n
> 
> Ejemplo: C(4,0) + C(4,1) + C(4,2) + C(4,3) + C(4,4)
>        = 1 + 4 + 6 + 4 + 1 = 16 = 2⁴
> ```
> 
> **Propiedad 3: Pascal (Relación Recurrente)**
> 
> ```
> C(n,r) = C(n-1,r-1) + C(n-1,r)
> 
> Esta es la base del Triángulo de Pascal
> ```
> 
> **Propiedad 4: Casos especiales**
> 
> ```
> C(n,0) = 1       (una forma de elegir nada)
> C(n,1) = n       (n formas de elegir un elemento)
> C(n,n) = 1       (una forma de elegir todo)
> C(n,n-1) = n     (n formas de dejar un elemento fuera)
> ```

## 📐 Triángulo de Pascal

> [!success]- Construcción y Propiedades
> 
> **Triángulo de Pascal:**
> 
> ```
>                    1              fila 0, C(0,0)
>                   1 1             fila 1, C(1,0), C(1,1)
>                  1 2 1            fila 2, C(2,0), C(2,1), C(2,2)
>                 1 3 3 1           fila 3
>                1 4 6 4 1          fila 4
>               1 5 10 10 5 1       fila 5
>              1 6 15 20 15 6 1    fila 6
> ```
> 
> **Regla de construcción:**
> 
> ```
> - Comienza con 1 en la cúspide
> - Cada número es suma de los dos números arriba
> - Los bordes son siempre 1
> 
> C(n,r) = C(n-1,r-1) + C(n-1,r)
> ```
> 
> **Interpretación:**
> 
> ```
> Fila n contiene los coeficientes de (a+b)ⁿ
> 
> (a+b)⁰ = 1
> (a+b)¹ = a + b                    [1, 1]
> (a+b)² = a² + 2ab + b²            [1, 2, 1]
> (a+b)³ = a³ + 3a²b + 3ab² + b³   [1, 3, 3, 1]
> (a+b)⁴ = a⁴ + 4a³b + 6a²b² + 4ab³ + b⁴  [1, 4, 6, 4, 1]
> ```

> [!note]- Propiedades del Triángulo de Pascal
> 
> **Suma de filas:**
> 
> ```
> Fila n suma a 2ⁿ
> 
> Ejemplo: Fila 3: 1 + 3 + 3 + 1 = 8 = 2³
> ```
> 
> **Números de Fibonacci:**
> 
> ```
> Las sumas diagonales forman la serie de Fibonacci
> 
> Diagonal 1: 1
> Diagonal 2: 1 + 1 = 2
> Diagonal 3: 1 + 2 + 1 = 4
> Diagonal 4: 1 + 3 + 3 + 1 = 8
> Diagonal 5: 1 + 4 + 6 + 4 + 1 = 16  (espera, no es Fibonacci)
> 
> Nota: Hay una relación con Fibonacci en diagonales específicas
> ```
> 
> **Paridad:**
> 
> ```
> Si escribimos en binario:
> - Si n y r tienen 1s en posiciones donde binario coincide,
>   entonces C(n,r) es impar
> - Si hay conflicto en binarios, C(n,r) es par
> 
> (Teorema de Lucas)
> ```

## 🔄 Permutaciones vs Combinaciones

> [!note]- Tabla Comparativa
> 
> |Aspecto|Permutaciones|Combinaciones|
> |---|---|---|
> |**Orden importa**|Sí|No|
> |**Fórmula**|P(n,r) = n!/(n-r)!|C(n,r) = n!/(r!(n-r)!)|
> |**Relación**|P(n,r) = C(n,r) × r!|C(n,r) = P(n,r)/r!|
> |**Ejemplo**|ABC ≠ BAC|{A,B,C} = {C,B,A}|
> |**Uso típico**|Rankings, códigos|Comités, grupos|
> |**Resultado**|Generalmente mayor|Generalmente menor|

## 🎪 Problemas Combinados

> [!example]- Problemas de Conteo Integrado
> 
> **Problema 1: Seleccionar y Ordenar**
> 
> ```
> De 15 estudiantes, ¿de cuántas formas se pueden escoger
> 5 para un viaje y luego designar líder, vicelecte y secretario?
> 
> Opción A: Primero combinación, luego permutación
> - Escoger 5: C(15,5) = 3,003
> - Asignar 3 roles entre 5: P(5,3) = 60
> - Total: 3,003 × 60 = 180,180
> 
> Opción B: Permutar directamente
> - Escoger líder: 15 opciones
> - Escoger vicelecte: 14 opciones
> - Escoger secretario: 13 opciones
> - Escoger 2 más del resto: P(12,2) = 132
> - Total: 15 × 14 × 13 × 132 = 403,860
> 
> ¿Cuál es correcto? Depende de la interpretación del problema.
> ```
> 
> **Problema 2: Restricciones**
> 
> ```
> ¿De cuántas formas se pueden sentar 8 personas
> en 8 sillas si dos personas específicas no pueden
> sentarse una al lado de la otra?
> 
> Método 1: Complemento
> Total sin restricción: 8! = 40,320
> Con A y B juntos: 7! × 2! = 5,040 × 2 = 10,080
> (tratar A y B como un bloque)
> 
> Respuesta: 40,320 - 10,080 = 30,240
> ```
> 
> **Problema 3: Distribución**
> 
> ```
> ¿De cuántas formas se pueden distribuir 10 monedas
> idénticas entre 3 personas diferentes?
> 
> Esto es un "stars and bars" problema
> 
> Fórmula: C(n+k-1, k-1) = C(10+3-1, 3-1) = C(12, 2) = 66
> 
> Donde n = monedas, k = personas
> ```

## 🌈 Técnicas Especiales

> [!success]- Principio de Pigeonhole (Palomar)
> 
> **Enunciado:**
> 
> ```
> Si n elementos se distribuyen en k contenedores
> y n > k,
> 
> entonces al menos un contenedor contiene
> más de un elemento
> ```
> 
> **Versión más fuerte:**
> 
> ```
> Si n elementos se distribuyen en k contenedores,
> entonces al menos un contenedor contiene
> al menos ⌈n/k⌉ elementos
> 
> (donde ⌈⌉ es el techo: redondear hacia arriba)
> ```
> 
> **Aplicaciones:**
> 
> ```
> - En 13 personas, al menos 2 nacen en el mismo mes
> - En 367 personas, al menos 2 nacen en el mismo día
> - En un disco de n+1 puntos, al menos 2 están
>   a distancia ≤ d de distancia
> ```

> [!success]- Stars and Bars (Estrellas y Barras)
> 
> **Problema típico:**
> 
> ```
> ¿De cuántas formas se pueden distribuir n objetos
> idénticos entre k recipientes distintos?
> ```
> 
> **Visualización:**
> 
> ```
> Usamos * para objetos y | para divisores
> 
> Ejemplo: 10 monedas entre 3 personas
> 
> **||*** representa: 2, 0, 8 monedas
> ***||**  representa: 3, 0, 7 monedas
> *|*|*   representa: 1, 1, 8 monedas
> 
> Total de arreglos: 10 estrellas y 2 barras (3-1)
> = C(10+2, 2) = C(12, 2) = 66
> ```
> 
> **Fórmula general:**
> 
> ```
> Distribuir n objetos idénticos entre k recipientes:
> 
> C(n + k - 1, k - 1) = C(n + k - 1, n)
> ```

> [!success]- Principio de Inclusión-Exclusión Avanzado
> 
> **Para encontrar derangements (permutaciones sin puntos fijos):**
> 
> ```
> D(n) = número de permutaciones de n elementos
>        donde ninguno está en su posición original
> 
> D(n) = n! × Σ (-1)ᵏ/k! para k=0 hasta n
> 
> D(n) ≈ n! / e  (para n grande)
> 
> Ejemplos:
> D(2) = 1  (solo 2-1)
> D(3) = 2  (2-3-1 y 3-1-2)
> D(4) = 9
> D(5) = 44
> ```

## 🔢 Factoriales y Notación Combinatoria

> [!note]- Hechos sobre Factoriales
> 
> **Definición:**
> 
> ```
> n! = n × (n-1) × (n-2) × ... × 2 × 1
> 0! = 1 (por definición)
> 
> Ejemplos:
> 1! = 1
> 2! = 2
> 3! = 6
> 4! = 24
> 5! = 120
> 10! = 3,628,800
> 20! = 2.432... × 10¹⁸
> ```
> 
> **Aproximación de Stirling:**
> 
> ```
> Para n grande:
> n! ≈ √(2πn) × (n/e)ⁿ
> 
> Error disminuye conforme n aumenta
> ```
> 
> **Propiedades:**
> 
> ```
> n! / (n-r)! = n × (n-1) × ... × (n-r+1) = P(n,r)
> 
> Cocientes factoriales aparecen frecuentemente
> en fórmulas combinatorias
> ```

## ⚠️ Errores Comunes

> [!warning]- Fallos Típicos en Conteo
> 
> **1. Confundir permutaciones y combinaciones**
> 
> ```
> ✗ INCORRECTO: "10 personas en 5 sillas"
>               = C(10,5) = 252
> 
> ✓ CORRECTO: = P(10,5) = 30,240
>             (el orden en las sillas importa)
> 
> ¿Cómo decidir? Preguntarse: ¿importa el orden?
> ```
> 
> **2. No considerar orden vs no-orden**
> 
> ```
> ✗ INCORRECTO: "Comité de 3 personas"
>               = P(n,3)
> 
> ✓ CORRECTO: = C(n,3)
>             (en un comité no hay "primer miembro")
> ```
> 
> **3. Contar duplicados**
> 
> ```
> ✗ INCORRECTO: Elegir 2 personas de 4
>               = 4 × 3 = 12
> 
> ✓ CORRECTO: = C(4,2) = 6
>             (cuando importa quiénes, no posiciones)
> ```
> 
> **4. Olvidar usar inclusión-exclusión**
> 
> ```
> ✗ INCORRECTO: Personas que hablan español O inglés
>               = 60 + 45 = 105 (con 100 personas totales!)
> 
> ✓ CORRECTO: = 60 + 45 - 25 = 80
>             (restar el solapamiento)
> ```
> 
> **5. No considerar restricciones**
> 
> ```
> ✗ INCORRECTO: "Código de 4 dígitos"
>               = 10⁴ = 10,000
> 
> ✓ CORRECTO (si todos deben ser distintos):
>            = P(10,4) = 5,040
> ```
> 
> **6. Aplicar multiplicación cuando debe ser suma**
> 
> ```
> ✗ INCORRECTO: "Pizza con 1 topping O 2 toppings"
>               = 12 × (12 × 11 / 2)
> 
> ✓ CORRECTO: = 12 + 66 = 78
>             (las categorías se suman, no multiplican)
> ```

> |Concepto|Fórmula|Cuándo usar|
> |---|---|---|
> |**Principio multiplicativo**|n₁ × n₂ × ... × nₖ|Etapas secuenciales|
> |**Principio aditivo**|n₁ + n₂ + ... + nₖ|Casos mutuamente excluyentes|
> |**Permutaciones**|P(n,r) = n!/(n-r)!|Orden importa|
> |**Combinaciones**|C(n,r) = n!/(r!(n-r)!)|Orden no importa|
> |**Perm. circulares**|(n-1)!|n objetos en círculo|
> |**Perm. repetidas**|n!/(n₁!n₂!...nₖ!)|Elementos repetidos|
> |**Stars and Bars**|C(n+k-1, k-1)|Distribuir n idénticos en k recipientes|
> |**Derangements**|D(n) = n! × Σ(-1)ᵏ/k!|Sin puntos fijos|
> |**Inclusión-Exclusión**|\|A ∪ B\| = \|A\| + \|B\| - \|A ∩ B\||Conjuntos con solapamiento|

## 🎯 Estrategia de Resolución

> [!tip]- Cómo Abordar Problemas de Conteo
> 
> **Paso 1: Comprender el problema**
> 
> ```
> - ¿Qué se está contando?
> - ¿Son elementos finitos?
> - ¿Hay restricciones?
> - ¿Es una selección o un arreglo?
> ```
> 
> **Paso 2: Identificar si es permutación o combinación**
> 
> ```
> Pregunta clave: ¿El orden importa?
> 
> SÍ → Permutación (ordenar, ranking, secuencia)
> NO → Combinación (seleccionar, grupo, comité)
> ```
> 
> **Paso 3: Buscar restricciones**
> 
> ```
> - ¿Hay elementos que no pueden estar juntos?
> - ¿Hay posiciones especiales?
> - ¿Hay elementos que deben estar juntos?
> - ¿Hay tipos diferentes?
> ```
> 
> **Paso 4: Elegir técnica**
> 
> ```
> - Etapas independientes → Multiplicativo
> - Casos mutuamente excluyentes → Aditivo
> - Elementos idénticos a distribuir → Stars and Bars
> - Solapamientos → Inclusión-Exclusión
> - Complemento más fácil → Contar opuesto
> ```
> 
> **Paso 5: Verificar con casos pequeños**
> 
> ```
> - Si es posible, verificar con n pequeño
> - Enumerar manualmente algunos casos
> - Confirmar que la fórmula da el resultado correcto
> ```

## 🎓 Problemas Resueltos Completos

> [!example]- Problema 1: Comité con Restricciones
> 
> **Enunciado:**
> 
> ```
> De 12 personas (7 hombres y 5 mujeres),
> se quiere formar un comité de 5 personas
> con al menos 2 mujeres.
> 
> ¿De cuántas formas se puede hacer?
> ```
> 
> **Solución:**
> 
> ```
> Método 1: Contar casos directos
> 
> Caso 1: Exactamente 2 mujeres y 3 hombres
> C(5,2) × C(7,3) = 10 × 35 = 350
> 
> Caso 2: Exactamente 3 mujeres y 2 hombres
> C(5,3) × C(7,2) = 10 × 21 = 210
> 
> Caso 3: Exactamente 4 mujeres y 1 hombre
> C(5,4) × C(7,1) = 5 × 7 = 35
> 
> Caso 4: Exactamente 5 mujeres y 0 hombres
> C(5,5) × C(7,0) = 1 × 1 = 1
> 
> Total: 350 + 210 + 35 + 1 = 596
> 
> Método 2: Complemento
> 
> Total de comités: C(12,5) = 792
> Comités con 0 o 1 mujer: C(5,0)×C(7,5) + C(5,1)×C(7,4)
>                        = 1×21 + 5×35
>                        = 21 + 175 = 196
> 
> Respuesta: 792 - 196 = 596 ✓
> ```

> [!example]- Problema 2: Arreglo con Restricciones
> 
> **Enunciado:**
> 
> ```
> ¿De cuántas formas se pueden sentar 5 personas
> (A, B, C, D, E) en una fila si:
> - A debe estar antes que B
> - D debe estar antes que E
> ```
> 
> **Solución:**
> 
> ```
> Método: Simetría
> 
> Total de arreglos sin restricciones: 5! = 120
> 
> Para cada arreglo, A puede estar antes o después de B.
> Por simetría, exactamente la mitad tiene A antes que B.
> 
> De esos, D puede estar antes o después de E.
> Por simetría, exactamente la mitad tiene D antes que E.
> 
> Respuesta: 120 / 2 / 2 = 30
> 
> Verificación con otra perspectiva:
> - Arreglar 5 posiciones: P(5,5) = 120
> - Elegir 2 para A y B: C(5,2) = 10
> - A va en la primera, B en la segunda: 1 forma
> - De las 3 restantes, elegir 2 para D y E: C(3,2) = 3
> - D va primero: 1 forma
> - Acomodar al restante: 1 forma
> - Total: C(5,2) × C(3,2) × 1! = 10 × 3 × 1 = 30 ✓
> ```

> [!example]- Problema 3: Palabras con Letras Repetidas
> 
> **Enunciado:**
> 
> ```
> ¿Cuántas palabras se pueden formar con las letras
> de STATISTICAL?
> 
> S: 3 veces
> T: 2 veces
> A: 2 veces
> I: 2 veces
> C: 1 vez
> L: 1 vez
> Total: 11 letras
> ```
> 
> **Solución:**
> 
> ```
> Fórmula para permutaciones con repetición:
> 
> Palabras = n! / (n₁! × n₂! × ... × nₖ!)
>          = 11! / (3! × 2! × 2! × 2! × 1! × 1!)
>          = 39,916,800 / (6 × 2 × 2 × 2 × 1 × 1)
>          = 39,916,800 / 48
>          = 831,600
> ```

> [!example]- Problema 4: Distribución de Objetos
> 
> **Enunciado:**
> 
> ```
> ¿De cuántas formas se pueden distribuir
> 15 manzanas idénticas entre 4 niños?
> ```
> 
> **Solución:**
> 
> ```
> Este es un problema de stars and bars.
> 
> Representamos con * las manzanas y | los divisores:
> ****|***|****|****  significa 4-3-4-4 manzanas
> 
> Necesitamos arreglar 15 estrellas y 3 barras (4-1).
> 
> Total: C(15+3, 3) = C(18, 3) = 18!/(3!×15!)
>      = (18 × 17 × 16) / (3 × 2 × 1)
>      = 4,896 / 6
>      = 816
> ```

> [!example]- Problema 5: Codigos y Placas
> 
> **Enunciado:**
> 
> ```
> Una placa de matrícula tiene 3 letras seguidas de 3 dígitos.
> 
> a) ¿Cuántas placas diferentes hay?
> b) ¿Si no se puede repetir letra?
> c) ¿Si no se puede repetir dígito?
> d) ¿Si no se puede repetir nada?
> ```
> 
> **Solución:**
> 
> ```
> a) Sin restricciones:
>    26 × 26 × 26 × 10 × 10 × 10 = 17,576,000
> 
> b) Sin repetir letras:
>    26 × 25 × 24 × 10 × 10 × 10 = 156,000,000
>    O: P(26,3) × 10³ = 15,600 × 1,000 = 15,600,000
> 
> c) Sin repetir dígitos:
>    26 × 26 × 26 × 10 × 9 × 8 = 11,232,000
>    O: 26³ × P(10,3) = 17,576 × 720 = 12,654,720
> 
> d) Sin repetir nada:
>    P(26,3) × P(10,3) = 15,600 × 720 = 11,232,000
> ```

> [!example]- Problema 6: Selección de Comisiones Múltiples
> 
> **Enunciado:**
> 
> ```
> De 20 personas, ¿de cuántas formas se pueden elegir:
> - 5 para una comisión de educación
> - 4 para una comisión de salud
> - 3 para una comisión de ambiente
> 
> (Sin solapamiento de personas)
> ```
> 
> **Solución:**
> 
> ```
> Método 1: Secuencial
> 
> Paso 1: Elegir 5 para educación: C(20,5)
> Paso 2: Elegir 4 para salud de las 15 restantes: C(15,4)
> Paso 3: Elegir 3 para ambiente de las 11 restantes: C(11,3)
> 
> Total: C(20,5) × C(15,4) × C(11,3)
>      = 15,504 × 1,365 × 165
>      = 3,487,594,800
> 
> Método 2: Fórmula multinomial
> 
> Total = 20! / (5! × 4! × 3! × 8!)
>       = 20! / (120 × 24 × 6 × 40,320)
>       = 2.432... × 10¹⁸ / 69,062,400
>       = 3,487,594,800 ✓
> ```

> - Minúsculas: 26

>

> 
> Para reducir colisiones, necesitamos valores mucho mayores
> ```

## 🧮 Aplicaciones en Probabilidad

> [!example]- Problemas Probabilísticos usando Conteo
> 
> **Ejemplo 1: Poker**
> 
> ```
> Probabilidad de escalera real (10-J-Q-K-A del mismo palo)
> 
> Número de escaleras reales: 4 (una por palo)
> Número total de manos: C(52,5) = 2,598,960
> 
> Probabilidad = 4 / 2,598,960 ≈ 0.0000015 ≈ 1 en 649,740
> ```
> 
> **Ejemplo 2: Cumpleaños**
> 
> ```
> Probabilidad de que 23 personas tengan cumpleaños diferentes:
> 
> P(distintos) = 365/365 × 364/365 × 363/365 × ... × 343/365
>              = 365! / (342! × 365²³)
> 
> Resultado: ≈ 0.493 = 49.3%
> 
> Entonces P(al menos dos iguales) ≈ 50.7%
> ```
> 
> **Ejemplo 3: Lotería**
> 
> ```
> Probabilidad de acertar 6 números de 49:
> 
> Formas de elegir 6: C(49,6) = 10,068,347
> Formas de acertar: 1
> 
> Probabilidad = 1 / 10,068,347 ≈ 0.00000994 ≈ 1 en 10 millones
> ```

## 🔀 Funciones Generatrices

> [!success]- Introducción a Funciones Generatrices
> 
> **Concepto:**
> 
> ```
> Una función generatriz es una serie de potencias
> cuya expansión codifica información combinatoria
> 
> f(x) = a₀ + a₁x + a₂x² + a₃x³ + ...
> 
> donde aₙ es el número de objetos de tamaño n
> ```
> 
> **Ejemplo simple:**
> 
> ```
> Función generatriz de monedas de 1¢ y 5¢:
> 
> f(x) = (1 + x + x² + ...)(1 + x⁵ + x¹⁰ + ...)
>      = 1/(1-x) × 1/(1-x⁵)
> 
> El coeficiente de xⁿ es el número de formas
> de hacer n centavos
> ```

## 📈 Complejidad Computacional

> [!note]- Análisis de Algoritmos con Conteo
> 
> **Complejidad de tiempo:**
> 
> ```
> Un algoritmo que itera sobre todas las permutaciones de n elementos:
> O(n!) complejidad
> 
> Por ejemplo: resolver el Problema del Viajante por fuerza bruta
> Número de recorridos: (n-1)!/2
> 
> Tiempo: muy prohibitivo para n > 12
> ```
> 
> **Complejidad de espacio:**
> 
> ```
> Almacenar todos los subconjuntos de un conjunto de n elementos:
> 2ⁿ espacios necesarios
> 
> Para n = 20: ~1 millón
> Para n = 30: ~1 billón
> ```
