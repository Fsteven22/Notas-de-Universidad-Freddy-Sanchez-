# 🎯 Clasificación de los Números Reales

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Los números reales son todos los números que pueden representarse en una recta continua, incluyendo números naturales, enteros, racionales (fracciones) e irracionales (como π y √2).**
> 
> **Elementos clave:**
> 
> - **Completitud:** Llenan completamente la recta sin "huecos"
> - **Jerarquía:** Cada sistema numérico contiene al anterior
> - **Operaciones:** Cerrados bajo suma, resta, multiplicación y división (excepto por cero)
> - **Orden:** Pueden compararse mediante < , > , ≤ , ≥

### 📖 Contexto Histórico

> [!note]- Desarrollo Histórico de los Sistemas Numéricos
> 
> **Números Naturales (3000 a.C. - presente):**
> 
> - **Orígenes:** Primeros símbolos numéricos en Mesopotamia y Egipto
> - **Función:** Contar objetos, medir cantidades discretas
> - **Peano (1889):** Axiomatización formal de ℕ
> 
> **Números Negativos (200 a.C. - 1700):**
> 
> - **China (200 a.C.):** Primeros usos en matemática comercial
> - **India (600 d.C.):** Brahmagupta establece reglas de operación
> - **Europa (1500s):** Resistencia inicial, aceptación gradual
> - **Cardano (1545):** Uso en solución de ecuaciones cúbicas
> 
> **Números Racionales (600 a.C. - presente):**
> 
> - **Babilonios:** Sistema sexagesimal con fracciones
> - **Egipcios:** Fracciones unitarias (1/n)
> - **Griegos:** Teoría de proporciones (Euclides)
> - **Descubrimiento crucial:** No todos los números son racionales
> 
> **Crisis de los Irracionales (500 a.C.):**
> 
> - **Pitágoras y su escuela:** "Todo es número (racional)"
> - **Hipaso de Metaponto:** Descubre que √2 es irracional
> - **Impacto:** Crisis filosófica y matemática
> - **Leyenda:** Hipaso fue ahogado por revelar el secreto
> - **Eudoxo:** Teoría de magnitudes para manejar inconmensurables
> 
> **Números Irracionales (500 a.C. - 1872):**
> 
> - **Griegos:** Reconocen √2, √3, √5 como inconmensurables
> - **Al-Khwarizmi (800):** Raíces cuadradas en álgebra
> - **Lambert (1761):** Demuestra que π es irracional
> - **Lindemann (1882):** Demuestra que π es trascendente
> 
> **Construcción Formal de ℝ (1850-1900):**
> 
> - **Cantor (1872):** Sucesiones de Cauchy
> - **Dedekind (1872):** Cortaduras (particiones de ℚ)
> - **Weierstrass:** Aproximaciones decimales
> - **Objetivo:** Fundamentar rigurosamente el cálculo
> - **Resultado:** Matemática puesta en base sólida
> 
> **Descubrimientos del Siglo XX:**
> 
> - **Cantor:** ℝ es no numerable (más "grande" que ℚ)
> - **Demostración:** Casi todos los números reales son trascendentes
> - **Paradoja:** Conocemos explícitamente muy pocos irracionales

## 🔢 Jerarquía de los Sistemas Numéricos

### 📊 Diagrama de Inclusión

> [!success]- Relaciones de Contención
> 
> ```
> ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ
>           ↗
>       𝕀 ⊂ ℝ
> ```
> 
> **Cadena de inclusiones:**
> 
> - Naturales están contenidos en Enteros
> - Enteros están contenidos en Racionales
> - Racionales están contenidos en Reales
> - Irracionales están contenidos en Reales
> - Racionales e Irracionales son disjuntos: ℚ ∩ 𝕀 = ∅
> - Juntos forman los Reales: ℚ ∪ 𝕀 = ℝ
> 
> **Propiedad fundamental:** Cada extensión agrega números que resuelven ecuaciones no resolubles en el sistema anterior.

## 🔤 Números Naturales (ℕ)

> [!success]- Los Números de Contar
> 
> **Definición:**
> 
> ```
> ℕ = {0, 1, 2, 3, 4, 5, ...}
> ```
> 
> **Notación alternativa:**
> 
> ```
> ℕ₀ = {0, 1, 2, 3, ...}  [con cero]
> ℕ⁺ = {1, 2, 3, 4, ...}  [sin cero]
> ℕ* = ℕ⁺                 [notación alternativa]
> ```
> 
> **Características:**
> 
> - **Discretos:** Hay un "siguiente" para cada número
> - **Primer elemento:** 0 (o 1 según convención)
> - **Sin límite superior:** Infinitos
> - **Cerrados bajo:** Suma y multiplicación
> - **NO cerrados bajo:** Resta y división
> 
> **Axiomas de Peano (definición formal):**
> 
> 1. 0 ∈ ℕ
> 2. Todo n ∈ ℕ tiene un sucesor S(n) ∈ ℕ
> 3. 0 no es sucesor de ningún número
> 4. Si S(n) = S(m), entonces n = m
> 5. **Inducción:** Si P(0) es cierto y P(n) → P(S(n)), entonces P(n) para todo n ∈ ℕ

> [!example]- Ejemplos y Aplicaciones
> 
> **Ejemplos típicos:**
> 
> ```
> 0, 1, 2, 3, 10, 100, 1000, 999999
> ```
> 
> **Aplicaciones:**
> 
> - Contar objetos: "Hay 25 estudiantes"
> - Indexación: Posiciones en listas
> - Numeración: Páginas, capítulos
> - Algoritmos: Contadores, iteraciones
> 
> **Subconjuntos importantes:**
> 
> ```
> Pares: {0, 2, 4, 6, ...} = {2n : n ∈ ℕ}
> Impares: {1, 3, 5, 7, ...} = {2n + 1 : n ∈ ℕ}
> Primos: {2, 3, 5, 7, 11, 13, ...}
> Cuadrados perfectos: {0, 1, 4, 9, 16, 25, ...} = {n² : n ∈ ℕ}
> ```
> 
> **Ecuaciones resolubles en ℕ:**
> 
> ```
> x + 3 = 5     ✓  x = 2
> 2x = 6        ✓  x = 3
> ```
> 
> **Ecuaciones NO resolubles en ℕ:**
> 
> ```
> x + 5 = 3     ✗  Necesita negativos (ℤ)
> 2x = 3        ✗  Necesita fracciones (ℚ)
> x² = 2        ✗  Necesita irracionales (ℝ)
> ```

## ➖ Números Enteros (ℤ)

> [!success]- Extensión con Números Negativos
> 
> **Definición:**
> 
> ```
> ℤ = {..., -3, -2, -1, 0, 1, 2, 3, ...}
> ```
> 
> **Notación del símbolo:**
> 
> - ℤ viene del alemán "Zahlen" (números)
> 
> **Variantes:**
> 
> ```
> ℤ⁺ = {1, 2, 3, ...}        [enteros positivos]
> ℤ⁻ = {..., -3, -2, -1}     [enteros negativos]
> ℤ⁰ = {0}                    [el cero]
> ℤ≥₀ = ℕ = {0, 1, 2, ...}    [no negativos]
> ℤ≤₀ = {..., -2, -1, 0}     [no positivos]
> ```
> 
> **Características:**
> 
> - **Simétricos:** Para cada n hay un -n
> - **Cerrados bajo:** Suma, resta y multiplicación
> - **NO cerrados bajo:** División
> - **Elemento neutro suma:** 0
> - **Elemento neutro producto:** 1
> 
> **Construcción formal:**
> 
> ```
> ℤ = ℕ ∪ {-n : n ∈ ℕ⁺}
> 
> O mediante pares ordenados:
> ℤ ≅ (ℕ × ℕ) / ~
> donde (a,b) ~ (c,d) ⟺ a + d = b + c
> [(a,b)] representa "a - b"
> ```

> [!example]- Ejemplos y Aplicaciones
> 
> **Ejemplos típicos:**
> 
> ```
> -1000, -5, -1, 0, 1, 7, 42, 2025
> ```
> 
> **Motivación histórica:**
> 
> - **Deudas:** "Debo $50" → -50
> - **Temperatura:** "5 grados bajo cero" → -5°C
> - **Altitud:** "200m bajo el nivel del mar" → -200m
> - **Tiempo:** "3 años a.C." → -3 (en línea temporal)
> 
> **Ecuaciones ahora resolubles:**
> 
> ```
> x + 5 = 3     ✓  x = -2
> x - 7 = 2     ✓  x = 9
> -3 + x = 1    ✓  x = 4
> ```
> 
> **Aún NO resolubles:**
> 
> ```
> 2x = 3        ✗  Necesita ℚ
> x² = -1       ✗  Necesita ℂ (complejos)
> ```
> 
> **Propiedades de orden:**
> 
> ```
> Para a, b ∈ ℤ:
> a < b  ⟺  b - a ∈ ℕ⁺
> 
> Ejemplos:
> -5 < -2  porque  -2 - (-5) = 3 ∈ ℕ⁺
> -100 < 0  porque  0 - (-100) = 100 ∈ ℕ⁺
> ```

## ➗ Números Racionales (ℚ)

> [!success]- Los Números que son Razones
> 
> **Definición:**
> 
> ```
> ℚ = {p/q : p ∈ ℤ, q ∈ ℤ, q ≠ 0}
> ```
> 
> "Cociente de dos enteros con denominador no cero"
> 
> **Notación del símbolo:**
> 
> - ℚ viene de "Quotient" (cociente en inglés)
> 
> **Representaciones equivalentes:**
> 
> ```
> 1/2 = 2/4 = 3/6 = -2/-4 = 50/100
> 
> En general: p/q = (kp)/(kq) para todo k ≠ 0
> ```
> 
> **Forma canónica (irreducible):**
> 
> - Numerador y denominador coprimos (MCD = 1)
> - Denominador positivo
> 
> ```
> Ejemplo: -6/8 → -3/4 (forma canónica)
> ```
> 
> **Características:**
> 
> - **Cerrados bajo:** Suma, resta, multiplicación y división (excepto por cero)
> - **Densos:** Entre dos racionales siempre hay infinitos racionales
> - **Numerables:** Mismo "tamaño" que ℕ (paradójicamente)
> - **Expansión decimal:** Finita o periódica

> [!example]- Ejemplos y Tipos de Racionales
> 
> **Enteros como racionales:**
> 
> ```
> 5 = 5/1
> -3 = -3/1
> 0 = 0/1
> ```
> 
> **Fracciones propias (|p| < |q|):**
> 
> ```
> 1/2, 3/4, -2/5, 7/10
> ```
> 
> **Fracciones impropias (|p| > |q|):**
> 
> ```
> 5/3, 7/2, -11/4
> ```
> 
> **Números mixtos:**
> 
> ```
> 2⅓ = 7/3
> -1½ = -3/2
> ```
> 
> **Decimales finitos:**
> 
> ```
> 0.5 = 1/2
> 0.25 = 1/4
> 0.125 = 1/8
> 3.75 = 15/4
> ```
> 
> **Decimales periódicos:**
> 
> ```
> 0.333... = 0.3̄ = 1/3
> 0.666... = 0.6̄ = 2/3
> 0.142857142857... = 0.142857̄ = 1/7
> 2.454545... = 2.4̄5̄ = 27/11
> ```
> 
> **Conversión decimal periódico a fracción:**
> 
> ```
> Ejemplo: x = 0.373737...
> 
> 100x = 37.373737...
> x = 0.373737...
> ___________________
> 99x = 37
> x = 37/99
> ```

> [!note]- Propiedades Importantes de ℚ
> 
> **Densidad:**
> 
> ```
> ∀a, b ∈ ℚ con a < b, ∃c ∈ ℚ tal que a < c < b
> 
> Construcción explícita: c = (a + b)/2
> ```
> 
> **Consecuencia:** Entre dos racionales hay infinitos racionales
> 
> **Numerabilidad (Cantor):**
> 
> - Se pueden enumerar: ℚ = {r₁, r₂, r₃, ...}
> - Mismo cardinal que ℕ: |ℚ| = |ℕ| = ℵ₀
> - Método: Diagonal de Cantor para fracciones
> 
> **Operaciones:**
> 
> ```
> Suma: a/b + c/d = (ad + bc)/(bd)
> Resta: a/b - c/d = (ad - bc)/(bd)
> Multiplicación: a/b × c/d = (ac)/(bd)
> División: (a/b) ÷ (c/d) = (ad)/(bc)  si c ≠ 0
> ```
> 
> **Ecuaciones ahora resolubles:**
> 
> ```
> 2x = 3        ✓  x = 3/2
> x/5 = 2       ✓  x = 10
> (x-1)/3 = 2   ✓  x = 7
> ```
> 
> **Aún NO resolubles en ℚ:**
> 
> ```
> x² = 2        ✗  x = ±√2 ∉ ℚ
> x² = 3        ✗  x = ±√3 ∉ ℚ
> x³ = 2        ✗  x = ∛2 ∉ ℚ
> ```

## 🌀 Números Irracionales (𝕀 o ℝ\ℚ)

> [!success]- Los Números "Sin Razón"
> 
> **Definición:**
> 
> ```
> 𝕀 = {x ∈ ℝ : x ∉ ℚ}
> ```
> 
> "Números reales que NO pueden expresarse como p/q con p, q ∈ ℤ"
> 
> **Notación:**
> 
> - 𝕀 o ℝ\ℚ (reales menos racionales)
> - ℚᶜ (complemento de ℚ en ℝ)
> 
> **Características:**
> 
> - **Expansión decimal:** Infinita NO periódica
> - **Densos:** Entre dos irracionales hay infinitos irracionales (y racionales)
> - **No numerables:** Más "numerosos" que ℚ
> - **NO cerrados:** La suma o producto de dos irracionales puede ser racional

> [!example]- Tipos y Ejemplos de Irracionales
> 
> **Raíces de enteros no perfectos:**
> 
> ```
> √2 = 1.41421356...
> √3 = 1.73205080...
> √5 = 2.23606797...
> ∛2 = 1.25992104...
> ⁴√7 = 1.62657656...
> ```
> 
> **Números trascendentes famosos:**
> 
> ```
> π = 3.14159265358979...  (razón circunferencia/diámetro)
> e = 2.71828182845904...  (base logaritmos naturales)
> φ = 1.61803398874989...  (razón áurea)
> γ = 0.57721566490153...  (constante Euler-Mascheroni)
> ```
> 
> **Constantes matemáticas:**
> 
> ```
> ln(2) = 0.69314718055994...
> ln(10) = 2.30258509299404...
> log₂(3) = 1.58496250072115...
> ```
> 
> **Irracionales constructibles:**
> 
> ```
> √2, √3, √5 + √7, (1 + √5)/2
> ```
> 
> **Valores trigonométricos:**
> 
> ```
> sin(1°) = 0.01745240643...  (irracional)
> cos(60°) = 1/2              (racional)
> tan(45°) = 1                (racional)
> sin(30°) = 1/2              (racional)
> ```
> 
> **Operaciones que dan racional:**
> 
> ```
> √2 × √2 = 2         (racional)
> √3 + (-√3) = 0      (racional)
> π/π = 1             (racional)
> ```
> 
> **Operaciones que dan irracional:**
> 
> ```
> √2 + √3             (irracional)
> π + e               (irracional - conjetura)
> 1 + √2              (irracional)
> ```

> [!note]- Demostración Clásica: √2 es Irracional
> 
> **Teorema:** √2 ∉ ℚ
> 
> **Demostración (por contradicción):**
> 
> Supongamos que √2 ∈ ℚ. Entonces:
> 
> 1. **Existe representación:** √2 = p/q donde p, q ∈ ℤ, q ≠ 0, MCD(p,q) = 1 (forma irreducible)
>     
> 2. **Elevamos al cuadrado:** 2 = p²/q²
>     
> 3. **Multiplicamos por q²:** 2q² = p²
>     
> 4. **Conclusión 1:** p² es par → p es par (Si p fuera impar, p² sería impar)
>     
> 5. **Escribimos:** p = 2k para algún k ∈ ℤ
>     
> 6. **Sustituimos:** 2q² = (2k)² = 4k²
>     
> 7. **Simplificamos:** q² = 2k²
>     
> 8. **Conclusión 2:** q² es par → q es par
>     
> 9. **Contradicción:** p y q son ambos pares → MCD(p,q) ≥ 2 Esto contradice que MCD(p,q) = 1
>     
> 
> **Conclusión:** La suposición es falsa. Por tanto, √2 ∉ ℚ ∎
> 
> **Generalización:** Este método prueba que √n es irracional si n no es cuadrado perfecto.

## 📏 Números Algebraicos vs Trascendentes

> [!tip]- Clasificación Alternativa de los Reales
> 
> **Números Algebraicos (𝔸):**
> 
> ```
> Soluciones de ecuaciones polinómicas con coeficientes racionales
> 
> 𝔸 = {x ∈ ℝ : ∃ aₙxⁿ + ... + a₁x + a₀ = 0, con aᵢ ∈ ℚ, aₙ ≠ 0}
> ```
> 
> **Ejemplos algebraicos:**
> 
> ```
> Racionales: 2/3  (solución de 3x - 2 = 0)
> Raíces: √2      (solución de x² - 2 = 0)
>        ∛5       (solución de x³ - 5 = 0)
> Razón áurea: φ  (solución de x² - x - 1 = 0)
> ```
> 
> **Números Trascendentes (𝕋):**
> 
> ```
> NO son raíces de ningún polinomio con coeficientes racionales
> 
> 𝕋 = ℝ \ 𝔸
> ```
> 
> **Ejemplos trascendentes:**
> 
> ```
> π  (Lindemann, 1882)
> e  (Hermite, 1873)
> 2^√2  (Gelfond-Schneider)
> ln(2)
> ```
> 
> **Relaciones:**
> 
> ```
> ℚ ⊂ 𝔸 ⊂ ℝ
> 𝕋 ⊂ ℝ
> 𝔸 ∩ 𝕋 = ∅
> 𝔸 ∪ 𝕋 = ℝ
> ```
> 
> **Propiedad sorprendente:**
> 
> - Los algebraicos son numerables: |𝔸| = ℵ₀
> - Los trascendentes son no numerables: |𝕋| = 𝔠
> - **Casi todos** los números reales son trascendentes
> - ¡Pero conocemos explícitamente muy pocos!

## 🌊 Números Reales (ℝ)

> [!success]- El Continuo Completo
> 
> **Definición intuitiva:**
> 
> ```
> ℝ = ℚ ∪ 𝕀
> ```
> 
> "Todos los números que pueden ubicarse en una recta continua"
> 
> **Características fundamentales:**
> 
> 1. **Completitud:** No hay "huecos" en la recta
> 2. **Orden total:** Cualquier par puede compararse
> 3. **Campo ordenado completo:** Único con estas propiedades
> 4. **Continuo:** Entre cualquier par hay infinitos números
> 5. **No numerable:** Más "grande" que ℚ o ℕ
> 
> **Axioma de Completitud:**
> 
> ```
> Todo conjunto no vacío de números reales acotado superiormente
> tiene un supremo (mínima cota superior) en ℝ
> ```
> 
> Este axioma distingue a ℝ de ℚ

> [!note]- Construcciones Formales de ℝ
> 
> **1. Cortaduras de Dedekind (1872):**
> 
> ```
> Una cortadura es un par (A, B) donde:
> - A, B ⊂ ℚ
> - A ∪ B = ℚ
> - A ∩ B = ∅
> - ∀a ∈ A, ∀b ∈ B: a < b
> - A no tiene máximo
> 
> Cada cortadura define un número real
> 
> Ejemplo: √2 definido por
> A = {q ∈ ℚ : q² < 2 o q < 0}
> B = {q ∈ ℚ : q² ≥ 2 y q > 0}
> ```
> 
> **2. Sucesiones de Cauchy (Cantor, 1872):**
> 
> ```
> ℝ = (conjunto de sucesiones de Cauchy en ℚ) / ~
> 
> donde {aₙ} ~ {bₙ} ⟺ lim(aₙ - bₙ) = 0
> 
> Ejemplo: √2 representado por
> {1, 1.4, 1.41, 1.414, 1.4142, ...}
> ```
> 
> **3. Expansiones decimales (Weierstrass):**
> 
> ```
> Todo número real tiene una expansión decimal única
> (si se evita 0.999... = 1.000...)
> 
> Racionales: decimales finitos o periódicos
> Irracionales: decimales infinitos no periódicos
> ```

> [!example]- Propiedades de ℝ
> 
> **Cardinalidad:**
> 
> ```
> |ℝ| = 𝔠 (cardinal del continuo)
> |ℝ| > |ℚ| = |ℕ| = ℵ₀
> 
> ℝ es no numerable (diagonal de Cantor)
> ```
> 
> **Densidad de subconjuntos:**
> 
> ```
> ℚ es denso en ℝ: entre dos reales hay un racional
> 𝕀 es denso en ℝ: entre dos reales hay un irracional
> ```
> 
> **Operaciones cerradas:**
> 
> ```
> ∀a, b ∈ ℝ:
> a + b ∈ ℝ
> a - b ∈ ℝ
> a × b ∈ ℝ
> a ÷ b ∈ ℝ  (si b ≠ 0)
> ```
> 
> **Propiedad arquimediana:**
> 
> ```
> ∀x, y ∈ ℝ con x, y > 0, ∃n ∈ ℕ tal que nx > y
> 
> "No hay infinitésimos en ℝ"
> ```
> 
> **Intervalos encajados:**
> 
> ```
> Si I₁ ⊇ I₂ ⊇ I₃ ⊇ ... son intervalos cerrados
> con longitud → 0, entonces ⋂Iₙ contiene exactamente un punto
> ```

## 🎯 Identificación Práctica de Números

> [!tip]- Cómo Clasificar un Número Dado
> 
> **Árbol de decisión:**
> 
> ```
> ¿Es entero positivo o cero?
>   └─ SÍ → ℕ

>

>   └─ SÍ → ℚ
>   └─ NO → 𝕀 (y por tanto ℝ)
> ```
>

## 🔢 Densidad y Completitud

> [!important]- Conceptos Fundamentales de la Estructura de ℝ
> 
> **Densidad de ℚ en ℝ:**
> ```
> Teorema: Entre dos números reales distintos siempre existe un racional
> 
> Formalmente: ∀a, b ∈ ℝ con a < b, ∃r ∈ ℚ tal que a < r < b
> 
> Construcción: Si a < b, sea n ∈ ℕ tal que n(b - a) > 1
>               Sea m el menor entero tal que m/n > a
>               Entonces a < m/n < b
> ```
> 
> **Densidad de 𝕀 en ℝ:**
> ```
> Teorema: Entre dos números reales distintos siempre existe un irracional
> 
> Construcción: Si a < b son reales,
>               entonces a/√2 < b/√2
>               Por densidad de ℚ: ∃r ∈ ℚ con a/√2 < r < b/√2
>               Luego a < r√2 < b donde r√2 es irracional
> ```
> 
> **Consecuencias filosóficas:**
> - Los racionales son "densos pero con huecos"
> - Los irracionales "llenan los huecos" de los racionales
> - Juntos forman el continuo sin agujeros
> 
> **Paradoja de la densidad:**
> ```
> - ℚ es denso en ℝ (parece "llenar" la recta)
> - Pero |ℚ| = ℵ₀ mientras |ℝ| = 𝔠 >> ℵ₀
> - Los "huecos" son "más numerosos" que los puntos racionales
> ```

> [!note]- Propiedad de Completitud
> 
> **Definición:**
> Un conjunto ordenado es **completo** si todo subconjunto no vacío acotado superiormente tiene supremo.
> 
> **Axioma del Supremo (Completitud de ℝ):**
> ```
> Si A ⊆ ℝ, A ≠ ∅, y A está acotado superiormente,
> entonces existe sup(A) ∈ ℝ
> ```
> 
> **Ejemplo donde ℚ NO es completo:**
> ```
> Sea A = {x ∈ ℚ : x² < 2}
> 
> A está acotado superiormente en ℚ (por ejemplo, 2 es cota superior)
> Pero sup(A) = √2 ∉ ℚ
> 
> Por tanto, el supremo no existe en ℚ
> ```
> 
> **¿Por qué importa la completitud?**
> - Garantiza existencia de límites
> - Permite definir integrales (área bajo curvas)
> - Fundamenta el cálculo diferencial e integral
> - Asegura convergencia de sucesiones de Cauchy
> 
> **Teorema:** ℝ es el ÚNICO campo ordenado completo (salvo isomorfismo)

## 🎲 Cardinalidad e Infinitos

> [!tip]- Comparando Tamaños de Infinito (Cantor)
> 
> **Conjuntos numerables (contables):**
> ```
> |ℕ| = |ℤ| = |ℚ| = ℵ₀ (aleph-cero)
> ```
> 
> Pueden ponerse en correspondencia 1-1 con ℕ
> 
> **Demostración: ℚ es numerable**
> ```
> Método de diagonal de Cantor:
> 
>     1/1  1/2  1/3  1/4  1/5  ...
>      ↓  ↗  ↓
>     2/1  2/2  2/3  2/4  2/5  ...
>      ↓    ↗  ↓
>     3/1  3/2  3/3  3/4  3/5  ...
>      ↓       ↗
>     4/1  4/2  4/3  4/4  4/5  ...
>     ...
> 
> Recorrido en zigzag enumera todas las fracciones
> ```
> 
> **ℝ es NO numerable:**
> ```
> |ℝ| = 𝔠 (cardinal del continuo)
> 𝔠 > ℵ₀
> ```
> 
> **Demostración (diagonal de Cantor, 1891):**
> ```
> Supongamos que ℝ es numerable: ℝ = {r₁, r₂, r₃, ...}
> 
> Escribimos decimales:
> r₁ = 0.a₁₁ a₁₂ a₁₃ a₁₄ ...
> r₂ = 0.a₂₁ a₂₂ a₂₃ a₂₄ ...
> r₃ = 0.a₃₁ a₃₂ a₃₃ a₃₄ ...
> r₄ = 0.a₄₁ a₄₂ a₄₃ a₄₄ ...
> ...
> 
> Construimos x = 0.b₁ b₂ b₃ b₄ ... donde:
> bₙ ≠ aₙₙ (difiere en la posición n del número n-ésimo)
> 
> Entonces x ∉ {r₁, r₂, r₃, ...} → contradicción
> 
> Por tanto, ℝ no es numerable
> ```
> 
> **Implicación sorprendente:**
> ```
> Como ℝ = ℚ ∪ 𝕀 y ℚ es numerable pero ℝ no lo es:
> 
> |𝕀| = 𝔠 (los irracionales son no numerables)
> 
> "Casi todos" los números reales son irracionales
> ```
> 
> **Hipótesis del Continuo (Cantor, 1878):**
> ```
> ¿Existe un cardinal entre ℵ₀ y 𝔠?
> 
> Respuesta (Gödel 1940, Cohen 1963):
> Es independiente de los axiomas ZFC
> (No se puede probar ni refutar)
> ```

## ⚠️ Errores Comunes y Confusiones

> [!warning]- Malentendidos Frecuentes
> 
> **1. "0.999... ≠ 1"**
> ```
> ✗ INCORRECTO
> ✓ CORRECTO: 0.999... = 1
> 
> Demostración algebraica:
> x = 0.999...
> 10x = 9.999...
> 10x - x = 9.999... - 0.999...
> 9x = 9
> x = 1
> 
> Demostración por límite:
> 0.999... = lim(0.9 + 0.09 + 0.009 + ...)
>          = lim(Σ 9/10ⁿ) = 9 · 1/(1-0.1) = 1
> ```
> 
> **2. "√4 = ±2"**
> ```
> ✗ INCORRECTO: √4 = ±2
> ✓ CORRECTO: √4 = 2 (raíz principal, positiva)
> 
> La ecuación x² = 4 tiene dos soluciones: x = ±2
> Pero el símbolo √ denota solo la raíz positiva
> ```
> 
> **3. "Todos los decimales infinitos son irracionales"**
> ```
> ✗ INCORRECTO
> ✓ CORRECTO: Solo los decimales infinitos NO periódicos
> 
> Contraejemplo: 0.333... = 1/3 ∈ ℚ
> ```
> 
> **4. "π = 22/7"**
> ```
> ✗ INCORRECTO
> ✓ CORRECTO: 22/7 ≈ 3.142857... es una aproximación
>             π = 3.141592... es irracional
> 
> 22/7 - π ≈ 0.001264... (error pequeño pero real)
> ```
> 
> **5. "Entre dos números consecutivos no hay nada"**
> ```
> ✗ INCORRECTO en ℝ (no hay números "consecutivos")
> ✓ CORRECTO en ℕ y ℤ (hay números consecutivos)
> 
> En ℝ: entre cualquier par siempre hay infinitos números
> ```
> 
> **6. "√(a²) = a"**
> ```
> ✗ INCORRECTO en general
> ✓ CORRECTO: √(a²) = |a|
> 
> Ejemplo: √((-3)²) = √9 = 3 = |-3| ≠ -3
> ```
> 
> **7. "La suma de dos irracionales es irracional"**
> ```
> ✗ INCORRECTO
> 
> Contraejemplo: √2 + (-√2) = 0 ∈ ℚ
> Otro: (1 + √2) + (1 - √2) = 2 ∈ ℚ
> ```

## 🧮 Operaciones y Propiedades en ℝ

> [!success]- Propiedades Algebraicas Fundamentales
> 
> **Campo (Field):** ℝ con suma y producto
> 
> **Propiedades de la suma:**
> ```
> 1. Clausura: a + b ∈ ℝ
> 2. Asociativa: (a + b) + c = a + (b + c)
> 3. Conmutativa: a + b = b + a
> 4. Neutro: ∃0 ∈ ℝ tal que a + 0 = a
> 5. Inverso: ∀a ∃(-a) tal que a + (-a) = 0
> ```
> 
> **Propiedades del producto:**
> ```
> 6. Clausura: a · b ∈ ℝ
> 7. Asociativa: (a · b) · c = a · (b · c)
> 8. Conmutativa: a · b = b · a
> 9. Neutro: ∃1 ∈ ℝ tal que a · 1 = a
> 10. Inverso: ∀a ≠ 0 ∃a⁻¹ tal que a · a⁻¹ = 1
> ```
> 
> **Propiedad distributiva:**
> ```
> a · (b + c) = a · b + a · c
> ```
> 
> **Propiedades de orden:**
> ```
> 11. Tricotomía: ∀a, b: exactamente una es cierta:
>    a < b  o  a = b  o  a > b
> 
> 12. Transitividad: Si a < b y b < c, entonces a < c
> 
> 13. Compatibilidad con suma:
>    Si a < b, entonces a + c < b + c
> 
> 14. Compatibilidad con producto:
>    Si a < b y c > 0, entonces ac < bc
>    Si a < b y c < 0, entonces ac > bc
> ```
