# 🎯 03.9 Valor Absoluto

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **El valor absoluto de un número real es su distancia al origen (cero) en la recta numérica, sin considerar la dirección.**
> 
> **Elementos clave:**
> 
> - **Magnitud sin signo:** Siempre no negativo (≥ 0)
> - **Distancia:** Mide "qué tan lejos" está un número de cero
> - **Simetría:** |a| = |-a| (números opuestos tienen el mismo valor absoluto)
> - **Función:** |·| : ℝ → ℝ≥₀

### 📖 Contexto Histórico

> [!note]- Desarrollo del Concepto de Valor Absoluto
> 
> **Orígenes implícitos (300 a.C. - 1500):**
> 
> - **Euclides:** Concepto de "magnitud" en geometría (siempre positiva)
> - **Matemáticos árabes:** Distancias en problemas geométricos
> - **Uso tácito:** Se entendía que las distancias son positivas
> 
> **Era algebraica (1500-1800):**
> 
> - **Cardano (1545):** Trabaja con "números ficticios" (negativos)
> - **Descartes (1637):** Coordenadas y distancias geométricas
> - **Problema:** Falta de notación estándar para magnitud
> 
> **Formalización de la notación (1800-1900):**
> 
> - **Weierstrass (1841):** Introduce la notación |x| moderna
> - **Contexto:** Formalización rigurosa del análisis
> - **Propósito:** Definir límites y continuidad con precisión
> 
> **Desarrollo del concepto (1850-1900):**
> 
> - **Cauchy:** Usa distancias en definición ε-δ de límites
> - **Dedekind y Cantor:** Construcción formal de ℝ
> - **Weierstrass:** Criterio M para series uniformemente convergentes
> 
> **Generalización (1900-presente):**
> 
> - **Espacios métricos (Fréchet, 1906):** Generalización de distancia
> - **Normas vectoriales:** |·| → ‖·‖ en espacios normados
> - **Valor absoluto p-ádico:** Alternativas algebraicas
> - **Análisis funcional:** Extensión a espacios infinito-dimensionales
> 
> **Impacto:** El valor absoluto se convirtió en herramienta fundamental para:
> 
> - Definir distancia y topología en ℝ
> - Expresar desigualdades y acotaciones
> - Formalizar límites, continuidad y convergencia
> - Base de espacios métricos y normados

## 📐 Definición Formal

### Definición por Casos

> [!success]- Definición Algebraica
> 
> **Definición:** Para todo x ∈ ℝ, el valor absoluto de x se define como:
> 
> ```
> |x| = { x,   si x ≥ 0
>       {-x,   si x < 0
> ```
> 
> **Interpretación:**
> 
> - Si x es positivo o cero: |x| = x (el número mismo)
> - Si x es negativo: |x| = -x (el opuesto, que es positivo)
> 
> **Ejemplos numéricos:**
> 
> ```
> |5|    = 5      (positivo → se queda igual)
> |-5|   = -(-5) = 5   (negativo → se cambia de signo)
> |0|    = 0      (cero → se queda igual)
> |3.7|  = 3.7
> |-π|   = π
> |√2|   = √2
> |-1/2| = 1/2
> ```

### Definición como Distancia

> [!note]- Interpretación Geométrica
> 
> **Definición alternativa:**
> 
> ```
> |x| = distancia de x al origen en la recta numérica
> ```
> 
> **Visualización:**
> 
> ```
>        |x| = 5               |x| = 5
>     <----•                     •---->
>          x=-5      0          x=5
> ─────────•────────•───────────•─────────
> 
> Ambos puntos están a distancia 5 del origen
> ```
> 
> **Propiedad fundamental:** La distancia es siempre no negativa: |x| ≥ 0 para todo x ∈ ℝ

### Definición como Raíz Cuadrada

> [!tip]- Forma Cuadrática
> 
> **Definición alternativa:**
> 
> ```
> |x| = √(x²)
> ```
> 
> **Justificación:**
> 
> - Si x ≥ 0: √(x²) = √(x·x) = x = |x| ✓
> - Si x < 0: √(x²) = √((-x)·(-x)) = -x = |x| ✓
> 
> **Ventaja:** Generaliza fácilmente a normas en dimensiones superiores
> 
> **Advertencia:**
> 
> ```
> √(x²) = |x|  ✓  CORRECTO
> √(x²) = x    ✗  INCORRECTO (solo cierto si x ≥ 0)
> 
> Ejemplo: √((-3)²) = √9 = 3 = |-3| ≠ -3
> ```

## 📊 Propiedades Fundamentales

### Propiedades Básicas

> [!success]- Propiedades Algebraicas Esenciales
> 
> **1. No negatividad:**
> 
> ```
> |x| ≥ 0  para todo x ∈ ℝ
> |x| = 0  ⟺  x = 0
> ```
> 
> **2. Simetría (par):**
> 
> ```
> |-x| = |x|  para todo x ∈ ℝ
> ```
> 
> **3. Desigualdad triangular:**
> 
> ```
> |x + y| ≤ |x| + |y|  para todo x, y ∈ ℝ
> 
> "El camino directo es el más corto"
> ```
> 
> **4. Multiplicatividad:**
> 
> ```
> |xy| = |x| · |y|  para todo x, y ∈ ℝ
> ```
> 
> **5. Preservación de cocientes:**
> 
> ```
> |x/y| = |x|/|y|  para todo x, y ∈ ℝ, y ≠ 0
> ```
> 
> **6. Potencias:**
> 
> ```
> |xⁿ| = |x|ⁿ  para todo x ∈ ℝ, n ∈ ℕ
> ```
> 
> **7. Acotación fundamental:**
> 
> ```
> -|x| ≤ x ≤ |x|  para todo x ∈ ℝ
> 
> Equivalentemente: |x| ≥ x  y  |x| ≥ -x
> ```

> [!example]- Ejemplos de Propiedades
> 
> **Simetría:**
> 
> ```
> |7| = |-7| = 7
> |√3| = |-√3| = √3
> ```
> 
> **Desigualdad triangular:**
> 
> ```
> |3 + 5| = |8| = 8
> |3| + |5| = 3 + 5 = 8
> → |3 + 5| = |3| + |5|  (igualdad cuando ambos tienen mismo signo)
> 
> |3 + (-5)| = |-2| = 2
> |3| + |-5| = 3 + 5 = 8
> → |3 + (-5)| < |3| + |-5|  (desigualdad estricta con signos opuestos)
> ```
> 
> **Multiplicatividad:**
> 
> ```
> |(-3) · 4| = |-12| = 12
> |-3| · |4| = 3 · 4 = 12  ✓
> 
> |(-2) · (-5)| = |10| = 10
> |-2| · |-5| = 2 · 5 = 10  ✓
> ```
> 
> **Acotación:**
> 
> ```
> Para x = 3:   -|3| = -3 ≤ 3 ≤ 3 = |3|  ✓
> Para x = -5:  -|-5| = -5 ≤ -5 ≤ 5 = |-5|  ✓
> ```

### Desigualdad Triangular Generalizada

> [!important]- Variantes y Extensiones
> 
> **Desigualdad triangular inversa:**
> 
> ```
> ||x| - |y|| ≤ |x - y|  para todo x, y ∈ ℝ
> 
> "La diferencia de distancias es menor que la distancia de la diferencia"
> ```
> 
> **Demostración:**
> 
> ```
> |x| = |(x - y) + y| ≤ |x - y| + |y|
> → |x| - |y| ≤ |x - y|
> 
> Análogamente: |y| - |x| ≤ |y - x| = |x - y|
> → -(|x| - |y|) ≤ |x - y|
> 
> Combinando: ||x| - |y|| ≤ |x - y|
> ```
> 
> **Desigualdad triangular para n términos:**
> 
> ```
> |x₁ + x₂ + ... + xₙ| ≤ |x₁| + |x₂| + ... + |xₙ|
> ```
> 
> **Demostración por inducción:**
> 
> ```
> Base: n = 2 (propiedad fundamental)
> 
> Paso inductivo:
> |x₁ + ... + xₙ₊₁| = |(x₁ + ... + xₙ) + xₙ₊₁|
>                    ≤ |x₁ + ... + xₙ| + |xₙ₊₁|  (desig. triangular)
>                    ≤ (|x₁| + ... + |xₙ|) + |xₙ₊₁|  (hip. inductiva)
>                    = |x₁| + ... + |xₙ| + |xₙ₊₁|
> ```

## 📏 Valor Absoluto y Distancia

### Distancia entre Dos Puntos

> [!success]- Métrica en la Recta Real
> 
> **Definición:** La distancia entre dos números reales a y b se define como:
> 
> ```
> d(a, b) = |b - a| = |a - b|
> ```
> 
> **Interpretación geométrica:**
> 
> ```
>     <----d---->
>     a          b
> ────•──────────•────
> 
> d(a, b) = longitud del segmento entre a y b
> ```
> 
> **Propiedades de la distancia (métrica):**
> 
> 1. **No negatividad:** d(a, b) ≥ 0
> 2. **Identidad:** d(a, b) = 0 ⟺ a = b
> 3. **Simetría:** d(a, b) = d(b, a)
> 4. **Desigualdad triangular:** d(a, c) ≤ d(a, b) + d(b, c)

> [!example]- Ejemplos de Distancias
> 
> **Cálculos directos:**
> 
> ```
> d(3, 7) = |7 - 3| = |4| = 4
> d(-2, 5) = |5 - (-2)| = |7| = 7
> d(-3, -8) = |-8 - (-3)| = |-5| = 5
> d(0, x) = |x - 0| = |x|  (distancia al origen)
> ```
> 
> **Verificación de simetría:**
> 
> ```
> d(3, 7) = |7 - 3| = 4
> d(7, 3) = |3 - 7| = |-4| = 4  ✓
> ```
> 
> **Desigualdad triangular:**
> 
> ```
> Puntos: a = 1, b = 3, c = 8
> 
> d(1, 8) = |8 - 1| = 7
> d(1, 3) + d(3, 8) = |3 - 1| + |8 - 3| = 2 + 5 = 7
> 
> → d(1, 8) = d(1, 3) + d(3, 8)  (igualdad cuando b está entre a y c)
> 
>     a   b       c
>     •───•───────•
>     1   3       8
> ```

### Vecindades y Entornos

> [!note]- Intervalos Definidos por Distancia
> 
> **ε-vecindad (epsilon-vecindad):**
> 
> ```
> Vε(a) = {x ∈ ℝ : |x - a| < ε}
>       = (a - ε, a + ε)
> 
> "Todos los puntos a distancia menor que ε de a"
> ```
> 
> **Visualización:**
> 
> ```
>         ε        ε
>     <----•---•---•---->
>         a-ε  a  a+ε
>          (=======)
>             Vε(a)
> ```
> 
> **Vecindad cerrada:**
> 
> ```
> V̄ε(a) = {x ∈ ℝ : |x - a| ≤ ε}
>        = [a - ε, a + ε]
> ```
> 
> **Vecindad reducida (perforada):**
> 
> ```
> V*ε(a) = {x ∈ ℝ : 0 < |x - a| < ε}
>        = (a - ε, a) ∪ (a, a + ε)
> 
> "Vecindad sin incluir el centro a"
> ```
> 
> **Ejemplos:**
> 
> ```
> V₂(5) = (3, 7)          vecindad de radio 2 en 5
> V₁(0) = (-1, 1)         vecindad unitaria del origen
> V₀.₅(-3) = (-3.5, -2.5) vecindad de radio 0.5 en -3
> ```

> [!tip]- Aplicaciones en Análisis
> 
> **Definición de límite (ε-δ):**
> 
> ```
> lim f(x) = L  significa:
> x→a
> 
> ∀ε > 0, ∃δ > 0 tal que:
> si 0 < |x - a| < δ entonces |f(x) - L| < ε
> 
> En términos de vecindades:
> si x ∈ V*δ(a) entonces f(x) ∈ Vε(L)
> ```
> 
> **Continuidad:**
> 
> ```
> f es continua en a si:
> ∀ε > 0, ∃δ > 0 tal que:
> si |x - a| < δ entonces |f(x) - f(a)| < ε
> 
> "Puntos cercanos se mapean a puntos cercanos"
> ```
> 
> **Convergencia de sucesiones:**
> 
> ```
> aₙ → L significa:
> ∀ε > 0, ∃N ∈ ℕ tal que:
> si n ≥ N entonces |aₙ - L| < ε
> 
> "Eventualmente todos los términos entran en cualquier vecindad de L"
> ```

## 🔢 Ecuaciones con Valor Absoluto

### Ecuaciones Simples

> [!success]- Resolver |x| = a
> 
> **Caso 1: a < 0**
> 
> ```
> |x| = a  con a < 0  →  Sin solución (∅)
> 
> Razón: |x| ≥ 0 siempre, no puede ser negativo
> 
> Ejemplo: |x| = -3  →  ∅
> ```
> 
> **Caso 2: a = 0**
> 
> ```
> |x| = 0  →  x = 0
> 
> Única solución: el cero
> ```
> 
> **Caso 3: a > 0**
> 
> ```
> |x| = a  →  x = a  o  x = -a
> 
> Dos soluciones simétricas respecto al origen
> 
> Ejemplo: |x| = 5  →  x = 5  o  x = -5
> ```
> 
> **Justificación:**
> 
> ```
> Por definición:
> |x| = { x   si x ≥ 0
>       {-x  si x < 0
> 
> Si |x| = a con a > 0:
> - Caso x ≥ 0: x = a
> - Caso x < 0: -x = a → x = -a
> ```

### Ecuaciones con Expresiones

> [!example]- |expresión| = a
> 
> **Método general:**
> 
> ```
> |f(x)| = a  con a > 0
> 
> ⟺ f(x) = a  o  f(x) = -a
> ```
> 
> **Ejemplo 1:**
> 
> ```
> |2x - 3| = 5
> 
> Caso 1: 2x - 3 = 5       Caso 2: 2x - 3 = -5
>        2x = 8                    2x = -2
>        x = 4                     x = -1
> 
> Soluciones: x = 4  o  x = -1
> 
> Verificación:
> |2(4) - 3| = |5| = 5  ✓
> |2(-1) - 3| = |-5| = 5  ✓
> ```
> 
> **Ejemplo 2:**
> 
> ```
> |x + 1| = 2x
> 
> Caso 1: x + 1 = 2x       Caso 2: x + 1 = -2x
>        1 = x                     3x = -1
>        x = 1                     x = -1/3
> 
> Verificación necesaria (la ecuación involucra x en ambos lados):
> x = 1:   |1 + 1| = 2 ≟ 2(1) = 2  ✓
> x = -1/3: |-1/3 + 1| = 2/3 ≟ 2(-1/3) = -2/3  ✗
> 
> Única solución válida: x = 1
> ```
> 
> **Ejemplo 3:**
> 
> ```
> |x - 2| = |x + 4|
> 
> Método: Igualar las expresiones o sus opuestas
> 
> Caso 1: x - 2 = x + 4
>        -2 = 4  (imposible)
> 
> Caso 2: x - 2 = -(x + 4)
>        x - 2 = -x - 4
>        2x = -2
>        x = -1
> 
> Solución: x = -1
> 
> Verificación:
> |-1 - 2| = |-3| = 3
> |-1 + 4| = |3| = 3  ✓
> ```
> 
> **Interpretación geométrica de |x - a| = |x - b|:**
> 
> ```
> "Puntos equidistantes de a y b"
> → x es el punto medio entre a y b
> → x = (a + b)/2
> 
> Para |x - 2| = |x + 4|:
> x = (2 + (-4))/2 = -2/2 = -1  ✓
> ```

### Ecuaciones con Múltiples Valores Absolutos

> [!tip]- Método de Análisis por Intervalos
> 
> **Estrategia:**
> 
> 1. Identificar puntos críticos (donde las expresiones dentro de |·| cambian de signo)
> 2. Dividir la recta en intervalos según estos puntos
> 3. En cada intervalo, eliminar los valores absolutos según el signo
> 4. Resolver en cada intervalo
> 5. Verificar que las soluciones pertenezcan a su intervalo
> 
> **Ejemplo: |x - 1| + |x + 2| = 5**
> 
> **Paso 1: Puntos críticos**
> 
> ```
> x - 1 = 0  →  x = 1
> x + 2 = 0  →  x = -2
> 
> Intervalos: (-∞, -2), [-2, 1], [1, ∞)
> ```
> 
> **Paso 2: Análisis de signos**
> 
> ```
> En (-∞, -2):    x - 1 < 0  y  x + 2 < 0
> En [-2, 1]:     x - 1 < 0  y  x + 2 ≥ 0
> En [1, ∞):      x - 1 ≥ 0  y  x + 2 > 0
> ```
> 
> **Paso 3: Resolver en cada intervalo**
> 
> ```
> Intervalo 1: x < -2
> -(x - 1) + (-(x + 2)) = 5
> -x + 1 - x - 2 = 5
> -2x - 1 = 5
> x = -3  ✓ (pertenece a (-∞, -2))
> 
> Intervalo 2: -2 ≤ x < 1
> -(x - 1) + (x + 2) = 5
> -x + 1 + x + 2 = 5
> 3 = 5  (imposible, sin solución en este intervalo)
> 
> Intervalo 3: x ≥ 1
> (x - 1) + (x + 2) = 5
> 2x + 1 = 5
> x = 2  ✓ (pertenece a [1, ∞))
> ```
> 
> **Soluciones: x = -3 o x = 2**
> 
> **Verificación:**
> 
> ```
> x = -3: |-3 - 1| + |-3 + 2| = |-4| + |-1| = 4 + 1 = 5  ✓
> x = 2:  |2 - 1| + |2 + 2| = |1| + |4| = 1 + 4 = 5  ✓
> ```

## ⚖️ Desigualdades con Valor Absoluto

### Desigualdades Básicas: |x| < a y |x| > a

> [!success]- Formas Fundamentales
> 
> **Tipo 1: |x| < a (a > 0)**
> 
> ```
> |x| < a  ⟺  -a < x < a
> 
> Solución: (-a, a)
> 
> Interpretación: "x está a menos de a unidades del origen"
> 
>     <----a---->
>         ○───────○
>        -a   0   a
> ```
> 
> **Tipo 2: |x| ≤ a (a > 0)**
> 
> ```
> |x| ≤ a  ⟺  -a ≤ x ≤ a
> 
> Solución: [-a, a]
> 
>     <----a---->
>         •───────•
>        -a   0   a
> ```
> 
> **Tipo 3: |x| > a (a > 0)**
> 
> ```
> |x| > a  ⟺  x < -a  o  x > a
> 
> Solución: (-∞, -a) ∪ (a, ∞)
> 
>     <====○         ○====>
>         -a    0    a
> ```
> 
> **Tipo 4: |x| ≥ a (a > 0)**
> 
> ```
> |x| ≥ a  ⟺  x ≤ -a  o  x ≥ a
> 
> Solución: (-∞, -a] ∪ [a, ∞)
> 
>     <====•         •====>
>         -a    0    a
> ```

> [!example]- Ejemplos Resueltos
> 
> **Ejemplo 1:**
> 
> ```
> |x| < 3
> 
> Solución: -3 < x < 3  →  (-3, 3)
> 
>     ○───────○
>    -3   0   3
> ```
> 
> **Ejemplo 2:**
> 
> ```
> |x| ≥ 5
> 
> Solución: x ≤ -5  o  x ≥ 5
>          (-∞, -5] ∪ [5, ∞)
> 
> <====•         •====>
>     -5    0    5
> ```
> 
> **Ejemplo 3:**
> 
> ```
> |x| < 0
> 
> Sin solución (∅)
> Razón: |x| ≥ 0 siempre, no puede ser < 0
> ```
> 
> **Ejemplo 4:**
> 
> ```
> |x| > 0
> 
> Solución: todos los números excepto 0
>          (-∞, 0) ∪ (0, ∞) = ℝ \ {0}
> ```

### Desigualdades con Expresiones

> [!important]- |f(x)| < a y |f(x)| > a
> 
> **Reglas generales:**
> 
> **Para |f(x)| < a (a > 0):**
> 
> ```
> |f(x)| < a  ⟺  -a < f(x) < a
> ```
> 
> **Para |f(x)| ≤ a (a > 0):**
> 
> ```
> |f(x)| ≤ a  ⟺  -a ≤ f(x) ≤ a
> ```
> 
> **Para |f(x)| > a (a > 0):**
> 
> ```
> |f(x)| > a  ⟺  f(x) < -a  o  f(x) > a
> ```
> 
> **Para |f(x)| ≥ a (a > 0):**
> 
> ```
> |f(x)| ≥ a  ⟺  f(x) ≤ -a  o  f(x) ≥ a
> ```

> [!example]- Ejemplos Paso a Paso
> 
> **Ejemplo 1:**
> 
> ```
> |2x - 3| < 5
> 
> -5 < 2x - 3 < 5
> -5 + 3 < 2x < 5 + 3
> -2 < 2x < 8
> -1 < x < 4
> 
> Solución: (-1, 4)
> 
>     ○───────────○
>    -1     0     4
> ```
> 
> **Ejemplo 2:**
> 
> ```
> |3x + 1| ≥ 7
> 
> 3x + 1 ≤ -7  o  3x + 1 ≥ 7
> 3x ≤ -8      o  3x ≥ 6
> x ≤ -8/3     o  x ≥ 2
> 
> Solución: (-∞, -8/3] ∪ [2, ∞)
> 
> <====•         •====>
>    -8/3   0    2
> ```
> 
> **Ejemplo 3:**
> 
> ```
> |x - 5| ≤ 2
> 
> -2 ≤ x - 5 ≤ 2
> -2 + 5 ≤ x ≤ 2 + 5
> 3 ≤ x ≤ 7
> 
> Solución: [3, 7]
> 
> Interpretación geométrica:
> "Todos los puntos a distancia ≤ 2 del punto 5"
> 
>         •───────•
>         3   5   7
> ```
> 
> **Ejemplo 4:**
> 
> ```
> |2x + 1| > 9
> 
> 2x + 1 < -9  o  2x + 1 > 9
> 2x < -10     o  2x > 8
> x < -5       o  x > 4
> 
> Solución: (-∞, -5) ∪ (4, ∞)
> 
> <====○         ○====>
>     -5    0    4
> ```

### Desigualdades Compuestas

> [!tip]- Casos Más Complejos
> 
> **Forma: a < |f(x)| < b**
> 
> ```
> Significa: |f(x)| > a  Y  |f(x)| < b
> 
> Resolver cada parte y tomar la intersección
> ```
> 
> **Ejemplo:**
> 
> ```
> 2 < |x - 1| < 5
> 
> Parte 1: |x - 1| > 2
> x - 1 < -2  o  x - 1 > 2
> x < -1      o  x > 3
> ```
> ```
> x < -1      o  x > 3
> → (-∞, -1) ∪ (3, ∞)
> 
> Parte 2: |x - 1| < 5
> -5 < x - 1 < 5
> -4 < x < 6
> → (-4, 6)
> 
> Solución: [(-∞, -1) ∪ (3, ∞)] ∩ (-4, 6)
>         = (-4, -1) ∪ (3, 6)
> 
> Visualización:
>     <====○     ○====>      Parte 1
>         -1  1  3
>     ○══════════════○        Parte 2
>    -4           1           6
>     ○═══○     ○═══○         Intersección
>    -4  -1     3   6
> ```

### Desigualdades con Dos Valores Absolutos

> [!note]- |f(x)| < |g(x)|
> 
> **Método 1: Elevar al cuadrado (válido porque ambos lados son ≥ 0)**
> ```
> |f(x)| < |g(x)|  ⟺  [f(x)]² < [g(x)]²
> ```
> 
> **Método 2: Análisis por casos**
> Considerar signos de f(x) y g(x)
> 
> **Ejemplo:**
> ```
> |x - 2| < |x + 1|
> 
> Método 1 (elevar al cuadrado):
> (x - 2)² < (x + 1)²
> x² - 4x + 4 < x² + 2x + 1
> -4x + 4 < 2x + 1
> -6x < -3
> x > 1/2
> 
> Solución: (1/2, ∞)
> 
> Interpretación geométrica:
> "Puntos más cercanos a 2 que a -1"
> El punto medio es x = (2 + (-1))/2 = 1/2
> Todos los puntos x > 1/2 están más cerca de 2
> 
>         •       •
>        -1   1/2 2
>     <===○   ○═══════>
> ```

## 📊 Gráfica de la Función Valor Absoluto

### Función f(x) = |x|

> [!success]- Gráfica Básica
> 
> **Definición:**
> ```
> f(x) = |x| = { x,   si x ≥ 0
>              {-x,   si x < 0
> ```
> 
> **Características:**
> - **Dominio:** ℝ (todos los números reales)
> - **Imagen:** [0, ∞) (solo valores no negativos)
> - **Vértice:** (0, 0)
> - **Simetría:** Par (simétrica respecto al eje y)
> - **Pendiente:** -1 para x < 0, +1 para x > 0
> - **Continuidad:** Continua en todo ℝ
> - **Derivabilidad:** NO derivable en x = 0 (punto angular)
> 
> **Representación ASCII:**
> ```
>   y
>   |
> 4 |      /|\
> 3 |     / | \
> 2 |    /  |  \
> 1 |   /   |   \
>   |  /    |    \
> --+------------------x
>  -4  -2   0   2   4
> 
> Para x < 0: recta y = -x (pendiente -1)
> Para x > 0: recta y = x (pendiente +1)
> ```
> 
> **Tabla de valores:**
> ```
> x  | -3 | -2 | -1 | 0 | 1 | 2 | 3 |
> ---|----|----|----|----|----|----|---|
> |x|| 3  | 2  | 1  | 0 | 1 | 2 | 3 |
> ```

### Transformaciones de |x|

> [!tip]- Familia de Funciones con Valor Absoluto
> 
> **1. Traslación vertical: f(x) = |x| + k**
> ```
> k > 0: Desplaza hacia arriba k unidades
> k < 0: Desplaza hacia abajo k unidades
> 
> Ejemplo: f(x) = |x| + 2
> Vértice en (0, 2)
> ```
> 
> **2. Traslación horizontal: f(x) = |x - h|**
> ```
> h > 0: Desplaza hacia la derecha h unidades
> h < 0: Desplaza hacia la izquierda h unidades
> 
> Ejemplo: f(x) = |x - 3|
> Vértice en (3, 0)
> ```
> 
> **3. Dilatación vertical: f(x) = a|x|**
> ```
> |a| > 1: Estira verticalmente (más "puntiaguda")
> 0 < |a| < 1: Comprime verticalmente (más "abierta")
> a < 0: Refleja respecto al eje x (parábola invertida)
> 
> Ejemplo: f(x) = 2|x|
> Pendientes: -2 y +2
> ```
> 
> **4. Dilatación horizontal: f(x) = |bx|**
> ```
> |b| > 1: Comprime horizontalmente
> 0 < |b| < 1: Estira horizontalmente
> 
> Ejemplo: f(x) = |2x|
> Más "puntiaguda" que |x|
> ```
> 
> **5. Forma general: f(x) = a|x - h| + k**
> ```
> Vértice: (h, k)
> Factor de estiramiento: |a|
> Reflejo si a < 0
> 
> Ejemplo: f(x) = -2|x - 1| + 3
> Vértice: (1, 3)
> Abre hacia abajo
> Estiramiento factor 2
> ```

> [!example]- Ejemplos de Gráficas
> 
> **Ejemplo 1: f(x) = |x - 2| - 1**
> ```
> Vértice: (2, -1)
> Traslación de |x|: 2 unidades derecha, 1 unidad abajo
> 
>   y
>   |
> 2 |        /\
> 1 |       /  \
>   |      /    \
> -1|-----•------  (vértice)
> -2|    /      \
>   +------------------x
>      0   2    4
> 
> Ramas:
> x < 2: y = -(x - 2) - 1 = -x + 1
> x ≥ 2: y = (x - 2) - 1 = x - 3
> ```
> 
> **Ejemplo 2: f(x) = -|x| + 2**
> ```
> Reflexión de |x| sobre eje x, subida 2 unidades
> Vértice máximo en (0, 2)
> 
>   y
>   |
> 2 |    •   (máximo)
> 1 |   / \
>   |  /   \
> -1| /     \
> -2|/_______\___x
>   -2  0   2
> 
> Forma de "V" invertida
> Imagen: (-∞, 2]
> ```

## 🔍 Aplicaciones del Valor Absoluto

### Distancia y Proximidad

> [!example]- Problemas de Distancia
> 
> **Problema 1: Temperatura**
> ```
> Un termostato debe mantener temperatura entre 20°C y 24°C.
> Si T es la temperatura actual, ¿cuándo funciona correctamente?
> 
> Temperatura ideal: 22°C (punto medio)
> Tolerancia: ±2°C
> 
> Condición: |T - 22| ≤ 2
> 
> Solución:
> -2 ≤ T - 22 ≤ 2
> 20 ≤ T ≤ 24
> 
> El termostato funciona si T ∈ [20, 24]
> ```
> 
> **Problema 2: Control de calidad**
> ```
> Una pieza debe medir 50mm con error máximo de 0.3mm.
> Si x es la medida real, ¿cuándo es aceptable?
> 
> Condición: |x - 50| ≤ 0.3
> 
> Solución: 49.7 ≤ x ≤ 50.3
> 
> Rango aceptable: [49.7, 50.3] mm
> ```
> 
> **Problema 3: Proximidad geográfica**
> ```
> ¿Qué números están a menos de 5 unidades de 10?
> 
> |x - 10| < 5
> -5 < x - 10 < 5
> 5 < x < 15
> 
> Respuesta: (5, 15)
> ```

### Error y Aproximación

> [!note]- Error Absoluto vs Error Relativo
> 
> **Error absoluto:**
> ```
> E_abs = |valor_medido - valor_real|
> 
> Mide la "magnitud" del error
> ```
> 
> **Error relativo:**
> ```
> E_rel = |valor_medido - valor_real| / |valor_real|
> 
> Mide el error "porcentualmente"
> ```
> 
> **Ejemplo:**
> ```
> Valor real: 1000
> Valor medido: 1005
> 
> Error absoluto: |1005 - 1000| = 5
> Error relativo: 5/1000 = 0.005 = 0.5%
> 
> ---
> 
> Valor real: 10
> Valor medido: 15
> 
> Error absoluto: |15 - 10| = 5  (mismo que antes)
> Error relativo: 5/10 = 0.5 = 50%  (¡mucho mayor!)
> ```

### Funciones Definidas por Tramos

> [!tip]- Modelando Situaciones Reales
> 
> **Ejemplo 1: Tarifa de taxi**
> ```
> Costo = $5 (banderazo) + $2 por cada km
> 
> Si la distancia mínima a cobrar es |x - x₀|:
> 
> C(x) = 5 + 2|x - x₀|
> 
> donde x₀ es el punto de partida
> ```
> 
> **Ejemplo 2: Función de costo con descuento**
> ```
> Una empresa cobra:
> - $100 por producto si se pide la cantidad exacta Q
> - $100 + $5 por unidad de diferencia si no
> 
> C(x) = 100 + 5|x - Q|
> 
> donde x es la cantidad pedida
> ```
> 
> **Ejemplo 3: Señal de audio**
> ```
> Rectificación de onda:
> y = |A sin(ωt)|
> 
> Convierte señal oscilante en solo valores positivos
> ```

## ⚠️ Errores Comunes

> [!warning]- Confusiones Frecuentes
> 
> **1. Distribución incorrecta del valor absoluto**
> ```
> ✗ |a + b| = |a| + |b|           INCORRECTO en general
> ✓ |a + b| ≤ |a| + |b|           CORRECTO (desig. triangular)
> 
> Contraejemplo: |3 + (-5)| = |-2| = 2
>                |3| + |-5| = 3 + 5 = 8
>                2 ≠ 8
> ```
> 
> **2. Elevar al cuadrado sin cuidado**
> ```
> ✗ Si |x| = |y|, entonces x = y   INCORRECTO
> ✓ Si |x| = |y|, entonces x = ±y  CORRECTO
> 
> Ejemplo: |-3| = |3| pero -3 ≠ 3
> ```
> 
> **3. Confundir |x| > a con solución**
> ```
> ✗ |x| > 3  →  x > 3             INCOMPLETO
> ✓ |x| > 3  →  x < -3 o x > 3    CORRECTO
> 
> Recordar: dos regiones disjuntas
> ```
> 
> **4. Resolver desigualdades sin verificar**
> ```
> Al resolver |f(x)| < g(x), verificar que g(x) > 0
> 
> Ejemplo: |x| < -2  →  ∅ (sin solución)
> ```
> 
> **5. Olvidar que √(x²) = |x|**
> ```
> ✗ √(x²) = x                     INCORRECTO si x < 0
> ✓ √(x²) = |x|                   SIEMPRE CORRECTO
> 
> Ejemplo: √((-4)²) = √16 = 4 = |-4| ≠ -4
> ```
> 
> **6. Manipulación algebraica incorrecta**
> ```
> ✗ |x|/x = 1                     INCORRECTO si x < 0
> ✓ |x|/x = { 1   si x > 0
>           {-1   si x < 0        CORRECTO
> 
> No está definido en x = 0
> ```
> 
> **7. Desigualdad con valores absolutos**
> ```
> ✗ Si |a| < |b|, entonces a < b   INCORRECTO
> 
> Contraejemplo: |-2| < |5| es cierto (2 < 5)
>                pero -2 < 5 no implica que la regla sea general
>                porque |-6| < |3| es falso pero -6 < 3 es cierto
> 
> ✓ |a| < |b|  ⟺  a² < b²         CORRECTO
> ```

## 🧮 Propiedades Avanzadas

### Máximos y Mínimos con Valor Absoluto

> [!note]- Identidades Útiles
> 
> **Máximo de dos números:**
> ```
> max{a, b} = (a + b + |a - b|)/2
> 
> Verificación:
> Si a > b: |a - b| = a - b
>          (a + b + a - b)/2 = 2a/2 = a  ✓
> 
> Si b > a: |a - b| = b - a
>          (a + b + b - a)/2 = 2b/2 = b  ✓
> ```
> 
> **Mínimo de dos números:**
> ```
> min{a, b} = (a + b - |a - b|)/2
> 
> Verificación:
> Si a < b: |a - b| = b - a
>          (a + b - b + a)/2 = 2a/2 = a  ✓
> 
> Si b < a: |a - b| = a - b
>          (a + b - a + b)/2 = 2b/2 = b  ✓
> ```
> 
> **Relación entre ambos:**
> ```
> max{a, b} + min{a, b} = a + b
> max{a, b} - min{a, b} = |a - b|
> ```

### Desigualdades Avanzadas

> [!important]- Teoremas Adicionales
> 
> **Desigualdad triangular generalizada:**
> ```
> ||a| - |b|| ≤ |a - b| ≤ |a| + |b|
> 
> "La diferencia de las distancias no excede 
>  la distancia de la diferencia, que no excede 
>  la suma de distancias"
> ```
> 
> **Desigualdad de Minkowski (caso n=1):**
> ```
> |a + b| ≤ |a| + |b|
> 
> Igualdad si y solo si ab ≥ 0 (mismo signo o alguno cero)
> ```
> 
> **Desigualdad del valor absoluto de un producto:**
> ```
> ||a| - |b|| ≤ |a - b|
> |a - b| ≤ |a - c| + |c - b|  para todo c ∈ ℝ
> ```
> 
> **Forma de Cauchy-Schwarz en ℝ:**
> ```
> |ab| ≤ (a² + b²)/2
> 
> (caso particular de |⟨u,v⟩| ≤ ‖u‖·‖v‖)
> ```

## 📐 Valor Absoluto en Otros Contextos

### Valor Absoluto de Funciones

> [!tip]- Composición con Valor Absoluto
> 
> **Función g(x) = |f(x)|:**
> ```
> Toma los valores de f(x) y los hace no negativos
> 
> Efecto gráfico:
> - Parte de f(x) sobre eje x: se mantiene
> - Parte de f(x) bajo eje x: se refleja hacia arriba
> ```
> 
> **Ejemplo: f(x) = x - 2**
> ```
> f(x) = x - 2  (recta con pendiente 1)
> 
>   y
>   |    /
> 2 |   /
> 1 |  /
>   | /
> -1|/___________x
>   |  2
> 
> |f(x)| = |x - 2|
> 
>   y
>   |   \  /
> 2 |    \/
> 1 |    /\
>   |   /  \
>   |  /____\______x
>      0  2  4
> 
> Reflejo de la parte negativa
> ```
> 
> **Propiedades:**
> ```
> - Dom(|f|) = Dom(f)
> - Im(|f|) = [0, ∞) si Im(f) ∩ ℝ⁻ ≠ ∅
> - Im(|f|) = Im(f) si Im(f) ⊆ [0, ∞)
> - |f| es par si f es par
> ```

### Funciones Definidas con Valor Absoluto

> [!example]- Ejemplos Comunes
> 
> **Función distancia a un punto:**
> ```
> d(x) = |x - a|
> 
> Mide distancia de x al punto fijo a
> Mínimo en x = a donde d(a) = 0
> ```
> 
> **Función "V":**
> ```
> f(x) = |x - a| + |x - b|  con a < b
> 
> Suma de distancias a dos puntos
> Mínimo cuando a ≤ x ≤ b (constante = b - a)
> ```
> 
> **Función norma L¹:**
> ```
> ‖x‖₁ = |x₁| + |x₂| + ... + |xₙ|
> 
> Generalización a ℝⁿ (suma de valores absolutos)
> ```
> 
> **Función signo:**
> ```
> sgn(x) = { 1   si x > 0
>          { 0   si x = 0
>          {-1   si x < 0
> 
> Relación: sgn(x) = x/|x| para x ≠ 0
> ```

## 🎓 Ejercicios Resueltos Completos

> [!example]- Problemas Desafiantes
> 
> **Ejercicio 1: Ecuación con parámetro**
> ```
> Resuelve |x - 3| = 2a sabiendo que tiene exactamente una solución.
> 
> Solución:
> |x - 3| = 2a tiene dos soluciones si 2a > 0:
> x - 3 = 2a  →  x = 3 + 2a
> x - 3 = -2a →  x = 3 - 2a
> 
> Para una única solución: 2a = 0  →  a = 0
> 
> Entonces: |x - 3| = 0  →  x = 3
> 
> Respuesta: a = 0, solución x = 3
> ```
> 
> **Ejercicio 2: Sistema con valor absoluto**
> ```
> Resuelve el sistema:
> |x| + |y| = 4
> x + y = 2
> 
> Solución:
> De la segunda ecuación: y = 2 - x
> 
> Sustituyendo en la primera:
> |x| + |2 - x| = 4
> 
> Análisis por casos:
> 
> Caso 1: x ≥ 2  (entonces 2 - x ≤ 0)
> x + (-(2 - x)) = 4
> x - 2 + x = 4
> 2x = 6
> x = 3  ✓ (cumple x ≥ 2)
> y = 2 - 3 = -1
> 
> Caso 2: 0 ≤ x < 2  (entonces 2 - x > 0)
> x + (2 - x) = 4
> 2 = 4  (imposible)
> 
> Caso 3: x < 0  (entonces 2 - x > 0)
> -x + (2 - x) = 4
> 2 - 2x = 4
> -2x = 2
> x = -1  ✓ (cumple x < 0)
> y = 2 - (-1) = 3
> 
> Soluciones: (3, -1) y (-1, 3)
> 
> Verificación:
> |3| + |-1| = 3 + 1 = 4  ✓,  3 + (-1) = 2  ✓
> |-1| + |3| = 1 + 3 = 4  ✓,  -1 + 3 = 2  ✓
> ```
> 
> **Ejercicio 3: Desigualdad con dos valores absolutos**
> ```
> Resuelve |x + 1| > 2|x - 2|
> 
> Solución (método: elevar al cuadrado):
> (x + 1)² > 4(x - 2)²
> x² + 2x + 1 > 4(x² - 4x + 4)
> x² + 2x + 1 > 4x² - 16x + 16
> 0 > 3x² - 18x + 15
> 0 > 3(x² - 6x + 5)
> 0 > 3(x - 1)(x - 5)
> 
> Para que el producto sea negativo:
> (x - 1) y (x - 5) tienen signos opuestos
> 
> Esto ocurre cuando: 1 < x < 5
> 
> Solución: (1, 5)
> 
> Verificación en puntos:
> x = 3: |3+1| = 4,  2|3-2| = 2  →  4 > 2  ✓
> x = 0: |0+1| = 1,  2|0-2| = 4  →  1 > 4  ✗
> x = 6: |6+1| = 7,  2|6-2| = 8  →  7 > 8  ✗
> ```
> 
> **Ejercicio 4: Optimización**
> ```
> Encuentra el valor de x que minimiza f(x) = |x - 2| + |x - 5| + |x - 9|
> 
> Solución:
> Esta función suma las distancias de x a tres puntos: 2, 5, 9
> 
> Propiedad: La suma de distancias se minimiza en la MEDIANA
> 
> Mediana de {2, 5, 9} = 5
> 
> Valor mínimo: f(5) = |5-2| + |5-5| + |5-9|
>                    = 3 + 0 + 4 = 7
> 
> Respuesta: x = 5 minimiza la función, con valor mínimo 7
> 
> Nota: Para verificar, evaluar en otros puntos:
> f(2) = 0 + 3 + 7 = 10
> f(9) = 7 + 4 + 0 = 11
> f(5) = 7 < 10, 11  ✓
> ```
