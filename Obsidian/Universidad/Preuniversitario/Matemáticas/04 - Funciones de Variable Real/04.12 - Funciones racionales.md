# 🔢 Funciones Racionales

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Una función racional es el cociente de dos polinomios. Representa la razón o proporción entre dos cantidades polinomiales. Son las funciones que aparecen naturalmente cuando dividimos una cantidad que varía polinomialmente entre otra.**
> 
> **Elementos clave:**
> 
> - **Forma:** Cociente de polinomios $\frac{P(x)}{Q(x)}$
> - **Restricción fundamental:** Denominador nunca puede ser cero
> - **Asíntotas:** Comportamiento característico cerca de valores prohibidos
> - **Discontinuidades:** Puntos donde la función no está definida
> - **Rango:** Generalmente más complejo que polinomios
> - **Simplificación:** Puede revelar u ocultar comportamiento

## 📝 Definición Formal

> [!success]- Definición Matemática Rigurosa
> 
> **Definición:** Una **función racional** es una función de la forma:
> 
> $$f(x) = \frac{P(x)}{Q(x)}$$
> 
> donde:
> 
> - $P(x)$ y $Q(x)$ son polinomios
> - $Q(x) \not\equiv 0$ (el denominador no es el polinomio cero)
> - $x \in \mathbb{R}$ (variable independiente)
> 
> **Notación extendida:** $$f(x) = \frac{a_nx^n + a_{n-1}x^{n-1} + \cdots + a_1x + a_0}{b_mx^m + b_{m-1}x^{m-1} + \cdots + b_1x + b_0}$$
> 
> con $b_m \neq 0$ (grado del denominador es $m$)
> 
> **Terminología:**
> 
> - **Numerador:** $P(x)$ (polinomio superior)
> - **Denominador:** $Q(x)$ (polinomio inferior)
> - **Grado del numerador:** $\deg(P) = n$
> - **Grado del denominador:** $\deg(Q) = m$
> - **Función racional propia:** Si $n < m$
> - **Función racional impropia:** Si $n \geq m$
> - **Forma reducida:** Cuando $\gcd(P, Q) = 1$ (sin factores comunes)

> [!warning]- Forma Reducida vs No Reducida
> 
> **Importancia de la simplificación:**
> 
> Una función racional puede no estar en forma reducida: $$f(x) = \frac{x^2 - 4}{x - 2} = \frac{(x-2)(x+2)}{x-2}$$
> 
> **Simplificación:** $$f(x) = x + 2, \quad x \neq 2$$
> 
> **CRÍTICO:** Aunque algebraicamente $f(x) = x + 2$, el dominio NO incluye $x = 2$
> 
> $$\text{Dom}(f) = \mathbb{R} \setminus {2}$$
> 
> **Discontinuidad removible:** La función tiene un "hueco" en $x = 2$
> 
> **Regla general:**
> 
> - Factores comunes en numerador y denominador → discontinuidades removibles
> - Factores solo en denominador → asíntotas verticales

## 🎯 Dominio de Funciones Racionales

> [!success]- Conjunto de Valores Permitidos
> 
> **Regla fundamental:** El dominio de $f(x) = \frac{P(x)}{Q(x)}$ es:
> 
> $$\text{Dom}(f) = {x \in \mathbb{R} : Q(x) \neq 0}$$
> 
> **Procedimiento para encontrar el dominio:**
> 
> 1. **Encontrar ceros del denominador:** Resolver $Q(x) = 0$
>     
> 2. **Excluir esos valores:** $$\text{Dom}(f) = \mathbb{R} \setminus {\text{raíces de } Q(x)}$$
>     
> 3. **Expresar como intervalos:** Unión de intervalos entre las raíces
>     
> 
> **Ejemplos:**
> 
> **Ejemplo 1:** $f(x) = \frac{1}{x}$
> 
> ```
> Denominador: x = 0
> Dom(f) = ℝ \ {0} = (-∞, 0) ∪ (0, +∞)
> ```
> 
> **Ejemplo 2:** $f(x) = \frac{x+1}{x^2 - 5x + 6}$
> 
> ```
> Denominador: x² - 5x + 6 = (x-2)(x-3) = 0
> Raíces: x = 2, x = 3
> Dom(f) = ℝ \ {2, 3} = (-∞, 2) ∪ (2, 3) ∪ (3, +∞)
> ```
> 
> **Ejemplo 3:** $f(x) = \frac{x^2 + 1}{x^2 + 4}$
> 
> ```
> Denominador: x² + 4 = 0
> x² = -4 (sin solución real)
> Dom(f) = ℝ (todo ℝ)
> 
> Nota: Esta función racional NO tiene asíntotas verticales
> ```
> 
> **Ejemplo 4:** $f(x) = \frac{x^2 - 9}{x^2 - 9}$
> 
> ```
> Simplificando: f(x) = 1 para x ≠ ±3
> 
> ✗ INCORRECTO: Dom(f) = ℝ
> ✓ CORRECTO: Dom(f) = ℝ \ {-3, 3}
> 
> Discontinuidades removibles en x = ±3
> ```

## 📐 Asíntotas

> [!important]- Concepto de Asíntota
> 
> **Definición:** Una **asíntota** es una recta que la gráfica de la función se aproxima arbitrariamente cuando $x$ o $f(x)$ tienden a infinito.
> 
> **Tipos de asíntotas:**
> 
> 1. **Asíntotas verticales:** $x = a$ (dominio discontinuo)
> 2. **Asíntotas horizontales:** $y = b$ (comportamiento en $\pm\infty$)
> 3. **Asíntotas oblicuas:** $y = mx + b$ (crecimiento lineal)

### Asíntotas Verticales

> [!tip]- Cómo Encontrar Asíntotas Verticales
> 
> **Definición:** La recta $x = a$ es una **asíntota vertical** si: $$\lim_{x \to a^-} f(x) = \pm\infty \quad \text{o} \quad \lim_{x \to a^+} f(x) = \pm\infty$$
> 
> **Procedimiento:**
> 
> 1. **Simplificar la función racional** (forma reducida)
> 2. **Encontrar raíces del denominador** que NO sean raíces del numerador
> 3. **Cada raíz restante** → asíntota vertical
> 
> **Regla práctica:** Para $f(x) = \frac{P(x)}{Q(x)}$ en forma reducida:
> 
> - Si $Q(a) = 0$ y $P(a) \neq 0$ → $x = a$ es asíntota vertical
> 
> **Ejemplos:**
> 
> **Ejemplo 1:** $f(x) = \frac{1}{x-3}$
> 
> ```
> Denominador: x - 3 = 0 → x = 3
> Numerador en x = 3: 1 ≠ 0
> 
> Asíntota vertical: x = 3
> 
> Comportamiento:
> lim(x→3⁻) f(x) = -∞
> lim(x→3⁺) f(x) = +∞
> ```
> 
> **Ejemplo 2:** $f(x) = \frac{x+1}{(x-2)(x+3)}$
> 
> ```
> Denominador: (x-2)(x+3) = 0
> Raíces: x = 2, x = -3
> Numerador: P(2) = 3 ≠ 0, P(-3) = -2 ≠ 0
> 
> Asíntotas verticales: x = 2 y x = -3
> ```
> 
> **Ejemplo 3:** $f(x) = \frac{x^2-4}{x-2} = \frac{(x-2)(x+2)}{x-2}$
> 
> ```
> Simplificando: f(x) = x + 2, x ≠ 2
> 
> ¡NO hay asíntota vertical!
> Discontinuidad removible en x = 2
> (hueco en la gráfica)
> ```
> 
> **Ejemplo 4:** $f(x) = \frac{2x}{x^2 + 1}$
> 
> ```
> Denominador: x² + 1 = 0
> Sin raíces reales
> 
> ¡NO hay asíntotas verticales!
> Dom(f) = ℝ
> ```

### Asíntotas Horizontales

> [!tip]- Cómo Encontrar Asíntotas Horizontales
> 
> **Definición:** La recta $y = L$ es una **asíntota horizontal** si: $$\lim_{x \to +\infty} f(x) = L \quad \text{o} \quad \lim_{x \to -\infty} f(x) = L$$
> 
> **Regla de los grados:** Para $f(x) = \frac{P(x)}{Q(x)} = \frac{a_nx^n + \cdots}{b_mx^m + \cdots}$
> 
> **Caso 1: $n < m$ (grado numerador < grado denominador)** $$\lim_{x \to \pm\infty} f(x) = 0$$ **Asíntota horizontal:** $y = 0$ (eje $x$)
> 
> **Caso 2: $n = m$ (grados iguales)** $$\lim_{x \to \pm\infty} f(x) = \frac{a_n}{b_m}$$ **Asíntota horizontal:** $y = \frac{a_n}{b_m}$ (cociente de coeficientes principales)
> 
> **Caso 3: $n > m$ (grado numerador > grado denominador)** $$\lim_{x \to \pm\infty} f(x) = \pm\infty$$ **NO hay asíntota horizontal** (posible asíntota oblicua)
> 
> **Ejemplos:**
> 
> **Ejemplo 1:** $f(x) = \frac{3x^2 + 5}{x^3 - 2}$
> 
> ```
> n = 2, m = 3
> n < m → y = 0
> 
> Asíntota horizontal: y = 0
> ```
> 
> **Ejemplo 2:** $f(x) = \frac{4x^2 - 3x + 1}{2x^2 + 7}$
> 
> ```
> n = 2, m = 2
> n = m → y = 4/2 = 2
> 
> Asíntota horizontal: y = 2
> ```
> 
> **Ejemplo 3:** $f(x) = \frac{5x^3 + 2x}{x^2 - 1}$
> 
> ```
> n = 3, m = 2
> n > m → No hay asíntota horizontal
> 
> (buscar asíntota oblicua)
> ```
> 
> **Ejemplo 4:** $f(x) = \frac{-2x^2 + 3x}{3x^2 - x + 5}$
> 
> ```
> n = 2, m = 2
> y = -2/3
> 
> Asíntota horizontal: y = -2/3
> ```

### Asíntotas Oblicuas

> [!tip]- Cómo Encontrar Asíntotas Oblicuas
> 
> **Definición:** La recta $y = mx + b$ (con $m \neq 0$) es una **asíntota oblicua** si: $$\lim_{x \to \pm\infty} [f(x) - (mx + b)] = 0$$
> 
> **Condición necesaria:** Solo puede existir si $\deg(P) = \deg(Q) + 1$
> 
> Es decir, grado numerador = grado denominador + 1
> 
> **Procedimiento:**
> 
> 1. **Dividir** $P(x)$ entre $Q(x)$ (división polinomial) $$\frac{P(x)}{Q(x)} = mx + b + \frac{R(x)}{Q(x)}$$ donde $\deg(R) < \deg(Q)$
>     
> 2. **Identificar cociente:** $y = mx + b$
>     
> 3. **Verificar:** $\lim_{x \to \pm\infty} \frac{R(x)}{Q(x)} = 0$
>     
> 
> **Fórmula directa:** $$m = \lim_{x \to \infty} \frac{f(x)}{x}$$ $$b = \lim_{x \to \infty} [f(x) - mx]$$
> 
> **Ejemplos:**
> 
> **Ejemplo 1:** $f(x) = \frac{x^2 + 3x - 2}{x - 1}$
> 
> ```
> División:
>      x² + 3x - 2
>      ─────────── = x + 4 + 2/(x-1)
>        x - 1
> 
> Cociente: y = x + 4
> Residuo: 2/(x-1) → 0 cuando x → ±∞
> 
> Asíntota oblicua: y = x + 4
> ```
> 
> **Ejemplo 2:** $f(x) = \frac{2x^3 - x + 5}{x^2 + 1}$
> 
> ```
> División:
> 2x³ - x + 5   
> ───────────  = 2x + (-3x+5)/(x²+1)
>    x² + 1
> 
> Asíntota oblicua: y = 2x
> ```
> 
> **Ejemplo 3:** $f(x) = \frac{x^3}{x^2 - 4}$
> 
> ```
> n = 3, m = 2
> n = m + 1 ✓
> 
> División:
> x³/(x²-4) = x + 4x/(x²-4)
> 
> Asíntota oblicua: y = x
> ```
> 
> **Observación importante:**
> 
> - Una función NO puede tener asíntota horizontal Y oblicua simultáneamente
> - Pero puede tener asíntota horizontal en una dirección y oblicua en otra (raro)

## 📊 Análisis de Comportamiento

> [!note]- Comportamiento cerca de Asíntotas Verticales
> 
> Para determinar el comportamiento cerca de una asíntota vertical $x = a$:
> 
> **Método de signos:**
> 
> 1. **Evaluar el signo** de $P(a)$ (numerador)
> 2. **Analizar el signo** de $Q(x)$ a la izquierda y derecha de $a$
> 3. **Determinar el signo** de $\frac{P(x)}{Q(x)}$ en cada lado
> 
> **Tabla de análisis:**
> 
> |$P(a)$|$Q(x)$ cerca de $a^-$|$Q(x)$ cerca de $a^+$|Comportamiento|
> |---|---|---|---|
> |$+$|$-$|$+$|$-\infty$ a $+\infty$|
> |$+$|$+$|$-$|$+\infty$ a $-\infty$|
> |$-$|$-$|$+$|$+\infty$ a $-\infty$|
> |$-$|$+$|$-$|$-\infty$ a $+\infty$|
> 
> **Ejemplo detallado:** $f(x) = \frac{x+1}{x-2}$
> 
> ```
> Asíntota vertical: x = 2
> P(2) = 3 > 0 (positivo)
> 
> Q(x) = x - 2:
> - Para x < 2: Q(x) < 0 (negativo)
> - Para x > 2: Q(x) > 0 (positivo)
> 
> Por tanto:
> - x → 2⁻: f(x) → -∞ (positivo/negativo)
> - x → 2⁺: f(x) → +∞ (positivo/positivo)
> ```

> [!note]- Intersecciones y Puntos Especiales
> 
> **Intersección con eje $y$:** (si $x = 0$ está en el dominio) $$y = f(0) = \frac{P(0)}{Q(0)}$$
> 
> **Intersecciones con eje $x$:** (raíces del numerador) Resolver $P(x) = 0$ y verificar que $Q(x) \neq 0$
> 
> **Ejemplo:** $f(x) = \frac{x^2 - 4}{x + 1}$
> 
> ```
> Intersección con eje y:
> f(0) = (-4)/1 = -4
> Punto: (0, -4)
> 
> Intersecciones con eje x:
> x² - 4 = 0
> x = ±2
> 
> Verificar denominador:
> Q(-2) = -1 ≠ 0 ✓
> Q(2) = 3 ≠ 0 ✓
> 
> Puntos: (-2, 0) y (2, 0)
> ```

## 🎨 Gráficas de Funciones Racionales

> [!tip]- Procedimiento para Graficar
> 
> **Pasos sistemáticos:**
> 
> **1. Simplificar** (si es posible)
> 
> - Factorizar numerador y denominador
> - Cancelar factores comunes
> - Identificar discontinuidades removibles
> 
> **2. Encontrar dominio**
> 
> - Raíces del denominador (en forma reducida)
> - Expresar como intervalos
> 
> **3. Identificar asíntotas**
> 
> - **Verticales:** raíces del denominador
> - **Horizontales:** comparar grados
> - **Oblicuas:** si $n = m + 1$
> 
> **4. Encontrar intersecciones**
> 
> - Con eje $y$: $f(0)$
> - Con eje $x$: resolver $P(x) = 0$
> 
> **5. Analizar comportamiento cerca de asíntotas**
> 
> - Método de signos para asíntotas verticales
> - Verificar posición respecto a asíntotas horizontales/oblicuas
> 
> **6. Puntos adicionales** (si es necesario)
> 
> - Evaluar en valores estratégicos
> - Uno o dos puntos por cada región del dominio
> 
> **7. Derivada** (opcional, para análisis detallado)
> 
> - Encontrar extremos locales
> - Determinar crecimiento/decrecimiento
> 
> **8. Trazar la gráfica**
> 
> - Dibujar asíntotas (líneas punteadas)
> - Marcar intersecciones y discontinuidades
> - Conectar suavemente respetando asíntotas

> [!example]- Ejemplo Completo de Graficación
> 
> **Función:** $f(x) = \frac{x^2 - 1}{x^2 - 4}$
> 
> **Paso 1: Simplificar** $$f(x) = \frac{(x-1)(x+1)}{(x-2)(x+2)}$$ No se puede simplificar más (sin factores comunes)
> 
> **Paso 2: Dominio** $$x^2 - 4 = 0 \implies x = \pm 2$$ $$\text{Dom}(f) = \mathbb{R} \setminus {-2, 2} = (-\infty, -2) \cup (-2, 2) \cup (2, +\infty)$$
> 
> **Paso 3: Asíntotas**
> 
> _Verticales:_
> 
> - $x = -2$ (raíz del denominador, no del numerador)
> - $x = 2$ (raíz del denominador, no del numerador)
> 
> _Horizontal:_
> 
> - $n = 2, m = 2$ (grados iguales)
> - $y = \frac{1}{1} = 1$
> 
> **Paso 4: Intersecciones**
> 
> _Con eje $y$:_ $$f(0) = \frac{-1}{-4} = \frac{1}{4}$$ Punto: $(0, 1/4)$
> 
> _Con eje $x$:_ $$x^2 - 1 = 0 \implies x = \pm 1$$ Verificar: $Q(-1) = -3 \neq 0$ ✓, $Q(1) = -3 \neq 0$ ✓ Puntos: $(-1, 0)$ y $(1, 0)$
> 
> **Paso 5: Comportamiento cerca de asíntotas verticales**
> 
> _Cerca de $x = -2$:_
> 
> ```
> P(-2) = 3 > 0
> Q(x) = (x-2)(x+2):
> - x → -2⁻: (neg)(neg) = pos
> - x → -2⁺: (neg)(pos) = neg
> 
> Por tanto:
> - x → -2⁻: f(x) → +∞
> - x → -2⁺: f(x) → -∞
> ```
> 
> _Cerca de $x = 2$:_
> 
> ```
> P(2) = 3 > 0
> Q(x):
> - x → 2⁻: (neg)(pos) = neg
> - x → 2⁺: (pos)(pos) = pos
> 
> Por tanto:
> - x → 2⁻: f(x) → -∞
> - x → 2⁺: f(x) → +∞
> ```
> 
> _Posición respecto a $y = 1$:_ $$f(x) - 1 = \frac{x^2-1}{x^2-4} - 1 = \frac{x^2-1-(x^2-4)}{x^2-4} = \frac{3}{x^2-4}$$
> 
> - Para $|x| < 2$: $x^2 - 4 < 0 \implies f(x) < 1$ (debajo de asíntota)
> - Para $|x| > 2$: $x^2 - 4 > 0 \implies f(x) > 1$ (encima de asíntota)
> 
> **Paso 6: Puntos adicionales**
> 
> ```
> f(-3) = 8/5 = 1.6
> f(-1.5) ≈ -1.0
> f(0.5) ≈ 0.2
> f(1.5) ≈ -0.6
> f(3) = 8/5 = 1.6
> ```
> 
> **Paso 7: Características de la gráfica**
> 
> - Función par: $f(-x) = f(x)$ (simétrica respecto al eje $y$)
> - Asíntotas verticales en $x = \pm 2$
> - Asíntota horizontal en $y = 1$
> - Cruza eje $x$ en $x = \pm 1$
> - Cruza eje $y$ en $(0, 1/4)$
> - Por debajo de $y = 1$ en $(-2, 2)$
> - Por encima de $y = 1$ en $(-\infty, -2) \cup (2, +\infty)$

## 🔧 Operaciones con Funciones Racionales

> [!note]- Álgebra de Funciones Racionales
> 
> **Suma y resta:** $$\frac{P_1(x)}{Q_1(x)} \pm \frac{P_2(x)}{Q_2(x)} = \frac{P_1(x)Q_2(x) \pm P_2(x)Q_1(x)}{Q_1(x)Q_2(x)}$$
> 
> **Ejemplo:** $$\frac{2}{x-1} + \frac{3}{x+2} = \frac{2(x+2) + 3(x-1)}{(x-1)(x+2)} = \frac{5x+1}{x^2+x-2}$$
> 
> **Producto:** $$\frac{P_1(x)}{Q_1(x)} \cdot \frac{P_2(x)}{Q_2(x)} = \frac{P_1(x)P_2(x)}{Q_1(x)Q_2(x)}$$
> 
> **Ejemplo:** $$\frac{x+1}{x-2} \cdot \frac{x-3}{x+1} = \frac{(x+1)(x-3)}{(x-2)(x+1)} = \frac{x-3}{x-2}, \quad x \neq -1$$
> 
>
> 
> **División:** $$\frac{P_1(x)}{Q_1(x)} \div \frac{P_2(x)}{Q_2(x)} = \frac{P_1(x)}{Q_1(x)} \cdot \frac{Q_2(x)}{P_2(x)} = \frac{P_1(x)Q_2(x)}{Q_1(x)P_2(x)}$$
> 
> **Ejemplo:** $$\frac{x^2-4}{x+1} \div \frac{x+2}{x-3} = \frac{x^2-4}{x+1} \cdot \frac{x-3}{x+2} = \frac{(x-2)(x+2)(x-3)}{(x+1)(x+2)} = \frac{(x-2)(x-3)}{x+1}, \quad x \neq -2$$
> 
> **Composición:** $$(f \circ g)(x) = f(g(x)) = \frac{P(g(x))}{Q(g(x))}$$
> 
> Generalmente resulta en una función racional más compleja
> 
> **Ejemplo:** $$f(x) = \frac{1}{x}, \quad g(x) = \frac{x+1}{x-1}$$ $$(f \circ g)(x) = f\left(\frac{x+1}{x-1}\right) = \frac{1}{\frac{x+1}{x-1}} = \frac{x-1}{x+1}$$
> 
> **Simplificación (MCD):** Para simplificar $\frac{P(x)}{Q(x)}$:
> 
> 1. Factorizar completamente $P(x)$ y $Q(x)$
> 2. Cancelar factores comunes
> 3. Anotar restricciones de dominio
> 
> **Ejemplo:** $$f(x) = \frac{x^3 - x}{x^2 + 2x - 3} = \frac{x(x^2-1)}{(x+3)(x-1)} = \frac{x(x-1)(x+1)}{(x+3)(x-1)} = \frac{x(x+1)}{x+3}, \quad x \neq 1$$

## 🧮 Descomposición en Fracciones Parciales

> [!important]- Técnica Fundamental de Integración
> 
> **Objetivo:** Expresar una función racional como suma de fracciones más simples
> 
> **Utilidad:**
> 
> - Facilita la integración
> - Simplifica transformadas de Laplace
> - Aplicaciones en ecuaciones diferenciales
> - Análisis de sistemas de control
> 
> **Requisito previo:** La función debe ser **propia** ($\deg(P) < \deg(Q)$)
> 
> Si es impropia, primero dividir: $$\frac{P(x)}{Q(x)} = \text{Cociente} + \frac{\text{Residuo}}{Q(x)}$$

> [!tip]- Casos de Descomposición
> 
> **Caso 1: Factores lineales distintos**
> 
> Si $Q(x) = (x-a_1)(x-a_2)\cdots(x-a_n)$ con $a_i$ distintos:
> 
> $$\frac{P(x)}{Q(x)} = \frac{A_1}{x-a_1} + \frac{A_2}{x-a_2} + \cdots + \frac{A_n}{x-a_n}$$
> 
> **Ejemplo:** $$\frac{5x-1}{(x-1)(x+2)} = \frac{A}{x-1} + \frac{B}{x+2}$$
> 
> Multiplicar por $(x-1)(x+2)$: $$5x - 1 = A(x+2) + B(x-1)$$
> 
> **Método 1: Sustitución**
> 
> - $x = 1$: $4 = 3A \implies A = \frac{4}{3}$
> - $x = -2$: $-11 = -3B \implies B = \frac{11}{3}$
> 
> **Resultado:** $$\frac{5x-1}{(x-1)(x+2)} = \frac{4/3}{x-1} + \frac{11/3}{x+2}$$
> 
> **Método 2: Coeficientes indeterminados** $$5x - 1 = A(x+2) + B(x-1) = (A+B)x + (2A-B)$$
> 
> Sistema: $$\begin{cases} A + B = 5 \ 2A - B = -1 \end{cases}$$
> 
> Solución: $A = \frac{4}{3}, B = \frac{11}{3}$
> 
> ---
> 
> **Caso 2: Factor lineal repetido**
> 
> Si $Q(x)$ contiene $(x-a)^m$:
> 
> $$\frac{P(x)}{Q(x)} = \frac{A_1}{x-a} + \frac{A_2}{(x-a)^2} + \cdots + \frac{A_m}{(x-a)^m} + \text{(otros términos)}$$
> 
> **Ejemplo:** $$\frac{2x+5}{(x-1)^3} = \frac{A}{x-1} + \frac{B}{(x-1)^2} + \frac{C}{(x-1)^3}$$
> 
> Multiplicar por $(x-1)^3$: $$2x + 5 = A(x-1)^2 + B(x-1) + C$$
> 
> **Método de sustitución y derivación:**
> 
> - $x = 1$: $7 = C$
> - Derivar: $2 = 2A(x-1) + B$
> - En $x = 1$: $2 = B$
> - Derivar otra vez: $0 = 2A \implies A = 0$
> 
> **Resultado:** $$\frac{2x+5}{(x-1)^3} = \frac{2}{(x-1)^2} + \frac{7}{(x-1)^3}$$
> 
> ---
> 
> **Caso 3: Factores cuadráticos irreducibles distintos**
> 
> Si $Q(x)$ contiene $ax^2 + bx + c$ (sin raíces reales):
> 
> $$\frac{P(x)}{Q(x)} = \cdots + \frac{Ax + B}{ax^2 + bx + c} + \cdots$$
> 
> **Ejemplo:** $$\frac{3x^2 + 2x + 1}{(x-1)(x^2+1)} = \frac{A}{x-1} + \frac{Bx + C}{x^2+1}$$
> 
> Multiplicar por $(x-1)(x^2+1)$: $$3x^2 + 2x + 1 = A(x^2+1) + (Bx+C)(x-1)$$
> 
> - $x = 1$: $6 = 2A \implies A = 3$
> 
> Expandir lado derecho: $$3x^2 + 2x + 1 = Ax^2 + A + Bx^2 - Bx + Cx - C$$ $$= (A+B)x^2 + (-B+C)x + (A-C)$$
> 
> Sistema: $$\begin{cases} A + B = 3 \ -B + C = 2 \ A - C = 1 \end{cases}$$
> 
> Con $A = 3$: $B = 0, C = 2$
> 
> **Resultado:** $$\frac{3x^2 + 2x + 1}{(x-1)(x^2+1)} = \frac{3}{x-1} + \frac{2}{x^2+1}$$
> 
> ---
> 
> **Caso 4: Factor cuadrático repetido**
> 
> Si $Q(x)$ contiene $(ax^2 + bx + c)^m$:
> 
> $$\frac{P(x)}{Q(x)} = \cdots + \frac{A_1x + B_1}{ax^2+bx+c} + \frac{A_2x + B_2}{(ax^2+bx+c)^2} + \cdots$$

> [!example]- Ejemplo Completo de Descomposición
> 
> **Problema:** Descomponer en fracciones parciales: $$f(x) = \frac{x^3 + 2x + 1}{x^3 - x}$$
> 
> **Paso 1: Verificar si es propia** $\deg(P) = 3, \deg(Q) = 3$ → NO es propia
> 
> Dividir: $$\frac{x^3 + 2x + 1}{x^3 - x} = 1 + \frac{3x + 1}{x^3 - x}$$
> 
> **Paso 2: Factorizar denominador** $$x^3 - x = x(x^2 - 1) = x(x-1)(x+1)$$
> 
> **Paso 3: Plantear descomposición** $$\frac{3x + 1}{x(x-1)(x+1)} = \frac{A}{x} + \frac{B}{x-1} + \frac{C}{x+1}$$
> 
> **Paso 4: Resolver** Multiplicar por $x(x-1)(x+1)$: $$3x + 1 = A(x-1)(x+1) + Bx(x+1) + Cx(x-1)$$
> 
> - $x = 0$: $1 = -A \implies A = -1$
> - $x = 1$: $4 = 2B \implies B = 2$
> - $x = -1$: $-2 = 2C \implies C = -1$
> 
> **Paso 5: Resultado final** $$f(x) = 1 - \frac{1}{x} + \frac{2}{x-1} - \frac{1}{x+1}$$
> 
> **Verificación:** $$1 - \frac{1}{x} + \frac{2}{x-1} - \frac{1}{x+1} = 1 + \frac{-(x-1)(x+1) + 2x(x+1) - x(x-1)}{x(x-1)(x+1)}$$ $$= 1 + \frac{-(x^2-1) + 2x^2 + 2x - x^2 + x}{x^3-x} = 1 + \frac{3x+1}{x^3-x}$$ ✓

## 📈 Análisis Avanzado con Derivadas

> [!tip]- Extremos y Concavidad
> 
> **Primera derivada:**
> 
> Para $f(x) = \frac{P(x)}{Q(x)}$, usar la regla del cociente:
> 
> $$f'(x) = \frac{P'(x)Q(x) - P(x)Q'(x)}{[Q(x)]^2}$$
> 
> **Puntos críticos:** Resolver $f'(x) = 0$ $$P'(x)Q(x) - P(x)Q'(x) = 0$$
> 
> **Segunda derivada:** $$f''(x) = \frac{d}{dx}\left[\frac{P'Q - PQ'}{Q^2}\right]$$
> 
> (más compleja, usar regla del cociente nuevamente)
> 
> **Criterio de la segunda derivada:**
> 
> - $f'(c) = 0$ y $f''(c) > 0$ → mínimo local en $x = c$
> - $f'(c) = 0$ y $f''(c) < 0$ → máximo local en $x = c$
> - $f'(c) = 0$ y $f''(c) = 0$ → test inconclusivo

> [!example]- Ejemplo: Análisis Completo
> 
> **Función:** $f(x) = \frac{x^2}{x^2 - 4}$
> 
> **Dominio:** $$x^2 - 4 \neq 0 \implies x \neq \pm 2$$ $$\text{Dom}(f) = (-\infty, -2) \cup (-2, 2) \cup (2, +\infty)$$
> 
> **Asíntotas:**
> 
> - Verticales: $x = -2, x = 2$
> - Horizontal: $y = 1$ (grados iguales, $\frac{1}{1} = 1$)
> 
> **Primera derivada:** $$f'(x) = \frac{2x(x^2-4) - x^2(2x)}{(x^2-4)^2} = \frac{2x^3 - 8x - 2x^3}{(x^2-4)^2} = \frac{-8x}{(x^2-4)^2}$$
> 
> **Punto crítico:** $$-8x = 0 \implies x = 0$$
> 
> **Análisis de monotonía:**
> 
> - $x < 0$: $f'(x) > 0$ → creciente
> - $x > 0$: $f'(x) < 0$ → decreciente
> 
> **Extremo:**
> 
> - Máximo local en $x = 0$: $f(0) = 0$
> 
> **Segunda derivada (para concavidad):** $$f''(x) = \frac{-8(x^2-4)^2 - (-8x) \cdot 2(x^2-4)(2x)}{(x^2-4)^4}$$ $$= \frac{-8(x^2-4) + 32x^2}{(x^2-4)^3} = \frac{24x^2 + 32}{(x^2-4)^3}$$
> 
> **Análisis de concavidad:** El numerador $24x^2 + 32 > 0$ siempre
> 
> El signo depende del denominador:
> 
> - $|x| < 2$: $(x^2-4)^3 < 0 \implies f''(x) < 0$ → cóncava hacia abajo
> - $|x| > 2$: $(x^2-4)^3 > 0 \implies f''(x) > 0$ → cóncava hacia arriba
> 
> **Intersecciones:**
> 
> - Con eje $y$: $f(0) = 0$
> - Con eje $x$: $x^2 = 0 \implies x = 0$
> 
> **Simetría:** $$f(-x) = \frac{(-x)^2}{(-x)^2-4} = \frac{x^2}{x^2-4} = f(x)$$ Función par → simétrica respecto al eje $y$
> 
> **Comportamiento cerca de asíntotas:**
> 
> Cerca de $x = 2$:
> 
> - $x \to 2^-$: $f(x) \to -\infty$ (numerador positivo, denominador negativo pequeño)
> - $x \to 2^+$: $f(x) \to +\infty$ (numerador positivo, denominador positivo pequeño)
> 
> Cerca de $x = -2$ (por simetría):
> 
> - $x \to -2^-$: $f(x) \to +\infty$
> - $x \to -2^+$: $f(x) \to -\infty$

## 🎯 Aplicaciones de Funciones Racionales

> [!example]- Aplicaciones en Ciencias e Ingeniería
> 
> **1. Física - Ley de Ohm generalizada:**
> 
> Impedancia en circuitos AC: $$Z(f) = R + \frac{1}{j\omega C}$$
> 
> donde $\omega = 2\pi f$ es la frecuencia angular
> 
> **2. Química - Cinética enzimática (Ecuación de Michaelis-Menten):**
> 
> Velocidad de reacción: $$v = \frac{V_{\max}[S]}{K_m + [S]}$$
> 
> donde:
> 
> - $v$ = velocidad de reacción
> - $[S]$ = concentración de sustrato
> - $V_{\max}$ = velocidad máxima
> - $K_m$ = constante de Michaelis
> 
> **Análisis:**
> 
> - Asíntota horizontal: $y = V_{\max}$ (saturación)
> - Para $[S] = K_m$: $v = \frac{V_{\max}}{2}$ (significado de $K_m$)
> 
> **3. Economía - Costo promedio:**
> 
> $$\overline{C}(x) = \frac{C(x)}{x} = \frac{C_f + C_v \cdot x}{x} = \frac{C_f}{x} + C_v$$
> 
> donde:
> 
> - $C_f$ = costo fijo
> - $C_v$ = costo variable por unidad
> - $x$ = número de unidades
> 
> **Análisis:**
> 
> - Asíntota vertical: $x = 0$ (no se puede dividir entre cero unidades)
> - Asíntota horizontal: $y = C_v$ (costo variable por unidad)
> - El costo fijo se "diluye" al producir más unidades
> 
> **4. Óptica - Ecuación del fabricante de lentes:**
> 
> $$\frac{1}{f} = (n-1)\left(\frac{1}{R_1} - \frac{1}{R_2}\right)$$
> 
> Relaciona distancia focal con radios de curvatura
> 
> **5. Dinámica poblacional - Efecto Allee:**
> 
> $$\frac{dN}{dt} = rN\left(\frac{N-A}{K}\right)\left(1 - \frac{N}{K}\right)$$
> 
> Función racional en el crecimiento poblacional
> 
> **6. Ingeniería de control - Función de transferencia:**
> 
> $$G(s) = \frac{N(s)}{D(s)} = \frac{b_ms^m + \cdots + b_0}{s^n + a_{n-1}s^{n-1} + \cdots + a_0}$$
> 
> - Polos (raíces de $D(s)$) → estabilidad del sistema
> - Ceros (raíces de $N(s)$) → respuesta en frecuencia
> 
> **7. Electromagnetismo - Resonancia en circuito RLC:**
> 
> $$|Z(\omega)| = \sqrt{R^2 + \left(\omega L - \frac{1}{\omega C}\right)^2}$$
> 
> Mínimo en frecuencia de resonancia: $\omega_0 = \frac{1}{\sqrt{LC}}$

> [!example]- Problema de Optimización
> 
> **Problema:** Una caja rectangular sin tapa debe tener un volumen de 500 cm³. El material de la base cuesta el doble que el de los lados. Encuentra las dimensiones que minimizan el costo.
> 
> **Solución:**
> 
> **Paso 1: Variables**
> 
> - Base cuadrada de lado $x$ cm
> - Altura $h$ cm
> - Volumen: $V = x^2h = 500$
> 
> **Paso 2: Función de costo**
> 
> - Costo base: $2c \cdot x^2$ (área $\times$ doble precio)
> - Costo lados: $c \cdot 4xh$ (4 caras)
> - Costo total: $C = 2cx^2 + 4cxh$
> 
> **Paso 3: Eliminar $h$** $$h = \frac{500}{x^2}$$
> 
> $$C(x) = 2cx^2 + 4cx \cdot \frac{500}{x^2} = 2cx^2 + \frac{2000c}{x}$$
> 
> **Función racional (sin constante $c$):** $$f(x) = 2x^2 + \frac{2000}{x}, \quad x > 0$$
> 
> **Paso 4: Derivada** $$f'(x) = 4x - \frac{2000}{x^2}$$
> 
> **Paso 5: Punto crítico** $$4x - \frac{2000}{x^2} = 0$$ $$4x^3 = 2000$$ $$x^3 = 500$$ $$x = \sqrt[3]{500} \approx 7.94 \text{ cm}$$
> 
> **Paso 6: Verificar que es mínimo** $$f''(x) = 4 + \frac{4000}{x^3}$$ $$f''(\sqrt[3]{500}) = 4 + \frac{4000}{500} = 12 > 0$$ ✓ (mínimo)
> 
> **Paso 7: Dimensiones óptimas** $$x = \sqrt[3]{500} \approx 7.94 \text{ cm}$$ $$h = \frac{500}{(\sqrt[3]{500})^2} = \frac{500}{500^{2/3}} = 500^{1/3} \approx 7.94 \text{ cm}$$
> 
> **Respuesta:** La caja debe ser cúbica con lado $\approx 7.94$ cm

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes
> 
> **1. "Simplificar no afecta el dominio"**
> 
> ```
> ✗ INCORRECTO
> 
> f(x) = (x²-4)/(x-2) = (x+2)(x-2)/(x-2) = x+2
> 
> Error: Concluir Dom(f) = ℝ
> 
> ✓ CORRECTO:
> Dom(f) = ℝ \ {2}
> La simplificación NO elimina la restricción original
> Hay una discontinuidad removible en x = 2
> ```
> 
> **2. "Asíntota horizontal significa que la función nunca la cruza"**
> 
> ```
> ✗ INCORRECTO en general
> 
> Ejemplo: f(x) = x/(x²+1)
> Asíntota horizontal: y = 0
> Pero f(0) = 0 (cruza la asíntota)
> 
> ✓ CORRECTO:
> Asíntota horizontal describe comportamiento cuando x → ±∞
> La función PUEDE cruzar la asíntota en valores finitos de x
> ```
> 
> **3. "Una función racional tiene a lo sumo una asíntota horizontal"**
> 
> ```
> ✗ INCORRECTO en casos especiales
> 
> Algunas funciones pueden tener diferentes asíntotas
> horizontales para x → +∞ y x → -∞
> 
> Ejemplo (poco común): f(x) = (x + |x|)/x²
> - x → +∞: y = 0
> - x → -∞: y = 0
> (mismo en este caso, pero pueden diferir)
> ```
> 
> **4. "Si grados son iguales, hay asíntota en y = 1"**
> 
> ```
> ✗ INCORRECTO
> 
> ✓ CORRECTO:
> Si n = m, asíntota en y = aₙ/bₘ
> (cociente de coeficientes PRINCIPALES)
> 
> Ejemplo: f(x) = (3x² + 5)/(2x² - 1)
> Asíntota: y = 3/2, NO y = 1
> ```
> 
> **5. "Toda discontinuidad es una asíntota vertical"**
> 
> ```
> ✗ INCORRECTO
> 
> Contraejemplo: f(x) = (x²-1)/(x-1) = (x+1)(x-1)/(x-1)
> Simplificando: f(x) = x+1, x ≠ 1
> 
> x = 1 es discontinuidad REMOVIBLE (hueco)
> NO es asíntota vertical
> 
> ✓ CORRECTO:
> Asíntota vertical solo cuando el factor
> del denominador NO se cancela
> ```
> 
> **6. "Funciones racionales no pueden ser acotadas"**
> 
> ```
> ✗ INCORRECTO
> 
> Contraejemplo: f(x) = x²/(x²+1)
> 
> Análisis:
> - Asíntota horizontal: y = 1
> - f(x) = x²/(x²+1) < 1 para todo x
> - f(x) ≥ 0 para todo x
> 
> 0 ≤ f(x) < 1 → ACOTADA
> ```
> 
> **7. "Descomposición en fracciones parciales es única"**
> 
> ```
> ✓ CORRECTO (con matices)
> 
> La descomposición ES única si:
> - La función está en forma reducida
> - Se sigue el procedimiento estándar
> 
> Pero las mismas constantes pueden
> escribirse de diferentes formas equivalentes
> ```

## 🔍 Casos Especiales

> [!note]- Situaciones Particulares
> 
> **1. Función racional constante:** $$f(x) = \frac{c}{d} = \frac{c}{d} \cdot \frac{1}{1}$$
> 
> - Técnicamente es función racional
> - Dominio: $\mathbb{R}$
> - Sin asíntotas
> - Gráfica: línea horizontal
> 
> **2. Polinomio como función racional:** $$f(x) = P(x) = \frac{P(x)}{1}$$
> 
> - Todo polinomio es función racional
> - Denominador constante = 1
> - Sin asíntotas verticales
> 
> **3. Función con discontinuidades removibles:** $$f(x) = \frac{x^2-a^2}{x-a} = \frac{(x-a)(x+a)}{x-a} = x+a, \quad x \neq a$$
> 
> - Hueco en $x = a$
> - Gráfica: línea recta con punto faltante
> - $\lim_{x \to a} f(x)$ existe pero $f(a)$ no
> 
> **4. Función racional sin raíces reales en denominador:** $$f(x) = \frac{P(x)}{x^2+1}$$
> 
> - Dominio: $\mathbb{R}$ (completo)
> - Sin asíntotas verticales
> - Comportamiento suave en todo $\mathbb{R}$
> 
> **5. Funciones pares e impares:**
> 
> - **Par:** $f(-x) = f(x)$ Ejemplo: $f(x) = \frac{x^2}{x^2+1}$
>     
> - **Impar:** $f(-x) = -f(x)$ Ejemplo: $f(x) = \frac{x}{x^2+1}$
>     
> 
> **6. Función de Witch of Agnesi:** $$f(x) = \frac{8a^3}{x^2+4a^2}$$
> 
> - Curva histórica famosa
> - Forma de campana
> - Sin asíntotas verticales
> - Asíntota horizontal: $y = 0$
