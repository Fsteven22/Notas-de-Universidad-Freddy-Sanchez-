# 📊 Funciones de Variable Real: Definición, Dominio y Rango

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Una función es una regla que asigna a cada valor de entrada (variable independiente) exactamente un valor de salida (variable dependiente). Es como una máquina que procesa números: introduces un número y obtienes otro número como resultado.**
> 
> **Elementos clave:**
> 
> - **Unicidad:** Cada entrada tiene exactamente una salida
> - **Correspondencia:** Relación sistemática entre conjuntos
> - **Dominio:** Todos los valores de entrada posibles
> - **Rango:** Todos los valores de salida que se obtienen
> - **Notación:** f(x) se lee "f de x" o "f en x"

### 📖 Contexto Histórico

> [!note]- Desarrollo Histórico del Concepto de Función
> 
> **Orígenes Antiguos (300 a.C. - 1600):**
> 
> - **Babilonios:** Tablas de valores relacionados (área vs lado)
> - **Griegos:** Relaciones geométricas implícitas
> - **Oresme (1350):** Primeras gráficas de "intensidad vs tiempo"
> - **Concepto implícito:** Relaciones sin formalización
> 
> **Nacimiento del Cálculo (1600-1700):**
> 
> - **Galileo (1638):** Leyes de caída libre (funciones físicas)
> - **Descartes (1637):** Geometría analítica, curvas algebraicas
> - **Newton (1665):** "Fluentes" y "fluxiones"
> - **Leibniz (1684):** Notación dy/dx, funciones como curvas
> - **Idea dominante:** Función = expresión analítica
> 
> **Formalización (1700-1800):**
> 
> - **Johann Bernoulli (1718):** Primera definición explícita "Una función es una expresión formada de cualquier manera a partir de variables y constantes"
> - **Euler (1748):** f(x) notación moderna "Una función de una cantidad variable es una expresión analítica"
> - **Lagrange (1797):** Funciones como series de potencias
> - **Limitación:** Solo funciones "expresables analíticamente"
> 
> **Ampliación del Concepto (1800-1850):**
> 
> - **Fourier (1822):** Series trigonométricas Crisis: funciones "discontinuas" representables
> - **Dirichlet (1837):** Definición moderna "y es función de x si a cada valor de x corresponde un único valor de y, sin importar cómo se establezca esta correspondencia"
> - **Revolución:** Funciones no necesitan fórmula
> 
> **Era de la Teoría de Conjuntos (1850-1900):**
> 
> - **Riemann (1854):** Función de Riemann (patológica)
> - **Weierstrass (1872):** Función continua pero no derivable en ningún punto
> - **Cantor (1874):** Teoría de conjuntos aplicada a funciones
> - **Dedekind (1888):** Funciones como correspondencias entre conjuntos
> 
> **Formalización Moderna (1900-presente):**
> 
> - **Bourbaki (1939):** Función como conjunto de pares ordenados
> - **Definición actual:** f: A → B como relación específica
> - **Generalización:** Funciones entre espacios abstractos
> - **Computación:** Funciones como algoritmos

## 📐 Definición Formal

> [!success]- Definición Matemática Rigurosa
> 
> **Definición (moderna):** Una **función** f de un conjunto A a un conjunto B es una regla que asigna a cada elemento x ∈ A exactamente un elemento y ∈ B.
> 
> **Notación:**
> 
> ```
> f: A → B
> x ↦ f(x)
> 
> Se lee: "f de A en B"
>         "f lleva x a f(x)"
> ```
> 
> **Componentes:**
> 
> - **f:** nombre de la función
> - **A:** dominio (conjunto de partida)
> - **B:** codominio (conjunto de llegada)
> - **x:** variable independiente (argumento, entrada)
> - **y = f(x):** variable dependiente (imagen, salida, valor)
> 
> **Definición como conjunto:** Una función es un conjunto de pares ordenados (x, y) tal que:
> 
> ```
> f = {(x, y) : x ∈ A, y = f(x) ∈ B}
> 
> Con la condición:
> Si (x, y₁) ∈ f y (x, y₂) ∈ f, entonces y₁ = y₂
> (unicidad de la imagen)
> ```
> 
> **Terminología:**
> 
> - **f(x):** imagen de x bajo f, valor de f en x
> - **x:** preimagen de f(x)
> - **Graf(f) = {(x, f(x)) : x ∈ Dom(f)}:** gráfica de f
> - **Regla de correspondencia:** expresión que define f(x)

> [!warning]- Condición Fundamental: Unicidad
> 
> **Criterio de función:** Para cada x en el dominio, existe EXACTAMENTE UN valor f(x)
> 
> **Ejemplos que SÍ son funciones:**
> 
> ```
> f(x) = x²
> Para x = 2: f(2) = 4 (único valor)
> 
> g(x) = √x  (raíz cuadrada positiva)
> Para x = 4: g(4) = 2 (único valor, no ±2)
> ```
> 
> **Ejemplos que NO son funciones:**
> 
> ```
> y² = x
> Para x = 4: y = ±2 (dos valores)
> No cumple unicidad
> 
> La "función" signo de un número complejo
> arg(z) multivaluada (infinitos valores)
> ```
> 
> **Test de la línea vertical:** Una curva representa una función si y solo si cualquier línea vertical la interseca en a lo sumo un punto

## 🎯 Dominio de una Función

> [!success]- Conjunto de Valores de Entrada Válidos
> 
> **Definición:** El **dominio** de una función f es el conjunto de todos los valores x para los cuales f(x) está definido.
> 
> **Notación:**
> 
> ```
> Dom(f) o D(f) o Df
> ```
> 
> **Tipos de dominio:**
> 
> **1. Dominio natural (implícito):** El mayor subconjunto de ℝ donde f(x) tiene sentido matemático
> 
> ```
> f(x) = 1/x
> Dom(f) = ℝ \ {0} = (-∞, 0) ∪ (0, +∞)
> (no se puede dividir por cero)
> ```
> 
> **2. Dominio restringido (explícito):** Especificado deliberadamente, puede ser menor que el natural
> 
> ```
> f: [0, 5] → ℝ
> f(x) = x²
> Dom(f) = [0, 5] (aunque x² está definida en todo ℝ)
> ```
> 
> **3. Dominio máximo:** El dominio natural más grande posible
> 
> ```
> f(x) = √x
> Dom(f) = [0, +∞)
> No se puede extender más en ℝ
> ```

> [!tip]- Restricciones Comunes que Determinan el Dominio
> 
> **1. División por cero:**
> 
> ```
> f(x) = 1/(x - 3)
> 
> Restricción: x - 3 ≠ 0
> Solución: x ≠ 3
> Dom(f) = ℝ \ {3} = (-∞, 3) ∪ (3, +∞)
> ```
> 
> **2. Raíces pares de números negativos:**
> 
> ```
> f(x) = √(x - 2)
> 
> Restricción: x - 2 ≥ 0
> Solución: x ≥ 2
> Dom(f) = [2, +∞)
> ```
> 
> **3. Logaritmos de números no positivos:**
> 
> ```
> f(x) = ln(x + 1)
> 
> Restricción: x + 1 > 0
> Solución: x > -1
> Dom(f) = (-1, +∞)
> ```
> 
> **4. Denominadores con raíces:**
> 
> ```
> f(x) = 1/√(4 - x²)
> 
> Restricciones:
> 1) 4 - x² > 0  (raíz cuadrada y denominador)
> 2) x² < 4
> 3) -2 < x < 2
> 
> Dom(f) = (-2, 2)
> ```
> 
> **5. Tangente y secante:**
> 
> ```
> f(x) = tan(x)
> 
> Restricción: cos(x) ≠ 0
> Solución: x ≠ π/2 + nπ, n ∈ ℤ
> Dom(f) = ℝ \ {π/2 + nπ : n ∈ ℤ}
> ```
> 
> **6. Arcoseno y arcocoseno:**
> 
> ```
> f(x) = arcsin(x)
> 
> Restricción: -1 ≤ x ≤ 1
> Dom(f) = [-1, 1]
> ```
> 
> **7. Múltiples restricciones:**
> 
> ```
> f(x) = √(x - 1)/(x - 3)
> 
> Restricciones:
> 4) x - 1 ≥ 0  ⟹  x ≥ 1
> 5) x - 3 ≠ 0  ⟹  x ≠ 3
> 
> Intersección: x ≥ 1 y x ≠ 3
> Dom(f) = [1, 3) ∪ (3, +∞)
> ```

> [!example]- Ejemplos de Cálculo de Dominios
> 
> **Ejemplo 1 - Función racional:**
> 
> ```
> f(x) = (x² - 4)/(x² - 5x + 6)
> 
> Factorizar denominador:
> x² - 5x + 6 = (x - 2)(x - 3)
> 
> Restricción: (x - 2)(x - 3) ≠ 0
> Solución: x ≠ 2 y x ≠ 3
> 
> Dom(f) = ℝ \ {2, 3}
>        = (-∞, 2) ∪ (2, 3) ∪ (3, +∞)
> ```
> 
> **Ejemplo 2 - Raíz cuadrada:**
> 
> ```
> f(x) = √(9 - x²)
> 
> Restricción: 9 - x² ≥ 0
> x² ≤ 9
> |x| ≤ 3
> -3 ≤ x ≤ 3
> 
> Dom(f) = [-3, 3]
> ```
> 
> **Ejemplo 3 - Combinación:**
> 
> ```
> f(x) = √x + 1/x
> 
> Restricciones:
> 6) x ≥ 0  (raíz cuadrada)
> 7) x ≠ 0  (división)
> 
> Intersección: x > 0
> Dom(f) = (0, +∞)
> ```
> 
> **Ejemplo 4 - Logaritmo:**
> 
> ```
> f(x) = ln(x² - 4)
> 
> Restricción: x² - 4 > 0
> x² > 4
> |x| > 2
> x < -2 o x > 2
> 
> Dom(f) = (-∞, -2) ∪ (2, +∞)
> ```
> 
> **Ejemplo 5 - Composición:**
> 
> ```
> f(x) = √(ln(x))
> 
> Restricciones:
> 8) ln(x) está definido: x > 0
> 9) √(ln(x)) requiere: ln(x) ≥ 0
>    ln(x) ≥ 0 ⟺ x ≥ 1
> 
> Dom(f) = [1, +∞)
> ```
> 
> **Ejemplo 6 - Trigonométrica:**
> 
> ```
> f(x) = 1/(sin(x) - 1)
> 
> Restricción: sin(x) - 1 ≠ 0
> sin(x) ≠ 1
> x ≠ π/2 + 2nπ, n ∈ ℤ
> 
> Dom(f) = ℝ \ {π/2 + 2nπ : n ∈ ℤ}
> ```

## 📈 Rango (o Imagen) de una Función

> [!success]- Conjunto de Valores de Salida
> 
> **Definición:** El **rango** o **imagen** de una función f es el conjunto de todos los valores que f(x) puede tomar.
> 
> **Notación:**
> 
> ```
> Ran(f) o Img(f) o Rg(f) o f(Dom(f))
> 
> Ran(f) = {y ∈ ℝ : ∃x ∈ Dom(f) tal que y = f(x)}
> ```
> 
> **Diferencia con codominio:**
> 
> ```
> Codominio: conjunto de llegada (especificado en f: A → B)
> Rango: valores realmente alcanzados
> 
> Ran(f) ⊆ Codominio
> 
> Ejemplo: f: ℝ → ℝ, f(x) = x²
> Codominio = ℝ
> Rango = [0, +∞) ⊂ ℝ
> ```
> 
> **Observación importante:** Calcular el rango suele ser más difícil que calcular el dominio

> [!tip]- Métodos para Determinar el Rango
> 
> **Método 1 - Análisis directo:**
> 
> ```
> Observar comportamiento de f(x)
> 
> Ejemplo: f(x) = x²
> x² ≥ 0 para todo x ∈ ℝ
> Todo y ≥ 0 es alcanzable: y = x² ⟺ x = ±√y
> Ran(f) = [0, +∞)
> ```
> 
> **Método 2 - Despejar x en términos de y:**
> 
> ```
> Dado y = f(x), resolver para x
> Las restricciones sobre x dan el rango
> 
> Ejemplo: f(x) = (2x + 1)/(x - 3), x ≠ 3
> 
> y = (2x + 1)/(x - 3)
> y(x - 3) = 2x + 1
> yx - 3y = 2x + 1
> yx - 2x = 3y + 1
> x(y - 2) = 3y + 1
> x = (3y + 1)/(y - 2)
> 
> Para que x exista: y - 2 ≠ 0
> y ≠ 2
> 
> Ran(f) = ℝ \ {2}
> ```
> 
> **Método 3 - Análisis de gráfica:**
> 
> ```
> Proyectar la gráfica sobre el eje y
> 
> Útil para funciones conocidas
> ```
> 
> **Método 4 - Cálculo (extremos):**
> 
> ```
> Usar derivadas para encontrar máximos y mínimos
> 
> Ejemplo: f(x) = -x² + 4x - 1 en [0, 3]
> f'(x) = -2x + 4 = 0 ⟹ x = 2
> 
> Evaluar: f(0) = -1, f(2) = 3, f(3) = 2
> Ran(f) = [-1, 3]
> ```
> 
> **Método 5 - Completar cuadrados:**
> 
> ```
> Para funciones cuadráticas
> 
> Ejemplo: f(x) = x² - 6x + 10
> = (x - 3)² + 1
> 
> Como (x - 3)² ≥ 0:
> f(x) ≥ 1
> 
> Ran(f) = [1, +∞)
> ```

> [!example]- Ejemplos de Cálculo de Rangos
> 
> **Ejemplo 1 - Función lineal:**
> 
> ```
> f(x) = 2x + 3
> Dom(f) = ℝ
> 
> Para cualquier y ∈ ℝ:
> y = 2x + 3 ⟹ x = (y - 3)/2 ∈ ℝ
> 
> Ran(f) = ℝ
> ```
> 
> **Ejemplo 2 - Función cuadrática:**
> 
> ```
> f(x) = x² - 4x + 5
> Dom(f) = ℝ
> 
> Completar cuadrado:
> f(x) = (x - 2)² + 1
> 
> Como (x - 2)² ≥ 0:
> f(x) ≥ 1
> 
> Para y ≥ 1: x = 2 ± √(y - 1) existe
> 
> Ran(f) = [1, +∞)
> ```
> 
> **Ejemplo 3 - Función con raíz:**
> 
> ```
> f(x) = √(4 - x²)
> Dom(f) = [-2, 2]
> 
> Como -2 ≤ x ≤ 2:
> 0 ≤ x² ≤ 4
> 0 ≤ 4 - x² ≤ 4
> 0 ≤ √(4 - x²) ≤ 2
> 
> f(-2) = f(2) = 0
> f(0) = 2
> 
> Ran(f) = [0, 2]
> ```
> 
> **Ejemplo 4 - Función racional:**
> 
> ```
> f(x) = 1/(x + 1)
> Dom(f) = ℝ \ {-1}
> 
> Método: despejar x
> y = 1/(x + 1)
> y(x + 1) = 1
> x = 1/y - 1
> 
> Para que x ≠ -1: 1/y - 1 ≠ -1
> 1/y ≠ 0
> y ≠ 0
> 
> Ran(f) = ℝ \ {0}
> ```
> 
> **Ejemplo 5 - Función exponencial:**
> 
> ```
> f(x) = 2ˣ + 1
> Dom(f) = ℝ
> 
> Como 2ˣ > 0 para todo x:
> f(x) = 2ˣ + 1 > 1
> 
> Además, 2ˣ toma todos los valores en (0, +∞)
> 
> Ran(f) = (1, +∞)
> ```
> 
> **Ejemplo 6 - Función trigonométrica:**
> 
> ```
> f(x) = 2sin(x) + 3
> Dom(f) = ℝ
> 
> Como -1 ≤ sin(x) ≤ 1:
> -2 ≤ 2sin(x) ≤ 2
> 1 ≤ 2sin(x) + 3 ≤ 5
> 
> Ran(f) = [1, 5]
> ```
> 
> **Ejemplo 7 - Dominio restringido:**
> 
> ```
> f(x) = x³, x ∈ [-1, 2]
> 
> f es creciente (f'(x) = 3x² ≥ 0)
> 
> Mínimo: f(-1) = -1
> Máximo: f(2) = 8
> 
> Ran(f) = [-1, 8]
> ```

## 🔍 Relación entre Dominio y Rango

> [!note]- Conceptos Complementarios
> 
> **Simetría conceptual:**
> 
> ```
> Dominio ←→ Rango
> Valores x ←→ Valores y
> Entrada ←→ Salida
> ```
> 
> **Para funciones inversas:**
> 
> ```
> Si f: A → B es invertible:
> Dom(f⁻¹) = Ran(f)
> Ran(f⁻¹) = Dom(f)
> 
> Ejemplo: f(x) = 2x + 1
> Dom(f) = ℝ, Ran(f) = ℝ
> f⁻¹(x) = (x - 1)/2
> Dom(f⁻¹) = ℝ, Ran(f⁻¹) = ℝ
> ```
> 
> **Restricciones naturales:**
> 
> ```
> Dominio: restricciones matemáticas (√, /, ln)
> Rango: consecuencia del dominio y la función
> 
> Ejemplo: f(x) = 1/x²
> Dom(f) = ℝ \ {0} (restricción: x ≠ 0)
> Ran(f) = (0, +∞) (consecuencia: 1/x² > 0)
> ```

## 📊 Notaciones y Convenciones

> [!tip]- Formas de Expresar Funciones
> 
> **Notación explícita:**
> 
> ```
> f(x) = x² + 2x - 1
> 
> Clara identificación de entrada y salida
> ```
> 
> **Notación implícita:**
> 
> ```
> x² + y² = 25
> 
> Define una relación, no necesariamente una función
> (aquí, dos funciones: y = ±√(25 - x²))
> ```
> 
> **Notación de mapeo:**
> 
> ```
> f: ℝ → ℝ
> x ↦ x² + 1
> 
> "f mapea x a x² + 1"
> ```
> 
> **Notación de conjunto:**
> 
> ```
> f = {(x, y) : y = 2x + 1, x ∈ ℝ}
> 
> Función como conjunto de pares ordenados
> ```
> 
> **Especificación completa:**
> 
> ```
> f: [0, 4] → ℝ
> f(x) = √x
> 
> Incluye: nombre, dominio, codominio, regla
> ```
> 
> **Notación por casos:**
> 
> ```
> f(x) = { x²     si x ≥ 0
>        { -x     si x < 0
> 
> Define f(x) = |x| · x
> ```

## 🎯 Tipos de Funciones según Dominio y Rango

> [!note]- Clasificación Importante
> 
> **Funciones polinomiales:**
> 
> ```
> f(x) = aₙxⁿ + ... + a₁x + a₀
> 
> Dom(f) = ℝ
> Ran(f) depende del grado:
> - Grado impar: ℝ
> - Grado par: [mínimo, +∞) o (-∞, máximo]
> ```
> 
> **Funciones racionales:**
> 
> ```
> f(x) = P(x)/Q(x)
> 
> Dom(f) = {x ∈ ℝ : Q(x) ≠ 0}
> Ran(f): generalmente ℝ \ {algunos valores}
> ```
> 
> **Funciones radicales:**
> 
> ```
> f(x) = ⁿ√g(x)
> 
> Dom(f): depende de n (par o impar) y de g(x)
> Ran(f): generalmente [0, +∞) para n par
> ```
> 
> **Funciones exponenciales:**
> 
> ```
> f(x) = aˣ, a > 0, a ≠ 1
> 
> Dom(f) = ℝ
> Ran(f) = (0, +∞)
> ```
> 
> **Funciones logarítmicas:**
> 
> ```
> f(x) = logₐ(x), a > 0, a ≠ 1
> 
> Dom(f) = (0, +∞)
> Ran(f) = ℝ
> ```
> 
> **Funciones trigonométricas:**
> 
> ```
> sin(x), cos(x): Dom = ℝ, Ran = [-1, 1]
> tan(x): Dom = ℝ \ {π/2 + nπ}, Ran = ℝ
> sec(x): Dom = ℝ \ {π/2 + nπ}, Ran = (-∞, -1] ∪ [1, +∞)
> ```
> 
> **Funciones inversas trigonométricas:**
> 
> ```
> arcsin(x): Dom = [-1, 1], Ran = [-π/2, π/2]
> arccos(x): Dom = [-1, 1], Ran = [0, π]
> arctan(x): Dom = ℝ, Ran = (-π/2, π/2)
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes
> 
> **1. "Dominio = codominio"**
> 
> ```
> ✗ INCORRECTO
> 
> f: ℝ → ℝ, f(x) = x²
> Dominio = ℝ (valores de x)
> Codominio = ℝ (conjunto de llegada especificado)
> Rango = [0, +∞) (valores realmente alcanzados)
> 
> Dominio y codominio son conceptos diferentes
> ```
> 
> **2. "Si y = x², entonces x = ±√y"**
> 
> ```
> ✗ INCORRECTO para función
> 
> f(x) = x² es función
> Pero x = ±√y no define función (dos valores)
> 
> ✓ CORRECTO:
> La inversa requiere restringir dominio
> f: [0, +∞) → [0, +∞), f(x) = x²
> f⁻¹(x) = √x (solo raíz positiva)
> ```
> 
> **3. "Rango = codominio siempre"**
> 
> ```
> ✗ INCORRECTO
> 
> f: ℝ → ℝ, f(x) = eˣ
> Codominio = ℝ
> Rango = (0, +∞) ≠ ℝ
> 
> Solo si f es sobreyectiva
> ```
> 
> **4. "√(x²) = x"**
> 
> ```
> ✗ INCORRECTO en general
> ✓ CORRECTO: √(x²) = |x|
> 
> Ejemplo: √((-3)²) = √9 = 3 = |-3| ≠ -3
> ```
> 
> **5. "Dom(f + g) = Dom(f) ∪ Dom(g)"**
> 
> ```
> ✗ INCORRECTO
> ✓ CORRECTO: Dom(f + g) = Dom(f) ∩ Dom(g)
> 
> Ejemplo:
> f(x) = √x, Dom(f) = [0, +∞)
> g(x) = √(1-x), Dom(g) = (-∞, 1]
> (f + g)(x) = √x + √(1-x)
> Dom(f + g) = [0, 1]
> ```
> 
> **6. "f(a + b) = f(a) + f(b)"**
> 
> ```
> ✗ INCORRECTO en general
> 
> Solo cierto para funciones lineales
> 
> Contraejemplo: f(x) = x²
> f(2 + 3) = f(5) = 25
> f(2) + f(3) = 4 + 9 = 13
> 25 ≠ 13
> ```
> 
> **7. "Olvidar restricciones del dominio"**
> 
> ```
> f(x) = √(x - 2) + 1/(x - 3)
> 
> ✗ INCORRECTO: Dom(f) = ℝ
> ✓ CORRECTO:
> 1) x - 2 ≥ 0 ⟹ x ≥ 2
> 2) x - 3 ≠ 0 ⟹ x ≠ 3
> Dom(f) = [2, 3) ∪ (3, +∞)
> ```

## 🔄 Operaciones con Funciones

> [!tip]- Álgebra de Funciones y sus Dominios
> 
> **Suma de funciones:**
> 
> ```
> (f + g)(x) = f(x) + g(x)
> Dom(f + g) = Dom(f) ∩ Dom(g)
> 
> Ejemplo:
> f(x) = √x, Dom(f) = [0, +∞)
> > g(x) = √(4-x), Dom(g) = (-∞, 4] (f + g)(x) = √x + √(4-x) Dom(f + g) = [0, 4]
> 
> ```
> 
> **Resta de funciones:**
> ```
> 
> (f - g)(x) = f(x) - g(x) Dom(f - g) = Dom(f) ∩ Dom(g)
> 
> Ejemplo: f(x) = x², Dom(f) = ℝ g(x) = 1/x, Dom(g) = ℝ \ {0} (f - g)(x) = x² - 1/x Dom(f - g) = ℝ \ {0}
> 
> ```
> 
> **Producto de funciones:**
> ```
> 
> (f · g)(x) = f(x) · g(x) Dom(f · g) = Dom(f) ∩ Dom(g)
> 
> Ejemplo: f(x) = √(x+1), Dom(f) = [-1, +∞) g(x) = √(2-x), Dom(g) = (-∞, 2] (f · g)(x) = √((x+1)(2-x)) Dom(f · g) = [-1, 2]
> 
> ```
> 
> **Cociente de funciones:**
> ```
> 
> (f/g)(x) = f(x)/g(x) Dom(f/g) = Dom(f) ∩ Dom(g) ∩ {x : g(x) ≠ 0}
> 
> Ejemplo: f(x) = x² - 1, Dom(f) = ℝ g(x) = x - 1, Dom(g) = ℝ (f/g)(x) = (x² - 1)/(x - 1) = (x+1)(x-1)/(x-1)
> 
> Restricción adicional: x - 1 ≠ 0 ⟹ x ≠ 1 Dom(f/g) = ℝ \ {1}
> 
> Nota: Aunque (x²-1)/(x-1) = x+1 algebraicamente, el dominio excluye x = 1
> 
> ```
> 
> **Múltiplo escalar:**
> ```
> 
> (c · f)(x) = c · f(x), c ∈ ℝ Dom(c · f) = Dom(f)
> 
> Ejemplo: f(x) = √x, Dom(f) = [0, +∞) (3f)(x) = 3√x, Dom(3f) = [0, +∞)
> 
> ```
> 
> **Composición de funciones:**
> ```
> 
> (f ∘ g)(x) = f(g(x)) Dom(f ∘ g) = {x ∈ Dom(g) : g(x) ∈ Dom(f)}
> 
> Ejemplo: f(x) = √x, Dom(f) = [0, +∞) g(x) = x - 3, Dom(g) = ℝ
> 
> (f ∘ g)(x) = f(g(x)) = √(x - 3)
> 
> Condiciones:
> 
> 1. x ∈ Dom(g) = ℝ ✓
> 2. g(x) ∈ Dom(f): x - 3 ≥ 0 ⟹ x ≥ 3
> 
> Dom(f ∘ g) = [3, +∞)
> ```

## 🔄 Composición de Funciones

> [!important]- Operación Fundamental
> 
> **Definición:** La **composición** de f con g es la función que resulta de aplicar primero g, luego f:
> 
> ```
> (f ∘ g)(x) = f(g(x))
> 
> Se lee: "f compuesta con g"
>         "f círculo g"
> ```
> 
> **Diagrama de flujo:**
> 
> ```
> x → [g] → g(x) → [f] → f(g(x))
> 
> Entrada → g → intermedio → f → Salida
> ```
> 
> **Dominio de la composición:**
> 
> ```
> Dom(f ∘ g) = {x ∈ Dom(g) : g(x) ∈ Dom(f)}
> 
> Dos condiciones:
> 1. x debe estar en el dominio de g
> 2. g(x) debe estar en el dominio de f
> ```
> 
> **Rango de la composición:**
> 
> ```
> Ran(f ∘ g) ⊆ Ran(f)
> 
> Los valores de salida vienen de f
> ```
> 
> **No conmutatividad:**
> 
> ```
> En general: f ∘ g ≠ g ∘ f
> 
> Ejemplo:
> f(x) = x², g(x) = x + 1
> 
> (f ∘ g)(x) = f(g(x)) = (x + 1)² = x² + 2x + 1
> (g ∘ f)(x) = g(f(x)) = x² + 1
> 
> x² + 2x + 1 ≠ x² + 1
> ```

> [!example]- Ejemplos de Composición
> 
> **Ejemplo 1 - Básico:**
> 
> ```
> f(x) = 2x + 1, g(x) = x²
> 
> (f ∘ g)(x) = f(g(x)) = f(x²) = 2x² + 1
> (g ∘ f)(x) = g(f(x)) = g(2x + 1) = (2x + 1)²
> 
> Dom(f ∘ g) = ℝ
> Dom(g ∘ f) = ℝ
> ```
> 
> **Ejemplo 2 - Con restricciones:**
> 
> ```
> f(x) = √x, Dom(f) = [0, +∞)
> g(x) = x² - 4, Dom(g) = ℝ
> 
> (f ∘ g)(x) = √(x² - 4)
> 
> Condiciones:
> 1) x ∈ ℝ ✓
> 2) x² - 4 ≥ 0
>    x² ≥ 4
>    |x| ≥ 2
>    x ≤ -2 o x ≥ 2
> 
> Dom(f ∘ g) = (-∞, -2] ∪ [2, +∞)
> ```
> 
> **Ejemplo 3 - Logaritmos:**
> 
> ```
> f(x) = ln(x), Dom(f) = (0, +∞)
> g(x) = x², Dom(g) = ℝ
> 
> (f ∘ g)(x) = ln(x²)
> 
> Condiciones:
> 1) x ∈ ℝ ✓
> 2) x² > 0 ⟹ x ≠ 0
> 
> Dom(f ∘ g) = ℝ \ {0} = (-∞, 0) ∪ (0, +∞)
> ```
> 
> **Ejemplo 4 - Triple composición:**
> 
> ```
> f(x) = x², g(x) = x + 1, h(x) = 1/x
> 
> (f ∘ g ∘ h)(x) = f(g(h(x)))
> = f(g(1/x))
> = f(1/x + 1)
> = (1/x + 1)²
> = ((1 + x)/x)²
> = (1 + x)²/x²
> 
> Dom(f ∘ g ∘ h) = ℝ \ {0}
> ```
> 
> **Ejemplo 5 - Descomponer función:**
> 
> ```
> Sea h(x) = √(x² + 1)
> 
> Descomposición 1:
> f(x) = √x, g(x) = x² + 1
> h = f ∘ g
> 
> Descomposición 2:
> f(x) = √(x + 1), g(x) = x²
> h = f ∘ g
> 
> Múltiples descomposiciones posibles
> ```

## 📊 Función Definida por Partes

> [!note]- Funciones por Casos
> 
> **Definición:** Una función **definida por partes** o **por tramos** se especifica mediante diferentes expresiones en diferentes partes del dominio.
> 
> **Notación general:**
> 
> ```
> f(x) = { f₁(x)  si x ∈ D₁
>        { f₂(x)  si x ∈ D₂
>        { f₃(x)  si x ∈ D₃
>        { ...
> 
> donde D₁, D₂, D₃, ... particionan el dominio
> ```
> 
> **Dominio:**
> 
> ```
> Dom(f) = D₁ ∪ D₂ ∪ D₃ ∪ ...
> ```
> 
> **Rango:**
> 
> ```
> Ran(f) = Ran(f₁|D₁) ∪ Ran(f₂|D₂) ∪ Ran(f₃|D₃) ∪ ...
> ```

> [!example]- Ejemplos de Funciones por Partes
> 
> **Ejemplo 1 - Valor absoluto:**
> 
> ```
> f(x) = |x| = { x   si x ≥ 0
>              { -x  si x < 0
> 
> Dom(f) = ℝ
> Ran(f) = [0, +∞)
> 
> Evaluaciones:
> f(3) = 3
> f(-2) = -(-2) = 2
> f(0) = 0
> ```
> 
> **Ejemplo 2 - Función signo:**
> 
> ```
> sgn(x) = { 1   si x > 0
>          { 0   si x = 0
>          { -1  si x < 0
> 
> Dom(sgn) = ℝ
> Ran(sgn) = {-1, 0, 1}
> ```
> 
> **Ejemplo 3 - Tarifa postal:**
> 
> ```
> C(w) = { 2.50   si 0 < w ≤ 1
>        { 4.00   si 1 < w ≤ 2
>        { 5.50   si 2 < w ≤ 3
>        { 7.00   si 3 < w ≤ 4
> 
> C = costo en $, w = peso en kg
> Dom(C) = (0, 4]
> Ran(C) = {2.50, 4.00, 5.50, 7.00}
> ```
> 
> **Ejemplo 4 - Función escalón:**
> 
> ```
> f(x) = { x²     si x < 0
>        { 1      si x = 0
>        { 2x + 1 si x > 0
> 
> Dom(f) = ℝ
> 
> Evaluaciones:
> f(-2) = (-2)² = 4
> f(0) = 1
> f(3) = 2(3) + 1 = 7
> 
> Para el rango:
> x < 0: y = x² ∈ (0, +∞)
> x = 0: y = 1
> x > 0: y = 2x + 1 ∈ (1, +∞)
> 
> Ran(f) = (0, +∞)
> ```
> 
> **Ejemplo 5 - Impuesto progresivo:**
> 
> ```
> T(I) = { 0.10I           si 0 ≤ I ≤ 10000
>        { 1000 + 0.15(I-10000)  si I > 10000
> 
> T = impuesto, I = ingreso
> 
> Para I = 8000: T(8000) = 0.10(8000) = 800
> Para I = 15000: T(15000) = 1000 + 0.15(5000) = 1750
> ```
> 
> **Ejemplo 6 - Con dominio restringido:**
> 
> ```
> f(x) = { √x      si 0 ≤ x < 4
>        { 8 - x   si 4 ≤ x ≤ 8
> 
> Dom(f) = [0, 8]
> 
> Para el rango:
> En [0, 4): f(x) = √x ∈ [0, 2)
> En [4, 8]: f(x) = 8 - x ∈ [0, 4]
> 
> Ran(f) = [0, 4]
> ```

## 🔍 Funciones Implícitas

> [!note]- Relaciones que Definen Funciones
> 
> **Definición:** Una función se define **implícitamente** cuando está dada por una ecuación que relaciona x e y, pero no despeja y explícitamente.
> 
> **Forma general:**
> 
> ```
> F(x, y) = 0
> 
> En lugar de: y = f(x)
> ```
> 
> **Problema:** No toda ecuación implícita define y como función de x
> 
> **Criterio:** Para cada valor de x, debe haber exactamente un valor de y
> 
> **Ejemplos:**
> 
> ```
> 1) x + y = 5
>    Define función: y = 5 - x ✓
>    Dom = ℝ, Ran = ℝ
> 
> 2) x² + y² = 9
>    NO define una función (para x = 0: y = ±3)
>    Define dos funciones:
>    y = √(9 - x²)  (semicírculo superior)
>    y = -√(9 - x²) (semicírculo inferior)
> 
> 3) y² = x
>    NO define función de x
>    Pero x = y² define función de y
> 
> 4) x³ + y³ = 6xy
>    (Folio de Descartes)
>    Define función implícitamente en regiones
> ```

## 🎨 Representaciones de Funciones

> [!tip]- Cuatro Formas de Expresar una Función
> 
> **1. Algebraica (fórmula):**
> 
> ```
> f(x) = x² - 3x + 2
> 
> Ventajas:
> - Precisa y compacta
> - Permite cálculos exactos
> - Fácil manipulación algebraica
> 
> Desventajas:
> - No siempre posible (datos empíricos)
> - Puede ocultar comportamiento visual
> ```
> 
> **2. Numérica (tabla de valores):**
> 
> ```
> x  | -2 | -1 | 0 | 1 | 2 | 3 | 4
> ---|----|----|---|---|---|---|---
> f(x)| 12 | 6  | 2 | 0 | 2 | 8 | 18
> 
> Ventajas:
> - Datos específicos claros
> - Útil para datos experimentales
> - Fácil de leer valores
> 
> Desventajas:
> - Finita (no todos los valores)
> - No muestra patrón general
> - Interpolación inexacta
> ```
> 
> **3. Gráfica (visual):**
> 
> ```
> Curva en el plano xy
> 
> Ventajas:
> - Visualiza comportamiento global
> - Muestra tendencias y patrones
> - Intuitiva y comprensible
> - Identifica máximos, mínimos, asíntotas
> 
> Desventajas:
> - Imprecisa para valores exactos
> - Difícil para altas dimensiones
> ```
> 
> **4. Verbal (descripción):**
> 
> ```
> "El área de un cuadrado en función de su lado"
> "La temperatura en grados Celsius en función del tiempo"
> 
> Ventajas:
> - Describe contexto y significado
> - Accesible sin matemáticas
> 
> Desventajas:
> - Imprecisa
> - No permite cálculos
> ```

## 🌐 Funciones en Contextos Aplicados

> [!example]- Modelaje con Funciones
> 
> **Física - Movimiento:**
> 
> ```
> Posición en función del tiempo:
> s(t) = s₀ + v₀t + ½at²
> 
> Dom(s) = [0, tₘₐₓ] (tiempo físico)
> Ran(s) depende de parámetros
> ```
> 
> **Economía - Costo:**
> 
> ```
> Costo total en función de unidades producidas:
> C(x) = Costo_fijo + Costo_variable · x
> C(x) = 5000 + 25x
> 
> Dom(C) = [0, +∞) o [0, capacidad_máxima]
> Ran(C) = [5000, +∞)
> ```
> 
> **Biología - Crecimiento poblacional:**
> 
> ```
> P(t) = P₀e^(rt)
> 
> P = población
> t = tiempo
> r = tasa de crecimiento
> P₀ = población inicial
> 
> Dom(P) = [0, +∞)
> Ran(P) = [P₀, +∞)
> ```
> 
> **Geometría - Área:**
> 
> ```
> Área de círculo en función del radio:
> A(r) = πr²
> 
> Dom(A) = [0, +∞) (radio no negativo)
> Ran(A) = [0, +∞)
> ```
> 
> **Ingeniería - Voltaje:**
> 
> ```
> Ley de Ohm:
> V(I) = R · I
> 
> V = voltaje (V)
> I = corriente (A)
> R = resistencia (Ω)
> 
> Dom(V) = [0, Iₘₐₓ]
> Ran(V) = [0, R·Iₘₐₓ]
> ```

## 💡 Estrategias de Resolución

> [!tip]- Cómo Abordar Problemas de Dominio y Rango
> 
> **Para encontrar dominios:**
> 
> 1. **Identificar restricciones:**
>     - Denominadores ≠ 0
>     - Raíces pares: radicando ≥ 0
>     - Logaritmos: argumento > 0
>     - Funciones trigonométricas inversas: argumentos en [-1, 1]
> 2. **Resolver desigualdades:**
>     - Factorizar cuando sea posible
>     - Usar recta numérica para signos
>     - Expresar como intervalos
> 3. **Intersectar condiciones:**
>     - Todas las restricciones deben cumplirse simultáneamente
>     - Dom(f) = condición₁ ∩ condición₂ ∩ ...
> 
> **Para encontrar rangos:**
> 
> 4. **Método del despeje:**
>     - Escribir y = f(x)
>     - Despejar x en términos de y
>     - Las restricciones sobre x determinan valores válidos de y
> 5. **Método analítico:**
>     - Estudiar comportamiento de f(x)
>     - Usar cálculo: derivadas para extremos
>     - Analizar límites en infinito
> 6. **Método gráfico:**
>     - Bosquejar la gráfica
>     - Proyectar sobre eje y
> 7. **Para funciones específicas:**
>     - Polinomios: completar cuadrados
>     - Trigonométricas: usar cotas conocidas
>     - Exponenciales/logaritmos: usar propiedades

## 🎯 Conceptos Clave para Recordar

> [!important]- Resumen Ejecutivo
> 
> **Definición esencial:**
> 
> - Función: regla que asigna a cada entrada exactamente una salida
> - Notación: f: A → B, y = f(x)
> - Criterio fundamental: unicidad de la imagen
> 
> **Dominio:**
> 
> - Conjunto de valores de entrada válidos
> - Determinado por restricciones matemáticas:
>     - División: denominador ≠ 0
>     - Raíces pares: radicando ≥ 0
>     - Logaritmos: argumento > 0
> - Dom(f) se expresa como intervalos o uniones
> 
> **Rango:**
> 
> - Conjunto de valores de salida alcanzados
> - Ran(f) ⊆ Codominio
> - Métodos: despeje, análisis, gráfica
> - Generalmente más difícil de calcular que el dominio
> 
> **Operaciones:**
> 
> - Álgebra: (f ± g)(x), (f · g)(x), (f/g)(x)
> - Composición: (f ∘ g)(x) = f(g(x))
> - Dom(f ∘ g) = {x ∈ Dom(g) : g(x) ∈ Dom(f)}
> 
> **Representaciones:**
> 
> - Algebraica (fórmula)
> - Numérica (tabla)
> - Gráfica (visual)
> - Verbal (descripción)
> 
> **Funciones especiales:**
> 
> - Por partes: diferentes expresiones en diferentes intervalos
> - Implícitas: definidas por ecuaciones F(x,y) = 0
> - Test de línea vertical: cada x → un solo y

## 🧩 Problemas Resueltos Paso a Paso

> [!example]- Soluciones Detalladas
> 
> **Problema 1: Dominio complejo**
> 
> ```
> Encuentra el dominio de f(x) = √(x² - 5x + 6)/(x - 4)
> 
> SOLUCIÓN:
> 
> Paso 1: Identificar restricciones
> - Raíz cuadrada: x² - 5x + 6 ≥ 0
> - Denominador: x - 4 ≠ 0
> 
> Paso 2: Resolver x² - 5x + 6 ≥ 0
> Factorizar: (x - 2)(x - 3) ≥ 0
> 
> Tabla de signos:
>       x < 2    2 < x < 3    x > 3
> x-2    (-)       (+)         (+)
> x-3    (-)       (-)         (+)
> Prod   (+)       (-)         (+)
> 
> Solución: x ≤ 2 o x ≥ 3
> Es decir: (-∞, 2] ∪ [3, +∞)
> 
> Paso 3: Resolver x - 4 ≠ 0
> x ≠ 4
> 
> Paso 4: Intersectar condiciones
> [(-∞, 2] ∪ [3, +∞)] ∩ (ℝ \ {4})
> = (-∞, 2] ∪ [3, 4) ∪ (4, +∞)
> 
> RESPUESTA: Dom(f) = (-∞, 2] ∪ [3, 4) ∪ (4, +∞)
> ```
> 
> **Problema 2: Rango mediante despeje**
> 
> ```
> Encuentra el rango de f(x) = (2x - 1)/(x + 3)
> 
> SOLUCIÓN:
> 
> Paso 1: Determinar dominio
> x + 3 ≠ 0 ⟹ x ≠ -3
> Dom(f) = ℝ \ {-3}
> 
> Paso 2: Despejar x en términos de y
> y = (2x - 1)/(x + 3)
> y(x + 3) = 2x - 1
> yx + 3y = 2x - 1
> yx - 2x = -1 - 3y
> x(y - 2) = -1 - 3y
> x = (-1 - 3y)/(y - 2)
> 
> Paso 3: Restricción sobre y
> Para que x exista: y - 2 ≠ 0
> y ≠ 2
> 
> Paso 4: Verificar que todo y ≠ 2 es alcanzable
> Para cualquier y ≠ 2, existe x = (-1 - 3y)/(y - 2)
> que pertenece a Dom(f) (verificar x ≠ -3)
> 
> Si x = -3: -3 = (-1 - 3y)/(y - 2)
> -3(y - 2) = -1 - 3y
> -3y + 6 = -1 - 3y
> 6 = -1 (contradicción)
> 
> Por tanto, x nunca es -3
> 
> RESPUESTA: Ran(f) = ℝ \ {2} = (-∞, 2) ∪ (2, +∞)
> ```
> 
> **Problema 3: Composición**
> 
> ```
> Sean f(x) = √(x - 1) y g(x) = x² + 1
> Encuentra (f ∘ g)(x) y su dominio
> 
> SOLUCIÓN:
> 
> Paso 1: Calcular (f ∘ g)(x)
> (f ∘ g)(x) = f(g(x))
>            = f(x² + 1)
>            = √((x² + 1) - 1)
>            = √(x²)
>            = |x|
> 
> Paso 2: Determinar dominio
> Condición 1: x ∈ Dom(g) = ℝ ✓
> 
> Condición 2: g(x) ∈ Dom(f)
> Dom(f) = [1, +∞)
> g(x) = x² + 1 ≥ 1 para todo x ∈ ℝ ✓
> 
> Ambas condiciones satisfechas para todo x ∈ ℝ
> 
> RESPUESTA:
> (f ∘ g)(x) = |x|
> Dom(f ∘ g) = ℝ
> ```
> 
> **Problema 4: Función por partes**
> 
> ```
> Define algebraicamente y encuentra dominio y rango:
> f(x) = |x - 2| + |x + 1|
> 
> SOLUCIÓN:
> 
> Paso 1: Identificar puntos críticos
> x - 2 = 0 ⟹ x = 2
> x + 1 = 0 ⟹ x = -1
> 
> Puntos críticos: -1, 2
> Intervalos: (-∞, -1), [-1, 2], (2, +∞)
> 
> Paso 2: Analizar por intervalos
> 
> Caso 1: x < -1
> x - 2 < 0 y x + 1 < 0
> f(x) = -(x - 2) - (x + 1) = -x + 2 - x - 1 = -2x + 1
> 
> Caso 2: -1 ≤ x ≤ 2
> x - 2 ≤ 0 y x + 1 ≥ 0
> f(x) = -(x - 2) + (x + 1) = -x + 2 + x + 1 = 3
> 
> Caso 3: x > 2
> x - 2 > 0 y x + 1 > 0
> f(x) = (x - 2) + (x + 1) = x - 2 + x + 1 = 2x - 1
> 
> Paso 3: Función por partes
> f(x) = { -2x + 1  si x < -1
>        {    3     si -1 ≤ x ≤ 2
>        {  2x - 1  si x > 2
> 
> Paso 4: Dominio
> Dom(f) = ℝ (sin restricciones)
> 
> Paso 5: Rango
> En x < -1: f(x) = -2x + 1 > -2(-1) + 1 = 3
>           f(x) ∈ (3, +∞)
> 
> En -1 ≤ x ≤ 2: f(x) = 3
>                f(x) = {3}
> 
> En x > 2: f(x) = 2x - 1 > 2(2) - 1 = 3
>          f(x) ∈ (3, +∞)
> 
> Unión: (3, +∞) ∪ {3} ∪ (3, +∞) = [3, +∞)
> 
> RESPUESTA:
> f(x) = { -2x + 1  si x < -1
>        {    3     si -1 ≤ x ≤ 2
>        {  2x - 1  si x > 2
> 
> Dom(f) = ℝ
> Ran(f) = [3, +∞)
> ```
> 
> **Problema 5: Dominio con logaritmo**
> 
> ```
> Encuentra el dominio de f(x) = ln(x² - 4) + √(3 - x)
> 
> SOLUCIÓN:
> 
> Paso 1: Restricción del logaritmo
> x² - 4 > 0
> (x - 2)(x + 2) > 0
> 
> Tabla de signos:
>       x < -2    -2 < x < 2    x > 2
> x-2    (-)        (-)          (+)
> x+2    (-)        (+)          (+)
> Prod   (+)        (-)          (+)
> 
> Solución: x < -2 o x > 2
> Es decir: (-∞, -2) ∪ (2, +∞)
> 
> Paso 2: Restricción de la raíz
> 3 - x ≥ 0
> x ≤ 3
> Es decir: (-∞, 3]
> 
> Paso 3: Intersectar ambas condiciones
> [(-∞, -2) ∪ (2, +∞)] ∩ (-∞, 3]
> = (-∞, -2) ∪ (2, 3]
> 
> RESPUESTA: Dom(f) = (-∞, -2) ∪ (2, 3]
> ```

## 🔍 Casos Especiales y Sutilezas

> [!warning]- Situaciones que Requieren Atención Especial
> 
> **1. Simplificación que oculta restricciones:**
> 
> ```
> f(x) = (x² - 4)/(x - 2) = (x+2)(x-2)/(x-2) = x + 2
> 
> ⚠️ CUIDADO: Aunque algebraicamente f(x) = x + 2,
> el dominio NO es ℝ
> 
> Dom(f) = ℝ \ {2}
> 
> Porque originalmente hay división por (x - 2)
> La simplificación no elimina la restricción del dominio
> ```
> 
> **2. Composición con restricciones ocultas:**
> 
> ```
> f(x) = √x, g(x) = x²
> (f ∘ g)(x) = √(x²) = |x|
> 
> ⚠️ Aunque |x| está definida en ℝ,
> hay que verificar el dominio paso a paso:
> 
> Dom(g) = ℝ
> g(x) = x² ≥ 0 para todo x ∈ ℝ
> x² ∈ Dom(f) = [0, +∞) ✓
> 
> Dom(f ∘ g) = ℝ (correcto en este caso)
> ```
> 
> **3. Funciones con discontinuidades removibles:**
> 
> ```
> f(x) = sin(x)/x
> 
> Algebraicamente: lim(x→0) sin(x)/x = 1
> 
> Pero Dom(f) = ℝ \ {0}
> 
> Función extendida:
> f̃(x) = { sin(x)/x  si x ≠ 0
>        {    1       si x = 0
> 
> Dom(f̃) = ℝ (discontinuidad removida)
> ```
> 
> **4. Raíces de índice par vs impar:**
> 
> ```
> f(x) = √x    Dom(f) = [0, +∞)
> g(x) = ³√x   Dom(g) = ℝ
> 
> Índice par: radicando ≥ 0
> Índice impar: sin restricción en ℝ
> ```
> 
> **5. Exponenciales con base variable:**
> 
> ```
> f(x) = x^x
> 
> ⚠️ Requiere x > 0 para valores reales
> Dom(f) = (0, +∞)
> 
> Aunque x^x tiene sentido en algunos x < 0
> (como (-1)^(-1) = -1), la función requiere
> continuidad, lo que limita al dominio (0, +∞)
> ```
> 
> **6. Funciones trigonométricas inversas:**
> 
> ```
> f(x) = arcsin(2x - 1)
> 
> Restricción: -1 ≤ 2x - 1 ≤ 1
>             0 ≤ 2x ≤ 2
>             0 ≤ x ≤ 1
> 
> Dom(f) = [0, 1]
> Ran(f) = [-π/2, π/2] (rango de arcsin)
> ```

## 📐 Relación con la Gráfica

> [!note]- Interpretación Geométrica
> 
> **Dominio en la gráfica:**
> 
> ```
> Proyección de la curva sobre el eje x
> 
> Si la gráfica "vive" sobre el intervalo [a, b],
> entonces Dom(f) ⊆ [a, b]
> ```
> 
> **Rango en la gráfica:**
> 
> ```
> Proyección de la curva sobre el eje y
> 
> Valores mínimos y máximos de la gráfica
> determinan el rango
> ```
> 
> **Test de la línea vertical:**
> 
> ```
> Una curva representa una función ⟺
> Cualquier línea vertical la interseca en ≤ 1 punto
> 
> Ejemplos:
> y = x² ✓ (función)
> x = y² ✗ (no función de x, pero función de y)
> x² + y² = 1 ✗ (círculo, no función)
> ```
> 
> **Test de la línea horizontal (para inyectividad):**
> 
> ```
> Una función es inyectiva ⟺
> Cualquier línea horizontal interseca la gráfica en ≤ 1 punto
> 
> Relacionado con existencia de función inversa
> ```
> 
> **Asíntotas y dominio:**
> 
> ```
> Asíntota vertical en x = a ⟹ a ∉ Dom(f)
> 
> Ejemplo: f(x) = 1/(x-2)
> Asíntota vertical en x = 2
> Dom(f) = ℝ \ {2}
> ```
> 
> **Asíntotas y rango:**
> 
> ```
> Asíntota horizontal en y = L ⟹ L ∉ Ran(f) (típicamente)
> 
> Ejemplo: f(x) = 1/x
> Asíntota horizontal en y = 0
> Ran(f) = ℝ \ {0} = (-∞, 0) ∪ (0, +∞)
> ```

## 🌟 Aplicaciones Avanzadas

> [!example]- Contextos Matemáticos Superiores
> 
> **Análisis funcional:**
> 
> ```
> Funciones como elementos de espacios vectoriales
> Dominio y rango en espacios abstractos
> f: L² → L² (espacios de Hilbert)
> ```
> 
> **Ecuaciones diferenciales:**
> 
> ```
> Solución y(t) es función del tiempo
> Dominio: intervalo de existencia
> Rango: valores físicamente posibles
> 
> dy/dt = ky, y(0) = y₀
> Solución: y(t) = y₀e^(kt)
> Dom(y) = ℝ o [0, T) según contexto
> ```
> 
> **Cálculo de variaciones:**
> 
> ```
> Funcionales: "funciones de funciones"
> J[y] = ∫ F(x, y, y') dx
> 
> Dominio: espacio de funciones admisibles
> Rango: ℝ (valores del funcional)
> ```
> 
> **Teoría de la medida:**
> 
> ```
> Funciones medibles: f: X → ℝ
> Dominio: espacio medible
> Restricciones: f^(-1)(B) medible para todo Borel B
> ```
> 
> **Variable compleja:**
> 
> ```
> f: ℂ → ℂ
> Dominio: región del plano complejo
> Rango: imagen en ℂ
> 
> Ejemplo: f(z) = 1/z
> Dom(f) = ℂ \ {0}
> Ran(f) = ℂ \ {0}
> ```

## 🎓 Conexión con Conceptos Futuros

> [!tip]- Preparación para Temas Avanzados
> 
> **Límites:**
> 
> ```
> lim(x→a) f(x) requiere a ∈ Dom(f) o en la frontera
> 
> Comportamiento cerca de puntos no en dominio
> determina asíntotas
> ```
> 
> **Continuidad:**
> 
> ```
> f continua en a ⟺ lim(x→a) f(x) = f(a)
> 
> Requiere a ∈ Dom(f)
> Continuidad en todo el dominio
> ```
> 
> **Derivabilidad:**
> 
> ```
> f'(a) requiere f definida en vecindad de a
> a ∈ interior de Dom(f)
> 
> Función derivada: Dom(f') ⊆ Dom(f)
> ```
> 
> **Integrabilidad:**
> 
> ```
> ∫ₐᵇ f(x) dx requiere [a,b] ⊆ Dom(f)
> 
> Funciones con discontinuidades:
> integrables Riemann vs Lebesgue
> ```
> 
> **Series de funciones:**
> 
> ```
> Σ fₙ(x) converge en región del dominio
> 
> Dominio de convergencia de series de potencias:
> Radio e intervalo de convergencia
> ```
