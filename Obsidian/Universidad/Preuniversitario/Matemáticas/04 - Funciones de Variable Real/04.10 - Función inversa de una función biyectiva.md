# Función Inversa de una Función Biyectiva

## Introducción

> [!info]- Visión General **La función inversa es aquella que "deshace" o "revierte" el efecto de una función original. Para que exista, la función debe ser biyectiva, es decir, cada elemento del codominio debe corresponder a exactamente un elemento del dominio.**
> 
> **Conceptos fundamentales:**
> 
> - **Función inversa:** Revierte la correspondencia original
> - **Biyectividad:** Condición necesaria y suficiente para existencia
> - **Notación:** f⁻¹ (no confundir con 1/f)
> - **Propiedad característica:** f⁻¹(f(x)) = x y f(f⁻¹(y)) = y
> - **Gráfica:** Reflexión respecto a la recta y = x

### Contexto Histórico

> [!note]- Desarrollo del Concepto
> 
> **Orígenes (siglo XVII):**
> 
> - **Leibniz:** Primeras ideas de funciones inversas
> - **Notación:** Uso inicial de exponente -1
> 
> **Formalización (siglo XIX):**
> 
> - **Dirichlet:** Definición moderna de función
> - **Concepto de biyección:** Requisito para invertibilidad
> 
> **Siglo XX:**
> 
> - **Teoría de conjuntos:** Formalización rigurosa
> - **Álgebra abstracta:** Inversos en estructuras generales

## Funciones Inyectivas, Sobreyectivas y Biyectivas

> [!success]- Clasificación Fundamental
> 
> **Función Inyectiva (uno a uno):**
> 
> ```
> Definición: f es inyectiva si:
> f(x₁) = f(x₂) ⟹ x₁ = x₂
> 
> Equivalentemente:
> x₁ ≠ x₂ ⟹ f(x₁) ≠ f(x₂)
> 
> Interpretación:
> - Elementos diferentes tienen imágenes diferentes
> - No hay dos flechas que lleguen al mismo punto
> - Test de la línea horizontal: cada horizontal corta ≤ 1 vez
> 
> Ejemplos:
> ✓ f(x) = 2x + 3 (inyectiva en ℝ)
> ✓ f(x) = x³ (inyectiva en ℝ)
> ✓ f(x) = eˣ (inyectiva en ℝ)
> ✗ f(x) = x² (NO inyectiva en ℝ, pues f(-2) = f(2) = 4)
> ✗ f(x) = sin(x) (NO inyectiva en ℝ, periódica)
> ```
> 
> **Función Sobreyectiva (onto):**
> 
> ```
> Definición: f: A → B es sobreyectiva si:
> Para todo y ∈ B, existe x ∈ A tal que f(x) = y
> 
> Equivalentemente:
> Ran(f) = B (codominio)
> 
> Interpretación:
> - Todos los elementos de B son alcanzados
> - No hay elementos "huérfanos" en el codominio
> 
> Ejemplos:
> ✓ f: ℝ → ℝ, f(x) = 2x + 3 (sobreyectiva)
> ✓ f: ℝ → ℝ, f(x) = x³ (sobreyectiva)
> ✗ f: ℝ → ℝ, f(x) = x² (NO sobreyectiva, Ran = [0,+∞) ≠ ℝ)
> ✓ f: ℝ → [0,+∞), f(x) = x² (sobreyectiva con codominio ajustado)
> ✗ f: ℝ → ℝ, f(x) = eˣ (NO sobreyectiva, Ran = (0,+∞) ≠ ℝ)
> ```
> 
> **Función Biyectiva:**
> 
> ```
> Definición: f es biyectiva si es inyectiva Y sobreyectiva
> 
> Equivalentemente:
> - Para todo y ∈ B, existe EXACTAMENTE UN x ∈ A tal que f(x) = y
> - Correspondencia uno a uno entre A y B
> 
> Condición para inversa:
> f tiene inversa ⟺ f es biyectiva
> 
> Ejemplos:
> ✓ f: ℝ → ℝ, f(x) = 2x + 3 (biyectiva)
> ✓ f: ℝ → ℝ, f(x) = x³ (biyectiva)
> ✓ f: [0,+∞) → [0,+∞), f(x) = x² (biyectiva con dominio restringido)
> ✗ f: ℝ → ℝ, f(x) = x² (NO biyectiva)
> ✗ f: ℝ → ℝ, f(x) = sin(x) (NO biyectiva)
> ```

> [!tip]- Tests de Inyectividad y Sobreyectividad
> 
> **Test de línea horizontal (inyectividad):**
> 
> ```
> f es inyectiva ⟺ toda línea horizontal corta la gráfica 
>                  a lo sumo una vez
> 
> Aplicar:
> 1. Dibujar gráfica de f
> 2. Imaginar líneas horizontales y = c
> 3. Si alguna corta más de una vez → NO inyectiva
> 
> Ejemplo:
> f(x) = x²: la línea y = 4 corta en x = -2 y x = 2
> ⟹ NO inyectiva
> ```
> 
> **Test algebraico (inyectividad):**
> 
> ```
> Método directo:
> Suponer f(x₁) = f(x₂) y demostrar x₁ = x₂
> 
> Ejemplo:
> f(x) = 3x - 5
> 
> Suponer: f(x₁) = f(x₂)
> 3x₁ - 5 = 3x₂ - 5
> 3x₁ = 3x₂
> x₁ = x₂ ✓
> 
> ⟹ f es inyectiva
> ```
> 
> **Test del rango (sobreyectividad):**
> 
> ```
> Para f: A → B sobreyectiva:
> Verificar que Ran(f) = B
> 
> Método:
> 4. Calcular Ran(f)
> 5. Comparar con codominio B
> 6. Si Ran(f) = B ⟹ sobreyectiva
> 
> Ejemplo:
> f: ℝ → ℝ, f(x) = x³
> Ran(f) = ℝ (todo real es cubo de otro real)
> ⟹ f es sobreyectiva
> ```

## Definición de Función Inversa

> [!success]- Concepto y Notación
> 
> **Definición:**
> 
> ```
> Sea f: A → B una función biyectiva.
> La función inversa f⁻¹: B → A se define como:
> 
> f⁻¹(y) = x ⟺ f(x) = y
> 
> En palabras:
> f⁻¹ asigna a cada y ∈ B el único x ∈ A tal que f(x) = y
> 
> Notación:
> - f⁻¹ se lee "f inversa"
> - NO confundir con 1/f(x) (recíproco)
> - (f⁻¹)⁻¹ = f (la inversa de la inversa es la original)
> ```
> 
> **Propiedad característica:**
> 
> ```
> Para f: A → B biyectiva con inversa f⁻¹: B → A:
> 
> 1) f⁻¹(f(x)) = x  para todo x ∈ A
> 2) f(f⁻¹(y)) = y  para todo y ∈ B
> 
> Equivalentemente:
> (f⁻¹ ∘ f)(x) = id_A(x) = x
> (f ∘ f⁻¹)(y) = id_B(y) = y
> 
> Verificación:
> Si f(x) = y, entonces:
> - f⁻¹(y) = x por definición
> - f⁻¹(f(x)) = f⁻¹(y) = x ✓
> - f(f⁻¹(y)) = f(x) = y ✓
> ```
> 
> **Existencia y unicidad:**
> 
> ```
> Teorema:
> f: A → B tiene inversa ⟺ f es biyectiva
> 
> Si existe, la inversa es única
> 
> Demostración de unicidad:
> Suponer que g y h son inversas de f
> Para todo y ∈ B:
> g(y) = g(f(h(y)))  [porque f(h(y)) = y]
>      = (g∘f)(h(y))
>      = id(h(y))     [porque g es inversa de f]
>      = h(y)
> 
> Por tanto g = h
> ```

## Dominio y Rango de la Inversa

> [!success]- Intercambio de Dominio y Rango
> 
> **Relación fundamental:**
> 
> ```
> Si f: A → B es biyectiva, entonces f⁻¹: B → A
> 
> Dom(f⁻¹) = Ran(f) = B
> Ran(f⁻¹) = Dom(f) = A
> 
> Interpretación:
> - Lo que entra a f⁻¹ es lo que sale de f
> - Lo que sale de f⁻¹ es lo que entra a f
> - Los papeles se invierten completamente
> ```
> 
> **Ejemplos:**
> 
> ```
> Ejemplo 1:
> f(x) = 2x + 3
> Dom(f) = ℝ, Ran(f) = ℝ
> 
> f⁻¹(y) = (y - 3)/2
> Dom(f⁻¹) = ℝ, Ran(f⁻¹) = ℝ
> 
> Verificación:
> Dom(f⁻¹) = Ran(f) = ℝ ✓
> Ran(f⁻¹) = Dom(f) = ℝ ✓
> 
> Ejemplo 2:
> f: [0,+∞) → [0,+∞), f(x) = x²
> Dom(f) = [0,+∞), Ran(f) = [0,+∞)
> 
> f⁻¹(y) = √y
> Dom(f⁻¹) = [0,+∞), Ran(f⁻¹) = [0,+∞)
> 
> Verificación:
> Dom(f⁻¹) = Ran(f) = [0,+∞) ✓
> Ran(f⁻¹) = Dom(f) = [0,+∞) ✓
> ```

## Método para Encontrar la Función Inversa

> [!tip]- Procedimiento Paso a Paso
> 
> **Algoritmo general:**
> 
> ```
> Para encontrar f⁻¹ dada f:
> 
> PASO 1: Verificar que f es biyectiva
>         (Si no lo es, no existe inversa)
> 
> PASO 2: Escribir y = f(x)
> 
> PASO 3: Despejar x en términos de y
>         x = expresión en y
> 
> PASO 4: Intercambiar variables
>         f⁻¹(y) = expresión en y
>         o equivalentemente:
>         f⁻¹(x) = expresión en x
> 
> PASO 5: Verificar:
>         (f⁻¹ ∘ f)(x) = x
>         (f ∘ f⁻¹)(x) = x
> ```
> 
> **Ejemplos detallados:**
> 
> ```
> Ejemplo 1: Función lineal
> f(x) = 3x - 5
> 
> PASO 1: f es lineal con pendiente ≠ 0 ⟹ biyectiva ✓
> 
> PASO 2: y = 3x - 5
> 
> PASO 3: Despejar x
>         y + 5 = 3x
>         x = (y + 5)/3
> 
> PASO 4: f⁻¹(x) = (x + 5)/3
> 
> PASO 5: Verificar
>         (f⁻¹∘f)(x) = f⁻¹(3x - 5)
>                    = ((3x - 5) + 5)/3
>                    = 3x/3 = x ✓
>         
>         (f∘f⁻¹)(x) = f((x + 5)/3)
>                    = 3((x + 5)/3) - 5
>                    = x + 5 - 5 = x ✓
> 
> Ejemplo 2: Función racional
> f(x) = (2x + 1)/(x - 3), x ≠ 3
> 
> PASO 1: Verificar biyectividad (omitimos detalles)
> 
> PASO 2: y = (2x + 1)/(x - 3)
> 
> PASO 3: Despejar x
>         y(x - 3) = 2x + 1
>         yx - 3y = 2x + 1
>         yx - 2x = 3y + 1
>         x(y - 2) = 3y + 1
>         x = (3y + 1)/(y - 2)
> 
> PASO 4: f⁻¹(x) = (3x + 1)/(x - 2), x ≠ 2
> 
> PASO 5: Verificar (ejercicio)
> 
> Ejemplo 3: Función exponencial
> f(x) = eˣ, Dom(f) = ℝ, Ran(f) = (0,+∞)
> 
> PASO 1: Exponencial es estrictamente creciente ⟹ biyectiva ✓
> 
> PASO 2: y = eˣ
> 
> PASO 3: Despejar x (usar logaritmo)
>         ln(y) = ln(eˣ) = x
>         x = ln(y)
> 
> PASO 4: f⁻¹(x) = ln(x)
> 
> Dom(f⁻¹) = (0,+∞) = Ran(f) ✓
> Ran(f⁻¹) = ℝ = Dom(f) ✓
> 
> PASO 5: Verificar
>         (f⁻¹∘f)(x) = ln(eˣ) = x ✓
>         (f∘f⁻¹)(x) = e^(ln(x)) = x ✓
> ```

## Propiedades de la Función Inversa

> [!success]- Propiedades Fundamentales
> 
> **Propiedad 1: Composición con identidad**
> 
> ```
> f⁻¹ ∘ f = id_Dom(f)
> f ∘ f⁻¹ = id_Ran(f)
> 
> Es decir:
> (f⁻¹ ∘ f)(x) = x para todo x ∈ Dom(f)
> (f ∘ f⁻¹)(y) = y para todo y ∈ Ran(f)
> ```
> 
> **Propiedad 2: Inversa de la inversa**
> 
> ```
> (f⁻¹)⁻¹ = f
> 
> La inversa de la inversa es la función original
> ```
> 
> **Propiedad 3: Inversa de composición**
> 
> ```
> Si f: A → B y g: B → C son biyectivas, entonces:
> 
> (g ∘ f)⁻¹ = f⁻¹ ∘ g⁻¹
> 
> (El orden se invierte)
> 
> Demostración:
> ((f⁻¹∘g⁻¹)∘(g∘f))(x) = (f⁻¹∘(g⁻¹∘g)∘f)(x)
>                        = (f⁻¹∘id∘f)(x)
>                        = (f⁻¹∘f)(x)
>                        = x
> ```
> 
> **Propiedad 4: Monotonía**
> 
> ```
> Si f es estrictamente creciente, entonces f⁻¹ es estrictamente creciente
> Si f es estrictamente decreciente, entonces f⁻¹ es estrictamente decreciente
> 
> Intuición:
> El orden se preserva o invierte consistentemente
> ```
> 
> **Propiedad 5: Continuidad**
> 
> ```
> Si f: [a,b] → [c,d] es continua y biyectiva, entonces f⁻¹ es continua
> 
> (Consecuencia del teorema del valor intermedio)
> ```
> 
> **Propiedad 6: Derivada**
> 
> ```
> Si f es derivable y f'(x) ≠ 0, entonces f⁻¹ es derivable y:
> 
> (f⁻¹)'(y) = 1/f'(x)  donde y = f(x)
> 
> Equivalentemente:
> (f⁻¹)'(f(x)) = 1/f'(x)
> 
> Fórmula de la cadena inversa
> ```

## Gráfica de la Función Inversa

> [!tip]- Interpretación Geométrica
> 
> **Relación entre gráficas:**
> 
> ```
> La gráfica de f⁻¹ es la reflexión de la gráfica de f
> respecto a la recta y = x
> 
> Razón:
> Si (a, b) está en la gráfica de f  [es decir, f(a) = b]
> Entonces (b, a) está en la gráfica de f⁻¹  [es decir, f⁻¹(b) = a]
> 
> El punto (b, a) es el reflejo de (a, b) respecto a y = x
> ```
> 
> **Método gráfico para obtener f⁻¹:**
> 
> ```
> 1. Dibujar gráfica de y = f(x)
> 2. Dibujar la recta y = x (bisectriz del primer cuadrante)
> 3. Reflejar la gráfica de f respecto a y = x
> 4. La imagen reflejada es la gráfica de y = f⁻¹(x)
> ```
> 
> **Ejemplos visuales:**
> 
> ```
> Ejemplo 1: f(x) = 2x
> Gráfica de f: recta que pasa por origen con pendiente 2
> Puntos: (0,0), (1,2), (2,4)
> 
> f⁻¹(x) = x/2
> Gráfica de f⁻¹: recta que pasa por origen con pendiente 1/2
> Puntos reflejados: (0,0), (2,1), (4,2)
> 
> Observación:
> La pendiente se invierte: 2 → 1/2
> 
> Ejemplo 2: f(x) = x², x ≥ 0
> Gráfica de f: parábola en cuadrante I
> 
> f⁻¹(x) = √x
> Gráfica de f⁻¹: medio superior de parábola rotada
> 
> Ambas se cruzan en (0,0) y (1,1)
> (puntos sobre la recta y = x)
> ```

## Restricción de Dominio para Obtener Inversa

> [!warning]- Funciones No Biyectivas
> 
> **Problema:**
> 
> ```
> Si f: A → B no es biyectiva, no tiene inversa
> 
> Solución:
> Restringir el dominio para hacerla biyectiva
> ```
> 
> **Procedimiento:**
> 
> ```
> 1. Identificar por qué f no es biyectiva
>    - ¿No inyectiva? (línea horizontal corta múltiples veces)
>    - ¿No sobreyectiva? (no cubre todo el codominio)
> 
> 2. Para no inyectiva:
>    Restringir dominio a región donde sea inyectiva
>    (generalmente donde sea monótona)
> 
> 3. Para no sobreyectiva:
>    Ajustar codominio a Ran(f)
> ```
> 
> **Ejemplos importantes:**
> 
> ```
> Ejemplo 1: f(x) = x²
> 
> Problema: f: ℝ → ℝ no es inyectiva
> f(-2) = f(2) = 4
> 
> Solución 1: Restringir a x ≥ 0
> f: [0,+∞) → [0,+∞), f(x) = x²
> Ahora es biyectiva
> f⁻¹(x) = √x
> 
> Solución 2: Restringir a x ≤ 0
> f: (-∞,0] → [0,+∞), f(x) = x²
> Ahora es biyectiva
> f⁻¹(x) = -√x
> 
> Ejemplo 2: f(x) = sin(x)
> 
> Problema: f: ℝ → [-1,1] no es inyectiva (periódica)
> 
> Solución estándar:
> f: [-π/2, π/2] → [-1,1], f(x) = sin(x)
> Ahora es biyectiva
> f⁻¹(x) = arcsin(x)
> 
> Dom(arcsin) = [-1,1]
> Ran(arcsin) = [-π/2, π/2]
> 
> Ejemplo 3: f(x) = cos(x)
> 
> Problema: no inyectiva en ℝ
> 
> Solución estándar:
> f: [0, π] → [-1,1], f(x) = cos(x)
> f⁻¹(x) = arccos(x)
> 
> Dom(arccos) = [-1,1]
> Ran(arccos) = [0, π]
> ```

## Funciones Inversas Importantes

> [!note]- Pares de Funciones Inversas Comunes
> 
> **Funciones lineales:**
> 
> ```
> f(x) = mx + b, m ≠ 0
> f⁻¹(x) = (x - b)/m
> 
> Dom(f) = Dom(f⁻¹) = ℝ
> Ran(f) = Ran(f⁻¹) = ℝ
> ```
> 
> **Potencias y raíces:**
> 
> ```
> f(x) = x^n, n impar
> f⁻¹(x) = ⁿ√x
> Dom = Ran = ℝ
> 
> f: [0,+∞) → [0,+∞), f(x) = x^n, n par
> f⁻¹(x) = ⁿ√x
> Dom = Ran = [0,+∞)
> ```
> 
> **Exponencial y logaritmo:**
> 
> ```
> f(x) = eˣ, Dom = ℝ, Ran = (0,+∞)
> f⁻¹(x) = ln(x), Dom = (0,+∞), Ran = ℝ
> 
> f(x) = aˣ, a > 0, a ≠ 1
> f⁻¹(x) = log_a(x)
> ```
> 
> **Trigonométricas e inversas:**
> 
> ```
> sin: [-π/2, π/2] → [-1,1]
> arcsin: [-1,1] → [-π/2, π/2]
> 
> cos: [0, π] → [-1,1]
> arccos: [-1,1] → [0, π]
> 
> tan: (-π/2, π/2) → ℝ
> arctan: ℝ → (-π/2, π/2)
> ```
> 
> **Hiperbólicas e inversas:**
> 
> ```
> sinh(x) = (eˣ - e⁻ˣ)/2, Dom = ℝ, Ran = ℝ
> arcsinh(x) = ln(x + √(x² + 1))
> 
> cosh: [0,+∞) → [1,+∞), cosh(x) = (eˣ + e⁻ˣ)/2
> arccosh: [1,+∞) → [0,+∞)
> 
> tanh(x) = (eˣ - e⁻ˣ)/(eˣ + e⁻ˣ), Dom = ℝ, Ran = (-1,1)
> arctanh: (-1,1) → ℝ
> ```

## Ejemplos Resueltos

> [!example]- Problemas Detallados
> 
> **Ejemplo 1: Encontrar y verificar inversa**
> 
> ```
> f(x) = (3x - 2)/(x + 1), x ≠ -1
> 
> Solución:
> 
> Paso 1: y = (3x - 2)/(x + 1)
> 
> Paso 2: Despejar x
> y(x + 1) = 3x - 2
> yx + y = 3x - 2
> yx - 3x = -y - 2
> x(y - 3) = -y - 2
> x = -(y + 2)/(y - 3)
> x = (-y - 2)/(y - 3)
> 
> Paso 3: f⁻¹(x) = (-x - 2)/(x - 3), x ≠ 3
> 
> Verificación:
> (f∘f⁻¹)(x) = f((-x-2)/(x-3))
>            = (3((-x-2)/(x-3)) - 2)/(((-x-2)/(x-3)) + 1)
>            = ((-3x-6)/(x-3) - 2)/(((-x-2+x-3))/(x-3))
>            = ((-3x-6-2x+6)/(x-3))/((-5)/(x-3))
>            = (-5x)/(x-3) · (x-3)/(-5)
>            = x ✓
> 
> Dom(f) = ℝ \ {-1}
> Ran(f) = ℝ \ {3}
> Dom(f⁻¹) = ℝ \ {3} = Ran(f) ✓
> Ran(f⁻¹) = ℝ \ {-1} = Dom(f) ✓
> ```
> 
> **Ejemplo 2: Restricción para obtener inversa**
> 
> ```
> f(x) = x² - 4x + 5
> 
> Análisis:
> Completar cuadrado:
> f(x) = (x - 2)² + 1
> 
> Vértice en (2, 1)
> Abre hacia arriba
> No es inyectiva en ℝ
> 
> Solución:
> Restringir a x ≥ 2 (rama derecha)
> f: [2, +∞) → [1, +∞), f(x) = (x-2)² + 1
> 
> Encontrar inversa:
> y = (x - 2)² + 1
> y - 1 = (x - 2)²
> √(y - 1) = x - 2  (tomamos raíz positiva, x ≥ 2)
> x = 2 + √(y - 1)
> 
> f⁻¹(x) = 2 + √(x - 1)
> 
> Dom(f⁻¹) = [1, +∞)
> Ran(f⁻¹) = [2, +∞)
> 
> Verificación:
> (f∘f⁻¹)(x) = f(2 + √(x-1))
>            = (2 + √(x-1) - 2)² + 1
>            = (√(x-1))² + 1
>            = x - 1 + 1 = x ✓
> ```

## Errores Comunes

> [!warning]- Confusiones Frecuentes
> 
> **1. f⁻¹(x) ≠ 1/f(x)**
> 
> ```
> ✗ INCORRECTO: f⁻¹(x) significa 1/f(x)
> 
> ✓ CORRECTO: f⁻¹(x) es la función inversa
>            1/f(x) es el recíproco, se denota [f(x)]⁻¹
> 
> Ejemplo:
> f(x) = 2x
> 
> f⁻¹(x) = x/2 (función inversa)
> 1/f(x) = 1/(2x) (recíproco)
> 
> Estos son diferentes!
> ```
> 
> **2. "Toda función tiene inversa"**
> 
> ```
> ✗ INCORRECTO
> 
> ✓ CORRECTO: Solo funciones biyectivas tienen inversa
> 
> Contraejemplo:
> f(x) = x², Dom = ℝ
> No es inyectiva: f(-2) = f(2) = 4
> No tiene inversa en ℝ
> ```
> 
> **3. "Para encontrar f⁻¹, solo despejar x"**
> 
> ```
> ✗ INCORRECTO (incompleto)
> 
> ✓ CORRECTO:
> 1. Verificar que f es biyectiva
> 2. Despejar x en términos de y
> 3. Intercambiar variables
> 4. Verificar dominio y rango
> 5. Comprobar composición
> 
> El despeje solo es un paso del proceso
> ```
> 
> **4. "Dom(f⁻¹) = Dom(f)"**
> 
> ```
> ✗ INCORRECTO
> 
> ✓ CORRECTO: Dom(f⁻¹) = Ran(f)
>            Ran(f⁻¹) = Dom(f)
> 
> Los dominios se intercambian con los rangos
> ```
> 
> **5. Olvidar restricciones al invertir**
> 
> ```
> f(x) = √x tiene Dom = [0, +∞)
> 
> Encontrar inversa:
> y = √x
> x = y²
> 
> ✗ INCORRECTO: f⁻¹(x) = x² con Dom = ℝ
> 
> ✓ CORRECTO: f⁻¹(x) = x² con Dom = [0, +∞)
> 
> Debe cumplir: Dom(f⁻¹) = Ran(f) = [0, +∞)
> ```
> 
> **6. "(f∘g)⁻¹ = f⁻¹∘g⁻¹"**
> 
> ```
> ✗ INCORRECTO (orden equivocado)
> 
> ✓ CORRECTO: (f∘g)⁻¹ = g⁻¹∘f⁻¹
> 
> El orden se invierte
> ```
> 
> **7. "Si f es par/impar, f⁻¹ es par/impar"**
> 
> ```
> ✗ INCORRECTO en general
> 
> Si f(x) = x³ (función impar)
> f⁻¹(x) = ³√x (también impar) ✓
> 
> Pero si f par, f NO es inyectiva en todo ℝ
> (excepto función constante)
> No puede tener inversa sin restricción
> ```

## Aplicaciones

> [!example]- Contextos Prácticos
> 
> **Conversión de unidades:**
> 
> ```
> Celsius a Fahrenheit:
> F(C) = (9/5)C + 32
> 
> Fahrenheit a Celsius (inversa):
> C(F) = (5/9)(F - 32)
> 
> Verificar:
> C(F(20)) = C(68) = (5/9)(68-32) = (5/9)(36) = 20 ✓
> ```
> 
> **Economía - Función de demanda:**
> 
> ```
> Precio en función de cantidad:
> p(q) = 100 - 2q
> 
> Cantidad en función de precio (inversa):
> q(p) = (100 - p)/2 = 50 - p/2
> 
> Interpretación:
> - p(q): ¿qué precio debo poner para vender q unidades?
> - q(p): ¿cuánto venderé si pongo precio p?
> ```
> 
> **Codificación y decodificación:**
> 
> ```
> Función de codificación (cifrado):
> E(x) = (3x + 7) mod 26
> 
> Función de decodificación (inversa):
> D(y) = 9(y - 7) mod 26
> 
> (Los inversos modulares permiten decodificar)
> ```

> |**Inversa**|(f⁻¹)⁻¹ = f|La inversa de f⁻¹ es f|

> |**Monotonía**|Creciente|Creciente|
> |**Monotonía**|Decreciente|Decreciente|
> |**Inyectividad**|Debe ser inyectiva|Siempre inyectiva|
> |**Sobreyectividad**|Debe ser sobreyectiva|Siempre sobreyectiva|

## Conceptos Clave para Recordar

> [!important]- Resumen Ejecutivo
> 
> **Existencia de inversa:**
> 
> - f tiene inversa ⟺ f es biyectiva (inyectiva Y sobreyectiva)
> - Test de línea horizontal para verificar inyectividad
> - Verificar que Ran(f) = Codominio para sobreyectividad
> 
> **Definición y notación:**
> 
> - f⁻¹(y) = x ⟺ f(x) = y
> - f⁻¹ NO significa 1/f(x) (eso es el recíproco)
> - Propiedad característica: f⁻¹(f(x)) = x y f(f⁻¹(y)) = y
> 
> **Dominio y rango:**
> 
> - Dom(f⁻¹) = Ran(f)
> - Ran(f⁻¹) = Dom(f)
> - Los papeles se intercambian completamente
> 
> **Método para encontrar f⁻¹:**
> 
> 1. Verificar biyectividad
> 2. Escribir y = f(x)
> 3. Despejar x en términos de y
> 4. Intercambiar variables
> 5. Verificar composiciones
> 
> **Propiedades importantes:**
> 
> - (f⁻¹)⁻¹ = f
> - (g∘f)⁻¹ = f⁻¹∘g⁻¹ (orden invertido)
> - Gráfica de f⁻¹ es reflexión de f sobre y = x
> - Si f es continua y biyectiva, f⁻¹ es continua
> - (f⁻¹)'(y) = 1/f'(x) donde y = f(x)
> 
> **Restricción de dominio:**
> 
> - Si f no es biyectiva, restringir dominio donde sea inyectiva
> - Generalmente elegir región donde f es monótona
> - Ajustar codominio al rango efectivo
