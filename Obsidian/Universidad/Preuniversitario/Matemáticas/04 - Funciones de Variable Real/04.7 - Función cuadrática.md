# 📚 Función Cuadrática

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva
> **Una función cuadrática es una función polinomial de grado 2, cuya forma general es f(x) = ax² + bx + c, donde a, b, c ∈ ℝ y a ≠ 0. Su gráfica es una parábola, una curva simétrica que puede abrir hacia arriba o hacia abajo.**
>
> **Características distintivas:**
> - **Grado:** 2 (el exponente más alto de x es 2)
> - **Gráfica:** Parábola (curva en forma de U o ∩)
> - **Simetría:** Eje vertical de simetría
> - **Punto extremo:** Vértice (máximo o mínimo)
> - **Tasa de cambio:** Variable (no constante como en lineales)

### 📖 Contexto Histórico

> [!note]- Desarrollo Histórico de las Funciones Cuadráticas
>
> **Mesopotamia (2000-1600 a.C.):**
> - **Tablillas babilónicas:** Primeros problemas cuadráticos
>   - Método de completar el cuadrado (sin notación algebraica)
>   - Problemas geométricos: áreas de terrenos
>   - Solución de ecuaciones cuadráticas específicas
> - **Tablilla YBC 7289:** Aproximación de √2 relacionada con cuadráticas
>
> **Grecia Antigua (600-300 a.C.):**
> - **Pitágoras (580-500 a.C.):** Relaciones cuadráticas en geometría
> - **Euclides (300 a.C.):** _Elementos_ Libro II
>   - Interpretación geométrica de identidades cuadráticas
>   - (a + b)² = a² + 2ab + b² como áreas
> - **Apolonio (262-190 a.C.):** _Cónicas_
>   - Primera clasificación sistemática de parábolas
>   - Secciones cónicas: cortes de conos
>   - Propiedades geométricas de la parábola
>
> **India Medieval (500-1200):**
> - **Brahmagupta (628):** _Brahmasphutasiddhanta_
>   - Fórmula general para ecuaciones cuadráticas
>   - Soluciones positivas y negativas
>   - Trabajo con números negativos
> - **Bhaskara II (1150):** _Bijaganita_
>   - Refinamiento de métodos algebraicos
>   - Chakravala (método cíclico)
>
> **Mundo Islámico (800-1200):**
> - **Al-Khwarizmi (830):** _Al-Kitab al-Mukhtasar fi Hisab al-Jabr wal-Muqabala_
>   - Clasificación de ecuaciones cuadráticas (6 tipos)
>   - Métodos sistemáticos de solución
>   - Origen del término "álgebra"
> - **Omar Khayyam (1070):** Solución geométrica usando cónicas
>
> **Renacimiento Europeo (1500-1700):**
> - **François Viète (1591):** _In artem analyticem isagoge_
>   - Notación algebraica simbólica
>   - Relaciones entre coeficientes y raíces
> - **René Descartes (1637):** _La Géométrie_
>   - Unión de álgebra y geometría
>   - Coordenadas cartesianas
>   - Ecuaciones de curvas (incluyendo parábolas)
>   - **Revolución:** La parábola como gráfica de y = x²
>
> **Era del Cálculo (1700-1800):**
> - **Isaac Newton (1687):** _Principia Mathematica_
>   - Movimiento parabólico de proyectiles
>   - Leyes del movimiento: x = ½at²
> - **Leonhard Euler (1748):** _Introductio in analysin infinitorum_
>   - Forma canónica de funciones cuadráticas
>   - Estudio sistemático de parábolas
>   - Traslación y transformaciones
>
> **Siglo XIX - Abstracción (1800-1900):**
> - **Carl Friedrich Gauss (1801):** _Disquisitiones Arithmeticae_
>   - Formas cuadráticas
>   - Teoría de números y cuadráticas
> - **Augustin-Louis Cauchy (1821):** Análisis riguroso
>   - Estudio de máximos y mínimos usando cálculo
> - **Desarrollo de álgebra lineal:** Formas cuadráticas generales
>
> **Siglo XX - Aplicaciones (1900-presente):**
> - **Física cuántica:** Potenciales armónicos (V = kx²)
> - **Optimización:** Programación cuadrática
> - **Estadística:** Mínimos cuadrados (regresión)
> - **Computación:** Algoritmos de complejidad O(n²)
> - **Economía:** Funciones de costo, utilidad
> - **Ingeniería:** Diseño de antenas parabólicas, puentes

## 📐 Formas de la Función Cuadrática

> [!success]- Tres Formas Equivalentes
>
> ### A. Forma General (Estándar)
>
> **Definición:**
> ```
> f(x) = ax² + bx + c
> 
> donde:
> a, b, c ∈ ℝ
> a ≠ 0 (condición esencial)
> ```
>
> **Coeficientes y su significado:**
> ```
> a (coeficiente principal):
> - Determina dirección de apertura
> - Controla "ancho" de la parábola
> - Si a > 0: parábola abre hacia arriba (U)
> - Si a < 0: parábola abre hacia abajo (∩)
> - |a| grande: parábola "estrecha"
> - |a| pequeño: parábola "ancha"
>
> b (coeficiente lineal):
> - Afecta posición horizontal del vértice
> - Influye en inclinación inicial
>
> c (término independiente):
> - Intercepto con eje y
> - f(0) = c
> - Desplazamiento vertical desde origen
> ```
>
> **Ventajas:**
> - Fácil de expandir desde forma factorizada
> - Directa para evaluar f(x)
> - Sencilla para sumar/restar funciones cuadráticas
>
> **Desventajas:**
> - No muestra directamente el vértice
> - No revela raíces inmediatamente
>
> **Ejemplos:**
> ```
> f(x) = x² - 4x + 3
> - a = 1 (abre arriba)
> - b = -4
> - c = 3 (corta eje y en (0, 3))
>
> g(x) = -2x² + 5x - 1
> - a = -2 (abre abajo)
> - b = 5
> - c = -1
>
> h(x) = 3x²
> - a = 3, b = 0, c = 0
> - Vértice en origen
> ```
> 
> ### B. Forma Canónica (Vértice)
>
> **Definición:**
> ```
> f(x) = a(x - h)² + k
> 
> donde:
> (h, k) es el vértice de la parábola
> a ≠ 0
> ```
>
> **Interpretación geométrica:**
> ```
> h: coordenada x del vértice (desplazamiento horizontal)
> k: coordenada y del vértice (desplazamiento vertical)
> a: mismo significado que en forma general
>
> Eje de simetría: x = h
> Vértice: (h, k)
> - Si a > 0: k es el valor mínimo de f
> - Si a < 0: k es el valor máximo de f
> ```
>
> **Ventajas:**
> - Muestra directamente el vértice
> - Revela eje de simetría
> - Ideal para transformaciones geométricas
> - Fácil identificar valor extremo
>
> **Desventajas:**
> - Requiere completar el cuadrado desde forma general
> - Expandir a forma general requiere trabajo algebraico
>
> **Ejemplos:**
> ```
> f(x) = 2(x - 3)² + 1
> - Vértice: (3, 1)
> - Eje de simetría: x = 3
> - Mínimo: k = 1
> - Abre hacia arriba
>
> g(x) = -(x + 2)² + 5
> - Vértice: (-2, 5)
> - Eje de simetría: x = -2
> - Máximo: k = 5
> - Abre hacia abajo
>
> h(x) = 0.5(x - 1)²
> - Vértice: (1, 0)
> - Eje de simetría: x = 1
> - Mínimo: k = 0 (vértice en eje x)
> ```
> 
> ### C. Forma Factorizada (Raíces)
>
> **Definición:**
> ```
> f(x) = a(x - r₁)(x - r₂)
> 
> donde:
> r₁, r₂ son las raíces (ceros) de la función
> a ≠ 0
> ```
>
> **Interpretación:**
> ```
> r₁, r₂: valores donde f(x) = 0
> - Interceptos con eje x
> - Puntos donde la parábola cruza el eje horizontal
>
> Si r₁ = r₂: raíz doble (vértice en eje x)
> ```
>
> **Ventajas:**
> - Muestra raíces directamente
> - Fácil resolver f(x) = 0
> - Útil para factorizar
> - Directa para graficar interceptos
>
> **Desventajas:**
> - Solo existe si hay raíces reales
> - No aplicable si discriminante < 0
> - No muestra directamente el vértice
>
> **Relación entre raíces y vértice:**
> ```
> Eje de simetría: x = (r₁ + r₂)/2
> Coordenada x del vértice: h = (r₁ + r₂)/2
> ```
>
> **Ejemplos:**
> ```
> f(x) = (x - 2)(x - 5)
> - Raíces: x = 2, x = 5
> - Vértice x: h = (2 + 5)/2 = 3.5
> - a = 1 (abre arriba)
>
> g(x) = -2(x + 1)(x - 3)
> - Raíces: x = -1, x = 3
> - Vértice x: h = (-1 + 3)/2 = 1
> - a = -2 (abre abajo, estrecha)
>
> h(x) = 3(x - 4)²
> - Raíz doble: x = 4
> - Vértice: (4, 0)
> - Parábola tangente al eje x
> ```

## 🔄 Conversión entre Formas

> [!tip]- Cómo Convertir de una Forma a Otra
>
> ### General → Canónica (Completar el Cuadrado)
>
> **Método:**
> ```
> Dado: f(x) = ax² + bx + c
>
> Paso 1: Factorizar a del término cuadrático y lineal
> f(x) = a(x² + (b/a)x) + c
>
> Paso 2: Completar el cuadrado dentro del paréntesis
> Añadir y restar (b/2a)²
> f(x) = a[x² + (b/a)x + (b/2a)² - (b/2a)²] + c
>
> Paso 3: Agrupar el cuadrado perfecto
> f(x) = a[(x + b/2a)² - (b/2a)²] + c
>
> Paso 4: Distribuir a y simplificar
> f(x) = a(x + b/2a)² - a(b/2a)² + c
> f(x) = a(x + b/2a)² + [c - b²/4a]
>
> Resultado:
> h = -b/2a
> k = c - b²/4a = (4ac - b²)/4a
>
> f(x) = a(x - h)² + k
> ```
>
> **Ejemplo:**
> ```
> f(x) = 2x² - 8x + 3
>
> Paso 1: f(x) = 2(x² - 4x) + 3
> Paso 2: Completar cuadrado: (4/2)² = 4
>          f(x) = 2(x² - 4x + 4 - 4) + 3
> Paso 3: f(x) = 2[(x - 2)² - 4] + 3
> Paso 4: f(x) = 2(x - 2)² - 8 + 3
>          f(x) = 2(x - 2)² - 5
>
> Vértice: (2, -5)
> ```
> 
> ### Canónica → General (Expandir)
>
> **Método:**
> ```
> Dado: f(x) = a(x - h)² + k
>
> Paso 1: Expandir (x - h)²
> (x - h)² = x² - 2hx + h²
>
> Paso 2: Multiplicar por a
> a(x - h)² = ax² - 2ahx + ah²
>
> Paso 3: Sumar k
> f(x) = ax² - 2ahx + ah² + k
>
> Resultado:
> a = a
> b = -2ah
> c = ah² + k
> ```
>
> **Ejemplo:**
> ```
> f(x) = 3(x - 1)² + 2
>
> Paso 1: (x - 1)² = x² - 2x + 1
> Paso 2: 3(x - 1)² = 3x² - 6x + 3
> Paso 3: f(x) = 3x² - 6x + 3 + 2
>
> f(x) = 3x² - 6x + 5
> ```
> 
> ### Factorizada → General (Expandir)
>
> **Método:**
> ```
> Dado: f(x) = a(x - r₁)(x - r₂)
>
> Paso 1: Expandir (x - r₁)(x - r₂)
> (x - r₁)(x - r₂) = x² - (r₁ + r₂)x + r₁r₂
>
> Paso 2: Multiplicar por a
> f(x) = a[x² - (r₁ + r₂)x + r₁r₂]
> f(x) = ax² - a(r₁ + r₂)x + ar₁r₂
>
> Resultado:
> a = a
> b = -a(r₁ + r₂)
> c = ar₁r₂
> ```
>
> **Ejemplo:**
> ```
> f(x) = 2(x - 3)(x + 1)
>
> Paso 1: (x - 3)(x + 1) = x² - 2x - 3
> Paso 2: f(x) = 2(x² - 2x - 3)
>
> f(x) = 2x² - 4x - 6
> ```
> 
> ### General → Factorizada (Fórmula General)
>
> **Método:**
> ```
> Dado: f(x) = ax² + bx + c
>
> Paso 1: Encontrar raíces con fórmula general
> x = [-b ± √(b² - 4ac)] / 2a
>
> r₁ = [-b + √(b² - 4ac)] / 2a
> r₂ = [-b - √(b² - 4ac)] / 2a
>
> Paso 2: Escribir forma factorizada
> f(x) = a(x - r₁)(x - r₂)
>
> Nota: Solo posible si b² - 4ac ≥ 0
> ```
>
> **Ejemplo:**
> ```
> f(x) = x² - 5x + 6
>
> Paso 1: Discriminante: Δ = 25 - 24 = 1
>         r₁ = [5 + 1]/2 = 3
>         r₂ = [5 - 1]/2 = 2
>
> Paso 2: f(x) = (x - 3)(x - 2)
> ```

## 📊 Elementos Clave de la Parábola

> [!example]- Componentes Geométricos
>
> ### A. Vértice
>
> **Definición:**
> ```
> El vértice es el punto extremo de la parábola
> - Punto más alto si a < 0 (máximo)
> - Punto más bajo si a > 0 (mínimo)
> ```
>
> **Coordenadas del vértice:**
> ```
> Desde forma general f(x) = ax² + bx + c:
>
> h = -b/(2a)
> k = f(h) = f(-b/2a) = c - b²/(4a)
>
> O equivalentemente:
> k = (4ac - b²)/(4a)
>
> Vértice: V = (h, k) = (-b/2a, 4ac - b²/4a)
> ```
>
> **Desde forma canónica:**
> ```
> f(x) = a(x - h)² + k
> Vértice: V = (h, k) [directo]
> ```
>
> **Desde forma factorizada:**
> ```
> f(x) = a(x - r₁)(x - r₂)
> h = (r₁ + r₂)/2
> k = f(h)
> ```
>
> **Interpretación:**
> ```
> - Punto de cambio de monotonía
> - Valor mínimo (si a > 0) o máximo (si a < 0)
> - Centro de simetría
> ```
> 
> ### B. Eje de Simetría
>
> **Definición:**
> ```
> Recta vertical que divide la parábola en dos mitades simétricas
> Ecuación: x = h
> ```
>
> **Cálculo:**
> ```
> Desde forma general:
> x = -b/(2a)
>
> Desde forma canónica:
> x = h
>
> Desde forma factorizada:
> x = (r₁ + r₂)/2
> ```
>
> **Propiedad de simetría:**
> ```
> Si (x₁, y) está en la parábola, entonces (2h - x₁, y) también
>
> Distancia del eje: |x - h|
> Puntos simétricos: (h - d, y) y (h + d, y)
> ```
> 
> ### C. Raíces (Ceros)
>
> **Definición:**
> ```
> Valores de x donde f(x) = 0
> Puntos donde la parábola cruza el eje x
> Interceptos con eje x
> ```
>
> **Fórmula General (Fórmula cuadrática):**
> ```
> Para ax² + bx + c = 0:
>
> x = [-b ± √(b² - 4ac)] / (2a)
>
> r₁ = [-b + √Δ] / (2a)
> r₂ = [-b - √Δ] / (2a)
>
> donde Δ = b² - 4ac es el discriminante
> ```
>
> **Discriminante y naturaleza de raíces:**
> ```
> Δ = b² - 4ac
>
> Δ > 0: Dos raíces reales distintas
> - La parábola cruza el eje x en dos puntos
> - Ejemplo: x² - 5x + 6 = 0 → Δ = 1 → x = 2, 3
>
> Δ = 0: Una raíz real doble (raíz repetida)
> - La parábola toca el eje x en un solo punto (vértice)
> - Ejemplo: x² - 4x + 4 = 0 → Δ = 0 → x = 2
>
> Δ < 0: No hay raíces reales (raíces complejas)
> - La parábola no cruza el eje x
> - Ejemplo: x² + x + 1 = 0 → Δ = -3 → sin raíces reales
> ```
>
> **Relaciones de Vieta:**
> ```
> Para f(x) = ax² + bx + c con raíces r₁ y r₂:
>
> Suma de raíces:    r₁ + r₂ = -b/a
> Producto de raíces: r₁ · r₂ = c/a
>
> Útil para verificar raíces y factorizar
> ```
>
> **Ejemplos:**
> ```
> f(x) = x² - 7x + 12
> Δ = 49 - 48 = 1 > 0 → dos raíces
> x = (7 ± 1)/2 → x = 4, x = 3
> Factorizada: f(x) = (x - 4)(x - 3)
>
> g(x) = x² - 6x + 9
> Δ = 36 - 36 = 0 → raíz doble
> x = 6/2 = 3
> Factorizada: g(x) = (x - 3)²
>
> h(x) = x² + 2x + 5
> Δ = 4 - 20 = -16 < 0 → sin raíces reales
> No factorizable en ℝ
> ```
> 
> ### D. Intercepto con Eje Y
>
> **Definición:**
> ```
> Punto donde la parábola cruza el eje y
> Ocurre cuando x = 0
> ```
>
> **Cálculo:**
> ```
> f(0) = a(0)² + b(0) + c = c
>
> Intercepto: (0, c)
> ```
>
> **Observación:**
> ```
> - Toda función cuadrática tiene exactamente un intercepto con eje y
> - Es el término independiente c en la forma general
> - Puede ser positivo, negativo o cero
> ```
>
> **Ejemplos:**
> ```
> f(x) = x² - 4x + 3 → intercepto (0, 3)
> g(x) = -2x² + 5x - 1 → intercepto (0, -1)
> h(x) = 3x² → intercepto (0, 0)
> ```
> 
> ### E. Concavidad
>
> **Definición:**
> ```
> Dirección hacia la cual la parábola "abre"
> Determinada por el signo de a
> ```
>
> **Tipos:**
> ```
> a > 0: Cóncava hacia arriba (convexa)
> - Forma de U
> - Vértice es mínimo
> - f(x) → +∞ cuando x → ±∞
> - Ejemplo: f(x) = x² + 2x + 1
>
> a < 0: Cóncava hacia abajo (cóncava)
> - Forma de ∩
> - Vértice es máximo
> - f(x) → -∞ cuando x → ±∞
> - Ejemplo: f(x) = -x² + 4x - 3
> ```
>
> **Relación con la derivada segunda:**
> ```
> f(x) = ax² + bx + c
> f'(x) = 2ax + b
> f''(x) = 2a
>
> f''(x) > 0 (a > 0): cóncava hacia arriba
> f''(x) < 0 (a < 0): cóncava hacia abajo
> ```
> 
> ### F. Ancho de la Parábola
>
> **Definición:**
> ```
> Qué tan "abierta" o "cerrada" es la parábola
> Controlado por |a|
> ```
>
> **Relación con |a|:**
> ```
> |a| > 1: Parábola "estrecha" (cerrada)
> - Crece/decrece rápidamente
> - Ejemplo: f(x) = 3x²
>
> |a| = 1: Parábola "estándar"
> - Referencia: f(x) = x²
>
> 0 < |a| < 1: Parábola "ancha" (abierta)
> - Crece/decrece lentamente
> - Ejemplo: f(x) = 0.25x²
> ```
>
> **Comparación visual:**
> ```
> f₁(x) = 0.25x²   (muy ancha)
> f₂(x) = 0.5x²    (ancha)
> f₃(x) = x²       (estándar)
> f₄(x) = 2x²      (estrecha)
> f₅(x) = 4x²      (muy estrecha)
>
> Todas pasan por (0, 0) pero con distinta apertura
> ```

## 📈 Propiedades de la Función Cuadrática

> [!success]- Características Algebraicas y Geométricas
>
> ### Dominio y Rango
>
> **Dominio:**
> ```
> Dom(f) = ℝ
>
> La función está definida para todo número real
> No hay restricciones en x
> ```
>
> **Rango:**
> ```
> Depende de a y del vértice (h, k):
>
> Si a > 0 (abre arriba):
> Ran(f) = [k, +∞)
> - Valor mínimo: k (en el vértice)
> - Sin límite superior
>
> Si a < 0 (abre abajo):
> Ran(f) = (-∞, k]
> - Valor máximo: k (en el vértice)
> - Sin límite inferior
> ```
>
> **Ejemplos:**
> ```
> f(x) = (x - 2)² + 3
> - a = 1 > 0
> - Vértice: (2, 3)
> - Dom = ℝ, Ran = [3, +∞)
>
> g(x) = -2(x + 1)² + 5
> - a = -2 < 0
> - Vértice: (-1, 5)
> - Dom = ℝ, Ran = (-∞, 5]
> ```
> 
> ### Continuidad y Derivabilidad
>
> **Continuidad:**
> ```
> Toda función cuadrática es continua en todo ℝ
>
> lim f(x) = f(c)  para todo c ∈ ℝ
> x→c
>
> No hay saltos, discontinuidades ni asíntotas
> ```
>
> **Derivabilidad:**
> ```
> Toda función cuadrática es derivable en todo ℝ
>
> f(x) = ax² + bx + c
> f'(x) = 2ax + b
>
> La derivada es una función lineal
> Tasa de cambio variable (no constante)
> ```
>
> **Derivada en el vértice:**
> ```
> En x = h = -b/(2a):
> f'(h) = 2a(-b/2a) + b = -b + b = 0
>
> El vértice es punto crítico (derivada cero)
> Tangente horizontal en el vértice
> ```
> 
> ### Monotonía (Crecimiento y Decrecimiento)
>
> **Para a > 0:**
> ```
> f(x) es decreciente en (-∞, h)
> f(x) es creciente en (h, +∞)
>
> Vértice h = -b/(2a) es punto mínimo
> ```
>
> **Para a < 0:**
> ```
> f(x) es creciente en (-∞, h)
> f(x) es decreciente en (h, +∞)
>
> Vértice h = -b/(2a) es punto máximo
> ```
>
> **Criterio de la derivada:**
> ```
> f'(x) = 2ax + b
>
> f'(x) = 0  ⟹  x = -b/(2a) = h
>
> Si a > 0:
> - f'(x) < 0 para x < h (decrece)
> - f'(x) > 0 para x > h (crece)
>
> Si a < 0:
> - f'(x) > 0 para x < h (crece)
> - f'(x) < 0 para x > h (decrece)
> ```
> 
> ### Simetría
>
> **Tipo:**
> ```
> Simetría axial respecto a x = h
> (No es par ni impar en general)
> ```
>
> **Propiedad:**
> ```
> f(h - d) = f(h + d)  para todo d ∈ ℝ
>
> Puntos equidistantes del eje tienen misma altura
> ```
>
> **Caso especial - Función par:**
> ```
> Si h = 0 (eje de simetría es x = 0):
> f(x) = ax² + c  (sin término lineal)
>
> f(-x) = a(-x)² + c = ax² + c = f(x)
>
> Ejemplo:
> 
> f(x) = 2x² + 3
> - Eje de simetría: x = 0 (eje y)
> - f(-x) = f(x) (función par)
> - Simétrica respecto al eje y
> ```
> 
> ### Inyectividad y Biyectividad
>
> **Inyectividad:**
> ```
> En general, NO es inyectiva en ℝ
>
> f(h - d) = f(h + d) para todo d ≠ 0
> Ejemplo: f(1) = f(3) si h = 2
>
> Falla el test de la línea horizontal
> ```
>
> **Restricción para hacerla inyectiva:**
> ```
> Restringir dominio a [h, +∞) o (-∞, h]
>
> f: [h, +∞) → Ran(f) es inyectiva
> O
> f: (-∞, h] → Ran(f) es inyectiva
> ```
>
> **Biyectividad:**
> ```
> Con restricción apropiada de dominio y codominio:
>
> Si a > 0:
> f: [h, +∞) → [k, +∞) es biyectiva
>
> Si a < 0:
> f: [h, +∞) → (-∞, k] es biyectiva
>
> Entonces existe función inversa
> ```
> 
> ### Paridad
>
> **En general:**
> ```
> Una función cuadrática general NO es par ni impar
> (Excepto casos especiales)
> ```
>
> **Caso par:**
> ```
> f(x) = ax² + c  (b = 0)
>
> f(-x) = a(-x)² + c = ax² + c = f(x)
>
> Eje de simetría: x = 0
> Vértice en eje y
>
> Ejemplo: f(x) = 3x² - 2
> ```
>
> **No puede ser impar:**
> ```
> Si f(x) = ax² + bx + c fuera impar:
> f(-x) = -f(x)
> ax² - bx + c = -ax² - bx - c
> 2ax² + 2c = 0 para todo x
>
> Esto requiere a = 0 y c = 0
> Pero a ≠ 0 para cuadrática
>
> Conclusión: No existe función cuadrática impar
> ```

## 🎯 Análisis Completo de una Parábola

> [!example]- Guía Paso a Paso
>
> **Dado:** f(x) = ax² + bx + c
>
> ### Paso 1: Identificar coeficientes
> ```
> a = ___ (determina apertura y ancho)
> b = ___ (afecta posición horizontal)
> c = ___ (intercepto y)
> ```
>
> ### Paso 2: Calcular vértice
> ```
> h = -b/(2a)
> k = f(h) = 4ac - b²/(4a)
>
> Vértice: V(h, k)
> ```
>
> ### Paso 3: Eje de simetría
> ```
> Ecuación: x = h
> ```
>
> ### Paso 4: Determinar concavidad
> ```
> Si a > 0: Abre hacia arriba (U)
>          Vértice es mínimo
>
> Si a < 0: Abre hacia abajo (∩)
>          Vértice es máximo
> ```
>
> ### Paso 5: Interceptos
> ```
> Intercepto y: (0, c)
>
> Interceptos x (raíces):
> Calcular Δ = b² - 4ac
>
> Si Δ > 0:
>   r₁ = (-b + √Δ)/(2a)
>   r₂ = (-b - √Δ)/(2a)
>   Interceptos: (r₁, 0) y (r₂, 0)
>
> Si Δ = 0:
>   r = -b/(2a) = h
>   Intercepto: (h, 0) [vértice en eje x]
>
> Si Δ < 0:
>   No hay interceptos x
> ```
>
> ### Paso 6: Dominio y rango
> ```
> Dom(f) = ℝ
>
> Si a > 0: Ran(f) = [k, +∞)
> Si a < 0: Ran(f) = (-∞, k]
> ```
>
> ### Paso 7: Intervalos de monotonía
> ```
> Si a > 0:
>   Decreciente: (-∞, h)
>   Creciente: (h, +∞)
>
> Si a < 0:
>   Creciente: (-∞, h)
>   Decreciente: (h, +∞)
> ```
>
> ### Paso 8: Forma canónica
> ```
> Completar cuadrado:
> f(x) = a(x - h)² + k
> ```
>
> ### Paso 9: Forma factorizada (si existe)
> ```
> Si Δ ≥ 0:
> f(x) = a(x - r₁)(x - r₂)
> ```
>
> ### Paso 10: Puntos adicionales
> ```
> Evaluar f(x) para valores convenientes
> Usar simetría para obtener más puntos
> ```

## 📊 Ejemplo Completo de Análisis

> [!note]- Análisis Detallado
>
> **Dada:** f(x) = -2x² + 8x - 6
>
> ### Solución:
>
> **Paso 1: Coeficientes**
> ```
> a = -2
> b = 8
> c = -6
> ```
>
> **Paso 2: Vértice**
> ```
> h = -b/(2a) = -8/(2(-2)) = -8/(-4) = 2
>
> k = f(2) = -2(2)² + 8(2) - 6
>   = -2(4) + 16 - 6
>   = -8 + 16 - 6
>   = 2
>
> Vértice: V(2, 2)
> ```
>
> **Paso 3: Eje de simetría**
> ```
> x = 2
> ```
>
> **Paso 4: Concavidad**
> ```
> a = -2 < 0
> Abre hacia abajo (∩)
> Vértice es punto máximo
> Valor máximo: f(2) = 2
> ```
>
> **Paso 5: Interceptos**
> ```
> Intercepto y:
> f(0) = -6
> Punto: (0, -6)
>
> Interceptos x:
> Δ = b² - 4ac = 64 - 4(-2)(-6)
>   = 64 - 48 = 16 > 0
>
> Dos raíces reales:
> r₁ = (-8 + √16)/(2(-2)) = (-8 + 4)/(-4) = -4/(-4) = 1
> r₂ = (-8 - √16)/(2(-2)) = (-8 - 4)/(-4) = -12/(-4) = 3
>
> Interceptos x: (1, 0) y (3, 0)
>
> Verificación con Vieta:
> r₁ + r₂ = 1 + 3 = 4 = -b/a = -8/(-2) ✓
> r₁ · r₂ = 1 · 3 = 3 = c/a = -6/(-2) ✓
> ```
>
> **Paso 6: Dominio y rango**
> ```
> Dom(f) = ℝ = (-∞, +∞)
> Ran(f) = (-∞, 2]
> ```
>
> **Paso 7: Monotonía**
> ```
> Creciente en: (-∞, 2)
> Decreciente en: (2, +∞)
>
> Punto crítico: x = 2 (máximo)
> ```
>
> **Paso 8: Forma canónica**
> ```
> f(x) = -2(x - 2)² + 2
>
> Verificación:
> -2(x - 2)² + 2 = -2(x² - 4x + 4) + 2
>                 = -2x² + 8x - 8 + 2
>                 = -2x² + 8x - 6 ✓
> ```
>
> **Paso 9: Forma factorizada**
> ```
> f(x) = -2(x - 1)(x - 3)
>
> Verificación:
> -2(x - 1)(x - 3) = -2(x² - 4x + 3)
>                   = -2x² + 8x - 6 ✓
> ```
>
> **Paso 10: Tabla de valores**
> ```
> x   | -1  | 0   | 1  | 2  | 3  | 4   | 5
> ----|-----|-----|----|----|----|----|----
> f(x)| -16 | -6  | 0  | 2  | 0  | -6 | -16
>
> Simetría evidente: f(0) = f(4) = -6
>                    f(1) = f(3) = 0
> ```
>
> **Resumen gráfico:**
> ```
> - Parábola que abre hacia abajo
> - Vértice (máximo): (2, 2)
> - Raíces: x = 1 y x = 3
> - Intercepto y: -6
> - Eje de simetría: x = 2
> - Pasa por: (-1, -16), (0, -6), (1, 0), (2, 2), (3, 0), (4, -6), (5, -16)
> ```

## 🔄 Transformaciones de la Parábola Básica

> [!tip]- De y = x² a y = a(x - h)² + k
>
> **Parábola básica:** y = x²
>
> ### Transformaciones individuales
>
> **1. Desplazamiento vertical: y = x² + k**
> ```
> k > 0: Desplaza k unidades hacia arriba
> k < 0: Desplaza |k| unidades hacia abajo
>
> Ejemplo:
> y = x² + 3: Sube 3 unidades
> y = x² - 2: Baja 2 unidades
>
> Vértice: (0, k)
> ```
>
> **2. Desplazamiento horizontal: y = (x - h)²**
> ```
> h > 0: Desplaza h unidades hacia la derecha
> h < 0: Desplaza |h| unidades hacia la izquierda
>
> Ejemplo:
> y = (x - 4)²: Derecha 4 unidades
> y = (x + 3)²: Izquierda 3 unidades
>
> Vértice: (h, 0)
>
> NOTA: El signo dentro del paréntesis es OPUESTO al desplazamiento
> ```
>
> **3. Estiramiento/compresión vertical: y = ax²**
> ```
> |a| > 1: Estira verticalmente (parábola más estrecha)
> 0 < |a| < 1: Comprime verticalmente (parábola más ancha)
>
> Ejemplo:
> y = 3x²: Estrecha (3 veces más alta)
> y = 0.5x²: Ancha (mitad de altura)
>
> Vértice: (0, 0)
> ```
>
> **4. Reflexión: y = -x²**
> ```
> a < 0: Reflexión respecto al eje x
> Parábola invertida (abre hacia abajo)
>
> Ejemplo:
> y = -x²: Refleja y = x²
> y = -2x²: Refleja y estira
>
> Vértice: (0, 0)
> ```
>
> ### Transformaciones combinadas
>
> **Orden de aplicación:**
> ```
> y = a(x - h)² + k
>
> 1. Desde y = x²
> 2. Aplicar estiramiento/reflexión (a)
> 3. Desplazar horizontalmente (h)
> 4. Desplazar verticalmente (k)
> ```
>
> **Ejemplos:**
> ```
> y = 2(x - 3)² + 1
> 1. Partir de y = x²
> 2. Estirar: y = 2x² (más estrecha)
> 3. Derecha 3: y = 2(x - 3)²
> 4. Subir 1: y = 2(x - 3)² + 1
> Vértice: (3, 1)
>
> y = -0.5(x + 2)² - 4
> 1. Partir de y = x²
> 2. Comprimir y reflejar: y = -0.5x²
> 3. Izquierda 2: y = -0.5(x + 2)²
> 4. Bajar 4: y = -0.5(x + 2)² - 4
> Vértice: (-2, -4)
> ```
>
> **Tabla de transformaciones:**
> ```
> Transformación         | Ecuación      | Efecto en vértice (0,0)
> -----------------------|---------------|------------------------
> Vertical ↑ k           | x² + k        | (0, k)
> Horizontal → h         | (x - h)²      | (h, 0)
> Estiramiento ×a        | ax²           | (0, 0) - más estrecha
> Compresión ×a (0<a<1)  | ax²           | (0, 0) - más ancha
> Reflexión horizontal   | (-x)²         | (0, 0) - sin cambio
> Reflexión vertical     | -x²           | (0, 0) - invertida
> Combinada              | a(x-h)²+k     | (h, k)
> ```

## 🎨 Graficación de Funciones Cuadráticas

> [!example]- Métodos de Graficación
>
> ### Método 1: Usando vértice y puntos adicionales
>
> **Pasos:**
> ```
> 1. Encontrar y marcar el vértice (h, k)
> 2. Trazar el eje de simetría x = h
> 3. Encontrar interceptos (si existen)
> 4. Calcular puntos adicionales a ambos lados del eje
> 5. Usar simetría para completar
> 6. Dibujar la parábola suave
> ```
>
> **Ejemplo:** f(x) = x² - 4x + 3
> ```
> Vértice: h = 4/2 = 2, k = f(2) = -1
> V(2, -1)
>
> Eje de simetría: x = 2
>
> Intercepto y: (0, 3)
>
> Interceptos x:
> Δ = 16 - 12 = 4
> x = (4 ± 2)/2 → x = 1, x = 3
> Puntos: (1, 0) y (3, 0)
>
> Puntos adicionales:
> f(0) = 3 → (0, 3)
> f(4) = 3 → (4, 3) [simétrico a (0, 3)]
> f(-1) = 8 → (-1, 8)
> f(5) = 8 → (5, 8) [simétrico]
>
> Graficar puntos y conectar con curva suave
> ```
> 
> ### Método 2: Usando forma canónica
>
> **Pasos:**
> ```
> 1. Convertir a forma f(x) = a(x - h)² + k
> 2. Identificar vértice (h, k)
> 3. Identificar dirección (signo de a)
> 4. Usar transformaciones desde y = x²
> 5. Marcar puntos clave
> 6. Dibujar parábola
> ```
>
> **Ejemplo:** f(x) = -2(x - 1)² + 8
> ```
> Forma canónica: ya está
> Vértice: (1, 8)
> a = -2 < 0: abre abajo
>
> Transformaciones:
> - Partir de y = x²
> - Estirar por 2: y = 2x²
> - Reflejar: y = -2x²
> - Derecha 1: y = -2(x - 1)²
> - Subir 8: y = -2(x - 1)² + 8
>
> Puntos adicionales:
> x = 0: f(0) = -2(1) + 8 = 6 → (0, 6)
> x = 2: f(2) = 6 → (2, 6) [simetría]
> x = -1: f(-1) = -8 + 8 = 0 → (-1, 0)
> x = 3: f(3) = 0 → (3, 0)
> ```
> 
> ### Método 3: Usando forma factorizada
>
> **Pasos:**
> ```
> 1. Identificar raíces r₁ y r₂
> 2. Marcar interceptos x: (r₁, 0) y (r₂, 0)
> 3. Calcular vértice: h = (r₁ + r₂)/2, k = f(h)
> 4. Encontrar intercepto y: f(0)
> 5. Usar simetría
> 6. Conectar puntos
> ```
>
> **Ejemplo:** f(x) = (x + 2)(x - 4)
> ```
> Raíces: r₁ = -2, r₂ = 4
> Interceptos x: (-2, 0) y (4, 0)
>
> Vértice: h = (-2 + 4)/2 = 1
>          k = f(1) = (3)(-3) = -9
> V(1, -9)
>
> Intercepto y: f(0) = (2)(-4) = -8
> Punto: (0, -8)
>
> Por simetría: (2, -8)
>
> a = 1 > 0: abre arriba
> ```
> 
> ### Consejos para graficación
>
> **Puntos clave a incluir:**
> ```
> ✓ Vértice (siempre)
> ✓ Interceptos x (si existen)
> ✓ Intercepto y (siempre)
> ✓ Al menos 2-3 puntos a cada lado del vértice
> ✓ Usar simetría para verificar
> ```
>
> **Errores comunes a evitar:**
> ```
> ✗ Dibujar la parábola con esquinas (debe ser suave)
> ✗ No respetar la simetría
> ✗ Confundir dirección de apertura
> ✗ Graficar interceptos inexistentes
> ✗ Vértice mal ubicado
> ✗ Parábola muy puntiaguda o muy plana
> ```
>
> **Verificación:**
> ```
> - Eje de simetría debe pasar por vértice
> - Puntos equidistantes del eje deben estar a misma altura
> - Si Δ < 0, no debe cruzar eje x
> - Concavidad debe coincidir con signo de a
> - Intercepto y debe ser c
> ```

## 🧮 Aplicaciones de Funciones Cuadráticas

> [!note]- Problemas del Mundo Real
>
> ### A. Movimiento Parabólico (Física)
>
> **Ecuación de altura:**
> ```
> h(t) = -½gt² + v₀t + h₀
>
> donde:
> g = 9.8 m/s² (gravedad)
> v₀ = velocidad inicial vertical
> h₀ = altura inicial
> t = tiempo
> ```
>
> **Ejemplo:** Proyectil lanzado
> ```
> Un objeto se lanza verticalmente hacia arriba desde el suelo
> con velocidad inicial de 30 m/s.
>
> h(t) = -4.9t² + 30t
>
> a) Altura máxima:
> Vértice: t = -30/(2(-4.9)) = 3.06 s
> h_max = h(3.06) = 45.9 m
>
> b) Tiempo en el aire:
> h(t) = 0 → t(−4.9t + 30) = 0
> t = 0 (lanzamiento) o t = 6.12 s (aterrizaje)
>
> c) Altura a los 2 s:
> h(2) = -4.9(4) + 60 = 40.4 m
> ```
> 
> ### B. Optimización (Máximos y Mínimos)
>
> **Problema de área máxima:**
> ```
> Se tiene 100 m de cerca para encerrar un terreno rectangular
> junto a un río (un lado no necesita cerca).
>
> Si x es el ancho, entonces:
> Perímetro usado: 2x + y = 100
> y = 100 - 2x
>
> Área: A(x) = x·y = x(100 - 2x) = -2x² + 100x
>
> Máximo en: x = -100/(2(-2)) = 25 m
> Largo: y = 100 - 50 = 50 m
> Área máxima: A(25) = 1250 m²
> ```
>
> **Problema de ingreso máximo:**
> ```
> Una compañía vende widgets a $50 cada uno.
> Por cada reducción de $2 en el precio, vende 10 unidades más.
> Actualmente vende 100 unidades.
>
> Si x = número de reducciones de $2:
> Precio: P(x) = 50 - 2x
> Cantidad: Q(x) = 100 + 10x
>
> Ingreso: I(x) = P·Q = (50 - 2x)(100 + 10x)
>                     = -20x² + 300x + 5000
>
> Máximo en: x = -300/(2(-20)) = 7.5
> Precio óptimo: 50 - 2(7.5) = $35
> Cantidad: 100 + 10(7.5) = 175 unidades
> Ingreso máximo: I(7.5) = $6125
> ```
> 
> ### C. Geometría y Construcción
>
> **Problema del puente parabólico:**
> ```
> Un arco de puente tiene forma parabólica.
> Ancho de 20 m en la base, altura máxima de 8 m en el centro.
>
> Sistema de coordenadas: origen en el centro de la base
> Vértice: (0, 8)
> Puntos base: (-10, 0) y (10, 0)
>
> Forma canónica: h(x) = a(x - 0)² + 8 = ax² + 8
>
> Usar punto (10, 0):
> 0 = a(100) + 8
> a = -8/100 = -0.08
>
> Ecuación: h(x) = -0.08x² + 8
>
> Altura a 5 m del centro:
> h(5) = -0.08(25) + 8 = 6 m
> ```
> 
> ### D. Economía y Negocios
>
> **Función de costo:**
> ```
> C(x) = costo fijo + costo variable + costo cuadrático
> C(x) = 1000 + 20x + 0.5x²
>
> donde x = unidades producidas
>
> Costo promedio: C̄(x) = C(x)/x = 1000/x + 20 + 0.5x
>
> Minimizar costo promedio (usando cálculo o métodos numéricos)
> ```
>
> **Función de utilidad:**
> ```
> Utilidad = Ingreso - Costo
> U(x) = I(x) - C(x)
>
> Si I(x) = 100x y C(x) = 1000 + 20x + 0.5x²:
> U(x) = 100x - (1000 + 20x + 0.5x²)
>      = -0.5x² + 80x - 1000
>
> Maximizar: x = -80/(2(-0.5)) = 80 unidades
> Utilidad máxima: U(80) = $2200
> ```
> 
> ### E. Biología y Medicina
>
> **Concentración de medicamento:**
> ```
> C(t) = -0.05t² + 0.8t + 0.1
>
> donde C = concentración (mg/L), t = horas
>
> Concentración máxima:
> t = -0.8/(2(-0.05)) = 8 horas
> C_max = C(8) = 3.3 mg/L
>
> Duración efectiva (C > 2 mg/L):
> -0.05t² + 0.8t + 0.1 = 2
> -0.05t² + 0.8t - 1.9 = 0
> Resolver para t
> ```
> 
> ### F. Ingeniería
>
> **Antena parabólica:**
> ```
> El receptor se ubica en el foco de la parábola
>
> Ecuación: x² = 4py
> donde p = distancia del vértice al foco
>
> Si la antena tiene 3 m de diámetro y 0.5 m de profundidad:
> Punto (1.5, 0.5) en la parábola
>
> (1.5)² = 4p(0.5)
> 2.25 = 2p
> p = 1.125 m
>
> Foco: (0, 1.125) - ubicar receptor ahí
> ```

## 🔢 Desigualdades Cuadráticas

> [!tip]- Resolver Desigualdades
>
> ### Método gráfico
>
> **Para resolver f(x) > 0, f(x) < 0, f(x) ≥ 0, f(x) ≤ 0:**
>
> ```
> Pasos:
> 1. Graficar f(x) = ax² + bx + c
> 2. Encontrar raíces (si existen)
> 3. Analizar signo en cada intervalo
> 4. Escribir solución según desigualdad
> ```
>
> **Ejemplo:** x² - 5x + 6 < 0
> ```
> 1. Factorizar: (x - 2)(x - 3) < 0
> 2. Raíces: x = 2, x = 3
> 3. Intervalos: (-∞, 2), (2, 3), (3, +∞)
>
> Análisis de signos:
> x < 2: f(1) = 2 > 0  (positivo)
> 2 < x < 3: f(2.5) = -0.25 < 0  (negativo) ✓
> x > 3: f(4) = 2 > 0  (positivo)
>
> Solución: x ∈ (2, 3)
> ```
>
> **Casos según discriminante:**
> ```
> Δ > 0 (dos raíces r₁ < r₂):
> - ax² + bx + c > 0:
>   Si a > 0: x ∈ (-∞, r₁) ∪ (r₂, +∞)
>   Si a < 0: x ∈ (r₁, r₂)
>
> - ax² + bx + c < 0:
>   Si a > 0: x ∈ (r₁, r₂)
>   Si a < 0: x ∈ (-∞, r₁) ∪ (r₂, +∞)
>
> Δ = 0 (una raíz r):
> - ax² + bx + c > 0:
>   Si a > 0: x ∈ ℝ \ {r}
>   Si a < 0: ∅
>
> - ax² + bx + c < 0:
>   Si a > 0: ∅
>   Si a < 0: x ∈ ℝ \ {r}
>
> Δ < 0 (sin raíces reales):
> - ax² + bx + c > 0:
>   Si a > 0: x ∈ ℝ
>   Si a < 0: ∅
>
> - ax² + bx + c < 0:
>   Si a > 0: ∅
>   Si a < 0: x ∈ ℝ
> ```
> 
> 
> ### Método algebraico (Tabla de signos)
>
> **Ejemplo:** -2x² + 7x - 3 ≥ 0
> ```
> Paso 1: Encontrar raíces
> Δ = 49 - 24 = 25
> x = (-7 ± 5)/(-4)
> r₁ = 1/2, r₂ = 3
>
> Paso 2: Tabla de signos
>
>
>
> Paso 3: Interpretar
> f(x) ≥ 0 en [1/2, 3]
> Incluir extremos porque ≥
>
> Solución: x ∈ [1/2, 3]
> ```
> 
> ### Desigualdades simultáneas
>
> **Ejemplo:** 1 < x² - 2x + 3 < 6
> ```
> Dividir en dos desigualdades:
>
> 1) x² - 2x + 3 > 1
>    x² - 2x + 2 > 0
>    Δ = 4 - 8 = -4 < 0
>    a = 1 > 0
>    Solución: x ∈ ℝ (siempre positiva)
>
> 2) x² - 2x + 3 < 6
>    x² - 2x - 3 < 0
>    (x - 3)(x + 1) < 0
>    Solución: x ∈ (-1, 3)
>
> Intersección: (-1, 3) ∩ ℝ = (-1, 3)
> Solución final: x ∈ (-1, 3)
> ```
> 
> ### Desigualdades racionales con cuadráticas
>
> **Ejemplo:** (x² - 4)/(x - 1) ≥ 0
> ```
> Paso 1: Factorizar numerador
> (x - 2)(x + 2)/(x - 1) ≥ 0
>
> Paso 2: Puntos críticos
> Raíces numerador: x = -2, x = 2
> Raíces denominador: x = 1 (excluir)
>
> Paso 3: Intervalos
> (-∞, -2), (-2, 1), (1, 2), (2, +∞)
>
> Paso 4: Tabla de signos
>
> Intervalo    | (-∞,-2) | (-2,1) | (1,2) | (2,+∞)
> -------------|---------|--------|-------|--------
> (x + 2)      |    -    |   +    |   +   |   +
> (x - 2)      |    -    |   -    |   -   |   +
> (x - 1)      |    -    |   -    |   +   |   +
> Cociente     |    -    |   +    |   -   |   +
>
> Paso 5: Solución
> f(x) ≥ 0 en: [-2, 1) ∪ [2, +∞)
> Incluir -2 y 2 (numerador cero)
> Excluir 1 (denominador cero)
> ```

## 📐 Sistemas con Ecuaciones Cuadráticas

> [!example]- Intersecciones y Sistemas
>
> ### A. Parábola con recta
>
> **Sistema:**
> ```
> y = ax² + bx + c
> y = mx + n
> ```
>
> **Método de sustitución:**
> ```
> ax² + bx + c = mx + n
> ax² + (b - m)x + (c - n) = 0
>
> Analizar discriminante:
> Δ = (b - m)² - 4a(c - n)
>
> Δ > 0: 2 puntos de intersección
> Δ = 0: 1 punto de intersección (tangente)
> Δ < 0: 0 puntos de intersección
> ```
>
> **Ejemplo:** y = x² - 3x + 2 y y = x - 1
> ```
> x² - 3x + 2 = x - 1
> x² - 4x + 3 = 0
> (x - 3)(x - 1) = 0
> x = 1, x = 3
>
> Puntos:
> x = 1: y = 0 → (1, 0)
> x = 3: y = 2 → (3, 2)
>
> Dos puntos de intersección
> ```
> 
> ### B. Dos parábolas
>
> **Sistema:**
> ```
> y = a₁x² + b₁x + c₁
> y = a₂x² + b₂x + c₂
> ```
>
> **Método:**
> ```
> a₁x² + b₁x + c₁ = a₂x² + b₂x + c₂
> (a₁ - a₂)x² + (b₁ - b₂)x + (c₁ - c₂) = 0
>
> Si a₁ ≠ a₂: ecuación cuadrática (hasta 2 soluciones)
> Si a₁ = a₂ pero b₁ ≠ b₂: ecuación lineal (1 solución)
> Si a₁ = a₂ y b₁ = b₂: parábolas idénticas o paralelas
> ```
>
> **Ejemplo:** y = x² + 2x - 3 y y = -x² + 4x + 1
> ```
> x² + 2x - 3 = -x² + 4x + 1
> 2x² - 2x - 4 = 0
> x² - x - 2 = 0
> (x - 2)(x + 1) = 0
> x = 2, x = -1
>
> Puntos:
> x = 2: y = 5 → (2, 5)
> x = -1: y = -4 → (-1, -4)
> ```
> 
> ### C. Parábola con circunferencia
>
> **Sistema:**
> ```
> y = ax² + bx + c
> (x - h)² + (y - k)² = r²
> ```
>
> **Método:**
> ```
> Sustituir la expresión de y en la ecuación del círculo
> (x - h)² + (ax² + bx + c - k)² = r²
>
> Expandir y resolver (ecuación de grado 4, pero métodos numéricos o casos especiales)
> ```
>
> **Ejemplo simplificado:** y = x² y x² + y² = 2
> ```
> x² + (x²)² = 2
> x² + x⁴ = 2
> x⁴ + x² - 2 = 0
>
> Sustitución u = x²:
> u² + u - 2 = 0
> (u + 2)(u - 1) = 0
> u = 1 (u = -2 no válido)
>
> x² = 1 → x = ±1
>
> x = 1: y = 1 → (1, 1)
> x = -1: y = 1 → (-1, 1)
>
> Dos puntos de intersección
> ```

## 🎓 Teoremas y Propiedades Importantes

> [!note]- Resultados Fundamentales
>
> ### Teorema Fundamental del Álgebra (Caso Cuadrático)
>
> ```
> Toda ecuación cuadrática ax² + bx + c = 0 (a ≠ 0)
> tiene exactamente 2 raíces en los números complejos,
> contando multiplicidad.
>
> En ℝ:
> - 2 raíces reales distintas si Δ > 0
> - 1 raíz real doble si Δ = 0
> - 0 raíces reales (2 complejas conjugadas) si Δ < 0
> ```
> 
> ### Relaciones de Vieta
>
> ```
> Para ax² + bx + c = 0 con raíces r₁ y r₂:
>
> Suma:     r₁ + r₂ = -b/a
> Producto: r₁ · r₂ = c/a
>
> Consecuencias:
> - Permite verificar raíces sin calcularlas
> - Reconstruir ecuación desde raíces
> - Simplificar expresiones simétricas
> ```
>
> **Aplicación:**
> ```
> Si r₁ = 3 y r₂ = -2 son raíces, con a = 2:
> Suma: 3 + (-2) = 1 = -b/2 → b = -2
> Producto: 3(-2) = -6 = c/2 → c = -12
>
> Ecuación: 2x² - 2x - 12 = 0
> o simplificado: x² - x - 6 = 0
> ```
> 
> ### Completar el Cuadrado (Teorema)
>
> ```
> Todo trinomio cuadrático ax² + bx + c puede expresarse como:
>
> ax² + bx + c = a[(x + b/(2a))² - b²/(4a²)] + c
>                = a(x + b/(2a))² + (c - b²/(4a))
>
> Esta es la justificación algebraica de la forma canónica
> ```
> 
> ### Propiedades de simetría
>
> ```
> Si f(x) = ax² + bx + c, entonces:
>
> 1. Para cualquier h, la función g(x) = f(x - h) desplaza
>    la gráfica h unidades a la derecha
>
> 2. f(h + d) = f(h - d) para todo d ∈ ℝ
>    donde h = -b/(2a) es el eje de simetría
>
> 3. El punto medio entre cualquier par de puntos
>    (x₁, f(x₁)) y (x₂, f(x₂)) con x₁ ≠ x₂ tiene
>    coordenada x igual a (x₁ + x₂)/2
> ```
> 
> ### Monotonía y Derivada
>
> ```
> f(x) = ax² + bx + c
> f'(x) = 2ax + b
>
> Punto crítico: f'(x) = 0 ⟹ x = -b/(2a)
>
> Si a > 0:
> - f'(x) < 0 para x < -b/(2a) (decrece)
> - f'(x) > 0 para x > -b/(2a) (crece)
> - Mínimo en x = -b/(2a)
>
> Si a < 0:
> - f'(x) > 0 para x < -b/(2a) (crece)
> - f'(x) < 0 para x > -b/(2a) (decrece)
> - Máximo en x = -b/(2a)
> ```
> 
> ### Concavidad y Segunda Derivada
>
> ```
> f(x) = ax² + bx + c
> f''(x) = 2a (constante)
>
> Si a > 0: f''(x) > 0 para todo x
>          → cóncava hacia arriba (convexa)
>
> Si a < 0: f''(x) < 0 para todo x
>          → cóncava hacia abajo (cóncava)
>
> No hay puntos de inflexión (f'' no cambia de signo)
> ```

## 🔍 Casos Especiales y Degenerados

> [!tip]- Situaciones Particulares
>
> ### A. Cuadrática "perfecta" (sin término lineal)
>
> ```
> f(x) = ax² + c  (b = 0)
>
> Características:
> - Eje de simetría: x = 0 (eje y)
> - Vértice: (0, c)
> - Función par: f(-x) = f(x)
> - Raíces: x = ±√(-c/a) si -c/a ≥ 0
>
> Ejemplos:
> f(x) = x² - 4 → raíces ±2
> f(x) = 2x² + 3 → sin raíces reales
> f(x) = -x² → vértice (0, 0), abre abajo
> ```
> 
> ### B. Cuadrado perfecto (Δ = 0)
>
> ```
> f(x) = a(x - r)²  donde r = -b/(2a)
>
> Características:
> - Una raíz doble
> - Vértice en el eje x: (r, 0)
> - Tangente al eje x
> - Rango: [0, +∞) si a > 0, o (-∞, 0] si a < 0
>
> Forma general: ax² + bx + c donde b² = 4ac
>
> Ejemplos:
> f(x) = x² - 6x + 9 = (x - 3)²
> f(x) = 4x² + 4x + 1 = (2x + 1)²
> ```
> 
> ### C. Sin término independiente (pasa por origen)
>
> ```
> f(x) = ax² + bx  (c = 0)
>
> Características:
> - Pasa por origen: f(0) = 0
> - Factorizable: f(x) = x(ax + b)
> - Raíces: x = 0 y x = -b/a
> - Vértice: h = -b/(2a), k = f(h) = -b²/(4a)
>
> Ejemplos:
> f(x) = x² - 4x = x(x - 4) → raíces 0 y 4
> f(x) = -2x² + 6x = -2x(x - 3) → raíces 0 y 3
> ```
> 
> ### D. Solo término cuadrático
>
> ```
> f(x) = ax²  (b = 0, c = 0)
>
> Características:
> - Vértice en origen: (0, 0)
> - Raíz doble en x = 0
> - Función par
> - Forma más simple de parábola
> - Tangente al eje x en origen
>
> Ejemplos:
> f(x) = x² (parábola básica)
> f(x) = 2x² (estrecha)
> f(x) = -x² (invertida)
> ```
> 
> ### E. Caso degenerado (a = 0)
>
> ```
> Si a = 0: f(x) = bx + c
>
> NO es función cuadrática, sino lineal
> La parábola se "aplana" a una recta
>
> Importante: La condición a ≠ 0 es esencial
> en la definición de función cuadrática
> ```

## 🧩 Problemas Típicos y Estrategias

> [!example]- Ejercicios Modelo
>
> ### Tipo 1: Encontrar ecuación desde condiciones
>
> **Problema:** Encontrar la ecuación cuadrática que:
> - Pasa por (0, 3)
> - Tiene vértice en (2, -1)
>
> **Solución:**
> ```
> Usar forma canónica: f(x) = a(x - h)² + k
>
> Vértice (2, -1): f(x) = a(x - 2)² - 1
>
> Pasa por (0, 3):
> 3 = a(0 - 2)² - 1
> 3 = 4a - 1
> 4a = 4
> a = 1
>
> Ecuación: f(x) = (x - 2)² - 1
> Expandir: f(x) = x² - 4x + 4 - 1 = x² - 4x + 3
> ```
> 
> ### Tipo 2: Encontrar ecuación desde tres puntos
>
> **Problema:** Parábola pasa por (1, 4), (2, 5), (3, 8)
>
> **Solución:**
> ```
> Usar f(x) = ax² + bx + c
>
> Sistema de ecuaciones:
> f(1) = a + b + c = 4      ... (1)
> f(2) = 4a + 2b + c = 5    ... (2)
> f(3) = 9a + 3b + c = 8    ... (3)
>
> (2) - (1): 3a + b = 1     ... (4)
> (3) - (2): 5a + b = 3     ... (5)
>
> (5) - (4): 2a = 2 → a = 1
>
> De (4): 3(1) + b = 1 → b = -2
>
> De (1): 1 + (-2) + c = 4 → c = 5
>
> Ecuación: f(x) = x² - 2x + 5
> ```
> 
> ### Tipo 3: Optimización con restricciones
>
> **Problema:** Maximizar área de rectángulo con perímetro 40 m
>
> **Solución:**
> ```
> Variables: largo = x, ancho = y
>
> Restricción: 2x + 2y = 40 → y = 20 - x
>
> Área: A(x) = x·y = x(20 - x) = -x² + 20x
>
> Máximo: x = -20/(2(-1)) = 10 m
> y = 20 - 10 = 10 m
>
> Área máxima: A(10) = 100 m²
>
> Conclusión: Cuadrado maximiza área
> ```
> 
> ### Tipo 4: Interpretación de parámetros
>
> **Problema:** Para qué valores de k la ecuación x² - 4x + k = 0
> tiene dos raíces reales distintas?
>
> **Solución:**
> ```
> Condición: Δ > 0
>
> Δ = b² - 4ac = 16 - 4(1)(k) = 16 - 4k
>
> 16 - 4k > 0
> 16 > 4k
> k < 4
>
> Respuesta: k ∈ (-∞, 4)
> ```
> 
> ### Tipo 5: Intersección y posiciones relativas
>
> **Problema:** Para qué valores de m la recta y = mx + 1
> es tangente a la parábola y = x² - 2x + 3?
>
> **Solución:**
> ```
> Condición de tangencia: Δ = 0
>
> x² - 2x + 3 = mx + 1
> x² - (2 + m)x + 2 = 0
>
> Δ = (2 + m)² - 4(1)(2) = 0
> (2 + m)² = 8
> 2 + m = ±2√2
> m = -2 ± 2√2
>
> Dos valores: m₁ = -2 + 2√2, m₂ = -2 - 2√2
> ```
> 
> ### Tipo 6: Dominio y rango con restricciones
>
> **Problema:** Si f(x) = x² - 4x + 5 con dominio [1, 4],
> encontrar el rango.
>
> **Solución:**
> ```
> Vértice: h = 4/2 = 2, k = f(2) = 4 - 8 + 5 = 1
>
> Como 2 ∈ [1, 4], el vértice está en el dominio
>
> Evaluar extremos:
> f(1) = 1 - 4 + 5 = 2
> f(4) = 16 - 16 + 5 = 5
>
> Mínimo: f(2) = 1 (vértice)
> Máximo: f(4) = 5 (extremo derecho)
>
> Rango: [1, 5]
> ```

## 📚 Errores Comunes y Cómo Evitarlos

> [!warning]- Equivocaciones Frecuentes
>
> ### 1. Confundir signo en desplazamientos horizontales
>
> **Error:**
> ```
> ✗ f(x) = (x + 3)² desplaza 3 unidades a la derecha
> ```
>
> **Correcto:**
> ```
> ✓ f(x) = (x + 3)² = (x - (-3))² desplaza 3 unidades a la IZQUIERDA
> ✓ Regla: (x - h)² → derecha h unidades si h > 0
> ```
> 
> ### 2. Olvidar el coeficiente a al completar cuadrado
>
> **Error:**
> ```
> ✗ 2x² + 8x + 3 = 2(x² + 4x) + 3
>                 = 2(x + 2)² + 3  INCORRECTO
> ```
>
> **Correcto:**
> ```
> ✓ 2x² + 8x + 3 = 2(x² + 4x) + 3
>                 = 2[(x + 2)² - 4] + 3
>                 = 2(x + 2)² - 8 + 3
>                 = 2(x + 2)² - 5
> ```
> 
> ### 3. Errores en la fórmula general
>
> **Error:**
> ```
> ✗ x = -b ± √(b² - 4ac) / 2a  (paréntesis mal ubicados)
> ```
>
> **Correcto:**
> ```
> ✓ x = [-b ± √(b² - 4ac)] / (2a)
> ✓ TODO el numerador se divide entre 2a
> ```
> 
> ### 4. Confundir vértice con raíces
>
> **Error:**
> ```
> ✗ "Las raíces son el vértice"
> ```
>
> **Correcto:**
> ```
> ✓ Raíces: donde f(x) = 0 (interceptos x)
> ✓ Vértice: punto extremo (máximo o mínimo)
> ✓ Vértice x = (raíz₁ + raíz₂)/2 (si existen raíces)
> ```
> 
> ### 5. Ignorar el dominio en problemas aplicados
>
> **Error:**
> ```
> ✗ h(t) = -4.9t² + 30t
>   Máximo en t = 3.06 s, luego cae indefinidamente
> ```
>
> **Correcto:**
> ```
> ✓ Dominio físico: t ∈ [0, 6.12]
> ✓ El objeto está en el suelo para t > 6.12
> ✓ h(t) solo es válida mientras el objeto está en el aire
> ```
> 
> ### 6. Mal análisis del discriminante
>
> **Error:**
> ```
> ✗ Δ = 0 → "no tiene raíces"
> ```
>
> **Correcto:**
> ```
> ✓ Δ > 0 → dos raíces reales distintas
> ✓ Δ = 0 → una raíz real doble (raíz repetida)
> ✓ Δ < 0 → no tiene raíces reales (raíces complejas)
> ```
> 
> ### 7. Olvidar incluir/excluir extremos en desigualdades
>
> **Error:**
> ```
> ✗ x² - 4 ≤ 0 → solución: (-2, 2)
> ```
>
> **Correcto:**
> ```
> ✓ x² - 4 ≤ 0 → solución: [-2, 2]
> ✓ El ≤ incluye los puntos donde f(x) = 0
> ```
> 
> ### 8. Confundir concavidad con monotonía
>
> **Error:**
> ```
> ✗ "Si a > 0, la función es creciente"
> ```
>
> **Correcto:**
> ```
> ✓ Si a > 0, la parábola abre hacia arriba (cóncava arriba)
> ✓ Es decreciente en (-∞, h) y creciente en (h, +∞)
> ✓ No es monótona en todo su dominio
> ```
