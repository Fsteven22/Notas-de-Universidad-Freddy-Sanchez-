# 📊 Funciones Definidas por Tramos

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva
> **Una función definida por tramos (o por partes) es aquella cuya regla de correspondencia cambia según el valor de la variable independiente. Es como un sistema de reglas múltiples: "si x está aquí, haz esto; si está allá, haz aquello".**
>
> **Elementos clave:**
> - **Múltiples expresiones:** Diferentes fórmulas en diferentes intervalos
> - **Partición del dominio:** División en subconjuntos disjuntos
> - **Unicidad preservada:** Cada x tiene exactamente un valor f(x)
> - **Fronteras:** Puntos críticos donde cambia la expresión
> - **Aplicaciones:** Modelan situaciones con comportamientos distintos

### 📖 Contexto Histórico

> [!note]- Desarrollo Histórico
> 
> **Orígenes Implícitos (1600-1750):**
> - **Newton y Leibniz:** Funciones con comportamientos distintos en regiones
> - **Bernoulli (1700s):** Problemas de brachistócrona con soluciones por tramos
> - **Euler (1750):** Vibraciones de cuerdas, soluciones por segmentos
> - **Concepto:** Funciones como expresiones analíticas únicas
>
> **Crisis del Concepto Clásico (1750-1830):**
> - **D'Alembert vs Euler (1750s):** Debate sobre qué es una función
> - **Cuerda vibrante:** ¿Puede la solución cambiar de forma?
> - **Posición inicial arbitraria:** Funciones discontinuas
> - **Problema:** ¿Son funciones legítimas?
>
> **Revolución de Fourier (1807-1830):**
> - **Fourier (1807):** _Théorie de la chaleur_
> - **Series trigonométricas:** Representan funciones "arbitrarias"
> - **Funciones discontinuas:** Representables por series
> - **Ejemplo revolucionario:**
>   ```
>   f(x) = { 0   si -π < x < 0
>          { π   si 0 < x < π
>   
>   Representable: f(x) = π/2 + (2/π)Σ[sin((2n-1)x)/(2n-1)]
>   ```
> - **Impacto:** Amplió radicalmente el concepto de función
>
> **Formalización de Dirichlet (1829-1837):**
> - **Dirichlet (1829):** Convergencia de series de Fourier
> - **Definición moderna (1837):** Correspondencia arbitraria
> - **Función de Dirichlet:**
>   ```
>   D(x) = { 1   si x es racional
>          { 0   si x es irracional
>   ```
> - **Revolución:** Función sin fórmula analítica única
>
> **Era del Rigor (1850-1900):**
> - **Riemann (1854):** Funciones con discontinuidades contables
> - **Weierstrass (1872):** Función continua sin derivada
> - **Cantor (1874):** Teoría de conjuntos aplicada
> - **Función escalón de Heaviside (1893):**
>   ```
>   H(x) = { 0   si x < 0
>          { 1   si x ≥ 0
>   ```
> - **Ingeniería eléctrica:** Modelaje de conmutación
>
> **Siglo XX - Aplicaciones (1900-presente):**
> - **Análisis de Fourier:** Señales periódicas discontinuas
> - **Teoría de la señal:** Pulsos, ondas cuadradas
> - **Control automático:** Funciones de conmutación
> - **Economía:** Impuestos progresivos, tarifas escalonadas
> - **Física:** Potenciales discontinuos, colisiones
> - **Matemática computacional:** Splines, interpolación por tramos

## 📐 Definición Formal

> [!success]- Definición Matemática Rigurosa
>
> **Definición:** Una función f se dice **definida por tramos** o **por partes** si su dominio puede partirse en un número finito (o numerable) de subconjuntos disjuntos, en cada uno de los cuales f está definida por una expresión diferente.
>
> **Notación estándar:**
> ```
> f(x) = { f₁(x)  si x ∈ D₁
>        { f₂(x)  si x ∈ D₂
>        { f₃(x)  si x ∈ D₃
>        { ...
>        { fₙ(x)  si x ∈ Dₙ
> ```
>
> **Condiciones:**
> 1. **Partición del dominio:**
>    ```
>    Dom(f) = D₁ ∪ D₂ ∪ D₃ ∪ ... ∪ Dₙ
>    ```
> 2. **Disjunción:**
>    ```
>    Dᵢ ∩ Dⱼ = ∅  para i ≠ j
>    ```
> 3. **Funcionalidad:** Cada fᵢ es una función en Dᵢ
>
> **Notación con condiciones:**
> ```
> f(x) = { f₁(x)  si condición₁
>        { f₂(x)  si condición₂
>        { ...
>        { fₙ(x)  si condiciónₙ
> 
> Donde las condiciones son mutuamente excluyentes
> ```
>
> **Terminología:**
> - **Tramos:** Cada subintervalo Dᵢ
> - **Puntos de transición:** Fronteras entre tramos
> - **Subfunciones:** Cada fᵢ
> - **Puntos críticos:** Donde cambia la expresión

> [!warning]- Aspectos Cruciales
>
> **1. Unicidad en las fronteras:**
> ```
> Si x₀ es frontera entre dos tramos, debe especificarse
> claramente a cuál pertenece
> 
> Incorrecto:
> f(x) = { x²    si x < 1
>        { 2x    si x > 1
> ¿Qué pasa en x = 1? No está definida
> 
> Correcto:
> f(x) = { x²    si x < 1
>        { 1     si x = 1
>        { 2x    si x > 1
> 
> o bien:
> 
> f(x) = { x²    si x ≤ 1
>        { 2x    si x > 1
> ```
>
> **2. Cobertura completa:**
> ```
> Todos los valores del dominio deben estar cubiertos
> 
> Incorrecto:
> f(x) = { x     si x < 0
>        { x²    si x > 2
> Falta el intervalo [0, 2]
> ```
>
> **3. No solapamiento:**
> ```
> Las condiciones deben ser mutuamente excluyentes
> 
> Ambiguo:
> f(x) = { x     si x ≤ 1
>        { x²    si x ≥ 1
> ¿Qué vale f(1)? ¿1 o 1²? (casualmente igual, pero conceptualmente ambiguo)
> ```

## 🎯 Funciones por Tramos Elementales

> [!example]- Ejemplos Fundamentales
>
> **1. Función valor absoluto:**
> ```
> f(x) = |x| = { -x   si x < 0
>              {  x   si x ≥ 0
> 
> Dom(f) = ℝ
> Ran(f) = [0, +∞)
> 
> Punto de transición: x = 0
> Gráfica: "V" con vértice en origen
> ```
>
> **2. Función signo (sign):**
> ```
> sgn(x) = {  1   si x > 0
>          {  0   si x = 0
>          { -1   si x < 0
> 
> Dom(sgn) = ℝ
> Ran(sgn) = {-1, 0, 1}
> 
> Puntos de transición: x = 0
> Discontinua en x = 0
> ```
>
> **3. Función escalón unitario (Heaviside):**
> ```
> H(x) = u(x) = { 0   si x < 0
>               { 1   si x ≥ 0
> 
> Dom(H) = ℝ
> Ran(H) = {0, 1}
> 
> Usado en: teoría de señales, ecuaciones diferenciales
> Salto de discontinuidad en x = 0
> ```
>
> **4. Función parte entera (piso, floor):**
> ```
> ⌊x⌋ = mayor entero ≤ x
> 
> Ejemplo:
> ⌊2.7⌋ = 2
> ⌊-1.3⌋ = -2
> ⌊5⌋ = 5
> 
> Por tramos en [0, 3]:
> ⌊x⌋ = { 0   si 0 ≤ x < 1
>       { 1   si 1 ≤ x < 2
>       { 2   si 2 ≤ x < 3
>       { 3   si x = 3
> 
> Dom(⌊x⌋) = ℝ
> Ran(⌊x⌋) = ℤ
> 
> Discontinua en cada entero
> ```
>
> **5. Función techo (ceiling):**
> ```
> ⌈x⌉ = menor entero ≥ x
> 
> Ejemplo:
> ⌈2.7⌉ = 3
> ⌈-1.3⌉ = -1
> ⌈5⌉ = 5
> 
> Relación: ⌈x⌉ = -⌊-x⌋
> ```
>
> **6. Función parte fraccionaria:**
> ```
> {x} = x - ⌊x⌋
> 
> Ejemplo:
> {2.7} = 0.7
> {-1.3} = 0.7
> {5} = 0
> 
> Dom({x}) = ℝ
> Ran({x}) = [0, 1)
> 
> Periódica con período 1
> ```

## 📊 Construcción de Funciones por Tramos

> [!tip]- Cómo Definir Funciones por Tramos
>
> **Método 1 - Desde una descripción verbal:**
>
> *Problema:* Una empresa de mensajería cobra $5 por los primeros 2 kg y $2 por cada kg adicional o fracción.
>
> *Solución:*
> ```
> C(w) = { 5           si 0 < w ≤ 2
>        { 5 + 2⌈w-2⌉  si w > 2
> 
> donde w = peso en kg
> 
> Evaluaciones:
> C(1.5) = 5
> C(2) = 5
> C(2.1) = 5 + 2(1) = 7
> C(3.8) = 5 + 2(2) = 9
> ```
>
> **Método 2 - Desde una gráfica:**
>
> *Problema:* Definir algebraicamente una función cuya gráfica forma una "casa":
>
> *Solución:*
> ```
> Descripción: línea desde (0,0) a (2,2), luego a (4,0)
> 
> f(x) = { x       si 0 ≤ x ≤ 2
>        { 4 - x   si 2 < x ≤ 4
> 
> Verificación:
> f(0) = 0, f(2) = 2, f(4) = 0 ✓
> Continua en x = 2: lim(x→2⁻) = 2 = lim(x→2⁺) = 2 ✓
> ```
>
> **Método 3 - Modificando funciones conocidas:**
>
> *Problema:* Definir f(x) = |x - 3|
>
> *Solución:*
> ```
> Analizar: x - 3 = 0 cuando x = 3
> 
> Si x < 3: x - 3 < 0, entonces |x - 3| = -(x - 3) = 3 - x
> Si x ≥ 3: x - 3 ≥ 0, entonces |x - 3| = x - 3
> 
> f(x) = { 3 - x   si x < 3
>        { x - 3   si x ≥ 3
> ```
>
> **Método 4 - Por condiciones matemáticas:**
>
> *Problema:* Definir una función que vale x² cuando x es racional y x³ cuando es irracional.
>
> *Solución:*
> ```
> f(x) = { x²   si x ∈ ℚ
>        { x³   si x ∈ ℝ \ ℚ
> 
> Dom(f) = ℝ
> 
> Nota: Esta función es extremadamente discontinua
> (discontinua en todos los puntos excepto x = 0, 1)
> ```

## 🔍 Evaluación de Funciones por Tramos

> [!example]- Cómo Evaluar Paso a Paso
>
> **Función ejemplo:**
> ```
> f(x) = { x² - 1    si x < -1
>        { 2x        si -1 ≤ x < 2
>        { 5         si x = 2
>        { √(x - 2)  si x > 2
> ```
>
> **Evaluaciones:**
>
> **1. f(-3):**
> ```
> Paso 1: Identificar el tramo
> -3 < -1 ✓
> 
> Paso 2: Usar la expresión correspondiente
> f(-3) = (-3)² - 1 = 9 - 1 = 8
> 
> Respuesta: f(-3) = 8
> ```
>
> **2. f(0):**
> ```
> Paso 1: Identificar el tramo
> -1 ≤ 0 < 2 ✓
> 
> Paso 2: Usar la expresión correspondiente
> f(0) = 2(0) = 0
> 
> Respuesta: f(0) = 0
> ```
>
> **3. f(2):**
> ```
> Paso 1: Identificar el tramo
> x = 2 ✓ (caso especial)
> 
> Paso 2: Usar la expresión correspondiente
> f(2) = 5
> 
> Respuesta: f(2) = 5
> 
> Nota: No usar 2(2) = 4 ni √(2-2) = 0
> ```
>
> **4. f(6):**
> ```
> Paso 1: Identificar el tramo
> 6 > 2 ✓
> 
> Paso 2: Usar la expresión correspondiente
> f(6) = √(6 - 2) = √4 = 2
> 
> Respuesta: f(6) = 2
> ```
>
> **5. f(-1):**
> ```
> Paso 1: Identificar el tramo
> -1 ≤ -1 < 2 ✓
> 
> Paso 2: Usar la expresión correspondiente
> f(-1) = 2(-1) = -2
> 
> Respuesta: f(-1) = -2
> 
> Nota: No usar x² - 1 porque la condición es x < -1 (estricto)
> ```

## 📏 Dominio y Rango de Funciones por Tramos

> [!tip]- Cómo Determinar Dom y Ran
>
> **Dominio:**
>
> ```
> Dom(f) = unión de todos los subdominios
> Dom(f) = D₁ ∪ D₂ ∪ ... ∪ Dₙ
> 
> Procedimiento:
> 1. Identificar cada subdominio Dᵢ
> 2. Verificar que cubren completamente (sin huecos)
> 3. Unir todos los subdominios
> ```
>
> **Rango:**
>
> ```
> Ran(f) = unión de los rangos de cada tramo
> Ran(f) = Ran(f₁|D₁) ∪ Ran(f₂|D₂) ∪ ... ∪ Ran(fₙ|Dₙ)
> 
> Procedimiento:
> 4. Para cada tramo, encontrar el rango en ese subdominio
> 5. Unir todos los rangos parciales
> 6. Simplificar la unión si es posible
> ```
>
> **Ejemplo detallado:**
>
> ```
> f(x) = { x + 2     si x < -1
>        { x²        si -1 ≤ x ≤ 2
>        { 6 - x     si x > 2
> 
> DOMINIO:
> D₁ = (-∞, -1)
> D₂ = [-1, 2]
> D₃ = (2, +∞)
> 
> Dom(f) = (-∞, -1) ∪ [-1, 2] ∪ (2, +∞) = ℝ
> 
> RANGO:
> 
> Tramo 1: f(x) = x + 2, x < -1
> x ∈ (-∞, -1) ⟹ f(x) ∈ (-∞, 1)
> (función creciente)
> 
> Tramo 2: f(x) = x², x ∈ [-1, 2]
> Mínimo: f(0) = 0
> En extremos: f(-1) = 1, f(2) = 4
> Ran₂ = [0, 4]
> 
> Tramo 3: f(x) = 6 - x, x > 2
> x ∈ (2, +∞) ⟹ f(x) ∈ (-∞, 4)
> (función decreciente)
> 
> Ran(f) = (-∞, 1) ∪ [0, 4] ∪ (-∞, 4)
>        = (-∞, 4]
> ```

## 🔄 Continuidad en Funciones por Tramos

> [!important]- Análisis de Continuidad
>
> **Definición de continuidad en un punto:**
> ```
> f es continua en x = a si:
> 1. f(a) está definida
> 2. lim(x→a) f(x) existe
> 3. lim(x→a) f(x) = f(a)
> ```
>
> **Para funciones por tramos:**
>
> ```
> La función puede ser discontinua en los puntos de transición
> 
> En x = a (punto de transición):
> - Límite por izquierda: lim(x→a⁻) f(x) = lim(x→a⁻) f_izq(x)
> - Límite por derecha: lim(x→a⁺) f(x) = lim(x→a⁺) f_der(x)
> - Valor en a: f(a) (según la definición)
> 
> f continua en a ⟺ lim(x→a⁻) f(x) = lim(x→a⁺) f(x) = f(a)
> ```
>
> **Ejemplo 1 - Función continua:**
> ```
> f(x) = { x²      si x ≤ 1
>        { 2x - 1  si x > 1
> 
> Análisis en x = 1:
> 
> lim(x→1⁻) f(x) = lim(x→1⁻) x² = 1
> lim(x→1⁺) f(x) = lim(x→1⁺) (2x - 1) = 2(1) - 1 = 1
> f(1) = 1² = 1
> 
> 1 = 1 = 1 ✓
> 
> f es continua en x = 1 (y en todo ℝ)
> ```
>
> **Ejemplo 2 - Función discontinua:**
> ```
> g(x) = { x + 1   si x < 2
>        { 5       si x ≥ 2
> 
> Análisis en x = 2:
> 
> lim(x→2⁻) g(x) = lim(x→2⁻) (x + 1) = 3
> lim(x→2⁺) g(x) = lim(x→2⁺) 5 = 5
> g(2) = 5
> 
> 3 ≠ 5 ✗
> 
> g es discontinua en x = 2
> Salto de discontinuidad: |5 - 3| = 2
> ```
>
> **Ejemplo 3 - Continuidad modificable:**
> ```
> h(x) = { x²     si x ≠ 1
>        { 3      si x = 1
> 
> Análisis en x = 1:
> 
> lim(x→1) h(x) = lim(x→1) x² = 1
> h(1) = 3
> 
> 1 ≠ 3 ✗
> 
> Discontinuidad removible
> 
> Para hacerla continua:
> h(x) = { x²     si x ≠ 1
>        { 1      si x = 1
> 
> o simplemente h(x) = x² en todo ℝ
> ```

## 📐 Gráficas de Funciones por Tramos

> [!tip]- Técnicas de Graficación
>
> **Procedimiento general:**
>
> ```
> 1. Identificar cada tramo y su dominio
> 2. Graficar cada subfunción en su dominio respectivo
> 3. Marcar puntos de transición:
>    • Círculo lleno (●) si el punto está incluido
>    • Círculo vacío (○) si el punto no está incluido
> 4. Verificar continuidad en transiciones
> 5. Indicar comportamiento en extremos (flechas)
> ```
>
> **Ejemplo paso a paso:**
>
> ```
> f(x) = { -x - 1    si x < -1
>        { x²        si -1 ≤ x ≤ 2
>        { 4         si x > 2
> 
> Paso 1: Tramo 1, x < -1
> Graficar y = -x - 1 para x < -1
> En x = -1: y = -(-1) - 1 = 0
> Punto (-1, 0) con círculo vacío ○
> 
> Paso 2: Tramo 2, -1 ≤ x ≤ 2
> Graficar y = x² para -1 ≤ x ≤ 2
> Puntos extremos:
> (-1, 1) círculo lleno ●
> (2, 4) círculo lleno ●
> 
> Paso 3: Tramo 3, x > 2
> Graficar y = 4 (línea horizontal) para x > 2
> Punto (2, 4) con círculo vacío ○
> (pero ya hay un ● en (2, 4) del tramo 2)
> 
> Paso 4: Análisis de continuidad
> En x = -1:
> lim(x→-1⁻) = 0, lim(x→-1⁺) = 1, f(-1) = 1
> Discontinua (salto)
> 
> En x = 2:
> lim(x→2⁻) = 4, lim(x→2⁺) = 4, f(2) = 4
> Continua ✓
> ```
>
> **Características visuales comunes:**
>
> ```
> 6. Saltos: discontinuidades donde hay "brincos"
> 7. Esquinas: puntos donde la función es continua pero no derivable
> 8. Segmentos horizontales: valores constantes
> 9. Segmentos inclinados: comportamiento lineal
> 10. Curvas: comportamiento no lineal
> ```

## 🧮 Operaciones con Funciones por Tramos

> [!example]- Álgebra de Funciones por Tramos
>
> **Suma de funciones por tramos:**
>
> ```
> Si f(x) = { f₁(x)  si x ∈ D₁     y     g(x) = { g₁(x)  si x ∈ E₁
>           { f₂(x)  si x ∈ D₂               { g₂(x)  si x ∈ E₂
> 
> Entonces (f + g)(x) requiere:
> 1. Identificar la partición común del dominio
> 2. En cada subintervalo, sumar las expresiones correspondientes
> ```
>
> **Ejemplo:**
> ```
> f(x) = { x      si x < 0         g(x) = { 1    si x < 0
>        { x²     si x ≥ 0                { 2x   si x ≥ 0
> 
> (f + g)(x) = { x + 1       si x < 0
>              { x² + 2x     si x ≥ 0
> 
> Verificación en x = -2:
> f(-2) = -2, g(-2) = 1
> (f + g)(-2) = -2 + 1 = -1 ✓
> ```
>
> **Multiplicación:**
> ```
> Mismo f(x) y g(x) anteriores
> 
> (f · g)(x) = { x · 1        si x < 0
>              { x² · 2x      si x ≥ 0
> 
>            = { x           si x < 0
>              { 2x³         si x ≥ 0
> ```
>
> **Composición:**
> ```
> La composición (f ∘ g)(x) = f(g(x)) es más compleja
> 
> Ejemplo:
> f(x) = { x²     si x ≥ 0         g(x) = { -1   si x < 0
>        { -x     si x < 0                { 1    si x ≥ 0
> 
> Para x < 0: g(x) = -1 < 0
> f(g(x)) = f(-1) = -(-1) = 1
> 
> Para x ≥ 0: g(x) = 1 ≥ 0
> f(g(x)) = f(1) = 1² = 1
> 
> (f ∘ g)(x) = { 1   si x < 0
>              { 1   si x ≥ 0
> 
>            = 1 (función constante)
> ```

## 🎨 Funciones por Tramos Comunes en Aplicaciones

> [!example]- Modelos Prácticos
>
> **1. Tarifas escalonadas (electricidad):**
> ```
> C(k) = { 0.10k                      si 0 ≤ k ≤ 100
>        { 10 + 0.08(k - 100)         si 100 < k ≤ 300
>        { 26 + 0.06(k - 300)         si k > 300
> 
> donde k = consumo en kWh
> 
> Interpretación:
> - Primeros 100 kWh: $0.10/kWh
> - Siguientes 200 kWh: $0.08/kWh
> - Después de 300 kWh: $0.06/kWh
> 
> Ejemplo: C(250) = 10 + 0.08(150) = $22
> ```
>
> **2. Impuesto sobre la renta (progresivo):**
> ```
> T(I) = { 0                          si I ≤ 10000
>        { 0.10(I - 10000)            si 10000 < I ≤ 30000
>        { 2000 + 0.15(I - 30000)     si 30000 < I ≤ 60000
>        { 6500 + 0.25(I - 60000)     si I > 60000
> 
> donde I = ingreso anual
> 
> Tasa marginal aumenta con el ingreso
> ```
>
> **3. Costos de envío:**
> ```
> S(w) = { 5                si 0 < w ≤ 1
>        { 5 + 2⌈w - 1⌉     si w > 1
> 
> donde w = peso en kg
> 
> $5 base más $2 por cada kg adicional o fracción
> 
> Ejemplos:
> S(0.5) = 5
> S(1) = 5
> S(1.1) = 5 + 2(1) = 7
> S(2.7) = 5 + 2(2) = 9
> ```
>**4. Estacionamiento:**
>
> 
> 
> ```
> P(t) = { 3                          si 0 < t ≤ 1
>        { 3 + 2⌈t - 1⌉               si 1 < t ≤ 4
>        { 12                         si t > 4
> 
> donde t = tiempo en horas
> 
> $3 la primera hora
> $2 por cada hora adicional o fracción
> Máximo: $12 al día
> 
> Ejemplo:
> P(0.5) = 3
> P(1) = 3
> P(1.5) = 3 + 2(1) = 5
> P(4) = 3 + 2(3) = 9
> P(5) = 12
> ```
>
> **5. Velocidad máxima por zona:**
> ```
> v_máx(x) = { 20   si 0 ≤ x < 0.5 (escuela)
>            { 40   si 0.5 ≤ x < 2 (residencial)
>            { 55   si 2 ≤ x < 5 (autopista)
>            { 70   si x ≥ 5 (autovía)
> 
> donde x = distancia desde ciudad en km
> 
> Diferentes límites de velocidad según zona
> ```
>
> **6. Función de descuento:**
> ```
> D(x) = { 0.00x           si 0 ≤ x < 100
>        { 0.05x           si 100 ≤ x < 500
>        { 0.10x           si 500 ≤ x < 1000
>        { 0.15x           si x ≥ 1000
> 
> donde x = monto de compra
> 
> A mayor compra, mayor porcentaje de descuento
> ```

## 🔍 Gráficas y Análisis Detallados

> [!tip]- Casos Especiales en Graficación
>
> **Función con esquina (no derivable):**
>
> ```
> f(x) = { x + 1    si x ≤ 0
>        { x²       si x > 0
> 
> En x = 0:
> - lim(x→0⁻) f(x) = 0 + 1 = 1
> - lim(x→0⁺) f(x) = 0² = 0
> - f(0) = 0 + 1 = 1
> 
> Discontinua en x = 0 (salto de 1 unidad)
> 
> Gráfica:
> - Línea con pendiente 1 hasta x = 0 (incluido, ●)
> - Parábola desde x = 0 (excluido, ○)
> - Punto de ruptura visual en (0, 1) y (0, 0)
> ```
>
> **Función con esquina (continua pero no derivable):**
>
> ```
> f(x) = { 2 - x    si x ≤ 1
>        { x        si x > 1
> 
> En x = 1:
> - lim(x→1⁻) f(x) = 2 - 1 = 1
> - lim(x→1⁺) f(x) = 1
> - f(1) = 2 - 1 = 1
> 
> Continua pero con esquina en (1, 1)
> Pendiente izquierda: -1
> Pendiente derecha: 1
> No derivable en x = 1 (cambio de pendiente)
> ```
>
> **Función "diente de sierra" (periódica por tramos):**
>
> ```
> f(x) = { 2x              si 0 ≤ x < 1
>        { 2(x - 1)        si 1 ≤ x < 2
>        { 2(x - 2)        si 2 ≤ x < 3
>        { ...
> 
> o más compactamente:
> 
> f(x) = 2(x - ⌊x⌋)  para x ≥ 0
> 
> Patrón repetido: sube de 0 a 2 cada unidad
> Período: 1
> ```

## 📝 Escritura de Definiciones por Tramos

> [!note]- Técnicas de Expresión
>
> **Forma 1 - Condiciones simples:**
> ```
> f(x) = { x²     si x < 0
>        { 0      si x = 0
>        { √x     si x > 0
> ```
>
> **Forma 2 - Con intervalos explícitos:**
> ```
> f(x) = { -x     si x ∈ (-∞, 0)
>        { x      si x ∈ [0, +∞)
> ```
>
> **Forma 3 - Usando desigualdades:**
> ```
> f(x) = { x + 3           si -2 ≤ x < 1
>        { -2x + 4         si 1 ≤ x ≤ 3
>        { (x - 3)²        si x > 3
> ```
>
> **Forma 4 - Notación con conjuntos:**
> ```
> f: ℝ → ℝ
> 
> f(x) = { |x - 2|    si x ∈ ℚ ∩ [0, 5]
>        { 1          si x ∈ (ℝ \ ℚ) ∩ (0, 5)
>        { 0          en otro caso
> ```

## 🔢 Cálculo de Dominio y Rango Avanzado

> [!example]- Casos Complejos
>
> **Ejemplo 1 - Con restricciones en cada tramo:**
>
> ```
> f(x) = { √(x + 2)    si -2 ≤ x < 0
>        { 1/x         si 0 < x < 3
>        { ln(x - 3)   si x > 4
> 
> DOMINIO:
> D₁ = [-2, 0): x + 2 ≥ 0 ✓
> D₂ = (0, 3): x ≠ 0 ✓
> D₃ = (4, +∞): x > 3 ✓
> 
> Dom(f) = [-2, 0) ∪ (0, 3) ∪ (4, +∞)
> 
> RANGO:
> Ran₁: x ∈ [-2, 0) ⟹ √(x + 2) ∈ [0, √2)
> Ran₂: x ∈ (0, 3) ⟹ 1/x ∈ (1/3, +∞)
> Ran₃: x ∈ (4, +∞) ⟹ ln(x-3) ∈ (ln(1), +∞) = (0, +∞)
> 
> Ran(f) = [0, √2) ∪ (1/3, +∞) ∪ (0, +∞)
>        = [0, √2) ∪ (1/3, +∞)
> 
> Nota: (1/3, +∞) ∪ (0, +∞) = (0, +∞)
>       [0, √2) ∪ (0, +∞) = [0, +∞)
> ```
>
> **Ejemplo 2 - Rango con valores aislados:**
>
> ```
> f(x) = { x²              si x ∈ (-∞, -1) ∪ (1, +∞)
>        { 1               si x ∈ [-1, 1]
> 
> RANGO:
> Parte 1: x ∈ (-∞, -1) ⟹ x² ∈ (1, +∞)
> Parte 2: x ∈ (1, +∞) ⟹ x² ∈ (1, +∞)
> Parte 3: x ∈ [-1, 1] ⟹ f(x) = 1
> 
> Ran(f) = (1, +∞) ∪ {1} = [1, +∞)
> ```

## ✅ Problemas Resueltos

> [!example]- Ejercicios Completos
>
> **Problema 1:**
>
> Dada:
> ```
> f(x) = { x - 1     si x ≤ 2
>        { 4 - x     si x > 2
> ```
>
> Encuentre:
> a) f(-1), f(2), f(3)
> b) Dominio y rango
> c) ¿Es continua?
>
> **Solución:**
>
> a) Evaluaciones:
> ```
> f(-1): -1 ≤ 2, usar f(x) = x - 1
> f(-1) = -1 - 1 = -2
> 
> f(2): 2 ≤ 2, usar f(x) = x - 1
> f(2) = 2 - 1 = 1
> 
> f(3): 3 > 2, usar f(x) = 4 - x
> f(3) = 4 - 3 = 1
> ```
>
> b) Dominio y rango:
> ```
> Dom(f) = ℝ
> 
> Tramo 1 (x ≤ 2): f(x) = x - 1
>   Rango: (-∞, 1]
> 
> Tramo 2 (x > 2): f(x) = 4 - x
>   Rango: (-∞, 2)
> 
> Ran(f) = (-∞, 1] ∪ (-∞, 2) = (-∞, 2)
> ```
>
> c) Continuidad en x = 2:
> ```
> lim(x→2⁻) f(x) = 2 - 1 = 1
> lim(x→2⁺) f(x) = 4 - 2 = 2
> f(2) = 1
> 
> 1 ≠ 2, discontinua en x = 2
> Salto de magnitud |2 - 1| = 1
> ```
>
> **Problema 2:**
>
> Defina por tramos la función f(x) = |x² - 4|
>
> **Solución:**
>
> ```
> Paso 1: Encontrar dónde x² - 4 = 0
> x² = 4 ⟹ x = ±2
> 
> Paso 2: Analizar signo
> x² - 4 < 0 cuando -2 < x < 2
> x² - 4 ≥ 0 cuando x ≤ -2 o x ≥ 2
> 
> Paso 3: Aplicar definición de |·|
> Si x² - 4 ≥ 0: |x² - 4| = x² - 4
> Si x² - 4 < 0: |x² - 4| = -(x² - 4) = 4 - x²
> 
> f(x) = { x² - 4     si x ≤ -2 o x ≥ 2
>        { 4 - x²     si -2 < x < 2
> 
> o equivalentemente:
> 
> f(x) = { x² - 4     si |x| ≥ 2
>        { 4 - x²     si |x| < 2
> ```

## 🎓 Integración con Tópicos de Gráficas (Ref. 04.2)

> [!note]- Conexiones Conceptuales
>
> **Simetría en funciones por tramos:**
>
> ```
> Una función por tramos puede ser par o impar
> 
> Ejemplo - Función par:
> f(x) = { 1 - x     si x ≤ -1
>        { x²        si -1 < x ≤ 1
>        { x - 1     si x > 1
> 
> Verificar: f(-x) = f(x) para todo x
> Si x ∈ (1, +∞): f(x) = x - 1
> Si -x ∈ (-∞, -1): -x < -1, entonces
> f(-x) = 1 - (-x) = 1 + x... (requiere ajuste en definición)
> ```
>
> **Asíntotas en funciones por tramos:**
>
> ```
> f(x) = { x                si x < 0
>        { 1/x              si x > 0
> 
> Asíntota vertical: x = 0
> lim(x→0⁻) f(x) = 0
> lim(x→0⁺) f(x) = +∞
> 
> Asíntota horizontal: y = 0
> lim(x→-∞) f(x) = -∞ (no horizontal)
> lim(x→+∞) f(x) = 0
> ```
>
> **Crecimiento/Decrecimiento:**
>
> ```
> f(x) = { -x      si x < -2
>        { 1       si -2 ≤ x ≤ 2
>        { x - 4   si x > 2
> 
> Intervalos:
> (-∞, -2): f'(x) = -1 < 0, decreciente
> (-2, 2): f'(x) = 0, constante
> (2, +∞): f'(x) = 1 > 0, creciente
> 
> Mínimo local en x = 2: f(2) = -2... (verificar)
> ```
>
> **Interceptos en funciones por tramos:**
>
> ```
> f(x) = { x² - 1     si x ≤ 0
>        { 2x - 2     si x > 0
> 
> Intercepto y: f(0) = 0² - 1 = -1
> Punto: (0, -1)
> 
> Interceptos x:
> Tramo 1: x² - 1 = 0 ⟹ x = ±1, pero solo x = -1 cumple x ≤ 0
> Punto: (-1, 0)
> 
> Tramo 2: 2x - 2 = 0 ⟹ x = 1, cumple x > 0
> Punto: (1, 0)
> 
> Interceptos totales: (-1, 0) y (1, 0)
> ```

## 💡 Estrategias de Resolución

> [!tip]- Consejos Prácticos
>
> **Para graficar:**
> 1. Identificar todos los tramos y sus dominios
> 2. Graficar cada subfunción como si fuera independiente
> 3. "Recortar" cada gráfica al dominio del tramo
> 4. Prestar especial atención a los puntos frontera:
>    - ¿Está incluido el punto (paréntesis [ o ])  
>    - ¿Cuál es el valor de f en ese punto?
> 5. Marcar con ● si incluido, ○ si no
> 6. Verificar continuidad comparando límites laterales
>
> **Para evaluar:**
> 1. Leer cuidadosamente cuál es el tramo
> 2. Verificar que x pertenece a ese intervalo
> 3. Usar SOLO la expresión de ese tramo
> 4. Calcular sustituyendo el valor
>
> **Para encontrar dominio:**
> 1. Unir los dominios de cada tramo
> 2. Verificar que no hay huecos
> 3. Verificar que los puntos frontera estén asignados
>
> **Para encontrar rango:**
> 4. Para cada tramo, calcular su rango en su dominio
> 5. Unir todos los rangos parciales
> 6. Simplificar la unión si hay solapamiento
