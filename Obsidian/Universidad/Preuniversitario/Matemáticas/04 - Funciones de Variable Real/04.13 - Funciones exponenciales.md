# 📈 Funciones Exponenciales

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Una función exponencial es aquella donde la variable independiente aparece en el exponente. Representa crecimiento o decrecimiento multiplicativo constante.**
> 
> **Elementos clave:**
> 
> - **Base constante:** a > 0, a ≠ 1
> - **Exponente variable:** x ∈ ℝ
> - **Forma:** f(x) = aˣ
> - **Crecimiento/Decrecimiento:** Multiplicación repetida
> - **Ubicuidad:** Naturaleza, finanzas, ciencias

### 📖 Contexto Histórico

> [!note]- Desarrollo Histórico
> 
> **Orígenes (1600-1700):**
> 
> - **Napier (1614):** Logaritmos (función inversa)
> - **Descartes (1637):** Notación de exponentes
> - **Wallis (1656):** Exponentes negativos y fraccionarios
> 
> **Formalización (1700-1800):**
> 
> - **Euler (1748):** Define eˣ mediante series
> - **Euler:** Descubre e ≈ 2.71828...
> - **Conexión:** eˣ, ln(x), y trigonometría compleja
> 
> **Era Moderna (1800-presente):**
> 
> - **Aplicaciones:** Crecimiento poblacional, radiactividad
> - **Física:** Ley de enfriamiento, desintegración
> - **Economía:** Interés compuesto continuo

## 📐 Definición Formal

> [!success]- Definición Matemática
> 
> **Definición:** Una **función exponencial** de base a es:
> 
> ```
> f(x) = aˣ
> 
> donde:
> - a ∈ ℝ⁺ \ {1}  (base positiva, distinta de 1)
> - x ∈ ℝ         (exponente variable)
> ```
> 
> **Restricciones sobre la base:**
> 
> - **a > 0:** Para garantizar valores reales
> - **a ≠ 1:** Para evitar función constante (1ˣ = 1)
> 
> **Propiedades fundamentales:**
> 
> ```
> Dom(f) = ℝ
> Ran(f) = (0, +∞)
> f(0) = a⁰ = 1
> f(1) = a¹ = a
> ```

## 🎯 Características Principales

> [!important]- Propiedades Básicas
> 
> **1. Dominio y Rango:**
> 
> ```
> f(x) = aˣ
> 
> Dominio: ℝ (todos los reales)
> Rango: (0, +∞) (siempre positiva)
> ```
> 
> **2. Comportamiento según la base:**
> 
> ```
> Si a > 1:  Función CRECIENTE
> - lim(x→-∞) aˣ = 0
> - lim(x→+∞) aˣ = +∞
> - Asíntota horizontal: y = 0 (x → -∞)
> 
> Si 0 < a < 1:  Función DECRECIENTE
> - lim(x→-∞) aˣ = +∞
> - lim(x→+∞) aˣ = 0
> - Asíntota horizontal: y = 0 (x → +∞)
> ```
> 
> **3. Puntos característicos:**
> 
> ```
> Intercepto con eje y: (0, 1)
> Pasa por: (1, a)
> No intercepta eje x (siempre > 0)
> ```
> 
> **4. Inyectividad:**
> 
> ```
> aˣ¹ = aˣ² ⟺ x₁ = x₂
> 
> Es función uno a uno (tiene inversa)
> ```

## 🔢 El Número e

> [!success]- La Base Natural
> **Definición del número e:**
> 
> ```
> e = lim(n→∞) (1 + 1/n)ⁿ ≈ 2.718281828...
> 
> También:
> e = Σ(n=0 to ∞) 1/n! = 1 + 1/1! + 1/2! + 1/3! + ...
> ```
> 
> **Función exponencial natural:**
> 
> ```
> f(x) = eˣ  o  f(x) = exp(x)
> 
> La más importante en matemáticas
> Única función que es su propia derivada: d/dx(eˣ) = eˣ
> ```
> 
> **Propiedades especiales de e:**
> 
> - Base natural de logaritmos
> - Aparece en cálculo, probabilidad, análisis complejo
> - Relaciona exponenciales y trigonometría: e^(ix) = cos(x) + i·sin(x)
> - Valor irracional y trascendente

## 📊 Leyes de Exponentes

> [!tip]- Álgebra de Exponenciales
> 
> **Leyes fundamentales:**
> 
> ```
> 1. aˣ · aʸ = aˣ⁺ʸ           (producto)
> 2. aˣ / aʸ = aˣ⁻ʸ           (cociente)
> 3. (aˣ)ʸ = aˣʸ              (potencia de potencia)
> 4. (ab)ˣ = aˣ · bˣ          (producto de bases)
> 5. (a/b)ˣ = aˣ / bˣ         (cociente de bases)
> 6. a⁰ = 1                   (exponente cero)
> 7. a⁻ˣ = 1/aˣ               (exponente negativo)
> 8. a^(1/n) = ⁿ√a            (exponente fraccionario)
> ```
> 
> **Para base e:**
> 
> ```
> eˣ · eʸ = eˣ⁺ʸ
> eˣ / eʸ = eˣ⁻ʸ
> (eˣ)ʸ = eˣʸ
> e⁻ˣ = 1/eˣ
> e⁰ = 1
> ```

## 📈 Transformaciones

> [!note]- Familia de Funciones Exponenciales
> 
> **Forma general:**
> 
> ```
> f(x) = A · aᵏˣ⁺ᶜ + D
> 
> Parámetros:
> - A: factor de escala vertical (estiramiento/reflexión)
> - a: base
> - k: factor de escala horizontal
> - c: traslación horizontal
> - D: traslación vertical
> ```
> 
> **Transformaciones comunes:**
> 
> ```
> f(x) = aˣ⁺ᶜ         Traslación horizontal c unidades
> f(x) = aˣ + D       Traslación vertical D unidades  
> f(x) = A·aˣ         Estiramiento vertical por |A|
>                     Reflexión en x si A < 0
> f(x) = aᵏˣ          Compresión (k>1) o estiramiento (0<k<1)
> f(x) = a⁻ˣ          Reflexión sobre eje y
> ```
> 
> **Asíntotas:**
> 
> ```
> f(x) = aˣ + D  ⟹  Asíntota horizontal: y = D
> ```

## 🎯 Ecuaciones Exponenciales

> [!example]- Métodos de Resolución
> 
> **Método 1 - Igualar bases:**
> 
> ```
> 2ˣ = 16
> 2ˣ = 2⁴
> x = 4
> ```
> 
> **Método 2 - Sustitución:**
> 
> ```
> 4ˣ - 5·2ˣ + 4 = 0
> Sea u = 2ˣ ⟹ 4ˣ = (2ˣ)² = u²
> u² - 5u + 4 = 0
> (u - 4)(u - 1) = 0
> u = 4 o u = 1
> 
> 2ˣ = 4 ⟹ x = 2
> 2ˣ = 1 ⟹ x = 0
> ```
> 
> **Método 3 - Logaritmos:**
> 
> ```
> 3ˣ = 7
> ln(3ˣ) = ln(7)
> x·ln(3) = ln(7)
> x = ln(7)/ln(3)
> ```
> 
> **Método 4 - Cambio de base:**
> 
> ```
> 2ˣ = 3ˣ⁻¹
> ln(2ˣ) = ln(3ˣ⁻¹)
> x·ln(2) = (x-1)·ln(3)
> x·ln(2) = x·ln(3) - ln(3)
> x(ln(2) - ln(3)) = -ln(3)
> x = -ln(3)/(ln(2) - ln(3))
> ```

## 🌍 Aplicaciones

> [!example]- Modelos del Mundo Real
> 
> **1. Crecimiento poblacional:**
> 
> ```
> P(t) = P₀·eʳᵗ
> 
> P₀: población inicial
> r: tasa de crecimiento
> t: tiempo
> ```
> 
> **2. Interés compuesto continuo:**
> 
> ```
> A(t) = P·eʳᵗ
> 
> P: capital inicial
> r: tasa de interés anual
> t: tiempo en años
> ```
> 
> **3. Desintegración radiactiva:**
> 
> ```
> N(t) = N₀·e⁻ᵏᵗ
> 
> N₀: cantidad inicial
> k: constante de desintegración
> Vida media: t₁/₂ = ln(2)/k
> ```
> 
> **4. Ley de enfriamiento de Newton:**
> 
> ```
> T(t) = Tₐ + (T₀ - Tₐ)·e⁻ᵏᵗ
> 
> T₀: temperatura inicial
> Tₐ: temperatura ambiente
> k: constante de enfriamiento
> ```
> 
> **5. Difusión de información:**
> 
> ```
> N(t) = L/(1 + Ce⁻ᵏᵗ)  (logística)
> 
> L: límite de población
> C, k: constantes
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes
> 
> **1. "aˣ puede ser negativo"**
> 
> ```
> ✗ INCORRECTO
> aˣ > 0 siempre (a > 0)
> Rango: (0, +∞), no ℝ
> ```
> 
> **2. "aˣ⁺ʸ = aˣ + aʸ"**
> 
> ```
> ✗ INCORRECTO
> ✓ CORRECTO: aˣ⁺ʸ = aˣ · aʸ
> 
> Ejemplo: 2³⁺² = 2⁵ = 32
>          2³ + 2² = 8 + 4 = 12 ≠ 32
> ```
> 
> **3. "Si aˣ = bˣ entonces a = b"**
> 
> ```
> ✗ INCORRECTO en general
> Solo cierto si x ≠ 0
> 
> Ejemplo: a⁰ = b⁰ = 1 para cualquier a, b
> ```
> 
> **4. "eˣ = e·x"**
> 
> ```
> ✗ INCORRECTO
> eˣ: exponencial (multiplicación repetida)
> e·x: producto simple
> 
> e² ≈ 7.389 ≠ e·2 ≈ 5.436
> ```

## 🔗 Relación con Logaritmos

> [!important]- Funciones Inversas
> 
> **Relación fundamental:**
> 
> ```
> y = aˣ  ⟺  x = logₐ(y)
> 
> Exponencial y logaritmo son inversas
> ```
> 
> **Composición:**
> 
> ```
> logₐ(aˣ) = x  para todo x ∈ ℝ
> aˡᵒᵍᵃ⁽ʸ⁾ = y  para todo y > 0
> ```
> 
> **Para base e:**
> 
> ```
> ln(eˣ) = x
> eˡⁿ⁽ˣ⁾ = x (x > 0)
> ```

## 💡 Estrategias de Resolución

> [!tip]- Cómo Abordar Problemas
> 
> **Para graficar:**
> 
> 1. Identificar base (creciente/decreciente)
> 2. Marcar puntos clave: (0,1), (1,a)
> 3. Dibujar asíntota horizontal
> 4. Aplicar transformaciones
> 
> **Para resolver ecuaciones:**
> 
> 1. Intentar igualar bases
> 2. Si no es posible, usar logaritmos
> 3. Para ecuaciones cuadráticas en aˣ, sustituir
> 
> **Para aplicaciones:**
> 
> 4. Identificar si hay crecimiento o decaimiento
> 5. Determinar constantes del modelo
> 6. Verificar unidades y contexto físico
