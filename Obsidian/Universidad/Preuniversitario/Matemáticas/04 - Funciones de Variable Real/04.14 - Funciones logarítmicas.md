# 📉 Funciones Logarítmicas

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Una función logarítmica es la inversa de una función exponencial. Responde a la pregunta: ¿a qué exponente debo elevar la base para obtener un número dado?**
> 
> **Elementos clave:**
> 
> - **Inversa de exponencial:** Si y = aˣ, entonces x = logₐ(y)
> - **Pregunta fundamental:** logₐ(x) = "¿qué potencia de a da x?"
> - **Base:** a > 0, a ≠ 1
> - **Argumento:** x > 0 (debe ser positivo)
> - **Notación:** logₐ(x) o log_a(x)

### 📖 Contexto Histórico

> [!note]- Desarrollo Histórico
> 
> **Invención (1600-1620):**
> 
> - **John Napier (1614):** Inventa logaritmos
> - **Motivación:** Simplificar cálculos astronómicos
> - **Idea:** Convertir multiplicaciones en sumas
> - **Tablas de Napier:** Primeras tablas logarítmicas
> 
> **Desarrollo (1620-1650):**
> 
> - **Henry Briggs (1617):** Logaritmos decimales (base 10)
> - **Tablas mejoradas:** Precisión de 14 decimales
> - **Reglas de cálculo:** Instrumentos basados en logaritmos
> 
> **Formalización (1700-1800):**
> 
> - **Euler (1748):** Define logaritmo natural (base e)
> - **Notación ln:** Logarithmus naturalis
> - **Conexión con áreas:** ln(x) = ∫₁ˣ (1/t) dt
> - **Series:** Representación como series infinitas
> 
> **Era Moderna (1800-presente):**
> 
> - **Escalas logarítmicas:** pH, decibeles, Richter
> - **Teoría de números:** Distribución de primos
> - **Complejidad computacional:** O(log n)
> - **Procesamiento digital:** Compresión, audio

## 📐 Definición Formal

> [!success]- Definición Matemática
> 
> **Definición:** El **logaritmo en base a** de x es el exponente al que hay que elevar a para obtener x:
> 
> ```
> y = logₐ(x)  ⟺  aʸ = x
> 
> donde:
> - a ∈ ℝ⁺ \ {1}  (base positiva, distinta de 1)
> - x ∈ ℝ⁺        (argumento positivo)
> - y ∈ ℝ         (resultado puede ser cualquier real)
> ```
> 
> **Función logarítmica:**
> 
> ```
> f(x) = logₐ(x)
> 
> Dom(f) = (0, +∞)
> Ran(f) = ℝ
> ```
> 
> **Relación con exponencial:**
> 
> ```
> f(x) = aˣ  y  g(x) = logₐ(x)  son inversas
> 
> f(g(x)) = a^(logₐ(x)) = x  (x > 0)
> g(f(x)) = logₐ(aˣ) = x     (x ∈ ℝ)
> ```
> 
> **Casos especiales:**
> 
> ```
> logₐ(1) = 0    (porque a⁰ = 1)
> logₐ(a) = 1    (porque a¹ = a)
> logₐ(aˣ) = x   (identidad)
> a^(logₐ(x)) = x (identidad)
> ```

## 🎯 Logaritmos Importantes

> [!important]- Tres Bases Principales
> 
> **1. Logaritmo natural (base e):**
> 
> ```
> ln(x) = logₑ(x)
> 
> Base: e ≈ 2.71828...
> Notación: ln (logarithmus naturalis)
> El más importante en matemáticas avanzadas
> 
> Definición integral:
> ln(x) = ∫₁ˣ (1/t) dt  (x > 0)
> ```
> 
> **2. Logaritmo decimal (base 10):**
> 
> ```
> log(x) = log₁₀(x)
> 
> Base: 10
> Notación: log (sin subíndice implica base 10)
> Usado en ciencias aplicadas
> 
> Aplicaciones:
> - Escala pH
> - Decibeles (dB)
> - Escala de Richter
> ```
> 
> **3. Logaritmo binario (base 2):**
> 
> ```
> log₂(x) = lb(x)
> 
> Base: 2
> Notación: log₂ o lb
> Usado en computación
> 
> Aplicaciones:
> - Teoría de información
> - Complejidad de algoritmos
> - Bits de información
> ```

## 📊 Propiedades de Logaritmos

> [!tip]- Leyes Fundamentales
> 
> **Leyes de logaritmos:**
> 
> ```
> 1. logₐ(xy) = logₐ(x) + logₐ(y)         (producto)
> 2. logₐ(x/y) = logₐ(x) - logₐ(y)        (cociente)
> 3. logₐ(xⁿ) = n·logₐ(x)                 (potencia)
> 4. logₐ(ⁿ√x) = logₐ(x)/n                (raíz)
> 5. logₐ(1) = 0                          (logaritmo de 1)
> 6. logₐ(a) = 1                          (logaritmo de la base)
> 7. logₐ(aˣ) = x                         (identidad 1)
> 8. a^(logₐ(x)) = x                      (identidad 2)
> ```
> 
> **Cambio de base:**
> 
> ```
> logₐ(x) = logᵦ(x)/logᵦ(a)
> 
> Casos especiales:
> logₐ(x) = ln(x)/ln(a)
> logₐ(x) = log(x)/log(a)
> log₂(x) = ln(x)/ln(2)
> ```
> 
> **Relación entre logaritmos:**
> 
> ```
> logₐ(b) · logᵦ(a) = 1
> logₐ(b) = 1/logᵦ(a)
> 
> Ejemplo: log₂(8) · log₈(2) = 3 · (1/3) = 1
> ```
> 
> **Propiedades de potencias:**
> 
> ```
> logₐⁿ(x) = (1/n)·logₐ(x)
> log₁/ₐ(x) = -logₐ(x)
> ```

## 📈 Características de la Gráfica

> [!success]- Comportamiento Geométrico
> 
> **Propiedades básicas:**
> 
> ```
> f(x) = logₐ(x)
> 
> Dominio: (0, +∞)
> Rango: ℝ
> Intercepto con eje x: (1, 0)
> No intercepta eje y
> Asíntota vertical: x = 0 (eje y)
> ```
> 
> **Comportamiento según la base:**
> 
> ```
> Si a > 1:  Función CRECIENTE
> - lim(x→0⁺) logₐ(x) = -∞
> - lim(x→+∞) logₐ(x) = +∞
> - Pasa por (1, 0) y (a, 1)
> - Cóncava hacia abajo
> 
> Si 0 < a < 1:  Función DECRECIENTE
> - lim(x→0⁺) logₐ(x) = +∞
> - lim(x→+∞) logₐ(x) = -∞
> - Pasa por (1, 0) y (a, 1)
> - Cóncava hacia arriba
> ```
> 
> **Puntos característicos:**
> 
> ```
> (1, 0):  logₐ(1) = 0
> (a, 1):  logₐ(a) = 1
> (1/a, -1): logₐ(1/a) = -1
> (a², 2):  logₐ(a²) = 2
> ```
> 
> **Simetría con exponencial:**
> 
> ```
> y = logₐ(x) es reflexión de y = aˣ
> sobre la recta y = x
> 
> Si (p, q) está en y = aˣ
> entonces (q, p) está en y = logₐ(x)
> ```

## 🔄 Transformaciones

> [!note]- Familia de Funciones Logarítmicas
> 
> **Forma general:**
> 
> ```
> f(x) = A·logₐ(k(x - h)) + v
> 
> Parámetros:
> - A: escala vertical (estiramiento/reflexión)
> - k: escala horizontal
> - h: traslación horizontal
> - v: traslación vertical
> - a: base
> ```
> 
> **Transformaciones comunes:**
> 
> ```
> f(x) = logₐ(x - h)     Traslación horizontal h
>                        Asíntota: x = h
> 
> f(x) = logₐ(x) + v     Traslación vertical v
>                        Intercepto x: (a⁻ᵛ, 0)
> 
> f(x) = A·logₐ(x)       Estiramiento vertical |A|
>                        Reflexión en x si A < 0
> 
> f(x) = logₐ(kx)        Compresión (k>1) o 
>                        estiramiento (0<k<1)
> 
> f(x) = -logₐ(x)        Reflexión sobre eje x
> 
> f(x) = logₐ(-x)        Reflexión sobre eje y
>                        Dom: (-∞, 0)
> ```
> 
> **Asíntotas verticales:**
> 
> ```
> f(x) = logₐ(x - h)  ⟹  Asíntota: x = h
> f(x) = logₐ(ax + b) ⟹  Asíntota: ax + b = 0
>                                   x = -b/a
> ```

## 🎯 Ecuaciones Logarítmicas

> [!example]- Métodos de Resolución
> 
> **Método 1 - Definición de logaritmo:**
> 
> ```
> log₂(x) = 5
> 
> Por definición:
> 2⁵ = x
> x = 32
> ```
> 
> **Método 2 - Igualar logaritmos:**
> 
> ```
> log₃(x + 2) = log₃(10)
> 
> Como las bases son iguales:
> x + 2 = 10
> x = 8
> 
> Verificar: x + 2 > 0 ✓
> ```
> 
> **Método 3 - Propiedades de logaritmos:**
> 
> ```
> log(x) + log(x + 3) = 1
> 
> log(x(x + 3)) = 1
> log(x² + 3x) = 1
> x² + 3x = 10¹ = 10
> x² + 3x - 10 = 0
> (x + 5)(x - 2) = 0
> 
> x = -5 (rechazar, x > 0)
> x = 2 ✓
> 
> Verificar: x > 0 y x + 3 > 0 ✓
> ```
> 
> **Método 4 - Cambio de variable:**
> 
> ```
> (log(x))² - 3log(x) + 2 = 0
> 
> Sea u = log(x):
> u² - 3u + 2 = 0
> (u - 2)(u - 1) = 0
> u = 2 o u = 1
> 
> log(x) = 2  ⟹  x = 10² = 100
> log(x) = 1  ⟹  x = 10¹ = 10
> ```
> 
> **Método 5 - Exponenciación:**
> 
> ```
> ln(x - 1) + ln(x + 1) = ln(3)
> 
> ln((x - 1)(x + 1)) = ln(3)
> (x - 1)(x + 1) = 3
> x² - 1 = 3
> x² = 4
> x = ±2
> 
> x = 2 ✓ (x - 1 > 0 y x + 1 > 0)
> x = -2 ✗ (x - 1 = -3 < 0)
> ```

## ⚖️ Ecuaciones Exponenciales con Logaritmos

> [!tip]- Usar Logaritmos para Resolver
> 
> **Estrategia general:**
> 
> ```
> Si aˣ = b, entonces x = logₐ(b)
> 
> O usando logaritmo natural:
> ln(aˣ) = ln(b)
> x·ln(a) = ln(b)
> x = ln(b)/ln(a)
> ```
> 
> **Ejemplos:**
> 
> ```
> 1) 5ˣ = 20
>    x = log₅(20) = ln(20)/ln(5) ≈ 1.861
> 
> 2) 3²ˣ⁺¹ = 10
>    (2x + 1)·ln(3) = ln(10)
>    2x + 1 = ln(10)/ln(3)
>    x = (ln(10)/ln(3) - 1)/2 ≈ 0.548
> 
> 3) e²ˣ = 7
>    2x = ln(7)
>    x = ln(7)/2 ≈ 0.973
> 
> 4) 2ˣ = 3ˣ⁻¹
>    ln(2ˣ) = ln(3ˣ⁻¹)
>    x·ln(2) = (x-1)·ln(3)
>    x·ln(2) = x·ln(3) - ln(3)
>    x(ln(2) - ln(3)) = -ln(3)
>    x = ln(3)/(ln(3) - ln(2)) ≈ 2.710
> ```

## 🌍 Aplicaciones

> [!example]- Modelos del Mundo Real
> 
> **1. Escala de pH (acidez):**
> 
> ```
> pH = -log₁₀([H⁺])
> 
> [H⁺]: concentración de iones hidrógeno (mol/L)
> 
> pH < 7: ácido
> pH = 7: neutro
> pH > 7: básico
> 
> Ejemplo: [H⁺] = 10⁻⁵ M ⟹ pH = 5
> ```
> 
> **2. Decibeles (intensidad de sonido):**
> 
> ```
> L = 10·log₁₀(I/I₀)
> 
> L: nivel de sonido (dB)
> I: intensidad del sonido
> I₀: intensidad de referencia (10⁻¹² W/m²)
> 
> Ejemplos:
> - Susurro: 20 dB
> - Conversación: 60 dB
> - Concierto: 110 dB
> ```
> 
> **3. Escala de Richter (magnitud sísmica):**
> 
> ```
> M = log₁₀(A/A₀)
> 
> M: magnitud
> A: amplitud de onda sísmica
> A₀: amplitud de referencia
> 
> Cada unidad = 10× más energía
> ```
> 
> **4. Vida media (desintegración radiactiva):**
> 
> ```
> Si N(t) = N₀·e⁻ᵏᵗ
> 
> Vida media t₁/₂:
> N₀/2 = N₀·e⁻ᵏᵗ¹ᐟ²
> 1/2 = e⁻ᵏᵗ¹ᐟ²
> ln(1/2) = -k·t₁/₂
> t₁/₂ = ln(2)/k ≈ 0.693/k
> ```
> 
> **5. Tiempo para duplicar (interés compuesto):**
> 
> ```
> Si A = P·eʳᵗ
> 
> Para duplicar (A = 2P):
> 2P = P·eʳᵗ
> 2 = eʳᵗ
> ln(2) = r·t
> t = ln(2)/r ≈ 0.693/r
> 
> Regla del 70: t ≈ 70/(r%) años
> ```
> 
> **6. Complejidad de algoritmos:**
> 
> ```
> Búsqueda binaria: O(log₂(n))
> 
> n elementos ⟹ log₂(n) comparaciones
> n = 1000 ⟹ ~10 comparaciones
> n = 1,000,000 ⟹ ~20 comparaciones
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes
> 
> **1. "log(x + y) = log(x) + log(y)"**
> 
> ```
> ✗ INCORRECTO
> ✓ CORRECTO: log(xy) = log(x) + log(y)
> 
> log(x + y) no se simplifica en general
> 
> Ejemplo: log(3 + 2) = log(5) ≈ 0.699
>          log(3) + log(2) ≈ 0.477 + 0.301 = 0.778
>          0.699 ≠ 0.778
> ```
> 
> **2. "log(x - y) = log(x) - log(y)"**
> 
> ```
> ✗ INCORRECTO
> ✓ CORRECTO: log(x/y) = log(x) - log(y)
> 
> log(x - y) no se simplifica en general
> ```
> 
> **3. "(log(x))ⁿ = n·log(x)"**
> 
> ```
> ✗ INCORRECTO
> ✓ CORRECTO: log(xⁿ) = n·log(x)
> 
> (log(x))ⁿ: elevar el logaritmo a la n
> log(xⁿ): logaritmo de x elevado a la n
> 
> Ejemplo: (log(10))² = 1² = 1
>          log(10²) = 2·log(10) = 2
> ```
> 
> **4. "log(x) puede ser negativo solo si x < 0"**
> 
> ```
> ✗ INCORRECTO
> 
> log(x) < 0 cuando 0 < x < 1 (para base > 1)
> x < 0 no está en el dominio
> 
> Ejemplo: log(0.1) = -1
> ```
> 
> **5. "ln y log son lo mismo"**
> 
> ```
> ✗ INCORRECTO
> 
> ln(x) = logaritmo natural (base e)
> log(x) = logaritmo decimal (base 10)
> 
> ln(100) ≈ 4.605
> log(100) = 2
> ```
> 
> **6. "No verificar dominio en ecuaciones"**
> 
> ```
> log(x) = 2  ⟹  x = 100 ✓
> 
> Pero: log(x - 5) = 2
>       x - 5 = 100
>       x = 105
> 
> Verificar: x - 5 > 0 ⟹ 105 - 5 = 100 > 0 ✓
> ```

> [!note]- Logaritmos vs Exponenciales
> 
> |Propiedad|Exponencial f(x) = aˣ|Logarítmica g(x) = logₐ(x)|
> |---|---|---|
> |Dominio|ℝ|(0, +∞)|

## 🔗 Relaciones Importantes

> [!important]- Conexiones Matemáticas
> 
> **Con exponenciales:**
> 
> ```
> y = aˣ  ⟺  x = logₐ(y)
> 
> Funciones inversas mutuas
> ```
> 
> **Con derivadas:**
> 
> ```
> d/dx(ln(x)) = 1/x
> d/dx(logₐ(x)) = 1/(x·ln(a))
> 
> El logaritmo natural aparece naturalmente
> ```
> 
> **Con integrales:**
> 
> ```
> ∫(1/x)dx = ln|x| + C
> 
> Función primitiva de 1/x
> ```
> 
> **Con números complejos (Euler):**
> 
> ```
> eⁱˣ = cos(x) + i·sin(x)
> ln(z) tiene infinitos valores en ℂ
> ```

## 💡 Estrategias de Resolución

> [!tip]- Cómo Abordar Problemas
> 
> **Para graficar:**
> 
> 1. Identificar base (creciente/decreciente)
> 2. Marcar asíntota vertical (x = h)
> 3. Puntos clave: intercepto x, (a, 1)
> 4. Aplicar transformaciones
> 
> **Para resolver ecuaciones:**
> 
> 1. Aislar el logaritmo si es posible
> 2. Usar propiedades para combinar logaritmos
> 3. Aplicar definición (exponenciar)
> 4. SIEMPRE verificar dominio
> 
> **Para aplicaciones:**
> 
> 1. Identificar si usa log₁₀, ln, o log₂
> 2. Interpretar significado físico
> 3. Verificar unidades
> 4. Contextualizar resultado

## 🎓 Conceptos Clave

> [!important]- Resumen Ejecutivo
> 
> **Definición:**
> 
> - logₐ(x) = y ⟺ aʸ = x
> - Inversa de función exponencial
> - Dom = (0, +∞), Ran = ℝ
> 
> **Tres logaritmos principales:**
> 
> - ln(x): base e (natural)
> - log(x): base 10 (decimal)
> - log₂(x): base 2 (binario)
> 
> **Propiedades esenciales:**
> 
> - log(xy) = log(x) + log(y)
> - log(x/y) = log(x) - log(y)
> - log(xⁿ) = n·log(x)
> - Cambio de base: logₐ(x) = ln(x)/ln(a)
> 
> **Características gráficas:**
> 
> - Asíntota vertical en x = 0
> - Pasa por (1, 0)
> - Crecimiento lento
> - Reflejo de exponencial sobre y = x
> 
> **Aplicaciones:**
> 
> - Escalas: pH, decibeles, Richter
> - Resolver ecuaciones exponenciales
> - Modelaje de crecimiento/decaimiento
> - Complejidad computacional
