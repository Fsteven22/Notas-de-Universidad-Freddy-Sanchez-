# 📊 Funciones Especiales de Variable Real

## 🌟 Introducción

> [!info]- Visión General **Las funciones especiales son familias de funciones que aparecen recurrentemente en matemáticas, ciencias e ingeniería debido a sus propiedades únicas y aplicaciones específicas. Aunque toda función es "especial" en algún sentido, ciertas funciones han ganado este título por su utilidad universal, propiedades notables, o por ser soluciones de ecuaciones importantes.**
> 
> **Características distintivas:**
> 
> - **Ubicuidad:** Aparecen en múltiples contextos
> - **Propiedades únicas:** Comportamientos característicos
> - **Aplicaciones:** Modelan fenómenos específicos
> - **Nomenclatura:** Tienen nombres propios establecidos
> - **Estudio extenso:** Literatura matemática dedicada

### 📖 Motivación Histórica

> [!note]- ¿Por Qué Estudiar Funciones Especiales?
> 
> **Razones matemáticas:**
> 
> - Soluciones de ecuaciones diferenciales importantes
> - Forman bases para espacios de funciones
> - Simplifican expresiones complejas
> - Conectan diferentes áreas de las matemáticas
> 
> **Razones prácticas:**
> 
> - Modelan fenómenos naturales específicos
> - Optimizan cálculos numéricos
> - Estándares en ciencia e ingeniería
> - Implementadas en software matemático
> 
> **Evolución histórica:**
> 
> - Surgieron de problemas aplicados (física, astronomía)
> - Fueron estudiadas antes de tener definiciones rigurosas
> - Se organizaron en familias con propiedades comunes
> - Continúan descubriéndose nuevas funciones especiales

## 🔢 Función Valor Absoluto

> [!success]- Definición y Propiedades Fundamentales
> 
> **Definición:** La **función valor absoluto** mide la distancia de un número real al origen.
> 
> **Notación:**
> 
> ```
> f(x) = |x|
> 
> Se lee: "valor absoluto de x"
>         "módulo de x"
> ```
> 
> **Definición por casos:**
> 
> ```
> |x| = { x   si x ≥ 0
>       { -x  si x < 0
> 
> Equivalentemente:
> |x| = √(x²)
> ```
> 
> **Componentes:**
> 
> ```
> Dom(|x|) = ℝ
> Ran(|x|) = [0, +∞)
> 
> Características:
> - Función par: |−x| = |x|
> - No derivable en x = 0
> - Continua en todo ℝ
> ```
> 
> **Interpretación geométrica:**
> 
> ```
> |x| = distancia de x al origen
> |x - a| = distancia entre x y a
> 
> La gráfica tiene forma de "V"
> Vértice en el origen (0, 0)
> ```

> [!tip]- Propiedades Algebraicas
> 
> **Propiedades fundamentales:**
> 
> ```
> 1) |x| ≥ 0 para todo x ∈ ℝ
> 2) |x| = 0 ⟺ x = 0
> 3) |−x| = |x| (simetría)
> 4) |xy| = |x||y| (multiplicativa)
> 5) |x/y| = |x|/|y|, y ≠ 0
> 6) |x + y| ≤ |x| + |y| (desigualdad triangular)
> 7) ||x| − |y|| ≤ |x − y| (desigualdad triangular inversa)
> 8) |xⁿ| = |x|ⁿ para n ∈ ℕ
> ```
> 
> **Ecuaciones e inecuaciones:**
> 
> ```
> Ecuación: |x| = a
> - Si a < 0: sin solución
> - Si a = 0: x = 0
> - Si a > 0: x = ±a
> 
> Inecuación: |x| < a (a > 0)
> Solución: −a < x < a
> Intervalo: (−a, a)
> 
> Inecuación: |x| > a (a > 0)
> Solución: x < −a o x > a
> Intervalo: (−∞, −a) ∪ (a, +∞)
> 
> Ecuación: |x − c| = a (a > 0)
> Solución: x = c ± a
> 
> Inecuación: |x − c| < a
> Solución: c − a < x < c + a
> ```
> 
> **Identidades útiles:**
> 
> ```
> |x|² = x²
> √(x²) = |x|
> max{x, −x} = |x|
> |x| = x · sgn(x), donde sgn es la función signo
> ```

> [!example]- Aplicaciones y Ejemplos
> 
> **Ejemplo 1 - Distancia:**
> 
> ```
> La distancia entre dos puntos a y b en ℝ:
> d(a, b) = |b − a| = |a − b|
> 
> Ejemplo numérico:
> d(3, −2) = |−2 − 3| = |−5| = 5
> ```
> 
> **Ejemplo 2 - Error absoluto:**
> 
> ```
> Si x es el valor real y x̃ es una aproximación:
> Error absoluto = |x − x̃|
> 
> Ejemplo: π ≈ 3.14159
> Error al usar 3.14: |π − 3.14| ≈ 0.00159
> ```
> 
> **Ejemplo 3 - Función definida con valor absoluto:**
> 
> ```
> f(x) = |x − 2| + |x + 1|
> 
> Puntos críticos: x = 2, x = −1
> 
> Por casos:
> x < −1:     f(x) = −(x−2) − (x+1) = −2x + 1
> −1 ≤ x ≤ 2: f(x) = −(x−2) + (x+1) = 3
> x > 2:      f(x) = (x−2) + (x+1) = 2x − 1
> 
> f(x) = { −2x + 1  si x < −1
>        {    3     si −1 ≤ x ≤ 2
>        {  2x − 1  si x > 2
> 
> Dom(f) = ℝ
> Ran(f) = [3, +∞)
> ```
> 
> **Ejemplo 4 - Desigualdades:**
> 
> ```
> Resolver: |2x − 3| < 5
> 
> Equivalente a: −5 < 2x − 3 < 5
> Sumar 3:      −2 < 2x < 8
> Dividir por 2: −1 < x < 4
> 
> Solución: x ∈ (−1, 4)
> ```
> 
> **Ejemplo 5 - Modelado:**
> 
> ```
> Temperatura que varía alrededor de 20°C:
> T(t) = 20 + 5|sin(πt/12)|
> 
> t en horas, 0 ≤ t ≤ 24
> 
> El valor absoluto asegura que la variación
> sea siempre positiva (calor)
> 
> Rango de temperatura: [20, 25]°C
> ```

## 🔺 Función Parte Entera (Piso)

> [!success]- Definición y Características
> 
> **Definición:** La **función parte entera** o **función piso** asigna a cada número real el mayor entero menor o igual que él.
> 
> **Notación:**
> 
> ```
> f(x) = ⌊x⌋
> 
> Se lee: "piso de x"
>         "parte entera de x"
>         "floor de x"
> 
> Notación alternativa: [x], E(x), int(x)
> ```
> 
> **Definición formal:**
> 
> ```
> ⌊x⌋ = max{n ∈ ℤ : n ≤ x}
> 
> Equivalentemente:
> ⌊x⌋ = n ⟺ n ≤ x < n + 1, donde n ∈ ℤ
> ```
> 
> **Características:**
> 
> ```
> Dom(⌊x⌋) = ℝ
> Ran(⌊x⌋) = ℤ (conjunto discreto)
> 
> Propiedades:
> - Discontinua en cada entero
> - Continua por la derecha en enteros
> - No derivable en enteros
> - Creciente (no estrictamente)
> ```
> 
> **Gráfica:**
> 
> ```
> Función escalonada
> Saltos de altura 1 en cada entero
> Segmentos horizontales en [n, n+1)
> 
>   3 |     ___
>   2 |   ___|
>   1 | ___|
>   0 |___| 
>  -1 |_____|_____|_____
>      -1   0   1   2   3
> ```

> [!tip]- Propiedades y Relaciones
> 
> **Propiedades fundamentales:**
> 
> ```
> 1) ⌊x⌋ ≤ x < ⌊x⌋ + 1
> 2) x − 1 < ⌊x⌋ ≤ x
> 3) ⌊x⌋ = x ⟺ x ∈ ℤ
> 4) ⌊x + n⌋ = ⌊x⌋ + n, n ∈ ℤ
> 5) ⌊−x⌋ = −⌈x⌉ (relación con techo)
> 6) ⌊x⌋ + ⌊−x⌋ = { 0  si x ∈ ℤ
>                  { −1 si x ∉ ℤ
> ```
> 
> **Operaciones:**
> 
> ```
> En general: ⌊x + y⌋ ≠ ⌊x⌋ + ⌊y⌋
> Pero: ⌊x⌋ + ⌊y⌋ ≤ ⌊x + y⌋ ≤ ⌊x⌋ + ⌊y⌋ + 1
> 
> Ejemplo de desigualdad:
> ⌊1.7⌋ + ⌊2.3⌋ = 1 + 2 = 3
> ⌊1.7 + 2.3⌋ = ⌊4⌋ = 4
> 3 ≠ 4
> ```
> 
> **Parte fraccionaria:**
> 
> ```
> {x} = x − ⌊x⌋
> 
> Propiedades:
> - 0 ≤ {x} < 1
> - {x} = 0 ⟺ x ∈ ℤ
> - {x + n} = {x}, n ∈ ℤ (periódica)
> 
> Descomposición:
> x = ⌊x⌋ + {x}
> (parte entera + parte fraccionaria)
> ```
> 
> **Identidades útiles:**
> 
> ```
> ⌊⌊x⌋⌋ = ⌊x⌋
> ⌊x/n⌋ = cantidad de múltiplos de n en [0, x)
> ⌊√n⌋² ≤ n < (⌊√n⌋ + 1)²
> ```

> [!example]- Aplicaciones Prácticas
> 
> **Ejemplo 1 - Conversión de unidades:**
> 
> ```
> Convertir 247 minutos a horas y minutos:
> 
> Horas completas: ⌊247/60⌋ = ⌊4.1167⌋ = 4
> Minutos restantes: 247 − 60·4 = 7
> 
> Resultado: 4 horas y 7 minutos
> ```
> 
> **Ejemplo 2 - Redondeo hacia abajo:**
> 
> ```
> Precio con descuento del 15%:
> Precio original: $47.85
> Descuento: 0.15 × 47.85 = 7.1775
> Precio con descuento: ⌊47.85 − 7.18⌋ = ⌊40.67⌋ = $40
> 
> (redondeando al entero inferior)
> ```
> 
> **Ejemplo 3 - Conteo de elementos:**
> 
> ```
> ¿Cuántos números enteros hay en [a, b]?
> 
> Cantidad = ⌊b⌋ − ⌊a⌋ + 1 (si a ≤ b)
> 
> Ejemplo: enteros en [2.5, 7.8]
> ⌊7.8⌋ − ⌊2.5⌋ + 1 = 7 − 2 + 1 = 6
> (son: 3, 4, 5, 6, 7, 8)
> ```
> 
> **Ejemplo 4 - Función diente de sierra:**
> 
> ```
> f(x) = x − ⌊x⌋ = {x}
> 
> Función periódica de período 1
> Valores en [0, 1)
> 
> Aplicación: señales de reloj digital
> ```
> 
> **Ejemplo 5 - Teoría de números:**
> 
> ```
> Cantidad de divisores de n menores o iguales a √n:
> d(n) = Σ(k=1 to ⌊√n⌋) [n mod k = 0]
> 
> Ejemplo: n = 12, √12 ≈ 3.46, ⌊√12⌋ = 3
> Divisores ≤ 3: 1, 2, 3
> Cantidad: 3
> ```

## 🔻 Función Techo

> [!success]- Complemento de la Función Piso
> 
> **Definición:** La **función techo** asigna a cada número real el menor entero mayor o igual que él.
> 
> **Notación:**
> 
> ```
> f(x) = ⌈x⌉
> 
> Se lee: "techo de x"
>         "ceiling de x"
> ```
> 
> **Definición formal:**
> 
> ```
> ⌈x⌉ = min{n ∈ ℤ : n ≥ x}
> 
> Equivalentemente:
> ⌈x⌉ = n ⟺ n − 1 < x ≤ n, donde n ∈ ℤ
> ```
> 
> **Características:**
> 
> ```
> Dom(⌈x⌉) = ℝ
> Ran(⌈x⌉) = ℤ
> 
> Propiedades:
> - Discontinua en cada entero
> - Continua por la izquierda en enteros
> - Creciente (no estrictamente)
> ```
> 
> **Relación con piso:**
> 
> ```
> ⌈x⌉ = −⌊−x⌋
> 
> ⌈x⌉ = { ⌊x⌋      si x ∈ ℤ
>       { ⌊x⌋ + 1  si x ∉ ℤ
> 
> ⌈x⌉ − ⌊x⌋ = { 0  si x ∈ ℤ
>             { 1  si x ∉ ℤ
> ```

> [!tip]- Propiedades y Uso
> 
> **Propiedades principales:**
> 
> ```
> 1) ⌈x⌉ − 1 < x ≤ ⌈x⌉
> 2) x ≤ ⌈x⌉ < x + 1
> 3) ⌈x⌉ = x ⟺ x ∈ ℤ
> 4) ⌈x + n⌉ = ⌈x⌉ + n, n ∈ ℤ
> 5) ⌈x/n⌉ = ⌊(x + n − 1)/n⌋, n > 0
> ```
> 
> **Aplicaciones típicas:**
> 
> ```
> Redondeo hacia arriba
> Cálculo de recursos necesarios (no se pueden fraccionar)
> División con redondeo superior
> Asignación de espacios discretos
> ```

> [!example]- Ejemplos de Aplicación
> 
> **Ejemplo 1 - Empaquetado:**
> 
> ```
> Tenemos 47 libros y cajas que contienen 12 libros cada una.
> ¿Cuántas cajas necesitamos?
> 
> Cajas = ⌈47/12⌉ = ⌈3.9167⌉ = 4
> 
> (No podemos usar 3.9167 cajas, necesitamos 4 completas)
> ```
> 
> **Ejemplo 2 - Escaleras:**
> 
> ```
> Altura a cubrir: 2.8 metros
> Cada escalón tiene 20 cm de altura
> 
> Escalones = ⌈280/20⌉ = ⌈14⌉ = 14
> 
> (Se necesitan exactamente 14 escalones)
> ```
> 
> **Ejemplo 3 - Paginación:**
> 
> ```
> Documento de 523 líneas
> Página con 40 líneas
> 
> Páginas = ⌈523/40⌉ = ⌈13.075⌉ = 14
> 
> Se necesitan 14 páginas para el documento completo
> ```
> 
> **Ejemplo 4 - Transporte:**
> 
> ```
> 85 personas, vehículos con capacidad de 15
> 
> Vehículos = ⌈85/15⌉ = ⌈5.667⌉ = 6
> 
> Se requieren 6 vehículos
> ```

## 🔀 Función Signo

> [!success]- Función Indicadora de Signo
> 
> **Definición:** La **función signo** indica el signo algebraico de un número real.
> 
> **Notación:**
> 
> ```
> sgn(x) o sign(x)
> 
> Se lee: "signo de x"
> ```
> 
> **Definición por casos:**
> 
> ```
> sgn(x) = {  1  si x > 0
>          {  0  si x = 0
>          { −1  si x < 0
> 
> Alternativamente:
> sgn(x) = { x/|x|  si x ≠ 0
>          {   0    si x = 0
> ```
> 
> **Características:**
> 
> ```
> Dom(sgn) = ℝ
> Ran(sgn) = {−1, 0, 1}
> 
> Propiedades:
> - Discontinua en x = 0
> - Constante en (−∞, 0), {0}, (0, +∞)
> - Función impar: sgn(−x) = −sgn(x)
> ```
> 
> **Gráfica:**
> 
> ```
>   1 |________●
>     |
>   0 |___●____
>     |   
>  -1 |●________
>     |___|___|___
>       -1  0  1
> 
> Tres segmentos horizontales
> Saltos en x = 0
> ```

> [!tip]- Propiedades y Relaciones
> 
> **Relaciones fundamentales:**
> 
> ```
> 1) sgn(x) · sgn(y) = sgn(xy)
> 2) sgn(xⁿ) = [sgn(x)]ⁿ para n impar
> 3) |x| = x · sgn(x)
> 4) x = |x| · sgn(x)
> 5) sgn(sgn(x)) = sgn(x) (idempotente)
> ```
> 
> **Derivada generalizada:**
> 
> ```
> d/dx sgn(x) = 2δ(x)
> 
> donde δ(x) es la función delta de Dirac
> (distribución, no función ordinaria)
> ```
> 
> **Expresión con límites:**
> 
> ```
> sgn(x) = lim(n→∞) tanh(nx)
> sgn(x) = lim(n→∞) (2/π) arctan(nx)
> ```

> [!example]- Aplicaciones
> 
> **Ejemplo 1 - Valor absoluto:**
> 
> ```
> |x| = x · sgn(x)
> 
> Ejemplo: |−7| = (−7) · sgn(−7) = (−7) · (−1) = 7
> ```
> 
> **Ejemplo 2 - Activación neuronal:**
> 
> ```
> En redes neuronales simples:
> salida = sgn(Σ wᵢxᵢ + b)
> 
> Clasifica en {−1, +1} según la entrada
> ```
> 
> **Ejemplo 3 - Control de dirección:**
> 
> ```
> Movimiento en una dimensión:
> velocidad = v₀ · sgn(x_destino − x_actual)
> 
> - Si objetivo está a la derecha: sgn > 0, mover derecha
> - Si objetivo está a la izquierda: sgn < 0, mover izquierda
> - Si está en el objetivo: sgn = 0, detenerse
> ```

## 📐 Función Parte Fraccionaria

> [!success]- Separando Enteros de Decimales
> 
> **Definición:** La **función parte fraccionaria** extrae la parte decimal de un número.
> 
> **Notación:**
> 
> ```
> {x} = x − ⌊x⌋
> 
> Notación alternativa: frac(x), x mod 1
> ```
> 
> **Definición equivalente:**
> 
> ```
> {x} es el único número en [0, 1) tal que:
> x = ⌊x⌋ + {x}
> ```
> 
> **Características:**
> 
> ```
> Dom({x}) = ℝ
> Ran({x}) = [0, 1)
> 
> Propiedades:
> - Periódica de período 1: {x + n} = {x}, n ∈ ℤ
> - Discontinua en cada entero
> - Continua por la derecha en enteros
> - {x} = 0 ⟺ x ∈ ℤ
> ```
> 
> **Gráfica:**
> 
> ```
> Función "diente de sierra"
>   1 |    /    /    /
>     |   /    /    /
>   ½ |  /    /    /
>     | /    /    /
>   0 |/____/____/____
>     0    1    2    3
> 
> Rampas de 0 a 1 que se repiten
> ```

> [!tip]- Propiedades y Extensiones
> 
> **Propiedades fundamentales:**
> 
> ```
> 1) 0 ≤ {x} < 1
> 2) {x + n} = {x}, n ∈ ℤ
> 3) {−x} = { 0      si x ∈ ℤ
>           { 1−{x}  si x ∉ ℤ
> 4) {{x}} = {x} (idempotente)
> 5) ⌊x⌋ + {x} = x
> ```
> 
> **Relación con módulo:**
> 
> ```
> {x} = x mod 1
> 
> Generalización: x mod p
> Para p > 0: x mod p = x − p⌊x/p⌋
> 
> Rango: [0, p)
> ```
> 
> **Serie de Fourier:**
> 
> ```
> {x} = ½ − (1/π) Σ(n=1 to ∞) sin(2πnx)/n
> 
> Descomposición en frecuencias periódicas
> ```

> [!example]- Aplicaciones y Ejemplos
> 
> **Ejemplo 1 - Obtener decimales:**
> 
> ```
> x = 3.14159
> {x} = 3.14159 − ⌊3.14159⌋ = 3.14159 − 3 = 0.14159
> 
> Parte fraccionaria = 0.14159
> ```
> 
> **Ejemplo 2 - Funciones periódicas:**
> 
> ```
> f(x) = sin(2π{x})
> 
> Periódica de período 1
> En [n, n+1), f(x) = sin(2π(x−n))
> 
> Aplicación: ondas repetitivas
> ```
> 
> **Ejemplo 3 - Reloj analógico:**
> 
> ```
> Posición del minutero en función del tiempo:
> θ(t) = 2π{t/60}
> 
> t en minutos, θ en radianes
> Completa una vuelta cada 60 minutos
> ```
> 
> **Ejemplo 4 - Distribución uniforme:**
> 
> ```
> Si x sigue una distribución uniforme en [0, 1),
> entonces {nx} también lo hace (para n entero)
> 
> Propiedad: equidistribución modulo 1
> ```
> 
> **Ejemplo 5 - Secuencia de Weyl:**
> 
> ```
> xₙ = {nα}, n = 1, 2, 3, ...
> 
> Para α irracional, {xₙ} es densa en [0, 1)
> Aplicación: generación de números cuasi-aleatorios
> ```

## ↗️ Función Rampa

> [!success]- Función Rectificadora Básica
> 
> **Definición:** La **función rampa** es la parte positiva de la identidad.
> 
> **Notación:**
> 
> ```
> R(x) = max{0, x}
> 
> Notación alternativa: x₊, ramp(x), ReLU(x)
> ```
> 
> **Definición por casos:**
> 
> ```
> R(x) = { x  si x ≥ 0
>        { 0  si x < 0
> 
> Equivalentemente:
> R(x) = (x + |x|)/2
> ```
> 
> **Características:**
> 
> ```
> Dom(R) = ℝ
> Ran(R) = [0, +∞)
> 
> Propiedades:
> - Continua en todo ℝ
> - No derivable en x = 0
> - Creciente
> - R(0) = 0
> ```
> 
> **Gráfica:**
> 
> ```
>     |    /
>     |   /
>     |  /
>     | /
>     |/________
>     0
> 
> Cero en (−∞, 0]
> Lineal en [0, +∞)
> ```

> [!tip]- Propiedades y Variantes
> 
> **Relaciones importantes:**
> 
> ```
> 1) R(x) + R(−x) = |x|
> 2) R(x) − R(−x) = x
> 3) R(x) = x · H(x), donde H es Heaviside
> 4) dR/dx = H(x) (excepto en x = 0)
> ```
> 
> **Función rampa desplazada:**
> 
> ```
> R(x − a) = max{0, x − a}
> 
> = { 0      si x < a
>   { x − a  si x ≥ a
> 
> "Enciende" en x = a
> ```
> 
> **Función rampa saturada:**
> 
> ```
> S(x) = { 0  si x ≤ 0
>        { x  si 0 < x < 1
>        { 1  si x ≥ 1
> 
> = min{1, max{0, x}}
> 
> Rampa con límite superior
> ```

> [!example]- Aplicaciones Importantes
> 
> **Ejemplo 1 - ReLU (Redes Neuronales):**
> 
> ```
> Función de activación ReLU:
> f(x) = max{0, x}
> 
> Ventajas:
> - Simple de calcular
> - No satura en positivos
> - Derivada simple: 0 o 1
> 
> Ampliamente usada en deep learning
> ```
> 
> **Ejemplo 2 - Circuitos:**
> 
> ```
> Rectificador de media onda:
> V_out(t) = R(V_in(t))
> 
> Si V_in(t) = V₀sin(ωt):
> V_out(t) = { V₀sin(ωt)  si sin(ωt) > 0
>            {     0       si sin(ωt) ≤ 0
> 
> Elimina semiciclos negativos
> ```
> 
>
> 
> **Ejemplo 3 - Economía (oferta y demanda):**
> 
> ```
> Exceso de demanda:
> E(p) = max{0, D(p) − S(p)}
> 
> donde D(p) = demanda al precio p
>       S(p) = oferta al precio p
> 
> E(p) > 0: escasez
> E(p) = 0: equilibrio o exceso de oferta
> ```
> 
> **Ejemplo 4 - Funciones por tramos:**
> 
> ```
> f(x) = R(x − 1) − R(x − 3)
> 
> = { 0      si x < 1
>   { x − 1  si 1 ≤ x < 3
>   { 2      si x ≥ 3
> 
> Rampa que se "aplana" en x = 3
> ```
> 
> **Ejemplo 5 - Integración:**
> 
> ```
> ∫₀ˣ R(t) dt = ∫₀ˣ max{0, t} dt
> 
> = { 0      si x ≤ 0
>   { x²/2   si x > 0
> 
> Relacionada con funciones spline
> ```

## 🔲 Función Heaviside (Escalón Unitario)

> [!success]- Función de Salto Fundamental
> 
> **Definición:** La **función de Heaviside** representa un salto instantáneo de 0 a 1.
> 
> **Notación:**
> 
> ```
> H(x) o u(x) o θ(x)
> 
> Se lee: "Heaviside de x"
>         "función escalón unitario"
> ```
> 
> **Definiciones comunes:**
> 
> ```
> Definición 1 (clásica):
> H(x) = { 0  si x < 0
>        { 1  si x ≥ 0
> 
> Definición 2 (simétrica):
> H(x) = { 0    si x < 0
>        { 1/2  si x = 0
>        { 1    si x > 0
> 
> Definición 3 (ingenieril):
> H(x) = { 0  si x < 0
>        { 1  si x > 0
>        (indefinida en x = 0)
> ```
> 
> **Características:**
> 
> ```
> Dom(H) = ℝ
> Ran(H) = {0, 1} (o {0, 1/2, 1})
> 
> Propiedades:
> - Discontinua en x = 0
> - Constante en (−∞, 0) y (0, +∞)
> - H(0) depende de la convención
> ```
> 
> **Gráfica:**
> 
> ```
>   1 |_________●
>     |
>   ½ |    ●    (opcional)
>     |
>   0 |●___
>     |___|___|___
>       -1  0  1
> 
> Salto de magnitud 1 en x = 0
> ```

> [!tip]- Propiedades y Derivada Generalizada
> 
> **Propiedades algebraicas:**
> 
> ```
> 1) H(x) + H(−x) = 1 (o depende de H(0))
> 2) H(x) · H(−x) = 0
> 3) H(x)² = H(x) (idempotente)
> 4) H(ax) = H(x) para a > 0
> 5) H(ax) = H(−x) = 1 − H(x) para a < 0
> ```
> 
> **Relación con otras funciones:**
> 
> ```
> R(x) = x · H(x)
> |x| = x · (2H(x) − 1) = x · sgn(x)
> sgn(x) = 2H(x) − 1 (si H(0) = 1/2)
> 
> max{x, 0} = x · H(x)
> min{x, 0} = x · H(−x)
> ```
> 
> **Derivada generalizada (distribución):**
> 
> ```
> dH/dx = δ(x)
> 
> donde δ(x) es la delta de Dirac:
> - δ(x) = 0 para x ≠ 0
> - ∫₋∞^∞ δ(x) dx = 1
> - ∫₋∞^∞ f(x)δ(x) dx = f(0)
> 
> No es función ordinaria, es distribución
> ```
> 
> **Función desplazada:**
> 
> ```
> H(x − a) = { 0  si x < a
>            { 1  si x ≥ a
> 
> Salto en x = a
> "Enciende" la señal en t = a
> ```

> [!example]- Aplicaciones Extensivas
> 
> **Ejemplo 1 - Función por partes:**
> 
> ```
> Construir f(x) = { x²     si x < 1
>                  { 2x−1   si x ≥ 1
> 
> Usando Heaviside:
> f(x) = x²·(1 − H(x−1)) + (2x−1)·H(x−1)
>      = x² − x²·H(x−1) + (2x−1)·H(x−1)
>      = x² + H(x−1)·(2x − 1 − x²)
> ```
> 
> **Ejemplo 2 - Ventana rectangular:**
> 
> ```
> w(x) = H(x − a) − H(x − b), donde a < b
> 
> = { 0  si x < a
>   { 1  si a ≤ x < b
>   { 0  si x ≥ b
> 
> "Enciende" en [a, b)
> 
> Aplicación: filtros, máscaras, señales limitadas
> ```
> 
> **Ejemplo 3 - Transformada de Laplace:**
> 
> ```
> ℒ{H(t)} = ∫₀^∞ H(t)e^(−st) dt = 1/s
> 
> ℒ{H(t−a)} = e^(−as)/s
> 
> Fundamental en análisis de circuitos y sistemas
> ```
> 
> **Ejemplo 4 - Fuerza impulsiva:**
> 
> ```
> Fuerza que se aplica en t = t₀:
> F(t) = F₀ · H(t − t₀)
> 
> F(t) = { 0   si t < t₀  (antes del impulso)
>        { F₀  si t ≥ t₀  (después del impulso)
> 
> Modelo de encendido súbito
> ```
> 
> **Ejemplo 5 - Corriente en circuito:**
> 
> ```
> Interruptor se cierra en t = 0:
> I(t) = I₀(1 − e^(−t/τ)) · H(t)
> 
> H(t) asegura que I = 0 para t < 0
> (antes de cerrar el interruptor)
> ```
> 
> **Ejemplo 6 - Convolución:**
> 
> ```
> Respuesta de sistema lineal:
> y(t) = (h * x)(t) = ∫₋∞^∞ h(τ)x(t−τ) dτ
> 
> Si h(t) es causal: h(t) = h(t) · H(t)
> (respuesta solo para t ≥ 0)
> ```

## 🔺 Función Delta de Dirac

> [!success]- Distribución Fundamental (No es Función Ordinaria)
> 
> **Advertencia:** La delta de Dirac **no es una función en el sentido clásico**, sino una **distribución** o **función generalizada**.
> 
> **Notación:**
> 
> ```
> δ(x)
> 
> Se lee: "delta de Dirac"
>         "impulso unitario"
> ```
> 
> **Propiedades definitorias:**
> 
> ```
> 1) δ(x) = 0 para todo x ≠ 0
> 
> 2) ∫₋∞^∞ δ(x) dx = 1
> 
> 3) Propiedad del muestreo:
>    ∫₋∞^∞ f(x)δ(x−a) dx = f(a)
>    
>    para cualquier función continua f
> ```
> 
> **Interpretación intuitiva:**
> 
> ```
> "Función" infinitamente alta y estrecha en x = 0
> con área total 1
> 
>      ∞ |  |
>        | ||
>        |||
>     ___|||___
>         0
> 
> Concentración infinita en un punto
> ```
> 
> **Como límite de funciones:**
> 
> ```
> δ(x) = lim(ε→0⁺) δₑ(x)
> 
> donde δₑ(x) puede ser:
> 
> 4) Gaussiana: δₑ(x) = (1/√(2πε²))e^(−x²/(2ε²))
> 
> 5) Rectangular: δₑ(x) = { 1/(2ε)  si |x| < ε
>                         { 0       si |x| ≥ ε
> 
> 6) Lorentziana: δₑ(x) = (ε/π)/(x² + ε²)
> 
> 7) Sinc: δₑ(x) = sin(x/ε)/(πx)
> ```

> [!tip]- Propiedades y Operaciones
> 
> **Propiedades fundamentales:**
> 
> ```
> 8) δ(−x) = δ(x) (par)
> 
> 9) δ(ax) = δ(x)/|a|, a ≠ 0
> 
> 10) x·δ(x) = 0
> 
> 11) δ(x²−a²) = [δ(x−a) + δ(x+a)]/(2|a|)
> 
> 12) ∫₋∞^∞ f(x)δ⁽ⁿ⁾(x−a) dx = (−1)ⁿf⁽ⁿ⁾(a)
>    (derivadas de δ)
> ```
> 
> **Relación con Heaviside:**
> 
> ```
> dH/dx = δ(x)
> 
> En sentido de distribuciones:
> ∫₋∞^x δ(t) dt = H(x)
> ```
> 
> **Representación integral:**
> 
> ```
> δ(x) = (1/2π) ∫₋∞^∞ e^(ikx) dk
> 
> Transformada de Fourier de la constante 1
> ```
> 
> **Composición:**
> 
> ```
> Si g(x) tiene ceros simples en x₁, x₂, ..., xₙ:
> 
> δ(g(x)) = Σᵢ δ(x − xᵢ)/|g'(xᵢ)|
> 
> Ejemplo: δ(sin x) = Σ(n∈ℤ) δ(x − nπ)/|cos(nπ)|
> ```

> [!example]- Aplicaciones Físicas y Matemáticas
> 
> **Ejemplo 1 - Carga puntual:**
> 
> ```
> Densidad de carga en x = a:
> ρ(x) = q·δ(x − a)
> 
> Carga total: Q = ∫₋∞^∞ ρ(x) dx = q
> 
> Toda la carga concentrada en un punto
> ```
> 
> **Ejemplo 2 - Impulso mecánico:**
> 
> ```
> Fuerza impulsiva en t = 0:
> F(t) = I·δ(t)
> 
> donde I es el impulso (∫F dt)
> 
> Cambio instantáneo de momentum:
> Δp = ∫₋∞^∞ F(t) dt = I
> ```
> 
> **Ejemplo 3 - Función de Green:**
> 
> ```
> Ecuación diferencial:
> Ly(x) = f(x)
> 
> Si LG(x, ξ) = δ(x − ξ), entonces:
> y(x) = ∫G(x, ξ)f(ξ) dξ
> 
> G es la función de Green del operador L
> ```
> 
> **Ejemplo 4 - Transformada de Fourier:**
> 
> ```
> ℱ{δ(t)} = ∫₋∞^∞ δ(t)e^(−iωt) dt = 1
> 
> La delta tiene todas las frecuencias por igual
> (espectro plano)
> ```
> 
> **Ejemplo 5 - Serie de Fourier:**
> 
> ```
> Tren de impulsos (peine de Dirac):
> 
> Ш(x) = Σ(n=−∞ to ∞) δ(x − nT)
> 
> Impulsos espaciados T unidades
> Aplicación: muestreo de señales
> ```
> 
> **Ejemplo 6 - Identidad integral:**
> 
> ```
> f(x) = ∫₋∞^∞ f(ξ)δ(x − ξ) dξ
> 
> La delta actúa como "identidad" bajo convolución
> δ * f = f
> ```

## 🔤 Función Rectangular (Pulso)

> [!success]- Ventana Básica
> 
> **Definición:** La **función rectangular** o **función pulso** define una ventana unitaria.
> 
> **Notación:**
> 
> ```
> rect(x) o Π(x)
> 
> Se lee: "rect de x"
>         "pulso rectangular"
> ```
> 
> **Definición estándar:**
> 
> ```
> rect(x) = { 0    si |x| > 1/2
>           { 1/2  si |x| = 1/2
>           { 1    si |x| < 1/2
> 
> Equivalentemente:
> rect(x) = H(x + 1/2) − H(x − 1/2)
> ```
> 
> **Características:**
> 
> ```
> Dom(rect) = ℝ
> Ran(rect) = {0, 1/2, 1} (o {0, 1})
> 
> Propiedades:
> - Función par: rect(−x) = rect(x)
> - Soporte compacto: [−1/2, 1/2]
> - ∫₋∞^∞ rect(x) dx = 1
> ```
> 
> **Gráfica:**
> 
> ```
>   1 |   ___
>     |  |   |
>   ½ |__|   |__
>     |
>   0 |________
>     -½  0  ½
> 
> Pulso de altura 1 y ancho 1
> Centrado en el origen
> ```

> [!tip]- Variantes y Generalizaciones
> 
> **Pulso escalado:**
> 
> ```
> rect((x−c)/w) = { 1  si |x−c| < w/2
>                 { 0  en otro caso
> 
> Centrado en x = c
> Ancho w
> ```
> 
> **Función signo mediante rect:**
> 
> ```
> sgn(x) = lim(a→∞) [rect((x−a)/2a) − rect((x+a)/2a)]
> ```
> 
> **Transformada de Fourier:**
> 
> ```
> ℱ{rect(t)} = sinc(f) = sin(πf)/(πf)
> 
> Espectro es una función sinc
> Importante en procesamiento de señales
> ```

> [!example]- Aplicaciones Prácticas
> 
> **Ejemplo 1 - Filtro digital:**
> 
> ```
> Ventana rectangular de datos:
> w(n) = rect(n/N)
> 
> Selecciona N muestras alrededor del origen
> ```
> 
> **Ejemplo 2 - Modulación de pulso:**
> 
> ```
> Señal portadora modulada:
> s(t) = A·cos(ω₀t)·rect(t/T)
> 
> Pulso de duración T centrado en t = 0
> ```
> 
> **Ejemplo 3 - Convolución:**
> 
> ```
> (rect * rect)(x) = Λ(x) (función triangular)
> 
> Λ(x) = { 1 − |x|  si |x| ≤ 1
>        { 0        si |x| > 1
> 
> Auto-convolución de rect produce triángulo
> ```
> 
> **Ejemplo 4 - Ventana de observación:**
> 
> ```
> Señal observada en [0, T]:
> x_obs(t) = x(t)·rect((t − T/2)/T)
> 
> Aísla la señal en el intervalo de interés
> ```

## 📐 Función Triangular

> [!success]- Función Techo Suavizada
> 
> **Definición:** La **función triangular** es un pulso de forma triangular.
> 
> **Notación:**
> 
> ```
> Λ(x) o tri(x)
> 
> Se lee: "lambda de x"
>         "función triangular"
> ```
> 
> **Definición:**
> 
> ```
> Λ(x) = { 1 − |x|  si |x| ≤ 1
>        { 0        si |x| > 1
> 
> Equivalentemente:
> Λ(x) = max{0, 1 − |x|}
> Λ(x) = (1 − |x|)·rect(x/2)
> ```
> 
> **Características:**
> 
> ```
> Dom(Λ) = ℝ
> Ran(Λ) = [0, 1]
> 
> Propiedades:
> - Función par: Λ(−x) = Λ(x)
> - Continua en todo ℝ
> - No derivable en x = ±1, 0
> - Soporte: [−1, 1]
> - ∫₋∞^∞ Λ(x) dx = 1
> ```
> 
> **Gráfica:**
> 
> ```
>   1 |    /\
>     |   /  \
>   ½ |  /    \
>     | /      \
>   0 |/________\
>     -1  0   1
> 
> Triángulo isósceles
> Pico en (0, 1)
> ```

> [!tip]- Propiedades y Construcción
> 
> **Como convolución:**
> 
> ```
> Λ(x) = (rect * rect)(x)
> 
> = ∫₋∞^∞ rect(t)·rect(x−t) dt
> 
> La función triangular es auto-convolución de rect
> ```
> 
> **Por casos:**
> 
> ```
> Λ(x) = { 1 + x  si −1 ≤ x ≤ 0
>        { 1 − x  si 0 < x ≤ 1
>        { 0      en otro caso
> 
> Dos rampas que se encuentran en x = 0
> ```
> 
> **Transformada de Fourier:**
> 
> ```
> ℱ{Λ(t)} = sinc²(f) = [sin(πf)/(πf)]²
> 
> Espectro es sinc al cuadrado
> Mayor concentración en bajas frecuencias que rect
> ```
> 
> **Función triangular escalada:**
> 
> ```
> Λ((x−c)/w) : triángulo centrado en c, base 2w
> ```

> [!example]- Aplicaciones
> 
> **Ejemplo 1 - Interpolación lineal:**
> 
> ```
> Aproximar f(x) usando valores en enteros:
> f̃(x) = Σₙ f(n)·Λ(x − n)
> 
> Conecta puntos con líneas rectas
> ```
> 
> **Ejemplo 2 - Filtro suavizante:**
> 
> ```
> Promediar datos con pesos triangulares:
> y(n) = Σₖ x(k)·Λ((n−k)/w)
> 
> Puntos cercanos tienen más peso
> ```
> 
> **Ejemplo 3 - Ventana de Bartlett:**
> 
> ```
> En análisis espectral:
> w(n) = Λ(2n/N − 1), n = 0, 1, ..., N−1
> 
> Reduce "ringing" en el espectro
> ```
> 
> **Ejemplo 4 - Función de forma:**
> 
> ```
> En elementos finitos, funciones base:
> φᵢ(x) = Λ((x − xᵢ)/h)
> 
> Soportes locales, interpolación continua
> ```

## 🔧 Función sinc

> [!success]- Función Cardinal del Seno
> 
> **Definición:** La **función sinc** es fundamental en teoría de señales y análisis de Fourier.
> 
> **Notación y definiciones:**
> 
> ```
> Definición normalizada:
> sinc(x) = sin(πx)/(πx)
> 
> Definición no normalizada:
> sinc(x) = sin(x)/x
> 
> IMPORTANTE: Usaremos la normalizada
> ```
> 
> **Valor en x = 0:**
> 
> ```
> sinc(0) = lim(x→0) sin(πx)/(πx) = 1
> 
> Por regla de L'Hôpital o serie de Taylor
> ```
> 
> **Características:**
> 
> ```
> Dom(sinc) = ℝ
> Ran(sinc) ⊆ [−0.217..., 1]
> 
> Propiedades:
> - Función par: sinc(−x) = sinc(x)
> - sinc(0) = 1 (máximo global)
> - Ceros en x = ±1, ±2, ±3, ... (enteros no cero)
> - Oscilación amortiguada
> - ∫₋∞^∞ sinc(x) dx = 1
> ```
> 
> **Gráfica:**
> 
> ```
>   1 |    ___
>     |   /   \
>     |  / \_/ \_/
>     | /   '   '
>   0 |/_____________
>     -3 -2 -1 0 1 2 3
> 
> Lóbulo central alto
> Lóbulos laterales decrecientes
> ```

> [!tip]- Propiedades Importantes
> 
> **Ceros:**
> 
> ```
> sinc(n) = 0 para todo n ∈ ℤ \ {0}
> 
> Ceros espaciados uniformemente en enteros
> ```
> 
> **Integral:**
> 
> ```
> ∫₋∞^∞ sinc(x) dx = 1
> 
> ∫₀^∞ sinc(x) dx = π/2
> 
> Integral de Dirichlet
> ```
> 
> **Transformada de Fourier:**
> 
> ```
> ℱ{sinc(t)} = rect(f)
> 
> La sinc es la transformada de la función rectangular
> Dual perfecto: rect ↔ sinc
> ```
> 
> **Producto:**
> 
> ```
> sinc²(x) = ℱ{Λ(t)}
> 
> sinc al cuadrado es transformada del triángulo
> ```
> 
> **Propiedad de interpolación:**
> 
> ```
> Si f(x) = Σₙ aₙ·sinc(x − n), entonces:
> f(n) = aₙ para todo n ∈ ℤ
> 
> Las funciones sinc desplazadas forman base ortogonal
> ```

> [!example]- Aplicaciones Fundamentales
> 
> **Ejemplo 1 - Teorema de muestreo (Shannon-Nyquist):**
> 
> ```
> Señal bandlimitada f(t) se reconstruye desde muestras:
> 
> f(t) = Σₙ f(nT)·sinc((t − nT)/T)
> 
> donde T = 1/(2B), B = ancho de banda
> 
> Interpolación perfecta usando sinc
> ```
> 
> **Ejemplo 2 - Respuesta al impulso ideal:**
> 
> ```
> Filtro pasa-bajos ideal:
> h(t) = 2B·sinc(2Bt)
> 
> donde B = frecuencia de corte
> 
> (No realizable físicamente, pero concepto importante)
> ```
> 
> **Ejemplo 3 - Difracción:**
> 
> ```
> Patrón de difracción por rendija rectangular:
> 
> I(θ) ∝ sinc²(ka·sin(θ))
> 
> k = 2π/λ, a = ancho de rendija
> 
> Máximo central, mínimos en sin(θ) = nλ/a
> ```
> 
> **Ejemplo 4 - Procesamiento de imágenes:**
> 
> ```
> Interpolación de píxeles:
> I(x, y) = ΣᵢΣⱼ I(i,j)·sinc(x−i)·sinc(y−j)
> 
> Reconstrucción suave desde muestreo discreto
> ```
> 
> **Ejemplo 5 - Filtro digital:**
> 
> ```
> Respuesta de FIR (Finite Impulse Response):
> h[n] = sinc((n − N/2)/fc)
> 
> Aproximación truncada del filtro ideal
> ```

## 🎲 Función sigmoide (Logística)

> [!success]- Curva en Forma de S
> 
> **Definición:** La **función sigmoide** o **logística** es una curva suave en forma de S que mapea ℝ → (0, 1).
> 
> **Forma estándar:**
> 
> ```
> σ(x) = 1/(1 + e⁻ˣ)
> 
> Se lee: "sigma de x"
>         "sigmoide de x"
> ```
> 
> **Forma general:**
> 
> ```
> σ(x) = L/(1 + e^(−k(x−x₀)))
> 
> donde:
> L = valor máximo (asíntota superior)
> k = tasa de crecimiento (pendiente)
> x₀ = punto medio (inflexión)
> ```
> 
> **Características:**
> 
> ```
> Dom(σ) = ℝ
> Ran(σ) = (0, 1) (o (0, L) para forma general)
> 
> Propiedades:
> - Continua y suave (C^∞)
> - Estrictamente creciente
> - σ(0) = 1/2
> - lim(x→−∞) σ(x) = 0
> - lim(x→+∞) σ(x) = 1
> - Punto de inflexión en x = 0 (o x₀)
> - Simétrica: σ(−x) + σ(x) = 1
> ```
> 
> **Gráfica:**
> 
> ```
>   1 |         ___
>     |       /
>   ½ |     ●
>     |   /
>   0 |___
>     |___|___|___
>       -2  0  2
> 
> Curva en S
> Transición suave de 0 a 1
> ```

> [!tip]- Propiedades y Derivada
> 
> **Derivada:**
> 
> ```
> dσ/dx = σ(x)·(1 − σ(x))
> 
> = e⁻ˣ/(1 + e⁻ˣ)²
> 
> Máximo de la derivada en x = 0: σ'(0) = 1/4
> ```
> 
> **Propiedades algebraicas:**
> 
> ```
> 1) σ(−x) = 1 − σ(x)
> 2) σ(x) = 1 − σ(−x)
> 3) σ'(x) = σ(x)σ(−x)
> 4) 1/σ(x) = 1 + e⁻ˣ
> 5) logit(σ(x)) = x, donde logit(p) = ln(p/(1−p))
> ```
> 
> **Relación con tanh:**
> 
> ```
> σ(x) = (1 + tanh(x/2))/2
> 
> tanh(x) = 2σ(2x) − 1
> 
> Ambas son funciones sigmoides
> ```
> 
> **Aproximación:**
> 
> ```
> Para x cerca de 0:
> σ(x) ≈ 1/2 + x/4
> ```
> **Aproximación:**
> 
> ```
> Para x cerca de 0:
> σ(x) ≈ 1/2 + x/4 − x³/48 + ...
> 
> Para |x| grande:
> σ(x) ≈ { 1       si x >> 0
>        { e^x     si x << 0
> ```
> 
> **Integral:**
> 
> ```
> ∫ σ(x) dx = ln(1 + e^x) + C
> 
> También conocida como función "softplus"
> ```
> 
> **Composición:**
> 
> ```
> σ(σ(x)) no tiene forma cerrada simple
> pero σ(logit(x)) = x para x ∈ (0,1)
> ```

> [!example]- Aplicaciones Extensivas
> 
> **Ejemplo 1 - Redes neuronales:**
> 
> ```
> Función de activación en neurona:
> a = σ(w·x + b)
> 
> Ventajas:
> - Rango acotado [0, 1] (interpretable como probabilidad)
> - Derivada simple: σ'(x) = σ(x)(1−σ(x))
> - Suave (diferenciable)
> 
> Usado en: clasificación binaria, gates en LSTM
> ```
> 
> **Ejemplo 2 - Regresión logística:**
> 
> ```
> Probabilidad de clase positiva:
> P(y=1|x) = σ(β₀ + β₁x₁ + β₂x₂ + ...)
> 
> Modelo lineal con salida probabilística
> 
> Decisión: clasificar como 1 si σ(·) > 0.5
> ```
> 
> **Ejemplo 3 - Crecimiento poblacional:**
> 
> ```
> Modelo logístico de Verhulst:
> P(t) = K/(1 + ((K−P₀)/P₀)e^(−rt))
> 
> P₀ = población inicial
> K = capacidad de carga
> r = tasa de crecimiento
> 
> Crece exponencialmente al inicio,
> se satura cerca de K
> ```
> 
> **Ejemplo 4 - Curva de adopción:**
> 
> ```
> Porcentaje de mercado que adopta tecnología:
> A(t) = 1/(1 + e^(−k(t−t₀)))
> 
> t₀ = tiempo de adopción del 50%
> k = velocidad de adopción
> 
> Modelo de difusión de innovaciones
> ```
> 
> **Ejemplo 5 - Dosis-respuesta:**
> 
> ```
> Respuesta biológica a dosis de medicamento:
> R(d) = Rₘₐₓ/(1 + (EC₅₀/d)ⁿ)
> 
> EC₅₀ = dosis para 50% de respuesta
> n = coeficiente de Hill
> 
> Farmacología y toxicología
> ```
> 
> **Ejemplo 6 - Suavizado de escalón:**
> 
> ```
> Aproximación suave de Heaviside:
> H_ε(x) = σ(x/ε)
> 
> Cuando ε → 0: H_ε(x) → H(x)
> 
> Útil en optimización y simulación
> ```

## 📈 Función Tangente Hiperbólica

> [!success]- Sigmoide Simétrica
> 
> **Definición:** La **tangente hiperbólica** es una función sigmoide centrada en el origen.
> 
> **Notación:**
> 
> ```
> tanh(x) = sinh(x)/cosh(x)
> 
> Se lee: "tangente hiperbólica de x"
> ```
> 
> **Forma explícita:**
> 
> ```
> tanh(x) = (e^x − e^(−x))/(e^x + e^(−x))
> 
> = (e^(2x) − 1)/(e^(2x) + 1)
> 
> = (1 − e^(−2x))/(1 + e^(−2x))
> ```
> 
> **Características:**
> 
> ```
> Dom(tanh) = ℝ
> Ran(tanh) = (−1, 1)
> 
> Propiedades:
> - Función impar: tanh(−x) = −tanh(x)
> - tanh(0) = 0
> - Estrictamente creciente
> - lim(x→±∞) tanh(x) = ±1
> - Punto de inflexión en (0, 0)
> - C^∞ (infinitamente diferenciable)
> ```
> 
> **Gráfica:**
> 
> ```
>   1 |         ___
>     |       /
>   0 |_____●_____
>     |   /
>  -1 |___
>     |___|___|___
>       -2  0  2
> 
> Curva en S simétrica
> Transición de −1 a 1
> ```

> [!tip]- Propiedades Algebraicas
> 
> **Derivada:**
> 
> ```
> d/dx tanh(x) = sech²(x) = 1 − tanh²(x)
> 
> = 4/(e^x + e^(−x))²
> 
> Máximo de la derivada en x = 0: tanh'(0) = 1
> ```
> 
> **Identidades:**
> 
> ```
> 1) tanh²(x) + sech²(x) = 1
> 2) tanh(x + y) = (tanh x + tanh y)/(1 + tanh x · tanh y)
> 3) tanh(2x) = 2tanh(x)/(1 + tanh²(x))
> 4) tanh(x/2) = (e^x − 1)/(e^x + 1)
> 5) 1 + tanh(x) = 2σ(2x)
> ```
> 
> **Relación con sigmoide:**
> 
> ```
> tanh(x) = 2σ(2x) − 1
> 
> σ(x) = (1 + tanh(x/2))/2
> 
> tanh es sigmoide escalada y desplazada
> ```
> 
> **Inversa:**
> 
> ```
> arctanh(x) = (1/2)ln((1+x)/(1−x))
> 
> Dom(arctanh) = (−1, 1)
> Ran(arctanh) = ℝ
> ```
> 
> **Serie de Taylor:**
> 
> ```
> tanh(x) = x − x³/3 + 2x⁵/15 − 17x⁷/315 + ...
> 
> = Σ(n=1 to ∞) B₂ₙ·4ⁿ(4ⁿ−1)/(2n)! · x^(2n−1)
> 
> donde Bₙ son números de Bernoulli
> ```

> [!example]- Aplicaciones
> 
> **Ejemplo 1 - Función de activación:**
> 
> ```
> En redes neuronales:
> a = tanh(w·x + b)
> 
> Ventajas sobre sigmoide:
> - Centrada en 0 (media cercana a 0)
> - Rango (−1, 1) simétrico
> - Gradientes más fuertes
> 
> Menos usado que ReLU en redes profundas,
> pero útil en LSTM/GRU
> ```
> 
> **Ejemplo 2 - Normalización:**
> 
> ```
> Mapear datos a (−1, 1):
> x_norm = tanh(αx)
> 
> α controla la "suavidad" del mapeo
> ```
> 
> **Ejemplo 3 - Velocidad relativista:**
> 
> ```
> En relatividad, rapidez η relaciona velocidad v:
> v/c = tanh(η)
> 
> donde c = velocidad de la luz
> 
> η ∈ (−∞, ∞) pero v/c ∈ (−1, 1)
> ```
> 
> **Ejemplo 4 - Modelado de saturación:**
> 
> ```
> Respuesta que satura simétricamente:
> R(x) = Rₘₐₓ · tanh(kx)
> 
> Saturación suave en ±Rₘₐₓ
> k controla rapidez de saturación
> ```
> 
> **Ejemplo 5 - Ecuación de Langevin:**
> 
> ```
> Magnetización en función del campo:
> M = M_s · tanh(μH/(kT))
> 
> M_s = magnetización de saturación
> Modelo de Langevin para paramagnetismo
> ```

## 🔵 Función Gaussiana

> [!success]- Campana de Gauss
> 
> **Definición:** La **función gaussiana** o **campana de Gauss** es fundamental en probabilidad y estadística.
> 
> **Forma estándar:**
> 
> ```
> φ(x) = e^(−x²/2)
> 
> Se lee: "fi de x"
>         "gaussiana estándar"
> ```
> 
> **Forma normalizada (densidad normal estándar):**
> 
> ```
> φ(x) = (1/√(2π)) e^(−x²/2)
> 
> ∫₋∞^∞ φ(x) dx = 1
> ```
> 
> **Forma general:**
> 
> ```
> f(x) = a · e^(−((x−μ)²)/(2σ²))
> 
> donde:
> a = amplitud (altura del pico)
> μ = media (centro)
> σ = desviación estándar (ancho)
> ```
> 
> **Características:**
> 
> ```
> Dom(φ) = ℝ
> Ran(φ) = (0, 1/√(2π)] ≈ (0, 0.399]
> 
> Propiedades:
> - Función par: φ(−x) = φ(x)
> - Máximo en x = 0: φ(0) = 1/√(2π)
> - Puntos de inflexión en x = ±1
> - lim(x→±∞) φ(x) = 0 (decae rápidamente)
> - C^∞ (infinitamente suave)
> ```
> 
> **Gráfica:**
> 
> ```
>     |    ___
>     |   /   \
>     |  /     \
>     | /       \
>     |/_________\
>      -3  0   3
> 
> Forma de campana
> Simétrica respecto al eje y
> ```

> [!tip]- Propiedades Analíticas
> 
> **Derivada:**
> 
> ```
> dφ/dx = −x·φ(x) = −x·e^(−x²/2)
> 
> φ⁽ⁿ⁾(x) = (−1)ⁿ·Hₙ(x)·φ(x)
> 
> donde Hₙ(x) son polinomios de Hermite
> ```
> 
> **Integral:**
> 
> ```
> Función de error:
> erf(x) = (2/√π) ∫₀ˣ e^(−t²) dt
> 
> Función de distribución normal:
> Φ(x) = (1/√(2π)) ∫₋∞ˣ e^(−t²/2) dt
>      = (1/2)[1 + erf(x/√2)]
> 
> No tiene forma cerrada en términos de funciones elementales
> ```
> 
> **Transformada de Fourier:**
> 
> ```
> ℱ{e^(−x²/(2σ²))} = √(2πσ²) · e^(−2π²σ²f²)
> 
> La gaussiana es auto-dual bajo Fourier
> (transformada es otra gaussiana)
> ```
> 
> **Convolución:**
> 
> ```
> Gaussianas bajo convolución:
> Si f₁ ~ N(μ₁, σ₁²) y f₂ ~ N(μ₂, σ₂²), entonces:
> 
> (f₁ * f₂) ~ N(μ₁ + μ₂, σ₁² + σ²)
> 
> Varianzas se suman
> ```
> 
> **Producto:**
> 
> ```
> Producto de dos gaussianas:
> e^(−a(x−μ₁)²) · e^(−b(x−μ₂)²) ∝ e^(−(a+b)(x−μ)²)
> 
> donde μ = (aμ₁ + bμ₂)/(a + b)
> 
> Resultado es otra gaussiana
> ```

> [!example]- Aplicaciones Universales
> 
> **Ejemplo 1 - Distribución normal:**
> 
> ```
> Variable aleatoria X ~ N(μ, σ²):
> f_X(x) = (1/(σ√(2π))) e^(−(x−μ)²/(2σ²))
> 
> Teorema Central del Límite:
> Suma de variables → distribución normal
> 
> Ubicua en estadística y ciencias
> ```
> 
> **Ejemplo 2 - Filtro gaussiano:**
> 
> ```
> Suavizado de imagen:
> G(x,y) = (1/(2πσ²)) e^(−(x²+y²)/(2σ²))
> 
> Convolución con imagen:
> I_smooth = I * G
> 
> Reduce ruido preservando bordes suaves
> ```
> 
> **Ejemplo 3 - Función de ventana:**
> 
> ```
> Ventana gaussiana en análisis de señales:
> w(n) = e^(−(n−N/2)²/(2σ²))
> 
> Mejor concentración espectral que rect
> Usado en STFT (Short-Time Fourier Transform)
> ```
> 
> **Ejemplo 4 - Kernel RBF:**
> 
> ```
> Radial Basis Function en ML:
> K(x, x') = e^(−‖x−x'‖²/(2σ²))
> 
> Mide "similitud" entre puntos
> Usado en SVM, interpolación
> ```
> 
> **Ejemplo 5 - Difusión del calor:**
> 
> ```
> Ecuación del calor en 1D:
> ∂u/∂t = α·∂²u/∂x²
> 
> Solución con condición inicial δ(x):
> u(x,t) = (1/√(4παt)) e^(−x²/(4αt))
> 
> Distribución gaussiana que se ensancha con el tiempo
> ```
> 
> **Ejemplo 6 - Mecánica cuántica:**
> 
> ```
> Paquete de onda gaussiano:
> ψ(x) = (1/(2πσ²)^(1/4)) e^(−x²/(4σ²) + ikx)
> 
> Estado de mínima incertidumbre:
> Δx·Δp = ℏ/2
> 
> Forma óptima del principio de incertidumbre
> ```
> 
> **Ejemplo 7 - Teoría de campos:**
> 
> ```
> Acción euclidiana en campo escalar:
> S = ∫ d⁴x [½(∂φ)² + ½m²φ²]
> 
> Propagador:
> ⟨0|φ(x)φ(y)|0⟩ ∝ e^(−m|x−y|)
> 
> Comportamiento gaussiano en fluctuaciones
> ```

## 🔄 Función Módulo (mod)

> [!success]- Resto de División
> 
> **Definición:** La **función módulo** devuelve el resto de la división euclidiana.
> 
> **Notación:**
> 
> ```
> x mod n
> 
> Se lee: "x módulo n"
> ```
> 
> **Definición:**
> 
> ```
> x mod n = x − n·⌊x/n⌋
> 
> Para n > 0, x mod n ∈ [0, n)
> ```
> 
> **Características:**
> 
> ```
> Dom: ℝ (para x), n fijo ≠ 0
> Ran: [0, n) para n > 0
> 
> Propiedades:
> - Periódica de período n
> - (x mod n) mod n = x mod n
> - (x + kn) mod n = x mod n, k ∈ ℤ
> ```
> 
> **Gráfica (para mod 5):**
> 
> ```
>   5 |    /    /    /
>     |   /    /    /
>     |  /    /    /
>     | /    /    /
>   0 |/____/____/____
>     0    5   10   15
> 
> Función "diente de sierra"
> Repite cada n unidades
> ```

> [!tip]- Propiedades Aritméticas
> 
> **Operaciones:**
> 
> ```
> (a + b) mod n = ((a mod n) + (b mod n)) mod n
> (a · b) mod n = ((a mod n) · (b mod n)) mod n
> (a^k) mod n = ((a mod n)^k) mod n
> ```
> 
> **Relación con parte fraccionaria:**
> 
> ```
> x mod 1 = {x} (parte fraccionaria)
> 
> x mod n = n·{x/n}
> ```

> [!example]- Aplicaciones
> 
> **Ejemplo 1 - Aritmética modular:**
> 
> ```
> Reloj de 12 horas:
> (hora_actual + horas_transcurridas) mod 12
> 
> Ejemplo: (10 + 5) mod 12 = 15 mod 12 = 3
> (10:00 + 5 horas = 3:00)
> ```
> 
> **Ejemplo 2 - Criptografía:**
> 
> ```
> RSA utiliza exponenciación modular:
> c = m^e mod n (cifrado)
> m = c^d mod n (descifrado)
> 
> Aritmética en ℤₙ
> ```
> 
> **Ejemplo 3 - Generador de números pseudoaleatorios:**
> 
> ```
> Congruencia lineal:
> xₙ₊₁ = (a·xₙ + c) mod m
> 
> Secuencia determinista que parece aleatoria
> ```
> 
> **Ejemplo 4 - Hash tables:**
> 
> ```
> Índice de almacenamiento:
> index = hash(key) mod table_size
> 
> Mapea claves arbitrarias a índices [0, table_size)
> ```

## 📉 Función Valor Máximo y Mínimo

> [!success]- Operaciones Puntuales
> 
> **Definiciones:**
> 
> ```
> max{x, y} = máximo entre x e y
> min{x, y} = mínimo entre x e y
> 
> Para conjuntos:
> max{x₁, x₂, ..., xₙ} = mayor elemento
> min{x₁, x₂, ..., xₙ} = menor elemento
> ```
> 
> **En términos de valor absoluto:**
> 
> ```
> max{x, y} = (x + y + |x − y|)/2
> min{x, y} = (x + y − |x − y|)/2
> 
> max{x, 0} = R(x) (función rampa)
> min{x, 0} = −R(−x)
> ```
> 
> **Propiedades:**
> 
> ```
> 1) max{x, y} + min{x, y} = x + y
> 2) max{x, y} − min{x, y} = |x − y|
> 3) max{max{x, y}, z} = max{x, y, z}
> 4) max{x, y} = −min{−x, −y}
> 5) max{x, x} = x (idempotente)
> ```

> [!example]- Aplicaciones
> 
> **Ejemplo 1 - Función ReLU generalizada:**
> 
> ```
> ReLU(x) = max{0, x}
> Leaky ReLU(x) = max{αx, x}, 0 < α < 1
> 
> Variantes de activación neuronal
> ```
> 
> **Ejemplo 2 - Clipping:**
> 
> ```
> Limitar valor a rango [a, b]:
> clip(x) = max{a, min{b, x}}
> 
> = { a  si x < a
>   { x  si a ≤ x ≤ b
>   { b  si x > b
> ```
> 
> **Ejemplo 3 - Norma infinito:**
> 
> ```
> ‖x‖_∞ = max{|x₁|, |x₂|, ..., |xₙ|}
> 
> Máxima componente en valor absoluto
> ```
> 
> **Ejemplo 4 - Optimización:**
> 
> ```
> Función de pérdida robusta:
> L(x) = min{x², M²}
> 
> Cuadrática cerca del origen,
> constante para errores grandes
> ```

## 🧮 Aproximaciones y Límites

> [!tip]- Comportamiento Asintótico y Aproximaciones
> 
> **Aproximaciones comunes:**
> 
> ```
> Para x pequeño (x → 0):
> σ(x) ≈ 1/2 + x/4
> tanh(x) ≈ x
> sinc(x) ≈ 1 − (πx)²/6
> e^(−x²/2) ≈ 1 − x²/2
> 
> Para x grande (|x| → ∞):
> σ(x) → { 1 si x > 0
>         { 0 si x < 0
> tanh(x) → ±1
> sinc(x) → 0 (oscilando)
> e^(−x²/2) → 0 (muy rápido)
> ```
> 
> **Relaciones límite:**
> 
> ```
> lim(ε→0) σ(x/ε) = H(x)
> lim(ε→0) δ_ε(x) = δ(x)
> lim(α→∞) e^(−αx²) ∝ δ(x)
> lim(n→∞) (sin(nx))/(πx) = δ(x)
> ```

## ⚠️ Errores Comunes

> [!warning]- Confusiones Frecuentes
> 
> **1. "⌊x⌋ + ⌊y⌋ = ⌊x + y⌋"**
> 
> ```
> ✗ INCORRECTO
> Contraejemplo: ⌊1.7⌋ + ⌊2.8⌋ = 1 + 2 = 3
>                ⌊1.7 + 2.8⌋ = ⌊4.5⌋ = 4
> ✓ CORRECTO: ⌊x⌋ + ⌊y⌋ ≤ ⌊x + y⌋ ≤ ⌊x⌋ + ⌊y⌋ + 1
> ```
> 
> **2. "δ(x) es una función"**
> 
> ```
> ✗ INCORRECTO
> δ(x) no puede evaluarse como función ordinaria
> 
> ✓ CORRECTO: δ(x) es una distribución
> Solo tiene sentido bajo integral: ∫f(x)δ(x)dx = f(0)
> ```
> 
> **3. "sinc(0) no está definido"**
> 
> ```
> ✗ INCORRECTO
> 
> ✓ CORRECTO: sinc(0) = 1 (por límite)
> lim(x→0) sin(πx)/(πx) = 1
> ```
> 
> **4. "|x|² = x"**
> 
> ```
> ✗ INCORRECTO
> 
> ✓ CORRECTO: |x|² = x²
> |x| = √(x²)
> ```
> 
> **5. "H(0) tiene un valor único"**
> 
> ```
> ✗ INCORRECTO (depende de convención)
> 
> Diferentes definiciones:
> - H(0) = 1 (convención clásica)
> - H(0) = 1/2 (convención simétrica)
> - H(0) indefinido (convención ingenieril)
> ```
> 
> **6. "tanh y σ son la misma función"**
> 
> ```
> ✗ INCORRECTO
> 
> ✓ CORRECTO: están relacionadas pero son distintas
> tanh(x) = 2σ(2x) − 1
> Ran(tanh) = (−1, 1)
> Ran(σ) = (0, 1)
> ```
> 
> **7. "{x} puede ser negativa"**
> 
> ```
> ✗ INCORRECTO
> 
> ✓ CORRECTO: 0 ≤ {x} < 1 siempre
> {x} = x − ⌊x⌋
> ```

## 🔍 Estrategias de Identificación

> [!tip]- Cómo Reconocer Cuándo Usar Cada Función
> 
> **Usa valor absoluto |x| cuando:**
> 
> - Necesites distancia o magnitud
> - Quieras eliminar el signo
> - Trabajes con normas o métricas
> 
> **Usa ⌊x⌋ o ⌈x⌉ cuando:**
> 
> - Necesites redondear a enteros
> - Cuentes elementos discretos
> - Trabajes con divisibilidad
> 
> **Usa sgn(x) cuando:**
> 
> - Solo importe la dirección, no la magnitud
> - Necesites normalizar el signo
> - Definas funciones por el signo del argumento
> 
> **Usa H(x) cuando:**
> 
> - Modeles encendido/apagado
> - Necesites causalidad (sistemas que empiezan en t=0)
> - Definas funciones por partes con salto
> 
> **Usa δ(x) cuando:**
> 
> - Modeles cargas o fuerzas puntuales
> - Necesites condiciones iniciales concentradas
> - Trabajes con funciones de Green
> 
> **Usa σ(x) o tanh(x) cuando:**
> 
> - Necesites transición suave entre valores
> - Trabajes con redes neuronales
> - Modeles saturación o límites
> 
> **Usa Gaussiana cuando:**
> 
> - Modeles distribuciones naturales
> - Necesites suavizado
> - Trabajes con probabilidad o estadística
> 
> **Usa sinc(x) cuando:**
> 
> - Trabajes con muestreo de señales
> - Necesites interpolación ideal
> - Analices difracción o interferencia

## 🎓 Conceptos Clave para Recordar

> [!important]- Resumen Ejecutivo
> 
> **Funciones discretizadoras:**
> 
> - **⌊x⌋:** mayor entero ≤ x
> - **⌈x⌉:** menor entero ≥ x
> - **{x}:** parte fraccionaria, x − ⌊x⌋
> - **sgn(x):** {−1, 0, 1}
> 
> **Funciones de activación:**
> 
> - **H(x):** escalón 0→1 en x=0
> - **R(x) = max{0,x}:** rampa (ReLU)
> - **σ(x) = 1/(1+e^(−x)):** sigmoide (0,1)
> - **tanh(x):** sigmoide simétrica (−1,1)
> 
> **Funciones de pulso:**
> 
> - **rect(x):** pulso rectangular
> - **Λ(x):** pulso triangular
> - **δ(x):** impulso (distribución)
> 
> **Funciones de análisis:**
> 
> - **sinc(x) = sin(πx)/(πx):** interpolación ideal
> - **φ(x) = e^(−x²/2):** gaussiana estándar
> - **|x|:** distancia, norma L¹
> 
> **Propiedades cruciales:**
> 
> - δ'(x) = dH/dx (distribucional)
> - rect ↔ sinc (Fourier)
> - Λ = rect * rect (convolución)
> - tanh(x) = 2σ(2x) − 1
> - |x| = x·sgn(x)
> - R(x) = x·H(x)
