# 📐 Figuras Geométricas en el Plano

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Las figuras geométricas en el plano son conjuntos de puntos en ℝ² que satisfacen ciertas propiedades o relaciones. Representan formas y objetos bidimensionales que pueden describirse mediante ecuaciones algebraicas, y constituyen la base del estudio de la geometría analítica.**
> 
> **Características clave:**
> 
> - **Representación dual:** Geométrica (visual) y algebraica (ecuaciones)
> - **Plano cartesiano:** Sistema de coordenadas (x, y)
> - **Ecuaciones:** Relacionan coordenadas de puntos
> - **Clasificación:** Líneas, curvas, regiones
> - **Propiedades métricas:** Distancias, áreas, perímetros

## 📝 El Plano Cartesiano

> [!success]- Sistema de Coordenadas **Definición:**
> 
> ```
> El plano cartesiano ℝ² es el conjunto de pares ordenados:
> ℝ² = {(x, y) : x, y ∈ ℝ}
> 
> Componentes:
> • Eje X (abscisas): horizontal
> • Eje Y (ordenadas): vertical
> • Origen: O = (0, 0)
> • Cuadrantes: I, II, III, IV
> ```
> 
> **Cuadrantes:**
> 
> ```
>     II  |  I
>    (-,+)|(+,+)
>   ------+------ 
>    (-,-)|(+,-)
>    III  |  IV
> 
> I:   x > 0, y > 0
> II:  x < 0, y > 0
> III: x < 0, y < 0
> IV:  x > 0, y < 0
> ```
> 
> **Distancia entre dos puntos:**
> 
> ```
> Dados P₁ = (x₁, y₁) y P₂ = (x₂, y₂):
> 
> d(P₁, P₂) = √[(x₂ - x₁)² + (y₂ - y₁)²]
> 
> Fórmula derivada del teorema de Pitágoras
> ```
> 
> **Punto medio:**
> 
> ```
> M = ((x₁ + x₂)/2, (y₁ + y₂)/2)
> 
> Promedio de coordenadas
> ```

## 📏 La Línea Recta

> [!important]- Ecuaciones de la Recta **1. Ecuación punto-pendiente:**
> 
> ```
> y - y₁ = m(x - x₁)
> 
> donde:
> • (x₁, y₁) = punto conocido
> • m = pendiente = (y₂ - y₁)/(x₂ - x₁)
> ```
> 
> **2. Ecuación pendiente-ordenada:**
> 
> ```
> y = mx + b
> 
> donde:
> • m = pendiente
> • b = ordenada al origen (intercepto en y)
> ```
> 
> **3. Ecuación general:**
> 
> ```
> Ax + By + C = 0
> 
> donde A, B, C ∈ ℝ, A² + B² ≠ 0
> 
> Pendiente: m = -A/B (si B ≠ 0)
> ```
> 
> **4. Forma simétrica (interceptos):**
> 
> ```
> x/a + y/b = 1
> 
> donde:
> • a = intercepto en x
> • b = intercepto en y
> ```
> 
> **Casos especiales:**
> 
> ```
> Recta vertical:   x = k (pendiente indefinida)
> Recta horizontal: y = k (pendiente m = 0)
> Recta por origen: y = mx (b = 0)
> ```
> 
> **Relaciones entre rectas:**
> 
> ```
> Rectas L₁: y = m₁x + b₁ y L₂: y = m₂x + b₂
> 
> Paralelas:      m₁ = m₂
> Perpendiculares: m₁ · m₂ = -1 (m₂ = -1/m₁)
> Coincidentes:   m₁ = m₂ y b₁ = b₂
> ```

## ⭕ El Círculo

> [!important]- Ecuaciones del Círculo **Ecuación canónica (ordinaria):**
> 
> ```
> (x - h)² + (y - k)² = r²
> 
> donde:
> • Centro: C = (h, k)
> • Radio: r > 0
> ```
> 
> **Círculo centrado en el origen:**
> 
> ```
> x² + y² = r²
> 
> Caso especial: h = k = 0
> ```
> 
> **Ecuación general:**
> 
> ```
> x² + y² + Dx + Ey + F = 0
> 
> Completando cuadrados:
> Centro: (-D/2, -E/2)
> Radio: r = √(D²/4 + E²/4 - F)
> 
> Existe círculo si: D²/4 + E²/4 - F > 0
> ```
> 
> **Propiedades:**
> 
> ```
> • Circunferencia: C = 2πr
> • Área: A = πr²
> • Diámetro: d = 2r
> • Todos los puntos equidistan del centro
> ```
> 
> **Ejemplo:**
> 
> ```
> Círculo con centro C = (2, -3) y radio r = 5:
> 
> (x - 2)² + (y + 3)² = 25
> 
> Expandiendo:
> x² - 4x + 4 + y² + 6y + 9 = 25
> x² + y² - 4x + 6y - 12 = 0
> ```

## 📐 Polígonos Básicos

> [!note]- Figuras Poligonales **Triángulo:**
> 
> ```
> Tres vértices: A = (x₁, y₁), B = (x₂, y₂), C = (x₃, y₃)
> 
> Área (fórmula del determinante):
> A = (1/2)|x₁(y₂ - y₃) + x₂(y₃ - y₁) + x₃(y₁ - y₂)|
> 
> Perímetro:
> P = d(A,B) + d(B,C) + d(C,A)
> 
> Tipos:
> • Equilátero: 3 lados iguales
> • Isósceles: 2 lados iguales
> • Escaleno: 3 lados diferentes
> • Rectángulo: tiene ángulo de 90°
> ```
> 
> **Cuadriláteros:**
> 
> ```
> Cuadrado:
> • 4 lados iguales
> • 4 ángulos rectos
> • Área: A = l²
> • Diagonales iguales y perpendiculares
> 
> Rectángulo:
> • Lados opuestos iguales
> • 4 ángulos rectos
> • Área: A = base × altura
> • Diagonales iguales
> 
> Rombo:
> • 4 lados iguales
> • Ángulos opuestos iguales
> • Área: A = (d₁ × d₂)/2 (diagonales)
> • Diagonales perpendiculares
> 
> Paralelogramo:
> • Lados opuestos paralelos e iguales
> • Ángulos opuestos iguales
> • Área: A = base × altura
> 
> Trapecio:
> • Un par de lados paralelos (bases)
> • Área: A = ((b₁ + b₂)/2) × h
> ```
> 
> **Polígonos regulares:**
> 
> ```
> n lados iguales, n ángulos iguales
> 
> Ángulo interior: α = (n-2)·180°/n
> Ángulo central: β = 360°/n
> 
> Área: A = (n·l·a)/2
> donde l = lado, a = apotema
> ```

## 🌐 Secciones Cónicas

> [!important]- Las Cuatro Cónicas **1. Parábola:**
> 
> ```
> Ecuación canónica (eje vertical):
> (x - h)² = 4p(y - k)
> 
> Vértice: V = (h, k)
> Foco: F = (h, k + p)
> Directriz: y = k - p
> Parámetro: p (distancia vértice-foco)
> 
> Ecuación canónica (eje horizontal):
> (y - k)² = 4p(x - h)
> 
> Foco: F = (h + p, k)
> Directriz: x = h - p
> ```
> 
> **2. Elipse:**
> 
> ```
> Ecuación canónica (centro en origen):
> x²/a² + y²/b² = 1
> 
> donde a > b > 0
> 
> Eje mayor: 2a (horizontal si a > b)
> Eje menor: 2b
> Semieje mayor: a
> Semieje menor: b
> Focos: F₁ = (-c, 0), F₂ = (c, 0)
> Excentricidad: e = c/a donde c² = a² - b²
> 
> Ecuación trasladada:
> (x - h)²/a² + (y - k)²/b² = 1
> Centro: (h, k)
> 
> Propiedad focal: d(P,F₁) + d(P,F₂) = 2a
> ```
> 
> **3. Hipérbola:**
> 
> ```
> Ecuación canónica (centro en origen):
> x²/a² - y²/b² = 1 (eje transversal horizontal)
> 
> o
> 
> y²/a² - x²/b² = 1 (eje transversal vertical)
> 
> Vértices: V₁ = (-a, 0), V₂ = (a, 0)
> Focos: F₁ = (-c, 0), F₂ = (c, 0)
> donde c² = a² + b²
> 
> Asíntotas: y = ±(b/a)x
> Excentricidad: e = c/a > 1
> 
> Propiedad focal: |d(P,F₁) - d(P,F₂)| = 2a
> ```
> 
> **4. Círculo:**
> 
> ```
> Caso especial de elipse con a = b = r
> x² + y² = r²
> 
> Excentricidad: e = 0
> ```
> 
> **Resumen de excentricidades:**
> 
> ```
> e = 0: Círculo
> 0 < e < 1: Elipse
> e = 1: Parábola
> e > 1: Hipérbola
> ```

## 🎯 Lugares Geométricos

> [!note]- Definición y Ejemplos **Concepto:**
> 
> ```
> Un lugar geométrico es el conjunto de todos los puntos
> del plano que satisfacen una propiedad o condición dada.
> ```
> 
> **Ejemplos clásicos:**
> 
> ```
> 1. Circunferencia:
>    Lugar geométrico de puntos equidistantes de un punto fijo
>    
> 2. Mediatriz de un segmento:
>    Puntos equidistantes de los extremos del segmento
>    Ecuación: recta perpendicular al segmento por su punto medio
>    
> 3. Bisectriz de un ángulo:
>    Puntos equidistantes de los dos lados del ángulo
>    
> 4. Parábola:
>    Puntos equidistantes de un punto (foco) y una recta (directriz)
>    
> 5. Elipse:
>    Puntos cuya suma de distancias a dos focos es constante
>    
> 6. Hipérbola:
>    Puntos cuya diferencia de distancias a dos focos es constante
> ```
> 
> **Método para encontrar lugares geométricos:**
> 
> ```
> 1. Identificar la condición geométrica
> 2. Expresar algebraicamente usando d(P₁, P₂)
> 3. Simplificar la ecuación
> 4. Identificar la curva resultante
> ```

## 📊 Áreas y Perímetros

> [!important]- Fórmulas Principales **Figuras básicas:**
> 
> ```
> Triángulo:
> • A = (1/2)·base·altura
> • A = (1/2)|x₁(y₂-y₃) + x₂(y₃-y₁) + x₃(y₁-y₂)|
> • A = √[s(s-a)(s-b)(s-c)] (Herón, s = semiperímetro)
> 
> Cuadrado de lado l:
> • A = l²
> • P = 4l
> 
> Rectángulo (base b, altura h):
> • A = b·h
> • P = 2(b + h)
> 
> Paralelogramo:
> • A = base·altura
> 
> Trapecio:
> • A = ((B + b)/2)·h
> donde B, b son bases, h altura
> 
> Círculo de radio r:
> • A = πr²
> • Circunferencia: C = 2πr
> 
> Sector circular (ángulo θ en radianes):
> • A = (1/2)r²θ
> • Arco: s = rθ
> 
> Elipse (semiejes a, b):
> • A = πab
> ```
> 
> **Polígono general (n vértices):**
> 
> ```
> Fórmula del área (shoelace formula):
> 
> A = (1/2)|∑(xᵢyᵢ₊₁ - xᵢ₊₁yᵢ)|
> 
> donde la suma es cíclica (xₙ₊₁ = x₁)
> ```

## 🧩 Problemas Resueltos

> [!example]- Ejemplos Detallados **Problema 1: Ecuación de recta**
> 
> ```
> Encontrar la ecuación de la recta que pasa por
> A = (2, 3) y B = (5, -1)
> 
> SOLUCIÓN:
> 
> Pendiente:
> m = (y₂ - y₁)/(x₂ - x₁) = (-1 - 3)/(5 - 2) = -4/3
> 
> Usando punto-pendiente con A:
> y - 3 = (-4/3)(x - 2)
> y - 3 = (-4/3)x + 8/3
> y = (-4/3)x + 8/3 + 3
> y = (-4/3)x + 17/3
> 
> Forma general:
> 3y = -4x + 17
> 4x + 3y - 17 = 0
> ```
> 
> **Problema 2: Círculo que pasa por tres puntos**
> 
> ```
> Encontrar la ecuación del círculo que pasa por:
> A = (0, 0), B = (4, 0), C = (0, 2)
> 
> SOLUCIÓN:
> 
> Ecuación general: x² + y² + Dx + Ey + F = 0
> 
> Sustituyendo A(0,0):
> 0 + 0 + 0 + 0 + F = 0 → F = 0
> 
> Sustituyendo B(4,0):
> 16 + 0 + 4D + 0 + 0 = 0 → D = -4
> 
> Sustituyendo C(0,2):
> 0 + 4 + 0 + 2E + 0 = 0 → E = -2
> 
> Ecuación: x² + y² - 4x - 2y = 0
> 
> Centro: (2, 1)
> Radio: r = √(4 + 1) = √5
> 
> Forma canónica: (x - 2)² + (y - 1)² = 5
> ```
> 
> **Problema 3: Área de triángulo**
> 
> ```
> Calcular el área del triángulo con vértices:
> A = (1, 2), B = (4, 6), C = (7, 3)
> 
> SOLUCIÓN:
> 
> Fórmula del determinante:
> A = (1/2)|x₁(y₂ - y₃) + x₂(y₃ - y₁) + x₃(y₁ - y₂)|
> 
> A = (1/2)|1(6 - 3) + 4(3 - 2) + 7(2 - 6)|
> A = (1/2)|1(3) + 4(1) + 7(-4)|
> A = (1/2)|3 + 4 - 28|
> A = (1/2)|-21|
> A = 21/2 = 10.5 unidades cuadradas
> ```
> 
> **Problema 4: Distancia punto a recta**
> 
> ```
> Calcular la distancia del punto P = (2, 3)
> a la recta L: 3x - 4y + 1 = 0
> 
> SOLUCIÓN:
> 
> Fórmula:
> d = |Ax₀ + By₀ + C|/√(A² + B²)
> 
> donde L: Ax + By + C = 0 y P = (x₀, y₀)
> 
> d = |3(2) - 4(3) + 1|/√(3² + 4²)
> d = |6 - 12 + 1|/√(9 + 16)
> d = |-5|/√25
> d = 5/5 = 1 unidad
> ```
> 
> **Problema 5: Identificar cónica**
> 
> ```
> Identificar y graficar: 9x² + 4y² = 36
> 
> SOLUCIÓN:
> 
> Dividir entre 36:
> x²/4 + y²/9 = 1
> 
> Forma canónica de elipse:
> x²/a² + y²/b² = 1
> 
> Identificación:
> a² = 4 → a = 2 (semieje en x)
> b² = 9 → b = 3 (semieje en y)
> 
> Como b > a: eje mayor vertical
> 
> Centro: (0, 0)
> Vértices: (0, ±3)
> Co-vértices: (±2, 0)
> c² = b² - a² = 9 - 4 = 5
> c = √5
> Focos: (0, ±√5)
> Excentricidad: e = √5/3 ≈ 0.745
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes **1. "La pendiente siempre existe"**
> 
> ```
> ✗ FALSO
> 
> Rectas verticales (x = k) no tienen pendiente definida
> La pendiente m = Δy/Δx no existe si Δx = 0
> ```
> 
> **2. "Dos rectas siempre se intersectan"**
> 
> ```
> ✗ FALSO
> 
> Rectas paralelas nunca se intersectan (mismo plano)
> Ejemplo: y = 2x + 1 y y = 2x + 5 (m₁ = m₂)
> ```
> 
> **3. "El círculo x² + y² + Dx + Ey + F = 0 siempre existe"**
> 
> ```
> ✗ FALSO
> 
> Debe cumplirse: D²/4 + E²/4 - F > 0
> 
> Si D²/4 + E²/4 - F = 0: punto
> Si D²/4 + E²/4 - F < 0: conjunto vacío
> ```
> 
> **4. "La distancia puede ser negativa"**
> 
> ```
> ✗ FALSO
> 
> d(P₁, P₂) ≥ 0 siempre
> d(P₁, P₂) = 0 ⟺ P₁ = P₂
> ```
> 
> **5. "En Ax + By + C = 0, la pendiente es A/B"**
> 
> ```
> ✗ FALSO
> 
> Pendiente: m = -A/B (signo negativo)
> 
> De Ax + By + C = 0:
> By = -Ax - C
> y = (-A/B)x - C/B
> ```
> 
> **6. "Toda parábola tiene la forma y = x²"**
> 
> ```
> ✗ FALSO
> 
> Puede tener eje horizontal: x = y²
> O estar trasladada y escalada: y = a(x-h)² + k
> ```

## 🎯 Transformaciones Geométricas

> [!note]- Operaciones en el Plano **Traslación:**
> 
> ```
> Desplazar figura por vector v = (h, k)
> 
> P = (x, y) → P' = (x + h, y + k)
> 
> Ejemplo: trasladar círculo x² + y² = r²
> por v = (2, 3):
> (x - 2)² + (y - 3)² = r²
> ```
> 
> **Reflexión (simetría):**
> 
> ```
> Respecto al eje x: (x, y) → (x, -y)
> Respecto al eje y: (x, y) → (-x, y)
> Respecto al origen: (x, y) → (-x, -y)
> Respecto a y = x: (x, y) → (y, x)
> ```
> 
> **Rotación (respecto al origen):**
> 
> ```
> Ángulo θ en sentido antihorario:
> 
> x' = x cos θ - y sen θ
> y' = x sen θ + y cos θ
> 
> Forma matricial:
> [x']   [cos θ  -sen θ] [x]
> [y'] = [sen θ   cos θ] [y]
> ```
> 
> **Homotecia (escalamiento):**
> 
> ```
> Factor k desde el origen:
> (x, y) → (kx, ky)
> 
> k > 1: ampliación
> 0 < k < 1: reducción
> k < 0: inversión y escalamiento
> ```

## 📐 Ángulos en el Plano

> [!important]- Medición de Ángulos **Ángulo entre dos rectas:**
> 
> ```
> Rectas L₁: y = m₁x + b₁ y L₂: y = m₂x + b₂
> 
> tan θ = |m₂ - m₁|/(1 + m₁m₂)
> 
> donde θ es el ángulo agudo entre ellas
> 
> Caso especial (perpendiculares):
> m₁m₂ = -1 → θ = 90°
> ```
> 
> **Ángulo de inclinación:**
> 
> ```
> Ángulo α que forma la recta con eje x positivo
> 
> m = tan α
> 
> 0° ≤ α < 180°
> 
> α = 0°: recta horizontal (m = 0)
> α = 90°: recta vertical (m indefinida)
> ```
> 
> **Ángulo en un triángulo:**
> 
> ```
> Dados vértices A, B, C:
> 
> Ángulo en B usando producto punto:
> cos(∠ABC) = (BA⃗ · BC⃗)/(|BA⃗||BC⃗|)
> 
> donde BA⃗ = A - B, BC⃗ = C - B
> ```

## 🎨 Simetría y Ejes

> [!note]- Propiedades de Simetría **Simetría axial:**
> 
> ```
> Figura simétrica respecto a recta L si:
> para cada punto P existe P' tal que:
> • L es mediatriz de PP'
> 
> Ejemplos:
> • Círculo: infinitos ejes (cualquier diámetro)
> • Elipse: 2 ejes (mayor y menor)
> • Parábola: 1 eje (eje de simetría)
> • Segmento: 2 ejes (mediatriz y recta que lo contiene)
> ```
> 
> **Simetría central:**
> 
> ```
> Figura simétrica respecto a punto O si:
> para cada punto P existe P' tal que:
> • O es punto medio de PP'
> 
> Ejemplos:
> • Círculo: centro
> • Elipse: centro
> • Hipérbola: centro
> • Paralelogramo: intersección de diagonales
> ```
> 
> **Simetría rotacional:**
> 
> ```
> Orden n: figura coincide consigo misma
> al rotar 360°/n
> 
> Ejemplos:
> • Círculo: orden infinito
> • Cuadrado: orden 4 (90°, 180°, 270°, 360°)
> • Triángulo equilátero: orden 3 (120°, 240°, 360°)
> ```

## 🔍 Análisis de Ecuaciones

> [!tip]- Identificación de Curvas **Ecuación general de segundo grado:**
> 
> ```
> Ax² + Bxy + Cy² + Dx + Ey + F = 0
> 
> Discriminante: Δ = B² - 4AC
> 
> Clasificación:
> • Δ < 0 y A = C, B = 0: Círculo
> • Δ < 0: Elipse (o punto o vacío)
> • Δ = 0: Parábola (o rectas paralelas)
> • Δ > 0: Hipérbola (o rectas secantes)
> 
> Invariantes bajo rotación:
> I₁ = A + C (suma de coeficientes cuadráticos)
> I₂ = AC - B²/4 (relacionado con determinante)
> ```
> 
> **Simplificación por rotación:**
> 
> ```
> Para eliminar término xy (B ≠ 0):
> 
> Rotar ángulo θ donde:
> tan(2θ) = B/(A - C)
> 
> Esto transforma a ecuación sin término cruzado
> ```
> 
> **Casos degenerados:**
> 
> ```
> La ecuación puede representar:
> • Punto: x² + y² = 0 → (0,0)
> • Recta: x² = 0 → x = 0 (eje y)
> • Dos rectas: x² - y² = 0 → x = ±y
> • Conjunto vacío: x² + y² = -1
> ```

## 📊 Relaciones Métricas Especiales

> [!important]- Fórmulas Avanzadas **Distancia de punto a recta:**
> 
> ```
> Punto P = (x₀, y₀)
> Recta L: Ax + By + C = 0
> 
> d(P, L) = |Ax₀ + By₀ + C|/√(A² + B²)
> 
> Nota: A² + B² ≠ 0 siempre
> ```
> 
> **Distancia entre rectas paralelas:**
> 
> ```
> L₁: Ax + By + C₁ = 0
> L₂: Ax + By + C₂ = 0 (mismo A, B)
> 
> d(L₁, L₂) = |C₂ - C₁|/√(A² + B²)
> ```
> 
> **Área de polígono por coordenadas:**
> 
> ```
> Vértices: (x₁,y₁), (x₂,y₂), ..., (xₙ,yₙ)
> 
> Fórmula de Gauss (shoelace):
> A = (1/2)|∑ᵢ₌₁ⁿ (xᵢyᵢ₊₁ - xᵢ₊₁yᵢ)|
> 
> donde xₙ₊₁ = x₁, yₙ₊₁ = y₁
> ```
> 
> **Longitud de arco:**
> 
> ```
> Círculo (ángulo θ en radianes):
> s = rθ
> 
> Elipse (no tiene fórmula cerrada simple):
> Aproximación: L ≈ π[3(a+b) - √((3a+b)(a+3b))]
> donde a, b son semiejes
> ```

## 🎯 Problemas Avanzados

> [!example]- Desafíos Adicionales **Problema 1: Lugar geométrico**
> 
> ```
> Encontrar el lugar geométrico de puntos P tales que
> la suma de cuadrados de distancias a A = (1, 0) y
> B = (-1, 0) es constante e igual a 10.
> 
> SOLUCIÓN:
> Sea P = (x, y)
> 
> d(P,A)² + d(P,B)² = 10
> [(x-1)² + y²] + [(x+1)² + y²] = 10
> x² - 2x + 1 + y² + x² + 2x + 1 + y² = 10
> 2x² + 2y² + 2 = 10
> 2x² + 2y² = 8
> x² + y² = 4
> 
> Respuesta: Círculo de centro (0,0) y radio 2
> ```
> 
> **Problema 2: Optimización**
> 
> ```
> En un triángulo con vértices A = (0,0), B = (4,0),
> C = (0,3), encontrar el punto P sobre AB que
> minimiza d(P,C).
> 
> SOLUCIÓN:
> La distancia mínima es la perpendicular.
> 
> AB está sobre eje x: y = 0
> Perpendicular desde C(0,3) a AB:
> Es la recta vertical x = 0
> 
> Intersección: P = (0, 0) = A
> 
> Distancia mínima: d(A,C) = 3
> 
> [Verificar que es mínima comparando con otros puntos]
> ```
> 
> **Problema 3: Familia de rectas**
> 
> ```
> Encontrar la ecuación del haz de rectas que
> pasan por la intersección de:
> L₁: 2x + y - 3 = 0
> L₂: x - y + 1 = 0
> 
> SOLUCIÓN:
> Ecuación del haz:
> (2x + y - 3) + λ(x - y + 1) = 0
> 
> donde λ ∈ ℝ es parámetro
> 
> Simplificando:
> (2 + λ)x + (1 - λ)y + (λ - 3) = 0
> 
> Para cada valor de λ: una recta del haz
> 
> λ = -2: x + 3y - 5 = 0
> λ = 1: 3x - 2 = 0 → x = 2/3
> λ → ∞: x - y + 1 = 0 (L₂)
> ```

## 🎓 Conceptos Clave - Mapa Mental

> [!important]- Estructura Conceptual
> 
> ```
> FIGURAS GEOMÉTRICAS EN EL PLANO
> │
> ├─── PLANO CARTESIANO
> │    ├─ Sistema ℝ² = {(x,y)}
> │    ├─ Cuadrantes (I, II, III, IV)
> │    ├─ Distancia: d = √[(x₂-x₁)² + (y₂-y₁)²]
> │    └─ Punto medio: M = ((x₁+x₂)/2, (y₁+y₂)/2)
> │
> ├─── LÍNEA RECTA
> │    ├─ y = mx + b (pendiente-ordenada)
> │    ├─ Ax + By + C = 0 (general)
> │    ├─ Pendiente: m = Δy/Δx
> │    ├─ Paralelas: m₁ = m₂
> │    └─ Perpendiculares: m₁·m₂ = -1
> │
> ├─── CÍRCULO
> │    ├─ (x-h)² + (y-k)² = r² (canónica)
> │    ├─ Centro: (h, k), Radio: r
> │    ├─ Área: A = πr²
> │    └─ Circunferencia: C = 2πr
> │
> ├─── POLÍGONOS
> │    ├─ Triángulo
> │    │  ├─ Área por determinante
> │    │  └─ Tipos: equilátero, isósceles, escaleno
> │    ├─ Cuadriláteros
> │    │  ├─ Cuadrado, rectángulo
> │    │  └─ Rombo, paralelogramo, trapecio
> │    └─ Regulares (n lados)
> │
> ├─── CÓNICAS
> │    ├─ Parábola: (x-h)² = 4p(y-k)
> │    │  ├─ Foco, directriz, vértice
> │    │  └─ Excentricidad: e = 1
> │    ├─ Elipse: x²/a² + y²/b² = 1
> │    │  ├─ Dos focos, dos ejes
> │    │  └─ Excentricidad: 0 < e < 1
> │    └─ Hipérbola: x²/a² - y²/b² = 1
> │       ├─ Dos ramas, asíntotas
> │       └─ Excentricidad: e > 1
> │
> ├─── TRANSFORMACIONES
> │    ├─ Traslación: (x,y) → (x+h, y+k)
> │    ├─ Reflexión: respecto a ejes
> │    ├─ Rotación: usando matrices
> │    └─ Homotecia: (x,y) → (kx, ky)
> │
> └─── PROPIEDADES MÉTRICAS
>      ├─ Distancias (punto-punto, punto-recta)
>      ├─ Áreas (fórmulas variadas)
>      ├─ Perímetros y longitudes
>      └─ Ángulos entre rectas
> ```
