# 🔷 Cuadriláteros

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Un cuadrilátero es un polígono de cuatro lados, formado por cuatro puntos no colineales (vértices) unidos por cuatro segmentos (lados). Es la segunda figura poligonal más simple después del triángulo, con propiedades estructurales ricas y diversas.**
> 
> **Características clave:**
> 
> - **Cuatro vértices:** Puntos A, B, C, D
> - **Cuatro lados:** Segmentos AB, BC, CD, DA
> - **Cuatro ángulos:** ∠A, ∠B, ∠C, ∠D (suma = 360°)
> - **Dos diagonales:** AC y BD
> - **Flexibilidad estructural:** No es rígido (a diferencia del triángulo)
> - **Descomposición:** Todo cuadrilátero se divide en dos triángulos

## 📐 Elementos del Cuadrilátero

> [!important]- Componentes Básicos **Elementos primarios:**
> 
> ```
> Vértices: A, B, C, D (sentido antihorario)
> 
> Lados:
> a = AB (primer lado)
> b = BC (segundo lado)
> c = CD (tercer lado)
> d = DA (cuarto lado)
> 
> Ángulos internos:
> α = ∠DAB (en vértice A)
> β = ∠ABC (en vértice B)
> γ = ∠BCD (en vértice C)
> δ = ∠CDA (en vértice D)
> 
> Propiedad fundamental:
> α + β + γ + δ = 360°
> 
> Diagonales:
> p = AC (une vértices opuestos A y C)
> q = BD (une vértices opuestos B y D)
> ```
> 
> **Notación estándar:**
> 
> ```
> Convención:
> • Vértices: letras mayúsculas consecutivas
> • Lados: longitudes a, b, c, d
> • Cuadrilátero ABCD se denota: □ABCD
> 
> Tipos:
> • Convexo: todos ángulos < 180°
> • Cóncavo: un ángulo > 180°
> • Cruzado: lados se intersectan
> ```

## 🎯 Clasificación de Cuadriláteros

> [!success]- Jerarquía de Cuadriláteros **Según paralelismo:**
> 
> ```
> 1. Trapecio:
>    • Un par de lados paralelos (bases)
>    • Bases: a ∥ c
>    • Lados no paralelos: laterales (b, d)
>    
>    Tipos:
>    • Trapecio escaleno: laterales diferentes
>    • Trapecio isósceles: laterales iguales (b = d)
>      - Ángulos de la base iguales
>      - Diagonales iguales
>    • Trapecio rectángulo: un ángulo recto
> 
> 2. Paralelogramo:
>    • Dos pares de lados paralelos
>    • a ∥ c y b ∥ d
>    
>    Propiedades:
>    • Lados opuestos iguales: a = c, b = d
>    • Ángulos opuestos iguales: α = γ, β = δ
>    • Ángulos consecutivos suplementarios
>    • Diagonales se bisecan mutuamente
>    
>    Tipos especiales:
>    
>    a) Rombo:
>       • Paralelogramo con 4 lados iguales
>       • a = b = c = d
>       • Diagonales perpendiculares
>       • Diagonales bisecan ángulos
>    
>    b) Rectángulo:
>       • Paralelogramo con 4 ángulos rectos
>       • α = β = γ = δ = 90°
>       • Diagonales iguales: p = q
>    
>    c) Cuadrado:
>       • Rombo + Rectángulo
>       • 4 lados iguales + 4 ángulos rectos
>       • Máxima simetría (4 ejes)
>       • Diagonales iguales y perpendiculares
>       • Diagonal: d = a√2
>       • Área: A = a²
> 
> 3. Trapezoide:
>    • Ningún par de lados paralelos
>    • Caso general
> ```
> 
> **Cuadriláteros especiales:**
> 
> ```
> 4. Cuadrilátero cíclico:
>    • Los 4 vértices sobre una circunferencia
>    • Ángulos opuestos suplementarios:
>      α + γ = 180°, β + δ = 180°
>    • Teorema de Ptolomeo aplica
> 
> 5. Cuadrilátero tangencial:
>    • Los 4 lados tangentes a una circunferencia
>    • Suma de lados opuestos iguales:
>      a + c = b + d
>    • Radio inscrito: r = A/s
>      donde s = (a+b+c+d)/2
> 
> 6. Cuadrilátero bicéntrico:
>    • Cíclico y tangencial simultáneamente
>    • Posee círculo inscrito y circunscrito
>    • Muy restrictivo (pocas configuraciones)
> ```

## 📊 Propiedades Fundamentales

> [!note]- Teoremas Básicos **Suma de ángulos:**
> 
> ```
> En todo cuadrilátero:
> α + β + γ + δ = 360°
> 
> Demostración:
> Una diagonal divide el cuadrilátero
> en dos triángulos
> 2 × 180° = 360°
> ```
> 
> **Teorema de Varignon:**
> 
> ```
> Los puntos medios de los lados de cualquier
> cuadrilátero forman un paralelogramo
> (paralelogramo de Varignon)
> 
> Propiedades:
> • Lados paralelos a las diagonales originales
> • Perímetro = suma de diagonales
> • Área = mitad del área original
> ```
> 
> **Paralelogramo - Propiedades:**
> 
> ```
> Si ABCD es paralelogramo:
> 
> 1. Lados opuestos:
>    AB = CD, BC = DA
> 
> 2. Ángulos opuestos:
>    ∠A = ∠C, ∠B = ∠D
> 
> 3. Ángulos consecutivos:
>    ∠A + ∠B = 180°
> 
> 4. Diagonales:
>    Se bisecan mutuamente
>    AO = OC, BO = OD (O = intersección)
> 
> 5. Área:
>    A = base × altura = ah
>    A = ab sen α
> ```
> 
> **Rombo - Propiedades:**
> 
> ```
> Además de propiedades del paralelogramo:
> 
> 6. Diagonales perpendiculares:
>    p ⊥ q
> 
> 7. Diagonales bisecan ángulos
> 
> 8. Área:
>    A = (pq)/2 (producto de diagonales)
>    A = a² sen α
> 
> 9. Relación lados-diagonales:
>    p² + q² = 4a²
> ```
> 
> **Rectángulo - Propiedades:**
> 
> ```
> 10. Todos los ángulos = 90°
> 
> 11. Diagonales iguales:
>    p = q = √(a² + b²)
> 
> 12. Área:
>    A = ab (base × altura)
> 
> 13. Perímetro:
>    P = 2(a + b)
> ```

## 📐 Fórmulas de Área

> [!important]- Métodos de Cálculo **Fórmula general (coordenadas):**
> 
> ```
> Vértices: A(x₁,y₁), B(x₂,y₂), C(x₃,y₃), D(x₄,y₄)
> 
> A = (1/2)|x₁(y₂-y₄) + x₂(y₃-y₁) + x₃(y₄-y₂) + x₄(y₁-y₃)|
> 
> O usando determinante (fórmula del agrimensor)
> ```
> 
> **Fórmula de Bretschneider:**
> 
> ```
> Cuadrilátero general con lados a, b, c, d
> y ángulos opuestos α, γ:
> 
> A = √[(s-a)(s-b)(s-c)(s-d) - abcd·cos²((α+γ)/2)]
> 
> donde s = (a+b+c+d)/2
> 
> Generaliza la fórmula de Herón
> ```
> 
> **Cuadrilátero cíclico (Fórmula de Brahmagupta):**
> 
> ```
> Para cuadrilátero inscrito en circunferencia:
> 
> A = √[(s-a)(s-b)(s-c)(s-d)]
> 
> donde s = (a+b+c+d)/2
> 
> (El término cos²((α+γ)/2) = 0 porque α+γ=180°)
> ```
> 
> **Con diagonales y ángulo:**
> 
> ```
> Diagonales p, q con ángulo θ entre ellas:
> 
> A = (1/2)pq sen θ
> 
> Caso especial:
> • Rombo (θ = 90°): A = pq/2
> ```
> 
> **Paralelogramo:**
> 
> ```
> A = base × altura = ah
> A = ab sen α
> 
> Con diagonales:
> A = (1/2)pq sen θ
> ```
> 
> **Trapecio:**
> 
> ```
> A = ((a + c)/2) × h
> 
> donde a, c son las bases y h la altura
> 
> Promedio de bases por altura
> ```
> 
> **Cuadrilátero tangencial:**
> 
> ```
> A = rs
> 
> donde r es el radio del círculo inscrito
> y s = (a+b+c+d)/2 es el semiperímetro
> ```

## 🎯 Teoremas Notables

> [!success]- Resultados Importantes **Teorema de Ptolomeo:**
> 
> ```
> En cuadrilátero cíclico ABCD:
> 
> AC·BD = AB·CD + BC·AD
> 
> (producto de diagonales = suma de productos
>  de lados opuestos)
> 
> Recíproco: Si se cumple la igualdad y el
> cuadrilátero es convexo, entonces es cíclico
> ```
> 
> **Teorema del cuadrilátero cíclico:**
> 
> ```
> Un cuadrilátero convexo es cíclico si y solo si:
> 
> 1. Ángulos opuestos son suplementarios:
>    α + γ = 180°, β + δ = 180°
> 
> 2. Un ángulo externo es igual al ángulo
>    interno opuesto
> 
> 3. Los cuatro vértices equidistan de un punto
> ```
> 
> **Teorema del cuadrilátero tangencial:**
> 
> ```
> Un cuadrilátero convexo es tangencial si y solo si:
> 
> a + c = b + d
> 
> (suma de lados opuestos iguales)
> 
> Teorema de Pitot
> ```
> 
> **Teorema de la mariposa:**
> 
> ```
> En trapecio con bases paralelas:
> Si las diagonales se cortan en O,
> 
> Triángulos AOB y COD tienen áreas iguales
> ```

## 🔷 Cuadriláteros Especiales

> [!tip]- Casos Notables **Cuadrado:**
> 
> ```
> Lado: a
> Diagonal: d = a√2
> Área: A = a² = d²/2
> Perímetro: P = 4a
> Radio circunscrito: R = a√2/2 = d/2
> Radio inscrito: r = a/2
> 
> Propiedades:
> • Máxima simetría entre cuadriláteros
> • 4 ejes de simetría
> • Rotación de 90° es simetría
> • Único polígono regular de 4 lados
> ```
> 
> **Rombo:**
> 
> ```
> Lado: a
> Diagonales: p, q (perpendiculares)
> 
> Relación: p² + q² = 4a²
> Área: A = pq/2 = a² sen α
> 
> Ángulos: opuestos iguales
> Si α es un ángulo, el opuesto también es α
> Los otros dos son (180° - α)
> ```
> 
> **Rectángulo áureo:**
> 
> ```
> Lados en proporción áurea:
> a/b = φ = (1+√5)/2 ≈ 1.618
> 
> Al quitar un cuadrado de lado b,
> queda otro rectángulo áureo
> 
> Presente en arte y arquitectura
> ```
> 
> **Cometa (kite):**
> 
> ```
> Dos pares de lados consecutivos iguales:
> a = b, c = d (pero a ≠ c)
> 
> Propiedades:
> • Una diagonal es eje de simetría
> • Diagonales perpendiculares
> • Una diagonal biseca a la otra
> ```
> 
> **Deltoide (cometa cóncava):**
> 
> ```
> Como cometa pero cóncavo
> Un ángulo > 180° (reflex)
> ```

## 🧮 Problemas Resueltos

> [!example]- Ejemplos Detallados **Problema 1: Área de paralelogramo**
> 
> ```
> Paralelogramo con lados a = 8 cm, b = 5 cm
> y ángulo α = 60°
> 
> SOLUCIÓN:
> 
> A = ab sen α
> A = 8 × 5 × sen 60°
> A = 40 × (√3/2)
> A = 20√3 ≈ 34.64 cm²
> ```
> 
> **Problema 2: Diagonales de rombo**
> 
> ```
> Rombo con lado a = 10 cm y una diagonal p = 16 cm
> Calcular la otra diagonal y el área
> 
> SOLUCIÓN:
> 
> Relación: p² + q² = 4a²
> 16² + q² = 4(10²)
> 256 + q² = 400
> q² = 144
> q = 12 cm
> 
> Área:
> A = pq/2 = (16 × 12)/2 = 96 cm²
> ```
> 
> **Problema 3: Verificar cuadrilátero cíclico**
> 
> ```
> Cuadrilátero con ángulos:
> α = 75°, β = 110°, γ = 105°, δ = 70°
> 
> ¿Es cíclico?
> 
> SOLUCIÓN:
> 
> Verificar suma: 75 + 110 + 105 + 70 = 360° ✓
> 
> Verificar opuestos suplementarios:
> α + γ = 75 + 105 = 180° ✓
> β + δ = 110 + 70 = 180° ✓
> 
> SÍ es cíclico
> ```
> 
> **Problema 4: Área de trapecio**
> 
> ```
> Trapecio con bases a = 12 cm, c = 8 cm
> y altura h = 5 cm
> 
> SOLUCIÓN:
> 
> A = ((a + c)/2) × h
> A = ((12 + 8)/2) × 5
> A = (20/2) × 5
> A = 10 × 5 = 50 cm²
> ```
> 
> **Problema 5: Cuadrado en coordenadas**
> 
> ```
> Vértices de cuadrado:
> A(0, 0), B(4, 0), C(4, 4), D(0, 4)
> 
> Verificar propiedades
> 
> SOLUCIÓN:
> 
> Lados:
> AB = 4, BC = 4, CD = 4, DA = 4 ✓
> 
> Diagonales:
> AC = √(16 + 16) = 4√2
> BD = √(16 + 16) = 4√2 ✓ (iguales)
> 
> Área:
> A = 4² = 16 unidades²
> O: A = (4√2)²/2 = 32/2 = 16 ✓
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes **1. "Todo cuadrilátero con 4 lados iguales es cuadrado"**
> 
> ```
> ✗ FALSO
> 
> Es un rombo
> Para ser cuadrado necesita también 4 ángulos rectos
> ```
> 
> **2. "Las diagonales de todo paralelogramo son perpendiculares"**
> 
> ```
> ✗ FALSO
> 
> Solo en el rombo y cuadrado
> En rectángulo y paralelogramo general no lo son
> ```
> 
> **3. "Un trapecio tiene dos pares de lados paralelos"**
> 
> ```
> ✗ FALSO
> 
> Eso es un paralelogramo
> Trapecio: solo UN par de lados paralelos
> ```
> 
> **4. "Área del cuadrado = 4 × lado"**
> 
> ```
> ✗ FALSO
> 
> Eso es el perímetro
> Área = lado²
> ```
