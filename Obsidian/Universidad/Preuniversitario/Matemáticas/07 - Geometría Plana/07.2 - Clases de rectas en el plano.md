# 📏 Clases de Rectas en el Plano

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Una recta en el plano es un conjunto infinito de puntos alineados que se extiende indefinidamente en ambas direcciones. Las rectas pueden clasificarse según su posición, orientación y relación con otras rectas o elementos del plano cartesiano.**
> 
> **Características clave:**
> 
> - **Infinita:** Sin principio ni fin
> - **Unidimensional:** Solo tiene longitud
> - **Determinación:** Dos puntos distintos determinan una recta única
> - **Ecuación lineal:** Se representa algebraicamente como ecuación de primer grado
> - **Clasificaciones múltiples:** Según posición, pendiente y relación con otras rectas

## 📝 Clasificación por Posición

> [!important]- Según Posición en el Plano **1. Rectas horizontales:**
> 
> ```
> Ecuación: y = k (constante)
> 
> Características:
> • Pendiente: m = 0
> • Paralela al eje x
> • Todos los puntos tienen la misma ordenada
> • No corta el eje x (excepto y = 0)
> 
> Ejemplos:
> y = 3  → recta horizontal a 3 unidades arriba del eje x
> y = 0  → el eje x mismo
> y = -2 → recta horizontal a 2 unidades debajo del eje x
> ```
> 
> **2. Rectas verticales:**
> 
> ```
> Ecuación: x = k (constante)
> 
> Características:
> • Pendiente: indefinida (∞)
> • Paralela al eje y
> • Todos los puntos tienen la misma abscisa
> • No corta el eje y (excepto x = 0)
> • No es función de x
> 
> Ejemplos:
> x = 2  → recta vertical a 2 unidades a la derecha del eje y
> x = 0  → el eje y mismo
> x = -5 → recta vertical a 5 unidades a la izquierda del eje y
> ```
> 
> **3. Rectas oblicuas:**
> 
> ```
> Ecuación: y = mx + b (m ≠ 0, m ≠ ∞)
> 
> Características:
> • Pendiente definida y no nula
> • Corta ambos ejes (salvo casos especiales)
> • Forma ángulo no recto con los ejes
> 
> Subtipos:
> a) Ascendente: m > 0 (sube de izquierda a derecha)
> b) Descendente: m < 0 (baja de izquierda a derecha)
> ```
> 
> **4. Rectas que pasan por el origen:**
> 
> ```
> Ecuación: y = mx (b = 0)
> 
> Características:
> • Pasa por (0, 0)
> • Ordenada al origen: b = 0
> • Divide el plano en dos regiones simétricas
> 
> Casos especiales:
> y = x   → bisectriz del 1er y 3er cuadrante (m = 1)
> y = -x  → bisectriz del 2do y 4to cuadrante (m = -1)
> ```

## 🎯 Clasificación por Pendiente

> [!success]- Según Valor de m **Pendiente positiva (m > 0):**
> 
> ```
> La recta es ascendente (sube)
> 
> Cuanto mayor es m, más empinada
> 
> Ejemplos:
> m = 0.5  → suave ascenso
> m = 1    → ángulo 45° (bisectriz)
> m = 2    → ascenso pronunciado
> m → ∞    → tiende a vertical
> 
> Ángulo de inclinación: 0° < α < 90°
> ```
> 
> **Pendiente negativa (m < 0):**
> 
> ```
> La recta es descendente (baja)
> 
> Cuanto más negativa, más empinada hacia abajo
> 
> Ejemplos:
> m = -0.5 → suave descenso
> m = -1   → ángulo 135° (bisectriz II y IV)
> m = -3   → descenso pronunciado
> m → -∞   → tiende a vertical
> 
> Ángulo de inclinación: 90° < α < 180°
> ```
> 
> **Pendiente cero (m = 0):**
> 
> ```
> Recta horizontal
> 
> y = b (constante)
> 
> Ángulo de inclinación: α = 0°
> ```
> 
> **Pendiente indefinida:**
> 
> ```
> Recta vertical
> 
> x = k (constante)
> 
> No se puede expresar como y = mx + b
> Ángulo de inclinación: α = 90°
> ```
> 
> **Relación pendiente-ángulo:**
> 
> ```
> m = tan α
> 
> donde α es el ángulo de inclinación
> (medido desde eje x positivo, sentido antihorario)
> 
> Tabla de valores comunes:
> α = 0°   → m = 0
> α = 30°  → m = 1/√3 ≈ 0.577
> α = 45°  → m = 1
> α = 60°  → m = √3 ≈ 1.732
> α = 90°  → m = ∞ (indefinida)
> α = 135° → m = -1
> ```

## 🔄 Clasificación por Relación entre Rectas

> [!important]- Posiciones Relativas de dos Rectas **1. Rectas paralelas:**
> 
> ```
> Definición: No se intersectan nunca
> 
> Condición algebraica:
> L₁: y = m₁x + b₁
> L₂: y = m₂x + b₂
> 
> L₁ ∥ L₂ ⟺ m₁ = m₂ y b₁ ≠ b₂
> 
> En forma general:
> A₁x + B₁y + C₁ = 0
> A₂x + B₂y + C₂ = 0
> 
> Paralelas si: A₁/A₂ = B₁/B₂ ≠ C₁/C₂
> ```
> 
> **Ejemplo:**
> 
> ```
> L₁: y = 2x + 3
> L₂: y = 2x - 1
> 
> m₁ = m₂ = 2, pero b₁ ≠ b₂
> → Son paralelas
> 
> Distancia entre ellas:
> d = |b₂ - b₁|/√(1 + m²) = |-1 - 3|/√5 = 4/√5
> ```
> 
> **2. Rectas perpendiculares (ortogonales):**
> 
> ```
> Definición: Se intersectan formando ángulo de 90°
> 
> Condición algebraica:
> L₁ ⊥ L₂ ⟺ m₁ · m₂ = -1
> 
> Equivalente: m₂ = -1/m₁ (pendientes recíprocas y opuestas)
> 
> Casos especiales:
> • Horizontal ⊥ Vertical
> • m₁ = 0 ⊥ m₂ = ∞
> ```
> 
> **Ejemplo:**
> 
> ```
> L₁: y = (3/4)x + 2
> L₂: y = -(4/3)x - 1
> 
> m₁ · m₂ = (3/4) · (-4/3) = -1 ✓
> → Son perpendiculares
> 
> Verificación:
> 3/4 y -4/3 son recíprocos con signo opuesto
> ```
> 
> **3. Rectas secantes (oblicuas):**
> 
> ```
> Definición: Se intersectan en un punto formando ángulo ≠ 90°
> 
> Condición:
> m₁ ≠ m₂ y m₁ · m₂ ≠ -1
> 
> Punto de intersección:
> Resolver sistema:
> y = m₁x + b₁
> y = m₂x + b₂
> 
> Solución única: x = (b₂ - b₁)/(m₁ - m₂)
> ```
> 
> **Ángulo entre rectas secantes:**
> 
> ```
> tan θ = |m₂ - m₁|/(1 + m₁m₂)
> 
> donde θ es el ángulo agudo entre las rectas
> 
> Si m₁m₂ = -1: θ = 90° (perpendiculares)
> ```
> 
> **4. Rectas coincidentes:**
> 
> ```
> Definición: Son la misma recta (infinitos puntos en común)
> 
> Condición:
> m₁ = m₂ y b₁ = b₂
> 
> En forma general:
> A₁/A₂ = B₁/B₂ = C₁/C₂
> 
> Ejemplo:
> 2x + 3y - 6 = 0
> 4x + 6y - 12 = 0  (misma recta, multiplicada por 2)
> ```
> 
> **Resumen de condiciones:**
> 
> ```
> Dadas L₁: A₁x + B₁y + C₁ = 0 y L₂: A₂x + B₂y + C₂ = 0
> 
> Coincidentes:     A₁/A₂ = B₁/B₂ = C₁/C₂
> Paralelas:        A₁/A₂ = B₁/B₂ ≠ C₁/C₂
> Secantes:         A₁/A₂ ≠ B₁/B₂
> Perpendiculares:  A₁A₂ + B₁B₂ = 0 (caso especial de secantes)
> ```

## 📐 Formas de la Ecuación de la Recta

> [!note]- Diversas Representaciones **1. Forma punto-pendiente:**
> 
> ```
> y - y₁ = m(x - x₁)
> 
> Útil cuando se conoce:
> • Un punto P₁ = (x₁, y₁)
> • La pendiente m
> 
> Ejemplo:
> Recta con m = 2 que pasa por (3, 1):
> y - 1 = 2(x - 3)
> y = 2x - 5
> ```
> 
> **2. Forma pendiente-ordenada (explícita):**
> 
> ```
> y = mx + b
> 
> Donde:
> • m = pendiente
> • b = ordenada al origen (y-intercepto)
> 
> Ventajas:
> • Forma más simple
> • Fácil identificar pendiente e intercepto
> • Directa para graficar
> 
> Limitación: no representa rectas verticales
> ```
> 
> **3. Forma general (implícita):**
> 
> ```
> Ax + By + C = 0
> 
> donde A, B, C ∈ ℝ y A² + B² ≠ 0
> 
> Características:
> • Representa cualquier recta (incluidas verticales)
> • Forma estándar para ecuaciones
> • Coeficientes enteros (usualmente)
> 
> Conversión a pendiente-ordenada:
> m = -A/B  (si B ≠ 0)
> b = -C/B
> 
> Si B = 0: x = -C/A (recta vertical)
> ```
> 
> **4. Forma simétrica (interceptos):**
> 
> ```
> x/a + y/b = 1
> 
> Donde:
> • a = x-intercepto (punto (a, 0))
> • b = y-intercepto (punto (0, b))
> 
> Condiciones: a ≠ 0, b ≠ 0
> 
> Ejemplo:
> x/4 + y/3 = 1
> 
> Corta x en (4, 0) y y en (0, 3)
> ```
> 
> **5. Forma paramétrica:**
> 
> ```
> x = x₀ + at
> y = y₀ + bt
> 
> donde t ∈ ℝ (parámetro)
> 
> P₀ = (x₀, y₀): punto de la recta
> v⃗ = (a, b): vector director
> 
> Ejemplo:
> x = 2 + 3t
> y = 1 - t
> 
> Pasa por (2, 1) con dirección (3, -1)
> ```
> 
> **6. Forma vectorial:**
> 
> ```
> r⃗ = r⃗₀ + tv⃗
> 
> donde:
> r⃗ = (x, y): punto genérico
> r⃗₀ = (x₀, y₀): punto fijo
> v⃗ = (a, b): vector director
> t ∈ ℝ: parámetro
> 
> Equivalente a forma paramétrica
> ```
> 
> **7. Forma normal:**
> 
> ```
> x cos α + y sen α - p = 0
> 
> donde:
> • α: ángulo de la normal con eje x
> • p: distancia del origen a la recta
> 
> Útil para distancias y proyecciones
> ```
> 
> **8. Forma de dos puntos:**
> 
> ```
> (y - y₁)/(y₂ - y₁) = (x - x₁)/(x₂ - x₁)
> 
> Dados dos puntos P₁ = (x₁, y₁) y P₂ = (x₂, y₂)
> 
> Forma alternativa (determinante):
> |x   y   1|
> |x₁  y₁  1| = 0
> |x₂  y₂  1|
> ```

## 🎯 Rectas Notables

> [!important]- Casos Especiales **Ejes coordenados:**
> 
> ```
> Eje x: y = 0
> • Recta horizontal
> • Divide plano en semiplanos superior e inferior
> 
> Eje y: x = 0
> • Recta vertical
> • Divide plano en semiplanos derecho e izquierdo
> ```
> 
> **Bisectrices de los cuadrantes:**
> 
> ```
> Bisectriz I-III: y = x
> • m = 1, b = 0
> • Ángulo 45° con ambos ejes
> • Divide I y III cuadrante
> 
> Bisectriz II-IV: y = -x
> • m = -1, b = 0
> • Ángulo 135° con eje x
> • Divide II y IV cuadrante
> 
> Propiedad: son perpendiculares entre sí
> ```
> 
> **Rectas tangentes:**
> 
> ```
> Tangente a un círculo:
> • Perpendicular al radio en punto de tangencia
> • Único punto de intersección con el círculo
> 
> Tangente a una cónica:
> • En parábola: una tangente por punto exterior
> • En elipse: dos tangentes por punto exterior
> • En hipérbola: dos tangentes por punto exterior
> ```
> 
> **Mediatrices:**
> 
> ```
> Mediatriz de segmento AB:
> • Perpendicular a AB
> • Pasa por punto medio M
> • Lugar geométrico: puntos equidistantes de A y B
> 
> Si A = (x₁, y₁) y B = (x₂, y₂):
> 1. M = ((x₁+x₂)/2, (y₁+y₂)/2)
> 2. m_AB = (y₂-y₁)/(x₂-x₁)
> 3. m_mediatriz = -1/m_AB
> 4. Ecuación: y - y_M = m_mediatriz(x - x_M)
> ```
> 
> **Alturas, medianas y bisectrices (en triángulos):**
> 
> ```
> Altura desde vértice A:
> • Perpendicular al lado opuesto BC
> 
> Mediana desde vértice A:
> • Une A con punto medio de BC
> 
> Bisectriz del ángulo en A:
> • Divide ángulo en dos partes iguales
> • Lugar geométrico: equidistante de lados
> ```

## 📊 Haces de Rectas

> [!note]- Familias de Rectas **Haz de rectas concurrentes:**
> 
> ```
> Todas pasan por un punto fijo P = (x₀, y₀)
> 
> Ecuación del haz:
> y - y₀ = m(x - x₀)
> 
> donde m varía en ℝ ∪ {∞}
> 
> Cada valor de m da una recta del haz
> ```
> 
> **Haz de rectas paralelas:**
> 
> ```
> Todas tienen la misma pendiente m
> 
> Ecuación del haz:
> y = mx + b
> 
> donde b varía en ℝ
> 
> Cada valor de b da una recta paralela
> ```
> 
> **Haz determinado por dos rectas:**
> 
> ```
> Dadas L₁ y L₂:
> L₁: A₁x + B₁y + C₁ = 0
> L₂: A₂x + B₂y + C₂ = 0
> 
> Ecuación del haz:
> (A₁x + B₁y + C₁) + λ(A₂x + B₂y + C₂) = 0
> 
> donde λ ∈ ℝ es parámetro
> 
> • λ = 0: recta L₁
> • λ = -1: recta L₂
> • λ ≠ 0, -1: otra recta del haz
> 
> Si L₁ y L₂ secantes: haz de rectas por intersección
> Si L₁ ∥ L₂: haz de paralelas
> ```

## 🧩 Problemas Resueltos

> [!example]- Ejemplos Detallados **Problema 1: Clasificar rectas**
> 
> ```
> Clasificar las siguientes rectas y determinar sus relaciones:
> L₁: 2x + 3y - 6 = 0
> L₂: 3x - 2y + 4 = 0
> L₃: 4x + 6y - 12 = 0
> 
> SOLUCIÓN:
> 
> Convertir a forma pendiente-ordenada:
> 
> L₁: 3y = -2x + 6
>     y = (-2/3)x + 2
>     m₁ = -2/3, b₁ = 2
> 
> L₂: -2y = -3x - 4
>     y = (3/2)x + 2
>     m₂ = 3/2, b₂ = 2
> 
> L₃: 6y = -4x + 12
>     y = (-2/3)x + 2
>     m₃ = -2/3, b₃ = 2
> 
> Análisis:
> • L₁ y L₃: m₁ = m₃ = -2/3, b₁ = b₃ = 2
>   → SON COINCIDENTES (misma recta)
> 
> • L₁ y L₂: m₁·m₂ = (-2/3)·(3/2) = -1
>   → SON PERPENDICULARES
> 
> Clasificación individual:
> • L₁, L₃: oblicuas descendentes (m < 0)
> • L₂: oblicua ascendente (m > 0)
> ```
> 
> **Problema 2: Encontrar recta perpendicular**
> 
> ```
> Encontrar la ecuación de la recta perpendicular a
> L: 2x - 5y + 3 = 0 que pasa por P = (1, -2)
> 
> SOLUCIÓN:
> 
> Paso 1: Pendiente de L
> 2x - 5y + 3 = 0
> -5y = -2x - 3
> y = (2/5)x + 3/5
> m_L = 2/5
> 
> Paso 2: Pendiente perpendicular
> m_⊥ = -1/m_L = -1/(2/5) = -5/2
> 
> Paso 3: Ecuación punto-pendiente
> y - y₁ = m(x - x₁)
> y - (-2) = (-5/2)(x - 1)
> y + 2 = (-5/2)x + 5/2
> y = (-5/2)x + 5/2 - 2
> y = (-5/2)x + 1/2
> 
> Forma general:
> 2y = -5x + 1
> 5x + 2y - 1 = 0
> 
> Verificación: 2·5 + (-5)·2 = 10 - 10 = 0 ✓
> (A₁A₂ + B₁B₂ = 0 confirma perpendicularidad)
> ```
> 
> **Problema 3: Intersección de rectas**
> 
> ```
> Encontrar punto de intersección y ángulo entre:
> L₁: x + 2y - 5 = 0
> L₂: 3x - y + 1 = 0
> 
> SOLUCIÓN:
> 
> Parte A: Punto de intersección
> Sistema:
> x + 2y = 5    ... (1)
> 3x - y = -1   ... (2)
> 
> De (2): y = 3x + 1
> Sustituir en (1):
> x + 2(3x + 1) = 5
> x + 6x + 2 = 5
> 7x = 3
> x = 3/7
> 
> y = 3(3/7) + 1 = 9/7 + 1 = 16/7
> 
> Intersección: P = (3/7, 16/7)
> 
> Parte B: Ángulo entre rectas
> Pendientes:
> m₁ = -1/2 (de L₁)
> m₂ = 3 (de L₂)
> 
> tan θ = |m₂ - m₁|/(1 + m₁m₂)
>       = |3 - (-1/2)|/(1 + (-1/2)·3)
>       = |7/2|/(1 - 3/2)
>       = (7/2)/(-1/2)
>       = -7
> 
> Como sale negativo, usar valor absoluto:
> tan θ = 7
> θ = arctan(7) ≈ 81.87°
> 
> Ángulo agudo: 180° - 81.87° = 98.13°
> Tomamos el menor: 81.87°
> ```
> 
> **Problema 4: Haz de rectas**
> 
> ```
> Encontrar la ecuación de la recta del haz determinado por
> L₁: x - y + 1 = 0 y L₂: 2x + y - 5 = 0
> que pasa por el punto P = (0, 3)
> 
> SOLUCIÓN:
> 
> Ecuación del haz:
> (x - y + 1) + λ(2x + y - 5) = 0
> 
> Expandir:
> x - y + 1 + 2λx + λy - 5λ = 0
> (1 + 2λ)x + (-1 + λ)y + (1 - 5λ) = 0
> 
> Pasa por P(0, 3):
> (1 + 2λ)·0 + (-1 + λ)·3 + (1 - 5λ) = 0
> -3 + 3λ + 1 - 5λ = 0
> -2λ - 2 = 0
> λ = -1
> 
> Sustituyendo λ = -1:
> (1 + 2(-1))x + (-1 + (-1))y + (1 - 5(-1)) = 0
> (1 - 2)x + (-2)y + (1 + 5) = 0
> -x - 2y + 6 = 0
> 
> Simplificando:
> x + 2y - 6 = 0
> 
> Verificación: 0 + 2(3) - 6 = 0 ✓
> ```
> 
> **Problema 5: Distancia punto a recta**
> 
> ```
> Calcular la distancia del punto P = (2, 3) a la recta
> L: 3x - 4y + 5 = 0
> 
> Luego, encontrar la ecuación de la recta paralela a L
> que pasa por P.
> 
> SOLUCIÓN:
> 
> Parte A: Distancia
> Fórmula: d = |Ax₀ + By₀ + C|/√(A² + B²)
> 
> d = |3(2) - 4(3) + 5|/√(3² + 4²)
>   = |6 - 12 + 5|/√(9 + 16)
>   = |-1|/√25
>   = 1/5 unidades
> 
> Parte B: Recta paralela
> Paralela tiene misma pendiente:
> 3x - 4y + C' = 0
> 
> Pasa por P(2, 3):
> 3(2) - 4(3) + C' = 0
> 6 - 12 + C' = 0
> C' = 6
> 
> Ecuación: 3x - 4y + 6 = 0
> 
> Verificación distancia entre paralelas:
> d = |C' - C|/√(A² + B²) = |6 - 5|/5 = 1/5 ✓
> ```

## 🎨 Regiones del Plano

> [!note]- Semiplanos y Desigualdades **Semiplanos definidos por rectas:**
> 
> ```
> Una recta L: Ax + By + C = 0 divide el plano en dos semiplanos
> 
> Semiplano superior/derecho: Ax + By + C > 0
> Semiplano inferior/izquierdo: Ax + By + C < 0
> 
> La recta misma: Ax + By + C = 0
> 
> Ejemplo:
> L: x - y = 0 (bisectriz y = x)
> 
> Región x - y > 0: debajo de la recta
> Región x - y < 0: arriba de la recta
> ```
> 
> **Sistemas de inecuaciones:**
> 
> ```
> Intersección de varios semiplanos
> 
> Ejemplo:
> x + y ≤ 5
> x - y ≥ -1
> x ≥ 0
> y ≥ 0
> 
> Define región poligonal (programación lineal)
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes **1. "Pendiente m = A/B en Ax + By + C = 0"**
> 
> ```
> ✗ FALSO
> 
> Pendiente correcta: m = -A/B (con signo negativo)
> 
> Razón: By = -Ax - C → y = (-A/B)x - C/B
> ```
> 
> **2. "Rectas perpendiculares tienen pendientes opuestas"**
> 
> ```
> ✗ FALSO (incompleto)
> 
> Son recíprocas y opuestas: m₂ = -1/m₁
> 
> Ejemplo:
> m₁ = 2 → m₂ = -1/2 (no m₂ = -2)
> ```
> 
> **3. "Si dos rectas no se intersectan, son paralelas"**

> ```
> ✗ FALSO en 3D, VERDADERO en 2D
> 
> En el plano: si no se intersectan → paralelas o coincidentes
> En el espacio: pueden ser alabeadas (skew lines)
> 
> En este tema (plano): la afirmación es correcta
> ```
> 
> **4. "La distancia entre dos rectas siempre existe"**
> 
> ```
> ✗ FALSO (mal planteado)
> 
> Solo tiene sentido para rectas paralelas
> 
> • Paralelas: distancia constante
> • Secantes: distancia = 0 (se intersectan)
> • Coincidentes: distancia = 0
> ```
> 
> **5. "Toda recta se puede escribir como y = mx + b"**
> 
> ```
> ✗ FALSO
> 
> Rectas verticales (x = k) no se pueden expresar así
> Necesitan forma general: Ax + By + C = 0
> ```
> 
> **6. "Si m₁ = m₂, las rectas son la misma"**
> 
> ```
> ✗ FALSO
> 
> Solo son paralelas (o coincidentes)
> Para ser la misma: m₁ = m₂ Y b₁ = b₂
> ```
> 
> **7. "El ángulo entre rectas siempre es agudo"**
> 
> ```
> ✗ FALSO (impreciso)
> 
> La fórmula tan θ = |m₂-m₁|/(1+m₁m₂) da el ángulo agudo
> Pero pueden formar ángulos de 0° a 180°
> 
> Usualmente se reporta el ángulo agudo (0° ≤ θ ≤ 90°)
> ```

## 🎯 Propiedades Métricas Avanzadas

> [!important]- Distancias y Proyecciones **Distancia entre rectas paralelas:**
> 
> ```
> L₁: Ax + By + C₁ = 0
> L₂: Ax + By + C₂ = 0  (mismo A, B)
> 
> d(L₁, L₂) = |C₂ - C₁|/√(A² + B²)
> 
> Ejemplo:
> L₁: 3x + 4y - 5 = 0
> L₂: 3x + 4y + 10 = 0
> 
> d = |10 - (-5)|/√(9 + 16) = 15/5 = 3 unidades
> ```
> 
> **Proyección de punto sobre recta:**
> 
> ```
> Punto P = (x₀, y₀)
> Recta L: Ax + By + C = 0
> 
> Proyección P' (pie de perpendicular):
> 
> 1. Recta perpendicular por P:
>    Bx - Ay + D = 0 donde D = -Bx₀ + Ay₀
> 
> 2. Intersección con L:
>    Resolver sistema de ecuaciones
> 
> Fórmula directa:
> P' = (x₀ - A·t, y₀ - B·t)
> donde t = (Ax₀ + By₀ + C)/(A² + B²)
> ```
> 
> **Simetría de punto respecto a recta:**
> 
> ```
> Punto P y su simétrico P' respecto a L:
> • L es mediatriz de PP'
> • Proyección P₀ es punto medio de PP'
> 
> P' = 2P₀ - P
> 
> Fórmulas:
> x' = x₀ - 2A·t
> y' = y₀ - 2B·t
> donde t = (Ax₀ + By₀ + C)/(A² + B²)
> ```

## 📐 Aplicaciones Especiales

> [!note]- Contextos Prácticos **1. Rectas de mejor ajuste (regresión lineal):**
> 
> ```
> Dados n puntos: (x₁, y₁), (x₂, y₂), ..., (xₙ, yₙ)
> 
> Recta de mínimos cuadrados: y = mx + b
> 
> m = [n∑(xᵢyᵢ) - ∑xᵢ·∑yᵢ] / [n∑(xᵢ²) - (∑xᵢ)²]
> 
> b = [∑yᵢ - m∑xᵢ] / n
> 
> Minimiza la suma de errores cuadrados
> ```
> 
> **2. Trayectorias rectilíneas:**
> 
> ```
> Movimiento rectilíneo uniforme (MRU):
> 
> x(t) = x₀ + v_x·t
> y(t) = y₀ + v_y·t
> 
> Ecuación paramétrica de recta
> Vector velocidad v⃗ = (v_x, v_y) es vector director
> ```
> 
> **3. Líneas de nivel:**
> 
> ```
> Función f(x,y) = c (constante)
> 
> Si f es lineal: f(x,y) = Ax + By
> Líneas de nivel son rectas paralelas
> 
> Ejemplo: campo eléctrico uniforme
> Equipotenciales son rectas paralelas
> ```
> 
> **4. Rectas de frontera:**
> 
> ```
> En optimización lineal:
> • Restricciones: Ax + By ≤ c
> • Frontera: Ax + By = c
> • Región factible: intersección de semiplanos
> • Solución óptima: en vértices (intersecciones)
> ```
> 
> **5. Trazado en arquitectura e ingeniería:**
> 
> ```
> • Replanteo de terrenos
> • Alineamiento de estructuras
> • Trazado de vías (pendientes constantes)
> • Niveles de construcción (horizontales)
> ```

## 🔄 Transformaciones de Rectas

> [!tip]- Bajo Transformaciones Geométricas **Traslación:**
> 
> ```
> Recta L: y = mx + b
> Traslación por vector v⃗ = (h, k):
> 
> L': y - k = m(x - h)
>     y = mx + (b - mh + k)
> 
> Nueva ordenada: b' = b - mh + k
> Pendiente no cambia: m' = m
> ```
> 
> **Reflexión respecto al eje x:**
> 
> ```
> L: y = mx + b
> L': y = -mx - b
> 
> Pendiente cambia de signo
> Ordenada cambia de signo
> ```
> 
> **Reflexión respecto al eje y:**
> 
> ```
> L: y = mx + b
> L': y = -mx + b
> 
> Pendiente cambia de signo
> Ordenada se mantiene
> ```
> 
> **Reflexión respecto al origen:**
> 
> ```
> L: y = mx + b
> L': y = mx - b
> 
> Pendiente se mantiene
> Ordenada cambia de signo
> ```
> 
> **Reflexión respecto a y = x:**
> 
> ```
> L: y = mx + b
> L': x = my + b  o  y = (1/m)x - b/m
> 
> Se intercambian roles de x e y
> Pendiente se invierte: m' = 1/m
> ```
> 
> **Rotación respecto al origen (ángulo θ):**
> 
> ```
> Recta por origen: y = mx
> Rotada: y = m'x donde m' = (m + tan θ)/(1 - m tan θ)
> 
> Si θ = 90°: m' = -1/m (perpendicular)
> ```
> 
> **Homotecia (escalamiento) desde origen:**
> 
> ```
> Factor k:
> L: y = mx + b
> L': y = mx + kb
> 
> Pendiente invariante
> Ordenada se escala
> ```

## 📊 Sistemas de Ecuaciones Lineales

> [!important]- Interpretación Geométrica **Sistema 2×2:**
> 
> ```
> a₁x + b₁y = c₁  ... L₁
> a₂x + b₂y = c₂  ... L₂
> 
> Solución = intersección de L₁ y L₂
> 
> Casos:
> 1. Solución única: L₁ y L₂ secantes
>    Determinante ≠ 0
> 
> 2. Sin solución: L₁ ∥ L₂ (distintas)
>    Determinante = 0, sistema inconsistente
> 
> 3. Infinitas soluciones: L₁ = L₂ (coincidentes)
>    Determinante = 0, sistema dependiente
> ```
> 
> **Ejemplo de análisis:**
> 
> ```
> Sistema:
> 2x + 3y = 6
> 4x + 6y = 12
> 
> Determinante:
> |2  3|
> |4  6| = 2·6 - 3·4 = 12 - 12 = 0
> 
> Verificar si son paralelas o coincidentes:
> L₁: y = -2/3·x + 2
> L₂: y = -4/6·x + 2 = -2/3·x + 2
> 
> Son la misma recta → infinitas soluciones
> Todos los puntos de la recta son solución
> ```

## 🎨 Construcciones Geométricas con Rectas

> [!tip]- Métodos Clásicos **Construcción de perpendicular:**
> 
> ```
> Dada recta L y punto P:
> 
> Método 1 (P sobre L):
> 1. Trazar arco con centro en P
> 2. Marca dos puntos A, B sobre L
> 3. Arcos desde A y B (mismo radio) se intersectan
> 4. Unir intersecciones
> 
> Método 2 (P fuera de L):
> 1. Arco con centro en P corta L en dos puntos
> 2. Mediatriz de ese segmento
> ```
> 
> **Construcción de paralela:**
> 
> ```
> Dada L y punto P:
> 
> 1. Trazar recta auxiliar por P que corte L
> 2. Copiar ángulo formado en P
> 3. Nueva recta es paralela
> 
> Método alternativo (con perpendiculares):
> 4. Perpendicular a L
> 5. Perpendicular a esa por P
> ```
> 
> **División de segmento:**
> 
> ```
> Dividir AB en n partes iguales:
> 
> Teorema de Tales:
> 6. Trazar semirrecta desde A
> 7. Marcar n puntos equidistantes
> 8. Unir último con B
> 9. Paralelas desde otros puntos dividen AB
> ```

## 🧮 Coordenadas y Ecuaciones Especiales

> [!note]- Representaciones Avanzadas **Ecuación segmentaria:**
> 
> ```
> Segmento de P₁ a P₂ (no recta completa):
> 
> (1-t)P₁ + tP₂  donde 0 ≤ t ≤ 1
> 
> x = (1-t)x₁ + tx₂
> y = (1-t)y₁ + ty₂
> 
> t = 0: punto P₁
> t = 1: punto P₂
> t = 0.5: punto medio
> ```
> 
> **Ecuación en coordenadas polares:**
> 
> ```
> Recta que no pasa por origen:
> r = p/(cos(θ - α))
> 
> donde:
> • p: distancia mínima al origen
> • α: ángulo de la perpendicular desde origen
> 
> Recta por origen:
> θ = constante
> ```
> 
> **Ecuación en forma de Hesse:**
> 
> ```
> x cos α + y sen α - p = 0
> 
> Forma normal, donde:
> • Vector normal: n⃗ = (cos α, sen α) unitario
> • p > 0: distancia dirigida del origen
> 
> Útil para cálculos de distancias orientadas
> ```

## 🎯 Problemas Avanzados

> [!example]- Desafíos Adicionales **Problema 1: Familia paramétrica**
> 
> ```
> Encontrar el valor de k para que las rectas:
> L₁: kx + 2y - 3 = 0
> L₂: 3x - ky + 5 = 0
> sean perpendiculares.
> 
> SOLUCIÓN:
> 
> Condición de perpendicularidad:
> A₁A₂ + B₁B₂ = 0
> 
> k·3 + 2·(-k) = 0
> 3k - 2k = 0
> k = 0
> 
> Verificación:
> Si k = 0:
> L₁: 2y - 3 = 0 → y = 3/2 (horizontal)
> L₂: 3x + 5 = 0 → x = -5/3 (vertical)
> 
> Horizontal y vertical son perpendiculares ✓
> ```
> 
> **Problema 2: Triángulo formado por rectas**
> 
> ```
> Encontrar el área del triángulo formado por:
> L₁: x + y = 4
> L₂: x - y = 2
> L₃: y = 1
> 
> SOLUCIÓN:
> 
> Paso 1: Vértices (intersecciones)
> 
> A = L₁ ∩ L₂:
> x + y = 4
> x - y = 2
> Sumando: 2x = 6 → x = 3, y = 1
> A = (3, 1)
> 
> B = L₁ ∩ L₃:
> x + 1 = 4 → x = 3
> B = (3, 1)... ¡mismo que A!
> 
> Revisión: L₃ pasa por A
> 
> B = L₂ ∩ L₃:
> x - 1 = 2 → x = 3
> x = 3, y = 1... también A
> 
> ERROR: Las tres rectas son concurrentes en (3,1)
> No forman triángulo (área = 0)
> 
> [Revisar enunciado o buscar otro punto]
> 
> Corrección del problema:
> Si L₃: y = 0 (eje x):
> 
> A = L₁ ∩ L₂ = (3, 1) [igual]
> B = L₁ ∩ L₃: x + 0 = 4 → B = (4, 0)
> C = L₂ ∩ L₃: x - 0 = 2 → C = (2, 0)
> 
> Vértices: A(3,1), B(4,0), C(2,0)
> 
> Área = (1/2)|x₁(y₂-y₃) + x₂(y₃-y₁) + x₃(y₁-y₂)|
>      = (1/2)|3(0-0) + 4(0-1) + 2(1-0)|
>      = (1/2)|0 - 4 + 2|
>      = (1/2)·2 = 1 unidad cuadrada
> ```
> 
> **Problema 3: Lugar geométrico**
> 
> ```
> Encontrar el lugar geométrico de puntos P tales que
> la suma de distancias a las rectas:
> L₁: x = 2 y L₂: x = -2
> es constante e igual a 6.
> 
> SOLUCIÓN:
> 
> Sea P = (x, y)
> 
> Distancia a L₁: d₁ = |x - 2|
> Distancia a L₂: d₂ = |x - (-2)| = |x + 2|
> 
> Condición: d₁ + d₂ = 6
> |x - 2| + |x + 2| = 6
> 
> Análisis por casos:
> 
> Caso 1: x ≥ 2
> (x - 2) + (x + 2) = 6
> 2x = 6
> x = 3
> 
> Caso 2: -2 ≤ x < 2
> -(x - 2) + (x + 2) = 6
> -x + 2 + x + 2 = 6
> 4 = 6 (FALSO)
> No hay solución en este intervalo
> 
> Caso 3: x < -2
> -(x - 2) - (x + 2) = 6
> -x + 2 - x - 2 = 6
> -2x = 6
> x = -3
> 
> Lugar geométrico: dos rectas verticales
> x = 3 y x = -3
> 
> Interpretación: puntos a distancia 1 de cada recta dada
> ```
> 
> **Problema 4: Optimización**
> 
> ```
> Entre todas las rectas que pasan por P = (2, 1),
> encontrar la que forma con los ejes coordenados
> positivos un triángulo de área mínima.
> 
> SOLUCIÓN:
> 
> Recta por P con interceptos a > 0, b > 0:
> x/a + y/b = 1
> 
> Pasa por P(2, 1):
> 2/a + 1/b = 1
> 
> De aquí: b = a/(a-2) donde a > 2
> 
> Área del triángulo:
> A = (1/2)ab = (1/2)a · a/(a-2) = a²/[2(a-2)]
> 
> Minimizar A:
> dA/da = [2a(a-2) - a²·1]/[2(a-2)²]
>       = [2a² - 4a - a²]/[2(a-2)²]
>       = [a² - 4a]/[2(a-2)²]
>       = a(a - 4)/[2(a-2)²]
> 
> dA/da = 0:
> a(a - 4) = 0
> a = 4 (a = 0 no válido)
> 
> Si a = 4: b = 4/(4-2) = 2
> 
> Área mínima: A = (1/2)·4·2 = 4 unidades²
> 
> Ecuación de la recta:
> x/4 + y/2 = 1
> x + 2y = 4
> ```
