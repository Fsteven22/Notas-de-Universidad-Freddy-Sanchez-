# 🔷 Poligonales y Polígonos

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Una poligonal es una sucesión finita de segmentos consecutivos donde el extremo de cada uno coincide con el origen del siguiente. Un polígono es una poligonal cerrada simple (no se cruza a sí misma) que delimita una región del plano.**
> 
> **Características clave:**
> 
> - **Vértices:** Puntos donde se unen los segmentos
> - **Lados:** Segmentos que conectan vértices consecutivos
> - **Cerrado vs Abierto:** Polígonos (cerrados) vs poligonales abiertas
> - **Simple vs Complejo:** Sin auto-intersecciones vs con cruces
> - **Región interior:** Área delimitada por el polígono

>

>     - Polígonos inscriptibles
> - **Arquímedes (250 a.C.):** Aproximaciones
>     - Cálculo de π usando polígonos

>

>     - Polígonos en espacios curvos

## 📐 Clasificación de Poligonales

> [!important]- Tipos de Poligonales **Por estructura:**
> 
> ```
> 1. Poligonal abierta:
>    • Extremos no coinciden
>    • No delimita región
>    • Ejemplo: camino, trayectoria
>    
>    Vértices: P₁, P₂, ..., Pₙ (P₁ ≠ Pₙ)
>    Lados: n - 1 segmentos
> 
> 2. Poligonal cerrada:
>    • Extremo final coincide con inicial
>    • Pₙ = P₁
>    • Delimita una o más regiones
>    
>    Lados: n segmentos (igual número de vértices)
> 
> 3. Poligonal simple:
>    • No se cruza a sí misma
>    • Los lados no se intersectan excepto en vértices
>    • Puede ser abierta o cerrada
> 
> 4. Poligonal compleja (no simple):
>    • Se cruza a sí misma
>    • Lados se intersectan
>    • Puede crear múltiples regiones
> ```
> 
> **Propiedades métricas:**
> 
> ```
> Longitud de poligonal:
> L = suma de longitudes de todos los lados
> L = |P₁P₂| + |P₂P₃| + ... + |Pₙ₋₁Pₙ|
> 
> Para poligonal cerrada:
> L = |P₁P₂| + |P₂P₃| + ... + |PₙP₁|
> (perímetro si es polígono)
> 
> Distancia entre extremos (poligonal abierta):
> d = |P₁Pₙ| (distancia directa)
> 
> Desigualdad triangular extendida:
> d ≤ L (con igualdad solo si es rectilínea)
> ```

## 🔷 Definición y Elementos de Polígonos

> [!success]- Componentes Básicos **Definición formal:**
> 
> ```
> Polígono: Poligonal cerrada simple que delimita
> una región conexa del plano
> 
> Notación: P = {P₁, P₂, ..., Pₙ}
> o simplemente: A₁A₂...Aₙ
> 
> Elementos:
> 
> 1. Vértices: Puntos Pᵢ (i = 1, 2, ..., n)
>    • n vértices para polígono de n lados
> 
> 2. Lados: Segmentos PᵢPᵢ₊₁
>    • n lados
>    • P₁P₂, P₂P₃, ..., PₙP₁
> 
> 3. Ángulos internos: αᵢ en cada vértice
>    • Medidos dentro del polígono
>    • Suma depende de n
> 
> 4. Ángulos externos: βᵢ = 180° - αᵢ
>    • Suma siempre 360° (polígono convexo)
> 
> 5. Diagonales: Segmentos entre vértices no consecutivos
>    • Número: D = n(n-3)/2
> 
> 6. Perímetro: P = suma de longitudes de lados
> 
> 7. Área: A = medida de la región interior
> ```
> 
> **Notación de vértices:**
> 
> ```
> Orden: Sentido antihorario (convención positiva)
> 
> Consecutivos: Pᵢ y Pᵢ₊₁ son adyacentes
> Opuestos: Separados por n/2 vértices (si n es par)
> 
> Ejemplo: Cuadrilátero ABCD
> Vértices consecutivos: A-B, B-C, C-D, D-A
> Vértices opuestos: A-C, B-D
> ```

## 📊 Clasificación de Polígonos

> [!important]- Según Distintos Criterios **Por número de lados:**
> 
> ```
> n = 3:  Triángulo
> n = 4:  Cuadrilátero
> n = 5:  Pentágono
> n = 6:  Hexágono
> n = 7:  Heptágono (o Septágono)
> n = 8:  Octágono (u Octógono)
> n = 9:  Eneágono (o Nonágono)
> n = 10: Decágono
> n = 11: Endecágono (o Undecágono)
> n = 12: Dodecágono
> n = 15: Pentadecágono
> n = 20: Icoságono
> n:      n-gono (término general)
> 
> Nombres especiales:
> n = 100: Hectágono
> n = 1000: Chiliágono
> n = 10000: Miriágono
> ```
> 
> **Por convexidad:**
> 
> ```
> 1. Polígono convexo:
>    • Todos los ángulos internos < 180°
>    • Toda diagonal está en el interior
>    • Segmento entre dos puntos interiores
>      está completamente dentro
>    • Intersección de semiplanos
>    
>    Propiedad: Suma ángulos internos = (n-2)×180°
> 
> 2. Polígono cóncavo (no convexo):
>    • Al menos un ángulo interno > 180°
>    • Alguna diagonal está fuera
>    • Tiene al menos un vértice "hacia dentro"
>    
>    Vértice reflex: ángulo interno > 180°
> 
> 3. Polígono estrellado:
>    • Polígono no simple con forma de estrella
>    • Lados se cruzan
>    • Notación: {n/k} (n puntas, salto de k)
>    
>    Ejemplos:
>    {5/2}: Pentagrama (estrella de 5 puntas)
>    {6/2}: Hexagrama (estrella de David)
> ```
> 
> **Por regularidad:**
> 
> ```
> 4. Polígono regular:
>    • Todos los lados congruentes (equilátero)
>    • Todos los ángulos congruentes (equiángulo)
>    • Inscriptible y circunscriptible
>    • Alta simetría
>    
>    Propiedades:
>    - Centro: equidista de todos los vértices
>    - Radio: distancia del centro al vértice
>    - Apotema: distancia del centro al lado
>    - Ángulo central: 360°/n
>    - Ángulo interno: (n-2)×180°/n
> 
> 5. Polígono irregular:
>    • Lados o ángulos diferentes
>    • Mayoría de polígonos prácticos
> 
> 6. Casos intermedios:
>    - Equilátero pero no equiángulo: Rombo (no cuadrado)
>    - Equiángulo pero no equilátero: Rectángulo (no cuadrado)
> ```
> 
> **Por inscriptibilidad:**
> 
> ```
> 7. Polígono inscrito (cíclico):
>    • Todos los vértices en una circunferencia
>    • Condición (cuadrilátero): α + γ = 180°
>    • Teorema de Ptolomeo se aplica
> 
> 8. Polígono circunscrito:
>    • Todos los lados tangentes a una circunferencia
>    • Condición (cuadrilátero): a + c = b + d
>      (lados opuestos suman igual)
> 
> 9. Polígono bicéntrico:
>    • Inscrito Y circunscrito simultáneamente
>    • Muy restrictivo
>    • Todos los regulares son bicéntricos
> ```

## 🎯 Propiedades Fundamentales

> [!note]- Teoremas Esenciales **Suma de ángulos:**
> 
> ```
> Polígono convexo de n lados:
> 
> Suma de ángulos internos:
> Sᵢ = (n - 2) × 180°
> 
> Demostración: Triangulación desde un vértice
> crea (n-2) triángulos, cada uno suma 180°
> 
> Suma de ángulos externos:
> Sₑ = 360° (siempre, para polígono convexo)
> 
> Demostración: Una vuelta completa al recorrer
> el perímetro girando en cada vértice
> 
> Relación:
> αᵢ + βᵢ = 180° en cada vértice
> Sumando: Sᵢ + Sₑ = n × 180°
> ```
> 
> **Diagonales:**
> 
> ```
> Número total de diagonales:
> D = n(n - 3)/2
> 
> Demostración:
> - Desde cada vértice: n - 3 diagonales
>   (no a sí mismo ni a adyacentes)
> - Total sin corregir: n(n - 3)
> - Dividir entre 2 (cada diagonal se cuenta 2 veces)
> 
> Diagonales desde un vértice: n - 3
> 
> Ejemplos:
> Triángulo (n=3): D = 0
> Cuadrilátero (n=4): D = 2
> Pentágono (n=5): D = 5
> Hexágono (n=6): D = 9
> Decágono (n=10): D = 35
> ```
> 
> **Triangulación:**
> 
> ```
> Todo polígono de n lados puede dividirse en triángulos:
> 
> Desde un vértice: n - 2 triángulos
> 
> Triangulación general:
> - Número de triángulos: n - 2
> - Número de diagonales usadas: n - 3
> 
> Método de las orejas (algoritmo):
> Siempre existe un vértice "oreja" que se puede cortar
> ```
> 
> **Perímetro y área:**
> 
> ```
> Perímetro:
> P = L₁ + L₂ + ... + Lₙ
> 
> Para polígono regular de lado a:
> P = n × a
> 
> Área (método general):
> Fórmula del agrimensor (coordenadas):
> 
> A = (1/2)|Σᵢ(xᵢyᵢ₊₁ - xᵢ₊₁yᵢ)|
> 
> donde (xₙ₊₁, yₙ₊₁) = (x₁, y₁)
> 
> Signo positivo: orientación antihoraria
> Signo negativo: orientación horaria
> ```

## 🔺 Triángulos

> [!important]- Polígono de 3 Lados **Clasificación por lados:**
> 
> ```
> 1. Equilátero:
>    • Tres lados iguales: a = b = c
>    • Tres ángulos iguales: α = β = γ = 60°
>    • Regular
>    • Máxima simetría
> 
> 2. Isósceles:
>    • Dos lados iguales: a = b ≠ c
>    • Dos ángulos iguales (base)
>    • Eje de simetría
> 
> 3. Escaleno:
>    • Tres lados diferentes: a ≠ b ≠ c
>    • Tres ángulos diferentes
>    • Sin simetría
> ```
> 
> **Clasificación por ángulos:**
> 
> ```
> 4. Acutángulo:
>    • Todos los ángulos agudos (< 90°)
>    
> 5. Rectángulo:
>    • Un ángulo recto (= 90°)
>    • Teorema de Pitágoras: a² + b² = c²
>    • Hipotenusa (lado mayor)
>    
> 6. Obtusángulo:
>    • Un ángulo obtuso (> 90°)
> ```
> 
> **Elementos notables:**
> 
> ```
> Alturas: Perpendiculares de vértice a lado opuesto
> - Ortocentro: Intersección de alturas
> 
> Medianas: De vértice a punto medio del lado opuesto
> - Baricentro: Intersección (centro de gravedad)
> - Divide cada mediana 2:1
> 
> Mediatrices: Perpendiculares en puntos medios
> - Circuncentro: Intersección (centro circunscrito)
> 
> Bisectrices: Dividen ángulos en dos partes iguales
> - Incentro: Intersección (centro inscrito)
> 
> Recta de Euler: O, G, H son colineales
> (Circuncentro, Baricentro, Ortocentro)
> ```
> 
> **Fórmulas de área:**
> 
> ```
> A = (1/2) × base × altura
> 
> Fórmula de Herón:
> A = √[s(s-a)(s-b)(s-c)]
> donde s = (a+b+c)/2 (semiperímetro)
> 
> Con dos lados y ángulo incluido:
> A = (1/2)ab sen C
> 
> Con coordenadas:
> A = (1/2)|x₁(y₂-y₃) + x₂(y₃-y₁) + x₃(y₁-y₂)|
> ```

## 🔶 Cuadriláteros

> [!success]- Polígono de 4 Lados **Clasificación general:**
> 
> ```
> Suma de ángulos internos: 360°
> Diagonales: 2
> 
> Árbol de clasificación:
> 
> CUADRILÁTERO
> ├── Paralelogramo (lados opuestos paralelos)
> │   ├── Rectángulo (4 ángulos rectos)
> │   │   └── Cuadrado (4 lados iguales)
> │   ├── Rombo (4 lados iguales)
> │   │   └── Cuadrado
> │   └── Romboide (caso general)
> │
> ├── Trapecio (un par de lados paralelos)
> │   ├── Isósceles (lados no paralelos iguales)
> │   ├── Rectángulo (dos ángulos rectos)
> │   └── Escaleno (caso general)
> │
> └── Trapezoide (ningún lado paralelo)
>     ├── Simétrico (deltoide/cometa)
>     └── Asimétrico
> ```
> 
> **Paralelogramos:**
> 
> ```
> Propiedades:
> • Lados opuestos paralelos e iguales
> • Ángulos opuestos iguales
> • Ángulos consecutivos suplementarios
> • Diagonales se bisecan mutuamente
> • Centro de simetría (punto medio de diagonales)
> 
> Área: A = base × altura
>       A = ab sen θ (θ: ángulo entre lados)
> 
> Tipos especiales:
> 
> 1. Cuadrado:
>    • Todos los lados iguales
>    • Todos los ángulos rectos
>    • Diagonales iguales y perpendiculares
>    • Máxima simetría
>    • A = a²
>    • A = d²/2 (d: diagonal)
> 
> 2. Rectángulo:
>    • Cuatro ángulos rectos
>    • Lados opuestos iguales
>    • Diagonales iguales
>    • A = base × altura
> 
> 3. Rombo:
>    • Cuatro lados iguales
>    • Ángulos opuestos iguales
>    • Diagonales perpendiculares
>    • A = (d₁ × d₂)/2
> 
> 4. Romboide:
>    • Paralelogramo general
>    • Sin propiedades adicionales
> ```
> 
> **Trapecios:**
> 
> ```
> Definición: Un par de lados paralelos (bases)
> 
> Elementos:
> • Base mayor: B
> • Base menor: b
> • Altura: h (distancia entre bases)
> • Lados laterales (no paralelos)
> 
> Área: A = (B + b) × h / 2
> 
> Mediana (segmento medio):
> m = (B + b) / 2
> A = m × h
> 
> Tipos:
> 
> 1. Isósceles:
>    • Lados no paralelos iguales
>    • Ángulos de la base iguales
>    • Diagonales iguales
>    • Inscriptible en circunferencia
> 
> 2. Rectángulo:
>    • Dos ángulos rectos
>    • Un lado lateral perpendicular a bases
> 
> 3. Escaleno:
>    • Caso general
> ```
> 
> **Cuadriláteros especiales:**
> 
> ```
> Deltoide (Cometa):
> • Dos pares de lados consecutivos iguales
> • Una diagonal es eje de simetría
> • Diagonales perpendiculares
> • A = (d₁ × d₂)/2
> 
> Cuadrilátero cíclico:
> • Inscrito en circunferencia
> • Ángulos opuestos suplementarios: α + γ = 180°
> • Fórmula de Brahmagupta:
>   A = √[(s-a)(s-b)(s-c)(s-d)]
>   donde s = (a+b+c+d)/2
> 
> Cuadrilátero tangencial:
> • Circunscrito a circunferencia
> • Suma de lados opuestos iguales: a + c = b + d
> • A = rs (r: radio inscrito, s: semiperímetro)
> ```

## ⬡ Polígonos Regulares

> [!important]- Propiedades y Fórmulas **Elementos del polígono regular:**
> 
> ```
> Polígono regular de n lados:
> 
> 1. Centro O: Equidista de todos los vértices
> 
> 2. Radio R: Distancia del centro al vértice
>    (Radio de la circunferencia circunscrita)
> 
> 3. Apotema a: Distancia del centro al lado
>    (Radio de la circunferencia inscrita)
>    
> 4. Lado L: Longitud de cada lado
> 
> Relaciones:
> 
> Ángulo central: θ = 360°/n = 2π/n rad
> 
> Ángulo interno: α = (n-2)×180°/n
>                 α = 180° - 360°/n
> 
> Ángulo externo: β = 360°/n
> 
> Lado y radio:
> L = 2R sen(180°/n)
> L = 2R sen(π/n)
> 
> Apotema y radio:
> a = R cos(180°/n)
> a = R cos(π/n)
> 
> Lado y apotema:
> L = 2a tan(180°/n)
> a = L/(2 tan(180°/n))
> 
> Relación pitagórica:
> R² = a² + (L/2)²
> ```
> 
> **Perímetro y área:**
> 
> ```
> Perímetro:
> P = nL
> 
> Área (varias fórmulas):
> 
> A = (1/2) × P × a
>   = (nL × a)/2
> 
> A = (nL²)/(4 tan(180°/n))
> 
> A = (nR²/2) sen(360°/n)
>   = (nR²/2) sen(2π/n)
> 
> A = na² tan(180°/n)
> 
> Aproximación para n grande:
> A → πR² (tiende al círculo)
> ```
> 
> **Tabla de polígonos regulares comunes:**
> 
> ```
> n  Nombre      Ángulo Int  Ángulo Ext  L (R=1)    a (R=1)
> 3  Triángulo   60°         120°        1.732      0.500
> 4  Cuadrado    90°         90°         1.414      0.707
> 5  Pentágono   108°        72°         1.176      0.809
> 6  Hexágono    120°        60°         1.000      0.866
> 8  Octágono    135°        45°         0.765      0.924
> 10 Decágono    144°        36°         0.618      0.951
> 12 Dodecágono  150°        30°         0.518      0.966
> 
> Fórmulas exactas:
> L₃ = R√3
> L₄ = R√2
> L₆ = R
> L₈ = R√(2-√2)
> ```
> 
> **Constructibilidad:**
> 
> ```
> Teorema de Gauss-Wantzel (1796):
> Un polígono regular de n lados es construible
> con regla y compás si y solo si:
> 
> n = 2ᵏ × p₁ × p₂ × ... × pₘ
> 
> donde pᵢ son primos de Fermat distintos
> 
> Primos de Fermat conocidos:
> F₀ = 3
> F₁ = 5
> F₂ = 17
> F₃ = 257
> F₄ = 65537
> 
> Polígonos constructibles hasta n=30:
> 3, 4, 5, 6, 8, 10, 12, 15, 16, 17, 20, 24, 30
> 
> NO constructibles:
> 7, 9, 11, 13, 14, 18, 19, 21, 22, 23, 25...
> ```

## 📐 Área de Polígonos

> [!note]- Métodos de Cálculo **Fórmula del agrimensor (coordenadas):**
> 
> ```
> Vértices: (x₁,y₁), (x₂,y₂), ..., (xₙ,yₙ)
> en orden (antihorario para área positiva)
> 
> A = (1/2)|Σᵢ₌₁ⁿ (xᵢyᵢ₊₁ - xᵢ₊₁yᵢ)|
> 
> donde (xₙ₊₁, yₙ₊₁) = (x₁, y₁)
> 
> Forma matricial (determinante):
> A = (1/2)|Σᵢ₌₁ⁿ det([xᵢ yᵢ; xᵢ₊₁ yᵢ₊₁])|
> 
> Forma desarrollada:
> A = (1/2)|x₁(y₂-yₙ) + x₂(y₃-y₁) + ... + xₙ(y₁-yₙ₋₁)|
> 
> Ventaja: Funciona para cualquier polígono
> (convexo o cóncavo)
> ```
> 
> **Triangulación:**
> 
> ```
> Dividir polígono en triángulos:
> 
> 1. Desde un vértice:
>    - Trazar n-3 diagonales
>    - Crear n-2 triángulos
>    - Área = suma de áreas de triángulos
> 
> 2. Método de abanico (desde centro):
>    - Unir centro con cada vértice
>    - n triángulos
>    - Útil para polígonos regulares
> 
> 3. Triangulación de Delaunay:
>    - Maximiza ángulo mínimo
>    - Única para polígonos convexos
> ```
> 
> **Método de descomposición:**
> 
> ```
> Polígonos irregulares:
> 
> 4. Dividir en figuras conocidas:
>    - Triángulos, rectángulos, trapecios
>    - Calcular área de cada parte
>    - Sumar o restar según corresponda
> 
> 5. Método de inclusión-exclusión:
>    - Encerrar en rectángulo
>    - Área = Rectángulo - Regiones externas
> ```
> 
> **Fórmula de Pick (polígonos en retícula):**
> 
> ```
> Para polígonos con vértices en puntos enteros:
> 
> A = I + B/2 - 1
> 
> donde:
> I = número de puntos interiores
> B = número de puntos en el borde
> 
> Ejemplo: Triángulo con vértices (0,0), (3,0), (0,4)
> I = 5 puntos interiores
> B = 10 puntos en borde
> A = 5 + 10/2 - 1 = 9 unidades cuadradas
> 
> Verificación: A = (3×4)/2 = 6... 
> [Reconteo necesario]
> ```

## 🎨 Teselaciones

> [!tip]- Recubrimientos del Plano **Teselaciones regulares:**
> 
> ```
> Solo 3 polígonos regulares teselan el plano:
> 
> 1. Triángulos equiláteros {3,6}:
>    • 6 triángulos en cada vértice
>    • Ángulo: 6 × 60° = 360°
> 
> 2. Cuadrados {4,4}:
>    • 4 cuadrados en cada vértice
>    • Ángulo: 4 × 90° = 360°
> 
> 3. Hexágonos regulares {6,3}:
>    • 3 hexágonos en cada vértice
>    • Ángulo: 3 × 120° = 360°
> 
> Condición: n × α_interior = 360°
> Solo se cumple para n = 3, 4, 6
> ```
> 
> **Teselaciones semi-regulares (arquimedianas):**
> 
> ```
> Combinación de polígonos regulares distintos
> Misma configuración en cada vértice
> 
> Existen exactamente 8:
> 
> 1. (3,3,3,3,6): Triángulos y hexágonos
> 2. (3,3,3,4,4): Triángulos y cuadrados 3. (3,3,4,3,4): Triángulos y cuadrados (alt.) 4. (3,4,6,4): Triángulo, cuadrado, hexágono 5. (3,6,3,6): Triángulos y hexágonos alternados 6. (3,12,12): Triángulo y dodecágonos 7. (4,6,12): Cuadrado, hexágono, dodecágono 8. (4,8,8): Cuadrado y octágonos
> 
> Notación (p,q,r,...): Polígonos alrededor de cada vértice
> 
> ```
> 
> **Teselaciones de Penrose:**
> ```
> 
> Teselaciones aperiódicas: • No son periódicas (no se repiten por traslación) • Cubren todo el plano sin huecos • Simetría quíntuple (relacionada con φ)
> 
> Dos piezas básicas:
> 
> - Cometa (kite)
> - Dardo (dart)
> 
> Aplicaciones: • Cuasicristales (Premio Nobel 2011) • Arte y arquitectura
> ```

## 🧩 Problemas Resueltos

> [!example]- Ejemplos Detallados **Problema 1: Número de lados**
> 
> ```
> Un polígono regular tiene ángulos internos de 156°.
> ¿Cuántos lados tiene? ¿Cuántas diagonales?
> 
> SOLUCIÓN:
> 
> Fórmula del ángulo interno:
> α = (n-2) × 180° / n = 156°
> 
> Resolviendo:
> (n-2) × 180° = 156n
> 180n - 360 = 156n
> 24n = 360
> n = 15 lados (pentadecágono)
> 
> Diagonales:
> D = n(n-3)/2 = 15(12)/2 = 90 diagonales
> 
> Verificación ángulo externo:
> β = 360°/15 = 24°
> α + β = 156° + 24° = 180° ✓
> ```
> 
> **Problema 2: Área con coordenadas**
> 
> ```
> Calcular el área del cuadrilátero con vértices:
> A(1,2), B(4,5), C(7,3), D(3,1)
> 
> SOLUCIÓN:
> 
> Fórmula del agrimensor:
> A = (1/2)|Σ(xᵢyᵢ₊₁ - xᵢ₊₁yᵢ)|
> 
> Ordenando vértices (antihorario):
> (x₁,y₁) = (1,2)
> (x₂,y₂) = (4,5)
> (x₃,y₃) = (7,3)
> (x₄,y₄) = (3,1)
> (x₅,y₅) = (1,2) [vuelve al inicio]
> 
> Calculando:
> x₁y₂ - x₂y₁ = 1(5) - 4(2) = 5 - 8 = -3
> x₂y₃ - x₃y₂ = 4(3) - 7(5) = 12 - 35 = -23
> x₃y₄ - x₄y₃ = 7(1) - 3(3) = 7 - 9 = -2
> x₄y₅ - x₅y₄ = 3(2) - 1(1) = 6 - 1 = 5
> 
> Suma = -3 - 23 - 2 + 5 = -23
> 
> A = (1/2)|-23| = 11.5 unidades cuadradas
> ```
> 
> **Problema 3: Polígono regular inscrito**
> 
> ```
> Un hexágono regular está inscrito en una circunferencia
> de radio 10 cm. Calcular:
> a) Longitud del lado
> b) Apotema
> c) Perímetro
> d) Área
> 
> SOLUCIÓN:
> 
> Datos: n = 6, R = 10 cm
> 
> a) Lado:
> L = 2R sen(180°/n)
> L = 2(10) sen(180°/6)
> L = 20 sen(30°)
> L = 20(0.5) = 10 cm
> 
> [Para hexágono: L = R siempre]
> 
> b) Apotema:
> a = R cos(180°/n)
> a = 10 cos(30°)
> a = 10(√3/2)
> a = 5√3 ≈ 8.66 cm
> 
> c) Perímetro:
> P = nL = 6(10) = 60 cm
> 
> d) Área:
> A = (1/2) × P × a
> A = (1/2) × 60 × 5√3
> A = 150√3 ≈ 259.81 cm²
> 
> Verificación con otra fórmula:
> A = (nR²/2) sen(360°/n)
> A = (6 × 100/2) sen(60°)
> A = 300(√3/2) = 150√3 ✓
> ```
> 
> **Problema 4: Trapecio**
> 
> ```
> Un trapecio isósceles tiene bases de 8 cm y 14 cm,
> y lados laterales de 5 cm.
> Calcular: a) altura, b) área, c) ángulos
> 
> SOLUCIÓN:
> 
> Datos: B = 14 cm, b = 8 cm, L = 5 cm
> 
> a) Altura:
> Proyección horizontal de cada lado lateral:
> p = (B - b)/2 = (14 - 8)/2 = 3 cm
> 
> Por Pitágoras:
> h² + p² = L²
> h² + 3² = 5²
> h² = 25 - 9 = 16
> h = 4 cm
> 
> b) Área:
> A = (B + b) × h / 2
> A = (14 + 8) × 4 / 2
> A = 22 × 2 = 44 cm²
> 
> c) Ángulos:
> Ángulos en la base mayor:
> tan α = h/p = 4/3
> α = arctan(4/3) ≈ 53.13°
> 
> Ángulos en la base menor:
> β = 180° - α ≈ 126.87°
> ```
> 
> **Problema 5: Diagonal del polígono**
> 
> ```
> ¿Cuántos lados tiene un polígono si el número
> de diagonales es 5 veces el número de lados?
> 
> SOLUCIÓN:
> 
> Relación dada: D = 5n
> 
> Fórmula de diagonales:
> D = n(n-3)/2
> 
> Igualando:
> n(n-3)/2 = 5n
> 
> Si n ≠ 0:
> (n-3)/2 = 5
> n - 3 = 10
> n = 13 lados (tridecágono)
> 
> Verificación:
> D = 13(10)/2 = 65 diagonales
> 5n = 5(13) = 65 ✓
> ```
> 
> **Problema 6: Polígono irregular**
> 
> ```
> Calcular el área del pentágono con vértices:
> (0,0), (4,0), (6,3), (3,5), (0,3)
> 
> SOLUCIÓN:
> 
> Método 1: Fórmula del agrimensor
> 
> Vértices en orden:
> (x₁,y₁) = (0,0)
> (x₂,y₂) = (4,0)
> (x₃,y₃) = (6,3)
> (x₄,y₄) = (3,5)
> (x₅,y₅) = (0,3)
> 
> A = (1/2)|x₁(y₂-y₅) + x₂(y₃-y₁) + x₃(y₄-y₂) 
>          + x₄(y₅-y₃) + x₅(y₁-y₄)|
> 
> A = (1/2)|0(0-3) + 4(3-0) + 6(5-0) 
>          + 3(3-3) + 0(0-5)|
> A = (1/2)|0 + 12 + 30 + 0 + 0|
> A = (1/2)|42| = 21 unidades cuadradas
> 
> Método 2: Descomposición
> Dividir en triángulos y trapecios
> [Similar resultado]
> ```
> 
> **Problema 7: Apotema de polígono regular**
> 
> ```
> Un octágono regular tiene lado de 6 cm.
> Calcular su apotema y área.
> 
> SOLUCIÓN:
> 
> Datos: n = 8, L = 6 cm
> 
> Apotema:
> a = L / (2 tan(180°/n))
> a = 6 / (2 tan(180°/8))
> a = 6 / (2 tan(22.5°))
> a = 6 / (2 × 0.4142...)
> a = 6 / 0.8284
> a ≈ 7.24 cm
> 
> Valor exacto:
> tan(22.5°) = √2 - 1
> a = 6 / (2(√2-1))
> a = 3 / (√2-1)
> a = 3(√2+1) / ((√2-1)(√2+1))
> a = 3(√2+1) / (2-1)
> a = 3(√2+1) = 3√2 + 3 ≈ 7.24 cm
> 
> Perímetro:
> P = 8 × 6 = 48 cm
> 
> Área:
> A = (1/2) × P × a
> A = (1/2) × 48 × 3(√2+1)
> A = 24 × 3(√2+1)
> A = 72(√2+1)
> A = 72√2 + 72 ≈ 173.82 cm²
> ```

## 🔄 Transformaciones de Polígonos

> [!note]- Operaciones Geométricas **Traslación:**
> 
> ```
> Mover polígono por vector v⃗ = (h, k)
> 
> Cada vértice (x, y) → (x+h, y+k)
> 
> Propiedades invariantes:
> • Forma y tamaño
> • Ángulos
> • Perímetro y área
> • Orientación
> ```
> 
> **Rotación:**
> 
> ```
> Rotar θ grados alrededor del origen:
> 
> x' = x cos θ - y sen θ
> y' = x sen θ + y cos θ
> 
> Alrededor de punto (a, b):
> 1. Trasladar a origen: (x-a, y-b)
> 2. Rotar
> 3. Trasladar de vuelta: (x'+a, y'+b)
> 
> Invariantes:
> • Forma, tamaño, área
> • Distancias y ángulos
> ```
> 
> **Reflexión:**
> 
> ```
> Respecto al eje x: (x, y) → (x, -y)
> Respecto al eje y: (x, y) → (-x, y)
> Respecto a y=x: (x, y) → (y, x)
> 
> Respecto a recta general:
> Usar fórmulas de simetría
> 
> Cambia orientación (horario ↔ antihorario)
> ```
> 
> **Homotecia:**
> 
> ```
> Escalar desde origen con factor k:
> (x, y) → (kx, ky)
> 
> Si k > 1: ampliación
> Si 0 < k < 1: reducción
> Si k < 0: inversión y cambio de tamaño
> 
> Área se multiplica por k²
> Perímetro por |k|
> ```
> 
> **Proyección:**
> 
> ```
> Proyección ortogonal sobre eje x:
> (x, y) → (x, 0)
> 
> Proyección sobre eje y:
> (x, y) → (0, y)
> 
> Reduce dimensión (polígono → segmento)
> ```

## 📊 Desigualdades y Optimización

> [!important]- Problemas de Extremos **Desigualdad isoperimétrica:**
> 
> ```
> Entre todos los polígonos de n lados
> con perímetro fijo P:
> 
> El de área máxima es el regular
> 
> A_max = P² / (4n tan(180°/n))
> 
> Caso límite (n → ∞):
> El círculo maximiza área para perímetro dado
> A_círculo = P² / (4π)
> 
> Desigualdad general:
> A ≤ P² / (4n tan(180°/n))
> 
> con igualdad solo para polígono regular
> ```
> 
> **Perímetro mínimo para área dada:**
> 
> ```
> Entre polígonos de n lados con área A fija:
> 
> El regular minimiza el perímetro
> 
> P_min = 2√(nA tan(180°/n))
> 
> Ejemplo: Rectángulos de área A
> Perímetro mínimo: cuadrado
> P_min = 4√A
> ```
> 
> **Teorema de Erdős-Mordell:**
> 
> ```
> Para un punto P interior a un triángulo:
> 
> Si d₁, d₂, d₃ = distancias a los lados
>    r₁, r₂, r₃ = distancias a los vértices
> 
> Entonces: r₁ + r₂ + r₃ ≥ 2(d₁ + d₂ + d₃)
> 
> Igualdad solo si triángulo equilátero
> y P es el centro
> ```
> 
> **Cuadrilátero de área máxima:**
> 
> ```
> Dados 4 lados a, b, c, d:
> 
> Área máxima cuando es cíclico (inscriptible)
> 
> Fórmula de Brahmagupta:
> A_max = √[(s-a)(s-b)(s-c)(s-d)]
> donde s = (a+b+c+d)/2
> 
> Caso especial (lados opuestos iguales):
> Si a=c y b=d → paralelogramo
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes **1. "Hexágono tiene 6 diagonales"**
> 
> ```
> ✗ FALSO
> 
> D = n(n-3)/2 = 6(3)/2 = 9 diagonales
> 
> No confundir con número de lados
> ```
> 
> **2. "Todo cuadrilátero con lados iguales es cuadrado"**
> 
> ```
> ✗ FALSO
> 
> Rombo tiene 4 lados iguales pero no es cuadrado
> Falta la condición: ángulos rectos
> 
> Cuadrado = Rombo + Rectángulo
> ```
> 
> **3. "La suma de ángulos depende del tipo de polígono"**
> 
> ```
> ✗ FALSO
> 
> Solo depende del número de lados n
> S = (n-2) × 180°
> 
> Regular o irregular: misma suma
> ```
> 
> **4. "Área = (Perímetro)²"**
> 
> ```
> ✗ FALSO (dimensionalmente imposible)
> 
> Perímetro: unidades lineales [L]
> Área: unidades cuadradas [L²]
> 
> No existe relación universal P → A
> ```
> 
> **5. "Fórmula de Herón vale para cualquier polígono"**
> 
> ```
> ✗ FALSO
> 
> Solo para triángulos (con semiperímetro)
> 
> Para cuadriláteros: Fórmula de Brahmagupta
> (solo si es cíclico)
> ```
> 
> **6. "Apotema = Radio/2"**
> 
> ```
> ✗ FALSO (solo cierto para hexágono)
> 
> Relación correcta:
> a = R cos(180°/n)
> 
> Depende del número de lados
> ```
> 
> **7. "Polígono cóncavo tiene área negativa"**
> 
> ```
> ✗ FALSO
> 
> El área siempre es positiva (valor absoluto)
> 
> El signo en la fórmula del agrimensor indica
> orientación, no área negativa
> ```

## 🎓 Conceptos Clave - Mapa Mental

> [!important]- Estructura Conceptual
> 
> ```
> POLIGONALES Y POLÍGONOS
> │
> ├── POLIGONALES
> │   ├── Abiertas (P₁ ≠ Pₙ)
> │   ├── Cerradas (P₁ = Pₙ)
> │   ├── Simples (no se cruzan)
> │   └── Complejas (se cruzan)
> │
> ├── DEFINICIÓN DE POLÍGONO
> │   ├── Elementos
> │   │   ├── Vértices (n puntos)
> │   │   ├── Lados (n segmentos)
> │   │   ├── Ángulos (internos/externos)
> │   │   ├── Diagonales: D = n(n-3)/2
> │   │   ├── Perímetro: suma de lados
> │   │   └── Área: región interior
> │   │
> │   └── Propiedades
> │       ├── Suma ángulos: (n-2)×180°
> │       ├── Suma externos: 360°
> │       └── Triangulación: n-2 triángulos
> │
> ├── CLASIFICACIÓN
> │   ├── Por lados
> │   │   ├── Triángulo (n=3)
> │   │   ├── Cuadrilátero (n=4)
> │   │   ├── Pentágono (n=5)
> │   │   └── n-gono
> │   │
> │   ├── Por convexidad
> │   │   ├── Convexo (α < 180°)
> │   │   ├── Cóncavo (algún α > 180°)
> │   │   └── Estrellado {n/k}
> │   │
> │   └── Por regularidad
> │       ├── Regular (lados y ángulos iguales)
> │       └── Irregular
> │
> ├── TRIÁNGULOS (n=3)
> │   ├── Por lados: equilátero, isósceles, escaleno
