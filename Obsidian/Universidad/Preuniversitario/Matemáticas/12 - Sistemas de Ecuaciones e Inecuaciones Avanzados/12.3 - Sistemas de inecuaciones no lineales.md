# 🔀 Sistemas de Inecuaciones No Lineales

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Un sistema de inecuaciones no lineales es un conjunto de dos o más desigualdades que involucran expresiones no lineales (cuadráticas, racionales, exponenciales, etc.) en dos o más variables. La solución es la región del plano o espacio que satisface simultáneamente todas las inecuaciones del sistema, formando regiones delimitadas por curvas.**
> 
> **Características clave:**
> 
> - **Múltiples restricciones:** Conjunto de desigualdades simultáneas
> - **Frontera no lineal:** Curvas (círculos, parábolas, hipérbolas, etc.)
> - **Región factible:** Intersección de regiones
> - **Representación gráfica:** Esencial para visualización
> - **Aplicaciones:** Optimización, ingeniería, economía

>     - Optimización con restricciones
>     - Máximos y mínimos
>

> 
> - **Cauchy (1821):** Desigualdades fundamentales
>     - Teoría rigurosa de desigualdades
> - **Weierstrass (1850s):** Teoría de optimización
>     - Existencia de extremos
> - **Farkas (1894-1902):** Lema de Farkas
>     - Teoría de sistemas de desigualdades lineales

## 📝 Definición Formal

> [!success]- Marco Matemático **Sistema de inecuaciones no lineales:**
> 
> ```
> Forma general en ℝ²:
> 
> ⎧ f₁(x, y) ≤ 0   (o ≥, <, >)
> ⎪ f₂(x, y) ≤ 0
> ⎨ f₃(x, y) ≤ 0
> ⎪ ⋮
> ⎩ fₙ(x, y) ≤ 0
> 
> donde al menos una fᵢ es no lineal
> 
> Solución: S = {(x, y) ∈ ℝ² : todas las inecuaciones se cumplen}
> S = ⋂ᵢ₌₁ⁿ Sᵢ  (intersección de regiones)
> ```
> 
> **Tipos de inecuaciones no lineales:**
> 
> ```
> 1. Cuadráticas:
>    ax² + bxy + cy² + dx + ey + f ≤ 0
>    Ejemplos: círculos, elipses, parábolas, hipérbolas
> 
> 2. Polinomiales:
>    Pₙ(x, y) ≤ 0 con grado n ≥ 2
> 
> 3. Racionales:
>    P(x,y)/Q(x,y) ≤ 0
>    Requiere Q(x,y) ≠ 0
> 
> 4. Exponenciales:
>    e^(ax+by) + c ≤ 0
> 
> 5. Logarítmicas:
>    ln(ax + by + c) ≤ d
> 
> 6. Trigonométricas:
>    sen(x) + cos(y) ≤ k
> 
> 7. Mixtas:
>    Combinación de tipos anteriores
> ```
> 
> **Clasificación de regiones:**
> 
> ```
> Según frontera:
> • Incluida: ≤ o ≥ (frontera parte de solución)
> • No incluida: < o > (frontera excluida)
> 
> Según topología:
> • Acotada: región finita
> • No acotada: región infinita
> • Conexa: una sola pieza
> • No conexa: varias componentes
> 
> Según convexidad:
> • Convexa: segmento entre dos puntos está en región
> • No convexa: puede tener "huecos" o concavidades
> ```

## 🎯 Método de Solución Gráfico

> [!important]- Proceso Sistemático **Algoritmo general:**
> 
> ```
> Para cada inecuación del sistema:
> 
> PASO 1: Graficar la frontera
> • Resolver ecuación fᵢ(x, y) = 0
> • Identificar tipo de curva (círculo, parábola, etc.)
> • Graficar con línea continua (≤, ≥) o discontinua (<, >)
> 
> PASO 2: Determinar región solución
> • Método del punto de prueba:
>   - Elegir punto conveniente (típicamente origen si no está en frontera)
>   - Evaluar fᵢ(x, y) en el punto
>   - Si cumple inecuación: región contiene el punto
>   - Si no cumple: región en lado opuesto
> 
> PASO 3: Sombrear región
> • Marcar región que satisface la inecuación
> • Usar trama o color distintivo
> 
> PASO 4: Intersección de regiones
> • Identificar región común a todas las inecuaciones
> • Esta es la solución del sistema
> • Verificar con puntos de prueba en región final
> 
> PASO 5: Identificar características
> • Vértices (intersecciones de fronteras)
> • Región acotada o no acotada
> • Conexa o no conexa
> ```
> 
> **Ejemplo básico:**
> 
> ```
> Sistema:
> ⎧ x² + y² ≤ 9      (interior del círculo r=3)
> ⎨ y ≥ x²          (encima de parábola)
> ⎩ y ≤ 4           (debajo de recta horizontal)
> 
> Solución paso a paso:
> 
> 1) Frontera 1: x² + y² = 9 (círculo centro origen, r=3)
>    Punto prueba (0,0): 0+0=0 ≤ 9 ✓
>    Región: interior del círculo
> 
> 2) Frontera 2: y = x² (parábola vertical)
>    Punto prueba (0,1): 1 ≥ 0 ✓
>    Región: encima de parábola
> 
> 3) Frontera 3: y = 4 (recta horizontal)
>    Punto prueba (0,0): 0 ≤ 4 ✓
>    Región: debajo de y=4
> 
> Solución: región donde se solapan las tres
> ```

## 📐 Sistemas con Cónicas

> [!note]- Inecuaciones Cuadráticas **Sistema con círculo:**
> 
> ```
> Ejemplo 1:
> ⎧ x² + y² ≤ 16     (dentro del círculo r=4)
> ⎩ x² + y² ≥ 4      (fuera del círculo r=2)
> 
> Solución: corona circular (anillo)
> 2 ≤ √(x²+y²) ≤ 4
> 
> Región acotada, conexa (una pieza)
> Área = π(4²) - π(2²) = 16π - 4π = 12π
> ```
> 
> **Sistema con elipse:**
> 
> ```
> Ejemplo 2:
> ⎧ x²/9 + y²/4 ≤ 1  (dentro de elipse)
> ⎨ x ≥ 0            (semiespacio derecho)
> ⎩ y ≥ 0            (semiespacio superior)
> 
> Solución: cuarto de elipse (primer cuadrante)
> 
> Vértices (fronteras):
> • (0, 0): origen
> • (3, 0): sobre eje x
> • (0, 2): sobre eje y
> • Arco de elipse conectando (3,0) con (0,2)
> 
> Área = (1/4)πab = (1/4)π(3)(2) = (3π/2)
> ```
> 
> **Sistema con parábola:**
> 
> ```
> Ejemplo 3:
> ⎧ y ≤ 4 - x²       (debajo de parábola)
> ⎨ y ≥ x² - 4       (encima de parábola)
> ⎩ |x| ≤ 2          (franja vertical)
> 
> Dos parábolas: una cóncava hacia abajo, otra hacia arriba
> 
> Intersecciones:
> 4 - x² = x² - 4
> 8 = 2x²
> x = ±2
> 
> Puntos: (2, 0) y (-2, 0)
> 
> Solución: región entre parábolas para -2 ≤ x ≤ 2
> ```
> 
> **Sistema con hipérbola:**
> 
> ```
> Ejemplo 4:
> ⎧ x² - y² ≥ 4      (fuera de hipérbola)
> ⎨ x² + y² ≤ 16     (dentro de círculo)
> ⎩ x ≥ 0            (semiespacio derecho)
> 
> Hipérbola: x²/4 - y²/4 = 1 (asíntotas y = ±x)
> Círculo: r = 4
> 
> Solución: dos regiones no conexas
> (una en cada rama de la hipérbola, dentro del círculo)
> ```

## 🔍 Sistemas Mixtos

> [!tip]- Combinación de Tipos **Sistema lineal-cuadrático:**
> 
> ```
> Ejemplo:
> ⎧ x² + y² ≤ 25     (círculo r=5)
> ⎨ 3x + 4y ≤ 20     (recta)
> ⎩ x ≥ 0, y ≥ 0     (primer cuadrante)
> 
> Análisis:
> 
> 1) Círculo x² + y² = 25
>    Interceptos: (±5, 0) y (0, ±5)
>    En cuadrante I: cuarto de círculo
> 
> 2) Recta 3x + 4y = 20
>    Interceptos: x: (20/3, 0), y: (0, 5)
>    Pendiente: m = -3/4
> 
> 3) Intersección recta-círculo:
>    Sustituir y = (20-3x)/4 en x²+y²=25
>    x² + [(20-3x)/4]² = 25
>    16x² + (20-3x)² = 400
>    16x² + 400 - 120x + 9x² = 400
>    25x² - 120x = 0
>    x(25x - 120) = 0
>    x = 0 o x = 4.8
>    
>    Puntos: (0, 5) y (4.8, 1.4)
> 
> Vértices de región:
> • (0, 0)
> • (0, 5)
> • (4.8, 1.4)
> • (5, 0)
> • Arco circular de (4.8, 1.4) a (5, 0)
> ```
> 
> **Sistema racional:**
> 
> ```
> Ejemplo:
> ⎧ 1/(x²+y²) ≤ 1    equivale a x²+y² ≥ 1
> ⎨ xy ≤ 1           (hipérbola)
> ⎩ x > 0, y > 0     (primer cuadrante)
> 
> Región 1: fuera de círculo unitario
> Región 2: debajo de hipérbola xy=1
> 
> Intersección:
> x² + y² = 1 y xy = 1
> x² + 1/x² = 1 (sustituyendo y=1/x)
> x⁴ - x² + 1 = 0
> 
> Discriminante: 1 - 4 = -3 < 0
> No hay intersección real en primer cuadrante
> 
> Solución: región "acotada" por círculo y asíntota de hipérbola
> ```
> 
> **Sistema exponencial-polinomial:**
> 
> ```
> Ejemplo:
> ⎧ e^x ≤ y + 1      (encima de curva exponencial desplazada)
> ⎨ y ≤ 4 - x²       (debajo de parábola)
> ⎩ x ≥ -2           (derecha de recta vertical)
> 
> Frontera 1: y = e^x - 1
> Frontera 2: y = 4 - x²
> 
> Intersección (numérica):
> e^x - 1 = 4 - x²
> e^x + x² = 5
> Resolver numéricamente: x ≈ 1.17
> y ≈ 2.63
> 
> Región: entre curvas para x ∈ [-2, 1.17]
> ```

## 🧩 Problemas Resueltos

> [!example]- Ejemplos Detallados **Problema 1: Sistema básico con círculo**
> 
> ```
> Resolver y graficar:
> ⎧ x² + y² ≤ 9
> ⎨ y ≥ x - 1
> ⎩ x + y ≤ 3
> 
> SOLUCIÓN:
> 
> Paso 1: Identificar fronteras
> 
> F₁: x² + y² = 9 (círculo, centro (0,0), r=3)
> F₂: y = x - 1 (recta, pendiente 1, ord. -1)
> F₃: x + y = 3 (recta, pendiente -1, ord. 3)
> 
> Paso 2: Determinar regiones
> 
> Inecuación 1: x² + y² ≤ 9
> Prueba (0,0): 0 ≤ 9 ✓
> Región: interior del círculo (incluye frontera)
> 
> Inecuación 2: y ≥ x - 1
> Prueba (0,0): 0 ≥ -1 ✓
> Región: encima de la recta
> 
> Inecuación 3: x + y ≤ 3
> Prueba (0,0): 0 ≤ 3 ✓
> Región: debajo de la recta
> 
> Paso 3: Intersecciones de fronteras
> 
> F₂ ∩ F₃: y = x-1 y x+y = 3
> x + (x-1) = 3 → 2x = 4 → x = 2, y = 1
> Punto: A = (2, 1)
> 
> F₁ ∩ F₂: x² + y² = 9 y y = x-1
> x² + (x-1)² = 9
> x² + x² - 2x + 1 = 9
> 2x² - 2x - 8 = 0
> x² - x - 4 = 0
> x = (1 ± √17)/2
> x₁ ≈ 2.56, y₁ ≈ 1.56
> x₂ ≈ -1.56, y₂ ≈ -2.56
> Puntos: B = (2.56, 1.56), C = (-1.56, -2.56)
> 
> F₁ ∩ F₃: x² + y² = 9 y x+y = 3
> x² + (3-x)² = 9
> x² + 9 - 6x + x² = 9
> 2x² - 6x = 0
> x(x - 3) = 0
> x = 0 → y = 3, o x = 3 → y = 0
> Puntos: D = (0, 3), E = (3, 0)
> 
> Paso 4: Vértices de la región solución
> 
> Verificar cuáles están en las tres regiones:
> • A = (2, 1): 4+1=5 ≤ 9 ✓, 1 ≥ 1 ✓, 2+1=3 ✓
> • B ≈ (2.56, 1.56): en círculo y F₂, verificar F₃:
>   2.56+1.56=4.12 > 3 ✗ (fuera)
> • D = (0, 3): 0+9=9 ≤ 9 ✓, 3 ≥ -1 ✓, 0+3=3 ✓
> • E = (3, 0): 9+0=9 ≤ 9 ✓, 0 ≥ 2 ✗ (fuera)
> 
> Vértices válidos: A, D y arco del círculo
> 
> SOLUCIÓN: Región acotada con vértices (2,1), (0,3)
> y arco de círculo entre ellos.
> ```
> 
> **Problema 2: Optimización con restricciones no lineales**
> 
> ```
> Maximizar f(x,y) = 3x + 4y sujeto a:
> ⎧ x² + y² ≤ 25
> ⎨ y ≥ x²/4
> ⎩ x ≥ 0, y ≥ 0
> 
> SOLUCIÓN:
> 
> Paso 1: Graficar región factible
> 
> R₁: x² + y² ≤ 25 (disco r=5)
> R₂: y ≥ x²/4 (encima de parábola)
> R₃, R₄: primer cuadrante
> 
> Paso 2: Encontrar vértices
> 
> a) Origen: (0, 0)
>    f(0,0) = 0
> 
> b) Intersección parábola-círculo (x>0):
>    x² + (x²/4)² = 25
>    x² + x⁴/16 = 25
>    16x² + x⁴ = 400
>    x⁴ + 16x² - 400 = 0
>    
>    u = x²: u² + 16u - 400 = 0
>    u = (-16 ± √(256+1600))/2
>    u = (-16 ± √1856)/2
>    u ≈ 17.56 (tomamos positivo)
>    x ≈ 4.19, y ≈ 4.39
>    
>    f(4.19, 4.39) ≈ 30.13
> 
> c) Intersección círculo-eje y:
>    (0, 5)
>    f(0, 5) = 20
> 
> d) Intersección círculo-eje x:
>    (5, 0)
>    Verificar: 0 ≥ 25/4 ✗ (no cumple y ≥ x²/4)
>    No es vértice válido
> 
> Paso 3: Evaluar en frontera
> 
> Sobre arco circular de (4.19, 4.39) a (0, 5):
> Parametrizar: x = 5cosθ, y = 5senθ
> f(θ) = 15cosθ + 20senθ
> 
> Máximo: f'(θ) = -15senθ + 20cosθ = 0
> tanθ = 20/15 = 4/3
> θ ≈ 53.13°
> x = 5cos(53.13°) ≈ 3
> y = 5sen(53.13°) ≈ 4
> f(3, 4) = 9 + 16 = 25
> 
> Comparando valores:
> • (0,0): 0
> • (4.19, 4.39): 30.13
> • (0,5): 20
> • (3,4): 25
> 
> MÁXIMO: f(4.19, 4.39) ≈ 30.13
> (En intersección parábola-círculo)
> ```
> 
> **Problema 3: Sistema con valor absoluto**
> 
> ```
> Resolver:
> ⎧ |x| + |y| ≤ 4
> ⎨ x² + y² ≥ 4
> ⎩ xy ≥ 0
> 
> SOLUCIÓN:
> 
> Paso 1: Interpretar inecuaciones
> 
> Inecuación 1: |x| + |y| ≤ 4
> • Frontera: |x| + |y| = 4
> • En cada cuadrante:
>   I: x + y = 4
>   II: -x + y = 4
>   III: -x - y = 4
>   IV: x - y = 4
> • Forma un cuadrado con vértices (±4, 0) y (0, ±4)
> • Región: interior del cuadrado (rombo)
> 
> Inecuación 2: x² + y² ≥ 4
> • Frontera: círculo r = 2
> • Región: exterior del círculo
> 
> Inecuación 3: xy ≥ 0
> • xy = 0: ejes coordenados
> • xy > 0: cuadrantes I y III
> • Región: cuadrantes I y III (incluye ejes)
> 
> Paso 2: Intersección
> 
> Región solución: cuatro "pétalos"
> • Dos en cuadrante I: entre círculo y recta x+y=4
> • Dos en cuadrante III: entre círculo y recta -x-y=4
> 
> Paso 3: Vértices (cuadrante I)
> 
> Intersección círculo-recta:
> x² + (4-x)² = 4
> x² + 16 - 8x + x² = 4
> 2x² - 8x + 12 = 0
> x² - 4x + 6 = 0
> 
> Discriminante: 16 - 24 = -8 < 0
> ¡No hay intersección!
> 
> Esto significa: el círculo está completamente
> dentro del cuadrado en esta región.
> 
> Vértices válidos en cuadrante I:
> • (2, 0): en círculo y eje x
> • (0, 2): en círculo y eje y
> • Arco de círculo entre ellos
> 
> Por simetría, igual en cuadrante III:
> • (-2, 0) y (0, -2)
> 
> SOLUCIÓN: Cuatro "segmentos circulares"
> en cuadrantes I y III
> ```
> 
> **Problema 4: Sistema con funciones trascendentes**
> 
> ```
> Resolver (numéricamente):
> ⎧ e^x ≤ y
> ⎨ ln(y) ≤ x
> ⎩ x² + y² ≤ 10
> 
> SOLUCIÓN:
> 
> Análisis:
> 
> Inecuación 1: y ≥ e^x
> • Encima de curva exponencial
> 
> Inecuación 2: x ≥ ln(y)
> • A la derecha de curva logarítmica
> • Equivale a: y ≤ e^x
> 
> ¡Contradicción!
> 
> De 1): y ≥ e^x
> De 2): y ≤ e^x
> 
> Por tanto: y = e^x necesariamente
> 
> Sustituyendo en 3):
> x² + e^(2x) ≤ 10
> 
> Resolver numéricamente:
> Para x = 0: 0 + 1 = 1 ≤ 10 ✓
> Para x = 1: 1 + e² ≈ 8.39 ≤ 10 ✓
> Para x = 1.5: 2.25 + e³ ≈ 22.34 > 10 ✗
> 
> Punto crítico entre 1 y 1.5
> Método numérico:
> x ≈ 1.28
> y = e^1.28 ≈ 3.60
> 
> Para x negativo:
> x = -1: 1 + e^(-2) ≈ 1.14 ≤ 10 ✓
> x → -∞: x² → ∞, rechazar
> 
> SOLUCIÓN: Segmento de curva y = e^x
> aproximadamente desde x ∈ [-2.8, 1.28]
> (valores numéricos aproximados)
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes **1. "La solución es siempre una región conexa"**
> 
> ```
> ✗ FALSO
> 
> Ejemplo:
> x² + y² ≥ 4 y x² + y² ≤ 9
> ∩ (xy ≥ 1 o xy ≤ -1)
> 
> Puede resultar en varias componentes separadas
> ```
> 
> **2. "Interior siempre corresponde a desigualdad estricta"**
> 
> ```
> ✗ IMPRECISO
> 
> ≤ y ≥ incluyen la frontera
> < y > excluyen la frontera
> 
> Representación gráfica:
> ≤, ≥: línea continua ─────
> <, >: línea discontinua - - - -
> ```
> 
> **3. "Punto de prueba puede ser cualquiera"**
> 
> ```
> ✗ FALSO
> 
> El punto de prueba NO debe estar:
> • En la frontera
> • En puntos donde la función no está definida
> 
> Origen (0,0) es conveniente pero puede estar en frontera
> ```
> 
> **4. "x² + y² ≤ r² y x² + y² ≥ r² no tienen solución"**
> 
> ```
> ✗ FALSO
> 
> SÍ tienen solución: la circunferencia x² + y² = r²
> (solo la frontera)
> 
> Sin solución sería: x² + y² < r² ∩ x² + y² > r²
> ```
> 
> **5. "Región no acotada implica área infinita"**
> 
> ```
> ✓ CORRECTO en general
> 
> Pero cuidado: puede tener "área finita" en sentido
> de integral impropia convergente (raro)
> ```
> 
> **6. "Optimizar f en región no acotada no tiene máximo"**
> 
> ```
> ✗ FALSO
> 
> Puede haber máximo local en interior o frontera
> Ejemplo: f(x,y) = -x² - y² en x ≥ 0, y ≥ 0
> Máximo en (0,0) = 0
> ```
> 
> **7. "Todas las fronteras se intersectan"**
> 
> ```
> ✗ FALSO
> 
> Algunas curvas pueden no intersectarse
> Región puede estar "separada" de otras fronteras
> ```

## 🎯 Aplicaciones Prácticas

> [!note]- Contextos Reales **1. Optimización en ingeniería:**
> 
> ```
> Diseño de estructuras:
> 
> Variables: dimensiones x, y (longitud, ancho)
> 
> Restricciones:
> • Resistencia: σ(x,y) ≤ σ_max (no lineal)
> • Estabilidad: factor seguridad ≥ k
> • Materiales: costo C(x,y) ≤ presupuesto
> • Geometría: x² + y² ≤ espacio disponible
Objetivo: Minimizar peso o maximizar eficiencia
>
> ```
> 
> **2. Economía y producción:**
> ```
> 
> Problema de producción:
> 
> Variables: x, y (cantidades de productos A, B)
> 
> Restricciones: • Recursos: r₁x² + r₂y² ≤ R (uso no lineal) • Demanda mínima: x ≥ d₁, y ≥ d₂ • Capacidad: x + y ≤ C_max • Sinergia: xy ≥ S (producción conjunta)
> 
> Objetivo: Maximizar beneficio B(x,y) = p₁x + p₂y - c₁x² - c₂y²
> 
> ```
> 
> **3. Diseño de antenas:**
> ```
> 
> Cobertura de señal:
> 
> Variables: (x, y) ubicación de antena
> 
> Restricciones: • Alcance: (x-x₁)² + (y-y₁)² ≤ R₁² (zona 1) • Interferencia: (x-x₂)² + (y-y₂)² ≥ R₂² (lejos de zona 2) • Terreno: y ≥ h(x) (encima de superficie) • Regulaciones: zonas prohibidas
> 
> Objetivo: Maximizar cobertura o minimizar potencia
> 
> ```
> 
> **4. Control de calidad:**
> ```
> 
> Especificaciones de producto:
> 
> Variables: parámetros x, y (temperatura, presión)
> 
> Restricciones: • Calidad: Q(x,y) = x²y/(x+y) ≥ Q_min • Seguridad: x² + y² ≤ límite • Eficiencia: x/y ≥ ratio_min • Costo: C(x,y) ≤ presupuesto
> 
> Región factible: zona de operación segura y eficiente
> 
> ```
> 
> **5. Navegación y trayectorias:**
> ```
> 
> Planificación de rutas:
> 
> Variables: (x, y) posición
> 
> Restricciones: • Obstáculos: (x-xᵢ)² + (y-yᵢ)² ≥ rᵢ² (evitar) • Zona segura: región convexa o no convexa • Alcance: √(x²+y²) ≤ R_max • Combustible: función no lineal de distancia
> 
> Objetivo: Ruta óptima (mínima distancia/tiempo/costo)
> 
> ```
> 
> **6. Machine Learning (SVM):**
> ```
> 
> Support Vector Machines con kernel no lineal:
> 
> Separación no lineal de clases: • Región clase A: φ(x,y) ≥ 1 • Región clase B: φ(x,y) ≤ -1 • Margen: -1 < φ(x,y) < 1 (zona de separación)
> 
> donde φ es transformación no lineal (kernel)
> 
> Ejemplo: kernel RBF φ(x,y) = exp(-γ||x-xᵢ||²)
> 
> ```
> 
> **7. Diseño de circuitos:**
> ```
> 
> Optimización de componentes:
> 
> Variables: R (resistencia), C (capacitancia)
> 
> Restricciones: • Frecuencia de corte: 1/(2πRC) ≥ f_min • Constante de tiempo: RC ≤ τ_max • Potencia disipada: V²/R ≤ P_max • Espacio físico: área ≤ límite
> 
> Región factible define diseños viables

## 🔬 Métodos Numéricos y Computacionales

> [!important]- Técnicas Avanzadas **Método de puntos interiores:**
> 
> ```
> Para optimización con restricciones no lineales:
> 
> min f(x, y)
> s.a. gᵢ(x, y) ≤ 0, i = 1,...,m
> 
> Algoritmo:
> 1. Partir de punto interior factible (x₀, y₀)
> 2. Moverse en dirección que:
>    • Mejora función objetivo
>    • Mantiene factibilidad
>    • Se aleja de fronteras (barrera)
> 3. Iterar hasta convergencia
> 
> Función barrera:
> F(x,y,μ) = f(x,y) - μ∑ln(-gᵢ(x,y))
> donde μ → 0⁺
> ```
> 
> **Método de penalización:**
> 
> ```
> Convertir restricciones en penalizaciones:
> 
> F_pen(x,y) = f(x,y) + ρ∑[max(0, gᵢ(x,y))]²
> 
> donde ρ > 0 es parámetro de penalización
> 
> Aumentar ρ progresivamente para forzar factibilidad
> ```
> 
> **Algoritmos genéticos:**
> 
> ```
> Para problemas con múltiples óptimos locales:
> 
> 4. Población inicial aleatoria en región factible
> 5. Evaluación de fitness (función objetivo)
> 6. Selección (mejores individuos)
> 7. Cruce (combinación de soluciones)
> 8. Mutación (exploración)
> 9. Verificar factibilidad (reparar o descartar)
> 10. Iterar hasta convergencia
> 
> Útil cuando región no es convexa
> ```
> 
> **Método de nivel de conjunto (Level Set):**
> 
> ```
> Para representar fronteras complejas:
> 
> Frontera como curva de nivel de función φ(x,y):
> Frontera = {(x,y) : φ(x,y) = 0}
> Interior = {(x,y) : φ(x,y) < 0}
> Exterior = {(x,y) : φ(x,y) > 0}
> 
> Evolución temporal de φ para optimización topológica
> ```

## 📊 Análisis de Sensibilidad

> [!tip]- Estudio de Variaciones **Perturbación de restricciones:**
> 
> ```
> Sistema original:
> ⎧ g₁(x,y) ≤ b₁
> ⎨ g₂(x,y) ≤ b₂
> ⎩ g₃(x,y) ≤ b₃
> 
> Análisis: ¿Cómo cambia región si bᵢ → bᵢ + ε?
> 
> Ejemplo:
> x² + y² ≤ r²
> 
> Si r → r + Δr:
> • Área aumenta: πr² → π(r+Δr)² ≈ πr² + 2πrΔr
> • Incremento relativo: ΔA/A ≈ 2Δr/r
> • Vértices se desplazan radialmente
> 
> Importancia: tolerancias en diseño
> ```
> 
> **Multiplicadores de Lagrange:**
> 
> ```
> En optimización con restricciones:
> 
> L(x,y,λ) = f(x,y) - λg(x,y)
> 
> λ = multiplicador de Lagrange
> 
> Interpretación:
> λ ≈ ∂f*/∂b (cambio en óptimo por cambio en restricción)
> 
> |λ| grande → restricción muy "activa" (crítica)
> |λ| pequeño → restricción poco restrictiva
> ```

## 🧮 Problemas Adicionales

> [!example]- Ejercicios Avanzados **Problema 5: Sistema con función racional**
> 
> ```
> Resolver:
> ⎧ x/(x²+y²) ≤ 1
> ⎨ y/(x²+y²) ≤ 1
> ⎩ x² + y² ≥ 1
> 
> SOLUCIÓN:
> 
> Simplificar usando x² + y² = r² ≥ 1:
> 
> Inecuación 1: x/r² ≤ 1
> x ≤ r²
> 
> Inecuación 2: y/r² ≤ 1
> y ≤ r²
> 
> En polares: x = r cos θ, y = r sen θ
> 
> 1) r cos θ ≤ r²
>    cos θ ≤ r
>    Como r ≥ 1: siempre cumple si cos θ ≤ 1 ✓
> 
> 2) r sen θ ≤ r²
>    sen θ ≤ r
>    Similar al anterior
> 
> Casos críticos cuando r = 1:
> • cos θ ≤ 1: θ ∈ [0, π] ∪ [π, 2π] = todo ✓
> • sen θ ≤ 1: θ ∈ [0, π/2] ∪ [3π/2, 2π]
> 
> SOLUCIÓN: exterior del círculo unitario
> excepto regiones donde sen θ > 1 (imposible)
> 
> Respuesta simplificada: x² + y² ≥ 1
> ```
> 
> **Problema 6: Optimización con área**
> 
> ```
> Entre todos los puntos (x,y) que satisfacen:
> ⎧ x² + y² ≤ 16
> ⎨ (x-2)² + (y-2)² ≥ 4
> ⎩ x ≥ 0, y ≥ 0
> 
> Encontrar el que maximiza x + 2y
> 
> SOLUCIÓN:
> 
> Región: cuarto de corona circular
> 
> Círculo grande: centro (0,0), r = 4
> Círculo pequeño: centro (2,2), r = 2
> Cuadrante: I
> 
> Función objetivo: f(x,y) = x + 2y
> Gradiente: ∇f = (1, 2)
> Dirección de crecimiento: hacia arriba-derecha
> 
> Candidatos:
> 
> a) Frontera exterior x² + y² = 16 en cuadrante I
>    Parametrizar: x = 4cos θ, y = 4sen θ, 0 ≤ θ ≤ π/2
>    f(θ) = 4cos θ + 8sen θ
>    f'(θ) = -4sen θ + 8cos θ = 0
>    tan θ = 2 → θ = arctan(2) ≈ 63.43°
>    
>    x = 4cos(63.43°) ≈ 1.79
>    y = 4sen(63.43°) ≈ 3.58
>    f ≈ 1.79 + 7.16 = 8.95
> 
> b) Frontera interior (x-2)² + (y-2)² = 4
>    Parametrizar: x = 2 + 2cos φ, y = 2 + 2sen φ
>    Verificar cuadrante I y factibilidad
>    
>    f(φ) = 2 + 2cos φ + 2(2 + 2sen φ)
>         = 6 + 2cos φ + 4sen φ
>    f'(φ) = -2sen φ + 4cos φ = 0
>    tan φ = 2 → φ ≈ 63.43°
>    
>    x = 2 + 2cos(63.43°) ≈ 2.89
>    y = 2 + 2sen(63.43°) ≈ 3.79
>    
>    Verificar si está en región:
>    x² + y² = 2.89² + 3.79² ≈ 22.71 > 16 ✗
>    Fuera del círculo grande, no válido
> 
> c) Ejes coordenados (fronteras x=0, y=0)
>    En x = 0: máximo y tal que y² ≤ 16 y y ≥ algo...
>    [Análisis detallado]
> 
> d) Intersecciones
>    [Calcular puntos específicos]
> 
> MÁXIMO: aproximadamente en (1.79, 3.58)
> con f ≈ 8.95
> ```
> 
> **Problema 7: Sistema paramétrico**
> 
> ```
> Para qué valores de k el sistema tiene solución:
> ⎧ x² + y² ≤ 9
> ⎨ (x-k)² + y² ≥ 4
> ⎩ y ≥ 0
> 
> SOLUCIÓN:
> 
> Región debe ser no vacía.
> 
> Círculo C₁: centro (0,0), r = 3
> Círculo C₂: centro (k,0), r = 2
> 
> Condición: C₂ debe intersectar C₁ en semiplano y ≥ 0
> 
> Distancia entre centros: d = |k|
> 
> Casos:
> 
> 1) Círculos externos: d > 3 + 2 = 5
>    |k| > 5: sin intersección → SIN SOLUCIÓN
> 
> 2) Círculos tangentes externos: d = 5
>    |k| = 5: un punto de intersección
>    Verificar si está en y ≥ 0
>    Para k = 5: punto (3, 0) ✓
>    Para k = -5: punto (-3, 0) ✓
>    CON SOLUCIÓN (un punto)
> 
> 3) Círculos intersectantes: |r₁ - r₂| < d < r₁ + r₂
>    1 < |k| < 5: dos puntos de intersección
>    Al menos uno en y ≥ 0 si k no muy negativo
>    CON SOLUCIÓN (región)
> 
> 4) C₂ dentro de C₁: d < |r₁ - r₂| = 1
>    |k| < 1: C₂ puede estar dentro de C₁
>    Región = semidisco superior menos disco interior
>    CON SOLUCIÓN si la resta es no vacía
>    
>    Para que región exterior de C₂ intersecte C₁:
>    k - 2 < 3 (lado izquierdo de C₂ dentro de C₁)
>    k < 5 ✓ (ya cumplido)
> 
> 5) C₂ contiene a C₁: d + r₁ < r₂
>    |k| + 3 < 2: imposible (|k| < -1)
>    SIN ESTE CASO
> 
> Conclusión:
> • SIN SOLUCIÓN: |k| > 5
> • CON SOLUCIÓN: |k| ≤ 5
> 
> Respuesta: -5 ≤ k ≤ 5
> ```

> │    ├─ Graficar cada frontera
> │    ├─ Determinar región (punto de prueba)
> │    ├─ Intersectar regiones
> │    ├─ Identificar vértices
> │    └─ Verificar factibilidad
> │
> ├─── CARACTERÍSTICAS DE REGIÓN
> │    ├─ Acotada vs no acotada
> │    ├─ Conexa vs no conexa
