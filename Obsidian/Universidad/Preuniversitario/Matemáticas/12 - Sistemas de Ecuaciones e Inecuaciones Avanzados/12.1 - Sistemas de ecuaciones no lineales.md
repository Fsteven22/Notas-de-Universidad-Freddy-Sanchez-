# 🔄 Sistemas de Ecuaciones No Lineales

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Un sistema de ecuaciones no lineales es un conjunto de dos o más ecuaciones donde al menos una ecuación contiene términos no lineales (potencias mayores que 1, productos de variables, funciones trigonométricas, exponenciales, etc.). A diferencia de los sistemas lineales, estos sistemas pueden tener múltiples soluciones, ninguna solución, o infinitas soluciones, y su resolución generalmente requiere métodos algebraicos específicos o técnicas numéricas.**
> 
> **Características clave:**
> 
> - **No linealidad:** Al menos una ecuación con términos cuadráticos, cúbicos, productos, etc.
> - **Soluciones múltiples:** Pueden tener 0, 1, 2, o más soluciones
> - **Métodos diversos:** Sustitución, eliminación, gráfico, numéricos
> - **Interpretación geométrica:** Intersección de curvas/superficies
> - **Complejidad:** Mayor dificultad que sistemas lineales
> - **Aplicaciones:** Física, ingeniería, economía, biología

## 🎯 Tipos de Sistemas No Lineales

> [!important]- Clasificación **Sistemas cuadráticos (2×2):**
> 
> ```
> Forma general:
> { ax² + bxy + cy² + dx + ey + f = 0
> { gx² + hxy + iy² + jx + ky + l = 0
> 
> Casos comunes:
> 
> 1. Lineal-cuadrática:
> { y = mx + n         (recta)
> { ax² + by² = c      (cónica)
> 
> 2. Cuadrática-cuadrática:
> { x² + y² = r²       (circunferencia)
> { x²/a² + y²/b² = 1  (elipse)
> 
> 3. Productos de variables:
> { x² + y² = 25
> { xy = 12
> 
> Interpretación geométrica:
> Intersección de dos curvas cónicas
> Puede tener 0, 1, 2, 3, o 4 soluciones
> ```
> 
> **Sistemas exponenciales/logarítmicos:**
> 
> ```
> Forma:
> { aˣ + bʸ = c
> { dˣ + eʸ = f
> 
> o
> 
> { log(x) + log(y) = a
> { x + y = b
> 
> Características:
> • Curvas no algebraicas
> • Crecimiento exponencial
> • Requieren cambio de variable o métodos numéricos
> ```
> 
> **Sistemas trigonométricos:**
> 
> ```
> Forma:
> { sen(x) + cos(y) = a
> { cos(x) - sen(y) = b
> 
> o
> 
> { x² + sen(y) = 1
> { y² + cos(x) = 1
> 
> Características:
> • Periodicidad
> • Múltiples soluciones (infinitas posiblemente)
> • Simetría
> ```
> 
> **Sistemas mixtos:**
> 
> ```
> Combinación de tipos:
> 
> { x² + y = 5
> { eˣ + y = 10
> 
> o
> 
> { xy = 12
> { x + sen(y) = 2
> 
> Generalmente requieren métodos numéricos
> ```

## 📐 Métodos Algebraicos

> [!success]- Técnicas de Solución **Método de sustitución:**
> 
> ```
> Procedimiento:
> 1. Despejar una variable de una ecuación
> 2. Sustituir en la otra ecuación
> 3. Resolver la ecuación resultante
> 4. Sustituir hacia atrás para obtener la otra variable
> 5. Verificar las soluciones
> 
> Ventajas:
> • Método sistemático
> • Funciona para muchos tipos
> • Da soluciones exactas
> 
> Desventajas:
> • Puede generar ecuaciones complejas
> • No siempre es posible despejar
> • Trabajoso para sistemas grandes
> 
> Mejor para:
> • Una ecuación lineal
> • Variables fáciles de despejar
> • Sistemas 2×2
> ```
> 
> **Método de eliminación:**
> 
> ```
> Procedimiento:
> 6. Multiplicar ecuaciones por constantes apropiadas
> 7. Sumar o restar para eliminar una variable
> 8. Resolver para la variable restante
> 9. Sustituir para encontrar la otra variable
> 
> Aplicable cuando:
> • Términos similares en ambas ecuaciones
> • Coeficientes permiten eliminación
> • Sistema tiene estructura especial
> 
> Variante - eliminación cuadrática:
> Si ambas ecuaciones tienen x² y y²:
> Eliminar x² o y² multiplicando y restando
> ```
> 
> **Método de igualación:**
> 
> ```
> Procedimiento:
> 10. Despejar la misma variable en ambas ecuaciones
> 11. Igualar las expresiones
> 12. Resolver la ecuación resultante
> 13. Sustituir para encontrar la otra variable
> 
> Útil cuando:
> • Variable fácil de despejar en ambas
> • Expresiones resultantes manejables
> ```
> 
> **Cambio de variable:**
> 
> ```
> Técnica:
> Introducir nuevas variables para simplificar
> 
> Ejemplos comunes:
> 
> 14. Variables recíprocas:
> Si aparecen 1/x, 1/y:
> u = 1/x, v = 1/y
> 
> 15. Variables cuadráticas:
> Si aparecen x², y²:
> u = x², v = y²
> 
> 16. Suma y producto:
> { x + y = s
> { xy = p
> Entonces x, y son raíces de: t² - st + p = 0
> 
> 17. Variables trigonométricas:
> Si sen²(x) + cos²(x):
> Usar identidades fundamentales
> 
> 18. Variables exponenciales:
> Si aparece aˣ:
> u = aˣ, entonces log_a(u) = x
> ```

## 🔍 Sistemas Cuadráticos Específicos

> [!note]- Casos Importantes **Sistema simétrico:**
> 
> ```
> Forma:
> { x + y = a
> { xy = b
> 
> Método de solución:
> x e y son raíces de la ecuación cuadrática:
> t² - at + b = 0
> 
> Soluciones:
> t = (a ± √(a² - 4b))/2
> 
> Entonces:
> x = (a + √(a² - 4b))/2
> y = (a - √(a² - 4b))/2
> 
> O viceversa
> 
> Discriminante:
> Δ = a² - 4b
> 
> Δ > 0: dos soluciones reales distintas
> Δ = 0: una solución real (x = y)
> Δ < 0: no hay soluciones reales
> 
> Ejemplo:
> { x + y = 7
> { xy = 12
> 
> t² - 7t + 12 = 0
> (t - 3)(t - 4) = 0
> x = 3, y = 4 o x = 4, y = 3
> ```
> 
> **Sistema con suma y diferencia:**
> 
> ```
> Forma:
> { x + y = a
> { x² + y² = b
> 
> Método:
> De la primera: y = a - x
> Sustituir en la segunda:
> x² + (a - x)² = b
> x² + a² - 2ax + x² = b
> 2x² - 2ax + (a² - b) = 0
> x² - ax + (a² - b)/2 = 0
> 
> Solución:
> x = [a ± √(a² - 2(a² - b))]/2
> x = [a ± √(2b - a²)]/2
> 
> Condición de existencia:
> 2b ≥ a²
> b ≥ a²/2
> ```
> 
> **Circunferencia y recta:**
> 
> ```
> Sistema:
> { x² + y² = r²      (circunferencia)
> { y = mx + c        (recta)
> 
> Sustitución:
> x² + (mx + c)² = r²
> x² + m²x² + 2mcx + c² = r²
> (1 + m²)x² + 2mcx + (c² - r²) = 0
> 
> Discriminante:
> Δ = (2mc)² - 4(1 + m²)(c² - r²)
> Δ = 4m²c² - 4(1 + m²)(c² - r²)
> Δ = 4[m²c² - c²(1 + m²) + r²(1 + m²)]
> Δ = 4[m²c² - c² - m²c² + r² + m²r²]
> Δ = 4[r²(1 + m²) - c²]
> 
> Interpretación geométrica:
> Δ > 0: recta secante (2 puntos)
> Δ = 0: recta tangente (1 punto)
> Δ < 0: recta exterior (0 puntos)
> 
> Condición de tangencia:
> r²(1 + m²) = c²
> |c|/√(1 + m²) = r
> (distancia punto-recta = radio)
> ```
> 
> **Dos circunferencias:**
> 
> ```
> Sistema:
> { x² + y² = r₁²              (C₁)
> { (x-h)² + (y-k)² = r₂²      (C₂)
> 
> Método de resta:
> Restar ecuaciones:
> x² + y² - [(x-h)² + (y-k)²] = r₁² - r₂²
> x² + y² - [x² - 2hx + h² + y² - 2ky + k²] = r₁² - r₂²
> 2hx + 2ky = h² + k² + r₁² - r₂²
> 
> Esto es una RECTA (eje radical)
> 
> Sustituir esta recta en una circunferencia
> para encontrar puntos de intersección
> 
> Número de soluciones depende de:
> Distancia entre centros d = √(h² + k²)
> 
> d > r₁ + r₂: no se intersectan (0 puntos)
> d = r₁ + r₂: tangentes externas (1 punto)
> |r₁ - r₂| < d < r₁ + r₂: secantes (2 puntos)
> d = |r₁ - r₂|: tangentes internas (1 punto)
> d < |r₁ - r₂|: una dentro de otra (0 puntos)
> ```

## 🧮 Problemas Resueltos

> [!example]- Ejemplos Detallados **Problema 1: Sistema simétrico**
> 
> ```
> Resolver:
> { x + y = 5
> { xy = 6
> 
> SOLUCIÓN:
> 
> Método 1 - Ecuación cuadrática:
> x e y son raíces de: t² - 5t + 6 = 0
> 
> Factorizar:
> (t - 2)(t - 3) = 0
> t = 2 o t = 3
> 
> Soluciones:
> (x, y) = (2, 3) o (x, y) = (3, 2)
> 
> Método 2 - Sustitución:
> De la primera: y = 5 - x
> Sustituir en la segunda:
> x(5 - x) = 6
> 5x - x² = 6
> x² - 5x + 6 = 0
> (x - 2)(x - 3) = 0
> x = 2 → y = 3
> x = 3 → y = 2
> 
> Verificación:
> (2, 3): 2 + 3 = 5 ✓, 2·3 = 6 ✓
> (3, 2): 3 + 2 = 5 ✓, 3·2 = 6 ✓
> ```
> 
> **Problema 2: Circunferencia y recta**
> 
> ```
> Resolver:
> { x² + y² = 25
> { y = x + 1
> 
> SOLUCIÓN:
> 
> Sustituir y = x + 1 en la primera:
> x² + (x + 1)² = 25
> x² + x² + 2x + 1 = 25
> 2x² + 2x + 1 = 25
> 2x² + 2x - 24 = 0
> x² + x - 12 = 0
> 
> Factorizar:
> (x + 4)(x - 3) = 0
> x = -4 o x = 3
> 
> Encontrar y:
> x = -4: y = -4 + 1 = -3
> x = 3: y = 3 + 1 = 4
> 
> Soluciones:
> (-4, -3) y (3, 4)
> 
> Verificación:
> (-4, -3): (-4)² + (-3)² = 16 + 9 = 25 ✓
>          -3 = -4 + 1 ✓
> (3, 4): 3² + 4² = 9 + 16 = 25 ✓
>         4 = 3 + 1 ✓
> 
> Interpretación:
> Recta secante corta circunferencia en 2 puntos
> ```
> 
> **Problema 3: Productos de variables**
> 
> ```
> Resolver:
> { x² + y² = 13
> { xy = 6
> 
> SOLUCIÓN:
> 
> Método de suma y producto:
> Sabemos: (x + y)² = x² + 2xy + y²
>         (x - y)² = x² - 2xy + y²
> 
> De las ecuaciones:
> x² + y² = 13
> xy = 6
> 
> Calcular (x + y)²:
> (x + y)² = x² + y² + 2xy
> (x + y)² = 13 + 2(6) = 13 + 12 = 25
> x + y = ±5
> 
> Calcular (x - y)²:
> (x - y)² = x² + y² - 2xy
> (x - y)² = 13 - 2(6) = 13 - 12 = 1
> x - y = ±1
> 
> Caso 1: x + y = 5, x - y = 1
> Sumar: 2x = 6 → x = 3
> Restar: 2y = 4 → y = 2
> Solución: (3, 2)
> 
> Caso 2: x + y = 5, x - y = -1
> Sumar: 2x = 4 → x = 2
> Restar: 2y = 6 → y = 3
> Solución: (2, 3)
> 
> Caso 3: x + y = -5, x - y = 1
> Sumar: 2x = -4 → x = -2
> Restar: 2y = -6 → y = -3
> Solución: (-2, -3)
> 
> Caso 4: x + y = -5, x - y = -1
> Sumar: 2x = -6 → x = -3
> Restar: 2y = -4 → y = -2
> Solución: (-3, -2)
> 
> Cuatro soluciones: (3,2), (2,3), (-2,-3), (-3,-2)
> ```
> 
> **Problema 4: Eliminación**
> 
> ```
> Resolver:
> { 2x² + 3y² = 21
> { 3x² - 4y² = 23
> 
> SOLUCIÓN:
> 
> Multiplicar primera ecuación por 4:
> 8x² + 12y² = 84
> 
> Multiplicar segunda ecuación por 3:
> 9x² - 12y² = 69
> 
> Sumar:
> 8x² + 12y² + 9x² - 12y² = 84 + 69
> 17x² = 153
> x² = 9
> x = ±3
> 
> Sustituir x² = 9 en primera ecuación:
> 2(9) + 3y² = 21
> 18 + 3y² = 21
> 3y² = 3
> y² = 1
> y = ±1
> 
> Soluciones:
> (3, 1), (3, -1), (-3, 1), (-3, -1)
> 
> Verificación (3, 1):
> 2(9) + 3(1) = 18 + 3 = 21 ✓
> 3(9) - 4(1) = 27 - 4 = 23 ✓
> ```
> 
> **Problema 5: Cambio de variable**
> 
> ```
> Resolver:
> { 1/x + 1/y = 3
> { 1/x² + 1/y² = 5
> 
> SOLUCIÓN:
> 
> Cambio de variable:
> u = 1/x, v = 1/y
> 
> Sistema transformado:
> { u + v = 3
> { u² + v² = 5
> 
> De la primera: v = 3 - u
> Sustituir en la segunda:
> u² + (3 - u)² = 5
> u² + 9 - 6u + u² = 5
> 2u² - 6u + 9 = 5
> 2u² - 6u + 4 = 0
> u² - 3u + 2 = 0
> 
> Factorizar:
> (u - 1)(u - 2) = 0
> u = 1 o u = 2
> 
> Si u = 1: v = 3 - 1 = 2
> Si u = 2: v = 3 - 2 = 1
> 
> Regresar a variables originales:
> u = 1, v = 2: 1/x = 1, 1/y = 2
>               x = 1, y = 1/2
> 
> u = 2, v = 1: 1/x = 2, 1/y = 1
>               x = 1/2, y = 1
> 
> Soluciones: (1, 1/2) y (1/2, 1)
> 
> Verificación (1, 1/2):
> 1/1 + 1/(1/2) = 1 + 2 = 3 ✓
> 1/1² + 1/(1/2)² = 1 + 4 = 5 ✓
> ```
> 
> **Problema 6: Dos circunferencias**
> 
> ```
> Resolver:
> { x² + y² = 25
> { (x-4)² + (y-3)² = 16
> 
> SOLUCIÓN:
> 
> Expandir segunda ecuación:
> x² - 8x + 16 + y² - 6y + 9 = 16
> x² + y² - 8x - 6y + 9 = 0
> 
> De la primera: x² + y² = 25
> Sustituir:
> 25 - 8x - 6y + 9 = 0
> -8x - 6y + 34 = 0
> 8x + 6y = 34
> 4x + 3y = 17  (eje radical)
> 
> Despejar y:
> y = (17 - 4x)/3
> 
> Sustituir en x² + y² = 25:
> x² + [(17 - 4x)/3]² = 25
> x² + (17 - 4x)²/9 = 25
> 9x² + (17 - 4x)² = 225
> 9x² + 289 - 136x + 16x² = 225
> 25x² - 136x + 64 = 0
> 
> Fórmula cuadrática:
> x = [136 ± √(136² - 4·25·64)]/(2·25)
> x = [136 ± √(18496 - 6400)]/50
> x = [136 ± √12096]/50
> x = [136 ± 109.98]/50
> 
> x₁ = (136 + 109.98)/50 ≈ 4.92
> x₂ = (136 - 109.98)/50 ≈ 0.52
> 
> Encontrar y correspondientes:
> y₁ = (17 - 4(4.92))/3 ≈ -0.89
> y₂ = (17 - 4(0.52))/3 ≈ 4.97
> 
> Soluciones aproximadas:
> (4.92, -0.89) y (0.52, 4.97)
> ```
> 
> **Problema 7: Exponencial-lineal**
> 
> ```
> Resolver:
> { 2ˣ + 2ʸ = 12
> { x + y = 4
> 
> SOLUCIÓN:
> 
> De la segunda: y = 4 - x
> Sustituir en la primera:
> 2ˣ + 2⁴⁻ˣ = 12
> 2ˣ + 16/2ˣ = 12
> 
> Cambio de variable: u = 2ˣ
> u + 16/u = 12
> u² + 16 = 12u
> u² - 12u + 16 = 0
> 
> Fórmula cuadrática:
> u = [12 ± √(144 - 64)]/2
> u = [12 ± √80]/2
> u = [12 ± 4√5]/2
> u = 6 ± 2√5
> 
> u₁ = 6 + 2√5 ≈ 10.472
> u₂ = 6 - 2√5 ≈ 1.528
> 
> Regresar a x:
> 2ˣ = 6 + 2√5
> x = log₂(6 + 2√5) ≈ 3.39
> y = 4 - 3.39 = 0.61
> 
> 2ˣ = 6 - 2√5
> x = log₂(6 - 2√5) ≈ 0.61
> y = 4 - 0.61 = 3.39
> 
> Soluciones: (3.39, 0.61) y (0.61, 3.39)
> ```
> 
> **Problema 8: Hipérbola y circunferencia**
> 
> ```
> Resolver:
> { xy = 8
> { x² + y² = 20
> 
> SOLUCIÓN:
> 
> Método similar al Problema 3:
> 
> (x + y)² = x² + y² + 2xy
> (x + y)² = 20 + 2(8) = 36
> x + y = ±6
> 
> (x - y)² = x² + y² - 2xy
> (x - y)² = 20 - 2(8) = 4
> x - y = ±2
> 
> Caso 1: x + y = 6, x - y = 2
> 2x = 8 → x = 4
> 2y = 4 → y = 2
> 
> Caso 2: x + y = 6, x - y = -2
> 2x = 4 → x = 2
> 2y = 8 → y = 4
> 
> Caso 3: x + y = -6, x - y = 2
> 2x = -4 → x = -2
> 2y = -8 → y = -4
> 
> Caso 4: x + y = -6, x - y = -2
> 2x = -8 → x = -4
> 2y = -4 → y = -2
> 
> Soluciones: (4,2), (2,4), (-2,-4), (-4,-2)
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes **1. "Sistemas no lineales tienen una única solución"**
> 
> ```
> ✗ FALSO - pueden tener múltiples soluciones
> 
> Ejemplo:
> { x² + y² = 25
> { xy = 12
> 
> Tiene 4 soluciones: (3,4), (4,3), (-3,-4), (-4,-3)
> 
> O pueden no tener solución:
> { x² + y² = 1
> { x + y = 3
> (recta no intersecta círculo)
> ```
> 
> **2. "Olvidar soluciones negativas"**
> ```
> ✗ ERROR común al resolver x² = 9
> 
> ✗ x = 3 solamente
> ✓ x = ±3
> 
> Ejemplo:
> { x² + y² = 25
> { y = 0
> 
> x² = 25
> ✗ x = 5 (incompleto)
> ✓ x = ±5
> 
> Soluciones: (5, 0) y (-5, 0)
> ```
> 
> **3. "Sustituir sin verificar todas las ramas"**
> 
> ```
> Sistema:
> { x + y = 5
> { xy = 6
> 
> ✗ Solo encontrar x = 2, y = 3
> ✓ También existe x = 3, y = 2
> 
> Ambas soluciones son válidas
> El sistema es simétrico
> ```
> 
> **4. "Dividir por expresiones que pueden ser cero"**
> 
> ```
> Sistema:
> { xy = 6
> { x² - y² = 5
> 
> ✗ PELIGRO: dividir primera entre segunda
> (xy)/(x² - y²) puede tener x² = y²
> 
> ✓ Mejor: método algebraico seguro
> ```
> 
> **5. "No verificar las soluciones"**
> 
> ```
> Al elevar al cuadrado o manipular,
> pueden aparecer soluciones extrañas
> 
> SIEMPRE verificar en ecuaciones originales
> 
> Ejemplo: al elevar √(x) = y
> obtenemos x = y²
> Pero √(x) ≥ 0, entonces y ≥ 0
> Soluciones con y < 0 son extrañas
> ```
> 
> **6. "Confundir métodos de sistemas lineales"**
> 
> ```
> ✗ No se puede usar eliminación gaussiana directamente
> ✗ Regla de Cramer no aplica
> 
> Los métodos de álgebra lineal
> NO funcionan para sistemas no lineales
> 
> Requieren métodos específicos
> ```
> 
> **7. "Ignorar restricciones del dominio"**
> 
> ```
> Sistema con logaritmos:
> { log(x) + log(y) = 2
> { x + y = 11
> 
> Restricción: x > 0, y > 0
> 
> Si se obtiene solución con x < 0 o y < 0,
> debe descartarse
> ```

## 🎯 Métodos Numéricos

> [!tip]- Aproximaciones Computacionales **Método de Newton-Raphson (2D):**
> 
> ```
> Para sistema:
> { f(x, y) = 0
> { g(x, y) = 0
> 
> Fórmula iterativa:
> [x_{n+1}]   [x_n]        [f(x_n, y_n)]
> [y_{n+1}] = [y_n] - J⁻¹  [g(x_n, y_n)]
> 
> donde J es la matriz jacobiana:
> 
> J = [∂f/∂x  ∂f/∂y]
>     [∂g/∂x  ∂g/∂y]
> 
> Pasos:
> 1. Elegir punto inicial (x₀, y₀)
> 2. Calcular jacobiano en (xₙ, yₙ)
> 3. Resolver sistema lineal para corrección
> 4. Actualizar: (xₙ₊₁, yₙ₊₁)
> 5. Repetir hasta convergencia
> 
> Criterio de parada:
> |xₙ₊₁ - xₙ| < ε y |yₙ₊₁ - yₙ| < ε
> 
> Ventajas:
> • Convergencia cuadrática (rápida)
> • Funciona para cualquier sistema diferenciable
> 
> Desventajas:
> • Requiere calcular derivadas
> • Puede diverger si punto inicial malo
> • Solo encuentra una solución por vez
> ```
> 
> **Método de punto fijo:**
> 
> ```
> Reformular sistema como:
> { x = φ(x, y)
> { y = ψ(x, y)
> 
> Iteración:
> x_{n+1} = φ(x_n, y_n)
> y_{n+1} = ψ(x_n, y_n)
> 
> Converge si:
> |∂φ/∂x| + |∂φ/∂y| < 1
> |∂ψ/∂x| + |∂ψ/∂y| < 1
> 
> Ejemplo:
> { x² + y = 5  →  y = 5 - x²
> { x + y² = 7  →  x = 7 - y²
> 
> Iteración:
> y_{n+1} = 5 - x_n²
> x_{n+1} = 7 - y_{n+1}²
> ```
> 
> **Método gráfico:**
> 
> ```
> Procedimiento:
> 6. Graficar ambas ecuaciones
> 7. Identificar puntos de intersección
> 8. Estimar coordenadas visualmente
> 9. Refinar con método numérico
> 
> Ventajas:
> • Visualiza todas las soluciones
> • Intuición geométrica
> • Identifica número de soluciones
> 
> Desventajas:
> • Precisión limitada
> • Difícil en más de 2 variables
> ```
> 
> **Software y calculadoras:**
> 
> ```
> MATLAB/Octave:
> fsolve(@(x) [f(x); g(x)], [x0; y0])
> 
> Python (SciPy):
> from scipy.optimize import fsolve
> fsolve(lambda x: [f(x), g(x)], [x0, y0])
> 
> Mathematica:
> FindRoot[{f[x,y]==0, g[x,y]==0}, {x,x0}, {y,y0}]
> 
> WolframAlpha:
> "solve x^2+y^2=25 and xy=12"
> 
> Calculadoras gráficas:
> Modo de resolución de ecuaciones
> Ingresar sistema
> Proporcionar estimación inicial
> ```

## 📊 Interpretación Geométrica

> [!important]- Visualización **Intersección de curvas:**
> 
> ```
> Sistema 2×2:
> { f(x, y) = 0  (curva C₁)
> { g(x, y) = 0  (curva C₂)
> 
> Soluciones = puntos donde C₁ ∩ C₂
> 
> Tipos de curvas:
> • Rectas: ecuaciones lineales
> • Circunferencias: x² + y² = r²
> • Parábolas: y = ax² + bx + c
> • Hipérbolas: xy = k
> • Elipses: x²/a² + y²/b² = 1
> 
> Número de intersecciones:
> Depende de geometría de las curvas
> Máximo teórico (Teorema de Bézout):
> m × n intersecciones (contando complejas)
> m, n = grados de las ecuaciones
> ```
> 
> **Casos geométricos:**
> 
> ```
> Recta y circunferencia:
> 0, 1, o 2 intersecciones
> 
> Dos circunferencias:
> 0, 1, 2, o infinitas (coinciden)
> 
> Circunferencia y parábola:
> 0, 1, 2, 3, o 4 intersecciones
> 
> Dos parábolas:
> 0, 1, 2, 3, o 4 intersecciones
> 
> Hipérbola y circunferencia:
> 0, 1, 2, 3, o 4 intersecciones
> 
> Hipérbola y parábola:
> 0, 1, 2, 3, o 4 intersecciones
> ```
> 
> **Regiones de solución:**
> 
> ```
> Para inecuaciones:
> { f(x, y) ≤ 0
> { g(x, y) ≤ 0
> 
> Solución = intersección de regiones
> 
> Ejemplo:
> { x² + y² ≤ 25  (interior del círculo)
> { y ≥ x         (arriba de diagonal)
> 
> Región: semicírculo superior izquierdo
> ```

## 🔬 Sistemas Especiales

> [!note]- Casos Avanzados **Sistema homogéneo:**
> 
> ```
> Forma:
> { f(x, y) = 0
> { g(x, y) = 0
> 
> donde f(tx, ty) = tⁿf(x, y)
>       g(tx, ty) = tᵐg(x, y)
> 
> Siempre tiene solución (0, 0)
> 
> Cambio de variable: y = tx
> Reduce a ecuación de una variable
> 
> Ejemplo:
> { x² - 2xy + y² = 0
> { x² + xy - 2y² = 0
> 
> Ambas homogéneas de grado 2
> ```
> 
> **Sistema paramétrico:**
> 
> ```
> Con parámetro k:
> { f(x, y, k) = 0
> { g(x, y, k) = 0
> 
> Solución depende de k
> Familia de soluciones
> 
> Ejemplo:
> { x + y = k
> { xy = k²
> 
> Para cada k, diferentes (x, y)
> ```
> 
> **Sistema con restricciones:**
> 
> ```
> Restricciones adicionales:
> x, y ∈ ℤ (enteros)
> x, y ≥ 0 (no negativos)
> x, y ∈ [a, b] (acotados)
> 
> Ejemplo - ecuaciones diofánticas:
> { x² + y² = 25
> { x, y ∈ ℤ
> 
> Soluciones enteras: (±5,0), (0,±5), (±3,±4), (±4,±3)
> ```
> 
> **Sistema implícito:**
> 
> ```
> No se puede despejar explícitamente
> 
> { F(x, y, u, v) = 0
> { G(x, y, u, v) = 0
> 
> Requiere métodos numéricos o implícitos
> ```

## 💡 Estrategias de Resolución

> [!tip]- Guía General **Paso 1: Análisis inicial**
> 
> ```
> 1. Identificar tipo de sistema
> 2. Verificar si hay ecuaciones lineales
> 3. Buscar simetrías
> 4. Estimar número de soluciones
> 5. Identificar restricciones del dominio
> ```
> 
> **Paso 2: Selección de método**
> 
> ```
> Si hay ecuación lineal:
> → Usar sustitución
> 
> Si términos similares (x², y²):
> → Usar eliminación
> 
> Si forma x + y, xy:
> → Usar fórmula de suma-producto
> 
> Si funciones trascendentes:
> → Considerar métodos numéricos
> 
> Si no es claro:
> → Probar sustitución primero
> ```
> 
> **Paso 3: Simplificación**
> 
> ```
> • Buscar cambios de variable útiles
> • Factorizar cuando sea posible
> • Usar identidades algebraicas
> • Combinar ecuaciones estratégicamente
> ```
> 
> **Paso 4: Resolución**
> 
> ```
> • Aplicar método elegido
> • Resolver ecuación resultante
> • Encontrar todas las soluciones
> • Sustituir hacia atrás
> ```
> 
> **Paso 5: Verificación**
> 
> ```
> • Sustituir cada solución en ambas ecuaciones
> • Verificar restricciones del dominio
> • Descartar soluciones extrañas
> • Interpretar geométricamente si es posible
> ```
