# 📐 Sistemas de Inecuaciones Lineales

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Un sistema de inecuaciones lineales es un conjunto de dos o más desigualdades lineales en dos o más variables que deben satisfacerse simultáneamente. A diferencia de las ecuaciones que tienen puntos como soluciones, las inecuaciones lineales tienen regiones del plano (o espacio) como soluciones. La solución del sistema es la intersección de todas las regiones que satisfacen cada inecuación individual, formando una región factible que puede ser acotada (polígono) o no acotada.**
> 
> **Características clave:**
> 
> - **Desigualdades:** Usan ≤, ≥, <, > en lugar de =
> - **Región solución:** Área del plano (no puntos aislados)
> - **Semiplanos:** Cada inecuación define un semiplano
> - **Región factible:** Intersección de todos los semiplanos
> - **Frontera:** Puede ser incluida (≤, ≥) o excluida (<, >)
> - **Vértices:** Puntos donde se intersectan las fronteras

## 🎯 Definiciones Básicas

> [!important]- Conceptos Fundamentales **Inecuación lineal (2 variables):**
> 
> ```
> Forma general:
> ax + by ≤ c  (o ≥, <, >)
> 
> donde:
> • a, b: coeficientes (constantes)
> • x, y: variables
> • c: término independiente
> 
> Formas equivalentes:
> ax + by + c ≤ 0
> ax + by ≥ c
> ax + by < c
> ax + by > c
> 
> Ejemplo:
> 2x + 3y ≤ 12
> x - y > 5
> ```
> 
> **Semiplano:**
> 
> ```
> Cada inecuación lineal divide el plano
> en dos regiones (semiplanos):
> 
> Frontera: recta ax + by = c
> 
> Semiplano superior: ax + by > c
> Semiplano inferior: ax + by < c
> 
> Frontera incluida: ≤ o ≥ (línea sólida)
> Frontera excluida: < o > (línea punteada)
> 
> Ejemplo: y ≤ 2x + 3
> Frontera: y = 2x + 3
> Región: debajo de la recta (incluyendo recta)
> ```
> 
> **Región factible:**
> 
> ```
> Conjunto de puntos que satisfacen
> TODAS las inecuaciones del sistema
> 
> Región factible = ∩ (intersección de semiplanos)
> 
> Puede ser:
> • Vacía: sistema incompatible
> • Acotada: región cerrada (polígono)
> • No acotada: región infinita
> • Un único punto: sistema muy restrictivo
> • Una recta: sistema degenerado
> 
> Notación:
> RF = {(x,y) ∈ ℝ² : satisface todas las inecuaciones}
> ```
> 
> **Vértices (puntos extremos):**
> 
> ```
> Puntos donde se intersectan dos o más
> fronteras de la región factible
> 
> Importancia:
> • Definen el polígono de soluciones
> • Puntos clave en optimización
> • Soluciones óptimas ocurren en vértices
> 
> Cálculo:
> Resolver sistemas 2×2 de ecuaciones
> formadas por las fronteras
> Verificar si pertenecen a región factible
> ```
> 
> **Restricciones de no negatividad:**
> 
> ```
> Comunes en problemas aplicados:
> x ≥ 0
> y ≥ 0
> 
> Limitan solución al primer cuadrante
> 
> Interpretación:
> Variables que representan cantidades físicas
> (no pueden ser negativas)
> ```

## 📊 Resolución Gráfica

> [!success]- Método Visual **Procedimiento paso a paso:**
> 
> ```
> Paso 1: Graficar cada frontera
> • Convertir inecuación en ecuación (=)
> • Encontrar dos puntos de la recta
> • Trazar la recta
> • Línea sólida si ≤ o ≥
> • Línea punteada si < o >
> 
> Paso 2: Determinar lado correcto
> • Elegir punto de prueba (usualmente (0,0))
> • Sustituir en la inecuación
> • Si se satisface: sombrear ese lado
> • Si no: sombrear el lado opuesto
> 
> Paso 3: Identificar región factible
> • Intersección de todas las regiones sombreadas
> • Puede usar diferentes colores o patrones
> • Región común a todas las inecuaciones
> 
> Paso 4: Identificar vértices
> • Puntos de intersección de fronteras
> • Resolver sistemas de ecuaciones
> • Verificar pertenencia a región factible
> 
> Paso 5: Clasificar región
> • Acotada o no acotada
> • Vacía si no hay intersección
> ```
> 
> **Ejemplo detallado:**
> 
> ```
> Sistema:
> { x + y ≤ 6
> { 2x + y ≤ 10
> { x ≥ 0
> { y ≥ 0
> 
> Frontera 1: x + y = 6
> Puntos: (0, 6) y (6, 0)
> Punto prueba (0,0): 0 + 0 ≤ 6 ✓
> Región: debajo de la recta
> 
> Frontera 2: 2x + y = 10
> Puntos: (0, 10) y (5, 0)
> Punto prueba (0,0): 0 + 0 ≤ 10 ✓
> Región: debajo de la recta
> 
> Frontera 3: x = 0 (eje y)
> Región: x ≥ 0 (derecha del eje)
> 
> Frontera 4: y = 0 (eje x)
> Región: y ≥ 0 (arriba del eje)
> 
> Vértices:
> A: intersección x = 0, y = 0 → (0, 0)
> B: intersección x = 0, x + y = 6 → (0, 6)
> C: intersección x + y = 6, 2x + y = 10
>    Resolver: x = 4, y = 2 → (4, 2)
> D: intersección 2x + y = 10, y = 0 → (5, 0)
> 
> Región factible: cuadrilátero ABCD
> Acotada: polígono cerrado
> ```
> 
> **Casos especiales:**
> 
> ```
> Región vacía:
> { x + y ≤ 2
> { x + y ≥ 5
> 
> Contradicción: ningún punto satisface ambas
> 
> Región no acotada:
> { x + y ≥ 3
> { x ≥ 0
> { y ≥ 0
> 
> Región infinita en dirección noreste
> 
> Región degenerada (una recta):
> { x + y ≤ 5
> { x + y ≥ 5
> 
> Región: recta x + y = 5
> 
> Un único punto:
> { x ≤ 3, x ≥ 3
> { y ≤ 2, y ≥ 2
> 
> Región: punto (3, 2)
> ```

## 🔢 Método Algebraico

> [!note]- Enfoque Analítico **Test de vértices:**
> 
> ```
> Para verificar si un punto es solución:
> 
> 1. Sustituir coordenadas en cada inecuación
> 2. Verificar que TODAS se satisfagan
> 3. Si una falla, el punto NO es solución
> 
> Ejemplo: verificar (2, 3) en sistema
> { x + y ≤ 6
> { 2x + y ≤ 10
> { x ≥ 0, y ≥ 0
> 
> Verificación:
> 2 + 3 = 5 ≤ 6 ✓
> 2(2) + 3 = 7 ≤ 10 ✓
> 2 ≥ 0 ✓
> 3 ≥ 0 ✓
> 
> (2, 3) es solución
> ```
> 
> **Determinación de vértices:**
> 
> ```
> Procedimiento sistemático:
> 
> 4. Listar todas las fronteras (ecuaciones)
> 5. Tomar combinaciones de 2 ecuaciones
> 6. Resolver cada sistema 2×2
> 7. Verificar si punto está en región factible
> 8. Los que satisfacen son vértices
> 
> Ejemplo:
> Fronteras: L₁: x + y = 6
>           L₂: 2x + y = 10
>           L₃: x = 0
>           L₄: y = 0
> 
> Intersecciones:
> L₁ ∩ L₂: sistema {x + y = 6, 2x + y = 10}
>         Solución: (4, 2) → verificar ✓
> 
> L₁ ∩ L₃: sistema {x + y = 6, x = 0}
>         Solución: (0, 6) → verificar ✓
> 
> L₁ ∩ L₄: sistema {x + y = 6, y = 0}
>         Solución: (6, 0) → verificar si está en RF
> 
> ... y así sucesivamente
> ```
> 
> **Método de eliminación de Fourier:**
> 
> ```
> Para eliminar una variable:
> 
> 9. Separar inecuaciones en tres grupos:
>    • Coeficiente positivo de x
>    • Coeficiente negativo de x
>    • No contienen x
> 
> 10. De grupo positivo: despejar x ≤ ...
> 11. De grupo negativo: despejar x ≥ ...
> 12. Combinar para obtener cotas sobre x
> 13. Repetir para y
> 
> Ejemplo:
> { x + y ≤ 6     (x ≤ 6 - y)
> { 2x - y ≥ 2    (x ≥ (2 + y)/2)
> { y ≥ 0
> 
> Entonces: (2 + y)/2 ≤ x ≤ 6 - y
> Con restricción: y ≥ 0
> ```

## 🧮 Problemas Resueltos

> [!example]- Ejemplos Detallados **Problema 1: Sistema básico**
> 
> ```
> Resolver gráficamente:
> { x + 2y ≤ 8
> { 3x + y ≤ 9
> { x ≥ 0
> { y ≥ 0
> 
> SOLUCIÓN:
> 
> Frontera 1: x + 2y = 8
> Puntos: (0, 4) y (8, 0)
> Prueba (0,0): 0 + 0 ≤ 8 ✓
> Región: debajo de L₁
> 
> Frontera 2: 3x + y = 9
> Puntos: (0, 9) y (3, 0)
> Prueba (0,0): 0 + 0 ≤ 9 ✓
> Región: debajo de L₂
> 
> Vértices:
> A: (0, 0) intersección x = 0, y = 0
> 
> B: (0, 4) intersección x = 0, x + 2y = 8
>    Verificar en 3x + y ≤ 9:
>    3(0) + 4 = 4 ≤ 9 ✓
> 
> C: intersección x + 2y = 8, 3x + y = 9
>    Resolver:
>    { x + 2y = 8    ... (1)
>    { 3x + y = 9    ... (2)
>    
>    De (1): x = 8 - 2y
>    En (2): 3(8 - 2y) + y = 9
>           24 - 6y + y = 9
>           -5y = -15
>           y = 3
>    x = 8 - 2(3) = 2
>    
>    Vértice C: (2, 3)
>    Verificar x ≥ 0, y ≥ 0: ✓
> 
> D: (3, 0) intersección 3x + y = 9, y = 0
>    Verificar en x + 2y ≤ 8:
>    3 + 0 = 3 ≤ 8 ✓
> 
> Región factible: cuadrilátero ABCD
> Vértices: (0,0), (0,4), (2,3), (3,0)
> ```
> 
> **Problema 2: Región no acotada**
> 
> ```
> Resolver:
> { x + y ≥ 4
> { 2x + y ≥ 6
> { x ≥ 0
> { y ≥ 0
> 
> SOLUCIÓN:
> 
> Frontera 1: x + y = 4
> Puntos: (0, 4) y (4, 0)
> Prueba (0,0): 0 + 0 ≥ 4 ✗
> Región: arriba de L₁
> 
> Frontera 2: 2x + y = 6
> Puntos: (0, 6) y (3, 0)
> Prueba (0,0): 0 + 0 ≥ 6 ✗
> Región: arriba de L₂
> 
> Vértices:
> A: (0, 6) intersección x = 0, 2x + y = 6
>    Verificar en x + y ≥ 4:
>    0 + 6 = 6 ≥ 4 ✓
> 
> B: intersección x + y = 4, 2x + y = 6
>    Resolver:
>    { x + y = 4
>    { 2x + y = 6
>    
>    Restar: x = 2
>    Entonces: y = 2
>    
>    Vértice B: (2, 2)
> 
> C: (4, 0) intersección x + y = 4, y = 0
>    Verificar en 2x + y ≥ 6:
>    2(4) + 0 = 8 ≥ 6 ✓
> 
> Región factible: no acotada
> Vértices: (0,6), (2,2), (4,0)
> Se extiende hacia infinito en dirección noreste
> ```
> 
> **Problema 3: Sistema incompatible**
> 
> ```
> Resolver:
> { x + y ≤ 3
> { x + y ≥ 5
> { x ≥ 0
> { y ≥ 0
> 
> SOLUCIÓN:
> 
> Análisis:
> Primera inecuación: x + y ≤ 3
> Segunda inecuación: x + y ≥ 5
> 
> Contradicción: no existe (x,y) tal que
> x + y ≤ 3 Y x + y ≥ 5 simultáneamente
> 
> Región factible: VACÍA
> Sistema incompatible (no tiene solución)
> ```
> 
> **Problema 4: Determinar si punto es solución**
> 
> ```
> Verificar si (1, 2) es solución de:
> { 2x + y ≤ 7
> { x - 3y ≤ -4
> { x ≥ 0
> { y ≥ 0
> 
> SOLUCIÓN:
> 
> Sustituir (1, 2) en cada inecuación:
> 
> Inecuación 1: 2(1) + 2 ≤ 7
>              4 ≤ 7 ✓
> 
> Inecuación 2: 1 - 3(2) ≤ -4
>              1 - 6 ≤ -4
>              -5 ≤ -4 ✓
> 
> Inecuación 3: 1 ≥ 0 ✓
> 
> Inecuación 4: 2 ≥ 0 ✓
> 
> Todas se satisfacen → (1, 2) SÍ es solución
> ```
> 
> **Problema 5: Encontrar todos los vértices**
> 
> ```
> Sistema:
> { x + y ≤ 5
> { x - y ≤ 1
> { x ≥ 0
> { y ≥ 0
> 
> SOLUCIÓN:
> 
> Fronteras:
> L₁: x + y = 5
> L₂: x - y = 1
> L₃: x = 0
> L₄: y = 0
> 
> Candidatos a vértices:
> 
> A = L₃ ∩ L₄: (0, 0)
>    Verificar: 0 + 0 ≤ 5 ✓, 0 - 0 ≤ 1 ✓
>    Vértice ✓
> 
> B = L₃ ∩ L₁: (0, 5)
>    Verificar: 0 - 5 = -5 ≤ 1 ✓
>    Vértice ✓
> 
> C = L₁ ∩ L₂:
>    { x + y = 5
>    { x - y = 1
>    Sumar: 2x = 6 → x = 3
>    Entonces: y = 2
>    Punto: (3, 2)
>    Verificar: 3 ≥ 0 ✓, 2 ≥ 0 ✓
>    Vértice ✓
> 
> D = L₂ ∩ L₄: (1, 0)
>    { x - y = 1
>    { y = 0
>    x = 1
>    Verificar: 1 + 0 = 1 ≤ 5 ✓
>    Vértice ✓
> 
> E = L₁ ∩ L₄: (5, 0)
>    Verificar: 5 - 0 = 5 ≤ 1 ✗
>    NO es vértice
> 
> F = L₃ ∩ L₂: (0, -1)
>    Verificar: -1 ≥ 0 ✗
>    NO es vértice
> 
> Vértices de la región factible:
> A(0,0), B(0,5), C(3,2), D(1,0)
> ```
> 
> **Problema 6: Aplicación - Producción**
> 
> ```
> Una fábrica produce mesas (x) y sillas (y).
> Restricciones:
> • Cada mesa requiere 3 horas, cada silla 2 horas
> • Disponibles 12 horas de trabajo
> • Cada mesa usa 4 unidades de madera
> • Cada silla usa 2 unidades de madera
> • Disponibles 16 unidades de madera
> • No negatividad: x ≥ 0, y ≥ 0
> 
> Plantear y resolver sistema de inecuaciones
> 
> SOLUCIÓN:
> 
> Planteo:
> { 3x + 2y ≤ 12    (tiempo)
> { 4x + 2y ≤ 16    (madera)
> { x ≥ 0
> { y ≥ 0
> 
> Frontera 1: 3x + 2y = 12
> Puntos: (0, 6) y (4, 0)
> 
> Frontera 2: 4x + 2y = 16
> Simplificar: 2x + y = 8
> Puntos: (0, 8) y (4, 0)
> 
> Vértices:
> A: (0, 0)
> B: (0, 6) - intersección x = 0, 3x + 2y = 12
>    Verificar: 4(0) + 2(6) = 12 ≤ 16 ✓
> 
> C: intersección 3x + 2y = 12, 4x + 2y = 16
>    Restar: -x = -4 → x = 4
>    En primera: 3(4) + 2y = 12
>                12 + 2y = 12
>                y = 0
>    Punto: (4, 0)
>    Verificar restricciones ✓
> 
> Región factible: triángulo con vértices
> (0,0), (0,6), (4,0)
> 
> Interpretación:
> Puede producir desde 0 hasta 6 sillas (sin mesas)
> Puede producir hasta 4 mesas (sin sillas)
> O cualquier combinación en el triángulo
> ```
> 
> **Problema 7: Tres variables (visualización 3D)**
> 
> ```
> Sistema (conceptual):
> { x + y + z ≤ 6
> { x ≥ 0
> { y ≥ 0
> { z ≥ 0
> 
> SOLUCIÓN:
> 
> Primera inecuación: plano x + y + z = 6
> Interceptos: (6,0,0), (0,6,0), (0,0,6)
> 
> Región: tetraedro con vértices:
> (0,0,0), (6,0,0), (0,6,0), (0,0,6)
> 
> Cada vértice es intersección de tres planos
> 
> Ejemplo: (6,0,0) es intersección de
> x + y + z = 6, y = 0, z = 0
> ```
> 
> **Problema 8: Región con desigualdades estrictas**
> 
> ```
> Resolver:
> { x + y < 4
> { x > 1
> { y > 0
> 
> SOLUCIÓN:
> 
> Frontera 1: x + y = 4 (línea punteada)
> Frontera 2: x = 1 (línea punteada)
> Frontera 3: y = 0 (línea punteada)
> 
> Región: interior del triángulo
> (sin incluir fronteras)
> 
> Vértices NO pertenecen a la región:
> (1, 0) - no incluido (y > 0, no y ≥ 0)
> (1, 3) - no incluido (fronteras abiertas)
> (4, 0) - no incluido
> 
> Región factible: interior abierto
> 
> Nota: No tiene vértices en sentido estricto
> (puntos frontera no incluidos)
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes **1. "Invertir dirección del sombreado"**
> 
> ```
> Para y ≤ 2x + 1:
> 
> ✗ Sombrear arriba de la recta
> ✓ Sombrear abajo de la recta
> 
> Siempre usar punto de prueba (0,0)
> para verificar lado correcto
> ```
> 
> **2. "Confundir línea sólida y punteada"**
> 
> ```
> ≤ o ≥ : línea sólida (frontera incluida)
> < o > : línea punteada (frontera excluida)
> 
> ✗ y < 3 con línea sólida
> ✓ y < 3 con línea punteada
> 
> Afecta si vértices pertenecen a región
> ```
> 
> **3. "No verificar vértices en todas las inecuaciones"**
> 
> ```
> Al encontrar intersección de dos rectas,
> NO asumir automáticamente que es vértice
> 
> SIEMPRE verificar en todas las demás inecuaciones
> 
> Ejemplo: intersección de L₁ y L₂ puede estar
> fuera de la región definida por L₃
> ```
> 
> **4. "Asumir región siempre es acotada"**
> 
> ```
> Sistemas solo con ≥ típicamente
> generan regiones no acotadas
> 
> { x + y ≥ 3
> { x ≥ 0, y ≥ 0
> 
> Región se extiende infinitamente
> No forma polígono cerrado
> ```
> 
> **5. "Olvidar restricciones de no negatividad"**
> 
> ```
> En problemas aplicados, típicamente:
> x ≥ 0, y ≥ 0
> 
> ✗ Permitir soluciones en otros cuadrantes
> ✓ Limitar a primer cuadrante
> 
> Variables representan cantidades físicas
> ```
> 
> **6. "Graficar incorrectamente la recta"**
> 
> ```
> Para 2x + 3y = 12:
> 
> ✗ Solo un punto
> ✓ Al menos dos puntos
> 
> Mejor: usar interceptos
> x = 0 → y = 4: punto (0, 4)
> y = 0 → x = 6: punto (6, 0)
> ```
> 
> **7. "No considerar sistema vacío"**
> 
> ```
> Sistema puede no tener solución
> 
> { x + y ≤ 2
> { x + y ≥ 5
> 
> ✗ Asumir siempre hay región factible ✓ Verificar compatibilidad del sistema
> 
> Región vacía = sistema incompatible
> 
> ```
> 
> **8. "Confundir intersección con unión"**
> 
> ```
> 
> Región factible es INTERSECCIÓN (∩) de todos los semiplanos
> 
> ✗ Unir todas las regiones sombreadas ✓ Solo la región común a todas
> 
> Debe satisfacer TODAS las inecuaciones simultáneamente
> ```

## 📐 Optimización Lineal

> [!tip]- Programación Lineal **Problema de optimización:**
> 
> ```
> Maximizar (o minimizar): Z = ax + by
> Sujeto a:
> { sistema de inecuaciones lineales
> { restricciones de no negatividad
> 
> Donde:
> Z: función objetivo
> ax + by: expresión lineal
> Restricciones: inecuaciones lineales
> 
> Ejemplo:
> Maximizar: Z = 3x + 2y
> Sujeto a:
> { x + y ≤ 6
> { 2x + y ≤ 10
> { x ≥ 0, y ≥ 0
> ```
> 
> **Teorema fundamental:**
> 
> ```
> Si la región factible es acotada y no vacía,
> entonces:
> 
> • El óptimo (máximo o mínimo) existe
> • Se alcanza en un vértice de la región
> • Si se alcanza en dos vértices, se alcanza
>   en todos los puntos del segmento entre ellos
> 
> Método de resolución:
> 1. Encontrar región factible
> 2. Identificar todos los vértices
> 3. Evaluar función objetivo en cada vértice
> 4. El vértice con mayor/menor valor es óptimo
> ```
> 
> **Método gráfico de isocuantas:**
> 
> ```
> Para Z = ax + by:
> 
> 1. Graficar región factible
> 2. Dibujar línea Z = k para algún k
>    (curva de nivel de Z)
> 3. Mover paralelamente la línea
>    - Hacia arriba/derecha para maximizar
>    - Hacia abajo/izquierda para minimizar
> 4. Último punto de contacto con región
>    es el óptimo
> 
> Ejemplo:
> Maximizar Z = 3x + 2y
> 
> Líneas de nivel: 3x + 2y = k
> A medida que k aumenta, línea se mueve
> hacia arriba-derecha
> 
> Última intersección con región factible
> da el máximo
> ```
> 
> **Casos especiales:**
> 
> ```
> Región no acotada:
> • Puede no tener máximo (Z → ∞)
> • Puede tener mínimo en vértice
> 
> Soluciones múltiples:
> • Si Z paralela a una arista
> • Todos los puntos de la arista son óptimos
> • Infinitas soluciones óptimas
> 
> Región vacía:
> • Problema no tiene solución
> • Restricciones incompatibles
> 
> Único vértice:
> • Restricciones muy estrictas
> • Única solución factible
> ```

## 🧮 Problemas de Optimización

> [!example]- Aplicaciones **Problema 1: Producción óptima**
> 
> ```
> Una empresa fabrica dos productos A y B.
> 
> Datos:
> • Producto A: ganancia $3, usa 2h máquina, 1h mano obra
> • Producto B: ganancia $2, usa 1h máquina, 2h mano obra
> • Disponible: 8h máquina, 8h mano obra
> 
> ¿Cuánto producir de cada uno para maximizar ganancia?
> 
> SOLUCIÓN:
> 
> Variables:
> x = unidades de A
> y = unidades de B
> 
> Función objetivo:
> Maximizar Z = 3x + 2y
> 
> Restricciones:
> { 2x + y ≤ 8    (máquina)
> { x + 2y ≤ 8    (mano obra)
> { x ≥ 0, y ≥ 0
> 
> Vértices de región factible:
> A: (0, 0) → Z = 0
> B: (0, 4) → Z = 3(0) + 2(4) = 8
> C: intersección 2x + y = 8, x + 2y = 8
>    Resolver: { 2x + y = 8
>              { x + 2y = 8
>    Multiplicar segunda por 2: 2x + 4y = 16
>    Restar: -3y = -8 → y = 8/3
>    x = (8 - 8/3)/2 = 8/3
>    Punto: (8/3, 8/3)
>    Z = 3(8/3) + 2(8/3) = 8 + 16/3 = 40/3 ≈ 13.33
> D: (4, 0) → Z = 3(4) + 2(0) = 12
> 
> Máximo: Z = 40/3 en (8/3, 8/3)
> 
> Respuesta: 
> Producir 8/3 ≈ 2.67 unidades de A
> y 8/3 ≈ 2.67 unidades de B
> Ganancia máxima: $13.33
> ```
> 
> **Problema 2: Dieta mínima**
> 
> ```
> Diseñar dieta con dos alimentos X e Y.
> 
> Requerimientos mínimos diarios:
> • Vitamina A: 20 unidades
> • Vitamina B: 30 unidades
> 
> Contenido por porción:
> • Alimento X: 2 unidades A, 6 unidades B, costo $1
> • Alimento Y: 4 unidades A, 3 unidades B, costo $2
> 
> Minimizar costo cumpliendo requerimientos
> 
> SOLUCIÓN:
> 
> Variables:
> x = porciones de X
> y = porciones de Y
> 
> Función objetivo:
> Minimizar C = x + 2y
> 
> Restricciones:
> { 2x + 4y ≥ 20    (vitamina A)
> { 6x + 3y ≥ 30    (vitamina B)
> { x ≥ 0, y ≥ 0
> 
> Simplificar:
> { x + 2y ≥ 10     (vitamina A)
> { 2x + y ≥ 10     (vitamina B)
> 
> Vértices:
> A: intersección x = 0, x + 2y = 10
>    y = 5, punto (0, 5)
>    Verificar: 2(0) + 5 = 5 ≱ 10 ✗
>    NO es vértice factible
> 
> B: intersección x = 0, 2x + y = 10
>    y = 10, punto (0, 10)
>    Verificar: 0 + 2(10) = 20 ≥ 10 ✓
>    C = 0 + 2(10) = 20
> 
> C: intersección x + 2y = 10, 2x + y = 10
>    { x + 2y = 10
>    { 2x + y = 10
>    Multiplicar primera por 2: 2x + 4y = 20
>    Restar: 3y = 10 → y = 10/3
>    x = 10 - 2(10/3) = 10/3
>    Punto: (10/3, 10/3)
>    C = 10/3 + 2(10/3) = 30/3 = 10
> 
> D: intersección y = 0, 2x + y = 10
>    x = 5, punto (5, 0)
>    Verificar: 5 + 0 = 5 ≱ 10 ✗
>    NO es vértice factible
> 
> Región no acotada (se extiende infinitamente)
> 
> Mínimo: C = 10 en (10/3, 10/3)
> 
> Respuesta:
> 10/3 ≈ 3.33 porciones de X
> 10/3 ≈ 3.33 porciones de Y
> Costo mínimo: $10
> ```
> 
> **Problema 3: Transporte**
> 
> ```
> Dos almacenes A₁ y A₂ deben abastecer dos tiendas T₁ y T₂
> 
> Capacidad almacenes:
> • A₁: 50 unidades
> • A₂: 60 unidades
> 
> Demanda tiendas:
> • T₁: 40 unidades
> • T₂: 30 unidades
> 
> Costos de transporte (por unidad):
> A₁ → T₁: $2
> A₁ → T₂: $3
> A₂ → T₁: $4
> A₂ → T₂: $1
> 
> Minimizar costo total de transporte
> 
> SOLUCIÓN:
> 
> Variables:
> x = unidades de A₁ a T₁
> y = unidades de A₁ a T₂
> 
> Entonces:
> De A₂ a T₁: 40 - x
> De A₂ a T₂: 30 - y
> 
> Función objetivo:
> Minimizar C = 2x + 3y + 4(40-x) + 1(30-y)
> C = 2x + 3y + 160 - 4x + 30 - y
> C = -2x + 2y + 190
> 
> Restricciones:
> { x + y ≤ 50        (capacidad A₁)
> { (40-x) + (30-y) ≤ 60  (capacidad A₂)
> { x ≥ 0, y ≥ 0
> { 40 - x ≥ 0  →  x ≤ 40
> { 30 - y ≥ 0  →  y ≤ 30
> 
> Simplificar segunda:
> 70 - x - y ≤ 60
> -x - y ≤ -10
> x + y ≥ 10
> 
> Sistema:
> { x + y ≤ 50
> { x + y ≥ 10
> { 0 ≤ x ≤ 40
> { 0 ≤ y ≤ 30
> 
> Vértices:
> (0, 10), (0, 30), (20, 30), (40, 10), (40, 0), (10, 0)
> 
> Evaluar C = -2x + 2y + 190:
> (0, 10): C = 0 + 20 + 190 = 210
> (0, 30): C = 0 + 60 + 190 = 250
> (20, 30): C = -40 + 60 + 190 = 210
> (40, 10): C = -80 + 20 + 190 = 130 ← Mínimo
> (40, 0): C = -80 + 0 + 190 = 110 ← Mínimo
> (10, 0): C = -20 + 0 + 190 = 170
> 
> Mínimo: C = 110 en (40, 0)
> 
> Distribución óptima:
> A₁ → T₁: 40 unidades
> A₁ → T₂: 0 unidades
> A₂ → T₁: 0 unidades
> A₂ → T₂: 30 unidades
> Costo mínimo: $110
> ```

## 🔍 Interpretación de Resultados

> [!important]- Análisis de Soluciones **Análisis de sensibilidad:**
> 
> ```
> Estudia cómo cambios en parámetros
> afectan la solución óptima
> 
> Preguntas típicas:
> • ¿Qué pasa si aumentamos un recurso?
> • ¿Cuánto vale un recurso adicional?
> • ¿Cómo afecta cambiar coeficientes?
> 
> Precio sombra (shadow price):
> Cambio en función objetivo por
> unidad adicional de recurso
> 
> Ejemplo:
> Si aumentar tiempo de máquina en 1h
> aumenta ganancia en $2,
> entonces precio sombra = $2
> ```
> 
> **Recursos ociosos:**
> 
> ```
> Recursos no usados completamente
> 
> Identificación:
> Si restricción no es activa en óptimo
> (desigualdad estricta)
> 
> Ejemplo:
> Restricción: x + y ≤ 10
> Óptimo: (3, 4)
> Verificar: 3 + 4 = 7 < 10
> 
> Recurso ocioso: 10 - 7 = 3 unidades
> ```
> 
> **Restricciones activas:**
> 
> ```
> Restricciones que se satisfacen con igualdad
> en el punto óptimo
> 
> Determinan los vértices óptimos
> Son las "restricciones críticas"
> 
> Modificar estas restricciones
> puede cambiar la solución óptima
> ```
> 
> **Soluciones alternativas:**
> 
> ```
> Cuando función objetivo es paralela
> a una arista de la región factible
> 
> Todos los puntos de esa arista
> son óptimos
> 
> Infinitas soluciones óptimas
> con el mismo valor objetivo
> 
> Útil para tener flexibilidad
> en la implementación
> ```

## 📚 Tabla de Referencia Rápida

> [!important]- Resumen de Conceptos
> 
> ```
> SISTEMAS DE INECUACIONES LINEALES - RESUMEN
> 
> ═══════════════════════════════════════════
> ELEMENTOS BÁSICOS
> ═══════════════════════════════════════════
> Inecuación lineal: ax + by ≤ c (o ≥, <, >)
> 
> Semiplano: región dividida por frontera
> Frontera: recta ax + by = c
> 
> Línea sólida: ≤ o ≥ (frontera incluida)
> Línea punteada: < o > (frontera excluida)
> 
> Región factible: intersección de semiplanos
> Vértice: intersección de dos fronteras
> 
> ═══════════════════════════════════════════
> MÉTODO GRÁFICO
> ═══════════════════════════════════════════
> 1. Graficar cada frontera (recta)
> 2. Determinar lado correcto (punto prueba)
> 3. Sombrear región de cada inecuación
> 4. Identificar intersección (región común)
> 5. Encontrar vértices
> 
> ═══════════════════════════════════════════
> TIPOS DE REGIONES
> ═══════════════════════════════════════════
> Acotada: región cerrada (polígono)
> No acotada: región infinita
> Vacía: sistema incompatible
> Punto único: sistema muy restrictivo
> 
> ═══════════════════════════════════════════
> OPTIMIZACIÓN LINEAL
> ═══════════════════════════════════════════
> Maximizar/Minimizar: Z = ax + by
> Sujeto a: sistema de inecuaciones
> 
> Teorema: Si región acotada y no vacía,
>          óptimo existe y está en vértice
> 
> Método:
> 6. Encontrar región factible
> 7. Identificar vértices
> 8. Evaluar Z en cada vértice
> 9. Elegir máximo/mínimo
> 
> ═══════════════════════════════════════════
> VERIFICACIÓN
> ═══════════════════════════════════════════
> Punto (x₀, y₀) es solución si:
> Satisface TODAS las inecuaciones
> 
> Vértice candidato:
> 10. Resolver intersección de fronteras
> 11. Verificar en todas las inecuaciones
> 12. Si todas se cumplen → vértice válido
> ```
