# 🎯 Tipos de Conjuntos y Cardinalidad

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Un conjunto es una colección bien definida de objetos distintos llamados elementos, donde la pertenencia de cada objeto es determinista (o está o no está). La cardinalidad de un conjunto es el número de elementos que contiene, y los tipos de conjuntos clasifican según sus características estructurales y su tamaño.**
> 
> **Elementos clave:**
> 
> - **Conjunto:** Colección sin orden de objetos distintos
> - **Elemento:** Objeto que pertenece a un conjunto
> - **Pertenencia:** Relación binaria (∈ o ∉)
> - **Cardinalidad:** Medida del "tamaño" de un conjunto
> - **Clasificación:** Finititud, vacuidad, igualdad, relaciones

### 📖 Contexto Histórico

> [!note]- Desarrollo de la Teoría de Conjuntos
> 
> **Orígenes (antigua Grecia):**
> 
> - Aristóteles: Primeras ideas sobre colecciones
> - Euclides: Agrupamientos en geometría
> 
> **Formación Moderna (1870-1900):**
> 
> - **Georg Cantor (1845-1918):** Fundador de la teoría de conjuntos
>     - 1874: Primer artículo sobre teoría de conjuntos
>     - Demostró que existen diferentes "infinitos"
>     - Introdujo la noción de cardinalidad
>     - Cardenal transfinito (ℵ₀, 𝔠)
> - **Gottlob Frege (1848-1925):** Axiomatización temprana
> - **Richard Dedekind (1831-1916):** Construcción de ℝ con conjuntos
> 
> **Crisis y Resolución (1900-1950):**
> 
> - **Paradoja de Russell (1901):** ¿Pertenece R = {x : x ∉ x} a sí mismo?
> - **Bertrand Russell (1872-1970):** Teoría de tipos
> - **Ernst Zermelo (1871-1953):** Axiomas de teoría de conjuntos
> - **Abraham Fraenkel (1891-1965):** Completó axiomas (ZFC)
> 
> **Matemáticas Modernas (1950-presente):**
> 
> - Teoría de conjuntos como fundamento de toda matemática
> - Extensiones: teoría de modelos, topología, categorías
> - Aplicaciones en computación e IA

## 🏗️ Notación y Definiciones Básicas

> [!success]- Lenguaje Fundamental
> 
> **Representación de conjuntos:**
> 
> ```
> Extensión: A = {1, 2, 3, 4, 5}
> Enumeración explícita de elementos
> 
> Comprensión: A = {x ∈ ℤ : 1 ≤ x ≤ 5}
> Descripción mediante propiedad
> 
> Construcción: A = {n | n ∈ ℕ ∧ n es primo ∧ n < 30}
> Forma general: {expresión | condiciones}
> ```
> 
> **Símbolos fundamentales:**
> 
> ```
> ∈  : Pertenencia         (a ∈ A: "a pertenece a A")
> ∉  : No pertenencia      (a ∉ A: "a no pertenece a A")
> ⊆  : Subconjunto         (A ⊆ B: "A es subconjunto de B")
> ⊂  : Subconjunto propio  (A ⊂ B: "A es subconjunto propio de B")
> ⊄  : No es subconjunto   (A ⊄ B: "A no es subconjunto de B")
> ∪  : Unión               (A ∪ B: "A unión B")
> ∩  : Intersección        (A ∩ B: "A intersección B")
> ∖  : Diferencia          (A ∖ B: "A menos B")
> Aᶜ : Complemento         (complemento de A)
> |A| : Cardinalidad       (número de elementos de A)
> ∅  : Conjunto vacío      (conjunto sin elementos)
> 𝒫(A) : Conjunto potencia (conjunto de todos los subconjuntos)
> ```
> 
> **Definiciones formales:**
> 
> ```
> Igualdad: A = B ⟺ ∀x: (x ∈ A ↔ x ∈ B)
> "Dos conjuntos son iguales si tienen exactamente los mismos elementos"
> 
> Subconjunto: A ⊆ B ⟺ ∀x: (x ∈ A → x ∈ B)
> "A es subconjunto de B si todo elemento de A está en B"
> 
> Subconjunto propio: A ⊂ B ⟺ (A ⊆ B ∧ A ≠ B)
> "A es subconjunto propio de B si A ⊆ B pero A ≠ B"
> ```

## 🎲 Tipos de Conjuntos Según su Contenido

> [!success]- Clasificación Fundamental
> 
> ### Conjunto Vacío (∅)
> 
> ```
> Definición: Conjunto que no contiene elementos
> Notación alternativa: { }
> Cardinalidad: |∅| = 0
> 
> Ejemplos:
> - {x ∈ ℕ : x < 0}  (no hay naturales negativos)
> - {x ∈ ℝ : x² = -1}  (no hay reales cuyo cuadrado sea -1)
> - {personas que viven en la Luna}  (actualmente vacío)
> 
> Propiedades importantes:
> ✓ Es único (existe un único conjunto vacío)
> ✓ Es subconjunto de todo conjunto: ∅ ⊆ A para todo A
> ✓ Pertenece al conjunto potencia: ∅ ∈ 𝒫(A) para todo A
> ✓ La unión con ∅ no añade: A ∪ ∅ = A
> ✓ La intersección con ∅ vacía: A ∩ ∅ = ∅
> 
> Distinción importante:
> ∅ ≠ {∅}  (conjunto vacío vs conjunto que contiene el conjunto vacío)
> |∅| = 0, pero |{∅}| = 1
> ```
> 
> ### Conjunto Unitario (Singleton)
> 
> ```
> Definición: Conjunto con exactamente un elemento
> Notación: {a}
> Cardinalidad: |{a}| = 1
> 
> Ejemplos:
> - {0}  (conjunto cuyo único elemento es cero)
> - {∅}  (conjunto cuyo único elemento es el conjunto vacío)
> - {π}  (conjunto cuyo único elemento es pi)
> - {persona más alta del mundo actualmente}
> 
> Propiedades:
> ✓ a ∈ {a}
> ✓ {a} ≠ a  (el conjunto NO es el elemento)
> ✓ ∅ ⊂ {a}  (conjunto vacío es subconjunto propio)
> ✓ {a} tiene exactamente 2 subconjuntos: ∅ y {a}
> 
> Comparación:
> {a} = {a} pero ≠ {a, a}  (duplicados colapsan)
> {1} ≠ {1, 1}  No, ambos son iguales (elementos son distintos)
> {1} ≠ {{1}}  Sí (uno contiene 1, otro contiene el conjunto {1})
> ```
> 
> ### Conjunto Finito
> 
> ```
> Definición: Conjunto con un número finito de elementos
> Cardinalidad: |A| = n donde n ∈ ℕ
> 
> Ejemplos:
> - {1, 2, 3}  (cardinal: 3)
> - {a, b, c, d, e}  (cardinal: 5)
> - Conjunto de todos los estudiantes en una clase
> - Conjunto de letras del alfabeto español: |A| = 27
> 
> Propiedades:
> ✓ Todo subconjunto es finito
> ✓ La unión de dos finitos es finita
> ✓ El conjunto potencia es finito: |𝒫(A)| = 2^|A|
> 
> Ejemplos de cálculo de cardinalidad:
> A = {1, 2, 3}  ⟹  |A| = 3
> B = {2, 3}     ⟹  |B| = 2
> A ∩ B = {2, 3} ⟹  |A ∩ B| = 2
> A ∪ B = {1, 2, 3} ⟹  |A ∪ B| = 3
> ```
> 
> ### Conjunto Infinito
> 
> ```
> Definición: Conjunto con infinitos elementos (no puede contarse)
> Notación: |A| = ∞ o |A| = ℵ (aleph)
> 
> Ejemplos:
> - ℕ = {0, 1, 2, 3, ...}  (números naturales)
> - ℤ = {..., -2, -1, 0, 1, 2, ...}  (números enteros)
> - ℚ = {p/q : p, q ∈ ℤ, q ≠ 0}  (números racionales)
> - ℝ  (números reales)
> - Conjunto de puntos en una línea
> 
> IMPORTANTE: No todos los infinitos son iguales
> Existen infinitos "más grandes" que otros
> 
> Propiedades:
> ✓ Todo conjunto infinito tiene un subconjunto infinito propio
> ✓ La unión de dos infinitos puede ser igual a uno de ellos
> ✓ Hay infinitos tipos diferentes de infinito
> ```

## 📊 Cardinalidad y Infinitos de Cantor

> [!success]- Medida del Tamaño de Conjuntos
> 
> ### Cardinalidad Finita
> 
> ```
> Definición formal: |A| = n si existe una biyección entre A y {1, 2, ..., n}
> 
> Ejemplos con cálculo:
> A = {a, b, c}           ⟹  |A| = 3
> B = {números pares de 1 a 20}  ⟹  |B| = 10
> C = {}                  ⟹  |C| = 0
> 
> Reglas básicas:
> |A ∪ B| = |A| + |B| - |A ∩ B|  (principio de inclusión-exclusión)
> |A × B| = |A| × |B|  (producto cartesiano)
> |𝒫(A)| = 2^|A|  (conjunto potencia)
> |{funciones A → B}| = |B|^|A|
> 
> Aplicación:
> A = {1, 2, 3}, B = {a, b}
> |A ∪ B| = 3 + 2 - 0 = 5
> |A × B| = 3 × 2 = 6 (pares: (1,a), (1,b), (2,a), (2,b), (3,a), (3,b))
> |𝒫(A)| = 2³ = 8
> ```
> 
> ### Cardinalidad Infinita (Cantor)
> 
> ```
> Definición formal:
> Dos conjuntos tienen la misma cardinalidad si existe una biyección entre ellos
> (no necesita ser finita, puede ser infinita)
> 
> Cardenal de ℕ: |ℕ| = ℵ₀ (aleph-cero)
> Cardenal de ℝ: |ℝ| = 𝔠 = 2^ℵ₀ (cardinal del continuo)
> 
> Comparación de infinitos (Cantor):
> ℵ₀ < 𝔠
> |ℕ| = |ℤ| = |ℚ| = ℵ₀  (TODOS son "igualmente infinitos")
> |ℝ| = 𝔠 > ℵ₀  (ℝ es "más infinito" que ℕ)
> 
> Interpretación intuitiva:
> "Entre 0 y 1 hay tantos puntos como números naturales"
> (Aunque parezca más pequeño, tienen la MISMA cantidad de elementos)
> 
> La diagonal de Cantor prueba |ℝ| > |ℕ|:
> Supongamos que ℝ es numerable: ℝ = {r₁, r₂, r₃, ...}
> r₁ = 0.a₁₁a₁₂a₁₃...
> r₂ = 0.a₂₁a₂₂a₂₃...
> r₃ = 0.a₃₁a₃₂a₃₃...
> 
> Construimos x = 0.b₁b₂b₃... donde bₙ ≠ aₙₙ
> Entonces x ∉ {r₁, r₂, r₃, ...} ⟹ CONTRADICCIÓN
> Por tanto, ℝ no es numerable, y |ℝ| > |ℕ|
> ```

## 🔢 Conjuntos Especiales según su Estructura

> [!success]- Clasificación por Propiedades
> 
> ### Conjunto Universal (U)
> 
> ```
> Definición: Conjunto que contiene todos los elementos relevantes
>            en un contexto específico
> 
> Varía según contexto:
> - En teoría de números: U = ℤ, ℕ, o ℝ
> - En geometría plana: U = ℝ²  (todos los puntos del plano)
> - En una clase: U = {todos los estudiantes de la clase}
> 
> Propiedades:
> ✓ A ⊆ U para todo A en el contexto
> ✓ A ∪ U = U
> ✓ A ∩ U = A
> ✓ Uᶜ = ∅
> ✓ A ∪ Aᶜ = U
> 
> Notación alternativa: X (letra X mayúscula)
> ```
> 
> ### Conjunto Complemento (Aᶜ)
> 
> ```
> Definición: Conjunto de todos los elementos del universal que NO están en A
> Notación alternativa: A' o U \ A
> Definición formal: Aᶜ = {x ∈ U : x ∉ A}
> 
> Ejemplos (con U = ℤ):
> A = {números pares}  ⟹  Aᶜ = {números impares}
> B = {números positivos}  ⟹  Bᶜ = {números no positivos} = {0, -1, -2, ...}
> C = {1, 2, 3}  ⟹  Cᶜ = ℤ \ {1, 2, 3}
> 
> Propiedades:
> ✓ (Aᶜ)ᶜ = A  (complemento del complemento)
> ✓ A ∩ Aᶜ = ∅  (no hay intersección)
> ✓ A ∪ Aᶜ = U  (cobertura completa)
> ✓ ∅ᶜ = U
> ✓ Uᶜ = ∅
> ✓ |A| + |Aᶜ| = |U|  (si finito)
> ```
> 
> ### Conjunto Potencia 𝒫(A)
> 
> ```
> Definición: Conjunto de TODOS los subconjuntos de A
> Notación alternativa: 2^A (porque hay 2^|A| subconjuntos)
> Definición formal: 𝒫(A) = {X : X ⊆ A}
> 
> Ejemplos:
> A = {1, 2}
> 𝒫(A) = {∅, {1}, {2}, {1,2}}
> |𝒫(A)| = 4 = 2²
> 
> B = {a}
> 𝒫(B) = {∅, {a}}
> |𝒫(B)| = 2 = 2¹
> 
> C = ∅
> 𝒫(C) = {∅}
> |𝒫(C)| = 1 = 2⁰
> 
> Propiedades:
> ✓ ∅ ∈ 𝒫(A) siempre
> ✓ A ∈ 𝒫(A) siempre
> ✓ Si |A| = n, entonces |𝒫(A)| = 2ⁿ
> ✓ Si A es finito, 𝒫(A) es finito
> ✓ Si A es infinito, |𝒫(A)| > |A|  (teorema de Cantor)
> 
> Cálculo del número de subconjuntos:
> A con 3 elementos ⟹ 2³ = 8 subconjuntos
> A con 4 elementos ⟹ 2⁴ = 16 subconjuntos
> A con n elementos ⟹ 2ⁿ subconjuntos
> ```

## 🔗 Relaciones entre Conjuntos

> [!success]- Tipos de Relaciones
> 
> ### Conjuntos Disjuntos
> 
> ```
> Definición: Dos conjuntos son disjuntos si no tienen elementos en común
> Notación: A ∩ B = ∅
> Definición formal: ∀x: (x ∈ A → x ∉ B) ∧ (x ∈ B → x ∉ A)
> 
> Ejemplos:
> A = {números pares}
> B = {números impares}
> A ∩ B = ∅  ✓ Son disjuntos
> 
> C = {1, 2, 3}
> D = {4, 5, 6}
> C ∩ D = ∅  ✓ Son disjuntos
> 
> E = {1, 2, 3}
> F = {3, 4, 5}
> E ∩ F = {3} ≠ ∅  ✗ NO son disjuntos
> 
> Propiedades:
> ✓ Si A ∩ B = ∅, entonces |A ∪ B| = |A| + |B|
> ✓ Múltiples conjuntos pueden ser mutuamente disjuntos
> ✓ ∅ es disjunto de todo conjunto (incluyéndose a sí mismo)
> ```
> 
> ### Conjuntos Equivalentes (Equinumerosos)
> 
> ```
> Definición: Dos conjuntos tienen la misma cardinalidad
>            (existe una biyección entre ellos)
> Notación: A ~ B o |A| = |B|
> 
> Ejemplos:
> A = {1, 2, 3}
> B = {a, b, c}
> Biyección: 1↔a, 2↔b, 3↔c
> A ~ B  ✓
> 
> C = ℕ = {0, 1, 2, 3, ...}
> D = {números pares} = {0, 2, 4, 6, ...}
> Biyección: n ↔ 2n
> C ~ D  ✓ (ambos tienen cardinalidad ℵ₀)
> 
> Propiedades:
> ✓ Reflexiva: A ~ A
> ✓ Simétrica: Si A ~ B, entonces B ~ A
> ✓ Transitiva: Si A ~ B y B ~ C, entonces A ~ C
> ✓ Es una relación de equivalencia
> 
> Sorpresa de Cantor:
> |ℕ| = |ℤ| = |ℚ| = ℵ₀
> ¡Los números pares tienen la "misma cantidad" que todos los naturales!
> ```
> 
> ### Conjuntos Comparables
> 
> ```
> Definición: Dos conjuntos A y B son comparables si:
>            |A| ≤ |B|  (existe una inyección A → B)
>            o |B| ≤ |A|  (existe una inyección B → A)
> 
> Teorema de Schröder-Bernstein:
> Si |A| ≤ |B| y |B| ≤ |A|, entonces |A| = |B|
> 
> Ejemplo:
> A = {1, 2, 3}
> B = {1, 2, 3, 4, 5}
> |A| ≤ |B|  (inyección identidad en elementos de A)
> B ⊂ A?  No, A no es subconjunto de B
> Pero comparables: |A| < |B|
> ```

## 📐 Operaciones entre Conjuntos y Cardinalidad

> [!note]- Propiedades Aritméticas
> 
> **Unión:**
> 
> ```
> A ∪ B = {x : x ∈ A ∨ x ∈ B}
> 
> Cardinalidad (finitos):
> |A ∪ B| = |A| + |B| - |A ∩ B|
> 
> Casos especiales:
> Si A ∩ B = ∅ (disjuntos): |A ∪ B| = |A| + |B|
> Si A ⊂ B: |A ∪ B| = |B|
> 
> Ejemplo:
> A = {1, 2, 3}, B = {3, 4, 5}
> A ∪ B = {1, 2, 3, 4, 5}
> |A ∪ B| = 3 + 3 - 1 = 5
> ```
> 
> **Intersección:**
> 
> ```
> A ∩ B = {x : x ∈ A ∧ x ∈ B}
> 
> Propiedades:
> Si A ∩ B = ∅: Conjuntos disjuntos
> Si A ⊆ B: A ∩ B = A
> 
> Cardinalidad:
> |A ∩ B| ≤ min(|A|, |B|)
> 
> Ejemplo:
> A = {1, 2, 3}, B = {3, 4, 5}
> A ∩ B = {3}
> |A ∩ B| = 1
> ```
> 
> **Diferencia:**
> 
> ```
> A \ B = {x : x ∈ A ∧ x ∉ B}
> 
> Propiedades:
> A \ B = A ∩ Bᶜ
> A \ A = ∅
> A \ ∅ = A
> ∅ \ A = ∅
> 
> Cardinalidad:
> |A \ B| = |A| - |A ∩ B|
> 
> Ejemplo:
> A = {1, 2, 3}, B = {3, 4, 5}
> A \ B = {1, 2}
> |A \ B| = 3 - 1 = 2
> ```
> 
> **Diferencia Simétrica:**
> 
> ```
> A ⊕ B = (A \ B) ∪ (B \ A) = (A ∪ B) \ (A ∩ B)
> Elementos que están en A o B pero no en ambos
> 
> Ejemplo:
> A = {1, 2, 3}, B = {3, 4, 5}
> A ⊕ B = {1, 2, 4, 5}
> |A ⊕ B| = 4
> ```
> 
> **Producto Cartesiano:**
> 
> ```
> A × B = {(a, b) : a ∈ A ∧ b ∈ B}
> 
> Cardinalidad:
> |A × B| = |A| × |B|
> 
> Ejemplo:
> A = {1, 2}, B = {a, b, c}
> A × B = {(1,a), (1,b), (1,c), (2,a), (2,b), (2,c)}
> |A × B| = 2 × 3 = 6
> 
> Propiedades:
> A × B ≠ B × A en general (no conmutativo)
> (A × B) × C ≠ A × (B × C) en general (no asociativo en representación)
> A × ∅ = ∅
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes
> 
> **1. "∅ ≠ {∅}" (Confusión crítica)**
> 
> ```
> ✗ INCORRECTO pensar que son iguales
> ✓ CORRECTO: ∅ ≠ {∅}
> 
> Explicación:
> ∅  es un conjunto sin elementos
> {∅} es un conjunto que CONTIENE el conjunto vacío
> |∅| = 0
> |{∅}| = 1
> ∅ ∈ {∅} es VERDADERO
> ∅ ∈ ∅ es FALSO
> ```
> 
> **2. "Subconjunto significa más pequeño" (INCORRECTO)**
> 
> ```
> ✗ INCORRECTO interpretación
> ✓ CORRECTO: A ⊆ B significa que todo elemento de A está en B
> 
> Puede ocurrir:
> A ⊆ A (un conjunto es subconjunto de sí mismo)
> A = B pero A ⊆ B
> A ⊂ B es más pequeño (subconjunto PROPIO)
> ```
> 
> **3. "{1, 1, 1} tiene 3 elementos" (INCORRECTO)**
> 
> ```
> ✗ INCORRECTO
> ✓ CORRECTO: {1, 1, 1} = {1}, |{1, 1, 1}| = 1
> 
> Razón: Los elementos de un conjunto son DISTINTOS
>       Las repeticiones se colapsan
> ```
> 
> **4. "La cardinalidad de ℕ es infinito" (IMPRECISO)**
> 
> ```
> ✗ IMPRECISO (aunque no totalmente incorrecto)
> ✓ PRECISO: |ℕ| = ℵ₀ (aleph-cero)
> 
> Razón: Existen diferentes tipos de infinito
>       ℵ₀ < 𝔠 (ℕ es "más pequeño" que ℝ)
> ```
> 
> **5. "ℕ tiene menos elementos que ℤ" (INCORRECTO)**
> 
> ```
> ✗ INCORRECTO
> ✓ CORRECTO: |ℕ| = |ℤ| = ℵ₀
> 
> Biyección:
> 0 ↔ 0
> 1 ↔ -1
> 2 ↔ 1
> 3 ↔ -2
> 4 ↔ 2
> 5 ↔ -3
> ...
> Ambos conjuntos tienen la "misma cantidad" de infinito
> ```
> 
> **6. "|A ∪ B| = |A| + |B| siempre" (INCORRECTO)**
> 
> ```
> ✗ INCORRECTO cuando hay intersección
> ✓ CORRECTO: |A ∪ B| = |A| + |B| - |A ∩ B|
> 
> Ejemplo error:
> A = {1, 2, 3}, B = {3, 4}
> ✗ |A ∪ B| = 3 + 2 = 5
> ✓ |A ∪ B| = 3 + 2 - 1 = 4 = |{1,2,3,4}|
> ```
> 
> **7. "𝒫(A) contiene A como elemento, no como subconjunto" (AMBOS)**
> 
> ```
> ✓ AMBOS SON CORRECTOS:
> A ∈ 𝒫(A)   (A ES elemento de su propio conjunto potencia)
> A ⊆ A      (A ES subconjunto de sí mismo)
> 
> Distinción:
> ∈ es relación de pertenencia (elemento)
> ⊆ es relación de subconjunto (colección)
> 
> Ejemplo:
> A = {1, 2}
> 𝒫(A) = {∅, {1}, {2}, {1,2}}
> {1,2} ∈ 𝒫(A)  (como ELEMENTO)
> {1,2} ⊆ {1,2}  (como SUBCONJUNTO)
> ```
> 
> **8. "Dos conjuntos infinitos tienen la misma cardinalidad" (INCORRECTO)**
> 
> ```
> ✗ INCORRECTO
> ✓ CORRECTO: Depende cuál infinito
> 
> |ℕ| = ℵ₀ ≠ 𝔠 = |ℝ|
> Existen infinitos más grandes y más pequeños
> Hay infinitamente muchos infinitos (Cantor)
> ```

## 🔬 Comparación de Cardinalidades

> [!tip]- Método para Comparar Tamaños
> 
> **Para conjuntos finitos:**
> 
> ```
> Simplemente contar elementos y comparar números
> 
> A = {a, b, c}   ⟹  |A| = 3
> B = {1, 2}      ⟹  |B| = 2
> 3 > 2, por tanto |A| > |B|
> ```
> 
> **Para conjuntos infinitos (Cantor):**
> 
> ```
> Buscar una BIYECCIÓN (función 1-1 y sobre)
> Si existe: |A| = |B|
> Si solo existe inyección A → B: |A| ≤ |B|
> Si no existe: |A| < |B|
> 
> Ejemplo: Demostrar |ℕ| = |ℤ|
> Biyección f: ℕ → ℤ definida por:
> f(0) = 0
> f(2n) = n para n > 0
> f(2n+1) = -n para n > 0
> 
> Esta función es:
> ✓ Inyectiva: números distintos mapean a resultados distintos
> ✓ Sobreyectiva: todo entero es imagen de algún natural
> Por tanto, es biyección y |ℕ| = |ℤ| = ℵ₀
> ```
> 
> **Escala de infinitos (por orden):**
> 
> ```
> ℵ₀ < 𝔠 < 2^𝔠 < 2^(2^𝔠) < ...
> 
> |ℕ| = |ℤ| = |ℚ| = ℵ₀  (infinitos "pequeños")
> |ℝ| = 𝔠 = 2^ℵ₀         (continuo, infinito medio)
> |𝒫(ℝ)| = 2^𝔠            (infinito muy grande)
> 
> Hipótesis del Continuo:
> ¿Existe un cardinal entre ℵ₀ y 𝔠?
> Respuesta (Gödel, Cohen): Independiente de ZFC
> (No se puede probar ni refutar)
> ```

## 🎯 Particiones de Conjuntos

> [!success]- División Sistemática
> 
> **Definición:**
> 
> ```
> Una partición de A es una colección de subconjuntos {A₁, A₂, ..., Aₙ}
> tal que:
> 1. Cada Aᵢ ≠ ∅  (no vacíos)
> 2. A₁ ∪ A₂ ∪ ... ∪ Aₙ = A  (cobertura completa)
> 3. Aᵢ ∩ Aⱼ = ∅ para i ≠ j  (mutuamente disjuntos)
> 
> Es decir: A se divide en partes que no se solapan
> ```
> 
> **Ejemplos:**
> 
> ```
> A = {1, 2, 3, 4}
> Partición 1: {{1}, {2}, {3}, {4}}  ✓
> Partición 2: {{1, 2}, {3, 4}}      ✓
> Partición 3: {{1, 2, 3}, {4}}      ✓
> No-partición: {{1}, {2}}           ✗ (falta 3 y 4)
> No-partición: {{1, 2}, {2, 3}}     ✗ (2 aparece en ambos)
> 
> Partición de ℤ:
> {{números pares}, {números impares}}  ✓
> 
> Partición de ℝ:
> {{números negativos}, {0}, {números positivos}}  ✓
> ```
> 
> **Aplicaciones:**
> 
> ```
> Clases de equivalencia:
> Si ~ es relación de equivalencia en A,
> entonces las clases de equivalencia forman una partición
> 
> Ejemplo:
> A = ℤ, relación: a ~ b si tienen el mismo signo
> Clases: {números negativos}, {0}, {números positivos}
> Es una partición
> 
> Cardinalidad de particiones:
> Si {A₁, A₂, ..., Aₙ} es partición de A:
> |A| = |A₁| + |A₂| + ... + |Aₙ|
> ```

## 🧮 Aplicaciones de Cardinalidad

> [!example]- Usos Prácticos
> 
> **Combinatoria:**
> 
> ```
> Contar arreglos y combinaciones usando cardinalidad
> 
> Principio de multiplicación:
> |A × B| = |A| × |B|
> 
> Si hay 3 camisas y 4 pantalones:
> Número de outfits = 3 × 4 = 12
> 
> Permutaciones:
> Si A tiene n elementos, número de permutaciones = n!
> (Es la cardinalidad del conjunto de todas las biyecciones A → A)
> 
> Combinaciones:
> Número de subconjuntos de tamaño k = C(n,k) = n!/(k!(n-k)!)
> ```
> 
> **Teoría de Funciones:**
> 
> ```
> Dada función f: A → B
> |f(A)| ≤ |B|  (imagen está contenida en el codominio)
> Si f es sobreyectiva: |f(A)| = |B|
> Si f es inyectiva: |A| ≤ |B|
> Si f es biyectiva: |A| = |B|
> 
> Ejemplo:
> f: {1,2,3} → {a,b,c,d}
> f es inyectiva: |{1,2,3}| = 3 ≤ 4 = |{a,b,c,d}|
> f NO puede ser sobreyectiva (no hay suficientes elementos en dominio)
> ```
> 
> **Probabilidad Clásica:**
> 
> ```
> Probabilidad = (número de casos favorables) / (número de casos totales)
>             = |A| / |U|
> donde A es evento, U es espacio muestral
> 
> Ejemplo:
> Tirar un dado:
> U = {1, 2, 3, 4, 5, 6}, |U| = 6
> A = "número par" = {2, 4, 6}, |A| = 3
> P(A) = 3/6 = 1/2
> ```
> 
> **Estructuras de Datos:**
> 
> ```
> La cardinalidad determina complejidad espacial
> 
> Array de n elementos: O(n) espacio
> Tabla hash con n elementos: O(n) espacio
> Árbol con n nodos: O(n) espacio
> 
> Complejidad de búsqueda:
> Array lineal: O(n)  donde n = |Array|
> Búsqueda binaria: O(log n)
> ```
