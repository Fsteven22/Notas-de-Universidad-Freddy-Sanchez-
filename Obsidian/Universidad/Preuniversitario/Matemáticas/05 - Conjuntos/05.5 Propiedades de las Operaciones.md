# 🎯 05.5 Propiedades de las Operaciones con Conjuntos

## 📐 Álgebra de Conjuntos

> [!info]- Sistema Algebraico Las operaciones con conjuntos forman un **álgebra booleana**, un sistema matemático con propiedades bien definidas que permiten simplificar y manipular expresiones de conjuntos de manera sistemática.
> 
> **Analogía con aritmética:**
> 
> - Así como tenemos propiedades de +, −, × en números
> - Tenemos propiedades de ∪, ∩, −, ' en conjuntos
> 
> Estas propiedades nos permiten:
> 
> - Simplificar expresiones complejas
> - Demostrar igualdades de conjuntos
> - Resolver problemas de manera eficiente

## 🔄 Propiedades Conmutativas

> [!success]- El Orden No Importa
> 
> **Conmutatividad de la unión:**
> 
> ```
> A ∪ B = B ∪ A
> ```
> 
> **Conmutatividad de la intersección:**
> 
> ```
> A ∩ B = B ∩ A
> ```
> 
> **Conmutatividad de la diferencia simétrica:**
> 
> ```
> A △ B = B △ A
> ```
> 
> **NO conmutativa: Diferencia**
> 
> ```
> A − B ≠ B − A  (en general)
> ```

### Demostraciones

> [!example]- Prueba: A ∪ B = B ∪ A
> 
> **Método de doble inclusión:**
> 
> **(⊆) Probar A ∪ B ⊆ B ∪ A:**
> 
> ```
> Sea x ∈ A ∪ B
> Entonces x ∈ A ∨ x ∈ B
> Por conmutatividad de ∨: x ∈ B ∨ x ∈ A
> Por tanto: x ∈ B ∪ A
> Conclusión: A ∪ B ⊆ B ∪ A
> ```
> 
> **(⊇) Probar B ∪ A ⊆ A ∪ B:**
> 
> ```
> Análogo al caso anterior
> ```
> 
> Por antisimetría: A ∪ B = B ∪ A ∎

## 🔗 Propiedades Asociativas

> [!success]- Agrupación Flexible
> 
> **Asociatividad de la unión:**
> 
> ```
> (A ∪ B) ∪ C = A ∪ (B ∪ C)
> ```
> 
> Por tanto podemos escribir: A ∪ B ∪ C sin ambigüedad
> 
> **Asociatividad de la intersección:**
> 
> ```
> (A ∩ B) ∩ C = A ∩ (B ∩ C)
> ```
> 
> Por tanto podemos escribir: A ∩ B ∩ C sin ambigüedad
> 
> **Asociatividad de la diferencia simétrica:**
> 
> ```
> (A △ B) △ C = A △ (B △ C)
> ```
> 
> **NO asociativa: Diferencia**
> 
> ```
> (A − B) − C ≠ A − (B − C)  (en general)
> ```

### Ejemplos de Asociatividad

> [!example]- Casos Concretos
> 
> **Unión asociativa:**
> 
> ```
> A = {1, 2}
> B = {2, 3}
> C = {3, 4}
> 
> (A ∪ B) ∪ C = {1, 2, 3} ∪ {3, 4} = {1, 2, 3, 4}
> A ∪ (B ∪ C) = {1, 2} ∪ {2, 3, 4} = {1, 2, 3, 4}
> ```
> 
> **Diferencia NO asociativa:**
> 
> ```
> A = {1, 2, 3}
> B = {2}
> C = {3}
> 
> (A − B) − C = {1, 3} − {3} = {1}
> A − (B − C) = {1, 2, 3} − {2} = {1, 3}
> 
> {1} ≠ {1, 3}  ✓
> ```

## 🎯 Propiedades de Identidad

> [!success]- Elementos Neutros
> 
> **Identidad de la unión (∅):**
> 
> ```
> A ∪ ∅ = A
> ```
> 
> El conjunto vacío es la identidad para la unión
> 
> **Identidad de la intersección (U):**
> 
> ```
> A ∩ U = A
> ```
> 
> El conjunto universal es la identidad para la intersección
> 
> **Identidad de la diferencia simétrica (∅):**
> 
> ```
> A △ ∅ = A
> ```

### Demostraciones

> [!example]- Prueba: A ∪ ∅ = A
> 
> **(⊆) Probar A ∪ ∅ ⊆ A:**
> 
> ```
> Sea x ∈ A ∪ ∅
> Entonces x ∈ A ∨ x ∈ ∅
> Como x ∈ ∅ es siempre falso: x ∈ A
> Por tanto: A ∪ ∅ ⊆ A
> ```
> 
> **(⊇) Probar A ⊆ A ∪ ∅:**
> 
> ```
> Sea x ∈ A
> Por definición de unión: x ∈ A ∪ ∅
> Por tanto: A ⊆ A ∪ ∅
> ```
> 
> Conclusión: A ∪ ∅ = A ∎

## 🔄 Propiedades de Idempotencia

> [!note]- Operación Consigo Mismo
> 
> **Idempotencia de la unión:**
> 
> ```
> A ∪ A = A
> ```
> 
> **Idempotencia de la intersección:**
> 
> ```
> A ∩ A = A
> ```
> 
> **Diferencia simétrica:**
> 
> ```
> A △ A = ∅
> ```
> 
> (No es idempotente, sino que se anula)

### Demostración

> [!example]- Prueba: A ∪ A = A
> 
> ```
> x ∈ A ∪ A
> ⟺ x ∈ A ∨ x ∈ A
> ⟺ x ∈ A  [idempotencia de ∨]
> 
> Por tanto: A ∪ A = A ∎
> ```

## ⚫ Propiedades de Dominancia (Absorción)

> [!warning]- Elementos Absorbentes
> 
> **Universal domina en unión:**
> 
> ```
> A ∪ U = U
> ```
> 
> El universal "absorbe" cualquier conjunto en la unión
> 
> **Vacío domina en intersección:**
> 
> ```
> A ∩ ∅ = ∅
> ```
> 
> El vacío "absorbe" cualquier conjunto en la intersección

### Demostración

> [!example]- Prueba: A ∩ ∅ = ∅
> 
> ```
> Probar A ∩ ∅ ⊆ ∅:
>   Sea x ∈ A ∩ ∅
>   Entonces x ∈ A ∧ x ∈ ∅
>   Pero x ∈ ∅ es imposible
>   Por tanto A ∩ ∅ tiene que ser vacío
> 
> Probar ∅ ⊆ A ∩ ∅:
>   Vacuamente verdadero (∅ ⊆ todo)
> 
> Por tanto: A ∩ ∅ = ∅ ∎
> ```

## 🔀 Leyes Distributivas

> [!success]- Distribución entre Operaciones
> 
> **Unión distribuye sobre intersección:**
> 
> ```
> A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
> ```
> 
> **Intersección distribuye sobre unión:**
> 
> ```
> A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
> ```
> 
> **Importante:** Ambas operaciones distribuyen sobre la otra (a diferencia de aritmética donde solo × distribuye sobre +)

### Demostración Detallada

> [!example]- Prueba: A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
> 
> **Usando equivalencias lógicas:**
> 
> ```
> x ∈ A ∩ (B ∪ C)
> ⟺ x ∈ A ∧ x ∈ (B ∪ C)
> ⟺ x ∈ A ∧ (x ∈ B ∨ x ∈ C)
> ⟺ (x ∈ A ∧ x ∈ B) ∨ (x ∈ A ∧ x ∈ C)  [distributividad de ∧ sobre ∨]
> ⟺ x ∈ (A ∩ B) ∨ x ∈ (A ∩ C)
> ⟺ x ∈ (A ∩ B) ∪ (A ∩ C)
> 
> Por tanto: A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C) ∎
> ```

### Aplicaciones de Distributividad

> [!tip]- Simplificación de Expresiones
> 
> **Ejemplo 1:**
> 
> ```
> A ∩ (B ∪ C) ∪ A ∩ (B ∪ D)
> = (A ∩ B) ∪ (A ∩ C) ∪ (A ∩ B) ∪ (A ∩ D)  [distributividad]
> = (A ∩ B) ∪ (A ∩ C) ∪ (A ∩ D)            [idempotencia]
> ```
> 
> **Ejemplo 2:**
> 
> ```
> (A ∪ B) ∩ (A ∪ C)
> = A ∪ (B ∩ C)  [distributividad inversa]
> ```

## 🔄 Leyes de Absorción

> [!success]- Simplificación Especial
> 
> **Absorción básica:**
> 
> ```
> A ∪ (A ∩ B) = A
> A ∩ (A ∪ B) = A
> ```
> 
> **Absorción con complemento:**
> 
> ```
> A ∪ (A' ∩ B) = A ∪ B
> A ∩ (A' ∪ B) = A ∩ B
> ```

### Demostraciones

> [!example]- Prueba: A ∪ (A ∩ B) = A
> 
> **Método 1 (inclusión doble):**
> 
> ```
> (⊆): Sea x ∈ A ∪ (A ∩ B)
>      Caso 1: x ∈ A → trivialmente x ∈ A
>      Caso 2: x ∈ (A ∩ B) → x ∈ A ∧ x ∈ B → x ∈ A
>      En ambos casos: x ∈ A
> 
> (⊇): Sea x ∈ A
>      Entonces x ∈ A ∪ (A ∩ B)  [por definición de ∪]
> 
> Por tanto: A ∪ (A ∩ B) = A ∎
> ```
> 
> **Método 2 (usando otras propiedades):**
> 
> ```
> A ∪ (A ∩ B)
> = (A ∩ U) ∪ (A ∩ B)           [identidad: A = A ∩ U]
> = A ∩ (U ∪ B)                  [distributividad]
> = A ∩ U                        [dominancia: U ∪ B = U]
> = A                            [identidad]
> ```

## ⚡ Leyes de De Morgan

> [!warning]- Dualidad Fundamental
> 
> **Para dos conjuntos:**
> 
> ```
> (A ∪ B)' = A' ∩ B'
> (A ∩ B)' = A' ∪ B'
> ```
> 
> **Patrón:** Al negar, unión se vuelve intersección y viceversa
> 
> **Generalización para n conjuntos:**
> 
> ```
> (⋃ᵢ₌₁ⁿ Aᵢ)' = ⋂ᵢ₌₁ⁿ Aᵢ'
> (⋂ᵢ₌₁ⁿ Aᵢ)' = ⋃ᵢ₌₁ⁿ Aᵢ'
> ```

### Demostración

> [!example]- Prueba: (A ∪ B)' = A' ∩ B'
> 
> ```
> x ∈ (A ∪ B)'
> ⟺ x ∉ (A ∪ B)
> ⟺ ¬(x ∈ A ∪ B)
> ⟺ ¬(x ∈ A ∨ x ∈ B)
> ⟺ ¬(x ∈ A) ∧ ¬(x ∈ B)  [De Morgan lógico]
> ⟺ x ∉ A ∧ x ∉ B
> ⟺ x ∈ A' ∧ x ∈ B'
> ⟺ x ∈ (A' ∩ B')
> 
> Por tanto: (A ∪ B)' = A' ∩ B' ∎
> ```

### Aplicaciones

> [!tip]- Uso de De Morgan
> 
> **Simplificar complementos:**
> 
> ```
> ((A ∩ B) ∪ C)'
> = (A ∩ B)' ∩ C'           [De Morgan]
> = (A' ∪ B') ∩ C'          [De Morgan otra vez]
> ```
> 
> **Eliminar complementos anidados:**
> 
> ```
> ((A' ∪ B')')'
> = (A' ∪ B')'              [doble complemento]
> = A ∩ B                   [De Morgan + doble complemento]
> ```

## 🔄 Propiedades del Complemento

> [!note]- Leyes Específicas del Complemento
> 
> **1. Doble complemento (Involución):**
> 
> ```
> (A')' = A
> ```
> 
> **2. Complementos extremos:**
> 
> ```
> U' = ∅
> ∅' = U
> ```
> 
> **3. Leyes de complementariedad:**
> 
> ```
> A ∪ A' = U
> A ∩ A' = ∅
> ```
> 
> **4. Anti-monotonía:**
> 
> ```
> Si A ⊆ B, entonces B' ⊆ A'
> ```
> 
> **5. Complemento de diferencia:**
> 
> ```
> A − B = A ∩ B'
> (A − B)' = A' ∪ B
> ```

### Demostraciones

> [!example]- Prueba: A ∪ A' = U
> 
> **Probar A ∪ A' ⊆ U:**
> 
> ```
> Trivial, porque todo conjunto es subconjunto de U
> ```
> 
> **Probar U ⊆ A ∪ A':**
> 
> ```
> Sea x ∈ U
> Por ley del tercero excluido: x ∈ A ∨ x ∉ A
> Si x ∈ A: entonces x ∈ A ∪ A'
> Si x ∉ A: entonces x ∈ A', por tanto x ∈ A ∪ A'
> En ambos casos: x ∈ A ∪ A'
> ```
> 
> Por tanto: A ∪ A' = U ∎

## 📋 Tabla Completa de Propiedades

> [!success]- Resumen Sistemático
> 
> |Propiedad|Unión|Intersección|
> |---|---|---|
> |**Conmutativa**|A ∪ B = B ∪ A|A ∩ B = B ∩ A|
> |**Asociativa**|(A ∪ B) ∪ C = A ∪ (B ∪ C)|(A ∩ B) ∩ C = A ∩ (B ∩ C)|
> |**Identidad**|A ∪ ∅ = A|A ∩ U = A|
> |**Dominancia**|A ∪ U = U|A ∩ ∅ = ∅|
> |**Idempotencia**|A ∪ A = A|A ∩ A = A|
> |**Complementariedad**|A ∪ A' = U|A ∩ A' = ∅|
> |**Absorción**|A ∪ (A ∩ B) = A|A ∩ (A ∪ B) = A|
> |**Distributiva**|A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)|A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)|
> |**De Morgan**|(A ∪ B)' = A' ∩ B'|(A ∩ B)' = A' ∪ B'|
> 
> **Propiedades del complemento:**
> 
> - (A')' = A
> - U' = ∅, ∅' = U
> - Si A ⊆ B entonces B' ⊆ A'

## 🎯 Dualidad

> [!tip]- Principio de Dualidad
> 
> **Concepto:** Si intercambiamos:
> 
> - ∪ ↔ ∩
> - ∅ ↔ U
> - ⊆ ↔ ⊇
> 
> Una identidad válida se transforma en otra identidad válida.
> 
> **Ejemplos:**
> 
> ```
> Original: A ∪ ∅ = A
> Dual:     A ∩ U = A
> 
> Original: A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
> Dual:     A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
> 
> Original: (A ∪ B)' = A' ∩ B'
> Dual:     (A ∩ B)' = A' ∪ B'
> ```
> 
> **Utilidad:** Si demostramos una propiedad, automáticamente sabemos que su dual es verdadero.

## 🔧 Estrategias de Simplificación

> [!success]- Técnicas Prácticas
> 
> **1. Usar leyes de absorción:**
> 
> ```
> A ∪ (A ∩ B) ∪ (A ∩ C)
> = A ∪ (A ∩ (B ∪ C))  [factorizar]
> = A                   [absorción]
> ```
> 
> **2. Aplicar distributividad:**
> 
> ```
> (A ∩ B) ∪ (A ∩ C)
> = A ∩ (B ∪ C)  [distributividad inversa]
> ```
> 
> **3. Usar De Morgan para complementos:**
> 
> ```
> (A ∪ B)' ∩ C
> = (A' ∩ B') ∩ C      [De Morgan]
> = A' ∩ B' ∩ C        [asociatividad]
> ```
> 
> **4. Eliminar términos redundantes:**
> 
> ```
> A ∪ A ∪ B
> = A ∪ B              [idempotencia]
> ```
> 
> **5. Simplificar con complementos:**
> 
> ```
> (A ∩ B) ∪ (A ∩ B')
> = A ∩ (B ∪ B')       [distributividad]
> = A ∩ U              [complementariedad]
> = A                  [identidad]
> ```

## 💡 Aplicaciones en Demostraciones

> [!example]- Problemas Resueltos
> 
> **Problema 1:** Demostrar que A − (B ∪ C) = (A − B) ∩ (A − C)
> 
> **Solución:**
> 
> ```
> A − (B ∪ C)
> = A ∩ (B ∪ C)'              [definición de −]
> = A ∩ (B' ∩ C')             [De Morgan]
> = (A ∩ B') ∩ (A ∩ C')       [distributividad]
> = (A − B) ∩ (A − C)         [definición de −]
> ∎
> ```
> 
> **Problema 2:** Demostrar que (A ∩ B) ∪ (A ∩ B') = A
> 
> **Solución:**
> 
> ```
> (A ∩ B) ∪ (A ∩ B')
> = A ∩ (B ∪ B')              [distributividad]
> = A ∩ U                     [complementariedad]
> = A                         [identidad]
> ∎
> ```
> 
> **Problema 3:** Simplificar (A ∪ B)' ∪ (A' ∩ B)
> 
> **Solución:**
> 
> ```
> (A ∪ B)' ∪ (A' ∩ B)
> = (A' ∩ B') ∪ (A' ∩ B)     [De Morgan]
> = A' ∩ (B' ∪ B)             [distributividad]
> = A' ∩ U                    [complementariedad]
> = A'                        [identidad]
> ∎
> ```

## 🔗 Conexión con Lógica Booleana

> [!tip]- Correspondencia Directa
> 
> |Conjuntos|Lógica|Significado|
> |---|---|---|
> |A ∪ B|A ∨ B|OR|
> |A ∩ B|A ∧ B|AND|
> |A'|¬A|NOT|
> |A ⊆ B|A → B|Implicación|
> |A = B|A ↔ B|Equivalencia|
> |∅|F (Falso)|Contradicción|
> |U|T (Verdadero)|Tautología|
> 
> **Implicación:** Todas las leyes del álgebra booleana se aplican al álgebra de conjuntos.
