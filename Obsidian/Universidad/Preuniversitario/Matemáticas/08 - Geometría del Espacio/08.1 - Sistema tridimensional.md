# 🎲 Sistema Tridimensional

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **El sistema tridimensional o espacio euclidiano 3D (ℝ³) es una extensión del plano que añade una tercera dimensión perpendicular a las dos anteriores. Permite representar y analizar objetos con volumen, describir posiciones en el espacio físico y modelar fenómenos que ocurren en tres dimensiones. Es el espacio de nuestra experiencia cotidiana.**
> 
> **Características clave:**
> 
> - **Tres ejes perpendiculares:** x, y, z mutuamente ortogonales
> - **Coordenadas:** Terna ordenada (x, y, z) para cada punto
> - **Origen:** Punto O(0, 0, 0) donde se intersectan los ejes
> - **Planos coordenados:** xy, xz, yz dividen el espacio en 8 octantes
> - **Distancia:** Extensión del teorema de Pitágoras al espacio
> - **Vectores 3D:** Magnitud, dirección y sentido en el espacio

## 📐 Sistema de Coordenadas Cartesianas 3D

> [!important]- Ejes y Coordenadas **Definición del sistema:**
> 
> ```
> Tres ejes mutuamente perpendiculares:
> 
> Eje X: horizontal (derecha-izquierda)
> Eje Y: horizontal (adelante-atrás)
> Eje Z: vertical (arriba-abajo)
> 
> Origen O: punto (0, 0, 0)
> Intersección de los tres ejes
> 
> Regla de la mano derecha:
> • Pulgar → eje X
> • Índice → eje Y
> • Medio → eje Z
> 
> Sistema dextrógiro (positivo)
> ```
> 
> **Coordenadas de un punto:**
> 
> ```
> Punto P en el espacio:
> P = (x, y, z)
> 
> donde:
> x = coordenada en eje X (abscisa)
> y = coordenada en eje Y (ordenada)
> z = coordenada en eje Z (cota o altura)
> 
> Interpretación geométrica:
> • x: distancia con signo del plano YZ
> • y: distancia con signo del plano XZ
> • z: distancia con signo del plano XY
> 
> Ejemplo:
> P(3, -2, 5):
> • 3 unidades en dirección +X
> • 2 unidades en dirección -Y
> • 5 unidades en dirección +Z
> ```
> 
> **Puntos especiales:**
> 
> ```
> Origen: O(0, 0, 0)
> 
> Sobre los ejes:
> Eje X: (x, 0, 0)
> Eje Y: (0, y, 0)
> Eje Z: (0, 0, z)
> 
> Sobre los planos coordenados:
> Plano XY (z=0): (x, y, 0)
> Plano XZ (y=0): (x, 0, z)
> Plano YZ (x=0): (0, y, z)
> 
> Puntos unitarios en ejes:
> î = (1, 0, 0) - vector unitario en X
> ĵ = (0, 1, 0) - vector unitario en Y
> k̂ = (0, 0, 1) - vector unitario en Z
> ```

## 🎯 Planos Coordenados y Octantes

> [!success]- División del Espacio **Planos coordenados:**
> 
> ```
> Tres planos que dividen el espacio:
> 
> 1. Plano XY:
>    Ecuación: z = 0
>    Contiene ejes X e Y
>    Horizontal (típicamente)
> 
> 2. Plano XZ:
>    Ecuación: y = 0
>    Contiene ejes X e Z
>    Vertical frontal
> 
> 3. Plano YZ:
>    Ecuación: x = 0
>    Contiene ejes Y e Z
>    Vertical lateral
> 
> Intersecciones:
> XY ∩ XZ = eje X
> XY ∩ YZ = eje Y
> XZ ∩ YZ = eje Z
> XY ∩ XZ ∩ YZ = origen O
> ```
> 
> **Los 8 octantes:**
> 
> ```
> Los tres planos dividen ℝ³ en 8 regiones
> 
> Octante I (primer octante):
>    x > 0, y > 0, z > 0
>    Todos positivos
>    Notación: (+, +, +)
> 
> Octante II:
>    x < 0, y > 0, z > 0
>    Notación: (-, +, +)
> 
> Octante III:
>    x < 0, y < 0, z > 0
>    Notación: (-, -, +)
> 
> Octante IV:
>    x > 0, y < 0, z > 0
>    Notación: (+, -, +)
> 
> Octante V:
>    x > 0, y > 0, z < 0
>    Notación: (+, +, -)
> 
> Octante VI:
>    x < 0, y > 0, z < 0
>    Notación: (-, +, -)
> 
> Octante VII:
>    x < 0, y < 0, z < 0
>    Todos negativos
>    Notación: (-, -, -)
> 
> Octante VIII:
>    x > 0, y < 0, z < 0
>    Notación: (+, -, -)
> 
> Convención: El primer octante es donde
> todas las coordenadas son positivas
> (análogo al primer cuadrante en 2D)
> ```
> 
> **Simetrías:**
> 
> ```
> Punto P(x, y, z) y sus simétricos:
> 
> Respecto al plano XY:
>    P'(x, y, -z)
> 
> Respecto al plano XZ:
>    P'(x, -y, z)
> 
> Respecto al plano YZ:
>    P'(-x, y, z)
> 
> Respecto al origen:
>    P'(-x, -y, -z)
> 
> Respecto al eje X:
>    P'(x, -y, -z)
> 
> Respecto al eje Y:
>    P'(-x, y, -z)
> 
> Respecto al eje Z:
>    P'(-x, -y, z)
> ```

## 📏 Distancia en el Espacio

> [!note]- Fórmula 3D de Pitágoras **Distancia entre dos puntos:**
> 
> ```
> Puntos: P₁(x₁, y₁, z₁) y P₂(x₂, y₂, z₂)
> 
> Distancia:
> d = √[(x₂-x₁)² + (y₂-y₁)² + (z₂-z₁)²]
> 
> Abreviado:
> d = √[(Δx)² + (Δy)² + (Δz)²]
> 
> donde:
> Δx = x₂ - x₁
> Δy = y₂ - y₁
> Δz = z₂ - z₁
> 
> Demostración (teorema de Pitágoras repetido):
> 1. Proyección en plano XY: d₁ = √[(Δx)² + (Δy)²]
> 2. Considerar Δz perpendicular: d = √[d₁² + (Δz)²]
> 3. Sustituir: d = √[(Δx)² + (Δy)² + (Δz)²]
> ```
> 
> **Distancia al origen:**
> 
> ```
> Punto P(x, y, z) al origen O(0, 0, 0):
> 
> d = √(x² + y² + z²)
> 
> Representa la norma o magnitud del vector posición
> |OP| = √(x² + y² + z²)
> ```
> 
> **Casos especiales:**
> 
> ```
> Puntos en mismo plano coordenado:
> 
> Si z₁ = z₂ = 0 (plano XY):
> d = √[(Δx)² + (Δy)²] (fórmula 2D)
> 
> Si y₁ = y₂ = 0 (plano XZ):
> d = √[(Δx)² + (Δz)²]
> 
> Si x₁ = x₂ = 0 (plano YZ):
> d = √[(Δy)² + (Δz)²]
> 
> Puntos en mismo eje:
> 
> Eje X (y=z=0):
> d = |x₂ - x₁|
> 
> Eje Y (x=z=0):
> d = |y₂ - y₁|
> 
> Eje Z (x=y=0):
> d = |z₂ - z₁|
> ```
> 
> **Propiedades de la distancia:**
> 
> ```
> 4. No negatividad:
>    d(P, Q) ≥ 0
>    d(P, Q) = 0 ⟺ P = Q
> 
> 5. Simetría:
>    d(P, Q) = d(Q, P)
> 
> 6. Desigualdad triangular:
>    d(P, R) ≤ d(P, Q) + d(Q, R)
>    
>    El camino directo es el más corto
> 
> 7. Invariancia por traslación:
>    Si trasladamos ambos puntos igual,
>    la distancia no cambia
> 
> 8. Escalamiento:
>    Si multiplicamos coordenadas por k,
>    distancia se multiplica por |k|
> ```

## 🔷 Punto Medio y División de Segmentos

> [!tip]- Segmentos en el Espacio **Punto medio:**
> 
> ```
> Dados P₁(x₁, y₁, z₁) y P₂(x₂, y₂, z₂)
> 
> Punto medio M:
> M = ((x₁+x₂)/2, (y₁+y₂)/2, (z₁+z₂)/2)
> 
> Fórmula compacta:
> M = (P₁ + P₂)/2
> 
> Interpretación:
> Promedio aritmético de coordenadas
> 
> Verificación:
> d(P₁, M) = d(M, P₂) = d(P₁, P₂)/2
> ```
> 
> **División de segmento en razón:**
> 
> ```
> Punto P que divide P₁P₂ en razón r:s
> (r partes desde P₁, s partes desde P₂)
> 
> P = (s·P₁ + r·P₂)/(r + s)
> 
> Coordenadas:
> x = (s·x₁ + r·x₂)/(r + s)
> y = (s·y₁ + r·y₂)/(r + s)
> z = (s·z₁ + r·z₂)/(r + s)
> 
> Casos especiales:
> 
> r = s = 1: punto medio
> P = (P₁ + P₂)/2
> 
> r = 2, s = 1: divide en 2:1
> P = (P₁ + 2P₂)/3 (más cerca de P₂)
> 
> r = 1, s = 3: divide en 1:3
> P = (3P₁ + P₂)/4 (más cerca de P₁)
> ```
> 
> **Baricentro de triángulo:**
> 
> ```
> Triángulo con vértices A, B, C
> 
> Baricentro G (centro de gravedad):
> G = (A + B + C)/3
> 
> Coordenadas:
> G = ((xₐ+xᵦ+xᶜ)/3, (yₐ+yᵦ+yᶜ)/3, (zₐ+zᵦ+zᶜ)/3)
> 
> Propiedades:
> • Punto de intersección de medianas
> • Divide cada mediana en razón 2:1
> • Centro de masa (densidad uniforme)
> ```
> 
> **Baricentro de tetraedro:**
> 
> ```
> Tetraedro con vértices A, B, C, D
> 
> Baricentro G:
> G = (A + B + C + D)/4
> 
> Promedio de los cuatro vértices
> Centro de masa del tetraedro
> ```

## 📊 Vectores en ℝ³

> [!important]- Representación Vectorial **Vector en el espacio:**
> 
> ```
> Vector v⃗ con componentes:
> v⃗ = (vₓ, vᵧ, vᵤ)
> 
> O en notación de vectores unitarios:
> v⃗ = vₓî + vᵧĵ + vᵤk̂
> 
> donde:
> î = (1, 0, 0) - unitario en X
> ĵ = (0, 1, 0) - unitario en Y
> k̂ = (0, 0, 1) - unitario en Z
> 
> Representación geométrica:
> Flecha desde origen hasta punto (vₓ, vᵧ, vᵤ)
> ```
> 
> **Magnitud de vector:**
> 
> ```
> Norma o módulo:
> |v⃗| = √(vₓ² + vᵧ² + vᵤ²)
> 
> Distancia desde origen al punto terminal
> 
> Propiedades:
> • |v⃗| ≥ 0
> • |v⃗| = 0 ⟺ v⃗ = 0⃗
> • |kv⃗| = |k|·|v⃗|
> ```
> 
> **Operaciones vectoriales:**
> 
> ```
> Suma:
> u⃗ + v⃗ = (uₓ+vₓ, uᵧ+vᵧ, uᵤ+vᵤ)
> 
> Resta:
> u⃗ - v⃗ = (uₓ-vₓ, uᵧ-vᵧ, uᵤ-vᵤ)
> 
> Multiplicación por escalar:
> kv⃗ = (kvₓ, kvᵧ, kvᵤ)
> 
> Vector unitario:
> û = v⃗/|v⃗|
> (dirección de v⃗, magnitud 1)
> ```
> 
> **Producto escalar (dot product):**
> 
> ```
> u⃗ · v⃗ = uₓvₓ + uᵧvᵧ + uᵤvᵤ
> 
> Interpretación geométrica:
> u⃗ · v⃗ = |u⃗||v⃗| cos θ
> 
> donde θ = ángulo entre vectores
> 
> Propiedades:
> • Conmutativo: u⃗ · v⃗ = v⃗ · u⃗
> • Distributivo: u⃗ · (v⃗ + w⃗) = u⃗ · v⃗ + u⃗ · w⃗
> • |v⃗|² = v⃗ · v⃗
> 
> Perpendicularidad:
> u⃗ ⊥ v⃗ ⟺ u⃗ · v⃗ = 0
> 
> Ángulo entre vectores:
> cos θ = (u⃗ · v⃗)/(|u⃗||v⃗|)
> ```
> 
> **Producto vectorial (cross product):**
> 
> ```
> u⃗ × v⃗ = |î  ĵ  k̂ |
>          |uₓ uᵧ uᵤ|
>          |vₓ vᵧ vᵤ|
> 
> Desarrollo:
> u⃗ × v⃗ = (uᵧvᵤ - uᵤvᵧ)î +
>         (uᵤvₓ - uₓvᵤ)ĵ +
>         (uₓvᵧ - uᵧvₓ)k̂
> 
> Componentes:
> (u⃗ × v⃗)ₓ = uᵧvᵤ - uᵤvᵧ
> (u⃗ × v⃗)ᵧ = uᵤvₓ - uₓvᵤ
> (u⃗ × v⃗)ᵤ = uₓvᵧ - uᵧvₓ
> 
> Propiedades:
> • Anticonmutativo: u⃗ × v⃗ = -(v⃗ × u⃗)
> • |u⃗ × v⃗| = |u⃗||v⃗| sen θ
> • u⃗ × v⃗ perpendicular a u⃗ y v⃗
> • Regla de la mano derecha
> 
> Paralelismo:
> u⃗ ∥ v⃗ ⟺ u⃗ × v⃗ = 0⃗
> 
> Área del paralelogramo:
> A = |u⃗ × v⃗|
> ```

## 🧮 Problemas Resueltos

> [!example]- Ejemplos Detallados **Problema 1: Distancia entre puntos**
> 
> ```
> Calcular distancia entre A(1, 2, 3) y B(4, -1, 5)
> 
> SOLUCIÓN:
> 
> Diferencias:
> Δx = 4 - 1 = 3
> Δy = -1 - 2 = -3
> Δz = 5 - 3 = 2
> 
> Distancia:
> d = √[(3)² + (-3)² + (2)²]
> d = √[9 + 9 + 4]
> d = √22 ≈ 4.69 unidades
> ```
> 
> **Problema 2: Punto medio**
> 
> ```
> Encontrar punto medio entre P(2, -3, 5) y Q(6, 1, -1)
> 
> SOLUCIÓN:
> 
> M = ((2+6)/2, (-3+1)/2, (5-1)/2)
> M = (8/2, -2/2, 4/2)
> M = (4, -1, 2)
> 
> Verificación:
> d(P, M) = √[(4-2)² + (-1+3)² + (2-5)²]
>          = √[4 + 4 + 9] = √17
> 
> d(M, Q) = √[(6-4)² + (1+1)² + (-1-2)²]
>          = √[4 + 4 + 9] = √17 ✓
> ```
> 
> **Problema 3: Octante**
> 
> ```
> Determinar en qué octante está el punto P(-2, 3, -4)
> 
> SOLUCIÓN:
> 
> Analizar signos:
> x = -2 < 0 (negativo)
> y = 3 > 0 (positivo)
> z = -4 < 0 (negativo)
> 
> Signos: (-, +, -)
> 
> Corresponde al Octante VI
> ```
> 
> **Problema 4: División de segmento**
> 
> ```
> Punto que divide segmento AB en razón 2:3
> A(1, 2, 3), B(6, 12, 8)
> 
> SOLUCIÓN:
> 
> Razón r:s = 2:3
> 
> P = (s·A + r·B)/(r + s)
> P = (3·A + 2·B)/5
> 
> Componentes:
> x = (3(1) + 2(6))/5 = (3 + 12)/5 = 15/5 = 3
> y = (3(2) + 2(12))/5 = (6 + 24)/5 = 30/5 = 6
> z = (3(3) + 2(8))/5 = (9 + 16)/5 = 25/5 = 5
> 
> P = (3, 6, 5)
> 
> Verificación:
> AP/PB = 2/3
> d(A,P) = √[(3-1)² + (6-2)² + (5-3)²]
>         = √[4 + 16 + 4] = √24 = 2√6
> 
> d(P,B) = √[(6-3)² + (12-6)² + (8-5)²]
>         = √[9 + 36 + 9] = √54 = 3√6
> 
> Razón: 2√6 / 3√6 = 2/3 ✓
> ```
> 
> **Problema 5: Magnitud de vector**
> 
> ```
> Vector v⃗ = (3, -4, 12)
> Calcular su magnitud y vector unitario
> 
> SOLUCIÓN:
> 
> Magnitud:
> |v⃗| = √(3² + (-4)² + 12²)
> |v⃗| = √(9 + 16 + 144)
> |v⃗| = √169 = 13
> 
> Vector unitario:
> û = v⃗/|v⃗| = (3, -4, 12)/13
> û = (3/13, -4/13, 12/13)
> 
> Verificación:
> |û| = √[(3/13)² + (-4/13)² + (12/13)²]
>      = √[(9 + 16 + 144)/169]
>      = √(169/169) = 1 ✓
> ```
> 
> **Problema 6: Producto escalar**
> 
> ```
> u⃗ = (2, -1, 3), v⃗ = (1, 4, -2)
> Calcular u⃗ · v⃗ y ángulo entre ellos
> 
> SOLUCIÓN:
> 
> Producto escalar:
> u⃗ · v⃗ = 2(1) + (-1)(4) + 3(-2)
> u⃗ · v⃗ = 2 - 4 - 6 = -8
> 
> Magnitudes:
> |u⃗| = √(4 + 1 + 9) = √14
> |v⃗| = √(1 + 16 + 4) = √21
> 
> Ángulo:
> cos θ = (u⃗ · v⃗)/(|u⃗||v⃗|)
> cos θ = -8/(√14 · √21)
> cos θ = -8/√294 ≈ -0.466
> 
> θ = arccos(-0.466) ≈ 117.8°
> 
> Ángulo obtuso (>90°), consistente con producto negativo
> ```
> 
> **Problema 7: Producto vectorial**
> 
> ```
> u⃗ = (1, 2, 3), v⃗ = (4, 5, 6)
> Calcular u⃗ × v⃗
> 
> SOLUCIÓN:
> 
> Método del determinante:
> u⃗ × v⃗ = |î  ĵ  k̂|
>          |1  2  3|
>          |4  5  6|
> 
> Componente î:
> î(2·6 - 3·5) = î(12 - 15) = -3î
> 
> Componente ĵ:
> -ĵ(1·6 - 3·4) = -ĵ(6 - 12) = -ĵ(-6) = 6ĵ
> 
> Componente k̂:
> k̂(1·5 - 2·4) = k̂(5 - 8) = -3k̂
> 
> u⃗ × v⃗ = -3î + 6ĵ - 3k̂
> u⃗ × v⃗ = (-3, 6, -3)
> 
> Verificación de perpendicularidad:
> (u⃗ × v⃗) · u⃗ = -3(1) + 6(2) + (-3)(3)
>                = -3 + 12 - 9 = 0 ✓
> 
> (u⃗ × v⃗) · v⃗ = -3(4) + 6(5) + (-3)(6)
>                = -12 + 30 - 18 = 0 ✓
> ```
> 
> **Problema 8: Baricentro de triángulo**
> 
> ```
> Triángulo con vértices:
> A(1, 0, 2), B(3, 4, 1), C(2, -2, 5)
> 
> Calcular baricentro
> 
> SOLUCIÓN:
> 
> G = (A + B + C)/3
> 
> Componentes:
> x = (1 + 3 + 2)/3 = 6/3 = 2
> y = (0 + 4 - 2)/3 = 2/3
> z = (2 + 1 + 5)/3 = 8/3
> 
> G = (2, 2/3,8/3)
> Verificación (distancias a vértices): d(G,A) = √[(2-1)² + (2/3-0)² + (8/3-2)²] = √[1 + 4/9 + 4/9] = √[17/9] = √17/3
> 
> d(G,B) = √[(2-3)² + (2/3-4)² + (8/3-1)²] = √[1 + 100/9 + 25/9] = √[134/9] = √134/3
> 
> (distancias diferentes, correcto para triángulo escaleno)
> ```

## 🔍 Transformaciones en el Espacio

> [!note]- Operaciones Geométricas **Traslación:**
> 
> ```
> Desplazar punto o figura por vector t⃗ = (tₓ, tᵧ, tᵤ)
> 
> P(x, y, z) → P'(x+tₓ, y+tᵧ, z+tᵤ)
> 
> Propiedades:
> • Preserva distancias
> • Preserva ángulos
> • Preserva paralelismo
> • Es una isometría
> 
> Traslación inversa: -t⃗
> ```
> 
> **Reflexión:**
> 
> ```
> Respecto a planos coordenados:
> 
> Plano XY (z=0):
> (x, y, z) → (x, y, -z)
> 
> Plano XZ (y=0):
> (x, y, z) → (x, -y, z)
> 
> Plano YZ (x=0):
> (x, y, z) → (-x, y, z)
> 
> Respecto al origen:
> (x, y, z) → (-x, -y, -z)
> 
> Respecto a un eje:
> Eje X: (x, y, z) → (x, -y, -z)
> Eje Y: (x, y, z) → (-x, y, -z)
> Eje Z: (x, y, z) → (-x, -y, z)
> ```
> 
> **Rotación:**
> 
> ```
> Alrededor del eje Z (ángulo θ):
> x' = x cos θ - y sen θ
> y' = x sen θ + y cos θ
> z' = z
> 
> Alrededor del eje X (ángulo θ):
> x' = x
> y' = y cos θ - z sen θ
> z' = y sen θ + z cos θ
> 
> Alrededor del eje Y (ángulo θ):
> x' = x cos θ + z sen θ
> y' = y
> z' = -x sen θ + z cos θ
> 
> Regla de la mano derecha:
> Pulgar en dirección positiva del eje,
> dedos indican rotación positiva
> ```
> 
> **Escalamiento:**
> 
> ```
> Escalamiento uniforme (factor k):
> (x, y, z) → (kx, ky, kz)
> 
> Escalamiento no uniforme:
> (x, y, z) → (kₓx, kᵧy, kᵤz)
> 
> Efectos:
> • Distancias se multiplican por k
> • Áreas se multiplican por k²
> • Volúmenes se multiplican por k³
> 
> k > 1: ampliación
> 0 < k < 1: reducción
> k < 0: escalamiento + reflexión
> ```
> 
> **Matriz de transformación:**
> 
> ```
> Transformación lineal general:
> 
> [x']   [a₁₁ a₁₂ a₁₃] [x]
> [y'] = [a₂₁ a₂₂ a₂₃] [y]
> [z']   [a₃₁ a₃₂ a₃₃] [z]
> 
> Composición de transformaciones:
> T₂(T₁(P)) = (T₂ ∘ T₁)(P)
> Matriz: M = M₂ × M₁
> ```

## 📐 Ecuaciones Básicas en 3D

> [!important]- Formas Fundamentales **Esfera:**
> 
> ```
> Centro C(h, k, l), radio r:
> 
> (x-h)² + (y-k)² + (z-l)² = r²
> 
> Forma expandida:
> x² + y² + z² + Dx + Ey + Fz + G = 0
> 
> Centro: (-D/2, -E/2, -F/2)
> Radio: √[(D²+E²+F²)/4 - G]
> 
> Esfera unitaria centrada en origen:
> x² + y² + z² = 1
> ```
> 
> **Planos:**
> 
> ```
> Forma general:
> Ax + By + Cz + D = 0
> 
> donde (A, B, C) es vector normal al plano
> 
> Planos coordenados:
> x = 0 (plano YZ)
> y = 0 (plano XZ)
> z = 0 (plano XY)
> 
> Planos paralelos a coordenados:
> x = k (paralelo a YZ)
> y = k (paralelo a XZ)
> z = k (paralelo a XY)
> 
> Interceptos:
> x/a + y/b + z/c = 1
> Intersecta ejes en (a,0,0), (0,b,0), (0,0,c)
> ```
> 
> **Recta en el espacio:**
> 
> ```
> Forma vectorial:
> r⃗(t) = r⃗₀ + tv⃗
> 
> donde r⃗₀ = punto inicial
>       v⃗ = vector director
>       t = parámetro
> 
> Forma paramétrica:
> x = x₀ + tvₓ
> y = y₀ + tvᵧ
> z = z₀ + tvᵤ
> 
> Forma simétrica:
> (x-x₀)/vₓ = (y-y₀)/vᵧ = (z-z₀)/vᵤ
> 
> Dos puntos P₁, P₂:
> r⃗(t) = P₁ + t(P₂ - P₁)
> t ∈ [0,1] para segmento
> t ∈ ℝ para recta completa
> ```
> 
> **Cilindro:**
> 
> ```
> Eje paralelo a Z, radio r:
> x² + y² = r²
> 
> Eje paralelo a X:
> y² + z² = r²
> 
> Eje paralelo a Y:
> x² + z² = r²
> 
> General (eje en cualquier dirección):
> Ecuación más compleja
> ```
> 
> **Cono:**
> 
> ```
> Vértice en origen, eje Z:
> x² + y² = (z tan α)²
> 
> donde α = semiángulo del cono
> 
> Forma general:
> x²/a² + y²/b² = z²/c²
> ```

## 🎯 Sistemas de Coordenadas Alternativos

> [!tip]- Otras Representaciones **Coordenadas cilíndricas:**
> 
> ```
> Extensión de polares al espacio
> 
> (ρ, φ, z)
> 
> donde:
> ρ = distancia al eje Z (radio cilíndrico)
> φ = ángulo azimutal (en plano XY)
> z = altura (coordenada Z)
> 
> Conversión desde cartesianas:
> ρ = √(x² + y²)
> φ = arctan(y/x)
> z = z
> 
> Conversión a cartesianas:
> x = ρ cos φ
> y = ρ sen φ
> z = z
> 
> Rango:
> ρ ≥ 0
> 0 ≤ φ < 2π
> z ∈ ℝ
> 
> Útil para: cilindros, simetría rotacional
> ```
> 
> **Coordenadas esféricas:**
> 
> ```
> (ρ, θ, φ)
> 
> donde:
> ρ = distancia al origen (radio esférico)
> θ = ángulo polar (desde eje Z positivo)
> φ = ángulo azimutal (en plano XY)
> 
> Conversión desde cartesianas:
> ρ = √(x² + y² + z²)
> θ = arccos(z/ρ)
> φ = arctan(y/x)
> 
> Conversión a cartesianas:
> x = ρ sen θ cos φ
> y = ρ sen θ sen φ
> z = ρ cos θ
> 
> Rango:
> ρ ≥ 0
> 0 ≤ θ ≤ π
> 0 ≤ φ < 2π
> 
> Útil para: esferas, física, astronomía
> 
> Relación con geográficas:
> θ = 90° - latitud
> φ = longitud
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes **1. "La distancia en 3D es solo sumar las diferencias"**
> 
> ```
> ✗ FALSO
> 
> NO es: d = |Δx| + |Δy| + |Δz| (distancia Manhattan)
> 
> SÍ es: d = √[(Δx)² + (Δy)² + (Δz)²] (distancia euclidiana)
> 
> La raíz cuadrada es esencial
> ```
> 
> **2. "El producto vectorial es conmutativo"**
> 
> ```
> ✗ FALSO
> 
> u⃗ × v⃗ = -(v⃗ × u⃗)
> 
> Es anticonmutativo, no conmutativo
> El orden importa
> ```
> 
> **3. "Todas las coordenadas positivas = primer octante"**
> 
> ```
> ✓ VERDADERO
> 
> Pero confusión común:
> NO todas las combinaciones de signos
> tienen nombres específicos memorizados
> 
> Solo el primer octante (+,+,+) tiene
> denominación universal
> ```
> 
> **4. "Punto medio = suma de coordenadas"**
> 
> ```
> ✗ FALSO
> 
> NO es: M = P₁ + P₂
> 
> SÍ es: M = (P₁ + P₂)/2
> 
> Hay que dividir entre 2 (promedio)
> ```
> 
> **5. "La magnitud de u⃗ × v⃗ es u⃗ · v⃗"**
> 
> ```
> ✗ FALSO
> 
> |u⃗ × v⃗| = |u⃗||v⃗| sen θ (área del paralelogramo)
> u⃗ · v⃗ = |u⃗||v⃗| cos θ (proyección)
> 
> Son conceptos diferentes
> ```
> 
> **6. "El eje Z siempre va hacia arriba"**
> 
> ```
> ✗ DEPENDE DE LA CONVENCIÓN
> 
> Matemáticas: generalmente Z arriba
> Computación gráfica: a veces Y arriba, Z profundidad
> CAD: varía según software
> 
> Siempre verificar la convención usada
> ```
> 
> **7. "Los octantes se numeran como los cuadrantes"**
> 
> ```
> ✗ NO HAY ESTÁNDAR UNIVERSAL
> 
> Solo el primer octante (+,+,+) está
> universalmente acordado
> 
> La numeración II-VIII varía según fuente
> ```
