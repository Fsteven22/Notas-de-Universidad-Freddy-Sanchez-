# 📊 Graficación en Coordenadas Polares

## 🌟 Concepto Fundamental

> [!info]- Introducción **La graficación en coordenadas polares es el proceso de visualizar ecuaciones de la forma r = f(θ), donde cada punto se determina por su distancia r del origen y su ángulo θ desde el eje polar. A diferencia de las gráficas cartesianas que muestran relaciones y = f(x), las gráficas polares revelan patrones geométricos naturales como espirales, pétalos y bucles.**
> 
> **Características clave:**
> 
> - **Punto de referencia:** El polo (origen)
> - **Dirección:** Ángulos medidos desde el eje polar
> - **Patrones circulares:** Naturalmente simétricos
> - **Interpretación visual:** Geometría intuitiva
> - **Periodicidad:** Muchas curvas se repiten cada 2π

### 📖 Contexto Visual

> [!note]- Por Qué Graficar en Polares **Ventajas sobre coordenadas cartesianas:**
> 
> - Ecuaciones simples para curvas complejas
> - Simetría natural en problemas circulares
> - Patrones de pétalos y espirales fáciles de expresar
> - Movimiento circular y angular intuitivo
> 
> **Ejemplos de simplicidad:**
> 
> ```
> CÍRCULO:
> Cartesiana: x² + y² = a²  (implícita)
> Polar: r = a  (explícita, simple)
> 
> ESPIRAL:
> Cartesiana: √(x² + y²) = a·arctan(y/x)  (compleja)
> Polar: r = aθ  (simple)
> 
> ROSA DE 4 PÉTALOS:
> Cartesiana: (x² + y²)³ = 4x²y²  (compleja)
> Polar: r = sin(2θ)  (simple)
> ```

## 🎯 Sistema de Coordenadas Polares

### Papel Polar

> [!tip]- Grid de Referencia **Estructura del papel polar:**
> 
> ```
> - CÍRCULOS CONCÉNTRICOS: marcan distancias r constantes
> - LÍNEAS RADIALES: marcan ángulos θ constantes
> - ORIGEN: el polo (centro)
> - EJE POLAR: línea horizontal derecha (θ = 0)
> 
>           π/2 (90°)
>             ↑
>             │
>   π ←───────O───────→ 0
>             │
>             ↓
>          3π/2 (270°)
> 
> Círculos: r = 1, 2, 3, ...
> Radios: θ = 0°, 30°, 45°, 60°, 90°, ...
> ```
> 
> **Divisiones comunes:**
> 
> ```
> ÁNGULOS (radianes):
> - Principales: 0, π/6, π/4, π/3, π/2, π, ...
> - Cada 15°: π/12, π/6, π/4, π/3, ...
> 
> RADIOS:
> - Unitarios: 1, 2, 3, 4, ...
> - Subdivisiones: 0.5, 1, 1.5, 2, ...
> ```

### Localización de Puntos

> [!note]- Graficar Puntos Individuales **Proceso para graficar (r, θ):**
> 
> ```
> 1. Ubicar el ángulo θ desde el eje polar
> 2. Medir distancia r desde el origen
> 3. Marcar el punto
> 
> Si r > 0: punto en dirección θ
> Si r < 0: punto en dirección opuesta (θ + π)
> Si r = 0: el polo (independiente de θ)
> ```
> 
> **Ejemplos:**
> 
> ```
> A(2, π/4):
> - Ángulo: 45° desde eje polar
> - Distancia: 2 unidades
> - Ubicación: cuadrante I
> 
> B(3, 2π/3):
> - Ángulo: 120° desde eje polar
> - Distancia: 3 unidades
> - Ubicación: cuadrante II
> 
> C(-2, π/6):
> - r negativo: girar π radianes adicionales
> - Equivalente a (2, 7π/6)
> - Ubicación: cuadrante III
> 
> D(1.5, 5π/4):
> - Ángulo: 225° desde eje polar
> - Distancia: 1.5 unidades
> - Ubicación: cuadrante III
> ```

## 📐 Técnicas de Graficación

### Método por Tabla de Valores

> [!tip]- Construcción Punto por Punto **Procedimiento:**
> 
> ```
> 1. Elegir valores de θ en intervalo relevante
> 2. Calcular r = f(θ) para cada θ
> 3. Graficar cada punto (r, θ)
> 4. Conectar puntos suavemente
> 5. Considerar simetría para completar
> ```
> 
> **Ejemplo: r = 2 + 2cos(θ) (cardioide)**
> 
> ```
> θ      │  0   │ π/6  │ π/4  │ π/3  │ π/2  │ 2π/3 │ 3π/4 │ 5π/6 │  π
> ───────┼──────┼──────┼──────┼──────┼──────┼──────┼──────┼──────┼─────
> cos(θ) │  1   │ √3/2 │ √2/2 │ 1/2  │  0   │ -1/2 │-√2/2 │-√3/2 │ -1
> r      │  4   │ 3.73 │ 3.41 │  3   │  2   │  1   │ 0.59 │ 0.27 │  0
> 
> Puntos clave:
> (4, 0)     - punto más alejado
> (2, π/2)   - punto lateral
> (0, π)     - toca el origen
> 
> Por simetría respecto al eje polar,
> reflejar para π < θ < 2π
> ```
> 
> **Valores estratégicos de θ:**
> 
> ```
> SIEMPRE INCLUIR:
> - θ = 0, π/2, π, 3π/2, 2π (ejes principales)
> - Valores donde r = 0 (curva pasa por origen)
> - Valores donde r alcanza máximos/mínimos
> - Valores donde dr/dθ = 0 (tangentes especiales)
> 
> PARA FUNCIONES TRIGONOMÉTRICAS:
> - Múltiplos de π/n donde n es el coeficiente de θ
> - Ejemplo: r = sin(3θ) → usar θ = 0, π/6, π/3, π/2, ...
> ```

### Análisis Previo a Graficar

> [!important]- Estrategias de Análisis **1. Identificar el tipo de curva:**
> 
> ```
> r = a                    → Círculo
> r = a(1 ± cos θ)        → Cardioide
> r = a ± b cos θ         → Limaçon
> r = a cos(nθ)           → Rosa de n o 2n pétalos
> r = aθ                   → Espiral de Arquímedes
> r² = a² cos(2θ)         → Lemniscata
> ```
> 
> **2. Determinar dominio relevante:**
> 
> ```
> Funciones periódicas:
> - r = sin(nθ), r = cos(nθ) → período π o 2π/n
> - Graficar una vuelta completa
> 
> Espirales:
> - r = aθ → no periódica, elegir intervalo [0, 4π]
> 
> Funciones con raíz cuadrada:
> - r² = f(θ) → solo valores donde f(θ) ≥ 0
> ```
> 
> **3. Analizar simetría:**
> 
> ```
> SIMETRÍA RESPECTO AL EJE POLAR (eje x):
> Si r(θ) = r(-θ)  o  r(θ) = r(2π - θ)
> Ejemplo: r = 1 + cos(θ)
> 
> SIMETRÍA RESPECTO A θ = π/2 (eje y):
> Si r(θ) = r(π - θ)
> Ejemplo: r = 1 + sin(θ)
> 
> SIMETRÍA RESPECTO AL ORIGEN:
> Si r(θ) = -r(θ + π)  o  r(θ) = r(θ + π)
> Ejemplo: r = sin(2θ)
> ```
> 
> **4. Encontrar puntos especiales:**
> 
> ```
> INTERSECCIÓN CON EL POLO:
> Resolver r = 0
> 
> PUNTOS MÁS ALEJADOS:
> Encontrar máximos de r: dr/dθ = 0 y r'' < 0
> 
> PUNTOS MÁS CERCANOS:
> Encontrar mínimos de r: dr/dθ = 0 y r'' > 0
> ```

## 🎨 Curvas Fundamentales

### Círculos

> [!note]- Ecuaciones Circulares **Círculo centrado en el origen:**
> 
> ```
> r = a  (a > 0)
> 
> Características:
> - Radio: a
> - Centro: (0, 0)
> - Todos los puntos equidistantes del origen
> 
> Graficación:
> r es constante para todo θ
> Marcar círculo de radio a
> ```
> 
> **Círculo que pasa por el origen:**
> 
> ```
> r = 2a cos(θ)  (tangente al eje y)
> 
> Características:
> - Diámetro: 2a
> - Centro: (a, 0) en cartesianas
> - Pasa por origen cuando θ = π/2
> 
> Tabla de valores:
> θ  │  0  │ π/6 │ π/4 │ π/3 │ π/2 │ 2π/3│ 3π/4│ 5π/6│  π
> ───┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼────
> r  │ 2a  │√3 a │√2 a │  a  │  0  │ -a  │-√2a │-√3a │-2a
> 
> Dominio efectivo: -π/2 ≤ θ ≤ π/2
> (valores negativos crean mismos puntos)
> ```
> 
> ```
> r = 2a sin(θ)  (tangente al eje x)
> 
> Características:
> - Diámetro: 2a
> - Centro: (0, a) en cartesianas
> - Pasa por origen cuando θ = 0, π
> 
> Dominio efectivo: 0 ≤ θ ≤ π
> ```

### Líneas Rectas

> [!note]- Rectas en Polares **Línea radial (pasa por origen):**
> 
> ```
> θ = α  (α constante)
> 
> Rayo desde el origen con ángulo fijo
> 
> Ejemplos:
> θ = 0     → eje polar (eje x positivo)
> θ = π/4   → diagonal 45°
> θ = π/2   → eje y positivo
> θ = π     → eje x negativo
> ```
> 
> **Rectas verticales y horizontales:**
> 
> ```
> VERTICAL: x = a
> r cos(θ) = a
> r = a sec(θ)
> 
> HORIZONTAL: y = a
> r sin(θ) = a
> r = a csc(θ)
> ```

### Cardioide

> [!important]- Curva en Forma de Corazón **Ecuaciones:**
> 
> ```
> r = a(1 + cos θ)  (simétrica respecto al eje x)
> r = a(1 - cos θ)  (apunta a la izquierda)
> r = a(1 + sin θ)  (simétrica respecto al eje y)
> r = a(1 - sin θ)  (apunta hacia abajo)
> ```
> 
> **Características de r = a(1 + cos θ):**
> 
> ```
> PUNTOS CLAVE:
> θ = 0:    r = 2a  (punto más alejado)
> θ = π/2:  r = a   (punto lateral)
> θ = π:    r = 0   (pasa por origen)
> θ = 3π/2: r = a   (punto lateral)
> θ = 2π:   r = 2a  (regresa al inicio)
> 
> SIMETRÍA: Respecto al eje polar
> 
> ÁREA ENCERRADA: (3/2)πa²
> 
> PERÍMETRO: 8a
> ```
> 
> **Pasos para graficar:**
> 
> ```
> 1. Crear tabla de valores (0 ≤ θ ≤ 2π)
> 2. Identificar punto más alejado (θ = 0: r = 2a)
> 3. Marcar paso por origen (θ = π)
> 4. Usar simetría para completar mitad inferior
> 5. Dibujar curva suave en forma de corazón
> ```

### Limaçon

> [!important]- Familia de Curvas "Caracol" **Ecuación general:**
> 
> ```
> r = a ± b cos(θ)
> r = a ± b sin(θ)
> 
> Clasificación según a/b:
> 
> 1. a/b < 1:  Limaçon con BUCLE INTERIOR
> 2. a/b = 1:  CARDIOIDE (caso especial)
> 3. 1 < a/b < 2:  Limaçon con HENDIDURA
> 4. a/b ≥ 2:  Limaçon CONVEXA (ovalada)
> ```
> 
> **Ejemplo 1: r = 1 + 2cos(θ) (con bucle)**
> 
> ```
> a = 1, b = 2, a/b = 0.5 < 1
> 
> Tabla de valores:
> θ    │  0  │ π/3 │ π/2 │ 2π/3│  π  │ 4π/3│ 3π/2│ 5π/3│ 2π
> ─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼────
> r    │  3  │  2  │  1  │  0  │ -1  │  0  │  1  │  2  │  3
> 
> BUCLE: π/3 < θ < 5π/3 (donde r < 0 o pequeño)
> Punto más alejado: θ = 0, r = 3
> Pasa por origen: θ = 2π/3, 4π/3
> ```
> 
> **Ejemplo 2: r = 2 + cos(θ) (convexa)**
> 
> ```
> a = 2, b = 1, a/b = 2
> 
> Todos los valores r > 0
> Forma ovalada sin bucle ni hendidura
> Siempre positiva: 1 ≤ r ≤ 3
> ```

### Rosas

> [!important]- Curvas de Pétalos **Ecuaciones:**
> 
> ```
> r = a cos(nθ)
> r = a sin(nθ)
> 
> n = número en el argumento
> 
> REGLA DE PÉTALOS:
> - Si n es IMPAR:  n pétalos
> - Si n es PAR:    2n pétalos
> ```
> 
> **Ejemplos:**
> 
> ```
> r = a cos(2θ)  → 4 pétalos
> r = a sin(3θ)  → 3 pétalos
> r = a cos(4θ)  → 8 pétalos
> r = a sin(5θ)  → 5 pétalos
> ```
> 
> **Características de r = a cos(nθ):**
> 
> ```
> LONGITUD DE PÉTALO: a (desde origen hasta punta)
> 
> UBICACIÓN DE PÉTALOS:
> Pétalos donde r = ±a (valores extremos)
> 
> Para r = a cos(2θ):
> θ = 0:     r = a   (pétalo en eje x+)
> θ = π/4:   r = 0   (entre pétalos)
> θ = π/2:   r = -a  (pétalo en eje x-)
> θ = 3π/4:  r = 0   (entre pétalos)
> θ = π:     r = a   (pétalo en eje x+)
> 
> 4 pétalos en θ = 0, π/2, π, 3π/2
> ```
> 
> **Pasos para graficar rosa de n pétalos:**
> 
> ```
> 1. Determinar número de pétalos (n o 2n)
> 2. Encontrar posiciones angulares de pétalos
> 3. Marcar r = 0 (entre pétalos)
> 4. Dibujar cada pétalo desde origen hasta r = a
> 5. Usar simetría para completar
> ```

### Lemniscata

> [!important]- Curva en Forma de ∞ **Ecuaciones:**
> 
> ```
> r² = a² cos(2θ)
> r² = a² sin(2θ)
> 
> Forma de "figura ocho" o símbolo infinito
> ```
> 
> **Características de r² = a² cos(2θ):**
> 
> ```
> DOMINIO: Solo donde cos(2θ) ≥ 0
> - -π/4 ≤ θ ≤ π/4  (bucle derecho)
> - 3π/4 ≤ θ ≤ 5π/4  (bucle izquierdo)
> 
> PUNTOS CLAVE:
> θ = 0:     r = a   (extremo derecho)
> θ = ±π/4:  r = 0   (origen, cruce)
> 
> SIMETRÍA: 
> - Respecto al eje polar
> - Respecto a θ = π/2
> - Respecto al origen
> 
> LONGITUD TOTAL: 4a√2
> ```
> 
> **Graficación:**
> 
> ```
> 1. Identificar dominio válido (cos(2θ) ≥ 0)
> 2. Graficar bucle derecho: -π/4 ≤ θ ≤ π/4
> 3. Graficar bucle izquierdo: 3π/4 ≤ θ ≤ 5π/4
> 4. Ambos bucles se encuentran en el origen
> 5. Forma de ∞ horizontal
> ```

### Espirales

> [!note]- Curvas que se Alejan del Origen **Espiral de Arquímedes:**
> 
> ```
> r = aθ  (a > 0)
> 
> Características:
> - Radio aumenta linealmente con θ
> - Espaciado uniforme entre vueltas
> - Cada vuelta completa (2π) aumenta r en 2πa
> 
> Para graficar:
> θ  │ 0  │ π/4│ π/2│ 3π/4│ π  │ 5π/4│ 3π/2│ 7π/4│ 2π
> ───┼────┼────┼────┼─────┼────┼─────┼─────┼─────┼───
> r  │ 0  │πa/4│πa/2│3πa/4│ πa │5πa/4│3πa/2│7πa/4│2πa
> 
> Continuar para θ > 2π para más vueltas
> ```
> 
> **Espiral logarítmica:**
> 
> ```
> r = ae^(bθ)  (a, b > 0)
> 
> Características:
> - Crecimiento exponencial
> - "Spira mirabilis" de Bernoulli
> - Ángulo constante entre radio y tangente
> - Autosimilar a diferentes escalas
> 
> Propiedades especiales:
> - Aparece en conchas de nautilus
> - Brazos de galaxias espirales
> - θ → -∞: r → 0 (tiende al origen)
> - θ → ∞: r → ∞ (crece sin límite)
> ```
> 
> **Espiral hiperbólica:**
> 
> ```
> r = a/θ  (θ > 0)
> 
> Características:
> - Radio disminuye al aumentar θ
> - θ → ∞: r → 0 (asintótica al origen)
> - θ → 0⁺: r → ∞ (asintótica vertical)
> ```

## 🔍 Técnicas Avanzadas de Graficación

### Análisis de Simetría Detallado

> [!tip]- Uso Eficiente de Simetría **Pruebas algebraicas:**
> 
> ```
> SIMETRÍA RESPECTO AL EJE POLAR:
> Reemplazar θ por -θ:
> Si r(-θ) = r(θ) → simétrica
> 
> Ejemplo: r = 2 + 3cos(θ)
> r(-θ) = 2 + 3cos(-θ) = 2 + 3cos(θ) ✓
> 
> SIMETRÍA RESPECTO A θ = π/2:
> Reemplazar θ por π - θ:
> Si r(π - θ) = r(θ) → simétrica
> 
> Ejemplo: r = 2 + 3sin(θ)
> r(π - θ) = 2 + 3sin(π - θ) = 2 + 3sin(θ) ✓
> 
> SIMETRÍA RESPECTO AL ORIGEN:
> Reemplazar (r, θ) por (-r, θ) o (r, θ + π):
> Si válido → simétrica
> 
> Ejemplo: r² = 4cos(2θ)
> (-r)² = r² → simétrica al origen ✓
> ```
> 
> **Estrategia de graficación con simetría:**
> 
> ```
> 1. Identificar simetrías presentes
> 2. Graficar solo una porción (ej: 0 ≤ θ ≤ π)
> 3. Reflejar según simetrías para completar
> 4. Verificar que la curva es continua
> ```

### Identificación de Intersecciones

> [!important]- Puntos de Cruce **Intersección con el polo (origen):**
> 
> ```
> Resolver: r = 0
> 
> Ejemplo: r = 1 + 2cos(θ)
> 1 + 2cos(θ) = 0
> cos(θ) = -1/2
> θ = 2π/3, 4π/3
> 
> La curva pasa por el origen en estos ángulos
> ```
> 
> **Intersección entre dos curvas:**
> 
> ```
> Método 1: Igualar ecuaciones
> r₁ = r₂  y resolver para θ
> 
> Método 2: Considerar representaciones múltiples
> Un punto (r₁, θ₁) en curva 1 puede ser
> (-r₁, θ₁ + π) en curva 2
> 
> Ejemplo: r = 1 y r = 2cos(θ)
> 1 = 2cos(θ)
> cos(θ) = 1/2
> θ = π/3, 5π/3
> 
> Puntos: (1, π/3) y (1, 5π/3)
> 
> ⚠️ SIEMPRE verificar el polo por separado:
> ¿Ambas curvas pasan por (0, θ) para algún θ?
> ```

### Tangentes y Puntos Críticos

> [!note]- Análisis de Pendiente **Tangentes horizontales y verticales:**
> 
> ```
> dx/dθ = (dr/dθ)cos(θ) - r sin(θ)
> dy/dθ = (dr/dθ)sin(θ) + r cos(θ)
> 
> TANGENTE HORIZONTAL: dy/dθ = 0
> TANGENTE VERTICAL: dx/dθ = 0
> ```
> 
> **Ejemplo: r = 1 + cos(θ)**
> 
> ```
> dr/dθ = -sin(θ)
> 
> Tangente horizontal:
> dy/dθ = -sin(θ)·sin(θ) + (1+cos θ)·cos(θ) = 0
> -sin²(θ) + cos(θ) + cos²(θ) = 0
> cos(2θ) + cos(θ) = 0
> 
> Soluciones numéricas: θ ≈ 2.09, 4.19
> 
> Tangente vertical:
> dx/dθ = -sin(θ)·cos(θ) - (1+cos θ)·sin(θ) = 0
> sin(θ)[-cos(θ) - 1 - cos(θ)] = 0
> sin(θ) = 0  o  cos(θ) = -1/2
> 
> θ = 0, π, 2π/3, 4π/3
> ```

## 🎨 Ejemplos de Graficación Completa

> [!example]- Problemas Resueltos Paso a Paso **Problema 1: Graficar r = 2 - 2sin(θ)**
> 
> ```
> PASO 1: Identificar tipo de curva
> Forma: r = a - b sin(θ) con a = b = 2
> Tipo: Cardioide (a/b = 1)
> Orientación: Apunta hacia abajo (signo negativo)
> 
> PASO 2: Analizar simetría
> r(π - θ) = 2 - 2sin(π - θ) = 2 - 2sin(θ) ✓
> Simétrica respecto a θ = π/2 (eje y)
> 
> PASO 3: Puntos clave
> θ = 0:     r = 2 - 0 = 2
> θ = π/2:   r = 2 - 2 = 0  (pasa por origen)
> θ = π:     r = 2 - 0 = 2
> θ = 3π/2:  r = 2 + 2 = 4  (punto más alejado)
> 
> PASO 4: Tabla de valores
> θ    │  0  │ π/6 │ π/3 │ π/2 │ 2π/3│ 5π/6│  π  │ 7π/6│ 4π/3│ 3π/2
> ─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────
> r    │  2  │ 1   │0.27 │  0  │0.27 │  1  │  2  │  3  │3.73 │  4
> 
> PASO 5: Graficar
> - Marcar puntos de la tabla
> - Forma de corazón apuntando hacia abajo
> - Pasa por origen en θ = π/2
> - Punto más alejado en θ = 3π/2, r = 4
> 
> RESPUESTA: Cardioide con cúspide en (0, π/2)
> y punto más alejado en (4, 3π/2)
> ```
> 
> **Problema 2: Graficar r = 3sin(2θ)**
> 
> ```
> PASO 1: Identificar tipo
> Forma: r = a sin(nθ) con a = 3, n = 2
> Tipo: Rosa de 2n = 4 pétalos (n par)
> 
> PASO 2: Analizar período
> Período de sin(2θ): 2π/2 = π
> Pero r puede ser negativo, considerar [0, 2π]
> 
> PASO 3: Encontrar pétalos
> r = máximo (±3) cuando sin(2θ) = ±1
> 2θ = π/2, 3π/2, 5π/2, 7π/2
> θ = π/4, 3π/4, 5π/4, 7π/4
> 
> r = 0 cuando sin(2θ) = 0
> 2θ = 0, π, 2π, 3π, 4π
> θ = 0, π/2, π, 3π/2, 2π
> 
> PASO 4: Tabla de valores
> θ    │ 0 │ π/8│ π/4│ 3π/8│ π/2│ 5π/8│ 3π/4│ 7π/8│ π

## 🔄 Transformaciones de Curvas

> [!tip]- Efectos de Modificaciones en Ecuaciones **Multiplicar r por constante k:**
> 
> ```
> r = f(θ)  →  r = k·f(θ)
> 
> Efecto: Escala radial (dilatación/contracción)
> k > 1: agranda la curva
> 0 < k < 1: reduce la curva
> k < 0: refleja respecto al origen
> 
> Ejemplo:
> r = 2cos(θ)  →  r = 4cos(θ)
> Radio duplicado, curva más grande
> ```
> 
> **Multiplicar θ por constante n:**
> 
> ```
> r = f(θ)  →  r = f(nθ)
> 
> Efecto: Cambia frecuencia angular
> n > 1: aumenta número de repeticiones
> 0 < n < 1: reduce número de repeticiones
> 
> Ejemplo:
> r = cos(θ)  →  r = cos(3θ)
> Círculo → Rosa de 3 pétalos
> ```
> 
> **Sumar/restar constante a r:**
> 
> ```
> r = f(θ)  →  r = f(θ) + c
> 
> Efecto: Desplazamiento radial
> c > 0: aleja del origen
> c < 0: acerca al origen
> 
> Ejemplo:
> r = cos(θ)  →  r = 1 + cos(θ)
> Círculo → Cardioide
> ```
> 
> **Sumar/restar constante a θ:**
> 
> ```
> r = f(θ)  →  r = f(θ - α)
> 
> Efecto: Rotación de la curva
> α > 0: rotación antihoraria
> α < 0: rotación horaria
> 
> Ejemplo:
> r = cos(θ)  →  r = cos(θ - π/4)
> Círculo rotado 45°
> ```

## ⚠️ Errores Comunes

> [!warning]- Equivocaciones Frecuentes **1. Olvidar valores negativos de r:**
> 
> ```
> ✗ Ignorar puntos donde r < 0
> 
> ✓ r < 0 significa dirección opuesta
>   Graficar en θ + π con |r|
> 
> Ejemplo: r = -2 en θ = π/4
> Equivalente a r = 2 en θ = 5π/4
> ```
> 
> **2. Dominio incorrecto:**
> 
> ```
> ✗ Para r² = a²cos(2θ), usar 0 ≤ θ ≤ 2π
> 
> ✓ Solo donde cos(2θ) ≥ 0
>   Dominios: [-π/4, π/4] ∪ [3π/4, 5π/4]
> ```
> 
> **3. Contar mal los pétalos:**
> 
> ```
> ✗ r = cos(4θ) tiene 4 pétalos
> 
> ✓ n par → 2n pétalos
>   r = cos(4θ) tiene 8 pétalos
> ```
> 
> **4. No usar simetría:**
> 
> ```
> ✗ Calcular todos los puntos manualmente
> 
> ✓ Identificar simetría primero
>   Graficar una porción y reflejar
>   Ahorra tiempo y evita errores
> ```
> 
> **5. Escala inconsistente:**
> 
> ```
> ✗ Usar diferentes escalas en r para distintas partes
> 
> ✓ Mantener escala uniforme
>   Marcar círculos concéntricos claramente
> ```
> 
> **6. Conectar puntos incorrectamente:**
> 
> ```
> ✗ Unir puntos con líneas rectas
> 
> ✓ Curvas suaves y continuas
>   Considerar comportamiento entre puntos
> ```
> 
> **7. No verificar paso por el origen:**
> 
> ```
> ✗ Asumir que curva no pasa por origen
> 
> ✓ Siempre resolver r = 0
>   Marcar ángulos donde ocurre
> ```

## 📐 Intersecciones y Áreas

> [!important]- Cálculos con Múltiples Curvas **Encontrar intersecciones:**
> 
> ```
> Método algebraico:
> 1. Igualar r₁(θ) = r₂(θ)
> 2. Resolver para θ
> 3. Calcular r correspondiente
> 4. VERIFICAR el polo por separado
> 
> Ejemplo: r = 2 y r = 4sin(θ)
> 2 = 4sin(θ)
> sin(θ) = 1/2
> θ = π/6, 5π/6
> 
> Puntos: (2, π/6) y (2, 5π/6)
> 
> Verificar polo:
> r = 2: nunca es 0
> r = 4sin(θ): r = 0 cuando θ = 0, π
> No hay intersección en el polo
> ```
> 
> **Área entre dos curvas:**
> 
> ```
> Si r₁(θ) ≤ r₂(θ) en [α, β]:
> 
>      β
>     ⌠  1
> A = │  ─ [r₂² - r₁²] dθ
>     ⌡  2
>      α
> 
> Ejemplo: Área entre r = 2 y r = 1 + cos(θ)
> 
> Intersecciones: cos(θ) = 1 → θ = 0, 2π
> 
> Para 0 < θ < π: r = 2 está afuera
> 
>      2π
>     ⌠  1
> A = │  ─ [4 - (1+cos θ)²] dθ
>     ⌡  2
>      0
> 
>   = ½∫₀²π [3 - 2cos θ - cos²θ] dθ
>   = 5π/2
> ```

## 📝 Resumen Ejecutivo

> [!important]- Puntos Clave **Proceso de graficación:**
> 
> - **Identificar tipo:** Reconocer patrón (círculo, rosa, cardioide, etc.)
> - **Analizar simetría:** Reduce trabajo a la mitad o más
> - **Dominio relevante:** Especialmente para r², verificar validez
> - **Puntos críticos:** r = 0, máximos, mínimos, tangentes
> - **Tabla de valores:** Elegir θ estratégicamente
> 
> **Curvas fundamentales:**
> 
> - **Círculos:** r = a, r = 2a cos(θ), r = 2a sin(θ)
> - **Cardioide:** r = a(1 ± cos θ), forma de corazón
> - **Limaçon:** r = a ± b cos(θ), clasificación por a/b
> - **Rosa:** r = a cos(nθ), n o 2n pétalos
> - **Lemniscata:** r² = a² cos(2θ), forma de ∞
> - **Espirales:** r = aθ, r = ae^(bθ)
> 
> **Técnicas especiales:**
> 
> - **r negativo:** punto en dirección opuesta (θ + π)
> - **Simetría:** Usar para completar gráfica eficientemente
> - **Período:** Determina intervalo mínimo a graficar
> - **Intersecciones:** Resolver algebraicamente + verificar polo
> 
> **Errores a evitar:**
> 
> - Olvidar valores negativos de r
> - Dominio incorrecto (especialmente con r²)
> - Contar mal pétalos (n par → 2n pétalos)
> - No usar simetría disponible
> - Escala inconsistente
