# 🌀 Coordenadas Polares

## 🌟 Concepto Fundamental

> [!info]- Introducción **Las coordenadas polares son un sistema de coordenadas bidimensional que localiza puntos mediante una distancia desde el origen y un ángulo respecto a un eje de referencia. A diferencia del sistema cartesiano que usa (x, y), el sistema polar usa (r, θ) donde r es el radio y θ es el ángulo.**
> 
> **Características clave:**
> 
> - **Radio (r):** Distancia desde el origen al punto
> - **Ángulo (θ):** Ángulo medido desde el eje polar (eje x positivo)
> - **Origen:** Llamado "polo"
> - **Eje polar:** Eje de referencia (usualmente eje x positivo)
> - **Representación múltiple:** Un punto puede tener infinitas coordenadas polares

### 📖 Contexto Histórico

> [!note]- Desarrollo Histórico **Orígenes antiguos (150 d.C. - 1600):**
> 
> - **Hiparco y Ptolomeo:** Tablas trigonométricas con ángulos
> - Astronomía: posiciones celestes con ángulos y distancias
> - No formalizado como sistema de coordenadas
> 
> **Desarrollo formal (1600-1700):**
> 
> - **Bonaventura Cavalieri (1635):** Ideas preliminares
> - **Gregoire de Saint-Vincent (1647):** Uso de ángulos y distancias
> - **Isaac Newton (1671):** Coordenadas polares para espirales
> - Método Fluxionum: utiliza coordenadas polares
> 
> **Formalización (1700-1800):**
> 
> - **Jakob Bernoulli (1691):** Publicación formal del sistema
> - Introduce término "coordenadas polares"
> - Estudia la espiral logarítmica: r = ae^(bθ)
> - **Leonhard Euler (1748):** Notación moderna (r, θ)
> - Desarrolla conversiones con coordenadas cartesianas
> 
> **Era moderna (1800-presente):**
> 
> - Integración en cálculo y análisis
> - Aplicaciones en física: movimiento circular
> - Ecuaciones diferenciales en coordenadas polares
> - Análisis complejo: forma polar de números complejos
> - Ingeniería: radar, navegación, robótica

## 📐 Definición y Notación

> [!success]- Sistema de Coordenadas Polares **Definición:**
> 
> ```
> Un punto P en el plano se representa por el par ordenado (r, θ):
> 
> r = distancia dirigida desde el polo (origen) hasta P
> θ = ángulo dirigido desde el eje polar hasta OP
> 
> Notación: P(r, θ)
> ```
> 
> **Elementos del sistema:**
> 
> ```
> POLO (O): Origen del sistema (análogo al origen cartesiano)
> 
> EJE POLAR: Rayo horizontal desde O hacia la derecha
>            (análogo al eje x positivo)
> 
> RADIO (r): Distancia desde O hasta P
>            r ∈ ℝ (puede ser negativa)
>            r ≥ 0 convencionalmente
> 
> ÁNGULO (θ): Medido desde el eje polar
>             Positivo: sentido antihorario (contrario a las agujas)
>             Negativo: sentido horario
>             θ ∈ ℝ (cualquier valor real)
> ```
> 
> **Convenciones:**
> 
> ```
> ÁNGULOS:
> - Radianes: medida preferida (0 ≤ θ < 2π)
> - Grados: alternativa (0° ≤ θ < 360°)
> - Ángulos coterminales: θ y θ + 2πk (k ∈ ℤ)
> 
> RADIO:
> - r > 0: punto en dirección del ángulo θ
> - r < 0: punto en dirección opuesta (θ + π)
> - r = 0: el polo (independiente de θ)
> ```
> 
> **Representación visual:**
> 
> ```
>         ↑ π/2 (90°)
>         │
>         │     P(r,θ)
>         │    /
>         │   /
>         │  / r
>         │ /
>         │/θ
> π ──────O───────→ 0 (eje polar)
>         │
>         │
>         │
>       3π/2 (270°)
> ```

## 🔄 Conversión entre Sistemas

### De Polares a Cartesianas

> [!important]- Fórmulas Fundamentales **Conversión (r, θ) → (x, y):**
> 
> ```
> x = r cos(θ)
> y = r sin(θ)
> 
> Donde:
> - (r, θ) son las coordenadas polares
> - (x, y) son las coordenadas cartesianas
> ```
> 
> **Demostración geométrica:**
> 
> ```
> En triángulo rectángulo formado por P, O y proyección:
> 
>         P(r,θ)
>        /|
>       / |
>    r /  | y = r sin(θ)
>     /   |
>    /θ   |
>   O─────┘
>   x = r cos(θ)
> 
> cos(θ) = x/r  →  x = r cos(θ)
> sin(θ) = y/r  →  y = r sin(θ)
> ```
> 
> **Ejemplos:**
> 
> ```
> 1) (r, θ) = (5, π/3)
>    x = 5 cos(π/3) = 5 · (1/2) = 2.5
>    y = 5 sin(π/3) = 5 · (√3/2) = 2.5√3 ≈ 4.33
>    Cartesianas: (2.5, 2.5√3)
> 
> 2) (r, θ) = (3, π/4)
>    x = 3 cos(π/4) = 3 · (√2/2) = 3√2/2
>    y = 3 sin(π/4) = 3 · (√2/2) = 3√2/2
>    Cartesianas: (3√2/2, 3√2/2)
> 
> 3) (r, θ) = (4, π)
>    x = 4 cos(π) = 4 · (-1) = -4
>    y = 4 sin(π) = 4 · 0 = 0
>    Cartesianas: (-4, 0)
> 
> 4) (r, θ) = (-2, π/6)
>    x = -2 cos(π/6) = -2 · (√3/2) = -√3
>    y = -2 sin(π/6) = -2 · (1/2) = -1
>    Cartesianas: (-√3, -1)
> ```

### De Cartesianas a Polares

> [!important]- Fórmulas de Conversión Inversa **Conversión (x, y) → (r, θ):**
> 
> ```
> r = ±√(x² + y²)
> 
> θ = arctan(y/x)  (con ajustes según cuadrante)
> 
> Alternativamente:
> θ = atan2(y, x)  (función que considera cuadrantes)
> ```
> 
> **Determinación del ángulo θ:**
> 
> ```
> CUADRANTE I (x > 0, y > 0):
> θ = arctan(y/x)
> 
> CUADRANTE II (x < 0, y > 0):
> θ = π + arctan(y/x)  o  θ = π - arctan(|y|/|x|)
> 
> CUADRANTE III (x < 0, y < 0):
> θ = π + arctan(y/x)  o  θ = π + arctan(|y|/|x|)
> 
> CUADRANTE IV (x > 0, y < 0):
> θ = 2π + arctan(y/x)  o  θ = -arctan(|y|/x)
> 
> CASOS ESPECIALES:
> x = 0, y > 0:  θ = π/2
> x = 0, y < 0:  θ = 3π/2
> x > 0, y = 0:  θ = 0
> x < 0, y = 0:  θ = π
> ```
> 
> **Tabla de referencia:**
> 
> ```
> Cuadrante │  x   │  y   │     θ (rango)
> ──────────┼──────┼──────┼──────────────────
>     I     │  +   │  +   │  0 < θ < π/2
>    II     │  -   │  +   │  π/2 < θ < π
>   III     │  -   │  -   │  π < θ < 3π/2
>    IV     │  +   │  -   │  3π/2 < θ < 2π
> ```
> 
> **Ejemplos:**
> 
> ```
> 1) (x, y) = (3, 4)
>    r = √(3² + 4²) = √25 = 5
>    θ = arctan(4/3) ≈ 0.927 rad ≈ 53.13°
>    Polares: (5, 0.927)
> 
> 2) (x, y) = (-3, 4)
>    r = √(9 + 16) = 5
>    θ = π - arctan(4/3) ≈ π - 0.927 ≈ 2.214 rad
>    Polares: (5, 2.214)
> 
> 3) (x, y) = (-1, -√3)
>    r = √(1 + 3) = 2
>    θ = π + arctan(√3/1) = π + π/3 = 4π/3
>    Polares: (2, 4π/3)
> 
> 4) (x, y) = (0, 5)
>    r = 5
>    θ = π/2
>    Polares: (5, π/2)
> ```

## 🎯 Representación Múltiple

> [!warning]- No Unicidad de Coordenadas Polares **Un punto tiene infinitas representaciones:**
> 
> ```
> El punto P puede representarse como:
> 
> (r, θ)
> (r, θ + 2πk)  para cualquier k ∈ ℤ
> (-r, θ + π + 2πk)  para cualquier k ∈ ℤ
> ```
> 
> **Ejemplos de representaciones equivalentes:**
> 
> ```
> El punto (2, π/4) también puede escribirse como:
> 
> (2, π/4 + 2π) = (2, 9π/4)
> (2, π/4 - 2π) = (2, -7π/4)
> (-2, π/4 + π) = (-2, 5π/4)
> (-2, π/4 - π) = (-2, -3π/4)
> 
> Todas representan el mismo punto
> ```
> 
> **El polo (origen):**
> 
> ```
> (0, θ) para cualquier θ
> 
> El polo se puede escribir como:
> (0, 0), (0, π), (0, π/2), (0, 5.7), etc.
> 
> El ángulo es irrelevante cuando r = 0
> ```
> 
> **Convención estándar:**
> 
> ```
> Para unicidad, se suele usar:
> r ≥ 0  y  0 ≤ θ < 2π
> 
> o bien:
> r > 0  y  -π < θ ≤ π
> ```

## 📊 Gráficas en Coordenadas Polares

### Curvas Básicas

> [!note]- Ecuaciones Polares Fundamentales **Círculo centrado en el origen:**
> 
> ```
> r = a  (a > 0)
> 
> Todos los puntos a distancia a del origen
> 
> Ejemplo: r = 3
> Círculo de radio 3
> ```
> 
> **Línea radial (rayo desde el origen):**
> 
> ```
> θ = α  (constante)
> 
> Todos los puntos con ángulo α
> 
> Ejemplo: θ = π/4
> Recta a 45° del eje polar
> ```
> 
> **Círculo que pasa por el origen:**
> 
> ```
> r = 2a cos(θ)  (círculo tangente al eje y)
> r = 2a sin(θ)  (círculo tangente al eje x)
> 
> Centro en (a, 0) o (0, a) en cartesianas
> Radio: a
> ```
> 
> **Espiral de Arquímedes:**
> 
> ```
> r = aθ  (a > 0)
> 
> Radio aumenta proporcionalmente al ángulo
> 
> Ejemplo: r = θ
> ```
> 
> **Espiral logarítmica:**
> 
> ```
> r = ae^(bθ)
> 
> Crecimiento exponencial con el ángulo
> "Spira mirabilis" de Jakob Bernoulli
> ```

### Curvas Especiales

> [!important]- Rosas, Limaçons y Lemniscatas **Rosas (pétalos):**
> 
> ```
> r = a cos(nθ)
> r = a sin(nθ)
> 
> n pétalos si n es impar
> 2n pétalos si n es par
> 
> Ejemplos:
> r = cos(2θ)  →  4 pétalos
> r = cos(3θ)  →  3 pétalos
> r = sin(5θ)  →  5 pétalos
> ```
> 
> **Cardioide:**
> 
> ```
> r = a(1 + cos(θ))
> r = a(1 + sin(θ))
> 
> Forma de corazón
> Caso especial de limaçon con a = b
> ```
> 
> **Limaçon (caracol):**
> 
> ```
> r = a + b cos(θ)
> r = a + b sin(θ)
> 
> Clasificación:
> a/b < 1:  con bucle interior
> a/b = 1:  cardioide
> 1 < a/b < 2:  con hendidura
> a/b ≥ 2:  convexa
> ```
> 
> **Lemniscata de Bernoulli:**
> 
> ```
> r² = a² cos(2θ)
> r² = a² sin(2θ)
> 
> Forma de ∞ (infinito)
> Similar a figura de 8
> ```

## 🔍 Simetría en Coordenadas Polares

> [!tip]- Pruebas de Simetría **Simetría respecto al eje polar (eje x):**
> 
> ```
> Si al reemplazar θ por -θ la ecuación no cambia:
> r(θ) = r(-θ)
> 
> La curva es simétrica respecto al eje x
> 
> Ejemplo: r = 1 + cos(θ)
> r(-θ) = 1 + cos(-θ) = 1 + cos(θ) ✓
> ```
> 
> **Simetría respecto al eje θ = π/2 (eje y):**
> 
> ```
> Si al reemplazar θ por π - θ la ecuación no cambia:
> r(θ) = r(π - θ)
> 
> La curva es simétrica respecto al eje y
> 
> Ejemplo: r = 1 + sin(θ)
> r(π - θ) = 1 + sin(π - θ) = 1 + sin(θ) ✓
> ```
> 
> **Simetría respecto al origen:**
> 
> ```
> Si al reemplazar (r, θ) por (-r, θ) o (r, θ + π)
> la ecuación no cambia:
> 
> r(θ) = -r(θ)  o  r(θ) = r(θ + π)
> 
> Ejemplo: r² = cos(2θ)
> Simétrica respecto al origen
> ```

## 📏 Distancia entre Puntos

> [!important]- Fórmula de Distancia **Entre dos puntos polares:**
> 
> ```
> P₁(r₁, θ₁)  y  P₂(r₂, θ₂)
> 
> d = √[r₁² + r₂² - 2r₁r₂ cos(θ₂ - θ₁)]
> 
> Ley de cosenos en el triángulo formado
> ```
> 
> **Casos especiales:**
> 
> ```
> 1) Mismo ángulo (θ₁ = θ₂):
>    d = |r₂ - r₁|
> 
> 2) Ángulos opuestos (θ₂ - θ₁ = π):
>    d = r₁ + r₂
> 
> 3) Ángulos perpendiculares (θ₂ - θ₁ = π/2):
>    d = √(r₁² + r₂²)
> ```
> 
> **Ejemplo:**
> 
> ```
> P₁(3, π/4)  y  P₂(5, π/3)
> 
> θ₂ - θ₁ = π/3 - π/4 = π/12
> 
> d = √[9 + 25 - 2(3)(5)cos(π/12)]
>   = √[34 - 30cos(π/12)]
>   = √[34 - 30(0.9659)]
>   ≈ √[34 - 28.977]
>   ≈ √5.023
>   ≈ 2.24
> ```

## 🎨 Área en Coordenadas Polares

> [!important]- Cálculo de Áreas **Área de sector circular:**
> 
> ```
> Para curva r = f(θ) entre θ = α y θ = β:
> 
>      β
>     ⌠  1
> A = │  ─ r² dθ
>     ⌡  2
>      α
> 
> Interpretación: suma de infinitos sectores circulares
> ```
> 
> **Área entre dos curvas:**
> 
> ```
> Si r₁(θ) ≤ r₂(θ) en [α, β]:
> 
>      β
>     ⌠  1
> A = │  ─ [r₂² - r₁²] dθ
>     ⌡  2
>      α
> ```
> 
> **Ejemplos:**
> 
> ```
> 1) Área del círculo r = a:
>    
>     2π
>    ⌠  1
> A =│  ─ a² dθ = ½a²[θ]₀²π = πa²  ✓
>    ⌡  2
>     0
> 
> 2) Área de un pétalo de r = cos(2θ):
>    Un pétalo: -π/4 ≤ θ ≤ π/4
>    
>     π/4
>    ⌠  1
> A =│  ─ cos²(2θ) dθ = π/8
>    ⌡  2
>    -π/4
> 
> 3) Área de cardioide r = 1 + cos(θ):
>    
>     2π
>    ⌠  1
> A =│  ─ (1 + cos θ)² dθ
>    ⌡  2
>     0
>   
>   = ½ ∫₀²π (1 + 2cosθ + cos²θ) dθ
>   = 3π/2
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes **1. Confundir ángulos en grados y radianes:**
> 
> ```
> ✗ (2, 90) asumiendo 90 radianes
> 
> ✓ Especificar unidad: (2, 90°) o (2, π/2)
>   En cálculo siempre usar radianes
> ```
> 
> **2. Olvidar que r puede ser negativo:**
> 
> ```
> ✗ r siempre positivo
> 
> ✓ r < 0 significa dirección opuesta
>   (-3, π/4) = (3, 5π/4)
> ```
> 
> **3. Ignorar representaciones múltiples:**
> 
> ```
> ✗ (2, π/3) es única representación
> 
> ✓ (2, π/3) = (2, π/3 + 2π) = (-2, 4π/3) = ...
> ```
> 
> **4. Error en conversión de cuadrantes:**
> 
> ```
> Para (x,y) = (-3, 4):
> 
> ✗ θ = arctan(4/-3) = arctan(-4/3) ≈ -0.927
>   (Esto da cuadrante IV, no II)
> 
> ✓ θ = π - arctan(4/3) ≈ 2.214 rad
>   (Cuadrante II correcto)
> ```
> 
> **5. Área con límites incorrectos:**
> 
> ```
> Para cardioide completa r = 1 + cos(θ):
> 
> ✗ Integrar de 0 a π (solo mitad)
> 
> ✓ Integrar de 0 a 2π (curva completa)
> ```

## 🧮 Ejemplos Completos

> [!example]- Problemas Resueltos **Problema 1: Conversión de coordenadas**
> 
> ```
> Convertir (x, y) = (√3, 1) a polares
> 
> SOLUCIÓN:
> 
> Paso 1: Calcular r
> r = √(x² + y²) = √[(√3)² + 1²]
>   = √(3 + 1) = √4 = 2
> 
> Paso 2: Determinar cuadrante
> x = √3 > 0, y = 1 > 0  →  Cuadrante I
> 
> Paso 3: Calcular θ
> tan(θ) = y/x = 1/√3
> θ = arctan(1/√3) = π/6
> 
> RESPUESTA: (r, θ) = (2, π/6) o (2, 30°)
> 
> Verificación:
> x = 2cos(π/6) = 2(√3/2) = √3 ✓
> y = 2sin(π/6) = 2(1/2) = 1 ✓
> ```
> 
> **Problema 2: Identificar curva polar**
> 
> ```
> Identificar la curva r = 4sin(θ)
> 
> SOLUCIÓN:
> 
> Método 1: Convertir a cartesianas
> r = 4sin(θ)
> 
> Multiplicar ambos lados por r:
> r² = 4r sin(θ)
> 
> Sustituir r² = x² + y² y r sin(θ) = y:
> x² + y² = 4y
> 
> Completar cuadrado:
> x² + y² - 4y = 0
> x² + (y² - 4y + 4) = 4
> x² + (y - 2)² = 4
> 
> RESPUESTA: Círculo con centro (0, 2) y radio 2
> 
> Características:
> - Pasa por el origen (cuando θ = 0, r = 0)
> - Diámetro = 4
> - Centro en el eje y
> ```
> 
> **Problema 3: Calcular área de región**
> 
> ```
> Calcular área encerrada por r = 2 + 2cos(θ)
> 
> SOLUCIÓN:
> 
> Esta es una cardioide (a = b = 2)
> 
> Paso 1: Identificar límites
> Curva completa: 0 ≤ θ ≤ 2π
> 
> Paso 2: Plantear integral
>      2π
>     ⌠  1
> A = │  ─ r² dθ
>     ⌡  2
>      0
> 
>      2π
>     ⌠  1
>   = │  ─ (2 + 2cos θ)² dθ
>     ⌡  2
>      0
> 
> Paso 3: Expandir
> (2 + 2cos θ)² = 4 + 8cos θ + 4cos²θ
> 
> Usar identidad: cos²θ = (1 + cos(2θ))/2
> = 4 + 8cos θ + 2(1 + cos(2θ))
> = 6 + 8cos θ + 2cos(2θ)
> 
> Paso 4: Integrar
>      2π
>     ⌠  1
> A = │  ─ [6 + 8cos θ + 2cos(2θ)] dθ
>     ⌡  2
>      0
> 
>   = ½[6θ + 8sin θ + sin(2θ)]₀²π
> 
>   = ½[(12π + 0 + 0) - (0 + 0 + 0)]
> 
>   = 6π
> 
> RESPUESTA: A = 6π unidades cuadradas
> ```
> 
> **Problema 4: Intersección de curvas**
> 
> ```
> Encontrar puntos de intersección de:
> r = 1 + cos(θ)  y  r = 1
> 
> SOLUCIÓN:
> 
> Paso 1: Igualar ecuaciones
> 1 + cos(θ) = 1
> cos(θ) = 0
> 
> Paso 2: Resolver para θ
> θ = π/2  o  θ = 3π/2
> 
> Paso 3: Encontrar puntos
> Para θ = π/2:
> r = 1  →  Punto (1, π/2)
> 
> Para θ = 3π/2:
> r = 1  →  Punto (1, 3π/2)
> 
> Paso 4: Verificar el polo
> Cardioide pasa por origen cuando:
> 1 + cos(θ) = 0
> cos(θ) = -1
> θ = π  →  Punto (0, π)
> 
> Círculo r = 1 nunca pasa por origen ✗
> 
> RESPUESTA: Dos puntos de intersección:
> (1, π/2) y (1, 3π/2)
> 
> En cartesianas:
> (0, 1) y (0, -1)
> ```

## 💡 Aplicaciones Prácticas

> [!example]- Contextos Reales **Navegación y aviación:**
> 
> ```
> - Posición de aeronaves: distancia y rumbo desde torre
> - Sistemas de radar: detectan objetos en (r, θ)
> - GPS: usa coordenadas esféricas (extensión 3D)
> - Navegación marítima: distancia y bearing
> ```
> 
> **Astronomía:**
> 
> ```
> - Posiciones celestes: ascensión recta y declinación
> - Órbitas planetarias: descritas naturalmente en polares
> - Telescopios: monturas ecuatoriales usan coordenadas polares
> - Mapas estelares: proyecciones polares
> ```
> 
> **Ingeniería:**
>

## 📐 Tangentes en Coordenadas Polares

> [!important]- Pendiente de Curvas Polares **Fórmula de la tangente:**
> 
> ```
> Para curva r = f(θ), la pendiente de la recta tangente es:
> 
>      dy   dr
>      ── = ── sin(θ) + r cos(θ)
>      dx   dθ
>      ── = ──────────────────────
>      dθ   dr
>           ── cos(θ) - r sin(θ)
>           dθ
> 
> Donde dr/dθ es la derivada de r respecto a θ
> ```
> 
> **Tangentes horizontales:**
> 
> ```
> Ocurren cuando dy/dθ = 0 (y dx/dθ ≠ 0)
> 
> dr
> ── sin(θ) + r cos(θ) = 0
> dθ
> ```
> 
> **Tangentes verticales:**
> 
> ```
> Ocurren cuando dx/dθ = 0 (y dy/dθ ≠ 0)
> 
> dr
> ── cos(θ) - r sin(θ) = 0
> dθ
> ```
> 
> **Ejemplo:**
> 
> ```
> Para cardioide r = 1 + cos(θ)
> 
> dr/dθ = -sin(θ)
> 
> Tangentes horizontales:
> -sin(θ)·sin(θ) + (1 + cos θ)·cos(θ) = 0
> -sin²(θ) + cos(θ) + cos²(θ) = 0
> cos(2θ) + cos(θ) = 0
> 
> Soluciones: θ = 2π/3, 4π/3
> 
> Tangentes verticales:
> -sin(θ)·cos(θ) - (1 + cos θ)·sin(θ) = 0
> -sin(θ)[cos(θ) + 1 + cos(θ)] = 0
> -sin(θ)[2cos(θ) + 1] = 0
> 
> Soluciones: θ = 0, π, 2π/3, 4π/3
> ```

## 🔄 Longitud de Arco

> [!important]- Cálculo de Longitud **Fórmula de longitud de arco:**
> 
> ```
> Para curva r = f(θ) entre θ = α y θ = β:
> 
>      β    ┌─────────────────
>     ⌠     │      2  ⎛dr⎞²
> L = │   ╲╱  r²(θ) + ⎜──⎟  dθ
>     ⌡               ⎝dθ⎠
>      α
> ```
> 
> **Derivación:**
> 
> ```
> Elemento de longitud:
> ds = √[(dx)² + (dy)²]
> 
> En polares:
> dx = cos(θ)dr - r sin(θ)dθ
> dy = sin(θ)dr + r cos(θ)dθ
> 
> (ds)² = (dr)² + r²(dθ)²
> 
>        ┌─────────────────
>       │      2  ⎛dr⎞²
> ds = ╲╱  r²(θ) + ⎜──⎟  dθ
>                  ⎝dθ⎠
> ```
> 
> **Ejemplos:**
> 
> ```
> 1) Longitud de círculo r = a:
>    dr/dθ = 0
>    
>     2π    
>    ⌠  
> L =│  √(a² + 0) dθ = a[θ]₀²π = 2πa  ✓
>    ⌡
>     0
> 
> 2) Longitud de cardioide r = a(1 + cos θ):
>    dr/dθ = -a sin(θ)
>    
>     2π
>    ⌠  ┌──────────────────────────────
> L =│ ╲╱ a²(1+cosθ)² + a²sin²(θ) dθ
>    ⌡
>     0
>    
>     2π
>    ⌠  
>  = │ a√[2(1 + cos θ)] dθ
>    ⌡
>     0
>  
>  = 8a
> ```

## 🌐 Coordenadas Polares en 3D

> [!note]- Extensión a Tres Dimensiones **Coordenadas cilíndricas:**
> 
> ```
> (r, θ, z)
> 
> Donde:
> r = distancia desde el eje z
> θ = ángulo en el plano xy
> z = altura
> 
> Conversión a cartesianas:
> x = r cos(θ)
> y = r sin(θ)
> z = z
> ```
> 
> **Coordenadas esféricas:**
> 
> ```
> (ρ, θ, φ)
> 
> Donde:
> ρ = distancia desde el origen
> θ = ángulo azimutal (en plano xy)
> φ = ángulo polar (desde eje z)
> 
> Conversión a cartesianas:
> x = ρ sin(φ) cos(θ)
> y = ρ sin(φ) sin(θ)
> z = ρ cos(φ)
> ```
> 
> **Aplicaciones:**
> 
> ```
> - Cilíndricas: problemas con simetría axial
>   (tubos, cables, campos magnéticos)
> 
> - Esféricas: problemas con simetría radial
>   (planetas, átomos, ondas esféricas)
> ```

## 🎲 Ecuaciones Diferenciales en Polares

> [!note]- EDO en Coordenadas Polares **Ecuación de movimiento central:**
> 
> ```
> Para fuerza central F = F(r):
> 
> d²r     ⎛dθ⎞²   F(r)
> ─── - r ⎜──⎟  = ────
> dt²     ⎝dt⎠     m
> 
> Momento angular L = mr²(dθ/dt) constante
> ```
> 
> **Ecuación de la órbita:**
> 
> ```
> d²u       F
> ─── + u = ────────
> dθ²      m(L²/m²)u²
> 
> Donde u = 1/r (cambio de variable)
> ```
> 
> **Aplicación a órbitas planetarias:**
> 
> ```
> Fuerza gravitacional: F = -GMm/r²
> 
> Solución: órbitas cónicas
> r = p/(1 + e cos θ)
> 
> Donde:
> p = parámetro de la cónica
> e = excentricidad
> 
> e = 0: círculo
> 0 < e < 1: elipse
> e = 1: parábola
> e > 1: hipérbola
> ```

## 📊 Transformaciones entre Ecuaciones

> [!tip]- Conversión de Ecuaciones **De cartesiana a polar:**
> 
> ```
> Sustituir:
> x = r cos(θ)
> y = r sin(θ)
> x² + y² = r²
> 
> Ejemplo 1: x² + y² = 9
> r² = 9  →  r = 3
> 
> Ejemplo 2: y = x
> r sin(θ) = r cos(θ)
> tan(θ) = 1  →  θ = π/4
> 
> Ejemplo 3: x² + y² = 4x
> r² = 4r cos(θ)
> r = 4cos(θ)
> ```
> 
> **De polar a cartesiana:**
> 
> ```
> Método: Multiplicar por factores convenientes
> 
> Ejemplo 1: r = 2
> r² = 4
> x² + y² = 4
> 
> Ejemplo 2: r = 4sin(θ)
> Multiplicar por r:
> r² = 4r sin(θ)
> x² + y² = 4y
> 
> Ejemplo 3: r = 1/(1 - cos θ)
> r(1 - cos θ) = 1
> r - r cos(θ) = 1
> √(x² + y²) - x = 1
> √(x² + y²) = x + 1
> x² + y² = (x + 1)²
> y² = 2x + 1
> ```

## 🧩 Problemas Adicionales

> [!example]- Más Ejercicios Resueltos **Problema 5: Área entre dos curvas**
> 
> ```
> Calcular área entre r = 2 y r = 1 + cos(θ)
> 
> SOLUCIÓN:
> 
> Paso 1: Encontrar intersecciones
> 2 = 1 + cos(θ)
> cos(θ) = 1
> θ = 0, 2π
> 
> Paso 2: Determinar cuál curva está "afuera"
> En θ = π/2: 
> r₁ = 2
> r₂ = 1 + cos(π/2) = 1
> 
> El círculo r = 2 está afuera
> 
> Paso 3: Plantear integral
>      2π
>     ⌠  1
> A = │  ─ [2² - (1+cos θ)²] dθ
>     ⌡  2
>      0
> 
> Paso 4: Simplificar
> 4 - (1 + 2cos θ + cos²θ) = 3 - 2cos θ - cos²θ
> 
> Usar cos²θ = (1 + cos 2θ)/2:
> = 3 - 2cos θ - (1 + cos 2θ)/2
> = 5/2 - 2cos θ - (cos 2θ)/2
> 
> Paso 5: Integrar
>      2π
>     ⌠  1
> A = │  ─ [5/2 - 2cos θ - (cos 2θ)/2] dθ
>     ⌡  2
>      0
> 
>   = ½[5θ/2 - 2sin θ - (sin 2θ)/4]₀²π
> 
>   = ½[(5π - 0 - 0) - (0 - 0 - 0)]
> 
>   = 5π/2
> 
> RESPUESTA: A = 5π/2 unidades cuadradas
> ```
> 
> **Problema 6: Puntos de tangencia vertical**
> 
> ```
> Para r = sin(2θ), encontrar puntos con tangente vertical
> 
> SOLUCIÓN:
> 
> Paso 1: Calcular dr/dθ
> dr/dθ = 2cos(2θ)
> 
> Paso 2: Condición para tangente vertical
> dx/dθ = 0
> 
> dr/dθ · cos(θ) - r sin(θ) = 0
> 2cos(2θ)cos(θ) - sin(2θ)sin(θ) = 0
> 
> Paso 3: Usar identidad sin(2θ) = 2sin(θ)cos(θ)
> 2cos(2θ)cos(θ) - 2sin²(θ)cos(θ) = 0
> 2cos(θ)[cos(2θ) - sin²(θ)] = 0
> 
> Caso 1: cos(θ) = 0
> θ = π/2, 3π/2
> 
> Caso 2: cos(2θ) = sin²(θ)
> cos(2θ) = (1 - cos(2θ))/2
> 3cos(2θ) = 1
> cos(2θ) = 1/3
> 2θ = arccos(1/3) ≈ 1.231
> θ ≈ 0.615 rad
> 
> Paso 4: Calcular puntos
> θ = π/2: r = sin(π) = 0 → (0, π/2) polo
> θ = 3π/2: r = sin(3π) = 0 → (0, 3π/2) polo
> θ ≈ 0.615: r ≈ sin(1.231) ≈ 0.943
> 
> RESPUESTA: Tangente vertical en aproximadamente
> (0.943, 0.615) y en el polo
> ```
> 
> **Problema 7: Rosa de 6 pétalos**
> 
> ```
> Para r = 3cos(3θ), determinar:
> a) Número de pétalos
> b) Longitud de un pétalo
> c) Área total
> 
> SOLUCIÓN:
> 
> a) Número de pétalos:
>    n = 3 (impar) → 3 pétalos ✗
>    
>    Espera: r = 3cos(3θ) tiene valores negativos
>    que crean 3 pétalos adicionales
>    
>    RESPUESTA: 3 pétalos visualmente
>    (pero técnicamente traza 3 pétalos dos veces)
> 
> b) Un pétalo: de θ donde r = 0 a siguiente r = 0
>    3cos(3θ) = 0
>    3θ = π/2, 3π/2, 5π/2, ...
>    θ = π/6, π/2, 5π/6, ...
>    
>    Primer pétalo: -π/6 ≤ θ ≤ π/6
>    
>     π/6   ┌────────────────
>    ⌠     │  
> L =│    ╲╱  9cos²(3θ) + 9sin²(3θ) dθ
>    ⌡
>    -π/6
>    
>     π/6
>    ⌠  
>  = │ 3 dθ = 3[θ]₋π/₆^π/₆ = 3(π/3) = π
>    ⌡
>    -π/6
> 
> c) Área total (3 pétalos):
>     π/6
>    ⌠  1
> A₁=│  ─ · 9cos²(3θ) dθ
>    ⌡  2
>    -π/6
>    
>  = (9/2) ∫₋π/₆^π/₆ (1 + cos(6θ))/2 dθ
>  
>  = (9/4)[θ + sin(6θ)/6]₋π/₆^π/₆
>  
>  = (9/4)(π/3) = 3π/4
>  
>  Área total = 3 · (3π/4) = 9π/4
> 
> RESPUESTAS:
> a) 3 pétalos
> b) Longitud de pétalo: π
> c) Área total: 9π/4
> ```

## 🎯 Aplicaciones en Números Complejos

> [!important]- Forma Polar de Números Complejos **Representación polar:**
> 
> ```
> Número complejo z = x + iy
> 
> Forma polar: z = r(cos θ + i sin θ) = r·e^(iθ)
> 
> Donde:
> r = |z| = √(x² + y²)  (módulo)
> θ = arg(z) = arctan(y/x)  (argumento)
> ```
> 
> **Fórmula de Euler:**
> 
> ```
> e^(iθ) = cos(θ) + i sin(θ)
> 
> Por tanto: z = r·e^(iθ)
> ```
> 
> **Multiplicación en forma polar:**
> 
> ```
> z₁ = r₁·e^(iθ₁)
> z₂ = r₂·e^(iθ₂)
> 
> z₁·z₂ = r₁r₂·e^(i(θ₁+θ₂))
> 
> Los módulos se multiplican
> Los argumentos se suman
> ```
> 
> **Teorema de De Moivre:**
> 
> ```
> (r·e^(iθ))ⁿ = rⁿ·e^(inθ)
> 
> [r(cos θ + i sin θ)]ⁿ = rⁿ(cos nθ + i sin nθ)
> ```
> 
> **Raíces n-ésimas:**
> 
> ```
> Las n raíces de z = r·e^(iθ) son:
> 
>          (θ + 2πk)
> zₖ = ⁿ√r · e^(i────────)  para k = 0,1,2,...,n-1
>              n
> 
> Distribuidas uniformemente en círculo de radio ⁿ√r
> ```

## 📚 Identidades Útiles en Polares

> [!tip]- Fórmulas de Referencia **Relaciones fundamentales:**
> 
> ```
> r² = x² + y²
> tan(θ) = y/x
> x = r cos(θ)
> y = r sin(θ)
> ```
> 
> **Derivadas:**
> 
> ```
> dx/dθ = (dr/dθ)cos(θ) - r sin(θ)
> dy/dθ = (dr/dθ)sin(θ) + r cos(θ)
> 
> dr/dθ = (x·dx/dθ + y·dy/dθ)/r
> ```
> 
> **Segundas derivadas:**
> 
> ```
> d²r/dθ² = d/dθ(dr/dθ)
> 
> Curvatura: κ = |r² + 2(dr/dθ)² - r(d²r/dθ²)|
>                 ────────────────────────────────
>                  [r² + (dr/dθ)²]^(3/2)
> ```

## 🌟 Patrones y Simetría Avanzada

> [!note]- Análisis de Simetría Complejo **Simetrías múltiples:**
> 
> ```
> Rosa r = a sin(nθ):
> - n impar: n pétalos con simetría rotacional de 360°/n
> - n par: 2n pétalos con simetría rotacional de 180°/n
> 
> Ejemplo: r = sin(4θ)
> - 8 pétalos
> - Simetría cada 45°
> - Simétrica respecto a θ = 0, π/2, π, 3π/2
> ```
> 
> **Periodicidad:**
> 
> ```
> Curva r = f(θ) tiene período T si:
> f(θ + T) = f(θ) para todo θ
> 
> Período mínimo determina curva completa
> 
> Ejemplos:
> r = cos(3θ): período π (no 2π)
> r = sin(2θ): período π
> r = θ: no periódica (espiral)
> ```

## 📝 Resumen Ejecutivo

> [!important]- Puntos Clave **Sistema de coordenadas:**
> 
> - **(r, θ):** radio y ángulo desde eje polar
> - **Representación múltiple:** infinitas formas para un punto
> - **Convención:** r ≥ 0, 0 ≤ θ < 2π
> 
> **Conversiones:**
> 
> - **Polar → Cartesiana:** x = r cos(θ), y = r sin(θ)
> - **Cartesiana → Polar:** r = √(x²+y²), θ = arctan(y/x) ajustado
> - **Cuidado con cuadrantes** al calcular θ
> 
> **Curvas importantes:**
> 
> - **Círculo:** r = a
> - **Espiral:** r = aθ o r = ae^(bθ)
> - **Rosa:** r = a cos(nθ) o r = a sin(nθ)
> - **Cardioide:** r = a(1 ± cos θ)
> - **Lemniscata:** r² = a² cos(2θ)
> 
> **Cálculo:**
> 
> - **Área:** A = ½∫r² dθ
> - **Longitud:** L = ∫√(r² + (dr/dθ)²) dθ
> - **Tangente:** dy/dx = [r' sin θ + r cos θ]/[r' cos θ - r sin θ]
> 
> **Aplicaciones:**
> 
> - Navegación, radar, astronomía
> - Física: movimiento circular y central
> - Números complejos: forma polar
> - Ecuaciones diferenciales con simetría radial
