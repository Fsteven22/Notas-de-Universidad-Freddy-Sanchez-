# 🌹 Rosas en Coordenadas Polares

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Las rosas (o rosáceas) son curvas en coordenadas polares definidas por ecuaciones de la forma r = a cos(nθ) o r = a sen(nθ), donde a > 0 determina el tamaño y n es un número entero positivo que determina el número de pétalos. Estas curvas reciben su nombre por su apariencia similar a flores con pétalos simétricos distribuidos uniformemente alrededor del origen. El número y disposición de pétalos depende de si n es par o impar.**
> 
> **Características clave:**
> 
> - **Ecuación general:** r = a cos(nθ) o r = a sen(nθ)
> - **Parámetro a:** longitud de cada pétalo
> - **Parámetro n:** determina número de pétalos
> - **n impar:** n pétalos
> - **n par:** 2n pétalos
> - **Simetría:** alta simetría rotacional

## 🎯 Ecuaciones Fundamentales

> [!important]- Formas Estándar **Ecuación con coseno:**
> 
> ```
> r = a cos(nθ)
> 
> donde:
> • a > 0: longitud del pétalo (radio máximo)
> • n ∈ ℕ: número que determina pétalos
> • θ ∈ [0, 2π]: ángulo polar
> 
> Características:
> • Primer pétalo sobre eje polar (θ = 0)
> • Simetría respecto al eje x
> • Pétalos distribuidos uniformemente
> 
> Valores de r:
> r_max = a (extremos de pétalos)
> r_min = 0 (centro)
> -a ≤ r ≤ a (rango completo)
> ```
> 
> **Ecuación con seno:**
> 
> ```
> r = a sen(nθ)
> 
> Características:
> • Primer pétalo sobre eje θ = π/(2n)
> • Simetría respecto a θ = π/2 (eje y)
> • Rotación de π/(2n) respecto a versión coseno
> 
> Relación con coseno:
> a sen(nθ) = a cos(nθ - π/2)
> 
> Rotación:
> Versión seno = versión coseno rotada π/(2n)
> ```
> 
> **Relación entre funciones:**
> 
> ```
> Equivalencias:
> r = a sen(nθ) = a cos(nθ - nπ/2)
> 
> Para convertir:
> cos(nθ) a sen(nθ): rotar -π/(2n)
> sen(nθ) a cos(nθ): rotar π/(2n)
> 
> Ambas formas describen la misma familia
> Solo difieren en orientación inicial
> ```

## 📊 Número de Pétalos

> [!success]- Regla Fundamental **Regla par-impar:**
> 
> ```
> Para r = a cos(nθ) o r = a sen(nθ):
> 
> Si n es IMPAR:
> Número de pétalos = n
> 
> Si n es PAR:
> Número de pétalos = 2n
> 
> Razón:
> Funciones trigonométricas completan
> diferentes números de ciclos en [0, 2π]
> ```
> 
> **Casos específicos (n impar):**
> 
> ```
> n = 1: r = a cos θ
> Pétalos: 1 (circunferencia)
> Forma: círculo de radio a/2, centro (a/2, 0)
> Caso degenerado de rosa
> 
> n = 3: r = a cos(3θ)
> Pétalos: 3 (tres pétalos)
> Ángulo entre pétalos: 120° = 2π/3
> Rosa de tres hojas
> 
> n = 5: r = a cos(5θ)
> Pétalos: 5 (cinco pétalos)
> Ángulo entre pétalos: 72° = 2π/5
> 
> n = 7: r = a cos(7θ)
> Pétalos: 7 (siete pétalos)
> Ángulo entre pétalos: 51.43° = 2π/7
> 
> Patrón general (n impar):
> Pétalos: n
> Ángulo entre pétalos: 2π/n
> ```
> 
> **Casos específicos (n par):**
> 
> ```
> n = 2: r = a cos(2θ)
> Pétalos: 4 (cuatro pétalos)
> Ángulo entre pétalos: 90° = π/2
> Rosa de cuatro hojas
> Forma de cruz o trébol de cuatro hojas
> 
> n = 4: r = a cos(4θ)
> Pétalos: 8 (ocho pétalos)
> Ángulo entre pétalos: 45° = π/4
> 
> n = 6: r = a cos(6θ)
> Pétalos: 12 (doce pétalos)
> Ángulo entre pétalos: 30° = π/6
> 
> n = 8: r = a cos(8θ)
> Pétalos: 16 (dieciséis pétalos)
> Ángulo entre pétalos: 22.5° = π/8
> 
> Patrón general (n par):
> Pétalos: 2n
> Ángulo entre pétalos: π/n
> ```
> 
> **Explicación de la regla:**
> 
> ```
> n impar:
> cos(nθ) completa n/2 ciclos en [0, π]
> Pero r < 0 en algunas regiones NO genera
> nuevos pétalos visibles (se superponen)
> Resultado: n pétalos distintos
> 
> n par:
> cos(nθ) completa n ciclos en [0, 2π]
> Cada medio ciclo genera un pétalo visible
> r ≥ 0 en [0, π/n], rosa tiene simetría
> Resultado: 2n pétalos distintos
> 
> Análisis de signo:
> n impar: pétalos con r < 0 se superponen
> n par: todos los pétalos visibles son distintos
> ```

## 🔄 Propiedades de Simetría

> [!note]- Características Geométricas **Simetría rotacional:**
> 
> ```
> Rosa con n pétalos (n impar):
> Simetría rotacional de orden n
> Rotación de 2π/n deja curva invariante
> 
> Rosa con 2n pétalos (n par):
> Simetría rotacional de orden 2n
> Rotación de π/n deja curva invariante
> 
> Todas las rosas:
> Altamente simétricas
> Múltiples ejes de simetría
> ```
> 
> **Simetría axial:**
> 
> ```
> r = a cos(nθ):
> • Simetría respecto al eje polar (eje x)
> • Simetría respecto al eje θ = π
> • Para n par: simetría adicional respecto a θ = π/2
> 
> r = a sen(nθ):
> • Simetría respecto a θ = π/2 (eje y)
> • Para n par: simetría adicional respecto al eje x
> 
> Ejes de simetría:
> n impar: n ejes
> n par: 2n ejes
> ```
> 
> **Periodicidad:**
> 
> ```
> Para r = a cos(nθ):
> 
> Período de la función:
> T = 2π/n
> 
> Rango completo para trazar:
> n impar: θ ∈ [0, π]
> n par: θ ∈ [0, 2π]
> 
> Aunque θ ∈ [0, 2π] traza curva completa
> para ambos casos
> 
> Rango mínimo necesario:
> n impar: [0, π] o [0, 2π] (mismo resultado)
> n par: [0, 2π] necesario para 2n pétalos
> ```
> 
> **Puntos de intersección con ejes:**
> 
> ```
> Para r = a cos(nθ):
> 
> Eje polar (θ = 0):
> r = a cos(0) = a
> Extremo de pétalo principal
> 
> Eje perpendicular (θ = π/2):
> r = a cos(nπ/2)
> Depende de n:
> - n = 1: r = 0
> - n = 2: r = -a (extremo de pétalo)
> - n = 3: r = 0
> - n = 4: r = a (extremo de pétalo)
> 
> Patrón: alterna según paridad de n
> ```

## 📐 Geometría de los Pétalos

> [!tip]- Estructura de Pétalos **Forma de un pétalo:**
> 
> ```
> Cada pétalo es simétrico respecto a su eje
> 
> Para r = a cos(nθ):
> k-ésimo pétalo (k = 0, 1, ..., n-1 para n impar)
>                (k = 0, 1, ..., 2n-1 para n par)
> 
> Centro del pétalo en ángulo:
> θ_k = kπ/n (para n par, pétalos 0 a 2n-1)
> θ_k = 2kπ/n (para n impar, pétalos 0 a n-1)
> 
> Extremo del pétalo:
> Distancia a desde origen
> En dirección θ_k
> 
> Ancho angular del pétalo:
> Δθ = π/n (para n par)
> Δθ = 2π/n (para n impar)
> ```
> 
> **Área de un pétalo:**
> 
> ```
> Para n impar, área de un pétalo:
> A_pétalo = (1/2) ∫_{-π/(2n)}^{π/(2n)} [a cos(nθ)]² dθ
> 
> Integrar:
> A_pétalo = (a²/2) ∫_{-π/(2n)}^{π/(2n)} cos²(nθ) dθ
> 
> Usando cos²(nθ) = (1 + cos(2nθ))/2:
> A_pétalo = (a²/4) ∫_{-π/(2n)}^{π/(2n)} [1 + cos(2nθ)] dθ
> A_pétalo = (a²/4)[θ + sen(2nθ)/(2n)]_{-π/(2n)}^{π/(2n)}
> A_pétalo = (a²/4)(π/n)
> A_pétalo = πa²/(4n)
> 
> Para n par, área de un pétalo:
> Similar análisis da:
> A_pétalo = πa²/(4n)
> 
> Área total de la rosa:
> n impar: A_total = n · πa²/(4n) = πa²/4
> n par: A_total = 2n · πa²/(4n) = πa²/2
> 
> Resultado notable:
> ¡Área total NO depende de n!
> (para n impar: πa²/4, para n par: πa²/2)
> ```
> 
> **Longitud de un pétalo:**
> 
> ```
> Longitud de arco de un pétalo:
> 
> L_pétalo = ∫ √(r² + (dr/dθ)²) dθ
> 
> Para r = a cos(nθ):
> dr/dθ = -na sen(nθ)
> 
> L_pétalo = ∫ √(a² cos²(nθ) + n²a² sen²(nθ)) dθ
> L_pétalo = a ∫ √(cos²(nθ) + n² sen²(nθ)) dθ
> 
> No tiene forma cerrada simple para n > 1
> Requiere funciones elípticas
> 
> Aproximación para n grande:
> L_pétalo ≈ πa/(2n) (arco circular)
> ```

## 🎨 Casos Especiales

> [!important]- Rosas Notables **Rosa de 3 pétalos (n = 3):**
> 
> ```
> r = a cos(3θ) o r = a sen(3θ)
> 
> Características:
> • 3 pétalos uniformemente espaciados
> • Ángulo entre pétalos: 120°
> • Forma clásica de trébol
> • Simetría rotacional de orden 3
> 
> Coseno:
> Pétalos en θ = 0°, 120°, 240°
> 
> Seno:
> Pétalos en θ = 30°, 150°, 270°
> 
> Área total: πa²/4
> 
> Aplicación:
> • Patrones decorativos
> • Símbolos (trébol)
> • Diseño de rotores
> ```
> 
> **Rosa de 4 pétalos (n = 2):**
> 
> ```
> r = a cos(2θ) o r = a sen(2θ)
> 
> Características:
> • 4 pétalos (n par → 2n pétalos)
> • Ángulo entre pétalos: 90°
> • Forma de cruz o trébol de 4 hojas
> • Doble simetría (x e y)
> 
> Coseno:
> Pétalos en θ = 0°, 90°, 180°, 270°
> Alineados con ejes coordenados
> 
> Seno:
> Pétalos en θ = 45°, 135°, 225°, 315°
> Rotados 45° respecto a coseno
> 
> Área total: πa²/2
> 
> Aplicaciones:
> • Trébol de cuatro hojas (símbolo)
> • Patrones de interferencia
> • Diseño de aspas
> ```
> 
> **Rosa de 5 pétalos (n = 5):**
> 
> ```
> r = a cos(5θ) o r = a sen(5θ)
> 
> Características:
> • 5 pétalos uniformemente espaciados
> • Ángulo entre pétalos: 72°
> • Relacionada con pentágono regular
> • Simetría de orden 5
> 
> Área total: πa²/4
> 
> Aplicaciones:
> • Flores naturales (aproximación)
> • Patrones decorativos
> • Diseño industrial
> ```
> 
> **Rosa de 8 pétalos (n = 4):**
> 
> ```
> r = a cos(4θ) o r = a sen(4θ)
> 
> Características:
> • 8 pétalos (n par → 2·4 = 8)
> • Ángulo entre pétalos: 45°
> • Alta simetría
> • Forma estrellada
> 
> Área total: πa²/2
> 
> Aplicaciones:
> • Patrones de radiación de antenas
> • Diseño de engranajes
> • Rosetones arquitectónicos
> ```
> 
> **Caso degenerado (n = 1):**
> 
> ```
> r = a cos θ
> 
> NO es una rosa típica
> Es una circunferencia:
> Centro: (a/2, 0)
> Radio: a/2
> 
> Considerado "rosa de 1 pétalo"
> Transición de rosa a círculo
> 
> Ecuación cartesiana:
> (x - a/2)² + y² = (a/2)²
> ```

## 🧮 Problemas Resueltos

> [!example]- Ejemplos Detallados **Problema 1: Identificar número de pétalos**
> 
> ```
> Determinar número de pétalos de cada rosa:
> a) r = 3 cos(5θ)
> b) r = 2 sen(4θ)
> c) r = 4 cos(7θ)
> d) r = 5 sen(6θ)
> 
> SOLUCIÓN:
> 
> a) n = 5 (impar)
>    Pétalos: 5
>    Longitud: a = 3
> 
> b) n = 4 (par)
>    Pétalos: 2(4) = 8
>    Longitud: a = 2
> 
> c) n = 7 (impar)
>    Pétalos: 7
>    Longitud: a = 4
> 
> d) n = 6 (par)
>    Pétalos: 2(6) = 12
>    Longitud: a = 5
> ```
> 
> **Problema 2: Área de rosa**
> 
> ```
> r = 4 cos(3θ)
> Calcular área total encerrada
> 
> SOLUCIÓN:
> 
> Identificar:
> a = 4, n = 3 (impar)
> 
> Fórmula para n impar:
> A = πa²/4
> 
> Sustituir:
> A = π(4)²/4
> A = 16π/4
> A = 4π unidades²
> 
> Verificación:
> 3 pétalos, cada uno con área πa²/(4n)
> A_pétalo = π(16)/(4·3) = 4π/3
> A_total = 3 · (4π/3) = 4π ✓
> ```
> 
> **Problema 3: Área de rosa par**
> 
> ```
> r = 6 sen(2θ)
> Calcular área total
> 
> SOLUCIÓN:
> 
> Identificar:
> a = 6, n = 2 (par)
> 
> Fórmula para n par:
> A = πa²/2
> 
> Sustituir:
> A = π(6)²/2
> A = 36π/2
> A = 18π unidades²
> 
> Nota: 4 pétalos (2n = 4)
> Cada pétalo: 18π/4 = 9π/2
> ```
> 
> **Problema 4: Puntos extremos de pétalo**
> 
> ```
> r = 5 cos(3θ)
> Encontrar coordenadas cartesianas de extremos de pétalos
> 
> SOLUCIÓN:
> 
> Rosa de 3 pétalos (n = 3 impar)
> 
> Extremos donde r = a = 5:
> cos(3θ) = 1
> 3θ = 0, 2π, 4π, ...
> θ = 0, 2π/3, 4π/3
> 
> Pétalo 1 (θ = 0):
> x = 5 cos(0) = 5
> y = 5 sen(0) = 0
> Punto: (5, 0)
> 
> Pétalo 2 (θ = 2π/3 = 120°):
> x = 5 cos(2π/3) = 5(-1/2) = -2.5
> y = 5 sen(2π/3) = 5(√3/2) ≈ 4.33
> Punto: (-2.5, 4.33)
> 
> Pétalo 3 (θ = 4π/3 = 240°):
> x = 5 cos(4π/3) = 5(-1/2) = -2.5
> y = 5 sen(4π/3) = 5(-√3/2) ≈ -4.33
> Punto: (-2.5, -4.33)
> ```
> 
> **Problema 5: Comparación de orientaciones**
> 
> ```
> Comparar r₁ = 3 cos(4θ) y r₂ = 3 sen(4θ)
> ¿Cuál es la relación entre ellas?
> 
> SOLUCIÓN:
> 
> Ambas son rosas de 8 pétalos (n = 4 par)
> Mismo tamaño (a = 3)
> 
> Relación trigonométrica:
> sen(4θ) = cos(4θ - π/2)
> 
> Por tanto:
> r₂ = 3 sen(4θ) = 3 cos(4θ - π/2)
> 
> Rotación:
> Ángulo de rotación = π/(2n) = π/8
> 
> r₂ es r₁ rotada π/8 radianes (22.5°) antihorario
> 
> Primer pétalo:
> r₁: en θ = 0
> r₂: en θ = π/8
> 
> Diferencia: 22.5° entre orientaciones
> ```
> 
> **Problema 6: Intersección con eje**
> 
> ```
> r = 4 cos(5θ)
> ¿En qué puntos la rosa cruza el eje x positivo?
> 
> SOLUCIÓN:
> 
> Eje x positivo: θ = 0 o θ = 2π
> 
> En θ = 0:
> r = 4 cos(0) = 4
> Punto: (4, 0)
> 
> También cuando θ = 0 + k(2π/5) y cos(5θ) > 0
> 
> Valores de θ en [0, 2π] donde cos(5θ) > 0
> y punto está en eje x:
> 
> 5θ ∈ [-π/2, π/2] ∪ [3π/2, 5π/2] ∪ ...
> 
> Para eje x positivo específicamente:
> Necesitamos cos θ > 0 también
> 
> Intersecciones en eje x positivo:
> θ = 0: r = 4 → (4, 0)
> θ = 2π/5: r = 4 cos(2π) = 4 → pero cos(2π/5) < 1
>           punto no está en eje x positivo
> 
> Solo (4, 0) en eje x positivo
> Otros extremos de pétalos en otras direcciones
> ```
> 
> **Problema 7: Conversión a cartesianas**
> 
> ```
> r = 2 cos(2θ)
> Expresar en coordenadas cartesianas
> 
> SOLUCIÓN:
> 
> Usar identidad trigonométrica:
> cos(2θ) = cos² θ - sen² θ
> 
> r = 2(cos² θ - sen² θ)
> 
> Sustituir:
> cos θ = x/r, sen θ = y/r
> 
> r = 2[(x/r)² - (y/r)²]
> r = 2(x² - y²)/r²
> r³ = 2(x² - y²)
> (x² + y²)^(3/2) = 2(x² - y²)
> 
> Elevar al cuadrado:
> (x² + y²)³ = 4(x² - y²)²
> 
> Ecuación implícita de 6to grado
> Mucho más compleja en cartesianas
> Demuestra ventaja de forma polar
> ```
> 
> **Problema 8: Rosa con parámetro**
> 
> ```
> r = a cos(nθ) con área total 9π
> Si n = 3, encontrar a
> 
> SOLUCIÓN:
> 
> n = 3 (impar)
> Fórmula de área: A = πa²/4
> 
> Dado: A = 9π
> 
> Ecuación:
> πa²/4 = 9π
> a²/4 = 9
> a² = 36
> a = 6 (positivo)
> 
> Rosa: r = 6 cos(3θ)
> 
> Verificación:
> A = π(6)²/4 = 36π/4 = 9π ✓
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes **1. "n pétalos siempre para r = a cos(nθ)"**
> 
> ```
> ✗ FALSO - depende de paridad de n
> 
> ✓ n impar: n pétalos
> ✓ n par: 2n pétalos
> 
> Ejemplo:
> n = 3: 3 pétalos ✓
> n = 4: 8 pétalos (no 4) ✓
> ```
> 
> **2. "Rango θ ∈ [0, π] suficiente siempre"**
> 
> ```
> ✗ FALSO para n par
> 
> n impar: θ ∈ [0, π] traza todos los pétalos
> n par: necesita θ ∈ [0, 2π] para todos los pétalos
> 
> Ejemplo r = cos(2θ):
> [0, π]: solo traza 2 pétalos
> [0, 2π]: traza los 4 pétalos completos
> ```
> 
> **3. "Área depende de n"**
> 
> ```
> ✗ FALSO para comparar dentro de paridad
> 
> n impar: A = πa²/4 (independiente de n)
> n par: A = πa²/2 (independiente de n)
> 
> ✓ Área solo depende de a y paridad de n
> 
> r = 2 cos(3θ) y r = 2 cos(5θ):
> Ambas tienen área π(2)²/4 = π
> ```
> 
> **4. "sen y cos dan misma rosa"**
> 
> ```
> ✗ FALSO - tienen diferente orientación
> 
> r = a cos(nθ) y r = a sen(nθ)
> son la MISMA curva rotada π/(2n)
> 
> Misma forma, diferente orientación
> ```
> 
> **5. "r negativo no importa"**
> 
> ```
> ✗ FALSO - es crucial para rosas
> 
> Cuando r < 0, el punto está en dirección opuesta
> Esto afecta cómo se trazan los pétalos
> 
> Para n impar: algunos valores negativos
> se superponen, dando solo n pétalos
> 
> Para n par: valores negativos crean
> pétalos adicionales, dando 2n pétalos
> ```
> 
> **6. "Todos los pétalos tienen misma orientación"**
> ```
> ✗ FALSO - están rotados uniformemente
> ✓ Pétalos distribuidos uniformemente
> 
> n impar: ángulo entre pétalos = 2π/n n par: ángulo entre pétalos = π/n
> 
> Ejemplo n = 5: Pétalos en 0°, 72°, 144°, 216°, 288°
> 
> ```
> 
> **7. "Longitud de pétalo = a"**
> 
> ```
> 
> ✗ FALSO - confunde radio con longitud de arco
> 
> a = radio máximo (distancia del origen al extremo) Longitud de arco del pétalo > a (curvo)
> 
> Distancia radial desde origen: a Longitud de la curva del pétalo: > a
> ```

## 📏 Variantes y Generalizaciones

> [!note]- Formas Extendidas **Rosa con amplitud variable:**
> 
> ```
> r = a + b cos(nθ)
> 
> Combinación de caracol y rosa
> 
> Si b < a: rosa con "piso" elevado
> Centro desplazado del origen
> 
> Si b > a: rosa con bucles
> Forma más compleja
> 
> Ejemplo:
> r = 2 + cos(3θ)
> Rosa de 3 pétalos sobre caracol
> ```
> 
> **Rosa con múltiples frecuencias:**
> 
> ```
> r = a cos(nθ) + b cos(mθ)
> 
> Superposición de dos rosas
> Patrones de interferencia
> 
> Si n y m son coprimos: forma compleja
> Si tienen factor común: simetría adicional
> 
> Ejemplo:
> r = cos(3θ) + cos(5θ)
> Patrón intrincado de 15 lóbulos
> ```
> 
> **Rosa con desfase:**
> 
> ```
> r = a cos(nθ + φ)
> 
> Rotación por ángulo φ/n
> Cambia orientación inicial
> 
> Ejemplo:
> r = 2 cos(3θ + π/4)
> Rosa de 3 pétalos rotada π/12
> ```
> 
> **Rosa con exponente:**
> 
> ```
> r = a cos^k(nθ)
> 
> k > 1: pétalos más "puntiagudos"
> 0 < k < 1: pétalos más "redondeados"
> 
> Ejemplo:
> r = 3 cos²(4θ)
> 8 pétalos con forma modificada
> ```
> 
> **Rosa con valor absoluto:**
> 
> ```
> r = a |cos(nθ)|
> 
> Siempre r ≥ 0
> Duplica número de pétalos
> 
> n impar: 2n pétalos (en vez de n)
> n par: 2n pétalos (igual que sin |·|)
> 
> Ejemplo:
> r = 2|cos(3θ)|
> 6 pétalos (en vez de 3)
> ```
> 
> **Rosa modulada:**
> 
> ```
> r = a(1 + k cos(mθ)) cos(nθ)
> 
> Modulación de amplitud
> Pétalos de tamaño variable
> 
> Aplicación: patrones de radiación complejos
> ```

## 🔬 Análisis Matemático Avanzado

> [!tip]- Propiedades Profundas **Curvatura:**
> 
> ```
> Curvatura en coordenadas polares:
> 
> κ = |r² + 2(dr/dθ)² - r(d²r/dθ²)|
>     ────────────────────────────────
>     [r² + (dr/dθ)²]^(3/2)
> 
> Para r = a cos(nθ):
> dr/dθ = -na sen(nθ)
> d²r/dθ² = -n²a cos(nθ)
> 
> En extremo de pétalo (θ = 0):
> r = a, dr/dθ = 0, d²r/dθ² = -n²a
> 
> κ = |a² + 0 - a(-n²a)|
>     ──────────────────
>     [a²]^(3/2)
> 
> κ = |a² + n²a²|   = a²(1 + n²)  = 1 + n²
>     ────────────    ────────────   ───────
>        a³              a³             a
> 
> Curvatura máxima en extremos
> Aumenta con n²
> ```
> 
> **Radio de curvatura:**
> 
> ```
> Radio de curvatura ρ = 1/κ
> 
> En extremo de pétalo:
> ρ = a/(1 + n²)
> 
> Para n grande:
> ρ ≈ a/n² (muy pequeño)
> Pétalos más "puntiagudos"
> 
> Para n = 1:
> ρ = a/2
> Rosa degenera en círculo
> ```
> 
> **Derivadas polares:**
> 
> ```
> Para r = a cos(nθ):
> 
> Primera derivada:
> dr/dθ = -na sen(nθ)
> 
> Segunda derivada:
> d²r/dθ² = -n²a cos(nθ) = -n²r
> 
> Ecuación diferencial:
> d²r/dθ² + n²r = 0
> 
> Solución armónica
> Movimiento periódico en coordenadas polares
> ```
> 
> **Integral de longitud:**
> 
> ```
> Longitud total de rosa:
> 
> L = ∫₀²π √(r² + (dr/dθ)²) dθ
> 
> Para r = a cos(nθ):
> L = ∫₀²π √(a² cos²(nθ) + n²a² sen²(nθ)) dθ
> L = a ∫₀²π √(cos²(nθ) + n² sen²(nθ)) dθ
> 
> Forma cerrada involucra integrales elípticas:
> L = 4nE(k)
> 
> donde E(k) es integral elíptica completa
> k = √(1 - 1/n²) para n > 1
> 
> Aproximación para n >> 1:
> L ≈ 2πna (perímetro de n círculos)
> ```
> 
> **Coordenadas del centroide:**
> 
> ```
> Por simetría:
> Para r = a cos(nθ): x̄ > 0, ȳ = 0
> Para r = a sen(nθ): x̄ = 0, ȳ > 0
> 
> Cálculo de x̄ para r = a cos(nθ):
> 
> x̄ = (1/A) ∫∫ x dA
> 
> En polares:
> x̄ = (2/A) ∫₀^π (1/3)r³ cos θ dθ
> 
> Requiere integrar [a cos(nθ)]³ cos θ
> Resultado depende de n
> 
> Para n = 3:
> x̄ = 2a/5 aproximadamente
> ```
> 
> **Momento de inercia:**
> 
> ```
> Momento respecto al origen:
> 
> I₀ = ∫∫ r² ρ dA
> 
> Para densidad uniforme ρ:
> I₀ = (ρ/2) ∫₀²π r⁴ dθ
> 
> Para r = a cos(nθ):
> I₀ = (ρ/2) ∫₀²π a⁴ cos⁴(nθ) dθ
> 
> Usando cos⁴(nθ) = (3 + 4cos(2nθ) + cos(4nθ))/8:
> 
> I₀ = (ρa⁴/2) ∫₀²π (3 + 4cos(2nθ) + cos(4nθ))/8 dθ
> I₀ = (ρa⁴/16)(3·2π) = 3πρa⁴/8
> 
> Independiente de n (notable)
> ```

## 🎯 Casos Límite y Transiciones

> [!note]- Comportamiento Asintótico **Límite n → ∞:**
> 
> ```
> Para r = a cos(nθ):
> 
> A medida que n aumenta:
> • Número de pétalos → ∞
> • Pétalos cada vez más delgados
> • Pétalos más "puntiagudos"
> • Radio de curvatura → 0
> • Límite: no converge a forma simple
> 
> Visualmente:
> Rosa se vuelve "peluda"
> Pétalos como agujas desde origen
> ```
> 
> **Límite n → 0:**
> 
> ```
> No tiene sentido matemático directo
> (n debe ser entero positivo)
> 
> Pero cos(nθ) → 1 cuando n → 0:
> r → a (circunferencia)
> ```
> 
> **Transición n = 1:**
> 
> ```
> r = a cos θ
> 
> No es rosa típica
> Es circunferencia:
> Centro: (a/2, 0)
> Radio: a/2
> 
> Caso límite entre rosa y círculo
> "Rosa de 1 pétalo"
> ```
> 
> **Límite a → 0:**
> 
> ```
> Rosa colapsa al origen
> Todos los pétalos longitud cero
> ```
> 
> **Límite a → ∞:**
> 
> ```
> Rosa crece sin límite
> Forma se mantiene
> Escalamiento uniforme
> ```

> ```
> ROSAS EN COORDENADAS POLARES - RESUMEN
> 
> ═══════════════════════════════════════════
> ECUACIONES ESTÁNDAR
> ═══════════════════════════════════════════
> r = a cos(nθ)  (eje horizontal)
> r = a sen(nθ)  (eje vertical)
> 
> a > 0: longitud de pétalos
> n ∈ ℕ: determina número de pétalos
> 
> ═══════════════════════════════════════════
> NÚMERO DE PÉTALOS
> ═══════════════════════════════════════════
> n IMPAR:  n pétalos
> n PAR:    2n pétalos
> 
> Ejemplos:
> n = 1: 1 pétalo (círculo)
> n = 2: 4 pétalos
> n = 3: 3 pétalos
> n = 4: 8 pétalos
> n = 5: 5 pétalos
> n = 6: 12 pétalos
> 
> ═══════════════════════════════════════════
> ÁNGULO ENTRE PÉTALOS
> ═══════════════════════════════════════════
> n impar: Δθ = 2π/n
> n par:   Δθ = π/n
> 
> ═══════════════════════════════════════════
> ÁREA TOTAL ENCERRADA
> ═══════════════════════════════════════════
> n impar: A = πa²/4
> n par:   A = πa²/2
> 
> Área de un pétalo:
> A_pétalo = πa²/(4n)  (n impar o par)
> 
> ═══════════════════════════════════════════
> ÁREA POR INTEGRACIÓN
> ═══════════════════════════════════════════
> A = (1/2) ∫₀²π r² dθ
> A = (1/2) ∫₀²π a² cos²(nθ) dθ
> 
> ═══════════════════════════════════════════
> SIMETRÍA
> ═══════════════════════════════════════════
> r = a cos(nθ): simetría eje x
> r = a sen(nθ): simetría eje y
> 
> Simetría rotacional:
> n impar: orden n
> n par: orden 2n
> 
> ═══════════════════════════════════════════
> RANGO DE θ
> ═══════════════════════════════════════════
> Para trazar completamente:
> n impar: [0, π] o [0, 2π]
> n par: [0, 2π] necesario
> 
> ═══════════════════════════════════════════
> EXTREMOS DE PÉTALOS
> ═══════════════════════════════════════════
> Para r = a cos(nθ):
> Extremos donde cos(nθ) = ±1
> nθ = kπ, k = 0, 1, 2, ...
> θ = kπ/n
> 
> Distancia del origen: a
> 
> ═══════════════════════════════════════════
> PASO POR ORIGEN
> ═══════════════════════════════════════════
> r = 0 cuando cos(nθ) = 0
> nθ = π/2 + kπ, k ∈ ℤ
> θ = π/(2n) + kπ/n
> 
> ═══════════════════════════════════════════
> CASOS ESPECIALES
> ═══════════════════════════════════════════
> n = 1: r = a cos θ (circunferencia)
> n = 2: 4 pétalos (cruz, trébol 4 hojas)
> n = 3: 3 pétalos (trébol)
> n = 4: 8 pétalos (octógono estrellado)
> 
> ═══════════════════════════════════════════
> RELACIÓN SENO-COSENO
> ═══════════════════════════════════════════
> r = a sen(nθ) = a cos(nθ - π/2)
> 
> Rotación: π/(2n) radianes
> ```
