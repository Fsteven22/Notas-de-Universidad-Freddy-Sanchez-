# 🎯 Plano Polar

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **El plano polar es un sistema de coordenadas bidimensional donde la posición de un punto se determina mediante su distancia a un punto fijo (polo) y el ángulo que forma con una dirección de referencia (eje polar). A diferencia del sistema cartesiano que usa distancias perpendiculares, el sistema polar usa distancia radial y dirección angular.**
> 
> **Características clave:**
> 
> - **Polo (O):** Punto de referencia fijo (equivalente al origen)
> - **Eje polar:** Semirrecta de referencia (generalmente horizontal derecha)
> - **Coordenada radial (r):** Distancia al polo
> - **Coordenada angular (θ):** Ángulo medido desde el eje polar
> - **Notación:** P(r, θ) o (r, θ)
> - **Intuición:** "¿Qué tan lejos?" y "¿En qué dirección?"

## 📐 Definición Formal del Sistema Polar

> [!success]- Componentes del Sistema **Elementos básicos:**
> 
> ```
> 1. POLO (O):
>    - Punto fijo de referencia
>    - Equivalente al origen en cartesianas
>    - Centro del sistema
> 
> 2. EJE POLAR:
>    - Semirrecta que parte del polo
>    - Dirección de referencia (usualmente horizontal derecha)
>    - Equivalente al eje x positivo
>    - También llamado "eje de referencia" o "línea inicial"
> 
> 3. COORDENADA RADIAL (r):
>    - Distancia del punto al polo
>    - r ∈ ℝ (puede ser negativa)
>    - |r| = magnitud de la distancia
>    - r > 0: en dirección del ángulo θ
>    - r < 0: en dirección opuesta a θ
>    - r = 0: el punto está en el polo
> 
> 4. COORDENADA ANGULAR (θ):
>    - Ángulo medido desde el eje polar
>    - Sentido positivo: antihorario (contrario a las agujas del reloj)
>    - Sentido negativo: horario
>    - Se mide en radianes o grados
>    - θ ∈ ℝ (puede dar múltiples vueltas)
> ```
> 
> **Notación de un punto:**
> 
> ```
> P(r, θ)  o  (r, θ)
> 
> Ejemplo: P(5, π/3)
> - r = 5: distancia de 5 unidades del polo
> - θ = π/3: ángulo de 60° desde el eje polar
> ```
> 
> **Convenciones:**
> 
> ```
> - θ = 0: eje polar (derecha)
> - θ = π/2: perpendicular hacia arriba
> - θ = π: dirección opuesta al eje polar (izquierda)
> - θ = 3π/2 o -π/2: perpendicular hacia abajo
> - θ = 2π: vuelta completa (equivale a θ = 0)
> ```

## 🎯 Localización de Puntos

> [!tip]- Cómo Ubicar un Punto en Coordenadas Polares **Procedimiento:**
> 
> ```
> Dado P(r, θ):
> 
> 1. Medir el ángulo θ desde el eje polar
>    - Si θ > 0: girar en sentido antihorario
>    - Si θ < 0: girar en sentido horario
> 
> 2. Desde el polo, moverse una distancia |r|
>    - Si r > 0: en la dirección del ángulo θ
>    - Si r < 0: en la dirección opuesta (θ + π)
> 
> 3. Marcar el punto resultante
> ```
> 
> **Casos especiales:**
> 
> ```
> r = 0, cualquier θ:
> - El punto está en el polo (origen)
> - P(0, θ) = O para todo θ
> 
> r > 0, θ = 0:
> - Punto sobre el eje polar
> - A la derecha del polo
> 
> r > 0, θ = π/2:
> - Punto perpendicular al eje polar
> - Arriba del polo
> 
> r < 0:
> - Interpretación: dar media vuelta (π radianes)
> - P(r, θ) = P(-r, θ + π) = P(-r, θ - π)
> ```

> [!example]- Ejemplos de Localización **Ejemplo 1: r > 0, θ en primer cuadrante**
> 
> ```
> P(3, π/4)
> 
> - Ángulo: π/4 = 45° desde eje polar (antihorario)
> - Distancia: 3 unidades en esa dirección
> 
> Ubicación: Primer cuadrante, 45° arriba del eje polar
> 
>         ↑ π/2
>         |
>         |    • P(3, π/4)
>         |  /
>         | /
>    ─────O───────→ 0 (eje polar)
>         |
>         |
>         ↓ 3π/2
> ```
> 
> **Ejemplo 2: r > 0, ángulo mayor que 2π**
> 
> ```
> Q(2, 5π/3)
> 
> 5π/3 = 300° = -60° (equivalente a -π/3)
> 
> - Girar 300° antihorario (o 60° horario)
> - Avanzar 2 unidades
> 
> Ubicación: Cuarto cuadrante
> ```
> 
> **Ejemplo 3: r < 0**
> 
> ```
> R(-4, π/6)
> 
> r negativo: invertir dirección
> 
> Equivalente a: R(4, π/6 + π) = R(4, 7π/6)
> 
> - Girar π/6 = 30°
> - Como r < 0, ir en dirección opuesta
> - Equivale a girar 7π/6 = 210° y avanzar 4
> 
> Ubicación: Tercer cuadrante
> ```
> 
> **Ejemplo 4: r = 0**
> 
> ```
> S(0, π/2)
> 
> Distancia cero → está en el polo
> El ángulo es irrelevante
> 
> S(0, π/2) = S(0, 0) = S(0, cualquier ángulo) = O
> ```
> 
> **Ejemplo 5: Ángulo negativo**
> 
> ```
> T(5, -π/3)
> 
> Ángulo negativo: girar en sentido horario
> 
> -π/3 = -60°
> 
> - Girar 60° en sentido horario desde eje polar
> - Avanzar 5 unidades
> 
> Equivalente a: T(5, 5π/3)
> 
> Ubicación: Cuarto cuadrante
> ```

## 🔄 Representaciones Múltiples

> [!important]- No Unicidad de Coordenadas Polares **Característica fundamental:**
> 
> ```
> A diferencia del sistema cartesiano, en coordenadas polares
> UN MISMO PUNTO puede tener INFINITAS representaciones
> ```
> 
> **Razones de no unicidad:**
> 
> ```
> 1. PERIODICIDAD DEL ÁNGULO:
>    θ y θ + 2πn representan la misma dirección
>    
>    P(r, θ) = P(r, θ + 2πn)  para todo n ∈ ℤ
> 
> 2. SIMETRÍA CON r NEGATIVO:
>    r negativo equivale a invertir dirección
>    
>    P(r, θ) = P(-r, θ + π) = P(-r, θ + (2n+1)π)
> 
> 3. EL POLO:
>    P(0, θ) = O para cualquier θ
> ```

> [!example]- Ejemplos de Representaciones Múltiples **Ejemplo 1: Mismo punto, diferentes coordenadas**
> 
> ```
> Punto: P(2, π/3)
> 
> Representaciones equivalentes:
> 
> 4. Sumar múltiplos de 2π:
>    (2, π/3 + 2π) = (2, 7π/3)
>    (2, π/3 + 4π) = (2, 13π/3)
>    (2, π/3 - 2π) = (2, -5π/3)
> 
> 5. Usar r negativo:
>    (-2, π/3 + π) = (-2, 4π/3)
>    (-2, π/3 - π) = (-2, -2π/3)
> 
> 6. Combinar ambos:
>    (-2, 4π/3 + 2π) = (-2, 10π/3)
> 
> Todas representan el MISMO punto
> ```
> 
> **Ejemplo 2: El polo**
> 
> ```
> Polo O:
> 
> (0, 0)
> (0, π/2)
> (0, π)
> (0, 5π/7)
> (0, -3π/4)
> (0, 100π)
> 
> Todas son el mismo punto: el polo
> El ángulo es irrelevante cuando r = 0
> ```
> 
> **Ejemplo 3: Encontrar representación específica**
> 
> ```
> Dado P(3, 5π/4), encontrar representación con:
> 
> a) r > 0 y 0 ≤ θ < 2π:
>    Ya está en esa forma: (3, 5π/4)
> 
> b) r < 0 y 0 ≤ θ < 2π:
>    (-3, 5π/4 - π) = (-3, π/4)
> 
> c) r > 0 y -2π ≤ θ < 0:
>    (3, 5π/4 - 2π) = (3, -3π/4)
> 
> d) r < 0 y 2π ≤ θ < 4π:
>    (-3, π/4 + 2π) = (-3, 9π/4)
> ```

## 🔀 Conversión entre Coordenadas

### 1️⃣ De Polares a Cartesianas

> [!success]- Fórmulas de Conversión **Dado P(r, θ) en polares, encontrar (x, y) en cartesianas:**
> 
> ```
> x = r cos(θ)
> y = r sin(θ)
> 
> Estas fórmulas siempre funcionan
> (incluso si r < 0 o θ fuera de [0, 2π))
> ```
> 
> **Origen de las fórmulas:**
> 
> ```
> Del triángulo rectángulo formado:
> 
>         P(x,y)
>        /|
>     r / |
>      /  | y
>     /θ  |
>    O────┴
>       x
> 
> cos(θ) = x/r  →  x = r cos(θ)
> sin(θ) = y/r  →  y = r sin(θ)
> ```
> 
> **Distancia al origen:**
> 
> ```
> r² = x² + y²
> 
> (se obtiene de x² + y² = r²cos²(θ) + r²sin²(θ) = r²)
> ```

> [!example]- Ejemplos de Polar a Cartesiana **Ejemplo 1:**
> 
> ```
> Convertir P(4, π/3) a cartesianas
> 
> x = r cos(θ) = 4 cos(π/3) = 4 · (1/2) = 2
> y = r sin(θ) = 4 sin(π/3) = 4 · (√3/2) = 2√3
> 
> RESPUESTA: P(2, 2√3)
> ```
> 
> **Ejemplo 2:**
> 
> ```
> Convertir Q(2, 3π/4) a cartesianas
> 
> x = 2 cos(3π/4) = 2 · (-√2/2) = -√2
> y = 2 sin(3π/4) = 2 · (√2/2) = √2
> 
> RESPUESTA: Q(-√2, √2)
> ```
> 
> **Ejemplo 3: r negativo**
> 
> ```
> Convertir R(-3, π/6) a cartesianas
> 
> x = -3 cos(π/6) = -3 · (√3/2) = -3√3/2
> y = -3 sin(π/6) = -3 · (1/2) = -3/2
> 
> RESPUESTA: R(-3√3/2, -3/2)
> 
> Nota: Las fórmulas funcionan incluso con r < 0
> ```
> 
> **Ejemplo 4: Ángulo mayor que 2π**
> 
> ```
> Convertir S(5, 7π/3) a cartesianas
> 
> Primero: 7π/3 = 2π + π/3 (equivalente a π/3)
> 
> x = 5 cos(7π/3) = 5 cos(π/3) = 5 · (1/2) = 5/2
> y = 5 sin(7π/3) = 5 sin(π/3) = 5 · (√3/2) = 5√3/2
> 
> RESPUESTA: S(5/2, 5√3/2)
> ```
> 
> **Ejemplo 5: El polo**
> 
> ```
> Convertir O(0, cualquier θ) a cartesianas
> 
> x = 0 · cos(θ) = 0
> y = 0 · sin(θ) = 0
> 
> RESPUESTA: O(0, 0)
> 
> Como esperábamos: el polo es el origen
> ```

### 2️⃣ De Cartesianas a Polares

> [!success]- Fórmulas de Conversión **Dado P(x, y) en cartesianas, encontrar (r, θ) en polares:**
> 
> ```
> r = ±√(x² + y²)
> 
> θ = arctan(y/x)  [con ajustes según cuadrante]
> 
> ⚠️ El ángulo θ requiere CUIDADO con el cuadrante
> ```
> 
> **Fórmula para r:**
> 
> ```
> r² = x² + y²
> 
> r = √(x² + y²)   [convención: r ≥ 0]
> o
> r = -√(x² + y²)  [menos común]
> 
> Usualmente tomamos r ≥ 0
> ```
> 
> **Fórmula para θ (con cuidado):**
> 
> ```
> tan(θ) = y/x  (si x ≠ 0)
> 
> Pero arctan solo da valores en (-π/2, π/2)
> Necesitamos ajustar según el cuadrante:
> 
> CUADRANTE I (x > 0, y > 0):
>   θ = arctan(y/x)
> 
> CUADRANTE II (x < 0, y > 0):
>   θ = arctan(y/x) + π = π - arctan(|y|/|x|)
> 
> CUADRANTE III (x < 0, y < 0):
>   θ = arctan(y/x) + π = π + arctan(|y|/|x|)
> 
> CUADRANTE IV (x > 0, y < 0):
>   θ = arctan(y/x) + 2π = 2π - arctan(|y|/|x|)
>   o θ = arctan(y/x)  [si aceptamos θ < 0]
> 
> EJE X POSITIVO (x > 0, y = 0):
>   θ = 0
> 
> EJE X NEGATIVO (x < 0, y = 0):
>   θ = π
> 
> EJE Y POSITIVO (x = 0, y > 0):
>   θ = π/2
> 
> EJE Y NEGATIVO (x = 0, y < 0):
>   θ = 3π/2 o -π/2
> 
> ORIGEN (x = 0, y = 0):
>   r = 0, θ = cualquier valor
> ```
> 
> **Función atan2 (en programación):**
> 
> ```
> θ = atan2(y, x)
> 
> Esta función automáticamente considera el cuadrante
> Devuelve θ ∈ (-π, π]
> Disponible en la mayoría de lenguajes de programación
> ```

> [!example]- Ejemplos de Cartesiana a Polar **Ejemplo 1: Primer cuadrante**
> 
> ```
> Convertir P(3, 3) a polares
> 
> r = √(3² + 3²) = √18 = 3√2
> 
> tan(θ) = 3/3 = 1
> θ = arctan(1) = π/4  (cuadrante I)
> 
> RESPUESTA: P(3√2, π/4)
> ```
> 
> **Ejemplo 2: Segundo cuadrante**
> 
> ```
> Convertir Q(-1, √3) a polares
> 
> r = √((-1)² + (√3)²) = √(1 + 3) = 2
> 
> tan(θ) = √3/(-1) = -√3
> Pero estamos en cuadrante II (x < 0, y > 0)
> 
> θ = π - arctan(√3/1) = π - π/3 = 2π/3
> 
> o usando la fórmula:
> θ = arctan(√3/(-1)) + π = -π/3 + π = 2π/3
> 
> RESPUESTA: Q(2, 2π/3)
> ```
> 
> **Ejemplo 3: Tercer cuadrante**
> 
> ```
> Convertir R(-2, -2) a polares
> 
> r = √((-2)² + (-2)²) = √8 = 2√2
> 
> tan(θ) = -2/(-2) = 1
> Cuadrante III (x < 0, y < 0)
> 
> θ = arctan(1) + π = π/4 + π = 5π/4
> 
> RESPUESTA: R(2√2, 5π/4)
> ```
> 
> **Ejemplo 4: Cuarto cuadrante**
> 
> ```
> Convertir S(√3, -1) a polares
> 
> r = √((√3)² + (-1)²) = √4 = 2
> 
> tan(θ) = -1/√3
> Cuadrante IV (x > 0, y < 0)
> 
> θ = arctan(-1/√3) = -π/6
> 
> o si queremos θ ∈ [0, 2π):
> θ = 2π - π/6 = 11π/6
> 
> RESPUESTA: S(2, -π/6) o S(2, 11π/6)
> ```
> 
> **Ejemplo 5: Sobre eje negativo**
> 
> ```
> Convertir T(-4, 0) a polares
> 
> r = √((-4)² + 0²) = 4
> 
> Punto sobre eje x negativo
> θ = π
> 
> RESPUESTA: T(4, π)
> 
> O con r negativo: T(-4, 0)
> ```
> 
> **Ejemplo 6: Origen**
> 
> ```
> Convertir O(0, 0) a polares
> 
> r = √(0² + 0²) = 0
> 
> θ = indeterminado (cualquier valor)
> 
> RESPUESTA: O(0, θ) para cualquier θ
> Usualmente: O(0, 0)
> ```

## 🎨 Gráficas Básicas en Coordenadas Polares

### 1️⃣ Círculo con Centro en el Polo

> [!note]- Ecuación r = a **Ecuación:**
> 
> ```
> r = a  (a > 0 constante)
> 
> Todos los puntos a distancia a del polo
> ```
> 
> **Características:**
> 
> ```
> - Centro: polo O
> - Radio: a
> - Ecuación cartesiana: x² + y² = a²
> ```
> 
> **Ejemplo:**
> 
> ```
> r = 3
> 
> Círculo de radio 3 centrado en el origen
> 
> Puntos: (3, 0), (3, π/4), (3, π/2), (3, π), ...
> Todos a distancia 3 del polo
> ```

### 2️⃣ Recta que Pasa por el Polo

> [!note]- Ecuación θ = α **Ecuación:**
> 
> ```
> θ = α  (α constante)
> 
> Todos los puntos en la dirección α
> ```
> 
> **Características:**
> 
> ```
> - Recta que pasa por el polo
> - Forma ángulo α con el eje polar
> - r puede tomar cualquier valor (positivo o negativo)
> ```
> 
> **Ejemplos:**
> 
> ```
> θ = 0:     Eje polar (eje x positivo)
> θ = π/2:   Perpendicular al eje polar (eje y positivo)
> θ = π:     Opuesto al eje polar (eje x negativo)
> θ = π/4:   Bisectriz del primer cuadrante
> ```

### 3️⃣ Circunferencia que Pasa por el Polo

> [!note]- Ecuaciones r = 2a cos(θ) y r = 2a sin(θ) **Horizontal (r = 2a cos(θ)):**
> 
> ```
> Centro: (a, 0) en cartesianas
> Radio: a
> Pasa por el polo
> Ecuación cartesiana: (x - a)² + y² = a²
> ```
> 
> **Vertical (r = 2a sin(θ)):**
> 
> ```
> Centro: (0, a) en cartesianas
> Radio: a
> Pasa por el polo
> Ecuación cartesiana: x² + (y - a)² = a²
> ```
> 
> **Ejemplo:**
> 
> ```
> r = 4 cos(θ)
> 
> Círculo con:
> - Centro: (2, 0)
> - Radio: 2
> - Pasa por (0,0) cuando θ = π/2
> - Diámetro sobre el eje x
> ```

## 🔍 Simetría en Coordenadas Polares

> [!important]- Tipos de Simetría **1. Simetría respecto al eje polar (eje x):**
> 
> ```
> La curva es simétrica si:
> (r, θ) está en la curva ⟹ (r, -θ) está en la curva
> 
> o equivalentemente:
> (r, θ) está en la curva ⟹ (r, 2π - θ) está en la curva
> 
> Test algebraico:
> Reemplazar θ por -θ en la ecuación
> Si se obtiene ecuación equivalente → simétrica
> ```
> 
> **2. Simetría respecto al eje perpendicular (eje y):**
> 
> ```
> La curva es simétrica si:
> (r, θ) está en la curva ⟹ (r, π - θ) está en la curva
> 
> o equivalentemente:
> (r, θ) está en la curva ⟹ (-r, -θ) está en la curva
> 
> Test algebraico:
> Reemplazar θ por (π - θ) en la ecuación
> Si se obtiene ecuación equivalente → simétrica
> ```
> 
> **3. Simetría respecto al polo (origen):**
> 
> ```
> La curva es simétrica si:
> (r, θ) está en la curva ⟹ (-r, θ) está en la curva
> 
> o equivalentemente:
> (r, θ) está en la curva ⟹ (r, θ + π) está en la curva
> 
> Test algebraico:
> Reemplazar r por -r en la ecuación
> Si se obtiene ecuación equivalente → simétrica
> ```

> [!example]- Ejemplos de Simetría
> **Ejemplo 1: r = 2 + 2cos(θ)**
> 
> ```
> Test de simetría respecto al eje polar:
> Reemplazar θ por -θ:
> r = 2 + 2cos(-θ) = 2 + 2cos(θ)
> 
> Es la MISMA ecuación ✓
> → Simétrica respecto al eje polar
> 
> Test respecto al eje perpendicular:
> Reemplazar θ por (π - θ):
> r = 2 + 2cos(π - θ) = 2 + 2(-cos(θ)) = 2 - 2cos(θ)
> 
> NO es la misma ecuación ✗
> → NO simétrica respecto al eje y
> 
> Test respecto al polo:
> Reemplazar r por -r:
> -r = 2 + 2cos(θ)
> r = -2 - 2cos(θ)
> 
> NO es la misma ecuación ✗
> → NO simétrica respecto al polo
> ```
> 
> **Ejemplo 2: r = sin(2θ)**
> 
> ```
> Test respecto al eje polar:
> r = sin(2(-θ)) = sin(-2θ) = -sin(2θ)
> → Reemplazar r por -r: -r = -sin(2θ) → r = sin(2θ) ✓
> 
> Test respecto al eje perpendicular:
> r = sin(2(π - θ)) = sin(2π - 2θ) = -sin(2θ)
> → Con r por -r: es equivalente ✓
> 
> Test respecto al polo:
> -r = sin(2θ) → r = -sin(2θ)
> NO es la misma ✗
> 
> Simétrica respecto a ambos ejes
> ```
> 
> **Ejemplo 3: r = θ (Espiral de Arquímedes)**
> 
> ```
> Test respecto al eje polar:
> r = -θ  (diferente) ✗
> 
> Test respecto al eje perpendicular:
> r = π - θ  (diferente) ✗
> 
> Test respecto al polo:
> -r = θ → r = -θ  (diferente) ✗
> 
> NO tiene ninguna simetría estándar
> ```

## 📏 Distancia entre Puntos en Polares

> [!important]- Fórmula de Distancia **Dados dos puntos P₁(r₁, θ₁) y P₂(r₂, θ₂):**
> 
> ```
> d(P₁, P₂) = √(r₁² + r₂² - 2r₁r₂cos(θ₂ - θ₁))
> 
> Esta es la ley de cosenos aplicada al triángulo
> formado por O, P₁, P₂
> ```
> 
> **Derivación:**
> 
> ```
> Convertir a cartesianas:
> P₁ = (r₁cos(θ₁), r₁sin(θ₁))
> P₂ = (r₂cos(θ₂), r₂sin(θ₂))
> 
> d² = (r₂cos(θ₂) - r₁cos(θ₁))² + (r₂sin(θ₂) - r₁sin(θ₁))²
> 
> Expandir:
> = r₂²cos²(θ₂) - 2r₁r₂cos(θ₁)cos(θ₂) + r₁²cos²(θ₁)
>   + r₂²sin²(θ₂) - 2r₁r₂sin(θ₁)sin(θ₂) + r₁²sin²(θ₁)
> 
> = r₂²(cos²(θ₂) + sin²(θ₂)) + r₁²(cos²(θ₁) + sin²(θ₁))
>   - 2r₁r₂(cos(θ₁)cos(θ₂) + sin(θ₁)sin(θ₂))
> 
> = r₁² + r₂² - 2r₁r₂cos(θ₂ - θ₁)
> ```
> 
> **Casos especiales:**
> 
> ```
> 1. Si θ₁ = θ₂ (mismo ángulo):
>    d = √(r₁² + r₂² - 2r₁r₂) = |r₁ - r₂|
>    (distancia sobre la misma línea radial)
> 
> 2. Si θ₂ - θ₁ = π/2 (ángulos perpendiculares):
>    d = √(r₁² + r₂²)
>    (teorema de Pitágoras)
> 
> 3. Si θ₂ - θ₁ = π (ángulos opuestos):
>    d = √(r₁² + r₂² + 2r₁r₂) = |r₁ + r₂|
>    (puntos en direcciones opuestas)
> 
> 4. Si uno está en el polo (r₁ = 0):
>    d = r₂
>    (distancia al polo)
> ```

> [!example]- Ejemplos de Distancia **Ejemplo 1: Ángulos diferentes**
> 
> ```
> P₁(3, π/6) y P₂(4, π/3)
> 
> θ₂ - θ₁ = π/3 - π/6 = π/6
> 
> d = √(3² + 4² - 2(3)(4)cos(π/6))
>   = √(9 + 16 - 24·(√3/2))
>   = √(25 - 12√3)
>   ≈ √(25 - 20.78)
>   ≈ √4.22
>   ≈ 2.05
> ```
> 
> **Ejemplo 2: Mismo ángulo**
> 
> ```
> P₁(2, π/4) y P₂(5, π/4)
> 
> Mismo ángulo → están sobre la misma línea radial
> 
> d = |5 - 2| = 3
> 
> Verificación con fórmula:
> d = √(4 + 25 - 2(2)(5)cos(0))
>   = √(29 - 20)
>   = √9 = 3 ✓
> ```
> 
> **Ejemplo 3: Ángulos perpendiculares**
> 
> ```
> P₁(3, 0) y P₂(4, π/2)
> 
> θ₂ - θ₁ = π/2
> 
> d = √(9 + 16 - 24cos(π/2))
>   = √(25 - 0)
>   = 5
> 
> (Teorema de Pitágoras: √(3² + 4²) = 5)
> ```
> 
> **Ejemplo 4: Con el polo**
> 
> ```
> P₁(0, cualquier) y P₂(7, π/3)
> 
> d = √(0 + 49 - 0) = 7
> 
> La distancia a cualquier punto desde el polo es r
> ```

## 🎯 Región del Plano en Polares

> [!tip]- Descripción de Regiones **Tipos de regiones:**
> 
> ```
> 1. CORONA CIRCULAR:
>    a ≤ r ≤ b  (todo θ)
>    
>    Región entre dos círculos concéntricos
> 
> 2. SECTOR CIRCULAR:
>    0 ≤ r ≤ a, α ≤ θ ≤ β
>    
>    "Rebanada de pastel"
> 
> 3. SEGMENTO ANULAR:
>    a ≤ r ≤ b, α ≤ θ ≤ β
>    
>    Combinación de corona y sector
> 
> 4. INTERIOR DE CURVA:
>    0 ≤ r ≤ f(θ), α ≤ θ ≤ β
>    
>    Región limitada por curva polar
> 
> 5. ENTRE DOS CURVAS:
>    f₁(θ) ≤ r ≤ f₂(θ), α ≤ θ ≤ β
> ```

> [!example]- Ejemplos de Regiones **Ejemplo 1: Corona circular**
> 
> ```
> 2 ≤ r ≤ 5
> 
> Región entre círculos de radio 2 y 5
> Todo θ ∈ [0, 2π)
> 
> Anillo de radio interior 2, radio exterior 5
> ```
> 
> **Ejemplo 2: Sector circular**
> 
> ```
> 0 ≤ r ≤ 4, π/6 ≤ θ ≤ π/3
> 
> Sector de círculo de radio 4
> Entre ángulos 30° y 60°
> "Rebanada" de 30° de amplitud
> ```
> 
> **Ejemplo 3: Interior de cardioide**
> 
> ```
> 0 ≤ r ≤ 1 + cos(θ), 0 ≤ θ ≤ 2π
> 
> Interior de la curva r = 1 + cos(θ)
> (cardioide completa)
> ```
> 
> **Ejemplo 4: Entre dos curvas**
> 
> ```
> 1 + sin(θ) ≤ r ≤ 2 + sin(θ), 0 ≤ θ ≤ 2π
> 
> Región entre dos cardioides
> Una trasladada de la otra
> ```

## 🔄 Ecuaciones de Curvas en Polares

> [!note]- Conversión de Ecuaciones **De cartesiana a polar:**
> 
> ```
> Sustituir:
> x = r cos(θ)
> y = r sin(θ)
> x² + y² = r²
> 
> Simplificar para obtener r en términos de θ
> ```
> 
> **De polar a cartesiana:**
> 
> ```
> Usar:
> r² = x² + y²
> tan(θ) = y/x
> r cos(θ) = x
> r sin(θ) = y
> 
> Eliminar r y θ para obtener relación entre x e y
> ```

> [!example]- Ejemplos de Conversión de Ecuaciones **Ejemplo 1: Recta vertical x = 3**
> 
> ```
> Cartesiana: x = 3
> 
> Sustituir x = r cos(θ):
> r cos(θ) = 3
> r = 3/cos(θ) = 3 sec(θ)
> 
> Polar: r = 3 sec(θ)
> ```
> 
> **Ejemplo 2: Recta horizontal y = 2**
> 
> ```
> Cartesiana: y = 2
> 
> Sustituir y = r sin(θ):
> r sin(θ) = 2
> r = 2/sin(θ) = 2 csc(θ)
> 
> Polar: r = 2 csc(θ)
> ```
> 
> **Ejemplo 3: Recta y = x**
> 
> ```
> Cartesiana: y = x
> 
> Sustituir:
> r sin(θ) = r cos(θ)
> sin(θ) = cos(θ)
> tan(θ) = 1
> θ = π/4  (o θ = 5π/4 para r < 0)
> 
> Polar: θ = π/4
> 
> (Recta que pasa por el polo)
> ```
> 
> **Ejemplo 4: Círculo x² + y² = 16**
> 
> ```
> Cartesiana: x² + y² = 16
> 
> Sustituir x² + y² = r²:
> r² = 16
> r = 4  (tomando r > 0)
> 
> Polar: r = 4
> ```
> 
> **Ejemplo 5: Círculo (x-2)² + y² = 4**
> 
> ```
> Cartesiana: (x-2)² + y² = 4
> 
> Expandir:
> x² - 4x + 4 + y² = 4
> x² + y² - 4x = 0
> 
> Sustituir x² + y² = r², x = r cos(θ):
> r² - 4r cos(θ) = 0
> r(r - 4cos(θ)) = 0
> 
> r = 0 (polo) o r = 4cos(θ)
> 
> Polar: r = 4cos(θ)
> ```
> 
> **Ejemplo 6: Parábola y² = 4x**
> 
> ```
> Cartesiana: y² = 4x
> 
> Sustituir y = r sin(θ), x = r cos(θ):
> r² sin²(θ) = 4r cos(θ)
> r sin²(θ) = 4 cos(θ)  (si r ≠ 0)
> r = 4 cos(θ)/sin²(θ)
> r = 4 cot(θ) csc(θ)
> 
> Polar: r = 4 cot(θ) csc(θ)
> ```
> 
> **Ejemplo 7: De polar a cartesiana r = 2sin(θ)**
> 
> ```
> Polar: r = 2sin(θ)
> 
> Multiplicar por r:
> r² = 2r sin(θ)
> 
> Sustituir r² = x² + y², r sin(θ) = y:
> x² + y² = 2y
> x² + y² - 2y = 0
> x² + (y - 1)² = 1
> 
> Cartesiana: x² + (y - 1)² = 1
> (Círculo con centro (0,1), radio 1)
> ```
> 
> **Ejemplo 8: De polar a cartesiana r = 1/(1 - cos(θ))**
> 
> ```
> Polar: r = 1/(1 - cos(θ))
> 
> Multiplicar ambos lados por (1 - cos(θ)):
> r(1 - cos(θ)) = 1
> r - r cos(θ) = 1
> 
> Sustituir r = √(x² + y²), r cos(θ) = x:
> √(x² + y²) - x = 1
> √(x² + y²) = 1 + x
> 
> Elevar al cuadrado:
> x² + y² = (1 + x)²
> x² + y² = 1 + 2x + x²
> y² = 1 + 2x
> y² = 2x + 1
> 
> Cartesiana: y² = 2(x + 1/2)
> (Parábola)
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes **1. "Las coordenadas polares son únicas"**
> 
> ```
> ✗ INCORRECTO
> 
> ✓ Un mismo punto tiene infinitas representaciones
>   debido a:
>   - Periodicidad: (r, θ) = (r, θ + 2πn)
>   - Simetría: (r, θ) = (-r, θ + π)
> 
> Ejemplo: (2, π/4) = (2, 9π/4) = (-2, 5π/4)
> ```
> 
> **2. "arctan(y/x) siempre da el ángulo correcto"**
> 
> ```
> ✗ INCORRECTO
> 
> ✓ arctan solo da valores en (-π/2, π/2)
>   Hay que ajustar según el cuadrante
> 
> Ejemplo: Punto (-1, 1)
> arctan(1/(-1)) = arctan(-1) = -π/4
> Pero el punto está en cuadrante II
> θ correcto = π - π/4 = 3π/4
> 
> Mejor usar atan2(y, x) en programación
> ```
> 
> **3. "r siempre es positivo"**
> 
> ```
> ✗ INCORRECTO
> 
> ✓ r puede ser negativo
>   r < 0 significa ir en dirección opuesta
> 
> (3, π/6) y (-3, 7π/6) son el mismo punto
> ```
> 
> **4. "Confundir θ en grados y radianes"**
> 
> ```
> ✗ π/4 = 3.14/4 ≈ 0.785 radianes ≠ 45 grados
> 
> ✓ π/4 radianes = 45°
>   Siempre verificar la unidad
> 
> En cálculo se usan RADIANES
> ```
> 
> **5. "El polo tiene coordenadas únicas"**
> 
> ```
> ✗ O = (0, 0) solamente
> 
> ✓ O = (0, θ) para cualquier θ
>   El ángulo es irrelevante cuando r = 0
> ```
> 
> **6. "Convertir mal de cartesiana a polar"**
> 
> ```
> Para P(-3, -4):
> 
> ✗ r = √9 + 16 = 5
>   θ = arctan(-4/-3) = arctan(4/3) ≈ 0.927
>   Resultado: (5, 0.927)
>   INCORRECTO (está en cuadrante I, punto en III)
> 
> ✓ r = 5
>   Cuadrante III: θ = π + arctan(4/3) ≈ 4.069
>   Resultado: (5, 4.069) ✓
> ```
> 
> **7. "Simetría incorrecta"**
> 
> ```
> Para probar simetría respecto al eje x:
> 
> ✗ Reemplazar y por -y en ecuación polar
>   (esto es para cartesianas)
> 
> ✓ Reemplazar θ por -θ
>   o verificar si (r, θ) = (r, -θ)
> ```
> 
> **8. "Olvidar el dominio de θ al convertir"**
> 
> ```
> y = x → tan(θ) = 1
> 
> ✗ θ = π/4 únicamente
> 
> ✓ θ = π/4 o θ = 5π/4
>   (con r positivo o negativo respectivamente)
>   Mejor: θ = π/4 describe toda la recta
> ```

## 📊 Cuadrantes y Ángulos

> [!note]- Sistema de Referencia **Cuadrantes en coordenadas polares:**
> 
> ```

>            |
>      II    |    I
>            |

## 🎓 Resumen Ejecutivo

> [!important]- Conceptos Clave **Sistema de coordenadas:**
> 
> - Polo (O): punto de referencia fijo
> - Eje polar: dirección de referencia
> - Punto P(r, θ): distancia r, ángulo θ
> 
> **Conversión cartesiana ↔ polar:**
> 
> ```
> Polar → Cartesiana:
> x = r cos(θ)
> y = r sin(θ)
> 
> Cartesiana → Polar:
> r = √(x² + y²)
> θ = atan2(y, x)  [cuidado con cuadrante]
> ```
> 
> **No unicidad:**
> 
> - (r, θ) = (r, θ + 2πn)
> - (r, θ) = (-r, θ + π)
> - (0, θ) = polo para cualquier θ
> 
> **Distancia entre puntos:**
> 
> ```
> d = √(r₁² + r₂² - 2r₁r₂cos(θ₂ - θ₁))
> ```
> 
> **Simetrías:**
> 
> - Eje x: (r, θ) → (r, -θ)
> - Eje y: (r, θ) → (r, π - θ)
> - Polo: (r, θ) → (-r, θ)
> 
> **Ventajas del sistema polar:**
> 
> - Natural para problemas circulares/radiales
> - Simplifica curvas con simetría central
> - Útil en física, navegación, ingeniería
