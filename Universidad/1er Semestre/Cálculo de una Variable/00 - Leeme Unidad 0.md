# 📊 Cálculo de una Variable — Unidad 0

**Código:** MATG1045 · **Semestre:** 1ro · **Créditos:** 4

> [!success] Bienvenido a Cálculo de una Variable
> Esta materia es la base fundamental para el resto de tu carrera en Ingeniería Computacional. Aquí aprenderás las herramientas matemáticas necesarias para modelar y resolver problemas de cambio, optimización y acumulación.

---

## 🎯 Objetivos de Aprendizaje

| Objetivo | Descripción |
|----------|-------------|
| **Límites** | Entender el concepto de límite y calcular límites de funciones de una variable |
| **Derivadas** | Calcular derivadas e interpretarlas geométricamente como tasas de cambio |
| **Aplicaciones** | Resolver problemas de optimización, relacionado con tasas y análisis de funciones |
| **Integrales** | Calcular integrales definidas e indefinidas y aplicar el Teorema Fundamental del Cálculo |
| **Aplicaciones de integrales** | Calcular áreas, volúmenes y longitudes de arco |
