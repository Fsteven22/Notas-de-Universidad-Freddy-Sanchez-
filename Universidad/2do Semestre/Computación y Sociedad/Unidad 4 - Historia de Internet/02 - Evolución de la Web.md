# 🌊 Evolución de la Web: de 1.0 a 4.0

## 🎯 Introducción

> [!info] 💡 La Web no nació terminada
> 
> Cuando Tim Berners-Lee creó la World Wide Web en 1991 ([[01 - Historia de Internet y Cómo Funciona]]), era apenas un sistema simple de documentos con enlaces. Desde entonces, la relación entre el usuario y el contenido ha cambiado radicalmente — de solo **leer** información, a **crear** contenido, a que la Web empiece a **entender y anticipar** lo que el usuario necesita.
> 
> Es común dividir esta evolución en generaciones o "versiones" de la Web para estudiar esos cambios.
> 
> ```mermaid
> graph LR
>     A["Web 1.0<br/>Solo lectura"] --> B["Web 2.0<br/>Lectura y escritura"]
>     B --> C["Web 3.0<br/>Datos inteligentes"]
>     C --> D["Web 4.0<br/>Web simbiótica / IA"]
>     style A fill:#e1f5ff
>     style D fill:#1e3a5f,color:#fff
> ```

## 📋 Las Generaciones de la Web

> [!note] 📋 Web 1.0 — La Web de solo lectura
> 
> **Época aproximada:** 1990s a inicios de los 2000s.
> 
> Las páginas eran **estáticas**: el mismo contenido se mostraba a todos los visitantes, sin posibilidad de comentar, editar o interactuar más allá de leer y hacer clic en enlaces. Funcionaban como un "folleto digital" o catálogo online.
> 
> - Tecnología principal: HTML básico.
> - Ejemplos típicos: páginas corporativas informativas, portales de noticias de solo lectura, primeras versiones de sitios como MSN.
>
> [!note] 📋 Web 2.0 — La Web social
> 
> **Época aproximada:** mediados de los 2000s en adelante.
> 
> El cambio central es que los usuarios pasan de ser solo lectores a **creadores de contenido**. Aparecen plataformas donde cualquiera puede publicar, comentar y compartir.
> 
> - Tecnologías clave: AJAX (permite actualizar partes de una página sin recargarla completa), lo que habilitó aplicaciones más interactivas.
> - Ejemplos típicos: redes sociales, blogs, wikis, plataformas de video como YouTube.
>
> [!note] 📋 Web 3.0 — La Web semántica
> 
> **Época aproximada:** concepto en desarrollo desde inicios de los 2000s, sin una fecha de "inicio" tan clara como 1.0/2.0.
> 
> La idea central es que los datos se estructuren de forma que las **máquinas puedan "entenderlos"**, no solo mostrarlos. Esto permite personalización, mejores búsquedas y recomendaciones automáticas basadas en inteligencia artificial.
> 
> - Tecnologías asociadas: datos estructurados, ontologías, algoritmos de IA aplicados a grandes volúmenes de datos.
> - Ejemplos típicos: motores de búsqueda que entienden intención (no solo palabras clave), sistemas de recomendación personalizados.
>
> [!note] 📋 Web 4.0 — La Web simbiótica
> 
> **Concepto emergente**, aún más difuso en su definición que las generaciones anteriores.
> 
> Describe una Web donde el mundo digital y el físico están estrechamente conectados: asistentes inteligentes que predicen necesidades, toman decisiones en tiempo real, y conectan dispositivos del entorno cotidiano.
> 
> - Tecnologías asociadas: inteligencia artificial avanzada, Internet de las Cosas (IoT), automatización predictiva.
> - Ejemplos típicos: asistentes de IA que anticipan lo que el usuario va a necesitar, dispositivos del hogar conectados que actúan sin intervención directa.

## 📊 Tabla Comparativa

> [!note] 📊 Web 1.0 vs. 2.0 vs. 3.0 vs. 4.0
> 
> |Generación|Rol del usuario|Idea central|Ejemplos|
> |---|---|---|---|
> |**Web 1.0**|Lector pasivo|Solo lectura, contenido estático|Páginas HTML simples, portales corporativos|
> |**Web 2.0**|Creador de contenido|Lectura y escritura, interacción social|Redes sociales, blogs, wikis, YouTube|
> |**Web 3.0**|Usuario personalizado|Datos estructurados para que las máquinas los entiendan|Búsquedas inteligentes, recomendaciones con IA|
> |**Web 4.0**|Usuario anticipado por el sistema|Web simbiótica: conexión digital-física en tiempo real|Asistentes de IA, Internet de las Cosas (IoT)|

## ⚠️ Errores Comunes

> [!warning] ⚠️ No todas las "Web X.0" tienen una fecha oficial de inicio
> 
> A diferencia de versiones de software con lanzamientos formales, las generaciones de la Web (especialmente 3.0 y 4.0) son categorías **retrospectivas y conceptuales** creadas por distintos autores para describir tendencias, no anuncios oficiales de un solo organismo. No hay una definición 100% estandarizada de cuándo empieza cada una.
>
> [!warning] ⚠️ Web 2.0 no fue un cambio de tecnología pura, sino de uso
> 
> Un error común es pensar que Web 2.0 fue "una nueva versión de HTML" o un cambio técnico exclusivamente. En realidad, el cambio más importante fue de **comportamiento**: los usuarios empezaron a generar contenido masivamente, y la tecnología (como AJAX) fue lo que hizo posible soportar ese comportamiento de forma fluida.

## 📝 Ejercicios Progresivos

> [!question] 🟩 Nivel 1 — Básico
> 
> 1. ¿Cuál es la diferencia principal entre Web 1.0 y Web 2.0?
> 2. Da un ejemplo de sitio o servicio típico de Web 1.0 y uno típico de Web 2.0.
> 3. ¿Qué significa que la Web 3.0 sea "semántica"?
>
> [!question] 🟨 Nivel 2 — Intermedio
> 
> 4. Explica qué tipo de tecnología permitió el salto de Web 1.0 (estática) a Web 2.0 (interactiva).
> 5. Compara Web 3.0 y Web 4.0: ¿en qué se parecen y en qué se diferencian sus objetivos?
>
> [!question] 🟥 Nivel 3 — Avanzado
> 
> 6. Argumenta por qué Web 3.0 y Web 4.0 son conceptos más difíciles de "fechar" que Web 1.0 y Web 2.0.
> 7. Un sitio permite a los usuarios comentar y compartir contenido, pero además personaliza automáticamente lo que cada usuario ve según su comportamiento pasado usando IA. ¿En qué generación(es) de la Web encaja este ejemplo? Justifica.
>
> [!success]- ✅ Respuestas
> 
> **Nivel 1:**
> 
> 8. Web 1.0 es de solo lectura (el usuario consume contenido fijo); Web 2.0 permite que el usuario también cree, comente y comparta contenido.
> 9. Web 1.0: una página corporativa estática de solo texto e imágenes sin comentarios. Web 2.0: una red social o blog donde los usuarios publican y comentan.
> 10. Que los datos están estructurados de forma que las máquinas (no solo las personas) puedan interpretarlos y relacionarlos, permitiendo búsquedas más inteligentes y personalización automática.
> 
> **Nivel 2:**
> 
> 11. Tecnologías como AJAX permitieron actualizar partes de una página sin recargarla por completo, lo que hizo posible aplicaciones mucho más interactivas y dinámicas, habilitando el modelo de creación y edición de contenido típico de Web 2.0.
> 12. Ambas usan inteligencia artificial y buscan mejorar la experiencia del usuario más allá de mostrar información fija. Se diferencian en el alcance: Web 3.0 se enfoca en que los datos sean comprensibles para las máquinas (personalización y búsqueda inteligente); Web 4.0 va más allá, buscando una integración en tiempo real entre el mundo físico y digital (dispositivos conectados, anticipación de necesidades).
> 
> **Nivel 3:**
> 
> 13. Web 1.0 y 2.0 describen cambios tecnológicos y de uso ya ocurridos y ampliamente documentados, con ejemplos concretos y consolidados en el tiempo. Web 3.0 y 4.0 describen tendencias todavía en desarrollo que distintos autores conceptualizan de forma algo distinta, por lo que no existe un evento o fecha única y universalmente aceptada que marque su "inicio", a diferencia de hitos históricos ya cerrados.
> 14. Encaja principalmente en Web 2.0 (por la interacción social: comentar y compartir) combinado con elementos de Web 3.0 (personalización automática basada en datos e IA). Esto ilustra que las generaciones de la Web no son compartimentos estrictamente separados: un sitio real puede combinar características de varias generaciones a la vez.
