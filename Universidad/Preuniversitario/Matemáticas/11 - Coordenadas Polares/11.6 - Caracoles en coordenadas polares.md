# 🐚 Caracoles en Coordenadas Polares

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Los caracoles (o limaçons) son una familia de curvas en coordenadas polares definidas por ecuaciones de la forma r = a ± b cos θ o r = a ± b sen θ, donde a, b > 0. Su nombre proviene del francés "limaçon" (caracol), debido a su forma característica que puede incluir un bucle interior, una hendidura, ser convexa o tener forma de cardioide. La relación entre a y b determina la forma específica de la curva.**
> 
> **Características clave:**
> 
> - **Ecuación general:** r = a ± b cos θ o r = a ± b sen θ
> - **Parámetros:** a, b > 0 determinan la forma
> - **Clasificación:** según la razón a/b
> - **Simetría:** respecto a ejes coordenados
> - **Casos especiales:** cardioide (a = b), circunferencia (b = 0)
> - **Bucles:** pueden aparecer cuando b > a

## 🎯 Definición y Ecuaciones

> [!important]- Formas Generales **Ecuación estándar (eje horizontal):**
> 
> ```
> Forma con coseno:
> r = a + b cos θ  (apertura hacia derecha)
> r = a - b cos θ  (apertura hacia izquierda)
> 
> donde:
> • a > 0: constante (controla tamaño)
> • b > 0: amplitud (controla forma)
> • θ ∈ [0, 2π]: ángulo polar
> 
> Simetría: respecto al eje polar (eje x)
> 
> Equivalencia:
> r = a - b cos θ = a + b cos(θ + π)
> (rotación de 180°)
> ```
> 
> **Ecuación estándar (eje vertical):**
> 
> ```
> Forma con seno:
> r = a + b sen θ  (apertura hacia arriba)
> r = a - b sen θ  (apertura hacia abajo)
> 
> Simetría: respecto al eje θ = π/2 (eje y)
> 
> Relación con coseno:
> r = a + b sen θ = a + b cos(θ - π/2)
> (rotación de 90°)
> ```
> 
> **Parámetros y escalamiento:**
> 
> ```
> Factor multiplicativo:
> r = k(a + b cos θ)
> 
> Escala toda la curva por factor k
> Forma se mantiene, tamaño cambia
> 
> Normalización común:
> Dividir por b: r/b = (a/b) + cos θ
> r = b[(a/b) + cos θ]
> 
> Razón crítica: λ = a/b
> Determina clasificación de la curva
> ```

## 📊 Clasificación por Forma

> [!success]- Tipos de Caracoles **Caso 1: b > a (λ < 1) - Caracol con bucle interior**
> 
> ```
> Condición: b > a  o  a/b < 1
> 
> Características:
> • Bucle interior (lazo)
> • Pasa por el origen DOS veces
> • r < 0 en cierto rango de θ
> • Forma de "8" o bucle interno
> 
> Valores de r:
> r_max = a + b (en θ = 0 para cos)
> r_min = a - b < 0 (en θ = π)
> 
> El bucle ocurre cuando r < 0:
> a + b cos θ < 0
> cos θ < -a/b
> θ ∈ [arccos(-a/b), 2π - arccos(-a/b)]
> 
> Ejemplo:
> r = 1 + 2 cos θ
> a = 1, b = 2, λ = 0.5
> Bucle cuando cos θ < -1/2
> θ ∈ [2π/3, 4π/3]
> ```
> 
> **Caso 2: b = a (λ = 1) - Cardioide**
> 
> ```
> Condición: a = b  o  a/b = 1
> 
> Ecuación: r = a(1 + cos θ) o r = a(1 + sen θ)
> 
> Características:
> • Forma de corazón
> • Pasa por origen UNA vez (tangente)
> • r ≥ 0 para todo θ
> • No hay bucle interior
> • Punto cúspide en el origen
> 
> Valores extremos:
> r_max = 2a (en θ = 0 para cos)
> r_min = 0 (en θ = π)
> 
> Nombre: del griego "kardia" (corazón)
> 
> Ejemplo:
> r = 3(1 + cos θ)
> Cardioide con "altura" 6
> ```
> 
> **Caso 3: a > b > 0, a < 2b (1 < λ < 2) - Caracol hendido**
> 
> ```
> Condición: a > b pero a < 2b
>            1 < a/b < 2
> 
> Características:
> • Hendidura (indentación) sin bucle
> • NO pasa por el origen
> • r > 0 para todo θ
> • Cintura estrecha (forma de riñón)
> • "Dimple" en inglés
> 
> Valores extremos:
> r_max = a + b
> r_min = a - b > 0
> 
> Radio mínimo positivo pero pequeño
> 
> Ejemplo:
> r = 3 + 2 cos θ
> a = 3, b = 2, λ = 1.5
> r_min = 1, r_max = 5
> ```
> 
> **Caso 4: a ≥ 2b (λ ≥ 2) - Caracol convexo**
> 
> ```
> Condición: a ≥ 2b  o  a/b ≥ 2
> 
> Características:
> • Forma convexa (ovalada)
> • Sin hendidura aparente
> • r > 0 para todo θ
> • Aspecto de elipse deformada
> • Suave y redondeada
> 
> Valores extremos:
> r_max = a + b
> r_min = a - b ≥ b > 0
> 
> Cuando a >> b: casi circular
> 
> Ejemplo:
> r = 5 + 2 cos θ
> a = 5, b = 2, λ = 2.5
> r_min = 3, r_max = 7
> Forma casi elíptica
> ```
> 
> **Caso 5: b = 0 - Circunferencia**
> 
> ```
> Condición: b = 0
> 
> Ecuación: r = a
> 
> Degeneración del caracol:
> Circunferencia de radio a centrada en origen
> 
> Límite: cuando b → 0, el caracol
> se aproxima a un círculo
> ```

## 🔄 Propiedades Geométricas

> [!note]- Características Importantes **Simetría:**
> 
> ```
> r = a + b cos θ:
> Simetría respecto al eje polar (eje x)
> Propiedad: r(θ) = r(-θ)
> 
> r = a + b sen θ:
> Simetría respecto a θ = π/2 (eje y)
> Propiedad: r(π - θ) = r(θ)
> 
> Ambas formas:
> Periodicidad de 2π
> r(θ + 2π) = r(θ)
> ```
> 
> **Puntos especiales:**
> 
> ```
> Para r = a + b cos θ:
> 
> Punto más alejado (θ = 0):
> r_max = a + b
> Coordenadas: (a+b, 0)
> Cartesianas: (a+b, 0)
> 
> Punto más cercano (θ = π):
> r_min = a - b
> Coordenadas: (|a-b|, π)
> Cartesianas: (-(a-b), 0) si a > b
>              (b-a, 0) si b > a
> 
> Intersección con eje y (θ = π/2, 3π/2):
> r = a
> Puntos: (a, π/2) y (a, 3π/2)
> Cartesianas: (0, a) y (0, -a)
> 
> Origen (si b ≥ a):
> a + b cos θ = 0
> cos θ = -a/b
> θ = arccos(-a/b), 2π - arccos(-a/b)
> ```
> 
> **Tangentes:**
> 
> ```
> Pendiente en coordenadas polares:
> dy/dx = (dr/dθ · sen θ + r cos θ)
>         ──────────────────────────
>         (dr/dθ · cos θ - r sen θ)
> 
> Para r = a + b cos θ:
> dr/dθ = -b sen θ
> 
> Tangente horizontal (dy/dx = 0):
> dr/dθ · sen θ + r cos θ = 0
> -b sen θ · sen θ + (a + b cos θ) cos θ = 0
> -b sen² θ + a cos θ + b cos² θ = 0
> b(cos² θ - sen² θ) + a cos θ = 0
> b cos(2θ) + a cos θ = 0
> 
> Tangente vertical (denominador = 0):
> dr/dθ · cos θ - r sen θ = 0
> -b sen θ cos θ - (a + b cos θ) sen θ = 0
> -b sen θ cos θ - a sen θ - b sen θ cos θ = 0
> -2b sen θ cos θ - a sen θ = 0
> sen θ(-b sen(2θ) - a) = 0
> ```
> 
> **Área encerrada:**
> 
> ```
> Área total del caracol:
> A = (1/2) ∫₀²π r² dθ
> 
> Para r = a + b cos θ:
> A = (1/2) ∫₀²π (a + b cos θ)² dθ
> A = (1/2) ∫₀²π (a² + 2ab cos θ + b² cos² θ) dθ
> 
> Desarrollar:
> ∫₀²π a² dθ = 2πa²
> ∫₀²π 2ab cos θ dθ = 0
> ∫₀²π b² cos² θ dθ = ∫₀²π b²(1 + cos 2θ)/2 dθ = πb²
> 
> A = (1/2)(2πa² + πb²)
> A = π(a² + b²/2)
> 
> Nota: incluye área del bucle si existe
> ```
> 
> **Longitud de arco:**
> 
> ```
> Longitud total:
> L = ∫₀²π √(r² + (dr/dθ)²) dθ
> 
> Para r = a + b cos θ:
> dr/dθ = -b sen θ
> 
> L = ∫₀²π √((a + b cos θ)² + b² sen² θ) dθ
> L = ∫₀²π √(a² + 2ab cos θ + b² cos² θ + b² sen² θ) dθ
> L = ∫₀²π √(a² + 2ab cos θ + b²) dθ
> 
> No tiene forma cerrada simple en general
> Requiere métodos numéricos o funciones elípticas
> ```

## 🎨 La Cardioide

> [!tip]- Caso Especial a = b **Definición:**
> 
> ```
> Cardioide: r = a(1 + cos θ) o r = a(1 + sen θ)
> 
> Nombre: del griego "kardia" (corazón)
> por su forma característica
> 
> Caso especial del caracol con a = b
> ```
> 
> **Propiedades especiales:**
> 
> ```
> Punto cúspide en el origen:
> r = 0 cuando θ = π (para coseno)
> Tangente vertical en el origen
> 
> Punto máximo:
> r = 2a cuando θ = 0 (para coseno)
> 
> Simetría perfecta:
> Respecto al eje que contiene el punto cúspide
> 
> Ancho máximo:
> En θ = π/2: r = a
> Ancho total: 2a
> 
> "Altura" total (para cos):
> Desde origen hasta punto más alejado: 2a
> ```
> 
> **Ecuaciones alternativas:**
> 
> ```
> Forma factorizada:
> r = a(1 + cos θ)
> r = a(1 - cos θ) (rotada 180°)
> r = a(1 + sen θ) (rotada 90°)
> r = a(1 - sen θ) (rotada 270°)
> 
> Forma cartesiana:
> (x² + y² - ax)² = a²(x² + y²)
> 
> Muy compleja en cartesianas
> Mucho más simple en polares
> ```
> 
> **Área de cardioide:**
> 
> ```
> A = (1/2) ∫₀²π [a(1 + cos θ)]² dθ
> A = (a²/2) ∫₀²π (1 + 2 cos θ + cos² θ) dθ
> A = (a²/2) ∫₀²π [1 + 2 cos θ + (1 + cos 2θ)/2] dθ
> A = (a²/2) ∫₀²π [3/2 + 2 cos θ + cos(2θ)/2] dθ
> A = (a²/2)[3θ/2 + 2 sen θ + sen(2θ)/4]₀²π
> A = (a²/2)(3π)
> A = 3πa²/2
> 
> Relación con círculo de radio a:
> A_cardioide = (3/2)πa² = (3/2)A_círculo
> ```
> 
> **Longitud de cardioide:**
> 
> ```
> L = 8a
> 
> Resultado notable: longitud = 8 veces el parámetro
> 
> Demostración requiere:
> L = ∫₀²π √(r² + (dr/dθ)²) dθ
> con r = a(1 + cos θ)
> Resultado: L = 8a
> ```
> 
> **Generación cinemática:**
> 
> ```
> Cardioide como:
> • Trayectoria de punto en círculo que rueda
>   alrededor de círculo fijo del mismo radio
> • Epicicloide con razón 1:1
> • Envolvente de círculos
> ```

## 🧮 Problemas Resueltos

> [!example]- Ejemplos Detallados **Problema 1: Clasificar caracol**
> 
> ```
> r = 2 + 3 cos θ
> Clasificar y describir
> 
> SOLUCIÓN:
> 
> Identificar parámetros:
> a = 2, b = 3
> 
> Razón: λ = a/b = 2/3 ≈ 0.67
> 
> Como b > a (o λ < 1):
> Caracol con bucle interior
> 
> Valores extremos:
> r_max = a + b = 2 + 3 = 5 (en θ = 0)
> r_min = a - b = 2 - 3 = -1 (en θ = π)
> 
> Bucle interior cuando r < 0:
> 2 + 3 cos θ < 0
> cos θ < -2/3
> θ ∈ [arccos(-2/3), 2π - arccos(-2/3)]
> θ ∈ [131.8°, 228.2°] aproximadamente
> 
> Pasa por origen cuando:
> cos θ = -2/3
> θ ≈ 2.30 rad y θ ≈ 3.98 rad
> 
> Simetría: respecto al eje x (polar)
> ```
> 
> **Problema 2: Cardioide**
> 
> ```
> r = 4(1 + sen θ)
> Encontrar área y puntos clave
> 
> SOLUCIÓN:
> 
> Tipo: Cardioide (a = b = 4)
> 
> Puntos clave:
> θ = 0: r = 4(1 + 0) = 4
>        Punto: (4, 0) → (4, 0) cartesiano
> 
> θ = π/2: r = 4(1 + 1) = 8
>          Punto: (8, π/2) → (0, 8) cartesiano
>          Punto más alejado
> 
> θ = π: r = 4(1 + 0) = 4
>        Punto: (4, π) → (-4, 0) cartesiano
> 
> θ = 3π/2: r = 4(1 - 1) = 0
>           Origen (punto cúspide)
> 
> Área:
> A = 3πa²/2 = 3π(4)²/2 = 24π unidades²
> 
> Simetría: respecto a θ = π/2 (eje y)
> ```
> 
> **Problema 3: Intersección con eje**
> 
> ```
> r = 3 + 2 cos θ
> Puntos donde cruza el eje y
> 
> SOLUCIÓN:
> 
> Eje y: θ = π/2 o θ = 3π/2
> 
> En θ = π/2:
> r = 3 + 2 cos(π/2) = 3 + 0 = 3
> Punto polar: (3, π/2)
> Cartesiano: (0, 3)
> 
> En θ = 3π/2:
> r = 3 + 2 cos(3π/2) = 3 + 0 = 3
> Punto polar: (3, 3π/2)
> Cartesiano: (0, -3)
> 
> Cruza eje y en (0, 3) y (0, -3)
> Simetría respecto al eje x
> ```
> 
> **Problema 4: Área de bucle**
> 
> ```
> r = 1 + 2 cos θ
> Encontrar área del bucle interior
> 
> SOLUCIÓN:
> 
> Bucle ocurre cuando r < 0:
> 1 + 2 cos θ < 0
> cos θ < -1/2
> 
> Límites: θ₁ = 2π/3, θ₂ = 4π/3
> 
> Área del bucle (valor absoluto):
> A_bucle = (1/2) ∫₂π/₃⁴π/³ r² dθ
> 
> Como r < 0 en este rango, usamos |r|:
> A_bucle = (1/2) ∫₂π/₃⁴π/³ (1 + 2 cos θ)² dθ
> 
> Expandir:
> (1 + 2 cos θ)² = 1 + 4 cos θ + 4 cos² θ
>                 = 1 + 4 cos θ + 2(1 + cos 2θ)
>                 = 3 + 4 cos θ + 2 cos 2θ
> 
> Integrar:
> A = (1/2)[3θ + 4 sen θ + sen 2θ]₂π/₃⁴π/³
> 
> Evaluar:
> En θ = 4π/3:
> 3(4π/3) + 4 sen(4π/3) + sen(8π/3)
> = 4π - 4(√3/2) + √3/2
> = 4π - 2√3 + √3/2 = 4π - 3√3/2
> 
> En θ = 2π/3:
> 3(2π/3) + 4 sen(2π/3) + sen(4π/3)
> = 2π + 4(√3/2) - √3/2
> = 2π + 2√3 - √3/2 = 2π + 3√3/2
> 
> A = (1/2)[(4π - 3√3/2) - (2π + 3√3/2)]
> A = (1/2)[2π - 3√3]
> A = π - 3√3/2 ≈ 0.544 unidades²
> ```
> 
> **Problema 5: Tangente en punto**
> 
> ```
> r = 2 + cos θ
> Encontrar ecuación de tangente en θ = π/3
> 
> SOLUCIÓN:
> 
> En θ = π/3:
> r = 2 + cos(π/3) = 2 + 1/2 = 5/2
> 
> Punto polar: (5/2, π/3)
> Cartesiano: x = (5/2) cos(π/3) = 5/4
>            y = (5/2) sen(π/3) = 5√3/4
> Punto: (5/4, 5√3/4)
> 
> Pendiente:
> dy/dx = (dr/dθ · sen θ + r cos θ)
>         ──────────────────────────
>         (dr/dθ · cos θ - r sen θ)
> 
> dr/dθ = -sen θ
> En θ = π/3: dr/dθ = -√3/2
> 
> Numerador:
> (-√3/2)(√3/2) + (5/2)(1/2)
> = -3/4 + 5/4 = 2/4 = 1/2
> 
> Denominador:
> (-√3/2)(1/2) - (5/2)(√3/2)
> = -√3/4 - 5√3/4 = -6√3/4 = -3√3/2
> 
> Pendiente:
> m = (1/2)/(-3√3/2) = -1/(3√3) = -√3/9
> 
> Ecuación tangente:
> y - 5√3/4 = (-√3/9)(x - 5/4)
> 
> Simplificar:
> 9y - 45√3/4 = -√3x + 5√3/4
> 9y = -√3x + 5√3/4 + 45√3/4
> 9y = -√3x + 50√3/4
> 36y = -4√3x + 50√3
> ```
> 
> **Problema 6: Convertir a cartesianas**
> 
> ```
> r = 3(1 + cos θ)
> Expresar en coordenadas cartesianas
> 
> SOLUCIÓN:
> 
> Método:
> r = 3 + 3 cos θ
> r = 3 + 3(x/r)
> r² = 3r + 3x
> x² + y² = 3√(x² + y²) + 3x
> 
> Aislar radical:
> x² + y² - 3x = 3√(x² + y²)
> 
> Elevar al cuadrado:
> (x² + y² - 3x)² = 9(x² + y²)
> 
> Expandir:
> (x² + y²)² - 6x(x² + y²) + 9x² = 9x² + 9y²
> (x² + y²)² - 6x(x² + y²) = 9y²
> 
> Forma implícita:
> (x² + y² - 3x)² = 9(x² + y²)
> 
> Mucho más compleja que forma polar
> Demuestra ventaja de coordenadas polares
> ```
> 
> **Problema 7: Familia de caracoles**
> 
> ```
> r = a + cos θ para a = 0.5, 1, 1.5, 2
> Describir cómo cambia la forma
> 
> SOLUCIÓN:
> 
> Parámetro b = 1 (fijo)
> Varía a, por tanto varía λ = a/b = a
> 
> a = 0.5: λ = 0.5 < 1
> Caracol con bucle interior
> r ∈ [-0.5, 1.5]
> 
> a = 1: λ = 1
> Cardioide (transición)
> r ∈ [0, 2]
> Punto cúspide en origen
> 
> a = 1.5: λ = 1.5 (1 < λ < 2)
> Caracol hendido
> r ∈ [0.5, 2.5]
> Hendidura visible
> 
> a = 2: λ = 2
> Caracol convexo (límite)
> r ∈ [1, 3]
> Casi ovalado
> 
> Transición: bucle → cardioide → hendidura → convexo
> ```
> 
> **Problema 8: Distancia máxima al origen**
> 
> ```
> r = 5 - 3 cos θ
> Encontrar punto más alejado del origen
> 
> SOLUCIÓN:
> 
> Forma: r = a - b cos θ
> a = 5, b = 3
> 
> Para r = a - b cos θ:
> r es máximo cuando cos θ es mínimo
> 
> cos θ_min = -1 en θ = π
> 
> r_max = 5 - 3(-1) = 5 + 3 = 8
> 
> Punto polar: (8, π)
> Cartesiano: (8 cos π, 8 sen π) = (-8, 0)
> 
> Punto más alejado: (-8, 0)
> Distancia al origen: 8 unidades
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes **1. "Si r < 0, el punto no existe"**
> 
> ```
> ✗ FALSO - r negativo es válido en polares
> 
> (r, θ) con r < 0 significa:
> Punto en dirección θ + π a distancia |r|
> 
> El bucle interior existe precisamente
> cuando r toma valores negativos
> ```
> 
> **2. "Cardioide siempre tiene forma de corazón vertical"**
> 
> ```
> ✗ FALSO - depende de la orientación
> 
> r = a(1 + cos θ): corazón horizontal (→)
> r = a(1 + sen θ): corazón vertical (↑) r = a(1 - cos θ): corazón horizontal (←) r = a(1 - sen θ): corazón vertical (↓)
> 
> La orientación depende de la función trigonométrica y del signo
> 
> ```
> 
> **3. "Confundir clasificación por λ = a/b"**
> 
> ```
> 
> ✗ λ < 1: bucle interior ✗ λ = 1: cardioide ✗ 1 < λ < 2: hendido ✗ λ ≥ 2: convexo
> 
> ERROR común: invertir la razón (usar b/a) CORRECTO: siempre usar λ = a/b
> 
> ```
> 
> **4. "El área del bucle es negativa"**
> 
> ```
> 
> ✗ FALSO - el área siempre es positiva
> 
> Aunque r < 0 en el bucle, la integral usa r², que siempre es positivo
> 
> A = (1/2) ∫ r² dθ ≥ 0 siempre
> 
> ```
> 
> **5. "Todos los caracoles pasan por el origen"**
> 
> ```
> 
> ✗ FALSO
> 
> Solo cuando b ≥ a el caracol pasa por origen
> 
> b > a: pasa dos veces (bucle) b = a: pasa una vez (cardioide, tangente) b < a: NO pasa por origen
> 
> ```
> 
> **6. "El rango de θ es [0, π]"**
> 
> ```
> 
> ✗ FALSO para caracoles
> 
> ✓ Rango completo: θ ∈ [0, 2π]
> 
> A diferencia de circunferencias tangentes, los caracoles requieren el rango completo para trazar toda la curva
> 
> ```
> 
> **7. "Área de caracol = suma de dos semicírculos"**
> 
> ```
> 
> ✗ FALSO - no son composiciones de círculos
> 
> Forma correcta: A = π(a² + b²/2)
> 
> Para cardioide (a = b): A = π(a² + a²/2) = 3πa²/2
> ```

## 📏 Variantes y Generalizaciones

> [!note]- Formas Extendidas **Caracol con desfase angular:**
> 
> ```
> r = a + b cos(θ - α)
> r = a + b sen(θ - β)
> 
> Efecto: rotación de la curva por ángulo α o β
> 
> Ejemplo:
> r = 2 + 3 cos(θ - π/4)
> Caracol con bucle rotado 45° antihorario
> ```
> 
> **Caracol con frecuencia modificada:**
> 
> ```
> r = a + b cos(nθ)
> 
> n = 1: caracol estándar
> n = 2: rosa de dos pétalos modificada
> n ≥ 3: formas complejas (no caracoles típicos)
> 
> Ejemplo:
> r = 2 + cos(2θ)
> Curva con cuatro lóbulos
> ```
> 
> **Caracol con múltiples términos:**
> 
> ```
> r = a + b cos θ + c cos(2θ)
> 
> Superposición de armónicos
> Formas más complejas y variadas
> 
> Aplicaciones en análisis de Fourier
> ```
> 
> **Caracol elíptico:**
> 
> ```
> r = a + b cos θ + c sen θ
> 
> Combinación de direcciones
> Asimetría en dos ejes
> No tiene simetría simple
> ```

## 🔬 Análisis Matemático Avanzado

> [!tip]- Propiedades Profundas **Curvatura:**
> 
> ```
> Curvatura κ en coordenadas polares:
> 
> κ = |r² + 2(dr/dθ)² - r(d²r/dθ²)|
>     ────────────────────────────────
>     [r² + (dr/dθ)²]^(3/2)
> 
> Para r = a + b cos θ:
> dr/dθ = -b sen θ
> d²r/dθ² = -b cos θ
> 
> En origen (cardioide a = b):
> θ = π, r = 0
> Curvatura infinita (punto cúspide)
> 
> En punto máximo:
> θ = 0, r = a + b
> Curvatura mínima
> ```
> 
> **Centro de masa:**
> 
> ```
> Para región encerrada por r = a + b cos θ:
> 
> Coordenadas del centroide (x̄, ȳ):
> 
> x̄ = (1/A) ∫∫ x dA
> ȳ = (1/A) ∫∫ y dA
> 
> En polares:
> x̄ = (1/3A) ∫₀²π r³ cos θ dθ
> ȳ = (1/3A) ∫₀²π r³ sen θ dθ
> 
> Para caracoles simétricos (cos θ):
> Por simetría: ȳ = 0
> x̄ > 0 (desplazado hacia +x)
> 
> Para cardioide r = a(1 + cos θ):
> x̄ = 5a/6
> ȳ = 0
> ```
> 
> **Momento de inercia:**
> 
> ```
> Momento respecto al origen:
> 
> I₀ = ∫∫ r² ρ dA
> 
> Donde ρ es densidad (asumida constante)
> 
> En polares:
> I₀ = ρ(1/2) ∫₀²π r⁴ dθ
> 
> Para r = a + b cos θ:
> Requiere expandir (a + b cos θ)⁴
> e integrar término a término
> ```
> 
> **Ecuación diferencial:**
> 
> ```
> Los caracoles satisfacen ciertas EDOs
> 
> Para r = a + b cos θ:
> (dr/dθ)² = b² sen² θ = b²(1 - cos² θ)
> 
> Desde r: cos θ = (r - a)/b
> 
> (dr/dθ)² = b²[1 - ((r-a)/b)²]
> (dr/dθ)² = b² - (r - a)²
> 
> dr/√(b² - (r-a)²) = dθ
> ```

> CARACOLES EN COORDENADAS POLARES - RESUMEN

> ECUACIONES ESTÁNDAR
> ═══════════════════════════════════════════
> Eje horizontal:
> r = a + b cos θ  (apertura derecha)
> r = a - b cos θ  (apertura izquierda)
> 
> Eje vertical:
> r = a + b sen θ  (apertura arriba)
> r = a - b sen θ  (apertura abajo)
> 
> Parámetros: a, b > 0
> Rango: θ ∈ [0, 2π]
> 
> ═══════════════════════════════════════════
> CLASIFICACIÓN POR λ = a/b
> ═══════════════════════════════════════════
> λ < 1 (b > a):
> Caracol con bucle interior
> Pasa por origen dos veces
> 
> λ = 1 (a = b):
> Cardioide
> Pasa por origen una vez (cúspide)
> 
> 1 < λ < 2 (a > b, a < 2b):
> Caracol hendido (dimpled)
> No pasa por origen
> Hendidura visible
> 
> λ ≥ 2 (a ≥ 2b):
> Caracol convexo
> Forma ovalada suave
> 
> ═══════════════════════════════════════════
> PUNTOS CLAVE (r = a + b cos θ)
> ═══════════════════════════════════════════
> Máximo: r = a + b en θ = 0
> Mínimo: r = a - b en θ = π
> Eje y: r = a en θ = π/2, 3π/2
> 
> Origen (si b ≥ a):
> θ = arccos(-a/b), 2π - arccos(-a/b)
> 
> ═══════════════════════════════════════════
> CARDIOIDE r = a(1 + cos θ)
> ═══════════════════════════════════════════
> Área: A = 3πa²/2
> Longitud: L = 8a
> Punto cúspide: origen (θ = π)
> Punto máximo: (2a, 0) en θ = 0
> 
> ═══════════════════════════════════════════
> ÁREA GENERAL
> ═══════════════════════════════════════════
> Caracol r = a + b cos θ:
> A = π(a² + b²/2)
> 
> Incluye área del bucle si existe
> 
> ═══════════════════════════════════════════
> SIMETRÍA
> ═══════════════════════════════════════════
> r = a + b cos θ: simetría eje x
> r = a + b sen θ: simetría eje y
> 
> Propiedad: r(θ) = r(-θ) para cos
>           r(π-θ) = r(θ) para sen
> ```

## 💡 Ejercicios Adicionales

> [!example]- Problemas para Práctica **Problema 9: Comparación de áreas**
> 
> ```
> Comparar áreas de:
> r₁ = 1 + cos θ (cardioide)
> r₂ = 1 + 2 cos θ (bucle)
> 
> ¿Cuál encierra mayor área?
> 
> SOLUCIÓN:
> 
> Área cardioide:
> A₁ = 3π(1)²/2 = 3π/2
> 
> Área caracol con bucle:
> A₂ = π(a² + b²/2) = π(1 + 4/2) = 3π
> 
> Comparación:
> A₂/A₁ = 3π/(3π/2) = 2
> 
> El caracol con bucle tiene DOBLE área
> ```
> 
> **Problema 10: Intersección de caracoles**
> 
> ```
> r₁ = 2 + cos θ
> r₂ = 1 + 2 cos θ
> Encontrar puntos de intersección
> 
> SOLUCIÓN:
> 
> Igualar:
> 2 + cos θ = 1 + 2 cos θ
> 2 - 1 = 2 cos θ - cos θ
> 1 = cos θ
> θ = 0
> 
> En θ = 0:
> r = 2 + 1 = 3
> 
> Punto: (3, 0) cartesiano
> 
> También verificar origen:
> r₁ = 0: no tiene solución (a > b)
> r₂ = 0: cos θ = -1/2, θ = 2π/3, 4π/3
> 
> Solo intersección en (3, 0)
> ```
> 
> **Problema 11: Rotación de caracol**
> 
> ```
> r = 3 + 2 cos θ
> Rotar 90° antihorario
> Encontrar nueva ecuación
> 
> SOLUCIÓN:
> 
> Rotación: θ → θ - π/2
> 
> Nueva ecuación:
> r = 3 + 2 cos(θ - π/2)
> r = 3 + 2 sen θ
> 
> Forma equivalente con seno
> Apertura hacia arriba
> ```
