# 📈 Gráficas de Funciones Trigonométricas

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Las gráficas de funciones trigonométricas son representaciones visuales de cómo varían el seno, coseno y otras funciones respecto al ángulo. Muestran patrones ondulatorios periódicos que modelan fenómenos oscilatorios.**
> 
> **Elementos clave:**
> 
> - **Periodicidad:** Patrones que se repiten regularmente
> - **Amplitud:** Altura máxima de la onda
> - **Fase:** Desplazamiento horizontal de la onda
> - **Frecuencia:** Rapidez de oscilación
> - **Asíntotas:** Líneas que la función se aproxima pero no toca

### 📖 Contexto Histórico

> [!note]- Desarrollo Visual de la Trigonometría
> 
> **Era Pre-Gráfica (300 a.C. - 1600):**
> 
> - **Hiparco y Ptolomeo:** Tablas numéricas solamente
> - **Sin representación visual:** Solo valores discretos
> - **Enfoque astronómico:** Cálculos, no visualización
> 
> **Nacimiento de las Gráficas (1600-1700):**
> 
> - **Descartes (1637):** Geometría analítica
> - **Coordenadas cartesianas:** Posibilidad de graficar
> - **Newton/Leibniz:** Cálculo y curvas
> 
> **Visualización Trigonométrica (1700-1800):**
> 
> - **Euler (1748):** Tratamiento analítico de funciones
> - **Primeras gráficas:** Representación de ondas
> - **Series de Fourier (1822):** Descomposición de ondas
> 
> **Era Moderna (1800-presente):**
> 
> - **Osciloscopios:** Visualización de ondas eléctricas
> - **Procesamiento de señales:** Análisis espectral
> - **Computación:** Graficación precisa e interactiva
> - **Aplicaciones:** Ondas, vibraciones, ciclos naturales

## 📊 Gráfica de y = sin(x)

> [!success]- La Función Seno
> 
> **Características fundamentales:**
> 
> ```
> f(x) = sin(x)
> 
> Dominio: ℝ
> Rango: [-1, 1]
> Periodo: 2π (360°)
> Amplitud: 1
> ```
> 
> **Puntos clave en un periodo [0, 2π]:**
> 
> ```
> x     | 0  | π/2 | π  | 3π/2 | 2π
> ------|----|----|----|----|----
> sin(x)| 0  | 1   | 0  | -1   | 0
> ```
> 
> **Comportamiento:**
> 
> ```
> [0, π/2]:     Creciente de 0 a 1
> [π/2, π]:     Decreciente de 1 a 0
> [π, 3π/2]:    Decreciente de 0 a -1
> [3π/2, 2π]:   Creciente de -1 a 0
> ```
> 
> **Propiedades de simetría:**
> 
> ```
> Función impar: sin(-x) = -sin(x)
> Simétrica respecto al origen
> 
> Si (a, b) está en la gráfica
> entonces (-a, -b) también está
> ```
> 
> **Ceros (intersecciones con eje x):**
> 
> ```
> sin(x) = 0 cuando x = nπ, n ∈ ℤ
> x = ..., -2π, -π, 0, π, 2π, 3π, ...
> ```
> 
> **Máximos y mínimos:**
> 
> ```
> Máximos: x = π/2 + 2nπ, n ∈ ℤ
>          sin(x) = 1
> 
> Mínimos: x = 3π/2 + 2nπ, n ∈ ℤ
>          sin(x) = -1
> ```
> 
> **Puntos de inflexión:**
> 
> ```
> En los ceros: x = nπ
> Donde la concavidad cambia
> ```

## 📈 Gráfica de y = cos(x)

> [!success]- La Función Coseno
> 
> **Características fundamentales:**
> 
> ```
> f(x) = cos(x)
> 
> Dominio: ℝ
> Rango: [-1, 1]
> Periodo: 2π (360°)
> Amplitud: 1
> ```
> 
> **Puntos clave en un periodo [0, 2π]:**
> 
> ```
> x     | 0  | π/2 | π  | 3π/2 | 2π
> ------|----|----|----|----|----
> cos(x)| 1  | 0   | -1 | 0    | 1
> ```
> 
> **Comportamiento:**
> 
> ```
> [0, π]:       Decreciente de 1 a -1
> [π, 2π]:      Creciente de -1 a 1
> ```
> 
> **Propiedades de simetría:**
> 
> ```
> Función par: cos(-x) = cos(x)
> Simétrica respecto al eje y
> 
> Si (a, b) está en la gráfica
> entonces (-a, b) también está
> ```
> 
> **Ceros:**
> 
> ```
> cos(x) = 0 cuando x = π/2 + nπ, n ∈ ℤ
> x = ..., -3π/2, -π/2, π/2, 3π/2, 5π/2, ...
> ```
> 
> **Máximos y mínimos:**
> 
> ```
> Máximos: x = 2nπ, n ∈ ℤ
>          cos(x) = 1
> 
> Mínimos: x = π + 2nπ, n ∈ ℤ
>          cos(x) = -1
> ```
> 
> **Relación con seno:**
> 
> ```
> cos(x) = sin(x + π/2)
> 
> El coseno es el seno desplazado π/2 a la izquierda
> ```

## 📉 Gráfica de y = tan(x)

> [!important]- La Función Tangente
> 
> **Características fundamentales:**
> 
> ```
> f(x) = tan(x) = sin(x)/cos(x)
> 
> Dominio: ℝ \ {π/2 + nπ}, n ∈ ℤ
> Rango: ℝ (todos los reales)
> Periodo: π (180°)
> No tiene amplitud (ilimitada)
> ```
> 
> **Puntos clave en un periodo (-π/2, π/2):**
> 
> ```
> x       | -π/2 | -π/4 | 0  | π/4 | π/2
> --------|------|------|----|----|-----
> tan(x)  | -∞   | -1   | 0  | 1   | +∞
> ```
> 
> **Asíntotas verticales:**
> 
> ```
> x = π/2 + nπ, n ∈ ℤ
> 
> Donde cos(x) = 0
> x = ..., -3π/2, -π/2, π/2, 3π/2, 5π/2, ...
> 
> lim(x→π/2⁻) tan(x) = +∞
> lim(x→π/2⁺) tan(x) = -∞
> ```
> 
> **Comportamiento:**
> 
> ```
> En cada intervalo (-π/2 + nπ, π/2 + nπ):
> - Función creciente en todo el intervalo
> - Pasa de -∞ a +∞
> - Cruza el origen (cuando n = 0)
> ```
> 
> **Ceros:**
> 
> ```
> tan(x) = 0 cuando x = nπ, n ∈ ℤ
> (donde sin(x) = 0)
> ```
> 
> **Simetría:**
> 
> ```
> Función impar: tan(-x) = -tan(x)
> Simétrica respecto al origen
> ```
> 
> **Puntos de inflexión:**
> 
> ```
> En los ceros: x = nπ
> ```

## 📊 Gráfica de y = cot(x)

> [!note]- La Función Cotangente
> 
> **Características fundamentales:**
> 
> ```
> f(x) = cot(x) = cos(x)/sin(x) = 1/tan(x)
> 
> Dominio: ℝ \ {nπ}, n ∈ ℤ
> Rango: ℝ
> Periodo: π
> ```
> 
> **Puntos clave en un periodo (0, π):**
> 
> ```
> x       | 0  | π/4 | π/2 | 3π/4 | π
> --------|----|----|-----|------|-
> cot(x)  | +∞ | 1   | 0   | -1   | -∞
> ```
> 
> **Asíntotas verticales:**
> 
> ```
> x = nπ, n ∈ ℤ
> 
> Donde sin(x) = 0
> x = ..., -2π, -π, 0, π, 2π, ...
> ```
> 
> **Comportamiento:**
> 
> ```
> En cada intervalo (nπ, (n+1)π):
> - Función decreciente en todo el intervalo
> - Pasa de +∞ a -∞
> ```
> 
> **Ceros:**
> 
> ```
> cot(x) = 0 cuando x = π/2 + nπ, n ∈ ℤ
> (donde cos(x) = 0)
> ```
> 
> **Simetría:**
> 
> ```
> Función impar: cot(-x) = -cot(x)
> ```

## 📈 Gráfica de y = sec(x)

> [!note]- La Función Secante
> 
> **Características fundamentales:**
> 
> ```
> f(x) = sec(x) = 1/cos(x)
> 
> Dominio: ℝ \ {π/2 + nπ}, n ∈ ℤ
> Rango: (-∞, -1] ∪ [1, +∞)
> Periodo: 2π
> ```
> 
> **Relación con coseno:**
> 
> ```
> La gráfica de sec(x) tiene forma de "U"
> sobre cada arco de cos(x)
> 
> Cuando |cos(x)| < 1: |sec(x)| > 1
> Cuando cos(x) = ±1: sec(x) = ±1
> ```
> 
> **Asíntotas verticales:**
> 
> ```
> x = π/2 + nπ, n ∈ ℤ
> (donde cos(x) = 0)
> ```
> 
> **Valores importantes:**
> 
> ```
> sec(0) = 1
> sec(π) = -1
> sec(2π) = 1
> 
> sec(x) ≥ 1 cuando cos(x) > 0
> sec(x) ≤ -1 cuando cos(x) < 0
> ```
> 
> **Puntos mínimos y máximos:**
> 
> ```
> Mínimos locales: x = 2nπ, sec(x) = 1
> Máximos locales: x = π + 2nπ, sec(x) = -1
> (correspondientes a máximos de |cos(x)|)
> ```

## 📉 Gráfica de y = csc(x)

> [!note]- La Función Cosecante
> 
> **Características fundamentales:**
> 
> ```
> f(x) = csc(x) = 1/sin(x)
> 
> Dominio: ℝ \ {nπ}, n ∈ ℤ
> Rango: (-∞, -1] ∪ [1, +∞)
> Periodo: 2π
> ```
> 
> **Relación con seno:**
> 
> ```
> La gráfica de csc(x) tiene forma de "U"
> sobre cada arco de sin(x)
> 
> Cuando |sin(x)| < 1: |csc(x)| > 1
> Cuando sin(x) = ±1: csc(x) = ±1
> ```
> 
> **Asíntotas verticales:**
> 
> ```
> x = nπ, n ∈ ℤ
> (donde sin(x) = 0)
> ```
> 
> **Valores importantes:**
> 
> ```
> csc(π/2) = 1
> csc(3π/2) = -1
> 
> csc(x) ≥ 1 cuando sin(x) > 0
> csc(x) ≤ -1 cuando sin(x) < 0
> ```
> 
> **Relación con sec:**
> 
> ```
> csc(x) = sec(x - π/2)
> 
> Cosecante es secante desplazada π/2 a la derecha
> ```

## 🔄 Transformaciones de Funciones Trigonométricas

> [!important]- Forma General y Parámetros
> 
> **Forma general para seno y coseno:**
> 
> ```
> f(x) = A·sin(B(x - C)) + D
> f(x) = A·cos(B(x - C)) + D
> 
> Parámetros:
> A: Amplitud (estiramiento vertical)
> B: Frecuencia (compresión/estiramiento horizontal)
> C: Desplazamiento de fase (traslación horizontal)
> D: Desplazamiento vertical
> ```
> 
> **Amplitud:**
> 
> ```
> Amplitud = |A|
> 
> Distancia del eje central a máximos/mínimos
> 
> Si A > 0: misma orientación
> Si A < 0: reflexión sobre eje x
> 
> Ejemplos:
> y = 3sin(x):    Amplitud = 3
> y = -2cos(x):   Amplitud = 2 (reflexión)
> ```
> 
> **Periodo:**
> 
> ```
> Periodo = 2π/|B|  (para sin, cos, sec, csc)
> Periodo = π/|B|   (para tan, cot)
> 
> Si B > 1: compresión (ciclos más rápidos)
> Si 0 < B < 1: estiramiento (ciclos más lentos)
> Si B < 0: reflexión horizontal
> 
> Ejemplos:
> y = sin(2x):    Periodo = 2π/2 = π
> y = cos(x/3):   Periodo = 2π/(1/3) = 6π
> y = tan(4x):    Periodo = π/4
> ```
> 
> **Frecuencia:**
> 
> ```
> Frecuencia = |B|/(2π)  (para sin/cos)
> Frecuencia = |B|/π     (para tan/cot)
> 
> Número de ciclos completos en 2π unidades
> 
> Ejemplos:
> y = sin(3x): Frecuencia = 3/(2π)
>              3 ciclos en 2π radianes
> ```
> 
> **Desplazamiento de fase:**
> 
> ```
> Desplazamiento = C
> 
> Si C > 0: desplazamiento a la derecha
> Si C < 0: desplazamiento a la izquierda
> 
> Alternativa: y = A·sin(Bx - D) + E
> Entonces: Desplazamiento = D/B
> 
> Ejemplos:
> y = sin(x - π/4):   Desplazamiento π/4 a la derecha
> y = cos(2x + π):    Desplazamiento π/2 a la izquierda
>                     (porque 2x + π = 2(x + π/2))
> ```
> 
> **Desplazamiento vertical:**
> 
> ```
> Desplazamiento vertical = D
> 
> Mueve la línea central (eje de oscilación)
> 
> Rango nuevo: [D - |A|, D + |A|]
> 
> Ejemplos:
> y = sin(x) + 2:     Oscila entre 1 y 3
> y = 3cos(x) - 1:    Oscila entre -4 y 2
> ```

## 🎨 Ejemplos de Transformaciones

> [!example]- Análisis de Funciones Transformadas
> 
> **Ejemplo 1: y = 2sin(3x)**
> 
> ```
> Comparar con y = A·sin(Bx)
> 
> A = 2:  Amplitud = 2
>         Rango: [-2, 2]
> 
> B = 3:  Periodo = 2π/3
>         Completa 3 ciclos en 2π
> 
> Sin desplazamientos (C = 0, D = 0)
> 
> Puntos clave en [0, 2π/3]:
> x = 0:        y = 0
> x = π/6:      y = 2
> x = π/3:      y = 0
> x = π/2:      y = -2
> x = 2π/3:     y = 0
> ```
> 
> **Ejemplo 2: y = -cos(x - π/2) + 1**
> 
> ```
> A = -1: Amplitud = 1, reflexión
> B = 1:  Periodo = 2π
> C = π/2: Desplazamiento π/2 a la derecha
> D = 1:  Desplazamiento 1 hacia arriba
> 
> Rango: [0, 2] (de D-|A| a D+|A|)
> 
> Observación:
> -cos(x - π/2) = -sin(x)
> Entonces: y = -sin(x) + 1
> ```
> 
> **Ejemplo 3: y = 3sin(2x + π)**
> 
> ```
> Reescribir: y = 3sin(2(x + π/2))
> 
> A = 3:   Amplitud = 3
> B = 2:   Periodo = π
> C = -π/2: Desplazamiento π/2 a la izquierda
> D = 0:   Sin desplazamiento vertical
> 
> Rango: [-3, 3]
> 
> Alternativa:
> sin(2x + π) = sin(2x)cos(π) + cos(2x)sin(π)
>             = -sin(2x)
> Entonces: y = -3sin(2x)
> ```
> 
> **Ejemplo 4: y = (1/2)cos(πx) - 2**
> 
> ```
> A = 1/2: Amplitud = 1/2
> B = π:   Periodo = 2π/π = 2
> C = 0:   Sin desplazamiento horizontal
> D = -2:  Desplazamiento 2 hacia abajo
> 
> Rango: [-5/2, -3/2]
> 
> En [0, 2]:
> x = 0:    y = 1/2 - 2 = -3/2
> x = 1:    y = -1/2 - 2 = -5/2
> x = 2:    y = 1/2 - 2 = -3/2
> ```
> 
> **Ejemplo 5: y = tan(x/2 - π/4)**
> 
> ```
> Reescribir: y = tan((1/2)(x - π/2))
> 
> B = 1/2: Periodo = π/(1/2) = 2π
> C = π/2: Desplazamiento π/2 a la derecha
> 
> Asíntotas de y = tan(x/2):
> x/2 = π/2 + nπ
> x = π + 2nπ
> 
> Asíntotas de y = tan(x/2 - π/4):
> x = π/2 + 2nπ, x = 5π/2 + 2nπ, ...
> ```

## 📐 Aplicaciones de las Gráficas

> [!example]- Modelado de Fenómenos Periódicos
> 
> **1. Movimiento armónico simple:**
> 
> ```
> Posición de masa en resorte:
> y(t) = A·cos(ωt + φ)
> 
> A: amplitud del movimiento
> ω: frecuencia angular
> φ: fase inicial
> 
> Ejemplo: y = 0.5cos(2πt)
> Amplitud: 0.5 m
> Periodo: 1 s
> Frecuencia: 1 Hz
> ```
> 
> **2. Ondas de sonido:**
> 
> ```
> Presión del aire:
> P(t) = P₀ + A·sin(2πft)
> 
> P₀: presión ambiente
> A: amplitud de presión
> f: frecuencia (Hz)
> 
> Ejemplo: Nota La (440 Hz)
> P(t) = P₀ + A·sin(880πt)
> ```
> 
> **3. Ciclos de temperatura:**
> 
> ```
> Temperatura diaria:
> T(t) = T_media + A·sin(2π(t - t₀)/24)
> 
> T_media: temperatura promedio
> A: variación de temperatura
> t: horas desde medianoche
> t₀: hora de temperatura mínima
> 
> Ejemplo: T(t) = 20 + 8·sin(π(t - 6)/12)
> Media: 20°C
> Rango: 12°C a 28°C
> Mínimo: 6 AM
> Máximo: 6 PM
> ```
> 
> **4. Mareas:**
> 
> ```
> Altura del agua:
> h(t) = h₀ + A·cos(2π(t - t₀)/T)
> 
> h₀: nivel medio del mar
> A: amplitud de marea
> T: periodo (~12.4 horas)
> t₀: tiempo de marea alta
> 
> Ejemplo: h(t) = 3 + 2·cos(π(t - 2)/6.2)
> Marea alta: cada ~12.4 horas
> Rango: 1 m a 5 m
> ```
> 
> **5. Corriente alterna:**
> 
> ```
> Voltaje:
> V(t) = V_max·sin(2πft)
> 
> V_max: voltaje pico
> f: frecuencia (60 Hz en América)
> 
> Ejemplo: V(t) = 170·sin(120πt)
> Voltaje RMS: 120 V
> Frecuencia: 60 Hz
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes
> 
> **1. "Confundir amplitud con rango"**
> 
> ```
> ✗ INCORRECTO: y = 2sin(x) tiene rango [0, 2]
> 
> ✓ CORRECTO:
> Amplitud = 2
> Rango = [-2, 2]
> 
> El rango va de -|A| a +|A| (si D = 0)
> ```
> 
> **2. "Periodo = B"**
> 
> ```
> ✗ INCORRECTO
> 
> ✓ CORRECTO:
> Periodo = 2π/|B| (para sin, cos)
> Periodo = π/|B| (para tan, cot)
> 
> Ejemplo: y = sin(4x)
> Periodo = 2π/4 = π/2, no 4
> ```
> 
> **3. "Desplazamiento de fase en y = sin(Bx + C)"**
> 
> ```
> ✗ INCORRECTO: Desplazamiento = C
> 
> ✓ CORRECTO: Desplazamiento = -C/B
> 
> Reescribir: sin(Bx + C) = sin(B(x + C/B))
> Desplazamiento es C/B a la izquierda
> 
> Ejemplo: sin(2x + π)
> Desplazamiento = π/2 a la izquierda
> ```
> 
> **4. "Olvidar el valor absoluto en amplitud"**
> 
> ```
> ✗ INCORRECTO: y = -3cos(x) tiene amplitud -3
> 
> ✓ CORRECTO: Amplitud = |-3| = 3
> 
> El signo negativo indica reflexión,
> no amplitud negativa
> ```
> 
> **5. "Confundir asíntotas de tan y cot"**
> 
> ```
> tan(x): asíntotas en x = π/2 + nπ
> cot(x): asíntotas en x = nπ
> 
> No son las mismas
> ```
> 
> **6. "Rango de funciones transformadas"**
> 
> ```
> ✗ INCORRECTO: y = 2sin(x) + 3 tiene rango [-2, 2]
> 
> ✓ CORRECTO:
> Rango = [D - |A|, D + |A|]
>       = [3 - 2, 3 + 2]
>       = [1, 5]
> ```

## 💡 Estrategias para Graficar

> [!tip]- Método Sistemático
> 
> **Para seno y coseno:**
> 
> 1. **Identificar parámetros:**
>     - A (amplitud)
>     - B (frecuencia)
>     - C (desplazamiento fase)
>     - D (desplazamiento vertical)
> 2. **Calcular características:**
>     - Amplitud = |A|
>     - Periodo = 2π/|B|
>     - Línea central: y = D
>     - Rango: [D - |A|, D + |A|]
> 3. **Marcar puntos clave:**
>     - Dividir un periodo en 4 partes iguales
>     - Para seno: 0, máx, 0, mín, 0
>     - Para coseno: máx, 0, mín, 0, máx
> 4. **Aplicar transformaciones:**
>     - Desplazamiento horizontal (C)
>     - Ajustar por desplazamiento vertical (D)
> 5. **Extender el patrón:**
>     - Repetir por periodicidad
> 
> **Para tangente y cotangente:**
> 
> 6. **Identificar periodo y asíntotas:**
>     - Periodo = π/|B|
>     - Localizar asíntotas
> 7. **Marcar puntos clave:**
>     - Ceros de la función
>     - Punto medio entre asíntotas
> 8. **Dibujar ramas:**
>     - Entre asíntotas consecutivas
>     - Creciente (tan) o decreciente (cot)
> 
> **Para secante y cosecante:**
> 
> 9. **Graficar función base:**
>     - Primero cos(x) para sec(x)
>     - Primero sin(x) para csc(x)
> 10. **Marcar asíntotas:**
>     - Donde función base = 0
> 11. **Dibujar "U"s:**
>     - Sobre arcos de función base
>     - Mínimos/máximos en ±1

## 🎯 Ejercicios Resueltos

> [!example]- Problemas Paso a Paso
> 
> **Problema 1: Análisis completo**
> 
> ```
> Analiza y = 3sin(2x - π) + 1
> 
> SOLUCIÓN:
> 
> Paso 1: Reescribir
> y = 3sin(2(x - π/2)) + 1
> 
> Paso 2: Identificar parámetros
> A = 3
> B = 2
> C = π/2
> D = 1
> 
> Paso 3: Características
> Amplitud = 3
> Periodo = 2π/2 = π
> Desplazamiento fase = π/2 (derecha)
> Desplazamiento vertical = 1
> Rango = [1-3, 1+3] = [-2, 4]
> 
> 
> 
> Paso 4: Puntos clave en [π/2, 3π/2]
> x = π/2:    y = 3sin(0) + 1 = 1
> x = 3π/4:   y = 3sin(π/2) + 1 = 4 (máximo)
> x = π:      y = 3sin(π) + 1 = 1
> x = 5π/4:   y = 3sin(3π/2) + 1 = -2 (mínimo)
> x = 3π/2:   y = 3sin(2π) + 1 = 1
> 
> RESPUESTA:
> - Amplitud: 3
> - Periodo: π
> - Desplazamiento: π/2 a la derecha
> - Línea central: y = 1
> - Rango: [-2, 4]
> - Ceros en: x = π/2 + kπ/2 donde k es impar
> ```
> 
> **Problema 2: Determinar ecuación**
> 
> ```
> Una función sinusoidal tiene:
> - Amplitud 4
> - Periodo 3π
> - Mínimo en x = 0 con valor -1
> 
> Encuentra su ecuación
> 
> SOLUCIÓN:
> 
> Paso 1: Determinar D (desplazamiento vertical)
> Si amplitud = 4 y mínimo = -1:
> D - 4 = -1
> D = 3
> 
> Paso 2: Determinar B (frecuencia)
> Periodo = 2π/B = 3π
> B = 2π/(3π) = 2/3
> 
> Paso 3: Elegir función base
> Como tiene mínimo en x = 0, usar coseno negativo:
> y = -A·cos(Bx) + D
> 
> Paso 4: Ecuación completa
> y = -4·cos((2/3)x) + 3
> 
> Verificación:
> x = 0: y = -4·cos(0) + 3 = -4 + 3 = -1 ✓
> x = 3π/2: y = -4·cos(π) + 3 = 4 + 3 = 7 (máximo) ✓
> 
> RESPUESTA: y = -4cos((2/3)x) + 3
> ```
> 
> **Problema 3: Identificar transformaciones**
> 
> ```
> La gráfica de y = cos(x) se transforma:
> 1. Estiramiento vertical por factor 2
> 2. Compresión horizontal por factor 1/3
> 3. Desplazamiento π/6 a la izquierda
> 4. Desplazamiento 5 hacia arriba
> 
> ¿Cuál es la ecuación resultante?
> 
> SOLUCIÓN:
> 
> Empezar con: y = cos(x)
> 
> 1. Estiramiento vertical ×2:
>    y = 2cos(x)
> 
> 2. Compresión horizontal ×(1/3):
>    Multiplicar x por 3:
>    y = 2cos(3x)
> 
> 3. Desplazamiento π/6 izquierda:
>    Reemplazar x por (x + π/6):
>    y = 2cos(3(x + π/6))
>    y = 2cos(3x + π/2)
> 
> 4. Desplazamiento +5 vertical:
>    y = 2cos(3x + π/2) + 5
> 
> Simplificación (opcional):
> cos(3x + π/2) = -sin(3x)
> y = -2sin(3x) + 5
> 
> RESPUESTA: y = 2cos(3x + π/2) + 5
>           o y = -2sin(3x) + 5
> ```
> 
> **Problema 4: Intersecciones**
> 
> ```
> Encuentra los puntos de intersección de
> y = sin(x) y y = cos(x) en [0, 2π]
> 
> SOLUCIÓN:
> 
> Paso 1: Igualar funciones
> sin(x) = cos(x)
> 
> Paso 2: Resolver
> sin(x)/cos(x) = 1
> tan(x) = 1
> 
> Paso 3: Encontrar soluciones en [0, 2π]
> tan(x) = 1 cuando:
> x = π/4 (cuadrante I)
> x = π/4 + π = 5π/4 (cuadrante III)
> 
> Paso 4: Calcular coordenadas y
> En x = π/4:
> y = sin(π/4) = √2/2
> 
> En x = 5π/4:
> y = sin(5π/4) = -√2/2
> 
> RESPUESTA: (π/4, √2/2) y (5π/4, -√2/2)
> ```
> 
> **Problema 5: Aplicación práctica**
> 
> ```
> La profundidad del agua en un puerto varía
> sinusoidalmente con las mareas.
> 
> Datos:
> - Profundidad máxima: 12 m (marea alta)
> - Profundidad mínima: 4 m (marea baja)
> - Tiempo entre mareas altas: 12 horas
> - Marea alta a las 3:00 AM (t = 3)
> 
> a) Encuentra la función h(t)
> b) ¿Profundidad a las 9:00 AM?
> c) ¿Cuándo profundidad = 10 m?
> 
> SOLUCIÓN:
> 
> a) Determinar parámetros:
> 
>    Amplitud: A = (12 - 4)/2 = 4
>    
>    Desplazamiento vertical:
>    D = (12 + 4)/2 = 8
>    
>    Periodo: T = 12
>    B = 2π/12 = π/6
>    
>    Máximo en t = 3, usar coseno:
>    h(t) = 4cos((π/6)(t - 3)) + 8
>    
>    O simplificado:
>    h(t) = 4cos((πt/6) - π/2) + 8
>    h(t) = 4sin(πt/6) + 8
> 
> b) A las 9 AM (t = 9):
>    h(9) = 4sin(9π/6) + 8
>         = 4sin(3π/2) + 8
>         = 4(-1) + 8
>         = 4 m
> 
> c) Resolver h(t) = 10:
>    4sin(πt/6) + 8 = 10
>    4sin(πt/6) = 2
>    sin(πt/6) = 1/2
>    
>    πt/6 = π/6 o πt/6 = 5π/6
>    t = 1 o t = 5
>    
>    Considerando periodicidad:
>    t = 1 + 12k o t = 5 + 12k, k ∈ ℤ
>    
>    En el primer ciclo [0, 12]:
>    t = 1 hora (1:00 AM)
>    t = 5 horas (5:00 AM)
> 
> RESPUESTA:
> a) h(t) = 4sin(πt/6) + 8
> b) 4 metros
> c) 1:00 AM y 5:00 AM (se repite cada 12 h)
> ```
> 
> **Problema 6: Función tangente**
> 
> ```
> Determina periodo y asíntotas de:
> y = 2tan(3x - π)
> 
> SOLUCIÓN:
> 
> Paso 1: Reescribir
> y = 2tan(3(x - π/3))
> 
> Paso 2: Identificar parámetros
> A = 2 (factor de estiramiento vertical)
> B = 3
> C = π/3 (desplazamiento)
> 
> Paso 3: Periodo
> Periodo = π/|B| = π/3
> 
> Paso 4: Asíntotas base de tan(u)
> u = π/2 + nπ, n ∈ ℤ
> 
> Para y = tan(3(x - π/3)):
> 3(x - π/3) = π/2 + nπ
> x - π/3 = π/6 + nπ/3
> x = π/3 + π/6 + nπ/3
> x = π/2 + nπ/3, n ∈ ℤ
> 
> Paso 5: Primeras asíntotas
> n = 0: x = π/2
> n = 1: x = π/2 + π/3 = 5π/6
> n = -1: x = π/2 - π/3 = π/6
> 
> RESPUESTA:
> Periodo: π/3
> Asíntotas: x = π/6 + nπ/3, n ∈ ℤ
> ```

## 🔍 Comparación de Gráficas

> [!note]- Relaciones Visuales entre Funciones
> 
> **Seno vs Coseno:**
> 
> ```
> cos(x) = sin(x + π/2)
> 
> El coseno es el seno desplazado π/2 a la izquierda
> 
> Ambas:
> - Mismo periodo (2π)
> - Misma amplitud (1)
> - Mismo rango [-1, 1]
> - Diferentes puntos de inicio
> 
> cos(x) empieza en máximo (x=0, y=1)
> sin(x) empieza en cero (x=0, y=0)
> ```
> 
> **Tangente vs Cotangente:**
> 
> ```
> cot(x) = -tan(x - π/2)
> 
> Ambas:
> - Periodo π
> - Rango ℝ
> - Asíntotas verticales (en lugares diferentes)
> - Funciones impares
> 
> tan(x): creciente entre asíntotas
> cot(x): decreciente entre asíntotas
> 
> Asíntotas desplazadas π/2
> ```
> 
> **Secante vs Cosecante:**
> 
> ```
> sec(x) = csc(x - π/2)
> 
> Ambas:
> - Periodo 2π
> - Rango (-∞, -1] ∪ [1, +∞)
> - Gráficas con forma de "U"
> - Asíntotas donde función base = 0
> 
> sec(x): "U"s sobre arcos de cos(x)
> csc(x): "U"s sobre arcos de sin(x)
> ```
> 
> **Funciones y sus recíprocas:**
> 
> ```
> Seno y Cosecante:
> - Comparten ceros (donde sin = 0)
> - csc tiene asíntotas donde sin = 0
> - Cuando |sin| < 1, |csc| > 1
> 
> Coseno y Secante:
> - Comparten ceros (donde cos = 0)
> - sec tiene asíntotas donde cos = 0
> - Cuando |cos| < 1, |sec| > 1
> 
> Tangente y Cotangente:
> - Producto = 1 (donde ambas definidas)
> - tan crece, cot decrece
> - Asíntotas intercaladas
> ```

## 🌊 Combinaciones de Funciones

> [!tip]- Suma de Funciones Trigonométricas
> 
> **Suma de senos con misma frecuencia:**
> 
> ```
> y = A₁sin(Bx + φ₁) + A₂sin(Bx + φ₂)
> 
> Resultado: También sinusoidal con frecuencia B
> 
> Ejemplo: y = sin(x) + cos(x)
> 
> Reescribir cos(x) = sin(x + π/2):
> y = sin(x) + sin(x + π/2)
> 
> Usando fórmula de suma:
> y = √2 · sin(x + π/4)
> 
> Amplitud resultante: √2
> Desplazamiento fase: π/4
> ```
> 
> **Suma con diferentes frecuencias:**
> 
> ```
> y = sin(x) + sin(2x)
> 
> NO es sinusoidal simple
> Patrón más complejo
> 
> Ejemplo de batimiento (beats):
> y = sin(10x) + sin(11x)
> 
> Crea patrón de amplitud variable
> Frecuencia de batimiento: |10 - 11| = 1
> ```
> 
> **Producto de funciones:**
> 
> ```
> y = sin(x)·cos(x)
> 
> Usando identidad: sin(x)cos(x) = sin(2x)/2
> y = (1/2)sin(2x)
> 
> Frecuencia dobla, amplitud reduce a mitad
> ```
> 
> **Suma seno + coseno con coeficientes:**
> 
> ```
> y = A·sin(x) + B·cos(x)
> 
> Convertir a forma única:
> y = R·sin(x + φ)
> 
> donde:
> R = √(A² + B²)
> tan(φ) = B/A
> 
> Ejemplo: y = 3sin(x) + 4cos(x)
> R = √(9 + 16) = 5
> tan(φ) = 4/3 → φ ≈ 0.927
> y = 5sin(x + 0.927)
> ```

## 📱 Aplicaciones en Tecnología

> [!example]- Señales y Ondas
> 
> **1. Procesamiento de audio:**
> 
> ```
> Nota musical = suma de armónicos
> 
> Nota fundamental: f₀
> Armónicos: 2f₀, 3f₀, 4f₀, ...
> 
> Ejemplo: Nota La (440 Hz)
> y = A₁sin(880πt) +           (fundamental)
>     A₂sin(1760πt) +          (2° armónico)
>     A₃sin(2640πt) + ...      (3° armónico)
> 
> Cada instrumento tiene diferentes Aᵢ
> (esto define el "timbre")
> ```
> 
> **2. Modulación AM (radio):**
> 
> ```
> Señal modulada:
> y = [A + m·sin(2πfₘt)]·sin(2πfct)
> 
> fₘ: frecuencia de señal (audio)
> fc: frecuencia portadora (radio)
> m: índice de modulación
> 
> Ejemplo: Radio AM
> fₘ ≈ 5 kHz (voz)
> fc ≈ 1000 kHz (estación)
> ```
> 
> **3. Análisis de Fourier:**
> 
> ```
> Cualquier señal periódica = suma de senos y cosenos
> 
> f(x) = a₀/2 + Σ[aₙcos(nx) + bₙsin(nx)]
> 
> Aplicaciones:
> - Compresión de audio (MP3)
> - Procesamiento de imágenes (JPEG)
> - Filtrado de señales
> - Análisis espectral
> ```
> 
> **4. Corriente alterna trifásica:**
> 
> ```
> Tres fases desfasadas 120°:
> 
> V₁(t) = V·sin(ωt)
> V₂(t) = V·sin(ωt - 2π/3)
> V₃(t) = V·sin(ωt - 4π/3)
> 
> Suma: V₁ + V₂ + V₃ = 0
> 
> Usado en distribución eléctrica
> ```
> 
> **5. GPS y navegación:**
> 
> ```
> Señal de satélite:
> y = A·cos(2πft + φ)
> 
> Desplazamiento Doppler:
> f' = f(1 + v/c)
> 
> Análisis de fase determina:
> - Posición
> - Velocidad
> - Tiempo preciso
> ```

## 🎨 Técnicas de Graficación

> [!tip]- Métodos Avanzados
> 
> **Método de puntos clave:**
> 
> ```
> Para y = A·sin(B(x - C)) + D:
> 
> 1. Calcular periodo T = 2π/B
> 2. Inicio del ciclo: x = C
> 3. Dividir periodo en 4 partes: T/4
> 
> Puntos clave (seno):
> x₀ = C:           y = D
> x₁ = C + T/4:     y = D + A
> x₂ = C + T/2:     y = D
> x₃ = C + 3T/4:    y = D - A
> x₄ = C + T:       y = D
> 
> Para coseno, empezar en D + A
> ```
> 
> **Uso de simetría:**
> 
> ```
> Funciones pares (cos, sec):
> - Graficar solo x ≥ 0
> - Reflejar sobre eje y
> 
> Funciones impares (sin, tan, cot, csc):
> - Graficar solo x ≥ 0
> - Reflejar con simetría origen
> 
> Ahorra tiempo de graficación
> ```
> 
> **Transformaciones secuenciales:**
> 
> ```
> Orden recomendado:
> 
> 1. Graficar función base
> 2. Aplicar estiramiento/compresión vertical (A)
> 3. Aplicar estiramiento/compresión horizontal (B)
> 4. Aplicar desplazamiento horizontal (C)
> 5. Aplicar desplazamiento vertical (D)
> 
> Cada paso parte del resultado anterior
> ```
> 
> **Graficación con calculadora/software:**
> 
> ```
> Consideraciones:
> 
> - Modo: RAD o DEG (verificar)
> - Ventana: ajustar para mostrar ciclos completos
> - Escala: apropiada para amplitud
> 
> Ventana sugerida para funciones base:
> x: [-2π, 2π] o [-360°, 360°]
> y: [-3, 3] (captura bien seno/coseno)
> 
> Para tangente:
> y: [-5, 5] o más amplio
> ```

## 🔬 Análisis de Características

> [!important]- Propiedades Analíticas
> 
> **Continuidad:**
> 
> ```
> sin(x), cos(x): Continuas en ℝ
> tan(x), sec(x): Discontinuas en x = π/2 + nπ
> cot(x), csc(x): Discontinuas en x = nπ
> 
> Discontinuidades infinitas (asíntotas)
> ```
> 
> **Derivabilidad:**
> 
> ```
> Funciones continuas son derivables en su dominio:
> 
> d/dx[sin(x)] = cos(x)
> d/dx[cos(x)] = -sin(x)
> d/dx[tan(x)] = sec²(x)
> 
> Máximos y mínimos donde derivada = 0
> ```
> 
> **Puntos críticos:**
> 
> ```
> Sin(x):
> - Máximos: x = π/2 + 2nπ
> - Mínimos: x = 3π/2 + 2nπ
> 
> Cos(x):
> - Máximos: x = 2nπ
> - Mínimos: x = π + 2nπ
> 
> Tan(x):
> - Sin máximos ni mínimos (siempre creciente)
> - Puntos de inflexión en ceros
> ```
> 
> **Concavidad:**
> 
> ```
> Segunda derivada determina concavidad:
> 
> d²/dx²[sin(x)] = -sin(x)
> - Cóncava arriba donde sin(x) < 0
> - Cóncava abajo donde sin(x) > 0
> 
> Puntos de inflexión en ceros
> ```
