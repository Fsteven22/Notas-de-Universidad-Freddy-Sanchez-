# 🔄 Funciones Trigonométricas Inversas

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Las funciones trigonométricas inversas "deshacen" las funciones trigonométricas: dado un valor de razón trigonométrica, devuelven el ángulo correspondiente. Responden a preguntas como: ¿qué ángulo tiene seno igual a 1/2?**
> 
> **Elementos clave:**
> 
> - **Inversión:** Intercambiar entrada y salida
> - **Restricción de dominio:** Necesaria para que sean funciones
> - **Notación:** arcsin, arccos, arctan (o sin⁻¹, cos⁻¹, tan⁻¹)
> - **Resultado:** Ángulo (no razón)
> - **Rango específico:** Cada inversa tiene rango limitado

### 📖 Contexto Histórico

> [!note]- Desarrollo Histórico
> 
> **Orígenes (1500-1700):**
> 
> - **Viète (1593):** Primeras tablas inversas implícitas
> - **Problema:** Dado un valor, encontrar el ángulo
> - **Método:** Búsqueda en tablas trigonométricas
> - **Sin notación formal:** Descripciones verbales
> 
> **Formalización (1700-1800):**
> 
> - **Daniel Bernoulli (1729):** Estudia funciones inversas
> - **Euler (1736):** Notación sin⁻¹, cos⁻¹, tan⁻¹
> - **Lambert (1761):** Término "arcoseno" (arco-seno)
> - **Razón del "arc":** Longitud de arco en círculo unitario
> 
> **Desarrollo Analítico (1800-1850):**
> 
> - **Necesidad de restricción:** Para garantizar función
> - **Definición de rangos principales:** Valores principales
> - **Representación en series:** Expansiones de potencias
> - **Integración:** ∫dx/√(1-x²) = arcsin(x) + C
> 
> **Notación Moderna (1850-presente):**
> 
> - **Dos notaciones:** arc- y -⁻¹
> - **Confusión con potencia:** sin⁻¹(x) ≠ 1/sin(x)
> - **Estandarización:** Rangos aceptados universalmente
> - **Calculadoras:** Teclas específicas (sin⁻¹, cos⁻¹, tan⁻¹)
> 
> **Aplicaciones contemporáneas:**
> 
> - **Navegación:** Cálculo de ángulos de dirección
> - **Robótica:** Cinemática inversa
> - **Gráficos 3D:** Rotaciones y orientaciones
> - **Procesamiento de señales:** Análisis de fase

## 🔄 Problema de la Inversión

> [!warning]- ¿Por qué Necesitamos Restricciones?
> 
> **Prueba de función horizontal:**
> 
> ```
> Para que una función tenga inversa, debe ser inyectiva
> (uno a uno)
> 
> Prueba: Si una línea horizontal interseca la gráfica
>         más de una vez, la función NO es inyectiva
> ```
> 
> **Problema con funciones trigonométricas:**
> 
> ```
> sin(30°) = 1/2
> Pero también:
> sin(150°) = 1/2
> sin(390°) = 1/2
> sin(-330°) = 1/2
> ...
> 
> ¿Cuál es "el" ángulo cuyo seno es 1/2?
> ¡Hay infinitos!
> ```
> 
> **Solución: Restringir el dominio**
> 
> ```
> Elegir un intervalo donde la función sea inyectiva
> (monotónica - siempre creciente o decreciente)
> 
> Este intervalo define el RANGO de la función inversa
> (los valores que puede devolver)
> ```
> 
> **Valor principal:**
> 
> ```
> De todos los ángulos posibles, la función inversa
> devuelve el VALOR PRINCIPAL: el ángulo en el rango
> especificado
> 
> arcsin(1/2) = 30° = π/6
> (no 150°, aunque también sin(150°) = 1/2)
> ```

## 📐 Función Arcoseno (sin⁻¹ o arcsin)

> [!success]- Inversa del Seno
> 
> **Definición:**
> 
> ```
> y = arcsin(x)  ⟺  sin(y) = x
> 
> donde:
> -1 ≤ x ≤ 1  (dominio)
> -π/2 ≤ y ≤ π/2  (rango - valores principales)
> 
> Notaciones equivalentes:
> arcsin(x) = sin⁻¹(x)
> 
> ⚠️ CUIDADO: sin⁻¹(x) ≠ 1/sin(x)
> Para recíproca usar: csc(x) = 1/sin(x)
> ```
> 
> **Restricción de dominio de sin(x):**
> 
> ```
> Para obtener arcsin, restringir:
> 
> sin: [-π/2, π/2] → [-1, 1]
> 
> En este intervalo, sin es creciente e inyectiva
> ```
> 
> **Características:**
> 
> ```
> Dominio: [-1, 1]
> Rango: [-π/2, π/2] o [-90°, 90°]
> 
> Función impar: arcsin(-x) = -arcsin(x)
> 
> Valores especiales:
> arcsin(0) = 0
> arcsin(1/2) = π/6 (30°)
> arcsin(√2/2) = π/4 (45°)
> arcsin(√3/2) = π/3 (60°)
> arcsin(1) = π/2 (90°)
> arcsin(-1) = -π/2 (-90°)
> ```
> 
> **Propiedades fundamentales:**
> 
> ```
> arcsin(sin(x)) = x  para x ∈ [-π/2, π/2]
> sin(arcsin(x)) = x  para x ∈ [-1, 1]
> 
> Ejemplo:
> arcsin(sin(π/6)) = π/6 ✓
> pero arcsin(sin(5π/6)) ≠ 5π/6
> arcsin(sin(5π/6)) = π/6
> (porque 5π/6 fuera del rango [-π/2, π/2])
> ```
> 
> **Gráfica:**
> 
> ```
> Reflexión de sin(x)|[-π/2, π/2] sobre la recta y = x
> 
> - Creciente en todo su dominio
> - Pasa por (0, 0)
> - Punto de inflexión en el origen
> - Límites: lim(x→±1) arcsin(x) = ±π/2
> ```

## 📈 Función Arcocoseno (cos⁻¹ o arccos)

> [!success]- Inversa del Coseno
> 
> **Definición:**
> 
> ```
> y = arccos(x)  ⟺  cos(y) = x
> 
> donde:
> -1 ≤ x ≤ 1  (dominio)
> 0 ≤ y ≤ π  (rango - valores principales)
> 
> Notaciones:
> arccos(x) = cos⁻¹(x)
> ```
> 
> **Restricción de dominio de cos(x):**
> 
> ```
> Para obtener arccos, restringir:
> 
> cos: [0, π] → [-1, 1]
> 
> En este intervalo, cos es decreciente e inyectiva
> ```
> 
> **Características:**
> 
> ```
> Dominio: [-1, 1]
> Rango: [0, π] o [0°, 180°]
> 
> NO es par ni impar (pero tiene relación con arcsin)
> 
> Valores especiales:
> arccos(1) = 0
> arccos(√3/2) = π/6 (30°)
> arccos(√2/2) = π/4 (45°)
> arccos(1/2) = π/3 (60°)
> arccos(0) = π/2 (90°)
> arccos(-1) = π (180°)
> ```
> 
> **Relación con arcsin:**
> 
> ```
> arccos(x) = π/2 - arcsin(x)
> 
> o equivalentemente:
> arcsin(x) + arccos(x) = π/2
> 
> Esta relación es muy útil para conversiones
> 
> Demostración:
> Sea θ = arcsin(x), entonces sin(θ) = x
> En el ángulo complementario (π/2 - θ):
> cos(π/2 - θ) = sin(θ) = x
> Por tanto: π/2 - θ = arccos(x)
> ```
> 
> **Propiedades fundamentales:**
> 
> ```
> arccos(cos(x)) = x  para x ∈ [0, π]
> cos(arccos(x)) = x  para x ∈ [-1, 1]
> 
> Propiedad de complemento:
> arccos(-x) = π - arccos(x)
> ```
> 
> **Gráfica:**
> 
> ```
> Reflexión de cos(x)|[0, π] sobre la recta y = x
> 
> - Decreciente en todo su dominio
> - Pasa por (1, 0) y (-1, π)
> - En (0, π/2): punto medio
> ```

## 📊 Función Arcotangente (tan⁻¹ o arctan)

> [!important]- Inversa de la Tangente
> 
> **Definición:**
> 
> ```
> y = arctan(x)  ⟺  tan(y) = x
> 
> donde:
> x ∈ ℝ  (dominio - todos los reales)
> -π/2 < y < π/2  (rango - intervalo abierto)
> 
> Notaciones:
> arctan(x) = tan⁻¹(x)
> ```
> 
> **Restricción de dominio de tan(x):**
> 
> ```
> Para obtener arctan, restringir:
> 
> tan: (-π/2, π/2) → ℝ
> 
> En este intervalo, tan es creciente e inyectiva
> ```
> 
> **Características:**
> 
> ```
> Dominio: ℝ (todos los reales)
> Rango: (-π/2, π/2) o (-90°, 90°)
> 
> Función impar: arctan(-x) = -arctan(x)
> 
> Asíntotas horizontales:
> lim(x→+∞) arctan(x) = π/2
> lim(x→-∞) arctan(x) = -π/2
> 
> Valores especiales:
> arctan(0) = 0
> arctan(√3/3) = π/6 (30°)
> arctan(1) = π/4 (45°)
> arctan(√3) = π/3 (60°)
> ```
> 
> **Propiedades fundamentales:**
> 
> ```
> arctan(tan(x)) = x  para x ∈ (-π/2, π/2)
> tan(arctan(x)) = x  para x ∈ ℝ
> 
> Propiedad útil:
> arctan(1/x) = π/2 - arctan(x)  (x > 0)
> arctan(1/x) = -π/2 - arctan(x) (x < 0)
> 
> Suma de arcotangentes:
> arctan(a) + arctan(b) = arctan((a+b)/(1-ab))
> (cuando ab < 1)
> ```
> 
> **Gráfica:**
> 
> ```
> Reflexión de tan(x)|(-π/2, π/2) sobre y = x
> 
> - Creciente en todo su dominio
> - Pasa por (0, 0)
> - Punto de inflexión en el origen
> - Asíntotas horizontales en y = ±π/2
> - Forma de "S" estirada
> ```

## 📉 Otras Funciones Inversas

> [!note]- Arcocotangente, Arcosecante, Arcocosecante
> 
> **Arcocotangente: arccot(x) o cot⁻¹(x)**
> 
> ```
> y = arccot(x)  ⟺  cot(y) = x
> 
> Dominio: ℝ
> Rango: (0, π) o (0°, 180°)
> 
> Relación con arctan:
> arccot(x) = π/2 - arctan(x)  (definición común)
> o arccot(x) = arctan(1/x)    (x > 0)
> 
> Valores especiales:
> arccot(0) = π/2
> arccot(1) = π/4
> arccot(-1) = 3π/4
> 
> Gráfica: Decreciente, asíntotas horizontales en 0 y π
> ```
> 
> **Arcosecante: arcsec(x) o sec⁻¹(x)**
> 
> ```
> y = arcsec(x)  ⟺  sec(y) = x
> 
> Dominio: (-∞, -1] ∪ [1, +∞)
> Rango: [0, π/2) ∪ (π/2, π] (común)
>        o [0, π] \ {π/2}
> 
> Relación con arccos:
> arcsec(x) = arccos(1/x)
> 
> Valores especiales:
> arcsec(1) = 0
> arcsec(2) = π/3
> arcsec(-1) = π
> 
> Menos usada que arcsin, arccos, arctan
> ```
> 
> **Arcocosecante: arccsc(x) o csc⁻¹(x)**
> 
> ```
> y = arccsc(x)  ⟺  csc(y) = x
> 
> Dominio: (-∞, -1] ∪ [1, +∞)
> Rango: [-π/2, 0) ∪ (0, π/2] (común)
>        o [-π/2, π/2] \ {0}
> 
> Relación con arcsin:
> arccsc(x) = arcsin(1/x)
> 
> Valores especiales:
> arccsc(1) = π/2
> arccsc(2) = π/6
> arccsc(-1) = -π/2
> 
> Menos usada que las tres principales
> ```
> 
> **Nota sobre notación:**
> 
> ```
> Las tres funciones principales (arcsin, arccos, arctan)
> están estandarizadas y disponibles en calculadoras
> 
> Las tres secundarias (arccot, arcsec, arccsc) tienen
> definiciones de rango que varían entre autores
> 
> Cuando sea necesario, usar:
> arcsec(x) = arccos(1/x)
> arccsc(x) = arcsin(1/x)
> arccot(x) = arctan(1/x) o π/2 - arctan(x)
> ```

## 🎯 Evaluación de Funciones Inversas

> [!tip]- Métodos de Cálculo
> 
> **Método 1: Valores exactos conocidos**
> 
> ```
> arcsin(1/2) = ?
> 
> Pregunta: ¿Qué ángulo en [-π/2, π/2] tiene seno 1/2?
> Respuesta: π/6 (30°)
> 
> arccos(0) = ?
> Pregunta: ¿Qué ángulo en [0, π] tiene coseno 0?
> Respuesta: π/2 (90°)
> ```
> 
> **Método 2: Triángulo rectángulo**
> 
> ```
> Evaluar: arctan(3/4)
> 
> Paso 1: Construir triángulo con tan(θ) = 3/4
>         opuesto = 3, adyacente = 4
> 
> Paso 2: Calcular hipotenusa
>         h = √(3² + 4²) = 5
> 
> Paso 3: Ahora podemos encontrar otras funciones:
>         sin(arctan(3/4)) = 3/5
>         cos(arctan(3/4)) = 4/5
> 
> El valor exacto de arctan(3/4) no es un ángulo "bonito"
> pero ≈ 0.6435 rad ≈ 36.87°
> ```
> 
> **Método 3: Composiciones**
> 
> ```
> Evaluar: sin(arccos(2/3))
> 
> Paso 1: Sea θ = arccos(2/3)
>         Entonces cos(θ) = 2/3
> 
> Paso 2: Usar identidad pitagórica
>         sin²(θ) + cos²(θ) = 1
>         sin²(θ) = 1 - (2/3)²
>         sin²(θ) = 1 - 4/9 = 5/9
>         sin(θ) = √5/3
> 
> Paso 3: Como θ ∈ [0, π], sin(θ) ≥ 0
>         Por tanto: sin(arccos(2/3)) = √5/3
> ```
> 
> **Método 4: Uso de identidades**
> 
> ```
> Evaluar: arcsin(x) + arccos(x)
> 
> Identidad fundamental:
> arcsin(x) + arccos(x) = π/2
> 
> Siempre, para cualquier x ∈ [-1, 1]
> ```
> 
> **Método 5: Calculadora**
> 
> ```
> Para valores no exactos:
> 
> arcsin(0.7) ≈ 0.7754 rad ≈ 44.43°
> arccos(-0.3) ≈ 1.8755 rad ≈ 107.46°
> arctan(2.5) ≈ 1.1903 rad ≈ 68.20°
> 
> Verificar modo: RAD o DEG
> ```

## 🔗 Identidades con Funciones Inversas

> [!important]- Relaciones Fundamentales
> 
> **Identidades de composición:**
> 
> ```
> arcsin(sin(x)) = x  si x ∈ [-π/2, π/2]
> arccos(cos(x)) = x  si x ∈ [0, π]
> arctan(tan(x)) = x  si x ∈ (-π/2, π/2)
> 
> sin(arcsin(x)) = x  si x ∈ [-1, 1]
> cos(arccos(x)) = x  si x ∈ [-1, 1]
> tan(arctan(x)) = x  si x ∈ ℝ
> ```
> 
> **Relaciones entre inversas:**
> 
> ```
> arcsin(x) + arccos(x) = π/2
> 
> arctan(x) + arccot(x) = π/2
> 
> arcsec(x) = arccos(1/x)  (|x| ≥ 1)
> arccsc(x) = arcsin(1/x)  (|x| ≥ 1)
> 
> arctan(x) = arcsin(x/√(1+x²))
> arctan(x) = arccos(1/√(1+x²))  (x ≥ 0)
> ```
> 
> **Propiedades de negación:**
> 
> ```
> arcsin(-x) = -arcsin(x)  (función impar)
> arctan(-x) = -arctan(x)  (función impar)
> arccot(-x) = π - arccot(x)
> 
> arccos(-x) = π - arccos(x)
> arcsec(-x) = π - arcsec(x)
> arccsc(-x) = -arccsc(x)
> ```
> 
> **Fórmulas de suma:**
> 
> ```
> arcsin(x) ± arcsin(y) = arcsin(x√(1-y²) ± y√(1-x²))
> (cuando el resultado está en el rango)
> 
> arctan(x) + arctan(y) = arctan((x+y)/(1-xy))
> (cuando xy < 1)
> 
> arctan(x) - arctan(y) = arctan((x-y)/(1+xy))
> (cuando xy > -1)
> ```
> 
> **Doble ángulo:**
> 
> ```
> 2arcsin(x) = arcsin(2x√(1-x²))  (|x| ≤ √2/2)
> 2arctan(x) = arctan(2x/(1-x²))  (|x| < 1)
> 2arctan(x) = arcsin(2x/(1+x²))
> ```

## 🎨 Gráficas de Funciones Inversas

> [!note]- Visualización y Propiedades Gráficas
> 
> **Simetría respecto a y = x:**
> 
> ```
> La gráfica de f⁻¹(x) es la reflexión de f(x)
> sobre la recta y = x
> 
> Si (a, b) está en la gráfica de f(x)
> entonces (b, a) está en la gráfica de f⁻¹(x)
> ```
> 
> **Características de arcsin(x):**
> 
> ```
> Dominio: [-1, 1]
> Rango: [-π/2, π/2]
> 
> Creciente en todo su dominio
> Impar: simétrica respecto al origen
> Punto de inflexión en (0, 0)
> Pendiente máxima en x = 0: pendiente = 1
> Pendientes verticales en x = ±1
> ```
> 
> **Características de arccos(x):**
> 
> ```
> Dominio: [-1, 1]
> Rango: [0, π]
> 
> Decreciente en todo su dominio
> Pasa por: (-1, π), (0, π/2), (1, 0)
> Concavidad hacia arriba
> Pendientes verticales en x = ±1
> ```
> 
> **Características de arctan(x):**
> 
> ```
> Dominio: ℝ
> Rango: (-π/2, π/2)
> 
> Creciente en todo su dominio
> Impar: simétrica respecto al origen
> Asíntotas horizontales:
>   y = π/2 (cuando x → +∞)
>   y = -π/2 (cuando x → -∞)
> Punto de inflexión en (0, 0)
> Forma de "S" estirada
> ```

## 🔧 Aplicaciones Prácticas

> [!example]- Uso en Problemas Reales
> 
> **1. Ángulo de elevación:**
> 
> ```
> Un edificio de 50 m está a 30 m de distancia
> ¿Cuál es el ángulo de elevación?
> 
> tan(θ) = 50/30 = 5/3
> θ = arctan(5/3) ≈ 59.04°
> ```
> 
> **2. Navegación:**
> 
> ```
> Un barco navega 8 km al este y 6 km al norte
> ¿Cuál es el rumbo (ángulo desde el este)?
> 
> tan(θ) = 6/8 = 3/4
> θ = arctan(3/4) ≈ 36.87°
> 
> Rumbo: 36.87° norte del este
> ```
> 
> **3. Física - Proyectiles:**
> 
> ```
> Un proyectil con velocidad v₀ alcanza altura h
> ¿Ángulo de lanzamiento?
> 
> v_y = v₀·sin(θ)
> Altura máxima: h = v_y²/(2g) = v₀²sin²(θ)/(2g)
> 
> sin²(θ) = 2gh/v₀²
> sin(θ) = √(2gh/v₀²)
> θ = arcsin(√(2gh/v₀²))
> ```
> 
> **4. Cinemática inversa (robótica):**
> 
> ```
> Brazo robótico de dos segmentos:
> - Segmento 1: longitud L₁
> - Segmento 2: longitud L₂
> - Punto final en (x, y)
> 
> Encontrar ángulos θ₁ y θ₂:
> 
> θ₂ = ±arccos((x² + y² - L₁² - L₂²)/(2L₁L₂))
> 
> θ₁ = arctan(y/x) - arctan((L₂·sin(θ₂))/(L₁ + L₂·cos(θ₂)))
> ```
> 
> **5. Geometría - Triángulos:**
> 
> ```
> Triángulo con lados a = 3, b = 4, c = 5
> Encontrar ángulo C (opuesto al lado c):
> 
> Ley de cosenos: c² = a² + b² - 2ab·cos(C)
> 25 = 9 + 16 - 24·cos(C)
> cos(C) = 0
> C = arccos(0) = π/2 (90°)
> 
> Es un triángulo rectángulo
> ```
> 
> **6. Procesamiento de señales:**
> 
> ```
> Encontrar fase de señal compleja:
> z = a + bi
> 
> Fase: φ = arctan(b/a)
> 
> Pero considerar cuadrante:
> Usar función atan2(b, a) en programación
> que devuelve ángulo correcto en [-π, π]
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes
> 
> **1. "sin⁻¹(x) = 1/sin(x)"**
> 
> ```
> ✗ INCORRECTO
> 
> sin⁻¹(x) = arcsin(x)  (función inversa)
> 1/sin(x) = csc(x)     (función recíproca)
> 
> Son completamente diferentes
> 
> Ejemplo:
> sin⁻¹(1/2) = π/6 ≈ 0.524
> 1/sin(1/2) = 1/0.479 ≈ 2.086
> ```
> 
> **2. "arcsin(sin(x)) = x siempre"**
> 
> ```
> ✗ INCORRECTO
> 
> Solo cierto si x ∈ [-π/2, π/2]
> 
> Contraejemplo:
> arcsin(sin(3π/4)) ≠ 3π/4
> arcsin(sin(3π/4)) = arcsin(√2/2) = π/4
> 
> (porque 3π/4 fuera del rango de arcsin)
> ```
> 
> **3. "arcsin tiene periodo 2π"**
> 
> ```
> ✗ INCORRECTO
> 
> Las funciones inversas NO son periódicas
> Solo están definidas en un intervalo limitado
> 
> Sin(x) es periódica, pero arcsin(x) no lo es
> ```
> 
> **4. "Olvidar restricciones de dominio"**
> 
> ```
> arcsin(2) no existe en números reales
> (porque 2 > 1)
> 
> arctan(2) = ??? existe
> (porque arctan acepta cualquier real)
> 
> Verificar siempre el dominio antes de evaluar
> ```
> 
> **5. "Signos incorrectos en composiciones"**
> 
> ```
> 
> 
> 
> cos(arcsin(x)) = ?
> 
> ✗ INCORRECTO: ±√(1-x²)
> 
> ✓ CORRECTO: √(1-x²)  (siempre positivo)
> 
> Razón: arcsin(x) ∈ [-π/2, π/2]
>        En este rango, cos siempre ≥ 0
> 
> Ejemplo: cos(arcsin(1/2)) = cos(π/6) = √3/2 > 0
> ```
> 
> **6. "Usar calculadora en modo incorrecto"**
> 
> ```
> ✗ ERROR COMÚN:
> Calculadora en grados, esperando radianes
> o viceversa
> 
> arcsin(0.5) en RAD = 0.5236 rad
> arcsin(0.5) en DEG = 30°
> 
> SIEMPRE verificar modo antes de calcular
> ```
> 
> **7. "Confundir rangos de diferentes funciones"**
> 
> ```
> arcsin devuelve: [-π/2, π/2]
> arccos devuelve: [0, π]
> arctan devuelve: (-π/2, π/2)
> 
> NO son los mismos rangos
> 
> Ejemplo:
> arcsin(-1/2) = -π/6 (negativo posible)
> arccos(-1/2) = 2π/3 (siempre no-negativo)
> ```
> 
> **8. "Errores con múltiples soluciones"**
> 
> ```
> Resolver: sin(x) = 1/2 en [0, 2π]
> 
> ✗ INCORRECTO: x = arcsin(1/2) = π/6
> 
> ✓ CORRECTO: 
> x₁ = arcsin(1/2) = π/6
> x₂ = π - arcsin(1/2) = π - π/6 = 5π/6
> 
> arcsin solo da UNA solución (valor principal)
> Hay que encontrar las demás usando geometría
> ```

## 🧮 Derivadas de Funciones Inversas

> [!important]- Cálculo Diferencial
> 
> **Fórmulas de derivadas:**
> 
> ```
> d/dx[arcsin(x)] = 1/√(1-x²)     para |x| < 1
> 
> d/dx[arccos(x)] = -1/√(1-x²)    para |x| < 1
> 
> d/dx[arctan(x)] = 1/(1+x²)      para todo x ∈ ℝ
> 
> d/dx[arccot(x)] = -1/(1+x²)     para todo x ∈ ℝ
> 
> d/dx[arcsec(x)] = 1/(|x|√(x²-1)) para |x| > 1
> 
> d/dx[arccsc(x)] = -1/(|x|√(x²-1)) para |x| > 1
> ```
> 
> **Demostración (ejemplo con arcsin):**
> 
> ```
> Sea y = arcsin(x), entonces sin(y) = x
> 
> Derivar implícitamente respecto a x:
> cos(y)·dy/dx = 1
> dy/dx = 1/cos(y)
> 
> Como y ∈ [-π/2, π/2], cos(y) ≥ 0
> cos(y) = √(1 - sin²(y)) = √(1 - x²)
> 
> Por tanto: dy/dx = 1/√(1-x²)
> ```
> 
> **Aplicaciones de derivadas:**
> 
> ```
> 1) Encontrar pendiente de gráfica:
>    En x = 0: d/dx[arcsin(x)]|ₓ₌₀ = 1/√1 = 1
>    Pendiente de 45° en el origen
> 
> 2) Puntos críticos:
>    arctan no tiene puntos críticos
>    (derivada siempre positiva)
> 
> 3) Concavidad:
>    d²/dx²[arctan(x)] = -2x/(1+x²)²
>    Cóncava abajo para x > 0
>    Cóncava arriba para x < 0
> ```

## 🔢 Integrales con Funciones Inversas

> [!success]- Cálculo Integral
> 
> **Fórmulas fundamentales:**
> 
> ```
> ∫ 1/√(1-x²) dx = arcsin(x) + C
> 
> ∫ 1/(1+x²) dx = arctan(x) + C
> 
> ∫ 1/(x√(x²-1)) dx = arcsec(|x|) + C
> 
> ∫ 1/√(a²-x²) dx = arcsin(x/a) + C
> 
> ∫ 1/(a²+x²) dx = (1/a)arctan(x/a) + C
> ```
> 
> **Integrales por partes:**
> 
> ```
> ∫ arcsin(x) dx:
> 
> u = arcsin(x)     dv = dx
> du = 1/√(1-x²) dx  v = x
> 
> ∫ arcsin(x) dx = x·arcsin(x) - ∫ x/√(1-x²) dx
>                = x·arcsin(x) + √(1-x²) + C
> 
> Similares:
> ∫ arccos(x) dx = x·arccos(x) - √(1-x²) + C
> ∫ arctan(x) dx = x·arctan(x) - (1/2)ln(1+x²) + C
> ```
> 
> **Sustitución trigonométrica:**
> 
> ```
> Para integrales tipo ∫ f(√(a²-x²)) dx:
> Sustituir x = a·sin(θ), dx = a·cos(θ)dθ
> θ = arcsin(x/a)
> 
> Para integrales tipo ∫ f(√(a²+x²)) dx:
> Sustituir x = a·tan(θ), dx = a·sec²(θ)dθ
> θ = arctan(x/a)
> 
> Para integrales tipo ∫ f(√(x²-a²)) dx:
> Sustituir x = a·sec(θ), dx = a·sec(θ)tan(θ)dθ
> θ = arcsec(x/a)
> ```
> 
> **Ejemplos resueltos:**
> 
> ```
> 1) ∫ 1/√(9-x²) dx
>    = ∫ 1/√(3²-x²) dx
>    = arcsin(x/3) + C
> 
> 2) ∫ 1/(4+x²) dx
>    = ∫ 1/(2²+x²) dx
>    = (1/2)arctan(x/2) + C
> 
> 3) ∫₀¹ 1/√(1-x²) dx
>    = arcsin(x)|₀¹
>    = arcsin(1) - arcsin(0)
>    = π/2 - 0 = π/2
> ```

## 🎯 Resolución de Ecuaciones

> [!tip]- Ecuaciones con Funciones Inversas
> 
> **Tipo 1: Inversas directas**
> 
> ```
> Resolver: arcsin(x) = π/6
> 
> Aplicar seno a ambos lados:
> sin(arcsin(x)) = sin(π/6)
> x = 1/2
> 
> Verificar: arcsin(1/2) = π/6 ✓
> ```
> 
> **Tipo 2: Composiciones**
> 
> ```
> Resolver: arccos(2x - 1) = π/3
> 
> Aplicar coseno:
> cos(arccos(2x-1)) = cos(π/3)
> 2x - 1 = 1/2
> 2x = 3/2
> x = 3/4
> 
> Verificar dominio: |2x-1| ≤ 1
> |2(3/4)-1| = |1/2| ≤ 1 ✓
> ```
> 
> **Tipo 3: Suma de inversas**
> 
> ```
> Resolver: arcsin(x) + arcsin(2x) = π/2
> 
> Usar: arcsin(x) + arccos(x) = π/2
> Por tanto: arcsin(2x) = arccos(x)
> 
> Aplicar seno:
> 2x = sin(arccos(x)) = √(1-x²)
> 4x² = 1 - x²
> 5x² = 1
> x = ±1/√5
> 
> Verificar restricciones:
> |x| ≤ 1 y |2x| ≤ 1 → |x| ≤ 1/2
> 
> Solo x = 1/√5 ≈ 0.447 es válida
> ```
> 
> **Tipo 4: Ecuaciones trigonométricas**
> 
> ```
> Resolver: 2sin(x) = 1 en [0, 2π]
> 
> sin(x) = 1/2
> 
> Solución principal:
> x₁ = arcsin(1/2) = π/6
> 
> Segunda solución en el mismo ciclo:
> x₂ = π - arcsin(1/2) = π - π/6 = 5π/6
> 
> Soluciones: x = π/6, 5π/6
> ```
> 
> **Tipo 5: Con tangente**
> 
> ```
> Resolver: tan(x) = -√3 en [0, 2π]
> 
> Solución principal de arctan:
> arctan(-√3) = -π/3 (fuera de [0, 2π])
> 
> Ajustar al rango deseado:
> x₁ = -π/3 + π = 2π/3 (cuadrante II)
> x₂ = -π/3 + 2π = 5π/3 (cuadrante IV)
> 
> Soluciones: x = 2π/3, 5π/3
> ```

## 🌐 Extensión a Números Complejos

> [!note]- Funciones Inversas Complejas
> 
> **Definiciones complejas:**
> 
> ```
> Para z ∈ ℂ:
> 
> arcsin(z) = -i·ln(iz + √(1-z²))
> 
> arccos(z) = -i·ln(z + √(z²-1))
> 
> arctan(z) = (i/2)·ln((i+z)/(i-z))
> 
> Estas fórmulas son multivaluadas en ℂ
> ```
> 
> **Ejemplo con número complejo:**
> 
> ```
> arcsin(2) en ℂ:
> 
> arcsin(2) = -i·ln(2i + √(1-4))
>           = -i·ln(2i + √(-3))
>           = -i·ln(2i + i√3)
>           = -i·ln(i(2 + √3))
>           ≈ 1.5708 - 1.3170i
> 
> Verificación:
> sin(1.5708 - 1.3170i) ≈ 2
> ```
> 
> **Ramas principales:**
> 
> ```
> En ℂ, las funciones inversas son multivaluadas
> La rama principal se elige convencionalmente
> 
> Esto extiende los rangos definidos para ℝ
> ```

## 📱 Funciones Inversas en Programación

> [!example]- Implementación Computacional
> 
> **Función atan2:**
> 
> ```
> atan2(y, x) devuelve arctan(y/x) considerando cuadrante
> 
> Rango: [-π, π] (o [-180°, 180°])
> 
> Ventaja sobre arctan:
> - Maneja x = 0 correctamente
> - Distingue los cuatro cuadrantes
> - Evita división por cero
> 
> Uso típico:
> ángulo = atan2(y, x)
> 
> Ejemplos:
> atan2(1, 1) = π/4 (cuadrante I)
> atan2(1, -1) = 3π/4 (cuadrante II)
> atan2(-1, -1) = -3π/4 (cuadrante III)
> atan2(-1, 1) = -π/4 (cuadrante IV)
> atan2(1, 0) = π/2 (eje y positivo)
> ```
> 
> **Conversión cartesiano ↔ polar:**
> 
> ```
> Cartesiano a polar:
> r = √(x² + y²)
> θ = atan2(y, x)
> 
> Polar a cartesiano:
> x = r·cos(θ)
> y = r·sin(θ)
> 
> Código (Python):
> import math
> 
> # Cartesiano a polar
> r = math.sqrt(x**2 + y**2)
> theta = math.atan2(y, x)
> 
> # Polar a cartesiano
> x = r * math.cos(theta)
> y = r * math.sin(theta)
> ```
> 
> **Precisión numérica:**
> 
> ```
> Cerca de límites del dominio, pueden ocurrir errores:
> 
> arcsin(1.0) puede dar π/2 + ε (error pequeño)
> 
> Para x muy cercano a ±1:
> arcsin(x) ≈ π/2 - √(2(1-|x|))  (aproximación)
> 
> Para x muy grande:
> arctan(x) ≈ π/2 - 1/x  (aproximación)
> ```
> 
> **Algoritmos de cálculo:**
> 
> ```
> Series de Taylor (para |x| pequeño):
> arcsin(x) = x + x³/6 + 3x⁵/40 + 5x⁷/112 + ...
> arctan(x) = x - x³/3 + x⁵/5 - x⁷/7 + ...
> 
> Aproximaciones racionales (métodos modernos):
> Más eficientes y precisos en computadoras
> 
> Reducción de rango:
> Usar identidades para reducir a intervalo pequeño
> donde series convergen rápidamente
> ```

## 🎨 Aplicaciones Avanzadas

> [!example]- Problemas Complejos
> 
> **1. Optimización con restricciones:**
> 
> ```
> Maximizar el área de un rectángulo inscrito
> en un semicírculo de radio R
> 
> Sea θ el ángulo desde el centro:
> Base: 2R·cos(θ)
> Altura: R·sin(θ)
> 
> Área: A(θ) = 2R²·sin(θ)·cos(θ) = R²·sin(2θ)
> 
> Máximo cuando sin(2θ) = 1:
> 2θ = π/2
> θ = π/4
> 
> Dimensiones óptimas:
> Base = 2R·cos(π/4) = R√2
> Altura = R·sin(π/4) = R√2/2
> ```
> 
> **2. Análisis de vibraciones:**
> 
> ```
> Sistema masa-resorte con amortiguamiento:
> x(t) = Ae^(-γt)·cos(ωt + φ)
> 
> Condiciones iniciales:
> x(0) = x₀
> v(0) = v₀
> 
> Determinar fase φ:
> x₀ = A·cos(φ)
> v₀ = -Aγ·cos(φ) - Aω·sin(φ)
> 
> Resolver:
> tan(φ) = -(v₀ + γx₀)/(ωx₀)
> φ = arctan(-(v₀ + γx₀)/(ωx₀))
> ```
> 
> **3. Refracción de luz (Ley de Snell):**
> 
> ```
> n₁·sin(θ₁) = n₂·sin(θ₂)
> 
> Encontrar ángulo de refracción:
> sin(θ₂) = (n₁/n₂)·sin(θ₁)
> θ₂ = arcsin((n₁/n₂)·sin(θ₁))
> 
> Ángulo crítico (reflexión total):
> Cuando θ₂ = 90°:
> sin(θc) = n₂/n₁
> θc = arcsin(n₂/n₁)
> ```
> 
> **4. Geodesia (distancia en esfera):**
> 
> ```
> Distancia entre dos puntos en la Tierra:
> (lat₁, lon₁) y (lat₂, lon₂)
> 
> Fórmula haversine:
> a = sin²(Δlat/2) + cos(lat₁)·cos(lat₂)·sin²(Δlon/2)
> c = 2·arcsin(√a)
> d = R·c
> 
> donde R = radio de la Tierra ≈ 6371 km
> ```
> 
> **5. Control de sistemas:**
> 
> ```
> Control PID con feedforward:
> u(t) = Kp·e(t) + Ki·∫e(t)dt + Kd·de/dt
> 
> Ajuste de ángulo de servomotor:
> θ_deseado = arcsin(x/L)
> 
> donde x es posición deseada
> y L es longitud del brazo
> ```

## 🎓 Conceptos Clave

> [!important]- Resumen Ejecutivo
> 
> **Definición:**
> 
> - Funciones inversas de las trigonométricas
> - Devuelven ángulos (no razones)
> - Requieren restricción de dominio original
> 
> **Notación:**
> 
> - arcsin, arccos, arctan (preferida)
> - sin⁻¹, cos⁻¹, tan⁻¹ (cuidado: no es potencia)
> - ⚠️ sin⁻¹(x) ≠ 1/sin(x)
> 
> **Rangos principales:**
> 
> - arcsin: [-π/2, π/2]
> - arccos: [0, π]
> - arctan: (-π/2, π/2)
> 
> **Identidades clave:**
> 
> - arcsin(x) + arccos(x) = π/2
> - arctan(x) + arccot(x) = π/2
> - arcsin(sin(x)) = x solo si x en rango
> 
> **Aplicaciones:**
> 
> - Encontrar ángulos dados razones
> - Resolver ecuaciones trigonométricas
> - Cálculo: derivadas e integrales
> - Geometría, física, ingeniería
> 
> **Composiciones:**
> 
> - Usar identidad pitagórica
> - Considerar signos según rango
> - Dibujar triángulo de referencia
> 
> **En programación:**
> 
> - atan2(y,x) para cuatro cuadrantes
> - Conversión cartesiano ↔ polar
> - Cuidado con precisión numérica
