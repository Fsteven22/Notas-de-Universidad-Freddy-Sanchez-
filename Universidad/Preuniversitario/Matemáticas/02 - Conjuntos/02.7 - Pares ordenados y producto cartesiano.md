# 🎯 Pares Ordenados y Producto Cartesiano

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Un par ordenado (a, b) es una estructura matemática que agrupa dos elementos donde el orden importa. El producto cartesiano A × B es el conjunto de todos los pares ordenados posibles formados con elementos de A y B.**
> 
> **Elementos clave:**
> 
> - **Orden crucial:** (a, b) ≠ (b, a) en general
> - **Coordenadas:** Generalización de posiciones en el plano
> - **Construcción:** Herramienta fundamental para definir relaciones y funciones
> - **Dimensionalidad:** Base para espacios n-dimensionales

### 📖 Contexto Histórico

> [!note]- Desarrollo Histórico
> 
> **Geometría Analítica (1637):**
> 
> - **René Descartes:** Introduce coordenadas para unir álgebra y geometría
> - **Pierre de Fermat:** Desarrollo independiente y simultáneo
> - **Innovación:** Representar curvas mediante ecuaciones algebraicas
> - **Impacto:** Revoluciona las matemáticas permitiendo visualizar álgebra
> 
> **Formalización de Pares Ordenados (1914-1921):**
> 
> - **Norbert Wiener (1914):** Primera definición conjuntista rigurosa
>     - `(a, b) = {{{a}, ∅}, {{b}}}`
> - **Kazimierz Kuratowski (1921):** Definición más elegante y estándar
>     - `(a, b) = {{a}, {a, b}}`
> - **Motivación:** Fundamentar rigurosamente la teoría de funciones
> 
> **Producto Cartesiano (siglo XIX-XX):**
> 
> - **Nombre:** En honor a René Descartes (Cartesius en latín)
> - **Cantor:** Uso en teoría de conjuntos
> - **Teoría de categorías (1940s):** Generalización abstracta del concepto
> - **Aplicaciones:** Base de bases de datos relacionales (Codd, 1970)
> 
> **Geometría de Dimensiones Superiores:**
> 
> - **Hermann Grassmann (1844):** Álgebra de espacios n-dimensionales
> - **Bernhard Riemann (1854):** Geometría de variedades
> - **Desarrollo:** De ℝ² y ℝ³ a ℝⁿ y espacios abstractos

## 📐 Pares Ordenados

### 🎯 Definición y Notación

> [!success]- Par Ordenado Formal
> 
> **Definición intuitiva:**
> 
> ```
> Un par ordenado es una colección de dos elementos (a, b)
> donde se distingue cuál es el primero y cuál el segundo
> ```
> 
> **Definición formal (Kuratowski, 1921):**
> 
> ```
> (a, b) = {{a}, {a, b}}
> ```
> 
> **Notación:**
> 
> - Paréntesis: `(a, b)`
> - Primera componente/coordenada: `a`
> - Segunda componente/coordenada: `b`
> 
> **Propiedad fundamental:**
> 
> ```
> (a, b) = (c, d) ⟺ a = c ∧ b = d
> ```
> 
> Esta propiedad define completamente qué es un par ordenado

> [!example]- Ejemplos Básicos
> 
> **Pares ordenados concretos:**
> 
> ```
> (1, 2)        - Par de números naturales
> (-3, 5)       - Par de enteros
> (π, √2)       - Par de reales
> ('a', 'b')    - Par de caracteres
> (Madrid, España) - Par de ubicaciones
> ```
> 
> **Importancia del orden:**
> 
> ```
> (2, 3) ≠ (3, 2)
> (5, 5) = (5, 5)  ✓ (componentes iguales permitidas)
> (a, b) = (b, a) ⟺ a = b
> ```
> 
> **Verificación de igualdad:**
> 
> ```
> (2, 3) = (2, 3)  ✓  (mismas coordenadas)
> (2, 3) = (3, 2)  ✗  (orden diferente)
> (2, 3) = (2, 4)  ✗  (segunda coordenada distinta)
> (x, 5) = (3, y)  ⟹  x = 3 ∧ y = 5
> ```

### 🔍 Verificación de la Definición de Kuratowski

> [!note]- ¿Por qué funciona {{a}, {a, b}}?
> 
> **Demostración de la propiedad característica:**
> 
> Queremos probar: `(a, b) = (c, d) ⟺ a = c ∧ b = d`
> 
> **Dirección (⟸):** Trivial
> 
> ```
> Si a = c ∧ b = d, entonces claramente
> {{a}, {a, b}} = {{c}, {c, d}}
> ```
> 
> **Dirección (⟹):** Más sutil
> 
> ```
> Supongamos {{a}, {a, b}} = {{c}, {c, d}}
> 
> Caso 1: a = b
>   Entonces (a, b) = {{a}, {a}} = {{a}}
>   Luego {{c}, {c, d}} = {{a}}
>   Por tanto {c} = {a} y {c, d} = {a}
>   Entonces c = a y d = a = b ✓
> 
> Caso 2: a ≠ b
>   Entonces (a, b) = {{a}, {a, b}} tiene dos elementos distintos
>   Luego {{c}, {c, d}} también tiene dos elementos distintos
>   Por tanto c ≠ d
>   
>   Como {a} ∈ {{a}, {a, b}} y {a} ∈ {{c}, {c, d}}:
>   Entonces {a} = {c} o {a} = {c, d}
>   
>   Si {a} = {c, d} con c ≠ d: contradicción (un singleton ≠ par)
>   Por tanto {a} = {c}, es decir a = c
>   
>   Análogamente, {a, b} = {c, d} = {a, d}
>   Como a ≠ b, necesariamente b = d ✓
> ```
> 
> **Conclusión:** La definición de Kuratowski captura perfectamente la noción de orden

## 🔲 Producto Cartesiano

### 📚 Definición Formal

> [!success]- Producto Cartesiano de Dos Conjuntos
> 
> **Definición:**
> 
> ```
> Sean A y B conjuntos. El producto cartesiano A × B es:
> 
> A × B = {(a, b) : a ∈ A ∧ b ∈ B}
> ```
> 
> "Conjunto de todos los pares ordenados donde la primera componente viene de A y la segunda de B"
> 
> **Notación:**
> 
> - Símbolo: `×` (multiplicación cartesiana)
> - Se lee: "A cruz B" o "A producto B"
> 
> **Elementos:**
> 
> ```
> Si A = {a₁, a₂, ..., aₙ} y B = {b₁, b₂, ..., bₘ}
> 
> Entonces A × B contiene n·m pares ordenados
> ```
> 
> **Propiedades básicas:**
> 
> ```
> 1. Si A o B es vacío: A × ∅ = ∅ × B = ∅
> 2. En general: A × B ≠ B × A
> 3. No es asociativo sin paréntesis adicionales
> 4. |A × B| = |A| · |B|
> ```

> [!example]- Ejemplos Concretos
> 
> **Ejemplo 1: Conjuntos pequeños finitos**
> 
> ```
> A = {1, 2}
> B = {a, b, c}
> 
> A × B = {(1,a), (1,b), (1,c), (2,a), (2,b), (2,c)}
> 
> |A × B| = 2 · 3 = 6 elementos
> ```
> 
> **Ejemplo 2: No conmutatividad**
> 
> ```
> A = {1, 2}
> B = {x, y}
> 
> A × B = {(1,x), (1,y), (2,x), (2,y)}
> B × A = {(x,1), (x,2), (y,1), (y,2)}
> 
> A × B ≠ B × A  (elementos de tipos diferentes)
> ```
> 
> **Ejemplo 3: Producto consigo mismo**
> 
> ```
> A = {0, 1}
> 
> A × A = {(0,0), (0,1), (1,0), (1,1)}
> 
> A² := A × A  (notación abreviada)
> ```
> 
> **Ejemplo 4: Con conjuntos numéricos**
> 
> ```
> A = {1, 2, 3}
> B = {10, 20}
> 
> A × B = {(1,10), (1,20), (2,10), (2,20), (3,10), (3,20)}
> ```
> 
> **Ejemplo 5: Aplicación práctica**
> 
> ```
> Tallas = {S, M, L}
> Colores = {Rojo, Azul}
> 
> Tallas × Colores = {
>   (S, Rojo), (S, Azul),
>   (M, Rojo), (M, Azul),
>   (L, Rojo), (L, Azul)
> }
> 
> Total de combinaciones: 3 × 2 = 6
> ```

### 🎯 Casos Especiales Importantes

> [!tip]- Productos Cartesianos Notables
> 
> **Producto con conjunto vacío:**
> 
> ```
> ∀A: A × ∅ = ∅
> ∀A: ∅ × A = ∅
> 
> Razón: No hay pares (a, b) donde b ∈ ∅
> ```
> 
> **Producto con singleton:**
> 
> ```
> A = {a}
> B = {b₁, b₂, ..., bₙ}
> 
> A × B = {(a, b₁), (a, b₂), ..., (a, bₙ)}
> 
> |A × B| = 1 · n = n
> ```
> 
> **Cuadrado cartesiano:**
> 
> ```
> A² = A × A
> 
> Si A = {1, 2, 3}:
> A² = {(1,1), (1,2), (1,3),
>       (2,1), (2,2), (2,3),
>       (3,1), (3,2), (3,3)}
> 
> |A²| = |A|² = 9
> ```
> 
> **Productos iterados:**
> 
> ```
> A³ = A × A × A  (triples ordenados)
> Aⁿ = A × A × ... × A  (n veces)
> 
> |Aⁿ| = |A|ⁿ
> ```

## 🔢 Cardinalidad del Producto Cartesiano

### 📏 Teorema de Cardinalidad

> [!success]- Fórmula Fundamental
> 
> **Teorema:**
> 
> ```
> Si A y B son conjuntos finitos, entonces:
> 
> |A × B| = |A| · |B|
> ```
> 
> **Demostración (idea):**
> 
> ```
> Para cada elemento a ∈ A:
>   Se forman |B| pares: (a, b₁), (a, b₂), ..., (a, b|B|)
> 
> Como hay |A| elementos en A:
>   Total de pares = |A| · |B|
> ```
> 
> **Consecuencias:**
> 
> ```
> |A × B × C| = |A| · |B| · |C|
> |Aⁿ| = |A|ⁿ
> 
> Si A = ∅ o B = ∅: |A × B| = 0
> ```

> [!example]- Aplicaciones Combinatorias
> 
> **Ejemplo 1: Menú de restaurante**
> 
> ```
> Entradas = {Sopa, Ensalada}         |Entradas| = 2
> Platos = {Pollo, Pescado, Carne}    |Platos| = 3
> Postres = {Helado, Pastel}          |Postres| = 2
> 
> Combinaciones posibles:
> |Entradas × Platos × Postres| = 2 · 3 · 2 = 12
> ```
> 
> **Ejemplo 2: Contraseñas**
> 
> ```
> Dígitos = {0, 1, 2, ..., 9}        |Dígitos| = 10
> PIN de 4 dígitos = Dígitos⁴
> 
> |Contraseñas| = 10⁴ = 10,000
> ```
> 
> **Ejemplo 3: Coordenadas en retícula**
> 
> ```
> X = {1, 2, 3, 4, 5}
> Y = {1, 2, 3}
> 
> Puntos en la cuadrícula: X × Y
> |X × Y| = 5 · 3 = 15 puntos
> ```

### 🌊 Productos Infinitos

> [!note]- Cuando A o B es Infinito
> 
> **Conjuntos numerables:**
> 
> ```
> |ℕ × ℕ| = ℵ₀  (numerable)
> |ℤ × ℤ| = ℵ₀  (numerable)
> |ℚ × ℚ| = ℵ₀  (numerable)
> ```
> 
> **Plano real:**
> 
> ```
> ℝ² = ℝ × ℝ
> |ℝ²| = 𝔠  (continuo)
> 
> Sorprendentemente: |ℝ²| = |ℝ|
> (Teorema de Cantor-Schröder-Bernstein)
> ```
> 
> **Generalización:**
> 
> ```
> Si A es infinito numerable y B es finito:
>   |A × B| = |A| = ℵ₀
> 
> Si A y B son infinitos numerables:
>   |A × B| = ℵ₀
> ```

## 🧮 Propiedades del Producto Cartesiano

### ⚖️ Propiedades Algebraicas

> [!success]- Leyes Fundamentales
> 
> **1. No conmutatividad:**
> 
> ```
> A × B ≠ B × A  (en general)
> 
> Excepción: Si A = B, entonces A × A = A × A
> Pero los pares (a, b) y (b, a) siguen siendo distintos si a ≠ b
> ```
> 
> **2. No asociatividad (sin paréntesis adicionales):**
> 
> ```
> (A × B) × C ≠ A × (B × C)
> 
> Elementos de tipos diferentes:
> (A × B) × C contiene ((a, b), c)
> A × (B × C) contiene (a, (b, c))
> 
> Nota: Son naturalmente isomorfos
> ```
> 
> **3. Distributividad sobre unión:**
> 
> ```
> A × (B ∪ C) = (A × B) ∪ (A × C)
> (A ∪ B) × C = (A × C) ∪ (B × C)
> ```
> 
> **4. Distributividad sobre intersección:**
> 
> ```
> A × (B ∩ C) = (A × B) ∩ (A × C)
> (A ∩ B) × C = (A × C) ∩ (B × C)
> ```
> 
> **5. Comportamiento con diferencia:**
> 
> ```
> A × (B \ C) = (A × B) \ (A × C)
> (A \ B) × C = (A × C) \ (B × C)
> ```
> 
> **6. Comportamiento con complemento:**
> 
> ```
> Si B, C ⊆ U:
> A × (U \ B) = (A × U) \ (A × B)
> ```

> [!note]- Demostraciones de Propiedades
> 
> **Demostración: A × (B ∪ C) = (A × B) ∪ (A × C)**
> 
> **(⊆)** Sea (x, y) ∈ A × (B ∪ C)
> 
> ```
> Entonces x ∈ A y y ∈ B ∪ C
> Por tanto y ∈ B o y ∈ C
> 
> Si y ∈ B: (x, y) ∈ A × B ⊆ (A × B) ∪ (A × C)
> Si y ∈ C: (x, y) ∈ A × C ⊆ (A × B) ∪ (A × C)
> 
> Por tanto (x, y) ∈ (A × B) ∪ (A × C)
> ```
> 
> **(⊇)** Sea (x, y) ∈ (A × B) ∪ (A × C)
> 
> ```
> Entonces (x, y) ∈ A × B o (x, y) ∈ A × C
> 
> Si (x, y) ∈ A × B: x ∈ A, y ∈ B ⊆ B ∪ C
> Si (x, y) ∈ A × C: x ∈ A, y ∈ C ⊆ B ∪ C
> 
> En ambos casos: (x, y) ∈ A × (B ∪ C)
> ```
> 
> ∴ A × (B ∪ C) = (A × B) ∪ (A × C) ∎

### 🔍 Inclusiones y Subconjuntos

> [!tip]- Relaciones de Contención
> 
> **Productos de subconjuntos:**
> 
> ```
> Si A₁ ⊆ A₂ y B₁ ⊆ B₂, entonces:
> A₁ × B₁ ⊆ A₂ × B₂
> ```
> 
> **Demostración:**
> 
> ```
> Sea (a, b) ∈ A₁ × B₁
> Entonces a ∈ A₁ ⊆ A₂ y b ∈ B₁ ⊆ B₂
> Por tanto (a, b) ∈ A₂ × B₂
> ```
> 
> **Igualdad de productos:**
> 
> ```
> A₁ × B₁ = A₂ × B₂ no implica A₁ = A₂ o B₁ = B₂
> (a menos que los conjuntos sean no vacíos)
> 
> Ejemplo: {1} × ∅ = {2} × ∅ = ∅
> pero {1} ≠ {2}
> ```
> 
> **Propiedad con conjuntos no vacíos:**
> 
> ```
> Si A × B = C × D y A, B, C, D ≠ ∅, entonces:
> A = C y B = D
> ```

## 🎲 Tuplas y Productos n-arios

### 📦 Generalización a n Coordenadas

> [!success]- Tuplas Ordenadas
> 
> **Definición recursiva:**
> 
> ```
> Par ordenado: (a, b) = {{a}, {a, b}}
> Triple ordenado: (a, b, c) = ((a, b), c)
> n-tupla: (a₁, a₂, ..., aₙ) = ((a₁, ..., aₙ₋₁), aₙ)
> ```
> 
> **Definición directa:**
> 
> ```
> Una n-tupla (a₁, a₂, ..., aₙ) es una secuencia ordenada
> donde aᵢ es la i-ésima componente
> ```
> 
> **Propiedad característica:**
> 
> ```
> (a₁, a₂, ..., aₙ) = (b₁, b₂, ..., bₙ) ⟺
> a₁ = b₁ ∧ a₂ = b₂ ∧ ... ∧ aₙ = bₙ
> ```
> 
> **Casos especiales:**
> 
> ```
> n = 0: tupla vacía ()
> n = 1: singleton (a) (técnicamente ≠ a)
> n = 2: par ordenado (a, b)
> n = 3: triple (a, b, c)
> n = 4: cuádrupla (a, b, c, d)
> ```

### 🔢 Producto Cartesiano n-ario

> [!success]- Definición General
> 
> **Producto de n conjuntos:**
> 
> ```
> A₁ × A₂ × ... × Aₙ = 
> {(a₁, a₂, ..., aₙ) : aᵢ ∈ Aᵢ para i = 1, 2, ..., n}
> ```
> 
> **Caso homogéneo:**
> 
> ```
> Aⁿ = A × A × ... × A  (n veces)
>    = {(a₁, a₂, ..., aₙ) : aᵢ ∈ A para todo i}
> ```
> 
> **Cardinalidad:**
> 
> ```
> |A₁ × A₂ × ... × Aₙ| = |A₁| · |A₂| · ... · |Aₙ|
> |Aⁿ| = |A|ⁿ
> ```

> [!example]- Ejemplos de Productos n-arios
> 
> **Espacio tridimensional:**
> 
> ```
> ℝ³ = ℝ × ℝ × ℝ
> Puntos: (x, y, z)
> 
> Ejemplo: P = (3, -2, 5)
> ```
> 
> **Colores RGB:**
> 
> ```
> [0, 255]³ = [0, 255] × [0, 255] × [0, 255]
> 
> Ejemplos:
> Rojo: (255, 0, 0)
> Verde: (0, 255, 0)
> Azul: (0, 0, 255)
> Blanco: (255, 255, 255)
> 
> Total de colores: 256³ = 16,777,216
> ```
> 
> **Dado de n caras lanzado m veces:**
> 
> ```
> Caras = {1, 2, 3, 4, 5, 6}
> Resultados de 3 lanzamientos: Caras³
> 
> |Caras³| = 6³ = 216 resultados posibles
> 
> Ejemplo: (1, 6, 4) - sacó 1, luego 6, luego 4
> ```
> 
> **Bases de datos:**
> 
> ```
> Estudiante = Nombres × Apellidos × ℕ × ℝ⁺
>            = (nombre, apellido, edad, promedio)
> 
> Ejemplo: ("María", "García", 20, 8.5)
> ```

### 🌐 Espacios n-dimensionales

> [!note]- Construcción de Espacios Vectoriales
> 
> **Espacios euclidianos:**
> 
> ```
> ℝⁿ = {(x₁, x₂, ..., xₙ) : xᵢ ∈ ℝ}
> 
> ℝ¹ = ℝ      (recta real)
> ℝ² = ℝ × ℝ  (plano)
> ℝ³          (espacio tridimensional)
> ℝⁿ          (hiperespacio)
> ```
> 
> **Operaciones vectoriales:**
> 
> ```
> Suma: (a₁, ..., aₙ) + (b₁, ..., bₙ) = (a₁+b₁, ..., aₙ+bₙ)
> Escalar: k(a₁, ..., aₙ) = (ka₁, ..., kaₙ)
> ```
> 
> **Producto punto:**
> 
> ```
> (a₁, ..., aₙ) · (b₁, ..., bₙ) = a₁b₁ + a₂b₂ + ... + aₙbₙ
> ```
> 
> **Norma euclidiana:**
> 
> ```
> ||(a₁, ..., aₙ)|| = √(a₁² + a₂² + ... + aₙ²)
> ```

## 🔗 Relaciones y Funciones

### 🎯 Definición de Relación

> [!success]- Relaciones como Subconjuntos del Producto Cartesiano
> 
> **Definición:**
> 
> ```
> Una relación R de A en B es cualquier subconjunto de A × B
> R ⊆ A × B
> ```
> 
> **Notación:**
> 
> ```
> Si (a, b) ∈ R, escribimos: a R b
> Se lee: "a está relacionado con b mediante R"
> ```
> 
> **Relación binaria en A:**
> 
> ```
> R ⊆ A × A
> Es una relación de A en sí mismo
> ```

> [!example]- Ejemplos de Relaciones
> 
> **Relaciones numéricas:**
> 
> ```
> Menor que: < ⊆ ℝ × ℝ
> < = {(x, y) ∈ ℝ² : x < y}
> 
> 3 < 5  porque (3, 5) ∈ 
> ```
> 
> **Divisibilidad:**
> 
> ```
> | ⊆ ℤ × ℤ  (divide a)
> | = {(a, b) : a divide a b}
> 
> 3 | 12  porque (3, 12) ∈ |
> ```
> 
> **Relación de pertenencia a curso:**
> 
> ```
> Estudiantes = {Ana, Luis, María}
> Cursos = {Matemáticas, Física}
> 
> Inscrito ⊆ Estudiantes × Cursos
> Inscrito = {(Ana, Matemáticas), (Ana, Física), (Luis, Matemáticas), (María, Física)}
> ```
> 
> **Relación de parentesco:**
> 
> ```
> Personas = {Juan, María, Pedro, Ana}
> 
> EsPadreDe ⊆ Personas × Personas
> EsPadreDe = {(Juan, Pedro), (Juan, Ana), (María, Pedro)}
> ```
> 
> **Relación vacía y universal:**
> 
> ```
> ∅ ⊆ A × B  (relación vacía - ningún par relacionado)
> A × B      (relación universal - todos relacionados)
> ```

### 📊 Funciones como Relaciones Especiales

> [!success]- De Relaciones a Funciones
> 
> **Definición:**
> 
> ```
> Una función f: A → B es una relación especial f ⊆ A × B donde:
> 
> ∀a ∈ A, ∃!b ∈ B tal que (a, b) ∈ f
> ```
> 
> "Para cada elemento de A, existe exactamente un elemento de B relacionado"
> 
> **Condiciones equivalentes:**
> 
> ```
> 1. Totalidad: Todo a ∈ A está relacionado con algún b
> 2. Unicidad: Si (a, b₁) ∈ f y (a, b₂) ∈ f, entonces b₁ = b₂
> ```
> 
> **Notación funcional vs relacional:**
> 
> ```
> Relacional: (a, b) ∈ f
> Funcional: f(a) = b
> 
> El conjunto f es literalmente el conjunto de pares:
> f = {(a, f(a)) : a ∈ A}
> ```

> [!example]- Ejemplos: Relaciones vs Funciones
> 
> **No es función (falla unicidad):**
> 
> ```
> A = {1, 2, 3}
> B = {a, b}
> 
> R = {(1, a), (1, b), (2, a), (3, b)}
>      ^^^^^^^^ problema: 1 relacionado con a y b
> 
> NO es función porque 1 está asociado a dos valores
> ```
> 
> **No es función (falla totalidad):**
> 
> ```
> R = {(1, a), (3, b)}
> 
> NO es función porque 2 ∈ A no está relacionado
> ```
> 
> **Sí es función:**
> 
> ```
> f = {(1, a), (2, b), (3, a)}
> 
> f: A → B es función porque:
> - Cada elemento de A aparece exactamente una vez
> - f(1) = a, f(2) = b, f(3) = a
> ```
> 
> **Función como fórmula:**
> 
> ```
> f: ℝ → ℝ definida por f(x) = x²
> 
> Como relación:
> f = {(x, x²) : x ∈ ℝ} ⊆ ℝ × ℝ
> 
> Ejemplos de pares:
> (0, 0) ∈ f
> (2, 4) ∈ f
> (-3, 9) ∈ f
> ```

## 📐 Interpretaciones Geométricas

### 🗺️ El Plano Cartesiano

> [!note]- ℝ² como Producto Cartesiano
> 
> **Construcción:**
> 
> ```
> ℝ² = ℝ × ℝ = {(x, y) : x, y ∈ ℝ}
> ```
> 
> **Componentes:**
> 
> - **Eje x:** Primera coordenada (abscisa)
> - **Eje y:** Segunda coordenada (ordenada)
> - **Origen:** O = (0, 0)
> - **Cuadrantes:** Divisiones del plano
> 
> **Cuadrantes:**
> 
> ```
>     II  |  I
>         |
>   ------+------
>         |
>    III  | IV
> 
> I:   x > 0, y > 0
> II:  x < 0, y > 0
> III: x < 0, y < 0
> IV:  x > 0, y < 0
> ```
> 
> **Distancia euclidiana:**
> 
> ```
> d((x₁, y₁), (x₂, y₂)) = √[(x₂-x₁)² + (y₂-y₁)²]
> ```

> [!example]- Subconjuntos de ℝ²
> 
> **Línea vertical:**
> 
> ```
> L = {x₀} × ℝ = {(x₀, y) : y ∈ ℝ}
> 
> Ejemplo: x = 3
> L = {(3, y) : y ∈ ℝ}
> ```
> 
> **Línea horizontal:**
> 
> ```
> L = ℝ × {y₀} = {(x, y₀) : x ∈ ℝ}
> 
> Ejemplo: y = -2
> L = {(x, -2) : x ∈ ℝ}
> ```
> 
> **Rectángulo:**
> 
> ```
> R = [a, b] × [c, d]
> R = {(x, y) : a ≤ x ≤ b, c ≤ y ≤ d}
> 
> Ejemplo: [0, 3] × [1, 4]
> ```
> 
> **Circunferencia:**
> 
> ```
> C = {(x, y) ∈ ℝ² : (x-h)² + (y-k)² = r²}
> 
> No es producto cartesiano, pero es subconjunto de ℝ²
> ```
> 
> **Primer cuadrante:**
> 
> ```
> Q₁ = ℝ⁺ × ℝ⁺ = {(x, y) : x > 0, y > 0}
> 
> Con origen incluido:
> Q₁ = [0, ∞) × [0, ∞)
> ```

### 🎯 Gráficas de Funciones

> [!tip]- La Gráfica como Subconjunto
> 
> **Definición:**
> 
> ```
> Si f: A → B, la gráfica de f es:
> 
> Graf(f) = {(x, f(x)) : x ∈ A} ⊆ A × B
> ```
> 
> **Prueba de la línea vertical:**
> 
> ```
> Un subconjunto R ⊆ ℝ² es gráfica de una función
> ⟺ cada línea vertical corta R en a lo más un punto
> ```
> 
> **Razón:**
> 
> ```
> Si x está en el dominio, debe existir exactamente
> un valor f(x), por tanto exactamente un punto (x, f(x))
> ```

> [!example]- Ejemplos de Gráficas
> 
> **Función lineal:**
> 
> ```
> f(x) = 2x + 1
> Graf(f) = {(x, 2x + 1) : x ∈ ℝ} ⊆ ℝ²
> 
> Pasa prueba línea vertical: ✓ es función
> ```
> 
> **Circunferencia unitaria:**
> 
> ```
> C = {(x, y) : x² + y² = 1}
> 
> Pasa prueba línea vertical: ✗ NO es función
> (x = 0 da dos puntos: (0, 1) y (0, -1))
> ```
> 
> **Función valor absoluto:**
> 
> ```
> f(x) = |x|
> Graf(f) = {(x, |x|) : x ∈ ℝ}
> 
> Ejemplos de puntos:
> (-2, 2), (-1, 1), (0, 0), (1, 1), (2, 2) ∈ Graf(f)
> ```

## ⚠️ Errores Comunes y Confusiones

> [!warning]- Malentendidos Frecuentes
> 
> **1. "A × B = B × A"**
> 
> ```
> ✗ INCORRECTO en general
> ✓ CORRECTO: A × B ≠ B × A (salvo casos especiales)
> 
> Contraejemplo:
> A = {1}, B = {a}
> A × B = {(1, a)}
> B × A = {(a, 1)}
> 
> (1, a) ≠ (a, 1)  (diferentes tipos de componentes)
> ```
> 
> **2. "El orden no importa en pares ordenados"**
> 
> ```
> ✗ INCORRECTO: (a, b) = (b, a) siempre
> ✓ CORRECTO: (a, b) = (b, a) ⟺ a = b
> 
> (2, 3) ≠ (3, 2)
> (5, 5) = (5, 5) ✓
> ```
> 
> **3. "Los pares ordenados son conjuntos"**
> 
> ```
> ✗ INCORRECTO: (a, b) = {a, b}
> ✓ CORRECTO: (a, b) = {{a}, {a, b}} (definición de Kuratowski)
> 
> {a, b} = {b, a}  (conjuntos: orden no importa)
> (a, b) ≠ (b, a) en general (pares: orden importa)
> ```
> 
> **4. "|A × B| = |A| + |B|"**
> 
> ```
> ✗ INCORRECTO
> ✓ CORRECTO: |A × B| = |A| · |B|
> 
> Ejemplo:
> A = {1, 2}, B = {a, b, c}
> |A × B| = 2 · 3 = 6 ✓
> |A × B| ≠ 2 + 3 = 5 ✗
> ```
> 
> **5. "A × ∅ = A"**
> 
> ```
> ✗ INCORRECTO
> ✓ CORRECTO: A × ∅ = ∅
> 
> Razón: No hay pares (a, b) donde b ∈ ∅
> ```
> 
> **6. "(a, b, c) = ((a, b), c) = (a, (b, c))"**
> 
> ```
> ✗ INCORRECTO: estas son estructuras diferentes
> 
> ((a, b), c)  - par donde primer elemento es par
> (a, (b, c))  - par donde segundo elemento es par
> (a, b, c)    - triple (convencionalmente = ((a, b), c))
> 
> Son naturalmente isomorfos pero técnicamente distintos
> ```
> 
> **7. "Todo subconjunto de A × B es una función"**
> 
> ```
> ✗ INCORRECTO
> ✓ CORRECTO: Solo los que satisfacen totalidad y unicidad
> 
> Contraejemplo:
> A = {1, 2}, B = {a, b}
> R = {(1, a), (1, b)} ⊆ A × B
> 
> NO es función (1 mapea a dos valores)
> ```

## 🧮 Propiedades Avanzadas

### 🔄 Proyecciones

> [!success]- Funciones de Proyección
> 
> **Definición:**
> 
> ```
> Dada (a, b) ∈ A × B:
> 
> π₁: A × B → A  (primera proyección)
> π₁((a, b)) = a
> 
> π₂: A × B → B  (segunda proyección)
> π₂((a, b)) = b
> ```
> 
> **Propiedades:**
> 
> ```
> π₁ es sobreyectiva si A ≠ ∅ y B ≠ ∅
> π₂ es sobreyectiva si A ≠ ∅ y B ≠ ∅
> 
> Para todo (a, b) ∈ A × B:
> (π₁((a, b)), π₂((a, b))) = (a, b)
> ```
> 
> **Generalización a n-tuplas:**
> 
> ```
> πᵢ: A₁ × ... × Aₙ → Aᵢ
> πᵢ((a₁, ..., aₙ)) = aᵢ
> 
> Ejemplo en ℝ³:
> π₁((x, y, z)) = x
> π₂((x, y, z)) = y
> π₃((x, y, z)) = z
> ```

> [!example]- Aplicaciones de Proyecciones
> 
> **Extracción de componentes:**
> 
> ```python
> # Python
> punto = (3, 4)
> x = punto[0]  # proyección π₁
> y = punto[1]  # proyección π₂
> ```
> 
> **Bases de datos:**
> 
> ```sql
> SELECT nombre FROM Estudiantes;
> -- Proyecta solo la coordenada "nombre"
> -- de cada tupla en la tabla
> ```
> 
> **Sombras geométricas:**
> 
> ```
> P = (x, y, z) ∈ ℝ³
> 
> Sombra en plano XY: (x, y, 0) = (π₁(P), π₂(P), 0)
> Sombra en plano XZ: (x, 0, z) = (π₁(P), 0, π₃(P))
> ```

### 🔀 Producto Cartesiano de Familias

> [!note]- Productos Infinitos
> 
> **Producto cartesiano arbitrario:**
> 
> ```
> Dada familia {Aᵢ}ᵢ∈I de conjuntos indexados por I:
> 
> ∏ᵢ∈I Aᵢ = {f: I → ⋃ᵢ∈I Aᵢ : f(i) ∈ Aᵢ para todo i ∈ I}
> ```
> 
> "Conjunto de todas las funciones elección que seleccionan un elemento de cada Aᵢ"
> 
> **Notación de tuplas (I finito):**
> 
> ```
> Si I = {1, 2, ..., n}:
> ∏ᵢ₌₁ⁿ Aᵢ = A₁ × A₂ × ... × Aₙ
> 
> Elementos: (a₁, a₂, ..., aₙ) donde aᵢ ∈ Aᵢ
> ```
> 
> **Axioma de elección:**
> 
> ```
> Si Aᵢ ≠ ∅ para todo i ∈ I, entonces ∏ᵢ∈I Aᵢ ≠ ∅
> 
> "Siempre se puede elegir un elemento de cada conjunto"
> (no demostrable sin este axioma cuando I es infinito)
> ```

### 🎭 Isomorfismos Naturales

> [!tip]- Equivalencias Estructurales
> 
> **Asociatividad natural:**
> 
> ```
> (A × B) × C ≅ A × (B × C) ≅ A × B × C
> 
> Mediante:
> φ: ((a, b), c) ↦ (a, (b, c)) ↦ (a, b, c)
> ```
> 
> **Conmutatividad:**
> 
> ```
> A × B ≅ B × A
> 
> Mediante: φ((a, b)) = (b, a)
> (biyección que intercambia coordenadas)
> ```
> 
> **Distributividad:**
> 
> ```
> A × (B ∪ C) ≅ (A × B) ∪ (A × C)
> A × (B ∩ C) ≅ (A × B) ∩ (A × C)
> ```
> 
> **Elemento neutro:**
> 
> ```
> A × {*} ≅ A  (donde {*} es singleton)
> 
> Mediante: φ((a, *)) = a
> ```

## 🎯 Ejercicios y Problemas

> [!example]- Problemas de Práctica
> 
> **Nivel básico:**
> 
> 1. **Cálculo directo:**
>     
>     ```
>     A = {1, 2, 3}, B = {a, b}
>     Encuentra: A × B, B × A, A × A, B × B
>     ```
>     
> 2. **Verificación:**
>     
>     ```
>     ¿Verdadero o falso?
>     a) (2, 3) = (3, 2)
>     b) |{1, 2} × {a, b, c}| = 6
>     c) ∅ × A = ∅
>     d) {1} × {2, 3} = {(1, 2), (1, 3)}
>     ```
>     
> 3. **Cardinalidad:**
>     
>     ```
>     Si |A| = 5 y |B| = 7, calcula:
>     a) |A × B|
>     b) |B × A|
>     c) |A²|
>     d) |A × B × A|
>     ```
>     
> 
> **Nivel intermedio:**
> 
> 4. **Demostración:**
>     
>     ```
>     Prueba que A × (B ∪ C) = (A × B) ∪ (A × C)
>     ```
>     
> 5. **Relaciones:**
>     
>     ```
>     A = {1, 2, 3}, B = {2, 3, 4}
>     Define R = {(a, b) ∈ A × B : a < b}
>     Enumera todos los pares en R
>     ¿Es R una función?
>     ```
>     
> 6. **Funciones:**
>     
>     ```
>     Sea f: {1, 2, 3} → {a, b} con f = {(1, a), (2, b), (3, a)}
>     a) Verifica que f es función
>     b) ¿Es inyectiva? ¿Sobreyectiva?
>     c) Dibuja Graf(f) como puntos en el plano
>     ```
>     
> 7. **Productos n-arios:**
>     
>     ```
>     ¿Cuántas contraseñas de 8 caracteres alfanuméricos existen?
>     (26 letras + 10 dígitos, sin distinguir mayúsculas)
>     ```
>     
> 
> **Nivel avanzado:**
> 
> 8. **Demostración de igualdad:**
>     
>     ```
>     Prueba: Si A × B = A × C y A ≠ ∅, entonces B = C
>     ```
>     
> 9. **Cardinalidad infinita:**
>     
>     ```
>     Demuestra que |ℕ × ℕ| = |ℕ|
>     (Sugerencia: usa la función de emparejamiento de Cantor)
>     ```
>

>     
>     ```
>     Para S ⊆ A × B, define:

>     Prueba que π₁(S₁ ∩ S₂) ⊆ π₁(S₁) ∩ π₁(S₂)
>     y da un contraejemplo para la igualdad

>     
> 
> **Problemas aplicados:**
> 
> 11. **Combinatoria:**
>

>     Un restaurante ofrece:
>     - 4 entradas
>     - 6 platos principales  
>     - 3 postres
