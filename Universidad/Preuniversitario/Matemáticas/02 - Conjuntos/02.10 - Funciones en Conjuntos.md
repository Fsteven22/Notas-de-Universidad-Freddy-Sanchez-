# 🎯Funciones en Conjuntos

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Una función es una regla que asigna a cada elemento de un conjunto (dominio) exactamente un elemento de otro conjunto (codominio). Es una relación especial donde cada entrada tiene una única salida.**
> 
> **Elementos clave:**
> 
> - **Unicidad:** Cada entrada tiene exactamente una salida
> - **Totalidad:** Toda entrada del dominio debe tener salida
> - **Dirección:** Va de un conjunto a otro de manera específica
> - **Notación:** f: A → B significa "f va de A hacia B"

### 📖 Contexto Histórico

> [!note]- Desarrollo Histórico del Concepto de Función
> 
> **Orígenes Implícitos (Antigüedad - 1600):**
> 
> - **Babilonios (1800 a.C.):** Tablas de valores (cuadrados, cubos)
> - **Grecia antigua:** Correspondencias geométricas
> - **Ptolomeo (150 d.C.):** Tablas trigonométricas
> - **Función sin formalización:** Uso práctico, no concepto abstracto
> 
> **Nacimiento del Concepto (1600-1750):**
> 
> - **Descartes (1637):** Geometría analítica
>     - Curvas como relaciones entre coordenadas
> - **Leibniz (1673):** Primer uso del término "función"
>     - Funciones como expresiones geométricas
> - **Johann Bernoulli (1718):** "Función es expresión analítica"
> - **Euler (1748):** Notación f(x)
>     - Sistematización del concepto
> 
> **Era Analítica (1750-1850):**
> 
> - **Euler (1748):** _Introductio in analysin infinitorum_
>     - Funciones como fórmulas analíticas
> - **Lagrange (1797):** Funciones como series de potencias
> - **Fourier (1822):** Funciones "arbitrarias"
>     - Series de Fourier amplían el concepto
> - **Dirichlet (1837):** Definición moderna
>     - "Correspondencia arbitraria entre números"
>     - Ya no requiere fórmula explícita
> 
> **Formalización Conjuntista (1850-1900):**
> 
> - **Dedekind (1888):** Funciones entre conjuntos abstractos
> - **Cantor (1874-1895):** Funciones en teoría de conjuntos
>     - Diferentes tamaños de infinito
> - **Frege (1893):** Funciones en lógica matemática
> - **Peano (1889):** Axiomas usando funciones (sucesor)
> 
> **Teoría Moderna (1900-presente):**
> 
> - **Zermelo-Fraenkel (1908-1922):** Funciones como conjuntos de pares
> - **Kuratowski (1921):** Definición formal de par ordenado
> - **Bourbaki (1939+):** Estructura moderna de funciones
>     - Inyectiva, sobreyectiva, biyectiva
> - **Eilenberg-Mac Lane (1945):** Teoría de categorías
>     - Funciones (morfismos) como objetos centrales
> 
> **Revolución Computacional (1930-presente):**
> 
> - **Church (1936):** Lambda cálculo
> - **Turing (1936):** Funciones computables
> - **Programación funcional:** Haskell, Lisp, ML
> - **Ciencias de la computación:** Funciones como algoritmos

## 📐 Definición Formal de Función

> [!success]- Concepto Fundamental
> 
> **Definición (conjuntista):**
> 
> Una **función** f de A en B, denotada f: A → B, es una relación de A en B tal que:
> 
> ```
> 1. Dom(f) = A  (totalidad)
> 2. ∀a ∈ A, ∀b₁, b₂ ∈ B: [(a,b₁) ∈ f ∧ (a,b₂) ∈ f] → b₁ = b₂  (unicidad)
> ```
> 
> **Interpretación:**
> 
> - Cada elemento de A tiene imagen
> - Cada elemento de A tiene exactamente una imagen
> 
> **Notación:**
> 
> ```
> f: A → B
> f(a) = b    [b es la imagen de a bajo f]
> a ↦ b       [a se mapea a b]
> ```
> 
> **Terminología:**
> 
> ```
> • A: Dominio (conjunto de partida)
> • B: Codominio (conjunto de llegada)
> • f(a): Imagen de a (valor de la función en a)
> • a: Preimagen de f(a)
> • Im(f) = {f(a) : a ∈ A} ⊆ B: Imagen o rango de f
> • f⁻¹(b) = {a ∈ A : f(a) = b}: Preimagen de b (conjunto)
> ```
> 
> **Igualdad de funciones:**
> 
> ```
> f = g ⟺ [Dom(f) = Dom(g) ∧ Codom(f) = Codom(g) ∧ ∀a ∈ Dom(f): f(a) = g(a)]
> ```

> [!example]- Ejemplos Fundamentales
> 
> **Ejemplo 1: Función simple**
> 
> ```
> f: {1, 2, 3} → {a, b, c, d}
> f = {(1,a), (2,c), (3,a)}
> 
> f(1) = a
> f(2) = c
> f(3) = a
> 
> Dom(f) = {1, 2, 3}
> Codom(f) = {a, b, c, d}
> Im(f) = {a, c} ⊊ Codom(f)
> ```
> 
> **Ejemplo 2: NO es función (falla unicidad)**
> 
> ```
> R = {(1,a), (1,b), (2,c)} ⊆ {1,2,3} × {a,b,c}
> 
> 1 tiene dos imágenes (a y b) ✗
> 3 no tiene imagen ✗
> ```
> 
> **Ejemplo 3: Función identidad**
> 
> ```
> id_A: A → A
> id_A(a) = a para todo a ∈ A
> 
> Para A = {1,2,3}:
> id_A = {(1,1), (2,2), (3,3)}
> ```
> 
> **Ejemplo 4: Función constante**
> 
> ```
> f: ℕ → {5}
> f(n) = 5 para todo n ∈ ℕ
> 
> Toda entrada se mapea al mismo valor
> ```
> 
> **Ejemplo 5: Función característica**
> 
> ```
> χ_S: A → {0, 1}  donde S ⊆ A
> 
> χ_S(x) = {1 si x ∈ S
>          {0 si x ∉ S
> 
> Representa subconjuntos mediante funciones
> ```
> 
> **Ejemplo 6: Funciones numéricas familiares**
> 
> ```
> f: ℝ → ℝ
> f(x) = x²
> 
> g: ℝ → ℝ
> g(x) = 2x + 1
> 
> h: ℝ₊ → ℝ
> h(x) = √x
> ```

## 🎭 Tipos de Funciones

### 📊 Clasificación por Inyectividad y Sobreyectividad

> [!success]- Funciones Inyectivas (Uno a Uno)
> 
> **Definición:**
> 
> f: A → B es **inyectiva** (o uno a uno) si:
> 
> ```
> ∀a₁, a₂ ∈ A: f(a₁) = f(a₂) → a₁ = a₂
> ```
> 
> **Equivalente (contrapositiva):**
> 
> ```
> ∀a₁, a₂ ∈ A: a₁ ≠ a₂ → f(a₁) ≠ f(a₂)
> ```
> 
> **Interpretación:**
> 
> - Elementos distintos tienen imágenes distintas
> - No hay "colisiones"
> - Cada elemento del codominio tiene a lo más una preimagen
> 
> **Notación:** f: A ↪ B
> 
> **Prueba de inyectividad:**
> 
> 1. Suponer f(a₁) = f(a₂)
> 2. Demostrar que a₁ = a₂
> 
> **Condición necesaria:**
> 
> ```
> Si f: A → B es inyectiva, entonces |A| ≤ |B|
> ```

> [!example]- Ejemplos de Funciones Inyectivas
> 
> **Ejemplo 1: Inyectiva**
> 
> ```
> f: {1, 2, 3} → {a, b, c, d, e}
> f(1) = a, f(2) = c, f(3) = e
> 
> ✓ Inyectiva: todos los valores de salida son diferentes
> ```
> 
> **Ejemplo 2: NO inyectiva**
> 
> ```
> f: {1, 2, 3} → {a, b}
> f(1) = a, f(2) = b, f(3) = a
> 
> ✗ f(1) = f(3) pero 1 ≠ 3
> ```
> 
> **Ejemplo 3: f(x) = 2x en ℝ → ℝ**
> 
> ```
> Prueba de inyectividad:
> f(x₁) = f(x₂)
> 2x₁ = 2x₂
> x₁ = x₂  ✓
> 
> Por tanto, f es inyectiva
> ```
> 
> **Ejemplo 4: f(x) = x² en ℝ → ℝ**
> 
> ```
> ✗ NO inyectiva:
> f(-2) = 4 = f(2) pero -2 ≠ 2
> ```
> 
> **Ejemplo 5: f(x) = x² en ℝ₊ → ℝ**
> 
> ```
> ✓ Inyectiva cuando restringimos el dominio a no negativos
> ```
> 
> **Ejemplo 6: Funciones piso y techo**
> 
> ```
> floor: ℝ → ℤ
> floor(x) = ⌊x⌋ (mayor entero ≤ x)
> 
> ✗ NO inyectiva: floor(2.3) = floor(2.7) = 2
> ```

> [!success]- Funciones Sobreyectivas (Sobre, Epiyectivas)
> 
> **Definición:**
> 
> f: A → B es **sobreyectiva** (o sobre) si:
> 
> ```
> ∀b ∈ B, ∃a ∈ A: f(a) = b
> ```
> 
> **Equivalente:**
> 
> ```
> Im(f) = B  (la imagen es todo el codominio)
> ```
> 
> **Interpretación:**
> 
> - Todo elemento del codominio es imagen de algo
> - El codominio está "cubierto" completamente
> - Cada elemento del codominio tiene al menos una preimagen
> 
> **Notación:** f: A ↠ B
> 
> **Prueba de sobreyectividad:**
> 
> 1. Tomar b ∈ B arbitrario
> 2. Encontrar (construir) a ∈ A tal que f(a) = b
> 
> **Condición necesaria:**
> 
> ```
> Si f: A → B es sobreyectiva, entonces |A| ≥ |B|
> ```

> [!example]- Ejemplos de Funciones Sobreyectivas
> 
> **Ejemplo 1: Sobreyectiva**
> 
> ```
> f: {1, 2, 3, 4} → {a, b, c}
> f(1) = a, f(2) = b, f(3) = c, f(4) = a
> 
> ✓ Sobreyectiva: cada elemento de {a,b,c} es imagen de algo
> ```
> 
> **Ejemplo 2: NO sobreyectiva**
> 
> ```
> f: {1, 2} → {a, b, c}
> f(1) = a, f(2) = b
> 
> ✗ c no es imagen de nada
> Im(f) = {a, b} ≠ {a, b, c}
> ```
> 
> **Ejemplo 3: f(x) = x² en ℝ → ℝ**
> 
> ```
> ✗ NO sobreyectiva:
> No existe x ∈ ℝ tal que x² = -1
> Im(f) = [0, ∞) ≠ ℝ
> ```
> 
> **Ejemplo 4: f(x) = x² en ℝ → [0,∞)**
> 
> ```
> ✓ Sobreyectiva cuando ajustamos el codominio
> Para cualquier y ≥ 0, podemos tomar x = √y
> ```
> 
> **Ejemplo 5: Proyección**
> 
> ```
> π₁: ℝ × ℝ → ℝ
> π₁(x, y) = x
> 
> ✓ Sobreyectiva: para cualquier a ∈ ℝ, π₁(a, 0) = a
> ```
> 
> **Ejemplo 6: Función módulo**
> 
> ```
> f: ℤ → {0, 1, 2}
> f(n) = n mod 3
> 
> ✓ Sobreyectiva: 
> f(0) = 0, f(1) = 1, f(2) = 2
> ```

> [!success]- Funciones Biyectivas (Correspondencias Uno a Uno)
> 
> **Definición:**
> 
> f: A → B es **biyectiva** si es:
> 
> ```
> Inyectiva ∧ Sobreyectiva
> ```
> 
> **Equivalente:**
> 
> ```
> ∀b ∈ B, ∃!a ∈ A: f(a) = b
> 
> ("existe único": exactamente una preimagen)
> ```
> 
> **Interpretación:**
> 
> - Emparejamiento perfecto uno a uno
> - Cada elemento de B corresponde a exactamente un elemento de A
> - Establece correspondencia biunívoca
> 
> **Notación:** f: A ≅ B o f: A ↔ B
> 
> **Propiedades:**
> 
> ```
> • f biyectiva → f tiene función inversa f⁻¹: B → A
> • f biyectiva → |A| = |B| (misma cardinalidad)
> • Composición de biyecciones es biyección
> • Inversa de biyección es biyección
> ```
> 
> **Condición necesaria y suficiente:**
> 
> ```
> f: A → B es biyectiva ⟺ existe g: B → A tal que
>   g ∘ f = id_A  y  f ∘ g = id_B
> ```

> [!example]- Ejemplos de Funciones Biyectivas
> 
> **Ejemplo 1: Biyección simple**
> 
> ```
> f: {1, 2, 3} → {a, b, c}
> f(1) = b, f(2) = a, f(3) = c
> 
> ✓ Inyectiva (todos diferentes)
> ✓ Sobreyectiva (cubre todo {a,b,c})
> ✓ Biyectiva
> 
> Inversa: f⁻¹(a) = 2, f⁻¹(b) = 1, f⁻¹(c) = 3
> ```
> 
> **Ejemplo 2: f(x) = 2x + 1 en ℝ → ℝ**
> 
> ```
> Inyectiva:
>   f(x₁) = f(x₂) → 2x₁ + 1 = 2x₂ + 1 → x₁ = x₂ ✓
> 
> Sobreyectiva:
>   Para y ∈ ℝ, tomar x = (y-1)/2
>   f(x) = 2·(y-1)/2 + 1 = y ✓
> 
> Biyectiva ✓
> Inversa: f⁻¹(y) = (y-1)/2
> ```
> 
> **Ejemplo 3: Función identidad**
> 
> ```
> id_A: A → A
> id_A(a) = a
> 
> ✓ Siempre biyectiva
> id_A⁻¹ = id_A
> ```
> 
> **Ejemplo 4: f(x) = x³ en ℝ → ℝ**
> 
> ```
> ✓ Inyectiva (función estrictamente creciente)
> ✓ Sobreyectiva (alcanza todos los valores)
> ✓ Biyectiva
> 
> Inversa: f⁻¹(y) = ∛y
> ```
> 
> **Ejemplo 5: NO biyectiva**
> 
> ```
> f(x) = x² en ℝ → ℝ
> ✗ NO inyectiva: f(-2) = f(2)
> ✗ NO sobreyectiva: -1 no está en la imagen
> ```
> 
> **Ejemplo 6: Biyección entre ℕ y ℤ**
> 
> ```
> f: ℕ → ℤ
> f(n) = {n/2        si n es par
>        {-(n+1)/2   si n es impar
> 
> f(0) = 0, f(1) = -1, f(2) = 1, f(3) = -2, f(4) = 2, ...
> 
> ✓ Biyectiva: |ℕ| = |ℤ|
> ```

## 🔄 Composición de Funciones

> [!success]- Operación Fundamental
> 
> **Definición:**
> 
> Dadas f: A → B y g: B → C, la **composición** g ∘ f: A → C es:
> 
> ```
> (g ∘ f)(a) = g(f(a)) para todo a ∈ A
> ```
> 
> **Notación:**
> 
> ```
> g ∘ f    [se lee "g compuesta con f" o "g círculo f"]
> g(f(x))  [notación funcional]
> ```
> 
> **Diagrama:**
> 
> ```
>     f       g
> A ───→ B ───→ C
>   └──────────┘
>      g ∘ f
> ```
> 
> **Requisito importante:**
> 
> ```
> Codom(f) debe ser compatible con Dom(g)
> 
> Si f: A → B y g: C → D, entonces:
> g ∘ f está definida ⟺ B ⊆ C (o B = C típicamente)
> ```
> 
> **Orden de aplicación:**
> 
> ```
> ⚠️ CUIDADO: (g ∘ f)(x) significa "primero f, luego g"
> 
> Se lee de derecha a izquierda: g ∘ f = "g después de f"
> ```

> [!note]- Propiedades de la Composición
> 
> **1. Asociatividad:**
> 
> ```
> h ∘ (g ∘ f) = (h ∘ g) ∘ f
> 
> Si f: A → B, g: B → C, h: C → D, entonces:
> h ∘ (g ∘ f) = (h ∘ g) ∘ f: A → D
> 
> Podemos escribir simplemente: h ∘ g ∘ f
> ```
> 
> **2. NO conmutatividad:**
> 
> ```
> g ∘ f ≠ f ∘ g  (en general)
> 
> Incluso cuando ambas composiciones están definidas
> ```
> 
> **3. Identidad:**
> 
> ```
> Para cualquier f: A → B:
> f ∘ id_A = f
> id_B ∘ f = f
> 
> La identidad es el neutro para composición
> ```
> 
> **4. Preservación de inyectividad:**
> 
> ```
> Si f: A → B y g: B → C son inyectivas,
> entonces g ∘ f: A → C es inyectiva
> ```
> 
> **Demostración:**
> 
> ```
> (g ∘ f)(a₁) = (g ∘ f)(a₂)
> → g(f(a₁)) = g(f(a₂))
> → f(a₁) = f(a₂)    [g inyectiva]
> → a₁ = a₂          [f inyectiva]
> ```
> 
> **5. Preservación de sobreyectividad:**
> 
> ```
> Si f: A → B y g: B → C son sobreyectivas,
> entonces g ∘ f: A → C es sobreyectiva
> ```
> 
> **Demostración:**
> 
> ```
> Sea c ∈ C
> Como g es sobreyectiva, ∃b ∈ B: g(b) = c
> Como f es sobreyectiva, ∃a ∈ A: f(a) = b
> Entonces (g ∘ f)(a) = g(f(a)) = g(b) = c
> ```
> 
> **6. Composición de biyecciones:**
> 
> ```
> Si f y g son biyectivas, entonces g ∘ f es biyectiva
> 
> Y además: (g ∘ f)⁻¹ = f⁻¹ ∘ g⁻¹  (orden invertido)
> ```

> [!example]- Ejemplos de Composición
> 
> **Ejemplo 1: Composición numérica**
> 
> ```
> f: ℝ → ℝ, f(x) = x + 1
> g: ℝ → ℝ, g(x) = 2x
> 
> (g ∘ f)(x) = g(f(x)) = g(x + 1) = 2(x + 1) = 2x + 2
> (f ∘ g)(x) = f(g(x)) = f(2x) = 2x + 1
> 
> g ∘ f ≠ f ∘ g  (no conmutan)
> ```
> 
> **Ejemplo 2: Composición con conjuntos finitos**
> 
> ```
> f: {1,2,3} → {a,b,c}
> f(1) = a, f(2) = b, f(3) = c
> 
> g: {a,b,c} → {x,y}
> g(a) = x, g(b) = x, g(c) = y
> 
> (g ∘ f): {1,2,3} → {x,y}
> (g ∘ f)(1) = g(f(1)) = g(a) = x
> (g ∘ f)(2) = g(f(2)) = g(b) = x
> (g ∘ f)(3) = g(f(3)) = g(c) = y
> ```
> 
> **Ejemplo 3: Composición múltiple**
> 
> ```
> f(x) = x²
> g(x) = x + 1
> h(x) = 3x
> 
> (h ∘ g ∘ f)(x) = h(g(f(x)))
>                 = h(g(x²))
>                 = h(x² + 1)
>                 = 3(x² + 1)
>                 = 3x² + 3
> ```
> 
> **Ejemplo 4: Potencias de funciones**
> 
> ```
> f: A → A
> 
> f² = f ∘ f
> f³ = f ∘ f ∘ f
> fⁿ = f ∘ f ∘ ... ∘ f  (n veces)
> f⁰ = id_A
> ```
> 
> **Ejemplo 5: Composición no definida**
> 
> ```
> f: {1,2} → {a,b}
> g: {x,y,z} → {α,β}
> 
> g ∘ f no está definida porque Codom(f) = {a,b} ≠ Dom(g) = {x,y,z}
> ```

## 🔁 Función Inversa

> [!success]- Concepto de Inversibilidad
> 
> **Definición:**
> 
> Una función f: A → B es **invertible** si existe g: B → A tal que:
> 
> ```
> g ∘ f = id_A  y  f ∘ g = id_B
> ```
> 
> La función g se llama **inversa** de f y se denota f⁻¹
> 
> **Teorema Fundamental:**
> 
> ```
> f: A → B es invertible ⟺ f es biyectiva
> ```
> 
> **Unicidad de la inversa:**
> 
> ```
> Si f tiene inversa, esta es única
> ```
> 
> **Propiedades de la inversa:**
> 
> ```
> 1. (f⁻¹)⁻¹ = f
> 2. (g ∘ f)⁻¹ = f⁻¹ ∘ g⁻¹  (orden invertido)
> 3. (id_A)⁻¹ = id_A
> 4. f⁻¹(f(a)) = a para todo a ∈ A
> 5. f(f⁻¹(b)) = b para todo b ∈ B
> ```
> 
> **Gráficamente:**
> 
> ```
> La gráfica de f⁻¹ es la reflexión de la gráfica de f
> sobre la línea y = x
> ```

> [!example]- Ejemplos de Funciones Inversas
> 
> **Ejemplo 1: Inversa simple**
> 
> ```
> f: {1,2,3} → {a,b,c}
> f(1) = b, f(2) = c, f(3) = a
> 
> f⁻¹: {a,b,c} → {1,2,3}
> f⁻¹(a) = 3, f⁻¹(b) = 1, f⁻¹(c) = 2
> 
> Verificación:
> (f⁻¹ ∘ f)(1) = f⁻¹(f(1)) = f⁻¹(b) = 1 ✓
> (f ∘ f⁻¹)(a) = f(f⁻¹(a)) = f(3) = a ✓
> ```
> 
> **Ejemplo 2: f(x) = 2x + 3**
> 
> ```
> f: ℝ → ℝ
> 
> Encontrar inversa:
> y = 2x + 3
> y - 3 = 2x
> x = (y - 3)/2
> 
> f⁻¹(y) = (y - 3)/2
> 
> Verificación:
> f(f⁻¹(y)) = 2((y-3)/2) + 3 = y - 3 + 3 = y ✓
> f⁻¹(f(x)) = (2x + 3 - 3)/2 = 2x/2 = x ✓
> ```
> 
> **Ejemplo 3: f(x) = x³**
> 
> ```
> f: ℝ → ℝ
> ```
> f: ℝ → ℝ
> f(x) = x³
> 
> f es biyectiva:
> • Inyectiva: x₁³ = x₂³ → x₁ = x₂
> • Sobreyectiva: para y ∈ ℝ, x = ∛y cumple f(x) = y
> 
> Inversa: f⁻¹(y) = ∛y
> ```
> 
> **Ejemplo 4: f(x) = eˣ**
> ```
> f: ℝ → ℝ₊ (solo positivos)
> 
> ✓ Biyectiva con ese codominio
> Inversa: f⁻¹(y) = ln(y)
> 
> ln(eˣ) = x
> e^(ln(y)) = y
> ```
> 
> **Ejemplo 5: NO invertible**
> ```
> f: ℝ → ℝ
> f(x) = x²
> 
> ✗ NO inyectiva: f(-2) = f(2) = 4
> ✗ NO tiene inversa en ℝ → ℝ
> 
> Pero restringiendo:
> f: [0,∞) → [0,∞), f(x) = x²
> ✓ Biyectiva
> Inversa: f⁻¹(y) = √y
> ```
> 
> **Ejemplo 6: Función afín invertible**
> ```
> f(x) = ax + b con a ≠ 0
> 
> f⁻¹(y) = (y - b)/a
> 
> Verificación:
> f(f⁻¹(y)) = a((y-b)/a) + b = y - b + b = y ✓
> ```

> [!warning]- Cuidado con la Notación f⁻¹
> 
> **Dos significados distintos:**
> 
> ```
> 1. f⁻¹: B → A  [función inversa]
>    Solo existe si f es biyectiva
>    f⁻¹(b) es UN elemento de A
> 
> 2. f⁻¹(S) = {a ∈ A : f(a) ∈ S} ⊆ A  [preimagen de conjunto]
>    Siempre está definida para S ⊆ B
>    f⁻¹(S) es un CONJUNTO
> ```
> 
> **Ejemplo:**
> ```
> f: ℝ → ℝ, f(x) = x²
> 
> f⁻¹ como función: NO EXISTE (f no es inyectiva)
> 
> f⁻¹({4}) como preimagen: {-2, 2} (conjunto de preimágenes)
> f⁻¹([0,4]) = [-2, 2]
> 
> 
> **Contexto clarifica el significado:**
> - Si f es biyectiva y b es un elemento: f⁻¹(b) es la función inversa
> - Si S es un conjunto: f⁻¹(S) es siempre la preimagen
> 

## 🎨 Representaciones de Funciones

> [!tip]- Formas de Representar Funciones
> 
> **1. Diagrama de Flechas:**
> ```
> A = {1, 2, 3}        B = {a, b, c}
> 
> 1 ────────→ a
> 2 ────────→ b
> 3 ────────→ c
> 
> Cada elemento de A tiene exactamente una flecha
> ```
> 
> **2. Conjunto de pares ordenados:**
> ```
> f = {(1,a), (2,b), (3,c)}
> ```
> 
> **3. Tabla de valores:**
> ```
> | x  | 1 | 2 | 3 |
> |----|---|---|---|
> |f(x)| a | b | c |
> ```
> 
> **4. Fórmula explícita:**
> ```
> f(x) = x² + 2x - 1
> f(x) = sin(x) + cos(x)
> f(n) = 2ⁿ
> ```
> 
> **5. Definición por casos:**
> ```
> f(x) = {x²      si x ≥ 0
>        {-x      si x < 0
> 
> sign(x) = {1   si x > 0
>           {0   si x = 0
>           {-1  si x < 0
> ```
> 
> **6. Recursiva (para ℕ):**
> ```
> f(0) = 1
> f(n+1) = 2·f(n)
> 
> [Define f(n) = 2ⁿ]
> ```
> 
> **7. Gráfica (para funciones ℝ → ℝ):**
> ```
>   y
>   |     ╱
>   |   ╱
>   | ╱
>   |───────── x
> 
> Conjunto de puntos (x, f(x))
> ```
> 
> **8. Algoritmo/Proceso:**
> ```
> f(x) = "el dígito más frecuente en la representación decimal de x"
> ```

## 🔢 Funciones Especiales Importantes

> [!success]- Funciones Fundamentales
> 
> **1. Función Identidad:**
> ```
> id_A: A → A
> id_A(a) = a
> 
> Propiedades:
> • Siempre biyectiva
> • Neutro para composición
> • id_A⁻¹ = id_A
> ```
> 
> **2. Función Constante:**
> ```
> f: A → B
> f(a) = c para todo a ∈ A (c ∈ B fijo)
> 
> Propiedades:
> • Im(f) = {c}
> • Sobreyectiva ⟺ B = {c}
> • Nunca inyectiva si |A| > 1
> ```
> 
> **3. Funciones de Inclusión:**
> ```
> i: A → B donde A ⊆ B
> i(a) = a
> 
> • Siempre inyectiva
> • Sobreyectiva ⟺ A = B
> ```
> 
> **4. Funciones de Proyección:**
> ```
> π₁: A × B → A
> π₁(a, b) = a
> 
> π₂: A × B → B
> π₂(a, b) = b
> 
> • Siempre sobreyectivas (si A, B no vacíos)
> • Inyectivas ⟺ el otro conjunto es singleton
> ```
> 
> **5. Función Característica:**
> ```
> χ_S: A → {0, 1} para S ⊆ A
> 
> χ_S(x) = {1 si x ∈ S
>          {0 si x ∉ S
> 
> Propiedades:
> χ_{A} = 1 (función constante 1)
> χ_{∅} = 0 (función constante 0)
> χ_{S'} = 1 - χ_S
> χ_{S∩T} = χ_S · χ_T
> χ_{S∪T} = χ_S + χ_T - χ_S · χ_T
> ```
> 
> **6. Función Piso y Techo:**
> ```
> ⌊·⌋: ℝ → ℤ
> ⌊x⌋ = mayor entero ≤ x
> 
> ⌈·⌉: ℝ → ℤ
> ⌈x⌉ = menor entero ≥ x
> 
> Ejemplos:
> ⌊3.7⌋ = 3, ⌈3.7⌉ = 4
> ⌊-2.3⌋ = -3, ⌈-2.3⌉ = -2
> ⌊5⌋ = 5, ⌈5⌉ = 5
> ```
> 
> **7. Función Valor Absoluto:**
> ```
> |·|: ℝ → ℝ₀⁺
> |x| = {x   si x ≥ 0
>       {-x  si x < 0
> 
> • Sobreyectiva: ℝ → [0,∞)
> • NO inyectiva: |2| = |-2|
> ```
> 
> **8. Función Signo:**
> ```
> sgn: ℝ → {-1, 0, 1}
> 
> sgn(x) = {1   si x > 0
>          {0   si x = 0
>          {-1  si x < 0
> 
> Relación: x = sgn(x) · |x|
> ```

> [!example]- Funciones en Teoría de Números
> 
> **Función φ de Euler:**
> ```
> φ: ℕ⁺ → ℕ⁺
> φ(n) = cantidad de enteros en [1,n] coprimos con n
> 
> Ejemplos:
> φ(1) = 1
> φ(6) = 2  (1 y 5 son coprimos con 6)
> φ(p) = p-1  si p es primo
> ```
> 
> **Función divisores:**
> ```
> d: ℕ⁺ → ℕ⁺
> d(n) = cantidad de divisores positivos de n
> 
> d(12) = 6  (divisores: 1,2,3,4,6,12)
> d(p) = 2 si p es primo
> ```
> 
> **Función suma de divisores:**
> ```
> σ: ℕ⁺ → ℕ⁺
> σ(n) = suma de todos los divisores positivos de n
> 
> σ(12) = 1+2+3+4+6+12 = 28
> ```
> 
> **Función parte entera módulo:**
> ```
> mod: ℤ × ℕ⁺ → ℕ
> a mod n = residuo de dividir a entre n
> 
> 17 mod 5 = 2
> -3 mod 7 = 4
> ```

## 📊 Cardinalidad y Funciones

> [!success]- Relación entre Funciones y Tamaños de Conjuntos
> 
> **Definición de cardinalidad:**
> ```
> |A| ≤ |B| ⟺ existe f: A → B inyectiva
> |A| = |B| ⟺ existe f: A → B biyectiva
> |A| < |B| ⟺ |A| ≤ |B| ∧ |A| ≠ |B|
> ```
> 
> **Teorema de Cantor-Bernstein:**
> ```
> Si |A| ≤ |B| y |B| ≤ |A|, entonces |A| = |B|
> 
> Es decir: si existen inyecciones en ambas direcciones,
> existe una biyección
> ```
> 
> **Conjuntos finitos:**
> ```
> Si |A| = n y |B| = m:
> 
> • Número de funciones A → B: m^n
> • Número de inyecciones A → B: P(m,n) = m!/(m-n)! si n ≤ m, sino 0
> • Número de sobreyecciones A → B: S(n,m)·m! (números de Stirling)
> • Número de biyecciones A → B: n! si n = m, sino 0
> ```
> 
> **Propiedades con conjuntos finitos:**
> ```
> f: A → B donde |A| = n, |B| = m
> 
> Si n > m: f NO puede ser inyectiva (Principio del Palomar)
> Si n < m: f NO puede ser sobreyectiva
> Si n = m: f inyectiva ⟺ f sobreyectiva ⟺ f biyectiva
> ```

> [!example]- Ejemplos de Cardinalidad
> 
> **Ejemplo 1: |ℕ| = |ℤ|**
> ```
> f: ℕ → ℤ
> f(n) = {n/2        si n par
>        {-(n+1)/2   si n impar
> 
> f(0)=0, f(1)=-1, f(2)=1, f(3)=-2, f(4)=2, ...
> 
> ✓ Biyectiva → |ℕ| = |ℤ|
> ```
> 
> **Ejemplo 2: |ℕ| = |ℕ × ℕ|**
> ```
> Función de emparejamiento de Cantor:
> f: ℕ × ℕ → ℕ
> f(m,n) = (m+n)(m+n+1)/2 + n
> 
> ✓ Biyectiva
> ```
> 
> **Ejemplo 3: |ℕ| < |ℝ|**
> ```
> Teorema de Cantor (diagonal):
> NO existe biyección ℕ → ℝ
> 
> Los reales son "más numerosos" que los naturales
> ```
> 
> **Ejemplo 4: |𝒫(A)| > |A|**
> ```
> Teorema de Cantor:
> Para cualquier conjunto A:
> |A| < |𝒫(A)|
> 
> NO existe biyección A → 𝒫(A)
> ```
> 
> **Ejemplo 5: Principio del Palomar**
> ```
> Si |A| = 10 y |B| = 5:
> Toda función f: A → B tiene al menos una colisión
> 
> ∃b ∈ B con |f⁻¹({b})| ≥ 2
> ```

## 🎯 Secuencias como Funciones

> [!success]- Secuencias Infinitas
> 
> **Definición:**
> 
> Una **secuencia** en A es una función:
> ```
> a: ℕ → A
> ```
> 
> **Notación:**
> ```
> (aₙ)_{n∈ℕ} o (a₀, a₁, a₂, a₃, ...)
> 
> donde aₙ = a(n)
> ```
> 
> **Tipos de secuencias:**
> 
> **1. Secuencia constante:**
> ```
> aₙ = c para todo n
> (5, 5, 5, 5, ...)
> ```
> 
> **2. Secuencia aritmética:**
> ```
> aₙ = a₀ + nd
> (2, 5, 8, 11, 14, ...) con a₀=2, d=3
> ```
> 
> **3. Secuencia geométrica:**
> ```
> aₙ = a₀ · rⁿ
> (1, 2, 4, 8, 16, ...) con a₀=1, r=2
> ```
> 
> **4. Secuencia recursiva:**
> ```
> Fibonacci: F₀=0, F₁=1, Fₙ₊₂=Fₙ₊₁+Fₙ
> (0, 1, 1, 2, 3, 5, 8, 13, ...)
> ```
> 
> **5. Secuencia definida por fórmula:**
> ```
> aₙ = 1/n
> (1, 1/2, 1/3, 1/4, ...)
> 
> bₙ = (-1)ⁿ
> (1, -1, 1, -1, 1, -1, ...)
> ```

> [!example]- Propiedades de Secuencias
> 
> **Monotonía:**
> ```
> Creciente: aₙ ≤ aₙ₊₁ para todo n
> Decreciente: aₙ ≥ aₙ₊₁ para todo n
> Estrictamente creciente: aₙ < aₙ₊₁
> ```
> 
> **Acotación:**
> ```
> Acotada superiormente: ∃M: aₙ ≤ M para todo n
> Acotada inferiormente: ∃m: aₙ ≥ m para todo n
> Acotada: ambas
> ```
> 
> **Convergencia:**
> ```
> lim_{n→∞} aₙ = L ⟺ 
> ∀ε > 0, ∃N ∈ ℕ: n > N → |aₙ - L| < ε
> ```
> 
> **Ejemplos:**
> ```
> lim_{n→∞} 1/n = 0 (convergente)
> lim_{n→∞} (-1)ⁿ no existe (oscilante)
> lim_{n→∞} n = ∞ (divergente)
> ```

## 🔬 Operaciones con Funciones

> [!success]- Operaciones Puntuales
> 
> Dadas f, g: A → ℝ (funciones a valores reales):
> 
> **1. Suma:**
> ```
> (f + g)(x) = f(x) + g(x)
> ```
> 
> **2. Resta:**
> ```
> (f - g)(x) = f(x) - g(x)
> ```
> 
> **3. Producto:**
> ```
> (f · g)(x) = f(x) · g(x)
> ```
> 
> **4. División:**
> ```
> (f/g)(x) = f(x)/g(x)  si g(x) ≠ 0
> ```
> 
> **5. Multiplicación por escalar:**
> ```
> (c · f)(x) = c · f(x)  para c ∈ ℝ
> ```
> 
> **6. Potencia:**
> ```
> (f^n)(x) = [f(x)]^n
> ```
> 
> **Propiedades:**
> ```
> • f + g = g + f (conmutativa)
> • (f + g) + h = f + (g + h) (asociativa)
> • f · g = g · f
> • f + 0 = f (donde 0 es función constante 0)
> • f · 1 = f (donde 1 es función constante 1)
> ```

> [!example]- Ejemplos de Operaciones
> 
> **Ejemplo 1:**
> ```
> f(x) = x² + 1
> g(x) = 2x - 3
> 
> (f + g)(x) = x² + 1 + 2x - 3 = x² + 2x - 2
> (f · g)(x) = (x² + 1)(2x - 3) = 2x³ - 3x² + 2x - 3
> (f/g)(x) = (x² + 1)/(2x - 3)  si x ≠ 3/2
> ```
> 
> **Ejemplo 2: Función valor absoluto**
> ```
> |f|(x) = |f(x)|
> 
> Si f(x) = x - 2, entonces:
> |f|(x) = |x - 2| = {x - 2   si x ≥ 2
>                    {2 - x   si x < 2
> ```
> 
> **Ejemplo 3: Combinación lineal**
> ```
> h(x) = 3f(x) - 2g(x)
> 
> Si f(x) = x² y g(x) = x:
> h(x) = 3x² - 2x
> ```

## ⚠️ Errores Comunes y Confusiones

> [!warning]- Malentendidos Frecuentes
> 
> **1. "Toda relación es una función"**
> ```
> ✗ INCORRECTO
> ✓ CORRECTO: Funciones son relaciones especiales
> 
> R = {(1,2), (1,3)} NO es función
> (1 tiene dos imágenes)
> ```
> 
> **2. "f(x) y f son lo mismo"**
> ```
> ✗ INCORRECTO
> 
> f: función completa (regla + dominio + codominio)
> f(x): valor de la función en x (un elemento)
> 
> Correcto: "Sea f: ℝ → ℝ definida por f(x) = x²"
> Incorrecto: "Sea f(x) = x² una función"
> ```
> 
> **3. "Si f no es inyectiva, no tiene inversa"**
> ```
> ✗ PARCIALMENTE INCORRECTO
> ✓ CORRECTO: No tiene inversa como función
>   Pero f⁻¹(S) como preimagen de conjunto siempre existe
> ```
> 
> **4. "g ∘ f = f ∘ g"**
> ```
> ✗ INCORRECTO en general
> 
> Contraejemplo:
> f(x) = x + 1, g(x) = 2x
> (g ∘ f)(x) = 2(x+1) = 2x + 2
> (f ∘ g)(x) = 2x + 1
> ```
> 
> **5. "Sobreyectiva significa Im(f) ⊇ B"**
> ```
> ✗ INCORRECTO (dirección errónea)
> ✓ CORRECTO: Sobreyectiva significa Im(f) = B
> 
> La contención Im(f) ⊆ B siempre se cumple por definición
> ```
> 
> **6. "Si f: A → B con |A| = |B|, entonces f es biyectiva"**
> ```
> ✗ INCORRECTO para conjuntos infinitos
> 
> Contraejemplo:
> f: ℕ → ℕ, f(n) = 2n
> |ℕ| = |ℕ| pero f NO es sobreyectiva
> (1, 3, 5, ... no están en la imagen)
> ```
> 
> **7. "(f ∘ g)⁻¹ = f⁻¹ ∘ g⁻¹"**
> ```
> ✗ INCORRECTO (orden equivocado)
> ✓ CORRECTO: (f ∘ g)⁻¹ = g⁻¹ ∘ f⁻¹
> 
> El orden se invierte
> ```
> 
> **8. "Dom(f ∘ g) = Dom(g)"**
> ```
> ✗ NO SIEMPRE
> ✓ CORRECTO si Im(g) ⊆ Dom(f)
> 
> En general: Dom(f ∘ g) = {x ∈ Dom(g) : g(x) ∈ Dom(f)}
> ```
> 
> **9. "Función inyectiva tiene función inversa"**
> ```
> ✗ INCORRECTO (también necesita ser sobreyectiva)
> 
> f: ℕ → ℕ, f(n) = 2n es inyectiva
> Pero NO tiene inversa como función ℕ → ℕ
> (solo tiene inversa como función parcial)
> ```

## 🎓 Teoremas Importantes

> [!note]- Resultados Fundamentales
> 
> **Teorema 1: Caracterización de Biyección**
> ```
> f: A → B es biyectiva ⟺ 
> existe g: B → A tal que g ∘ f = id_A y f ∘ g = id_B
> ```
> 
> **Teorema 2: Unicidad de Inversa**
> ```
> Si f: A → B tiene inversa, esta es única
> ```
> 
> **Demostración:**
> ```
> Supongamos g₁, g₂ son inversas de f
> g₁ = g₁ ∘ id_B = g₁ ∘ (f ∘ g₂) = (g₁ ∘ f) ∘ g₂ = id_A ∘ g₂ = g₂
> ```
> 
> **Teorema 3: Composición preserva propiedades**
> ```
> • f, g inyectivas → g ∘ f inyectiva
> • f, g sobreyectivas → g ∘ f sobreyectiva
> • f, g biyectivas → g ∘ f biyectiva
> ```
> 
> **Teorema 4: Descomposición**
> ```
> Toda función f: A → B puede descomponerse:
> 
> A →^π A/∼ →^φ Im(f) →^i B
> 
> donde:
> • π sobreyectiva (proyección canónica)
> • φ biyectiva
> • i inyectiva (inclusión)
> 
> f = i ∘ φ ∘ π
> ```
> 
> **Teorema 5: Teorema de Cantor**
> ```
> Para cualquier conjunto A:
> NO existe función sobreyectiva f: A → 𝒫(A)
> 
> Corolario: |A| < |𝒫(A)|
> ```
> 
> **Teorema 6: Axioma de Elección (equivalente)**
> ```
> Si {Aᵢ}_{i∈I} es familia de conjuntos no vacíos,
> existe función f: I → ⋃Aᵢ tal que f(i) ∈ Aᵢ para todo i
> 
> ("Función de elección")
> ```
