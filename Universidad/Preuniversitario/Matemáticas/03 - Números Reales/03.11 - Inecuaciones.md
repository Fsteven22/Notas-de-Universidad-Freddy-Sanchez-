# 🎯 Inecuaciones

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Una inecuación es una desigualdad que contiene una o más incógnitas, y resolverla significa encontrar todos los valores que la hacen verdadera.**
> 
> **Elementos clave:**
> 
> - **Desigualdad:** Usa símbolos <, >, ≤, ≥ en lugar de =
> - **Conjunto solución:** Generalmente intervalos o uniones de intervalos
> - **Propiedades de orden:** Mantener o invertir según las operaciones
> - **Representación:** Algebraica, gráfica y en la recta numérica

### 📖 Contexto Histórico

> [!note]- Desarrollo Histórico de las Inecuaciones
> 
> **Orígenes Antiguos (300 a.C. - 1600):**
> 
> - **Euclides:** Comparaciones de magnitudes geométricas
> - **Arquímedes:** Método de exhausción (aproximaciones por desigualdades)
> - **Matemáticos medievales:** Desigualdades en comercio y astronomía
> - **Función implícita:** Restricciones sin notación formal
> 
> **Desarrollo de la Notación (1600-1800):**
> 
> - **Thomas Harriot (1631):** Introduce símbolos < y > (publicación póstuma)
> - **Desarrollo gradual:** Símbolos ≤ y ≥ aparecen más tarde
> - **Pierre Bouguer (1734):** Usa desigualdades en navegación
> - **Resistencia inicial:** Preferencia por igualdades exactas
> 
> **Formalización Matemática (1800-1900):**
> 
> - **Cauchy (1821):** Desigualdades en análisis riguroso
> - **Desigualdad de Cauchy-Schwarz (1821-1888):** Fundamental en álgebra lineal
> - **Chebyshev (1850s):** Desigualdades en teoría de probabilidad
> - **Weierstrass:** Aproximaciones mediante desigualdades
> 
> **Siglo XX - Teoría Moderna:**
> 
> - **Hardy, Littlewood, Pólya (1934):** _Inequalities_ - Tratado fundamental
> - **Programación lineal (1940s):** Optimización con restricciones
> - **Desigualdades en análisis:** Herramienta esencial en demostraciones
> - **Teoría de optimización:** Inecuaciones como restricciones
> 
> **Aplicaciones Contemporáneas:**
> 
> - **Ingeniería:** Restricciones de diseño y seguridad
> - **Economía:** Modelos de optimización con restricciones
> - **Ciencias de datos:** Machine learning y optimización
> - **Investigación operativa:** Problemas de asignación de recursos

## 📊 Tipos de Inecuaciones

### 🔢 Clasificación por Grado

> [!success]- Taxonomía de Inecuaciones
> 
> **Inecuaciones lineales (grado 1):**
> 
> ```
> ax + b < 0
> ax + b ≤ 0
> ax + b > 0
> ax + b ≥ 0
> ```
> 
> donde a, b ∈ ℝ, a ≠ 0
> 
> **Inecuaciones cuadráticas (grado 2):**
> 
> ```
> ax² + bx + c < 0
> ax² + bx + c ≤ 0
> ax² + bx + c > 0
> ax² + bx + c ≥ 0
> ```
> 
> donde a, b, c ∈ ℝ, a ≠ 0
> 
> **Inecuaciones polinómicas (grado n ≥ 3):**
> 
> ```
> aₙxⁿ + aₙ₋₁xⁿ⁻¹ + ... + a₁x + a₀ < 0
> ```
> 
> **Inecuaciones racionales:**
> 
> ```
> P(x)/Q(x) < 0  donde P(x), Q(x) son polinomios
> ```
> 
> **Inecuaciones con valor absoluto:**
> 
> ```
> |f(x)| < a
> |f(x)| > a
> ```
> 
> **Inecuaciones irracionales:**
> 
> ```
> √f(x) < g(x)
> ⁿ√f(x) > g(x)
> ```
> 
> **Inecuaciones exponenciales:**
> 
> ```
> aᶠ⁽ˣ⁾ < aᵍ⁽ˣ⁾
> ```
> 
> **Inecuaciones logarítmicas:**
> 
> ```
> logₐ(f(x)) < logₐ(g(x))
> ```

## 🔑 Propiedades Fundamentales

### ⚖️ Propiedades de las Desigualdades

> [!important]- Reglas para Manipular Inecuaciones
> 
> **1. Propiedad transitiva:**
> 
> ```
> Si a < b y b < c, entonces a < c
> ```
> 
> **2. Suma/resta de un número:**
> 
> ```
> Si a < b, entonces:
> a + c < b + c  (para cualquier c ∈ ℝ)
> a - c < b - c  (para cualquier c ∈ ℝ)
> ```
> 
> **La desigualdad NO cambia de sentido**
> 
> **3. Multiplicación/división por número positivo:**
> 
> ```
> Si a < b y c > 0, entonces:
> ac < bc
> a/c < b/c
> ```
> 
> **La desigualdad NO cambia de sentido**
> 
> **4. Multiplicación/división por número negativo:**
> 
> ```
> Si a < b y c < 0, entonces:
> ac > bc  ← INVIERTE
> a/c > b/c  ← INVIERTE
> ```
> 
> **⚠️ CRÍTICO: La desigualdad CAMBIA de sentido**
> 
> **5. Reciprocidad (números del mismo signo):**
> 
> ```
> Si 0 < a < b, entonces 1/a > 1/b
> Si a < b < 0, entonces 1/a > 1/b
> ```
> 
> **La desigualdad SE INVIERTE**
> 
> **6. Potencias impares:**
> 
> ```
> Si a < b, entonces aⁿ < bⁿ  (n impar)
> ```
> 
> **Preserva el orden**
> 
> **7. Potencias pares (números positivos):**
> 
> ```
> Si 0 ≤ a < b, entonces a² < b²
> ```
> 
> **⚠️ CUIDADO: No funciona con negativos**
> 
> **8. Raíces (números positivos):**
> 
> ```
> Si 0 ≤ a < b, entonces √a < √b
> ```

> [!warning]- Errores Críticos a Evitar
> 
> **❌ NO HACER:**
> 
> 1. **Multiplicar por variable sin conocer su signo:**
> 
> ```
> ❌ x < 5  →  x² < 5x  (ERROR: depende del signo de x)
> ```
> 
> 2. **Elevar al cuadrado sin restricciones:**
> 
> ```
> ❌ x < 3  →  x² < 9  (FALSO: si x = -5, entonces 25 > 9)
> ```
> 
> 3. **Simplificar sin considerar ceros del denominador:**
> 
> ```
> ❌ x(x-1)/(x-1) < 2  →  x < 2  (FALTA: x ≠ 1)
> ```
> 
> 4. **Aplicar funciones no monótonas:**
> 
> ```
> ❌ sin(a) < sin(b)  →  a < b  (FALSO en general)
> ```

## 📐 Inecuaciones Lineales

> [!success]- Forma General y Resolución
> 
> **Forma estándar:**
> 
> ```
> ax + b < 0  (o ≤, >, ≥)
> ```
> 
> donde a ≠ 0
> 
> **Método de resolución:**
> 
> 1. **Aislar el término con x:**
> 
> ```
> ax < -b
> ```
> 
> 2. **Dividir por el coeficiente de x:**
>     
> 
> - **Si a > 0:** Mantener el sentido
> 
> ```
> x < -b/a
> ```
> 
> - **Si a < 0:** Invertir el sentido
> 
> ```
> x > -b/a
> ```
> 
> **Representación del conjunto solución:**
> 
> ```
> • Como intervalo
> • En la recta numérica
> • En notación de conjuntos
> ```

> [!example]- Ejemplos Resueltos de Inecuaciones Lineales
> 
> **Ejemplo 1: Coeficiente positivo**
> 
> ```
> Resolver: 3x - 7 < 5
> 
> Solución:
> 3x - 7 < 5
> 3x < 5 + 7
> 3x < 12
> x < 4  (dividimos por 3 > 0, no cambia sentido)
> 
> Conjunto solución: (-∞, 4)
> 
> Recta numérica:
> ←———————○━━━━→
>         4
> ```
> 
> **Ejemplo 2: Coeficiente negativo**
> 
> ```
> Resolver: -2x + 5 ≥ 11
> 
> Solución:
> -2x + 5 ≥ 11
> -2x ≥ 11 - 5
> -2x ≥ 6
> x ≤ -3  (dividimos por -2 < 0, ¡INVIERTE!)
> 
> Conjunto solución: (-∞, -3]
> 
> Recta numérica:
> ←━━━━●———————→
>      -3
> ```
> 
> **Ejemplo 3: Con fracciones**
> 
> ```
> Resolver: (2x - 1)/3 > (x + 2)/2
> 
> Solución:
> Multiplicamos por 6 (MCM de 3 y 2):
> 6 · (2x - 1)/3 > 6 · (x + 2)/2
> 2(2x - 1) > 3(x + 2)
> 4x - 2 > 3x + 6
> 4x - 3x > 6 + 2
> x > 8
> 
> Conjunto solución: (8, +∞)
> ```
> 
> **Ejemplo 4: Con paréntesis**
> 
> ```
> Resolver: 2(x - 3) - 5 ≤ 3(x + 1)
> 
> Solución:
> 2x - 6 - 5 ≤ 3x + 3
> 2x - 11 ≤ 3x + 3
> 2x - 3x ≤ 3 + 11
> -x ≤ 14
> x ≥ -14  (multiplicamos por -1, invierte)
> 
> Conjunto solución: [-14, +∞)
> ```

## 🔷 Inecuaciones Cuadráticas

> [!success]- Método Analítico y Gráfico
> 
> **Forma general:**
> 
> ```
> ax² + bx + c < 0  (o ≤, >, ≥)
> ```
> 
> donde a ≠ 0
> 
> **Método de resolución (análisis de signos):**
> 
> **Paso 1:** Encontrar las raíces de ax² + bx + c = 0
> 
> ```
> x = (-b ± √(b² - 4ac))/(2a)
> ```
> 
> **Paso 2:** Analizar el discriminante Δ = b² - 4ac
> 
> - **Δ > 0:** Dos raíces reales distintas x₁, x₂
> - **Δ = 0:** Una raíz doble x₀
> - **Δ < 0:** Sin raíces reales
> 
> **Paso 3:** Construir tabla de signos
> 
> **Paso 4:** Seleccionar intervalos según la desigualdad
> 
> **Criterio del signo de la parábola:**
> 
> - **Si a > 0:** Parábola abre hacia arriba (∪)
>     - ax² + bx + c > 0 fuera de las raíces
>     - ax² + bx + c < 0 entre las raíces
> - **Si a < 0:** Parábola abre hacia abajo (∩)
>     - ax² + bx + c > 0 entre las raíces
>     - ax² + bx + c < 0 fuera de las raíces

> [!example]- Ejemplos Resueltos de Inecuaciones Cuadráticas
> 
> **Ejemplo 1: Dos raíces reales, a > 0**
> 
> ```
> Resolver: x² - 5x + 6 < 0
> 
> Solución:
> Paso 1: Factorizar o encontrar raíces
> x² - 5x + 6 = 0
> (x - 2)(x - 3) = 0
> x₁ = 2, x₂ = 3
> 
> Paso 2: Tabla de signos (a = 1 > 0, parábola ∪)
> 
>      x     | -∞    2    3    +∞
>   ---------|-------------------
>   x² - 5x + 6 | +  0  -  0  +
> 
> Paso 3: Queremos < 0, tomamos donde es negativo
> 
> Solución: (2, 3)
> 
> Recta numérica:
> ←———○━━━○———→
>      2   3
> 
> Gráfica:
>       |
>     6 |___
>       |   \    /
>     0 |____\__/____
>       |    2  3
>       |
> ```
> 
> **Ejemplo 2: Dos raíces reales, a < 0**
> 
> ```
> Resolver: -x² + 4x - 3 ≥ 0
> 
> Solución:
> Multiplicar por -1 (invierte):
> x² - 4x + 3 ≤ 0
> 
> Raíces: x² - 4x + 3 = 0
> (x - 1)(x - 3) = 0
> x₁ = 1, x₂ = 3
> 
> Tabla de signos para x² - 4x + 3:
>      x     | -∞    1    3    +∞
>   ---------|-------------------
>   x² - 4x + 3 | +  0  -  0  +
> 
> Queremos ≤ 0:
> 
> Solución: [1, 3]
> 
> Recta numérica:
> ←———●━━━●———→
>      1   3
> ```
> 
> **Ejemplo 3: Sin raíces reales**
> 
> ```
> Resolver: x² + 2x + 5 > 0
> 
> Solución:
> Discriminante: Δ = 4 - 20 = -16 < 0
> No hay raíces reales
> 
> Como a = 1 > 0, la parábola abre hacia arriba
> y no toca el eje x, siempre es positiva
> 
> Solución: ℝ (todos los reales)
> o equivalentemente: (-∞, +∞)
> 
> Recta numérica:
> ←━━━━━━━━━━━→
> ```
> 
> **Ejemplo 4: Raíz doble**
> 
> ```
> Resolver: x² - 6x + 9 ≤ 0
> 
> Solución:
> x² - 6x + 9 = (x - 3)²
> 
> Como (x - 3)² ≥ 0 para todo x,
> (x - 3)² = 0 solo cuando x = 3
> 
> Solución: {3}
> 
> Recta numérica:
> ←———————●———————→
>          3
> ```
> 
> **Ejemplo 5: Forma factorizada**
> 
> ```
> Resolver: (x + 2)(x - 5) > 0
> 
> Solución:
> Raíces: x = -2 y x = 5
> 
> Tabla de signos:
>      x     | -∞   -2    5    +∞
>   ---------|-------------------
>    x + 2   | -   0  +   +   +
>    x - 5   | -   -  -   0   +
>   ---------|-------------------
>   Producto | +   0  -   0   +
> 
> Queremos > 0:
> 
> Solución: (-∞, -2) ∪ (5, +∞)
> 
> Recta numérica:
> ←━━━○———○━━━→
>     -2   5
> ```

## 🔢 Inecuaciones con Valor Absoluto

> [!success]- Propiedades y Métodos de Resolución
> 
> **Recordatorio:** |x| = √(x²) = max{x, -x}
> 
> **Propiedad fundamental:**
> 
> ```
> |x| < a  ⟺  -a < x < a  (si a > 0)
> |x| > a  ⟺  x < -a  o  x > a  (si a > 0)
> ```
> 
> **Formas equivalentes:**
> 
> **Tipo 1: |f(x)| < a**
> 
> ```
> |f(x)| < a  ⟺  -a < f(x) < a
> 
> Solución: intersección de dos inecuaciones
> ```
> 
> **Tipo 2: |f(x)| > a**
> 
> ```
> |f(x)| > a  ⟺  f(x) < -a  o  f(x) > a
> 
> Solución: unión de dos inecuaciones
> ```
> 
> **Tipo 3: |f(x)| < |g(x)|**
> 
> ```
> Método 1: Elevar al cuadrado
> |f(x)| < |g(x)|  ⟺  [f(x)]² < [g(x)]²
> 
> Método 2: Análisis por casos
> Considerar signos de f(x) y g(x)
> ```
> 
> **Tipo 4: |f(x)| + |g(x)| < a**
> 
> ```
> Resolver por casos según signos de f(x) y g(x)
> ```

> [!example]- Ejemplos Resueltos con Valor Absoluto
> 
> **Ejemplo 1: Desigualdad simple tipo <**
> 
> ```
> Resolver: |x - 3| < 5
> 
> Solución:
> |x - 3| < 5  ⟺  -5 < x - 3 < 5
> 
> Sumamos 3 a toda la inecuación:
> -5 + 3 < x < 5 + 3
> -2 < x < 8
> 
> Solución: (-2, 8)
> 
> Recta numérica:
> ←———○━━━━━━━○———→
>     -2      8
> ```
> 
> **Ejemplo 2: Desigualdad simple tipo >**
> 
> ```
> Resolver: |2x + 1| ≥ 7
> 
> Solución:
> |2x + 1| ≥ 7  ⟺  2x + 1 ≤ -7  o  2x + 1 ≥ 7
> 
> Caso 1: 2x + 1 ≤ -7
> 2x ≤ -8
> x ≤ -4
> 
> Caso 2: 2x + 1 ≥ 7
> 2x ≥ 6
> x ≥ 3
> 
> Solución: (-∞, -4] ∪ [3, +∞)
> 
> Recta numérica:
> ←━━━●———○———●━━━→
>     -4      3
> ```
> 
> **Ejemplo 3: Doble valor absoluto**
> 
> ```
> Resolver: |x - 2| < |x + 1|
> 
> Solución (Método 1: elevar al cuadrado):
> |x - 2|² < |x + 1|²
> (x - 2)² < (x + 1)²
> x² - 4x + 4 < x² + 2x + 1
> -4x + 4 < 2x + 1
> -6x < -3
> x > 1/2
> 
> Solución: (1/2, +∞)
> 
> Verificación gráfica:
> |x - 2| es distancia de x a 2
> |x + 1| es distancia de x a -1
> 
> Queremos que x esté más cerca de 2 que de -1
> El punto medio es (-1 + 2)/2 = 1/2
> ```
> 
> **Ejemplo 4: Suma de valores absolutos**
> 
> ```
> Resolver: |x - 1| + |x + 2| ≤ 5
> 
> Solución (por casos):
> Puntos críticos: x = 1, x = -2
> 
> Caso 1: x < -2
> -(x - 1) + -(x + 2) ≤ 5
> -x + 1 - x - 2 ≤ 5
> -2x - 1 ≤ 5
> -2x ≤ 6
> x ≥ -3
> 
> En este caso: -3 ≤ x < -2
> 
> Caso 2: -2 ≤ x < 1
> -(x - 1) + (x + 2) ≤ 5
> -x + 1 + x + 2 ≤ 5
> 3 ≤ 5  ✓ (siempre cierto)
> 
> En este caso: -2 ≤ x < 1 (todo el intervalo)
> 
> Caso 3: x ≥ 1
> (x - 1) + (x + 2) ≤ 5
> 2x + 1 ≤ 5
> 2x ≤ 4
> x ≤ 2
> 
> En este caso: 1 ≤ x ≤ 2
> 
> Solución total: [-3, -2) ∪ [-2, 1) ∪ [1, 2] = [-3, 2]
> 
> Recta numérica:
> ←———●━━━━━━━●———→
>     -3      2
> ```
> 
> **Ejemplo 5: Comparación con expresión**
> 
> ```
> Resolver: |3x - 2| > x + 4
> 
> Solución (por casos):
> 
> Caso 1: 3x - 2 ≥ 0  ⟹  x ≥ 2/3
> Entonces |3x - 2| = 3x - 2
> 3x - 2 > x + 4
> 2x > 6
> x > 3
> 
> Intersección con x ≥ 2/3: x > 3
> 
> Caso 2: 3x - 2 < 0  ⟹  x < 2/3
> Entonces |3x - 2| = -(3x - 2) = -3x + 2
> -3x + 2 > x + 4
> -4x > 2
> x < -1/2
> 
> Intersección con x < 2/3: x < -1/2
> 
> Solución: (-∞, -1/2) ∪ (3, +∞)
> 
> Recta numérica:
> ←━━━○———○———○━━━→
>    -1/2 2/3  3
> ```

## ➗ Inecuaciones Racionales

> [!success]- Método de los Puntos Críticos
> 
> **Forma general:**
> 
> ```
> P(x)/Q(x) < 0  (o ≤, >, ≥)
> ```
> 
> donde P(x) y Q(x) son polinomios
> 
> **Método de resolución:**
> 
> **Paso 1:** Llevar todo a un lado
> 
> ```
> P(x)/Q(x) - a < 0  ⟹  [P(x) - aQ(x)]/Q(x) < 0
> ```
> 
> **Paso 2:** Identificar puntos críticos
> 
> - **Ceros del numerador:** P(x) = 0
> - **Ceros del denominador:** Q(x) = 0 (NO son solución)
> 
> **Paso 3:** Construir tabla de signos
> 
> - Evaluar signo en cada intervalo
> - Cuidado: los ceros del denominador dividen pero no pertenecen
> 
> **Paso 4:** Seleccionar intervalos
> 
> - Para < 0 o ≤ 0: intervalos negativos
> - Para > 0 o ≥ 0: intervalos positivos
> - **Cuidado con ≤ y ≥:** incluir ceros del numerador, excluir del denominador

> [!example]- Ejemplos Resueltos de Inecuaciones Racionales
> 
> **Ejemplo 1: Racional simple**
> 
> ```
> Resolver: (x - 2)/(x + 3) > 0
> 
> Solución:
> Puntos críticos:
> • Numerador: x - 2 = 0  ⟹  x = 2
> • Denominador: x + 3 = 0  ⟹  x = -3
> 
> Tabla de signos:
>      x      | -∞   -3    2    +∞
>   ----------|-------------------
>    x - 2    | -    -  0  +   +
>    x + 3    | -  0 +  +  +   +
>   ----------|-------------------
>   Cociente  | +  ∅  -  0  +
> 
> Queremos > 0:
> 
> Solución: (-∞, -3) ∪ (2, +∞)
> 
> Recta numérica:
> ←━━━○———○━━━→
>     -3   2
> 
> Nota: x = -3 nunca es solución (anula denominador)
>       x = 2 no es solución porque > (estricto)
> ```
> 
> **Ejemplo 2: Con desigualdad ≤**
> 
> ```
> Resolver: (2x + 1)/(x - 4) ≤ 0
> 
> Solución:
> Puntos críticos:
> • Numerador: 2x + 1 = 0  ⟹  x = -1/2
> • Denominador: x - 4 = 0  ⟹  x = 4
> 
> Tabla de signos:
>      x      | -∞   -1/2   4    +∞
>   ----------|--------------------
>   2x + 1    | -   0  +    +   +
>   x - 4     | -   -  -  0 +   +
>   ----------|--------------------
>   Cociente  | +   0  -  ∅  +
> 
> Queremos ≤ 0:
> 
> Solución: [-1/2, 4)
> 
> Nota: Incluimos x = -1/2 (anula numerador)
>       Excluimos x = 4 (anula denominador)
> 
> Recta numérica:
> ←———●━━━○———→
>    -1/2  4
> ```
> 
> **Ejemplo 3: Con término adicional**
> 
> ```
> Resolver: 1/(x - 1) > 2
> 
> Solución:
> Paso 1: Llevar todo a un lado
> 1/(x - 1) - 2 > 0
> [1 - 2(x - 1)]/(x - 1) > 0
> [1 - 2x + 2]/(x - 1) > 0
> (3 - 2x)/(x - 1) > 0
> 
> Puntos críticos:
> • Numerador: 3 - 2x = 0  ⟹  x = 3/2
> • Denominador: x - 1 = 0  ⟹  x = 1
> 
> Tabla de signos:
>      x      | -∞    1    3/2   +∞
>   ----------|--------------------
>   3 - 2x    | +    +  0  -    -
>   x - 1     | -  0 +  +  +    +
>   ----------|--------------------
>   Cociente  | -  ∅  +  0  -
> 
> Queremos > 0:
> 
> Solución: (1, 3/2)
> 
> Recta numérica:
> ←———○━━━○———→
>      1  3/2
> ```
> 
> 
> **Ejemplo 4: Producto en el numerador**
> 
> ```
> Resolver: (x + 1)(x - 3)/(x - 2) ≤ 0
> 
> Solución:
> Puntos críticos:
> • Numerador: (x + 1)(x - 3) = 0  ⟹  x = -1, x = 3
> • Denominador: x - 2 = 0  ⟹  x = 2
> 
> Tabla de signos:
>      x      | -∞   -1    2    3    +∞
>   ----------|--------------------------
>    x + 1    | -   0 +   +   +   +   +
>    x - 3    | -   - -   -   -  0  +
>    x - 2    | -   - - 0 +   +   +   +
>   ----------|--------------------------
>   Cociente  | -   0 +  ∅  -   0  +
> 
> Queremos ≤ 0:
> 
> Solución: (-∞, -1] ∪ (2, 3]
> 
> Nota: Incluimos x = -1 y x = 3 (anulan numerador)
>       Excluimos x = 2 (anula denominador)
> 
> Recta numérica:
> ←━━━●———○━━━●———→
>     -1   2   3
> ```
> 
> **Ejemplo 5: Racional compleja**
> 
> ```
> Resolver: (x² - 4)/(x² - 9) ≥ 0
> 
> Solución:
> Factorizamos:
> [(x - 2)(x + 2)]/[(x - 3)(x + 3)] ≥ 0
> 
> Puntos críticos:
> • Numerador: x = 2, x = -2
> • Denominador: x = 3, x = -3
> 
> Tabla de signos:
>      x      | -∞   -3   -2    2    3    +∞
>   ----------|--------------------------------
>    x - 2    | -   -    -  0  +   +   +   +
>    x + 2    | -   -  0 +  +   +   +   +   +
>    x - 3    | -   -  -  -  -   -   - 0  +
>    x + 3    | - 0 +  +  +   +   +   +   +
>   ----------|--------------------------------
>   Cociente  | +  ∅  -  0  +   0   -  ∅  +
> 
> Queremos ≥ 0:
> 
> Solución: (-∞, -3) ∪ [-2, 2] ∪ (3, +∞)
> 
> Recta numérica:
> ←━━━○———●━━━●———○━━━→
>     -3  -2   2   3
> ```

## 🌿 Inecuaciones Irracionales

> [!success]- Tratamiento de Raíces en Inecuaciones
> 
> **Forma general:**
> 
> ```
> √f(x) < g(x)  o  √f(x) > g(x)
> ```
> 
> **Restricciones fundamentales:**
> 
> - El radicando debe ser no negativo: f(x) ≥ 0
> - Para raíces cuadradas: √f(x) ≥ 0 siempre
> 
> **Casos principales:**
> 
> **Tipo 1: √f(x) < g(x)**
> 
> ```
> Condiciones:
> 1. f(x) ≥ 0  (existe la raíz)
> 2. g(x) > 0  (si g(x) ≤ 0, no hay solución)
> 3. f(x) < [g(x)]²  (elevar al cuadrado)
> 
> Solución: intersección de las tres condiciones
> ```
> 
> **Tipo 2: √f(x) > g(x)**
> 
> ```
> Caso A: Si g(x) < 0
>   Como √f(x) ≥ 0 > g(x), se cumple automáticamente
>   Solución parcial: f(x) ≥ 0 y g(x) < 0
> 
> Caso B: Si g(x) ≥ 0
>   Elevar al cuadrado: f(x) > [g(x)]²
>   Solución parcial: f(x) ≥ 0, g(x) ≥ 0, y f(x) > [g(x)]²
> 
> Solución total: unión de ambos casos
> ```
> 
> **Tipo 3: √f(x) < √g(x)**
> 
> ```
> Condiciones:
> 4. f(x) ≥ 0 y g(x) ≥ 0
> 5. f(x) < g(x)  (la función raíz es creciente)
> 
> Solución: intersección de ambas
> ```

> [!example]- Ejemplos Resueltos de Inecuaciones Irracionales
> 
> **Ejemplo 1: Raíz menor que expresión**
> 
> ```
> Resolver: √(x - 1) < x - 3
> 
> Solución:
> Condiciones:
> 6. x - 1 ≥ 0  ⟹  x ≥ 1
> 7. x - 3 > 0  ⟹  x > 3
> 8. x - 1 < (x - 3)²
> 
> Desarrollamos condición 3:
> x - 1 < x² - 6x + 9
> 0 < x² - 7x + 10
> 0 < (x - 2)(x - 5)
> 
> Solución de la inecuación cuadrática:
> x < 2  o  x > 5
> 
> Intersección de todas las condiciones:
> x ≥ 1  ∩  x > 3  ∩  (x < 2 o x > 5)
> 
> = (x > 3) ∩ (x < 2 o x > 5)
> = (3, +∞) ∩ ((-∞, 2) ∪ (5, +∞))
> = (5, +∞)
> 
> Solución: (5, +∞)
> 
> Verificación:
> x = 6: √5 ≈ 2.24 < 3 ✓
> x = 4: √3 ≈ 1.73 < 1 ✗
> ```
> 
> **Ejemplo 2: Raíz mayor que expresión**
> 
> ```
> Resolver: √(2x + 3) > x
> 
> Solución:
> Caso A: x < 0
> Como √(2x + 3) ≥ 0 > x, se cumple siempre que exista la raíz
> 2x + 3 ≥ 0  ⟹  x ≥ -3/2
> 
> Solución parcial A: [-3/2, 0)
> 
> Caso B: x ≥ 0
> Elevamos al cuadrado:
> 2x + 3 > x²
> 0 > x² - 2x - 3
> 0 > (x - 3)(x + 1)
> 
> Solución de la cuadrática: -1 < x < 3
> 
> Intersección con x ≥ 0 y 2x + 3 ≥ 0:
> Solución parcial B: [0, 3)
> 
> Solución total: [-3/2, 0) ∪ [0, 3) = [-3/2, 3)
> 
> Recta numérica:
> ←———●━━━━━━━○———→
>    -3/2      3
> ```
> 
> **Ejemplo 3: Dos raíces**
> 
> ```
> Resolver: √(x + 5) < √(3x - 1)
> 
> Solución:
> Condiciones de existencia:
> 9. x + 5 ≥ 0  ⟹  x ≥ -5
> 10. 3x - 1 ≥ 0  ⟹  x ≥ 1/3
> 
> Como la función raíz es creciente:
> √(x + 5) < √(3x - 1)  ⟺  x + 5 < 3x - 1
> 
> Resolvemos:
> x + 5 < 3x - 1
> 6 < 2x
> x > 3
> 
> Intersección de todas las condiciones:
> x ≥ -5  ∩  x ≥ 1/3  ∩  x > 3  =  x > 3
> 
> Solución: (3, +∞)
> ```
> 
> **Ejemplo 4: Raíz más término**
> 
> ```
> Resolver: √(x - 2) + 1 ≤ x
> 
> Solución:
> √(x - 2) ≤ x - 1
> 
> Condiciones:
> 11. x - 2 ≥ 0  ⟹  x ≥ 2
> 12. x - 1 ≥ 0  ⟹  x ≥ 1  (para poder elevar al cuadrado)
> 13. x - 2 ≤ (x - 1)²
> 
> Desarrollamos condición 3:
> x - 2 ≤ x² - 2x + 1
> 0 ≤ x² - 3x + 3
> 
> Discriminante: Δ = 9 - 12 = -3 < 0
> Como el coeficiente de x² es positivo, la parábola
> nunca toca el eje x: siempre es positiva
> 
> Por tanto, la condición 3 siempre se cumple
> 
> Solución: intersección de condiciones 1 y 2
> x ≥ 2  ∩  x ≥ 1  =  x ≥ 2
> 
> Solución: [2, +∞)
> ```
> 
> **Ejemplo 5: Caso sin solución**
> 
> ```
> Resolver: √(x + 1) < -2
> 
> Solución:
> Como √(x + 1) ≥ 0 para todo x donde existe,
> y 0 > -2, la raíz nunca puede ser menor que -2
> 
> Solución: ∅ (conjunto vacío)
> 
> Interpretación: es imposible que una raíz cuadrada
> sea negativa.
> ```

## 📈 Inecuaciones Exponenciales y Logarítmicas

> [!success]- Uso de Funciones Monótonas
> 
> **Inecuaciones exponenciales:**
> 
> **Caso 1: Base a > 1 (función creciente)**
> 
> ```
> aᶠ⁽ˣ⁾ < aᵍ⁽ˣ⁾  ⟺  f(x) < g(x)
> 
> Preserva el sentido de la desigualdad
> ```
> 
> **Caso 2: Base 0 < a < 1 (función decreciente)**
> 
> ```
> aᶠ⁽ˣ⁾ < aᵍ⁽ˣ⁾  ⟺  f(x) > g(x)
> 
> Invierte el sentido de la desigualdad
> ```
> 
> **Inecuaciones logarítmicas:**
> 
> **Caso 1: Base a > 1 (función creciente)**
> 
> ```
> logₐ(f(x)) < logₐ(g(x))  ⟺  f(x) < g(x)
> 
> Condición: f(x) > 0 y g(x) > 0
> Preserva el sentido
> ```
> 
> **Caso 2: Base 0 < a < 1 (función decreciente)**
> 
> ```
> logₐ(f(x)) < logₐ(g(x))  ⟺  f(x) > g(x)
> 
> Condición: f(x) > 0 y g(x) > 0
> Invierte el sentido
> ```

> [!example]- Ejemplos Resueltos Exponenciales y Logarítmicas
> 
> **Ejemplo 1: Exponencial con base > 1**
> 
> ```
> Resolver: 2ˣ⁺¹ > 8
> 
> Solución:
> 2ˣ⁺¹ > 2³  (expresamos 8 como potencia de 2)
> 
> Como 2 > 1, la función es creciente:
> x + 1 > 3
> x > 2
> 
> Solución: (2, +∞)
> ```
> 
> **Ejemplo 2: Exponencial con base < 1**
> 
> ```
> Resolver: (1/3)ˣ⁻² ≤ 9
> 
> Solución:
> (1/3)ˣ⁻² ≤ 3²
> (3⁻¹)ˣ⁻² ≤ 3²
> 3⁻⁽ˣ⁻²⁾ ≤ 3²
> 3²⁻ˣ ≤ 3²
> 
> Como 3 > 1, la función es creciente:
> 2 - x ≤ 2
> -x ≤ 0
> x ≥ 0
> 
> Solución: [0, +∞)
> 
> Nota alternativa: Como 0 < 1/3 < 1, al comparar:
> (1/3)ˣ⁻² ≤ (1/3)⁻²
> La función (1/3)ˣ es decreciente, así que:
> x - 2 ≥ -2
> x ≥ 0
> ```
> 
> **Ejemplo 3: Logaritmo base > 1**
> 
> ```
> Resolver: log₂(x - 1) < 3
> 
> Solución:
> Condición de existencia: x - 1 > 0  ⟹  x > 1
> 
> log₂(x - 1) < log₂(8)  (pues 2³ = 8)
> 
> Como 2 > 1, el logaritmo es creciente:
> x - 1 < 8
> x < 9
> 
> Intersección: x > 1  y  x < 9
> 
> Solución: (1, 9)
> ```
> 
> **Ejemplo 4: Logaritmo base < 1**
> 
> ```
> Resolver: log₁/₂(x + 3) ≥ -2
> 
> Solución:
> Condición de existencia: x + 3 > 0  ⟹  x > -3
> 
> log₁/₂(x + 3) ≥ log₁/₂((1/2)⁻²)
> log₁/₂(x + 3) ≥ log₁/₂(4)
> 
> Como 0 < 1/2 < 1, el logaritmo es decreciente:
> x + 3 ≤ 4  (invierte)
> x ≤ 1
> 
> Intersección: x > -3  y  x ≤ 1
> 
> Solución: (-3, 1]
> ```
> 
> **Ejemplo 5: Logaritmo vs número**
> 
> ```
> Resolver: ln(x² - 3x) > 0
> 
> Solución:
> ln(x² - 3x) > 0 = ln(1)
> 
> Condición de existencia: x² - 3x > 0
> x(x - 3) > 0
> 
> Tabla de signos:
>      x      | -∞    0    3    +∞
>   ----------|-------------------
>   x(x - 3)  | +   0 -  0  +
> 
> Condición: x < 0  o  x > 3
> 
> Como ln es creciente (base e > 1):
> x² - 3x > 1
> x² - 3x - 1 > 0
> 
> Raíces: x = (3 ± √13)/2
> x₁ ≈ -0.30, x₂ ≈ 3.30
> 
> Inecuación cuadrática:
> x < (3 - √13)/2  o  x > (3 + √13)/2
> 
> Intersección con condición de existencia:
> [x < 0  o  x > 3]  ∩  [x < -0.30  o  x > 3.30]
> 
> = [x < -0.30]  ∪  [x > 3.30]
> 
> Solución: (-∞, (3-√13)/2) ∪ ((3+√13)/2, +∞)
> ```
> 
> **Ejemplo 6: Comparación de logaritmos**
> 
> ```
> Resolver: log₃(x + 1) > log₃(2x - 5)
> 
> Solución:
> Condiciones de existencia:
> 1. x + 1 > 0  ⟹  x > -1
> 2. 2x - 5 > 0  ⟹  x > 5/2
> 
> Intersección: x > 5/2
> 
> Como 3 > 1, log₃ es creciente:
> x + 1 > 2x - 5
> 6 > x
> x < 6
> 
> Intersección final: x > 5/2  y  x < 6
> 
> Solución: (5/2, 6)
> ```

## 🔄 Sistemas de Inecuaciones

> [!success]- Resolución de Sistemas
> 
> **Definición:** Un sistema de inecuaciones es un conjunto de dos o más inecuaciones que deben cumplirse simultáneamente.
> 
> **Solución:** La solución de un sistema es la **intersección** de las soluciones individuales.
> 
> **Representación:**
> 
> ```
> { f₁(x) < a₁
> { f₂(x) > a₂
> { f₃(x) ≤ a₃
> 
> Solución: S₁ ∩ S₂ ∩ S₃
> ```
> 
> **Método de resolución:**
> 
> 1. Resolver cada inecuación por separado
> 2. Representar cada solución en la recta numérica
> 3. Encontrar la intersección (zona común)
> 4. Expresar la solución final como intervalo o unión

> [!example]- Ejemplos Resueltos de Sistemas
> 
> **Ejemplo 1: Sistema lineal simple**
> 
> ```
> Resolver: { 2x - 3 < 5
>           { x + 1 ≥ -2
> 
> Solución:
> Primera inecuación:
> 2x - 3 < 5
> 2x < 8
> x < 4
> S₁ = (-∞, 4)
> 
> Segunda inecuación:
> x + 1 ≥ -2
> x ≥ -3
> S₂ = [-3, +∞)
> 
> Solución: S₁ ∩ S₂ = (-∞, 4) ∩ [-3, +∞) = [-3, 4)
> 
> Recta numérica:
> ←———●━━━━━━━○———→
>     -3      4
> ```
> 
> **Ejemplo 2: Sistema de tres inecuaciones**
> 
> ```
> Resolver: { x + 2 > 0
>           { 3x - 1 < 8
>           { -x ≤ 5
> 
> Solución:
> Primera: x > -2     S₁ = (-2, +∞)
> Segunda: 3x < 9  ⟹  x < 3     S₂ = (-∞, 3)
> Tercera: x ≥ -5     S₃ = [-5, +∞)
> 
> Intersección: (-2, +∞) ∩ (-∞, 3) ∩ [-5, +∞)
> = (-2, 3)
> 
> Recta numérica:
> ←———○━━━○———→
>     -2   3
> ```
> 
> **Ejemplo 3: Sistema con cuadrática**
> 
> ```
> Resolver: { x² - 4 < 0
>           { x + 1 > 0
> 
> Solución:
> Primera inecuación:
> (x - 2)(x + 2) < 0
> S₁ = (-2, 2)
> 
> Segunda inecuación:
> S₂ = (-1, +∞)
> 
> Intersección: (-2, 2) ∩ (-1, +∞) = (-1, 2)
> 
> Recta numérica:
> ←———○━━━━━━━○———→
>     -1      2
> ```
> 
> **Ejemplo 4: Sistema con racional**
> 
> ```
> Resolver: { 2x - 1 ≤ 5
>           { x/(x - 3) > 0
> 
> Solución:
> Primera inecuación:
> 2x ≤ 6
> x ≤ 3
> S₁ = (-∞, 3]
> 
> Segunda inecuación (racional):
> Puntos críticos: x = 0, x = 3
> 
> Tabla de signos:
>      x      | -∞    0    3    +∞
>   ----------|-------------------
>   x/(x-3)   | +   0 -  ∅  +
> 
> S₂ = (-∞, 0) ∪ (3, +∞)
> 
> Intersección: (-∞, 3] ∩ [(-∞, 0) ∪ (3, +∞)]
> = (-∞, 0)
> 
> Nota: x = 3 no entra porque anula el denominador
> 
> Recta numérica:
> ←━━━○———————○———→
>      0       3
> ```
> 
> **Ejemplo 5: Sistema sin solución**
> 
> ```
> Resolver: { x + 2 < 1
>           { 2x - 1 > 5
> 
> Solución:
> Primera: x < -1     S₁ = (-∞, -1)
> Segunda: 2x > 6  ⟹  x > 3     S₂ = (3, +∞)
> 
> Intersección: (-∞, -1) ∩ (3, +∞) = ∅
> 
> Solución: ∅ (no hay valores que satisfagan ambas)
> 
> Interpretación: es imposible que x sea simultáneamente
> menor que -1 y mayor que 3
> ```

## 🎨 Representación Gráfica

> [!tip]- Visualización de Soluciones
> 
> **En la recta numérica:**
> 
> **Símbolos:**
> 
> ```
> ○ : extremo abierto (< o >)
> ● : extremo cerrado (≤ o ≥)
> ━ : intervalo solución
> ∅ : punto excluido
> ```
> 
> **Ejemplos:**
> 
> ```
> x < 3:           ←━━━○———→
>                       3
> 
> x ≥ -2:          ←———●━━━→
>                      -2
> 
> -1 < x ≤ 4:      ←———○━━━●———→
>                      -1   4
> 
> x < -2 o x > 1:  ←━━━○———○━━━→
>                      -2   1
> ```
> 
> **En el plano cartesiano:**
> 
> Para inecuaciones con dos variables:
> 
> ```
> y < f(x):  región bajo la curva (no incluye la curva)
> y ≤ f(x):  región bajo la curva (incluye la curva)
> y > f(x):  región sobre la curva (no incluye la curva)
> y ≥ f(x):  región sobre la curva (incluye la curva)
> ```
> 
> **Técnica:**
> 
> 1. Graficar la frontera y = f(x)
> 2. Usar línea continua para ≤ o ≥
> 3. Usar línea punteada para < o >
> 4. Sombrear la región correspondiente
> 5. Verificar con un punto de prueba

## ⚠️ Errores Comunes

> [!warning]- Malentendidos y Trampas Frecuentes
> 
> **1. Olvidar invertir al multiplicar por negativo**
> 
> ```
> ❌ INCORRECTO:
> -2x > 6  →  x > -3
> 
> ✓ CORRECTO:
> -2x > 6  →  x < -3  (invierte al dividir por -2)
> ```
> 
> **2. Elevar al cuadrado sin precaución**
> 
> ```
> ❌ INCORRECTO:
> x < 3  →  x² < 9  (FALSO si x es negativo)
> 
> ✓ CORRECTO:
> Si 0 ≤ x < 3, entonces x² < 9
> Si x < 0, no se puede concluir
> ```
> 
> **3. No considerar el dominio en racionales**
> 
> ```
> ❌ INCORRECTO:
> x/(x-1) < 2  →  x < 2(x-1)  →  x < 2x - 2  →  x > 2
> 
> ✓ CORRECTO:
> Debe usarse método de signos, y excluir x = 1
> ```
> 
> **4. Confundir unión con intersección**
> 
> ```
> |x| > 2  ⟺  x < -2  o  x > 2  (UNIÓN)
> ❌ No escribir: -2 > x > 2  (imposible)
> 
> |x| < 2  ⟺  -2 < x < 2  (INTERSECCIÓN)
> ✓ Correcto: un solo intervalo
> ```
> 
> **5. Ignorar condiciones de existencia**
> 
> ```
> ❌ INCORRECTO:
> √(x-1) < 3  →  x - 1 < 9  →  x < 10
> 
> ✓ CORRECTO:
> Primero: x - 1 ≥ 0  ⟹  x ≥ 1
> Luego: x - 1 < 9  ⟹  x < 10
> Solución: [1, 10)
> ```
> 
> **6. Simplificar incorrectamente valores absolutos**
> 
> ```
> ❌ INCORRECTO:
> |x - 2| < 3  →  x - 2 < 3  →  x < 5
> 
> ✓ CORRECTO:
> |x - 2| < 3  →  -3 < x - 2 < 3  →  -1 < x < 5
> ```
> 
> **7. No verificar la solución final**
> 
> ```
> Siempre es recomendable:
> • Verificar con valores de prueba
> • Comprobar extremos de intervalos
> • Verificar puntos excluidos
> ```

## 🧮 Aplicaciones Prácticas

> [!example]- Problemas del Mundo Real
> 
> **Aplicación 1: Restricciones de producción**
> 
> ```
> Problema:
> Una fábrica produce x unidades por día. Los costos fijos son $500
> y el costo variable es $20 por unidad. Si venden cada unidad a $35,
> ¿cuántas unidades deben producir para obtener ganancia?
> 
> Solución:
> Ingresos: I(x) = 35x
> Costos: C(x) = 500 + 20x
> Ganancia: G(x) = I(x) - C(x) > 0
> 
> 35x - (500 + 20x) > 0
> 35x - 500 - 20x > 0
> 15x > 500
> x > 500/15
> x > 33.33...
> 
> Como x debe ser entero: x ≥ 34 unidades
> 
> Respuesta: Deben producir al menos 34 unidades para tener ganancia.
> ```
> 
> **Aplicación 2: Temperatura de reacción química**
> 
> ```
> Problema:
> Una reacción química requiere temperatura T (en °C) que satisfaga:
> |T - 80| ≤ 5
> 
> ¿Cuál es el rango de temperatura permitido?
> 
> Solución:
> |T - 80| ≤ 5
> -5 ≤ T - 80 ≤ 5
> 75 ≤ T ≤ 85
> 
> ```
> **Aplicación 2: Temperatura de reacción química** (continuación)
> 
> ```
> Respuesta: La temperatura debe estar entre 75°C y 85°C,
> inclusive. El rango permitido es de 10°C centrado en 80°C.
> ```
> 
> **Aplicación 3: Velocidad segura en una curva**
> 
> ```
> Problema:
> En una curva de radio r = 100 m, la velocidad segura v (en m/s)
> debe satisfacer: v²/(10r) ≤ 0.4
> 
> ¿Cuál es la velocidad máxima segura?
> 
> Solución:
> v²/(10 × 100) ≤ 0.4
> v²/1000 ≤ 0.4
> v² ≤ 400
> |v| ≤ 20
> 
> Como v ≥ 0 (velocidad): 0 ≤ v ≤ 20 m/s
> 
> Conversión a km/h: 20 m/s × 3.6 = 72 km/h
> 
> Respuesta: La velocidad máxima segura es 72 km/h.
> ```
> 
> **Aplicación 4: Rango de inversión**
> 
> ```
> Problema:
> Un inversionista quiere colocar un capital C en un fondo que
> rinde 6% anual. Necesita que el interés anual I sea al menos
> $3,000 pero no más de $8,000. ¿Qué rango de capital debe invertir?
> 
> Solución:
> Interés: I = 0.06C
> 
> Restricciones: 3000 ≤ 0.06C ≤ 8000
> 
> Dividimos por 0.06:
> 3000/0.06 ≤ C ≤ 8000/0.06
> 50,000 ≤ C ≤ 133,333.33
> 
> Respuesta: Debe invertir entre $50,000 y $133,333.33
> ```
> 
> **Aplicación 5: Dimensiones de un rectángulo**
> 
> ```
> Problema:
> Un rectángulo tiene perímetro 40 cm. Si el largo es x cm,
> ¿qué valores puede tomar x si el área debe ser al menos 75 cm²?
> 
> Solución:
> Ancho: y = (40 - 2x)/2 = 20 - x
> Área: A = x(20 - x) ≥ 75
> 
> x(20 - x) ≥ 75
> 20x - x² ≥ 75
> -x² + 20x - 75 ≥ 0
> x² - 20x + 75 ≤ 0
> 
> Raíces: x = (20 ± √(400 - 300))/2 = (20 ± 10)/2
> x₁ = 5, x₂ = 15
> 
> Como a = 1 > 0, parábola ∪:
> x² - 20x + 75 ≤ 0 entre las raíces
> 
> Solución: 5 ≤ x ≤ 15
> 
> Restricciones adicionales:
> • x > 0 (largo positivo)
> • y = 20 - x > 0  ⟹  x < 20
> 
> Respuesta: El largo debe estar entre 5 cm y 15 cm.
> ```
> 
> **Aplicación 6: Descuento óptimo**
> 
> ```
> Problema:
> Una tienda vende un producto a $p por unidad. A ese precio,
> vende 100 unidades diarias. Por cada dólar de descuento,
> vende 10 unidades más. El precio de costo es $15 por unidad.
> ¿Cuál debe ser el descuento d para que la ganancia diaria
> sea al menos $1,500?
> 
> Solución:
> Precio final: p - d
> Cantidad vendida: 100 + 10d
> Costo unitario: 15
> 
> Ganancia: G = (p - d - 15)(100 + 10d)
> 
> Supongamos p = 30:
> G = (30 - d - 15)(100 + 10d)
> G = (15 - d)(100 + 10d)
> G ≥ 1500
> 
> (15 - d)(100 + 10d) ≥ 1500
> 1500 + 150d - 100d - 10d² ≥ 1500
> 50d - 10d² ≥ 0
> 10d(5 - d) ≥ 0
> 
> Puntos críticos: d = 0, d = 5
> 
> Tabla de signos:
>      d      | -∞    0    5    +∞
>   ----------|-------------------
>   10d(5-d)  | -   0 +  0  -
> 
> Solución matemática: 0 ≤ d ≤ 5
> 
> Restricciones adicionales:
> • d ≥ 0 (descuento no negativo)
> • d ≤ 15 (precio final positivo)
> 
> Respuesta: El descuento debe estar entre $0 y $5.
> ```
> 
> **Aplicación 7: Tiempo de caída libre**
> 
> ```
> Problema:
> Un objeto se deja caer desde una altura de 80 m.
> Su altura h(t) = 80 - 5t² (metros), donde t es el tiempo en segundos.
> ¿Durante qué intervalo de tiempo el objeto está a más de 35 m
> del suelo?
> 
> Solución:
> h(t) > 35
> 80 - 5t² > 35
> 45 > 5t²
> 9 > t²
> t² < 9
> |t| < 3
> -3 < t < 3
> 
> Como t ≥ 0 (tiempo positivo): 0 ≤ t < 3
> 
> Respuesta: Durante los primeros 3 segundos de caída.
> ```

## 🎯 Estrategias de Resolución

> [!tip]- Guía Metodológica General
> 
> **Algoritmo general para resolver inecuaciones:**
> 
> **Paso 1: Identificar el tipo**
> 
> ```
> • Lineal
> • Cuadrática
> • Polinómica
> • Racional
> • Con valor absoluto
> • Irracional
> • Exponencial/logarítmica
> ```
> 
> **Paso 2: Simplificar**
> 
> ```
> • Eliminar paréntesis
> • Eliminar fracciones (cuidado con signos)
> • Agrupar términos semejantes
> • Llevar todo a un lado si es necesario
> ```
> 
> **Paso 3: Encontrar puntos críticos**
> 
> ```
> • Ceros del numerador
> • Ceros del denominador
> • Puntos donde cambia definición
> • Restricciones de dominio
> ```
> 
> **Paso 4: Análisis de signos**
> 
> ```
> • Construir tabla de signos
> • Evaluar en cada intervalo
> • Considerar comportamiento en los extremos
> ```
> 
> **Paso 5: Seleccionar solución**
> 
> ```
> • Elegir intervalos según desigualdad
> • Decidir inclusión de extremos (≤, ≥ vs <, >)
> • Excluir puntos problemáticos
> ```
> 
> **Paso 6: Verificar**
> 
> ```
> • Probar con valores específicos
> • Comprobar extremos
> • Verificar dominio
> ```
> 
> **Consejos prácticos:**
> 
> ✓ **Siempre** verifica puntos críticos en la solución original ✓ **Grafica** mentalmente o en papel la situación ✓ **Usa** recta numérica para visualizar ✓ **Comprueba** con valores de prueba ✓ **Cuidado** con denominadores y raíces pares ✓ **Recuerda** invertir con multiplicación/división negativa

## 📚 Casos Especiales

> [!note]- Inecuaciones Más Complejas
> 
> **Inecuaciones con múltiples valores absolutos:**
> 
> ```
> Ejemplo: |x - 1| + |x + 2| < 5
> 
> Método: Resolver por casos según puntos críticos
> Puntos críticos: x = 1, x = -2
> 
> Caso 1: x < -2
> -(x - 1) + -(x + 2) < 5
> -x + 1 - x - 2 < 5
> -2x < 6
> x > -3
> Solución parcial: -3 < x < -2
> 
> Caso 2: -2 ≤ x < 1
> -(x - 1) + (x + 2) < 5
> -x + 1 + x + 2 < 5
> 3 < 5 ✓ (siempre cierto)
> Solución parcial: -2 ≤ x < 1
> 
> Caso 3: x ≥ 1
> (x - 1) + (x + 2) < 5
> 2x + 1 < 5
> x < 2
> Solución parcial: 1 ≤ x < 2
> 
> Solución total: (-3, 2)
> ```
> 
> **Inecuaciones con parte entera:**
> 
> ```
> Ejemplo: ⌊x⌋ ≤ 2x - 3
> 
> donde ⌊x⌋ es la parte entera de x
> 
> Método: Analizar por intervalos enteros
> Si n ≤ x < n + 1, entonces ⌊x⌋ = n
> 
> Para cada n, resolver:
> n ≤ 2x - 3
> 2x ≥ n + 3
> x ≥ (n + 3)/2
> 
> Intersectar con n ≤ x < n + 1
> ```
> 
> **Inecuaciones trigonométricas:**
> 
> ```
> Ejemplo: sin(x) > 1/2, x ∈ [0, 2π]
> 
> Método:
> 1. Encontrar soluciones de sin(x) = 1/2
>    x = π/6, x = 5π/6
> 
> 2. Analizar signo de sin(x) - 1/2
>    Positivo en: (π/6, 5π/6)
> 
> Solución: (π/6, 5π/6)
> ```
> 
> **Inecuaciones con máximo/mínimo:**
> 
> ```
> Ejemplo: max{x, x²} < 2
> 
> Método:
> max{x, x²} = { x²  si x² ≥ x  (⟺ x ≤ 0 o x ≥ 1)
>              { x   si x² < x  (⟺ 0 < x < 1)
> 
> Caso 1: x ≤ 0 o x ≥ 1
> x² < 2  ⟹  -√2 < x < √2
> Intersección: [-√2, 0] ∪ [1, √2)
> 
> Caso 2: 0 < x < 1
> x < 2 ✓ (siempre cierto en este intervalo)
> Solución parcial: (0, 1)
> 
> Solución total: [-√2, √2)
> ```

## 📖 Teoremas Importantes

> [!important]- Resultados Fundamentales
> 
> **Teorema 1: Preservación del orden**
> 
> ```
> Si a < b, entonces:
> • a + c < b + c  para todo c ∈ ℝ
> • ac < bc  si c > 0
> • ac > bc  si c < 0
> ```
> 
> **Teorema 2: Propiedad transitiva**
> 
> ```
> Si a < b y b < c, entonces a < c
> ```
> 
> **Teorema 3: Propiedad de Arquímedes**
> 
> ```
> Para todo a, b ∈ ℝ con a, b > 0,
> existe n ∈ ℕ tal que na > b
> ```
> 
> **Teorema 4: Desigualdad triangular**
> 
> ```
> |a + b| ≤ |a| + |b|  para todo a, b ∈ ℝ
> 
> Generalización:
> |a - b| ≥ ||a| - |b||
> ```
> 
> **Teorema 5: Media aritmética-geométrica (AM-GM)**
> 
> ```
> Para a, b > 0:
> √(ab) ≤ (a + b)/2
> 
> La igualdad ocurre si y solo si a = b
> ```
> 
> **Teorema 6: Desigualdad de Cauchy-Schwarz**
> 
> ```
> Para números reales a₁, a₂, ..., aₙ y b₁, b₂, ..., bₙ:
> 
> (Σ aᵢbᵢ)² ≤ (Σ aᵢ²)(Σ bᵢ²)
> ```
> 
> **Teorema 7: Completitud de ℝ**
> 
> ```
> Si S ⊆ ℝ es no vacío y acotado superiormente,
> entonces existe sup(S) ∈ ℝ
> 
> (Fundamenta la resolución de muchas inecuaciones)
> ```
