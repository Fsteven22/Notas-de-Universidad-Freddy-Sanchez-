# 🎯 01 - Ecuaciones en ℝ

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva
> **Una ecuación es una afirmación de igualdad entre dos expresiones matemáticas que contiene una o más incógnitas. Resolver una ecuación significa encontrar todos los valores de las incógnitas que hacen verdadera la igualdad.**
> 
> **Elementos clave:**
> 
> - **Igualdad condicional:** Solo es verdadera para ciertos valores (no identidad)
> - **Incógnita(s):** Variable(s) cuyo valor se busca determinar
> - **Conjunto solución:** Todos los valores que satisfacen la ecuación
> - **Equivalencia:** Transformaciones que preservan las soluciones

### 📖 Contexto Histórico

> [!note]- Desarrollo del Álgebra y las Ecuaciones
> 
> **Antigüedad (2000 a.C. - 500 d.C.):**
> 
> - **Babilonios (1800 a.C.):** Resolvían ecuaciones cuadráticas con métodos geométricos
> - **Egipcios (Papiro de Rhind, 1650 a.C.):** Método de "falsa posición" para ecuaciones lineales
> - **Griegos (Euclides, 300 a.C.):** Álgebra geométrica, evitaban números negativos
> - **Diofanto (250 d.C.):** Primera notación algebraica primitiva, ecuaciones diofánticas
> 
> **Era Islámica (500-1200):**
> 
> - **Al-Khwarizmi (820):** "Al-jabr" → origen de la palabra "álgebra"
>   - Clasificación de ecuaciones cuadráticas
>   - Métodos de resolución sistemáticos
> - **Omar Khayyam (1070):** Soluciones geométricas de cúbicas
> - **Al-Karaji:** Álgebra con exponentes
> 
> **Renacimiento Europeo (1200-1600):**
> 
> - **Fibonacci (1202):** Introduce álgebra árabe en Europa
> - **Cardano (1545):** Fórmula para ecuaciones cúbicas
>   - Trabaja con números negativos y complejos
> - **Ferrari (1545):** Solución de ecuaciones cuárticas
> - **Viète (1591):** Álgebra simbólica moderna
>   - Usa letras para incógnitas y parámetros
> 
> **Era Moderna (1600-1800):**
> 
> - **Descartes (1637):** Geometría analítica
>   - Conexión ecuaciones-gráficas
>   - Notación exponencial moderna
> - **Newton-Leibniz (1670s):** Métodos numéricos de aproximación
> - **Euler (1748):** Sistematización del álgebra
> 
> **Teoría Abstracta (1800-presente):**
> 
> - **Gauss (1799):** Teorema fundamental del álgebra
> - **Abel-Ruffini (1824):** Imposibilidad de fórmula para quínticas
> - **Galois (1830):** Teoría de grupos y resolubilidad
> - **Teoría moderna:** Álgebra abstracta, ecuaciones diferenciales
> 
> **Impacto:** Las ecuaciones se convirtieron en:
> 
> - Lenguaje fundamental de las matemáticas
> - Herramienta de modelación científica
> - Base de computación y algoritmos
> - Puente entre álgebra, geometría y análisis

## 📝 Definición Formal

### Ecuación y Conjunto Solución

> [!success]- Definición Rigurosa
> 
> **Definición:** Una ecuación en una variable x es una expresión de la forma:
> 
> ```
> f(x) = g(x)
> ```
> 
> donde f y g son funciones de x.
> 
> **Conjunto solución (o conjunto raíz):**
> 
> ```
> S = {x ∈ ℝ : f(x) = g(x)}
> ```
> 
> **Notación alternativa:**
> 
> ```
> f(x) - g(x) = 0
> 
> Definiendo h(x) = f(x) - g(x), buscar ceros de h
> ```
> 
> **Terminología:**
> 
> - **Solución/raíz:** Valor x₀ ∈ S
> - **Resolver:** Encontrar S explícitamente
> - **Verificar:** Comprobar que x₀ ∈ S sustituyendo

> [!example]- Ejemplos de Conjuntos Solución
> 
> **Ejemplo 1: Solución única**
> 
> ```
> 2x + 3 = 7
> 
> S = {2}
> 
> Verificación: 2(2) + 3 = 4 + 3 = 7 ✓
> ```
> 
> **Ejemplo 2: Dos soluciones**
> 
> ```
> x² = 4
> 
> S = {-2, 2}
> 
> Verificación: (-2)² = 4 ✓, (2)² = 4 ✓
> ```
> 
> **Ejemplo 3: Sin solución**
> 
> ```
> x² + 1 = 0  (en ℝ)
> 
> S = ∅
> 
> Razón: x² ≥ 0 para todo x ∈ ℝ, entonces x² + 1 ≥ 1 > 0
> ```
> 
> **Ejemplo 4: Infinitas soluciones**
> 
> ```
> 2(x + 1) = 2x + 2
> 
> S = ℝ
> 
> Esta es una identidad, no una ecuación propiamente dicha
> ```
> 
> **Ejemplo 5: Solución con restricciones**
> 
> ```
> √x = 2
> 
> S = {4}
> 
> Nota: x = 4 es la única solución porque √x requiere x ≥ 0
> y √4 = 2 (raíz principal positiva)
> ```

### Equivalencia de Ecuaciones

> [!important]- Operaciones que Preservan Soluciones
> 
> **Definición:** Dos ecuaciones son equivalentes si tienen el mismo conjunto solución.
> 
> ```
> f₁(x) = g₁(x)  es equivalente a  f₂(x) = g₂(x)
> 
> si y solo si S₁ = S₂
> ```
> 
> **Operaciones elementales equivalentes:**
> 
> **1. Sumar/restar la misma expresión a ambos lados:**
> 
> ```
> f(x) = g(x)  ⟺  f(x) + h(x) = g(x) + h(x)
> 
> para cualquier función h definida en el dominio
> ```
> 
> **2. Multiplicar/dividir por constante no nula:**
> 
> ```
> f(x) = g(x)  ⟺  k·f(x) = k·g(x)  con k ≠ 0
> ```
> 
> **3. Simplificar expresiones algebraicas:**
> 
> ```
> 2(x + 1) = 6  ⟺  2x + 2 = 6
> ```
> 
> **Operaciones NO siempre equivalentes:**
> 
> **1. Multiplicar por expresión con x (puede introducir soluciones):**
> 
> ```
> x = 2
> x·(x - 1) = 2·(x - 1)
> x² - x = 2x - 2
> x² - 3x + 2 = 0
> (x - 1)(x - 2) = 0
> 
> Soluciones: x = 1 o x = 2
> 
> ¡x = 1 es solución EXTRAÑA! (no satisface la ecuación original)
> ```
> 
> **2. Elevar a potencia par (puede introducir soluciones):**
> 
> ```
> x = 2
> x² = 4
> 
> La segunda tiene soluciones x = 2 y x = -2
> ```
> 
> **3. Dividir por expresión con x (puede perder soluciones):**
> 
> ```
> x² = x
> x²/x = x/x  (dividiendo por x)
> x = 1
> 
> ¡Se perdió la solución x = 0!
> ```
> 
> **Regla de oro:** Siempre verificar soluciones cuando se usa multiplicación, división o potenciación que involucre la variable.

### Verificación de Soluciones

> [!tip]- Proceso de Verificación
> 
> **Método estándar:**
> 
> 1. Sustituir el valor candidato en la ecuación original
> 2. Evaluar ambos lados independientemente
> 3. Confirmar que ambos lados son iguales
> 
> **¿Por qué verificar?**
> 
> - Detectar soluciones extrañas
> - Confirmar que no hay errores de cálculo
> - Validar restricciones del dominio
> 
> **Ejemplo completo:**
> 
> ```
> Resolver: √(x + 5) = x - 1
> 
> Elevando al cuadrado:
> x + 5 = (x - 1)²
> x + 5 = x² - 2x + 1
> 0 = x² - 3x - 4
> 0 = (x - 4)(x + 1)
> 
> Candidatos: x = 4 o x = -1
> 
> Verificación x = 4:
> √(4 + 5) = 4 - 1
> √9 = 3
> 3 = 3 ✓ VÁLIDA
> 
> Verificación x = -1:
> √(-1 + 5) = -1 - 1
> √4 = -2
> 2 = -2 ✗ EXTRAÑA
> 
> Solución: S = {4}
> ```

## 🔢 Ecuaciones Lineales

### Forma General

> [!success]- Ecuación Lineal en Una Variable
> 
> **Definición:** Una ecuación lineal en x es de la forma:
> 
> ```
> ax + b = 0
> 
> donde a, b ∈ ℝ y a ≠ 0
> ```
> 
> **Forma general extendida:**
> 
> ```
> ax + b = cx + d
> 
> que se reduce a (a - c)x + (b - d) = 0
> ```
> 
> **Características:**
> 
> - **Grado 1:** El exponente más alto de x es 1
> - **Una solución:** Si a ≠ 0, existe exactamente una solución
> - **Gráfica:** Línea recta que cruza el eje x en la solución
> - **Fácil resolución:** Despejar algebraicamente

### Método de Resolución

> [!example]- Algoritmo Paso a Paso
> 
> **Paso 1: Simplificar ambos lados**
> 
> ```
> Eliminar paréntesis, combinar términos semejantes
> ```
> 
> **Paso 2: Agrupar términos con x en un lado**
> 
> ```
> Usar propiedad aditiva de la igualdad
> ```
> 
> **Paso 3: Agrupar términos constantes en el otro lado**
> 
> ```
> Continuar usando propiedad aditiva
> ```
> 
> **Paso 4: Despejar x**
> 
> ```
> Dividir entre el coeficiente de x
> ```
> 
> **Ejemplo 1: Ecuación simple**
> 
> ```
> 3x - 7 = 2x + 5
> 
> 3x - 2x = 5 + 7        (agrupando)
> x = 12                  (simplificando)
> 
> S = {12}
> 
> Verificación: 3(12) - 7 = 36 - 7 = 29
>               2(12) + 5 = 24 + 5 = 29 ✓
> ```
> 
> **Ejemplo 2: Con paréntesis**
> 
> ```
> 2(x + 3) - 5 = 3(x - 1) + 4
> 
> 2x + 6 - 5 = 3x - 3 + 4     (distributiva)
> 2x + 1 = 3x + 1              (simplificando)
> 2x - 3x = 1 - 1              (agrupando)
> -x = 0                        (simplificando)
> x = 0                         (multiplicando por -1)
> 
> S = {0}
> ```
> 
> **Ejemplo 3: Con fracciones**
> 
> ```
> (x - 2)/3 + (x + 1)/4 = 5
> 
> Multiplicar todo por MCM(3, 4) = 12:
> 
> 4(x - 2) + 3(x + 1) = 60
> 4x - 8 + 3x + 3 = 60
> 7x - 5 = 60
> 7x = 65
> x = 65/7
> 
> S = {65/7}
> ```
> 
> **Ejemplo 4: Con decimales**
> 
> ```
> 0.5x + 1.2 = 0.3x - 0.4
> 
> Multiplicar por 10 para eliminar decimales:
> 
> 5x + 12 = 3x - 4
> 5x - 3x = -4 - 12
> 2x = -16
> x = -8
> 
> S = {-8}
> ```

### Casos Especiales

> [!warning]- Ecuaciones Sin Solución o con Infinitas Soluciones
> 
> **Caso 1: Sin solución (inconsistente)**
> 
> ```
> 2x + 3 = 2x + 7
> 
> 2x - 2x = 7 - 3
> 0 = 4  (contradicción)
> 
> S = ∅
> 
> Interpretación: Las rectas son paralelas (no se intersectan)
> ```
> 
> **Caso 2: Infinitas soluciones (identidad)**
> 
> ```
> 3(x + 2) = 3x + 6
> 
> 3x + 6 = 3x + 6
> 0 = 0  (identidad)
> 
> S = ℝ
> 
> Interpretación: Son la misma recta
> ```
> 
> **Caso 3: Solución única (caso normal)**
> 
> ```
> 3x + 2 = 5x - 8
> 
> -2x = -10
> x = 5
> 
> S = {5}
> 
> Interpretación: Las rectas se intersectan en un punto
> ```

### Aplicaciones

> [!example]- Problemas del Mundo Real
> 
> **Problema 1: Problema de edades**
> 
> ```
> María tiene 5 años más que su hermano Juan.
> En 10 años, la suma de sus edades será 45.
> ¿Cuántos años tiene cada uno ahora?
> 
> Variables:
> x = edad actual de Juan
> x + 5 = edad actual de María
> 
> En 10 años:
> (x + 10) + (x + 5 + 10) = 45
> 
> Resolución:
> x + 10 + x + 15 = 45
> 2x + 25 = 45
> 2x = 20
> x = 10
> 
> Respuesta:
> Juan tiene 10 años
> María tiene 15 años
> 
> Verificación: En 10 años tendrán 20 y 25 años
> 20 + 25 = 45 ✓
> ```
> 
> **Problema 2: Mezclas**
> 
> ```
> Se mezclan dos soluciones: una al 20% de alcohol y otra al 50%.
> ¿Cuántos litros de cada una se necesitan para obtener 
> 30 litros de solución al 35%?
> 
> Variables:
> x = litros de solución al 20%
> 30 - x = litros de solución al 50%
> 
> Ecuación (cantidad de alcohol):
> 0.20x + 0.50(30 - x) = 0.35(30)
> 
> Resolución:
> 0.20x + 15 - 0.50x = 10.5
> -0.30x = -4.5
> x = 15
> 
> Respuesta:
> 15 litros de solución al 20%
> 15 litros de solución al 50%
> 
> Verificación: 0.20(15) + 0.50(15) = 3 + 7.5 = 10.5
>               0.35(30) = 10.5 ✓
> ```
> 
> **Problema 3: Movimiento uniforme**
> 
> ```
> Dos autos parten simultáneamente de ciudades separadas 
> por 450 km y van al encuentro. Uno viaja a 80 km/h 
> y el otro a 70 km/h. ¿Cuánto tiempo tardan en encontrarse?
> 
> Variables:
> t = tiempo hasta el encuentro (horas)
> 
> Distancias recorridas:
> Auto 1: 80t
> Auto 2: 70t
> 
> Ecuación:
> 80t + 70t = 450
> 
> Resolución:
> 150t = 450
> t = 3
> 
> Respuesta: Se encuentran en 3 horas
> 
> Verificación: 80(3) + 70(3) = 240 + 210 = 450 ✓
> ```

## 📏 Ecuaciones con Valor Absoluto

### Tipo |f(x)| = a

> [!success]- Método Básico
> 
> **Regla fundamental:**
> 
> ```
> |f(x)| = a
> 
> Caso a < 0:  S = ∅  (sin solución)
> Caso a = 0:  f(x) = 0
> Caso a > 0:  f(x) = a  o  f(x) = -a
> ```
> 
> **Justificación:**
> 
> ```
> Por definición de valor absoluto:
> |f(x)| = a significa que f(x) está a distancia a del origen
> 
> Esto ocurre en exactamente dos puntos: a y -a
> (o uno solo si a = 0)
> ```

> [!example]- Ejemplos Resueltos
> 
> **Ejemplo 1: Simple**
> 
> ```
> |x - 3| = 5
> 
> x - 3 = 5    o    x - 3 = -5
> x = 8        o    x = -2
> 
> S = {-2, 8}
> 
> Verificación:
> |-2 - 3| = |-5| = 5 ✓
> |8 - 3| = |5| = 5 ✓
> ```
> 
> **Ejemplo 2: Con coeficiente**
> 
> ```
> |2x + 1| = 7
> 
> 2x + 1 = 7    o    2x + 1 = -7
> 2x = 6        o    2x = -8
> x = 3         o    x = -4
> 
> S = {-4, 3}
> ```
> 
> **Ejemplo 3: Sin solución**
> 
> ```
> |x + 2| = -3
> 
> S = ∅
> 
> Razón: El valor absoluto siempre es ≥ 0
> ```
> 
> **Ejemplo 4: Solución única**
> 
> ```
> |3x - 6| = 0
> 
> 3x - 6 = 0
> x = 2
> 
> S = {2}
> ```
> 
> **Ejemplo 5: Con la variable en ambos lados**
> 
> ```
> |x + 1| = 2x
> 
> Caso 1: x + 1 = 2x
>        1 = x
>        x = 1
> 
> Caso 2: x + 1 = -2x
>        3x = -1
>        x = -1/3
> 
> Verificación necesaria:
> x = 1:   |1 + 1| = 2 = 2(1) = 2 ✓
> x = -1/3: |-1/3 + 1| = |2/3| = 2/3 ≠ 2(-1/3) = -2/3 ✗
> 
> S = {1}
> 
> Nota: x = -1/3 es extraña porque 2x debe ser ≥ 0 
> para que |x + 1| = 2x tenga sentido
> ```

### Tipo |f(x)| = |g(x)|

> [!important]- Igualdad de Valores Absolutos
> 
> **Regla:**
> 
> ```
> |f(x)| = |g(x)|  ⟺  f(x) = g(x)  o  f(x) = -g(x)
> ```
> 
> **Justificación:**
> 
> ```
> Dos números tienen el mismo valor absoluto si:
> - Son iguales, o
> - Son opuestos
> ```
> 
> **Método alternativo (elevar al cuadrado):**
> 
> ```
> |f(x)| = |g(x)|
> [f(x)]² = [g(x)]²
> [f(x)]² - [g(x)]² = 0
> [f(x) - g(x)][f(x) + g(x)] = 0
> 
> f(x) = g(x)  o  f(x) = -g(x)
> ```

> [!example]- Ejemplos Trabajados
> 
> **Ejemplo 1: Básico**
> 
> ```
> |x - 2| = |x + 4|
> 
> Caso 1: x - 2 = x + 4
>        -2 = 4  (imposible)
> 
> Caso 2: x - 2 = -(x + 4)
>        x - 2 = -x - 4
>        2x = -2
>        x = -1
> 
> S = {-1}
> 
> Verificación: |-1 - 2| = |-3| = 3
>               |-1 + 4| = |3| = 3 ✓
> 
> Interpretación geométrica:
> Punto equidistante de 2 y -4
> x = (2 + (-4))/2 = -1 ✓
> ```
> 
> **Ejemplo 2: Con coeficientes**
> 
> ```
> |2x - 1| = |x + 3|
> 
> Caso 1: 2x - 1 = x + 3
>        x = 4
> 
> Caso 2: 2x - 1 = -(x + 3)
>        2x - 1 = -x - 3
>        3x = -2
>        x = -2/3
> 
> S = {-2/3, 4}
> 
> Verificación:
> x = 4:    |2(4) - 1| = |7| = 7,  |4 + 3| = |7| = 7 ✓
> x = -2/3: |2(-2/3) - 1| = |-7/3| = 7/3,  |-2/3 + 3| = |7/3| = 7/3 ✓
> ```
> 
> **Ejemplo 3: Método de elevar al cuadrado**
> 
> ```
> |x - 1| = |2x + 3|
> 
> (x - 1)² = (2x + 3)²
> x² - 2x + 1 = 4x² + 12x + 9
> 0 = 3x² + 14x + 8
> 0 = (3x + 2)(x + 4)
> 
> x = -2/3  o  x = -4
> 
> S = {-4, -2/3}
> 
> (Verificación recomendada)
> ```

### Ecuaciones con Múltiples Valores Absolutos

> [!tip]- Método de Análisis por Intervalos
> 
> **Estrategia general:**
> 
> 1. Identificar puntos críticos (donde expresiones dentro de |·| cambian signo)
> 2. Dividir la recta en intervalos según estos puntos
> 3. En cada intervalo, eliminar valores absolutos según signos
> 4. Resolver en cada intervalo
> 5. Verificar que soluciones pertenezcan a su intervalo
> 
> **Principio:** En cada intervalo, sabemos el signo de cada expresión, así que podemos eliminar |·|

> [!example]- Ejemplo Completo
> 
> **Resolver: |x - 1| + |x + 2| = 5**
> 
> **Paso 1: Puntos críticos**
> 
> ```
> x - 1 = 0  →  x = 1
> x + 2 = 0  →  x = -2
> 
> Intervalos: (-∞, -2), [-2, 1], [1, ∞)
> ```
> 
> **Paso 2: Análisis de signos**
> 
> ```
> En (-∞, -2):    x - 1 < 0  y  x + 2 < 0
> En [-2, 1]:     x - 1 < 0  y  x + 2 ≥ 0  
> En [1, ∞):      x - 1 ≥ 0  y  x + 2 > 0
> ```
> 
> **Paso 3: Resolver en cada intervalo**
> 
> ```
> Intervalo 1: x < -2
> -(x - 1) + (-(x + 2)) = 5
> -x + 1 - x - 2 = 5
> -2x - 1 = 5
> -2x = 6
> x = -3 ✓ (pertenece a (-∞, -2))
> 
> Intervalo 2: -2 ≤ x < 1
> -(x - 1) + (x + 2) = 5
> -x + 1 + x + 2 = 5
> 3 = 5 (imposible)
> 
> Intervalo 3: x ≥ 1
> (x - 1) + (x + 2) = 5
> 2x + 1 = 5
> 2x = 4
> x = 2 ✓ (pertenece a [1, ∞))
> ```
> 
> **Solución: S = {-3, 2}**
> 
> **Verificación:**
> 
> ```
> x = -3: |-3 - 1| + |-3 + 2| = |-4| + |-1| = 4 + 1 = 5 ✓
> x = 2:  |2 - 1| + |2 + 2| = |1| + |4| = 1 + 4 = 5 ✓
> ```

> [!example]- Ejemplo 2: Tres Valores Absolutos
> 
> **Resolver: |x| + |x - 2| + |x - 4| = 6**
> 
> **Puntos críticos:** x = 0, x = 2, x = 4
> 
> **Intervalos:** (-∞, 0), [0, 2], [2, 4], [4, ∞)
> 
> **Análisis:**
> 
> ```
> Intervalo 1: x < 0
> -x + (-(x - 2)) + (-(x - 4)) = 6
> -x - x + 2 - x + 4 = 6
> -3x + 6 = 6
> x = 0 (frontera, revisar en siguiente intervalo)
> 
> Intervalo 2: 0 ≤ x < 2
> x + (-(x - 2)) + (-(x - 4)) = 6
> x - x + 2 - x + 4 = 6
> -x + 6 = 6
> x = 0 ✓
> 
> Intervalo 3: 2 ≤ x < 4
> x + (x - 2) + (-(x - 4)) = 6
> x + x - 2 - x + 4 = 6
> x + 2 = 6
> x = 4 (frontera, revisar en siguiente intervalo)
> 
> Intervalo 4: x ≥ 4
> x + (x - 2) + (x - 4) = 6
> 3x - 6 = 6
> 3x = 12
> x = 4 ✓
> ```
> 
> **Solución: S = {0, 4}**
> 
> **Verificación:**
> 
> ```
> x = 0: |0| + |0 - 2| + |0 - 4| = 0 + 2 + 4 = 6 ✓
> x = 4: |4| + |4 - 2| + |4 - 4| = 4 + 2 + 0 = 6 ✓
> ```

## 🎯 Ecuaciones Cuadráticas

### Forma General

> [!success]- Ecuación Cuadrática Estándar
> 
> **Definición:** Una ecuación cuadrática en x es de la forma:
> 
> ```
> ax² + bx + c = 0
> 
> donde a, b, c ∈ ℝ y a ≠ 0
> ```
> 
> **Elementos:**
> 
> - **a:** Coeficiente cuadrático (determina concavidad)
> - **b:** Coeficiente lineal
> - **c:** Término independiente
> - **Grado 2:** El exponente más alto es 2
> 
> **Características:**
> 
> - Puede tener 0, 1 o 2 soluciones reales
> - Gráfica: parábola
> - Las soluciones son las intersecciones con el eje x
> 
> **Formas equivalentes:**
> 
> ```
> Forma estándar:    ax² + bx + c = 0
> Forma factorizada: a(x - r₁)(x - r₂) = 0
> Forma canónica:    a(x - h)² + k = 0
> ```

### Método 1: Factorización

> [!example]- Factorización Directa
> 
> **Principio:** Si ax² + bx + c = (px + q)(rx + s), entonces:
> 
> ```
> (px + q)(rx + s) = 0
> 
> px + q = 0  o  rx + s = 0
> 
> (Propiedad del producto cero)
> ```
> 
> **Casos comunes:**
> 
> **Tipo 1: x² + bx + c (coeficiente cuadrático = 1)**
> 
> ```
> Buscar dos números que:
> - Sumen b
> - Multipliquen c
> 
> x² + bx + c = (x + m)(x + n)
> donde m + n = b y m·n = c
> ```
> 
> **Ejemplo:**
> 
> ```
> x² + 5x + 6 = 0
> 
> Buscar m, n tal que: m + n = 5 y m·n = 6
> → m = 2, n = 3
> 
> (x + 2)(x + 3) = 0
> 
> x + 2 = 0  o  x + 3 = 0
> x = -2     o  x = -3
> 
> S = {-3, -2}
> ```
> 
> **Tipo 2: ax² + bx + c (coeficiente cuadrático ≠ 1)**
> 
> ```
> Método AC:
> 1. Calcular AC = a·c
> 2. Buscar dos números que sumen b y multipliquen AC
> 3. Reescribir el término medio
> 4. Factorizar por agrupación
> ```
> 
> **Ejemplo:**
> 
> ```
> 2x² + 7x + 3 = 0
> 
> AC = 2·3 = 6
> Buscar números que sumen 7 y multipliquen 6: 6 y 1
> 
> 2x² + 6x + 1x + 3 = 0
> 2x(x + 3) + 1(x + 3) = 0
> (2x + 1)(x + 3) = 0
> 
> 2x + 1 = 0  o  x + 3 = 0
> x = -1/2    o  x = -3
> 
> S = {-3, -1/2}
> ```
> 
> **Tipo 3: Diferencia de cuadrados**
> 
> ```
> x² - a² = 0
> (x - a)(x + a) = 0
> 
> x = a  o  x = -a
> ```
> 
> **Ejemplo:**
> 
> ```
> 4x² - 9 = 0
> (2x)² - 3² = 0
> (2x - 3)(2x + 3) = 0
> 
> x = 3/2  o  x = -3/2
> 
> S = {-3/2, 3/2}
> ```
> 
> **Tipo 4: Trinomio cuadrado perfecto**
> 
> ```
> x² + 2ax + a² = (x + a)²
> x² - 2ax + a² = (x - a)²
> ```
> 
> **Ejemplo:**
> 
> ```
> x² - 6x + 9 = 0
> (x - 3)² = 0
> x - 3 = 0
> x = 3 (solución doble)
> 
> S = {3}
> ```

### Método 2: Completar el Cuadrado

> [!tip]- Técnica de Completación
> 
> **Principio:** Transformar ax² + bx + c en a(x - h)² + k
> 
> **Algoritmo:**
> 
> ```
> Dado: ax² + bx + c = 0
> 
> Paso 1: Dividir por a (si a ≠ 1)
> x² + (b/a)x + c/a = 0
> 
> Paso 2: Mover el término constante
> x² + (b/a)x = -c/a
> 
> Paso 3: Completar el cuadrado
> x² + (b/a)x + (b/2a)² = -c/a + (b/2a)²
> 
> Paso 4: Factorizar el lado izquierdo
> (x + b/2a)² = -c/a + b²/4a²
> 
> Paso 5: Simplificar el lado derecho
> (x + b/2a)² = (b² - 4ac)/4a²
> 
> Paso 6: Extraer raíz cuadrada
> x + b/2a = ±√[(b² - 4ac)/4a²]
> 
> Paso 7: Despejar x
> x = -b/2a ± √(b² - 4ac)/2a
> ```

> [!example]- Ejemplos Paso a Paso
> 
> **Ejemplo 1:**
> 
> ```
> x² + 6x + 5 = 0
> 
> x² + 6x = -5
> x² + 6x + 9 = -5 + 9    (agregando (6/2)² = 9)
> (x + 3)² = 4
> x + 3 = ±2
> 
> x + 3 = 2   o   x + 3 = -2
> x = -1      o   x = -5
> 
> S = {-5, -1}
> ```
> 
> **Ejemplo 2: Con coeficiente a ≠ 1**
> 
> ```
> 2x² - 8x + 6 = 0
> 
> x² - 4x + 3 = 0         (dividiendo por 2)
> x² - 4x = -3
> x² - 4x + 4 = -3 + 4    (agregando (-4/2)² = 4)
> (x - 2)² = 1
> x - 2 = ±1
> 
> x = 2 + 1 = 3   o   x = 2 - 1 = 1
> 
> S = {1, 3}
> ```
> 
> **Ejemplo 3: Sin soluciones reales**
> 
> ```
> x² + 2x + 5 = 0
> 
> x² + 2x = -5
> x² + 2x + 1 = -5 + 1
> (x + 1)² = -4
> 
> No tiene solución real (√-4 no existe en ℝ)
> 
> S = ∅
> ```

### Método 3: Fórmula General (Cuadrática)

> [!success]- Fórmula de Bhaskara
> 
> **Teorema:** Para la ecuación ax² + bx + c = 0 con a ≠ 0:
> 
> ```
> x = (-b ± √(b² - 4ac)) / 2a
> ```
> 
> **Discriminante:**
> 
> ```
> Δ = b² - 4ac
> 
> Determina el número y tipo de soluciones:
> 
> Δ > 0:  Dos soluciones reales distintas
> Δ = 0:  Una solución real (doble)
> Δ < 0:  Sin soluciones reales (dos complejas conjugadas)
> ```
> 
> **Fórmulas derivadas:**
> 
> ```
> x₁ = (-b + √Δ) / 2a
> x₂ = (-b - √Δ) / 2a
> 
> O en forma compacta: x = (-b ± √Δ) / 2a
> ```

> [!example]- Aplicación de la Fórmula
> 
> **Ejemplo 1: Dos soluciones**
> 
> ```
> 2x² - 5x + 2 = 0
> 
> a = 2, b = -5, c = 2
> 
> Δ = (-5)² - 4(2)(2) = 25 - 16 = 9
> 
> x = (5 ± √9) / 4 = (5 ± 3) / 4
> 
> x₁ = (5 + 3) / 4 = 2
> x₂ = (5 - 3) / 4 = 1/2
> 
> S = {1/2, 2}
> ```
> 
> **Ejemplo 2: Una solución**
> 
> ```
> x² - 4x + 4 = 0
> 
> a = 1, b = -4, c = 4
> 
> Δ = (-4)² - 4(1)(4) = 16 - 16 = 0
> 
> x = 4 / 2 = 2
> 
> S = {2} (solución doble)
> ```
> 
> **Ejemplo 3: Sin solución real**
> 
> ```
> x² + x + 1 = 0
> 
> a = 1, b = 1, c = 1
> 
> Δ = 1² - 4(1)(1) = 1 - 4 = -3 < 0
> 
> S = ∅ (en ℝ)
> ```
> 
> **Ejemplo 4: Coeficientes fraccionarios**
> 
> ```
> (1/2)x² - x - 3/2 = 0
> 
> Multiplicar por 2: x² - 2x - 3 = 0
> 
> a = 1, b = -2, c = -3
> 
> Δ = (-2)² - 4(1)(-3) = 4 + 12 = 16
> 
> x = (2 ± √16) / 2 = (2 ± 4) / 2
> 
> x₁ = 6/2 = 3
> x₂ = -2/2 = -1
> 
> S = {-1, 3}
> ```

### Análisis del Discriminante

> [!important]- Interpretación Geométrica
> 
> **El discriminante Δ = b² - 4ac indica:**
> 
> ```
> Δ > 0: La parábola corta el eje x en dos puntos
>        ___
>       /   \___
>   ___/        \___
>     x₁    x₂
> 
> Δ = 0: La parábola es tangente al eje x (vértice en x)
>        ___
>       /   \___
>   ___/        \___
>          x
> 
> Δ < 0: La parábola no corta el eje x
>      \___/
>       \ /
>        ∨
>   _______________
> ```
> 
> **Casos especiales:**
> 
> ```
> Δ = k² (cuadrado perfecto): Soluciones racionales
> Δ > 0 pero no cuadrado perfecto: Soluciones irracionales
> ```
> 
> **Ejemplo de análisis sin resolver:**
> 
> ```
> Determinar cuántas soluciones tiene: 3x² - 5x + k = 0
> para diferentes valores de k.
> 
> Δ = (-5)² - 4(3)(k) = 25 - 12k
> 
> Dos soluciones: 25 - 12k > 0  →  k < 25/12
> Una solución:   25 - 12k = 0  →  k = 25/12
> Sin solución:   25 - 12k < 0  →  k > 25/12
> ```

### Relaciones entre Raíces y Coeficientes

> [!note]- Fórmulas de Vieta
> 
> **Teorema:** Si x₁ y x₂ son las raíces de ax² + bx + c = 0, entonces:
> 
> ```
> Suma de raíces:      x₁ + x₂ = -b/a
> Producto de raíces:  x₁ · x₂ = c/a
> ```
> 
> **Demostración:**
> 
> ```
> De la fórmula cuadrática:
> x₁ = (-b + √Δ)/2a
> x₂ = (-b - √Δ)/2a
> 
> Suma: x₁ + x₂ = (-b + √Δ)/2a + (-b - √Δ)/2a 
>               = -2b/2a = -b/a ✓
> 
> Producto: x₁·x₂ = [(-b + √Δ)/2a][(-b - √Δ)/2a]
>                 = [(-b)² - (√Δ)²]/4a²
>                 = (b² - Δ)/4a²
>                 = (b² - b² + 4ac)/4a²
>                 = 4ac/4a² = c/a ✓
> ```
> 
> **Aplicaciones:**
> 
> **1. Verificar soluciones sin calcularlas:**
> 
> ```
> 2x² - 7x + 3 = 0
> 
> Suma de raíces: -(-7)/2 = 7/2
> Producto: 3/2
> 
> Si x₁ = 3 y x₂ = 1/2:
> 3 + 1/2 = 7/2 ✓
> 3 · 1/2 = 3/2 ✓
> ```
> 
> **2. Encontrar ecuación dado raíces:**
> 
> ```
> Si las raíces son x₁ = 2 y x₂ = -3:
> 
> Suma: 2 + (-3) = -1 = -b/a  →  b/a = 1
> Producto: 2·(-3) = -6 = c/a
> 
> Tomando a = 1: b = 1, c = -6
> 
> Ecuación: x² + x - 6 = 0
> ```
> 
> **3. Encontrar una raíz conociendo la otra:**
> 
> ```
> Si x² - 5x + 6 = 0 tiene una raíz x₁ = 2:
> 
> x₁ + x₂ = 5  →  2 + x₂ = 5  →  x₂ = 3
> 
> Verificación: 2·3 = 6 = c/a ✓
> ```

### Ecuaciones Reducibles a Cuadráticas

> [!tip]- Ecuaciones Bicuadradas
> 
> **Forma:** ax⁴ + bx² + c = 0
> 
> **Método:** Sustitución u = x²
> 
> ```
> au² + bu + c = 0
> 
> Resolver para u, luego x² = u
> ```

> [!example]- Ejemplos de Bicuadradas
> 
> **Ejemplo 1:**
> 
> ```
> x⁴ - 5x² + 4 = 0
> 
> Sea u = x²:
> u² - 5u + 4 = 0
> (u - 1)(u - 4) = 0
> u = 1  o  u = 4
> 
> Regresando a x:
> x² = 1  →  x = ±1
> x² = 4  →  x = ±2
> 
> S = {-2, -1, 1, 2}
> 
> Verificación: (-2)⁴ - 5(-2)² + 4 = 16 - 20 + 4 = 0 ✓
> ```
> 
> **Ejemplo 2:**
> 
> ```
> 2x⁴ - 3x² - 2 = 0
> 
> Sea u = x²:
> 2u² - 3u - 2 = 0
> (2u + 1)(u - 2) = 0
> u = -1/2  o  u = 2
> 
> Regresando a x:
> x² = -1/2  →  sin solución real
> x² = 2     →  x = ±√2
> 
> S = {-√2, √2}
> ```

### Aplicaciones de Ecuaciones Cuadráticas

> [!example]- Problemas del Mundo Real
> 
> **Problema 1: Geometría**
> 
> ```
> Un rectángulo tiene perímetro 28 cm y área 48 cm².
> Encuentra sus dimensiones.
> 
> Variables:
> x = largo
> y = ancho
> 
> Ecuaciones:
> 2x + 2y = 28  →  x + y = 14  →  y = 14 - x
> xy = 48
> 
> Sustituyendo:
> x(14 - x) = 48
> 14x - x² = 48
> x² - 14x + 48 = 0
> (x - 6)(x - 8) = 0
> 
> x = 6  o  x = 8
> 
> Si x = 6: y = 8
> Si x = 8: y = 6
> 
> Dimensiones: 6 cm × 8 cm
> ```
> 
> **Problema 2: Movimiento**
> 
> ```
> Un objeto se lanza verticalmente con velocidad inicial 
> v₀ = 20 m/s. Su altura está dada por:
> h(t) = -5t² + 20t
> 
> ¿Cuándo toca el suelo (h = 0)?
> 
> -5t² + 20t = 0
> -5t(t - 4) = 0
> t = 0  o  t = 4
> 
> Respuesta: En t = 4 segundos
> (t = 0 es el instante inicial)
> ```
> 
> **Problema 3: Números consecutivos**
> 
> ```
> El producto de dos números enteros consecutivos es 132.
> ¿Cuáles son los números?
> 
> Variables:
> x = primer número
> x + 1 = segundo número
> 
> Ecuación:
> x(x + 1) = 132
> x² + x - 132 = 0
> (x + 12)(x - 11) = 0
> 
> x = -12  o  x = 11
> 
> Soluciones:
> {-12, -11} o {11, 12}
> ```
> 
> **Problema 4: Optimización**
> 
> ```
> Se tiene 40 m de cerca para encerrar un área rectangular 
> contra una pared (que no necesita cerca). ¿Qué dimensiones
> maximizan el área?
> 
> Variables:
> x = ancho perpendicular a la pared
> y = largo paralelo a la pared
> 
> Restricción: 2x + y = 40  →  y = 40 - 2x
> Área: A = xy = x(40 - 2x) = 40x - 2x²
> 
> El área es cuadrática en x. Máximo en el vértice:
> x = -b/2a = -40/(2·(-2)) = 10
> 
> y = 40 - 2(10) = 20
> 
> Dimensiones óptimas: 10 m × 20 m
> Área máxima: 200 m²
> ```

## √ Ecuaciones con Radicales

### Principios Básicos

> [!success]- Método de Resolución
> 
> **Estrategia general:**
> 
> 1. Aislar el radical en un lado
> 2. Elevar ambos lados a la potencia adecuada
> 3. Resolver la ecuación resultante
> 4. **SIEMPRE verificar** (pueden aparecer soluciones extrañas)
> 
> **Por qué aparecen soluciones extrañas:**
> 
> ```
> Elevar al cuadrado no es operación equivalente:
> 
> x = 2  ⟹  x² = 4  (correcto)
> x² = 4  ⟹̸  x = 2  (incorrecto, también x = -2)
> 
> Al elevar al cuadrado, perdemos información del signo
> ```

> [!example]- Casos Básicos
> 
> **Tipo 1: Un solo radical**
> 
> ```
> √(x + 5) = 3
> 
> (√(x + 5))² = 3²
> x + 5 = 9
> x = 4
> 
> Verificación: √(4 + 5) = √9 = 3 ✓
> 
> S = {4}
> ```
> 
> **Tipo 2: Radical = expresión con x**
> 
> ```
> √(x + 12) = x
> 
> Restricción inicial: x ≥ 0 (lado derecho debe ser ≥ 0)
> 
> x + 12 = x²
> x² - x - 12 = 0
> (x - 4)(x + 3) = 0
> x = 4  o  x = -3
> 
> Verificación:
> x = 4:  √(4 + 12) = √16 = 4 ✓
> x = -3: √(-3 + 12) = √9 = 3 ≠ -3 ✗
> 
> S = {4}
> ```
> 
> **Tipo 3: Raíz cúbica**
> 
> ```
> ∛(2x - 1) = 3
> 
> 2x - 1 = 27
> 2x = 28
> x = 14
> 
> Verificación: ∛(2(14) - 1) = ∛27 = 3 ✓
> 
> S = {14}
> 
> Nota: Las raíces impares no requieren restricciones
> ```

### Ecuaciones con Múltiples Radicales

> [!tip]- Estrategia de Aislamiento Sucesivo
> 
> **Principio:** Aislar y eliminar un radical a la vez
> 
> **Algoritmo:**
> 
> 1. Aislar uno de los radicales
> 2. Elevar a la potencia adecuada
> 3. Simplificar
> 4. Si quedan radicales, repetir desde paso 1
> 5. Resolver la ecuación resultante
> 6. Verificar todas las soluciones candidatas

> [!example]- Ejemplos Detallados
> 
> **Ejemplo 1: Dos radicales**
> 
> ```
> √(x + 7) = √(2x - 5)
> 
> Elevar al cuadrado ambos lados:
> x + 7 = 2x - 5
> 12 = x
> 
> Verificación: √(12 + 7) = √19, √(2·12 - 5) = √19 ✓
> 
> S = {12}
> ```
> 
> **Ejemplo 2: Suma de radicales**
> 
> ```
> √x + √(x - 5) = 5
> 
> Paso 1: Aislar un radical
> √x = 5 - √(x - 5)
> 
> Paso 2: Elevar al cuadrado
> x = 25 - 10√(x - 5) + (x - 5)
> x = 20 + x - 10√(x - 5)
> 10√(x - 5) = 20
> √(x - 5) = 2
> 
> Paso 3: Elevar al cuadrado nuevamente
> x - 5 = 4
> x = 9
> 
> Verificación: √9 + √(9 - 5) = 3 + √4 = 3 + 2 = 5 ✓
> 
> S = {9}
> ```
> 
> **Ejemplo 3: Radical en ambos lados**
> 
> ```
> √(3x + 1) = √(x + 2) + 1
> 
> Aislar: √(3x + 1) - √(x + 2) = 1
> 
> Reorganizar: √(3x + 1) = 1 + √(x + 2)
> 
> Elevar al cuadrado:
> 3x + 1 = 1 + 2√(x + 2) + x + 2
> 3x + 1 = 3 + x + 2√(x + 2)
> 2x - 2 = 2√(x + 2)
> x - 1 = √(x + 2)
> 
> Elevar al cuadrado:
> (x - 1)² = x + 2
> x² - 2x + 1 = x + 2
> x² - 3x - 1 = 0
> 
> Fórmula cuadrática:
> x = (3 ± √(9 + 4))/2 = (3 ± √13)/2
> 
> x₁ = (3 + √13)/2 ≈ 3.303
> x₂ = (3 - √13)/2 ≈ -0.303
> 
> Verificación x₁:
> √(3·3.303 + 1) ≈ √10.909 ≈ 3.303
> √(3.303 + 2) + 1 ≈ √5.303 + 1 ≈ 2.303 + 1 = 3.303 ✓
> 
> Verificación x₂:
> √(3·(-0.303) + 1) ≈ √0.091 ≈ 0.303
> √(-0.303 + 2) + 1 ≈ √1.697 + 1 ≈ 1.303 + 1 = 2.303 ✗
> 
> S = {(3 + √13)/2}
> ```
> 
> **Ejemplo 4: Tres radicales**
> 
> ```
> √x + √(x + 1) + √(x + 2) = 4
> 
> (Ejercicio complejo, requiere aislamiento múltiple)
> Estrategia: Aislar √x y √(x + 2) en un lado,
> √(x + 1) en el otro
> ```

### Ecuaciones con Radicales Anidados

> [!note]- Radicales Dentro de Radicales
> 
> **Ejemplo:**
> 
> ```
> √(x + √(x + 6)) = 4
> 
> Elevar al cuadrado:
> x + √(x + 6) = 16
> √(x + 6) = 16 - x
> 
> Restricción: 16 - x ≥ 0  →  x ≤ 16
> 
> Elevar al cuadrado:
> x + 6 = (16 - x)²
> x + 6 = 256 - 32x + x²
> 0 = x² - 33x + 250
> 
> Fórmula cuadrática:
> x = (33 ± √(1089 - 1000))/2 = (33 ± √89)/2
> 
> x₁ = (33 + √89)/2 ≈ 21.22 > 16 ✗ (fuera de restricción)
> x₂ = (33 - √89)/2 ≈ 11.78 ≤ 16 ✓
> 
> Verificación x₂ ≈ 11.78:
> √(11.78 + √(11.78 + 6)) = √(11.78 + √17.78)
>                         ≈ √(11.78 + 4.22)
>                         ≈ √16 = 4 ✓
> 
> S = {(33 - √89)/2}
> ```

## 🔗 Sistemas de Ecuaciones

### Sistemas Lineales 2×2

> [!success]- Métodos de Resolución
> 
> **Sistema general:**
> 
> ```
> { a₁x + b₁y = c₁
> { a₂x + b₂y = c₂
> ```
> 
> **Interpretación geométrica:**
> 
> - Cada ecuación representa una recta
> - La solución es la intersección de las rectas
> - Puede haber 1, 0 o infinitas soluciones

### Método 1: Sustitución

> [!example]- Algoritmo de Sustitución
> 
> **Pasos:**
> 
> 1. Despejar una variable de una ecuación
> 2. Sustituir en la otra ecuación
> 3. Resolver para la variable restante
> 4. Sustituir hacia atrás para encontrar la otra variable
> 
> **Ejemplo:**
> 
> ```
> { 2x + y = 8      ... (1)
> { x - y = 1       ... (2)
> 
> De (2): x = y + 1
> 
> Sustituyendo en (1):
> 2(y + 1) + y = 8
> 2y + 2 + y = 8
> 3y = 6
> y = 2
> 
> Regresando a x:
> x = 2 + 1 = 3
> 
> Solución: (3, 2)
> 
> Verificación:
> 2(3) + 2 = 6 + 2 = 8 ✓
> 3 - 2 = 1 ✓
> ```

### Método 2: Igualación

> [!example]- Algoritmo de Igualación
> 
> **Pasos:**
> 
> 1. Despejar la misma variable de ambas ecuaciones
> 2. Igualar las expresiones
> 3. Resolver para la variable restante
> 4. Sustituir para encontrar la otra variable
> 
> **Ejemplo:**
> 
> ```
> { 3x + 2y = 12    ... (1)
> { 2x - y = 1      ... (2)
> 
> Despejando y de (1): y = (12 - 3x)/2
> Despejando y de (2): y = 2x - 1
> 
> Igualando:
> (12 - 3x)/2 = 2x - 1
> 12 - 3x = 4x - 2
> 14 = 7x
> x = 2
> 
> Sustituyendo:
> y = 2(2) - 1 = 3
> 
> Solución: (2, 3)
> ```

### Método 3: Eliminación (Reducción)

> [!example]- Algoritmo de Eliminación
> 
> **Pasos:**
> 
> 1. Multiplicar ecuaciones para igualar coeficientes
> 2. Sumar o restar para eliminar una variable
> 3. Resolver para la variable restante
> 4. Sustituir para encontrar la otra variable
> 
> **Ejemplo:**
> 
> ```
> { 3x + 2y = 13    ... (1)
> { 2x - y = 4      ... (2)
> 
> Multiplicar (2) por 2:
> { 3x + 2y = 13    ... (1)
> { 4x - 2y = 8     ... (2')
> 
> Sumar (1) + (2'):
> 7x = 21
> x = 3
> 
> Sustituyendo en (2):
> 2(3) - y = 4
> 6 - y = 4
> y = 2
> 
> Solución: (3, 2)
> ```

### Casos Especiales

> [!warning]- Sistemas Inconsistentes e Indeterminados
> 
> **Caso 1: Sin solución (rectas paralelas)**
> 
> ```
> { x + 2y = 5
> { x + 2y = 8
> 
> Restando:
> 0 = -3  (contradicción)
> 
> S = ∅
> 
> Las rectas tienen la misma pendiente pero diferente 
> ordenada al origen (paralelas)
> ```
> 
> **Caso 2: Infinitas soluciones (misma recta)**
> 
> ```
> { 2x + 4y = 8
> { x + 2y = 4
> 
> La segunda ecuación es la primera dividida por 2
> Son la misma recta
> 
> S = {(x, y) : x + 2y = 4}
> 
> En forma paramétrica: y = t, x = 4 - 2t con t ∈ ℝ
> ```
> 
> **Caso 3: Solución única (rectas secantes)**
> 
> ```
> Ocurre cuando las rectas tienen pendientes diferentes
> Es el caso "normal"
> ```

### Sistemas No Lineales

> [!tip]- Sistemas con Ecuaciones Cuadráticas
> 
> **Ejemplo 1: Lineal + Cuadrática**
> 
> ```
> { y = x + 1           ... (1)
> { x² + y² = 13        ... (2)
> 
> Sustituyendo (1) en (2):
> x² + (x + 1)² = 13
> x² + x² + 2x + 1 = 13
> 2x² + 2x - 12 = 0
> x² + x - 6 = 0
> (x + 3)(x - 2) = 0
> 
> x = -3  o  x = 2
> 
> Si x = -3: y = -3 + 1 = -2  →  (-3, -2)
> Si x = 2:  y = 2 + 1 = 3    →  (2, 3)
> 
> Soluciones: (-3, -2) y (2, 3)
> 
> Interpretación: Intersección de recta y círculo
> ```
> 
> **Ejemplo 2: Dos ecuaciones cuadráticas**
> 
> ```
> { x² + y² = 25        ... (1)
> { x² - y² = 7         ... (2)
> 
> Sumando (1) + (2):
> 2x² = 32
> x² = 16
> x = ±4
> 
> De (2): y² = x² - 7
> 
> Si x = 4:  y² = 16 - 7 = 9  →  y = ±3
> Si x = -4: y² = 16 - 7 = 9  →  y = ±3
> 
> Soluciones: (4, 3), (4, -3), (-4, 3), (-4, -3)
> 
> Interpretación: Intersección de círculo e hipérbola
> ```
> 
> **Ejemplo 3: Sistema con valor absoluto**
> 
> ```
> { |x| + |y| = 4
> { x + y = 2
> 
> De la segunda: y = 2 - x
> 
> Sustituyendo en la primera:
> |x| + |2 - x| = 4
> 
> Análisis por casos (puntos críticos: x = 0, x = 2):
> 
> Caso x < 0:
> -x + (2 - x) = 4  →  -2x = 2  →  x = -1
> y = 2 - (-1) = 3  →  (-1, 3) ✓
> 
> Caso 0 ≤ x < 2:
> x + (2 - x) = 4  →  2 = 4  (imposible)
> 
> Caso x ≥ 2:
> x + (x - 2) = 4  →  2x = 6  →  x = 3
> y = 2 - 3 = -1  →  (3, -1) ✓
> 
> Soluciones: (-1, 3) y (3, -1)
> ```

## 📊 Ecuaciones Paramétricas

### Ecuaciones con Parámetros

> [!note]- Análisis según Valores del Parámetro
> 
> **Definición:** Ecuación que contiene uno o más parámetros además de la incógnita
> 
> **Objetivo:** Determinar para qué valores del parámetro la ecuación tiene ciertas propiedades

> [!example]- Ejemplos con Parámetros
> 
> **Ejemplo 1: Ecuación lineal con parámetro**
> 
> ```
> kx + 3 = 2x + k
> 
> (k - 2)x = k - 3
> 
> Análisis:
> 
> Si k ≠ 2: x = (k - 3)/(k - 2)  (solución única)
> 
> Si k = 2: 0 = 2 - 3 = -1  (contradicción, sin solución)
> 
> Respuesta:
> k ≠ 2: S = {(k - 3)/(k - 2)}
> k = 2: S = ∅
> ```
> 
> **Ejemplo 2: Ecuación cuadrática con parámetro**
> 
> ```
> x² + 2kx + (k - 2) = 0
> 
> Determinar k para que tenga:
> a) Dos soluciones reales distintas
> b) Una solución doble
> c) Sin soluciones reales
> 
> Discriminante: Δ = (2k)² - 4(1)(k - 2)
>                  = 4k² - 4k + 8
>                  = 4(k² - k + 2)
> 
> Analizando k² - k + 2:
> Completar cuadrado: (k - 1/2)² - 1/4 + 2 = (k - 1/2)² + 7/4
> 
> Como (k - 1/2)² ≥ 0, entonces (k - 1/2)² + 7/4 ≥ 7/4 > 0
> 
> Por lo tanto Δ > 0 para todo k ∈ ℝ
> 
> Respuesta:
> a) Para todo k ∈ ℝ: dos soluciones distintas
> b) Ningún valor de k: una solución
> c) Ningún valor de k: sin soluciones
> ```
> 
> **Ejemplo 3: Encontrar k para solución específica**
> 
> ```
> x² - kx + 2k = 0 tiene una raíz x = 4
> 
> Sustituyendo x = 4:
> 16 - 4k + 2k = 0
> 16 - 2k = 0
> k = 8
> 
> Con k = 8: x² - 8x + 16 = 0
>           (x - 4)² = 0
>           x = 4 (solución doble)
> 
> Respuesta: k = 8
> ```
> 
> **Ejemplo 4: Suma de raíces dada**
> 
> ```
> x² + kx + 12 = 0
> 
> Determinar k si la suma de las raíces es 7
> 
> Por fórmulas de Vieta: x₁ + x₂ = -k/1 = -k
> 
> Condición: -k = 7  →  k = -7
> 
> Verificación con producto:
> x₁·x₂ = 12/1 = 12
> 
> Con k = -7: x² - 7x + 12 = 0
>            (x - 3)(x - 4) = 0
>            x = 3, x = 4
>            
> Suma: 3 + 4 = 7 ✓
> Producto: 3·4 = 12 ✓
> 
> Respuesta: k = -7
> ```

## ⚠️ Errores Comunes

> [!warning]- Confusiones y Equivocaciones Frecuentes
> 
> **1. Perder soluciones al dividir**
> 
> ```
> ✗ INCORRECTO:
> x² = 3x
> x = 3  (dividiendo por x)
> 
> ✓ CORRECTO:
> x² - 3x = 0
> x(x - 3) = 0
> x = 0  o  x = 3
> 
> Se perdió x = 0 al dividir por x
> ```
> 
> **2. No verificar soluciones de radicales**
> 
> ```
> ✗ INCORRECTO:
> √x = -2
> x = 4  (elevando al cuadrado)
> 
> ✓ CORRECTO:
> √x = -2
> S = ∅
> 
> Razón: √x ≥ 0 siempre, no puede ser -2
> ```
> 
> **3. Olvidar ± al extraer raíz cuadrada**
> 
> ```
> ✗ INCORRECTO:
> x² = 9
> x = 3
> 
> ✓ CORRECTO:
> x² = 9
> x = ±3
> ```
> 
> **4. Error en discriminante**
> 
> ```
> Para x² - 6x + 9 = 0:
> 
> ✗ INCORRECTO:
> Δ = 6² - 4(1)(9) = 36 - 36 = 0
> (olvidó el signo de b)
> 
> ✓ CORRECTO:
> Δ = (-6)² - 4(1)(9) = 36 - 36 = 0
> ```
> 
> **5. Manipulación incorrecta de valor absoluto**
> 
> ```
> ✗ INCORRECTO:
> |x + 2| = 3
> x + 2 = 3
> x = 1
> 
> ✓ CORRECTO:
> |x + 2| = 3
> x + 2 = 3  o  x + 2 = -3
> x = 1     o  x = -5
> ```
> 
> **6. Elevar ecuación sin aislar radical**
> 
> ```
> ✗ INCORRECTO:
> √x + 1 = 3
> x + 1 = 9
> x = 8
> 
> ✓ CORRECTO:
> √x + 1 = 3
> √x = 2
> x = 4
> 
> O bien: (√x + 1)² = 9
>        x + 2√x + 1 = 9
>        (más complicado)
> ```
> 
> **7. Factorización incorrecta**
> 
> ```
> ✗ INCORRECTO:
> x² + 5x + 6 = 0
> (x + 2)(x + 4) = 0  (producto: 8 ≠ 6)
> 
> ✓ CORRECTO:
> x² + 5x + 6 = 0
> (x + 2)(x + 3) = 0
> 
> Verificar: 2 + 3 = 5 ✓, 2·3 = 6 ✓
> ```
> 
> **8. Confundir solución con verificación**
> 
> ```
> Resolver ≠ Verificar
> 
> Resolver: Encontrar todos los candidatos
> Verificar: Confirmar cuáles son válidos
> 
> Siempre hacer ambos pasos
> ```

## 🎓 Ejercicios Resueltos Completos

> [!example]- Problemas Integradores
> 
> **Ejercicio 1: Ecuación con múltiples técnicas**
> 
> ```
> Resolver: (x² - 4)/(x - 2) = x + 2
> 
> Solución:
> 
> Restricción: x ≠ 2 (denominador no puede ser cero)
> 
> Simplificando el lado izquierdo:
> (x² - 4)/(x - 2) = (x - 2)(x + 2)/(x - 2) = x + 2  (si x ≠ 2)
> 
> La ecuación se convierte en:
> x + 2 = x + 2
> 
> Esta es una identidad para todo x ≠ 2
> 
> S = ℝ \ {2} = (-∞, 2) ∪ (2, ∞)
> 
> Interpretación: Cualquier número excepto 2 es solución
> ```
> 
> **Ejercicio 2: Problema de optimización**
> 
> ```
> Un granjero tiene 100 m de cerca y quiere encerrar un área
> rectangular máxima usando un río como uno de los lados 
> (no necesita cerca en ese lado). ¿Qué dimensiones debe usar?
> 
> Solución:
> 
> Variables:
> x = ancho (perpendicular al río)
> y = largo (paralelo al río)
> 
> Restricción: 2x + y = 100  →  y = 100 - 2x
> 
> Área: A(x) = xy = x(100 - 2x) = 100x - 2x²
> 
> Esta es una parábola que abre hacia abajo.
> Máximo en el vértice:
> 
> x = -b/(2a) = -100/(2·(-2)) = 100/4 = 25
> 
> y = 100 - 2(25) = 50
> 
> Área máxima: A(25) = 25·50 = 1250 m²
> 
> Respuesta: 25 m × 50 m
> ```
> 
> **Ejercicio 3: Sistema no lineal**
> 
> ```
> Resolver:
> { xy = 12
> { x + y = 7
> 
> Solución:
> 
> De la segunda ecuación: y = 7 - x
> 
> Sustituyendo en la primera:
> x(7 - x) = 12
> 7x - x² = 12
> x² - 7x + 12 = 0
> (x - 3)(x - 4) = 0
> 
> x = 3  o  x = 4
> 
> Si x = 3: y = 7 - 3 = 4  →  (3, 4)
> Si x = 4: y = 7 - 4 = 3  →  (4, 3)
> 
> Verificación:
> (3, 4): 3·4 = 12 ✓, 3 + 4 = 7 ✓
> (4, 3): 4·3 = 12 ✓, 4 + 3 = 7 ✓
> 
> Soluciones: (3, 4) y (4, 3)
> ```
> 
> **Ejercicio 4: Ecuación con radicales complejos**
> 
> ```
> Resolver: √(2x + 3) - √(x - 2) = 2
> 
> Solución:
> 
> Restricciones: 2x + 3 ≥ 0 y x - 2 ≥ 0
>               x ≥ -3/2 y x ≥ 2
>               Por tanto: x ≥ 2
> 
> Paso 1: Aislar un radical
> √(2x + 3) = 2 + √(x - 2)
> 
> Paso 2: Elevar al cuadrado
> 2x + 3 = 4 + 4√(x - 2) + (x - 2)
> 2x + 3 = 2 + x + 4√(x - 2)
> x + 1 = 4√(x - 2)
> 
> Paso 3: Elevar al cuadrado nuevamente
> (x + 1)² = 16(x - 2)
> x² + 2x + 1 = 16x - 32
> x² - 14x + 33 = 0
> (x - 3)(x - 11) = 0
> 
> x = 3  o  x = 11
> 
> Verificación x = 3:
> √(2·3 + 3) - √(3 - 2) = √9 - √1 = 3 - 1 = 2 ✓
> 
> Verificación x = 11:
> √(2·11 + 3) - √(11 - 2) = √25 - √9 = 5 - 3 = 2 ✓
> 
> Ambas válidas: S = {3, 11}
> ```
> 
> **Ejercicio 5: Ecuación con parámetro**
> 
> ```
> Para qué valores de m la ecuación x² - 2mx + m² - 1 = 0
> tiene dos raíces reales cuyo producto sea 3.
> 
> Solución:
> 
> Por fórmulas de Vieta:
> Producto de raíces: x₁·x₂ = c/a = (m² - 1)/1 = m² - 1
> 
> Condición: m² - 1 = 3
>           m² = 4
>           m = ±2
> 
> Verificar que hay dos raíces distintas (Δ > 0):
> 
> Para m = 2:
> Δ = (-2·2)² - 4(1)(2² - 1) = 16 - 12 = 4 > 0 ✓
> 
> Para m = -2:
> Δ = (-2·(-2))² - 4(1)((-2)² - 1) = 16 - 12 = 4 > 0 ✓
> 
> Respuesta: m = 2 o m = -2
> 
> Verificación completa para m = 2:
> x² - 4x + 3 = 0
> (x - 1)(x - 3) = 0
> x = 1, x = 3
> Producto: 1·3 = 3 ✓
> ```

## 📝 Resumen Ejecutivo

> [!success]- Puntos Clave para Recordar
> 
> **Conceptos fundamentales:**
> 
> 1. **Ecuación:** Igualdad condicional con incógnita(s)
> 2. **Solución:** Valor que satisface la ecuación
> 3. **Conjunto solución:** Todos los valores que satisfacen
> 4. **Equivalencia:** Operaciones que preservan soluciones
> 
> **Tipos principales:**
> 
> ```
> Lineales:      ax + b = 0
> Cuadráticas:   ax² + bx + c = 0
> Valor absoluto: |f(x)| = a
> Radicales:     √f(x) = a
> Sistemas:      Múltiples ecuaciones simultáneas
> ```
> 
> **Métodos esenciales:**
> 
> - **Lineales:** Despejar algebraicamente
> - **Cuadráticas:** Factorización, completar cuadrado, fórmula general
> - **Valor absoluto:** Dividir en casos (±)
> - **Radicales:** Aislar y elevar a potencias (verificar)
> - **Sistemas:** Sustitución, igualación, eliminación
> 
> **Reglas de oro:**
> 
> 1. ✓ Verificar siempre las soluciones
> 2. ✓ Cuidado con operaciones no equivalentes (multiplicar por x, elevar al cuadrado)
> 3. ✓ Respetar restricciones del dominio
> 4. ✓ No dividir entre expresiones con la variable sin verificar ≠ 0
> 5. ✓ En radicales pares, verificar soluciones extrañas
> 
> **Fórmulas clave:**
> 
> ```
> Cuadrática: x = (-b ± √(b² - 4ac))/(2a)
> 
> Discriminante: Δ = b² - 4ac
>   Δ > 0: dos soluciones
>   Δ = 0: una solución
>   Δ < 0: sin soluciones reales
> 
> Vieta: x₁ + x₂ = -b/a
>        x₁ · x₂ = c/a
> ```

## 🎯 Estrategias de Resolución

> [!tip]- Guía General de Estrategia
> 
> **Paso 1: Identificar el tipo**
> 
> ```
> ¿Qué tipo de ecuación es?
> - Lineal → método directo
> - Cuadrática → factorización o fórmula
> - Valor absoluto → análisis por casos
> - Radical → aislar y elevar
> - Sistema → método apropiado
> ```
> 
> **Paso 2: Simplificar**
> 
> ```
> - Eliminar paréntesis
> - Combinar términos semejantes
> - Eliminar fracciones (MCM)
> - Eliminar decimales (multiplicar por potencia de 10)
> ```
> 
> **Paso 3: Resolver**
> 
> ```
> Aplicar el método apropiado según el tipo
> Mantener registro de restricciones
> ```
> 
> **Paso 4: Verificar**
> 
> ```
> Sustituir cada solución en la ecuación ORIGINAL
> Confirmar que satisface restricciones del dominio
> Descartar soluciones extrañas
> ```
> 
> **Paso 5: Expresar la respuesta**
> 
> ```
> S = {x₁, x₂, ...}  para soluciones discretas
> S = intervalo       para soluciones continuas
> S = ∅               si no hay solución
> ```

## 🧩 Problemas Desafiantes

> [!example]- Ejercicios Avanzados
> 
> **Problema 1: Ecuación exponencial-algebraica**
> 
> ```
> 2^x = x²
> 
> Este tipo no tiene solución algebraica cerrada.
> Métodos: gráfico o numérico
> 
> Análisis gráfico:
> - f(x) = 2^x crece exponencialmente
> - g(x) = x² es parábola
> 
> Soluciones aproximadas: x ≈ 2, x ≈ 4
> 
> (Requiere métodos numéricos como Newton-Raphson)
> ```
> 
> **Problema 2: Ecuación funcional**
> 
> ```
> Encontrar todas las funciones f: ℝ → ℝ tales que:
> f(x + y) = f(x) + f(y) para todo x, y ∈ ℝ
> f(1) = 2
> 
> Solución:
> 
> Esta es la ecuación de Cauchy.
> Para f continua: f(x) = cx
> 
> Con f(1) = 2: c·1 = 2, entonces c = 2
> 
> Respuesta: f(x) = 2x
> 
> Verificación:
> f(x + y) = 2(x + y) = 2x + 2y = f(x) + f(y) ✓
> f(1) = 2·1 = 2 ✓
> ```
> 
> **Problema 3: Sistema no lineal complejo**
> 
> ```
> { x³ + y³ = 35
> { x + y = 5
> 
> Solución usando identidad algebraica:
> 
> Sabemos: (x + y)³ = x³ + 3x²y + 3xy² + y³
>                    = x³ + y³ + 3xy(x + y)
> 
> De la segunda ecuación: x + y = 5
> 
> Sustituyendo en la identidad:
> 5³ = 35 + 3xy(5)
> 125 = 35 + 15xy
> 90 = 15xy
> xy = 6
> 
> Ahora tenemos:
> { x + y = 5
> { xy = 6
> 
> Estas son suma y producto de raíces de:
> t² - 5t + 6 = 0
> (t - 2)(t - 3) = 0
> t = 2 o t = 3
> 
> Por tanto: x = 2, y = 3 o x = 3, y = 2
> 
> Soluciones: (2, 3) y (3, 2)
> 
> Verificación:
> 2³ + 3³ = 8 + 27 = 35 ✓
> 2 + 3 = 5 ✓
> ```
> 
> **Problema 4: Ecuación con múltiples radicales**
> 
> ```
> √(x + √(2x - 1)) + √(x - √(2x - 1)) = √6
> 
> Estrategia: Elevar al cuadrado
> 
> Sea u = √(x + √(2x - 1))
> Sea v = √(x - √(2x - 1))
> 
> Entonces: u + v = √6 ... (1)
> 
> Calculando u²·v²:
> u²·v² = [x + √(2x - 1)][x - √(2x - 1)]
>       = x² - (2x - 1)
>       = x² - 2x + 1
>       = (x - 1)²
> 
> Por tanto: uv = |x - 1| = x - 1 (asumiendo x ≥ 1) ... (2)
> 
> De (1) y (2), u y v son raíces de:
> t² - √6·t + (x - 1) = 0
> 
> Para que tenga soluciones reales:
> Δ ≥ 0
> 6 - 4(x - 1) ≥ 0
> 6 - 4x + 4 ≥ 0
> 10 - 4x ≥ 0
> x ≤ 5/2
> 
> Además, elevando (1) al cuadrado:
> u² + 2uv + v² = 6
> (x + √(2x - 1)) + 2(x - 1) + (x - √(2x - 1)) = 6
> 2x + 2x - 2 = 6
> 4x = 8
> x = 2
> 
> Verificación: (calcular numéricamente)
> x = 2 satisface 1 ≤ x ≤ 5/2 ✓
> 
> Respuesta: x = 2
> ```
> 
> **Problema 5: Ecuación con parámetro complejo**
> 
> ```
> Determinar todos los valores de a para los cuales
> la ecuación x⁴ - 2ax² + a² - 1 = 0 tiene exactamente
> tres raíces reales distintas.
> 
> Solución:
> 
> Sea u = x²:
> u² - 2au + a² - 1 = 0
> 
> Fórmula cuadrática:
> u = (2a ± √(4a² - 4(a² - 1)))/2
>   = (2a ± √4)/2
>   = (2a ± 2)/2
>   = a ± 1
> 
> Entonces: u₁ = a + 1, u₂ = a - 1
> 
> Regresando a x:
> x² = a + 1  →  x = ±√(a + 1)
> x² = a - 1  →  x = ±√(a - 1)
> 
> Para 4 raíces reales: a + 1 > 0 y a - 1 > 0 → a > 1
> Para 2 raíces reales: solo una ecuación da reales
> Para 3 raíces reales: una da raíz doble (x = 0) y otra da dos raíces
> 
> Para 3 raíces distintas:
> - Una ecuación debe dar x = 0 (raíz doble que cuenta como una)
> - La otra debe dar dos raíces distintas
> 
> Caso 1: a - 1 = 0 y a + 1 > 0
>        a = 1 y a > -1 → a = 1
>        Raíces: 0, √2, -√2 (tres raíces) ✓
> 
> Caso 2: a + 1 = 0 y a - 1 > 0
>        a = -1 y a > 1 (imposible)
> 
> Respuesta: a = 1
> ```

## 🔍 Ecuaciones Especiales

> [!note]- Formas No Estándar
> 
> **Ecuaciones simétricas:**
> 
> ```
> Si f(x, y) = f(y, x), podemos usar u = x + y, v = xy
> 
> Ejemplo:
> { x² + y² = 10
> { x + y = 4
> 
> De (x + y)² = x² + 2xy + y²:
> 16 = 10 + 2xy
> xy = 3
> 
> x, y son raíces de: t² - 4t + 3 = 0
>                     (t - 1)(t - 3) = 0
> Soluciones: (1, 3) y (3, 1)
> ```
> 
> **Ecuaciones recíprocas:**
> 
> ```
> Si aₙxⁿ + aₙ₋₁xⁿ⁻¹ + ... + a₁x + a₀ = 0
> con aᵢ = aₙ₋ᵢ
> 
> Ejemplo: x⁴ + 3x³ + 4x² + 3x + 1 = 0
> 
> Dividir por x²: x² + 3x + 4 + 3/x + 1/x² = 0
> 
> Agrupar: (x² + 1/x²) + 3(x + 1/x) + 4 = 0
> 
> Sea u = x + 1/x:
> u² - 2 + 3u + 4 = 0
> u² + 3u + 2 = 0
> (u + 1)(u + 2) = 0
> 
> u = -1: x + 1/x = -1 → x² + x + 1 = 0 (sin solución real)
> u = -2: x + 1/x = -2 → x² + 2x + 1 = 0 → x = -1
> 
> Solución: x = -1
> ```
> 
> **Ecuaciones homogéneas:**
> 
> ```
> Todos los términos tienen el mismo grado total
> 
> Ejemplo: x² - 3xy + 2y² = 0
> 
> Dividir por y² (si y ≠ 0):
> (x/y)² - 3(x/y) + 2 = 0
> 
> Sea t = x/y:
> t² - 3t + 2 = 0
> (t - 1)(t - 2) = 0
> 
> t = 1: x/y = 1 → x = y
> t = 2: x/y = 2 → x = 2y
> 
> Soluciones: {(y, y) : y ∈ ℝ} ∪ {(2y, y) : y ∈ ℝ}
> ```

## 🎨 Aplicaciones Interdisciplinarias

> [!example]- Ecuaciones en Contexto
> 
> **Física - Cinemática:**
> 
> ```
> Movimiento uniformemente acelerado:
> s = s₀ + v₀t + (1/2)at²
> 
> Problema: Un objeto se lanza hacia arriba con v₀ = 30 m/s
> desde s₀ = 0. Gravedad: a = -10 m/s²
> ¿Cuándo alcanza altura de 40 m?
> 
> 40 = 0 + 30t + (1/2)(-10)t²
> 40 = 30t - 5t²
> 5t² - 30t + 40 = 0
> t² - 6t + 8 = 0
> (t - 2)(t - 4) = 0
> 
> t = 2 s (subida) o t = 4 s (bajada)
> ```
> 
> **Economía - Punto de equilibrio:**
> 
> ```
> Oferta: p = 2q + 10
> Demanda: p = -q + 40
> 
> Equilibrio cuando oferta = demanda:
> 2q + 10 = -q + 40
> 3q = 30
> q = 10
> 
> p = 2(10) + 10 = 30
> 
> Punto de equilibrio: (q, p) = (10, 30)
> ```
> 
> **Geometría - Intersecciones:**
> 
> ```
> Círculo: x² + y² = 25
> Recta: y = x + 1
> 
> Sustituyendo:
> x² + (x + 1)² = 25
> x² + x² + 2x + 1 = 25
> 2x² + 2x - 24 = 0
> x² + x - 12 = 0
> (x + 4)(x - 3) = 0
> 
> x = -4: y = -3 → (-4, -3)
> x = 3: y = 4 → (3, 4)
> 
> Puntos de intersección: (-4, -3) y (3, 4)
> ```
> 
> **Química - Estequiometría:**
> 
> ```
> Reacción: 2H₂ + O₂ → 2H₂O
> 
> Si tenemos 10 moles de H₂ y x moles de O₂,
> y queremos que reaccionen completamente:
> 
> Por cada 2 moles de H₂ se necesita 1 mol de O₂
> 10 moles H₂ → 5 moles O₂
> 
> Ecuación: x = 10/2 = 5
> 
> Se necesitan 5 moles de O₂
> ```
> 
> **Biología - Crecimiento poblacional:**
> 
> ```
> Modelo logístico simplificado:
> P(t) = K/(1 + Ae^(-rt))
> 
> Encontrar t cuando P(t) = K/2 (mitad de capacidad):
> 
> K/2 = K/(1 + Ae^(-rt))
> 1/2 = 1/(1 + Ae^(-rt))
> 1 + Ae^(-rt) = 2
> Ae^(-rt) = 1
> e^(-rt) = 1/A
> -rt = ln(1/A)
> t = -ln(1/A)/r = ln(A)/r
> ```

## 📖 Teoría Complementaria

> [!note]- Conceptos Avanzados
> 
> **Teorema Fundamental del Álgebra:**
> 
> ```
> Todo polinomio de grado n ≥ 1 con coeficientes complejos
> tiene exactamente n raíces complejas (contando multiplicidad).
> 
> Consecuencia: Un polinomio de grado n tiene a lo más n raíces reales.
> ```
> 
> **Multiplicidad de raíces:**
> 
> ```
> Si (x - r)^k divide a p(x) pero (x - r)^(k+1) no,
> entonces r es raíz de multiplicidad k.
> 
> Ejemplo: (x - 2)³(x + 1) = 0
> x = 2 tiene multiplicidad 3
> x = -1 tiene multiplicidad 1
> ```
> 
> **Raíces racionales (Teorema de las raíces racionales):**
> 
> ```
> Si p(x) = aₙxⁿ + ... + a₁x + a₀ con coeficientes enteros
> tiene una raíz racional p/q (en mínimos términos),
> entonces:
> - p divide a a₀
> - q divide a aₙ
> 
> Ejemplo: x³ - 6x² + 11x - 6 = 0
> Candidatos: ±1, ±2, ±3, ±6
> Probando: x = 1 funciona
> Factorizando: (x - 1)(x² - 5x + 6) = 0
>              (x - 1)(x - 2)(x - 3) = 0
> Raíces: 1, 2, 3
> ```
> 
> **Descomposición en fracciones parciales:**
> 
> ```
> Para resolver ecuaciones racionales complejas
> 
> Ejemplo: 1/(x² - 1) = A/(x - 1) + B/(x + 1)
> 
> 1 = A(x + 1) + B(x - 1)
> 
> x = 1:  1 = 2A → A = 1/2
> x = -1: 1 = -2B → B = -1/2
> 
> Por tanto: 1/(x² - 1) = 1/(2(x - 1)) - 1/(2(x + 1))
> ```
