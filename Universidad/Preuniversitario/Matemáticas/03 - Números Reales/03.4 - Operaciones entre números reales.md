# 🎯 Operaciones entre Números Reales

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **Las operaciones entre números reales son reglas que combinan números reales para producir otros números reales, preservando las propiedades algebraicas fundamentales que hacen de ℝ un campo ordenado completo.**
> 
> **Elementos clave:**
> 
> - **Cuatro operaciones básicas:** Suma, resta, multiplicación, división
> - **Clausura:** El resultado siempre es un número real (excepto división por cero)
> - **Estructura de campo:** ℝ con suma y multiplicación forma un campo
> - **Compatibilidad con orden:** Las operaciones respetan el orden de ℝ

### 📖 Contexto Histórico

> [!note]- Desarrollo Histórico de las Operaciones Aritméticas
> 
> **Operaciones Básicas en la Antigüedad (3000 a.C. - 500 d.C.):**
> 
> - **Suma y resta:** Primeras operaciones formalizadas en Mesopotamia
> - **Multiplicación:** Desarrollada mediante tablas (babilonios)
> - **División:** Uso de fracciones en Egipto y Babilonia
> - **Algoritmos:** Métodos sistemáticos para calcular
> 
> **Números Negativos y Regla de Signos (200 a.C. - 1600):**
> 
> - **China (200 a.C.):** Uso de varillas rojas (positivo) y negras (negativo)
> - **Brahmagupta (628):** Primeras reglas para operar con negativos
>     - "El producto de dos negativos es positivo"
>     - "El producto de positivo y negativo es negativo"
> - **Europa (1500s):** Resistencia inicial a números "ficticios"
> - **Descartes (1637):** Interpretación geométrica en recta numérica
> 
> **Notación Moderna (1400-1700):**
> 
> - **Fibonacci (1202):** Introduce notación árabe en Europa
> - **Recorde (1557):** Símbolo = para igualdad
> - **Oughtred (1631):** Símbolo × para multiplicación
> - **Leibniz (1684):** Símbolo · para multiplicación
> - **Rahn (1659):** Símbolo ÷ para división
> 
> **Formalización Axiomática (1800-1900):**
> 
> - **Peacock (1830):** Principio de permanencia de formas
> - **Dedekind (1872):** Construcción rigurosa de ℝ
> - **Peano (1889):** Axiomas para operaciones aritméticas
> - **Hilbert (1899):** Axiomas de campo ordenado
> 
> **Álgebra de Computadoras (1940-presente):**
> 
> - **Von Neumann (1945):** Aritmética binaria en computadoras
> - **IEEE 754 (1985):** Estándar para aritmética de punto flotante
> - **Complejidad:** Análisis de eficiencia de algoritmos aritméticos

## ➕ Adición (Suma)

### 📊 Definición y Propiedades

> [!success]- Operación de Adición
> 
> **Definición:** La **adición** es una operación binaria:
> 
> $$+ : \mathbb{R} \times \mathbb{R} \to \mathbb{R}$$
> 
> que asocia a cada par $(a, b)$ un único número real $a + b$ llamado **suma**.
> 
> **Propiedades fundamentales (axiomas de campo):**
> 
> 1. **Clausura:** $\forall a, b \in \mathbb{R}: a + b \in \mathbb{R}$
>     
> 2. **Conmutatividad:** $\forall a, b \in \mathbb{R}: a + b = b + a$
>     
> 3. **Asociatividad:** $\forall a, b, c \in \mathbb{R}: (a + b) + c = a + (b + c)$
>     
> 4. **Elemento neutro:** $\exists 0 \in \mathbb{R}: a + 0 = 0 + a = a$
>     
> 5. **Elemento inverso:** $\forall a \in \mathbb{R}, \exists (-a) \in \mathbb{R}: a + (-a) = 0$
>     
> 
> **Consecuencia:** $(\mathbb{R}, +)$ es un **grupo abeliano**

> [!example]- Ejemplos de Adición
> 
> **Suma de naturales:**
> 
> ```
> 5 + 3 = 8
> 0 + 7 = 7
> 12 + 0 = 12
> ```
> 
> **Suma con enteros:**
> 
> ```
> 5 + (-3) = 2
> (-7) + 4 = -3
> (-5) + (-8) = -13
> (-6) + 6 = 0
> ```
> 
> **Suma de racionales:**
> 
> ```
> 1/2 + 1/3 = 3/6 + 2/6 = 5/6
> 2/5 + 3/4 = 8/20 + 15/20 = 23/20
> 0.25 + 0.75 = 1
> ```
> 
> **Suma con irracionales:**
> 
> ```
> √2 + √2 = 2√2
> π + 2 = π + 2 (no se simplifica)
> √3 + √5 ≈ 1.732 + 2.236 = 3.968
> e + π ≈ 2.718 + 3.142 = 5.860
> ```
> 
> **Verificación de conmutatividad:**
> 
> ```
> 7 + (-3) = 4
> (-3) + 7 = 4
> ∴ 7 + (-3) = (-3) + 7 ✓
> ```
> 
> **Verificación de asociatividad:**
> 
> ```
> (5 + 3) + 2 = 8 + 2 = 10
> 5 + (3 + 2) = 5 + 5 = 10
> ∴ (5 + 3) + 2 = 5 + (3 + 2) ✓
> ```

### 🔍 Propiedades Adicionales

> [!note]- Propiedades Derivadas de la Suma
> 
> **Unicidad del neutro:**
> 
> ```
> Si a + e₁ = a y a + e₂ = a para todo a,
> entonces e₁ = e₂ = 0
> 
> Demostración:
> e₁ = e₁ + e₂ = e₂
> ```
> 
> **Unicidad del inverso:**
> 
> ```
> Si a + b₁ = 0 y a + b₂ = 0,
> entonces b₁ = b₂ = -a
> 
> Demostración:
> b₁ = b₁ + 0 = b₁ + (a + b₂) = (b₁ + a) + b₂ = 0 + b₂ = b₂
> ```
> 
> **Ley de cancelación:**
> 
> ```
> Si a + b = a + c, entonces b = c
> 
> Demostración:
> a + b = a + c
> (-a) + (a + b) = (-a) + (a + c)
> ((-a) + a) + b = ((-a) + a) + c
> 0 + b = 0 + c
> b = c
> ```
> 
> **Doble negativo:**
> 
> ```
> -(-a) = a
> 
> Demostración:
> (-a) + a = 0  (definición de inverso)
> Por unicidad del inverso: -(-a) = a
> ```
> 
> **Distributividad del opuesto:**
> 
> ```
> -(a + b) = (-a) + (-b)
> 
> Demostración:
> (a + b) + ((-a) + (-b)) = (a + (-a)) + (b + (-b)) = 0 + 0 = 0
> ```
> 
> **Regla del cero:**
> 
> ```
> a + 0 = a  (neutro aditivo)
> Si a + b = a, entonces b = 0
> ```

## ➖ Sustracción (Resta)

### 📊 Definición como Operación Derivada

> [!success]- Operación de Sustracción
> 
> **Definición:** La **sustracción** se define en términos de la adición:
> 
> $$a - b := a + (-b)$$
> 
> "Restar $b$ es sumar el opuesto de $b$"
> 
> **Características:**
> 
> - **NO es conmutativa:** $a - b \neq b - a$ (en general)
> - **NO es asociativa:** $(a - b) - c \neq a - (b - c)$ (en general)
> - **NO tiene elemento neutro derecho universal**
> - **Clausura:** Cerrada en ℝ, ℚ, ℤ pero NO en ℕ
> 
> **Relación con la suma:**
> 
> ```
> a - b = c  ⟺  a = b + c
> ```

> [!example]- Ejemplos de Sustracción
> 
> **Resta de naturales (puede salir de ℕ):**
> 
> ```
> 7 - 3 = 4 ∈ ℕ
> 3 - 7 = -4 ∉ ℕ (necesita ℤ)
> 5 - 5 = 0
> ```
> 
> **Resta de enteros:**
> 
> ```
> 5 - 3 = 5 + (-3) = 2
> 5 - (-3) = 5 + 3 = 8
> -5 - 3 = -5 + (-3) = -8
> -5 - (-3) = -5 + 3 = -2
> ```
> 
> **Resta de racionales:**
> 
> ```
> 3/4 - 1/2 = 3/4 - 2/4 = 1/4
> 2/3 - 5/6 = 4/6 - 5/6 = -1/6
> 0.75 - 0.25 = 0.50
> ```
> 
> **Resta con irracionales:**
> 
> ```
> √8 - √2 = 2√2 - √2 = √2
> π - 2 ≈ 3.14159 - 2 = 1.14159
> e - 1 ≈ 2.718 - 1 = 1.718
> ```
> 
> **No conmutatividad:**
> 
> ```
> 5 - 3 = 2
> 3 - 5 = -2
> 2 ≠ -2 ∴ NO conmutativa
> ```
> 
> **No asociatividad:**
> 
> ```
> (10 - 5) - 2 = 5 - 2 = 3
> 10 - (5 - 2) = 10 - 3 = 7
> 3 ≠ 7 ∴ NO asociativa
> ```

### 🎯 Reglas de Signos en la Resta

> [!tip]- Reglas para Operar con Signos
> 
> **Reglas básicas:**
> 
> ```
> 1. a - (+b) = a - b
> 2. a - (-b) = a + b
> 3. -(a - b) = -a + b = b - a
> 4. (a - b) + b = a
> 5. a - (b + c) = a - b - c
> 6. a - (b - c) = a - b + c
> ```
> 
> **Demostración de regla 2:**
> 
> ```
> a - (-b) = a + (-(-b))  (definición de resta)
>          = a + b        (doble negativo)
> ```
> 
> **Demostración de regla 3:**
> 
> ```
> -(a - b) = -(a + (-b))        (definición)
>          = (-a) + (-(-b))     (distributividad)
>          = (-a) + b           (doble negativo)
>          = b + (-a)           (conmutatividad)
>          = b - a              (definición)
> ```

> [!example]- Ejemplos de Aplicación de Reglas
> 
> **Simplificación de expresiones:**
> 
> ```
> 7 - (-3) = 7 + 3 = 10
> 
> -5 - (-8) = -5 + 8 = 3
> 
> 10 - (3 + 4) = 10 - 3 - 4 = 3
> 
> 10 - (3 - 4) = 10 - 3 + 4 = 11
> 
> -(7 - 5) = -7 + 5 = 5 - 7 = -2
> ```
> 
> **Expresiones complejas:**
> 
> ```
> 15 - (8 - (3 - 1))
> = 15 - (8 - 2)
> = 15 - 6
> = 9
> 
> Alternativa:
> = 15 - 8 + (3 - 1)
> = 15 - 8 + 3 - 1
> = 9
> ```

## ✖️ Multiplicación (Producto)

### 📊 Definición y Propiedades

> [!success]- Operación de Multiplicación
> 
> **Definición:** La **multiplicación** es una operación binaria:
> 
> $$\cdot : \mathbb{R} \times \mathbb{R} \to \mathbb{R}$$
> 
> que asocia a cada par $(a, b)$ un único número real $a \cdot b$ (o $ab$) llamado **producto**.
> 
> **Propiedades fundamentales:**
> 
> 1. **Clausura:** $\forall a, b \in \mathbb{R}: a \cdot b \in \mathbb{R}$
>     
> 2. **Conmutatividad:** $\forall a, b \in \mathbb{R}: a \cdot b = b \cdot a$
>     
> 3. **Asociatividad:** $\forall a, b, c \in \mathbb{R}: (a \cdot b) \cdot c = a \cdot (b \cdot c)$
>     
> 4. **Elemento neutro:** $\exists 1 \in \mathbb{R}: a \cdot 1 = 1 \cdot a = a$
>     
> 5. **Elemento inverso:** $\forall a \in \mathbb{R}\backslash{0}, \exists a^{-1} \in \mathbb{R}: a \cdot a^{-1} = 1$
>     
> 6. **Distributividad sobre la suma:** $a \cdot (b + c) = a \cdot b + a \cdot c$
>     
> 
> **Consecuencia:** $(\mathbb{R}\backslash{0}, \cdot)$ es un **grupo abeliano**
> 
> **Estructura completa:** $(\mathbb{R}, +, \cdot)$ es un **campo**

> [!example]- Ejemplos de Multiplicación
> 
> **Producto de naturales:**
> 
> ```
> 5 × 3 = 15
> 7 × 0 = 0
> 1 × 8 = 8
> ```
> 
> **Producto de enteros:**
> 
> ```
> 5 × 3 = 15
> 5 × (-3) = -15
> (-5) × 3 = -15
> (-5) × (-3) = 15
> ```
> 
> **Producto de racionales:**
> 
> ```
> (2/3) × (3/4) = 6/12 = 1/2
> (1/2) × 4 = 4/2 = 2
> 0.5 × 0.2 = 0.1
> (-2/5) × (3/7) = -6/35
> ```
> 
> **Producto con irracionales:**
> 
> ```
> √2 × √2 = 2 (racional)
> √2 × √3 = √6 (irracional)
> π × 2 = 2π
> √5 × 3 = 3√5
> ```
> 
> **Verificación de conmutatividad:**
> 
> ```
> 4 × 7 = 28
> 7 × 4 = 28
> ∴ 4 × 7 = 7 × 4 ✓
> ```
> 
> **Verificación de asociatividad:**
> 
> ```
> (2 × 3) × 5 = 6 × 5 = 30
> 2 × (3 × 5) = 2 × 15 = 30
> ∴ (2 × 3) × 5 = 2 × (3 × 5) ✓
> ```

### 🎨 Reglas de Signos

> [!success]- Leyes de los Signos en el Producto
> 
> **Reglas fundamentales:**
> 
> $$\begin{align} (+a) \times (+b) &= +(ab) \ (+a) \times (-b) &= -(ab) \ (-a) \times (+b) &= -(ab) \ (-a) \times (-b) &= +(ab) \end{align}$$
> 
> **Forma resumida:**
> 
> ```
> Signos iguales    → Producto positivo
> Signos diferentes → Producto negativo
> ```
> 
> **Justificación del producto de negativos:**
> 
> ```
> Queremos que 0 = a · 0 para todo a
> 
> 0 = a · 0
>   = a · (b + (-b))
>   = a · b + a · (-b)
> 
> Por tanto: a · (-b) = -(a · b)
> 
> Ahora con a = -1, b cualquiera:
> (-1) · b = -b
> 
> Entonces:
> (-a) · (-b) = ((-1) · a) · ((-1) · b)
>             = (-1) · (-1) · a · b
>             
> Para que sea consistente:
> (-1) · (-1) = 1
> 
> Por tanto: (-a) · (-b) = a · b
> ```

> [!example]- Ejemplos de Reglas de Signos
> 
> **Aplicación directa:**
> 
> ```
> 3 × 5 = 15          (+ × + = +)
> 3 × (-5) = -15      (+ × - = -)
> (-3) × 5 = -15      (- × + = -)
> (-3) × (-5) = 15    (- × - = +)
> ```
> 
> **Expresiones más complejas:**
> 
> ```
> (-2) × (-3) × (-4) = 6 × (-4) = -24
> 
> (-1) × (-1) × (-1) × (-1) = 1
> 
> -(3 × 4) = -12
> (-3) × 4 = -12
> 3 × (-4) = -12
> ```
> 
> **Potencias de -1:**
> 
> ```
> (-1)¹ = -1
> (-1)² = 1
> (-1)³ = -1
> (-1)⁴ = 1
> 
> Patrón: (-1)ⁿ = { 1  si n es par
>                { -1 si n es impar
> ```

### 🔍 Propiedades Adicionales

> [!note]- Propiedades Derivadas del Producto
> 
> **Propiedad del cero:**
> 
> ```
> a · 0 = 0  para todo a ∈ ℝ
> 
> Demostración:
> a · 0 = a · (0 + 0)
>       = a · 0 + a · 0
> 
> Restando a · 0 en ambos lados:
> 0 = a · 0
> ```
> 
> **Producto nulo:**
> 
> ```
> Si a · b = 0, entonces a = 0 o b = 0
> 
> Demostración (por contradicción):
> Supongamos a ≠ 0 y b ≠ 0
> Entonces existen a⁻¹ y b⁻¹
> a · b = 0
> a⁻¹ · (a · b) = a⁻¹ · 0
> (a⁻¹ · a) · b = 0
> 1 · b = 0
> b = 0
> Contradicción con b ≠ 0
> ```
> 
> **Ley de cancelación:**
> 
> ```
> Si a · b = a · c y a ≠ 0, entonces b = c
> 
> Demostración:
> a · b = a · c
> a⁻¹ · (a · b) = a⁻¹ · (a · c)
> (a⁻¹ · a) · b = (a⁻¹ · a) · c
> 1 · b = 1 · c
> b = c
> ```
> 
> **Inverso del producto:**
> 
> ```
> (a · b)⁻¹ = a⁻¹ · b⁻¹  (si a, b ≠ 0)
> 
> Demostración:
> (a · b) · (a⁻¹ · b⁻¹) = a · (b · a⁻¹) · b⁻¹
>                        = a · (a⁻¹ · b) · b⁻¹
>                        = (a · a⁻¹) · (b · b⁻¹)
>                        = 1 · 1 = 1
> ```
> 
> **Distributividad:**
> 
> ```
> a(b + c) = ab + ac           (izquierda)
> (b + c)a = ba + ca           (derecha)
> a(b - c) = ab - ac
> (a + b)(c + d) = ac + ad + bc + bd
> ```

## ➗ División

### 📊 Definición como Operación Derivada

> [!success]- Operación de División
> 
> **Definición:** La **división** se define en términos de la multiplicación:
> 
> $$a \div b := a \cdot b^{-1} = \frac{a}{b} \quad \text{para } b \neq 0$$
> 
> "Dividir entre $b$ es multiplicar por el inverso de $b$"
> 
> **Características:**
> 
> - **NO es conmutativa:** $a \div b \neq b \div a$ (en general)
> - **NO es asociativa:** $(a \div b) \div c \neq a \div (b \div c)$ (en general)
> - **NO está definida para divisor cero**
> - **Clausura:** Cerrada en ℝ{0}, ℚ{0}, pero NO en ℤ o ℕ
> 
> **Relación con la multiplicación:**
> 
> ```
> a ÷ b = c  ⟺  a = b · c  (donde b ≠ 0)
> ```

> [!example]- Ejemplos de División
> 
> **División exacta:**
> 
> ```
> 12 ÷ 3 = 4
> 20 ÷ 5 = 4
> 15 ÷ 15 = 1
> 7 ÷ 1 = 7
> ```
> 
> **División con enteros (sale de ℤ):**
> 
> ```
> 7 ÷ 2 = 7/2 = 3.5 ∉ ℤ
> 5 ÷ 4 = 5/4 = 1.25 ∉ ℤ
> ```
> 
> **División de racionales:**
> 
> ```
> (2/3) ÷ (4/5) = (2/3) × (5/4) = 10/12 = 5/6
> 
> (3/4) ÷ 2 = (3/4) × (1/2) = 3/8
> 
> 0.8 ÷ 0.2 = 4
> ```
> 
> **División con irracionales:**
> 
> ```
> √8 ÷ √2 = √(8/2) = √4 = 2 (racional)
> π ÷ 2 = π/2 ≈ 1.5708
> 6 ÷ √3 = 6/√3 = 6√3/3 = 2√3
> ```
> 
> **No conmutatividad:**
> 
> ```
> 12 ÷ 3 = 4
> 3 ÷ 12 = 1/4 = 0.25
> 4 ≠ 0.25 ∴ NO conmutativa
> ```
> 
> **No asociatividad:**
> 
> ```
> (24 ÷ 4) ÷ 2 = 6 ÷ 2 = 3
> 24 ÷ (4 ÷ 2) = 24 ÷ 2 = 12
> 3 ≠ 12 ∴ NO asociativa
> ```

### 🎯 Reglas de Signos en la División

> [!success]- Leyes de los Signos en el Cociente
> 
> **Reglas fundamentales:**
> 
> $$\begin{align} \frac{+a}{+b} &= +\frac{a}{b} \[0.5em] \frac{+a}{-b} &= -\frac{a}{b} \[0.5em] \frac{-a}{+b} &= -\frac{a}{b} \[0.5em] \frac{-a}{-b} &= +\frac{a}{b} \end{align}$$
> 
> **Forma resumida:**
> 
> ```
> Signos iguales    → Cociente positivo
> Signos diferentes → Cociente negativo
> ```
> 
> **Justificación:**
> 
> ```
> Como a ÷ b = a · b⁻¹, las reglas de signos
> son las mismas que para la multiplicación.
> ```

> [!example]- Ejemplos de Reglas de Signos
> 
> **División con signos:**
> 
> ```
> 12 ÷ 3 = 4           (+ ÷ + = +)
> 12 ÷ (-3) = -4       (+ ÷ - = -)
> (-12) ÷ 3 = -4       (- ÷ + = -)
> (-12) ÷ (-3) = 4     (- ÷ - = +)
> ```
> 
> **Fracciones con signos:**
> 
> ```
> -6/2 = -3
> 6/(-2) = -3
> -6/(-2) = 3
> 
> -(-5/3) = 5/3
> ```
> 
> **Expresiones complejas:**
> 
> ```
> (-15) ÷ (-3) ÷ 5 = 5 ÷ 5 = 1
> 
> -20/4 = -5
> -(20/4) = -5
> 20/(-4) = -5
> ```

### ⚠️ División por Cero

> [!warning]- Por Qué No Se Puede Dividir por Cero
> 
> **Problema fundamental:**
> 
> ```
> Si permitimos a ÷ 0 = x, entonces debería cumplirse:
> a = 0 · x
> 
> Pero 0 · x = 0 para todo x
> Por tanto: a = 0
> 
> Esto solo funciona si a = 0, creando contradicciones
> ```
> 
> **Caso 1: a ≠ 0**
> 
> ```
> Si 5 ÷ 0 = x, entonces 5 = 0 · x = 0
> Contradicción: 5 ≠ 0
> ∴ No existe x tal que 5 ÷ 0 = x
> ```
> 
> **Caso 2: 0 ÷ 0 (indeterminación)**
> 
> ```
> Si 0 ÷ 0 = x, entonces 0 = 0 · x
> 
> Pero 0 · x = 0 es cierto para TODO x
> 
> ∴ 0 ÷ 0 podría ser cualquier número
> Es una forma indeterminada
> ```
> 
> **Consecuencias si permitiéramos división por cero:**
> 
> ```
> Supongamos 1/0 = ∞ (infinito)
> 
> Entonces:
> 1 = 0 · ∞
> 2 = 0 · (2∞)
> 
> Pero 0 · ∞ = 0 · (2∞) debería implicar ∞ = 2∞
> 
> Dividiendo por ∞: 1 = 2
> 
> ¡Contradicción! Toda la aritmética se destruye
> ```
> 
> **Conclusión:**
> 
> ```
> La división por cero NO ESTÁ DEFINIDA en ℝ
> 
> Es un error matemático, no una operación válida
> ```

## 🎯 Orden de Operaciones (PEMDAS/BODMAS)

> [!tip]- Precedencia de Operaciones
> 
> **Jerarquía estándar:**
> ```
> 1. Paréntesis (y otros símbolos de agrupación)
> 2. Exponentes (potencias y raíces)
> 3. Multiplicación y División (de izquierda a derecha)
> 4. Suma y Resta (de izquierda a derecha)
> ```
> 
> **Mnemónica PEMDAS (inglés):**
> 
> ```
> P - Parentheses (Paréntesis)
> E - Exponents (Exponentes)
> M - Multiplication (Multiplicación)
> D - Division (División)
> A - Addition (Adición)
> S - Subtraction (Sustracción)
> ```
> 
> **Mnemónica BODMAS (británico):**
> 
> ```
> B - Brackets (Corchetes)
> O - Orders (Órdenes/Exponentes)
> D - Division (División)
> M - Multiplication (Multiplicación)
> A - Addition (Adición)
> S - Subtraction (Sustracción)
> ```
> 
> **Símbolos de agrupación (en orden de evaluación):**
> 
> ```
> 1. Paréntesis internos: ( )
> 2. Corchetes: [ ]
> 3. Llaves: { }
> 4. Barras de valor absoluto: | |
> 5. Barras de fracción: ─────
> ```
> 

> [!example]- Ejemplos de Orden de Operaciones
> 
> **Ejemplo 1: Operaciones mixtas básicas**
> 
> ```
> 5 + 3 × 4 = ?
> 
> Incorrecto: (5 + 3) × 4 = 8 × 4 = 32
> Correcto:   5 + (3 × 4) = 5 + 12 = 17
> 
> La multiplicación tiene prioridad sobre la suma
> ```
> 
> **Ejemplo 2: Con paréntesis**
> 
> ```
> (5 + 3) × 4 = ?
> 
> Primero: 5 + 3 = 8
> Luego:   8 × 4 = 32
> 
> Los paréntesis modifican el orden natural
> ```
> 
> **Ejemplo 3: Múltiples operaciones**
> 
> ```
> 10 + 6 ÷ 2 × 3 = ?
> 
> Paso 1: 6 ÷ 2 = 3        (división primero)
> Paso 2: 3 × 3 = 9         (multiplicación)
> Paso 3: 10 + 9 = 19       (suma al final)
> 
> Resultado: 19
> ```
> 
> **Ejemplo 4: Con exponentes**
> 
> ```
> 2 + 3² × 4 = ?
> 
> Paso 1: 3² = 9            (exponente primero)
> Paso 2: 9 × 4 = 36        (multiplicación)
> Paso 3: 2 + 36 = 38       (suma)
> 
> Resultado: 38
> ```
> 
> **Ejemplo 5: Anidamiento de paréntesis**
> 
> ```
> 2 × [3 + (4 - 1) × 2] = ?
> 
> Paso 1: 4 - 1 = 3         (paréntesis más interno)
> Paso 2: 3 × 2 = 6         (multiplicación en corchetes)
> Paso 3: 3 + 6 = 9         (suma en corchetes)
> Paso 4: 2 × 9 = 18        (multiplicación final)
> 
> Resultado: 18
> ```
> 
> **Ejemplo 6: División y multiplicación consecutivas**
> 
> ```
> 24 ÷ 4 × 2 = ?
> 
> Se evalúa de izquierda a derecha:
> Paso 1: 24 ÷ 4 = 6
> Paso 2: 6 × 2 = 12
> 
> Resultado: 12
> 
> Nota: NO es 24 ÷ (4 × 2) = 24 ÷ 8 = 3
> ```
> 
> **Ejemplo 7: Expresión compleja**
> 
> ```
> 10 - 2 × (5 + 3²) ÷ 7 + 4 = ?
> 
> Paso 1: 3² = 9                    (exponente)
> Paso 2: 5 + 9 = 14                (paréntesis)
> Paso 3: 2 × 14 = 28               (multiplicación)
> Paso 4: 28 ÷ 7 = 4                (división)
> Paso 5: 10 - 4 + 4 = 10           (suma y resta)
> 
> Resultado: 10
> ```
> 

## 🔄 Compatibilidad con el Orden

### 📊 Operaciones y Desigualdades

> [!success]- Propiedades de Orden en las Operaciones
> 
> **Compatibilidad de la suma con el orden:**
> 
> $$\text{Si } a < b \text{, entonces } a + c < b + c \quad \forall c \in \mathbb{R}$$
> 
> **Demostración:**
> 
> ```
> a < b significa b - a > 0
> (b + c) - (a + c) = b - a > 0
> Por tanto: a + c < b + c
> ```
> 
> **Compatibilidad del producto con el orden:**
> 
> $$\begin{align} \text{Si } a < b \text{ y } c > 0 &\implies a \cdot c < b \cdot c \ \text{Si } a < b \text{ y } c < 0 &\implies a \cdot c > b \cdot c \end{align}$$
> 
> **Interpretación:**
> 
> ```
> Multiplicar por positivo: preserva el orden
> Multiplicar por negativo: invierte el orden
> ```
> 

> [!example]- Ejemplos de Orden y Operaciones
> 
> **Suma preserva orden:**
> 
> ```
> 5 < 8
> 5 + 3 < 8 + 3
> 8 < 11 ✓
> 
> -2 < 3
> -2 + 10 < 3 + 10
> 8 < 13 ✓
> ```
> 
> **Multiplicación por positivo preserva orden:**
> 
> ```
> 3 < 7
> 3 × 2 < 7 × 2
> 6 < 14 ✓
> 
> -5 < -2
> (-5) × 3 < (-2) × 3
> -15 < -6 ✓
> ```
> 
> **Multiplicación por negativo invierte orden:**
> 
> ```
> 3 < 7
> 3 × (-2) > 7 × (-2)
> -6 > -14 ✓
> 
> -5 < -2
> (-5) × (-3) > (-2) × (-3)
> 15 > 6 ✓
> ```
> 
> **División sigue las mismas reglas:**
> 
> ```
> 8 < 12
> 8 ÷ 2 < 12 ÷ 2
> 4 < 6 ✓
> 
> 8 < 12
> 8 ÷ (-2) > 12 ÷ (-2)
> -4 > -6 ✓
> ```
> 
> **Aplicación a desigualdades:**
> 
> ```
> Resolver: 2x + 3 < 7
> 
> 2x + 3 - 3 < 7 - 3    (restar 3, preserva orden)
> 2x < 4
> 2x ÷ 2 < 4 ÷ 2        (dividir por 2 > 0, preserva)
> x < 2
> 
> Solución: x ∈ (-∞, 2)
> ```
> 

## 🎲 Propiedades Especiales

### 🔍 Absorción y Anulación

> [!note]- Elementos Especiales en Operaciones
> 
> **Elemento absorbente de la multiplicación:**
> 
> ```
> 0 · a = a · 0 = 0  para todo a ∈ ℝ
> 
> El cero "absorbe" cualquier producto
> ```
> 
> **No hay elemento absorbente para la suma:**
> 
> ```
> No existe e ∈ ℝ tal que e + a = e para todo a
> 
> (Si existiera: e + 1 = e ⟹ 1 = 0, contradicción)
> ```
> 
> **Idempotencia del máximo y mínimo:**
> 
> ```
> max(a, a) = a
> min(a, a) = a
> 
> Pero la suma no es idempotente: a + a = 2a ≠ a
> ```
> 

### 🔗 Leyes Distributivas Extendidas

> [!note]- Distributividad en Expresiones Complejas
> 
> **Producto de binomios:**
> 
> ```
> (a + b)(c + d) = ac + ad + bc + bd
> 
> Demostración:
> (a + b)(c + d) = (a + b)c + (a + b)d     (distributiva)
>                 = ac + bc + ad + bd       (distributiva)
>                 = ac + ad + bc + bd       (conmutativa)
> ```
> 
> **Cuadrado de binomio:**
> 
> ```
> (a + b)² = a² + 2ab + b²
> (a - b)² = a² - 2ab + b²
> 
> Demostración de (a + b)²:
> (a + b)² = (a + b)(a + b)
>          = a² + ab + ba + b²
>          = a² + 2ab + b²
> ```
> 
> **Diferencia de cuadrados:**
> 
> ```
> (a + b)(a - b) = a² - b²
> 
> Demostración:
> (a + b)(a - b) = a² - ab + ba - b²
>                = a² - ab + ab - b²
>                = a² - b²
> ```
> 
> **Cubo de binomio:**
> 
> ```
> (a + b)³ = a³ + 3a²b + 3ab² + b³
> (a - b)³ = a³ - 3a²b + 3ab² - b³
> ```

> [!example]- Ejemplos de Productos Notables
> 
> **Cuadrado de suma:**
> 
> ```
> (x + 3)² = x² + 2(x)(3) + 3²
>          = x² + 6x + 9
> 
> (2a + 5)² = (2a)² + 2(2a)(5) + 5²
>           = 4a² + 20a + 25
> ```
> 
> **Cuadrado de diferencia:**
> 
> ```
> (x - 4)² = x² - 2(x)(4) + 4²
>          = x² - 8x + 16
> 
> (3y - 2)² = (3y)² - 2(3y)(2) + 2²
>           = 9y² - 12y + 4
> ```
> 
> **Diferencia de cuadrados:**
> 
> ```
> (x + 5)(x - 5) = x² - 25
> 
> (2a + 3)(2a - 3) = (2a)² - 3²
>                   = 4a² - 9
> ```
> 
> **Suma de cubos:**
> 
> ```
> a³ + b³ = (a + b)(a² - ab + b²)
> 
> Ejemplo: 8 + 27 = 2³ + 3³
>                 = (2 + 3)(4 - 6 + 9)
>                 = 5(7) = 35 ✓
> ```
> 
> **Diferencia de cubos:**
> 
> ```
> a³ - b³ = (a - b)(a² + ab + b²)
> 
> Ejemplo: 64 - 8 = 4³ - 2³
>                 = (4 - 2)(16 + 8 + 4)
>                 = 2(28) = 56 ✓
> ```
> 

## 📐 Operaciones con Raíces y Potencias

### 🔢 Propiedades de Potencias

> [!success]- Leyes de Exponentes
> 
> **Definición básica:**
> 
> ```
> aⁿ = a × a × ... × a  (n factores)
> a⁰ = 1  (para a ≠ 0)
> a⁻ⁿ = 1/aⁿ  (para a ≠ 0)
> ```
> 
> **Leyes fundamentales:**
> 
> ```
> 1. aᵐ · aⁿ = aᵐ⁺ⁿ
> 
> 2. aᵐ ÷ aⁿ = aᵐ⁻ⁿ
> 
> 3. (aᵐ)ⁿ = aᵐⁿ
> 
> 4. (ab)ⁿ = aⁿbⁿ
> 
> 5. (a/b)ⁿ = aⁿ/bⁿ  (b ≠ 0)
> 
> 6. a⁻ⁿ = 1/aⁿ  (a ≠ 0)
> 
> 7. (a/b)⁻ⁿ = (b/a)ⁿ  (a, b ≠ 0)
> ```
> 

> [!example]- Ejemplos de Operaciones con Potencias
> 
> **Multiplicación de potencias:**
> 
> ```
> 2³ · 2⁴ = 2³⁺⁴ = 2⁷ = 128
> 
> x⁵ · x² = x⁵⁺² = x⁷
> 
> 3² · 3⁻¹ = 3²⁺⁽⁻¹⁾ = 3¹ = 3
> ```
> 
> **División de potencias:**
> 
> ```
> 5⁶ ÷ 5² = 5⁶⁻² = 5⁴ = 625
> 
> x⁸ ÷ x³ = x⁸⁻³ = x⁵
> 
> 2⁻³ ÷ 2⁻⁵ = 2⁻³⁻⁽⁻⁵⁾ = 2² = 4
> ```
> 
> **Potencia de potencia:**
> 
> ```
> (3²)³ = 3²ˣ³ = 3⁶ = 729
> 
> (x³)⁴ = x³ˣ⁴ = x¹²
> 
> ((2²)²)² = 2²ˣ²ˣ² = 2⁸ = 256
> ```
> 
> **Potencia de producto:**
> 
> ```
> (2 · 3)⁴ = 2⁴ · 3⁴ = 16 · 81 = 1296
> 
> (xy)³ = x³y³
> 
> (2a)⁵ = 2⁵a⁵ = 32a⁵
> ```
> 
> **Exponentes negativos:**
> 
> ```
> 2⁻³ = 1/2³ = 1/8
> 
> x⁻² = 1/x²
> 
> (3/4)⁻² = (4/3)² = 16/9
> ```
> 

### √ Propiedades de Raíces

> [!success]- Leyes de Radicales
> 
> **Definición:**
> 
> ```
> ⁿ√a = a^(1/n)  (raíz n-ésima de a)
> 
> √a = a^(1/2)   (raíz cuadrada)
> ³√a = a^(1/3)  (raíz cúbica)
> ```
> 
> **Leyes fundamentales:**
> 
> ```
> 1. ⁿ√(ab) = ⁿ√a · ⁿ√b  (a, b ≥ 0 si n par)
> 
> 2. ⁿ√(a/b) = ⁿ√a / ⁿ√b  (b ≠ 0, a, b ≥ 0 si n par)
> 
> 3. ᵐ√(ⁿ√a) = ᵐⁿ√a
> 
> 4. (ⁿ√a)ᵐ = ⁿ√(aᵐ)
> 
> 5. ⁿ√(aⁿ) = |a|  (si n es par)
>            = a   (si n es impar)
> ```
> 
> **Racionalización:**
> 
> ```
> Para eliminar raíces del denominador:
> 
> 1/√a = √a/a
> 
> 1/(a + √b) = (a - √b)/(a² - b)
> 
> 1/(√a + √b) = (√a - √b)/(a - b)
> ```
> 

> [!example]- Ejemplos de Operaciones con Raíces
> 
> **Producto de raíces:**
> 
> ```
> √2 · √8 = √(2 · 8) = √16 = 4
> 
> √3 · √12 = √(3 · 12) = √36 = 6
> 
> ³√2 · ³√4 = ³√(2 · 4) = ³√8 = 2
> ```
> 
> **División de raíces:**
> 
> ```
> √50 ÷ √2 = √(50/2) = √25 = 5
> 
> √72 / √8 = √(72/8) = √9 = 3
> 
> ⁴√16 / ⁴√2 = ⁴√(16/2) = ⁴√8
> ```
> 
> **Simplificación de raíces:**
> 
> ```
> √18 = √(9 · 2) = √9 · √2 = 3√2
> 
> √48 = √(16 · 3) = 4√3
> 
> ³√54 = ³√(27 · 2) = 3³√2
> ```
> 
> **Suma de raíces similares:**
> 
> ```
> 2√3 + 5√3 = 7√3
> 
> √12 + √27 = 2√3 + 3√3 = 5√3
> 
> Pero: √2 + √3 ≠ √5  (no se simplifican)
> ```
> 
> **Racionalización:**
> 
> ```
> 1/√5 = 1/√5 · √5/√5 = √5/5
> 
> 3/√2 = 3/√2 · √2/√2 = 3√2/2
> 
> 1/(2 + √3) = (2 - √3)/((2 + √3)(2 - √3))
>            = (2 - √3)/(4 - 3)
>            = 2 - √3
> ```
> 
> **Raíces anidadas:**
> 
> ```
> √(√16) = √4 = 2
> 
> ³√(√64) = ³√8 = 2
> 
> √(2 + √3) no se simplifica más
> ```
> 

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes
> 
> **1. Orden de operaciones incorrecto**
> 
> ```
> ✗ INCORRECTO: 2 + 3 × 4 = 5 × 4 = 20
> ✓ CORRECTO:   2 + 3 × 4 = 2 + 12 = 14
> 
> La multiplicación tiene prioridad
> ```
> 
> **2. Distributiva mal aplicada**
> 
> ```
> ✗ INCORRECTO: (a + b)² = a² + b²
> ✓ CORRECTO:   (a + b)² = a² + 2ab + b²
> 
> Ejemplo: (2 + 3)² = 25 ≠ 13 = 2² + 3²
> ```
> 
> **3. Raíz de suma**
> 
> ```
> ✗ INCORRECTO: √(a + b) = √a + √b
> ✓ CORRECTO:   √(a + b) no se simplifica así
> 
> Ejemplo: √(9 + 16) = √25 = 5 ≠ 7 = 3 + 4
> ```
> 
> **4. Cancelación incorrecta**
> 
> ```
> ✗ INCORRECTO: (a + b)/a = b
> ✓ CORRECTO:   (a + b)/a = 1 + b/a
> 
> Solo se cancela si es factor común:
> (ab)/a = b  ✓
> ```
> 
> **5. Exponentes y raíces**
> 
> ```
> ✗ INCORRECTO: (aᵐ)ⁿ = aᵐ⁺ⁿ
> ✓ CORRECTO:   (aᵐ)ⁿ = aᵐⁿ
> 
> ✗ INCORRECTO: aᵐ · bⁿ = (ab)ᵐ⁺ⁿ
> ✓ CORRECTO:   Solo si m = n: aⁿ · bⁿ = (ab)ⁿ
> ```
> 
> **6. División de fracciones**
> 
> ```
> ✗ INCORRECTO: (a/b) / (c/d) = (a/c) / (b/d)
> ✓ CORRECTO:   (a/b) / (c/d) = (a/b) · (d/c) = ad/bc
> 
> Ejemplo: (1/2) / (1/3) = (1/2) · (3/1) = 3/2
> ```
> 
> **7. Signo en potencias**
> 
> ```
> ✗ INCORRECTO: (-2)² = -4
> ✓ CORRECTO:   (-2)² = 4
> 
> Pero: -2² = -(2²) = -4  (exponente solo al 2)
> ```
> 
> **8. Cero elevado a cero**
> 
> ```
> 0⁰ está INDETERMINADO (no es 1)
> 
> En diferentes contextos puede definirse diferente
> ```
> 
> **9. Racionalización mal hecha**
> 
> ```
> ✗ INCORRECTO: 1/(√a + √b) = 1/√a + 1/√b
> ✓ CORRECTO:   Multiplicar por conjugado
> 
> 1/(√a + √b) · (√a - √b)/(√a - √b) = (√a - √b)/(a - b)
> ```
> 
> **10. Valor absoluto en raíces**
> 
> ```
> ✗ INCORRECTO: √(x²) = x
> ✓ CORRECTO:   √(x²) = |x|
> 
> Ejemplo: √((-3)²) = √9 = 3 = |-3| ≠ -3
> ```
> 

## 🎯 Estrategias de Cálculo

> [!tip]- Técnicas para Simplificar Cálculos
> 
> **Factorización para simplificar:**
> 
> ```
> 48 × 7 + 48 × 3 = 48(7 + 3) = 48 × 10 = 480
> 
> Más fácil que: 336 + 144 = 480
> ```
> 
> **Uso de propiedades conmutativa y asociativa:**
> 
> ```
> 37 + 58 + 13 = 37 + 13 + 58 = 50 + 58 = 108
> 
> 25 × 13 × 4 = 25 × 4 × 13 = 100 × 13 = 1300
> ```
> 
> **Completar a números redondos:**
> 
> ```
> 98 + 57 = (100 - 2) + 57 = 157 - 2 = 155
> 
> 19 × 5 = (20 - 1) × 5 = 100 - 5 = 95
> ```
> 
> **Fraccionamiento:**
> 
> ```
> 45 × 12 = 45 × 10 + 45 × 2
>         = 450 + 90
>         = 540
> ```
> 
> **Diferencia de cuadrados:**
> 
> ```
> 23² - 17² = (23 + 17)(23 - 17)
>           = 40 × 6
>           = 240
> 
> Más rápido que: 529 - 289 = 240
> ```
> 
> **Racionalización simplifica cálculos:**
> 
> ```
> 10/√5 = 10√5/5 = 2√5 ≈ 4.47
> 
> Más simple que trabajar con decimales
> ```
>

> - Resistencias en paralelo: $\frac{1}{R_T} = \frac{1}{R_1} + \frac{1}{R_2}$
> 
> **Estadística:**
> 
> - Media: suma de datos ÷ cantidad
> - Desviación estándar: raíces y potencias
> - Varianza: suma de cuadrados de diferencias
> 
> **Vida cotidiana:**
> 
> - Compras: precio × cantidad
> - Propinas: total × porcentaje
> - Recetas: multiplicar/dividir ingredientes
> - Distancias: velocidad × tiempo
