# 🎯 Binomio de Newton

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva
> 
> **El Binomio de Newton es una fórmula que permite expandir la potencia de un binomio (a+b)ⁿ como suma de términos con coeficientes binomiales.**
> 
> **Elementos clave:**
> 
> - **Binomio:** Expresión algebraica con dos términos (a + b)
> - **Exponente:** Número natural n que indica la potencia
> - **Expansión:** Desarrollo como suma de monomios
> - **Coeficientes binomiales:** Números C(n,k) que multiplican cada término
> - **Aplicaciones:** Álgebra, probabilidad, cálculo, análisis combinatorio

### 📖 Contexto Histórico

> [!note]- Desarrollo Histórico del Binomio de Newton
> 
> **Período antiguo (2000 a.C. - 1000 d.C.):**
> 
> - **Babilonios:** Conocen casos particulares (cuadrados y cubos)
> - **Griegos:** Geométricamente equivalente
> - **Árabes (800-1400):** Desarrollan álgebra sistemática
> 
> **Período de Formalización (1500-1665):**
> 
> - **Tartaglia (1556):** Triángulo para expandir binomios
> - **Pascal (1665):** Formaliza el Triángulo de Pascal
>     - Demuestra relación con coeficientes binomiales
>     - Conecta con análisis combinatorio
> - **Blaise Pascal:** Prueba las propiedades del triángulo
> 
> **Isaac Newton (1642-1726):**
> 
> - **Descubrimiento revolucionario (1665-1666):**
>     - Años de peste, Newton se retira a casa
>     - Descubre expansión para exponentes negativos y fraccionarios
> - **Generalización:** (a+b)ⁿ para n no necesariamente entero positivo
> - **Demostración:** Usando cálculo diferencial e integral
> - **Impacto:** Fundamental para desarrollo del cálculo
> 
> **Era Moderna (1700-1900):**
> 
> - **Euler:** Extensiones y aplicaciones
> - **Gauss:** Métodos analíticos
> - **Legendre y Chebyshev:** Polinomios ortogonales relacionados
> 
> **Era Contemporánea (1900-presente):**
> 
> - **Álgebra abstracta:** Generalización a otros estructuras
> - **Análisis funcional:** Fórmulas en espacios infinito-dimensionales
> - **Computación:** Algoritmos eficientes para calcular expansiones

## 🔢 Fórmula del Binomio de Newton

> [!success]- Enunciado de la Fórmula
> 
> **Teorema del Binomio de Newton:**
> 
> ```
> Para todo n ∈ ℕ y a, b ∈ ℝ (o ℂ):
> 
> (a + b)ⁿ = Σ C(n,k) aⁿ⁻ᵏ bᵏ  para k=0 hasta n
> 
> Donde C(n,k) = n! / (k!(n-k)!) es el coeficiente binomial
> ```
> 
> **Notación alternativa:**
> 
> ```
> (a + b)ⁿ = Σ (n k) aⁿ⁻ᵏ bᵏ     (usando (n k) para C(n,k))
> 
> (a + b)ⁿ = Σ ₙCₖ aⁿ⁻ᵏ bᵏ      (usando ₙCₖ)
> ```
> 
> **Forma expandida:**
> 
> ```
> (a + b)ⁿ = C(n,0)aⁿb⁰ + C(n,1)aⁿ⁻¹b¹ + C(n,2)aⁿ⁻²b² 
>            + ... + C(n,n-1)a¹bⁿ⁻¹ + C(n,n)a⁰bⁿ
> 
>          = aⁿ + naⁿ⁻¹b + n(n-1)/2! aⁿ⁻²b² + ... + nbabⁿ⁻¹ + bⁿ
> ```
> 
> **Término general (k-ésimo término):**
> 
> ```
> Tₖ = C(n,k) aⁿ⁻ᵏ bᵏ    o    Tₖ₊₁ = C(n,k) aⁿ⁻ᵏ bᵏ
> 
> (Depende de si numeramos desde 0 o 1)
> ```

> [!note]- Demostración del Binomio de Newton
> 
> **Por inducción matemática:**
> 
> ```
> CASO BASE (n = 1):
> (a + b)¹ = a + b
> Fórmula: C(1,0)a¹b⁰ + C(1,1)a⁰b¹ = a + b ✓
> 
> PASO INDUCTIVO:
> Hipótesis inductiva: (a+b)^k = Σ C(k,j) a^(k-j) b^j
> 
> Debemos probar: (a+b)^(k+1) = Σ C(k+1,j) a^(k+1-j) b^j
> 
> (a+b)^(k+1) = (a+b)·(a+b)^k
>             = (a+b)·Σ C(k,j) a^(k-j) b^j        [por H.I.]
>             = a·Σ C(k,j) a^(k-j) b^j + b·Σ C(k,j) a^(k-j) b^j
>             = Σ C(k,j) a^(k+1-j) b^j + Σ C(k,j) a^(k-j) b^(j+1)
> 
> Reorganizamos los índices:
>             = C(k,0) a^(k+1) + Σ [C(k,j) + C(k,j-1)] a^(k+1-j) b^j + C(k,k) b^(k+1)
> 
> Usamos la identidad de Pascal: C(k,j) + C(k,j-1) = C(k+1,j)
> 
>             = C(k+1,0) a^(k+1) + Σ C(k+1,j) a^(k+1-j) b^j + C(k+1,k+1) b^(k+1)
>             = Σ C(k+1,j) a^(k+1-j) b^j  ✓
> 
> Por inducción matemática, la fórmula es verdadera ∀n ∈ ℕ  ∎
> ```

## 📊 Ejemplos de Expansiones

> [!example]- Binomios de Potencia Baja
> 
> **n = 0:**
> 
> ```
> (a + b)⁰ = 1
> ```
> 
> **n = 1:**
> 
> ```
> (a + b)¹ = a + b
> Coeficientes: [1, 1]
> ```
> 
> **n = 2:**
> 
> ```
> (a + b)² = a² + 2ab + b²
> Coeficientes: [1, 2, 1]
> ```
> 
> **n = 3:**
> 
> ```
> (a + b)³ = a³ + 3a²b + 3ab² + b³
> Coeficientes: [1, 3, 3, 1]
> ```
> 
> **n = 4:**
> 
> ```
> (a + b)⁴ = a⁴ + 4a³b + 6a²b² + 4ab³ + b⁴
> Coeficientes: [1, 4, 6, 4, 1]
> ```
> 
> **n = 5:**
> 
> ```
> (a + b)⁵ = a⁵ + 5a⁴b + 10a³b² + 10a²b³ + 5ab⁴ + b⁵
> Coeficientes: [1, 5, 10, 10, 5, 1]
> ```

> [!example]- Aplicaciones Numéricas
> 
> **Ejemplo 1: Expandir (2x + 3)³**
> 
> ```
> (2x + 3)³ = Σ C(3,k) (2x)^(3-k) (3)^k
>           = C(3,0)(2x)³(3)⁰ + C(3,1)(2x)²(3)¹ + C(3,2)(2x)¹(3)² + C(3,3)(2x)⁰(3)³
>           = 1·8x³·1 + 3·4x²·3 + 3·2x·9 + 1·1·27
>           = 8x³ + 36x² + 54x + 27
> ```
> 
> **Ejemplo 2: Expandir (a - b)⁴**
> 
> ```
> (a - b)⁴ = (a + (-b))⁴
>          = Σ C(4,k) a^(4-k) (-b)^k
>          = a⁴ - 4a³b + 6a²b² - 4ab³ + b⁴
> 
> Nota: Los signos alternan debido a (-b)^k
> ```
> 
> **Ejemplo 3: Calcular (1.02)⁵ aproximadamente**
> 
> ```
> (1.02)⁵ = (1 + 0.02)⁵
>         = C(5,0)·1⁵·(0.02)⁰ + C(5,1)·1⁴·(0.02)¹ + C(5,2)·1³·(0.02)² + ...
>         = 1 + 5(0.02) + 10(0.0004) + 10(0.000008) + ...
>         = 1 + 0.1 + 0.004 + 0.00008 + ...
>         ≈ 1.10408
> 
> (Valor exacto: 1.10408...)
> ```

## 🔍 Término General y Propiedades

> [!success]- Fórmula del Término General
> 
> **Definición:**
> 
> ```
> El término general (o término k-ésimo) de la expansión de (a+b)ⁿ es:
> 
> Tₖ = C(n, k-1) a^(n-k+1) b^(k-1)    (contando desde k=1)
> 
> O equivalentemente:
> 
> Tₖ₊₁ = C(n,k) a^(n-k) b^k           (contando desde k=0)
> ```
> 
> **Aplicación:**
> 
> ```
> Para encontrar un término específico sin expandir todo:
> 
> Ejemplo: Encontrar el término con x⁵ en (2x + 3)⁷
> 
> El término k-ésimo contiene (2x)^(7-k+1) = (2x)^(8-k)
> Necesitamos: 8 - k = 5, entonces k = 3
> 
> T₃ = C(7, 2) · (2x)⁵ · 3²
>    = 21 · 32x⁵ · 9
>    = 6,048x⁵
> ```

> [!success]- Propiedades del Binomio de Newton
> 
> **Propiedad 1: Simetría de coeficientes**
> 
> ```
> Los coeficientes son simétricos:
> C(n,0) = C(n,n)
> C(n,1) = C(n,n-1)
> C(n,k) = C(n,n-k)
> 
> Esto refleja la simetría: (a+b)ⁿ = (b+a)ⁿ
> ```
> 
> **Propiedad 2: Suma de coeficientes**
> 
> ```
> Σ C(n,k) = 2ⁿ  para k=0 hasta n
> 
> Demostración: Hacer a = b = 1 en (a+b)ⁿ
> (1+1)ⁿ = 2ⁿ = Σ C(n,k) · 1 · 1
> 
> Ejemplo: Para n=3: 1+3+3+1 = 8 = 2³
> ```
> 
> **Propiedad 3: Suma alternada de coeficientes**
> 
> ```
> Σ (-1)ᵏ C(n,k) = 0  para k=0 hasta n (si n > 0)
> 
> Demostración: Hacer a = 1, b = -1 en (a+b)ⁿ
> (1-1)ⁿ = 0 = Σ C(n,k) · (-1)ᵏ
> 
> Ejemplo: Para n=3: 1-3+3-1 = 0
> ```
> 
> **Propiedad 4: Identidad de Pascal**
> 
> ```
> C(n,k) + C(n,k+1) = C(n+1,k+1)
> 
> Esta es la base del Triángulo de Pascal
> ```
> 
> **Propiedad 5: Máximo coeficiente**
> 
> ```
> El coeficiente máximo ocurre en el término central:
> 
> Si n es par: C(n, n/2) es el máximo
> Si n es impar: C(n, (n-1)/2) y C(n, (n+1)/2) son iguales y máximos
> ```

## 🔄 Binomio de Newton Generalizado

> [!success]- Expansión para Exponentes Negativos y Fraccionarios
> 
> **Descubrimiento de Newton:**
> 
> ```
> Para |x| < 1 y r ∈ ℝ (no necesariamente natural):
> 
> (1 + x)ʳ = Σ (r k) xᵏ  para k=0 hasta ∞
> 
> Donde (r k) = r(r-1)(r-2)...(r-k+1) / k!
> 
> Este es un coeficiente binomial generalizado
> ```
> 
> **Ejemplos importantes:**
> 
> ```
> (1 + x)⁻¹ = 1 - x + x² - x³ + x⁴ - ...
>           = Σ (-1)ᵏ xᵏ
> 
> (1 + x)⁻² = 1 - 2x + 3x² - 4x³ + 5x⁴ - ...
>           = Σ (-1)ᵏ(k+1)xᵏ
> 
> (1 + x)^(1/2) = 1 + (1/2)x - (1/8)x² + (1/16)x³ - ...
> 
> (1 + x)^(-1/2) = 1 - (1/2)x + (3/8)x² - (5/16)x³ + ...
> ```

> [!example]- Aplicación del Binomio Generalizado
> 
> **Ejemplo 1: Aproximación de √(1.1)**
> 
> ```
> √(1.1) = (1 + 0.1)^(1/2)
> 
> = 1 + (1/2)(0.1) + (1/2)(-1/2)/2! · (0.1)² + (1/2)(-1/2)(-3/2)/3! · (0.1)³ + ...
> 
> = 1 + 0.05 - 0.00125 + 0.0000625 - ...
> 
> ≈ 1.04881
> 
> (Valor exacto: 1.04881...)
> ```
> 
> **Ejemplo 2: Desarrollo de 1/(1-x)**
> 
> ```
> 1/(1-x) = (1-x)^(-1) = (1+(-x))^(-1)
> 
> = Σ (-1)ᵏ(-x)ᵏ = Σ xᵏ  para k=0 hasta ∞
> 
> = 1 + x + x² + x³ + ...
> 
> (Serie geométrica)
> ```

## 🧮 Aplicaciones del Binomio de Newton

> [!example]- Aplicaciones Algebraicas
> 
> **Expansión de polinomios:**
> 
> ```
> (x + 2)⁶ = Σ C(6,k) x^(6-k) 2^k
> 
> = x⁶ + 6x⁵(2) + 15x⁴(4) + 20x³(8) + 15x²(16) + 6x(32) + 64
> = x⁶ + 12x⁵ + 60x⁴ + 160x³ + 240x² + 192x + 64
> ```
> 
> **Simplificación de expresiones:**
> 
> ```
> (a + b)³ - (a - b)³
> = (a³ + 3a²b + 3ab² + b³) - (a³ - 3a²b + 3ab² - b³)
> = 6a²b + 2b³
> = 2b(3a² + b²)
> ```
> 
> **Ecuaciones diofánticas:**
> 
> ```
> Encontrar soluciones enteras basándose en
> expansiones del binomio
> ```

> [!example]- Aplicaciones en Análisis Combinatorio
> 
> **Conteo de subconjuntos:**
> 
> ```
> El número de subconjuntos de tamaño k en un conjunto de n elementos
> es C(n,k), que aparece como coeficiente en (a+b)ⁿ
> 
> Σ C(n,k) = 2ⁿ = número total de subconjuntos
> ```
> 
> **Distribuciones:**
> 
> ```
> El número de formas de distribuir n objetos idénticos
> entre k cajas distintas es C(n+k-1, k-1)
> 
> Relacionado con la expansión (1+x+x²+...)^k
> ```

> [!example]- Aplicaciones en Probabilidad
> 
> **Distribución binomial:**
> 
> ```
> P(X = k) = C(n,k) p^k (1-p)^(n-k)
> 
> Esta es exactamente la forma del término en (p + (1-p))ⁿ
> ```
> 
> **Ejemplo: Lanzar moneda 5 veces**
> 
> ```
> Probabilidad de exactamente 3 caras:
> C(5,3) · (1/2)³ · (1/2)² = 10 · (1/32) = 10/32 = 5/16
> ```

> [!example]- Aplicaciones en Análisis
> 
> **Series de Taylor:**
> 
> ```
> El binomio de Newton es el caso especial de series de Taylor
> para funciones potenciales
> 
> f(x) = (1+x)ⁿ desarrollado en Taylor alrededor de x=0
> da exactamente la fórmula del binomio
> ```
> 
> **Desarrollo de funciones trigonométricas:**
> 
> ```
> Se pueden usar expansiones binomiales en combinación
> con fórmulas de Euler para desarrollar sin(x), cos(x), etc.
> ```

## 🎯 Técnicas de Resolución

> [!tip]- Estrategia para Problemas del Binomio
> 
> **Paso 1: Identificar la forma**
> 
> ```
> ¿Es (a+b)ⁿ, (a-b)ⁿ, o una variación?
> ¿Es expansión completa o buscar un término específico?
> ```
> 
> **Paso 2: Elegir método**
> 
> ```
> A. Expandir completamente: usar la fórmula general
> B. Encontrar un término: usar la fórmula del término general
> C. Encontrar un coeficiente específico: identificar el k correcto
> D. Aplicación práctica: reconocer el contexto (probabilidad, etc.)
> ```
> 
> **Paso 3: Aplicar la fórmula**
> 
> ```
> (a + b)ⁿ = Σ C(n,k) a^(n-k) b^k
> 
> - Calcular los coeficientes binomiales C(n,k)
> - Aplicar potencias correctas de a y b
> - Simplificar términos
> ```
> 
> **Paso 4: Verificar**
> 
> ```
> - Comprobar el número de términos: debe ser n+1
> - Comprobar la suma de exponentes: siempre es n
> - Comprobar los coeficientes: deben ser simétricos
> ```

## 🎪 Problemas Resueltos

> [!example]- Problema 1: Expansión Directa
> 
> **Enunciado:**
> 
> ```
> Expandir (2x - 3y)⁴
> ```
> 
> **Solución:**
> 
> ```
> (2x - 3y)⁴ = Σ C(4,k) (2x)^(4-k) (-3y)^k
> 
> k=0: C(4,0)(2x)⁴(-3y)⁰ = 1 · 16x⁴ · 1 = 16x⁴
> k=1: C(4,1)(2x)³(-3y)¹ = 4 · 8x³ · (-3y) = -96x³y
> k=2: C(4,2)(2x)²(-3y)² = 6 · 4x² · 9y² = 216x²y²
> k=3: C(4,3)(2x)¹(-3y)³ = 4 · 2x · (-27y³) = -216xy³
> k=4: C(4,4)(2x)⁰(-3y)⁴ = 1 · 1 · 81y⁴ = 81y⁴
> 
> Resultado: 16x⁴ - 96x³y + 216x²y² - 216xy³ + 81y⁴
> ```

> [!example]- Problema 2: Encontrar un Término Específico
> 
> **Enunciado:**
> 
> ```
> En la expansión de (3x² + 1/x)⁶,
> encuentra el término que no contiene x
> ```
> 
> **Solución:**
> 
> ```
> El término general es:
> Tₖ₊₁ = C(6,k) (3x²)^(6-k) (1/x)^k
>      = C(6,k) · 3^(6-k) · x^(2(6-k)) · x^(-k)
>      = C(6,k) · 3^(6-k) · x^(12-2k-k)
>      = C(6,k) · 3^(6-k) · x^(12-3k)
> 
> Para que no haya x, necesitamos:
> 12 - 3k = 0
> k = 4
> 
> Por lo tanto:
> T₅ = C(6,4) · 3^(6-4) · x⁰
>    = 15 · 3² · 1
>    = 15 · 9
>    = 135
> ```

> [!example]- Problema 3: Coeficiente de un Término
> 
> **Enunciado:**
> 
> ```
> En la expansión de (√x + 1/∛x)⁸,
> encuentra el coeficiente de x
> ```
> 
> **Solución:**
> 
> ```
> Reescribimos: (x^(1/2) + x^(-1/3))⁸
> 
> El término general es:
> Tₖ₊₁ = C(8,k) (x^(1/2))^(8-k) (x^(-1/3))^k
>      = C(8,k) x^((8-k)/2) x^(-k/3)
>      = C(8,k) x^((8-k)/2 - k/3)
> 
> Necesitamos el exponente igual a 1:
> (8-k)/2 - k/3 = 1
> 3(8-k) - 2k = 6          [multiplicar por 6]
> 24 - 3k - 2k = 6
> 24 - 5k = 6
> 5k = 18
> k = 18/5 = 3.6
> 
> Como k no es entero, no hay término con x exactamente.
> Probamos con los enteros cercanos:
> 
> Si k=3: exponente = (8-3)/2 - 3/3 = 2.5 - 1 = 1.5  (no)
> Si k=4: exponente = (8-4)/2 - 4/3 = 2 - 1.333... = 0.666...  (no)
> 
> No hay término con x exacto en esta expansión.
> ```

> [!example]- Problema 4: Suma de Coeficientes
> 
> **Enunciado:**
> 
> ```
> Encuentra la suma de los coeficientes en la expansión de
> (2x - 3)⁵
> ```
> 
> **Solución:**
> 
> ```
> La suma de coeficientes se obtiene haciendo x = 1:
> 
> (2(1) - 3)⁵ = (2 - 3)⁵ = (-1)⁵ = -1
> 
> Por lo tanto, la suma de los coeficientes es -1.
> 
> Verificación desarrollando:
> (2x - 3)⁵ = Σ C(5,k) (2x)^(5-k) (-3)^k
> 
> Coeficientes:
> k=0: C(5,0) · 2⁵ · (-3)⁰ = 32
> k=1: C(5,1) · 2⁴ · (-3)¹ = 5 · 16 · (-3) = -240
> k=2: C(5,2) · 2³ · (-3)² = 10 · 8 · 9 = 720
> k=3: C(5,3) · 2² · (-3)³ = 10 · 4 · (-27) = -1080
> k=4: C(5,4) · 2¹ · (-3)⁴ = 5 · 2 · 81 = 810
> k=5: C(5,5) · 2⁰ · (-3)⁵ = 1 · 1 · (-243) = -243
> 
> Suma: 32 - 240 + 720 - 1080 + 810 - 243 = -1 ✓
> ```

> [!example]- Problema 5: Demostración Combinatoria
> 
> **Enunciado:**
> 
> ```
> Demuestra que Σ C(n,k)² = C(2n,n)  para k=0 hasta n
> ```
> 
> **Solución (Demostración Combinatoria):**
> 
> ```
> Interpretación combinatoria:
> 
> Lado izquierdo: C(n,k)²
> Significa: elegir k elementos de un conjunto A de n elementos
>          Y elegir k elementos de un conjunto B de n elementos
> 
> Total: Σ C(n,k)² = número de formas de elegir subconjuntos
>        de igual tamaño de A y B
> 
> Lado derecho: C(2n,n)
> Significa: elegir n elementos de un conjunto de 2n elementos
> 
> Argumento: Consideremos A ∪ B como conjunto de 2n elementos.
> Para cada forma de elegir n elementos de A ∪ B,
> si elegimos exactamente k de A, debemos elegir n-k de B.
> 
> Por cada k posible:
> - Formas de elegir k de A: C(n,k)
> - Formas de elegir n-k de B: C(n,n-k) = C(n,k)
> - Total para este k: C(n,k)²
> 
> Sumando sobre todos los k: Σ C(n,k)² = C(2n,n) ✓
> ```

## ⚠️ Errores Comunes

> [!warning]- Fallos Típicos con el Binomio
> 
> **1. Olvidar alternancia de signos con restas**
> 
> ```
> ✗ INCORRECTO: (a - b)² = a² - b²
> ✓ CORRECTO: (a - b)² = a² - 2ab + b²
> 
> Razón: (-b)^k da (-1)^k, causando alternancia
> ```
> 
> **2. Confundir el orden de a y b en el término general**
> 
> ```
> ✗ INCORRECTO: Término k-ésimo de (a+b)ⁿ = C(n,k) b^(n-k) a^k
> ✓ CORRECTO: Término k-ésimo = C(n,k) a^(n-k) b^k
> 
> La potencia de a disminuye, la de b aumenta
> ```
> 
> **3. Contar términos incorrectamente**
> 
> ```
> ✗ INCORRECTO: (a+b)ⁿ tiene n términos
> ✓ CORRECTO: (a+b)ⁿ tiene n+1 términos
> 
> Ejemplo: (a+b)³ = a³ + 3a²b + 3ab² + b³ (4 términos, no 3)
> ```
> 
> **4. Mal cálculo de coeficientes binomiales**
> 
> ```
> ✗ INCORRECTO: C(5,2) = 5/2 = 2.5
> ✓ CORRECTO: C(5,2) = 5!/(2!·3!) = 120/(2·6) = 10
> ```
> 
> **5. No simplificar potencias correctamente**
> 
> ```
> ✗ INCORRECTO: (2x)³ = 2x³
> ✓ CORRECTO: (2x)³ = 8x³
> 
> La potencia afecta al coeficiente también
> ```
> 
> **6. Aplicar mal la fórmula generalizada**
> 
> ```
> ✗ INCORRECTO: (1+x)^(-1) = 1 - x - x² - x³ - ...
> ✓ CORRECTO: (1+x)^(-1) = 1 - x + x² - x³ + ...
> 
> Los signos son (-1)^k, no todos negativos
> ```
> 
> **7. Ignorar el rango de validez**
> 
> ```
> ✗ INCORRECTO: (1+x)^(1/2) = 1 + (1/2)x + ... para todo x
> ✓ CORRECTO: Solo válido para |x| < 1
> 
> Fuera de este rango, la serie diverge
> ```

## 🔗 Triángulo de Pascal y el Binomio

> [!success]- Conexión con el Triángulo de Pascal
> 
> **Estructura del triángulo:**
> 
> ```
>                    Fila 0: 1                    [1]
>                   Fila 1: 1 1                   [1, 1]
>                  Fila 2: 1 2 1                  [1, 2, 1]
>                 Fila 3: 1 3 3 1                 [1, 3, 3, 1]
>                Fila 4: 1 4 6 4 1                [1, 4, 6, 4, 1]
>               Fila 5: 1 5 10 10 5 1             [1, 5, 10, 10, 5, 1]
> ```
> 
> **Relación con (a+b)ⁿ:**
> 
> ```
> La fila n contiene exactamente los coeficientes de (a+b)ⁿ
> 
> (a+b)³: coeficientes 1, 3, 3, 1  (Fila 3)
> (a+b)⁴: coeficientes 1, 4, 6, 4, 1  (Fila 4)
> ```
> 
> **Construcción del triángulo:**
> 
> ```
> Cada número es suma de los dos números arriba:
> C(n,k) = C(n-1,k-1) + C(n-1,k)
> 
> Ejemplo: 10 (en fila 5) = 4 (arriba-izq) + 6 (arriba-der)
> ```

## 🎨 Aplicaciones Prácticas Avanzadas

> [!example]- Aplicaciones en Cálculo
> 
> **Aproximación de funciones:**
> 
> ```
> Aproximar e = 2.71828...
> 
> Usamos: e^x = (1+x)·e^(x-1) cerca de x=1
> O: e = Σ 1/n! usando expansión de e^x en x=1
> 
> Con el binomio:
> (1 + 1/n)ⁿ → e cuando n → ∞
> 
> Para n = 10: (1.1)¹⁰ ≈ 2.5937
> Para n = 100: (1.01)¹⁰⁰ ≈ 2.7048
> Para n = 1000: (1.001)¹⁰⁰⁰ ≈ 2.7169
> ```
> 
> **Cálculo de límites:**
> 
> ```
> lim (1 + 1/n)ⁿ = e
> n→∞
> 
> Demostración usando binomio:
> (1 + 1/n)ⁿ = Σ C(n,k) (1/n)^k
>           = 1 + n·(1/n) + n(n-1)/2!·(1/n)² + ...
>           = 1 + 1 + (1 - 1/n)/2! + ...
>           → 1 + 1 + 1/2! + 1/3! + ... = e
> ```

> [!example]- Aplicaciones en Física
> 
> **Aproximación binomial en física:**
> 
> ```
> Muchas fórmulas físicas pueden aproximarse usando el binomio
> 
> Energía relativista:
> E = mc²/√(1 - v²/c²) = mc²(1 - v²/c²)^(-1/2)
> 
> Para v << c:
> ≈ mc²(1 + v²/(2c²)) = mc² + ½mv²
> 
> El primer término es energía en reposo
> El segundo es energía cinética clásica
> ```
> 
> **Péndulo simple:**
> 
> ```
> Período exacto: T = 4√(L/g) · ∫ dθ/√(1 - sin²(θ/2)sin²(θ₀/2))
> 
> Para amplitudes pequeñas θ₀ ≈ 0:
> Usar expansión binomial para simplificar
> T ≈ 2π√(L/g)
> ```

> [!example]- Aplicaciones en Economía y Finanzas
> 
> **Crecimiento compuesto:**
> 
> ```
> Fórmula: A = P(1 + r/n)^(nt)
> 
> Para n grande (capitalización continua):
> (1 + r/n)^n ≈ e^r usando binomio generalizado
> 
> A ≈ Pe^(rt)
> ```
> 
> **Aproximación de opciones financieras:**
> 
> ```
> Modelo binomial de opciones usa:
> Expansión de (1 + u)^n y (1 + d)^n
> 
> Para calcular precios en múltiples períodos
> ```

## 🔢 Propiedades Numéricas Especiales

> [!note]- Identidades Binomiales Importantes
> 
> **Identidad 1: Suma de fila**
> 
> ```
> Σ C(n,k) = 2ⁿ
> 
> Demostración: (1+1)ⁿ = 2ⁿ
> ```
> 
> **Identidad 2: Suma alternada**
> 
> ```
> Σ (-1)^k C(n,k) = 0 (para n > 0)
> 
> Demostración: (1-1)ⁿ = 0
> ```
> 
> **Identidad 3: Suma ponderada**
> 
> ```
> Σ k·C(n,k) = n·2^(n-1)
> 
> Demostración: Derivar (1+x)ⁿ = Σ C(n,k)x^k
> d/dx: n(1+x)^(n-1) = Σ k·C(n,k)x^(k-1)
> En x=1: n·2^(n-1) = Σ k·C(n,k)
> ```
> 
> **Identidad 4: Suma de cuadrados**
> 
> ```
> Σ C(n,k)² = C(2n,n)
> 
> Demostración: Coeficiente de x^n en (1+x)ⁿ(1+x)ⁿ = (1+x)^(2n)
> ```
> 
> **Identidad 5: Convolución de Vandermonde**
> 
> ```
> Σ C(m,k)C(n,r-k) = C(m+n,r)
> 
> Esta es fundamental en combinatoria
> ```

## 📈 Casos Límite y Asintótica

> [!note]- Comportamiento Límite
> 
> **Coeficiente binomial para n grande:**
> 
> ```
> El coeficiente máximo C(n, ⌊n/2⌋) crece como:
> C(n, n/2) ≈ 2ⁿ/√(πn/2)
> 
> Esto es la aproximación de Stirling aplicada
> ```
> 
> **Términos individuales en (a+b)ⁿ:**
> 
> ```
> A medida que n aumenta, los términos se concentran
> alrededor del término central
> 
> Esto explica por qué el binomio es fundamental en
> la distribución normal
> ```
> 
> **Convergencia de series binomiales:**
> 
> ```
> (1+x)ʳ = Σ (r k) x^k converge para |x| < 1
> 
> En los bordes x = ±1, depende del valor de r
> ```

## 🎓 Problemas Complejos

> [!example]- Problema 6: Encontrar Término sin Variable
> 
> **Enunciado:**
> 
> ```
> En la expansión de (x^(1/3) - x^(-1/2))⁹,
> encuentra el término independiente de x
> ```
> 
> **Solución:**
> 
> ```
> El término general es:
> Tₖ₊₁ = C(9,k) (x^(1/3))^(9-k) (-x^(-1/2))^k
>      = C(9,k) · x^((9-k)/3) · (-1)^k · x^(-k/2)
>      = C(9,k) · (-1)^k · x^((9-k)/3 - k/2)
> 
> Para término independiente:
> (9-k)/3 - k/2 = 0
> 2(9-k) - 3k = 0      [multiplicar por 6]
> 18 - 2k - 3k = 0
> 18 - 5k = 0
> k = 18/5
> 
> Como k debe ser entero y 18/5 = 3.6 no lo es,
> no hay término independiente en esta expansión
> 
> (Si el problema fuera diferente y k resultara entero,
> el término sería C(9,k)·(-1)^k)
> ```

> [!example]- Problema 7: Suma Combinatoria
> 
> **Enunciado:**
> 
> ```
> Calcula: Σ C(10,k)·2^k para k=0 hasta 10
> ```
> 
> **Solución:**
> 
> ```
> Reconocemos que esto es el binomio de Newton:
> (1 + 2)¹⁰ = Σ C(10,k)·1^(10-k)·2^k
>           = Σ C(10,k)·2^k
>           = 3¹⁰
>           = 59,049
> ```

> [!example]- Problema 8: Coeficiente en Expansión Múltiple
> 
> **Enunciado:**
> 
> ```
> En la expansión de (1 + x + x²)³,
> encuentra el coeficiente de x⁴
> ```
> 
> **Solución:**
> 
> ```
> Método 1: Expandir como potencia de trinomio
> (1 + x + x²)³ = [(1 + x(1 + x))]³
> 
> O más directo, usando multinomio:
> (1 + x + x²)³ = Σ (3!)/(n₀!n₁!n₂!) · 1^n₀ · x^n₁ · (x²)^n₂
> 
> Donde n₀ + n₁ + n₂ = 3 y queremos n₁ + 2n₂ = 4
> 
> Casos posibles:
> 1) n₁=4, n₂=0: imposible pues n₁ ≤ 3
> 2) n₁=2, n₂=1: n₀=0, n₁+n₂=3 ✓
>    Contribución: (3!)/(0!2!1!) = 3
> 3) n₁=0, n₂=2: n₀=1, n₁+n₂=2, pero necesitamos 3 ✗
> 
> Por lo tanto, coeficiente de x⁴ = 3
> ```

> [!example]- Problema 9: Aplicación a Probabilidad
> 
> **Enunciado:**
> 
> ```
> Un dado se lanza 5 veces. ¿Cuál es la probabilidad
> de obtener exactamente 3 números pares?
> ```
> 
> **Solución:**
> 
> ```
> Probabilidad de par en un lanzamiento: p = 3/6 = 1/2
> Probabilidad de impar: q = 1/2
> 
> Usamos distribución binomial:
> P(X=3) = C(5,3) · (1/2)³ · (1/2)²
>        = 10 · (1/8) · (1/4)
>        = 10/32
>        = 5/16
> 
> Este es exactamente el coeficiente C(5,3) de (p+q)⁵
> cuando p = q = 1/2
> ```

> [!example]- Problema 10: Demostración Analítica
> 
> **Enunciado:**
> 
> ```
> Demuestra que:
> Σ C(n,k)·cos(kθ) = 2^(n-1)·cos(nθ/2)·cos((n-1)θ/2)
> ```
> 
> **Solución (Esquema):**
> 
> ```
> Usa la expansión:
> (1 + e^(iθ))ⁿ = Σ C(n,k) e^(ikθ)
> 
> Parte real:
> (1 + cos(θ) + i·sin(θ))ⁿ tiene parte real igual a Σ C(n,k)·cos(kθ)
> 
> Convertir 1 + e^(iθ):
> 1 + e^(iθ) = e^(iθ/2)(e^(-iθ/2) + e^(iθ/2))
>            = e^(iθ/2) · 2cos(θ/2)
> 
> Por lo tanto:
> (1 + e^(iθ))ⁿ = e^(inθ/2) · 2^n · cos^n(θ/2)
> 
> Tomando parte real y simplificando:
> Σ C(n,k)·cos(kθ) = 2^n·cos^n(θ/2)·cos(nθ/2)
> 
> (Nota: La fórmula exacta requiere más cálculos)
> ```
