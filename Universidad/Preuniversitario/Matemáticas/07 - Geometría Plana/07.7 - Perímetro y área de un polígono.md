# 📏 Perímetro y Área de un Polígono

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva **El perímetro de un polígono es la longitud total de su contorno, mientras que el área es la medida de la superficie que encierra. Estos conceptos fundamentales cuantifican dos aspectos esenciales: la frontera (perímetro) y el contenido (área) de cualquier región poligonal.**
> 
> **Características clave:**
> 
> - **Perímetro (P):** Suma de longitudes de todos los lados
>     - Medida unidimensional (longitud)
>     - Unidades: cm, m, km, etc.
> - **Área (A):** Extensión de la superficie interior
>     - Medida bidimensional (superficie)
>     - Unidades: cm², m², km², etc.
> - **Independencia:** Polígonos diferentes pueden tener igual perímetro o igual área
> - **Isoperimetría:** Para perímetro fijo, el círculo maximiza el área

## 📐 Perímetro de Polígonos

> [!important]- Definición y Cálculo **Definición formal:**
> 
> ```
> El perímetro P de un polígono es la suma
> de las longitudes de todos sus lados
> 
> Para polígono con n lados: l₁, l₂, ..., lₙ
> 
> P = l₁ + l₂ + l₃ + ... + lₙ = Σ lᵢ
>                                i=1 to n
> ```
> 
> **Polígonos regulares:**
> 
> ```
> Polígono regular de n lados, cada uno de longitud a:
> 
> P = n × a
> 
> Ejemplos:
> • Triángulo equilátero: P = 3a
> • Cuadrado: P = 4a
> • Pentágono regular: P = 5a
> • Hexágono regular: P = 6a
> • n-ágono regular: P = na
> ```
> 
> **Fórmulas específicas:**
> 
> ```
> Triángulo:
> P = a + b + c
> 
> Cuadrilátero:
> P = a + b + c + d
> 
> Rectángulo (lados a, b):
> P = 2(a + b) = 2a + 2b
> 
> Rombo (lado a):
> P = 4a
> 
> Trapecio (lados a, b, c, d):
> P = a + b + c + d
> ```
> 
> **Con coordenadas:**
> 
> ```
> Vértices: (x₁,y₁), (x₂,y₂), ..., (xₙ,yₙ)
> 
> Distancia entre vértices consecutivos:
> lᵢ = √[(xᵢ₊₁ - xᵢ)² + (yᵢ₊₁ - yᵢ)²]
> 
> Perímetro:
> P = Σ √[(xᵢ₊₁ - xᵢ)² + (yᵢ₊₁ - yᵢ)²]
>     i=1 to n
> 
> donde (xₙ₊₁, yₙ₊₁) = (x₁, y₁)
> ```

## 📊 Área de Polígonos

> [!success]- Métodos de Cálculo **1. Descomposición en triángulos:**
> 
> ```
> Todo polígono puede dividirse en triángulos
> 
> Área del polígono = Σ áreas de triángulos
> 
> Método:
> 1. Elegir un vértice (o punto interior)
> 2. Trazar diagonales desde ese punto
> 3. Calcular área de cada triángulo
> 4. Sumar todas las áreas
> 
> Para polígono de n lados:
> Se forman (n-2) triángulos
> ```
> 
> **2. Fórmula del agrimensor (coordenadas):**
> 
> ```
> Vértices en orden: (x₁,y₁), (x₂,y₂), ..., (xₙ,yₙ)
> 
> A = (1/2)|x₁(y₂-yₙ) + x₂(y₃-y₁) + ... + xₙ(y₁-yₙ₋₁)|
> 
> Forma compacta:
> A = (1/2)|Σ(xᵢyᵢ₊₁ - xᵢ₊₁yᵢ)|
>          i=1 to n
> 
> donde (xₙ₊₁, yₙ₊₁) = (x₁, y₁)
> 
> Forma de determinante:
> A = (1/2)|Σ det([xᵢ  yᵢ ])|
>          [xᵢ₊₁ yᵢ₊₁]
> 
> Signo indica orientación:
> + : antihorario
> - : horario
> ```
> 
> **3. Para polígonos regulares:**
> 
> ```
> Polígono regular de n lados, longitud a:
> 
> A = (1/4) × n × a² × cot(π/n)
> 
> O usando apotema (distancia centro a lado):
> A = (1/2) × perímetro × apotema
> A = (1/2) × P × ap
> 
> Apotema: ap = a/(2 tan(π/n))
> 
> Fórmulas específicas:
> 
> Triángulo equilátero:
> A = (a²√3)/4
> 
> Cuadrado:
> A = a²
> 
> Pentágono regular:
> A = (a²/4)√(25 + 10√5)
> 
> Hexágono regular:
> A = (3a²√3)/2
> 
> Octógono regular:
> A = 2a²(1 + √2)
> ```
> 
> **4. Con diagonales:**
> 
> ```
> Cuadrilátero con diagonales p, q y ángulo θ:
> A = (1/2)pq sen θ
> 
> Especialmente útil para:
> • Rombos (θ = 90°)
> • Cuadriláteros simples
> ```

## 📐 Áreas de Polígonos Específicos

> [!note]- Fórmulas Detalladas **Triángulos:**
> 
> ```
> 1. Base-altura:
>    A = (1/2)bh
> 
> 2. Fórmula de Herón (tres lados):
>    A = √[s(s-a)(s-b)(s-c)]
>    donde s = (a+b+c)/2
> 
> 3. Dos lados y ángulo:
>    A = (1/2)ab sen C
> 
> 4. Coordenadas:
>    A = (1/2)|x₁(y₂-y₃) + x₂(y₃-y₁) + x₃(y₁-y₂)|
> ```
> 
> **Cuadriláteros:**
> 
> ```
> Rectángulo (lados a, b):
> A = ab
> 
> Cuadrado (lado a):
> A = a²
> 
> Paralelogramo (base b, altura h):
> A = bh
> O: A = ab sen α (lados a,b, ángulo α)
> 
> Rombo (diagonales p, q):
> A = (pq)/2
> 
> Trapecio (bases B, b, altura h):
> A = ((B + b)/2)h
> 
> Cuadrilátero general (Bretschneider):
> A = √[(s-a)(s-b)(s-c)(s-d) - abcd·cos²((α+γ)/2)]
> 
> Cuadrilátero cíclico (Brahmagupta):
> A = √[(s-a)(s-b)(s-c)(s-d)]
> ```
> 
> **Pentágono:**
> 
> ```
> Regular (lado a):
> A = (a²/4)√(25 + 10√5)
> A ≈ 1.720 a²
> 
> Apotema: ap = (a/2)√(5 + 2√5)
> ```
> 
> **Hexágono:**
> 
> ```
> Regular (lado a):
> A = (3a²√3)/2
> A ≈ 2.598 a²
> 
> Con radio circunscrito R:
> A = (3R²√3)/2
> 
> Apotema: ap = (a√3)/2
> 
> Descomposición:
> 6 triángulos equiláteros desde el centro
> ```
> 
> **Octógono:**
> 
> ```
> Regular (lado a):
> A = 2a²(1 + √2)
> A ≈ 4.828 a²
> 
> Apotema: ap = (a/2)(1 + √2)
> ```

## 🎯 Propiedades y Teoremas

> [!important]- Relaciones Fundamentales **Desigualdad isoperimétrica:**
> 
> ```
> Para perímetro fijo P:
> 
> A ≤ P²/(4π)
> 
> con igualdad solo para el círculo
> 
> Entre polígonos con n lados y perímetro P:
> El regular tiene área máxima
> 
> Consecuencia:
> El círculo es el "límite" de polígonos regulares
> cuando n → ∞
> ```
> 
> **Teorema de Pick:**
> 
> ```
> Para polígono simple en red de puntos enteros:
> 
> A = I + (B/2) - 1
> 
> donde:
> I = número de puntos interiores
> B = número de puntos en el borde
> 
> Ejemplo: Cuadrado unitario
> I = 0, B = 4
> A = 0 + 4/2 - 1 = 1 ✓
> ```
> 
> **Relación perímetro-área:**
> 
> ```
> Para polígono regular de n lados:
> 
> A = (P²)/(4n tan(π/n))
> 
> Cuando n → ∞:
> A → P²/(4π) (círculo)
> 
> Radio inscrito:
> r = A/s = 2A/P
> donde s es el semiperímetro
> ```
> 
> **Área bajo transformaciones:**
> 
> ```
> Homotecia de razón k:
> • Perímetro se multiplica por k
> • Área se multiplica por k²
> 
> Rotación o traslación:
> • Perímetro invariante
> • Área invariante
> 
> Reflexión:
> • Perímetro invariante
> • Área invariante (valor absoluto)
> ```

## 🧮 Problemas Resueltos

> [!example]- Ejemplos Detallados **Problema 1: Perímetro de pentágono**
> 
> ```
> Pentágono con vértices:
> A(0,0), B(4,0), C(5,3), D(2,5), E(-1,3)
> 
> SOLUCIÓN:
> 
> Calcular cada lado:
> AB = √[(4-0)² + (0-0)²] = 4
> BC = √[(5-4)² + (3-0)²] = √10 ≈ 3.16
> CD = √[(2-5)² + (5-3)²] = √13 ≈ 3.61
> DE = √[(-1-2)² + (3-5)²] = √13 ≈ 3.61
> EA = √[(0-(-1))² + (0-3)²] = √10 ≈ 3.16
> 
> P = 4 + √10 + √13 + √13 + √10
> P = 4 + 2√10 + 2√13
> P ≈ 17.54 unidades
> ```
> 
> **Problema 2: Área con fórmula del agrimensor**
> 
> ```
> Cuadrilátero con vértices:
> A(1,1), B(4,2), C(5,5), D(2,4)
> 
> SOLUCIÓN:
> 
> Fórmula del agrimensor:
> A = (1/2)|x₁(y₂-y₄) + x₂(y₃-y₁) + x₃(y₄-y₂) + x₄(y₁-y₃)|
> 
> A = (1/2)|1(2-4) + 4(5-1) + 5(4-2) + 2(1-5)|
> A = (1/2)|1(-2) + 4(4) + 5(2) + 2(-4)|
> A = (1/2)|-2 + 16 + 10 - 8|
> A = (1/2)|16|
> A = 8 unidades²
> ```
> 
> **Problema 3: Hexágono regular**
> 
> ```
> Hexágono regular inscrito en círculo de radio R = 6 cm
> Calcular perímetro y área
> 
> SOLUCIÓN:
> 
> Para hexágono regular inscrito:
> lado = radio = R = 6 cm
> 
> Perímetro:
> P = 6a = 6(6) = 36 cm
> 
> Área:
> A = (3a²√3)/2
> A = (3(36)√3)/2
> A = (108√3)/2
> A = 54√3 ≈ 93.53 cm²
> 
> O usando radio:
> A = (3R²√3)/2 = (3(36)√3)/2 = 54√3 ✓
> ```
> 
> **Problema 4: Trapecio con coordenadas**
> 
> ```
> Trapecio ABCD con:
> A(0,0), B(6,0), C(5,4), D(1,4)
> 
> Calcular perímetro y área
> 
> SOLUCIÓN:
> 
> Perímetro:
> AB = 6
> BC = √[(5-6)² + (4-0)²] = √17 ≈ 4.12
> CD = 4
> DA = √[(0-1)² + (0-4)²] = √17 ≈ 4.12
> 
> P = 6 + √17 + 4 + √17 = 10 + 2√17 ≈ 18.25
> 
> Área (fórmula del agrimensor):
> A = (1/2)|0(0-4) + 6(4-0) + 5(4-0) + 1(0-4)|
> A = (1/2)|0 + 24 + 20 - 4|
> A = (1/2)|40|
> A = 20 unidades²
> 
> Verificación (trapecio):
> Bases: AB = 6, CD = 4
> Altura: h = 4
> A = ((6+4)/2)(4) = 5(4) = 20 ✓
> ```
> 
> **Problema 5: Teorema de Pick**
> 
> ```
> Polígono en red con:
> 12 puntos en el interior
> 8 puntos en el borde
> 
> SOLUCIÓN:
> 
> Fórmula de Pick:
> A = I + (B/2) - 1
> A = 12 + (8/2) - 1
> A = 12 + 4 - 1
> A = 15 unidades²
> ```
> 
> **Problema 6: Polígono regular de 10 lados**
> 
> ```
> Decágono regular con lado a = 5 cm
> Calcular perímetro, apotema y área
> 
> SOLUCIÓN:
> 
> Perímetro:
> P = 10a = 10(5) = 50 cm
> 
> Apotema:
> ap = a/(2 tan(π/10))
> ap = 5/(2 tan 18°)
> ap ≈ 5/(2 × 0.3249)
> ap ≈ 7.69 cm
> 
> Área:
> A = (1/2)P × ap
> A = (1/2)(50)(7.69)
> A ≈ 192.25 cm²
> 
> O directamente:
> A = (1/4) × 10 × 25 × cot(18°)
> A = (250/4) × 3.078
> A ≈ 192.25 cm²
> ```

## 🔍 Métodos Especiales

> [!tip]- Técnicas Avanzadas **Método de exhausción (Arquímedes):**
> 
> ```
> Aproximar área de figura curva con polígonos:
> 
> 1. Inscribir polígono de n lados
> 2. Circunscribir polígono de n lados
> 3. Área real está entre ambas
> 4. Aumentar n para mejorar aproximación
> 
> Ejemplo: Aproximar área de círculo
> n = 6: hexágonos → π ≈ 3
> n = 96: polígonos de 96 lados → π ≈ 3.14
> ```
> 
> **Integración (cálculo):**
> 
> ```
> Para región R delimitada por polígono:
> 
> A = ∫∫_R dx dy
> 
> Teorema de Green:
> A = (1/2)∮_∂R (x dy - y dx)
> 
> Generaliza fórmula del agrimensor
> ```
> 
> **Área con vectores:**
> 
> ```
> Vértices: P₀, P₁, ..., Pₙ₋₁
> 
> Vectores desde origen:
> r₀, r₁, ..., rₙ₋₁
> 
> Área:
> A = (1/2)|Σ (rᵢ × rᵢ₊₁)|
>          i=0 to n-1
> 
> donde × es el producto cruz (componente z)
> ```
> 
> **Cuadrículas:**
> 
> ```
> Para polígono irregular en cuadrícula:
> 
> 1. Contar cuadrados completos
> 2. Aproximar cuadrados parciales
> 3. Sumar para estimar área
> 
> Refinamiento: usar cuadrícula más fina
> ```

## 📐 Polígonos Regulares

> [!success]- Tabla de Fórmulas **Resumen para polígono regular de n lados:**
> 
> ```
> Lado: a
> 
> Ángulo central: θ = 360°/n = 2π/n
> Ángulo interior: αᵢ = (n-2)×180°/n = (n-2)π/n
> Ángulo exterior: αₑ = 360°/n = 2π/n
> 
> Radio circunscrito (vértices):
> R = a/(2 sen(π/n))
> 
> Apotema (radio inscrito):
> ap = a/(2 tan(π/n))
> 
> Relación: R = ap/cos(π/n)
> 
> Perímetro:
> P = na
> 
> Área:
> A = (na²/4) cot(π/n)
> A = (1/2)P × ap
> A = (nR²/2) sen(2π/n)
> A = n × ap² × tan(π/n)
> ```
> 
> **Tabla de valores comunes:**
> 
> ```
> n | Nombre      | Ángulo int. | A/a²
> --|-------------|-------------|-------
> 3 | Triángulo   | 60°         | 0.433
> 4 | Cuadrado    | 90°         | 1.000
> 5 | Pentágono   | 108°        | 1.720
> 6 | Hexágono    | 120°        | 2.598
> 7 | Heptágono   | 128.57°     | 3.634
> 8 | Octágono    | 135°        | 4.828
> 9 | Eneágono    | 140°        | 6.182
> 10| Decágono    | 144°        | 7.694
> 12| Dodecágono  | 150°        | 11.196
> ∞ | Círculo     | 180°        | π ≈ 3.142
> ```

## 🎨 Estrategias de Cálculo

> [!note]- Guía Práctica **Elección del método:**
> 
> ```
> Tipo de polígono → Método recomendado
> 
> Triángulo:
> • Base-altura si se conoce altura
> • Herón si se conocen tres lados
> • Coordenadas si están en plano
> 
> Cuadrilátero:
> • Fórmulas específicas (rectángulo, rombo)
> • Descomposición en triángulos
> • Coordenadas (agrimensor)
> 
> Polígono regular:
> • Fórmula directa con lado o radio
> • Descomposición en triángulos desde centro
> 
> Polígono irregular:
> • Fórmula del agrimensor (coordenadas)
> • Descomposición en triángulos
> • Teorema de Pick (en red)
> 
> Polígono complejo:
> • División en polígonos simples
> • Suma algebraica de áreas
> ```
> 
> **Pasos generales:**
> 
> ```
> 1. Identificar tipo de polígono
> 2. Listar datos conocidos
> 3. Elegir método apropiado
> 4. Aplicar fórmula
> 5. Verificar unidades
> 6. Comprobar razonabilidad del resultado
> ```

## ⚠️ Errores Comunes

> [!warning]- Malentendidos Frecuentes **1. "Perímetro = 4 × lado" para todo cuadrilátero**
> 
> ```
> ✗ FALSO
> 
> Solo para cuadrado y rombo
> En general: P = suma de todos los lados
> ```
> 
> **2. "Área = (perímetro)²"**
> 
> ```
> ✗ FALSO
> 
> No existe tal relación universal
> Depende completamente de la forma
> ```
> 
> **3. Confundir apotema con radio**
> 
> ```
> ✗ FALSO
> 
> Apotema: distancia centro a lado (perpendicular)
> Radio: distancia centro a vértice
> 
> R > ap (siempre)
> ```
> 
> **4. "Doblar los lados duplica el área"**
> 
> ```
> ✗ FALSO
> 
> Si lados × 2, entonces:
> • Perímetro × 2
> • Área × 4
> 
> (homotecia de razón k: área × k²)
> ```
> 
> **5. Olvidar el factor 1/2 en fórmula del agrimensor**
> 
> ```
> ✗ ERROR COMÚN
> 
> A = (1/2)|suma|, no solo |suma|
> ```
> 
> **6. Usar fórmula del triángulo para cuadrilátero**
> 
> ```
> ✗ FALSO
> 
> No existe "base × altura" simple para cuadrilátero
> (excepto paralelogramo y trapecio)
> ```

## 🎯 Problemas Adicionales

> [!example]- Ejercicios Variados **Problema 7: Área de polígono estrellado**
> 
> ```
> Estrella de 5 puntas con vértices alternados:
> Exteriores en círculo R = 5
> Interiores en círculo r = 2
> 
> SOLUCIÓN:
> 
> Área = 5 triángulos isósceles
> Base de cada triángulo: lado del pentágono en R
> Altura: desde círculo interior
> 
> Lado pentágono: a = 2R sen(36°) ≈ 5.88
> 
> Área de cada triángulo:
> A_tri ≈ (1/2)(5.88)(5-2) = 8.82
> 
> Área total: 5 × 8.82 ≈ 44.1 unidades²
> 
> (Método alternativo: área pentágono grande 
>  menos área pentágono pequeño)
> ```
> 
> **Problema 8: Optimización**
> 
> ```
> Dado perímetro P = 40 cm, encontrar polígono
> regular que maximiza el área
> 
> SOLUCIÓN:
> 
> Para n lados:
> Lado: a = P/n = 40/n
> 
> Área: A = (P²/(4n)) cot(π/n)
> 
> Cuando n → ∞, A → P²/(4π) (círculo)
> A_círculo = 1600/(4π) ≈ 127.32 cm²
> 
> Conclusión: El círculo maximiza el área (desigualdad isoperimétrica)
> 
> Entre polígonos regulares finitos: Mayor n → mayor área
> ```

## 🔬 Propiedades Avanzadas

> [!success]- Resultados Profundos **Desigualdad de Zenodoro:**
> 
> ```
> Entre todos los polígonos de n lados
> con perímetro fijo, el regular tiene área máxima
> 
> Para n fijo y P fijo:
> A ≤ (P²/(4n)) cot(π/n)
> 
> con igualdad solo para polígono regular
> ```
> 
> **Teorema de Euler para poliedros (relacionado):**
> 
> ```
> V - A + C = 2
> 
> donde:
> V = vértices
> A = aristas  
> C = caras
> 
> Para polígono en el plano (C = 2: interior + exterior):
> V - A + 2 = 2
> ⟹ V = A (obvio: cada vértice conecta a 2 aristas)
> ```
> 
> **Área máxima con n lados y longitudes fijas:**
> 
> ```
> Dados n lados de longitudes a₁, a₂, ..., aₙ
> 
> El área se maximiza cuando el polígono
> puede inscribirse en un círculo
> (polígono cíclico)
> 
> Condición: ángulos opuestos suplementarios
> (para n = 4)
> ```
> 
> **Fórmula de L'Huilier (generalización de Herón):**
> 
> ```
> Para cuadrilátero cíclico:
> 
> A = √[(s-a)(s-b)(s-c)(s-d)]
> 
> Generalización para n-ágono cíclico es compleja
> ```

## 🎨 Construcciones Geométricas

> [!note]- Métodos Prácticos **Dividir polígono en partes iguales:**
> 
> ```
> Para dividir polígono en n partes de igual área:
> 
> Método 1: Líneas desde un vértice
> • Trazar diagonales desde un vértice
> • Cada triángulo resultante ajustar
> 
> Método 2: Líneas paralelas
> • Para figuras convexas simples
> • Calcular alturas apropiadas
> 
> Método 3: Ham sandwich theorem
> • Cualquier línea puede bisecar el área
>   (orientación correcta)
> ```
> 
> **Construir polígono dada área:**
> 
> ```
> Polígono regular de n lados con área A:
> 
> 1. Despejar lado:
>    a = √(4A/(n cot(π/n)))
> 
> 2. Construir ángulo central: 360°/n
> 
> 3. Marcar n vértices en círculo
> 
> 4. Conectar vértices consecutivos
> ```
> 
> **Aproximar círculo con polígonos:**
> 
> ```
> Método de Arquímedes:
> 
> 1. Empezar con hexágono (n = 6)
> 2. Duplicar lados: n → 2n
> 3. Calcular nuevo perímetro
> 4. Repetir hasta precisión deseada
> 
> Convergencia:
> P_n → 2πR cuando n → ∞
> A_n → πR² cuando n → ∞
> ```

## 🧩 Problemas Especiales

> [!example]- Desafíos Avanzados **Problema 9: Polígono con área máxima inscrito**
> 
> ```
> Inscribir cuadrilátero de área máxima
> en triángulo dado (lados 6, 8, 10)
> 
> SOLUCIÓN:
> 
> El cuadrilátero óptimo tiene:
> • Un lado coincide con el lado mayor del triángulo
> • Los otros tres vértices dividen los otros
>   dos lados en proporciones específicas
> 
> Para triángulo rectángulo 6-8-10:
> Área triángulo = 24
> 
> Área máxima del cuadrilátero ≈ 16
> (2/3 del área del triángulo)
> ```
> 
> **Problema 10: Polígono cóncavo**
> 
> ```
> Calcular área de polígono cóncavo:
> A(0,0), B(4,0), C(6,3), D(3,2), E(2,4), F(0,3)
> 
> SOLUCIÓN:
> 
> Fórmula del agrimensor funciona también:
> 
> A = (1/2)|0(0-3) + 4(3-0) + 6(2-0) + 
>          3(4-3) + 2(3-2) + 0(0-4)|
> 
> A = (1/2)|0 + 12 + 12 + 3 + 2 + 0|
> A = (1/2)|29|
> A = 14.5 unidades²
> 
> Nota: El signo automáticamente maneja concavidad
> ```
> 
> **Problema 11: Área entre polígonos**
> 
> ```
> Hexágono regular de lado 4 cm
> con hexágono regular inscrito de lado 2 cm
> (vértices en puntos medios)
> 
> Calcular área de la corona hexagonal
> 
> SOLUCIÓN:
> 
> Área hexágono grande:
> A₁ = (3(4²)√3)/2 = 24√3 cm²
> 
> Área hexágono pequeño:
> A₂ = (3(2²)√3)/2 = 6√3 cm²
> 
> Área corona:
> A = A₁ - A₂ = 24√3 - 6√3 = 18√3 ≈ 31.18 cm²
> ```
> 
> **Problema 12: Escalamiento no uniforme**
> 
> ```
> Rectángulo 6×4 se escala:
> • Horizontal: factor 1.5
> • Vertical: factor 2
> 
> Calcular nuevo perímetro y área
> 
> SOLUCIÓN:
> 
> Original: P = 20, A = 24
> 
> Nuevo rectángulo: 9×8
> 
> Perímetro:
> P_nuevo = 2(9 + 8) = 34
> Factor: 34/20 = 1.7
> 
> Área:
> A_nuevo = 9 × 8 = 72
> Factor: 72/24 = 3 = 1.5 × 2 ✓
> 
> Conclusión: Área se multiplica por
> producto de factores de escala
> ```

## 📐 Fórmulas de Conversión

> [!important]- Unidades y Escalas **Conversión de unidades lineales:**
> 
> ```
> Perímetro:
> 1 m = 100 cm = 1000 mm
> 1 km = 1000 m
> 1 in = 2.54 cm
> 1 ft = 30.48 cm = 12 in
> 1 yd = 91.44 cm = 3 ft
> 1 mi = 1.609 km = 5280 ft
> ```
> 
> **Conversión de unidades de área:**
> 
> ```
> Área:
> 1 m² = 10,000 cm² = 1,000,000 mm²
> 1 km² = 1,000,000 m² = 100 ha
> 1 ha (hectárea) = 10,000 m²
> 1 acre = 4,047 m²
> 1 in² = 6.4516 cm²
> 1 ft² = 929.03 cm²
> 1 mi² = 2.59 km²
> 
> Regla: (factor lineal)² = factor de área
> ```
> 
> **Escalas en mapas:**
> 
> ```
> Escala 1:n significa:
> • 1 cm en mapa = n cm en realidad
> 
> Si escala es 1:10,000:
> • Perímetro real = perímetro mapa × 10,000
> • Área real = área mapa × 10,000²
> 
> Ejemplo: Polígono en mapa 1:50,000
> Área en mapa: 8 cm²
> Área real: 8 × 50,000² = 20,000,000,000 cm²
>          = 2 km²
> ```

## 🎯 Aplicaciones en Geometría Computacional

> [!tip]- Algoritmos **Detección de punto interior:**
> 
> ```
> ¿Punto P está dentro del polígono?
> 
> Algoritmo ray casting:
> 1. Trazar rayo desde P hacia infinito
> 2. Contar intersecciones con lados
> 3. Si impar: P interior
>    Si par: P exterior
> 
> Complejidad: O(n) donde n = número de lados
> ```
> 
> **Triangulación de polígonos:**
> 
> ```
> Dividir polígono de n vértices en (n-2) triángulos
> 
> Algoritmo ear clipping:
> 4. Encontrar "oreja" (triángulo sin vértices internos)
> 5. Remover oreja
> 6. Repetir hasta quedar un triángulo
> 
> Uso: renderizado 3D, análisis de elementos finitos
> ```
> 
> **Casco convexo:**
> 
> ```
> Encontrar polígono convexo mínimo que
> contiene todos los puntos
> 
> Algoritmo de Graham:
> 7. Encontrar punto más bajo
> 8. Ordenar por ángulo polar
> 9. Construir casco iterativamente
> 
> Complejidad: O(n log n)
> ```

## 🌟 Curiosidades Matemáticas

> [!note]- Hechos Interesantes **Problema de la cerca:**
> 
> ```
> Con 100 m de cerca, ¿qué forma maximiza el área?
> 
> Respuesta: Círculo (no polígono)
> A_círculo = P²/(4π) ≈ 795.77 m²
> 
> Entre polígonos regulares:
> Cuadrado: 625 m²
> Hexágono: 722.69 m²
> Dodecágono: 773.37 m²
> 
> El círculo es ~27% más eficiente que el cuadrado
> ```
> 
> **Paradoja de Banach-Tarski (relacionada):**
> 
> ```
> En 3D, se puede descomponer una esfera
> en piezas finitas y reensamblarlas en
> dos esferas del mismo tamaño
> 
> (No aplica a polígonos 2D por teorema de Pick
>  y conservación de área)
> ```
> 
> **Polígonos en la naturaleza:**
> 
> ```
> • Panales de abejas: hexágonos regulares
>   (máxima eficiencia de área/perímetro)
> • Cristales de hielo: hexágonos
> • Basalto columnar: hexágonos irregulares
> • Caparazones de tortugas: polígonos irregulares
> ```
> 
> **Número de diagonales:**
> 
> ```
> Polígono de n lados tiene:
> d = n(n-3)/2 diagonales
> 
> Ejemplos:
> n=4: d = 2
> n=5: d = 5
> n=6: d = 9
> n=10: d = 35
> ```

## 📈 Límites y Convergencia

> [!success]- Comportamiento Asintótico **Polígonos regulares → Círculo:**
> 
> ```
> Para polígono regular de n lados inscrito
> en círculo de radio R:
> 
> Perímetro:
> P_n = 2nR sen(π/n)
> 
> lim P_n = lim 2nR sen(π/n) = 2πR
> n→∞     n→∞
> 
> (usando lim sen(x)/x = 1 cuando x→0)
>    x→0
> 
> Área:
> A_n = (nR²/2) sen(2π/n)
> 
> lim A_n = πR²
> n→∞
> ```
> 
> **Razón área/perímetro²:**
> 
> ```
> Para polígono regular de n lados:
> 
> Q_n = A/P² = cot(π/n)/(4n)
> 
> lim Q_n = 1/(4π)
> n→∞
> 
> (razón del círculo)
> 
> Eficiencia aumenta con n
> ```

> def area_polygon(vertices):
>     """Calcula área usando fórmula del agrimensor"""
>     n = len(vertices)
>     area = 0
>     for i in range(n):
>         j = (i + 1) % n
>         area += vertices[i][0] * vertices[j][1]
>         area -= vertices[j][0] * vertices[i][1]
>     return abs(area) / 2
> 
> def perimeter_polygon(vertices):
>     """Calcula perímetro"""
>     n = len(vertices)
>     perimeter = 0
>     for i in range(n):
>         j = (i + 1) % n
>         dx = vertices[j][0] - vertices[i][0]
>         dy = vertices[j][1] - vertices[i][1]
>         perimeter += (dx**2 + dy**2)**0.5
>     return perimeter
> ```

## 📚 Resumen de Fórmulas Clave

> [!important]- Referencia Rápida **Perímetro:**
> 
> ```
> General: P = Σ lᵢ (suma de lados)
> Regular: P = n × a
> Coordenadas: P = Σ √[(Δx)² + (Δy)²]
> ```
> 
> **Área - Métodos principales:**
> 
> ```
> 1. Coordenadas (agrimensor):
>    A = (1/2)|Σ(xᵢyᵢ₊₁ - xᵢ₊₁yᵢ)|
> 
> 2. Polígono regular:
>    A = (na²/4) cot(π/n)
>    A = (1/2)P × apotema
> 
> 3. Descomposición:
>    A = Σ A_triángulos
> 
> 4. Pick (red entera):
>    A = I + B/2 - 1
> 
> 5. Específicas:
>    Triángulo: (1/2)bh, √[s(s-a)(s-b)(s-c)]
>    Rectángulo: ab
>    Paralelogramo: bh
>    Trapecio: ((B+b)/2)h
>    Rombo: (pq)/2
> ```
> 
> **Polígonos regulares clave:**
> 
> ```
> Triángulo equilátero: A = (a²√3)/4
> Cuadrado: A = a²
> Pentágono: A ≈ 1.720a²
> Hexágono: A = (3a²√3)/2
> Octógono: A = 2a²(1+√2)
> ```
