# 📚 Tipos de Funciones

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva
> **Los tipos de funciones son categorías que clasifican a las funciones según sus propiedades algebraicas, comportamiento, forma o estructura. Cada tipo tiene características particulares que afectan cómo se comportan, cómo se grafican y dónde se aplican.**
>
> **Criterios de clasificación:**
> - **Por estructura algebraica:** Polinomial, racional, radical, etc.
> - **Por comportamiento:** Monótona, periódica, acotada, etc.
> - **Por aplicación:** Exponencial, logarítmica, trigonométrica, etc.
> - **Por inyectividad:** Inyectiva, sobreyectiva, biyectiva
> - **Por propiedades gráficas:** Par, impar, creciente, cóncava, etc.

### 📖 Contexto Histórico

> [!note]- Desarrollo Histórico de la Clasificación
>
> **Antigüedad (300 a.C. - 1600):**
> - **Euclides y Apolonio:** Clasificación geométrica de curvas
> - **Griegos:** No concepto de "función" aún
> - **Idea:** Distintos tipos de curvas (líneas, círculos, cónicas)
>
> **Revolución Cartesiana (1637-1700):**
> - **Descartes (1637):** _La Géométrie_
>   - Ecuaciones algebraicas → curvas geométricas
>   - Separación de curvas "algebraicas" vs "trascendentes"
> - **Leibniz (1684):** Notación diferencial
>   - Funciones del cálculo vs geometría clásica
>
> **Era de Euler (1700-1783):**
> - **Euler (1748):** _Introductio in analysin infinitorum_
>   - Primera clasificación sistemática de funciones
>   - **Funciones algebraicas:** Operaciones finitarias
>   - **Funciones trascendentes:** Procesos infinitos (e^x, ln(x), trigonométricas)
>   - **Funciones elementales:** Combinaciones de las anteriores
> - **Bernoulli:** Funciones especiales (gamma, beta)
>
> **Siglo XIX - Rigor y Generalización (1800-1900):**
> - **Cauchy (1821):** Rigurización del cálculo
>   - Funciones continuas vs discontinuas
>   - Derivables vs no derivables
> - **Fourier (1822):** Series trigonométricas
>   - Funciones periódicas descomponibles
> - **Dirichlet (1829-1837):** Definición moderna
>   - Función = correspondencia arbitraria
>   - Amplía tipos de funciones posibles
> - **Riemann (1854):** Integración y continuidad
> - **Weierstrass (1872):** Funciones patológicas
>
> **Siglo XX - Abstracción (1900-presente):**
> - **Lebesgue (1901):** Integración y medida
> - **Funciones medibles** en análisis funcional
> - **Espacios de funciones:** L², L^∞, C[a,b], etc.
> - **Análisis funcional:** Funcionales como "funciones de funciones"
> - **Computación:** Funciones recursivas, computables
> - **Teoría de categorías:** Función como morfismo

## 📐 Clasificación Principal: Funciones Algebraicas

> [!success]- Funciones Algebraicas
>
> **Definición:** Una función es **algebraica** si puede expresarse mediante un número finito de operaciones algebraicas (suma, resta, multiplicación, división, radicación) sobre la variable independiente.
>
> **Forma general:**
> ```
> f(x) = P(x) / Q(x) o f(x) = ⁿ√[P(x)/Q(x)]
> donde P y Q son polinomios
> ```
>
> ### A. Funciones Polinomiales
>
> **Definición:** Función de la forma
> ```
> f(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + ... + a₁x + a₀
> donde n ∈ ℕ ∪ {0}, aᵢ ∈ ℝ, aₙ ≠ 0
> ```
>
> **Características:**
> - **Dominio:** ℝ
> - **Rango:** Depende del grado
> - **Continuidad:** Continua en todo ℝ
> - **Derivabilidad:** Derivable en todo ℝ
> - **Grado:** n (exponente más alto)
>
> **Tipos por grado:**
>
> ```
> Grado 0: f(x) = c (constante)
> - Horizontal
> - Ran(f) = {c}
> 
> Grado 1: f(x) = mx + b (lineal)
> - Recta no horizontal
> - Dominio y rango: ℝ
> - Inyectiva
> 
> Grado 2: f(x) = ax² + bx + c (cuadrática)
> - Parábola
> - Vértice: (-b/(2a), f(-b/(2a)))
> - Si a > 0: U, mínimo
> - Si a < 0: ∩, máximo
> 
> Grado 3: f(x) = ax³ + bx² + cx + d (cúbica)
> - Forma de S
> - Crece más rápido que cuadrática
> 
> Grado n: Comportamiento general
> - Par, n ≥ 2: ambas ramas van mismo sentido
> - Impar, n ≥ 3: ramas opuestas
> - n raíces reales o complejas (Teorema Fundamental del Álgebra)
> ```
>
> **Propiedades:**
> ```
> 1. Suma de polinomios: polinomio
> 2. Producto: polinomio de grado suma
> 3. Composición: polinomio
> 4. Derivada: polinomio de grado n-1
> 5. Antiderivada: polinomio de grado n+1
> ```
>
> **Ejemplos:**
> ```
> f(x) = 5 (grado 0)
> f(x) = 2x - 3 (grado 1, lineal)
> f(x) = x² - 4x + 3 (grado 2, cuadrática)
> f(x) = x³ - 2x² + x - 1 (grado 3, cúbica)
> f(x) = x⁵ + 3x⁴ - x² + 2 (grado 5, quíntica)
> ```
> ### B. Funciones Racionales
>
> **Definición:** Cociente de dos polinomios
> ```
> f(x) = P(x) / Q(x)
> donde P y Q son polinomios, Q(x) ≠ 0
> ```
>
> **Características:**
> - **Dominio:** ℝ \ {raíces de Q}
> - **Discontinuidades:** Asíntotas verticales (generalmente)
> - **Derivable:** En todo su dominio
>
> **Asíntotas (Reglas Prácticas):**
>
> ```
> Sea grado(P) = m, grado(Q) = n
>
> 1. Asíntotas verticales: en raíces de Q no canceladas
>
> 2. Asíntota horizontal:
>    - Si m < n: y = 0
>    - Si m = n: y = coef. principal P / coef. principal Q
>    - Si m > n: no hay (hay asíntota oblicua/curvilínea)
>
> 3. Asíntota oblicua:
>    - Si m = n + 1: hacer división larga
>    - y = cociente de la división
>
> 4. Asíntota curvilínea:
>    - Si m > n + 1: curva parabólica, cúbica, etc.
> ```
>
> **Ejemplos:**
> ```
> f(x) = 1/x
> - Asíntota vertical: x = 0
> - Asíntota horizontal: y = 0
> 
> f(x) = (2x + 1)/(x - 3)
> - Asíntota vertical: x = 3
> - Asíntota horizontal: y = 2
> 
> f(x) = x²/(x - 1)
> - Asíntota vertical: x = 1
> - Asíntota oblicua: y = x + 1
> 
> f(x) = (x² + 1)/(x)
> - Asíntota vertical: x = 0
> - Asíntota oblicua: y = x
> ```
> ### C. Funciones Radicales (Irracionales)
>
> **Definición:** Contienen raíces de la variable
> ```
> f(x) = ⁿ√[P(x)]  donde P es polinomio o racional
> ```
>
> **Características:**
> - **Dominio:** Restricciones del radicando
> - **Continuidad:** Continua en su dominio
>
> **Tipos:**
>
> ```
> Raíz cuadrada: f(x) = √(P(x))
> - Dominio: P(x) ≥ 0
> - Ejemplo: √(x - 2), dominio [2, +∞)
>
> Raíz cúbica: f(x) = ∛(P(x))
> - Dominio: ℝ (si n impar)
> - Ejemplo: ∛(x - 1), dominio ℝ
>
> Raíz enésima: f(x) = ⁿ√(P(x))
> - n par: P(x) ≥ 0
> - n impar: todo ℝ
> ```
>
> **Ejemplos:**
> ```
> f(x) = √x, Dom = [0, +∞), Ran = [0, +∞)
> f(x) = √(x² - 4), Dom = (-∞, -2] ∪ [2, +∞)
> f(x) = ∛(2x + 1), Dom = ℝ
> f(x) = √[1/(x - 1)], Dom = (1, +∞)
> ```

## 📈 Clasificación: Funciones Trascendentes

> [!success]- Funciones Trascendentes
>
> **Definición:** Funciones que NO son algebraicas. Incluyen operaciones no algebraicas (exponenciación, logaritmación, trigonometría, hiperbólicas).
>
> ### A. Funciones Exponenciales
>
> **Definición:**
> ```
> f(x) = aˣ  donde a > 0, a ≠ 1
> ```
>
> **Características:**
> - **Dominio:** ℝ
> - **Rango:** (0, +∞)
> - **Continua:** En todo ℝ
> - **Derivable:** En todo ℝ
> - **Asíntota horizontal:** y = 0 (cuando x → -∞)
>
> **Comportamiento:**
> ```
> a > 1: Función creciente
> - Crece lentamente para x < 0
> - Crece rápidamente para x > 0
> - Ejemplo: 2ˣ, eˣ
>
> 0 < a < 1: Función decreciente
> - Decrece lentamente para x > 0
> - Decrece rápidamente para x < 0
> - Ejemplo: (1/2)ˣ, e⁻ˣ
> ```
>
> **Casos especiales:**
> ```
> eˣ: base e (número de Euler ≈ 2.71828)
> - Derivada: (eˣ)' = eˣ
> - Exponencial "natural"
> - Más común en cálculo y ciencias
>
> 10ˣ: base 10
> - Común en aplicaciones logarítmicas
> 
> 2ˣ: base 2
> - Común en computación
> ```
>
> **Aplicaciones:**
> ```
> - Crecimiento poblacional: P(t) = P₀eʳᵗ
> - Decaimiento radiactivo: N(t) = N₀e⁻λᵗ
> - Interés compuesto: A(t) = P(1 + r)ᵗ
> - Crecimiento logístico: P(t) = K/(1 + e⁻ʳᵗ)
> ```

> ### B. Funciones Logarítmicas
>
> **Definición:**
> ```
> f(x) = logₐ(x)  donde a > 0, a ≠ 1
> f(x) = ln(x)    logaritmo natural (base e)
> ```
>
> **Características:**
> - **Dominio:** (0, +∞)
> - **Rango:** ℝ
> - **Continua:** En su dominio
> - **Derivable:** En su dominio
> - **Asíntota vertical:** x = 0
> - **Inversa:** de la función exponencial
>
> **Relación con exponencial:**
> ```
> y = aˣ     ⟺     x = logₐ(y)
> 
> logₐ(aˣ) = x
> aˡᵒᵍᵃ⁽ˣ⁾ = x
> ```
>
> **Bases comunes:**
> ```
> ln(x) = logₑ(x)      logaritmo natural
> log(x) = log₁₀(x)    logaritmo común (base 10)
> log₂(x)               logaritmo binario (informática)
> ```
>
> **Propiedades algebraicas:**
> ```
> logₐ(xy) = logₐ(x) + logₐ(y)
> logₐ(x/y) = logₐ(x) - logₐ(y)
> logₐ(xⁿ) = n·logₐ(x)
> logₐ(x) = log_b(x) / log_b(a)  [cambio de base]
> ```
>
> **Comportamiento:**
> ```
> a > 1: Función creciente
> - Crece muy lentamente
> - Ejemplo: ln(x), log₁₀(x)
>
> 0 < a < 1: Función decreciente
> - Ejemplo: log₀.₅(x)
> ```
>
> **Ejemplos:**
> ```
> f(x) = ln(x)
> f(x) = log₂(x)
> f(x) = log(x² - 1)
> f(x) = ln(|x|)
> ```

> ### C. Funciones Trigonométricas
>
> **Las seis funciones trigonométricas:**
>
> ```
> 1. sin(x)  - seno
> 2. cos(x)  - coseno
> 3. tan(x)  - tangente
> 4. cot(x)  - cotangente
> 5. sec(x)  - secante
> 6. csc(x)  - cosecante
> ```
>
> **Propiedades de sen(x) y cos(x):**
> ```
> Dominio:           ℝ
> Rango:             [-1, 1]
> Período:           2π
> Continuidad:       En todo ℝ
> Derivabilidad:     En todo ℝ
>
> sin(x):
> - Impar: sin(-x) = -sin(x)
> - Ceros: x = nπ
> - Máximos: (π/2 + 2nπ, 1)
> - Mínimos: (3π/2 + 2nπ, -1)
>
> cos(x):
> - Par: cos(-x) = cos(x)
> - Ceros: x = π/2 + nπ
> - Máximos: (2nπ, 1)
> - Mínimos: (π + 2nπ, -1)
> ```
>
> **Propiedades de tan(x):**
> ```
> Dominio:       ℝ \ {π/2 + nπ}
> Rango:         ℝ
> Período:       π
> Discontinuidades: En x = π/2 + nπ
> Asíntotas verticales: x = π/2 + nπ
> Impar:         tan(-x) = -tan(x)
> ```
>
> **Identidades trigonométricas:**
> ```
> Fundamental:        sin²(x) + cos²(x) = 1
> Ángulo doble:       sin(2x) = 2sin(x)cos(x)
> Suma:               sin(x + y) = sin(x)cos(y) + cos(x)sin(y)
> Diferencia:         cos(x - y) = cos(x)cos(y) + sin(x)sin(y)
> Derivadas:          (sin x)' = cos x, (cos x)' = -sin x
> ```

> ### D. Funciones Hiperbólicas
>
> **Definición en términos de exponenciales:**
> ```
> sinh(x) = (eˣ - e⁻ˣ)/2      seno hiperbólico
> cosh(x) = (eˣ + e⁻ˣ)/2      coseno hiperbólico
> tanh(x) = sinh(x)/cosh(x)   tangente hiperbólica
> ```
>
> **Características:**
> ```
> sinh(x):
> - Dominio: ℝ
> - Rango: ℝ
> - Impar, creciente
> - Asimétota: ninguna en el plano real
>
> cosh(x):
> - Dominio: ℝ
> - Rango: [1, +∞)
> - Par, mínimo en (0, 1)
> - Forma de catenaria (cadena colgante)
>
> tanh(x):
> - Dominio: ℝ
> - Rango: (-1, 1)
> - Impar, creciente
> - Asíntotas: y = ±1
> ```
>
> **Relación con trigonométricas:**
> ```
> e^(ix) = cos(x) + i·sin(x)  [Fórmula de Euler]
> 
> sinh(x) = -i·sin(ix)
> cosh(x) = cos(ix)
> tanh(x) = -i·tan(ix)
> ```
>
> **Aplicaciones:**
> ```
> - Catenaria: y = a·cosh(x/a)
> - Relatividad especial
> - Ecuaciones diferenciales
> - Geometría hiperbólica
> ```

> ### E. Funciones Trigonométricas Inversas
>
> **Definición:** Funciones inversa de las trigonométricas (restringidas)
>
> ```
> arcsin(x) = sen⁻¹(x)
> - Dominio: [-1, 1]
> - Rango: [-π/2, π/2]
> - Derivada: 1/√(1 - x²)
>
> arccos(x) = cos⁻¹(x)
> - Dominio: [-1, 1]
> - Rango: [0, π]
> - Derivada: -1/√(1 - x²)
>
> arctan(x) = tan⁻¹(x)
> - Dominio: ℝ
> - Rango: (-π/2, π/2)
> - Derivada: 1/(1 + x²)
> - Asíntotas: y = ±π/2
> ```

## 🔄 Clasificación: Por Inyectividad

> [!tip]- Funciones Inyectivas, Sobreyectivas y Biyectivas
>
> > [!note]- Definiciones
> >
> > **Función inyectiva (uno a uno):**
> > ```
> > f: A → B es inyectiva si:
> > ∀x₁, x₂ ∈ A: f(x₁) = f(x₂) ⟹ x₁ = x₂
> >
> > O equivalentemente:
> > x₁ ≠ x₂ ⟹ f(x₁) ≠ f(x₂)
> >
> > Interpretación visual: Toda línea horizontal cruza la gráfica ≤ 1 vez
> > ```
> >
> > **Función sobreyectiva (sobre):**
> > ```
> > f: A → B es sobreyectiva si:
> > ∀y ∈ B ∃x ∈ A: f(x) = y
> >
> > Rango coincide con codominio
> > Ran(f) = B
> > ```
> >
> > **Función biyectiva:**
> > ```
> > f es biyectiva si es inyectiva Y sobreyectiva
> > ⟺ f tiene inversa f⁻¹
> > ⟺ f es una correspondencia uno a uno
> > ```
>
> **Ejemplos:**
> ```
> f(x) = x²  en ℝ
> - NO inyectiva: f(-2) = f(2) = 4
> - NO sobreyectiva: Ran = [0, +∞)
> - NO biyectiva
>
> f(x) = x  en ℝ
> - Inyectiva: ✓
> - Sobreyectiva: ✓
> - Biyectiva: ✓
>
> f(x) = x²  en [0, +∞)
> - Inyectiva: ✓
> - Sobreyectiva en [0, +∞): ✓
> - Biyectiva: ✓
>
> f(x) = sin(x)  en ℝ
> - NO inyectiva: sin(0) = sin(π) = 0
> - NO sobreyectiva: Ran = [-1, 1]
> - NO biyectiva
>
> f(x) = sin(x)  en [-π/2, π/2]
> - Inyectiva: ✓
> - Sobreyectiva a [-1, 1]: ✓
> - Biyectiva: ✓
> ```

## 📊 Clasificación: Por Propiedades Gráficas

> [!example]- Funciones Pares e Impares
>
> **Función par:**
> ```
> f(-x) = f(x)  para todo x ∈ Dom(f)
>
> Interpretación geométrica: Simétrica respecto al eje y
>
> Ejemplos:
> - f(x) = x²
> - f(x) = cos(x)
> - f(x) = |x|
> - f(x) = x⁴ - 2x² + 1
> ```
>
> **Función impar:**
> ```
> f(-x) = -f(x)  para todo x ∈ Dom(f)
>
> Interpretación geométrica: Simétrica respecto al origen (rotación 180°)
>
> Ejemplos:
> - f(x) = x³
> - f(x) = sin(x)
> - f(x) = 1/x
> - f(x) = x - 1/x
> ```
>
> **Propiedades:**
> ```
> 1. Una función no puede ser par e impar (excepto f(x) = 0)
> 2. Suma de funciones pares es par
> 3. Suma de funciones impares es impar
> 4. Producto de pares es par
> 5. Producto de impares es par
> 6. Producto de par e impar es impar
> ```

> [!example]- Funciones Periódicas
>
> **Definición:**
> ```
> f es periódica con período T > 0 si:
> f(x + T) = f(x)  para todo x ∈ Dom(f)
>
> Período fundamental: el menor T > 0 que satisface esto
> ```
>
> **Ejemplos:**
> ```
> sin(x):     período T = 2π
> cos(x):     período T = 2π
> tan(x):     período T = π
> sin(2x):    período T = π
> sin(x/2):   período T = 4π
> ```
>
> **Propiedades:**
> ```
> 1. Si f tiene período T, también tiene período 2T, 3T, etc.
> 2. sin(x) y cos(x) son las más "básicas"
> 3. Cualquier suma de sen y cos es periódica (Serie de Fourier)
> 4. Para graficar: dibujar un período y repetir
> ```

> [!example]- Funciones Acotadas
>
> **Acotada superiormente:**
> ```
> f es acotada superiormente si ∃M ∈ ℝ:
> f(x) ≤ M  para todo x ∈ Dom(f)
>
> Ejemplo: sin(x) ≤ 1
> ```
>
> **Acotada inferiormente:**
> ```
> f es acotada inferiormente si ∃m ∈ ℝ:
> f(x) ≥ m  para todo x ∈ Dom(f)
>
> Ejemplo: sin(x) ≥ -1
> ```
>
> **Acotada:**
> ```
> f es acotada si es acotada superior e inferiormente
> ⟺ ∃M > 0: |f(x)| ≤ M  para todo x ∈ Dom(f)
>
> Ejemplo: sin(x) es acotada
> ```

> [!example]- Funciones Monótonas
>
> **Función creciente:**
> ```
> f es creciente si: x₁ < x₂ ⟹ f(x₁) ≤ f(x₂)
> f es estrictamente creciente si: x₁ < x₂ ⟹ f(x₁) < f(x₂)
> ```
>
> **Función decreciente:**
> ```
> f es decreciente si: x₁ < x₂ ⟹ f(x₁) ≥ f(x₂)
> f es estrictamente decreciente si: x₁ < x₂ ⟹ f(x₁) > f(x₂)
> ```
>
> **Función monótona:**
> ```
> f es monótona si es creciente en todo su dominio O decreciente
> ```

## 🔀 Operaciones y Composiciones

> [!tip]- Combinando Funciones
>
> **Suma, resta, multiplicación, división:**
> ```
> (f + g)(x) = f(x) + g(x)
> (f - g)(x) = f(x) - g(x)
> (f·g)(x) = f(x)·g(x)
> (f/g)(x) = f(x)/g(x),  g(x) ≠ 0
>
> Dominio: intersección de dominios (excepto división excluye ceros de g)
> ```
>
> **Composición:**
> ```
> (f ∘ g)(x) = f(g(x))
>
> Dominio: {x ∈ Dom(g) : g(x) ∈ Dom(f)}
>
> Ejemplo:
> f(x) = √x,  g(x) = x - 2
> (f ∘ g)(x) = √(x - 2)
> Dominio: x - 2 ≥ 0, es decir, x ≥ 2
> ```
>
> **Nota:** Composición NO es conmutativa
> ```
> f ∘ g ≠ g ∘ f  en general
>
> Ejemplo:
> f(x) = x², g(x) = x + 1
> (f ∘ g)(x) = (x + 1)² = x² + 2x + 1
> (g ∘ f)(x) = x² + 1
> 
> Son diferentes
> ```

## 📚 Clasificación: Funciones Especiales

> [!example]- Funciones de Interés Particular
>
> **Función escalonada (step function):**
> ```
> Toma valores constantes en intervalos
>
> Ejemplo: Función parte entera ⌊x⌋
> Función de Heaviside H(x)
> Función signo sgn(x)
> ```
>
> **Función gaussiana (normal):**
> ```
> f(x) = e^(-x²)  o  f(x) = (1/√(2π))e^(-x²/2)
>
> Campana simétrica
> Base de la distribución normal
> ```
>
> **Función logística:**
> ```
> f(x) = 1/(1 + e^(-x))  o  f(x) = 1/(1 + e^(-kx))
>
> Curva en forma de S (sigmoide)
> Rango (0, 1) o [-1, 1]
> Creciente
> Aplicaciones: redes neuronales, modelaje de crecimiento
> ```
>
> **Función valor absoluto:**
> ```
> f(x) = |x|
>
> Vértice en origen
> Forma de V
> Continua pero no derivable en x = 0
> ```
>
> **Función error (erf):**
> ```
> erf(x) = (2/√π) ∫₀ˣ e^(-t²) dt
>
> Relacionada con la distribución normal
> Función especial del análisis
> ```
>
> 
> 
> **Función gamma (Γ):**
> ```
> Γ(n) = (n-1)!  para n ∈ ℕ
> Γ(n) = ∫₀^∞ t^(n-1)·e^(-t) dt  en general
>
> Propiedades:
> - Extensión de factorial a números reales
> - Γ(n+1) = n·Γ(n)
> - Γ(1/2) = √π
> - Γ(n) indefinida en 0, -1, -2, ...
>
> Aplicaciones: distribuciones de probabilidad, combinatoria
> ```
>
> **Función beta (B):**
> ```
> B(x, y) = ∫₀¹ t^(x-1)·(1-t)^(y-1) dt
>
> Relación con gamma: B(x, y) = Γ(x)·Γ(y) / Γ(x+y)
>
> Aplicaciones: estadística, análisis
> ```
>
> **Función zeta de Riemann (ζ):**
> ```
> ζ(s) = Σ(n=1 a ∞) 1/n^s  para Re(s) > 1
>
> Propiedades:
> - Relacionada con números primos
> - Hipótesis de Riemann (problema sin resolver)
> - ζ(2) = π²/6
> - Continuación analítica a todo ℂ
> ```

## 🎯 Funciones por Aplicación Específica

> [!example]- Según Contexto de Uso
>
> **Funciones de crecimiento y decaimiento:**
> ```
> Crecimiento exponencial:
> N(t) = N₀·a^t  o  N(t) = N₀·e^(rt)
> - Crecimiento sin límite
> - Aplicación: poblaciones, interés compuesto
>
> Crecimiento logístico:
> N(t) = K / (1 + e^(-rt))
> - Crecimiento limitado por capacidad K
> - Aplicación: epidemiología, ecología
>
> Decaimiento exponencial:
> N(t) = N₀·e^(-λt)
> - Disminución gradual
> - Aplicación: radiactividad, medicamentos en el cuerpo
>
> Crecimiento por saturación:
> y = L(1 - e^(-kt))
> - Aproximación gradual a límite L
> ```
>
> **Funciones oscilantes:**
> ```
> Armónico simple:
> x(t) = A·sin(ωt + φ) + B
> - A: amplitud
> - ω: frecuencia angular
> - φ: fase inicial
> - B: desplazamiento vertical
>
> Amortiguado:
> x(t) = A·e^(-γt)·sin(ωt + φ)
> - Oscilación que disminuye con el tiempo
> - Aplicación: sistemas mecánicos, circuitos RLC
> ```
>
> **Funciones potencia:**
> ```
> f(x) = x^α  donde α ∈ ℝ
>
> Casos especiales:
> α > 1: crece más rápido que lineal
> 0 < α < 1: crece más lentamente que lineal
> α = 0: función constante 1
> α < 0: función recíproca, decrece
>
> Ejemplos:
> x^2 (cuadrática)
> x^(1/2) = √x (raíz)
> x^(-1) = 1/x (recíproca)
> x^(2/3) (potencia fraccionaria)
> ```

## 🔢 Funciones de Números Especiales

> [!note]- Funciones Relacionadas con Números
>
> **Función divisor (τ o d):**
> ```
> τ(n) = número de divisores positivos de n
>
> Ejemplos:
> τ(1) = 1
> τ(6) = 4 (divisores: 1, 2, 3, 6)
> τ(12) = 6 (divisores: 1, 2, 3, 4, 6, 12)
>
> Aplicación: teoría de números
> ```
>
> **Función de Möbius (μ):**
> ```
> μ(n) = {  1    si n es producto de primos distintos (número par)
>        { -1    si n es producto de primos distintos (número impar)
>        {  0    si n tiene factor primo repetido
>
> Ejemplos:
> μ(1) = 1
> μ(2) = -1 (un primo)
> μ(6) = 1 (6 = 2·3, dos primos distintos)
> μ(12) = 0 (12 = 2²·3, tiene 2² repetido)
>
> Aplicación: inversión de Möbius en teoría de números
> ```
>
> **Función de Euler (φ):**
> ```
> φ(n) = cantidad de números ≤ n coprimos con n
>
> Ejemplos:
> φ(1) = 1
> φ(6) = 2 (números: 1, 5)
> φ(12) = 4 (números: 1, 5, 7, 11)
>
> Propiedades:
> φ(p) = p - 1  si p es primo
> φ(p^k) = p^(k-1)·(p - 1)
>
> Aplicación: criptografía RSA
> ```
>
> **Función parte entera y funciones relacionadas:**
> ```
> ⌊x⌋ - piso (floor): mayor entero ≤ x
> ⌈x⌉ - techo (ceiling): menor entero ≥ x
> {x} - parte fraccionaria: x - ⌊x⌋
> round(x) - redondeo: entero más cercano
> trunc(x) - truncamiento: entero removiendo decimales
> ```

## 📐 Funciones Vectoriales y Multivariables

> [!success]- Extensiones a Dimensiones Superiores
>
> **Funciones vectoriales:**
> ```
> f: ℝ → ℝⁿ
>
> f(t) = (f₁(t), f₂(t), ..., fₙ(t))
>
> Ejemplo: Curva paramétrica
> f(t) = (cos(t), sin(t))  [círculo unitario]
> 
> Propiedades:
> - Dominio: ℝ (o subconjunto)
> - Rango: curva o superficie en ℝⁿ
> - Derivable: vector tangente
> - Integrable: longitud de arco
> ```
>
> **Funciones multivariables:**
> ```
> f: ℝⁿ → ℝ
>
> f(x₁, x₂, ..., xₙ) = y
>
> Ejemplo: Función de dos variables
> f(x, y) = x² + y²  [paraboloide]
>
> Propiedades:
> - Dominio: región en ℝⁿ
> - Rango: valores reales
> - Gráfica: superficie en ℝⁿ⁺¹
> - Derivadas parciales: ∂f/∂x, ∂f/∂y, ...
> - Gradiente: ∇f = (∂f/∂x, ∂f/∂y, ...)
> ```
>
> **Campos vectoriales:**
> ```
> F: ℝⁿ → ℝⁿ
>
> F(x₁, x₂, ..., xₙ) = (F₁, F₂, ..., Fₙ)
>
> Ejemplo: Campo de velocidades en fluido
> F(x, y) = (-y, x)  [rotación]
>
> Aplicación: ecuaciones diferenciales, física
> ```

## 🔗 Funcionales y Espacios de Funciones

> [!note]- Funciones Avanzadas
>
> **Funcionales:**
> ```
> Un funcional es una función cuyo dominio es un espacio de funciones
>
> J[f] = valor numérico asociado a la función f
>
> Ejemplos:
> - Longitud de arco: L[f] = ∫ √(1 + f'²) dx
> - Energía: E[f] = ∫ |f'|² dx
> - Norma: ||f|| = ∫ |f|² dx
>
> Aplicación: cálculo de variaciones, teoría de control
> ```
>
> **Espacios de funciones:**
> ```
> Conjunto de funciones con propiedades comunes
>
> C[a,b]: funciones continuas en [a,b]
> C^n[a,b]: funciones n veces derivables con derivada continua
> L²(a,b): funciones integrables (cuadrado integrable)
> H^s: espacios de Sobolev (derivadas generalizadas)
>
> Norma y métrica permiten hablar de "distancia" entre funciones
> ```

## 🎨 Combinaciones y Transformaciones

> [!example]- Funciones Derivadas de Otras
>
> **Función inversa:**
> ```
> Si f: A → B es biyectiva, existe f⁻¹: B → A
> f⁻¹(f(x)) = x  para todo x ∈ A
> f(f⁻¹(y)) = y  para todo y ∈ B
>
> Gráfica de f⁻¹ = reflexión de f respecto a y = x
>
> Ejemplo:
> f(x) = 2x + 3
> f⁻¹(x) = (x - 3)/2
> ```
>
> **Función compuesta:**
> ```
> (f ∘ g)(x) = f(g(x))
>
> Permite "encadenar" funciones simples para crear complejas
>
> Ejemplo: f(x) = sin(2x + 1)
> - g(x) = 2x + 1 (lineal)
> - h(x) = sin(x) (trigonométrica)
> - f = h ∘ g
> ```
>
> **Función desplazada/transformada:**
> ```
> Traslación: f(x ± a) ± b
> Reflexión: -f(x), f(-x)
> Escalado: a·f(b·x)
>
> Ejemplo: y = -2sin(3x - π) + 1
> - sin(x) base
> - sin(3x): compresión horizontal por factor 3
> - sin(3x - π): desplazamiento
> - -2sin(...): reflexión y estiramiento
> - ... + 1: desplazamiento vertical
> ```

## ✅ Reconocimiento de Tipos de Funciones

> [!example]- Cómo Identificar el Tipo
>
> **Procedimiento sistemático:**
>
> ```
> 1. ¿Hay radicales?
>    SÍ → Función radical (algebraica)
>    NO → Continuar
>
> 2. ¿Hay división por polinomios?
>    SÍ → Función racional (algebraica)
>    NO → Continuar
>
> 3. ¿Hay solo operaciones algebraicas finitas?
>    SÍ → Función polinomial (algebraica)
>    NO → Continuar (es trascendente)
>
> 4. ¿Hay base^variable (como e^x)?
>    SÍ → Función exponencial
>    NO → Continuar
>
> 5. ¿Hay logaritmo?
>    SÍ → Función logarítmica
>    NO → Continuar
>
> 6. ¿Hay sin, cos, tan?
>    SÍ → Función trigonométrica
>    NO → Continuar
>
> 7. ¿Hay sinh, cosh, tanh?
>    SÍ → Función hiperbólica
>    NO → Es otra especial
> ```
>
> **Ejemplos:**
> ```
> f(x) = x³ - 2x + 1
> → Operaciones algebraicas finitas
> → POLINOMIAL
>
> f(x) = (x² + 1)/(x - 3)
> → División por polinomio
> → RACIONAL
>
> f(x) = √(x² - 4)
> → Raíz
> → RADICAL
>
> f(x) = e^(2x) + 3
> → Base e elevada a variable
> → EXPONENCIAL
>
> f(x) = ln(x - 1)
> → Logaritmo
> → LOGARÍTMICA
>
> f(x) = 3sin(2x) - cos(x)
> → Seno y coseno
> → TRIGONOMÉTRICA
>
> f(x) = (e^x - e^(-x))/2
> → Sinh(x)
> → HIPERBÓLICA
>
> f(x) = e^(-x²)
> → Exponencial de función compuesta
> → GAUSSIANA (especial)
> ```

## 🎯 Conceptos Clave para Recordar

> [!important]- Resumen Ejecutivo
>
> **Clasificación primaria:**
> - **Algebraicas:** Operaciones finitas sobre variable
>   - Polinomiales, racionales, radicales
> - **Trascendentes:** Operaciones infinitas o no algebraicas
>   - Exponencial, logarítmica, trigonométrica, hiperbólica, especiales
>
> **Propiedades gráficas:**
> - Pares (simetría eje y), Impares (simetría origen)
> - Periódicas (se repiten), Acotadas (limitadas en rango)
> - Monótonas (siempre crecen o decrecen)
>
> **Inyectividad:**
> - Inyectivas: uno a uno (test línea horizontal)
> - Sobreyectivas: sobre todo codominio
> - Biyectivas: tienen inversa
>
> **Combinaciones:**
> - Suma, resta, producto, división: operan puntualmente
> - Composición: aplicar una dentro de otra
> - Inversa: intercambiar entrada y salida (si es biyectiva)
>
> **Aplicación:**
> - Elegir tipo según contexto: ¿Crece sin límite? ¿Periódico? ¿Con asíntotas?
> - Combinar tipos para modelar fenómenos complejos
> - Entender propiedades para predecir comportamiento
