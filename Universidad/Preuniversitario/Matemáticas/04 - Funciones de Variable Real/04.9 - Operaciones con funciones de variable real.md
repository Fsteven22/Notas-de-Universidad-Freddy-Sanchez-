# 🔧 Operaciones con Funciones de Variable Real

## 🌟 Introducción

> [!info]- Visión General **Las operaciones con funciones permiten construir funciones nuevas y más complejas a partir de funciones conocidas. Estas operaciones son fundamentales en el análisis matemático y proporcionan herramientas poderosas para modelar fenómenos complejos mediante la combinación de comportamientos más simples.**
> 
> **Tipos principales de operaciones:**
> 
> - **Operaciones algebraicas:** Suma, resta, multiplicación, división
> - **Composición:** Aplicar una función al resultado de otra
> - **Transformaciones:** Traslaciones, reflexiones, escalamientos
> - **Operaciones punto a punto:** Combinaciones elemento por elemento
> - **Operaciones funcionales:** Derivación, integración, convolución
> 
> **Importancia:**
> 
> - Construir funciones complejas desde componentes simples
> - Analizar propiedades heredadas de las funciones originales
> - Simplificar problemas mediante descomposición
> - Establecer relaciones entre diferentes funciones

### 📖 Contexto Histórico

> [!note]- Desarrollo del Álgebra de Funciones
> 
> **Orígenes (1600-1700):**
> 
> - **Leibniz y Newton:** Operaciones básicas con "fluentes"
> - **Euler (1748):** Sistematización de operaciones algebraicas
> - **Concepto inicial:** Funciones como expresiones algebraicas
> 
> **Formalización (1800-1850):**
> 
> - **Cauchy (1821):** Rigor en operaciones aritméticas
> - **Dirichlet (1837):** Extensión a funciones generales
> - **Weierstrass:** Análisis de convergencia en operaciones
> 
> **Teoría moderna (1900-presente):**
> 
> - **Espacios vectoriales de funciones:** Estructura algebraica completa
> - **Análisis funcional:** Operadores entre espacios de funciones
> - **Álgebras de funciones:** Estructuras algebraicas abstractas
> - **Teoría de categorías:** Perspectiva unificadora

## ➕ Operaciones Algebraicas Básicas

> [!success]- Suma y Resta de Funciones
> 
> **Definición - Suma:**
> 
> ```
> Dadas f: Dₓ → ℝ y g: Dᵧ → ℝ, la suma es:
> 
> (f + g)(x) = f(x) + g(x)
> 
> Notación: (f + g) o f + g
> Se lee: "f más g"
> ```
> 
> **Dominio de la suma:**
> 
> ```
> Dom(f + g) = Dom(f) ∩ Dom(g)
> 
> La suma está definida solo donde ambas funciones existen
> 
> Ejemplo:
> f(x) = √x,     Dom(f) = [0, +∞)
> g(x) = √(1−x), Dom(g) = (−∞, 1]
> 
> (f + g)(x) = √x + √(1−x)
> Dom(f + g) = [0, +∞) ∩ (−∞, 1] = [0, 1]
> ```
> 
> **Definición - Resta:**
> 
> ```
> (f − g)(x) = f(x) − g(x)
> 
> Dom(f − g) = Dom(f) ∩ Dom(g)
> 
> Nota: f − g ≠ g − f (no es conmutativa)
> ```
> 
> **Propiedades algebraicas:**
> 
> ```
> 1) Conmutatividad: f + g = g + f
> 2) Asociatividad: (f + g) + h = f + (g + h)
> 3) Elemento neutro: f + 0 = f (donde 0 es función constante cero)
> 4) Elemento opuesto: f + (−f) = 0
> 5) Distributividad: c(f + g) = cf + cg, c ∈ ℝ
> ```
> 
> **Rango de la suma:**
> 
> ```
> En general: Ran(f + g) ⊆ Ran(f) + Ran(g)
> 
> donde Ran(f) + Ran(g) = {a + b : a ∈ Ran(f), b ∈ Ran(g)}
> 
> La inclusión puede ser estricta
> 
> Ejemplo:
> f(x) = sin(x), Ran(f) = [−1, 1]
> g(x) = cos(x), Ran(g) = [−1, 1]
> (f + g)(x) = sin(x) + cos(x) = √2·sin(x + π/4)
> Ran(f + g) = [−√2, √2] ⊊ [−2, 2]
> ```

> [!example]- Ejemplos de Suma y Resta
> 
> **Ejemplo 1 - Funciones polinomiales:**
> 
> ```
> f(x) = 2x² + 3x − 1
> g(x) = x² − 5x + 2
> 
> (f + g)(x) = 3x² − 2x + 1
> (f − g)(x) = x² + 8x − 3
> 
> Dom(f + g) = Dom(f − g) = ℝ
> ```
> 
> **Ejemplo 2 - Funciones racionales:**
> 
> ```
> f(x) = 1/x,         Dom(f) = ℝ \ {0}
> g(x) = 1/(x − 1),   Dom(g) = ℝ \ {1}
> 
> (f + g)(x) = 1/x + 1/(x−1)
>            = (x−1 + x)/(x(x−1))
>            = (2x − 1)/(x² − x)
> 
> Dom(f + g) = ℝ \ {0, 1}
> ```
> 
> **Ejemplo 3 - Funciones trigonométricas:**
> 
> ```
> f(x) = sin(x)
> g(x) = cos(x)
> 
> (f + g)(x) = sin(x) + cos(x)
>            = √2·sin(x + π/4)
> 
> Dom(f + g) = ℝ
> Ran(f + g) = [−√2, √2]
> ```
> 
> **Ejemplo 4 - Funciones con radicales:**
> 
> ```
> f(x) = √(x − 1),    Dom(f) = [1, +∞)
> g(x) = √(3 − x),    Dom(g) = (−∞, 3]
> 
> (f + g)(x) = √(x−1) + √(3−x)
> Dom(f + g) = [1, 3]
> 
> Valor máximo en x = 2: (f+g)(2) = 1 + 1 = 2
> ```
> 
> **Ejemplo 5 - Construcción por partes:**
> 
> ```
> f(x) = { x      si x < 0
>        { x²     si x ≥ 0
> 
> g(x) = { 2x     si x < 0
>        { 1      si x ≥ 0
> 
> (f + g)(x) = { 3x      si x < 0
>              { x² + 1   si x ≥ 0
> 
> Sumar caso por caso en cada región
> ```

## ✖️ Multiplicación de Funciones

> [!success]- Producto Punto a Punto
> 
> **Definición:**
> 
> ```
> (f · g)(x) = f(x) · g(x)
> 
> Notación: f·g, fg, o (fg)(x)
> Se lee: "f por g"
> ```
> 
> **Dominio del producto:**
> 
> ```
> Dom(f · g) = Dom(f) ∩ Dom(g)
> 
> Excepción importante:
> Si f(x₀) = 0 en un punto donde g no está definida,
> algunos autores extienden el dominio incluyendo x₀
> 
> Ejemplo controversial:
> f(x) = x,      Dom(f) = ℝ
> g(x) = 1/x,    Dom(g) = ℝ \ {0}
> 
> (f · g)(x) = x · (1/x) = 1
> 
> Algebraicamente: (f·g)(x) = 1 para todo x
> Pero formalmente: Dom(f·g) = ℝ \ {0}
> 
> (El "agujero" en x=0 persiste)
> ```
> 
> **Propiedades algebraicas:**
> 
> ```
> 1) Conmutatividad: f · g = g · f
> 2) Asociatividad: (f · g) · h = f · (g · h)
> 3) Elemento neutro: f · 1 = f (función constante 1)
> 4) Distributividad: f · (g + h) = f·g + f·h
> 5) Potencias: fⁿ = f · f · ... · f (n veces)
> ```
> 
> **Rango del producto:**
> 
> ```
> Ran(f · g) ⊆ Ran(f) · Ran(g)
> 
> donde A · B = {ab : a ∈ A, b ∈ B}
> 
> Casos especiales:
> - Si 0 ∈ Ran(f) o 0 ∈ Ran(g), entonces 0 ∈ Ran(f·g)
> - Si Ran(f), Ran(g) ⊆ (0,∞), entonces Ran(f·g) ⊆ (0,∞)
> ```
> 
> **Ceros del producto:**
> 
> ```
> (f · g)(x) = 0 ⟺ f(x) = 0 o g(x) = 0
> 
> Ceros(f · g) = Ceros(f) ∪ Ceros(g)
> 
> Propiedad fundamental para factorización
> ```

> [!example]- Ejemplos de Multiplicación
> 
> **Ejemplo 1 - Modulación de amplitud:**
> 
> ```
> f(x) = e^(−x²)  (envolvente gaussiana)
> g(x) = sin(x)   (oscilación)
> 
> (f · g)(x) = e^(−x²)·sin(x)
> 
> Oscilación con amplitud decreciente
> Aplicación: señales moduladas, paquetes de onda
> 
> Dom(f·g) = ℝ
> Ran(f·g) ⊆ [−1, 1]
> ```
> 
> **Ejemplo 2 - Función ventana:**
> 
> ```
> f(x) = x²
> g(x) = H(x) − H(x−1)  (función ventana en [0,1])
> 
> (f · g)(x) = { x²   si 0 ≤ x ≤ 1
>              { 0    en otro caso
> 
> Restringe f al intervalo [0,1]
> ```
> 
> **Ejemplo 3 - Polinomios:**
> 
> ```
> f(x) = x + 1
> g(x) = x − 2
> 
> (f · g)(x) = (x+1)(x−2) = x² − x − 2
> 
> Producto de factores lineales produce cuadrática
> ```
> 
> **Ejemplo 4 - Cancelación aparente:**
> 
> ```
> f(x) = x² − 4
> g(x) = 1/(x + 2)
> 
> Dom(f) = ℝ
> Dom(g) = ℝ \ {−2}
> 
> (f · g)(x) = (x²−4)/(x+2) 
>            = (x−2)(x+2)/(x+2)
>            = x − 2  (para x ≠ −2)
> 
> Algebraicamente: x − 2
> Pero Dom(f·g) = ℝ \ {−2}
> 
> ¡El agujero permanece!
> ```
> 
> **Ejemplo 5 - Funciones trigonométricas:**
> 
> ```
> f(x) = sin(x)
> g(x) = cos(x)
> 
> (f · g)(x) = sin(x)·cos(x) = sin(2x)/2
> 
> Usando identidad: 2sin(x)cos(x) = sin(2x)
> ```

## ➗ División de Funciones

> [!success]- Cociente de Funciones
> 
> **Definición:**
> 
> ```
> (f/g)(x) = f(x)/g(x)
> 
> Notación: f/g, (f/g)(x)
> Se lee: "f entre g"
> ```
> 
> **Dominio del cociente:**
> 
> ```
> Dom(f/g) = Dom(f) ∩ Dom(g) ∩ {x : g(x) ≠ 0}
> 
> = {x : x ∈ Dom(f), x ∈ Dom(g), g(x) ≠ 0}
> 
> Tres condiciones simultáneas:
> 1) x debe estar en Dom(f)
> 2) x debe estar en Dom(g)
> 3) g(x) ≠ 0
> 
> Ejemplo:
> f(x) = √x,      Dom(f) = [0, +∞)
> g(x) = x − 4,   Dom(g) = ℝ
> 
> (f/g)(x) = √x/(x−4)
> 
> Dom(f/g) = [0, +∞) ∩ ℝ ∩ {x : x ≠ 4}
>          = [0, 4) ∪ (4, +∞)
> ```
> 
> **Propiedades:**
> 
> ```
> 4) NO conmutativa: f/g ≠ g/f (en general)
> 5) NO asociativa: (f/g)/h ≠ f/(g/h)
> 6) f/f = 1 en Dom(f) \ Ceros(f)
> 7) f/1 = f (función constante 1)
> 8) (f·g)/h = f·(g/h) si están definidas
> ```
> 
> **Rango del cociente:**
> 
> ```
> Determinar Ran(f/g) generalmente requiere análisis caso por caso
> 
> Técnica: Si y = f(x)/g(x), despejar x en términos de y
> ```
> 
> **Discontinuidades removibles:**
> 
> ```
> Si f(x₀) = g(x₀) = 0 pero lim(x→x₀) f(x)/g(x) existe:
> 
> La función tiene discontinuidad removible en x₀
> 
> Ejemplo:
> f(x) = x² − 1
> g(x) = x − 1
> 
> (f/g)(x) = (x²−1)/(x−1) = (x+1)(x−1)/(x−1)
> 
> Para x ≠ 1: (f/g)(x) = x + 1
> Dom(f/g) = ℝ \ {1}
> 
> Pero lim(x→1) (f/g)(x) = 2
> 
> Función extendida:
> (f/g)*(x) = { (x²−1)/(x−1)  si x ≠ 1
>             { 2              si x = 1
> 
> Continua en ℝ
> ```

> [!example]- Ejemplos de División
> 
> **Ejemplo 1 - Función racional básica:**
> 
> ```
> f(x) = x² + 3x + 2
> g(x) = x + 1
> 
> (f/g)(x) = (x²+3x+2)/(x+1)
>          = (x+1)(x+2)/(x+1)
>          = x + 2  (para x ≠ −1)
> 
> Dom(f) = ℝ
> Dom(g) = ℝ
> g(x) = 0 cuando x = −1
> 
> Dom(f/g) = ℝ \ {−1}
> Ran(f/g) = ℝ \ {1}
> ```
> 
> **Ejemplo 2 - Con radicales:**
> 
> ```
> f(x) = √(x + 1)
> g(x) = √(x − 1)
> 
> (f/g)(x) = √(x+1)/√(x−1) = √((x+1)/(x−1))
> 
> Dom(f) = [−1, +∞)
> Dom(g) = [1, +∞)
> g(x) ≠ 0 cuando x ≠ 1
> 
> Dom(f/g) = (1, +∞)
> 
> Nota: x = 1 excluido aunque g(1) = 0
> ```
> 
> **Ejemplo 3 - Funciones trigonométricas:**
> 
> ```
> f(x) = sin(x)
> g(x) = cos(x)
> 
> (f/g)(x) = sin(x)/cos(x) = tan(x)
> 
> Dom(tan) = ℝ \ {π/2 + nπ : n ∈ ℤ}
> 
> Donde cos(x) = 0
> ```
> 
> **Ejemplo 4 - Límite indeterminado:**
> 
> ```
> f(x) = x² − 4
> g(x) = x − 2
> 
> (f/g)(x) = (x²−4)/(x−2) = (x−2)(x+2)/(x−2)
> 
> Para x ≠ 2: (f/g)(x) = x + 2
> 
> lim(x→2) (f/g)(x) = 4
> 
> Forma indeterminada 0/0 en x = 2
> Discontinuidad removible
> ```
> 
> **Ejemplo 5 - Razón de cambio:**
> 
> ```
> f(x) = distancia recorrida en tiempo x
> g(x) = tiempo transcurrido = x
> 
> (f/g)(x) = velocidad promedio
> 
> Si f(x) = 5x² (movimiento acelerado):
> (f/g)(x) = 5x²/x = 5x (para x ≠ 0)
> ```

## 🔄 Múltiplos Escalares

> [!success]- Multiplicación por Constantes
> 
> **Definición:**
> 
> ```
> Dado c ∈ ℝ y función f, el múltiplo escalar es:
> 
> (c · f)(x) = c · f(x)
> 
> Notación: cf, c·f
> Se lee: "c por f"
> ```
> 
> **Propiedades del dominio:**
> 
> ```
> Dom(c·f) = Dom(f)
> 
> El múltiplo escalar no cambia el dominio
> ```
> 
> **Propiedades del rango:**
> 
> ```
> Si c ≠ 0:
> Ran(c·f) = c · Ran(f) = {c·y : y ∈ Ran(f)}
> 
> Si c > 0: escalamiento positivo
> Si c < 0: escalamiento y reflexión
> Si c = 0: función constante cero
> 
> Ejemplos:
> f(x) = x², Ran(f) = [0, +∞)
> 
> 2f: Ran(2f) = [0, +∞)
> −f: Ran(−f) = (−∞, 0]
> 0f: Ran(0f) = {0}
> ```
> 
> **Propiedades algebraicas:**
> 
> ```
> 1) c(f + g) = cf + cg (distributiva)
> 2) (c + d)f = cf + df (distributiva)
> 3) c(df) = (cd)f (asociativa)
> 4) 1·f = f (identidad)
> 5) 0·f = 0 (aniquilador)
> ```
> 
> **Interpretación geométrica:**
> 
> ```
> c·f estira (|c| > 1) o comprime (|c| < 1) verticalmente
> 
> Si c < 0: también refleja respecto al eje x
> ```

> [!example]- Ejemplos de Múltiplos Escalares
> 
> **Ejemplo 1 - Escalamiento simple:**
> 
> ```
> f(x) = sin(x), Ran(f) = [−1, 1]
> 
> 3f(x) = 3sin(x)
> Dom(3f) = ℝ
> Ran(3f) = [−3, 3]
> 
> Amplitud triplicada
> ```
> 
> **Ejemplo 2 - Reflexión:**
> 
> ```
> f(x) = e^x
> 
> −f(x) = −e^x
> Dom(−f) = ℝ
> Ran(f) = (0, +∞)
> Ran(−f) = (−∞, 0)
> 
> Gráfica reflejada respecto al eje x
> ```
> 
> **Ejemplo 3 - Normalización:**
> 
> ```
> f(x) = x² en [0, 2]
> Ran(f) = [0, 4]
> 
> Para normalizar a [0, 1]:
> g(x) = (1/4)f(x) = x²/4
> Ran(g) = [0, 1]
> ```
> 
> **Ejemplo 4 - Cambio de escala en aplicaciones:**
> 
> ```
> T(x) = temperatura en Celsius
> 
> T_F(x) = (9/5)T(x) + 32
> 
> Conversión a Fahrenheit
> (combinación de múltiplo escalar y traslación)
> ```

## 🔗 Composición de Funciones

> [!success]- Aplicación Sucesiva de Funciones
> 
> **Definición:**
> 
> ```
> Dadas f: A → B y g: C → D, la composición g∘f es:
> 
> (g ∘ f)(x) = g(f(x))
> 
> Notación: g∘f, (g∘f)(x)
> Se lee: "g compuesta con f"
>         "g círculo f"
>         "g de f de x"
> 
> Diagrama de flujo:
> x → [f] → f(x) → [g] → g(f(x))
> ```
> 
> **Dominio de la composición:**
> 
> ```
> Dom(g ∘ f) = {x ∈ Dom(f) : f(x) ∈ Dom(g)}
> 
> Dos condiciones:
> 1) x debe estar en Dom(f)
> 2) f(x) debe estar en Dom(g)
> 
> Ejemplo:
> f(x) = √x,     Dom(f) = [0, +∞)
> g(x) = 1/x,    Dom(g) = ℝ \ {0}
> 
> (g ∘ f)(x) = g(f(x)) = 1/√x
> 
> Condición 1: x ≥ 0 ✓
> Condición 2: √x ≠ 0, es decir, x ≠ 0 ✓
> 
> Dom(g ∘ f) = (0, +∞)
> ```
> 
> **Rango de la composición:**
> 
> ```
> Ran(g ∘ f) = g(Ran(f) ∩ Dom(g))
> 
> El rango de g∘f es la imagen bajo g de aquellos
> valores de f(x) que están en Dom(g)
> 
> En general: Ran(g ∘ f) ⊆ Ran(g)
> ```
> 
> **No conmutatividad:**
> 
> ```
> En general: g ∘ f ≠ f ∘ g
> 
> Contraejemplo:
> f(x) = x², g(x) = x + 1
> 
> (g ∘ f)(x) = g(x²) = x² + 1
> (f ∘ g)(x) = f(x+1) = (x+1)² = x² + 2x + 1
> 
> x² + 1 ≠ x² + 2x + 1
> ```
> 
> **Asociatividad:**
> 
> ```
> (h ∘ g) ∘ f = h ∘ (g ∘ f)
> 
> Ambas producen: h(g(f(x)))
> 
> Se puede escribir sin ambigüedad: h ∘ g ∘ f
> ```
> 
> **Función identidad:**
> 
> ```
> id(x) = x
> 
> id ∘ f = f ∘ id = f
> 
> La función identidad es elemento neutro de la composición
> ```

> [!tip]- Técnicas para Analizar Composiciones
> 
> **Método 1 - De adentro hacia afuera:**
> 
> ```
> Para evaluar (g ∘ f)(x₀):
> 
> Paso 1: Calcular f(x₀)
> Paso 2: Calcular g(f(x₀))
> 
> Ejemplo: f(x) = x², g(x) = √x, x₀ = 3
> 
> f(3) = 9
> g(9) = 3
> 
> (g ∘ f)(3) = 3
> ```
> 
> **Método 2 - Sustitución:**
> 
> ```
> Para encontrar (g ∘ f)(x):
> 
> Paso 1: Escribir g(u) donde u es la variable de g
> Paso 2: Sustituir u = f(x)
> Paso 3: Simplificar
> 
> Ejemplo:
> f(x) = 2x + 1
> g(u) = u²
> 
> (g ∘ f)(x) = g(2x+1) = (2x+1)²
> ```
> 
> **Método 3 - Descomposición:**
> 
> ```
> Dada h(x), encontrar f y g tales que h = g ∘ f
> 
> Estrategia: Identificar función "interna" y "externa"
> 
> Ejemplo: h(x) = √(x² + 1)
> 
> Función interna: f(x) = x² + 1
> Función externa: g(u) = √u
> 
> Verificación: (g ∘ f)(x) = g(x²+1) = √(x²+1) ✓
> 
> Nota: La descomposición NO es única
> 
> Alternativa:
> f(x) = x, g(u) = √(u²+1)
> También funciona pero menos útil
> ```
> 
> **Método 4 - Análisis del dominio:**
> 
> ```
> Para Dom(g ∘ f):
> 
> 1. Determinar Dom(f)
> 2. Calcular Ran(f)
> 3. Determinar Dom(g)
> 4. Encontrar intersección: Ran(f) ∩ Dom(g)
> 5. Retroceder: ¿qué x ∈ Dom(f) producen f(x) en esa intersección?
> 
> Ejemplo:
> f(x) = x − 3,   Dom(f) = ℝ,    Ran(f) = ℝ
> g(x) = √x,      Dom(g) = [0, +∞)
> 
> (g ∘ f)(x) = √(x−3)
> 
> Paso 4: ℝ ∩ [0, +∞) = [0, +∞)
> Paso 5: ¿Cuándo f(x) ≥ 0?
>         x − 3 ≥ 0 ⟹ x ≥ 3
> 
> Dom(g ∘ f) = [3, +∞)
> ```

> [!example]- Ejemplos Detallados de Composición
> 
> **Ejemplo 1 - Composiciones básicas:**
> 
> ```
> f(x) = x + 2
> g(x) = 3x
> 
> (g ∘ f)(x) = g(x+2) = 3(x+2) = 3x + 6
> (f ∘ g)(x) = f(3x) = 3x + 2
> 
> g ∘ f ≠ f ∘ g
> ```
> 
> 
> **Ejemplo 2 - Con radicales (continuación):**
> 
> ```
> (f ∘ g)(x) = f(x²−4) = √(x²−4)
> 
> Condiciones:
> 1) x ∈ Dom(g) = ℝ ✓
> 2) x²−4 ∈ Dom(f), es decir, x²−4 ≥ 0
>    x² ≥ 4
>    |x| ≥ 2
> 
> Dom(f ∘ g) = (−∞, −2] ∪ [2, +∞)
> 
> Nota: Dom(g∘f) ≠ Dom(f∘g)
> ```
> 
> **Ejemplo 3 - Funciones trigonométricas:**
> 
> ```
> f(x) = sin(x)
> g(x) = x²
> 
> (g ∘ f)(x) = sin²(x)
> Dom(g ∘ f) = ℝ
> Ran(g ∘ f) = [0, 1]
> 
> (f ∘ g)(x) = sin(x²)
> Dom(f ∘ g) = ℝ
> Ran(f ∘ g) = [−1, 1]
> 
> Funciones distintas con propiedades diferentes
> ```
> 
> **Ejemplo 4 - Composición triple:**
> 
> ```
> f(x) = x + 1
> g(x) = x²
> h(x) = √x
> 
> (h ∘ g ∘ f)(x) = h(g(x+1))
>                 = h((x+1)²)
>                 = √((x+1)²)
>                 = |x+1|
> 
> Dom(h ∘ g ∘ f) = ℝ (todo x funciona)
> 
> Orden de aplicación: f primero, luego g, luego h
> ```
> 
> **Ejemplo 5 - Función inversa:**
> 
> ```
> f(x) = 2x + 3
> f⁻¹(x) = (x−3)/2
> 
> (f ∘ f⁻¹)(x) = f((x−3)/2) = 2((x−3)/2) + 3 = x
> (f⁻¹ ∘ f)(x) = f⁻¹(2x+3) = ((2x+3)−3)/2 = x
> 
> f ∘ f⁻¹ = f⁻¹ ∘ f = id
> 
> Propiedad característica de funciones inversas
> ```
> 
> **Ejemplo 6 - Con funciones racionales:**
> 
> ```
> f(x) = 1/x,     Dom(f) = ℝ \ {0}
> g(x) = x/(x−1), Dom(g) = ℝ \ {1}
> 
> (g ∘ f)(x) = g(1/x) = (1/x)/((1/x)−1)
>            = (1/x)/(1−x)/x)
>            = 1/(1−x)
> 
> Condiciones para Dom(g∘f):
> 1) x ≠ 0 (Dom de f)
> 2) 1/x ≠ 1 (Dom de g)
>    1/x ≠ 1 ⟹ x ≠ 1
> 
> Dom(g ∘ f) = ℝ \ {0, 1}
> ```
> 
> **Ejemplo 7 - Descomposición de funciones complejas:**
> 
> ```
> h(x) = sin(√(x² + 1))
> 
> Descomposición posible:
> f₁(x) = x²
> f₂(x) = x + 1
> f₃(x) = √x
> f₄(x) = sin(x)
> 
> h = f₄ ∘ f₃ ∘ f₂ ∘ f₁
> 
> Verificación:
> x → x² → x²+1 → √(x²+1) → sin(√(x²+1)) ✓
> 
> Descomposición alternativa más simple:
> g(x) = x² + 1
> k(x) = sin(√x)
> 
> h = k ∘ g
> ```

## 🔀 Transformaciones de Funciones

> [!success]- Traslaciones, Reflexiones y Escalamientos
> 
> **Traslación horizontal:**
> 
> ```
> Dada f(x), la función trasladada horizontalmente es:
> 
> g(x) = f(x − h)
> 
> h > 0: desplazamiento hacia la DERECHA
> h < 0: desplazamiento hacia la IZQUIERDA
> 
> Dom(g) = {x : x−h ∈ Dom(f)} = Dom(f) + h
> 
> Ejemplo:
> f(x) = x²
> g(x) = (x−3)² : parábola desplazada 3 unidades a la derecha
> h(x) = (x+2)² : parábola desplazada 2 unidades a la izquierda
> ```
> 
> **Traslación vertical:**
> 
> ```
> g(x) = f(x) + k
> 
> k > 0: desplazamiento hacia ARRIBA
> k < 0: desplazamiento hacia ABAJO
> 
> Dom(g) = Dom(f) (no cambia)
> Ran(g) = Ran(f) + k
> 
> Ejemplo:
> f(x) = sin(x),    Ran(f) = [−1, 1]
> g(x) = sin(x) + 2, Ran(g) = [1, 3]
> ```
> 
> **Traslación general:**
> 
> ```
> g(x) = f(x − h) + k
> 
> Desplazamiento horizontal por h
> Desplazamiento vertical por k
> 
> Ejemplo:
> f(x) = x²
> g(x) = (x−2)² + 3
> 
> Vértice se mueve de (0,0) a (2,3)
> ```
> 
> **Reflexión respecto al eje x:**
> 
> ```
> g(x) = −f(x)
> 
> Dom(g) = Dom(f)
> Ran(g) = −Ran(f) = {−y : y ∈ Ran(f)}
> 
> Gráfica invertida verticalmente
> 
> Ejemplo:
> f(x) = e^x,  Ran(f) = (0, +∞)
> g(x) = −e^x, Ran(g) = (−∞, 0)
> ```
> 
> **Reflexión respecto al eje y:**
> 
> ```
> g(x) = f(−x)
> 
> Dom(g) = −Dom(f) = {x : −x ∈ Dom(f)}
> Ran(g) = Ran(f)
> 
> Gráfica invertida horizontalmente
> 
> Ejemplo:
> f(x) = √x,    Dom(f) = [0, +∞)
> g(x) = √(−x), Dom(g) = (−∞, 0]
> ```
> 
> **Escalamiento vertical:**
> 
> ```
> g(x) = a·f(x), a > 0
> 
> a > 1: estiramiento vertical
> 0 < a < 1: compresión vertical
> 
> Dom(g) = Dom(f)
> Ran(g) = a·Ran(f)
> 
> Ejemplo:
> f(x) = sin(x), Ran(f) = [−1, 1]
> g(x) = 3sin(x), Ran(g) = [−3, 3]
> ```
> 
> **Escalamiento horizontal:**
> 
> ```
> g(x) = f(bx), b > 0
> 
> b > 1: compresión horizontal
> 0 < b < 1: estiramiento horizontal
> 
> Dom(g) = (1/b)·Dom(f)
> Ran(g) = Ran(f)
> 
> Ejemplo:
> f(x) = sin(x), período 2π
> g(x) = sin(2x), período π (compresión)
> h(x) = sin(x/2), período 4π (estiramiento)
> ```

> [!tip]- Combinaciones de Transformaciones
> 
> **Orden de aplicación:**
> 
> ```
> Para g(x) = a·f(b(x−h)) + k:
> 
> 1. Traslación horizontal: x → x−h
> 2. Escalamiento horizontal: x → bx
> 3. Escalamiento vertical: y → ay
> 4. Traslación vertical: y → y+k
> 
> Ejemplo:
> f(x) = x²
> g(x) = 2(3(x−1))² + 4
>      = 2(3x−3)² + 4
>      = 2·9(x−1)² + 4
>      = 18(x−1)² + 4
> 
> Paso 1: x → x−1 (derecha 1)
> Paso 2: x → 3x (compresión horizontal por 1/3)
> Paso 3: y → 18y (estiramiento vertical por 18)
> Paso 4: y → y+4 (arriba 4)
> ```
> 
> **Forma canónica de cuadrática:**
> 
> ```
> f(x) = ax² + bx + c
> 
> Completar cuadrado:
> f(x) = a(x − h)² + k
> 
> donde h = −b/(2a), k = c − b²/(4a)
> 
> Vértice: (h, k)
> 
> Transformación de f₀(x) = x²:
> - Traslación horizontal por h
> - Escalamiento vertical por a
> - Traslación vertical por k
> 
> Ejemplo:
> f(x) = 2x² − 8x + 11
> 
> f(x) = 2(x² − 4x) + 11
>      = 2(x² − 4x + 4 − 4) + 11
>      = 2((x−2)² − 4) + 11
>      = 2(x−2)² − 8 + 11
>      = 2(x−2)² + 3
> 
> Vértice en (2, 3)
> ```

> [!example]- Ejemplos de Transformaciones
> 
> **Ejemplo 1 - Familia de parábolas:**
> 
> ```
> Función base: f(x) = x²
> 
> g(x) = (x−1)²     : traslación derecha 1
> h(x) = x² + 2     : traslación arriba 2
> k(x) = −x²        : reflexión eje x
> m(x) = (−x)² = x² : reflexión eje y (igual)
> n(x) = 2x²        : estiramiento vertical
> p(x) = (2x)² = 4x²: compresión horizontal
> ```
> 
> **Ejemplo 2 - Función sinusoidal general:**
> 
> ```
> f(x) = A·sin(B(x − C)) + D
> 
> A = amplitud (|A|)
> B = frecuencia (período = 2π/|B|)
> C = desplazamiento de fase
> D = línea media (desplazamiento vertical)
> 
> Ejemplo específico:
> f(x) = 3·sin(2(x − π/4)) + 1
> 
> Amplitud: 3
> Período: 2π/2 = π
> Fase: π/4 a la derecha
> Desplazamiento vertical: 1
> Rango: [−3+1, 3+1] = [−2, 4]
> ```
> 
> **Ejemplo 3 - Función exponencial modificada:**
> 
> ```
> Base: f(x) = e^x
> 
> g(x) = e^(x−2) − 3
> 
> Transformaciones:
> 1. Traslación derecha 2: e^(x−2)
> 2. Traslación abajo 3: e^(x−2) − 3
> 
> Asíntota horizontal: y = −3 (en lugar de y = 0)
> Dom(g) = ℝ
> Ran(g) = (−3, +∞)
> ```
> 
> **Ejemplo 4 - Valor absoluto transformado:**
> 
> ```
> Base: f(x) = |x|
> 
> g(x) = −2|x+3| + 5
> 
> Transformaciones:
> 1. Traslación izquierda 3: |x+3|
> 2. Estiramiento vertical por 2: 2|x+3|
> 3. Reflexión eje x: −2|x+3|
> 4. Traslación arriba 5: −2|x+3| + 5
> 
> Vértice: (−3, 5)
> Abre hacia abajo
> Ran(g) = (−∞, 5]
> ```

## 🎯 Operaciones Especiales

> [!success]- Valor Absoluto de Funciones
> 
> **Definición:**
> 
> ```
> |f|(x) = |f(x)|
> 
> Se lee: "valor absoluto de f"
> ```
> 
> **Propiedades:**
> 
> ```
> Dom(|f|) = Dom(f)
> Ran(|f|) ⊆ [0, +∞)
> 
> |f|(x) = { f(x)   si f(x) ≥ 0
>          { −f(x)  si f(x) < 0
> 
> Relación con máximo:
> |f|(x) = max{f(x), −f(x)}
> ```
> 
> **Efecto gráfico:**
> 
> ```
> La gráfica de |f| se obtiene de la gráfica de f:
> - Mantener partes donde f(x) ≥ 0
> - Reflejar partes donde f(x) < 0 respecto al eje x
> 
> Resultado: gráfica completamente sobre o en el eje x
> ```

> [!example]- Ejemplos de Valor Absoluto
> 
> **Ejemplo 1:**
> 
> ```
> f(x) = x − 2
> 
> |f|(x) = |x − 2| = { x − 2   si x ≥ 2
>                    { 2 − x   si x < 2
> 
> Gráfica: V con vértice en (2, 0)
> ```
> 
> **Ejemplo 2:**
> 
> ```
> f(x) = sin(x)
> 
> |f|(x) = |sin(x)|
> 
> Período: π (mitad del original)
> Rango: [0, 1] (en lugar de [−1, 1])
> 
> Partes negativas reflejadas hacia arriba
> ```

> [!success]- Potencias de Funciones
> 
> **Definición:**
> 
> ```
> f^n(x) = [f(x)]^n
> 
> Nota: f^n ≠ f∘f∘...∘f (composición n veces)
> 
> Para composición: f^(n) o f^∘n
> ```
> 
> **Propiedades:**
> 
> ```
> Dom(f^n) depende de n:
> 
> - Si n es entero positivo:
>   Dom(f^n) = Dom(f)
> 
> - Si n es par:
>   Ran(f^n) ⊆ [0, +∞)
> 
> - Si n es impar:
>   Ran(f^n) puede tener signo según Ran(f)
> 
> - Si n es fraccionario o negativo:
>   Restricciones adicionales
> ```

> [!example]- Ejemplos de Potencias
> 
> **Ejemplo 1:**
> 
> ```
> f(x) = x − 1
> f²(x) = (x−1)²
> f³(x) = (x−1)³
> 
> Dom(f) = Dom(f²) = Dom(f³) = ℝ
> 
> Ran(f) = ℝ
> Ran(f²) = [0, +∞)
> Ran(f³) = ℝ
> ```
> 
> **Ejemplo 2:**
> 
> ```
> f(x) = sin(x)
> 
> f²(x) = sin²(x)
> Ran(f²) = [0, 1]
> 
> Identidad: sin²(x) + cos²(x) = 1
> ```

> [!success]- Parte Positiva y Negativa
> 
> **Definiciones:**
> 
> ```
> Parte positiva:
> f⁺(x) = max{f(x), 0} = { f(x)  si f(x) ≥ 0
>                         { 0     si f(x) < 0
> 
> Parte negativa:
> f⁻(x) = max{−f(x), 0} = { 0      si f(x) ≥ 0
>                          { −f(x)  si f(x) < 0
> 
> Nota: f⁻(x) ≥ 0 siempre (a pesar del nombre)
> ```
> 
> **Relaciones:**
> 
> ```
> f(x) = f⁺(x) − f⁻(x)
> |f(x)| = f⁺(x) + f⁻(x)
> 
> f⁺(x) = (f(x) + |f(x)|)/2
> f⁻(x) = (|f(x)| − f(x))/2
> ```

## 🔄 Operaciones Funcionales Avanzadas

> [!success]- Convolución de Funciones
> 
> **Definición:**
> 
> ```
> (f * g)(x) = ∫₋∞^∞ f(t)g(x−t) dt
> 
> Se lee: "f convolución g"
> 
> Cuando existe la integral
> ```
> 
> **Propiedades:**
> 
> ```
> 1) Conmutativa: f * g = g * f
> 2) Asociativa: (f * g) * h = f * (g * h)
> 3) Distributiva: f * (g + h) = f*g + f*h
> 4) Identidad: f * δ = f (delta de Dirac)
> 5) Transformada de Fourier:
>    ℱ{f * g} = ℱ{f} · ℱ{g}
> ```
> 
> **Aplicaciones:**
> 
> ```
> - Procesamiento de señales (filtros)
> - Teoría de probabilidad (suma de variables aleatorias)
> - Ecuaciones diferenciales (función de Green)
> - Procesamiento de imágenes (blur, edge detection)
> ```

> [!example]- Ejemplo de Convolución
> 
> ```
> f(x) = rect(x) (pulso rectangular)
> g(x) = rect(x)
> 
> (f * g)(x) = Λ(x) (función triangular)
> 
> La convolución de dos pulsos rectangulares
> produce un pulso triangular
> ```

> [!success]- Derivada e Integral de Funciones
> 
> **Derivada:**
> 
> ```
> Si f es derivable, define:
> f'(x) = df/dx = lim(h→0) [f(x+h) − f(x)]/h
> 
> Operación que produce nueva función
> 
> Dom(f') ⊆ Dom(f) (puede ser más pequeño)
> ```
> 
> **Propiedades de la derivada:**
> 
> ```
> (f + g)' = f' + g'  (linealidad)
> (cf)' = c·f'
> (fg)' = f'g + fg'   (regla del producto)
> (f/g)' = (f'g − fg')/g²  (regla del cociente)
> (f ∘ g)' = (f' ∘ g)·g'   (regla de la cadena)
> ```
> 
> **Integral indefinida:**
> 
> ```
> Si F'(x) = f(x), entonces F es antiderivada de f
> 
> ∫f(x)dx = F(x) + C
> 
> Familia de funciones (constante arbitraria C)
> ```
> 
> **Integral definida:**
> 
> ```
> Para f integrable en [a, b]:
> 
> ∫ₐᵇ f(x)dx = número real
> 
> Operación que produce número, no función
> 
> Pero define función:
> F(x) = ∫ₐˣ f(t)dt
> 
> Teorema Fundamental: F'(x) = f(x)
> ```

## 📊 Propiedades Heredadas

> [!tip]- Cómo las Operaciones Afectan Propiedades
> 
> **Continuidad:**
> 
> ```
> Si f y g son continuas en x₀:
> 
> ✓ f + g es continua en x₀
> ✓ f − g es continua en x₀
> ✓ f · g es continua en x₀
> ✓ f/g es continua en x₀ si g(x₀) ≠ 0
> ✓ g ∘ f es continua en x₀ si f continua en x₀ y g continua en f(x₀)
> ✓ c·f es continua en x₀
> ```
> 
> **Derivabilidad:**
> 
> ```
> Si f y g son derivables en x₀:
> 
> ✓ f + g es derivable en x₀
> ✓ f − g es derivable en x₀
> ✓ f · g es derivable en x₀
> ✓ f/g es derivable en x₀ si g(x₀) ≠ 0
> ✓ g ∘ f es derivable si f derivable en x₀ y g derivable en f(x₀)
> 
> Advertencia: |f| puede no ser derivable aunque f lo sea
> Ejemplo: f(x) = x es derivable en 0
>          |f|(x) = |x| NO es derivable en 0
> ```
> 
> **Monotonía:**
> 
> ```
> Si f y g son crecientes:
> 
> ✓ f + g es creciente
> ✗ f · g puede no ser creciente (si hay valores negativos)
> ✓ g ∘ f es creciente
> 
> Si f creciente y g decreciente:
> ✗ f + g puede no ser monótona
> ```
> 
> **Paridad:**
> 
> ```
> f par: f(−x) = f(x)
> f impar: f(−x) = −f(x)
> 
> Operaciones:
> par + par = par
> impar + impar = impar
> par · par = par
> par · impar = impar
> impar · impar = par
> f par ∘ g cualquiera = par
> f cualquiera ∘ g par = par
> ```
> 
> **Periodicidad:**
> 
> ```
> Si f tiene período T: f(x+T) = f(x)
> 
> Operaciones:
> ✓ f + g periódica si f, g tienen períodos conmensurables
> ✓ f · g periódica bajo misma condición
> ✓ c·f tiene mismo período T
> ✓ f(bx) tiene período T/|b|
> ✗ g ∘ f generalmente NO periódica
> ```
> 
> **Acotación:**
> 
> ```
> Si |f(x)| ≤ M y |g(x)| ≤ N:
> 
> ✓ |f + g| ≤ M + N
> ✓ |f · g| ≤ M·N
> ✓ |c·f| ≤ |c|M
> 
> Para composición:
> Si |g| ≤ M y f acotada en [−M, M], entonces f∘g acotada
> ```

## ⚠️ Errores Comunes

> [!warning]- Confusiones Frecuentes
> 
> **1. "Dom(f+g) = Dom(f) ∪ Dom(g)"**
> 
> ```
> ✗ INCORRECTO
> 
> ✓ CORRECTO: Dom(f+g) = Dom(f) ∩ Dom(g)
> 
> Contraejemplo:
> f(x) = √x,     Dom(f) = [0, +∞)
> g(x) = √(-x),  Dom(g) = (-∞, 0]
> 
> Dom(f) ∪ Dom(g) = ℝ
> Pero (f+g)(x) = √x + √(-x) solo existe en {0}
> Dom(f+g) = {0} ≠ ℝ
> ```
> 
> **2. "(f·g)(x) = 0 implica f(x) = 0 y g(x) = 0"**
> 
> ```
> ✗ INCORRECTO
> 
> ✓ CORRECTO: f(x) = 0 O g(x) = 0 (no necesariamente ambos)
> 
> Ejemplo:
> f(x) = x, g(x) = sin(x)
> (f·g)(π) = π·sin(π) = π·0 = 0
> Pero f(π) = π ≠ 0
> ```
> 
> **3. "g∘f = f∘g siempre"**
> 
> ```
> ✗ INCORRECTO (la composición NO es conmutativa)
> 
> Contraejemplo:
> f(x) = x + 1, g(x) = x²
> 
> (g∘f)(x) = (x+1)² = x² + 2x + 1
> (f∘g)(x) = x² + 1
> 
> x² + 2x + 1 ≠ x² + 1
> ```
> 
> **4. "(f/g)(x) = f(x)/g(x) está definida si f y g están definidas"**
> 
> ```
> ✗ INCORRECTO
> 
> ✓ CORRECTO: También se requiere g(x) ≠ 0
> 
> Ejemplo:
> f(x) = x², g(x) = x
> Ambas definidas en x = 0
> Pero (f/g)(0) = 0/0 NO está definida
> ```
> 
> **5. "Dom(f∘g) = Dom(g)"**
> 
> ```
> ✗ INCORRECTO (falta verificar que g(x) ∈ Dom(f))
> 
> ✓ CORRECTO: Dom(f∘g) = {x ∈ Dom(g) : g(x) ∈ Dom(f)}
> 
> Contraejemplo:
> f(x) = √x,    Dom(f) = [0, +∞)
> g(x) = x - 5,  Dom(g) = ℝ
> 
> (f∘g)(x) = √(x-5)
> Dom(f∘g) = [5, +∞) ≠ ℝ
> ```
> 
> **6. "|f + g| = |f| + |g|"**
> 
> ```
> ✗ INCORRECTO
> 
> ✓ CORRECTO: |f + g| ≤ |f| + |g| (desigualdad triangular)
> 
> Contraejemplo:
> f(x) = x, g(x) = -x
> 
> |f(x) + g(x)| = |0| = 0
> |f(x)| + |g(x)| = |x| + |-x| = 2|x|
> 
> 0 ≠ 2|x| para x ≠ 0
> ```
> 
> **7. "(f²)' = 2f'"**
> 
> ```
> ✗ INCORRECTO
> 
> ✓ CORRECTO: (f²)' = 2f·f' (regla de la cadena)
> 
> Ejemplo:
> f(x) = x + 1, f'(x) = 1
> f²(x) = (x+1)²
> 
> (f²)'(x) = 2(x+1)·1 = 2x + 2
> Pero 2f'(x) = 2·1 = 2
> 
> 2x + 2 ≠ 2
> ```
> 
> **8. "Si f trasladada h unidades: f(x+h)"**
> 
> ```
> ✗ INCORRECTO (signo opuesto)
> 
> ✓ CORRECTO: f(x-h) traslada h unidades a la DERECHA
>            f(x+h) traslada h unidades a la IZQUIERDA
> 
> Ejemplo:
> f(x) = x²
> g(x) = (x-3)² tiene vértice en x = 3 (derecha)
> h(x) = (x+3)² tiene vértice en x = -3 (izquierda)
> 
> Regla mnemotécnica: el signo es opuesto a la dirección
> ```
> 
> **9. "Ran(f·g) = Ran(f)·Ran(g)"**
> 
> ```
> ✗ INCORRECTO (solo inclusión)
> 
> ✓ CORRECTO: Ran(f·g) ⊆ Ran(f)·Ran(g)
> 
> Contraejemplo:
> f(x) = x,     Dom(f) = [-1, 1], Ran(f) = [-1, 1]
> g(x) = -x,    Dom(g) = [-1, 1], Ran(g) = [-1, 1]
> 
> (f·g)(x) = -x²
> Ran(f·g) = [-1, 0]
> 
> Ran(f)·Ran(g) = {ab : a,b ∈ [-1,1]}
>                = [-1, 1]
> 
> [-1, 0] ⊊ [-1, 1]
> ```
> 
> **10. "f∘(g+h) = f∘g + f∘h"**
> 
> ```
> ✗ INCORRECTO (composición NO distribuye sobre suma)
> 
> Contraejemplo:
> f(x) = x², g(x) = x, h(x) = 1
> 
> f∘(g+h)(x) = f(x+1) = (x+1)² = x² + 2x + 1
> 
> (f∘g + f∘h)(x) = f(x) + f(1) = x² + 1
> 
> x² + 2x + 1 ≠ x² + 1
> ```

## 🎯 Casos Especiales y Sutilezas

> [!warning]- Situaciones que Requieren Atención Especial
> 
> **1. Simplificación algebraica vs dominio:**
> 
> ```
> f(x) = (x² - 4)/(x - 2)
> 
> Algebraicamente: f(x) = (x+2)(x-2)/(x-2) = x + 2
> 
> ⚠️ PERO: Dom(f) = ℝ \ {2}
> 
> La simplificación no elimina la restricción original
> f tiene discontinuidad removible en x = 2
> 
> Función extendida:
> f̃(x) = { (x²-4)/(x-2)  si x ≠ 2
>        {     4          si x = 2
> 
> f̃ es continua en ℝ
> ```
> 
> **2. Composición con funciones inversas:**
> 
> ```
> Si f: A → B es biyectiva con inversa f⁻¹: B → A
> 
> (f⁻¹ ∘ f)(x) = x para todo x ∈ A
> (f ∘ f⁻¹)(y) = y para todo y ∈ B
> 
> Pero si f no es biyectiva:
> 
> Ejemplo: f(x) = x², Dom(f) = ℝ, Ran(f) = [0, +∞)
> No es inyectiva, no tiene inversa en ℝ
> 
> Restricción: f: [0,+∞) → [0,+∞), f(x) = x²
> Ahora sí tiene inversa: f⁻¹(x) = √x
> 
> (f⁻¹ ∘ f)(x) = √(x²) = |x| = x  (en [0,+∞))
> (f ∘ f⁻¹)(x) = (√x)² = x  ✓
> ```
> 
> **3. Operaciones con funciones por partes:**
> 
> ```
> f(x) = { x      si x < 0
>        { x²     si x ≥ 0
> 
> g(x) = { 2x     si x < 0
>        { 1      si x ≥ 0
> 
> Para sumar: analizar cada región
> 
> (f + g)(x) = { x + 2x = 3x     si x < 0
>              { x² + 1          si x ≥ 0
> 
> Verificar continuidad en puntos de transición:
> lím(x→0⁻) (f+g)(x) = 0
> lím(x→0⁺) (f+g)(x) = 1
> 
> Discontinuidad de salto en x = 0
> ```
> 
> **4. Transformaciones y asíntotas:**
> 
> ```
> f(x) = 1/x tiene asíntota vertical en x = 0
>                   asíntota horizontal en y = 0
> 
> Traslación: g(x) = 1/(x-2) + 3
> 
> Asíntota vertical: x = 2 (desplazada)
> Asíntota horizontal: y = 3 (desplazada)
> 
> Dom(g) = ℝ \ {2}
> Ran(g) = ℝ \ {3}
> ```
> 
> **5. Composición que extiende dominio:**
> 
> ```
> f(x) = √x,     Dom(f) = [0, +∞)
> g(x) = x²,     Dom(g) = ℝ
> 
> (f ∘ g)(x) = √(x²) = |x|
> 
> Dom(f∘g) = ℝ (más grande que Dom(f))
> 
> g "preprocesa" para hacer valores admisibles para f
> ```
> 
> **6. Periodicidad y operaciones:**
> 
> ```
> f(x) = sin(x),  período 2π
> g(x) = cos(x),  período 2π
> 
> (f + g)(x) = sin(x) + cos(x) = √2·sin(x + π/4)
> Período: 2π  ✓
> 
> Pero: h(x) = sin(x) + sin(√2·x)
> 
> sin(x) tiene período 2π
> sin(√2·x) tiene período 2π/√2 = √2·π
> 
> Razón 2π/(√2·π) = √2 es irracional
> ⟹ h NO es periódica
> ```

## 📐 Estructura Algebraica del Espacio de Funciones

> [!success]- Funciones como Espacio Vectorial
> 
> **Definición:**
> 
> ```
> Sea F(A, ℝ) el conjunto de todas las funciones f: A → ℝ
> 
> Con operaciones:
> - Suma: (f + g)(x) = f(x) + g(x)
> - Múltiplo escalar: (c·f)(x) = c·f(x)
> 
> F(A, ℝ) es un espacio vectorial sobre ℝ
> ```
> 
> **Axiomas verificados:**
> 
> ```
> 1. Cerradura suma: f, g ∈ F ⟹ f+g ∈ F
> 2. Conmutatividad: f + g = g + f
> 3. Asociatividad: (f+g)+h = f+(g+h)
> 4. Elemento neutro: función cero 0(x) = 0
>    f + 0 = f
> 5. Elemento opuesto: -f donde (-f)(x) = -f(x)
>    f + (-f) = 0
> 6. Cerradura escalar: c ∈ ℝ, f ∈ F ⟹ c·f ∈ F
> 7. Distributividad: c(f+g) = cf + cg
> 8. Distributividad: (c+d)f = cf + df
> 9. Asociatividad: c(df) = (cd)f
> 10. Identidad: 1·f = f
> ```
> 
> **Subespacios importantes:**
> 
> ```
> - C(A): funciones continuas en A
> - C^n(A): funciones n veces diferenciables
> - C^∞(A): funciones infinitamente diferenciables
> - L²(A): funciones de cuadrado integrable
> - P_n: polinomios de grado ≤ n
> 
> Todos son subespacios vectoriales de F(A, ℝ)
> ```

> [!success]- Álgebra de Funciones
> 
> **Definición:**
> 
> ```
> F(A, ℝ) con suma y producto punto a punto es un álgebra
> 
> Operaciones:
> - Suma: (f + g)(x) = f(x) + g(x)
> - Producto: (f·g)(x) = f(x)·g(x)
> - Múltiplo escalar: (c·f)(x) = c·f(x)
> ```
> 
> **Propiedades del producto:**
> 
> ```
> 1. Conmutatividad: f·g = g·f
> 2. Asociatividad: (f·g)·h = f·(g·h)
> 3. Distributividad: f·(g+h) = f·g + f·h
> 4. Elemento identidad: función 1(x) = 1
>    f·1 = f
> 5. Compatible con escalares: c(f·g) = (cf)·g
> ```
> 
> **No es álgebra de división:**
> 
> ```
> No todo elemento no nulo tiene inverso multiplicativo
> 
> Ejemplo: f(x) = x
> Si existe f⁻¹ tal que f·f⁻¹ = 1:
> x·f⁻¹(x) = 1 para todo x
> 
> Pero en x = 0: 0·f⁻¹(0) = 1 (imposible)
> 
> ⟹ f no tiene inverso multiplicativo en F(ℝ,ℝ)
> ```

## 🔄 Simetrías y Operaciones

> [!tip]- Funciones Pares e Impares
> 
> **Definiciones:**
> 
> ```
> f es PAR si: f(-x) = f(x) para todo x ∈ Dom(f)
> f es IMPAR si: f(-x) = -f(x) para todo x ∈ Dom(f)
> 
> Nota: Dom(f) debe ser simétrico respecto al origen
> ```
> 
> **Ejemplos:**
> 
> ```
> Pares:
> - f(x) = x²
> - f(x) = cos(x)
> - f(x) = |x|
> - f(x) = x⁴ + x² + 1
> 
> Impares:
> - f(x) = x
> - f(x) = sin(x)
> - f(x) = x³
> - f(x) = tan(x)
> ```
> 
> **Operaciones con paridad:**
> 
> ```
> PAR + PAR = PAR
> Ejemplo: x² + cos(x) es par
> 
> IMPAR + IMPAR = IMPAR
> Ejemplo: x + sin(x) es impar
> 
> PAR + IMPAR = ni par ni impar
> Ejemplo: x² + x
> 
> PAR · PAR = PAR
> Ejemplo: x²·cos(x) es par
> 
> IMPAR · IMPAR = PAR
> Ejemplo: x·sin(x) es par
> 
> PAR · IMPAR = IMPAR
> Ejemplo: x²·sin(x) es impar
> ```
> 
> **Composición y paridad:**
> 
> ```
> PAR ∘ cualquiera = PAR
> Si f es par: (f∘g)(-x) = f(g(-x)) = f(g(x)) = (f∘g)(x)
> 
> cualquiera ∘ PAR = PAR
> Si g es par: (f∘g)(-x) = f(g(-x)) = f(g(x)) = (f∘g)(x)
> 
> IMPAR ∘ IMPAR = IMPAR
> Si f, g impares:
> (f∘g)(-x) = f(g(-x)) = f(-g(x)) = -f(g(x)) = -(f∘g)(x)
> ```
> 
> **Descomposición en parte par e impar:**
> 
> ```
> Toda función f: ℝ → ℝ se puede escribir como:
> 
> f(x) = f_par(x) + f_impar(x)
> 
> donde:
> f_par(x) = [f(x) + f(-x)]/2  (parte par)
> f_impar(x) = [f(x) - f(-x)]/2  (parte impar)
> 
> Verificación:
> f_par(-x) = [f(-x) + f(x)]/2 = f_par(x) ✓
> f_impar(-x) = [f(-x) - f(x)]/2 = -f_impar(x) ✓
> 
> f_par + f_impar = [f(x)+f(-x)]/2 + [f(x)-f(-x)]/2
>                 = 2f(x)/2 = f(x) ✓
> 
> Ejemplo:
> f(x) = e^x
> f_par(x) = (e^x + e^(-x))/2 = cosh(x)
> f_impar(x) = (e^x - e^(-x))/2 = sinh(x)
> 
> e^x = cosh(x) + sinh(x)
> ```

## 🎓 Ejemplos Integrados

> [!example]- Problemas Resueltos Completos
> 
> **Problema 1: Operaciones múltiples**
> 
> ```
> Sean f(x) = √(x-1) y g(x) = 1/(x-2)
> 
> Encontrar dominio de:
> a) (f + g)(x)
> b) (f · g)(x)
> c) (f/g)(x)
> d) (f∘g)(x)
> e) (g∘f)(x)
> 
> SOLUCIÓN:
> 
> Dominios originales:
> Dom(f) = [1, +∞)  (por raíz cuadrada)
> Dom(g) = ℝ \ {2}  (por división)
> 
> a) Dom(f+g) = Dom(f) ∩ Dom(g)
>              = [1, +∞) ∩ (ℝ \ {2})
>              = [1, 2) ∪ (2, +∞)
> 
> b) Dom(f·g) = Dom(f) ∩ Dom(g)
>              = [1, 2) ∪ (2, +∞)  (igual que suma)
> 
> c) (f/g)(x) = √(x-1) / [1/(x-2)]
>             = (x-2)√(x-1)
> 
>    Dom(f/g) = Dom(f) ∩ Dom(g) ∩ {x : g(x) ≠ 0}
>              = [1, +∞) ∩ (ℝ\{2}) ∩ (ℝ\{2})
>              = [1, 2) ∪ (2, +∞)
> 
> d) (f∘g)(x) = f(g(x)) = f(1/(x-2)) = √(1/(x-2) - 1)
>             = √((1 - x + 2)/(x-2))
>             = √((3-x)/(x-2))
> 
>    Condiciones:
>    1) x ∈ Dom(g): x ≠ 2 ✓
>    2) g(x) ∈ Dom(f): 1/(x-2) ≥ 1
>       
>       Caso 1: x > 2
>       1/(x-2) ≥ 1 ⟹ 1 ≥ x-2 ⟹ x ≤ 3
>       Solución: 2 < x ≤ 3
>       
>       Caso 2: x < 2
>       1/(x-2) ≥ 1 (denominador negativo)
>       1 ≤ x-2 (falso para x < 2)
>       No hay solución
> 
>    Dom(f∘g) = (2, 3]
> 
> e) (g∘f)(x) = g(f(x)) = g(√(x-1)) = 1/(√(x-1) - 2)
> 
>    Condiciones:
>    1) x ∈ Dom(f): x ≥ 1 ✓
>    2) f(x) ∈ Dom(g): √(x-1) ≠ 2
>       x-1 ≠ 4
>       x ≠ 5
> 
>    Dom(g∘f) = [1, 5) ∪ (5, +∞)
> ```
> 
> **Problema 2: Descomposición de función compleja**
> 
> ```
> Dada h(x) = |sin(√(x² + 1))|
> 
> Descomponer en funciones simples usando composición
> 
> SOLUCIÓN:
> 
> Método: identificar capas desde adentro hacia afuera
> 
> Capa 1 (más interna): f₁(x) = x²
> Capa 2: f₂(x) = x + 1
> Capa 3: f₃(x) = √x
> Capa 4: f₄(x) = sin(x)
> Capa 5 (más externa): f₅(x) = |x|
> 
> Verificación:
> x → x² → x²+1 → √(x²+1) → sin(√(x²+1)) → |sin(√(x²+1))|
> 
> h = f₅ ∘ f₄ ∘ f₃ ∘ f₂ ∘ f₁
> 
> Dominios:
> Dom(f₁) = ℝ
> Dom(f₂) = ℝ
> Dom(f₃) = [0, +∞)
> Dom(f₄) = ℝ
> Dom(f₅) = ℝ
> 
> Dom(h) = ℝ (verificar compatibilidad en cada paso)
> 
> Paso 1: f₁(x) = x² ∈ [0,+∞) ⊆ Dom(f₂) ✓
> Paso 2: (f₂∘f₁)(x) = x²+1 ≥ 1 ⊆ [0,+∞) = Dom(f₃) ✓
> Paso 3: (f₃∘f₂∘f₁)(x) = √(x²+1) ∈ ℝ = Dom(f₄) ✓
> Paso 4: (f₄∘f₃∘f₂∘f₁)(x) ∈ [-1,1] ⊆ ℝ = Dom(f₅) ✓
> 
> Por tanto Dom(h) = ℝ
> ```
> 
> **Problema 3: Transformaciones complejas**
> 
> ```
> Partir de f(x) = √x y obtener g(x) = -2√(3-x) + 5
> mediante transformaciones
> 
> SOLUCIÓN:
> 
> Secuencia de transformaciones:
> 
> Paso 1: f₁(x) = √x
>         Dom = [0, +∞)
> 
> Paso 2: Reflexión horizontal
>         f₂(x) = √(-x)
>         Dom = (-∞, 0]
> 
> Paso 3: Traslación horizontal (3 unidades derecha)
>         f₃(x) = √(-(x-3)) = √(3-x)
>         Dom = (-∞, 3]
> 
> Paso 4: Estiramiento vertical (factor 2)
>         f₄(x) = 2√(3-x)
>         Dom = (-∞, 3]
> 
> Paso 5: Reflexión vertical
>         f₅(x) = -2√(3-x)
>         Dom = (-∞, 3]
>         Ran = (-∞, 0]
> 
> Paso 6: Traslación vertical (5 unidades arriba)
>         g(x) = -2√(3-x) + 5
>         Dom = (-∞, 3]
>         Ran = (-∞, 5]
> 
> Puntos clave:
> - f(0) = 0 → g(3) = 5 (punto inicial se mueve a (3,5))
> - Asíntota horizontal: y = 5
> - Función decreciente en todo su dominio
> ```

## 💡 Estrategias de Resolución

> [!tip]- Técnicas para Trabajar con Operaciones
> 
> **Para encontrar dominios de operaciones:**
> 
> 1. **Identificar dominios individuales**
>     - Determinar Dom(f) y Dom(g) por separado
>     - Considerar todas las restricciones (raíces, divisiones, logaritmos)
> 2. **Para suma, resta, producto:**
>     - Dom(f ± g) = Dom(f) ∩ Dom(g)
>     - Dom(f · g) = Dom(f) ∩ Dom(g)
>     - Intersectar los dominios
> 3. **Para división:**
>     - Dom(f/g) = Dom(f) ∩ Dom(g) ∩ {x : g(x) ≠ 0}
>     - Encontrar ceros de g y excluirlos
> 4. **Para composición f∘g:**
>     - Paso A: x debe estar en Dom(g)
>     - Paso B: g(x) debe estar en Dom(f)
>     - Dom(f∘g) = {x ∈ Dom(g) : g(x) ∈ Dom(f)}
>     - Trabajar "de adentro hacia afuera"
> 
> **Para simplificar expresiones:**
> 
> 5. **Identificar estructuras conocidas**
>     - Diferencia de cuadrados: a² - b² = (a+b)(a-b)
>     - Cuadrado perfecto: a² ± 2ab + b² = (a±b)²
>     - Identidades trigonométricas
> 6. **Mantener restricciones originales**
>     - Aunque se simplifique, el dominio original prevalece
>     - Ejemplo: (x²-4)/(x-2) se simplifica a x+2, pero x≠2
> 
> **Para descomponer funciones:**
> 
> 7. **Método de las capas (cebolla)**
>     - Identificar operación más externa
>     - Pelar capas de afuera hacia adentro
>     - Cada capa es una función componente
> 8. **Verificar la descomposición**
>     - Componer en orden inverso
>     - Verificar que se obtiene la función original

## 🔗 Aplicaciones y Contextos

> [!example]- Modelaje con Operaciones de Funciones
> 
> **Física - Superposición de ondas:**
> 
> ```
> Dos ondas sinusoidales:
> f(t) = A₁sin(ω₁t + φ₁)
> g(t) = A₂sin(ω₂t + φ₂)
> 
> Onda resultante (principio de superposición):
> h(t) = (f + g)(t) = A₁sin(ω₁t + φ₁) + A₂sin(ω₂t + φ₂)
> 
> Caso especial (misma frecuencia):
> ω₁ = ω₂ = ω
> h(t) = [A₁cos(φ₁) + A₂cos(φ₂)]sin(ωt) + [A₁sin(φ₁) + A₂sin(φ₂)]cos(ωt)
>      = A_resultante·sin(ωt + φ_resultante)
> 
> Interferencia constructiva: φ₁ = φ₂
> Interferencia destructiva: φ₁ = φ₂ + π
> ```
> 
> **Economía - Funciones de costo:**
> 
> ```
> Costo fijo: C_f(x) = F (constante)
> Costo variable: C_v(x) = v·x
> 
> Costo total:
> C(x) = (C_f + C_v)(x) = F + v·x
> 
> Ingreso: I(x) = p·x (p = precio unitario)
> 
> Utilidad:
> U(x) = (I - C)(x) = p·x - (F + v·x)
>      = (p - v)·x - F
> 
> Punto de equilibrio: U(x) = 0
> (p - v)·x = F
> x* = F/(p - v)
> ```
> 
> **Biología - Crecimiento poblacional con capacidad de carga:**
> 
> ```
> Crecimiento exponencial base: f(t) = P₀e^(rt)
> Factor de limitación: g(P) = (K - P)/K
> 
> Modelo logístico (composición implícita):
> dP/dt = r·P·(1 - P/K)
> 
> Solución:
> P(t) = K/(1 + Ae^(-rt))
> 
> donde A = (K - P₀)/P₀
> 
> P(t) es composición de funciones exponencial e hiperbólica
> ```
> 
> **Ingeniería - Sistemas en cascada:**
> 
> ```
> Sistema con múltiples etapas:
> 
> Entrada → [H₁] → [H₂] → [H₃] → Salida
> 
> Si cada etapa es un sistema lineal:
> H₁(x) = a₁x + b₁
> H₂(x) = a₂x + b₂
> H₃(x) = a₃x + b₃
> 
> Sistema total:
> H = H₃ ∘ H₂ ∘ H₁
> 
> H(x) = a₃(a₂(a₁x + b₁) + b₂) + b₃
>      = a₃a₂a₁x + a₃a₂b₁ + a₃b₂ + b₃
> 
> Ganancia total: a₃a₂a₁ (producto de ganancias)
> ```
> 
> **Química - Reacciones en cadena:**
> 
> ```
> Concentración inicial: C₀
> 
> Primera reacción: C₁(t) = C₀e^(-k₁t)
> Segunda reacción usa producto de primera:
> C₂(t) = f(C₁(t))
> 
> Si la segunda es de primer orden:
> C₂(t) = C₁(t)·(1 - e^(-k₂t))
>       = C₀e^(-k₁t)·(1 - e^(-k₂t))
> 
> Producto de dos funciones exponenciales
> ```
> 
> **Procesamiento de señales - Filtros:**
> 
> ```
> Señal de entrada: s(t)
> 
> Filtro pasa-bajas: f(s) = promedio de s
> Filtro pasa-altas: g(s) = s - f(s)
> 
> Filtro pasa-banda:
> h = g ∘ f (aplicar pasa-bajas, luego pasa-altas)
> 
> Elimina frecuencias muy bajas y muy altas,
> conserva banda intermedia
> ```

## 🧮 Operaciones con Funciones Especiales

> [!success]- Funciones Especiales y sus Operaciones
> 
> **Funciones hiperbólicas:**
> 
> ```
> Definidas mediante exponenciales:
> 
> sinh(x) = (e^x - e^(-x))/2  (parte impar de e^x)
> cosh(x) = (e^x + e^(-x))/2  (parte par de e^x)
> 
> Relación fundamental:
> cosh²(x) - sinh²(x) = 1
> 
> Derivación:
> cosh²(x) - sinh²(x) = [(e^x + e^(-x))/2]² - [(e^x - e^(-x))/2]²
>                     = (e^(2x) + 2 + e^(-2x))/4 - (e^(2x) - 2 + e^(-2x))/4
>                     = 4/4 = 1
> 
> Otras funciones:
> tanh(x) = sinh(x)/cosh(x) = (e^x - e^(-x))/(e^x + e^(-x))
> 
> Dom(sinh) = Dom(cosh) = ℝ
> Dom(tanh) = ℝ
> 
> Ran(sinh) = ℝ
> Ran(cosh) = [1, +∞)
> Ran(tanh) = (-1, 1)
> ```
> 
> **Funciones definidas por integrales:**
> 
> ```
> Función error:
> erf(x) = (2/√π)∫₀^x e^(-t²) dt
> 
> Es composición de:
> - Función exponencial cuadrática: f(t) = e^(-t²)
> - Operación de integración
> - Multiplicación por constante: 2/√π
> 
> Propiedades:
> erf(-x) = -erf(x)  (función impar)
> lím(x→∞) erf(x) = 1
> lím(x→-∞) erf(x) = -1
> 
> Función error complementaria:
> erfc(x) = 1 - erf(x)
> 
> Operación: (1 - erf), donde 1 es función constante
> ```
> 
> **Funciones de Bessel:**
> 
> ```
> J_n(x) = función de Bessel de orden n
> 
> Relación de recurrencia (operación recursiva):
> J_(n+1)(x) = (2n/x)J_n(x) - J_(n-1)(x)
> 
> Expresión en términos de operaciones:
> J_(n+1) = [(2n/id)·J_n] - J_(n-1)
> 
> donde id(x) = x es la función identidad
> ```
> 
> **Polinomios ortogonales:**
> 
> ```
> Polinomios de Legendre: P_n(x)
> 
> Fórmula de Rodrigues (n-ésima derivada):
> P_n(x) = (1/(2^n·n!))·(d^n/dx^n)[(x² - 1)^n]
> 
> Operaciones involucradas:
> 1. Potencia: (x² - 1)^n
> 2. Derivación n veces
> 3. División por constante
> 
> Ejemplo: P₂(x)
> P₂(x) = (1/8)·(d²/dx²)[(x² - 1)²]
>       = (1/8)·(d²/dx²)[x⁴ - 2x² + 1]
>       = (1/8)·(d/dx)[4x³ - 4x]
>       = (1/8)·[12x² - 4]
>       = (3x² - 1)/2
> ```

## 🎨 Visualización de Operaciones

> [!tip]- Interpretación Gráfica
> 
> **Suma de funciones:**
> 
> ```
> h(x) = f(x) + g(x)
> 
> Método gráfico:
> Para cada x:
> 1. Encontrar f(x) en gráfica de f
> 2. Encontrar g(x) en gráfica de g
> 3. Sumar verticalmente: h(x) = f(x) + g(x)
> 
> Ejemplo visual:
> f(x) = x,     gráfica: línea recta
> g(x) = sin(x), gráfica: onda sinusoidal
> 
> h(x) = x + sin(x): línea recta con oscilaciones
> 
> La oscilación de sin(x) "modula" la recta
> ```
> 
> **Producto de funciones:**
> 
> ```
> h(x) = f(x)·g(x)
> 
> Características gráficas:
> 
> 4. Ceros: h tiene cero donde f o g tienen cero
>    Ceros(h) = Ceros(f) ∪ Ceros(g)
> 
> 5. Signo: h es positiva donde f y g tienen mismo signo
>    h es negativa donde f y g tienen signos opuestos
> 
> 6. Amplitud: h es grande donde ambas son grandes
>    h es pequeña si alguna es pequeña
> 
> Ejemplo:
> f(x) = e^(-x²)   (campana gaussiana)
> g(x) = sin(x)    (oscilación)
> 
> h(x) = e^(-x²)sin(x): oscilación con envolvente gaussiana
> 
> Amplitud máxima en centro, decae a los lados
> ```
> 
> **Composición de funciones:**
> 
> ```
> h(x) = (f∘g)(x) = f(g(x))
> 
> Interpretación:
> 7. g "deforma" el eje x
> 8. f se aplica sobre eje x deformado
> 
> Ejemplo:
> f(x) = x²       (parábola)
> g(x) = sin(x)   (oscilación)
> 
> h(x) = sin²(x):
> - Rango [0,1] en lugar de [-1,1]
> - Período π en lugar de 2π (compresión)
> - Siempre no negativa
> 
> La composición "rectifica" la onda sinusoidal
> ```
> 
> **Transformaciones:**
> 
> ```
> Traslación vertical f(x) + k:
> - Gráfica completa se mueve k unidades verticalmente
> - Forma no cambia
> - Asíntotas horizontales se mueven
> 
> Traslación horizontal f(x-h):
> - Gráfica completa se mueve h unidades horizontalmente
> - Forma no cambia
> - Asíntotas verticales se mueven
> 
> Reflexión -f(x):
> - Gráfica se voltea sobre eje x
> - Partes positivas → negativas y viceversa
> 
> Reflexión f(-x):
> - Gráfica se voltea sobre eje y
> - Izquierda ↔ derecha
> 
> Escalamiento a·f(x), a > 0:
> - a > 1: estiramiento vertical (gráfica más alta)
> - 0 < a < 1: compresión vertical (gráfica más baja)
> - Ceros no cambian
> 
> Escalamiento f(bx), b > 0:
> - b > 1: compresión horizontal (más estrecha)
> - 0 < b < 1: estiramiento horizontal (más ancha)
> - Intercepto y no cambia (si x=0 en dominio)
> ```

## 📋 Tabla de Propiedades Heredadas

> [!note]- Resumen de Herencia de Propiedades
> 
> |Propiedad|f+g|f-g|f·g|f/g|c·f|f∘g|
> |---|---|---|---|---|---|---|
> |**Continuidad**|✓|✓|✓|✓*|✓|✓**|
> |**Derivabilidad**|✓|✓|✓|✓*|✓|✓**|
> |**Integrabilidad**|✓|✓|✓|✓*|✓|✗|
> |**Monotonía creciente***|✓|?|?|?|✓|✓|
> |**Acotación**|✓|✓|✓|?|✓|✓|
> |**Periodicidad**|?†|?†|?†|?†|✓‡|✗|
> 
> **Leyenda:**
> 
> - ✓ : Propiedad se hereda siempre
> - ✓* : Se hereda si g(x) ≠ 0
> - ✓** : Se hereda con condiciones de dominio apropiadas
> - ✓‡ : Se hereda con mismo período
> - ? : Depende de condiciones adicionales
> - ?† : Se hereda si períodos son conmensurables
> - ✗ : No se hereda en general
> 
> **Notas adicionales:**
> 
> ```
> Monotonía:
> - f, g crecientes ⟹ f+g creciente ✓
> - f, g crecientes ⟹ f·g puede no ser creciente
>   (contraejemplo: f(x)=g(x)=x en ℝ, producto negativo para x<0)
> - f creciente, g creciente ⟹ f∘g creciente ✓
> 
> Periodicidad:
> - f período T₁, g período T₂
> - f+g periódica ⟺ T₁/T₂ racional
> - f∘g generalmente NO periódica
>   (contraejemplo: f(x)=sin(x), g(x)=2x
>    f∘g(x)=sin(2x) es periódica, pero caso especial)
> ```

## 🔍 Análisis Profundo de Casos Especiales

> [!warning]- Casos Patológicos y Límites
> 
> **Funciones con discontinuidades removibles:**
> 
> ```
> f(x) = (x² - 1)/(x - 1), g(x) = (x + 1)
> 
> Dom(f) = ℝ \ {1}
> Dom(g) = ℝ
> 
> Algebraicamente: f(x) = x + 1 para x ≠ 1
> 
> (f · g)(x) = [(x² - 1)/(x - 1)] · (x + 1)
>            = (x + 1)² para x ≠ 1
> 
> Dom(f·g) = ℝ \ {1}
> 
> Pero lím(x→1) (f·g)(x) = 4
> 
> Función extendida:
> (f·g)*(x) = { (x+1)²  si x ≠ 1
>             { 4       si x = 1
> 
> es continua en ℝ
> ```
> 
> **Indeterminaciones en composición:**
> 
> ```
> f(x) = 1/x, Dom(f) = ℝ \ {0}
> g(x) = sin(x), Dom(g) = ℝ
> 
> (f∘g)(x) = 1/sin(x)
> 
> Dom(f∘g) = {x ∈ ℝ : sin(x) ≠ 0}
>          = ℝ \ {nπ : n ∈ ℤ}
> 
> Infinitas discontinuidades (asíntotas verticales)
> en x = nπ para todo entero n
> ```
> 
> **Funciones oscilatorias:**
> 
> ```
> f(x) = x, g(x) = sin(1/x)
> 
> Dom(g) = ℝ \ {0}
> 
> (f · g)(x) = x·sin(1/x)
> 
> Comportamiento cerca de x = 0:
> |x·sin(1/x)| ≤ |x| → 0 cuando x → 0
> 
> Función extendida:
> h(x) = { x·sin(1/x)  si x ≠ 0
>        { 0           si x = 0
> 
> h es continua en x = 0 pero NO derivable ahí
> 
> Oscila infinitamente cerca del origen
> ```
> 
> **Composiciones que colapsan dominio:**
> 
> ```
> f(x) = √x,     Dom(f) = [0, +∞)
> g(x) = -x²,    Dom(g) = ℝ
> 
> (f∘g)(x) = √(-x²)
> 
> Condiciones:
> 1) x ∈ Dom(g) = ℝ ✓
> 2) g(x) ∈ Dom(f): -x² ≥ 0
>    Esto solo ocurre si x² ≤ 0
>    Como x² ≥ 0 siempre, solo x = 0 cumple
> 
> Dom(f∘g) = {0}
> 
> Dominio se reduce a un solo punto!
> (f∘g)(0) = 0
> ```

## 💻 Aplicaciones Computacionales

> [!tip]- Implementación y Algoritmos
> 
> **Evaluación eficiente de composiciones:**
> 
> ```python
> # Evaluación directa (ineficiente para múltiples puntos)
> def compose(f, g, x):
>     return f(g(x))
> 
> # Pre-computación para arrays (eficiente)
> import numpy as np
> 
> def compose_array(f, g, x_array):
>     # Primero aplicar g a todo el array
>     intermediate = g(x_array)
>     # Luego aplicar f al resultado
>     return f(intermediate)
> 
> # Ejemplo:
> f = lambda x: np.sqrt(x)
> g = lambda x: x**2 + 1
> 
> x = np.linspace(-5, 5, 1000)
> y = compose_array(f, g, x)
> # Más eficiente que evaluar punto por punto
> ```
> 
> **Verificación de dominio:**
> 
> ```python
> def safe_compose(f, g, x, dom_f, dom_g):
>     """
>     Composición con verificación de dominio
>     dom_f, dom_g: funciones que retornan True si x está en dominio
>     """
>     if not dom_g(x):
>         raise ValueError(f"{x} no está en dominio de g")
>     
>     g_x = g(x)
>     
>     if not dom_f(g_x):
>         raise ValueError(f"g({x}) = {g_x} no está en dominio de f")
>     
>     return f(g_x)
> 
> # Ejemplo:
> f = lambda x: np.sqrt(x)
> dom_f = lambda x: x >= 0
> 
> g = lambda x: x - 5
> dom_g = lambda x: True  # definida en todos los reales
> 
> # Esto funciona:
> result = safe_compose(f, g, 10, dom_f, dom_g)  # √(10-5) = √5
> 
> # Esto lanza error:
> # result = safe_compose(f, g, 2, dom_f, dom_g)  # √(2-5) = √(-3) error!
> ```
> 
> **Transformaciones paramétricas:**
> 
> ```python
> class FunctionTransformer:
>     """
>     Clase para aplicar transformaciones a funciones
>     """
>     def __init__(self, f):
>         self.f = f
>     
>     def translate_h(self, h):
>         """Traslación horizontal"""
>         return lambda x: self.f(x - h)
>     
>     def translate_v(self, k):
>         """Traslación vertical"""
>         return lambda x: self.f(x) + k
>     
>     def scale_h(self, b):
>         """Escalamiento horizontal"""
>         return lambda x: self.f(b * x)
>     
>     def scale_v(self, a):
>         """Escalamiento vertical"""
>         return lambda x: a * self.f(x)
>     
>     def reflect_h(self):
>         """Reflexión horizontal"""
>         return lambda x: self.f(-x)
>     
>     def reflect_v(self):
>         """Reflexión vertical"""
>         return lambda x: -self.f(x)
>     
>     def transform(self, a=1, b=1, h=0, k=0, reflect_x=False, reflect_y=False):
>         """Transformación general: a·f(b(x-h)) + k con reflexiones opcionales"""
>         def transformed(x):
>             x_val = x
>             if reflect_x:
>                 x_val = -x_val
>             x_val = b * (x_val - h)
>             y_val = self.f(x_val)
>             if reflect_y:
>                 y_val = -y_val
>             return a * y_val + k
>         return transformed
> 
> # Ejemplo de uso:
> base = lambda x: x**2
> transformer = FunctionTransformer(base)
> 
> # g(x) = -2(x-3)² + 5
> g = transformer.transform(a=-2, h=3, k=5)
> ```

## 🎓 Conceptos Clave para Recordar

> [!important]- Resumen Ejecutivo
> 
> **Operaciones algebraicas:**
> 
> - **(f ± g)(x) = f(x) ± g(x)** con Dom(f±g) = Dom(f) ∩ Dom(g)
> - **(f · g)(x) = f(x) · g(x)** con Dom(f·g) = Dom(f) ∩ Dom(g)
> - **(f/g)(x) = f(x)/g(x)** con Dom(f/g) = Dom(f) ∩ Dom(g) ∩ {x : g(x) ≠ 0}
> - **(c·f)(x) = c·f(x)** con Dom(c·f) = Dom(f)
> 
> **Composición:**
> 
> - **(f∘g)(x) = f(g(x))**: aplicar primero g, luego f
> - **Dom(f∘g) = {x ∈ Dom(g) : g(x) ∈ Dom(f)}**
> - **NO es conmutativa:** f∘g ≠ g∘f en general
> - **ES asociativa:** (h∘g)∘f = h∘(g∘f)
> 
> **Transformaciones:**
> 
> - **f(x-h):** traslación horizontal h unidades (derecha si h>0)
> - **f(x)+k:** traslación vertical k unidades (arriba si k>0)
> - **-f(x):** reflexión respecto al eje x
> - **f(-x):** reflexión respecto al eje y
> - **a·f(x), a>0:** escalamiento vertical (estira si a>1)
> - **f(bx), b>0:** escalamiento horizontal (comprime si b>1)
> 
> **Propiedades heredadas:**
> 
> - Continuidad se preserva en suma, producto, composición (con condiciones)
> - Derivabilidad se preserva con reglas específicas
> - Paridad: par±par=par, impar±impar=impar, par·impar=impar
> - Periodicidad se preserva si períodos son conmensurables
> 
> **Errores comunes a evitar:**
> 
> - Dom(f+g) ≠ Dom(f) ∪ Dom(g), es la **intersección**
> - f∘g ≠ g∘f en general
> - Dom(f∘g) no es simplemente Dom(g)
> - Simplificación algebraica no elimina restricciones de dominio
> - |f+g| ≠ |f|+|g| en general (desigualdad triangular)
> 
> **Estructura algebraica:**
> 
> - Funciones forman espacio vectorial bajo suma y múltiplo escalar
> - Con producto punto a punto, forman álgebra conmutativa
> - Composición no distribuye sobre suma: f∘(g+h) ≠ f∘g + f∘h

## 💡 Consejos Prácticos

> [!tip]- Estrategias de Trabajo
> 
> **Al trabajar con dominios:**
> 
> 1. **Siempre determinar dominios primero**
>     - Antes de simplificar algebraicamente
>     - Considerar todas las restricciones simultáneamente
> 2. **Para operaciones algebraicas:**
>     - Intersectar dominios individuales
>     - Para división, excluir también ceros del denominador
> 3. **Para composición f∘g:**
>     - Verificar que x ∈ Dom(g)
>     - Verificar que g(x) ∈ Dom(f)
>     - Trabajar "de adentro hacia afuera"
> 
> **Al simplificar expresiones:**
> 
> 4. **Mantener restricciones originales**
>     - (x²-4)/(x-2) = x+2 PERO con x ≠ 2
>     - Anotar discontinuidades removibles
> 5. **Factorizar cuando sea posible**
>     - Ayuda a identificar ceros y discontinuidades
>     - Útil para encontrar dominio de cocientes
> 
> **Al componer funciones:**
> 
> 6. **Método de sustitución directa**
>     - Escribir g(x) explícitamente
>     - Sustituir cada x en f por la expresión de g(x)
>     - Simplificar resultado
> 7. **Para descomponer:**
>     - Identificar "capas" de operaciones
>     - Separar función más externa
>     - Continuar hacia adentro
> 
> **Al aplicar transformaciones:**
> 
> 8. **Recordar que los signos se invierten**
>     - f(x-h) desplaza hacia la DERECHA (signo opuesto)
>     - Para desplazar derecha h, usar f(x-h), no f(x+h)
> 9. **Orden de transformaciones importa**
>     - Para a·f(b(x-h))+k: aplicar en orden h, b, a, k
>     - Horizontal primero, luego vertical
> 
> **Verificación:**
> 
> 10. **Evaluar en puntos específicos**
>     - Probar con x=0, x=1, x=-1 si aplica
>     - Verificar comportamiento en extremos de dominio
>     - Confirmar discontinuidades y asíntotas

## 🧩 Problemas Resueltos Adicionales

> [!example]- Soluciones Completas Paso a Paso
> 
> **Problema Avanzado 1: Composición múltiple con análisis de dominio**
> 
> ```
> Sean f(x) = 1/√x, g(x) = x² - 4, h(x) = |x|
> 
> Encuentra (f∘g∘h)(x) y su dominio
> 
> SOLUCIÓN:
> 
> Paso 1: Identificar dominios individuales
> Dom(f) = (0, +∞)  [raíz cuadrada y denominador]
> Dom(g) = ℝ
> Dom(h) = ℝ
> 
> Paso 2: Calcular g∘h
> (g∘h)(x) = g(h(x)) = g(|x|) = |x|² - 4 = x² - 4
> 
> Dom(g∘h): 
> - x ∈ Dom(h) = ℝ ✓
> - h(x) = |x| ∈ Dom(g) = ℝ ✓
> 
> Dom(g∘h) = ℝ
> 
> Paso 3: Calcular f∘(g∘h)
> (f∘g∘h)(x) = f((g∘h)(x)) = f(x² - 4) = 1/√(x² - 4)
> 
> Paso 4: Determinar dominio final
> Condiciones:
> 1) x ∈ Dom(g∘h) = ℝ ✓
> 2) (g∘h)(x) ∈ Dom(f) = (0, +∞)
>    
>    Necesitamos: x² - 4 > 0
>    x² > 4
>    |x| > 2
>    x < -2  o  x > 2
> 
> RESPUESTA:
> (f∘g∘h)(x) = 1/√(x² - 4)
> Dom(f∘g∘h) = (-∞, -2) ∪ (2, +∞)
> 
> Verificación:
> - En x = 3: (f∘g∘h)(3) = 1/√(9-4) = 1/√5 ✓
> - En x = -3: (f∘g∘h)(-3) = 1/√(9-4) = 1/√5 ✓
> - En x = 2: No definida (√0 en denominador) ✓
> - En x = 0: No definida (√(-4) no real) ✓
> ```
> 
> **Problema Avanzado 2: Ecuación funcional**
> 
> ```
> Encuentra todas las funciones f: ℝ → ℝ que satisfacen:
> f(x + y) = f(x) + f(y) + 2xy
> para todo x, y ∈ ℝ
> 
> SOLUCIÓN:
> 
> Paso 1: Evaluar en puntos especiales
> Hacer y = 0:
> f(x + 0) = f(x) + f(0) + 2x·0
> f(x) = f(x) + f(0)
> 
> Por tanto: f(0) = 0
> 
> Paso 2: Buscar forma general
> Hacer y = x:
> f(2x) = f(x) + f(x) + 2x²
> f(2x) = 2f(x) + 2x²
> 
> Dividir por 2:
> f(2x)/2 = f(x) + x²
> 
> Si hacemos u = 2x, entonces x = u/2:
> f(u)/2 = f(u/2) + u²/4
> 
> Esto sugiere que f tiene término cuadrático
> 
> Paso 3: Proponer solución
> Intentemos f(x) = x² + cx para alguna constante c
> 
> Verificar:
> f(x+y) = (x+y)² + c(x+y)
>        = x² + 2xy + y² + cx + cy
> 
> f(x) + f(y) + 2xy = x² + cx + y² + cy + 2xy
>                    = x² + 2xy + y² + cx + cy
> 
> ¡Coinciden! ✓
> 
> Paso 4: Probar unicidad
> Sean f y g dos soluciones. Sea h = f - g.
> Entonces:
> h(x+y) = f(x+y) - g(x+y)
>        = [f(x) + f(y) + 2xy] - [g(x) + g(y) + 2xy]
>        = [f(x) - g(x)] + [f(y) - g(y)]
>        = h(x) + h(y)
> 
> Entonces h satisface: h(x+y) = h(x) + h(y)
> Con h(0) = 0
> 
> Esta es la ecuación de Cauchy. Si pedimos continuidad,
> la única solución es h(x) = dx para alguna d ∈ ℝ.
> 
> Pero h(x) = f(x) - g(x) = (x² + c₁x) - (x² + c₂x)
>           = (c₁ - c₂)x
> 
> Es decir, d = c₁ - c₂
> 
> RESPUESTA:
> La familia de soluciones es:
> f(x) = x² + cx
> 
> donde c es una constante arbitraria en ℝ
> 
> Casos particulares:
> - c = 0: f(x) = x²
> - c = 1: f(x) = x² + x
> - c = -1: f(x) = x² - x
> ```
> 
> **Problema Avanzado 3: Transformación inversa**
> 
> ```
> La gráfica de y = f(x) pasa por los puntos:
> (0, 2), (1, 5), (2, 4), (3, 1)
> 
> ¿Por qué puntos pasa la gráfica de:
> g(x) = -2f(x-1) + 3 ?
> 
> SOLUCIÓN:
> 
> Método: Aplicar transformación a cada punto
> 
> Transformación: g(x) = -2f(x-1) + 3
> Descomponer:
> 1) f(x-1): traslación derecha 1
> 2) -2f(x-1): reflexión vertical y escalamiento por 2
> 3) -2f(x-1) + 3: traslación arriba 3
> 
> Para cada punto (a, b) en f:
> 
> Punto (0, 2):
> - Traslación derecha 1: (0, 2) → (1, 2)
> - Reflexión y escala: (1, 2) → (1, -4)
> - Traslación arriba: (1, -4) → (1, -1)
> Resultado: (1, -1)
> 
> Punto (1, 5):
> - Traslación derecha 1: (1, 5) → (2, 5)
> - Reflexión y escala: (2, 5) → (2, -10)
> - Traslación arriba: (2, -10) → (2, -7)
> Resultado: (2, -7)
> 
> Punto (2, 4):
> - Traslación derecha 1: (2, 4) → (3, 4)
> - Reflexión y escala: (3, 4) → (3, -8)
> - Traslación arriba: (3, -8) → (3, -5)
> Resultado: (3, -5)
> 
> Punto (3, 1):
> - Traslación derecha 1: (3, 1) → (4, 1)
> - Reflexión y escala: (4, 1) → (4, -2)
> - Traslación arriba: (4, -2) → (4, 1)
> Resultado: (4, 1)
> 
> Verificación algebraica para (1, -1):
> g(1) = -2f(1-1) + 3 = -2f(0) + 3 = -2(2) + 3 = -1 ✓
> 
> RESPUESTA:
> La gráfica de g pasa por:
> (1, -1), (2, -7), (3, -5), (4, 1)
> 
> Observación:
> - Todos los x aumentaron en 1 (traslación horizontal)
> - Todos los y se transformaron según: y_nuevo = -2y_viejo + 3
> ```

## 🎨 Visualización de Conceptos

> [!note]- Diagramas Conceptuales
> 
> **Diagrama de flujo para composición:**
> 
> ```
> Composición (f∘g)(x) = f(g(x))
> 
>     x (entrada)
>      ↓
>   ┌──────┐
>   │  g   │ ← Función interior (se aplica primero)
>   └──────┘
>      ↓
>    g(x) (valor intermedio)
>      ↓
>   ┌──────┐
>   │  f   │ ← Función exterior (se aplica al resultado)
>   └──────┘
>      ↓
>   f(g(x)) (salida final)
> 
> Restricciones de dominio:
> 1. x debe estar en Dom(g)
> 2. g(x) debe estar en Dom(f)
> ```
> 
> **Representación de operaciones algebraicas:**
> 
> ```
> Suma (f + g)(x):
> 
>     x
>    ↙ ↘
>   f   g
>   ↓   ↓
> f(x) g(x)
>    ↘ ↙
>     +  ← Suma de valores
>     ↓
>  f(x)+g(x)
> 
> Producto (f · g)(x):
> 
>     x
>    ↙ ↘
>   f   g
>   ↓   ↓
> f(x) g(x)
>    ↘ ↙
>     ×  ← Producto de valores
>     ↓
>  f(x)·g(x)
> 
> División (f/g)(x):
> 
>     x
>    ↙ ↘
>   f   g
>   ↓   ↓
> f(x) g(x)≠0 ← Restricción adicional
>    ↘ ↙
>     ÷
>     ↓
>  f(x)/g(x)
> ```
> 
> **Jerarquía de transformaciones:**
> 
> ```
> Función base: y = f(x)
>                 ↓
> Transformaciones horizontales (afectan x):
>   • f(x-h): traslación horizontal
>   • f(bx): escalamiento horizontal
>   • f(-x): reflexión horizontal
>                 ↓
> Transformaciones verticales (afectan y):
>   • a·f(...): escalamiento vertical
>   • -f(...): reflexión vertical
>   • ...+k: traslación vertical
>                 ↓
> Función transformada: y = a·f(b(x-h)) + k
> ```

## 🔮 Extensiones y Generalizaciones

> [!success]- Conceptos Avanzados
> 
> **Operaciones en espacios de funciones:**
> 
> ```
> Espacio C([a,b]): funciones continuas en [a,b]
> 
> Norma supremo:
> ||f||_∞ = max{|f(x)| : x ∈ [a,b]}
> 
> Propiedades:
> ||f + g||_∞ ≤ ||f||_∞ + ||g||_∞  (desigualdad triangular)
> ||c·f||_∞ = |c|·||f||_∞  (homogeneidad)
> ||f·g||_∞ ≤ ||f||_∞·||g||_∞  (submultiplicatividad)
> 
> Con esta norma, C([a,b]) es un álgebra de Banach
> ```
> 
> **Convolución de funciones:**
> 
> ```
> Definición:
> (f * g)(x) = ∫_{-∞}^{+∞} f(t)g(x-t) dt
> 
> Propiedades:
> 1. Conmutativa: f * g = g * f
> 2. Asociativa: (f * g) * h = f * (g * h)
> 3. Distributiva: f * (g + h) = f*g + f*h
> 4. Elemento identidad: δ (delta de Dirac)
>    f * δ = f
> 
> Transformada de Fourier:
> ℱ{f * g} = ℱ{f} · ℱ{g}
> 
> La convolución en dominio espacial
> es producto en dominio de frecuencias
> ```
> 
> **Operadores diferenciales:**
> 
> ```
> Operador derivada: D
> D[f] = f'
> 
> Propiedades:
> D[f + g] = D[f] + D[g]  (linealidad)
> D[c·f] = c·D[f]
> D[f·g] = D[f]·g + f·D[g]  (regla del producto)
> D[f∘g] = (D[f]∘g)·D[g]  (regla de la cadena)
> 
> Operador integral: I
> I[f](x) = ∫_a^x f(t) dt
> 
> Relación:
> D[I[f]] = f  (Teorema Fundamental del Cálculo)
> I[D[f]] = f - f(a)
> ```
> 
> **Composición infinita:**
> 
> ```
> Para función f: [0,1] → [0,1] contractiva
> 
> Secuencia de iteradas:
> f^(1) = f
> f^(2) = f∘f
> f^(3) = f∘f∘f
> ...
> f^(n) = f∘f∘...∘f (n veces)
> 
> Teorema del punto fijo de Banach:
> Si |f(x) - f(y)| ≤ k|x - y| con 0 < k < 1
> 
> Entonces existe único punto fijo x* tal que:
> f(x*) = x*
> 
> Y para cualquier x₀:
> lim_{n→∞} f^(n)(x₀) = x*
> 
> Aplicación: métodos iterativos de solución
> ```

## 🔬 Casos de Estudio

> [!example]- Análisis de Situaciones Reales
> 
> **Caso 1: Modelo epidemiológico SIR**
> 
> ```
> Población dividida en:
> - S(t): susceptibles
> - I(t): infectados  
> - R(t): recuperados
> 
> Sistema de ecuaciones:
> dS/dt = -β·S·I
> dI/dt = β·S·I - γ·I
> dR/dt = γ·I
> 
> Restricción: S + I + R = N (constante)
> 
> Operaciones:
> 1. Producto S·I (contactos infectivos)
> 2. Suma: S + I + R
> 3. Composición implícita en solución
> 
> Número reproductivo básico:
> R₀ = (β/γ)·S₀
> 
> Es cociente de funciones de parámetros
> ```
> 
> **Caso 2: Circuito RLC en serie**
> 
> ```
> Voltaje en circuito:
> V(t) = V_R + V_L + V_C
> 
> donde:
> V_R(t) = R·I(t)
> V_L(t) = L·(dI/dt)
> V_C(t) = (1/C)·∫₀^t I(τ) dτ
> 
> Operaciones:
> - Suma de tres funciones
> - Múltiplo escalar (por R, L, 1/C)
> - Derivada de I
> - Integral de I
> 
> Ecuación diferencial resultante:
> L·(d²I/dt²) + R·(dI/dt) + (1/C)·I = dV/dt
> 
> Involucra composición con operadores diferenciales
> ```
> 
> **Caso 3: Función de producción Cobb-Douglas**
> 
> ```
> Producción en economía:
> Q(K, L) = A·K^α·L^β
> 
> donde:
> K = capital
> L = trabajo
> A = productividad total
> α, β = elasticidades
> 
> Si K es función del tiempo: K = K(t)
> Y L es función del tiempo: L = L(t)
> 
> Entonces:
> Q(t) = A·[K(t)]^α·[L(t)]^β
> 
> Es composición:
> Q = (potencias)∘(K, L)
> 
> Rendimientos a escala:
> - α + β = 1: constantes
> - α + β > 1: crecientes
> - α + β < 1: decrecientes
> 
> Relacionado con suma de exponentes
> ```
