# 📊 Técnicas de Graficación de Funciones

## 🌟 Concepto Fundamental

> [!info]- Definición Intuitiva
> **La graficación de funciones es el arte de representar visualmente el comportamiento de una función en el plano cartesiano. Es traducir la información algebraica a una imagen geométrica que revela patrones, tendencias y características clave de la función.**
> 
> **Elementos clave:**
> - **Visualización:** Convertir símbolos en imágenes comprensibles
> - **Análisis:** Identificar características importantes antes de graficar
> - **Precisión:** Ubicar puntos críticos, asíntotas, interceptos
> - **Interpretación:** Leer información matemática desde la gráfica
> - **Síntesis:** Combinar múltiples técnicas para graficar eficientemente

### 📖 Contexto Histórico

> [!note]- Desarrollo Histórico de la Graficación
> 
> **Orígenes Antiguos (300 a.C. - 1600):**
> - **Apolonio (200 a.C.):** Estudio geométrico de cónicas
> - **Griegos:** Curvas como lugares geométricos
> - **Sin sistema de coordenadas:** Descripción puramente geométrica
> - **Limitación:** No existía conexión álgebra-geometría
> 
> **Revolución de las Coordenadas (1600-1700):**
> - **Fermat (1629):** Primeras ideas de coordenadas
> - **Descartes (1637):** *La Géométrie* - Sistema de coordenadas cartesianas
>   - Unificó álgebra y geometría
>   - Ecuaciones representan curvas
>   - "Cada ecuación determina una curva"
> - **Roberval (1640s):** Método de tangentes por graficación
> - **Impacto:** Nació la geometría analítica
> 
> **Era del Cálculo (1700-1800):**
> - **Newton (1687):** Clasificación de curvas cúbicas (72 tipos)
> - **Leibniz (1684):** Gráficas para visualizar derivadas
> - **Euler (1748):** *Introductio in analysin infinitorum*
>   - Graficación sistemática de funciones elementales
>   - Funciones trigonométricas, exponenciales, logarítmicas
> - **Lagrange (1797):** Uso de derivadas para analizar gráficas
> - **Revolución:** Gráficas como herramienta de análisis
> 
> **Formalización (1800-1900):**
> - **Cauchy (1821):** Continuidad visualizada gráficamente
> - **Weierstrass (1872):** Función continua sin derivada
>   - Demostró que intuición gráfica puede engañar
>   - Necesidad de rigor analítico
> - **Riemann (1854):** Integral como área bajo curva
> - **Peano (1890):** Curvas que llenan el plano
>   - Desafió nociones intuitivas de dimensión
> - **Desarrollo:** Gráficas más sofisticadas y "patológicas"
> 
> **Era Moderna (1900-1980):**
> - **Monge (1800s):** Geometría descriptiva
> - **Desarrollo de papel cuadriculado:** Estandarización
> - **Calculadoras gráficas (1985):** Texas Instruments TI-81
>   - Democratización de graficación precisa
>   - Cambió enseñanza del cálculo
> - **Software matemático (1988):** Mathematica
>   - Graficación computacional accesible
> 
> **Era Digital (1980-presente):**
> - **Desmos (2011):** Graficación interactiva en línea
> - **GeoGebra (2001):** Herramienta educativa dinámica
> - **Wolfram Alpha (2009):** Graficación instantánea con análisis
> - **Realidad virtual:** Visualización 3D inmersiva
> - **Impacto:** Énfasis en interpretación sobre cálculo manual

## 📐 Fundamentos de la Graficación

> [!success]- Sistema de Coordenadas Cartesianas
> 
> **Componentes básicos:**
> ```
> Plano cartesiano:
> - Eje horizontal: eje x (abscisas)
> - Eje vertical: eje y (ordenadas)
> - Origen: punto O = (0, 0)
> - Cuadrantes: I, II, III, IV (sentido antihorario)
> ```
> 
> **Representación de puntos:**
> ```
> Punto P = (x₀, y₀)
> - Primera coordenada: x₀ (desplazamiento horizontal)
> - Segunda coordenada: y₀ (desplazamiento vertical)
> 
> Cuadrante I:   x > 0, y > 0
> Cuadrante II:  x < 0, y > 0
> Cuadrante III: x < 0, y < 0
> Cuadrante IV:  x > 0, y < 0
> ```
> 
> **Gráfica de una función:**
> ```
> Graf(f) = {(x, f(x)) : x ∈ Dom(f)}
> 
> Conjunto de todos los puntos (x, y) donde y = f(x)
> 
> Interpretación:
> - Cada x en el dominio genera un punto
> - La colección de puntos forma la curva
> - La curva visualiza el comportamiento de f
> ```
> 
> **Escalas:**
> ```
> Escalas iguales: Misma unidad en ambos ejes
> Útil para: círculos, proporciones geométricas
> 
> Escalas diferentes: Unidades distintas
> Útil para: rangos muy diferentes, zoom selectivo
> 
> Escala logarítmica: Para rangos exponenciales
> Útil para: crecimiento exponencial, datos científicos
> ```

## 🔍 Método Sistemático de Graficación

> [!tip]- Proceso de 8 Pasos
> 
> **Paso 1: Determinar el dominio**
> ```
> Identificar valores de x para los cuales f(x) existe
> 
> Restricciones comunes:
> - Denominadores ≠ 0
> - Radicandos pares ≥ 0
> - Logaritmos > 0
> - Dominios trigonométricos
> 
> Resultado: Saber dónde graficar
> ```
> 
> **Paso 2: Encontrar interceptos**
> ```
> Intercepto en y: f(0) si 0 ∈ Dom(f)
> Punto: (0, f(0))
> 
> Interceptos en x: Resolver f(x) = 0
> Puntos: (x₁, 0), (x₂, 0), ...
> 
> Importancia: Puntos donde curva cruza ejes
> ```
> 
> **Paso 3: Analizar simetría**
> ```
> Par: f(-x) = f(x) → Simétrica respecto al eje y
> Impar: f(-x) = -f(x) → Simétrica respecto al origen
> Ninguna: Sin simetría especial
> 
> Ventaja: Graficar solo mitad de la función
> ```
> 
> **Paso 4: Identificar asíntotas**
> ```
> Verticales: Donde denominador = 0 (funciones racionales)
> Horizontales: lim(x→±∞) f(x) = L
> Oblicuas: Si grado numerador = grado denominador + 1
> 
> Importancia: Comportamiento en extremos
> ```
> 
> **Paso 5: Calcular primera derivada**
> ```
> f'(x): Indica crecimiento y puntos críticos
> 
> f'(x) > 0: Función creciente
> f'(x) < 0: Función decreciente
> f'(x) = 0: Posibles extremos locales
> 
> Resultado: Intervalos de monotonía
> ```
> 
> **Paso 6: Calcular segunda derivada**
> ```
> f''(x): Indica concavidad y puntos de inflexión
> 
> f''(x) > 0: Cóncava hacia arriba (∪)
> f''(x) < 0: Cóncava hacia abajo (∩)
> f''(x) = 0: Posibles puntos de inflexión
> 
> Resultado: Curvatura de la gráfica
> ```
> 
> **Paso 7: Construir tabla de valores**
> ```
> Evaluar f(x) en puntos estratégicos:
> - Puntos críticos
> - Puntos de inflexión
> - Interceptos
> - Valores entre características clave
> 
> Resultado: Puntos para trazar la curva
> ```
> 
> **Paso 8: Trazar la gráfica**
> ```
> Combinar toda la información:
> 1. Marcar dominio en eje x
> 2. Dibujar asíntotas (líneas punteadas)
> 3. Ubicar interceptos
> 4. Marcar puntos de tabla
> 5. Conectar con curva suave
> 6. Respetar crecimiento, concavidad, simetría
> 
> Resultado: Gráfica completa y precisa
> ```

## 📊 Características Clave a Identificar

> [!important]- Elementos Esenciales de una Gráfica
> 
> **1. Dominio y rango visual:**
> ```
> Dominio: Extensión horizontal de la gráfica
> Se lee: Proyección sobre eje x
> 
> Rango: Extensión vertical de la gráfica
> Se lee: Proyección sobre eje y
> 
> Ejemplo: f(x) = √(4 - x²)
> Dominio visual: [-2, 2]
> Rango visual: [0, 2]
> ```
> 
> **2. Interceptos:**
> ```
> Intercepto en y: Donde la curva cruza el eje y
> Se encuentra: Evaluar f(0)
> Máximo: 1 intercepto en y (por definición de función)
> 
> Interceptos en x: Donde la curva cruza el eje x
> Se encuentran: Resolver f(x) = 0
> Cantidad: Depende de la función (0, 1, 2, ...)
> 
> Importancia: Puntos de referencia obvios
> ```
> 
> **3. Extremos locales:**
> ```
> Máximo local: Pico de la función
> En x = c: f(c) ≥ f(x) para x cerca de c
> Indicador: f'(c) = 0 y f''(c) < 0
> 
> Mínimo local: Valle de la función
> En x = c: f(c) ≤ f(x) para x cerca de c
> Indicador: f'(c) = 0 y f''(c) > 0
> 
> Extremos globales: Máximo/mínimo absoluto en todo el dominio
> ```
> 
> **4. Puntos de inflexión:**
> ```
> Definición: Donde cambia la concavidad
> 
> Indicador: f''(x) cambia de signo
> 
> Visual: La curva pasa de ∪ a ∩ (o viceversa)
> 
> Importancia: Cambio en la tasa de crecimiento
> 
> Ejemplo: f(x) = x³ tiene punto de inflexión en (0,0)
> ```
> 
> **5. Continuidad y discontinuidades:**
> ```
> Función continua: Se puede trazar sin levantar el lápiz
> 
> Discontinuidad removible: "Hueco" en la gráfica
> Ejemplo: f(x) = (x²-1)/(x-1) en x = 1
> 
> Discontinuidad de salto: "Salto" vertical
> Ejemplo: Función escalón
> 
> Discontinuidad infinita: Asíntota vertical
> Ejemplo: f(x) = 1/x en x = 0
> ```
> 
> **6. Comportamiento asintótico:**
> ```
> Asíntota vertical en x = a:
> lim(x→a⁺) f(x) = ±∞ o lim(x→a⁻) f(x) = ±∞
> Visual: Curva tiende a infinito verticalmente
> 
> Asíntota horizontal en y = L:
> lim(x→±∞) f(x) = L
> Visual: Curva se aproxima a línea horizontal
> 
> Asíntota oblicua y = mx + b:
> lim(x→±∞) [f(x) - (mx + b)] = 0
> Visual: Curva se aproxima a línea inclinada
> ```

## 🎯 Técnicas Específicas por Tipo de Función

> [!example]- Funciones Polinomiales
> 
> **Características generales:**
> ```
> f(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + ... + a₁x + a₀
> 
> Propiedades:
> - Dominio: ℝ (siempre)
> - Continuas en todo ℝ
> - Suaves (diferenciables infinitamente)
> - Sin asíntotas verticales
> - Comportamiento en ±∞ determinado por término dominante
> ```
> 
> **Grado 0 (Constante):**
> ```
> f(x) = c
> 
> Gráfica: Línea horizontal en y = c
> 
> Características:
> - Sin pendiente
> - Un solo valor en rango: {c}
> - Intercepto en y: (0, c)
> - Intercepto en x: ninguno (si c ≠ 0)
> ```
> 
> **Grado 1 (Lineal):**
> ```
> f(x) = mx + b
> 
> Gráfica: Línea recta
> 
> Técnica rápida:
> 1. Intercepto en y: (0, b)
> 2. Pendiente m: Por cada unidad en x, subir m unidades en y
> 3. Dos puntos determinan la recta
> 
> m > 0: Creciente
> m < 0: Decreciente
> m = 0: Horizontal (constante)
> ```
> 
> **Grado 2 (Cuadrática):**
> ```
> f(x) = ax² + bx + c
> 
> Gráfica: Parábola
> 
> Forma estándar: f(x) = a(x - h)² + k
> Vértice: V = (h, k)
> 
> Técnica de graficación:
> 4. Completar el cuadrado para encontrar vértice
>    h = -b/(2a), k = f(h)
> 
> 5. Determinar orientación:
>    a > 0: ∪ (abre hacia arriba, vértice es mínimo)
>    a < 0: ∩ (abre hacia abajo, vértice es máximo)
> 
> 6. Encontrar interceptos:
>    En y: (0, c)
>    En x: Resolver ax² + bx + c = 0
>    
>    Discriminante Δ = b² - 4ac:
>    Δ > 0: Dos interceptos en x
>    Δ = 0: Un intercepto en x (toca el eje)
>    Δ < 0: Sin interceptos en x
> 
> 7. Simetría: Eje de simetría x = h
> 
> 8. Puntos adicionales: Evaluar en x = h ± 1, h ± 2
> 
> Ejemplo: f(x) = x² - 4x + 3
> = (x - 2)² - 1
> Vértice: (2, -1)
> Abre hacia arriba
> Interceptos en x: x = 1, x = 3
> Intercepto en y: (0, 3)
> ```
> 
> **Grado 3 (Cúbica):**
> ```
> f(x) = ax³ + bx² + cx + d
> 
> Comportamiento general:
> - Siempre tiene punto de inflexión
> - Puede tener 0, 1, 2 o 3 interceptos en x
> - Puede tener 0 o 2 extremos locales
> 
> Comportamiento en infinito:
> a > 0: f(x) → -∞ cuando x → -∞, f(x) → +∞ cuando x → +∞
> a < 0: f(x) → +∞ cuando x → -∞, f(x) → -∞ cuando x → +∞
> 
> Técnica:
> 1. Encontrar f'(x) = 3ax² + 2bx + c
> 2. Puntos críticos: Resolver f'(x) = 0
> 3. Evaluar f''(x) para clasificar extremos
> 4. Punto de inflexión: Resolver f''(x) = 0
> 5. Tabla de valores en puntos clave
> 
> Ejemplo: f(x) = x³ - 3x² + 2
> f'(x) = 3x² - 6x = 3x(x - 2)
> Puntos críticos: x = 0, x = 2
> f''(x) = 6x - 6
> f''(0) = -6 < 0 → Máximo local en (0, 2)
> f''(2) = 6 > 0 → Mínimo local en (2, -2)
> Punto de inflexión: x = 1, f(1) = 0
> ```
> 
> **Grado n ≥ 4:**
> ```
> Principio general:
> - Hasta n interceptos en x
> - Hasta n-1 extremos locales
> - Hasta n-2 puntos de inflexión
> 
> Grado par:
> - Comportamiento similar en ±∞
> - Puede tener mínimo o máximo global
> 
> Grado impar:
> - Comportamiento opuesto en ±∞
> - Rango = ℝ
> 
> Técnica:
> 1. Factorizar si es posible: f(x) = a(x - r₁)ᵐ¹(x - r₂)ᵐ² ...
> 2. Multiplicidad de raíces:
>    - Impar: Curva cruza el eje
>    - Par: Curva toca el eje y rebota
> 3. Usar cálculo para extremos e inflexiones
> 4. Comportamiento en ±∞ del término dominante
> ```

> [!example]- Funciones Racionales
> 
> **Forma general:**
> ```
> f(x) = P(x)/Q(x)
> 
> donde P(x) y Q(x) son polinomios
> ```
> 
> **Pasos de graficación:**
> 
> **1. Dominio:**
> ```
> Dom(f) = {x ∈ ℝ : Q(x) ≠ 0}
> 
> Encontrar ceros del denominador: Q(x) = 0
> Estos valores quedan excluidos del dominio
> ```
> 
> **2. Simplificación:**
> ```
> Factorizar P(x) y Q(x)
> Cancelar factores comunes
> 
> Factor cancelado (x - a): Discontinuidad removible en x = a
> ("Hueco" en la gráfica)
> ```
> 
> **3. Asíntotas verticales:**
> ```
> En x = a donde Q(a) = 0 pero P(a) ≠ 0
> (Después de simplificar)
> 
> Comportamiento cerca de asíntota:
> lim(x→a⁺) f(x) = ±∞
> lim(x→a⁻) f(x) = ±∞
> 
> Determinar signos evaluando cerca de a
> ```
> 
> **4. Asíntotas horizontales:**
> ```
> Comparar grados de P(x) y Q(x):
> 
> Caso 1: grado(P) < grado(Q)
> → Asíntota horizontal: y = 0
> 
> Caso 2: grado(P) = grado(Q)
> → Asíntota horizontal: y = (coef. dominante P)/(coef. dominante Q)
> 
> Caso 3: grado(P) > grado(Q)
> → Sin asíntota horizontal
>   Si grado(P) = grado(Q) + 1: Asíntota oblicua
> ```
> 
> **5. Asíntotas oblicuas:**
> ```
> Si grado(P) = grado(Q) + 1
> 
> División larga: P(x) = Q(x)·(mx + b) + R(x)
> donde grado(R) < grado(Q)
> 
> Asíntota oblicua: y = mx + b
> 
> f(x) se aproxima a mx + b cuando x → ±∞
> ```
> 
> **6. Interceptos:**
> ```
> Intercepto en y: f(0) si 0 ∈ Dom(f)
> 
> Interceptos en x: Resolver P(x) = 0
> Verificar que Q(x) ≠ 0 en esas raíces
> ```
> 
> **7. Análisis de signo:**
> ```
> Tabla de signos para determinar dónde f(x) > 0 o f(x) < 0
> 
> Puntos críticos para la tabla:
> - Ceros del numerador (interceptos en x)
> - Ceros del denominador (asíntotas verticales)
> ```
> 
> **Ejemplo completo:**
> ```
> f(x) = (x² - 1)/(x² - 4)
> 
> 1. Dominio:
>    x² - 4 = 0 → x = ±2
>    Dom(f) = ℝ \ {-2, 2}
> 
> 2. Simplificación:
>    = (x-1)(x+1)/[(x-2)(x+2)]
>    No hay factores comunes
> 
> 3. Asíntotas verticales:
>    x = -2 y x = 2
>    
>    Cerca de x = 2:
>    x → 2⁺: numerador → 3 > 0, denominador → 0⁺
>    f(x) → +∞
>    
>    x → 2⁻: numerador → 3 > 0, denominador → 0⁻
>    f(x) → -∞
>    
>    Similar análisis para x = -2
> 
> 4. Asíntota horizontal:
>    grado(numerador) = grado(denominador) = 2
>    y = 1/1 = 1
> 
> 5. Interceptos:
>    En y: f(0) = -1/-4 = 1/4, punto (0, 1/4)
>    En x: x² - 1 = 0 → x = ±1
>    Puntos: (-1, 0) y (1, 0)
> 
> 6. Tabla de signos:
>    Intervalos: (-∞,-2), (-2,-1), (-1,1), (1,2), (2,∞)
>    
>    En (-∞,-2): f(-3) = 8/5 > 0
>    En (-2,-1): f(-1.5) = -1.25/0.75 < 0
>    En (-1,1): f(0) = 1/4 > 0
>    En (1,2): f(1.5) = -1.25/0.75 < 0
>    En (2,∞): f(3) = 8/5 > 0
> 
> 7. Gráfica:
>    - Marcar asíntotas verticales (líneas punteadas)
>    - Marcar asíntota horizontal y = 1
>    - Ubicar interceptos
>    - Trazar curva respetando signos y asíntotas
> ```

> [!example]- Funciones Radicales
> 
> **Raíz cuadrada básica:**
> ```
> f(x) = √x
> 
> Características:
> - Dom(f) = [0, +∞)
> - Ran(f) = [0, +∞)
> - Creciente en todo su dominio
> - Cóncava hacia abajo
> - Punto inicial: (0, 0)
> - No tiene asíntotas
> 
> Puntos clave: (0,0), (1,1), (4,2), (9,3)
> ```
> 
> **Raíz cuadrada transformada:**
> ```
> f(x) = a√(x - h) + k
> 
> Técnica:
> 1. Identificar transformaciones:
>    - h: Traslación horizontal
>    - k: Traslación vertical
>    - a: Estiramiento vertical
>    - a < 0: Reflexión sobre eje x
> 
> 2. Dominio: x - h ≥ 0 → x ≥ h
>    Dom(f) = [h, +∞)
> 
> 3. Punto inicial: (h, k)
> 
> 4. Rango:
>    Si a > 0: [k, +∞)
>    Si a < 0: (-∞, k]
> 
> 5. Puntos adicionales: Evaluar en h+1, h+4, h+9
> 
> Ejemplo: f(x) = 2√(x - 1) + 3
> Dom(f) = [1, +∞)
> Punto inicial: (1, 3)
> Puntos: (2, 5), (5, 7), (10, 9)
> ```
> 
> **Raíz cuadrada con expresión compleja:**
> ```
> f(x) = √(g(x))
> 
> Pasos:
> 6. Dominio: Resolver g(x) ≥ 0
> 
> 7. Interceptos:
>    En y: √(g(0)) si 0 ∈ Dom(f)
>    En x: Resolver g(x) = 0
> 
> 8. Comportamiento:
>    f(x) = 0 donde g(x) = 0
>    f(x) crece/decrece según g(x)
> 
> Ejemplo: f(x) = √(4 - x²)
> Dominio: 4 - x² ≥ 0 → x² ≤ 4 → -2 ≤ x ≤ 2
> Dom(f) = [-2, 2]
> 
> Interceptos:
> En y: f(0) = 2
> En x: 4 - x² = 0 → x = ±2
> 
> Puntos adicionales: f(±1) = √3 ≈ 1.73
> 
> Gráfica: Semicírculo superior de radio 2
> ```
> 
> **Raíz cúbica:**
> ```
> f(x) = ³√x
> 
> Características:
> - Dom(f) = ℝ (puede ser negativa)
> - Ran(f) = ℝ
> - Creciente en todo ℝ
> - Punto de inflexión en origen
> - Sin asíntotas
> - Función impar: f(-x) = -f(x)
> 
> Puntos clave: (-8,-2), (-1,-1), (0,0), (1,1), (8,2)
> ```

> [!example]- Funciones Exponenciales
> 
> **Forma básica:**
> ```
> f(x) = aˣ, a > 0, a ≠ 1
> 
> Dos casos fundamentales:
> 
> Caso 1: a > 1 (crecimiento exponencial)
> - Creciente en todo ℝ
> - lim(x→-∞) aˣ = 0
> - lim(x→+∞) aˣ = +∞
> - Asíntota horizontal: y = 0 (eje x)
> - Pasa por (0, 1)
> - Cóncava hacia arriba
> 
> Caso 2: 0 < a < 1 (decaimiento exponencial)
> - Decreciente en todo ℝ
> - lim(x→-∞) aˣ = +∞
> - lim(x→+∞) aˣ = 0
> - Asíntota horizontal: y = 0 (eje x)
> - Pasa por (0, 1)
> - Cóncava hacia arriba
> ```
> 
> **Función exponencial natural:**
> ```
> f(x) = eˣ donde e ≈ 2.71828...
> 
> Propiedades especiales:
> - f'(x) = eˣ (su derivada es ella misma)
> - Tasa de crecimiento = valor de la función
> - Base natural del cálculo
> 
> Puntos clave: (-1, 1/e), (0, 1), (1, e), (2, e²)
> ```
> 
> **Forma transformada:**
> ```
> f(x) = Aeᵏˣ + B
> 
> Parámetros:
> - A: Factor de escala vertical
> - k: Tasa de crecimiento (k > 0) o decaimiento (k < 0)
> - B: Traslación vertical (nueva asíntota)
> 
>
> 
> Técnica de graficación:
> 1. Asíntota horizontal: y = B
> 
> 2. Intercepto en y: f(0) = A + B
> 
> 3. Comportamiento:
>    Si k > 0 y A > 0:
>      - Creciente
>      - Se aproxima a B desde abajo cuando x → -∞
>      - Crece a +∞ cuando x → +∞
>    
>    Si k < 0 y A > 0:
>      - Decreciente
>      - Crece a +∞ cuando x → -∞
>      - Se aproxima a B desde arriba cuando x → +∞
> 
> 4. Reflexiones:
>    Si A < 0: Refleja verticalmente
> 
> Ejemplo: f(x) = 2e⁻ˣ + 1
> Asíntota: y = 1
> Intercepto en y: (0, 3)
> Decreciente (k = -1 < 0)
> Puntos: (1, 1+2/e), (2, 1+2/e²)
> ```
> 
> **Aplicaciones:**
> ```
> Crecimiento poblacional: P(t) = P₀eᵏᵗ
> Decaimiento radiactivo: N(t) = N₀e⁻ᵏᵗ
> Interés compuesto continuo: A(t) = P₀eʳᵗ
> Enfriamiento de Newton: T(t) = Tₐₘb + (T₀ - Tₐₘb)e⁻ᵏᵗ
> ```

> [!example]- Funciones Logarítmicas
> 
> **Forma básica:**
> ```
> f(x) = logₐ(x), a > 0, a ≠ 1
> 
> Propiedades fundamentales:
> - Dom(f) = (0, +∞)
> - Ran(f) = ℝ
> - Asíntota vertical: x = 0 (eje y)
> - Pasa por (1, 0)
> - Inversa de f(x) = aˣ
> 
> Dos casos:
> 
> Caso 1: a > 1
> - Creciente en (0, +∞)
> - lim(x→0⁺) logₐ(x) = -∞
> - lim(x→+∞) logₐ(x) = +∞
> - Cóncava hacia abajo
> 
> Caso 2: 0 < a < 1
> - Decreciente en (0, +∞)
> - lim(x→0⁺) logₐ(x) = +∞
> - lim(x→+∞) logₐ(x) = -∞
> - Cóncava hacia arriba
> ```
> 
> **Logaritmo natural:**
> ```
> f(x) = ln(x) = logₑ(x)
> 
> Propiedades especiales:
> - f'(x) = 1/x
> - ∫(1/x)dx = ln|x| + C
> - Inversa de eˣ
> 
> Puntos clave: (1/e, -1), (1, 0), (e, 1), (e², 2)
> ```
> 
> **Forma transformada:**
> ```
> f(x) = A·ln(x - h) + k
> 
> Técnica:
> 1. Asíntota vertical: x = h
> 
> 2. Dominio: x - h > 0 → x > h
>    Dom(f) = (h, +∞)
> 
> 3. Intercepto en x: Resolver A·ln(x - h) + k = 0
>    ln(x - h) = -k/A
>    x - h = e⁻ᵏ/ᴬ
>    x = h + e⁻ᵏ/ᴬ
> 
> 4. Puntos clave: Evaluar en x = h+1, h+e, h+e²
> 
> Ejemplo: f(x) = 2ln(x - 1) + 3
> Asíntota vertical: x = 1
> Dom(f) = (1, +∞)
> Intercepto en x: x = 1 + e⁻³/²
> Puntos: (2, 3), (1+e, 5), (1+e², 7)
> ```
> 
> **Logaritmo con argumento complejo:**
> ```
> f(x) = ln(g(x))
> 
> Pasos:
> 1. Dominio: Resolver g(x) > 0
> 
> 2. Asíntotas verticales: Donde g(x) = 0⁺
> 
> 3. Comportamiento:
>    - f(x) → -∞ cuando g(x) → 0⁺
>    - f(x) → +∞ cuando g(x) → +∞
> 
> Ejemplo: f(x) = ln(x² - 4)
> Dominio: x² - 4 > 0
>          (x-2)(x+2) > 0
>          x < -2 o x > 2
> Dom(f) = (-∞, -2) ∪ (2, +∞)
> 
> Asíntotas verticales: x = -2 y x = 2
> 
> En x → 2⁺: f(x) → -∞
> En x → 2⁻: no definida
> En x → -2⁺: no definida
> En x → -2⁻: f(x) → -∞
> 
> Interceptos en x: x² - 4 = 1 → x = ±√5
> ```

> [!example]- Funciones Trigonométricas
> 
> **Seno y coseno básicos:**
> ```
> f(x) = sin(x)
> g(x) = cos(x)
> 
> Características comunes:
> - Dom = ℝ
> - Ran = [-1, 1]
> - Periódicas con período 2π
> - Continuas y suaves
> - Sin asíntotas
> 
> sin(x):
> - Impar: sin(-x) = -sin(x)
> - Ceros: x = nπ, n ∈ ℤ
> - Máximos: x = π/2 + 2nπ, valor = 1
> - Mínimos: x = -π/2 + 2nπ, valor = -1
> - Puntos de inflexión: x = nπ
> 
> cos(x):
> - Par: cos(-x) = cos(x)
> - Ceros: x = π/2 + nπ, n ∈ ℤ
> - Máximos: x = 2nπ, valor = 1
> - Mínimos: x = π + 2nπ, valor = -1
> - Puntos de inflexión: x = π/2 + nπ
> ```
> 
> **Forma general sinusoidal:**
> ```
> f(x) = A·sin(B(x - C)) + D
> o
> f(x) = A·cos(B(x - C)) + D
> 
> Parámetros:
> - |A|: Amplitud (altura máxima desde línea media)
> - Período: T = 2π/|B|
> - C: Desplazamiento de fase (horizontal)
> - D: Desplazamiento vertical (línea media)
> 
> Técnica de graficación:
> 
> 1. Línea media: y = D
> 
> 2. Amplitud: Oscila entre D - |A| y D + |A|
>    Rango: [D - |A|, D + |A|]
> 
> 3. Período: T = 2π/|B|
>    La función completa un ciclo cada T unidades
> 
> 4. Desplazamiento de fase: C
>    Si B > 0: Desplazar C unidades a la derecha
>    Si B < 0: Desplazar C unidades a la izquierda y reflejar
> 
> 5. Puntos clave en un período (para seno):
>    Inicio del período: x = C
>    Primer máximo: x = C + T/4
>    Cruce por línea media: x = C + T/2
>    Mínimo: x = C + 3T/4
>    Fin del período: x = C + T
> 
> Ejemplo: f(x) = 3sin(2(x - π/4)) + 1
> 
> Amplitud: A = 3
> Período: T = 2π/2 = π
> Desplazamiento de fase: C = π/4
> Línea media: y = 1
> Rango: [1 - 3, 1 + 3] = [-2, 4]
> 
> Puntos clave:
> x = π/4: f = 1 (inicio)
> x = π/4 + π/4 = π/2: f = 4 (máximo)
> x = π/4 + π/2 = 3π/4: f = 1 (línea media)
> x = π/4 + 3π/4 = π: f = -2 (mínimo)
> x = π/4 + π = 5π/4: f = 1 (fin)
> ```
> 
> **Tangente:**
> ```
> f(x) = tan(x)
> 
> Características:
> - Dom(f) = ℝ \ {π/2 + nπ : n ∈ ℤ}
> - Ran(f) = ℝ
> - Período: π (no 2π)
> - Asíntotas verticales: x = π/2 + nπ
> - Función impar: tan(-x) = -tan(x)
> - Ceros: x = nπ, n ∈ ℤ
> - Creciente en cada intervalo de su dominio
> - Puntos de inflexión: x = nπ
> 
> Forma general: f(x) = A·tan(B(x - C)) + D
> - Período: T = π/|B|
> - Asíntotas verticales: x = C + (π/2 + nπ)/B
> ```
> 
> **Secante y cosecante:**
> ```
> sec(x) = 1/cos(x)
> csc(x) = 1/sin(x)
> 
> Características:
> - Asíntotas verticales donde la función base es cero
> - Rango: (-∞, -1] ∪ [1, +∞)
> - Forma de "U" o "∩" entre asíntotas
> 
> Técnica de graficación:
> 1. Graficar la función base (sin o cos)
> 2. Marcar asíntotas donde la base es cero
> 3. Donde la base tiene máximo/mínimo (±1),
>    la recíproca también (±1)
> 4. Curvas se alejan de línea y = 0
> ```

> [!example]- Funciones Trigonométricas Inversas
> 
> **Arcoseno:**
> ```
> f(x) = arcsin(x) = sin⁻¹(x)
> 
> Propiedades:
> - Dom(f) = [-1, 1]
> - Ran(f) = [-π/2, π/2]
> - Creciente en todo su dominio
> - Puntos clave: (-1, -π/2), (0, 0), (1, π/2)
> - Punto de inflexión: (0, 0)
> - Asíntotas verticales: Ninguna (pero derivada → ∞ en x = ±1)
> ```
> 
> **Arcocoseno:**
> ```
> f(x) = arccos(x) = cos⁻¹(x)
> 
> Propiedades:
> - Dom(f) = [-1, 1]
> - Ran(f) = [0, π]
> - Decreciente en todo su dominio
> - Puntos clave: (-1, π), (0, π/2), (1, 0)
> - Relación: arccos(x) = π/2 - arcsin(x)
> ```
> 
> **Arcotangente:**
> ```

> - Creciente en todo ℝ

> [!example]- Funciones Definidas por Partes
> 
> **Técnica general:**
> ```
> f(x) = { f₁(x)  si x ∈ D₁
>        { f₂(x)  si x ∈ D₂
>        { f₃(x)  si x ∈ D₃
>        { ...
> 
> Pasos de graficación:
> 
> 1. Identificar intervalos: D₁, D₂, D₃, ...
> 
> 2. Graficar cada pieza por separado:
>    - En D₁: Graficar f₁(x)
>    - En D₂: Graficar f₂(x)
>    - En D₃: Graficar f₃(x)
> 
> 3. Atención en fronteras:
>    - Puntos incluidos: Círculo lleno (•)
>    - Puntos excluidos: Círculo vacío (○)
> 
> 4. Verificar continuidad:
>    - En x = a: ¿lim(x→a⁻) f(x) = lim(x→a⁺) f(x) = f(a)?
> 
> 5. Analizar cada pieza independientemente:
>    - Dominio, rango, crecimiento, concavidad
> ```
> 
> **Valor absoluto:**
> ```
> f(x) = |x| = { x   si x ≥ 0
>              { -x  si x < 0
> 
> Características:
> - Forma de "V"
> - Vértice en (0, 0)
> - Pendiente = 1 para x > 0
> - Pendiente = -1 para x < 0
> - No diferenciable en x = 0 (esquina aguda)
> 
> Forma general: f(x) = a|x - h| + k
> - Vértice: (h, k)
> - "V" hacia arriba si a > 0
> - "V" hacia abajo si a < 0
> - Factor de estiramiento: |a|
> ```
> 
> **Función escalón unitario (Heaviside):**
> ```
> H(x) = { 0  si x < 0
>        { 1  si x ≥ 0
> 
> Gráfica: Salto discontinuo en x = 0
> 
> Aplicaciones: Modelar encendido/apagado, switches
> ```
> 
> **Función piso (floor):**
> ```
> f(x) = ⌊x⌋ = mayor entero ≤ x
> 
> Ejemplos:
> ⌊2.7⌋ = 2
> ⌊-1.3⌋ = -2
> ⌊5⌋ = 5
> 
> Gráfica: Escalera con saltos en cada entero
> - Discontinuidad de salto en cada n ∈ ℤ
> - Constante en [n, n+1)
> ```
> 
> **Función techo (ceiling):**
> ```
> f(x) = ⌈x⌉ = menor entero ≥ x
> 
> Ejemplos:
> ⌈2.7⌉ = 3
> ⌈-1.3⌉ = -1
> ⌈5⌉ = 5
> 
> Gráfica: Similar a piso pero desplazada
> ```
> 
> **Ejemplo complejo:**
> ```
> f(x) = { x²        si x < -1
>        { 2x + 1    si -1 ≤ x < 2
>        { √(x - 2)  si x ≥ 2
> 
> Análisis:
> 
> Pieza 1: x² en (-∞, -1)
> - Parábola hacia arriba
> - En x → -1⁻: f(x) → 1
> - Punto no incluido: (-1, 1) con círculo vacío
> 
> Pieza 2: 2x + 1 en [-1, 2)
> - Línea recta, pendiente 2
> - Punto inicial: (-1, -1) con círculo lleno
> - En x → 2⁻: f(x) → 5
> - Punto no incluido: (2, 5) con círculo vacío
> 
> Pieza 3: √(x - 2) en [2, +∞)
> - Raíz cuadrada trasladada
> - Punto inicial: (2, 0) con círculo lleno
> 
> Continuidad:
> En x = -1: lim(x→-1⁻) = 1 ≠ f(-1) = -1
>           Discontinuidad de salto
> 
> En x = 2: lim(x→2⁻) = 5 ≠ f(2) = 0
>          Discontinuidad de salto
> 
> Dominio total: ℝ
> Rango: [0, +∞) ∪ [-1, 5)
> ```

## 🔄 Técnicas de Transformaciones

> [!tip]- Modificaciones Sistemáticas de Gráficas
> 
> **Traslaciones verticales:**
> ```
> g(x) = f(x) + k
> 
> Efecto: Desplazar toda la gráfica k unidades verticalmente
> - k > 0: Hacia arriba
> - k < 0: Hacia abajo
> 
> Cambios:
> - Forma: No cambia
> - Dominio: No cambia
> - Rango: Desplazado k unidades
> - Intercepto en y: f(0) + k
> - Asíntotas horizontales: Desplazadas k unidades
> 
> Ejemplo: Si f(x) = x², entonces g(x) = x² + 3
> Parábola desplazada 3 unidades arriba
> Vértice: (0, 0) → (0, 3)
> ```
> 
> **Traslaciones horizontales:**
> ```
> g(x) = f(x - h)
> 
> Efecto: Desplazar toda la gráfica h unidades horizontalmente
> - h > 0: Hacia la derecha
> - h < 0: Hacia la izquierda
> 
> ⚠️ CUIDADO: El signo es opuesto a la intuición
> f(x - 2) desplaza 2 unidades a la DERECHA
> f(x + 2) desplaza 2 unidades a la IZQUIERDA
> 
> Cambios:
> - Forma: No cambia
> - Dominio: Desplazado h unidades
> - Rango: No cambia
> - Interceptos en x: Desplazados h unidades
> - Asíntotas verticales: Desplazadas h unidades
> 
> Ejemplo: Si f(x) = √x, entonces g(x) = √(x - 4)
> Raíz cuadrada desplazada 4 unidades a la derecha
> Dominio: [0, +∞) → [4, +∞)
> Punto inicial: (0, 0) → (4, 0)
> ```
> 
> **Reflexiones:**
> ```
> Reflexión sobre eje x: g(x) = -f(x)
> Efecto: Voltear verticalmente (espejo horizontal)
> - Puntos positivos se vuelven negativos
> - Puntos negativos se vuelven positivos
> - Rango: [a, b] → [-b, -a]
> 
> Reflexión sobre eje y: g(x) = f(-x)
> Efecto: Voltear horizontalmente (espejo vertical)
> - Lado derecho pasa a izquierdo y viceversa
> - Dominio: [a, b] → [-b, -a]
> - Convierte función creciente en decreciente
> 
> Ejemplo: f(x) = eˣ
> - g(x) = -eˣ: Exponencial volteada hacia abajo
>   Asíntota: y = 0, pero curva debajo del eje
> 
> - h(x) = e⁻ˣ: Exponencial decreciente
>   Equivale a reflejar eˣ sobre eje y
> ```
> 
> **Estiramientos y compresiones verticales:**
> ```
> g(x) = a·f(x), a > 0
> 
> Efecto: Escalar verticalmente por factor a
> 
> Si a > 1: Estiramiento vertical
> - Gráfica se "estira" alejándose del eje x
> - Amplitud multiplicada por a
> - Pendientes multiplicadas por a
> 
> Si 0 < a < 1: Compresión vertical
> - Gráfica se "aplasta" hacia el eje x
> - Amplitud dividida entre 1/a
> - Pendientes divididas entre 1/a
> 
> Cambios:
> - Dominio: No cambia
> - Rango: Multiplicado por a
> - Interceptos en x: No cambian (f(x)=0 → a·f(x)=0)
> - Intercepto en y: Multiplicado por a
> 
> Ejemplo: f(x) = sin(x), amplitud = 1
> g(x) = 3sin(x), amplitud = 3
> h(x) = 0.5sin(x), amplitud = 0.5
> ```
> 
> **Estiramientos y compresiones horizontales:**
> ```
> g(x) = f(bx), b > 0
> 
> Efecto: Escalar horizontalmente por factor 1/b
> 
> ⚠️ CUIDADO: El efecto es recíproco al número
> 
> Si b > 1: Compresión horizontal (factor 1/b)
> - Gráfica se "encoge" hacia el eje y
> - Período dividido entre b
> - Función "más rápida"
> 
> Si 0 < b < 1: Estiramiento horizontal (factor 1/b)
> - Gráfica se "estira" alejándose del eje y
> - Período multiplicado por 1/b
> - Función "más lenta"
> 
> Cambios:
> - Dominio: Dividido entre b
> - Rango: No cambia
> - Período (funciones periódicas): Dividido entre b
> 
> Ejemplo: f(x) = sin(x), período = 2π
> g(x) = sin(2x), período = π (compresión)
> h(x) = sin(x/2), período = 4π (estiramiento)
> ```
> 
> **Transformación compuesta:**
> ```
> g(x) = a·f(b(x - h)) + k
> 
> Orden de aplicación (desde dentro hacia fuera):
> 
> 1. Traslación horizontal: x → x - h
>    Desplazar h unidades horizontalmente
> 
> 2. Estiramiento/compresión horizontal: x → bx
>    Escalar por factor 1/b
> 
> 3. Estiramiento/compresión vertical: f → a·f
>    Escalar por factor a
> 
> 4. Traslación vertical: f → f + k
>    Desplazar k unidades verticalmente
> 
> Reflexiones:
> - Si a < 0: Aplicar reflexión sobre eje x después del paso 3
> - Si b < 0: Aplicar reflexión sobre eje y después del paso 2
> 
> Ejemplo completo:
> f(x) = x²
> g(x) = -2(x - 3)² + 5
> 
> Pasos:
> 1. Desplazar 3 unidades a la derecha
> 2. Estirar verticalmente por factor 2
> 3. Reflejar sobre eje x
> 4. Desplazar 5 unidades arriba
> 
> Vértice: (0, 0) → (3, 5)
> Abre hacia abajo
> ```

## 📈 Análisis con Cálculo

> [!important]- Uso de Derivadas para Graficación Precisa
> 
> **Primera derivada - Monotonía:**
> ```
> f'(x) determina crecimiento/decrecimiento
> 
> Interpretación:
> f'(x) > 0 en intervalo I → f creciente en I
> f'(x) < 0 en intervalo I → f decreciente en I
> f'(x) = 0 en x = c → Punto crítico (posible extremo)
> 
> Procedimiento:
> 1. Calcular f'(x)
> 2. Encontrar puntos críticos: Resolver f'(x) = 0
> 3. Encontrar donde f'(x) no existe
> 4. Tabla de signos de f'(x)
> 5. Clasificar intervalos: creciente/decreciente
> 
> Ejemplo: f(x) = x³ - 3x² + 2
> 
> f'(x) = 3x² - 6x = 3x(x - 2)
> 
> Puntos críticos: x = 0, x = 2
> 
> Tabla de signos:
>       x < 0    0 < x < 2    x > 2
> 3x     (-)       (+)         (+)
> x-2    (-)       (-)         (+)
> f'(x)  (+)       (-)         (+)
> f(x)    ↗         ↘           ↗
> 
> Conclusión:
> - Creciente en (-∞, 0) ∪ (2, +∞)
> - Decreciente en (0, 2)
> ```
> 
> **Criterio de la primera derivada - Extremos:**
> ```
> Sea c un punto crítico (f'(c) = 0 o no existe)
> 
> Máximo local en x = c:
> - f'(x) cambia de (+) a (-) en c
> - f' > 0 antes de c, f' < 0 después de c
> - La función sube luego baja
> 
> Mínimo local en x = c:
> - f'(x) cambia de (-) a (+) en c
> - f' < 0 antes de c, f' > 0 después de c
> - La función baja luego sube
> 
> No es extremo:
> - f'(x) no cambia de signo en c
> - Puede ser punto de inflexión con tangente horizontal
> 
> Ejemplo (continuación):
> En x = 0: f' cambia de (+) a (-)
> → Máximo local en (0, 2)
> 
> En x = 2: f' cambia de (-) a (+)
> → Mínimo local en (2, -2)
> ```
> 
> **Segunda derivada - Concavidad:**
> ```
> f''(x) determina curvatura
> 
> Interpretación:
> f''(x) > 0 en intervalo I → Cóncava hacia arriba (∪) en I
> f''(x) < 0 en intervalo I → Cóncava hacia abajo (∩) en I
> f''(x) = 0 en x = c → Posible punto de inflexión
> 
> Procedimiento:
> 1. Calcular f''(x)
> 2. Resolver f''(x) = 0
> 3. Encontrar donde f''(x) no existe
> 4. Tabla de signos de f''(x)
> 5. Clasificar concavidad
> 
> Ejemplo (continuación):
> f''(x) = 6x - 6 = 6(x - 1)
> 
> f''(x) = 0: x = 1
> 
> Tabla:
>       x < 1    x > 1
> f''(x)  (-)      (+)
> Conc.   ∩        ∪
> 
> Conclusión:
> - Cóncava hacia abajo en (-∞, 1)
> - Cóncava hacia arriba en (1, +∞)
> - Punto de inflexión en x = 1
> ```
> 
>
> 
> **Puntos de inflexión:**
> ```
> Definición: Donde cambia la concavidad
> 
> Candidatos: Donde f''(x) = 0 o no existe
> 
> Verificación: f''(x) debe cambiar de signo
> 
> No todo f''(x) = 0 es punto de inflexión
> Contraejemplo: f(x) = x⁴
> f''(x) = 12x², f''(0) = 0
> Pero f''(x) ≥ 0 para todo x (no cambia signo)
> x = 0 NO es punto de inflexión
> 
> Ejemplo (continuación):
> En x = 1: f''(x) cambia de (-) a (+)
> → Punto de inflexión en (1, 0)
> f(1) = 1³ - 3(1)² + 2 = 0
> ```
> 
> **Criterio de la segunda derivada - Extremos:**
> ```
> Sea c un punto crítico con f'(c) = 0
> 
> Si f''(c) > 0:
> → Mínimo local en x = c
> (cóncava hacia arriba en el punto crítico)
> 
> Si f''(c) < 0:
> → Máximo local en x = c
> (cóncava hacia abajo en el punto crítico)
> 
> Si f''(c) = 0:
> → El criterio no es concluyente
> (usar criterio de la primera derivada)
> 
> Ejemplo (continuación):
> f'(0) = 0, f''(0) = -6 < 0 → Máximo local
> f'(2) = 0, f''(2) = 6 > 0 → Mínimo local
> ```
> 
> **Síntesis para graficación:**
> ```
> Algoritmo completo con cálculo:
> 
> 1. Dominio y restricciones
> 2. Interceptos
> 3. Simetría
> 4. Asíntotas
> 5. f'(x): Intervalos de crecimiento/decrecimiento
> 6. f'(x) = 0: Extremos locales
> 7. f''(x): Intervalos de concavidad
> 8. f''(x) = 0: Puntos de inflexión
> 9. Tabla de valores en puntos clave
> 10. Trazar con toda la información
> 
> Resultado: Gráfica precisa y completa
> ```

## 🎨 Técnicas Rápidas de Bocetaje

> [!tip]- Métodos para Graficación Aproximada
> 
> **Análisis cualitativo sin cálculo:**
> ```
> Para bocetos rápidos:
> 
> 1. Identificar tipo de función
>    - Polinomial: grado y coeficiente principal
>    - Racional: asíntotas obvias
>    - Trigonométrica: período y amplitud
>    - Exponencial/logarítmica: comportamiento básico
> 
> 2. Puntos fáciles de calcular
>    - f(0), f(1), f(-1)
>    - Interceptos sencillos
>    - Valores en múltiplos de π (trig)
> 
> 3. Comportamiento en extremos
>    - x → ±∞
>    - Cerca de asíntotas
> 
> 4. Conectar con curva suave
>    - Respetar tipo de función
>    - Sin cambios bruscos (si es suave)
> ```
> 
> **Técnica de los "cinco puntos" (periódicas):**
> ```
> Para funciones sinusoidales:
> 
> f(x) = A·sin(B(x - C)) + D
> 
> Marcar 5 puntos en un período:
> 1. Inicio: (C, D)
> 2. Primer máximo: (C + T/4, D + A)
> 3. Punto medio: (C + T/2, D)
> 4. Mínimo: (C + 3T/4, D - A)
> 5. Final: (C + T, D)
> 
> Conectar con onda suave
> Repetir el patrón
> ```
> 
> **Método de "puntos y pendientes":**
> ```
> Para funciones diferenciables:
> 
> 6. Marcar puntos conocidos
> 7. Estimar pendiente en cada punto
>    - Positiva: /
>    - Negativa: \
>    - Cero: —
>    - Infinita: |
> 
> 8. Conectar con curvas que respeten pendientes
> 
> Ejemplo: f(x) = x²
> Puntos: (-2,4), (-1,1), (0,0), (1,1), (2,4)
> Pendientes: \, \, —, /, /
> ```
> 
> **Uso de simetría para ahorrar trabajo:**
> ```
> Función par: Graficar solo x ≥ 0, reflejar
> Función impar: Graficar solo x ≥ 0, rotar 180°
> Periódica: Graficar un período, repetir
> ```

## 📊 Ejemplos Completos Paso a Paso

> [!example]- Graficación Detallada de Funciones
> 
> **Ejemplo 1: Función polinomial cúbica**
> ```
> f(x) = x³ - 6x² + 9x + 1
> 
> Paso 1: Dominio
> Dom(f) = ℝ (polinomio)
> 
> Paso 2: Interceptos
> En y: f(0) = 1, punto (0, 1)
> En x: x³ - 6x² + 9x + 1 = 0
> (difícil resolver, usar calculadora o métodos numéricos)
> Una raíz aproximada: x ≈ -0.11
> 
> Paso 3: Simetría
> f(-x) = -x³ - 6x² - 9x + 1 ≠ f(x) ≠ -f(x)
> Sin simetría
> 
> Paso 4: Asíntotas
> Ninguna (polinomio)
> Comportamiento en infinito:
> x → +∞: f(x) → +∞
> x → -∞: f(x) → -∞
> 
> Paso 5: Primera derivada
> f'(x) = 3x² - 12x + 9 = 3(x² - 4x + 3) = 3(x - 1)(x - 3)
> Puntos críticos: x = 1, x = 3
> 
> Tabla de signos:
>       x < 1    1 < x < 3    x > 3
> f'(x)   (+)       (-)         (+)
> f(x)     ↗         ↘           ↗
> 
> Paso 6: Clasificar extremos
> x = 1: f' cambia de (+) a (-)
> → Máximo local en (1, f(1)) = (1, 5)
> 
> x = 3: f' cambia de (-) a (+)
> → Mínimo local en (3, f(3)) = (3, 1)
> 
> Paso 7: Segunda derivada
> f''(x) = 6x - 12 = 6(x - 2)
> f''(x) = 0: x = 2
> 
> Tabla:
>       x < 2    x > 2
> f''(x)  (-)      (+)
> Conc.   ∩        ∪
> 
> Paso 8: Punto de inflexión
> x = 2: f''(x) cambia de signo
> → Punto de inflexión en (2, 3)
> 
> Paso 9: Tabla de valores
> x  | -1 | 0 | 1 | 2 | 3 | 4
> ---|-------|---|---|---|---|---
> f(x)| -15 | 1 | 5 | 3 | 1 | 5
> 
> Paso 10: Trazar
> - Marcar interceptos
> - Ubicar extremos y punto de inflexión
> - Trazar curva respetando:
>   * Creciente: (-∞,1) ∪ (3,∞)
>   * Decreciente: (1,3)
>   * Cóncava ∩: (-∞,2)
>   * Cóncava ∪: (2,∞)
> ```
> 
> **Ejemplo 2: Función racional compleja**
> ```
> f(x) = (x² - 4)/(x² - 1)
> 
> Paso 1: Dominio
> x² - 1 = 0 → x = ±1
> Dom(f) = ℝ \ {-1, 1}
> 
> Paso 2: Simplificación
> f(x) = (x-2)(x+2)/[(x-1)(x+1)]
> No hay factores comunes
> Sin discontinuidades removibles
> 
> Paso 3: Interceptos
> En y: f(0) = -4/-1 = 4, punto (0, 4)
> En x: x² - 4 = 0 → x = ±2
> Puntos: (-2, 0) y (2, 0)
> 
> Paso 4: Simetría
> f(-x) = ((-x)² - 4)/((-x)² - 1) = (x² - 4)/(x² - 1) = f(x)
> → Función PAR (simétrica respecto al eje y)
> Ventaja: Solo graficar x ≥ 0, luego reflejar
> 
> Paso 5: Asíntotas verticales
> x = 1 y x = -1
> 
> Análisis en x = 1:
> x → 1⁺: numerador → -3 < 0, denominador → 0⁺
> f(x) → -∞
> 
> x → 1⁻: numerador → -3 < 0, denominador → 0⁻
> f(x) → +∞
> 
> Por simetría, en x = -1: comportamiento reflejado
> 
> Paso 6: Asíntota horizontal
> grado(num) = grado(den) = 2
> y = 1/1 = 1
> 
> Paso 7: Primera derivada
> f'(x) = [(x²-1)(2x) - (x²-4)(2x)]/(x²-1)²
>       = [2x(x²-1 - x²+4)]/(x²-1)²
>       = [2x(3)]/(x²-1)²
>       = 6x/(x²-1)²
> 
> Puntos críticos: 6x = 0 → x = 0
> f'(x) no existe en x = ±1 (asíntotas)
> 
> Tabla de signos:
>      x < -1   -1 < x < 0   0 < x < 1   x > 1
> 6x     (-)       (-)         (+)        (+)
> (.)²   (+)       (+)         (+)        (+)
> f'(x)  (-)       (-)         (+)        (+)
> f(x)    ↘         ↘           ↗          ↗
> 
> Paso 8: Extremo
> x = 0: f' cambia de (-) a (+)
> → Mínimo local en (0, 4)
> 
> Paso 9: Segunda derivada (opcional para este ejemplo)
> 
> Paso 10: Tabla de valores (usando x ≥ 0)
> x  | 0 | 0.5 | 2 | 3 | 4
> ---|---|-----|---|---|---
> f(x)| 4 | 5  | 0 |1.25|1.5
> 
> Paso 11: Trazar
> - Marcar asíntotas verticales: x = ±1 (líneas punteadas)
> - Marcar asíntota horizontal: y = 1 (línea punteada)
> - Interceptos: (-2,0), (0,4), (2,0)
> - Mínimo: (0,4)
> - Para x > 0: Trazar curva
> - Reflejar sobre eje y por simetría
> ```
> 
> **Ejemplo 3: Función con raíz y cociente**
> ```
> f(x) = √(x)/(x - 1)
> 
> Paso 1: Dominio
> Restricciones:
> 1. x ≥ 0 (raíz cuadrada)
> 2. x - 1 ≠ 0 → x ≠ 1
> 
> Dom(f) = [0, 1) ∪ (1, +∞)
> 
> Paso 2: Interceptos
> En y: f(0) = 0/(-1) = 0, punto (0, 0)
> En x: √x = 0 → x = 0, punto (0, 0)
> 
> Paso 3: Simetría
> Dominio no simétrico → No hay simetría
> 
> Paso 4: Asíntota vertical
> x = 1:
> x → 1⁺: numerador → 1 > 0, denominador → 0⁺
> f(x) → +∞
> 
> x → 1⁻: numerador → 1 > 0, denominador → 0⁻
> f(x) → -∞
> 
> Paso 5: Asíntota horizontal
> lim(x→+∞) √x/(x-1) = lim(x→+∞) x^(1/2)/x = lim(x→+∞) 1/x^(1/2) = 0
> → Asíntota horizontal: y = 0
> 
> Paso 6: Primera derivada (regla del cociente)
> f'(x) = [(x-1)·(1/(2√x)) - √x·1]/(x-1)²
>       = [(x-1)/(2√x) - √x]/(x-1)²
>       = [(x-1 - 2x)/(2√x)]/(x-1)²
>       = [(-x-1)/(2√x)]/(x-1)²
>       = -(x+1)/[2√x(x-1)²]
> 
> Análisis:
> - Numerador: -(x+1) < 0 para x > 0
> - Denominador: 2√x(x-1)² > 0 para x > 0, x ≠ 1
> 
> → f'(x) < 0 en todo el dominio
> → f es decreciente en [0,1) y en (1,+∞)
> 
> Sin puntos críticos (f'(x) nunca es 0)
> 
> Paso 7: Tabla de valores
> x   | 0 | 0.25| 0.5 | 0.75| 2  | 4  | 9
> ----|---|-----|-----|-----|----|----|---
> f(x)| 0 |-0.67|-1  |-3.46|1.41|0.67|0.38
> 
> Paso 8: Trazar
> - Marcar dominio: [0,1) ∪ (1,+∞)
> - Asíntota vertical: x = 1
> - Asíntota horizontal: y = 0
> - Intercepto: (0, 0)
> - Curva decreciente en ambas ramas
> - En [0,1): Desde (0,0) baja a -∞
> - En (1,+∞): Desde +∞ baja hacia 0
> ```

## ⚠️ Errores Comunes en Graficación

> [!warning]- Errores Frecuentes y Cómo Evitarlos
> 
> **1. Confundir dominio con codominio:**
> ```
> ✗ INCORRECTO:
> f(x) = 1/x tiene dominio ℝ
> 
> ✓ CORRECTO:
> Dom(f) = ℝ \ {0}
> (x = 0 excluido por división por cero)
> ```
> 
> **2. Olvidar discontinuidades removibles:**
> ```
> ✗ INCORRECTO:
> f(x) = (x²-1)/(x-1) = x+1 para todo x
> 
> ✓ CORRECTO:
> f(x) = x+1 para x ≠ 1
> Hay "hueco" en x = 1
> Marcar con círculo vacío en (1, 2)
> ```
> 
> **3. Asíntotas oblicuas ignoradas:**
> ```
> f(x) = (x² + 1)/x
> 
> ✗ INCORRECTO:
> Solo identificar asíntota vertical en x = 0
> 
> ✓ CORRECTO:
> - Asíntota vertical: x = 0
> - Asíntota oblicua: y = x
>   (división: x² + 1 = x·x + 1)
> ```
> 
> **4. Ignorar multiplicidad de raíces:**
> ```
> f(x) = (x - 2)²(x + 1)
> 
> ✗ INCORRECTO:
> Curva cruza el eje en x = 2 y x = -1
> 
> ✓ CORRECTO:
> - En x = -1: cruza (multiplicidad impar = 1)
> - En x = 2: toca y rebota (multiplicidad par = 2)
> ```
> 
> **5. Escala inconsistente:**
> ```
> ✗ INCORRECTO:
> Usar escalas diferentes sin notarlo
> Círculo parece elipse
> 
> ✓ CORRECTO:
> - Para círculos: escalas iguales
> - Indicar si escalas son diferentes
> - Etiquetar ambos ejes claramente
> ```
> 
> **6. Conectar puntos discontinuos:**
> ```
> ✗ INCORRECTO:
> Función por partes con saltos
> Conectar todo con líneas
> 
> ✓ CORRECTO:
> - Marcar discontinuidades
> - Círculos llenos/vacíos
> - No conectar entre discontinuidades
> ```
> 
> **7. Periodicidad incorrecta:**
> ```
> f(x) = tan(x)
> 
> ✗ INCORRECTO:
> Período = 2π
> 
> ✓ CORRECTO:
> Período = π
> (la tangente repite cada π, no 2π)
> ```
> 
> **8. Derivada mal aplicada:**
> ```
> ✗ INCORRECTO:
> f'(x) = 0 en x = c
> → Siempre hay extremo en c
> 
> ✓ CORRECTO:
> f'(x) = 0 en x = c
> → c es punto crítico
> Verificar con f''(c) o cambio de signo de f'(x)
> Puede ser punto de inflexión con tangente horizontal
> ```

## 🎓 Aplicaciones y Contextos

> [!example]- Uso de Gráficas en Problemas Reales
> 
> **Física - Movimiento:**
> ```
> Posición vs tiempo: s(t)
> - Pendiente = velocidad
> - Concavidad = aceleración
> - Máximos/mínimos = puntos de retorno
> - Interceptos = cruces por origen
> 
> Ejemplo: s(t) = -5t² + 20t + 3
> Parábola hacia abajo
> Máximo en t = 2 (altura máxima)
> Interceptos en t: cuando objeto toca el suelo
> ```
> 
> **Economía - Análisis marginal:**
> ```
> Costo total: C(x)
> - C'(x) = costo marginal
> - Mínimo de C'(x) = producción eficiente
> 
> Ingreso: R(x)
> Ganancia: G(x) = R(x) - C(x)
> - Máximo de G(x) = producción óptima
> - G(x) = 0 = punto de equilibrio
> ```
> 
> **Biología - Poblaciones:**
> ```
> P(t) = población en tiempo t
> 
> Exponencial: P(t) = P₀e^(kt)
> - Crecimiento ilimitado
> - k > 0: crecimiento
> - k < 0: extinción
> 
> Logística: P(t) = K/(1 + Ae^(-rt))
> - Crecimiento limitado
> - Asíntota horizontal en K (capacidad de carga)
> - Punto de inflexión en K/2
> ```
> 
> **Ingeniería - Señales:**
> ```
> Funciones periódicas: ondas, vibraciones
> 
> Análisis de Fourier:
> f(t) = suma de senos y cosenos
> Gráfica muestra componentes de frecuencia
> 
> Aplicaciones:
> - Procesamiento de audio
> - Comunicaciones
> - Filtrado de señales
> ```

## 💡 Estrategias Avanzadas

> [!tip]- Técnicas para Funciones Complejas
> 
> **Descomposición de funciones:**
> ```
> Para f(x) compleja, identificar:
> f(x) = combinación de funciones básicas
> 
> Ejemplo: f(x) = e^(x²)sin(x) + ln(x+1)
> 
> Analizar cada componente:
> 1. g(x) = e^(x²): exponencial de parábola
> 2. h(x) = sin(x): oscilación
> 3. g(x)·h(x): exponencial modulada
> 4. k(x) = ln(x+1): crecimiento logarítmico
> 5. f(x) = g·h + k: suma de componentes
> 
> Graficar componentes separadas
> Combinar visualmente
> ```
> 
> **Análisis asintótico:**
> ```
> Para comportamiento en infinito:
> 
> Comparar tasas de crecimiento:
> ln(x) << x^a << e^x << x! << x^x
> 
> Ejemplo: f(x) = (e^x + x³)/(e^x + x²)
> 
> Para x → +∞:
> Numerador ≈ e^x (domina)
> Denominador ≈ e^x (domina)
> f(x) → e^x/e^x = 1
> 
> Asíntota horizontal: y = 1
> ```
> 
> **Graficación paramétrica:**
> ```
> Curvas dadas por:
> x = f(t)
> y = g(t)
> 
> Técnica:
> 6. Tabla de valores para t
> 7. Calcular (x,y) para cada t
> 8. Graficar puntos en plano xy
> 9. Conectar en orden de t creciente
> 10. Indicar dirección con flechas
> 
> Ejemplo: Círculo
> x = cos(t)
> y = sin(t)
> t ∈ [0, 2π]
> ```
> 
> **Gráficas en coordenadas polares:**
> ```
> r = f(θ)
> 
> Técnica:
> 11. Tabla de valores para θ
> 12. Para cada θ, calcular r
> 13. Marcar punto a distancia r en dirección θ
> 14. Conectar puntos
> 
> Ejemplo: Rosa de 4 pétalos
> r = sin(2θ)
> ```
